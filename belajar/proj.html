Proyek Portofolio: Proyek berstandar industri untuk melamar kerja

Standar proyek yang dicari perekrut, proyek full-stack langkah demi langkah (PostgreSQL, Django REST API, React), proyek mini dan proyek besar untuk setiap jalur karier, serta menyajikan portofolio, CV, dan wawancara.

5 modul · 49 pelajaran

Mulai belajar di aplikasi

Modul 1: Standar proyek yang dicari perekrut

Pemula

Apa yang dinilai perekrut dari sebuah proyek, struktur repo dan alur Git, README yang menjual, kualitas kode (lint, test, CI), serta deploy dan demo.

  1. Apa yang dinilai dari proyek portofolio
  2. Struktur repo, branch, dan commit
  3. README yang menjual proyekmu
  4. Kualitas kode: lint, test, dan CI
  5. Deploy, data demo, dan pemantauan dasar

Modul 2: Proyek full-stack: database → API → frontend

Menengah

Membangun KasirKu langkah demi langkah: memahami alur satu request, merancang tabel PostgreSQL, membuat REST API dengan Django REST Framework (validasi, auth JWT, transaksi stok), lalu frontend React + TypeScript dengan status loading/error, sampai testing, Docker Compose, CI, dan deploy.

  1. Peta besar: perjalanan satu request
  2. Kebutuhan, user story, dan kontrak API
  3. Merancang database PostgreSQL
  4. Menyiapkan backend Django REST Framework
  5. Model, migrasi, dan admin
  6. Serializer dan validasi
  7. ViewSet, router, pencarian, dan pagination
  8. Auth JWT dan izin per peran
  9. Transaksi: pesanan yang mengurangi stok dengan aman
  10. Frontend: proyek React dan klien API
  11. Halaman produk: loading, error, kosong, dan pagination
  12. Form dan mutasi: menampilkan error dari API
  13. Login, menyimpan token, dan rute terlindungi
  14. Testing tiga lapis: API, komponen, dan end-to-end
  15. Docker Compose: satu perintah untuk semuanya
  16. Rilis: deploy dan checklist akhir

Modul 3: Proyek mini per jalur karier

Menengah

Tiga proyek mini untuk setiap jalur karier (logika, Java, frontend, Django, mobile, data analyst, data scientist, data engineer, UI/UX, QA, DBA, analis SI), masing-masing dengan fitur wajib, tantangan, dan definisi selesai.

  1. Proyek mini: Logika & Python dasar
  2. Proyek mini: Backend Java
  3. Proyek mini: Frontend
  4. Proyek mini: Backend Python (Django)
  5. Proyek mini: Mobile (Flutter / Android)
  6. Proyek mini: Data Analyst & BI
  7. Proyek mini: Data Scientist
  8. Proyek mini: Data Engineer
  9. Proyek mini: UI/UX Designer
  10. Proyek mini: QA Engineer
  11. Proyek mini: Database Administrator
  12. Proyek mini: Analis Sistem Informasi

Modul 4: Proyek besar (capstone) per jalur karier

Lanjutan

Satu proyek besar 4 minggu untuk setiap jalur karier: masalah nyata, fitur wajib, stack, rencana mingguan, dan standar industri yang dinilai.

  1. Proyek besar: Aplikasi keuangan pribadi CLI
  2. Proyek besar: Sistem reservasi lapangan futsal
  3. Proyek besar: Toko online UMKM (storefront)
  4. Proyek besar: Platform kelas online kecil (LMS)
  5. Proyek besar: Aplikasi antrean klinik
  6. Proyek besar: Analisis churn dan retensi aplikasi langganan
  7. Proyek besar: Sistem prediksi churn sampai produksi
  8. Proyek besar: Pipeline data transportasi kota
  9. Proyek besar: Studi kasus aplikasi bank sampah
  10. Proyek besar: Suite pengujian untuk aplikasi toko demo
  11. Proyek besar: Operasional PostgreSQL untuk aplikasi kasir
  12. Proyek besar: Sistem informasi inventaris aset kampus

Modul 5: Menyajikan portofolio dan melamar kerja

Profesional

Merapikan profil GitHub dan LinkedIn, menulis proyek di CV yang lolos ATS, menceritakan proyek dengan metode STAR, serta menghadapi take-home test dan live coding.

  1. Profil GitHub dan LinkedIn yang meyakinkan
  2. Menulis proyek di CV (lolos ATS)
  3. Menceritakan proyek saat wawancara (STAR)
  4. Take-home test dan live coding
