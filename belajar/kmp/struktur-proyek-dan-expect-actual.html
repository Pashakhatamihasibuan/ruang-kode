Kotlin Multiplatform · Modul 1 · Konsep & kode

Struktur proyek dan expect/actual

Buka versi interaktif

Buat proyek dengan Kotlin Multiplatform Wizard di kmp.jetbrains.com, lalu buka di Android Studio atau IntelliJ IDEA. Folder shared berisi source set: commonMain (kode bersama), androidMain, dan iosMain (kode khusus platform).

Jika kode bersama butuh fitur platform (nama perangkat, UUID, penyimpanan aman), deklarasikan dengan expect di commonMain lalu isi dengan actual di setiap platform. Kompiler memastikan setiap platform punya implementasinya.

Membangun aplikasi iOS tetap membutuhkan Mac dengan Xcode. Di Windows atau Linux kamu tetap bisa mengembangkan dan menguji bagian Android, desktop, dan logika bersama.

Source set KMP
FolderIsi
commonMainKode bersama: model, repository, aturan bisnis
androidMainImplementasi khusus Android
iosMainImplementasi khusus iOS (memanggil API Apple)
commonTestTes yang dijalankan di semua platform
composeAppTampilan bersama jika memakai Compose Multiplatform
KODE
// shared/src/commonMain/kotlin/Platform.kt
expect fun namaPlatform(): String

class Sapaan {
    fun sapa(): String = "Halo dari ${namaPlatform()}!"
}

// shared/src/androidMain/kotlin/Platform.android.kt
actual fun namaPlatform(): String = "Android ${android.os.Build.VERSION.SDK_INT}"

// shared/src/iosMain/kotlin/Platform.ios.kt
import platform.UIKit.UIDevice
actual fun namaPlatform(): String =
    UIDevice.currentDevice.systemName() + " " + UIDevice.currentDevice.systemVersion

Soal latihan

  1. Buat expect fun idUnik(): String dengan implementasi Android (java.util.UUID) dan iOS (NSUUID).

    Petunjuk

    expect di commonMain, actual di androidMain dan iosMain.

    Lihat jawaban
    KODE
    // commonMain
expect fun idUnik(): String

// androidMain
actual fun idUnik(): String = java.util.UUID.randomUUID().toString()

// iosMain
import platform.Foundation.NSUUID
actual fun idUnik(): String = NSUUID().UUIDString()

  2. Tulis blok sourceSets Gradle yang menambahkan coroutines ke kode bersama dan Ktor engine yang berbeda per platform.

    Petunjuk

    commonMain.dependencies, androidMain.dependencies, iosMain.dependencies.

    Lihat jawaban
    KODE
    kotlin {
    sourceSets {
        commonMain.dependencies {
            implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.9.0")
            implementation("io.ktor:ktor-client-core:3.0.1")
        }
        androidMain.dependencies {
            implementation("io.ktor:ktor-client-okhttp:3.0.1")
        }
        iosMain.dependencies {
            implementation("io.ktor:ktor-client-darwin:3.0.1")
        }
    }
}

Poin penting

  • commonMain untuk kode bersama.
  • expect di common, actual di tiap platform.
  • iOS butuh Mac + Xcode untuk dibangun.
