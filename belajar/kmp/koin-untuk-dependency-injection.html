Koin untuk dependency injection

Buka versi interaktif

Koin adalah library dependency injection yang ringan dan berjalan di semua target KMP. Kamu mendeklarasikan module berisi cara membuat setiap objek, lalu Koin yang merangkai dan memberikannya.

single { } membuat satu objek untuk seluruh aplikasi (misalnya HttpClient), factory { } membuat objek baru setiap diminta, dan viewModel { } untuk ViewModel. get() mengambil dependensi yang sudah didaftarkan.

Di Compose Multiplatform, ambil objek dengan koinViewModel() atau koinInject(). Mulai Koin sekali saat aplikasi dibuka dengan startKoin { modules(...) } atau KoinApplication.

KODE
val modulData = module {
    single {
        HttpClient {
            install(ContentNegotiation) { json(Json { ignoreUnknownKeys = true }) }
        }
    }
    single { KursApi(get()) }
    single { KursRepository(get()) }
}

val modulUi = module {
    viewModel { KursViewModel(get()) }
}

@Composable
fun App() {
    KoinApplication(application = { modules(modulData, modulUi) }) {
        MaterialTheme {
            val vm = koinViewModel<KursViewModel>()
            LayarKurs(vm)
        }
    }
}

Soal latihan

  1. Daftarkan FormatRupiah sebagai factory dan Database sebagai single di module baru.

    Petunjuk

    factory { FormatRupiah() } dan single { buatDatabase() }.

    Lihat jawaban
    KODE
    val modulUtil = module {
    factory { FormatRupiah() }
    single { buatDatabase(get()) }
}

  2. Buat module khusus platform: Android memberi Context ke driver database, iOS tidak.

    Petunjuk

    expect val modulPlatform: Module, lalu actual di androidMain dan iosMain.

    Lihat jawaban
    KODE
    // commonMain
expect val modulPlatform: Module

// androidMain
actual val modulPlatform = module {
    single<SqlDriver> { AndroidSqliteDriver(AppDb.Schema, androidContext(), "app.db") }
}

// iosMain
actual val modulPlatform = module {
    single<SqlDriver> { NativeSqliteDriver(AppDb.Schema, "app.db") }
}

Poin penting

  • module { single, factory, viewModel }.
  • get() mengambil dependensi.
  • koinViewModel() di Compose.
