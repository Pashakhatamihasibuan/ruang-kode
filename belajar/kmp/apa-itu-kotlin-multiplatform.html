Apa itu Kotlin Multiplatform

Buka versi interaktif

Kotlin Multiplatform (KMP) memungkinkan satu kode Kotlin dipakai bersama di Android, iOS, desktop, web, dan server. Bedanya dengan Flutter: KMP fokus berbagi logika (jaringan, database, aturan bisnis), sementara tampilan boleh tetap native (Compose di Android, SwiftUI di iOS) atau ikut dibagi dengan Compose Multiplatform.

KMP dinyatakan stabil oleh JetBrains sejak November 2023, dan Google mendukungnya secara resmi untuk berbagi logika antara Android dan iOS. Compose Multiplatform untuk iOS dinyatakan stabil pada 2025.

KMP cocok untuk tim yang sudah punya aplikasi Android berbahasa Kotlin dan ingin membawa logikanya ke iOS tanpa menulis ulang dari nol.

Soal latihan

  1. Sebuah startup punya tim Android (Kotlin) yang kuat dan ingin merilis aplikasi iOS tanpa menulis ulang logika bisnisnya. Apa saja yang sebaiknya dibagi lewat KMP, dan apa yang tetap native?

    Petunjuk

    Pisahkan logika (bisa dibagi) dari tampilan (bisa dibagi dengan Compose Multiplatform atau tetap native).

    Lihat jawaban
    KODE
    // Dibagi di commonMain:
//  - model data dan validasi
//  - pemanggilan API (Ktor) dan parsing JSON
//  - database lokal (SQLDelight / Room KMP)
//  - aturan bisnis: diskon, pajak, status pesanan
//
// Tetap native atau Compose Multiplatform:
//  - UI: Compose di Android, SwiftUI di iOS
//    (atau Compose Multiplatform jika ingin satu UI)
//  - fitur khusus platform: notifikasi, pembayaran in-app

  2. Kapan memilih Flutter, dan kapan memilih KMP? Tulis dua alasan untuk masing-masing.

    Petunjuk

    Pertimbangkan bahasa tim, kebutuhan UI native, dan apakah aplikasi Android sudah ada.

    Lihat jawaban
    KODE
    // Pilih Flutter jika:
//  1. Tim baru dan ingin satu bahasa + satu UI untuk semua platform.
//  2. Butuh tampilan sama persis di Android, iOS, dan web dengan cepat.
//
// Pilih KMP jika:
//  1. Sudah punya aplikasi Android Kotlin dan ingin berbagi logikanya ke iOS.
//  2. Ingin UI tetap native (SwiftUI/Compose) atau memilih per layar.

Poin penting

  • KMP berbagi logika; UI bisa native atau Compose Multiplatform.
  • Stabil sejak 2023.
  • Bisa diadopsi bertahap.
