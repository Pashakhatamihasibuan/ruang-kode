Kotlin Multiplatform · Modul 3 · Konsep & kode

Menyiapkan proyek dengan KMP wizard

Buka versi interaktif

Cara termudah memulai: buka kmp.jetbrains.com (Kotlin Multiplatform Wizard), pilih target Android, iOS, dan opsional Desktop/Web, lalu pilih apakah UI iOS memakai Compose Multiplatform atau SwiftUI. Unduh proyeknya dan buka di Android Studio atau IntelliJ IDEA dengan plugin Kotlin Multiplatform.

Kebutuhan: JDK 17+, Android Studio, dan untuk iOS sebuah Mac dengan Xcode. Jalankan Android dari Android Studio seperti biasa; jalankan iOS dari konfigurasi iosApp atau buka iosApp/iosApp.xcodeproj di Xcode.

Struktur hasil wizard: composeApp/ (UI bersama dan titik masuk Android), shared/ (logika bersama, jika dipisah), dan iosApp/ (proyek Xcode). Versi library dicatat di gradle/libs.versions.toml.

Soal latihan

  1. Tulis perintah Gradle untuk menjalankan tes kode bersama hanya di JVM/Android, lalu membangun framework iOS.

    Petunjuk

    Nama task mengikuti target: testDebugUnitTest, linkDebugFrameworkIosSimulatorArm64.

    Lihat jawaban
    TERMINAL
    ./gradlew :shared:testDebugUnitTest
./gradlew :shared:linkDebugFrameworkIosSimulatorArm64

  2. Tambahkan kotlinx-datetime ke commonMain dan tampilkan tanggal hari ini.

    Petunjuk

    Clock.System.now() lalu toLocalDateTime(TimeZone.currentSystemDefault()).

    Lihat jawaban
    TERMINAL
    // build.gradle.kts
commonMain.dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-datetime:0.6.1")
}

// commonMain
fun hariIni(): String {
    val t = Clock.System.now().toLocalDateTime(TimeZone.currentSystemDefault())
    return "${t.dayOfMonth}/${t.monthNumber}/${t.year}"
}

Poin penting

  • Mulai dari KMP wizard.
  • iOS butuh Mac dan Xcode.
  • Catat versi di libs.versions.toml.
