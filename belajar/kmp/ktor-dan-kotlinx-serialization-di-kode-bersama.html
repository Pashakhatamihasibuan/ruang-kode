Ktor dan kotlinx.serialization di kode bersama

Buka versi interaktif

Library di commonMain harus mendukung multiplatform. Yang paling umum: Ktor Client (HTTP), kotlinx.serialization (JSON), kotlinx.coroutines, kotlinx-datetime (tanggal), SQLDelight atau Room versi KMP (database), dan Koin (dependency injection).

Ktor memakai engine berbeda di setiap platform (OkHttp di Android, Darwin di iOS), tetapi kode pemanggilnya sama. Model data ditandai @Serializable agar JSON otomatis diubah menjadi objek.

Satu repository yang ditulis sekali di commonMain dipakai oleh layar Android maupun iOS.

KODE
@Serializable
data class Produk(val id: Int, val nama: String, val harga: Int)

class ProdukRepository(private val client: HttpClient) {
    suspend fun semua(): List<Produk> =
        client.get("https://api.contoh.id/produk").body()
}

fun buatClient() = HttpClient {
    install(ContentNegotiation) {
        json(Json { ignoreUnknownKeys = true })
    }
}

Soal latihan

  1. Tambahkan fungsi POST yang mengirim pesanan baru berformat JSON dengan Ktor.

    Petunjuk

    client.post(url) { contentType(ContentType.Application.Json); setBody(objek) }.

    Lihat jawaban
    KODE
    @Serializable
data class PesananBaru(val produkId: Int, val qty: Int)

suspend fun kirim(client: HttpClient, p: PesananBaru): Boolean {
    val res = client.post("https://api.contoh.id/pesanan") {
        contentType(ContentType.Application.Json)
        setBody(p)
    }
    return res.status == HttpStatusCode.Created
}

  2. Pasang plugin Logging dan batas waktu 10 detik pada HttpClient.

    Petunjuk

    install(Logging) dan install(HttpTimeout) { requestTimeoutMillis = 10_000 }.

    Lihat jawaban
    KODE
    val client = HttpClient {
    install(ContentNegotiation) { json(Json { ignoreUnknownKeys = true }) }
    install(Logging) { level = LogLevel.INFO }
    install(HttpTimeout) { requestTimeoutMillis = 10_000 }
}

Poin penting

  • Pakai library yang mendukung multiplatform.
  • Ktor: engine per platform, kode sama.
  • @Serializable untuk JSON.
