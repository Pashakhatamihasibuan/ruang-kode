Compose Multiplatform: satu tampilan untuk semua

Buka versi interaktif

Compose Multiplatform dari JetBrains membawa Jetpack Compose ke iOS, desktop, dan web. Composable yang sama (Column, Text, Button, Material 3) dipakai di semua platform.

Di iOS, tampilan Compose dibungkus ComposeUIViewController sehingga bisa dicampur dengan SwiftUI. Jadi kamu bisa memilih: semua layar memakai Compose, atau hanya sebagian.

Gambar dan string disimpan di folder composeResources dan dipanggil dengan painterResource(Res.drawable.logo) serta stringResource(Res.string.judul).

KODE
// composeApp/src/commonMain/kotlin/App.kt
@Composable
fun App() {
    MaterialTheme {
        var tampil by remember { mutableStateOf(false) }
        Column(
            Modifier.fillMaxSize().padding(24.dp),
            horizontalAlignment = Alignment.CenterHorizontally,
        ) {
            Button(onClick = { tampil = !tampil }) {
                Text(if (tampil) "Sembunyikan" else "Sapa")
            }
            AnimatedVisibility(tampil) {
                Text(Sapaan().sapa())
            }
        }
    }
}

// composeApp/src/iosMain/kotlin/MainViewController.kt
fun MainViewController() = ComposeUIViewController { App() }

Soal latihan

  1. Tampilkan logo dari resource bersama di Compose Multiplatform.

    Petunjuk

    Simpan gambar di composeResources/drawable, lalu painterResource(Res.drawable.logo).

    Lihat jawaban
    KODE
    // composeApp/src/commonMain/composeResources/drawable/logo.png
Image(
    painter = painterResource(Res.drawable.logo),
    contentDescription = "Logo RuangKode",
    modifier = Modifier.size(96.dp),
)

  2. Tampilkan teks berbeda untuk Android dan iOS dari Composable bersama.

    Petunjuk

    expect val namaPlatform: String, lalu pakai di Text.

    Lihat jawaban
    KODE
    // commonMain
expect val namaPlatform: String

@Composable
fun Sapa() { Text("Halo dari $namaPlatform") }

// androidMain
actual val namaPlatform: String = "Android ${android.os.Build.VERSION.SDK_INT}"

// iosMain
actual val namaPlatform: String = UIDevice.currentDevice.systemName()

Poin penting

  • Composable yang sama di Android, iOS, desktop, web.
  • ComposeUIViewController untuk iOS.
  • composeResources untuk gambar dan string.
