Proyek: aplikasi kurs mata uang

Buka versi interaktif

Proyek akhir: aplikasi kurs mata uang yang berjalan di Android dan iOS dengan satu kode. Data diambil dari API memakai Ktor, disimpan dengan SQLDelight agar tetap tampil saat offline, dirangkai dengan Koin, dan ditampilkan dengan Compose Multiplatform.

Alur datanya: UI meminta ViewModel, ViewModel membaca Flow dari repository, repository menyegarkan data dari API lalu menyimpannya ke database. UI selalu membaca dari database, sehingga data terakhir tetap tampil tanpa internet.

Kerjakan tantangan di bawah untuk melengkapinya.

KODE
class KursViewModel(private val repo: KursRepository) : ViewModel() {
    val daftar = repo.semua.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())
    var pesan by mutableStateOf<String?>(null)
        private set

    init { segarkan() }

    fun segarkan() = viewModelScope.launch {
        pesan = try {
            repo.segarkan()
            null
        } catch (e: Exception) {
            "Gagal memperbarui. Menampilkan data terakhir."
        }
    }
}

@Composable
fun LayarKurs(vm: KursViewModel) {
    val daftar by vm.daftar.collectAsState()
    Column(Modifier.fillMaxSize().padding(16.dp)) {
        Row(verticalAlignment = Alignment.CenterVertically) {
            Text("Kurs ke Rupiah", style = MaterialTheme.typography.headlineSmall, modifier = Modifier.weight(1f))
            IconButton(onClick = { vm.segarkan() }) { Icon(Icons.Default.Refresh, "Segarkan") }
        }
        vm.pesan?.let { Text(it, color = MaterialTheme.colorScheme.error) }
        LazyColumn {
            items(daftar, key = { it.kode }) { k ->
                ListItem(
                    headlineContent = { Text(k.kode) },
                    trailingContent = { Text("Rp${k.nilai.toLong()}") },
                )
            }
        }
    }
}

Soal latihan

  1. Tambahkan kolom input jumlah dan tampilkan hasil konversi ke Rupiah untuk setiap mata uang.

    Petunjuk

    Simpan jumlah sebagai teks, ubah dengan toDoubleOrNull(), kalikan dengan k.nilai.

    Lihat jawaban
    KODE
    var jumlah by remember { mutableStateOf("1") }
OutlinedTextField(
    value = jumlah,
    onValueChange = { jumlah = it },
    label = { Text("Jumlah") },
    keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Decimal),
)
val n = jumlah.toDoubleOrNull() ?: 0.0
// di item
trailingContent = { Text("Rp${(k.nilai * n).toLong()}") }

  2. Tulis tes bersama (commonTest) untuk fungsi konversi.

    Petunjuk

    kotlin.test: @Test dan assertEquals; berjalan di semua target dengan ./gradlew allTests.

    Lihat jawaban
    KODE
    // commonMain
fun keRupiah(jumlah: Double, kurs: Double): Long = (jumlah * kurs).toLong()

// commonTest
class KonversiTest {
    @Test
    fun duaDolar() {
        assertEquals(31600L, keRupiah(2.0, 15800.0))
    }
}

  3. Tampilkan waktu pembaruan terakhir memakai kotlinx-datetime.

    Petunjuk

    Instant.fromEpochMilliseconds(...).toLocalDateTime(...).

    Lihat jawaban
    KODE
    fun teksWaktu(ms: Long): String {
    val t = Instant.fromEpochMilliseconds(ms).toLocalDateTime(TimeZone.currentSystemDefault())
    val jam = t.hour.toString().padStart(2, '0')
    val menit = t.minute.toString().padStart(2, '0')
    return "Diperbarui $jam:$menit"
}

Poin penting

  • UI membaca dari database; API hanya menyegarkan.
  • Ktor + SQLDelight + Koin + Compose MP.
  • Tes di commonTest berjalan di semua platform.
