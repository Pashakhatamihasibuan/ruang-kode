Database bersama: SQLDelight dan Room KMP

Buka versi interaktif

SQLDelight membalik cara kerja ORM: kamu menulis SQL di file .sq, lalu SQLDelight membuat fungsi Kotlin bertipe aman dari SQL itu. Cocok untuk tim yang nyaman dengan SQL, dan sudah matang di KMP.

Sejak versi 2.7, Room juga mendukung KMP (Android, iOS, desktop). Jika tim sudah memakai Room di Android, kode Entity dan DAO bisa dipindah ke commonMain.

Kedua pilihan butuh driver berbeda per platform (Android memakai Context, iOS memakai driver native), jadi pembuatan driver diletakkan di androidMain dan iosMain.

SQL
-- shared/src/commonMain/sqldelight/id/ruangkode/Kurs.sq
CREATE TABLE kurs (
  kode TEXT NOT NULL PRIMARY KEY,
  nilai REAL NOT NULL,
  diperbarui INTEGER NOT NULL
);

semua:
SELECT * FROM kurs ORDER BY kode;

simpan:
INSERT OR REPLACE INTO kurs(kode, nilai, diperbarui) VALUES (?, ?, ?);

Soal latihan

  1. Tambahkan query SQLDelight untuk mencari kurs berdasarkan kode dan menghapus kurs lama.

    Petunjuk

    Beri nama query diikuti titik dua; parameter memakai ? atau :nama.

    Lihat jawaban
    SQL
    cariKode:
SELECT * FROM kurs WHERE kode = ?;

hapusLama:
DELETE FROM kurs WHERE diperbarui < :batas;

  2. Simpan kurs dari API ke database dan baca kembali sebagai Flow di repository.

    Petunjuk

    Panggil queries.simpan untuk setiap item, lalu semua().asFlow().mapToList().

    Lihat jawaban
    SQL
    class KursRepository(private val api: KursApi, db: AppDb) {
    private val q = db.kursQueries

    val semua: Flow<List<Kurs>> = q.semua().asFlow().mapToList(Dispatchers.IO)

    suspend fun segarkan() {
        val waktu = Clock.System.now().toEpochMilliseconds()
        api.ambil().forEach { (kode, nilai) -> q.simpan(kode, nilai, waktu) }
    }
}

Poin penting

  • SQLDelight: SQL dulu, Kotlin dibuat otomatis.
  • Room juga mendukung KMP.
  • Driver dibuat per platform.
