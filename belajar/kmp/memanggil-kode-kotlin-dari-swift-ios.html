Kotlin Multiplatform · Modul 3 · Konsep & kode

Memanggil kode Kotlin dari Swift (iOS)

Buka versi interaktif

Kode bersama dikompilasi menjadi framework iOS (misalnya Shared.framework) yang bisa di-import di Swift. Class Kotlin muncul sebagai class Swift biasa.

Beberapa hal butuh perhatian: suspend fun muncul sebagai fungsi dengan completion handler atau async di Swift, dan Flow tidak langsung bisa dipakai. Library SKIE (dari Touchlab) membuat suspend menjadi async dan Flow menjadi AsyncSequence sehingga terasa alami di Swift.

Jika UI iOS memakai SwiftUI, buat ViewModel bersama di Kotlin lalu amati state-nya dari Swift. Jika memakai Compose Multiplatform, Swift hanya memanggil MainViewControllerKt.MainViewController().

KODE
// Kotlin, commonMain
class Sapaan {
    fun halo(nama: String) = "Halo, $nama!"
    suspend fun ambilKurs(): Double { delay(300); return 15800.0 }
}

// Swift, iosApp (dengan SKIE)
import SwiftUI
import Shared

struct IsiView: View {
    @State private var kurs = "Memuat..."
    var body: some View {
        VStack(spacing: 12) {
            Text(Sapaan().halo(nama: "Rina"))
            Text(kurs)
        }
        .task {
            let n = try? await Sapaan().ambilKurs()
            kurs = "USD = Rp\(Int(n?.doubleValue ?? 0))"
        }
    }
}

Soal latihan

  1. Tampilkan UI Compose Multiplatform di aplikasi iOS dari Swift.

    Petunjuk

    Buat fungsi MainViewController() di iosMain, lalu bungkus dengan UIViewControllerRepresentable.

    Lihat jawaban
    KODE
    // iosMain
fun MainViewController() = ComposeUIViewController { App() }

// Swift
struct ComposeView: UIViewControllerRepresentable {
    func makeUIViewController(context: Context) -> UIViewController {
        MainViewControllerKt.MainViewController()
    }
    func updateUIViewController(_ vc: UIViewController, context: Context) {}
}

struct ContentView: View {
    var body: some View { ComposeView().ignoresSafeArea() }
}

  2. Tambahkan plugin SKIE ke modul shared.

    Petunjuk

    Tambahkan id("co.touchlab.skie") di blok plugins.

    Lihat jawaban
    KODE
    plugins {
    kotlin("multiplatform")
    id("co.touchlab.skie") version "0.9.3"
}

Poin penting

  • Kode bersama menjadi framework iOS.
  • SKIE: suspend → async, Flow → AsyncSequence.
  • Compose MP di iOS lewat ComposeUIViewController.
