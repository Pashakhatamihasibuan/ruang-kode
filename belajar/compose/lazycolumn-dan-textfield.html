LazyColumn dan TextField

Buka versi interaktif

LazyColumn menampilkan daftar panjang secara efisien. Isi dengan items(daftar, key = { it.id }) { ... }. Memberi key membantu Compose menjaga posisi dan animasi saat isi daftar berubah.

OutlinedTextField menerima value dan onValueChange: kamu yang menyimpan teksnya di state. Atur keyboardOptions untuk angka, email, atau telepon, dan tampilkan error dengan isError + supportingText.

Contoh di bawah menggabungkan keduanya: kotak pencarian yang menyaring daftar produk secara langsung.

KODE
data class Produk(val id: Int, val nama: String)

@Composable
fun CariProduk(semua: List<Produk>) {
    var kata by remember { mutableStateOf("") }
    val hasil = semua.filter { it.nama.contains(kata, ignoreCase = true) }

    Column(Modifier.padding(16.dp)) {
        OutlinedTextField(
            value = kata,
            onValueChange = { kata = it },
            label = { Text("Cari produk") },
            singleLine = true,
            modifier = Modifier.fillMaxWidth(),
        )
        Text("${hasil.size} hasil", Modifier.padding(vertical = 8.dp))
        LazyColumn(verticalArrangement = Arrangement.spacedBy(8.dp)) {
            items(hasil, key = { it.id }) { p ->
                ListItem(headlineContent = { Text(p.nama) })
            }
        }
    }
}

Soal latihan

  1. Ubah daftar produk menjadi grid yang kolomnya menyesuaikan lebar layar (minimal 160 dp per kartu).

    Petunjuk

    LazyVerticalGrid(columns = GridCells.Adaptive(160.dp)).

    Lihat jawaban
    KODE
    LazyVerticalGrid(
    columns = GridCells.Adaptive(minSize = 160.dp),
    contentPadding = PaddingValues(12.dp),
    horizontalArrangement = Arrangement.spacedBy(12.dp),
    verticalArrangement = Arrangement.spacedBy(12.dp),
) {
    items(produk, key = { it.id }) { p -> KartuProduk(p) }
}

  2. Buat TextField email yang menampilkan pesan error jika tidak mengandung "@".

    Petunjuk

    isError dan supportingText pada OutlinedTextField.

    Lihat jawaban
    KODE
    var email by rememberSaveable { mutableStateOf("") }
val salah = email.isNotEmpty() && "@" !in email
OutlinedTextField(
    value = email,
    onValueChange = { email = it },
    label = { Text("Email") },
    isError = salah,
    supportingText = { if (salah) Text("Format email belum benar, contoh: nama@mail.com") },
    keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Email),
    singleLine = true,
)

Poin penting

  • LazyColumn + items + key.
  • TextField: value + onValueChange.
  • Saring daftar langsung dari state.
