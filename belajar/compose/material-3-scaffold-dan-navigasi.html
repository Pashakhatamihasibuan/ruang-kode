Material 3, Scaffold, dan navigasi

Buka versi interaktif

Scaffold menyediakan kerangka layar: topBar, bottomBar, floatingActionButton, dan snackbarHost. Komponen Material 3 (TopAppBar, NavigationBar, Card, FilledButton) mengikuti tema yang mendukung dynamic color di Android 12 ke atas.

Navigation Compose mengatur perpindahan layar. Buat NavController dengan rememberNavController(), daftarkan layar di NavHost, lalu pindah dengan navController.navigate("detail/12"). Versi terbaru juga mendukung rute bertipe aman memakai kotlinx.serialization.

Ikuti pedoman Material: satu aksi utama per layar, area sentuh minimal 48 dp, dan kontras teks yang cukup.

KODE
@Composable
fun AplikasiToko() {
    val nav = rememberNavController()
    NavHost(navController = nav, startDestination = "beranda") {
        composable("beranda") {
            BerandaScreen(onBuka = { id -> nav.navigate("detail/$id") })
        }
        composable("detail/{id}") { entry ->
            val id = entry.arguments?.getString("id") ?: return@composable
            DetailScreen(id = id, onKembali = { nav.popBackStack() })
        }
    }
}

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun BerandaScreen(onBuka: (String) -> Unit) {
    Scaffold(
        topBar = { TopAppBar(title = { Text("Toko Kopi") }) },
    ) { padding ->
        LazyColumn(contentPadding = padding) {
            items(listOf("12", "15")) { id ->
                ListItem(
                    headlineContent = { Text("Produk $id") },
                    modifier = Modifier.clickable { onBuka(id) },
                )
            }
        }
    }
}

Soal latihan

  1. Tambahkan FloatingActionButton yang memunculkan Snackbar "Produk ditambahkan".

    Petunjuk

    SnackbarHostState + rememberCoroutineScope, karena showSnackbar adalah suspend function.

    Lihat jawaban
    KODE
    val snackbar = remember { SnackbarHostState() }
val scope = rememberCoroutineScope()
Scaffold(
    snackbarHost = { SnackbarHost(snackbar) },
    floatingActionButton = {
        FloatingActionButton(onClick = {
            scope.launch { snackbar.showSnackbar("Produk ditambahkan") }
        }) { Icon(Icons.Default.Add, contentDescription = "Tambah") }
    },
) { padding -> Konten(Modifier.padding(padding)) }

  2. Buat rute detail yang menerima id produk bertipe Int dengan Navigation Compose.

    Petunjuk

    Rute "detail/{id}" dan navArgument("id") { type = NavType.IntType }.

    Lihat jawaban
    KODE
    NavHost(nav, startDestination = "daftar") {
    composable("daftar") {
        Daftar(onPilih = { id -> nav.navigate("detail/$id") })
    }
    composable(
        "detail/{id}",
        arguments = listOf(navArgument("id") { type = NavType.IntType }),
    ) { entry ->
        Detail(id = entry.arguments?.getInt("id") ?: 0, onKembali = { nav.popBackStack() })
    }
}

Poin penting

  • Scaffold: topBar, bottomBar, FAB, snackbar.
  • NavHost + composable + navigate.
  • Material 3 dengan dynamic color.

Cek pemahaman

Fungsi untuk kembali ke layar sebelumnya?

Jawaban: nav.popBackStack()

popBackStack mengeluarkan layar teratas.

Kenapa showSnackbar butuh coroutine scope?

Jawaban: Karena suspend function

Snackbar menunggu sampai ditutup.
