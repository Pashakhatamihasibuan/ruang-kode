Side effect: LaunchedEffect dan rememberCoroutineScope

Buka versi interaktif

Fungsi Composable bisa dipanggil berkali-kali (recomposition), jadi kode yang punya efek di luar UI, seperti memanggil API atau menampilkan Snackbar, tidak boleh ditulis langsung di dalamnya. Compose menyediakan effect handler.

LaunchedEffect(kunci) { ... } menjalankan coroutine saat Composable tampil, dan mengulanginya hanya jika kunci berubah. rememberCoroutineScope() dipakai untuk menjalankan coroutine dari event, misalnya klik tombol. DisposableEffect untuk mendaftar dan melepas listener.

derivedStateOf menghitung nilai turunan dari state lain dan hanya memicu pembaruan saat hasilnya berubah, misalnya tombol "kembali ke atas" yang muncul setelah daftar digulir.

KODE
@Composable
fun LayarDetail(id: Int, vm: DetailViewModel = viewModel()) {
    // dijalankan sekali per id
    LaunchedEffect(id) { vm.muat(id) }

    val daftar = rememberLazyListState()
    val scope = rememberCoroutineScope()
    val tampilkanAtas by remember {
        derivedStateOf { daftar.firstVisibleItemIndex > 3 }
    }

    Box {
        LazyColumn(state = daftar) { /* ... */ }
        if (tampilkanAtas) {
            SmallFloatingActionButton(
                onClick = { scope.launch { daftar.animateScrollToItem(0) } },
                modifier = Modifier.align(Alignment.BottomEnd).padding(16.dp),
            ) { Icon(Icons.Default.KeyboardArrowUp, contentDescription = "Ke atas") }
        }
    }
}

Soal latihan

  1. Tampilkan Snackbar setiap kali ViewModel mengirim pesan error baru.

    Petunjuk

    LaunchedEffect(pesan) { if (pesan != null) snackbar.showSnackbar(pesan) }.

    Lihat jawaban
    KODE
    val pesan = vm.pesanError.collectAsStateWithLifecycle().value
LaunchedEffect(pesan) {
    if (pesan != null) {
        snackbar.showSnackbar(pesan)
        vm.pesanSudahTampil()
    }
}

  2. Buat hitung mundur 10 detik yang dimulai saat layar tampil.

    Petunjuk

    LaunchedEffect(Unit) dengan loop dan delay(1000).

    Lihat jawaban
    KODE
    var sisa by remember { mutableIntStateOf(10) }
LaunchedEffect(Unit) {
    while (sisa > 0) {
        delay(1000)
        sisa--
    }
}
Text(if (sisa > 0) "Kirim ulang OTP dalam $sisa detik" else "Kirim ulang OTP")

Poin penting

  • Jangan memanggil API langsung di badan Composable.
  • LaunchedEffect(kunci) untuk efek saat tampil.
  • rememberCoroutineScope untuk efek dari event.
