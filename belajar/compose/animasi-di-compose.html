Animasi di Compose

Buka versi interaktif

animate*AsState menganimasikan satu nilai saat targetnya berubah: animateDpAsState, animateColorAsState, animateFloatAsState. Cukup ganti nilai biasa dengan versi animasinya.

AnimatedVisibility memunculkan dan menyembunyikan konten dengan efek, AnimatedContent berganti konten (misalnya angka), dan Modifier.animateContentSize() menghaluskan perubahan ukuran.

Untuk animasi berulang pakai rememberInfiniteTransition. Animasi dari desainer bisa diputar dengan library Lottie Compose.

KODE
@Composable
fun KartuLipat(judul: String, isi: String) {
    var buka by remember { mutableStateOf(false) }
    val putar by animateFloatAsState(if (buka) 180f else 0f, label = "putar")
    val warna by animateColorAsState(
        if (buka) MaterialTheme.colorScheme.primaryContainer else MaterialTheme.colorScheme.surfaceVariant,
        label = "warna",
    )
    Card(
        onClick = { buka = !buka },
        colors = CardDefaults.cardColors(containerColor = warna),
        modifier = Modifier.fillMaxWidth().animateContentSize(),
    ) {
        Row(Modifier.padding(16.dp), verticalAlignment = Alignment.CenterVertically) {
            Text(judul, Modifier.weight(1f), style = MaterialTheme.typography.titleMedium)
            Icon(Icons.Default.KeyboardArrowDown, null, Modifier.rotate(putar))
        }
        AnimatedVisibility(buka) {
            Text(isi, Modifier.padding(start = 16.dp, end = 16.dp, bottom = 16.dp))
        }
    }
}

Soal latihan

  1. Buat angka keranjang yang bergeser ke atas saat bertambah memakai AnimatedContent.

    Petunjuk

    AnimatedContent(targetState = jumlah, transitionSpec = { slideInVertically { it } togetherWith slideOutVertically { -it } }).

    Lihat jawaban
    KODE
    AnimatedContent(
    targetState = jumlah,
    transitionSpec = { slideInVertically { it } togetherWith slideOutVertically { -it } },
    label = "jumlah",
) { n ->
    Text("$n", style = MaterialTheme.typography.headlineMedium)
}

  2. Buat titik "sedang memuat" yang berdenyut terus.

    Petunjuk

    rememberInfiniteTransition().animateFloat(0.3f, 1f, infiniteRepeatable(tween(600), RepeatMode.Reverse)).

    Lihat jawaban
    KODE
    val t = rememberInfiniteTransition(label = "denyut")
val alfa by t.animateFloat(
    initialValue = 0.3f,
    targetValue = 1f,
    animationSpec = infiniteRepeatable(tween(600), RepeatMode.Reverse),
    label = "alfa",
)
Box(Modifier.size(16.dp).alpha(alfa).background(MaterialTheme.colorScheme.primary, CircleShape))

Poin penting

  • animate*AsState untuk satu nilai.
  • AnimatedVisibility, AnimatedContent, animateContentSize.
  • rememberInfiniteTransition untuk animasi berulang.
