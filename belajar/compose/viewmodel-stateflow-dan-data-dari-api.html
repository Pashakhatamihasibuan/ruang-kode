ViewModel, StateFlow, dan data dari API

Buka versi interaktif

Arsitektur yang direkomendasikan Google: UI (composable) → ViewModel (state layar dan logika) → Repository (sumber data: API dan database). ViewModel bertahan saat layar diputar dan menjalankan coroutine di viewModelScope.

ViewModel menyimpan state di MutableStateFlow dan membukanya sebagai StateFlow hanya-baca. Composable membacanya dengan collectAsStateWithLifecycle(). Gabungkan dengan sealed interface UiState agar layar memuat, gagal, dan berhasil tertangani.

Data API diambil dengan Retrofit (antarmuka dengan anotasi @GET) atau Ktor, disimpan di Room agar bisa dibuka tanpa internet, dan semua bagian dirangkai dengan Hilt (dependency injection).

KODE
sealed interface CuacaState {
    data object Memuat : CuacaState
    data class Ok(val kota: List<String>) : CuacaState
    data class Gagal(val pesan: String) : CuacaState
}

interface CuacaApi {
    @GET("cuaca")
    suspend fun daftar(): List<String>
}

@HiltViewModel
class CuacaViewModel @Inject constructor(private val api: CuacaApi) : ViewModel() {
    private val _state = MutableStateFlow<CuacaState>(CuacaState.Memuat)
    val state: StateFlow<CuacaState> = _state.asStateFlow()

    init { muat() }

    fun muat() = viewModelScope.launch {
        _state.value = CuacaState.Memuat
        _state.value = try {
            CuacaState.Ok(api.daftar())
        } catch (e: Exception) {
            CuacaState.Gagal(e.message ?: "Terjadi kesalahan")
        }
    }
}

@Composable
fun CuacaScreen(vm: CuacaViewModel = hiltViewModel()) {
    when (val s = vm.state.collectAsStateWithLifecycle().value) {
        CuacaState.Memuat -> CircularProgressIndicator()
        is CuacaState.Gagal -> Button(onClick = { vm.muat() }) { Text("Coba lagi: ${s.pesan}") }
        is CuacaState.Ok -> LazyColumn { items(s.kota) { Text(it) } }
    }
}

Soal latihan

  1. Buat sealed interface UiState (Memuat, Sukses, Gagal) dan tampilkan dengan when di Composable.

    Petunjuk

    ViewModel memegang MutableStateFlow<UiState>; Composable memakai collectAsStateWithLifecycle.

    Lihat jawaban
    KODE
    sealed interface UiState {
    data object Memuat : UiState
    data class Sukses(val data: List<Produk>) : UiState
    data class Gagal(val pesan: String) : UiState
}

@Composable
fun LayarProduk(vm: ProdukViewModel = viewModel()) {
    when (val s = vm.state.collectAsStateWithLifecycle().value) {
        UiState.Memuat -> CircularProgressIndicator()
        is UiState.Sukses -> DaftarProduk(s.data)
        is UiState.Gagal -> TeksError(s.pesan, onCobaLagi = vm::muat)
    }
}

  2. Tulis fungsi muat() di ViewModel yang menangani error jaringan.

    Petunjuk

    viewModelScope.launch, try/catch, lalu ubah _state.value.

    Lihat jawaban
    KODE
    fun muat() {
    _state.value = UiState.Memuat
    viewModelScope.launch {
        _state.value = try {
            UiState.Sukses(repo.semua())
        } catch (e: IOException) {
            UiState.Gagal("Tidak ada koneksi. Periksa internet lalu coba lagi.")
        }
    }
}

Poin penting

  • UI → ViewModel → Repository.
  • StateFlow + collectAsStateWithLifecycle.
  • Retrofit/Ktor, Room, Hilt.
