Room: database lokal

Buka versi interaktif

Room adalah lapisan di atas SQLite yang direkomendasikan Google. Kamu menulis tiga bagian: Entity (tabel, berupa data class), DAO (fungsi query dengan anotasi SQL), dan Database.

Query diperiksa saat kompilasi, jadi salah nama kolom langsung ketahuan. Fungsi DAO bisa berupa suspend (sekali jalan) atau mengembalikan Flow (otomatis memancarkan data baru setiap tabel berubah), yang cocok dipadukan dengan StateFlow di ViewModel.

Room memakai KSP untuk membuat kode. Tambahkan plugin com.google.devtools.ksp dan dependensi room-runtime, room-ktx, serta ksp(room-compiler).

KODE
@Entity(tableName = "catatan")
data class Catatan(
    @PrimaryKey(autoGenerate = true) val id: Int = 0,
    val judul: String,
    val isi: String,
    val dibuat: Long = System.currentTimeMillis(),
)

@Dao
interface CatatanDao {
    @Query("SELECT * FROM catatan ORDER BY dibuat DESC")
    fun semua(): Flow<List<Catatan>>

    @Query("SELECT * FROM catatan WHERE judul LIKE '%' || :kata || '%'")
    fun cari(kata: String): Flow<List<Catatan>>

    @Insert
    suspend fun tambah(c: Catatan)

    @Delete
    suspend fun hapus(c: Catatan)
}

@Database(entities = [Catatan::class], version = 1)
abstract class AppDb : RoomDatabase() {
    abstract fun catatanDao(): CatatanDao
}

val db = Room.databaseBuilder(context, AppDb::class.java, "catatan.db").build()

Soal latihan

  1. Tambahkan fungsi DAO untuk mengubah catatan dan menghitung jumlah catatan.

    Petunjuk

    @Update untuk mengubah; @Query("SELECT COUNT(*) FROM catatan") untuk jumlah.

    Lihat jawaban
    KODE
    @Update
suspend fun ubah(c: Catatan)

@Query("SELECT COUNT(*) FROM catatan")
fun jumlah(): Flow<Int>

  2. Tulis dependensi Gradle (libs.versions.toml tidak wajib) untuk Room dengan KSP.

    Petunjuk

    Plugin ksp, lalu implementation room-runtime dan room-ktx, ksp room-compiler.

    Lihat jawaban
    KODE
    plugins {
    id("com.google.devtools.ksp") version "2.0.21-1.0.27"
}

dependencies {
    val room = "2.6.1"
    implementation("androidx.room:room-runtime:$room")
    implementation("androidx.room:room-ktx:$room")
    ksp("androidx.room:room-compiler:$room")
}

Poin penting

  • Entity, DAO, Database.
  • Flow dari DAO otomatis diperbarui.
  • KSP membuat kode Room.
