Tema Material 3 dan mode gelap

Buka versi interaktif

Tema Compose didefinisikan di MaterialTheme(colorScheme, typography, shapes). Proyek baru Android Studio sudah membuat file ui/theme/Theme.kt, Color.kt, dan Type.kt.

Android 12 ke atas mendukung warna dinamis (Material You): palet diambil dari wallpaper pengguna lewat dynamicLightColorScheme(context). Untuk perangkat lama, sediakan lightColorScheme dan darkColorScheme sendiri. isSystemInDarkTheme() membaca pengaturan mode gelap.

Di Composable, ambil warna dan huruf dari tema: MaterialTheme.colorScheme.primary dan MaterialTheme.typography.titleLarge. Hindari menulis warna langsung agar mode gelap otomatis benar.

KODE
private val Terang = lightColorScheme(
    primary = Color(0xFF8B4A2B),
    secondary = Color(0xFF6F5B40),
)
private val Gelap = darkColorScheme(
    primary = Color(0xFFFFB59A),
    secondary = Color(0xFFDCC3A1),
)

@Composable
fun KopiTheme(
    gelap: Boolean = isSystemInDarkTheme(),
    warnaDinamis: Boolean = true,
    content: @Composable () -> Unit,
) {
    val ctx = LocalContext.current
    val skema = when {
        warnaDinamis && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S ->
            if (gelap) dynamicDarkColorScheme(ctx) else dynamicLightColorScheme(ctx)
        gelap -> Gelap
        else -> Terang
    }
    MaterialTheme(colorScheme = skema, typography = Typography(), content = content)
}

Soal latihan

  1. Matikan warna dinamis dan pakai warna merek di layar utama.

    Petunjuk

    Panggil KopiTheme(warnaDinamis = false) { ... } di setContent.

    Lihat jawaban
    KODE
    setContent {
    KopiTheme(warnaDinamis = false) {
        Surface(Modifier.fillMaxSize(), color = MaterialTheme.colorScheme.background) {
            AplikasiKopi()
        }
    }
}

  2. Pasang font Poppins untuk semua judul lewat Typography.

    Petunjuk

    FontFamily(Font(R.font.poppins_bold, FontWeight.Bold)) lalu salin titleLarge dan headlineMedium.

    Lihat jawaban
    KODE
    val Poppins = FontFamily(
    Font(R.font.poppins_regular),
    Font(R.font.poppins_bold, FontWeight.Bold),
)
val Bawaan = Typography()
val KopiTypography = Typography(
    headlineMedium = Bawaan.headlineMedium.copy(fontFamily = Poppins, fontWeight = FontWeight.Bold),
    titleLarge = Bawaan.titleLarge.copy(fontFamily = Poppins),
)

Poin penting

  • MaterialTheme(colorScheme, typography, shapes).
  • Warna dinamis di Android 12+.
  • Ambil warna dari MaterialTheme.colorScheme.
