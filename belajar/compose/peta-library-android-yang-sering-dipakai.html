Jetpack Compose · Modul 5 · Konsep & kode

Peta library Android yang sering dipakai

Buka versi interaktif

Aplikasi Android modern dibangun dengan Jetpack (library resmi Google) ditambah beberapa library pihak ketiga yang sudah menjadi standar industri. Tabel di bawah merangkum yang paling sering ditemui di lowongan kerja dan proyek nyata.

Kelola versi di file gradle/libs.versions.toml (version catalog) agar semua modul memakai versi yang sama. Untuk Compose, pakai Compose BOM sehingga versi semua library Compose otomatis serasi.

Tidak perlu memakai semuanya. Mulai dari Compose, ViewModel, Navigation, Retrofit/Ktor, Room, dan Coil; tambahkan sisanya saat dibutuhkan.

Soal latihan

  1. Pilih library untuk aplikasi berita yang memuat ribuan artikel per halaman, menampilkan gambar, dan menyegarkan data setiap 6 jam di latar belakang.

    Petunjuk

    Butuh Paging 3, Coil, Retrofit, Room (cache), dan WorkManager.

    Lihat jawaban
    YAML
    dependencies {
    implementation("androidx.paging:paging-compose:3.3.2")
    implementation("io.coil-kt:coil-compose:2.7.0")
    implementation("com.squareup.retrofit2:retrofit:2.11.0")
    implementation("androidx.room:room-paging:2.6.1")
    implementation("androidx.work:work-runtime-ktx:2.9.1")
}

  2. Tampilkan gambar dari internet dengan Coil, lengkap dengan placeholder dan sudut membulat.

    Petunjuk

    AsyncImage(model, contentDescription, placeholder, modifier.clip(...)).

    Lihat jawaban
    YAML
    AsyncImage(
    model = produk.gambarUrl,
    contentDescription = produk.nama,
    placeholder = painterResource(R.drawable.placeholder),
    contentScale = ContentScale.Crop,
    modifier = Modifier.size(96.dp).clip(RoundedCornerShape(12.dp)),
)

Poin penting

  • Jetpack + library standar industri.
  • Version catalog dan Compose BOM.
  • Tambah library sesuai kebutuhan.
