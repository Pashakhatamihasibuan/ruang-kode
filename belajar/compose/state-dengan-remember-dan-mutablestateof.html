State dengan remember dan mutableStateOf

Buka versi interaktif

Data yang berubah disimpan di mutableStateOf. Agar nilainya tidak hilang setiap recomposition, bungkus dengan remember: var jumlah by remember { mutableStateOf(0) }. Pakai rememberSaveable agar nilai bertahan saat layar diputar.

State hoisting: pindahkan state ke composable induk, dan kirim ke anak sebagai parameter nilai + onUbah. Anak menjadi stateless, mudah dipakai ulang dan diuji. Pola ini sama dengan "lifting state up" di React.

Jangan menyimpan state penting di composable untuk data yang dipakai banyak layar; simpan di ViewModel (modul berikutnya).

KODE
@Composable
fun Penghitung(jumlah: Int, onUbah: (Int) -> Unit) {
    Row(verticalAlignment = Alignment.CenterVertically) {
        IconButton(onClick = { onUbah(jumlah - 1) }, enabled = jumlah > 0) {
            Icon(Icons.Default.Remove, contentDescription = "Kurangi")
        }
        Text("$jumlah", style = MaterialTheme.typography.titleLarge)
        IconButton(onClick = { onUbah(jumlah + 1) }) {
            Icon(Icons.Default.Add, contentDescription = "Tambah")
        }
    }
}

@Composable
fun HalamanKeranjang() {
    var jumlah by rememberSaveable { mutableStateOf(1) }  // state di induk
    Column {
        Penghitung(jumlah = jumlah, onUbah = { jumlah = it })
        Text("Total: Rp${jumlah * 18000}")
    }
}

Soal latihan

  1. Tambahkan tombol Kurangi yang nonaktif saat angka 0.

    Petunjuk

    Button(enabled = jumlah > 0, onClick = { jumlah-- }).

    Lihat jawaban
    KODE
    @Composable
fun Penghitung() {
    var jumlah by remember { mutableIntStateOf(0) }
    Row(verticalAlignment = Alignment.CenterVertically) {
        OutlinedButton(onClick = { jumlah-- }, enabled = jumlah > 0) { Text("Kurangi") }
        Text("$jumlah", style = MaterialTheme.typography.headlineMedium, modifier = Modifier.padding(horizontal = 16.dp))
        Button(onClick = { jumlah++ }) { Text("Tambah") }
    }
}

  2. Buat angka tidak kembali ke 0 saat layar diputar.

    Petunjuk

    Ganti remember dengan rememberSaveable.

    Lihat jawaban
    KODE
    var jumlah by rememberSaveable { mutableIntStateOf(0) }

  3. Terapkan state hoisting: pisahkan Penghitung(jumlah, onTambah) yang stateless dari pemilik state.

    Petunjuk

    Composable stateless menerima nilai dan lambda; induknya yang menyimpan state.

    Lihat jawaban
    KODE
    @Composable
fun Penghitung(jumlah: Int, onTambah: () -> Unit) {
    Button(onClick = onTambah) { Text("Jumlah: $jumlah") }
}

@Composable
fun Layar() {
    var jumlah by rememberSaveable { mutableIntStateOf(0) }
    Penghitung(jumlah = jumlah, onTambah = { jumlah++ })
}

Poin penting

  • remember + mutableStateOf menyimpan state.
  • rememberSaveable bertahan saat rotasi.
  • Hoisting: anak stateless (nilai + onUbah).
