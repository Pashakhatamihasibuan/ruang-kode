WorkManager untuk tugas latar

Buka versi interaktif

Tugas yang harus pasti selesai walau aplikasi ditutup atau ponsel di-restart (sinkronisasi pesanan offline, unggah foto, backup) dijadwalkan dengan WorkManager. Ia memilih cara terbaik sesuai versi Android dan menghormati penghemat baterai.

Atur constraint (hanya saat ada internet, saat mengisi daya, baterai tidak rendah), backoff untuk mencoba ulang, dan periodic work minimal setiap 15 menit. Pantau statusnya sebagai Flow untuk ditampilkan di UI.

Bukan untuk segala hal: pekerjaan singkat selama layar terbuka cukup dengan coroutine di ViewModel.

KODE
class SinkronWorker(ctx: Context, params: WorkerParameters) : CoroutineWorker(ctx, params) {
    override suspend fun doWork(): Result {
        return try {
            val terkirim = repo.kirimPesananTertunda()
            Log.d("Sinkron", "$terkirim pesanan terkirim")
            Result.success()
        } catch (e: IOException) {
            Result.retry()
        }
    }
}

val kerja = OneTimeWorkRequestBuilder<SinkronWorker>()
    .setConstraints(Constraints(requiredNetworkType = NetworkType.CONNECTED))
    .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 30, TimeUnit.SECONDS)
    .build()
WorkManager.getInstance(context)
    .enqueueUniqueWork("sinkron", ExistingWorkPolicy.KEEP, kerja)

Soal latihan

  1. Jadwalkan SinkronWorker berkala setiap 1 jam yang hanya berjalan saat terhubung Wi-Fi (unmetered).

    Petunjuk

    PeriodicWorkRequestBuilder dan NetworkType.UNMETERED.

    Lihat jawaban
    KODE
    val berkala = PeriodicWorkRequestBuilder<SinkronWorker>(1, TimeUnit.HOURS)
    .setConstraints(Constraints(requiredNetworkType = NetworkType.UNMETERED))
    .build()
WorkManager.getInstance(context)
    .enqueueUniquePeriodicWork("sinkron-jam", ExistingPeriodicWorkPolicy.KEEP, berkala)

Poin penting

  • WorkManager untuk tugas yang harus pasti selesai.
  • Constraint, backoff, periodic minimal 15 menit.
  • Tugas singkat di layar cukup coroutine.
