Paging 3 untuk daftar panjang

Buka versi interaktif

Daftar ribuan produk tidak boleh dimuat sekaligus. Paging 3 memuat data per halaman saat pengguna menggulir, menyimpan cache, dan menyediakan status memuat serta error untuk ditampilkan di akhir daftar.

Buat PagingSource yang tahu cara memuat halaman berikutnya, bungkus dengan Pager, lalu di Compose kumpulkan dengan collectAsLazyPagingItems(). Untuk offline-first, pakai RemoteMediator yang mengisi Room.

Tampilkan indikator di bawah daftar saat loadState.append sedang memuat, dan tombol "Coba lagi" jika error.

KODE
class ProdukPagingSource(private val api: ProdukApi) : PagingSource<Int, ProdukDto>() {
    override suspend fun load(params: LoadParams<Int>): LoadResult<Int, ProdukDto> = try {
        val hal = params.key ?: 1
        val data = api.semua(hal)
        LoadResult.Page(data, prevKey = if (hal == 1) null else hal - 1,
                         nextKey = if (data.isEmpty()) null else hal + 1)
    } catch (e: IOException) {
        LoadResult.Error(e)
    }
    override fun getRefreshKey(state: PagingState<Int, ProdukDto>) = state.anchorPosition
}

@Composable
fun DaftarPanjang(vm: KatalogViewModel = hiltViewModel()) {
    val item = vm.produk.collectAsLazyPagingItems()
    LazyColumn {
        items(item.itemCount, key = item.itemKey { it.id }) { i -> item[i]?.let { KartuProduk(it) } }
        if (item.loadState.append is LoadState.Loading) item { CircularProgressIndicator() }
        if (item.loadState.append is LoadState.Error) item { Button(onClick = item::retry) { Text("Coba lagi") } }
    }
}

Poin penting

  • Paging 3 memuat per halaman saat menggulir.
  • PagingSource + Pager + collectAsLazyPagingItems.
  • Tampilkan loadState memuat dan error.

Cek pemahaman

Nilai nextKey saat halaman kosong?

Jawaban: null (tidak ada halaman berikutnya)

Menandai akhir data.
