UI deklaratif dengan Compose

Buka versi interaktif

Jetpack Compose adalah cara modern membuat tampilan Android yang direkomendasikan Google, menggantikan file XML. Tampilan ditulis sebagai fungsi Kotlin bertanda @Composable, dan kamu cukup mendeskripsikan tampilan berdasarkan data. Saat data berubah, Compose menggambar ulang bagian yang terdampak (recomposition).

Buat proyek di Android Studio dengan template Empty Activity (sudah memakai Compose). Fungsi bertanda @Preview tampil langsung di panel desain tanpa menjalankan emulator.

Konsepnya sangat mirip Flutter dan React: tampilan adalah fungsi dari state. Jika kamu sudah paham salah satunya, belajar Compose akan terasa cepat.

Soal latihan

  1. Buat Composable Sapa(nama: String) dan pratinjaunya dengan @Preview.

    Petunjuk

    @Composable fun Sapa(nama: String) { Text("Halo, $nama") } lalu fungsi @Preview tanpa parameter.

    Lihat jawaban
    KODE
    @Composable
fun Sapa(nama: String, modifier: Modifier = Modifier) {
    Text(text = "Halo, $nama!", modifier = modifier)
}

@Preview(showBackground = true)
@Composable
fun SapaPreview() {
    MaterialTheme { Sapa("Rina") }
}

  2. Buat kartu profil berisi nama tebal dan prodi di bawahnya.

    Petunjuk

    Card { Column(Modifier.padding(16.dp)) { Text(..., fontWeight = FontWeight.Bold); Text(...) } }

    Lihat jawaban
    KODE
    @Composable
fun KartuProfil(nama: String, prodi: String) {
    Card(modifier = Modifier.fillMaxWidth()) {
        Column(Modifier.padding(16.dp)) {
            Text(nama, style = MaterialTheme.typography.titleMedium, fontWeight = FontWeight.Bold)
            Text(prodi, style = MaterialTheme.typography.bodyMedium)
        }
    }
}

Poin penting

  • @Composable = fungsi yang menggambar UI.
  • Recomposition saat state berubah.
  • @Preview untuk melihat tanpa emulator.
