Column, Row, Box, dan Modifier

Buka versi interaktif

Column menyusun vertikal, Row horizontal, dan Box menumpuk. Jarak antaranak diatur dengan Arrangement.spacedBy(8.dp), perataan dengan Alignment.

Modifier mengatur ukuran, jarak, latar, sudut, klik, dan lainnya, dirangkai dengan titik. Urutan modifier penting: padding sebelum background memberi jarak di luar warna, sedangkan setelahnya memberi jarak di dalam warna.

Satuan ukuran memakai dp (density-independent pixel) untuk jarak dan ukuran, serta sp untuk teks agar mengikuti pengaturan ukuran huruf pengguna.

KODE
@Composable
fun KartuProduk(nama: String, harga: String, onBeli: () -> Unit) {
    Row(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
            .background(MaterialTheme.colorScheme.surfaceVariant, RoundedCornerShape(16.dp))
            .padding(16.dp),
        verticalAlignment = Alignment.CenterVertically,
        horizontalArrangement = Arrangement.spacedBy(12.dp),
    ) {
        Icon(Icons.Default.ShoppingCart, contentDescription = null)
        Column(modifier = Modifier.weight(1f)) {
            Text(nama, style = MaterialTheme.typography.titleMedium)
            Text(harga, style = MaterialTheme.typography.bodyMedium)
        }
        Button(onClick = onBeli) { Text("Beli") }
    }
}

Soal latihan

  1. Buat baris ikon, nama produk panjang, dan harga yang tidak terpotong di layar sempit.

    Petunjuk

    Beri teks nama Modifier.weight(1f) agar mengisi sisa ruang.

    Lihat jawaban
    KODE
    Row(
    modifier = Modifier.fillMaxWidth().padding(12.dp),
    verticalAlignment = Alignment.CenterVertically,
) {
    Icon(Icons.Default.ShoppingCart, contentDescription = null)
    Spacer(Modifier.width(12.dp))
    Text("Kopi Arabika Gayo Wine Process 250 gram", modifier = Modifier.weight(1f))
    Spacer(Modifier.width(12.dp))
    Text("Rp85.000", style = MaterialTheme.typography.titleMedium)
}

  2. Taruh label "Diskon 20%" di pojok kiri atas sebuah gambar.

    Petunjuk

    Box + Modifier.align(Alignment.TopStart) pada label.

    Lihat jawaban
    KODE
    Box {
    Image(painterResource(R.drawable.kopi), contentDescription = "Kopi Gayo")
    Text(
        "Diskon 20%",
        color = Color.White,
        modifier = Modifier
            .align(Alignment.TopStart)
            .padding(8.dp)
            .background(Color.Red, RoundedCornerShape(8.dp))
            .padding(horizontal = 8.dp, vertical = 4.dp),
    )
}

  3. Jelaskan dengan kode kenapa urutan Modifier penting: padding lalu background berbeda dengan background lalu padding.

    Petunjuk

    Modifier diterapkan dari kiri ke kanan, dari luar ke dalam.

    Lihat jawaban
    KODE
    // warna hanya di bagian dalam, ada jarak transparan di luar
Modifier.padding(16.dp).background(Color.Yellow)

// warna memenuhi termasuk area padding
Modifier.background(Color.Yellow).padding(16.dp)

Poin penting

  • Column, Row, Box untuk tata letak.
  • Urutan Modifier memengaruhi hasil.
  • dp untuk ukuran, sp untuk teks.
