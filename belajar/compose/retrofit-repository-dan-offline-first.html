Retrofit, repository, dan offline-first

Buka versi interaktif

Retrofit mengubah API HTTP menjadi interface Kotlin dengan fungsi suspend. Dipadukan dengan kotlinx.serialization atau Moshi untuk JSON, dan OkHttp interceptor untuk header token dan logging.

Repository adalah satu-satunya pintu data bagi ViewModel. Pola offline-first yang direkomendasikan Google: UI selalu membaca dari Room (sumber kebenaran tunggal) sebagai Flow, sementara repository menyegarkan Room dari jaringan. Aplikasi tetap bisa dipakai saat sinyal hilang, hal yang sangat penting di daerah dengan koneksi tidak stabil.

Tangani error jaringan dengan jelas: tampilkan data lama plus pesan "Gagal memperbarui, menampilkan data terakhir".

KODE
interface ProdukApi {
    @GET("produk")
    suspend fun semua(@Query("halaman") halaman: Int = 1): List<ProdukDto>
}

class ProdukRepository @Inject constructor(
    private val api: ProdukApi,
    private val dao: ProdukDao,
) {
    fun aliranProduk(): Flow<List<Produk>> =
        dao.semua().map { daftar -> daftar.map { it.keDomain() } }

    suspend fun segarkan(): Result<Unit> = runCatching {
        val baru = api.semua()
        dao.gantiSemua(baru.map { it.keEntity() })
    }
}

Poin penting

  • Retrofit: API sebagai interface suspend.
  • Repository = satu pintu data.
  • Offline-first: UI membaca Room, jaringan menyegarkan Room.
