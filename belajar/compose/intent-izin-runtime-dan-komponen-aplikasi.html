Intent, izin runtime, dan komponen aplikasi

Buka versi interaktif

Intent adalah pesan untuk memulai sesuatu. Explicit intent menyebut tujuan yang pasti; implicit intent menyebut aksi (buka URL, bagikan teks, telepon) dan sistem memilih aplikasi yang cocok.

Izin berbahaya (kamera, lokasi, notifikasi di Android 13+) harus diminta saat runtime, tepat ketika fitur dipakai, dengan penjelasan alasan. Di Compose, pakai rememberLauncherForActivityResult(RequestPermission()).

Komponen aplikasi lain: Service (pekerjaan tanpa UI; foreground service untuk musik atau navigasi, wajib menampilkan notifikasi), BroadcastReceiver (menerima kejadian sistem seperti boot selesai), dan ContentProvider (berbagi data antar aplikasi, misalnya kontak).

KODE
@Composable
fun TombolBagikan(produk: String) {
    val context = LocalContext.current
    Button(onClick = {
        val kirim = Intent(Intent.ACTION_SEND).apply {
            type = "text/plain"
            putExtra(Intent.EXTRA_TEXT, "Cek $produk di Tokoku: https://tokoku.id")
        }
        context.startActivity(Intent.createChooser(kirim, "Bagikan lewat"))
    }) { Text("Bagikan") }
}

@Composable
fun TombolKamera(bukaKamera: () -> Unit) {
    var ditolak by remember { mutableStateOf(false) }
    val izin = rememberLauncherForActivityResult(ActivityResultContracts.RequestPermission()) { ok ->
        if (ok) bukaKamera() else ditolak = true
    }
    Button(onClick = { izin.launch(Manifest.permission.CAMERA) }) { Text("Scan QR") }
    if (ditolak) Text("Izin kamera dibutuhkan untuk memindai kode QR.")
}

Poin penting

  • Explicit vs implicit intent.
  • Minta izin berbahaya saat fitur dipakai.
  • Service, BroadcastReceiver, ContentProvider.
