Activity, lifecycle, dan manifest

Buka versi interaktif

Aplikasi Compose modern biasanya punya satu Activity yang memanggil setContent { }, lalu layar-layar diatur oleh Navigation Compose. Activity tetap penting karena ia pintu masuk dari sistem.

Lifecycle Activity: onCreate → onStart → onResume (terlihat dan interaktif) → onPause → onStop → onDestroy. Saat layar diputar atau bahasa diganti, Activity dihancurkan dan dibuat ulang; simpan state di ViewModel atau rememberSaveable agar tidak hilang.

AndroidManifest.xml mendeklarasikan komponen aplikasi, izin, Activity pembuka (intent-filter MAIN/LAUNCHER), dan fitur perangkat yang dibutuhkan. Di Compose, kumpulkan lifecycle dengan collectAsStateWithLifecycle() agar Flow berhenti dikumpulkan saat aplikasi di latar.

KODE
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        Log.d("Siklus", "onCreate")
        setContent { TokoTheme { AplikasiToko() } }
    }
    override fun onStart() { super.onStart(); Log.d("Siklus", "onStart") }
    override fun onResume() { super.onResume(); Log.d("Siklus", "onResume") }
    override fun onPause() { super.onPause(); Log.d("Siklus", "onPause") }
    override fun onStop() { super.onStop(); Log.d("Siklus", "onStop") }
    override fun onDestroy() { super.onDestroy(); Log.d("Siklus", "onDestroy") }
}
