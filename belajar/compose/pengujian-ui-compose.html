Pengujian UI Compose

Buka versi interaktif

Compose punya API pengujian sendiri: createComposeRule() menampilkan Composable, lalu kamu mencari node dengan onNodeWithText, onNodeWithContentDescription, atau onNodeWithTag, melakukan aksi (performClick, performTextInput), dan memeriksa (assertIsDisplayed, assertIsEnabled).

ViewModel dan repository diuji dengan unit test biasa. MockK membuat objek tiruan, Turbine memudahkan menguji Flow, dan kotlinx-coroutines-test menyediakan runTest.

Tes UI berjalan di emulator (androidTest). Dengan Robolectric, sebagian tes bisa dijalankan di JVM tanpa emulator sehingga lebih cepat.

KODE
class PenghitungTest {
    @get:Rule
    val rule = createComposeRule()

    @Test
    fun tombolTambahMenaikkanAngka() {
        rule.setContent { Penghitung() }
        rule.onNodeWithText("0").assertIsDisplayed()
        rule.onNodeWithText("Tambah").performClick()
        rule.onNodeWithText("1").assertIsDisplayed()
        rule.onNodeWithText("Kurangi").assertIsEnabled()
    }
}

class ProdukViewModelTest {
    @Test
    fun sukses() = runTest {
        val repo = mockk<ProdukRepo> { coEvery { semua() } returns listOf(Produk(1, "Kopi")) }
        val vm = ProdukViewModel(repo)
        vm.state.test {
            assertEquals(UiState.Memuat, awaitItem())
            vm.muat()
            assertTrue(awaitItem() is UiState.Sukses)
        }
    }
}

Soal latihan

  1. Tulis tes: tombol Kurangi harus nonaktif saat angka 0.

    Petunjuk

    onNodeWithText("Kurangi").assertIsNotEnabled().

    Lihat jawaban
    KODE
    @Test
fun kurangiNonaktifSaatNol() {
    rule.setContent { Penghitung() }
    rule.onNodeWithText("Kurangi").assertIsNotEnabled()
}

  2. Tulis tes form: mengetik email salah harus menampilkan pesan error.

    Petunjuk

    performTextInput pada field, lalu onNodeWithText(pesan).assertIsDisplayed().

    Lihat jawaban
    KODE
    @Test
fun emailSalahMenampilkanError() {
    rule.setContent { FormEmail() }
    rule.onNodeWithText("Email").performTextInput("rina.mail.com")
    rule.onNodeWithText("Format email belum benar", substring = true).assertIsDisplayed()
}

Poin penting

  • createComposeRule + onNode... + perform... + assert....
  • MockK, Turbine, runTest untuk ViewModel.
  • Robolectric untuk tes cepat di JVM.
