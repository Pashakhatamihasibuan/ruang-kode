Dependency injection dengan Hilt

Buka versi interaktif

Dependency injection (DI) berarti objek menerima kebutuhannya dari luar, bukan membuatnya sendiri. Hasilnya kelas lebih mudah diuji (kebutuhan bisa diganti versi palsu) dan konfigurasi terpusat.

Hilt adalah DI resmi Android berbasis Dagger. Tandai Application dengan @HiltAndroidApp, Activity dengan @AndroidEntryPoint, ViewModel dengan @HiltViewModel dan @Inject constructor. Cara membuat objek dari pustaka luar (Retrofit, Room) ditulis di @Module dengan fungsi @Provides.

Di Compose, ambil ViewModel dengan hiltViewModel(). Alternatif yang lebih ringan dan multiplatform adalah Koin.

KODE
@HiltAndroidApp
class TokoApp : Application()

@Module
@InstallIn(SingletonComponent::class)
object JaringanModule {
    @Provides @Singleton
    fun retrofit(): Retrofit = Retrofit.Builder()
        .baseUrl("https://api.tokoku.id/")
        .addConverterFactory(Json.asConverterFactory("application/json".toMediaType()))
        .build()

    @Provides @Singleton
    fun produkApi(r: Retrofit): ProdukApi = r.create(ProdukApi::class.java)
}

@HiltViewModel
class ProdukViewModel @Inject constructor(
    private val repo: ProdukRepository,
) : ViewModel() {
    val produk = repo.aliranProduk()
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), emptyList())
}

@Composable
fun LayarProduk(vm: ProdukViewModel = hiltViewModel()) {
    val daftar by vm.produk.collectAsStateWithLifecycle()
    LazyColumn { items(daftar, key = { it.id }) { KartuProduk(it) } }
}

Poin penting

  • DI: kebutuhan diberikan dari luar.
  • @HiltAndroidApp, @AndroidEntryPoint, @HiltViewModel, @Module.
  • hiltViewModel() di Compose.
