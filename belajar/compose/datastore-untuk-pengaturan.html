DataStore untuk pengaturan

Buka versi interaktif

DataStore menggantikan SharedPreferences untuk menyimpan pengaturan kecil: mode gelap, bahasa, token sesi. Semua operasinya asinkron (Flow dan suspend), jadi tidak membuat UI tersendat.

Preferences DataStore menyimpan pasangan kunci-nilai. Proto DataStore menyimpan objek bertipe aman dengan skema. Untuk kebanyakan aplikasi, Preferences DataStore sudah cukup.

Data rahasia sebaiknya dienkripsi atau disimpan dengan Android Keystore, bukan teks biasa.

KODE
val Context.pengaturan by preferencesDataStore(name = "pengaturan")
private val KUNCI_GELAP = booleanPreferencesKey("gelap")

class PengaturanRepo(private val context: Context) {
    val gelap: Flow<Boolean> = context.pengaturan.data.map { it[KUNCI_GELAP] ?: false }

    suspend fun setGelap(nilai: Boolean) {
        context.pengaturan.edit { it[KUNCI_GELAP] = nilai }
    }
}

Soal latihan

  1. Tambahkan pengaturan bahasa ("id" atau "en") ke PengaturanRepo.

    Petunjuk

    stringPreferencesKey("bahasa"), baca dengan map, tulis dengan edit.

    Lihat jawaban
    KODE
    private val KUNCI_BAHASA = stringPreferencesKey("bahasa")

val bahasa: Flow<String> = context.pengaturan.data.map { it[KUNCI_BAHASA] ?: "id" }

suspend fun setBahasa(kode: String) {
    context.pengaturan.edit { it[KUNCI_BAHASA] = kode }
}

  2. Hubungkan sakelar mode gelap di Compose ke PengaturanRepo lewat ViewModel.

    Petunjuk

    stateIn untuk mengubah Flow menjadi StateFlow; Switch memanggil fungsi ViewModel.

    Lihat jawaban
    KODE
    class PengaturanViewModel(private val repo: PengaturanRepo) : ViewModel() {
    val gelap = repo.gelap.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), false)
    fun ubah(v: Boolean) = viewModelScope.launch { repo.setGelap(v) }
}

@Composable
fun BarisGelap(vm: PengaturanViewModel) {
    val gelap by vm.gelap.collectAsStateWithLifecycle()
    ListItem(
        headlineContent = { Text("Mode gelap") },
        trailingContent = { Switch(checked = gelap, onCheckedChange = vm::ubah) },
    )
}

Poin penting

  • DataStore menggantikan SharedPreferences.
  • Baca lewat Flow, tulis lewat edit (suspend).
  • stateIn untuk dipakai di UI.

Cek pemahaman

Kenapa DataStore lebih baik dari SharedPreferences?

Jawaban: Asinkron dan aman dari error baca-tulis bersamaan

Tidak memblokir thread UI.

Kerjakan latihannya di aplikasi

Sebelumnya: Room: database lokal

Berikutnya: Peta library Android yang sering dipakai
