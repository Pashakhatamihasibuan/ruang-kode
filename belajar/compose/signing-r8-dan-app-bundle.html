Signing, R8, dan App Bundle

Buka versi interaktif

Setiap aplikasi Android harus ditandatangani. Buat upload key dengan keytool, simpan di tempat aman (kehilangan kunci berarti repot), lalu aktifkan Play App Signing agar Google menyimpan kunci rilis yang sebenarnya.

R8 memperkecil (shrink), mengaburkan (obfuscate), dan mengoptimasi kode saat build rilis. Aktifkan isMinifyEnabled dan isShrinkResources; tambahkan aturan proguard-rules.pro jika pustaka memakai refleksi.

Google Play mewajibkan format Android App Bundle (.aab). Play membuat APK khusus per perangkat (bahasa, kepadatan layar, arsitektur CPU), sehingga ukuran unduhan pengguna lebih kecil.

KODE
// app/build.gradle.kts
android {
    signingConfigs {
        create("rilis") {
            storeFile = file(System.getenv("KEYSTORE_PATH") ?: "upload.jks")
            storePassword = System.getenv("KEYSTORE_PASS")
            keyAlias = "upload"
            keyPassword = System.getenv("KEY_PASS")
        }
    }
    buildTypes {
        release {
            isMinifyEnabled = true
            isShrinkResources = true
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
            signingConfig = signingConfigs.getByName("rilis")
        }
    }
}

$ ./gradlew bundleRelease

Poin penting

  • Upload key + Play App Signing.
  • R8 untuk shrink dan obfuscate.
  • Rilis sebagai .aab.
