Simbol Do: menu yang berulang

Buka versi interaktif

Simbol Do menjalankan isi loop dulu, baru memeriksa kondisi di bawah. Loop lanjut selama kondisi benar. Cocok untuk menu, karena menu harus tampil minimal sekali.

Pada contoh, menu tampil, pengguna memilih, program memproses, lalu kondisi pilih <> 0 dicek. Pilihan 0 menghentikan loop.

Input bawaan: 1 (cek saldo), 2 (isi saldo), 1 (cek lagi), 0 (keluar).

PSEUDOCODE
START
    DECLARE pilih, saldo : INTEGER
    saldo ← 50000
    REPEAT
        OUTPUT "1 Cek saldo  2 Isi 10000  0 Keluar"
        INPUT pilih
        IF pilih = 1 THEN
            OUTPUT "Saldo: ", saldo
        ELSE
            IF pilih = 2 THEN
                saldo ← saldo + 10000
                OUTPUT "Saldo bertambah"
            ENDIF
        ENDIF
    UNTIL pilih = 0
    OUTPUT "Terima kasih"
END

Soal latihan

  1. Buat menu kalkulator: 1 Tambah, 2 Kurang, 0 Keluar, yang terus tampil sampai pengguna memilih 0.

    Petunjuk

    Do ... loop while pilihan != 0; di dalamnya If untuk setiap pilihan.

    Lihat jawaban
    CONTOH
    Declare pilih, a, b : Integer
Do
    Output "1 Tambah, 2 Kurang, 0 Keluar"
    Input pilih
    If pilih == 1 → Input a, Input b, Output a + b
    If pilih == 2 → Input a, Input b, Output a - b
Loop while pilih != 0
Output "Sampai jumpa"

  2. Minta PIN sampai benar (1234), lalu tampilkan berapa kali mencoba.

    Petunjuk

    Do ... while pin != 1234, hitung percobaan di dalam loop.

    Lihat jawaban
    CONTOH
    Declare pin, coba : Integer
Assign coba = 0
Do
    Input pin
    Assign coba = coba + 1
Loop while pin != 1234
Output "Berhasil setelah " & coba & " kali"

Poin penting

  • Do menjalankan isi dulu, cek di akhir.
  • Lanjut selama kondisi benar.
  • Ideal untuk menu dan validasi input.
