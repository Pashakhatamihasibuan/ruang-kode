Proyek: kasir dengan diskon

Buka versi interaktif

Proyek ini menggabungkan Do (input barang sampai harga 0), akumulator, If untuk diskon, dan If-Else untuk kembalian. Bangun ulang di aplikasi Flowgorithm, simbol demi simbol, lalu bandingkan dengan simulator ini.

Saat membangun di Flowgorithm, jalankan setiap kali menambah 2 sampai 3 simbol. Menguji sedikit-sedikit jauh lebih mudah daripada mencari kesalahan di flowchart yang sudah besar.

Tantangan: tambahkan pajak 11% setelah diskon, dan tampilkan jumlah barang yang dibeli.

PSEUDOCODE
START
    DECLARE harga, jumlah, total, bayar, kembali : INTEGER
    total ← 0
    REPEAT
        INPUT harga
        IF harga > 0 THEN
            INPUT jumlah
            total ← total + harga * jumlah
        ENDIF
    UNTIL harga = 0
    IF total > 100000 THEN
        total ← total - Int(total * 10 / 100)
        OUTPUT "Diskon 10% diberikan"
    ENDIF
    OUTPUT "Total: ", total
    INPUT bayar
    IF bayar >= total THEN
        kembali ← bayar - total
        OUTPUT "Kembalian: ", kembali
    ELSE
        OUTPUT "Uang kurang ", (total - bayar)
    ENDIF
END

Poin penting

  • Gabungkan Do, akumulator, dan If.
  • Uji setiap beberapa simbol.
  • Uji juga kasus uang kurang dan total di bawah batas diskon.

Cek pemahaman

Kenapa jumlah barang tidak diminta saat harga 0?

Jawaban: Karena 0 adalah tanda selesai

If di dalam Do melewati input jumlah saat sentinel muncul.

Total 120000 mendapat diskon 10%. Total baru?

Jawaban: 108000

120000 - 12000 = 108000.
