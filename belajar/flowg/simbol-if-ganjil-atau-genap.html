Simbol If: ganjil atau genap

Buka versi interaktif

Simbol If berbentuk belah ketupat dengan dua cabang: True di kanan dan False di kiri. Isi kondisinya dengan ekspresi yang hasilnya benar atau salah, misalnya x mod 2 = 0.

Bilangan genap habis dibagi 2, sehingga sisa baginya 0. Jika kondisi benar, cabang kanan menampilkan "genap"; jika salah, cabang kiri menampilkan "ganjil". Kedua cabang bertemu lagi di titik bulat di bawah.

Di Flowgorithm, kamu bisa menaruh beberapa simbol di setiap cabang, atau membiarkan satu cabang kosong.

Coba input 17, 0, dan -4.

PSEUDOCODE
START
    DECLARE x : INTEGER
    INPUT x
    IF x mod 2 = 0 THEN
        OUTPUT x, " genap"
    ELSE
        OUTPUT x, " ganjil"
    ENDIF
END

Soal latihan

  1. Buat flowchart yang memeriksa apakah sebuah angka habis dibagi 5.

    Petunjuk

    If n % 5 == 0.

    Lihat jawaban
    CONTOH
    Declare n : Integer
Input n
If n % 5 == 0
    True : Output n & " habis dibagi 5"
    False: Output n & " tidak habis dibagi 5"

  2. Tampilkan angka yang lebih besar dari dua input, atau "sama" jika keduanya sama.

    Petunjuk

    If bersarang: cek a == b dulu, lalu a > b.

    Lihat jawaban
    CONTOH
    Declare a, b : Integer
Input a
Input b
If a == b
    True : Output "sama"
    False: If a > b
               True : Output a
               False: Output b

Poin penting

  • If punya cabang True (kanan) dan False (kiri).
  • mod 2 = 0 berarti genap.
  • Kedua cabang bertemu kembali.

Cek pemahaman

Kondisi untuk "x habis dibagi 3"?

Jawaban: x mod 3 = 0

Sisa bagi 0 berarti habis dibagi.

Apakah 0 genap menurut program ini?

Jawaban: Ya

0 mod 2 = 0.
