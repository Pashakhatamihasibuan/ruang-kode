If bersarang: nilai huruf

Buka versi interaktif

Untuk lebih dari dua kemungkinan, taruh If baru di cabang False. Setiap tingkat memeriksa satu batas, dari yang tertinggi ke yang terendah.

Flowchart If bersarang bisa melebar ke samping. Di Flowgorithm, ini normal. Kuncinya: cek urutan batas dan uji setiap jalur.

Uji dengan 90, 78, 60, dan 30 untuk melewati keempat jalur.

PSEUDOCODE
START
    DECLARE nilai : INTEGER
    DECLARE huruf : STRING
    INPUT nilai
    IF nilai >= 85 THEN
        huruf ← "A"
    ELSE
        IF nilai >= 70 THEN
            huruf ← "B"
        ELSE
            IF nilai >= 55 THEN
                huruf ← "C"
            ELSE
                huruf ← "D"
            ENDIF
        ENDIF
    ENDIF
    OUTPUT "Nilai huruf: ", huruf
END

Soal latihan

  1. Tentukan kategori BMI: < 18.5 kurus, < 25 normal, < 30 gemuk, selain itu obesitas. BMI = berat / (tinggi × tinggi), tinggi dalam meter.

    Petunjuk

    Hitung BMI dulu dengan Assign, lalu If bersarang dari batas terkecil.

    Lihat jawaban
    CONTOH
    Declare berat, tinggi, bmi : Real
Input berat
Input tinggi
Assign bmi = berat / (tinggi * tinggi)
If bmi < 18.5 → Output "Kurus"
Else If bmi < 25 → Output "Normal"
Else If bmi < 30 → Output "Gemuk"
Else → Output "Obesitas"

  2. Tarif listrik: pemakaian ≤ 100 kWh Rp1.000/kWh, di atas itu Rp1.500/kWh untuk kelebihannya. Hitung tagihan.

    Petunjuk

    Jika lebih dari 100: 100 × 1000 + (kwh − 100) × 1500.

    Lihat jawaban
    CONTOH
    Declare kwh, tagihan : Integer
Input kwh
If kwh <= 100
    True : Assign tagihan = kwh * 1000
    False: Assign tagihan = 100 * 1000 + (kwh - 100) * 1500
Output "Tagihan: Rp" & tagihan

Poin penting

  • If bersarang ditaruh di cabang False.
  • Cek batas tertinggi lebih dulu.
  • Uji setiap jalur.

Cek pemahaman

Nilai 70 mendapat huruf apa di program ini?

Jawaban: B

70 >= 70 benar.

Berapa simbol If yang dibutuhkan untuk 4 nilai huruf?

Jawaban: 3

Pilihan terakhir (D) adalah sisa ketika semua kondisi salah.

Kerjakan latihannya di aplikasi

Sebelumnya: Simbol If: ganjil atau genap

Berikutnya: Simbol For: tabel perkalian dan hitung mundur
