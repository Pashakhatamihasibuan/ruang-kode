Array dengan input

Buka versi interaktif

Untuk membuat array di Flowgorithm, centang Array? pada simbol Declare dan isi ukurannya. Indeks dimulai dari 0, jadi array berukuran 5 punya indeks 0 sampai 4.

Input ke array memakai For: Input nilai[i] untuk i dari 0 sampai 4. Setelah semua terisi, For kedua menghitung total dan mencari nilai tertinggi.

Memisahkan "mengisi data" dan "mengolah data" ke dua loop membuat flowchart lebih jelas dan mudah diperiksa.

PSEUDOCODE
START
    DECLARE nilai : ARRAY[5] OF INTEGER
    DECLARE i, maks, total : INTEGER
    DECLARE rata : REAL
    FOR i ← 0 TO 4 DO
        INPUT nilai[i]
    ENDFOR
    maks ← nilai[0]
    total ← 0
    FOR i ← 0 TO 4 DO
        total ← total + nilai[i]
        IF nilai[i] > maks THEN
            maks ← nilai[i]
        ENDIF
    ENDFOR
    rata ← total / 5
    OUTPUT "Tertinggi: ", maks
    OUTPUT "Rata-rata: ", rata
END

Soal latihan

  1. Masukkan 5 nilai ke array, lalu tampilkan berapa yang lulus (≥ 75).

    Petunjuk

    Satu For untuk input, satu For untuk menghitung.

    Lihat jawaban
    CONTOH
    Declare nilai : Integer array[5]
Declare i, lulus : Integer
For i = 0 to 4
    Input nilai[i]
Assign lulus = 0
For i = 0 to 4
    If nilai[i] >= 75 → Assign lulus = lulus + 1
Output lulus & " mahasiswa lulus"

  2. Tampilkan isi array dari belakang ke depan.

    Petunjuk

    For i dari 4 turun ke 0 (step -1).

    Lihat jawaban
    CONTOH
    For i = 4 to 0 step -1
    Output nilai[i]

Poin penting

  • Centang Array? dan isi ukurannya.
  • Indeks dari 0 sampai ukuran - 1.
  • Pisahkan loop pengisian dan loop pengolahan.

Cek pemahaman

Array ukuran 10, For yang benar untuk mengisinya?

Jawaban: i = 0 to 9

Indeks 0 sampai 9.

Akses nilai[5] pada array ukuran 5 akan?

Jawaban: Error karena di luar batas

Indeks terakhir adalah 4.
