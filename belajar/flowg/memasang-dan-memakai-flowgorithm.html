Memasang dan memakai Flowgorithm

Buka versi interaktif

Unduh Flowgorithm dari situs resminya, flowgorithm.org. Aplikasinya gratis dan dibuat untuk Windows. Di macOS atau Linux, sebagian pengguna menjalankannya lewat Wine; kamu juga bisa berlatih dengan simulator di Ruang Kode.

Saat membuat program baru, sudah ada simbol Main dan End. Untuk menambah simbol, klik panah di antara dua simbol, lalu pilih jenis simbol dari daftar. Klik dua kali sebuah simbol untuk mengisi isinya, misalnya nama variabel atau ekspresi.

Tekan tombol Run untuk menjalankan. Jendela Console menampilkan input dan output. Gunakan juga jendela Variable Watch untuk melihat isi setiap variabel saat program berjalan, dan jalankan langkah demi langkah untuk mencari kesalahan logika. Kecepatan eksekusi bisa diatur agar alur mudah diikuti.

Kebiasaan baik: simpan file (.fprg) sesering mungkin, beri nama variabel yang bermakna, dan tambahkan simbol Comment untuk menjelaskan bagian yang rumit.

Langkah membuat program pertama
LangkahYang dilakukan
1File → New, muncul Main dan End
2Klik panah, tambah Declare: panjang, lebar, luas bertipe Integer
3Tambah Input panjang, lalu Input lebar
4Tambah Assign: luas = panjang * lebar
5Tambah Output: "Luas = " & luas
6Tekan Run, isi input di Console
PSEUDOCODE
START
    DECLARE panjang, lebar, luas : INTEGER
    INPUT panjang
    INPUT lebar
    luas ← panjang * lebar
    OUTPUT "Luas = ", luas
END

Poin penting

  • Klik panah untuk menambah simbol, klik dua kali untuk mengisi.
  • Variable Watch dan jalan langkah demi langkah membantu mencari kesalahan.
  • Simpan sering dan beri nama yang bermakna.
