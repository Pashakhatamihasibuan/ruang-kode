Dari flowchart ke kode: Source Code Viewer

Buka versi interaktif

Setelah flowchart berjalan benar, buka jendela Source Code Viewer di Flowgorithm (dari menu Tools). Pilih bahasa (Python, Java, JavaScript, C++, C#, dan lainnya), dan Flowgorithm menuliskan kode yang setara. Klik sebuah simbol dan baris kode yang sesuai ikut tersorot.

Gunakan fitur ini untuk belajar membaca kode, bukan untuk menyalin tugas. Bandingkan setiap simbol dengan baris kodenya: Declare menjadi deklarasi variabel, While menjadi while, Output menjadi print atau System.out.println.

Kode Python di bawah setara dengan flowchart tabel perkalian. Ubah nilai n lalu jalankan. Setelah itu, lanjutkan ke jalur Python, Java, atau JavaScript di Ruang Kode, termasuk modul latihan algoritma di masing-masing jalur.

Soal latihan

  1. Terjemahkan flowchart "jumlah 1 sampai n" ke Java sesuai hasil Source Code Viewer.

    Petunjuk

    For di Flowgorithm menjadi for (i = 1; i <= n; i++).

    Lihat jawaban
    JAVA
    Scanner input = new Scanner(System.in);
int n = input.nextInt();
int total = 0;
for (int i = 1; i <= n; i++) {
    total = total + i;
}
System.out.println("Jumlah = " + total);

  2. Terjemahkan flowchart ganjil/genap ke Python.

    Petunjuk

    If menjadi if/else, % tetap sama.

    Lihat jawaban
    PYTHON
    n = int(input())
if n % 2 == 0:
    print(n, "genap")
else:
    print(n, "ganjil")

Poin penting

  • Source Code Viewer menerjemahkan flowchart ke banyak bahasa.
  • Pakai untuk belajar membaca kode, bukan menyalin.
  • Setiap simbol punya padanan baris kode.
