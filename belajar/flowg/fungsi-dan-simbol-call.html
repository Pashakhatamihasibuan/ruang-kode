Fungsi dan simbol Call

Buka versi interaktif

Flowgorithm mendukung fungsi. Buat fungsi baru lewat Function Manager (daftar fungsi di toolbar), lalu isi nama, parameter, dan tipe nilai kembali. Fungsi punya flowchart sendiri dengan simbol awal dan akhir.

Fungsi dipanggil di dalam ekspresi, misalnya luas = HitungLuas(p, l). Fungsi yang tidak mengembalikan nilai (prosedur) dipanggil dengan simbol Call.

Gunakan fungsi saat langkah yang sama dipakai di beberapa tempat, atau saat flowchart utama terlalu panjang. Satu fungsi sebaiknya punya satu tugas yang jelas.

Soal latihan

  1. Buat fungsi Luas(p, l) yang mengembalikan luas, lalu panggil dari Main untuk dua persegi panjang.

    Petunjuk

    Fungsi punya Return Type Integer dan variabel return.

    Lihat jawaban
    CONTOH
    Function Luas(Integer p, Integer l) → Integer hasil
    Assign hasil = p * l
End

Main
    Output "Luas A = " & Luas(4, 5)
    Output "Luas B = " & Luas(7, 3)

  2. Buat prosedur (tanpa return) CetakBintang(n) yang mencetak n bintang dalam satu baris, lalu Call untuk n = 1 sampai 3.

    Petunjuk

    Return Type: None. Dipanggil dengan simbol Call.

    Lihat jawaban
    CONTOH
    Function CetakBintang(Integer n) → None
    Declare i : Integer
    Declare s : String
    Assign s = ""
    For i = 1 to n
        Assign s = s & "*"
    Output s
End

Main
    For k = 1 to 3
        Call CetakBintang(k)

Poin penting

  • Fungsi punya flowchart sendiri.
  • Fungsi dengan nilai kembali dipanggil di ekspresi.
  • Prosedur (tanpa nilai kembali) dipanggil dengan Call.
