Luas dan keliling lingkaran

Buka versi interaktif

Program paling dasar mengikuti pola Input → Proses → Output. Terima jari-jari dari pengguna, hitung luas dan keliling, lalu tampilkan.

Karena jari-jari dan hasilnya bisa pecahan, semua variabel bertipe Real. Rumusnya: luas = π × r × r dan keliling = 2 × π × r, dengan π ≈ 3.14159.

Di Flowgorithm, satu simbol Assign berisi satu perhitungan. Memecah rumus menjadi beberapa Assign membuat flowchart lebih mudah dibaca dan diperiksa.

Jalankan dengan r = 7, lalu coba r = 10 dan r = 0.5.

PSEUDOCODE
START
    DECLARE r, luas, keliling : REAL
    INPUT r
    luas ← 3.14159 * r * r
    keliling ← 2 * 3.14159 * r
    OUTPUT "Luas: ", luas
    OUTPUT "Keliling: ", keliling
END

Poin penting

  • Pola dasar: Input → Proses → Output.
  • Pakai Real untuk nilai pecahan.
  • Satu Assign, satu perhitungan.

Cek pemahaman

Tipe yang tepat untuk jari-jari 2.5?

Jawaban: Real

2.5 adalah pecahan.

Jawaban: Declare, Input, Assign, Output

Variabel disiapkan, data diterima, dihitung, lalu ditampilkan.
