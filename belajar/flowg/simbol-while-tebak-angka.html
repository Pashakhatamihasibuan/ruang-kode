Simbol While: tebak angka

Buka versi interaktif

Simbol While memeriksa kondisi di awal. Selama benar, simbol-simbol di dalamnya dijalankan, lalu kembali ke atas. Pakai While saat jumlah putaran tidak diketahui.

Pada permainan tebak angka, kita tidak tahu berapa kali pengguna akan menebak. Loop berjalan selama tebakan <> rahasia. Agar kondisi bisa dicek pertama kali, tebakan diisi 0 lebih dulu.

Input bawaan adalah tiga tebakan: 50, 30, 42. Ubah urutannya dan perhatikan jumlah percobaan berubah.

PSEUDOCODE
START
    DECLARE rahasia, tebakan, kali : INTEGER
    rahasia ← 42
    kali ← 0
    tebakan ← 0
    WHILE tebakan <> rahasia DO
        INPUT tebakan
        kali ← kali + 1
        IF tebakan < rahasia THEN
            OUTPUT "Terlalu kecil"
        ELSE
            IF tebakan > rahasia THEN
                OUTPUT "Terlalu besar"
            ELSE
                OUTPUT "Benar!"
            ENDIF
        ENDIF
    ENDWHILE
    OUTPUT "Ditebak dalam ", kali, " kali"
END

Soal latihan

  1. Hitung berapa kali sebuah angka bisa dibagi 2 sampai menjadi 1 (contoh 64 → 6 kali).

    Petunjuk

    While n > 1: n = Int(n / 2), lalu hitung bertambah 1. Int() membuang bagian pecahan.

    Lihat jawaban
    CONTOH
    Declare n, hitung : Integer
Input n
Assign hitung = 0
While n > 1
    Assign n = Int(n / 2)
    Assign hitung = hitung + 1
Output hitung & " kali"
    KELUARAN
    64 → 6 kali

  2. Batasi tebak angka menjadi paling banyak 5 kesempatan.

    Petunjuk

    Tambahkan syarat kesempatan < 5 pada kondisi While dengan and.

    Lihat jawaban
    CONTOH
    Declare rahasia, tebakan, kesempatan : Integer
Assign rahasia = Random(10) + 1
Assign tebakan = 0
Assign kesempatan = 0
While tebakan != rahasia and kesempatan < 5
    Input tebakan
    Assign kesempatan = kesempatan + 1
If tebakan == rahasia
    True : Output "Benar!"
    False: Output "Kesempatan habis. Jawabannya " & rahasia

Poin penting

  • While cek di awal; bisa 0 kali.
  • Variabel di kondisi harus punya nilai sebelum loop.
  • Badan loop harus bisa membuat kondisi salah.

Cek pemahaman

Kenapa tebakan diisi 0 sebelum While?

Jawaban: Agar kondisi bisa dicek pada putaran pertama

Variabel tanpa nilai tidak bisa dibandingkan.

Rahasia 42, tebakan pertama 42. Berapa kali badan loop jalan?

Jawaban: 1

Kondisi awal 0 <> 42 benar, jadi masuk sekali, lalu tebakan benar.
