Memakai design system lewat CDN dan paket

Buka versi interaktif

Banyak design system bisa langsung dipakai di halaman web lewat CDN (Content Delivery Network) tanpa proses build: cukup satu tag <script> atau <link>. Cocok untuk prototipe cepat, uji usability dengan HTML sungguhan, atau halaman statis.

Contoh: Bootstrap dari jsDelivr, Material Web (komponen Material 3 untuk web), Shoelace / Web Awesome (web components netral), Google Fonts untuk tipografi, dan Material Symbols untuk ikon. Selalu tulis versi yang pasti agar tampilan tidak berubah sendiri.

Untuk produk jangka panjang, pasang lewat npm agar versinya terkunci, ukuran bisa dioptimasi, dan tidak bergantung pada server pihak ketiga. Pertimbangkan juga privasi pengguna: CDN pihak ketiga dapat melihat alamat IP pengunjung.

HTML
<!-- Tipografi dan ikon dari Google Fonts -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;700&display=swap">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Rounded">

<!-- Bootstrap 5 dari jsDelivr (versi dikunci) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

<!-- Komponen Material 3 untuk web -->
<script type="module">
  import 'https://esm.run/@material/web@2.2.0/all.js';
</script>

<md-filled-button>Pesan sekarang</md-filled-button>
<md-outlined-text-field label="Email" type="email"></md-outlined-text-field>
<span class="material-symbols-rounded">local_cafe</span>

<!-- Ganti warna Material lewat token CSS -->
<style>
  :root { --md-sys-color-primary: #8A4B2A; --md-sys-shape-corner-full: 12px; }
</style>

Poin penting

  • CDN: satu tag, cocok untuk prototipe dan halaman statis.
  • Kunci versi di URL.
  • npm untuk produk jangka panjang.
