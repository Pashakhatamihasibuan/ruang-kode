Unduh kit Kopi Kita dan impor ke Figma

Buka versi interaktif

Kit ini berisi seluruh tahapan kerja UI/UX designer untuk satu produk: aplikasi pesan kopi Kopi Kita (HP) dan landing page-nya (web). Semua file berupa SVG dengan layer bernama dan teks asli, jadi setelah diimpor kamu bisa mengedit, membuat komponen, dan men-slicing-nya.

Urutan folder mengikuti hierarki kerja industri: 01 riset, 02 struktur, 03 wireframe lo-fi, 04 mid-fi, 05 hi-fi (plus state, variasi gaya, dan peta motion), 06 design system, 07 handoff. Ada juga prototype/index.html yang bisa dibuka di browser untuk merasakan alur dan animasinya.

Batasan yang perlu kamu tahu: SVG tidak membawa auto layout, component, atau variables Figma. Itu sengaja jadi latihanmu: mengubah gambar statis menjadi sistem yang hidup.

Impor kit ke Figma dalam 6 langkah
LangkahCara
1. Ekstrak & pasang fontEkstrak ZIP, pasang font Google yang tertulis di README (Plus Jakarta Sans + font gaya kit).
2. Seret SVG ke kanvasDrag file .svg ke Figma atau Ctrl/Cmd+Shift+K. Nama layer dan teks tetap bisa diedit.
3. Jadikan frameKlik kanan grup > Frame selection (Ctrl/Cmd+Alt+G), beri nama sesuai file.
4. Komponen & auto layoutTombol/kartu: Create component (Ctrl/Cmd+Alt+K), gabungkan state jadi Variant; tumpukan: Shift+A.
5. TokenImpor tokens.json (DTCG 2025.10) lewat Tokens Studio / Variables Import, hubungkan ke warna.
6. PrototypeBuka prototype/index.html untuk melihat alur, lalu tiru di tab Prototype dengan Smart Animate.

Poin penting

  • Kit = 1 ZIP berisi 7 tahap kerja UI/UX lengkap.
  • SVG: layer bernama, teks bisa diedit; auto layout dan komponen dibuat sendiri.
  • Buka prototype/index.html untuk melihat alur dan animasi.

Cek pemahaman

Kenapa setelah impor SVG kamu masih perlu membuat component dan auto layout sendiri?

Jawaban: SVG hanya membawa bentuk, teks, dan nama layer, bukan struktur Figma

SVG adalah format gambar vektor; struktur khusus Figma harus dibangun di Figma.
