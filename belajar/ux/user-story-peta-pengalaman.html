User story & peta pengalaman

Buka versi interaktif

User story menuliskan kebutuhan dari sudut pengguna: Sebagai [peran], saya ingin [aksi], agar [manfaat], dilengkapi kriteria penerimaan yang bisa diuji.

Peta pengalaman (customer journey) menyusun tahap pengguna dari sadar sampai loyal: apa yang dilakukan, dipikirkan, dirasakan, dan di mana titik sakitnya. Peluang desain biasanya muncul di titik emosi terendah.

Flowchart sederhana menunjukkan langkah, keputusan, dan cabang error sebelum layar digambar.

CONTOH
User story
Sebagai karyawan bergaji bulanan, saya ingin tabungan
terpotong otomatis di tanggal gajian, agar tidak lupa.

Kriteria penerimaan
- bisa memilih tanggal 1-31 dan nominal minimal Rp 10.000
- jika saldo kurang, autodebet dicoba ulang besok, ada notifikasi
- autodebet bisa dijeda tanpa menghubungi CS

Flow: Beranda → Target → Nominal → Tanggal → [Saldo cukup?] → Sukses / Coba ulang

Poin penting

  • User story: peran, aksi, manfaat + kriteria penerimaan.
  • Journey map: tahap, aksi, pikiran, emosi, peluang.
  • Flowchart memperlihatkan cabang error.
