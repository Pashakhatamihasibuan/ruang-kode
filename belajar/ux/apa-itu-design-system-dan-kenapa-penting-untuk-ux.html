UX Design · Modul 9 · Konsep & kode

Apa itu design system dan kenapa penting untuk UX

Buka versi interaktif

Design system adalah sumber kebenaran tunggal sebuah produk: prinsip desain, token (warna, tipografi, jarak), komponen beserta kode, pola interaksi, panduan konten, dan aturan aksesibilitas. Bukan sekadar UI kit di Figma.

Untuk UX, design system memberi konsistensi (pengguna belajar sekali, bisa dipakai di semua layar), kecepatan (tim tidak mendesain ulang tombol), dan kualitas bawaan (komponen sudah lolos uji aksesibilitas dan usability).

Ada tiga lapisan token yang umum: primitive (coklat-600 = #8A4B2A), semantic (color.action.primary), dan component (button.primary.background). Format pertukarannya kini distandarkan oleh W3C Design Tokens Community Group (DTCG).

JSON
{
  "color": {
    "coklat": { "600": { "$type": "color", "$value": "#8A4B2A" } },
    "action": {
      "primary": { "$type": "color", "$value": "{color.coklat.600}" }
    }
  },
  "button": {
    "primary": {
      "background": { "$type": "color", "$value": "{color.action.primary}" }
    }
  },
  "radius": { "md": { "$type": "dimension", "$value": "12px" } }
}

Poin penting

  • Design system = prinsip, token, komponen, pola, konten, aksesibilitas.
  • Konsistensi, kecepatan, kualitas bawaan.
  • Token tiga lapis: primitive, semantic, component.
