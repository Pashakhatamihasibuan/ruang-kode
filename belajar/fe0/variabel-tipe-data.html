Variabel & tipe data

Buka versi interaktif

JavaScript adalah bahasa pemrograman yang berjalan di browser. Variabel dibuat dengan const (nilainya tidak akan diganti) atau let (boleh diganti). Hindari var yang sudah usang.

Tipe dasarnya: string (teks), number (bilangan bulat dan pecahan sama-sama number), boolean, null (sengaja kosong), undefined (belum diberi nilai), serta object dan array. Operator typeof menunjukkan tipenya.

Template literal memakai backtick dan ${...} untuk menyisipkan nilai. console.log mencetak ke panel konsol di bawah pratinjau.

HTML
<p>Lihat panel Konsol di bawah.</p>
JAVASCRIPT
const nama = "Sinta";
let saldo = 50000;
saldo = saldo - 12000;          // let boleh diganti
const aktif = true;

console.log(`Halo, ${nama}! Saldo: ${saldo}`);
console.log(typeof nama, typeof saldo, typeof aktif);
console.log(0.1 + 0.2);          // pecahan biner tidak selalu tepat
console.log("5" + 3, "5" - 3);   // + menyambung string, - mengubah ke angka

Tantangan

  1. Buat variabel kota berisi "Bandung" lalu cetak dengan console.log.

Kode pemula vs kode rapi

Template literal untuk menyusun teks

Backtick dan ${...} menyisipkan nilai langsung ke teks, tanpa tanda + dan tanda kutip yang mudah tertukar. toLocaleString("id-ID") memberi pemisah ribuan gaya Indonesia.

KODE PEMULA
var nama = "Sari";
var total = 1250000;
console.log("Halo " + nama + ", totalmu Rp" + total + ".");
KODE RAPI (BEST PRACTICE)
const nama = "Sari";
const total = 1_250_000;
console.log(`Halo ${nama}, totalmu Rp${total.toLocaleString("id-ID")}.`);

Poin penting

  • const untuk nilai tetap, let untuk nilai yang berubah.
  • typeof memeriksa tipe.
  • Template literal: `Halo ${nama}`.
  • "5" + 3 menghasilkan "53"; hati-hati dengan konversi otomatis.
