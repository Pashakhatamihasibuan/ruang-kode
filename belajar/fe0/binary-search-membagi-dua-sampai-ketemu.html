Binary search: membagi dua sampai ketemu

Buka versi interaktif

Mencari harga di daftar 1.000 barang satu per satu (linear search) bisa butuh 1.000 langkah. Jika daftarnya sudah terurut, kita bisa jauh lebih cepat: lihat bagian tengah, lalu buang separuh daftar yang pasti tidak berisi jawabannya.

Simpan dua batas, kiri dan kanan. Selama kiri <= kanan, hitung tengah. Jika nilai tengah terlalu kecil, geser kiri ke tengah + 1. Jika terlalu besar, geser kanan ke tengah - 1. Banyak langkahnya tidak diketahui sebelumnya, jadi loopnya while.

Setiap langkah membuang separuh data, jadi 1.000 data cukup dicari dalam paling banyak 10 langkah, dan 1 juta data dalam 20 langkah. Inilah alasan database dan kamus memakai data terurut.

Visual di bawah mencari harga di 7 data. Coba input 5000, 35000, atau 9000 (tidak ada di daftar) dan perhatikan bagaimana kiri dan kanan bergerak.

JAVASCRIPT
const harga = [5000, 8000, 12000, 15000, 20000, 27000, 35000];
const cari = 20000;
let kiri = 0, kanan = harga.length - 1, langkah = 0, posisi = -1;
// WHILE: berhenti saat ketemu atau ruang pencarian habis
while (kiri <= kanan) {
  langkah++;
  const tengah = Math.floor((kiri + kanan) / 2);
  console.log(`Langkah ${langkah}: cek indeks ${tengah} (${harga[tengah]})`);
  if (harga[tengah] === cari) { posisi = tengah; break; }
  else if (harga[tengah] < cari) kiri = tengah + 1;
  else kanan = tengah - 1;
}
console.log(`Ketemu di indeks ${posisi} setelah ${langkah} langkah`);
KELUARAN
Langkah 1: cek indeks 3 (15000)
Langkah 2: cek indeks 5 (27000)
Langkah 3: cek indeks 4 (20000)
Ketemu di indeks 4 setelah 3 langkah
PSEUDOCODE
START
    DECLARE harga : ARRAY[7] OF INTEGER
    harga ← [5000, 8000, 12000, 15000, 20000, 27000, 35000]
    DECLARE cari, kiri, kanan, tengah, posisi : INTEGER
    INPUT cari
    kiri ← 0
    kanan ← 6
    posisi ← -1
    WHILE kiri <= kanan and posisi = -1 DO
        tengah ← Int((kiri + kanan) / 2)
        IF harga[tengah] = cari THEN
            posisi ← tengah
        ELSE
            IF harga[tengah] < cari THEN
                kiri ← tengah + 1
            ELSE
                kanan ← tengah - 1
            ENDIF
        ENDIF
    ENDWHILE
    OUTPUT "Posisi: ", posisi
END

Soal latihan

  1. Komputer menebak angka rahasia 73 di antara 1 sampai 100 dengan cara binary search. Tampilkan setiap tebakan.

    Petunjuk

    Sama seperti mencari di array terurut, hanya saja "array"-nya adalah rentang angka 1 sampai 100.

    Lihat jawaban
    JAVASCRIPT
    const rahasia = 73;
let bawah = 1, atas = 100;
while (true) {
  const tebak = Math.floor((bawah + atas) / 2);
  console.log("Tebak", tebak);
  if (tebak === rahasia) break;
  if (tebak < rahasia) bawah = tebak + 1;
  else atas = tebak - 1;
}

  2. Berapa langkah paling banyak yang dibutuhkan binary search untuk 1.000 data? Hitung dengan membagi dua terus sampai habis.

    Petunjuk

    Selama masih ada data (n > 0), bagi dua dan tambah 1 langkah. Ini while karena jumlah langkah adalah hal yang dicari.

    Lihat jawaban
    JAVASCRIPT
    let n = 1000, langkah = 0;
while (n > 0) {
  n = Math.floor(n / 2);
  langkah++;
}
console.log("Maksimal", langkah, "langkah");

Poin penting

  • Binary search hanya untuk data terurut.
  • Setiap langkah membuang separuh ruang pencarian.
  • Berhenti saat ketemu atau kiri > kanan.
