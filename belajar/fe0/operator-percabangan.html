Operator & percabangan

Buka versi interaktif

Bandingkan nilai dengan === (sama nilai dan tipe) dan !==. Hindari == karena mengubah tipe diam-diam: "0" == 0 bernilai true.

Percabangan memakai if / else if / else, atau operator ternary kondisi ? a : b untuk pilihan singkat. Operator logika: && (dan), || (atau), ! (tidak). Operator ?? memberi nilai cadangan hanya jika nilainya null atau undefined.

HTML
<p>Lihat panel Konsol.</p>
JAVASCRIPT
const total = 135000;
const member = true;

let ongkir;
if (total >= 100000) {
  ongkir = 0;
} else if (member) {
  ongkir = 5000;
} else {
  ongkir = 15000;
}
console.log("Ongkir:", ongkir);

const label = total > 200000 ? "besar" : "biasa";
console.log("Pesanan", label);

console.log("0" == 0, "0" === 0);
const kupon = null;
console.log(kupon ?? "tanpa kupon");

Tantangan

  1. Ubah total menjadi 80000 dan pastikan konsol mencetak "Ongkir: 5000".

Kode pemula vs kode rapi

|| dan ?? berbeda saat nilainya 0

|| menganggap 0 dan "" sebagai kosong, sehingga stok 0 malah diganti 10. ?? hanya mengganti null dan undefined. Gunakan juga ===, bukan ==, agar 0 == "" tidak dianggap sama.

KODE PEMULA
const stok = 0;
const tampil = stok || 10;
console.log(tampil);
console.log(0 == "");
KODE RAPI (BEST PRACTICE)
const stok = 0;
const tampil = stok ?? 10;
console.log(tampil);
console.log(0 === "");

Poin penting

  • Pakai === dan !==, hindari ==.
  • Ternary untuk pilihan singkat.
  • ?? memberi cadangan untuk null/undefined.
