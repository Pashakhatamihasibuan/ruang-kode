Modul: import & export

Buka versi interaktif

Saat kode bertambah, satu berkas besar sulit dirawat. Modul memecahnya: setiap berkas punya tanggung jawab sendiri dan hanya membagikan yang perlu dengan export.

Ada dua jenis ekspor. Named export (export function hitungTotal) diimpor dengan nama yang sama di dalam kurung kurawal. Default export hanya satu per berkas dan boleh diberi nama apa saja saat diimpor.

Di browser, muat berkas utama dengan <script type="module">. Modul otomatis berjalan dalam mode ketat, variabelnya tidak bocor ke global, dan dijalankan setelah HTML selesai dibaca.

JAVASCRIPT
// berkas: rupiah.js
export function rupiah(angka) {
  return "Rp" + angka.toLocaleString("id-ID");
}
export const PPN = 0.11;

// berkas: keranjang.js
import { rupiah, PPN } from "./rupiah.js";
export default function total(barang) {
  const sub = barang.reduce((t, b) => t + b.harga * b.qty, 0);
  return rupiah(Math.round(sub * (1 + PPN)));
}

// berkas: main.js
import hitungTotal from "./keranjang.js";
console.log(hitungTotal([{ harga: 85_000, qty: 2 }]));  // Rp188.700

<!-- index.html -->
<script type="module" src="main.js"></script>

Poin penting

  • export membagikan fungsi atau nilai dari berkas.
  • Named export diimpor dengan { nama }.
  • Default export satu per berkas, nama bebas.
  • Browser: <script type="module">.
