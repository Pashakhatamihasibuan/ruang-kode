Array & objek

Buka versi interaktif

Array menyimpan daftar berurutan: ["kopi", "teh"]. Objek menyimpan pasangan kunci-nilai: { nama: "Kopi", harga: 85000 }. Data dari server hampir selalu berbentuk array berisi objek.

Metode array yang paling sering dipakai: map (ubah setiap elemen), filter (saring), reduce (ringkas jadi satu nilai), find, dan sort. Destructuring const { nama } = produk dan spread [...a, x] membuat kode ringkas.

HTML
<p>Lihat panel Konsol.</p>
JAVASCRIPT
const produk = [
  { nama: "Kopi Gayo", harga: 85000, stok: 40 },
  { nama: "Teh Melati", harga: 25000, stok: 120 },
  { nama: "Rendang Kaleng", harga: 75000, stok: 0 },
];

const tersedia = produk.filter(p => p.stok > 0);
const nama = tersedia.map(p => p.nama);
const totalStok = produk.reduce((jml, p) => jml + p.stok, 0);

console.log(nama);
console.log("Total stok:", totalStok);

const { harga } = produk[0];
const baru = [...produk, { nama: "Madu", harga: 120000, stok: 15 }];
console.log(harga, baru.length);

Tantangan

  1. Cetak array harga semua produk memakai map.

Kode pemula vs kode rapi

map, filter, dan reduce

Ketiga method ini mengganti loop dengan variabel penampung. Kodenya terbaca sebagai langkah: saring, ubah, jumlahkan.

KODE PEMULA
const keranjang = [{ nama: "Kopi", harga: 85000, qty: 1 }, { nama: "Teh", harga: 25000, qty: 0 }, { nama: "Gula", harga: 18000, qty: 2 }];
let total = 0;
for (let i = 0; i < keranjang.length; i++) {
  if (keranjang[i].qty > 0) {
    total = total + keranjang[i].harga * keranjang[i].qty;
  }
}
console.log(total);
KODE RAPI (BEST PRACTICE)
const keranjang = [{ nama: "Kopi", harga: 85_000, qty: 1 }, { nama: "Teh", harga: 25_000, qty: 0 }, { nama: "Gula", harga: 18_000, qty: 2 }];
const total = keranjang
  .filter((b) => b.qty > 0)
  .reduce((jml, b) => jml + b.harga * b.qty, 0);
console.log(total);
KELUARAN KEDUANYA
121000
Destructuring dan spread

Destructuring mengambil beberapa properti sekaligus, dan spread ... menyalin objek sambil mengubah sebagian isinya tanpa mengubah aslinya.

KODE PEMULA
const produk = { nama: "Kopi", harga: 85000, stok: 40 };
const nama = produk.nama;
const harga = produk.harga;
const baru = { nama: produk.nama, harga: produk.harga, stok: 39 };
console.log(nama, harga, baru, produk.stok);
KODE RAPI (BEST PRACTICE)
const produk = { nama: "Kopi", harga: 85_000, stok: 40 };
const { nama, harga } = produk;
const baru = { ...produk, stok: 39 };
console.log(nama, harga, baru, produk.stok);
KELUARAN KEDUANYA
Kopi 85000 { nama: 'Kopi', harga: 85000, stok: 39 } 40

Poin penting

  • Array berurutan, objek kunci-nilai.
  • map, filter, reduce, find adalah alat utama.
  • Destructuring dan spread meringkas kode.
