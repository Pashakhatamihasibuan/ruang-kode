Menangani error dengan try...catch

Buka versi interaktif

Program bisa gagal karena hal di luar kendali: data JSON rusak, koneksi putus, atau masukan pengguna salah. Tanpa penanganan, satu error menghentikan seluruh skrip dan halaman bisa macet.

try membungkus kode yang mungkin gagal, catch menerima objek error, dan finally selalu dijalankan, cocok untuk mematikan indikator memuat. Kamu juga bisa melempar error sendiri dengan throw new Error("pesan") saat data tidak masuk akal.

Tampilkan pesan yang dimengerti pengguna ("Data gagal dimuat, coba lagi"), dan simpan detail teknisnya di console.error untuk developer.

JAVASCRIPT
function bacaKeranjang(teks) {
  try {
    const data = JSON.parse(teks);
    if (!Array.isArray(data)) throw new Error("format keranjang salah");
    return data;
  } catch (err) {
    console.log("Gagal membaca keranjang:", err.message);
    return [];
  } finally {
    console.log("selesai memeriksa");
  }
}

console.log(bacaKeranjang('["kopi","teh"]'));
console.log(bacaKeranjang("{rusak"));
console.log(bacaKeranjang('{"kopi": 1}'));

Poin penting

  • try membungkus kode yang mungkin gagal.
  • catch menerima objek error (err.message).
  • finally selalu dijalankan.
  • throw untuk data yang tidak masuk akal.
