npm & package.json

Buka versi interaktif

npm (Node Package Manager) memasang pustaka buatan orang lain ke proyekmu. Pustaka tercatat di package.json, file daftar isi proyek, dan disimpan di folder node_modules yang tidak perlu ikut di-commit.

npm install nama memasang pustaka, npm install -D nama untuk alat pengembangan saja, dan npm run dev menjalankan skrip yang ditulis di bagian scripts. File package-lock.json mengunci versi persis agar semua anggota tim mendapat versi yang sama.

Untuk memulai proyek frontend modern, perintah npm create vite@latest menyiapkan kerangka lengkap dalam hitungan detik.

TERMINAL
$ npm create vite@latest toko-nusantara -- --template react
$ cd toko-nusantara
$ npm install
$ npm install -D vitest
$ npm run dev
  VITE ready in 312 ms
  ➜  Local:   http://localhost:5173/

Poin penting

  • package.json mencatat pustaka dan skrip.
  • node_modules tidak di-commit.
  • -D untuk alat pengembangan.
  • package-lock.json mengunci versi.
