FizzBuzz dan bilangan prima: break dan loop bersarang

Buka versi interaktif

FizzBuzz adalah soal wawancara klasik: untuk angka 1 sampai 15, tampilkan "Fizz" jika habis dibagi 3, "Buzz" jika habis dibagi 5, "FizzBuzz" jika habis dibagi keduanya, dan angkanya sendiri jika tidak. Rentangnya jelas, jadi pakai for. Jebakannya: cek kelipatan 15 lebih dulu, karena jika cek 3 duluan, angka 15 sudah keburu menjadi "Fizz".

Bilangan prima hanya habis dibagi 1 dan dirinya sendiri. Untuk setiap angka (loop luar), kita coba pembagi dari 2 (loop dalam). Begitu ketemu satu pembagi, angka itu pasti bukan prima, jadi break menghentikan loop dalam tanpa membuang waktu.

Pembagi cukup dicoba sampai akar angkanya (d * d <= x). Jika 36 = 4 × 9, salah satu faktornya pasti ≤ 6. Ini mengubah 1.000 percobaan menjadi sekitar 31. Variabel penanda isPrima mencatat apakah loop dalam pernah berhenti karena break.

Visual di bawah memeriksa satu angka dengan while dan penanda, karena Flowgorithm tidak punya break. Ganti inputnya, misalnya 91 atau 97, lalu jalankan.

JAVASCRIPT
// FizzBuzz: FOR karena rentangnya jelas (1 sampai 15)
const hasil = [];
for (let i = 1; i <= 15; i++) {
  if (i % 15 === 0) hasil.push("FizzBuzz");
  else if (i % 3 === 0) hasil.push("Fizz");
  else if (i % 5 === 0) hasil.push("Buzz");
  else hasil.push(i);
}
console.log(hasil.join(" "));

// Bilangan prima 2..30: FOR bersarang + break
const prima = [];
for (let x = 2; x <= 30; x++) {
  let isPrima = true;
  for (let d = 2; d * d <= x; d++) {
    if (x % d === 0) {
      isPrima = false;
      break;          // tidak perlu cek pembagi lain
    }
  }
  if (isPrima) prima.push(x);
}
console.log("Prima:", prima.join(" "));

PSEUDOCODE
START
    DECLARE x, d : INTEGER
    DECLARE prima : BOOLEAN
    INPUT x
    prima ← x >= 2
    d ← 2
    WHILE d * d <= x and prima DO
        IF x mod d = 0 THEN
            prima ← false
        ENDIF
        d ← d + 1
    ENDWHILE
    IF prima THEN
        OUTPUT x, " adalah prima"
    ELSE
        OUTPUT x, " bukan prima"
    ENDIF
END

Soal latihan

  1. Tampilkan tabel perkalian 1 sampai 5 dalam bentuk kotak (5 baris, 5 kolom).

    Petunjuk

    For luar untuk baris, for dalam untuk kolom. Keduanya punya batas yang jelas.

    Lihat jawaban
    JAVASCRIPT
    for (let i = 1; i <= 5; i++) {
  let baris = "";
  for (let j = 1; j <= 5; j++) {
    baris += String(i * j).padStart(4);
  }
  console.log(baris);
}

  2. Cari bilangan prima pertama yang lebih besar dari 100.

    Petunjuk

    Kita tidak tahu harus mencoba berapa angka, jadi loop luar memakai while. Pengecekan pembagi tetap memakai for dengan break.

    Lihat jawaban
    JAVASCRIPT
    let x = 101;
while (true) {
  let prima = true;
  for (let d = 2; d * d <= x; d++) {
    if (x % d === 0) { prima = false; break; }
  }
  if (prima) break;
  x++;
}
console.log("Prima pertama > 100:", x);

Poin penting

  • Urutan if penting: kondisi paling khusus dicek lebih dulu.
  • break menghentikan loop terdekat saat jawaban sudah pasti.
  • Pembagi prima cukup dicek sampai akar angkanya.

Cek pemahaman

Jika FizzBuzz mengecek "habis dibagi 3" lebih dulu, apa yang tampil untuk 15?

Jawaban: Fizz

Kondisi pertama yang benar langsung dipakai.

Pada loop bersarang, break menghentikan loop yang mana?

Jawaban: Loop terdekat yang membungkusnya

break hanya keluar dari satu tingkat loop.

Untuk mengecek apakah 97 prima, pembagi paling besar yang perlu dicoba adalah?

Jawaban: 9

9 × 9 = 81 ≤ 97, sedangkan 10 × 10 = 100 > 97.
