Perulangan: for, for...of & while

Buka versi interaktif

Perulangan menjalankan kode berulang kali. for klasik cocok saat kamu butuh nomor urut. for...of membaca isi array satu per satu dan lebih jarang salah karena tidak ada indeks yang perlu dijaga.

while dipakai saat jumlah putaran belum diketahui, misalnya menabung sampai target tercapai. Pastikan kondisinya suatu saat menjadi salah, kalau tidak program berputar selamanya.

break menghentikan perulangan, dan continue melompat ke putaran berikutnya. Untuk mengolah array menjadi array baru, method seperti map dan filter biasanya lebih rapi.

JAVASCRIPT
const keranjang = ["kopi", "teh", "gula"];

for (let i = 0; i < keranjang.length; i++) {
  console.log(`${i + 1}. ${keranjang[i]}`);
}

for (const barang of keranjang) {
  if (barang === "teh") continue;
  console.log("dikemas:", barang);
}

let tabungan = 0;
let minggu = 0;
while (tabungan < 100_000) {
  tabungan += 30_000;
  minggu++;
}
console.log(`Target tercapai di minggu ke-${minggu}: Rp${tabungan}`);
KELUARAN
1. kopi
2. teh
3. gula
dikemas: kopi
dikemas: gula
Target tercapai di minggu ke-4: Rp120000

Poin penting

  • for: saat butuh nomor urut.
  • for...of: membaca isi array tanpa indeks.
  • while: saat jumlah putaran belum diketahui.
  • break berhenti, continue melompat.
