Menerbitkan situs

Buka versi interaktif

Situs statis (HTML, CSS, JS) bisa diterbitkan gratis. GitHub Pages menerbitkan langsung dari repositori. Vercel, Netlify, dan Cloudflare Pages terhubung ke GitHub dan otomatis membangun ulang setiap kali kamu push.

Untuk proyek Vite, perintah npm run build menghasilkan folder dist berisi file siap terbit. Ruang Kode yang sedang kamu pakai diterbitkan dengan cara ini: push ke GitHub, Vercel membangun dan menerbitkan otomatis.

TERMINAL
$ npm run build
  dist/index.html          0.46 kB
  dist/assets/index.js   143.21 kB
$ git add .
$ git commit -m "Siap terbit"
$ git push
# Vercel mendeteksi push lalu menerbitkan ke https://toko-nusantara.vercel.app

Poin penting

  • GitHub Pages, Vercel, Netlify gratis untuk situs statis.
  • npm run build menghasilkan folder dist.
  • Deploy otomatis setiap push.
