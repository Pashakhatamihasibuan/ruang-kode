Menguji kode dengan Vitest

Buka versi interaktif

Tes otomatis memeriksa bahwa kodemu bekerja, dan terus bekerja setelah diubah. Vitest adalah test runner yang cepat dan menyatu dengan Vite.

Tes ditulis di file *.test.js: describe mengelompokkan, it atau test menulis satu kasus, dan expect(nilai).toBe(harapan) memeriksa hasil. Jalankan dengan npx vitest.

JAVASCRIPT
// harga.js
export const hargaAkhir = (harga, diskon = 0) => harga - harga * diskon;

// harga.test.js
import { describe, it, expect } from "vitest";
import { hargaAkhir } from "./harga.js";

describe("hargaAkhir", () => {
  it("tanpa diskon harga tetap", () => {
    expect(hargaAkhir(85000)).toBe(85000);
  });
  it("diskon 20%", () => {
    expect(hargaAkhir(85000, 0.2)).toBe(68000);
  });
});

/* $ npx vitest run
 ✓ harga.test.js (2 tests) 3ms
 Test Files  1 passed (1)
      Tests  2 passed (2) */

Poin penting

  • Tes mencegah bug lama muncul lagi.
  • describe, it, expect adalah pola dasar.
  • Jalankan tes sebelum push.
