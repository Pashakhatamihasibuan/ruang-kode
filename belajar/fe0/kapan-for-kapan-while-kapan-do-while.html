Kapan for, kapan while, kapan do-while

Buka versi interaktif

Semua loop bisa saling menggantikan, tetapi programmer yang baik memilih loop yang paling jujur menggambarkan niatnya. Pertanyaan kuncinya satu: apakah jumlah putarannya sudah diketahui sebelum loop dimulai?

Jika jumlahnya pasti (5 hari, 10 suku, setiap kursi 1 sampai 40), pakai for seperti for (let i = 0; i < n; i++). Jika yang diketahui hanya kondisi berhentinya (sampai saldo cukup, sampai data habis, sampai tidak ada pertukaran lagi), pakai while. Jika badan loop harus jalan minimal sekali sebelum dicek (menampilkan menu, meminta PIN), pakai do-while: do { ... } while (kondisi);.

Untuk membaca setiap isi koleksi tanpa butuh nomor indeks, pakai for-each: for (const k of daftar). Lebih ringkas dan tidak mungkin salah indeks (error klasik "off by one").

Pada contoh kode di bawah, keempat jenis loop dipakai sesuai kasusnya masing-masing. Tebak keluarannya dulu, lalu coba latihan memilih loop di visual interaktif.

JAVASCRIPT
// FOR: jumlah pengulangan sudah diketahui (5 hari)
let total = 0;
for (let hari = 1; hari <= 5; hari++) {
  total += 10000;
}
console.log("Tabungan 5 hari:", total);

// WHILE: berhenti saat kondisi tercapai, jumlah putaran belum diketahui
let saldo = 0, minggu = 0;
while (saldo < 75000) {
  saldo += 20000;
  minggu++;
}
console.log(`Target tercapai di minggu ke-${minggu}`);

// DO-WHILE: badan loop dijalankan minimal sekali
const pilihanUser = [2, 1, 0];
let i = 0, pilihan;
do {
  pilihan = pilihanUser[i++];
  console.log("Menu dipilih:", pilihan);
} while (pilihan !== 0);

// FOR...OF: membaca setiap isi array
for (const k of ["Medan", "Bandung", "Makassar"]) {
  console.log("Kirim ke", k);
}

Soal latihan

  1. Hitung mundur peluncuran roket: tampilkan 5, 4, 3, 2, 1 lalu "Meluncur!". Loop apa yang paling cocok?

    Petunjuk

    Awal dan akhir hitungan sudah pasti (5 sampai 1), jadi pakai for yang nilainya berkurang.

    Lihat jawaban
    JAVASCRIPT
    for (let detik = 5; detik >= 1; detik--) {
  console.log(detik);
}
console.log("Meluncur!");

  2. Galon diisi 3 liter setiap menit, mulai dari kosong. Berapa menit sampai isinya minimal 19 liter? Tampilkan menit dan isinya.

    Petunjuk

    Jumlah menit belum diketahui, yang diketahui hanya kondisi berhenti (isi ≥ 19). Itu tanda while.

    Lihat jawaban
    JAVASCRIPT
    let isi = 0, menit = 0;
while (isi < 19) {
  isi += 3;
  menit++;
}
console.log(`${menit} menit, isi ${isi} liter`);

Poin penting

  • Jumlah putaran diketahui → for.
  • Hanya kondisi berhenti yang diketahui → while.
  • Harus jalan minimal sekali → do-while.
  • Hanya membaca isi koleksi → for-each.
