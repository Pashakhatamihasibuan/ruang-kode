Mengambil data: fetch, JSON & async

Buka versi interaktif

Data dari server biasanya berbentuk JSON, teks yang mirip objek JavaScript. JSON.parse mengubah teks menjadi objek, JSON.stringify sebaliknya.

fetch(url) meminta data dan mengembalikan Promise, janji hasil yang datang nanti. Dengan async/await, kode menunggu hasil tanpa membekukan halaman. Bungkus dengan try/catch untuk menangani gagal jaringan.

Contoh di bawah memakai server tiruan agar bisa berjalan di mana saja; polanya sama persis dengan fetch sungguhan.

HTML
<button id="muat">Muat produk</button><ul id="hasil"></ul>
JAVASCRIPT
// server tiruan: membalas setelah 600 ms
const fetchTiruan = () => new Promise(res => setTimeout(() =>
  res({ ok: true, json: async () => JSON.parse('[{"nama":"Kopi Gayo","harga":85000},{"nama":"Teh Melati","harga":25000}]') }), 600));

async function muatProduk() {
  console.log("Meminta data...");
  try {
    const res = await fetchTiruan("/api/produk");
    if (!res.ok) throw new Error("Gagal memuat");
    const data = await res.json();
    console.log("Diterima", data.length, "produk");
    document.querySelector("#hasil").innerHTML = "";
    data.forEach(p => {
      const li = document.createElement("li");
      li.textContent = p.nama + " - Rp" + p.harga.toLocaleString("id-ID");
      document.querySelector("#hasil").append(li);
    });
  } catch (err) {
    console.log("Error:", err.message);
  }
}
document.querySelector("#muat").addEventListener("click", muatProduk);
console.log("Kode di bawah fetch tetap jalan duluan.");

Tantangan

  1. Klik tombol "Muat produk" sampai daftar terisi.

Poin penting

  • JSON adalah format tukar data.
  • fetch mengembalikan Promise.
  • async/await membuat kode asinkron terbaca berurutan.
  • Selalu tangani error dengan try/catch.
