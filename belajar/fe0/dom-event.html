DOM & event

Buka versi interaktif

DOM (Document Object Model) adalah HTML dalam bentuk objek yang bisa diubah JavaScript. Ambil elemen dengan document.querySelector(".kelas"), ubah teksnya dengan textContent, dan ubah gaya dengan classList.add/remove/toggle.

Event adalah kejadian seperti klik, ketikan, atau kirim form. Daftarkan pendengarnya dengan elemen.addEventListener("click", fungsi). Buat elemen baru dengan document.createElement lalu append.

HTML
<h3>Daftar belanja</h3>
<form id="f"><input id="isi" placeholder="Contoh: Kopi Gayo" aria-label="Barang"> <button>Tambah</button></form>
<ul id="daftar"></ul>
<p id="jumlah">0 barang</p>
CSS
li{cursor:pointer}li.selesai{text-decoration:line-through;color:#999}body{font:14px sans-serif}
JAVASCRIPT
const form = document.querySelector("#f");
const daftar = document.querySelector("#daftar");

form.addEventListener("submit", e => {
  e.preventDefault();                       // jangan muat ulang halaman
  const isi = document.querySelector("#isi");
  if (!isi.value.trim()) return;
  const li = document.createElement("li");
  li.textContent = isi.value;
  li.addEventListener("click", () => li.classList.toggle("selesai"));
  daftar.append(li);
  isi.value = "";
  document.querySelector("#jumlah").textContent = daftar.children.length + " barang";
});

Tantangan

  1. Tambahkan tiga barang lewat form, lalu klik salah satunya hingga tercoret.

Poin penting

  • querySelector mengambil elemen.
  • textContent dan classList mengubah isi dan gaya.
  • addEventListener mendaftarkan event.
  • preventDefault mencegah form memuat ulang halaman.
