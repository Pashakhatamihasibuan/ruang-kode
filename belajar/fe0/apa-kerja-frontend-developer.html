Apa kerja frontend developer?

Buka versi interaktif

Frontend developer membangun bagian situs atau aplikasi yang dilihat dan disentuh pengguna. Tiga bahan utamanya: HTML untuk struktur dan isi, CSS untuk tampilan, dan JavaScript untuk perilaku (apa yang terjadi saat tombol ditekan).

Di atas tiga bahan itu ada alat kerja: Git dan GitHub untuk menyimpan riwayat kode dan bekerja sama, npm untuk memasang pustaka, framework seperti React untuk membangun antarmuka yang rumit, dan Tailwind untuk menata gaya lebih cepat.

Jalur ini mengikuti urutan roadmap frontend pemula: HTML, CSS, JavaScript, Git, GitHub, npm, Tailwind, React, lalu Vitest untuk pengujian. Di akhir, kamu membangun dan menerbitkan satu proyek sendiri.

Poin penting

  • HTML = struktur, CSS = tampilan, JavaScript = perilaku.
  • Git dan GitHub untuk riwayat kode dan kolaborasi.
  • npm memasang pustaka; React membangun UI; Tailwind menata gaya.
  • Belajar paling cepat dengan membuat proyek kecil.
