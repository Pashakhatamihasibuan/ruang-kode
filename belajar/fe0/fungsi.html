Fungsi

Buka versi interaktif

Fungsi membungkus langkah agar bisa dipakai ulang. Ada dua bentuk umum: deklarasi function hitung(a, b) { ... } dan arrow function const hitung = (a, b) => a + b.

Parameter bisa punya nilai bawaan: (harga, diskon = 0) => .... Fungsi adalah nilai biasa, jadi bisa dikirim ke fungsi lain (callback), misalnya ke setTimeout atau addEventListener.

HTML
<p>Lihat panel Konsol.</p>
JAVASCRIPT
function rupiah(n) {
  return "Rp" + n.toLocaleString("id-ID");
}
const hargaAkhir = (harga, diskon = 0) => harga - harga * diskon;

console.log(rupiah(85000));
console.log(rupiah(hargaAkhir(85000, 0.2)));
console.log(rupiah(hargaAkhir(25000)));

// fungsi sebagai argumen (callback)
setTimeout(() => console.log("Pesan ini muncul 1 detik kemudian"), 1000);

Tantangan

  1. Buat fungsi pajak(n) yang mengembalikan 11% dari n, lalu cetak pajak(100000) (hasilnya 11000).

Poin penting

  • function deklarasi dan arrow function.
  • Parameter bawaan: (x = 0).
  • Fungsi bisa dikirim sebagai callback.

Cek pemahaman

Bentuk arrow function yang benar?

Jawaban: const f = (a, b) => a + b

Parameter lebih dari satu dalam kurung.
