Korelasi

Buka versi interaktif

Koefisien korelasi Pearson berkisar −1 sampai 1: mendekati 1 berarti naik bersama, mendekati −1 berlawanan arah, sekitar 0 tidak ada hubungan linear.

df.corr() membuat matriks korelasi antar semua kolom angka; biasanya ditampilkan sebagai heatmap.

Korelasi bukan sebab-akibat. Penjualan es krim dan kasus tenggelam sama-sama naik di musim panas karena faktor ketiga: cuaca.

PYTHON
import pandas as pd

df = pd.DataFrame({
    "iklan_juta": [1, 2, 3, 4, 5, 6],
    "pengunjung": [120, 190, 260, 300, 390, 450],
    "hari_hujan": [9, 7, 8, 6, 8, 7],
})
print(df.corr().round(2))
KELUARAN
            iklan_juta  pengunjung  hari_hujan
iklan_juta        1.00        1.00       -0.46
pengunjung        1.00        1.00       -0.41
hari_hujan       -0.46       -0.41        1.00

Poin penting

  • Pearson: −1 sampai 1.
  • corr() → matriks, tampilkan sebagai heatmap.
  • Korelasi ≠ kausalitas.

Cek pemahaman

Korelasi iklan dan pengunjung mendekati 1 membuktikan iklan menyebabkan kunjungan?

Jawaban: Tidak, perlu eksperimen seperti A/B test

Korelasi tinggi belum membuktikan sebab.
