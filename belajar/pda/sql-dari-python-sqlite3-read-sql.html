SQL dari Python: sqlite3 & read_sql

Buka versi interaktif

Banyak data perusahaan tinggal di database. Modul sqlite3 bawaan Python cukup untuk berlatih; di kantor biasanya memakai SQLAlchemy untuk terhubung ke PostgreSQL atau MySQL.

pd.read_sql(query, koneksi) menjalankan query lalu mengembalikan DataFrame. Biarkan database melakukan penyaringan dan agregasi berat; pandas untuk langkah lanjutan.

DuckDB adalah database analitik di dalam proses yang bisa menjalankan SQL langsung ke berkas Parquet atau DataFrame, sangat cepat untuk jutaan baris.

PYTHON
import sqlite3
import pandas as pd

con = sqlite3.connect(":memory:")
con.executescript("""
CREATE TABLE pesanan(id INTEGER, kota TEXT, total INTEGER);
INSERT INTO pesanan VALUES (1,'Jakarta',255000),(2,'Bandung',250000),
  (3,'Jakarta',375000),(4,'Medan',340000);
""")
q = "SELECT kota, COUNT(*) AS n, SUM(total) AS omzet FROM pesanan GROUP BY kota ORDER BY omzet DESC"
df = pd.read_sql(q, con)
print(df)
print(df["omzet"].sum())
KELUARAN

0  Jakarta  2  630000

Poin penting

  • sqlite3 untuk latihan, SQLAlchemy untuk produksi.
  • read_sql → DataFrame.
  • DuckDB: SQL cepat untuk berkas lokal.
