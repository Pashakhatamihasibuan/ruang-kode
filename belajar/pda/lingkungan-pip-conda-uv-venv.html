Lingkungan: pip, conda, uv & venv

Buka versi interaktif

Setiap proyek analisis sebaiknya punya lingkungan virtual sendiri agar versi pandas proyek A tidak bertabrakan dengan proyek B.

venv + pip adalah bawaan Python. conda populer di dunia data karena juga mengelola pustaka non-Python. uv adalah pengelola paket baru yang sangat cepat dan kini banyak dipakai.

Catat dependensi di requirements.txt atau pyproject.toml agar rekan bisa mengulang analisismu persis.

TERMINAL
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install pandas matplotlib seaborn jupyterlab
pip freeze > requirements.txt

# alternatif cepat dengan uv
uv venv && uv pip install pandas seaborn

jupyter lab

Poin penting

  • Satu proyek, satu lingkungan.
  • venv+pip bawaan; conda; uv cepat.
  • Simpan daftar dependensi.
