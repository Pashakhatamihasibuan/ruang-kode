Membaca CSV, Excel, JSON & web

Buka versi interaktif

pd.read_csv adalah pintu masuk paling umum. Parameter penting: sep (pemisah, CSV Indonesia sering memakai titik koma), decimal, parse_dates, dan usecols.

Sumber lain: read_excel (butuh openpyxl), read_json, read_parquet (format kolom yang cepat dan hemat), read_sql. Untuk API, ambil dengan requests.get(url).json() lalu pd.json_normalize.

Contoh di bawah membaca CSV dari teks dengan io.StringIO, persis seperti membaca berkas.

PYTHON
import io
import pandas as pd

csv = """tanggal;kota;omzet
2024-10-01;Jakarta;255000,5
2024-10-02;Bandung;250000
2024-10-03;Surabaya;170000"""

df = pd.read_csv(io.StringIO(csv), sep=";", decimal=",", parse_dates=["tanggal"])
print(df)
print(df["tanggal"].dt.day_name().tolist())

data_api = [{"id": 1, "kota": {"nama": "Medan", "prov": "Sumut"}},
            {"id": 2, "kota": {"nama": "Bogor", "prov": "Jabar"}}]
print(pd.json_normalize(data_api))

Poin penting

  • read_csv: sep, decimal, parse_dates, usecols.
  • read_excel, read_json, read_parquet, read_sql.
  • json_normalize untuk JSON bersarang dari API.

Cek pemahaman

CSV dari Excel Indonesia memakai ; dan koma desimal. Parameter yang perlu?

Jawaban: sep=";", decimal=","

Pengaturan regional memengaruhi format ekspor.
