Polars, Dask & PySpark

Buka versi interaktif

Saat data tidak muat di memori atau pandas terlalu lambat: Polars (DataFrame berbasis Rust, multi-core, lazy), Dask (pandas yang dipecah per bagian), dan PySpark (klaster banyak mesin).

Simpan data analitik dalam Parquet: kolom terkompresi, membawa tipe data, dan jauh lebih cepat dibaca daripada CSV.

Analisis yang dijalankan rutin dijadikan pipeline terjadwal dengan Airflow atau Prefect. Detailnya ada di jalur Data Engineer.

PYTHON
import polars as pl

hasil = (
    pl.scan_parquet("penjualan_2024/*.parquet")   # lazy, belum dibaca
      .filter(pl.col("status") == "selesai")
      .group_by("kota")
      .agg(pl.col("omzet").sum().alias("omzet"))
      .sort("omzet", descending=True)
      .collect()                                   # baru dieksekusi
)
print(hasil.head())

Poin penting

  • Polars: cepat, lazy, multi-core.
  • Dask/Spark untuk data lebih besar dari memori.
  • Parquet > CSV untuk analitik.
