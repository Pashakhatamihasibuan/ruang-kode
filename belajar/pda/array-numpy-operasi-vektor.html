Array NumPy & operasi vektor

Buka versi interaktif

ndarray adalah array angka bertipe sama yang disimpan rapat di memori. Operasi pada array berlaku untuk semua elemen sekaligus (vektorisasi), puluhan kali lebih cepat daripada perulangan for biasa.

Atribut penting: shape (ukuran tiap dimensi), dtype (tipe elemen), ndim (jumlah dimensi). Broadcasting memungkinkan array berukuran berbeda dioperasikan, misalnya matriks dikali vektor.

Ubah contoh di bawah, misalnya ganti diskon menjadi 0.2, lalu jalankan.

PYTHON
import numpy as np

harga = np.array([85000, 25000, 15000, 120000])
jumlah = np.array([3, 10, 25, 1])

omzet = harga * jumlah          # per elemen, tanpa for
print(omzet)
print("total:", omzet.sum())

diskon = 0.1
print(harga * (1 - diskon))

stok = np.array([[40, 120], [200, 15]])
print(stok.shape, stok.ndim, stok.dtype)
print(stok + np.array([10, 0]))  # broadcasting per kolom

Poin penting

  • Operasi vektor = tanpa for, jauh lebih cepat.
  • shape, ndim, dtype.
  • Broadcasting menyesuaikan ukuran.

Cek pemahaman

np.array([1,2,3]) * 2 menghasilkan?

Jawaban: [2 4 6]

Operasi berlaku per elemen. Pada list Python, hasilnya diulang.
