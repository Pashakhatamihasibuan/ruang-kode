Memilih grafik yang tepat

Buka versi interaktif

Grafik dipilih dari pertanyaannya. Membandingkan kategori: batang. Tren waktu: garis. Distribusi: histogram atau boxplot. Hubungan dua angka: scatter. Komposisi: batang bertumpuk (pie hanya untuk 2-3 bagian).

Matplotlib adalah fondasi: fig, ax = plt.subplots() lalu ax.bar, ax.plot. Seaborn di atasnya memberi grafik statistik dengan satu baris: sns.histplot, sns.boxplot, sns.heatmap.

Coba visualisasi di atas: pilih pertanyaan, lihat grafik yang disarankan.

PYTHON
import matplotlib.pyplot as plt
import seaborn as sns

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
per_kota.plot.barh(y="omzet", ax=axes[0], legend=False)
axes[0].set_title("Omzet per kota (Rp)")
axes[0].set_xlabel("")

sns.histplot(data=penjualan, x="jumlah", bins=8, ax=axes[1])
axes[1].set_title("Sebaran jumlah per transaksi")

fig.tight_layout()
fig.savefig("ringkasan.png", dpi=150)

Soal latihan

  1. Pilih jenis grafik untuk: (a) omzet 12 bulan, (b) omzet 5 cabang, (c) sebaran umur pelanggan, (d) hubungan diskon dan jumlah beli, (e) gaji per divisi.

    Petunjuk

    Tren: garis; bandingkan: batang; distribusi: histogram; hubungan: scatter; sebaran antargrup: boxplot.

    Lihat jawaban
    CONTOH

(b) batang horizontal, diurutkan
(c) histogram

(e) boxplot per divisi

  2. Buat grafik batang horizontal omzet per kota yang diurutkan, dengan judul yang menyampaikan temuan.

    Petunjuk

    sort_values lalu plot.barh; judul berupa kalimat temuan.

    Lihat jawaban
    PYTHON
    import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import pandas as pd

omzet = pd.Series({"Medan": 66, "Bandung": 24, "Jakarta": 135}).sort_values()
fig, ax = plt.subplots(figsize=(6, 3))
omzet.plot.barh(ax=ax, color="#0B6FA4")
ax.set_title("Jakarta menyumbang 60% omzet bulan ini")
ax.set_xlabel("Omzet (ribu Rp)")
fig.tight_layout()
fig.savefig("omzet_kota.png", dpi=150)
print(omzet.idxmax(), round(omzet.max() / omzet.sum() * 100))
    KELUARAN
    Jakarta 60

Poin penting

  • Judul menjawab pertanyaan; buang hiasan.
