Deret waktu: resample & rolling

Buka versi interaktif

Data transaksi harian sering perlu diringkas per minggu atau per bulan. Jadikan kolom tanggal sebagai indeks, lalu resample("W") atau resample("ME") mengelompokkan berdasarkan periode waktu, mirip groupby untuk tanggal.

rolling(3) membuat jendela bergeser, misalnya rata-rata 3 hari terakhir. Rata-rata bergerak menghaluskan naik-turun harian sehingga tren lebih mudah terlihat. Tiga baris pertama bernilai kosong karena jendelanya belum penuh, kecuali kamu menetapkan min_periods.

pct_change() menghitung perubahan persen dari periode sebelumnya, berguna untuk melihat pertumbuhan.

PYTHON
import pandas as pd
df = pd.DataFrame({"tanggal": pd.date_range("2024-01-01", periods=10, freq="D"), "omzet": [120, 95, 130, 88, 150, 101, 115, 99, 140, 105]})
harian = df.set_index("tanggal")["omzet"]
print(harian.resample("W").sum().to_string())
print(harian.rolling(3).mean().round(1).tolist())
print((harian.pct_change() * 100).round(1).head(4).tolist())

Poin penting

  • Tanggal sebagai indeks, lalu resample per periode.
  • rolling(n) untuk jendela bergeser.
  • Rata-rata bergerak menghaluskan data harian.
  • pct_change() untuk pertumbuhan.
