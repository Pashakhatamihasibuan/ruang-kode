Memilih & menyaring: loc, iloc, query

Buka versi interaktif

df["kolom"] memilih satu kolom, df[["a","b"]] beberapa kolom.

loc memilih berdasarkan label dan kondisi: df.loc[df["kota"]=="Jakarta", ["produk","jumlah"]]. iloc berdasarkan posisi: df.iloc[0:3].

query menulis kondisi seperti kalimat: df.query("jumlah >= 5 and kota != 'Medan'"). isin untuk daftar nilai.

PYTHON
import pandas as pd
penjualan = pd.DataFrame({
    "tanggal": ["2024-10-01","2024-10-01","2024-10-02","2024-10-03","2024-10-03","2024-10-04","2024-10-05","2024-10-05"],
    "kota": ["Jakarta","Bandung","Jakarta","Surabaya","Bandung","Jakarta","Medan","Surabaya"],
    "produk": ["Kopi Gayo","Teh Melati","Keripik","Kopi Gayo","Madu Hutan","Teh Melati","Kopi Gayo","Keripik"],
    "jumlah": [3, 10, 25, 2, 1, 6, 4, 30],
    "harga": [85000, 25000, 15000, 85000, 120000, 25000, 85000, 15000],
})

print(penjualan.loc[penjualan["kota"] == "Jakarta", ["produk", "jumlah"]])
print(penjualan.iloc[0:2, 1:3])
print(penjualan.query("jumlah >= 10")[["kota", "produk", "jumlah"]])
print(penjualan[penjualan["produk"].isin(["Madu Hutan", "Keripik"])].shape[0])

Poin penting

  • loc = label/kondisi; iloc = posisi.
  • query untuk kondisi yang mudah dibaca.
  • isin untuk beberapa nilai.
