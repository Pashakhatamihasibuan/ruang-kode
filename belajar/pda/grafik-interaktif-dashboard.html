Grafik interaktif & dashboard

Buka versi interaktif

Plotly Express membuat grafik interaktif (hover, zoom) dengan sintaks ringkas: px.line(df, x="tanggal", y="omzet", color="kota").

Streamlit mengubah skrip Python menjadi aplikasi web dashboard tanpa HTML. Dash (dari Plotly) lebih fleksibel untuk aplikasi besar.

Untuk dashboard bisnis yang dipakai banyak orang, tim sering memilih Power BI, Tableau, atau Looker; lihat jalur BI Analyst.

PYTHON
# app.py  -> jalankan: streamlit run app.py
import streamlit as st
import pandas as pd
import plotly.express as px

df = pd.read_csv("penjualan.csv", parse_dates=["tanggal"])
kota = st.multiselect("Kota", sorted(df["kota"].unique()), default=["Jakarta"])
pilih = df[df["kota"].isin(kota)]

st.metric("Total omzet", f"Rp {pilih['omzet'].sum():,.0f}".replace(",", "."))
st.plotly_chart(px.line(pilih, x="tanggal", y="omzet", color="kota"))

Poin penting

  • Plotly untuk grafik interaktif.
  • Streamlit: skrip → dashboard web.
  • Dashboard organisasi: Power BI, Tableau, Looker.
