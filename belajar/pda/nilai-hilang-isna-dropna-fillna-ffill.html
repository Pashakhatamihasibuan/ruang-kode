Python Analisis Data · Modul 5 · Konsep & kode

Nilai hilang: isna, dropna, fillna, ffill

Buka versi interaktif

Data nyata hampir selalu bolong. Hitung dulu dengan df.isna().sum(), lalu putuskan: buang baris (dropna) jika sedikit dan acak, atau isi (fillna) dengan nilai masuk akal seperti median atau "Tidak diketahui".

Untuk data berurutan waktu, ffill mengisi dengan nilai sebelumnya (misalnya harga terakhir yang diketahui), bfill dengan nilai sesudahnya.

Catat setiap keputusan pembersihan; cara mengisi nilai hilang bisa mengubah kesimpulan.

PYTHON
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "kota": ["Jakarta", None, "Bandung", "Medan", None],
    "umur": [24, 31, np.nan, 45, 29],
    "harga_kopi": [85000, np.nan, np.nan, 90000, 88000],
})
print(df.isna().sum())
print(df.dropna().shape)

df["kota"] = df["kota"].fillna("Tidak diketahui")
df["umur"] = df["umur"].fillna(df["umur"].median())
df["harga_kopi"] = df["harga_kopi"].ffill()
print(df)

Soal latihan

  1. Hitung nilai kosong per kolom, isi kota kosong dengan "Tidak diketahui" dan harga kosong dengan median, lalu buang baris tanpa produk.

    Petunjuk

    isna().sum(), fillna({...}), dropna(subset=[...]).

    Lihat jawaban
    PYTHON
    import numpy as np
import pandas as pd

df = pd.DataFrame({
    "produk": ["Kopi", "Teh", None, "Susu"],
    "kota": ["Medan", None, "Bandung", "Medan"],
    "harga": [18000, np.nan, 12000, 15000],
})
print(df.isna().sum().to_dict())
df = df.fillna({"kota": "Tidak diketahui", "harga": df["harga"].median()})
df = df.dropna(subset=["produk"])
print(df)
    KELUARAN

0   Kopi            Medan  18000.0
1    Teh  Tidak diketahui  15000.0
3   Susu            Medan  15000.0

  2. Data suhu sensor per jam punya jam yang kosong. Isi dengan nilai sebelumnya (ffill) dan dengan interpolasi, lalu bandingkan.

    Petunjuk

    ffill() menyalin nilai terakhir; interpolate() menarik garis lurus.

    Lihat jawaban
    PYTHON
    import numpy as np
import pandas as pd

suhu = pd.Series([26.0, np.nan, np.nan, 29.0])
print(suhu.ffill().tolist())
print(suhu.interpolate().tolist())
    KELUARAN
    [26.0, 26.0, 26.0, 29.0]
[26.0, 27.0, 28.0, 29.0]

Poin penting

  • Hitung dulu: isna().sum().
  • dropna jika sedikit; fillna jika masuk akal.
  • ffill/bfill untuk deret waktu.
