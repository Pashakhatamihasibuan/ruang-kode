Nilai hilang: isna, dropna, fillna, ffill

Buka versi interaktif

Data nyata hampir selalu bolong. Hitung dulu dengan df.isna().sum(), lalu putuskan: buang baris (dropna) jika sedikit dan acak, atau isi (fillna) dengan nilai masuk akal seperti median atau "Tidak diketahui".

Untuk data berurutan waktu, ffill mengisi dengan nilai sebelumnya (misalnya harga terakhir yang diketahui), bfill dengan nilai sesudahnya.

Catat setiap keputusan pembersihan; cara mengisi nilai hilang bisa mengubah kesimpulan.

PYTHON
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "kota": ["Jakarta", None, "Bandung", "Medan", None],
    "umur": [24, 31, np.nan, 45, 29],
    "harga_kopi": [85000, np.nan, np.nan, 90000, 88000],
})
print(df.isna().sum())
print(df.dropna().shape)

df["kota"] = df["kota"].fillna("Tidak diketahui")
df["umur"] = df["umur"].fillna(df["umur"].median())
df["harga_kopi"] = df["harga_kopi"].ffill()
print(df)

Poin penting

  • Hitung dulu: isna().sum().
  • dropna jika sedikit; fillna jika masuk akal.
  • ffill/bfill untuk deret waktu.
