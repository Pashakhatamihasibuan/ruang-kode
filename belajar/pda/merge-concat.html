merge & concat

Buka versi interaktif

pd.merge menggabungkan dua tabel berdasarkan kunci, persis seperti JOIN di SQL: how="inner", "left", "right", "outer".

pd.concat menumpuk tabel berbentuk sama, misalnya penjualan Oktober dan November.

Selalu periksa jumlah baris sebelum dan sesudah merge. Kunci yang tidak unik akan melipatgandakan baris tanpa peringatan; parameter validate="many_to_one" membantu menangkapnya.

PYTHON
import pandas as pd

pesanan = pd.DataFrame({"id": [101, 102, 103, 104], "pelanggan_id": [1, 2, 1, 9], "total": [255000, 250000, 375000, 90000]})
pelanggan = pd.DataFrame({"pelanggan_id": [1, 2, 3], "nama": ["Andi", "Budi", "Citra"]})

print(pd.merge(pesanan, pelanggan, on="pelanggan_id", how="left", validate="many_to_one"))

okt = pd.DataFrame({"bulan": ["Okt"], "omzet": [1_200_000]})
nov = pd.DataFrame({"bulan": ["Nov"], "omzet": [1_450_000]})
print(pd.concat([okt, nov], ignore_index=True))

Poin penting

  • merge = JOIN (inner, left, right, outer).
  • concat = tumpuk tabel.
  • Periksa jumlah baris; pakai validate.
