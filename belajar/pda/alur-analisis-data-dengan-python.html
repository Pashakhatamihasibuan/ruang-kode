Alur analisis data dengan Python

Buka versi interaktif

Analisis data hampir selalu mengikuti alur yang sama: tanya (pertanyaan bisnis yang jelas), kumpulkan (CSV, Excel, database, API), bersihkan (nilai hilang, duplikat, format), eksplorasi (statistik, grafik), simpulkan, lalu komunikasikan.

Analis Python biasanya bekerja di notebook: JupyterLab di komputer sendiri, Google Colab di browser tanpa instalasi, atau VS Code dengan ekstensi Jupyter. Notebook menyimpan kode, hasil, grafik, dan catatan dalam satu berkas.

Pustaka inti: NumPy (array angka), pandas (tabel), Matplotlib/Seaborn/Plotly (grafik), SciPy/scikit-learn (statistik dan model). Di kursus ini contoh pandas dijalankan langsung di browser.

CONTOH
Pertanyaan : kota mana yang paling banyak membeli kopi bulan ini?
Data       : penjualan.csv (ekspor kasir), pelanggan dari database
Bersihkan  : tanggal teks -> datetime, kota kosong, transaksi ganda
Eksplorasi : total per kota, tren harian, outlier
Simpulan   : Jakarta 41% omzet kopi, naik 12% dari bulan lalu
Komunikasi : 1 grafik batang + 3 kalimat untuk manajer

Poin penting

  • Tanya → kumpulkan → bersihkan → eksplorasi → simpulkan → komunikasikan.
  • Notebook: Jupyter, Colab, VS Code.
  • NumPy, pandas, Matplotlib/Seaborn, SciPy/scikit-learn.
