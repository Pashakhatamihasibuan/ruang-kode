Membaca file besar per potongan

Buka versi interaktif

File CSV berukuran beberapa gigabyte bisa melebihi memori laptop. pd.read_csv(..., chunksize=n) membaca file per potongan n baris, sehingga kamu bisa mengolah lalu membuang setiap potongan.

Polanya: hitung ringkasan per potongan, simpan di list, lalu gabungkan di akhir. Untuk jumlah dan hitungan, menjumlahkan hasil per potongan memberi hasil yang sama dengan membaca seluruh file.

Hemat memori juga dengan usecols (hanya kolom yang perlu) dan dtype yang tepat, misalnya category untuk kolom kota yang nilainya berulang. Untuk data yang sangat besar, pertimbangkan Polars atau DuckDB.

PYTHON
import pandas as pd, io
csv = "kota,total\n" + "\n".join(f"{k},{t}" for k, t in
       [("Medan", 120), ("Bandung", 90), ("Medan", 45), ("Ambon", 70), ("Bandung", 30), ("Medan", 60), ("Ambon", 25)])

bagian = []
for potongan in pd.read_csv(io.StringIO(csv), chunksize=3, usecols=["kota", "total"]):
    print("potongan", len(potongan), "baris")
    bagian.append(potongan.groupby("kota")["total"].sum())

hasil = pd.concat(bagian).groupby(level=0).sum()
print(hasil.to_dict())

Poin penting

  • chunksize membaca file per potongan.
  • Ringkas per potongan, gabungkan di akhir.
  • usecols dan dtype menghemat memori.
  • Data sangat besar: Polars atau DuckDB.
