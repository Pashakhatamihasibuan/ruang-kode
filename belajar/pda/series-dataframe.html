Series & DataFrame

Buka versi interaktif

Series adalah satu kolom berlabel; DataFrame adalah tabel yang tersusun dari beberapa Series dengan indeks yang sama.

Langkah pertama setiap analisis: lihat datanya. head() menampilkan baris awal, shape ukuran tabel, describe() ringkasan statistik kolom angka.

Kolom baru dibuat dengan operasi vektor seperti NumPy: df["omzet"] = df["jumlah"] * df["harga"].

PYTHON
import pandas as pd
penjualan = pd.DataFrame({
    "tanggal": ["2024-10-01","2024-10-01","2024-10-02","2024-10-03","2024-10-03","2024-10-04","2024-10-05","2024-10-05"],
    "kota": ["Jakarta","Bandung","Jakarta","Surabaya","Bandung","Jakarta","Medan","Surabaya"],
    "produk": ["Kopi Gayo","Teh Melati","Keripik","Kopi Gayo","Madu Hutan","Teh Melati","Kopi Gayo","Keripik"],
    "jumlah": [3, 10, 25, 2, 1, 6, 4, 30],
    "harga": [85000, 25000, 15000, 85000, 120000, 25000, 85000, 15000],
})

print(penjualan.head(3))
print(penjualan.shape)

penjualan["omzet"] = penjualan["jumlah"] * penjualan["harga"]
print(penjualan["omzet"].describe().round(0))

Kode pemula vs kode rapi

Kolom baru tanpa loop baris

iterrows memproses baris satu per satu dengan Python biasa. Operasi kolom (vektor) dikerjakan pandas sekaligus dan bisa ratusan kali lebih cepat untuk data besar.

KODE PEMULA
import pandas as pd
df = pd.DataFrame({"kota": ["Medan", "Bandung", "Medan", "Ambon", "Bandung"], "produk": ["Kopi", "Teh", "Teh", "Kopi", "Kopi"], "harga": [85000, 25000, 25000, 85000, 85000], "qty": [2, 4, 1, 3, 1]})

total = []
for i, baris in df.iterrows():
    total.append(baris["harga"] * baris["qty"])
df["total"] = total
print(df["total"].tolist())
KODE RAPI (BEST PRACTICE)
import pandas as pd
df = pd.DataFrame({"kota": ["Medan", "Bandung", "Medan", "Ambon", "Bandung"], "produk": ["Kopi", "Teh", "Teh", "Kopi", "Kopi"], "harga": [85000, 25000, 25000, 85000, 85000], "qty": [2, 4, 1, 3, 1]})

df["total"] = df["harga"] * df["qty"]
print(df["total"].tolist())

Poin penting

  • Series = kolom; DataFrame = tabel.
  • head(), shape, describe() untuk inspeksi awal.
  • Kolom baru = operasi vektor.
