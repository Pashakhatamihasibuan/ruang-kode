Duplikat & encoding kategori

Buka versi interaktif

Transaksi ganda karena tombol bayar ditekan dua kali akan menggandakan omzet. Temukan dengan duplicated() dan buang dengan drop_duplicates(), boleh berdasarkan kolom tertentu lewat subset.

Model machine learning butuh angka. One-hot encoding (pd.get_dummies) membuat satu kolom 0/1 per kategori; cocok untuk kategori tanpa urutan seperti kota.

Kategori berurutan (S, M, L) lebih tepat dipetakan ke angka berurutan dengan map atau tipe Categorical ber-ordered.

PYTHON
import pandas as pd

df = pd.DataFrame({
    "id_trx": [1, 2, 2, 3],
    "kota": ["Jakarta", "Bandung", "Bandung", "Medan"],
    "ukuran": ["M", "L", "L", "S"],
})
print(df.duplicated().tolist())
df = df.drop_duplicates(subset="id_trx")

print(pd.get_dummies(df["kota"], dtype=int))
df["ukuran_kode"] = df["ukuran"].map({"S": 1, "M": 2, "L": 3})
print(df[["ukuran", "ukuran_kode"]])

Poin penting

  • duplicated / drop_duplicates(subset=...).
  • get_dummies untuk kategori tanpa urutan.
  • map untuk kategori berurutan.
