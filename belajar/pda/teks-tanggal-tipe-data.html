Teks, tanggal & tipe data

Buka versi interaktif

Aksesor .str menjalankan method string ke seluruh kolom: strip, lower, title, replace, split, contains.

Angka yang tersimpan sebagai teks ("Rp 85.000") harus dibersihkan lalu diubah dengan astype(int) atau pd.to_numeric.

pd.to_datetime mengubah teks menjadi tanggal; setelah itu aksesor .dt memberi tahun, bulan, nama hari, dan sebagainya. Format Indonesia hari/bulan/tahun butuh dayfirst=True atau format.

PYTHON
import pandas as pd

df = pd.DataFrame({
    "kota": ["  jakarta", "BANDUNG ", "Surabaya"],
    "harga": ["Rp 85.000", "Rp 25.000", "Rp 120.000"],
    "tgl": ["01/10/2024", "15/10/2024", "03/11/2024"],
})
df["kota"] = df["kota"].str.strip().str.title()
df["harga"] = df["harga"].str.replace("Rp ", "").str.replace(".", "").astype(int)
df["tgl"] = pd.to_datetime(df["tgl"], format="%d/%m/%Y")
df["bulan"] = df["tgl"].dt.month
print(df)
print(df["harga"].sum())

Kode pemula vs kode rapi

Method .str untuk seluruh kolom teks

Aksesor .str menjalankan method teks untuk seluruh kolom tanpa apply dan lambda, dan tidak error saat ada nilai kosong.

KODE PEMULA
import pandas as pd
nama = pd.Series(["  sari ", "BUDI", "rina  "])
rapi = nama.apply(lambda s: s.strip().title())
print(rapi.tolist())
KODE RAPI (BEST PRACTICE)
import pandas as pd
nama = pd.Series(["  sari ", "BUDI", "rina  "])
print(nama.str.strip().str.title().tolist())
KELUARAN KEDUANYA
['Sari', 'Budi', 'Rina']

Poin penting

  • .str untuk operasi teks per kolom.
  • Bersihkan simbol lalu astype/to_numeric.
  • to_datetime + .dt untuk komponen tanggal.
