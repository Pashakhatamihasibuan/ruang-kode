Outlier: IQR & z-score

Buka versi interaktif

Metode IQR: hitung kuartil Q1 dan Q3, IQR = Q3 − Q1. Nilai di bawah Q1 − 1,5·IQR atau di atas Q3 + 1,5·IQR dianggap outlier. Ini juga dasar garis pada boxplot.

Z-score mengukur berapa simpangan baku sebuah nilai dari rata-rata. |z| > 3 sering dianggap ekstrem, tetapi metode ini kurang cocok untuk data yang sangat miring.

Outlier tidak otomatis dibuang. Bisa jadi salah input (umur 230), bisa jadi pelanggan grosir yang justru penting.

PYTHON
import pandas as pd

belanja = pd.Series([120, 135, 150, 160, 170, 180, 195, 210, 2400], name="ribu")
q1, q3 = belanja.quantile([0.25, 0.75])
iqr = q3 - q1
bawah, atas = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print(q1, q3, iqr, bawah, atas)
print(belanja[(belanja < bawah) | (belanja > atas)].tolist())

z = (belanja - belanja.mean()) / belanja.std()
print(z.round(2).tolist())

Soal latihan

  1. Temukan outlier omzet harian dengan metode IQR (di luar Q1 - 1,5 IQR dan Q3 + 1,5 IQR).

    Petunjuk

    quantile([.25, .75]), lalu batas bawah dan atas.

    Lihat jawaban
    PYTHON
    import pandas as pd

omzet = pd.Series([120, 135, 128, 140, 132, 410, 125, 30])
q1, q3 = omzet.quantile([0.25, 0.75])
iqr = q3 - q1
bawah, atas = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print(bawah, atas)
print(omzet[(omzet < bawah) | (omzet > atas)].tolist())
    KELUARAN
    105.0 155.0
[410, 30]

  2. Tandai outlier dengan z-score lebih dari 2 untuk data yang sama. Kenapa hasilnya bisa berbeda dengan IQR?

    Petunjuk

    z = (x - mean) / std. Outlier besar ikut menaikkan std sehingga z-score kurang peka.

    Lihat jawaban
    PYTHON
    import pandas as pd

omzet = pd.Series([120, 135, 128, 140, 132, 410, 125, 30])
z = (omzet - omzet.mean()) / omzet.std()
print(z.round(2).tolist())
print(omzet[z.abs() > 2].tolist())
    KELUARAN
    [-0.3, -0.16, -0.22, -0.11, -0.19, 2.34, -0.25, -1.11]
[410]

Poin penting

  • IQR: di luar Q1−1,5·IQR atau Q3+1,5·IQR.
  • Z-score: |z| > 3 ekstrem.
  • Selidiki dulu sebelum membuang.
