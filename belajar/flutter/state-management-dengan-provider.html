State management dengan Provider

Buka versi interaktif

Jika data keranjang dibutuhkan di layar produk, keranjang, dan checkout, mengoper data lewat constructor menjadi rumit. State management menyimpan data di satu tempat yang bisa dibaca widget mana pun.

Provider adalah pilihan paling sederhana. Data disimpan di class turunan ChangeNotifier; setelah data berubah, panggil notifyListeners(). Widget membaca dengan context.watch<T>() (ikut diperbarui) atau context.read<T>() (sekali baca, misalnya di onPressed).

Tabel di bawah membandingkan pilihan populer. Untuk pemula dan aplikasi kecil-menengah, Provider atau Riverpod sudah cukup.

KODE
class Keranjang extends ChangeNotifier {
  final List<String> _isi = [];
  List<String> get isi => List.unmodifiable(_isi);
  int get jumlah => _isi.length;

  void tambah(String produk) {
    _isi.add(produk);
    notifyListeners();
  }
}

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (_) => Keranjang(),
      child: const MaterialApp(home: TokoPage()),
    ),
  );
}

class TokoPage extends StatelessWidget {
  const TokoPage({super.key});
  @override
  Widget build(BuildContext context) {
    final jumlah = context.watch<Keranjang>().jumlah;
    return Scaffold(
      appBar: AppBar(title: Text('Keranjang ($jumlah)')),
      body: Center(
        child: FilledButton(
          onPressed: () => context.read<Keranjang>().tambah('Kopi Gayo'),
          child: const Text('Tambah kopi'),
        ),
      ),
    );
  }
}

Soal latihan

  1. Tambahkan method hapus(produk) dan getter total pada Keranjang yang menyimpan harga.

    Petunjuk

    Simpan Map<String, int> nama → harga. Panggil notifyListeners() setelah mengubah data.

    Lihat jawaban
    KODE
    class Keranjang extends ChangeNotifier {
  final Map<String, int> _isi = {};
  Map<String, int> get isi => Map.unmodifiable(_isi);
  int get total => _isi.values.fold(0, (a, b) => a + b);

  void tambah(String nama, int harga) {
    _isi[nama] = harga;
    notifyListeners();
  }

  void hapus(String nama) {
    _isi.remove(nama);
    notifyListeners();
  }
}

Poin penting

  • ChangeNotifier + notifyListeners.
  • watch untuk tampilan, read untuk aksi.
  • Pilih library sesuai ukuran aplikasi dan tim.
