Database lokal: sqflite, drift, Hive, dan Isar

Buka versi interaktif

Untuk data yang banyak dan harus tersedia tanpa internet, pakai database lokal. sqflite adalah SQLite dengan query SQL biasa. drift juga SQLite, tetapi tabel ditulis dalam Dart dan query diperiksa saat kompilasi, sehingga salah ketik nama kolom langsung ketahuan.

Hive dan Isar adalah database NoSQL yang menyimpan objek Dart langsung dan sangat cepat. Cocok untuk cache dan data yang tidak butuh relasi rumit.

Apa pun pilihannya, pisahkan kode database ke class repository agar tampilan tidak tahu data berasal dari mana.

Membandingkan database lokal
PackageJenisKelebihan
sqfliteSQLite, SQL mentahSederhana, SQL yang sudah dikenal
driftSQLite bertipe amanQuery diperiksa saat kompilasi, Stream reaktif, migrasi
hive / hive_ceKey-value NoSQLSangat ringan dan cepat
isarNoSQL objekQuery dan indeks cepat, cocok untuk data besar
KODE
// drift: definisi tabel dalam Dart
class Catatan extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get judul => text().withLength(min: 1, max: 80)();
  TextColumn get isi => text()();
  DateTimeColumn get dibuat => dateTime().withDefault(currentDateAndTime)();
}

@DriftDatabase(tables: [Catatan])
class AppDb extends _$AppDb {
  AppDb() : super(driftDatabase(name: 'catatan'));
  @override
  int get schemaVersion => 1;

  Stream<List<CatatanData>> semua() =>
      (select(catatan)..orderBy([(t) => OrderingTerm.desc(t.dibuat)])).watch();

  Future<int> tambah(String judul, String isi) =>
      into(catatan).insert(CatatanCompanion.insert(judul: judul, isi: isi));
}

// sqflite: SQL biasa
final db = await openDatabase('toko.db', version: 1,
    onCreate: (db, v) => db.execute(
        'CREATE TABLE produk(id INTEGER PRIMARY KEY, nama TEXT, harga INTEGER)'));
await db.insert('produk', {'nama': 'Kopi Gayo', 'harga': 85000});
final mahal = await db.query('produk', where: 'harga > ?', whereArgs: [50000]);

Soal latihan

  1. Dengan sqflite, tulis fungsi yang menghapus produk berdasarkan id dan fungsi yang mengubah harganya.

    Petunjuk

    db.delete dan db.update dengan where: 'id = ?'.

    Lihat jawaban
    KODE
    Future<void> hapusProduk(Database db, int id) =>
    db.delete('produk', where: 'id = ?', whereArgs: [id]);

Future<void> ubahHarga(Database db, int id, int harga) =>
    db.update('produk', {'harga': harga}, where: 'id = ?', whereArgs: [id]);

  2. Tampilkan daftar catatan drift yang otomatis diperbarui saat data berubah.

    Petunjuk

    StreamBuilder dengan stream db.semua().

    Lihat jawaban
    KODE
    StreamBuilder<List<CatatanData>>(
  stream: db.semua(),
  builder: (context, snap) {
    final data = snap.data ?? [];
    if (data.isEmpty) return const Center(child: Text('Belum ada catatan'));
    return ListView(
      children: [for (final c in data) ListTile(title: Text(c.judul), subtitle: Text(c.isi))],
    );
  },
)

Poin penting

  • sqflite: SQL langsung; drift: SQL bertipe aman.
  • Hive/Isar: NoSQL cepat.
  • Bungkus akses data dalam repository.

Cek pemahaman

Kenapa memakai whereArgs ([id]) dan bukan menyambung string?

Jawaban: Mencegah SQL injection dan salah tanda kutip

Parameter dikirim terpisah dari perintah SQL.

Kerjakan latihannya di aplikasi

Sebelumnya: Model data dengan freezed dan json_serializable
