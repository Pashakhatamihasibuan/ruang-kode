Penyimpanan lokal dan Firebase

Buka versi interaktif

shared_preferences menyimpan data kecil berupa kunci-nilai: tema gelap, bahasa, sudah melihat onboarding. Untuk data terstruktur yang banyak (riwayat transaksi, catatan), pakai database lokal: sqflite (SQL), drift (SQL dengan tipe aman), atau hive/isar (NoSQL cepat).

Data rahasia seperti token login simpan di flutter_secure_storage, yang memakai Keychain (iOS) dan Keystore (Android), bukan di shared_preferences.

Firebase menyediakan backend siap pakai: firebase_auth (login email, Google, nomor HP), cloud_firestore (database realtime), firebase_storage (file), dan firebase_messaging (notifikasi). Konfigurasinya dibuat otomatis dengan flutterfire configure.

Future<void> simpanTema(bool gelap) async {

Future<bool> bacaTema() async {
  final prefs = await SharedPreferences.getInstance();
  return prefs.getBool('tema_gelap') ?? false;
}

// Firebase: login dengan email
Future<void> masuk(String email, String sandi) async {
  await FirebaseAuth.instance.signInWithEmailAndPassword(
    email: email,
    password: sandi,
  );
}

Soal latihan

  1. Simpan dan baca daftar kata pencarian terakhir (maksimal 5) dengan shared_preferences.

    Petunjuk

    setStringList dan getStringList. Sisipkan di depan, lalu take(5).

    Lihat jawaban
    KODE
    Future<void> simpanCari(String kata) async {
  final p = await SharedPreferences.getInstance();
  final lama = p.getStringList('cari') ?? [];
  final baru = [kata, ...lama.where((k) => k != kata)].take(5).toList();
  await p.setStringList('cari', baru);
}

  2. Login dengan email dan kata sandi memakai firebase_auth, dan tampilkan pesan yang ramah jika gagal.

    Petunjuk

    FirebaseAuth.instance.signInWithEmailAndPassword; tangkap FirebaseAuthException dan baca e.code.

    Lihat jawaban
    KODE
    Future<String?> masuk(String email, String sandi) async {
  try {
    await FirebaseAuth.instance
        .signInWithEmailAndPassword(email: email, password: sandi);
    return null; // berhasil
  } on FirebaseAuthException catch (e) {
    return switch (e.code) {
      'invalid-credential' || 'wrong-password' => 'Email atau kata sandi salah',
      'too-many-requests' => 'Terlalu banyak percobaan, coba lagi nanti',
      _ => 'Gagal masuk (${e.code})',
    };
  }
}

Poin penting

  • shared_preferences untuk pengaturan kecil.
  • Token di secure storage.
  • Firebase untuk login dan database cloud.
