Platform channel dan plugin

Buka versi interaktif

Flutter berkomunikasi dengan kode native (Kotlin di Android, Swift di iOS) lewat platform channel. MethodChannel untuk panggilan sekali (ambil level baterai), EventChannel untuk aliran data dari native (sensor). Data dikirim sebagai tipe dasar: angka, string, list, map.

Sebagian besar kebutuhan sudah tersedia sebagai plugin di pub.dev (kamera, lokasi, biometrik). Tulis channel sendiri hanya jika plugin belum ada, misalnya SDK printer kasir atau EDC bank tertentu.

Alternatif yang lebih aman tipe: Pigeon membuat kode channel Dart, Kotlin, dan Swift dari satu definisi, sehingga tidak ada salah ketik nama metode.

KODE
// Dart
import 'package:flutter/services.dart';

class Baterai {
  static const _ch = MethodChannel('id.tokoku/baterai');
  static Future<int> level() async {
    final int? n = await _ch.invokeMethod<int>('levelBaterai');
    return n ?? -1;
  }
}

// Kotlin (android/app/src/main/kotlin/.../MainActivity.kt)
class MainActivity : FlutterActivity() {
  override fun configureFlutterEngine(engine: FlutterEngine) {
    super.configureFlutterEngine(engine)
    MethodChannel(engine.dartExecutor.binaryMessenger, "id.tokoku/baterai")
      .setMethodCallHandler { call, result ->
        if (call.method == "levelBaterai") {
          val bm = getSystemService(BATTERY_SERVICE) as BatteryManager
          result.success(bm.getIntProperty(BatteryManager.BATTERY_PROPERTY_CAPACITY))
        } else result.notImplemented()
      }
  }
}

Poin penting

  • MethodChannel untuk panggilan, EventChannel untuk aliran.
  • Cari plugin di pub.dev dulu.
  • Pigeon untuk channel yang aman tipe.
