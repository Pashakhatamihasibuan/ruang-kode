Animasi implisit dan Hero

Buka versi interaktif

Animasi implisit paling mudah: ganti widget biasa dengan versi Animated..., lalu ubah nilainya lewat setState. Flutter menganimasikan perubahan itu sendiri. Contoh: AnimatedContainer, AnimatedOpacity, AnimatedSwitcher, AnimatedAlign.

Hero menerbangkan widget (biasanya gambar) dari satu layar ke layar berikutnya. Beri tag yang sama di kedua layar.

Untuk animasi yang dikendalikan penuh (berulang, berurutan) pakai AnimationController. Untuk animasi dari desainer, package lottie memutar file JSON dari After Effects, dan rive untuk animasi interaktif. Selalu hormati pengaturan "kurangi animasi" (MediaQuery.of(context).disableAnimations).

KODE
class KartuPilih extends StatefulWidget {
  const KartuPilih({super.key});
  @override
  State<KartuPilih> createState() => _KartuPilihState();
}

class _KartuPilihState extends State<KartuPilih> {
  bool dipilih = false;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: () => setState(() => dipilih = !dipilih),
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 250),
        curve: Curves.easeOut,
        width: dipilih ? 220 : 160,
        padding: const EdgeInsets.all(16),
        decoration: BoxDecoration(
          color: dipilih ? Colors.brown : Colors.brown.shade100,
          borderRadius: BorderRadius.circular(dipilih ? 24 : 8),
        ),
        child: Text(dipilih ? 'Dipilih' : 'Ketuk saya',
            style: TextStyle(color: dipilih ? Colors.white : Colors.black)),
      ),
    );
  }
}

Soal latihan

  1. Pakai AnimatedSwitcher agar angka penghitung berganti dengan efek memudar.

    Petunjuk

    Bungkus Text dengan AnimatedSwitcher dan beri key: ValueKey(jumlah) agar Flutter tahu widgetnya berganti.

    Lihat jawaban
    KODE
    AnimatedSwitcher(
  duration: const Duration(milliseconds: 300),
  child: Text(
    '$jumlah',
    key: ValueKey(jumlah),
    style: const TextStyle(fontSize: 40),
  ),
)

  2. Buat ikon yang berputar terus-menerus dengan AnimationController.

    Petunjuk

    Pakai SingleTickerProviderStateMixin, controller..repeat(), lalu RotationTransition.

    Lihat jawaban
    KODE
    class Muter extends StatefulWidget {
  const Muter({super.key});
  @override
  State<Muter> createState() => _MuterState();
}

class _MuterState extends State<Muter> with SingleTickerProviderStateMixin {
  late final c = AnimationController(vsync: this, duration: const Duration(seconds: 2))..repeat();

  @override
  void dispose() {
    c.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) =>
      RotationTransition(turns: c, child: const Icon(Icons.sync, size: 48));
}

Poin penting

  • Animated... untuk animasi implisit.
  • Hero dengan tag sama di dua layar.
  • AnimationController untuk kendali penuh; lottie/rive dari desainer.
