Form dan validasi input

Buka versi interaktif

TextFormField di dalam Form bisa divalidasi bersama. Setiap field punya validator yang mengembalikan pesan error, atau null jika valid. GlobalKey<FormState> dipakai untuk memanggil validate() saat tombol ditekan.

Pakai keyboardType yang tepat (angka, email, telepon) dan TextEditingController untuk membaca isi field. Jangan lupa memanggil dispose() pada controller di State.dispose agar memori tidak bocor.

Pesan error sebaiknya menjelaskan cara memperbaiki: "Nomor HP minimal 10 digit", bukan sekadar "Input salah".

KODE
class FormDaftar extends StatefulWidget {
  const FormDaftar({super.key});
  @override
  State<FormDaftar> createState() => _FormDaftarState();
}

class _FormDaftarState extends State<FormDaftar> {
  final _form = GlobalKey<FormState>();
  final _hp = TextEditingController();

  @override
  void dispose() {
    _hp.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: _form,
      child: Column(children: [
        TextFormField(
          controller: _hp,
          keyboardType: TextInputType.phone,
          decoration: const InputDecoration(labelText: 'Nomor HP'),
          validator: (v) => (v == null || v.length < 10)
              ? 'Nomor HP minimal 10 digit'
              : null,
        ),
        const SizedBox(height: 12),
        FilledButton(
          onPressed: () {
            if (_form.currentState!.validate()) {
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text('Terdaftar: ${_hp.text}')),
              );
            }
          },
          child: const Text('Daftar'),
        ),
      ]),
    );
  }
}

Soal latihan

  1. Tambahkan field email dengan validasi: tidak boleh kosong dan harus mengandung "@".

    Petunjuk

    validator: (v) { if (v == null || v.isEmpty) return ...; if (!v.contains('@')) return ...; return null; }

    Lihat jawaban
    KODE
    TextFormField(
  decoration: const InputDecoration(labelText: 'Email'),
  keyboardType: TextInputType.emailAddress,
  validator: (v) {
    if (v == null || v.trim().isEmpty) return 'Email wajib diisi';
    if (!v.contains('@')) return 'Format email belum benar, contoh: nama@mail.com';
    return null;
  },
)

  2. Tambahkan field kata sandi yang bisa ditampilkan atau disembunyikan dengan ikon mata.

    Petunjuk

    obscureText dari bool di State, suffixIcon berisi IconButton yang memanggil setState.

    Lihat jawaban
    KODE
    TextFormField(
  obscureText: sembunyi,
  decoration: InputDecoration(
    labelText: 'Kata sandi',
    suffixIcon: IconButton(
      icon: Icon(sembunyi ? Icons.visibility : Icons.visibility_off),
      onPressed: () => setState(() => sembunyi = !sembunyi),
    ),
  ),
  validator: (v) => (v ?? '').length < 8 ? 'Minimal 8 karakter' : null,
)

Poin penting

  • validator mengembalikan pesan error atau null.
  • GlobalKey<FormState> untuk validate().
  • dispose controller agar tidak bocor memori.
