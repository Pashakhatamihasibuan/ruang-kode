DevTools dan performa

Buka versi interaktif

Flutter DevTools menyediakan Widget Inspector (melihat pohon dan layout), Performance (frame yang lambat berwarna merah), CPU Profiler, Memory, dan Network. Selalu ukur performa di mode profile pada perangkat nyata (flutter run --profile), bukan mode debug.

Kebiasaan yang menjaga 60 fps: pakai konstruktor const agar widget tidak dibuat ulang, ListView.builder untuk daftar panjang, pecah widget besar menjadi widget kecil agar yang di-rebuild sedikit, hindari Opacity dan ClipPath pada animasi, dan ubah ukuran gambar sesuai tampilan (cacheWidth).

Setiap frame punya jatah sekitar 16 ms (60 Hz) atau 8 ms (120 Hz). Jika build atau raster melewati jatah itu, terjadi jank.

KODE
// buruk: seluruh layar di-rebuild setiap detik
setState(() => detik++);

// baik: hanya teks jam yang di-rebuild
class Jam extends StatelessWidget {
  const Jam({super.key, required this.detik});
  final ValueListenable<int> detik;
  @override
  Widget build(BuildContext context) => ValueListenableBuilder(
        valueListenable: detik,
        builder: (_, d, __) => Text('$d'),
      );
}

// gambar besar diperkecil saat decode
Image.network(url, cacheWidth: 400)

Poin penting

  • Ukur di mode profile pada perangkat nyata.
  • const, builder, widget kecil, gambar seukuran tampilan.
  • Jatah frame 16 ms atau 8 ms.
