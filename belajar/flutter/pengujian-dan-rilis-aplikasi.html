Pengujian dan rilis aplikasi

Buka versi interaktif

Flutter punya tiga jenis tes: unit test (fungsi dan class), widget test (satu widget dirender di memori, lalu ditekan dan diperiksa), dan integration test (aplikasi utuh di emulator/perangkat). Jalankan dengan flutter test.

Sebelum rilis: ganti ikon dan nama aplikasi, atur version di pubspec.yaml, buat keystore untuk menandatangani aplikasi Android, lalu flutter build appbundle untuk Google Play. Untuk iOS, flutter build ipa di Mac dan unggah lewat Xcode atau Transporter.

Periksa performa dengan Flutter DevTools: widget yang dibangun ulang terlalu sering, gambar terlalu besar, dan frame yang lambat.

KODE
void main() {
  testWidgets('tombol tambah menaikkan angka', (tester) async {
    await tester.pumpWidget(const MaterialApp(home: Scaffold(body: Penghitung())));

    expect(find.text('0'), findsOneWidget);
    await tester.tap(find.byIcon(Icons.add));
    await tester.pump();
    expect(find.text('1'), findsOneWidget);
  });
}

Soal latihan

  1. Tulis unit test untuk fungsi hitungTotal(harga, jumlah).

    Petunjuk

    test('deskripsi', () { expect(hasil, nilaiYangDiharapkan); });

    Lihat jawaban
    KODE
    import 'package:test/test.dart';

int hitungTotal(int harga, int jumlah) => harga * jumlah;

void main() {
  test('total = harga x jumlah', () {
    expect(hitungTotal(18000, 2), 36000);
  });
  test('jumlah nol menghasilkan nol', () {
    expect(hitungTotal(18000, 0), 0);
  });
}

  2. Tulis perintah untuk membangun App Bundle rilis dengan nomor versi 1.2.0 build 5.

    Petunjuk

    flutter build appbundle --build-name ... --build-number ...

    Lihat jawaban
    TERMINAL
    flutter build appbundle --release --build-name=1.2.0 --build-number=5

Poin penting

  • Unit, widget, dan integration test.
  • appbundle untuk Google Play, ipa untuk App Store.
  • DevTools untuk performa.

Cek pemahaman

Jawaban: Untuk menggambar ulang frame setelah state berubah
