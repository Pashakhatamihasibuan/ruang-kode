Mengambil data API dengan http dan dio

Buka versi interaktif

Package http cukup untuk permintaan sederhana: await http.get(Uri.parse(url)), lalu periksa statusCode dan ubah body JSON dengan jsonDecode. dio menambahkan fitur yang dibutuhkan aplikasi besar: interceptor (misalnya menyisipkan token login), timeout, dan unggah file.

Ubah JSON menjadi objek model dengan fromJson. Untuk banyak model, package json_serializable atau freezed membuat kode itu otomatis lewat dart run build_runner build.

Tampilkan tiga keadaan layar: memuat (indikator), gagal (pesan + tombol coba lagi), dan berhasil. FutureBuilder menangani ketiganya lewat snapshot.

KODE
class Kota {
  final String nama;
  final int suhu;
  Kota({required this.nama, required this.suhu});
  factory Kota.fromJson(Map<String, dynamic> j) =>
      Kota(nama: j['nama'] as String, suhu: j['suhu'] as int);
}

Future<List<Kota>> ambilCuaca() async {
  final res = await http.get(Uri.parse('https://api.contoh.id/cuaca'));
  if (res.statusCode != 200) {
    throw Exception('Server menjawab ${res.statusCode}');
  }
  final data = jsonDecode(res.body) as List;
  return data.map((e) => Kota.fromJson(e as Map<String, dynamic>)).toList();
}

Soal latihan

  1. Kirim data pesanan baru dengan http.post dalam format JSON.

    Petunjuk

    Set header 'Content-Type': 'application/json' dan body: jsonEncode(map). Status 201 berarti dibuat.

    Lihat jawaban
    KODE
    Future<void> kirimPesanan(String produk, int qty) async {
  final res = await http.post(
    Uri.parse('https://api.contoh.id/pesanan'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({'produk': produk, 'qty': qty}),
  );
  if (res.statusCode != 201) {
    throw Exception('Gagal mengirim (${res.statusCode})');
  }
}

  2. Buat instance dio dengan baseUrl, batas waktu 10 detik, dan interceptor yang menambahkan token ke setiap permintaan.

    Petunjuk

    Dio(BaseOptions(...)) lalu dio.interceptors.add(InterceptorsWrapper(onRequest: ...)).

    Lihat jawaban
    KODE
    final dio = Dio(BaseOptions(
  baseUrl: 'https://api.contoh.id',
  connectTimeout: const Duration(seconds: 10),
  receiveTimeout: const Duration(seconds: 10),
));

void pasangToken(String token) {
  dio.interceptors.add(InterceptorsWrapper(
    onRequest: (options, handler) {
      options.headers['Authorization'] = 'Bearer $token';
      handler.next(options);
    },
  ));
}

Poin penting

  • Periksa statusCode sebelum memakai data.
  • fromJson atau json_serializable untuk model.
  • Tampilkan keadaan memuat, gagal, berhasil.
