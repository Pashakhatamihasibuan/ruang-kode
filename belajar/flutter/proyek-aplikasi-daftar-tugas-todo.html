Proyek: aplikasi daftar tugas (Todo)

Buka versi interaktif

Proyek akhir ini menggabungkan modul-modul sebelumnya: model data, state management Riverpod, penyimpanan lokal dengan shared_preferences, form input, ListView, dan tema Material 3.

Fitur: menambah tugas, mencentang selesai, menghapus dengan geser (Dismissible), filter (semua, aktif, selesai), dan data tetap tersimpan setelah aplikasi ditutup.

Salin kode ke proyek baru, pasang flutter_riverpod dan shared_preferences, lalu kerjakan tantangan pengembangannya.

KODE
class Tugas {
  final String id, judul;
  final bool selesai;
  const Tugas(this.id, this.judul, {this.selesai = false});
  Tugas toggle() => Tugas(id, judul, selesai: !selesai);
  Map<String, Object> toJson() => {'id': id, 'judul': judul, 'selesai': selesai};
  factory Tugas.fromJson(Map<String, dynamic> j) =>
      Tugas(j['id'] as String, j['judul'] as String, selesai: j['selesai'] as bool);
}

class DaftarTugas extends Notifier<List<Tugas>> {
  @override
  List<Tugas> build() {
    _muat();
    return [];
  }

  Future<void> _muat() async {
    final p = await SharedPreferences.getInstance();
    final s = p.getString('tugas');
    if (s != null) {
      state = [for (final j in jsonDecode(s) as List) Tugas.fromJson(j as Map<String, dynamic>)];
    }
  }

  Future<void> _simpan() async {
    final p = await SharedPreferences.getInstance();
    await p.setString('tugas', jsonEncode([for (final t in state) t.toJson()]));
  }

  void tambah(String judul) {
    state = [...state, Tugas(DateTime.now().microsecondsSinceEpoch.toString(), judul)];
    _simpan();
  }

  void toggle(String id) {
    state = [for (final t in state) t.id == id ? t.toggle() : t];
    _simpan();
  }

  void hapus(String id) {
    state = state.where((t) => t.id != id).toList();
    _simpan();
  }
}

final tugasProvider = NotifierProvider<DaftarTugas, List<Tugas>>(DaftarTugas.new);

class HalamanTugas extends ConsumerWidget {
  const HalamanTugas({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final daftar = ref.watch(tugasProvider);
    final aksi = ref.read(tugasProvider.notifier);
    final c = TextEditingController();
    return Scaffold(
      appBar: AppBar(title: Text('Tugas (${daftar.where((t) => !t.selesai).length} aktif)')),
      body: Column(children: [
        Padding(
          padding: const EdgeInsets.all(12),
          child: TextField(
            controller: c,
            decoration: const InputDecoration(hintText: 'Tambah tugas lalu tekan Enter'),
            onSubmitted: (v) {
              if (v.trim().isNotEmpty) aksi.tambah(v.trim());
              c.clear();
            },
          ),
        ),
        Expanded(
          child: daftar.isEmpty
              ? const Center(child: Text('Belum ada tugas. Tulis satu di atas.'))
              : ListView(children: [
                  for (final t in daftar)
                    Dismissible(
                      key: ValueKey(t.id),
                      onDismissed: (_) => aksi.hapus(t.id),
                      background: Container(color: Colors.red),
                      child: CheckboxListTile(
                        value: t.selesai,
                        onChanged: (_) => aksi.toggle(t.id),
                        title: Text(t.judul,
                            style: TextStyle(
                                decoration: t.selesai ? TextDecoration.lineThrough : null)),
                      ),
                    ),
                ]),
        ),
      ]),
    );
  }
}

Soal latihan

  1. Tambahkan filter Semua / Aktif / Selesai dengan SegmentedButton.

    Petunjuk

    Simpan filter di StateProvider atau Notifier kecil, lalu saring daftar sebelum ditampilkan.

    Lihat jawaban
    KODE
    enum Filter { semua, aktif, selesai }
final filterProvider = StateProvider((_) => Filter.semua);

// di build
final f = ref.watch(filterProvider);
final tampil = switch (f) {
  Filter.semua => daftar,
  Filter.aktif => daftar.where((t) => !t.selesai).toList(),
  Filter.selesai => daftar.where((t) => t.selesai).toList(),
};

SegmentedButton<Filter>(
  segments: const [
    ButtonSegment(value: Filter.semua, label: Text('Semua')),
    ButtonSegment(value: Filter.aktif, label: Text('Aktif')),
    ButtonSegment(value: Filter.selesai, label: Text('Selesai')),
  ],
  selected: {f},
  onSelectionChanged: (s) => ref.read(filterProvider.notifier).state = s.first,
)

  2. Tampilkan SnackBar "Tugas dihapus" dengan tombol Urungkan setelah tugas digeser.

    Petunjuk

    Simpan tugas yang dihapus, lalu tambahkan kembali saat tombol Urungkan ditekan.

    Lihat jawaban

    onDismissed: (_) {
  final terhapus = t;

  ScaffoldMessenger.of(context).showSnackBar(SnackBar(

    action: SnackBarAction(

// di DaftarTugas
void pulihkan(Tugas t) {
  state = [...state, t];
  _simpan();
}

  3. Tulis widget test: mengetik "Belajar Dart" lalu Enter harus menampilkan tugas itu di daftar.

    Petunjuk

    tester.enterText, tester.testTextInput.receiveAction(TextInputAction.done), lalu pump.

    Lihat jawaban
    KODE
    testWidgets('menambah tugas', (tester) async {
  SharedPreferences.setMockInitialValues({});
  await tester.pumpWidget(const ProviderScope(
      child: MaterialApp(home: HalamanTugas())));

  await tester.enterText(find.byType(TextField), 'Belajar Dart');
  await tester.testTextInput.receiveAction(TextInputAction.done);

});

Poin penting

  • Notifier menyimpan daftar dan logika.
  • shared_preferences + jsonEncode untuk menyimpan.
  • Dismissible untuk hapus dengan geser.

Cek pemahaman

Kenapa state diganti dengan list baru ([...state, x]) dan bukan state.add(x)?

Jawaban: Riverpod mendeteksi perubahan dari objek baru

Mengubah isi list lama tidak memicu pembaruan tampilan.
