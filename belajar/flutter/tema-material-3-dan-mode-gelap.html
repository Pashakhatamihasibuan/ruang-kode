Tema Material 3 dan mode gelap

Buka versi interaktif

Atur warna dan huruf seluruh aplikasi di satu tempat lewat ThemeData. Material 3 cukup diberi satu warna benih: ColorScheme.fromSeed(seedColor: ...) membuat seluruh palet (primary, secondary, surface, error) yang serasi dan kontrasnya terjaga.

Isi theme untuk mode terang dan darkTheme untuk mode gelap, lalu themeMode: ThemeMode.system agar mengikuti pengaturan ponsel. Di widget, ambil warna dari tema dengan Theme.of(context).colorScheme.primary, jangan menulis warna langsung.

Font kustom bisa dipasang lewat aset atau package google_fonts: textTheme: GoogleFonts.poppinsTextTheme().

KODE
class AplikasiKopi extends StatelessWidget {
  const AplikasiKopi({super.key});

  @override
  Widget build(BuildContext context) {
    const benih = Color(0xFF8B4A2B);
    return MaterialApp(
      themeMode: ThemeMode.system,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: benih),
        useMaterial3: true,
      ),
      darkTheme: ThemeData(
        colorScheme: ColorScheme.fromSeed(
          seedColor: benih,
          brightness: Brightness.dark,
        ),
        useMaterial3: true,
      ),
      home: const Beranda(),
    );
  }
}

class Beranda extends StatelessWidget {
  const Beranda({super.key});
  @override
  Widget build(BuildContext context) {
    final warna = Theme.of(context).colorScheme;
    final teks = Theme.of(context).textTheme;
    return Scaffold(
      body: Center(
        child: Text('Kopi Senja',
            style: teks.headlineMedium?.copyWith(color: warna.primary)),
      ),
    );
  }
}

Soal latihan

  1. Ubah gaya semua FilledButton di aplikasi menjadi bersudut 12 dan tinggi 48 lewat tema.

    Petunjuk

    ThemeData(filledButtonTheme: FilledButtonThemeData(style: FilledButton.styleFrom(...))).

    Lihat jawaban
    KODE
    theme: ThemeData(
  colorScheme: ColorScheme.fromSeed(seedColor: benih),
  filledButtonTheme: FilledButtonThemeData(
    style: FilledButton.styleFrom(
      minimumSize: const Size.fromHeight(48),
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
    ),
  ),
)

  2. Tambahkan sakelar (Switch) di halaman pengaturan untuk mengganti mode gelap secara manual.

    Petunjuk

    Simpan ThemeMode di state management, lalu MaterialApp membaca nilainya.

    Lihat jawaban
    KODE
    SwitchListTile(
  title: const Text('Mode gelap'),
  value: context.watch<Pengaturan>().gelap,
  onChanged: (v) => context.read<Pengaturan>().setGelap(v),
)

// MaterialApp
themeMode: context.watch<Pengaturan>().gelap ? ThemeMode.dark : ThemeMode.light,

Poin penting

  • ColorScheme.fromSeed membuat palet lengkap.
  • theme + darkTheme + themeMode.
  • Ambil warna dari Theme.of(context).
