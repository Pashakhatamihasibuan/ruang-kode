Aplikasi Flutter profesional hampir selalu memakai package dari pub.dev. Tabel di bawah merangkum pilihan yang paling sering dipakai di industri, dikelompokkan menurut kebutuhan. Kamu tidak harus memakai semuanya; pilih satu per kebutuhan.

Sebelum memasang package, periksa: Likes dan Pub Points tinggi, mendukung platform yang kamu targetkan (Android, iOS, web), penerbit terverifikasi, dan dirilis dalam setahun terakhir.

Package yang ditandai Flutter Favorite sudah dinilai tim Flutter dari sisi kualitas dan perawatan.

Soal latihan

  1. Pilih package untuk aplikasi kasir offline yang harus menyimpan 10.000 transaksi dan mencetak laporan grafik. Tulis perintah pemasangannya.

    Petunjuk

    Butuh database lokal yang kuat (drift atau isar), format Rupiah (intl), dan grafik (fl_chart).

    Lihat jawaban
    TERMINAL
    flutter pub add drift sqlite3_flutter_libs path_provider path intl fl_chart
flutter pub add --dev drift_dev build_runner

  2. Aplikasi butuh login Google, menyimpan profil di cloud, dan notifikasi promo. Package Firebase apa saja yang dipasang?

    Petunjuk

    Selalu butuh firebase_core, lalu satu package per layanan.

    Lihat jawaban
    TERMINAL
    flutter pub add firebase_core firebase_auth google_sign_in cloud_firestore firebase_messaging
dart pub global activate flutterfire_cli
flutterfire configure

Poin penting

  • Satu package per kebutuhan, konsisten di seluruh tim.
  • Periksa Likes, Pub Points, platform, dan tanggal rilis.
  • dev_dependencies untuk generator dan pengujian.
