Fitur perangkat: kamera, izin, lokasi, dan tautan

Buka versi interaktif

Package plugin menghubungkan Dart ke fitur asli ponsel. image_picker mengambil foto dari kamera atau galeri, geolocator membaca lokasi GPS, url_launcher membuka situs, WhatsApp, atau telepon, dan share_plus membuka lembar berbagi.

Fitur sensitif butuh izin. Tambahkan deskripsi izin di android/app/src/main/AndroidManifest.xml dan ios/Runner/Info.plist, lalu minta izin saat fitur akan dipakai (bukan saat aplikasi dibuka), dengan penjelasan kenapa izin itu dibutuhkan. permission_handler membantu memeriksa dan meminta izin.

Selalu sediakan jalan keluar jika izin ditolak, misalnya memilih kota secara manual jika lokasi tidak diizinkan.

KODE
Future<void> ambilFoto() async {
  final foto = await ImagePicker().pickImage(
    source: ImageSource.camera,
    maxWidth: 1080,
    imageQuality: 80,
  );
  if (foto == null) return; // pengguna membatalkan
  setState(() => path = foto.path);
}

Future<Position?> lokasiSaya() async {
  var izin = await Geolocator.checkPermission();
  if (izin == LocationPermission.denied) {
    izin = await Geolocator.requestPermission();
  }
  if (izin == LocationPermission.denied ||
      izin == LocationPermission.deniedForever) {
    return null; // tawarkan pilih kota manual
  }
  return Geolocator.getCurrentPosition();
}

Future<void> chatWa(String nomor) async {
  final uri = Uri.parse('https://wa.me/$nomor?text=${Uri.encodeComponent('Halo, saya mau pesan')}');
  await launchUrl(uri, mode: LaunchMode.externalApplication);
}

Soal latihan

  1. Tambahkan deskripsi izin kamera di Info.plist iOS.

    Petunjuk

    Kunci NSCameraUsageDescription berisi alasan dalam bahasa pengguna.

    Lihat jawaban
    HTML
    <key>NSCameraUsageDescription</key>
<string>Kamera dipakai untuk memotret bukti pembayaran.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Galeri dipakai untuk memilih foto profil.</string>

  2. Buat tombol yang membuka aplikasi telepon dengan nomor toko.

    Petunjuk

    Uri(scheme: 'tel', path: nomor) lalu launchUrl.

    Lihat jawaban
    KODE
    FilledButton.icon(
  icon: const Icon(Icons.call),
  label: const Text('Telepon toko'),
  onPressed: () => launchUrl(Uri(scheme: 'tel', path: '+6281234567890')),
)

Poin penting

  • Plugin menghubungkan Dart ke fitur asli.
  • Deskripsi izin di AndroidManifest dan Info.plist.
  • Minta izin saat dibutuhkan dan sediakan jalan keluar.
