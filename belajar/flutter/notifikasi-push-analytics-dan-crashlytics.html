Notifikasi push, Analytics, dan Crashlytics

Buka versi interaktif

Firebase Cloud Messaging (FCM) mengirim notifikasi push ke Android dan iOS gratis. Langkahnya: pasang firebase_messaging, minta izin (Android 13+ dan iOS wajib), ambil token perangkat, kirim token ke server, lalu tangani pesan saat aplikasi di depan, di belakang, dan tertutup.

Firebase Analytics mencatat event (logEvent(name: 'tambah_keranjang')) untuk memahami perilaku pengguna. Crashlytics melaporkan crash dan error lengkap dengan stack trace, versi aplikasi, dan perangkat. Ingat UU PDP: jelaskan di kebijakan privasi data apa yang dikumpulkan.

Konfigurasi semua platform sekaligus dengan flutterfire configure.

KODE
Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);

  // Crashlytics menangkap error Flutter dan error asinkron
  FlutterError.onError = FirebaseCrashlytics.instance.recordFlutterFatalError;
  PlatformDispatcher.instance.onError = (e, s) {
    FirebaseCrashlytics.instance.recordError(e, s, fatal: true);
    return true;
  };

  final fcm = FirebaseMessaging.instance;
  await fcm.requestPermission();
  final token = await fcm.getToken();
  await api.simpanToken(token);
  FirebaseMessaging.onMessage.listen((m) => tampilkanBanner(m.notification?.title));

  runApp(const AplikasiToko());
}

Poin penting

  • FCM: izin, token, tangani pesan di tiga keadaan.
  • Analytics untuk event, Crashlytics untuk crash.
  • Patuhi kebijakan privasi dan UU PDP.
