StatelessWidget dan StatefulWidget

Buka versi interaktif

StatelessWidget tidak punya data yang berubah; tampilannya hanya bergantung pada parameter yang diterima. Contohnya kartu produk yang hanya menampilkan nama dan harga.

StatefulWidget punya State yang bisa berubah, misalnya jumlah di keranjang. Ubah data di dalam setState(() { ... }): Flutter lalu memanggil ulang build dan layar diperbarui.

Aturan praktis: mulai dengan StatelessWidget. Ubah menjadi StatefulWidget hanya jika widget itu sendiri perlu mengingat data yang berubah. Jika data dipakai di banyak layar, pakai state management (modul berikutnya).

KODE
class Penghitung extends StatefulWidget {
  const Penghitung({super.key});

  @override
  State<Penghitung> createState() => _PenghitungState();
}

class _PenghitungState extends State<Penghitung> {
  int jumlah = 0;

  @override
  Widget build(BuildContext context) {
    return Row(
      mainAxisSize: MainAxisSize.min,
      children: [
        IconButton(
          onPressed: jumlah > 0 ? () => setState(() => jumlah--) : null,
          icon: const Icon(Icons.remove),
        ),
        Text('$jumlah', style: const TextStyle(fontSize: 20)),
        IconButton(
          onPressed: () => setState(() => jumlah++),
          icon: const Icon(Icons.add),
        ),
      ],
    );
  }
}

Soal latihan

  1. Tambahkan tombol "Kurangi" pada Penghitung yang tidak bisa membuat angka di bawah 0.

    Petunjuk

    onPressed: jumlah == 0 ? null : () => setState(() => jumlah--). null membuat tombol nonaktif.

    Lihat jawaban
    KODE
    Row(
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    OutlinedButton(
      onPressed: jumlah == 0 ? null : () => setState(() => jumlah--),
      child: const Text('Kurangi'),
    ),
    Padding(
      padding: const EdgeInsets.symmetric(horizontal: 16),
      child: Text('$jumlah', style: const TextStyle(fontSize: 32)),
    ),
    FilledButton(
      onPressed: () => setState(() => jumlah++),
      child: const Text('Tambah'),
    ),
  ],
)

  2. Buat StatelessWidget KartuSapa yang menerima parameter nama wajib dan menampilkan "Halo, {nama}".

    Petunjuk

    Field final + constructor dengan required this.nama.

    Lihat jawaban
    KODE
    class KartuSapa extends StatelessWidget {
  const KartuSapa({super.key, required this.nama});
  final String nama;

  @override
  Widget build(BuildContext context) {
    return Card(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Text('Halo, $nama'),
      ),
    );
  }
}

// pemakaian: const KartuSapa(nama: 'Rina')

  3. Buat tombol suka (ikon hati) yang berganti antara kosong dan penuh saat ditekan.

    Petunjuk

    Simpan bool suka di State, lalu pilih Icons.favorite atau Icons.favorite_border.

    Lihat jawaban
    KODE
    class TombolSuka extends StatefulWidget {
  const TombolSuka({super.key});
  @override
  State<TombolSuka> createState() => _TombolSukaState();
}

class _TombolSukaState extends State<TombolSuka> {
  bool suka = false;

  @override
  Widget build(BuildContext context) {
    return IconButton(
      icon: Icon(suka ? Icons.favorite : Icons.favorite_border,
          color: suka ? Colors.red : null),
      onPressed: () => setState(() => suka = !suka),
    );
  }
}

Poin penting

  • Stateless: hanya dari parameter.
  • Stateful: punya State, diubah dengan setState.
  • Mulai dari Stateless; naikkan bila perlu.

Cek pemahaman

Apa yang terjadi setelah setState dipanggil?

Jawaban: build dipanggil ulang dan layar diperbarui

setState memberi tahu Flutter bahwa data berubah.

onPressed: null pada tombol membuat tombol?

Jawaban: Nonaktif

Tombol dengan onPressed null tampil nonaktif.
