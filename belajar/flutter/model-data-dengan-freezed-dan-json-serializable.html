Model data dengan freezed dan json_serializable

Buka versi interaktif

Menulis fromJson, toJson, ==, hashCode, dan copyWith untuk setiap model sangat melelahkan dan rawan salah. freezed membuatnya otomatis dari deklarasi singkat.

Tulis class dengan anotasi @freezed, sertakan baris part, lalu jalankan dart run build_runner build -d (atau watch agar terus diperbarui). File .freezed.dart dan .g.dart akan dibuat di sebelahnya.

Hasilnya objek immutable: untuk mengubah satu field, pakai produk.copyWith(stok: 5), yang membuat objek baru. Pola ini cocok dengan Riverpod dan BLoC yang membandingkan state lama dan baru.

KODE
import 'package:freezed_annotation/freezed_annotation.dart';

part 'produk.freezed.dart';
part 'produk.g.dart';

@freezed
class Produk with _$Produk {
  const factory Produk({
    required int id,
    required String nama,
    required int harga,
    @Default(0) int stok,
    @JsonKey(name: 'gambar_url') String? gambar,
  }) = _Produk;

  factory Produk.fromJson(Map<String, dynamic> json) => _$ProdukFromJson(json);
}

// pemakaian
final p = Produk.fromJson({'id': 1, 'nama': 'Kopi Gayo', 'harga': 85000});
final p2 = p.copyWith(stok: 10);
print(p == p2);       // false, stok berbeda
print(p2.toJson());

Soal latihan

  1. Buat model Pengguna dengan freezed: id, nama, email, dan bool aktif bawaan true.

    Petunjuk

    @Default(true) bool aktif.

    Lihat jawaban
    KODE
    @freezed
class Pengguna with _$Pengguna {
  const factory Pengguna({
    required String id,
    required String nama,
    required String email,
    @Default(true) bool aktif,
  }) = _Pengguna;

  factory Pengguna.fromJson(Map<String, dynamic> json) => _$PenggunaFromJson(json);
}

  2. Buat sealed union freezed untuk status layar: memuat, sukses(List<Produk>), gagal(String pesan), lalu tampilkan dengan switch.

    Petunjuk

    Beberapa factory constructor di satu class freezed menjadi union.

    Lihat jawaban
    KODE
    @freezed
sealed class StatusProduk with _$StatusProduk {
  const factory StatusProduk.memuat() = Memuat;
  const factory StatusProduk.sukses(List<Produk> data) = Sukses;
  const factory StatusProduk.gagal(String pesan) = Gagal;
}

Widget tampil(StatusProduk s) => switch (s) {
      Memuat() => const CircularProgressIndicator(),
      Sukses(:final data) => Text('${data.length} produk'),
      Gagal(:final pesan) => Text(pesan),
    };

Poin penting

  • freezed: fromJson, toJson, ==, copyWith otomatis.
  • build_runner build/watch membuat file .freezed.dart dan .g.dart.
  • copyWith untuk mengubah objek immutable.
