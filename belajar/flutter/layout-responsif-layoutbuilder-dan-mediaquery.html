Layout responsif: LayoutBuilder dan MediaQuery

Buka versi interaktif

Aplikasi Flutter bisa berjalan di ponsel, tablet, dan web, jadi tata letaknya harus menyesuaikan. MediaQuery.sizeOf(context) memberi ukuran layar, sedangkan LayoutBuilder memberi ruang yang tersedia untuk widget itu sendiri (lebih tepat untuk komponen).

Pola umum Material 3: lebar < 600 memakai NavigationBar di bawah, 600–839 memakai NavigationRail di samping, dan ≥ 840 memakai rail atau drawer permanen dengan dua panel (daftar dan detail).

Hindari ukuran piksel tetap untuk lebar. Pakai Expanded, Flexible, FractionallySizedBox, atau batasi lebar maksimum dengan ConstrainedBox(constraints: BoxConstraints(maxWidth: 600)) agar teks di layar lebar tetap nyaman dibaca.

KODE
class KerangkaAdaptif extends StatelessWidget {
  const KerangkaAdaptif({super.key, required this.indeks, required this.pilih, required this.isi});
  final int indeks;
  final ValueChanged<int> pilih;
  final Widget isi;

  static const tujuan = [
    (Icons.home, 'Beranda'),
    (Icons.receipt_long, 'Pesanan'),
    (Icons.person, 'Profil'),
  ];

  @override
  Widget build(BuildContext context) {
    final lebar = MediaQuery.sizeOf(context).width;
    if (lebar < 600) {
      return Scaffold(
        body: isi,
        bottomNavigationBar: NavigationBar(
          selectedIndex: indeks,
          onDestinationSelected: pilih,
          destinations: [
            for (final (ikon, label) in tujuan)
              NavigationDestination(icon: Icon(ikon), label: label),
          ],
        ),
      );
    }
    return Scaffold(
      body: Row(children: [
        NavigationRail(
          extended: lebar >= 840,
          selectedIndex: indeks,
          onDestinationSelected: pilih,
          destinations: [
            for (final (ikon, label) in tujuan)
              NavigationRailDestination(icon: Icon(ikon), label: Text(label)),
          ],
        ),
        const VerticalDivider(width: 1),
        Expanded(child: isi),
      ]),
    );
  }
}

Soal latihan

  1. Buat widget yang menampilkan 2 kolom kartu di ponsel, 3 di tablet, dan 4 di layar lebar memakai LayoutBuilder.

    Petunjuk

    Hitung jumlah kolom dari constraints.maxWidth.

    Lihat jawaban
    KODE
    LayoutBuilder(
  builder: (context, c) {
    final kolom = c.maxWidth >= 1000 ? 4 : c.maxWidth >= 600 ? 3 : 2;
    return GridView.count(
      crossAxisCount: kolom,
      children: [for (final p in produk) KartuProduk(p)],
    );
  },
)

  2. Batasi lebar form login maksimal 420 px dan taruh di tengah layar lebar.

    Petunjuk

    Center + ConstrainedBox(maxWidth: 420).

    Lihat jawaban
    KODE
    Center(
  child: ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 420),
    child: const FormLogin(),
  ),
)

Poin penting

  • MediaQuery untuk ukuran layar, LayoutBuilder untuk ruang widget.
  • < 600 NavigationBar, ≥ 600 NavigationRail.
  • Batasi lebar baca dengan ConstrainedBox.

Cek pemahaman

Widget yang memberi ukuran ruang yang tersedia untuk dirinya sendiri?

Jawaban: LayoutBuilder

LayoutBuilder memberi constraints dari induknya.
