Future, Stream, dan isolate

Buka versi interaktif

Future mewakili satu nilai yang datang nanti (hasil HTTP, baca file). Tunggu dengan await di fungsi async, atau tampilkan di UI dengan FutureBuilder. Stream mewakili banyak nilai berturut-turut (lokasi GPS, pesan chat, perubahan Firestore); dengarkan dengan await for, listen, atau StreamBuilder.

Dart berjalan di satu thread dengan event loop. await tidak memblokir; ia memberi giliran ke tugas lain. Tetapi komputasi berat (mengurai JSON 5 MB, memproses gambar) tetap membuat UI patah-patah (jank).

Untuk komputasi berat, jalankan di isolate lain dengan Isolate.run() atau compute(). Isolate punya memori sendiri, berkomunikasi lewat pesan, sehingga UI tetap mulus 60 sampai 120 fps.

KODE
import 'dart:async';
import 'dart:isolate';

Future<String> ambilNama() async {
  await Future.delayed(const Duration(milliseconds: 100));
  return 'Rina';
}

Stream<int> hitungMundur(int dari) async* {
  for (var i = dari; i > 0; i--) {
    await Future.delayed(const Duration(milliseconds: 50));
    yield i;
  }
}

int jumlahBerat(int n) {
  var s = 0;
  for (var i = 1; i <= n; i++) {
    s += i;
  }
  return s;
}

void main() async {
  print('Mulai');
  final nama = await ambilNama();
  print('Halo, $nama');
  await for (final x in hitungMundur(3)) {
    print('Hitung $x');
  }
  final hasil = await Isolate.run(() => jumlahBerat(1000000));
  print('Jumlah: $hasil');
}
KELUARAN
Mulai
Halo, Rina
Hitung 3
Hitung 2
Hitung 1
Jumlah: 500000500000

Soal latihan

  1. Buat Stream detik() yang memancarkan 1, 2, 3 lalu selesai, dan cetak setiap nilainya dengan awalan "Detik ".

    Petunjuk

    Fungsi async* dengan loop dan yield.

    Lihat jawaban

void main() async {

Poin penting

  • Future satu nilai, Stream banyak nilai.
  • async* dan yield membuat Stream.
  • Isolate.run untuk komputasi berat.
