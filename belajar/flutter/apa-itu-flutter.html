Apa itu Flutter

Buka versi interaktif

Flutter adalah framework UI dari Google untuk membuat aplikasi Android, iOS, web, Windows, macOS, dan Linux dari satu kode Dart. Flutter menggambar sendiri setiap piksel lewat mesin grafisnya (Impeller), sehingga tampilan sama persis di semua platform.

Semua yang tampil di Flutter adalah widget: teks, tombol, jarak, bahkan tata letak. Widget disusun bertingkat seperti pohon. Kamu tidak mengubah tampilan secara langsung; kamu mengubah data (state), lalu Flutter menggambar ulang widget yang terdampak.

Fitur yang disukai developer: hot reload (perubahan kode tampil dalam hitungan detik tanpa kehilangan state), komponen Material 3 dan Cupertino siap pakai, dan ekosistem package yang besar di pub.dev. Aplikasi seperti Google Pay, BMW, dan banyak startup Indonesia memakai Flutter.

Soal latihan

  1. Ubah aplikasi contoh agar judul AppBar berbunyi "Toko Kopi" dan isi layar menampilkan teks "Selamat datang" di tengah.

    Petunjuk

    Scaffold(appBar: AppBar(title: ...), body: Center(child: Text(...))).

    Lihat jawaban
    KODE
    class AplikasiSaya extends StatelessWidget {
  const AplikasiSaya({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Toko Kopi')),
        body: const Center(child: Text('Selamat datang')),
      ),
    );
  }
}

  2. Matikan pita "DEBUG" di pojok kanan atas dan beri aplikasi warna tema hijau.

    Petunjuk

    MaterialApp punya debugShowCheckedModeBanner dan theme: ThemeData(colorSchemeSeed: ...).

    Lihat jawaban
    KODE
    MaterialApp(
  debugShowCheckedModeBanner: false,
  theme: ThemeData(colorSchemeSeed: Colors.green, useMaterial3: true),
  home: const Beranda(),
)

Poin penting

  • Satu kode Dart untuk banyak platform.
  • Semua tampilan adalah widget.
  • Ubah state, Flutter menggambar ulang.
