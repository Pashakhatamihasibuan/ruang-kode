ListView, gambar, dan aset

Buka versi interaktif

ListView.builder membuat daftar panjang secara efisien: hanya item yang terlihat yang dibuat. Pakai ini untuk daftar produk, chat, atau riwayat transaksi, bukan Column di dalam SingleChildScrollView.

Gambar dari internet: Image.network(url), atau package cached_network_image agar gambar disimpan dan tidak diunduh ulang. Gambar lokal disimpan di folder assets/, didaftarkan di pubspec.yaml, lalu dipanggil dengan Image.asset('assets/logo.png').

Untuk grid seperti katalog toko, pakai GridView.builder dengan SliverGridDelegateWithMaxCrossAxisExtent, sehingga jumlah kolom menyesuaikan lebar layar.

KODE
class DaftarProduk extends StatelessWidget {
  const DaftarProduk({super.key, required this.produk});
  final List<Map<String, Object>> produk;

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      itemCount: produk.length,
      itemBuilder: (context, i) {
        final p = produk[i];
        return ListTile(
          leading: ClipRRect(
            borderRadius: BorderRadius.circular(8),
            child: Image.network(p['foto'] as String, width: 56, fit: BoxFit.cover),
          ),
          title: Text(p['nama'] as String),
          subtitle: Text('Rp${p['harga']}'),
          trailing: const Icon(Icons.chevron_right),
          onTap: () {},
        );
      },
    );
  }
}

Soal latihan

  1. Ubah daftar produk menjadi grid yang kolomnya menyesuaikan lebar layar (maksimal 200 px per kartu).

    Petunjuk

    GridView.builder dengan SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 200).

    Lihat jawaban
    KODE
    GridView.builder(
  padding: const EdgeInsets.all(12),
  gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(
    maxCrossAxisExtent: 200,
    mainAxisSpacing: 12,
    crossAxisSpacing: 12,
    childAspectRatio: 3 / 4,
  ),
  itemCount: produk.length,
  itemBuilder: (context, i) => Card(
    child: Column(
      children: [
        Expanded(child: Image.network(produk[i]['gambar'] as String, fit: BoxFit.cover)),
        Padding(
          padding: const EdgeInsets.all(8),
          child: Text(produk[i]['nama'] as String),
        ),
      ],
    ),
  ),
)

  2. Tambahkan garis pemisah antaritem dan fitur tarik-untuk-muat-ulang pada ListView.

    Petunjuk

    ListView.separated + RefreshIndicator(onRefresh: ...).

    Lihat jawaban
    KODE
    RefreshIndicator(
  onRefresh: muatUlang, // Future<void> Function()
  child: ListView.separated(
    itemCount: produk.length,
    separatorBuilder: (_, __) => const Divider(height: 1),
    itemBuilder: (context, i) => ListTile(title: Text(produk[i]['nama'] as String)),
  ),
)

Poin penting

  • ListView.builder untuk daftar panjang.
  • cached_network_image untuk gambar dari internet.
  • Aset lokal didaftarkan di pubspec.yaml.
