Row, Column, Container, dan Expanded

Buka versi interaktif

Column menyusun widget dari atas ke bawah, Row dari kiri ke kanan. Atur posisinya dengan mainAxisAlignment (searah susunan) dan crossAxisAlignment (tegak lurus).

Padding memberi jarak dalam, SizedBox memberi jarak antarwidget atau ukuran tetap, dan Container menggabungkan ukuran, warna, sudut membulat, dan bayangan lewat BoxDecoration.

Expanded membuat anak Row/Column mengisi sisa ruang. Error paling terkenal di Flutter, garis kuning-hitam "RenderFlex overflowed", muncul saat isi Row lebih lebar dari layar. Solusinya: bungkus teks panjang dengan Expanded, atau pakai Wrap agar isinya turun ke baris berikut.

Widget kartuProduk() {
  return Container(
    padding: const EdgeInsets.all(16),
    decoration: BoxDecoration(
      color: Colors.white,
      borderRadius: BorderRadius.circular(16),

    child: Row(
      children: [
        const CircleAvatar(radius: 24, child: Icon(Icons.coffee)),
        const SizedBox(width: 12),
        const Expanded(

            crossAxisAlignment: CrossAxisAlignment.start,

              Text('Rp85.000 · 250 gram'),
            ],
          ),
        ),
        FilledButton(onPressed: () {}, child: const Text('Beli')),
      ],
    ),
  );
}

Soal latihan

  1. Buat baris berisi ikon, nama produk panjang, dan harga, tanpa overflow di layar sempit.

    Petunjuk

    Bungkus Text nama dengan Expanded dan beri overflow: TextOverflow.ellipsis atau biarkan turun baris.

    Lihat jawaban
    KODE
    Row(
  children: [
    const Icon(Icons.coffee),
    const SizedBox(width: 12),
    const Expanded(
      child: Text('Kopi Arabika Gayo Wine Process 250 gram',
          maxLines: 2),
    ),
    const SizedBox(width: 12),
    Text('Rp85.000', style: Theme.of(context).textTheme.titleMedium),
  ],
)

  2. Buat label "Diskon 20%" yang menempel di pojok kiri atas sebuah gambar.

    Petunjuk

    Stack + Positioned(top: 8, left: 8).

    Lihat jawaban
    KODE
    Stack(
  children: [
    ClipRRect(
      borderRadius: BorderRadius.circular(12),
      child: Image.asset('assets/images/kopi.jpg'),
    ),
    Positioned(
      top: 8,
      left: 8,
      child: Container(
        padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 4),
        decoration: BoxDecoration(
          color: Colors.red,
          borderRadius: BorderRadius.circular(8),
        ),
        child: const Text('Diskon 20%', style: TextStyle(color: Colors.white)),
      ),
    ),
  ],
)

Poin penting

  • Column vertikal, Row horizontal.
  • Expanded mengisi sisa ruang dan mencegah overflow.
  • SafeArea menghindari poni layar.
