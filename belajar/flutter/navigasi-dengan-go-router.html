Navigasi dengan go_router

Buka versi interaktif

Flutter punya Navigator.push bawaan untuk berpindah layar. Untuk aplikasi yang lebih besar (dan web yang butuh alamat URL), tim Flutter merekomendasikan package go_router: setiap layar punya alamat, misalnya /produk/12.

Daftarkan rute di GoRouter, lalu berikan ke MaterialApp.router. Pindah layar dengan context.go('/keranjang') (mengganti tumpukan) atau context.push(...) (menambah di atas, bisa kembali).

Parameter di alamat (:id) dibaca dari state.pathParameters. Fitur redirect dipakai untuk melindungi layar yang butuh login.

KODE
final router = GoRouter(
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const BerandaPage(),
      routes: [
        GoRoute(
          path: 'produk/:id',
          builder: (context, state) =>
              DetailPage(id: state.pathParameters['id']!),
        ),
      ],
    ),
    GoRoute(path: '/keranjang', builder: (context, state) => const KeranjangPage()),
  ],
);

void main() => runApp(MaterialApp.router(routerConfig: router));

// di dalam widget:
// onTap: () => context.push('/produk/12'),

Soal latihan

  1. Tambahkan rute /login dan redirect: pengguna yang belum login diarahkan ke /login.

    Petunjuk

    GoRouter(redirect: (context, state) { ... return null; }). null berarti tidak dialihkan.

    Lihat jawaban
    KODE
    final router = GoRouter(
  redirect: (context, state) {
    final sudahLogin = auth.sudahLogin;
    final keLogin = state.matchedLocation == '/login';
    if (!sudahLogin && !keLogin) return '/login';
    if (sudahLogin && keLogin) return '/';
    return null;
  },
  routes: [
    GoRoute(path: '/', builder: (_, __) => const BerandaPage()),
    GoRoute(path: '/login', builder: (_, __) => const LoginPage()),
  ],
);

  2. Buat navigasi bawah tiga tab (Beranda, Pesanan, Profil) yang tetap tampil saat berpindah tab.

    Petunjuk

    ShellRoute atau StatefulShellRoute membungkus beberapa rute dengan satu Scaffold.

    Lihat jawaban
    KODE
    StatefulShellRoute.indexedStack(
  builder: (context, state, shell) => Scaffold(
    body: shell,
    bottomNavigationBar: NavigationBar(
      selectedIndex: shell.currentIndex,
      onDestinationSelected: shell.goBranch,
      destinations: const [
        NavigationDestination(icon: Icon(Icons.home), label: 'Beranda'),
        NavigationDestination(icon: Icon(Icons.receipt), label: 'Pesanan'),
        NavigationDestination(icon: Icon(Icons.person), label: 'Profil'),
      ],
    ),
  ),
  branches: [
    StatefulShellBranch(routes: [GoRoute(path: '/', builder: (_, __) => const BerandaPage())]),
    StatefulShellBranch(routes: [GoRoute(path: '/pesanan', builder: (_, __) => const PesananPage())]),
    StatefulShellBranch(routes: [GoRoute(path: '/profil', builder: (_, __) => const ProfilPage())]),
  ],
)

Poin penting

  • go_router: setiap layar punya alamat.
  • context.go mengganti, context.push menumpuk.
  • redirect untuk melindungi layar login.

Cek pemahaman

Jawaban: context.push('/produk/12')
