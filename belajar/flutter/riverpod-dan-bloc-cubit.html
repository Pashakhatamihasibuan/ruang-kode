Riverpod dan BLoC/Cubit

Buka versi interaktif

Riverpod (dari pembuat Provider) menyimpan state di provider global yang aman dan mudah diuji. Bungkus aplikasi dengan ProviderScope, lalu baca dengan ref.watch di ConsumerWidget. Untuk state yang punya logika, pakai Notifier dan NotifierProvider.

BLoC memisahkan tampilan dari logika: tampilan mengirim event, BLoC mengeluarkan state baru. Versi ringkasnya, Cubit, cukup memanggil emit(stateBaru). Tampilan memakai BlocBuilder. Banyak perusahaan besar memilih BLoC karena alurnya jelas dan mudah diuji.

Ketiganya menyelesaikan masalah yang sama. Pelajari satu dengan baik dulu; konsep "state di satu tempat, tampilan hanya membaca" berlaku di semuanya.

KODE
// ---- Riverpod ----
class Penghitung extends Notifier<int> {
  @override
  int build() => 0;
  void tambah() => state++;
}
final penghitungProvider = NotifierProvider<Penghitung, int>(Penghitung.new);

class HalamanAngka extends ConsumerWidget {
  const HalamanAngka({super.key});
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final angka = ref.watch(penghitungProvider);
    return TextButton(
      onPressed: () => ref.read(penghitungProvider.notifier).tambah(),
      child: Text('Angka: $angka'),
    );
  }
}
// main: runApp(const ProviderScope(child: MyApp()));

// ---- Cubit (flutter_bloc) ----
class SaldoCubit extends Cubit<int> {
  SaldoCubit() : super(0);
  void isi(int n) => emit(state + n);
}
// BlocBuilder<SaldoCubit, int>(builder: (context, saldo) => Text('$saldo'))

Soal latihan

  1. Buat FutureProvider Riverpod yang mengambil daftar kota, lalu tampilkan memuat/gagal/berhasil dengan .when.

    Petunjuk

    ref.watch(provider).when(data: ..., loading: ..., error: ...).

    Lihat jawaban
    KODE
    final kotaProvider = FutureProvider<List<Kota>>((ref) => ambilCuaca());

class HalamanKota extends ConsumerWidget {
  const HalamanKota({super.key});
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    return ref.watch(kotaProvider).when(
          loading: () => const Center(child: CircularProgressIndicator()),
          error: (e, _) => Center(child: Text('Gagal: $e')),
          data: (daftar) => ListView(
            children: [for (final k in daftar) ListTile(title: Text(k.nama))],
          ),
        );
  }
}

  2. Buat Cubit TemaCubit yang menyimpan bool gelap dan method ganti().

    Petunjuk

    class TemaCubit extends Cubit<bool> { TemaCubit() : super(false); void ganti() => emit(!state); }

    Lihat jawaban
    KODE
    class TemaCubit extends Cubit<bool> {
  TemaCubit() : super(false);
  void ganti() => emit(!state);
}

// di MaterialApp
BlocBuilder<TemaCubit, bool>(
  builder: (context, gelap) => MaterialApp(
    themeMode: gelap ? ThemeMode.dark : ThemeMode.light,
    darkTheme: ThemeData.dark(useMaterial3: true),
    home: const Beranda(),
  ),
)

Poin penting

  • Riverpod: ProviderScope, ref.watch, Notifier.
  • Cubit: emit state baru.
  • Konsepnya sama: state di satu tempat.

Cek pemahaman

Di Cubit, cara mengubah state?

Jawaban: emit(...)

emit mengeluarkan state baru.

Di Riverpod, widget yang bisa membaca provider adalah?

Jawaban: ConsumerWidget

ConsumerWidget menerima WidgetRef.
