Memasang Flutter dan membuat proyek

Buka versi interaktif

Unduh Flutter SDK dari docs.flutter.dev sesuai sistem operasimu, lalu tambahkan folder flutter/bin ke PATH. Pasang Android Studio (untuk Android SDK dan emulator) dan VS Code dengan ekstensi Flutter. Membuat aplikasi iOS memerlukan Mac dengan Xcode.

Perintah flutter doctor memeriksa apa yang belum lengkap dan memberi saran perbaikannya. Jalankan berulang sampai semua bagian yang kamu butuhkan bercentang hijau.

Buat proyek dengan flutter create toko_kopi, masuk ke foldernya, lalu flutter run. Kode utama ada di lib/main.dart, dependensi di pubspec.yaml, dan folder android/, ios/, web/ berisi konfigurasi tiap platform.

Struktur proyek Flutter
Folder/fileIsi
lib/main.dartTitik awal aplikasi
lib/Seluruh kode Dart (layar, widget, model, layanan)
pubspec.yamlNama, versi, package, aset, font
assets/Gambar dan file lain (didaftarkan di pubspec)
test/Unit test dan widget test
android/, ios/, web/Konfigurasi khusus platform
TERMINAL
# periksa instalasi
flutter doctor

# buat dan jalankan proyek
flutter create toko_kopi
cd toko_kopi
flutter run

# tambah package
flutter pub add provider go_router http

# build untuk rilis
flutter build apk --release
flutter build web

Soal latihan

  1. Tulis perintah untuk membuat proyek bernama kasir_app dengan nama organisasi id.ruangkode, hanya untuk Android dan iOS.

    Petunjuk

    flutter create punya opsi --org dan --platforms.

    Lihat jawaban
    TERMINAL
    flutter create --org id.ruangkode --platforms android,ios kasir_app

  2. Daftarkan folder gambar assets/images/ dan font Poppins di pubspec.yaml.

    Petunjuk

    Bagian flutter: berisi assets: dan fonts:.

    Lihat jawaban
    YAML
    flutter:
  uses-material-design: true
  assets:
    - assets/images/
  fonts:
    - family: Poppins
      fonts:
        - asset: assets/fonts/Poppins-Regular.ttf
        - asset: assets/fonts/Poppins-Bold.ttf
          weight: 700

Poin penting

  • flutter doctor memeriksa instalasi.
  • flutter create, flutter run.
  • Kode utama di lib/, dependensi di pubspec.yaml.
