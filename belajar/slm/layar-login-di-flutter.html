Layar login di Flutter

Buka versi interaktif

Desain login: logo, judul "Masuk", subjudul, field email, field kata sandi dengan tombol tampilkan, link "Lupa kata sandi" rata kanan, tombol Masuk lebar penuh, dan teks "Belum punya akun? Daftar" di bawah. Padding layar 24, gap antar field 16, tombol tinggi 52.

Strukturnya: Scaffold → SafeArea → SingleChildScrollView (agar tidak tertutup keyboard) → Padding → Column. Warna dan teks diambil dari tema. Field memakai TextFormField dengan InputDecoration berlabel, bukan hanya hint.

Perhatikan detail dari desain yang sering terlewat: keyboardType: TextInputType.emailAddress, textInputAction: TextInputAction.next agar tombol keyboard pindah ke field berikutnya, dan autofillHints agar pengelola sandi bisa mengisi otomatis.

KODE
class LoginPage extends StatefulWidget {
  const LoginPage({super.key});
  @override
  State<LoginPage> createState() => _LoginPageState();
}

class _LoginPageState extends State<LoginPage> {
  bool _sembunyi = true;

  @override
  Widget build(BuildContext context) {
    final t = Theme.of(context);
    return Scaffold(
      body: SafeArea(
        child: SingleChildScrollView(
          padding: const EdgeInsets.all(24),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            spacing: 16,
            children: [
              const SizedBox(height: 32),
              Text('Masuk', style: t.textTheme.headlineMedium),
              Text('Lanjutkan belajarmu hari ini.', style: t.textTheme.bodyLarge),
              const TextField(
                keyboardType: TextInputType.emailAddress,
                textInputAction: TextInputAction.next,
                autofillHints: [AutofillHints.email],
                decoration: InputDecoration(labelText: 'Email', border: OutlineInputBorder()),
              ),
              TextField(
                obscureText: _sembunyi,
                autofillHints: const [AutofillHints.password],
                decoration: InputDecoration(
                  labelText: 'Kata sandi',
                  border: const OutlineInputBorder(),
                  suffixIcon: IconButton(
                    tooltip: _sembunyi ? 'Tampilkan sandi' : 'Sembunyikan sandi',
                    icon: Icon(_sembunyi ? Icons.visibility : Icons.visibility_off),
                    onPressed: () => setState(() => _sembunyi = !_sembunyi),
                  ),
                ),
              ),
              Align(
                alignment: Alignment.centerRight,
                child: TextButton(onPressed: () {}, child: const Text('Lupa kata sandi?')),
              ),
              FilledButton(
                style: FilledButton.styleFrom(minimumSize: const Size.fromHeight(52)),
                onPressed: () {},
                child: const Text('Masuk'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Soal latihan

  1. Tambahkan validasi pada field email login: wajib diisi dan harus mengandung @, dengan pesan error berbahasa Indonesia.

    Petunjuk

    TextFormField + validator di dalam Form.

    Lihat jawaban
    KODE
    TextFormField(
  decoration: const InputDecoration(labelText: 'Email', border: OutlineInputBorder()),
  keyboardType: TextInputType.emailAddress,
  validator: (v) {
    if (v == null || v.trim().isEmpty) return 'Email wajib diisi';
    if (!v.contains('@')) return 'Format email belum benar, contoh: nama@contoh.com';
    return null;
  },
)

Poin penting

  • Scaffold → SafeArea → SingleChildScrollView → Column.
  • labelText, keyboardType, textInputAction, autofillHints.
  • Tombol lebar penuh: minimumSize Size.fromHeight(52).

Jawaban: textInputAction: TextInputAction.next
