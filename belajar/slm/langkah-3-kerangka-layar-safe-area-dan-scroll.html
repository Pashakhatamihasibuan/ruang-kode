Langkah 3: kerangka layar, safe area, dan scroll

Buka versi interaktif

Bungkus layar dengan Scaffold dan safe area agar tidak tertimpa status bar atau notch. Isi diletakkan dalam kolom yang bisa di-scroll, supaya saat keyboard muncul pengguna tetap bisa mencapai tombol Masuk.

Pakai padding 24 dp dari token. Batasi lebar maksimum isi (misalnya 480 dp) dan letakkan di tengah agar di tablet form tidak melebar sepanjang layar.

Kerangka Compose padanannya: Scaffold + Column(Modifier.verticalScroll(rememberScrollState()).imePadding().padding(24.dp).widthIn(max = 480.dp)).

KODE
class LayarMasuk extends StatelessWidget {
  const LayarMasuk({super.key});

  @override
  Widget build(BuildContext context) {
    final t = Theme.of(context).textTheme;
    return Scaffold(
      body: SafeArea(
        child: Center(
          child: SingleChildScrollView(
            padding: const EdgeInsets.all(24),
            child: ConstrainedBox(
              constraints: const BoxConstraints(maxWidth: 480),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.stretch,
                children: [
                  const Align(alignment: Alignment.centerLeft, child: LogoKopi(ukuran: 48)),
                  const SizedBox(height: 24),
                  Text('Masuk', style: t.headlineSmall),
                  const SizedBox(height: 4),
                  Text('Pesan kopi favoritmu lebih cepat.', style: t.bodyMedium),
                  const SizedBox(height: 32),
                  const FormMasuk(),
                ],
              ),
            ),
          ),
        ),
      ),
    );
  }
}

Poin penting

  • Scaffold + SafeArea.
  • Isi bisa di-scroll agar tidak tertutup keyboard.
  • Lebar maksimum 480 dp untuk tablet.
