Kartu produk dan LazyVerticalGrid di Compose

Buka versi interaktif

Di Compose, grid yang bisa digulir adalah LazyVerticalGrid. GridCells.Fixed(2) untuk dua kolom tetap, atau GridCells.Adaptive(minSize = 160.dp) untuk jumlah kolom yang menyesuaikan layar, persis seperti auto-fill minmax(160px, 1fr) di CSS.

Kartu memakai Card Material 3. Foto dimuat dari internet dengan pustaka Coil (AsyncImage) dan dipotong dengan ContentScale.Crop serta Modifier.aspectRatio(1f).

Beri setiap item key yang stabil (misalnya id produk) agar Compose tidak menggambar ulang semua kartu saat daftar berubah.

KODE
@Composable
fun KatalogGrid(produk: List<Produk>, onTambah: (Produk) -> Unit) {
    val rupiah = remember { NumberFormat.getCurrencyInstance(Locale("id", "ID")).apply { maximumFractionDigits = 0 } }
    LazyVerticalGrid(
        columns = GridCells.Adaptive(minSize = 160.dp),
        contentPadding = PaddingValues(16.dp),
        horizontalArrangement = Arrangement.spacedBy(12.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        items(produk, key = { it.id }) { p ->
            Card(shape = RoundedCornerShape(12.dp)) {
                AsyncImage(
                    model = p.fotoUrl, contentDescription = p.nama,
                    contentScale = ContentScale.Crop,
                    modifier = Modifier.fillMaxWidth().aspectRatio(1f)
                )
                Column(Modifier.padding(12.dp), verticalArrangement = Arrangement.spacedBy(4.dp)) {
                    Text(p.nama, maxLines = 2, overflow = TextOverflow.Ellipsis, style = MaterialTheme.typography.titleSmall)
                    Text(
                        rupiah.format(p.harga),
                        style = MaterialTheme.typography.titleMedium,
                        fontWeight = FontWeight.Bold,
                        color = MaterialTheme.colorScheme.primary
                    )
                }
            }
        }
    }
}

Soal latihan

  1. Tambahkan lencana "Baru" di pojok kiri atas foto kartu Compose.

    Petunjuk

    Box dengan Modifier.align(Alignment.TopStart).

    Lihat jawaban
    KODE
    Box {
    AsyncImage(model = p.fotoUrl, contentDescription = p.nama, contentScale = ContentScale.Crop,
        modifier = Modifier.fillMaxWidth().aspectRatio(1f))
    Surface(
        shape = CircleShape, color = Color.White,
        modifier = Modifier.align(Alignment.TopStart).padding(8.dp)
    ) {
        Text("Baru", style = MaterialTheme.typography.labelMedium, modifier = Modifier.padding(horizontal = 8.dp, vertical = 2.dp))
    }
}

Poin penting

  • LazyVerticalGrid + GridCells.Adaptive mirip auto-fill.
  • AsyncImage (Coil) + ContentScale.Crop + aspectRatio.
  • key yang stabil untuk setiap item.

Cek pemahaman

GridCells.Adaptive(160.dp) di layar 400dp (abaikan padding) menghasilkan berapa kolom?

Jawaban: 2

400 / 160 = 2 kolom muat.
