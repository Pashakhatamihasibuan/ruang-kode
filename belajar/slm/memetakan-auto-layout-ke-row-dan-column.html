Memetakan auto layout ke Row dan Column

Buka versi interaktif

Auto layout Figma diterjemahkan hampir satu banding satu. Vertical menjadi Column, horizontal menjadi Row, gap menjadi SizedBox atau spacing (Flutter 3.27+) dan Arrangement.spacedBy() di Compose, padding menjadi Padding atau Modifier.padding.

Fill container menjadi Expanded (Flutter) atau Modifier.weight(1f) / fillMaxWidth() (Compose). Hug contents adalah perilaku bawaan. Elemen bertumpuk (gambar dengan lencana di pojok) menjadi Stack di Flutter dan Box di Compose.

Daftar panjang yang bisa digulir jangan memakai Column biasa: pakai ListView.builder (Flutter) atau LazyColumn (Compose) agar hanya item yang terlihat yang dibuat.

Soal latihan

  1. Terjemahkan ke Flutter: frame horizontal, padding 16, gap 12, align center; anak: avatar 40×40, kolom teks (Fill), ikon chevron (Hug).

    Petunjuk

    Row + Expanded untuk Fill.

    Lihat jawaban
    KODE
    Padding(
  padding: const EdgeInsets.all(16),
  child: Row(
    spacing: 12,
    children: [
      const CircleAvatar(radius: 20),
      Expanded(
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: const [Text('Rina Siregar'), Text('Flutter Developer')],
        ),
      ),
      const Icon(Icons.chevron_right),
    ],
  ),
)

Poin penting

  • Vertical = Column, horizontal = Row.
  • Fill = Expanded / weight; bertumpuk = Stack / Box.
  • Daftar panjang = ListView.builder / LazyColumn.
