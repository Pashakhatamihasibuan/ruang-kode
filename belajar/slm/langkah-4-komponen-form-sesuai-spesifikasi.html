Langkah 4: komponen form sesuai spesifikasi

Buka versi interaktif

Buat field email dan kata sandi dengan TextFormField (Flutter) atau OutlinedTextField (Compose). Lengkapi atribut yang tidak terlihat di desain tetapi penting: keyboardType, textInputAction, autofillHints (agar password manager bekerja), dan ikon untuk menampilkan kata sandi.

Jarak antar elemen mengikuti redline (16, 8, 24 dp). Tombol utama memakai FilledButton lebar penuh setinggi 48 dp dari tema; tombol Google memakai OutlinedButton.

Label teks yang dibaca pembaca layar (TalkBack) harus jelas: ikon mata perlu tooltip atau contentDescription "Tampilkan kata sandi".

KODE
class FormMasuk extends StatefulWidget {
  const FormMasuk({super.key});
  @override
  State<FormMasuk> createState() => _FormMasukState();
}

class _FormMasukState extends State<FormMasuk> {
  bool sembunyi = true;

  @override
  Widget build(BuildContext context) {
    return AutofillGroup(
      child: Column(crossAxisAlignment: CrossAxisAlignment.stretch, children: [
        const TextField(
          keyboardType: TextInputType.emailAddress,
          textInputAction: TextInputAction.next,
          autofillHints: [AutofillHints.email],
          decoration: InputDecoration(labelText: 'Email'),
        ),
        const SizedBox(height: 16),
        TextField(
          obscureText: sembunyi,
          textInputAction: TextInputAction.done,
          autofillHints: const [AutofillHints.password],
          decoration: InputDecoration(
            labelText: 'Kata sandi',
            suffixIcon: IconButton(
              tooltip: sembunyi ? 'Tampilkan kata sandi' : 'Sembunyikan kata sandi',
              icon: Icon(sembunyi ? Icons.visibility : Icons.visibility_off),
              onPressed: () => setState(() => sembunyi = !sembunyi),
            ),
          ),
        ),
        const SizedBox(height: 8),
        Align(alignment: Alignment.centerRight,
            child: TextButton(onPressed: () {}, child: const Text('Lupa kata sandi?'))),
        const SizedBox(height: 24),
        FilledButton(onPressed: () {}, child: const Text('Masuk')),
        const SizedBox(height: 16),
        const Text('atau', textAlign: TextAlign.center),
        const SizedBox(height: 16),
        OutlinedButton(onPressed: () {}, child: const Text('Lanjut dengan Google')),
      ]),
    );
  }
}

Soal latihan

  1. Tulis field kata sandi Compose dengan ikon mata untuk menampilkan atau menyembunyikan, tinggi minimal 56 dp.

    Petunjuk

    OutlinedTextField + visualTransformation + trailingIcon.

    Lihat jawaban
    KODE
    var sandi by remember { mutableStateOf("") }
var lihat by remember { mutableStateOf(false) }
OutlinedTextField(
    value = sandi,
    onValueChange = { sandi = it },
    label = { Text("Kata sandi") },
    singleLine = true,
    visualTransformation = if (lihat) VisualTransformation.None else PasswordVisualTransformation(),
    keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Password, imeAction = ImeAction.Done),
    trailingIcon = {
        IconButton(onClick = { lihat = !lihat }) {
            Icon(if (lihat) Icons.Default.VisibilityOff else Icons.Default.Visibility,
                 contentDescription = if (lihat) "Sembunyikan kata sandi" else "Tampilkan kata sandi")
        }
    },
    shape = RoundedCornerShape(12.dp),
    modifier = Modifier.fillMaxWidth().heightIn(min = 56.dp),
)

Poin penting

  • keyboardType, textInputAction, autofillHints.
  • Jarak sesuai redline, ukuran dari tema.
  • Tooltip untuk ikon agar terbaca TalkBack.
