Layar login di Jetpack Compose

Buka versi interaktif

Desain yang sama di Compose: Scaffold memberi innerPadding untuk inset sistem, lalu Column dengan verticalScroll, imePadding() agar naik di atas keyboard, dan Arrangement.spacedBy(16.dp) untuk gap.

State field disimpan dengan rememberSaveable agar tidak hilang saat layar diputar. OutlinedTextField sudah punya label mengambang sesuai Material 3. Opsi keyboard diatur lewat KeyboardOptions.

Nilai ukuran diambil langsung dari Figma: padding 24.dp, tinggi tombol 52.dp, radius 12.dp. Warna dan gaya teks dari MaterialTheme.

KODE
@Composable
fun LoginScreen(onMasuk: (String, String) -> Unit) {
    var email by rememberSaveable { mutableStateOf("") }
    var sandi by rememberSaveable { mutableStateOf("") }
    var sembunyi by rememberSaveable { mutableStateOf(true) }

    Scaffold { innerPadding ->
        Column(
            modifier = Modifier
                .padding(innerPadding)
                .imePadding()
                .verticalScroll(rememberScrollState())
                .padding(24.dp),
            verticalArrangement = Arrangement.spacedBy(16.dp)
        ) {
            Spacer(Modifier.height(32.dp))
            Text("Masuk", style = MaterialTheme.typography.headlineMedium)
            Text("Lanjutkan belajarmu hari ini.", style = MaterialTheme.typography.bodyLarge)
            OutlinedTextField(
                value = email, onValueChange = { email = it },
                label = { Text("Email") }, singleLine = true,
                keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Email, imeAction = ImeAction.Next),
                modifier = Modifier.fillMaxWidth()
            )
            OutlinedTextField(
                value = sandi, onValueChange = { sandi = it },
                label = { Text("Kata sandi") }, singleLine = true,
                visualTransformation = if (sembunyi) PasswordVisualTransformation() else VisualTransformation.None,
                trailingIcon = {
                    IconButton(onClick = { sembunyi = !sembunyi }) {
                        Icon(
                            if (sembunyi) Icons.Filled.Visibility else Icons.Filled.VisibilityOff,
                            contentDescription = if (sembunyi) "Tampilkan sandi" else "Sembunyikan sandi"
                        )
                    }
                },
                keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Password, imeAction = ImeAction.Done),
                modifier = Modifier.fillMaxWidth()
            )
            TextButton(onClick = {}, modifier = Modifier.align(Alignment.End)) { Text("Lupa kata sandi?") }
            Button(
                onClick = { onMasuk(email, sandi) },
                shape = RoundedCornerShape(12.dp),
                modifier = Modifier.fillMaxWidth().height(52.dp)
            ) { Text("Masuk") }
        }
    }
}

Soal latihan

  1. Tampilkan pesan error di bawah OutlinedTextField email jika tidak mengandung @.

    Petunjuk

    Parameter isError dan supportingText.

    Lihat jawaban
    KODE
    val salah = email.isNotEmpty() && !email.contains("@")
OutlinedTextField(
    value = email, onValueChange = { email = it },
    label = { Text("Email") },
    isError = salah,
    supportingText = { if (salah) Text("Format email belum benar, contoh: nama@contoh.com") },
    modifier = Modifier.fillMaxWidth()
)

Poin penting

  • Scaffold innerPadding + imePadding + verticalScroll.
  • rememberSaveable untuk state field.
  • contentDescription untuk ikon yang bisa ditekan.
