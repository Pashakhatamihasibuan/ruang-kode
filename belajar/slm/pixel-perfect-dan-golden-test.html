Pixel-perfect dan golden test

Buka versi interaktif

Di mobile, membandingkan dengan desain dilakukan dengan menjalankan aplikasi di emulator berukuran sama dengan frame Figma (misalnya Pixel 7, 412 × 915 dp), mengambil tangkapan layar, lalu menumpuknya dengan ekspor frame di Figma (opacity 50%). Flutter juga punya Flutter Inspector dengan "Show guidelines" untuk melihat padding dan batas widget.

Agar tampilan yang sudah benar tidak rusak diam-diam di kemudian hari, buat golden test (Flutter) atau screenshot test (Compose, dengan Roborazzi atau Paparazzi). Tes merender widget, menyimpan gambar acuan, dan gagal jika tampilan berubah walau satu piksel.

Simpan gambar acuan di repositori, dan perbarui hanya jika perubahan tampilan memang disengaja (flutter test --update-goldens).

KODE
// test/kartu_produk_golden_test.dart
void main() {
  testWidgets('KartuProduk sesuai desain', (tester) async {
    tester.view.physicalSize = const Size(360, 300);
    tester.view.devicePixelRatio = 1.0;
    await tester.pumpWidget(MaterialApp(
      theme: temaKopiNusa,
      home: const Scaffold(body: KartuProduk(nama: 'Kopi Susu Aren', harga: 22000)),
    ));
    await expectLater(find.byType(KartuProduk), matchesGoldenFile('goldens/kartu_produk.png'));
  });
}

// Jalankan pertama kali (membuat gambar acuan):
//   flutter test --update-goldens
// Jalankan berikutnya (membandingkan):
//   flutter test

Soal latihan

  1. Tulis langkah membandingkan layar Beranda di emulator dengan frame Figma.

    Petunjuk

    Ukuran sama, tangkapan layar, tumpuk dengan opacity.

    Lihat jawaban
    CONTOH
    1. Buat emulator dengan lebar sama dengan frame (misal 412 dp).
2. Jalankan aplikasi, ambil tangkapan layar Beranda.
3. Ekspor frame Figma pada skala yang sama dengan densitas emulator.
4. Tumpuk di Figma: tangkapan layar di atas, opacity 50%.
5. Catat selisih jarak, ukuran huruf, warna; perbaiki yang berdampak besar dulu.

Poin penting

  • Bandingkan di emulator berukuran sama dengan frame Figma.
  • Golden test (Flutter) dan screenshot test (Roborazzi, Paparazzi).
  • Perbarui acuan hanya untuk perubahan yang disengaja.
