Ekspor aset dan ikon

Buka versi interaktif

Ikon: ekspor sebagai SVG. Di Flutter, pakai paket flutter_svg, atau ubah ikon menjadi font ikon. Di Android, impor SVG lewat Resource Manager → Vector Asset sehingga menjadi file XML di res/drawable. Jika ikon ada di Material Symbols, langsung pakai Icons.Outlined.ShoppingCart tanpa ekspor.

Gambar bitmap: Flutter memakai folder resolusi assets/images/, assets/images/2.0x/, assets/images/3.0x/ dengan nama file yang sama; Flutter memilih otomatis. Android memakai drawable-mdpi, -hdpi, -xhdpi, -xxhdpi, -xxxhdpi (1×, 1,5×, 2×, 3×, 4×), atau cukup WebP satu ukuran besar di drawable-nodpi untuk ilustrasi.

Nama aset: huruf kecil, garis bawah, tanpa spasi (ic_cart.xml, img_onboarding_1.webp). Android menolak nama dengan huruf besar atau tanda hubung.

YAML
# pubspec.yaml (Flutter)
dependencies:
  flutter_svg: ^2.0.10

flutter:
  assets:
    - assets/icons/
    - assets/images/

# Struktur folder
assets/
  icons/ic_cart.svg
  images/img_hero.png
  images/2.0x/img_hero.png
  images/3.0x/img_hero.png

Soal latihan

  1. Tampilkan ikon SVG keranjang 24×24 berwarna primary tema di Flutter.

    Petunjuk

    SvgPicture.asset dengan colorFilter.

    Lihat jawaban
    KODE
    SvgPicture.asset(
  'assets/icons/ic_cart.svg',
  width: 24,
  height: 24,
  colorFilter: ColorFilter.mode(Theme.of(context).colorScheme.primary, BlendMode.srcIn),
  semanticsLabel: 'Keranjang',
)

Poin penting

  • Ikon SVG: flutter_svg atau Vector Asset Android.
  • Bitmap: folder 2.0x 3.0x (Flutter) atau drawable-xxhdpi (Android).
  • Nama aset huruf kecil dan garis bawah.
