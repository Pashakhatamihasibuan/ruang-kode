Layar berbagai ukuran

Buka versi interaktif

Desain biasanya hanya untuk ponsel 360 sampai 393 dp, tetapi aplikasi juga berjalan di ponsel kecil (320 dp), ponsel lipat, dan tablet. Uji desain di ukuran terkecil (teks tidak terpotong, tombol tidak bertumpuk) dan terbesar (konten tidak melar terlalu lebar).

Flutter: LayoutBuilder memberi lebar induk, MediaQuery.sizeOf(context) memberi ukuran layar. Compose: currentWindowAdaptiveInfo().windowSizeClass memberi kelas compact (< 600 dp), medium (600 sampai 839), dan expanded (≥ 840). Pustaka adaptive navigation suite otomatis mengganti NavigationBar menjadi NavigationRail di layar lebar.

Jangan lupa pengguna dengan ukuran huruf besar di pengaturan sistem. Uji dengan skala huruf 1,3× dan 2×: tinggi tetap pada kontainer teks adalah penyebab utama teks terpotong. Pakai tinggi minimum, bukan tinggi tetap.

KODE
// Flutter: 2 kolom di ponsel, 4 kolom mulai 600 dp
LayoutBuilder(
  builder: (context, c) {
    final kolom = c.maxWidth >= 840 ? 4 : c.maxWidth >= 600 ? 3 : 2;
    return GridView.count(crossAxisCount: kolom, children: kartu);
  },
)

// Compose: NavigationBar di ponsel, NavigationRail di layar lebar
val kelas = currentWindowAdaptiveInfo().windowSizeClass
if (kelas.isWidthAtLeastBreakpoint(WindowSizeClass.WIDTH_DP_MEDIUM_LOWER_BOUND)) {
    Row { NavigationRail { /* ... */ }; Konten() }
} else {
    Scaffold(bottomBar = { NavigationBar { /* ... */ } }) { Konten() }
}

Soal latihan

  1. Batasi lebar konten maksimal 600 dan letakkan di tengah agar tidak melar di tablet.

Poin penting

  • Uji di ukuran terkecil dan terbesar.
  • LayoutBuilder / WindowSizeClass: compact, medium, expanded.
  • Uji skala huruf 1,3× dan 2×; hindari tinggi tetap.
