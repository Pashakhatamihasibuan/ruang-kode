Langkah 2: token menjadi tema

Buka versi interaktif

Jangan menulis warna dan ukuran teks langsung di setiap widget. Masukkan token ke tema: ThemeData dengan ColorScheme.fromSeed di Flutter, atau MaterialTheme dengan lightColorScheme di Compose. Bentuk input dan tombol (radius 12) juga diatur sekali di tema.

Dengan tema, mode gelap tinggal menambah skema gelap, dan semua komponen Material 3 otomatis mengikuti.

Kode di bawah memakai Flutter. Versi Compose ada di soal latihan.

KODE
final temaKopi = ThemeData(
  useMaterial3: true,
  colorScheme: ColorScheme.fromSeed(
    seedColor: const Color(0xFF8A4B2A),
    primary: const Color(0xFF8A4B2A),
    surface: const Color(0xFFFBF7F2),
  ),
  textTheme: const TextTheme(
    headlineSmall: TextStyle(fontSize: 24, height: 32 / 24, fontWeight: FontWeight.w700),
  ),
  inputDecorationTheme: InputDecorationTheme(
    filled: true,
    fillColor: Colors.white,
    border: OutlineInputBorder(borderRadius: BorderRadius.circular(12)),
  ),
  filledButtonTheme: FilledButtonThemeData(
    style: FilledButton.styleFrom(
      minimumSize: const Size.fromHeight(48),
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
    ),
  ),
);

// MaterialApp(theme: temaKopi, darkTheme: temaKopiGelap, home: const LayarMasuk())

Soal latihan

  1. Tulis tema Compose dengan primary #8A4B2A, surface #FBF7F2, dan headlineSmall 24/32 sp bold.

    Petunjuk

    lightColorScheme dan Typography.

    Lihat jawaban
    KODE
    private val Skema = lightColorScheme(
    primary = Color(0xFF8A4B2A),
    surface = Color(0xFFFBF7F2),
)
private val Huruf = Typography(
    headlineSmall = TextStyle(fontSize = 24.sp, lineHeight = 32.sp, fontWeight = FontWeight.Bold),
)

@Composable
fun TemaKopi(isi: @Composable () -> Unit) =
    MaterialTheme(colorScheme = Skema, typography = Huruf, shapes = Shapes(medium = RoundedCornerShape(12.dp)), content = isi)

Poin penting

  • Token masuk ke tema, bukan ke setiap widget.
  • Bentuk input dan tombol diatur sekali.
  • Mode gelap cukup skema kedua.
