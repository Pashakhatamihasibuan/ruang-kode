Proyek: slicing aplikasi kedai kopi

Buka versi interaktif

Proyek akhir: slicing empat layar aplikasi KopiNusa dari desain (atau buat desain sederhana sendiri di Figma terlebih dahulu): Login, Beranda (sapaan, banner promo, kategori chip, grid produk), Detail produk (foto besar, pilihan ukuran dan gula dengan SegmentedButton atau ChoiceChip, jumlah, tombol Tambah), dan Keranjang (daftar item, total, tombol Bayar).

Pilih salah satu: Flutter atau Jetpack Compose. Kerjakan berurutan: tema dan token dulu, lalu komponen (KartuProduk, ChipKategori, BarisKeranjang), baru susun layar. Pakai data dummy dari list lokal.

Kriteria selesai di tabel bawah. Unggah ke GitHub dengan README berisi tangkapan layar setiap layar dan perbandingan dengan desain.
