Langkah 6: QA dengan desain dan serah terima

Buka versi interaktif

Bandingkan hasil dengan desain di perangkat nyata atau emulator 360 × 800 dp. Ambil tangkapan layar dan tumpuk di atas frame Figma (opacity 50%). Periksa jarak, ukuran teks, warna, dan radius.

Uji kasus yang tidak ada di desain: ukuran huruf sistem 200%, layar kecil 320 dp, tablet, mode gelap, orientasi lanskap, TalkBack, dan keyboard terbuka. Kunci tampilan dengan golden test (Flutter) atau screenshot test seperti Roborazzi atau Paparazzi (Compose) agar perubahan tak sengaja langsung ketahuan.

Serah terima: rekaman layar alur Masuk, tangkapan layar setiap state, daftar perbedaan yang disengaja, dan build uji (Firebase App Distribution atau internal testing Play).

KODE
testWidgets('layar Masuk sesuai desain', (tester) async {
  tester.view.physicalSize = const Size(1080, 2400);   // 360 × 800 dp pada 3x
  tester.view.devicePixelRatio = 3;
  await tester.pumpWidget(MaterialApp(theme: temaKopi, home: const LayarMasuk()));
  await expectLater(find.byType(LayarMasuk), matchesGoldenFile('goldens/masuk_360.png'));
});

// perbarui golden setelah desain disetujui:
// flutter test --update-goldens

Poin penting

  • Overlay dengan frame Figma di 360 × 800 dp.
  • Uji huruf besar, layar kecil, tablet, gelap, TalkBack.
  • Golden atau screenshot test untuk mengunci tampilan.
