Kartu produk dan grid di Flutter

Buka versi interaktif

Desain katalog: grid 2 kolom, gap 12, padding layar 16. Kartu berisi foto rasio 1:1 dengan radius 12, nama produk (maksimal 2 baris), harga tebal berwarna primary, dan tombol tambah kecil.

Pakai GridView.builder dengan SliverGridDelegateWithFixedCrossAxisCount (jumlah kolom tetap) atau SliverGridDelegateWithMaxCrossAxisExtent (lebar maksimum kartu, jumlah kolom menyesuaikan layar, mirip auto-fill di CSS). Atur childAspectRatio agar tinggi kartu cukup untuk foto dan teks, atau pakai mainAxisExtent untuk tinggi tetap.

Teks panjang dibatasi dengan maxLines: 2 dan overflow: TextOverflow.ellipsis. Format harga Rupiah dengan paket intl: NumberFormat.currency(locale: 'id', symbol: 'Rp', decimalDigits: 0).

KODE
final rupiah = NumberFormat.currency(locale: 'id', symbol: 'Rp', decimalDigits: 0);

GridView.builder(
  padding: const EdgeInsets.all(16),
  gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(
    maxCrossAxisExtent: 200,
    mainAxisSpacing: 12,
    crossAxisSpacing: 12,
    mainAxisExtent: 260,
  ),
  itemCount: produk.length,
  itemBuilder: (context, i) {
    final p = produk[i];
    final t = Theme.of(context);
    return Card(
      clipBehavior: Clip.antiAlias,
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          AspectRatio(aspectRatio: 1, child: Image.asset(p.foto, fit: BoxFit.cover)),
          Padding(
            padding: const EdgeInsets.all(12),
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              spacing: 4,
              children: [
                Text(p.nama, maxLines: 2, overflow: TextOverflow.ellipsis, style: t.textTheme.titleSmall),
                Text(rupiah.format(p.harga),
                    style: t.textTheme.titleMedium?.copyWith(color: t.colorScheme.primary, fontWeight: FontWeight.w700)),
              ],
            ),
          ),
        ],
      ),
    );
  },
)

    AspectRatio(aspectRatio: 1, child: Image.asset(p.foto, fit: BoxFit.cover)),
    Positioned(
      top: 8, left: 8,
      child: Container(
        padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 2),
        decoration: BoxDecoration(color: Colors.white, borderRadius: BorderRadius.circular(99)),
        child: const Text('Baru', style: TextStyle(fontSize: 12, fontWeight: FontWeight.w600)),

    ),
  ],

Poin penting

  • GridView.builder dengan MaxCrossAxisExtent mirip auto-fill.
  • AspectRatio 1 + BoxFit.cover untuk foto.
  • maxLines + ellipsis, format Rupiah dengan intl.

Cek pemahaman

Delegate yang menyesuaikan jumlah kolom dengan lebar layar?

Jawaban: SliverGridDelegateWithMaxCrossAxisExtent

Menentukan lebar maksimum, bukan jumlah kolom.
