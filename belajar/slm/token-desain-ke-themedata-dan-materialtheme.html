Token desain ke ThemeData dan MaterialTheme

Buka versi interaktif

Sama seperti di web, langkah pertama slicing mobile adalah memindahkan token. Di Flutter, warna masuk ke ColorScheme dan gaya teks ke TextTheme di dalam ThemeData. Di Compose, warna masuk ke lightColorScheme() atau darkColorScheme() dan teks ke Typography di dalam MaterialTheme.

Setelah itu, widget mengambil warna dari tema, bukan kode hex: Theme.of(context).colorScheme.primary di Flutter, MaterialTheme.colorScheme.primary di Compose. Dark mode cukup menyediakan skema kedua.

Jika desainer memakai Material Theme Builder di Figma, kamu bisa langsung mengekspor kode tema untuk Flutter dan Compose dari plugin itu.

// Flutter
final tema = ThemeData(
  useMaterial3: true,
  colorScheme: ColorScheme.fromSeed(seedColor: const Color(0xFF6D4C41)),
  textTheme: const TextTheme(
    headlineSmall: TextStyle(fontSize: 24, fontWeight: FontWeight.w600, height: 32 / 24),
    bodyLarge: TextStyle(fontSize: 16, height: 24 / 16),
    labelLarge: TextStyle(fontSize: 14, fontWeight: FontWeight.w500, letterSpacing: 0.1),
  ),
);

// Pemakaian
Text('Menu favorit', style: Theme.of(context).textTheme.headlineSmall);
Container(color: Theme.of(context).colorScheme.primaryContainer);

Soal latihan

  1. Buat skema warna terang Compose dari token: primary #6D4C41, onPrimary #FFFFFF, primaryContainer #FFDBCF, surface #FFF8F5.

    Petunjuk

    lightColorScheme dengan parameter bernama.

    Lihat jawaban
    KODE
    val KopiLight = lightColorScheme(
    primary = Color(0xFF6D4C41),
    onPrimary = Color(0xFFFFFFFF),
    primaryContainer = Color(0xFFFFDBCF),
    surface = Color(0xFFFFF8F5)
)

@Composable
fun KopiTheme(content: @Composable () -> Unit) {
    MaterialTheme(colorScheme = KopiLight, content = content)
}

Poin penting

  • Warna ke ColorScheme, teks ke TextTheme / Typography.
  • Widget mengambil dari tema, bukan hex.
  • Material Theme Builder bisa mengekspor kode tema.
