Bottom navigation dan top app bar

Buka versi interaktif

Material 3 menyebut bottom navigation sebagai NavigationBar: 3 sampai 5 tujuan, ikon dan label, indikator pill di item aktif. Di Flutter: NavigationBar dengan NavigationDestination. Di Compose: NavigationBar dengan NavigationBarItem.

Gunakan ikon outlined untuk item tidak aktif dan filled untuk item aktif jika desain memintanya (Flutter: icon dan selectedIcon). Badge jumlah notifikasi memakai widget Badge di keduanya.

Top app bar: AppBar (Flutter) atau TopAppBar / CenterAlignedTopAppBar (Compose). Desain dengan judul besar yang mengecil saat menggulir menjadi SliverAppBar.large di Flutter dan LargeTopAppBar dengan scrollBehavior di Compose.

KODE
// Flutter
NavigationBar(
  selectedIndex: indeks,
  onDestinationSelected: (i) => setState(() => indeks = i),
  destinations: const [
    NavigationDestination(icon: Icon(Icons.home_outlined), selectedIcon: Icon(Icons.home), label: 'Beranda'),
    NavigationDestination(icon: Icon(Icons.menu_book_outlined), selectedIcon: Icon(Icons.menu_book), label: 'Menu'),
    NavigationDestination(
      icon: Badge(label: Text('2'), child: Icon(Icons.shopping_bag_outlined)),
      selectedIcon: Icon(Icons.shopping_bag), label: 'Pesanan'),
    NavigationDestination(icon: Icon(Icons.person_outline), selectedIcon: Icon(Icons.person), label: 'Profil'),
  ],
)

// Jetpack Compose
NavigationBar {
    tujuan.forEachIndexed { i, t ->
        NavigationBarItem(
            selected = indeks == i,
            onClick = { indeks = i },
            icon = { Icon(if (indeks == i) t.ikonAktif else t.ikon, contentDescription = null) },
            label = { Text(t.label) }
        )
    }
}

Soal latihan

  1. Buat CenterAlignedTopAppBar dengan judul "KopiNusa" dan tombol ikon keranjang di kanan.

    Petunjuk

    actions berisi IconButton dengan contentDescription.

    Lihat jawaban
    KODE
    CenterAlignedTopAppBar(
    title = { Text("KopiNusa") },
    actions = {
        IconButton(onClick = onKeranjang) {
            Icon(Icons.Outlined.ShoppingCart, contentDescription = "Keranjang")
        }
    }
)

Poin penting

  • NavigationBar: 3–5 tujuan, ikon + label, indikator.
  • icon dan selectedIcon untuk outlined dan filled.
  • SliverAppBar.large / LargeTopAppBar untuk judul besar yang mengecil.

Cek pemahaman

Kenapa contentDescription ikon NavigationBarItem boleh null?

Jawaban: Karena label teks sudah menjelaskan tujuannya

Menghindari dibacakan dua kali.

Kerjakan latihannya di aplikasi

Sebelumnya: Kartu produk dan LazyVerticalGrid di Compose

Berikutnya: Layar berbagai ukuran
