Footer dan form newsletter

Buka versi interaktif

Footer berisi kelompok link (Produk, Perusahaan, Bantuan), media sosial, form newsletter, dan hak cipta. Di desktop kelompok link berdampingan; di mobile bertumpuk atau dilipat.

Form newsletter di desain sering hanya menampilkan input dengan placeholder "Email kamu" dan tombol. Input tetap butuh label; jika desain tidak menampilkannya, sembunyikan secara visual dengan kelas .sr-only tetapi tetap terbaca pembaca layar. Pakai type="email" dan autocomplete="email" agar keyboard ponsel menampilkan tombol @.

Ikon media sosial yang hanya berupa ikon wajib punya aria-label ("Instagram Ruang Kode").

Form newsletter di pratinjau belum punya label dan tipe input yang tepat.

HTML
<footer class="kaki">
  <form class="news">
    <input id="surel" placeholder="Email kamu">
    <button>Langganan</button>
  </form>
  <p>© 2026 RuangKode</p>
</footer>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.kaki { padding: 32px 16px; background: #0F172A; color: #CBD5E1; }
.news { display: flex; gap: 8px; flex-wrap: wrap; max-width: 420px; }
.news input { flex: 1; min-width: 200px; padding: 12px; border-radius: 10px; border: 1px solid #475569; background: #1E293B; color: #fff; font-size: 16px; }
.news button { padding: 12px 20px; border: 0; border-radius: 10px; background: #F59E0B; color: #1F2933; font-weight: 600; }
.sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0 0 0 0); white-space: nowrap; border: 0; }

Tantangan

  1. Tambahkan <label class="sr-only" for="surel">Email</label>, lalu beri input type="email" dan autocomplete="email".

Soal latihan

  1. Tulis tautan ikon Instagram dan YouTube yang aksesibel.

    Petunjuk

    aria-label pada tautan, aria-hidden pada ikon.

    Lihat jawaban
    HTML
    <a href="https://instagram.com/ruangkode" aria-label="Instagram Ruang Kode"><svg aria-hidden="true" width="24" height="24">...</svg></a>
<a href="https://youtube.com/@ruangkode" aria-label="YouTube Ruang Kode"><svg aria-hidden="true" width="24" height="24">...</svg></a>

Poin penting

  • Label tetap ada; sembunyikan secara visual dengan .sr-only.
  • type="email" dan autocomplete="email".
  • Ikon sosial butuh aria-label.
