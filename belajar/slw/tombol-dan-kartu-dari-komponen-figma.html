Tombol dan kartu dari komponen Figma

Buka versi interaktif

Komponen di Figma (tombol, kartu, badge) ditulis sekali sebagai kelas CSS, lalu dipakai ulang. Ambil semua variant-nya dari component set: ukuran, warna, state. Jangan lupa state yang tidak terlihat di frame utama: hover, focus-visible, active, disabled.

Efek hover kartu di desain sering berupa bayangan yang lebih tebal dan kartu sedikit naik. Tulis dengan transition agar halus (150 sampai 250 ms), dan hormati pengguna yang mematikan animasi dengan @media (prefers-reduced-motion: reduce).

Nilai bayangan Figma X 0, Y 8, Blur 24, Spread 0, #000 12% menjadi box-shadow: 0 8px 24px rgb(0 0 0 / .12).

Kartu menu di pratinjau belum punya efek hover.

HTML
<div class="grid">
  <article class="kartu"><div class="foto"></div><h3>Kopi Susu Aren</h3><p>Rp22.000</p></article>
  <article class="kartu"><div class="foto"></div><h3>Americano</h3><p>Rp18.000</p></article>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(160px, 1fr)); gap: 16px; padding: 16px; }
.kartu { background: #fff; border-radius: 16px; padding: 12px; box-shadow: 0 1px 3px rgb(0 0 0 / .12); transition: box-shadow .2s, transform .2s; }
.kartu h3 { margin: 12px 0 4px; font-size: 16px; }
.kartu p { margin: 0; color: #6D4C41; font-weight: 600; }
.foto { aspect-ratio: 1; border-radius: 12px; background: #D7B899; }
@media (prefers-reduced-motion: reduce) { .kartu { transition: none; } }

Tantangan

  1. Tambahkan aturan .kartu:hover dengan box-shadow: 0 8px 24px rgb(0 0 0 / .12) dan transform: translateY(-2px).

Soal latihan

  1. Tulis tombol primary dengan state hover, focus-visible, active, dan disabled.

    Petunjuk

    Lima aturan untuk satu komponen.

    Lihat jawaban
    CSS
    .btn-primary { background: #4F46E5; color: #fff; padding: 12px 20px; border: 0; border-radius: 12px; font-weight: 600; transition: background .15s; }
.btn-primary:hover { background: #4338CA; }
.btn-primary:focus-visible { outline: 3px solid #A5B4FC; outline-offset: 2px; }
.btn-primary:active { transform: translateY(1px); }
.btn-primary:disabled { background: #C7D2FE; cursor: not-allowed; }

Poin penting

  • Satu komponen Figma = satu kelas CSS dengan semua variant dan state.
  • Transisi 150–250 ms dan prefers-reduced-motion.
  • Bayangan Figma X Y Blur Spread → box-shadow.

Cek pemahaman

Drop shadow Figma Y 4, Blur 12, hitam 10% menjadi?

Jawaban: box-shadow: 0 4px 12px rgb(0 0 0 / .1)

Urutan: x y blur warna.
