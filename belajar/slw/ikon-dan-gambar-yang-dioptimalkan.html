Slicing Website · Modul 2 · Praktik langsung

Ikon dan gambar yang dioptimalkan

Buka versi interaktif

Ekspor dari Figma: ikon sebagai SVG (pilih ikon, Export, SVG), lalu sisipkan inline atau sebagai <img>. Foto sebagai WebP atau AVIF, dengan lebar 1× dan 2× ukuran tampilannya. Foto 4000 px untuk kartu 300 px membuat halaman lambat terutama di koneksi seluler.

Setiap <img> wajib: alt (deskripsi singkat, atau alt="" jika dekoratif), width dan height (agar browser menyiapkan ruang dan halaman tidak "melompat" saat gambar dimuat, yang diukur sebagai CLS), serta loading="lazy" untuk gambar di bawah layar pertama.

Gambar hero di layar pertama justru jangan diberi lazy; beri fetchpriority="high" agar dimuat paling awal.

Gambar di pratinjau belum punya atribut penting.

HTML
<section class="galeri">
  <img src="data:image/svg+xml,%3Csvg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 4 3'%3E%3Crect width='4' height='3' fill='%23D7B899'/%3E%3C/svg%3E">
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.galeri { padding: 16px; }
.galeri img { max-width: 100%; height: auto; border-radius: 12px; display: block; }

Tantangan

  1. Beri gambar alt="Biji kopi Gayo", width="400", height="300", dan loading="lazy".

Soal latihan

  1. Tulis tag gambar hero yang dimuat paling awal, dan gambar galeri yang dimuat lambat.

    Petunjuk

    Hero: fetchpriority high tanpa lazy. Galeri: loading lazy.

    Lihat jawaban
    HTML
    <img src="hero.webp" alt="Barista menuang susu" width="1200" height="800" fetchpriority="high">
<img src="galeri-1.webp" alt="Interior kedai" width="600" height="400" loading="lazy">

Poin penting

  • Ikon SVG, foto WebP/AVIF 1× dan 2×.
  • alt, width, height, loading="lazy".
  • Gambar hero: tanpa lazy, fetchpriority="high".

Cek pemahaman

Kenapa img diberi width dan height?

Jawaban: Agar halaman tidak melompat saat gambar dimuat

Browser menyiapkan ruang lebih dulu (mengurangi CLS).

Gambar hero di bagian paling atas sebaiknya?

Jawaban: Tanpa lazy, fetchpriority="high"

Harus dimuat paling awal.
