Langkah 6: layout desktop untuk kontainer, navbar, dan hero

Buka versi interaktif

Sekarang bentuk versi website sesuai Frame 1 (Desktop 1440). Gaya mobile sudah jadi, jadi kita hanya menambah aturan di dalam @media (min-width: 768px). Tekan tombol Desktop 1280 di atas pratinjau untuk melihat hasilnya seperti di monitor, lalu HP 360 untuk memastikan versi mobile tidak rusak.

Kontainer 1120. Di desain, isi halaman tidak pernah lebih lebar dari 1120 px dan selalu di tengah (redline 160 px di kiri dan kanan pada frame 1440). Caranya tanpa div pembungkus: padding-inline: max(var(--ruang-4), calc((100% - 1120px) / 2)). Di tablet hasilnya 32 px, di 1440 hasilnya 160 px.

Navbar: menu yang tadi disembunyikan ditampilkan (display: flex), padding atas-bawah 20. Hero: dua kolom sama lebar (teks kiri, gambar kanan) dengan jarak 48 dan judul 40 px.

Tantangan

  1. Tulis @media (min-width: 768px) yang: menampilkan .menu sebagai flex, membuat .hero dua kolom (1fr 1fr), dan memberi .nav padding samping dengan batas isi 1120px.

Poin penting

  • Desktop ditambahkan di media query min-width, bukan menulis ulang.
  • Kontainer 1120 dengan padding-inline max().
  • Cek di Desktop 1280 dan HP 360 bergantian.

Cek pemahaman

Kenapa memakai max(var(--ruang-4), calc((100% - 1120px) / 2))?

Jawaban: Isi maksimal 1120 px di tengah, tetapi tetap ada jarak minimal 32 px di tablet

Di layar sempit nilai kedua negatif, jadi max() memilih 32 px.
