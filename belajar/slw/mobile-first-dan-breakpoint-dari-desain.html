Mobile-first dan breakpoint dari desain

Buka versi interaktif

Desainer biasanya memberi dua atau tiga frame: mobile (360 atau 390), tablet (768), dan desktop (1440). Mobile-first berarti CSS dasar ditulis untuk mobile, lalu ditambah dengan @media (min-width: ...) untuk layar yang lebih lebar. Kodenya lebih ringkas daripada sebaliknya.

Breakpoint diambil dari titik desain berubah, bukan dari nama perangkat. Jika frame tablet menunjukkan kartu menjadi 2 kolom, tulis @media (min-width: 768px). Di antara dua frame, bayangkan sendiri perilakunya: apa yang melar, apa yang dibatasi lebar maksimumnya.

Uji di DevTools (Ctrl + Shift + M) dengan menyeret lebar layar pelan-pelan dari 320 sampai 1600 px. Bagian yang rusak di lebar "tanggung" seperti 900 px sering terlewat jika hanya mengecek tiga ukuran frame.

Daftar kelas di pratinjau satu kolom. Buat 2 kolom mulai lebar 600px.

HTML
<ul class="daftar">
  <li>HTML</li><li>CSS</li><li>JavaScript</li><li>Figma</li>
</ul>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.daftar { list-style: none; margin: 0; padding: 16px; display: grid; gap: 12px; }
.daftar li { padding: 16px; border-radius: 12px; background: #F0FDFA; font-weight: 600; }
/* tulis media query di bawah */

Tantangan

  1. Tambahkan @media (min-width: 600px) { .daftar { grid-template-columns: 1fr 1fr; } }.

Soal latihan

  1. Desain punya frame 390 (1 kolom kartu), 834 (2 kolom), 1440 (4 kolom, lebar konten maks 1200). Tulis rencana breakpoint dan CSS-nya.

    Petunjuk

    Breakpoint dari titik perubahan; container maks 1200.

    Lihat jawaban
    CONTOH
    .wrap { max-width: 1200px; margin: 0 auto; padding: 0 16px; }
.grid { display: grid; gap: 16px; }
@media (min-width: 768px)  { .grid { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 1200px) { .grid { grid-template-columns: repeat(4, 1fr); } }

Poin penting

  • CSS dasar untuk mobile, tambah dengan min-width.
  • Breakpoint dari titik desain berubah.
  • Seret lebar layar pelan-pelan, jangan hanya 3 ukuran.
