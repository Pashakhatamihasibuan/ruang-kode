Membaca desain di Figma Dev Mode

Buka versi interaktif

Dev Mode (ikon </> atau Shift + D di Figma) adalah tampilan khusus developer. Klik elemen untuk melihat ukuran, jarak ke elemen lain (tahan Alt atau Option sambil mengarahkan kursor), warna dan nama variabelnya, tipografi, serta potongan kode CSS. Developer tidak bisa mengubah desain secara tidak sengaja di mode ini.

Cara membaca auto layout: frame dengan auto layout ditampilkan sebagai display: flex, lengkap dengan gap, padding, dan arah. Hug contents berarti lebar mengikuti isi, Fill container berarti flex: 1 atau width: 100%. Jangan menyalin position: absolute dan width piksel tetap dari panel kode mentah-mentah; itu hanya cocok untuk ukuran frame itu saja.

Kebiasaan baik: periksa nama variabel (misalnya color/brand/600) dan pakai nama itu di CSS, bukan kode hex. Periksa juga apakah frame ditandai Ready for dev; frame lain mungkin masih eksplorasi. Jika tidak punya akses Dev Mode (berbayar), mode Inspect di akun gratis tetap menampilkan ukuran dan warna.

Soal latihan

  1. Dev Mode menampilkan: auto layout vertical, gap 12, padding 20/24, fill #F8FAFC, radius 16, stroke 1 #E2E8F0, shadow 0 2 8 #0F172A14. Tulis CSS-nya.

    Petunjuk

    Terjemahkan satu per satu, warna alpha 14 hex ≈ 8%.

    Lihat jawaban
    CSS
    .kartu {
  display: flex;
  flex-direction: column;
  gap: 12px;
  padding: 20px 24px;
  background: #F8FAFC;
  border: 1px solid #E2E8F0;
  border-radius: 16px;
  box-shadow: 0 2px 8px rgb(15 23 42 / .08);
}

Poin penting

  • Dev Mode: ukuran, jarak, variabel, kode.
  • Auto layout = flexbox; jangan salin posisi absolut mentah.
  • Pakai nama variabel, cek status Ready for dev.
