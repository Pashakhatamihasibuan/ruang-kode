Token desain ke CSS variables

Buka versi interaktif

Langkah pertama menulis CSS dari desain: pindahkan token ke :root. Buka panel Variables di Figma (atau Local styles untuk file lama) dan salin warna, font, spacing, radius, dan bayangan menjadi CSS variables.

Setelah token ada, semua aturan CSS memakai var(--...). Jika desainer mengubah warna merek minggu depan, kamu cukup mengubah satu baris. Jika desain punya mode gelap, tambahkan blok token kedua.

Beri nama variabel sama seperti di Figma agar mudah dicocokkan: color/brand/600 menjadi --color-brand-600, spacing/4 menjadi --spacing-4.

Desain di pratinjau memakai warna merek #0F766E dan radius 12. Pindahkan ke token.

HTML
<section class="promo">
  <h2>Kelas baru: Slicing Website</h2>
  <p>Ubah desain Figma menjadi halaman nyata.</p>
  <a class="tombol" href="#">Daftar</a>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
:root {
  /* token dari Figma: tulis di sini */
}
.promo { margin: 16px; padding: 24px; border-radius: 12px; background: #CCFBF1; }
.promo h2 { margin: 0 0 8px; color: #134E4A; }
.tombol { display: inline-block; margin-top: 8px; padding: 12px 24px; border-radius: 12px; background: #0F766E; color: #fff; text-decoration: none; font-weight: 600; }

Tantangan

  1. Buat token --color-brand-600: #0F766E dan --radius-md: 12px di :root, lalu pakai keduanya di .tombol.

Soal latihan

  1. Ubah daftar variabel Figma berikut menjadi CSS: color/brand/500 #6366F1, color/text/primary #111827, spacing/2 8, spacing/4 16, radius/lg 16, font/body Inter.

    Petunjuk

    Garis miring menjadi tanda hubung, angka spacing diberi px.

    Lihat jawaban
    CSS
    :root {
  --color-brand-500: #6366F1;
  --color-text-primary: #111827;
  --spacing-2: 8px;
  --spacing-4: 16px;
  --radius-lg: 16px;
  --font-body: "Inter", system-ui, sans-serif;
}

Poin penting

  • Token dari Figma Variables ke :root.
  • Semua aturan memakai var().
  • Nama variabel sama dengan nama di Figma.

Cek pemahaman

Nama CSS yang cocok untuk variabel Figma spacing/4?

Jawaban: --spacing-4

Sama dengan nama di Figma.
