Section fitur dengan grid

Buka versi interaktif

Section fitur biasanya: judul section, subjudul, lalu 3 sampai 6 kartu berisi ikon, judul, dan teks singkat. Di desain desktop 3 kolom, tablet 2 kolom, ponsel 1 kolom. Dengan repeat(auto-fit, minmax(240px, 1fr)), kamu tidak perlu menulis media query sama sekali.

Ukur gap antar kartu dan jarak judul section ke grid dari desain. Biasanya judul section rata tengah dengan lebar teks terbatas, sedangkan isi kartu rata kiri.

Ikon di kartu fitur sering diletakkan di dalam lingkaran atau kotak berwarna lembut. Buat dengan display: grid; place-items: center dan ukuran tetap (48 × 48).

Grid fitur di pratinjau belum dibuat.

HTML
<section class="fitur">
  <h2>Kenapa belajar di sini?</h2>
  <div class="grid">
    <article><span class="ikon">⚡</span><h3>Langsung praktik</h3><p>Editor jalan di browser, tanpa instalasi.</p></article>
    <article><span class="ikon">🇮🇩</span><h3>Bahasa Indonesia</h3><p>Penjelasan runtut dengan contoh lokal.</p></article>
    <article><span class="ikon">📱</span><h3>Bisa offline</h3><p>Pasang sebagai aplikasi di ponsel.</p></article>
  </div>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.fitur { padding: 48px 16px; max-width: 1080px; margin: 0 auto; }
.fitur h2 { text-align: center; margin: 0 0 32px; }
.grid article { padding: 24px; border-radius: 16px; background: #F5F7FA; }
.grid h3 { margin: 16px 0 8px; font-size: 18px; }
.grid p { margin: 0; color: #52606D; }
.ikon { width: 48px; height: 48px; display: grid; place-items: center; border-radius: 12px; background: #E0F2F1; font-size: 22px; }

Tantangan

  1. Jadikan .grid grid fluid: display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 24px.

Soal latihan

  1. Buat grid fitur yang tepat 3 kolom di desktop (≥ 1024px), 2 kolom di tablet, 1 kolom di ponsel, memakai media query.

    Petunjuk

    Mobile-first dengan min-width.

    Lihat jawaban
    CSS
    .grid { display: grid; gap: 24px; }
@media (min-width: 640px) { .grid { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 1024px) { .grid { grid-template-columns: repeat(3, 1fr); } }

Poin penting

  • auto-fit + minmax: 1–3 kolom tanpa media query.
  • Judul section rata tengah, isi kartu rata kiri.
  • Ikon dalam kotak 48 × 48 dengan place-items: center.
