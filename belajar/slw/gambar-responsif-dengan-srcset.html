Gambar responsif dengan srcset

Buka versi interaktif

Satu gambar besar untuk semua layar membuang kuota pengguna ponsel. Atribut srcset memberi browser beberapa pilihan file, dan sizes memberi tahu lebar tampil gambar. Browser lalu memilih file terkecil yang tetap tajam untuk layar itu.

Contoh: srcset="kopi-480.webp 480w, kopi-960.webp 960w, kopi-1440.webp 1440w" dan sizes="(min-width: 768px) 50vw, 100vw". Artinya: di layar lebar gambar tampil selebar setengah layar, di ponsel selebar penuh.

Jika desain meminta potongan berbeda (art direction), misalnya foto lebar di desktop tetapi potongan persegi di mobile, pakai <picture> dengan beberapa <source media="...">.

Gambar di pratinjau hanya punya satu file.

HTML
<img class="foto" src="kopi-960.webp" alt="Barista menyeduh kopi" width="960" height="640">
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.foto { display: block; max-width: 100%; height: auto; background: #D7B899; }

Tantangan

  1. Tambahkan srcset dengan tiga ukuran (480w, 960w, 1440w) dan sizes="(min-width: 768px) 50vw, 100vw".

Soal latihan

  1. Tulis elemen picture: desktop memakai foto lebar 16:9, ponsel memakai potongan persegi.

    Petunjuk

    source dengan media min-width untuk desktop, img sebagai cadangan.

    Lihat jawaban
    HTML
    <picture>
  <source media="(min-width: 768px)" srcset="hero-lebar-1280.webp 1280w, hero-lebar-1920.webp 1920w" sizes="100vw">
  <img src="hero-persegi-720.webp" srcset="hero-persegi-480.webp 480w, hero-persegi-720.webp 720w" sizes="100vw" alt="Kedai KopiNusa" width="720" height="720">
</picture>

Poin penting

  • srcset: daftar file dengan lebar aslinya (w).
  • sizes: lebar tampil gambar di setiap kondisi.
  • picture + source untuk potongan berbeda.
