Mini 3: Dashboard cuaca (loading, error, offline)

Buka versi interaktif

Brief. Dashboard cuaca kota: kondisi sekarang, prakiraan per jam dan 7 hari, kualitas udara. Wajib state memuat (skeleton), error, dan offline.

Kit berisi desain hi-fi (Dashboard cuaca), wireframe lo-fi, variasi 3 gaya lain, prototype beranimasi, tokens.json, ikon, dan BRIEF.md berisi kriteria penerimaan. Gaya utama: Liquid Glass.

Cara mengerjakan: impor ke Figma, periksa ukuran dengan Dev Mode, ubah token menjadi CSS custom properties, lalu slicing per komponen dari yang terkecil (tombol, input, kartu) sebelum menyusun halaman.

Peta slicing. Tabel di bawah memetakan setiap blok di frame desain ke elemen HTML dan susunannya di HP dan desktop. Kode contoh adalah titik awal: token sudah diambil dari tokens.json kit ini, kerangka HTML mengikuti urutan blok di frame, dan CSS sudah dipisah menjadi gaya HP (dasar) dan desktop (media query 768 px). Isi setiap bagian sampai sama dengan frame web, lalu periksa di lebar 360, 768, dan 1440.

/* 1. MOBILE dulu (tanpa media query): semua bagian 1 kolom, padding samping 16 */
.wadah, main > section, header, footer { padding-inline: var(--ruang-2); }

/* 2. DESKTOP sesuai frame web: isi maks 1200 di tengah */
@media (min-width: 768px) {
  main > section, header, footer { padding-inline: max(var(--ruang-4), calc((100% - 1200px) / 2)); }
  .navbar { /* desktop: logo · menu flex gap 24 · CTA */ }
  .statistik { /* desktop: grid 4 kolom */ }
  .grafik { /* desktop: lebar penuh, tinggi 320 */ }
  .tabel { /* desktop: tabel penuh */ }
}
