HTML semantik dari desain

Buka versi interaktif

Desain hanya menunjukkan rupa; slicer yang menentukan makna. Navbar adalah <header> berisi <nav>, isi utama adalah <main>, setiap bagian adalah <section> dengan judul, kartu artikel adalah <article>, dan bagian bawah adalah <footer>.

Judul harus berurutan: satu <h1> per halaman (biasanya judul hero), lalu <h2> untuk judul section, <h3> untuk judul kartu. Pilih tag berdasarkan tingkat, bukan ukuran huruf di desain; ukuran diatur oleh CSS.

Yang terlihat seperti tombol tetapi pindah halaman adalah <a>; yang menjalankan aksi di halaman yang sama adalah <button>. HTML semantik membuat halaman terbaca pembaca layar, mudah ditemukan Google, dan lebih mudah di-styling.

Kerangka di pratinjau hanya berisi div. Ganti dengan landmark yang tepat.

HTML
<div class="atas"><div class="logo">RuangKode</div><div class="menu"><a href="#">Kelas</a><a href="#">Harga</a></div></div>
<div class="isi">
  <div class="judul-besar">Belajar slicing dari desain nyata</div>
  <p>Latihan dengan file Figma sungguhan.</p>
</div>
<div class="bawah">© 2026 RuangKode</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.atas, header { display: flex; justify-content: space-between; align-items: center; padding: 16px; border-bottom: 1px solid #E4E7EB; }
.menu, nav { display: flex; gap: 16px; }
.isi, main { padding: 24px 16px; }
.judul-besar, h1 { font-size: 28px; font-weight: 700; margin: 0 0 8px; }
.bawah, footer { padding: 16px; color: #52606D; font-size: 14px; }

Tantangan

  1. Ganti kerangkanya: header berisi nav, main berisi h1, dan footer.

Soal latihan

  1. Tulis kerangka HTML semantik untuk halaman blog: navbar, judul artikel, info penulis, isi, artikel terkait (3 kartu), footer.

    Petunjuk

    header/nav, main/article, aside atau section, footer.

    Lihat jawaban
    HTML
    <header><nav>...</nav></header>
<main>
  <article>
    <h1>Judul artikel</h1>
    <p class="meta">Oleh Rina · 5 menit baca</p>
    <p>Isi...</p>
  </article>
  <section aria-labelledby="terkait">
    <h2 id="terkait">Artikel terkait</h2>
    <article><h3>...</h3></article>
    <article><h3>...</h3></article>
    <article><h3>...</h3></article>
  </section>
</main>
<footer>...</footer>

Poin penting

  • header, nav, main, section, article, footer.
  • Satu h1, judul berurutan.
  • Pindah halaman: a. Aksi di halaman: button.

Jawaban: Satu
