Slicing Website · Modul 4 · Praktik langsung

Aksesibilitas hasil slicing

Buka versi interaktif

Desain jarang menunjukkan hal yang tidak terlihat, padahal itu tanggung jawab slicer: urutan fokus keyboard yang logis, indikator fokus yang jelas, alt gambar, label form, bahasa halaman (<html lang="id">), dan skip link.

Skip link adalah tautan pertama di halaman, tersembunyi sampai difokuskan dengan Tab, yang langsung melompat ke konten utama. Pengguna keyboard tidak perlu melewati 15 link navbar di setiap halaman.

Uji cepat setelah slicing: tekan Tab dari atas sampai bawah tanpa mouse; jalankan Lighthouse (tab Lighthouse di DevTools, kategori Accessibility); zoom browser 200% dan pastikan tidak ada teks terpotong atau scroll horizontal.

Halaman di pratinjau belum punya skip link.

HTML
<header class="nav"><a href="#">Beranda</a><a href="#">Kelas</a><a href="#">Harga</a><a href="#">Blog</a><a href="#">Masuk</a></header>
<main><h1>Kelas Slicing Website</h1><p>Konten utama halaman.</p></main>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.nav { display: flex; gap: 12px; flex-wrap: wrap; padding: 12px 16px; border-bottom: 1px solid #E4E7EB; }
main { padding: 24px 16px; }
.skip { position: absolute; left: 8px; top: -48px; background: #1F2933; color: #fff; padding: 8px 12px; border-radius: 8px; }
.skip:focus { top: 8px; }

Tantangan

  1. Tambahkan <a class="skip" href="#isi">Lewati ke konten</a> sebagai elemen pertama, dan beri main id="isi".

Soal latihan

  1. Tulis 5 langkah uji aksesibilitas cepat yang bisa kamu lakukan dalam 10 menit setelah slicing.

    Petunjuk

    Keyboard, Lighthouse, zoom, alt, kontras.

    Lihat jawaban
    CONTOH
    1. Tekan Tab dari atas ke bawah: urutan logis dan fokus terlihat.
2. Lighthouse → Accessibility, perbaiki semua temuan merah.
3. Zoom 200%: tidak ada teks terpotong atau scroll horizontal.
4. Matikan gambar atau baca alt di DevTools: alt bermakna.
5. Cek kontras teks abu-abu dengan DevTools color picker.

Poin penting

  • Slicer bertanggung jawab atas fokus, alt, label, lang, skip link.
  • Skip link melompati navigasi.
  • Uji: Tab, Lighthouse, zoom 200%.
