Slicing Website · Modul 3 · Praktik langsung

Tabel harga dengan paket unggulan

Buka versi interaktif

Section harga berisi 2 sampai 4 kartu paket: nama, harga, periode, daftar fitur, dan tombol. Satu paket biasanya ditonjolkan (paling populer) dengan border tebal warna merek, lencana, dan tombol primary, sementara paket lain memakai tombol secondary.

Tulis harga dengan format lokal yang benar: Rp49.000 per bulan (titik sebagai pemisah ribuan, tanpa spasi setelah Rp). Fitur ditulis sebagai daftar <ul> dengan tanda centang; fitur yang tidak termasuk jangan hanya diberi warna abu-abu, beri juga teks atau ikon silang.

Agar tombol semua kartu sejajar di bawah walau daftar fiturnya beda panjang, jadikan kartu display: flex; flex-direction: column dan beri tombol margin-top: auto.

Kartu Pro di pratinjau harus menjadi paket unggulan.

HTML
<section class="harga">
  <article class="paket"><h3>Gratis</h3><p class="h">Rp0</p><ul><li>✓ 50 pelajaran</li></ul><a href="#" class="b">Mulai</a></article>
  <article class="paket pro"><h3>Pro</h3><p class="h">Rp49.000<small>/bulan</small></p><ul><li>✓ Semua pelajaran</li><li>✓ Sertifikat</li><li>✓ Proyek dinilai mentor</li></ul><a href="#" class="b">Pilih Pro</a></article>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.harga { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 16px; padding: 16px; }
.paket { display: flex; flex-direction: column; padding: 24px; border: 1px solid #D5D9E0; border-radius: 16px; }
.paket h3 { margin: 0; }
.h { font-size: 28px; font-weight: 700; margin: 8px 0 16px; }
.h small { font-size: 14px; font-weight: 400; color: #52606D; }
.paket ul { list-style: none; padding: 0; margin: 0 0 24px; display: grid; gap: 8px; }
.b { margin-top: auto; text-align: center; padding: 12px; border-radius: 12px; border: 1px solid #1D5FA8; color: #1D5FA8; text-decoration: none; font-weight: 600; }

Tantangan

  1. Tonjolkan paket Pro: .pro diberi border: 2px solid #1D5FA8, dan tombolnya (.pro .b) berlatar #1D5FA8 dengan teks putih.

Soal latihan

  1. Tambahkan lencana "Paling populer" di kartu Pro dan fitur yang tidak termasuk di kartu Gratis dengan ikon dan teks.

    Petunjuk

    Jangan hanya abu-abu; tulis "Tidak termasuk".

    Lihat jawaban
    HTML
    <article class="paket pro">
  <span class="lencana">Paling populer</span>
  ...
</article>
<article class="paket">
  <ul>
    <li>✓ 50 pelajaran</li>
    <li class="tidak">✕ Sertifikat <span class="sr-only">(tidak termasuk)</span></li>
  </ul>
</article>

Poin penting

  • Satu paket unggulan: border, lencana, tombol primary.
  • Format harga Rp49.000.
  • Tombol sejajar bawah: flex column + margin-top: auto.
