Testimoni dengan scroll-snap

Buka versi interaktif

Desain mobile sering menampilkan testimoni sebagai carousel yang digeser horizontal. Kamu tidak perlu library JavaScript: CSS scroll-snap sudah cukup. Wadahnya display: flex; overflow-x: auto; scroll-snap-type: x mandatory, setiap kartu scroll-snap-align: start dan lebar tetap (misalnya 85% layar).

Sisakan sebagian kartu berikutnya terlihat (peek) agar pengguna tahu bisa digeser. Pastikan carousel juga bisa digeser dengan keyboard (beri tabindex="0" dan label pada wadah), dan jangan memutar otomatis tanpa tombol jeda.

Di desktop, carousel yang sama bisa berubah menjadi grid tiga kolom dengan media query.

Wadah testimoni di pratinjau sudah menggulir, tetapi belum "mengunci" ke kartu.

HTML
<section class="testi" aria-label="Testimoni siswa" tabindex="0">
  <blockquote class="k">"Akhirnya paham flexbox setelah 3 hari."<cite>Rina, Medan</cite></blockquote>
  <blockquote class="k">"Proyek slicing pertamaku diterima klien."<cite>Andi, Makassar</cite></blockquote>
  <blockquote class="k">"Materinya runtut dan ada soal latihannya."<cite>Sari, Bandung</cite></blockquote>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.testi { display: flex; gap: 12px; overflow-x: auto; padding: 16px; }
.k { flex: 0 0 85%; margin: 0; padding: 24px; border-radius: 16px; background: #EEF2FF; font-size: 17px; }
.k cite { display: block; margin-top: 12px; font-size: 14px; font-style: normal; color: #4338CA; }

Tantangan

  1. Tambahkan scroll-snap-type: x mandatory pada .testi dan scroll-snap-align: start pada .k.

Soal latihan

  1. Ubah carousel testimoni menjadi grid 3 kolom tanpa scroll di layar ≥ 1024px.

    Petunjuk

    Di media query, ganti display dan matikan overflow.

    Lihat jawaban
    CSS
    @media (min-width: 1024px) {
  .testi { display: grid; grid-template-columns: repeat(3, 1fr); overflow: visible; }
  .k { flex: none; }
}

Poin penting

  • Carousel tanpa JS: overflow-x + scroll-snap.
  • Sisakan peek kartu berikutnya.
  • Bisa digeser keyboard, jangan autoplay tanpa jeda.

Cek pemahaman

Kenapa kartu carousel dibuat 85% lebar, bukan 100%?

Jawaban: Agar kartu berikutnya terlihat sedikit sebagai petunjuk bisa digeser

Peek memberi isyarat.

Kerjakan latihannya di aplikasi

Sebelumnya: Section fitur dengan grid

Berikutnya: Tabel harga dengan paket unggulan
