Navbar responsif

Buka versi interaktif

Navbar di desain biasanya: logo di kiri, link di tengah atau kanan, tombol aksi di kanan. Di CSS cukup flexbox: display: flex; justify-content: space-between; align-items: center.

Di mobile, link biasanya disembunyikan di balik tombol menu (hamburger). Cara tanpa JavaScript: <details> dan <summary>. Cara umum: tombol dengan aria-expanded yang mengubah kelas menu lewat JavaScript. Ukur tinggi navbar dari desain (biasanya 56 sampai 72 px) dan pastikan setiap link punya area klik yang cukup.

Untuk navbar yang tetap terlihat saat menggulir, pakai position: sticky; top: 0 dan beri latar serta z-index agar konten tidak tembus.

Navbar di pratinjau masih menumpuk. Susun dengan flexbox.

HTML
<header class="nav">
  <a class="logo" href="#">Kopi<b>Nusa</b></a>
  <nav class="link"><a href="#">Menu</a><a href="#">Lokasi</a><a href="#">Tentang</a></nav>
  <a class="cta" href="#">Pesan</a>
</header>
<main style="padding:16px">Konten halaman...</main>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.nav { padding: 12px 16px; border-bottom: 1px solid #E7E0D8; background: #FFFBF5; }
.logo { font-size: 20px; color: #3E2723; text-decoration: none; }
.link { display: flex; gap: 16px; }
.link a { color: #5D4037; text-decoration: none; padding: 8px 0; }
.cta { background: #6D4C41; color: #fff; padding: 8px 16px; border-radius: 999px; text-decoration: none; }

Tantangan

  1. Jadikan .nav flex: display: flex; justify-content: space-between; align-items: center, dan buat navbar menempel saat menggulir (position: sticky; top: 0).

Soal latihan

  1. Buat navbar dengan tombol menu mobile tanpa JavaScript memakai details dan summary.

    Petunjuk

    summary menjadi tombol, isi details adalah daftar link.

    Lihat jawaban
    HTML
    <header class="nav">
  <a class="logo" href="/">KopiNusa</a>
  <details class="menu-m">
    <summary aria-label="Buka menu">☰</summary>
    <nav><a href="#menu">Menu</a><a href="#lokasi">Lokasi</a><a href="#tentang">Tentang</a></nav>
  </details>
</header>

Poin penting

  • Navbar: flex + space-between + align-items center.
  • Mobile: menu tersembunyi dengan aria-expanded.
  • Sticky: position sticky, top 0, latar, z-index.
