Langkah 4: layout mobile-first untuk navbar dan hero

Buka versi interaktif

Tulis CSS untuk layar terkecil dulu (360 px), tanpa media query. Navbar: logo kiri, tombol kanan, sejajar vertikal, dengan flexbox. Menu disembunyikan di mobile sesuai desain. Hero: satu kolom, judul 28 px, jarak sesuai redline.

Salin angka dari redline, bukan dari perkiraan mata: padding 16 px di sisi, 32 px di atas dan bawah hero, jarak antar tombol 8 px. Semua angka itu ada di skala token (--ruang-1 sampai --ruang-5), jadi pakai variabelnya.

Pratinjau sudah punya token dan gaya tombol, tetapi navbar dan hero belum ditata.

Tantangan

  1. Tata .nav dengan flex: justify-content: space-between dan align-items: center. Beri .hero h1 ukuran 28px, dan sembunyikan .menu di mobile.

Poin penting

  • Mobile dulu, tanpa media query.
  • Angka dari redline, ditulis dengan token.
  • Flexbox untuk navbar.
