Hero section

Buka versi interaktif

Hero adalah section pertama yang dilihat pengunjung: judul (h1), satu sampai dua kalimat penjelas, satu sampai dua tombol, dan gambar. Di desktop biasanya dua kolom (teks kiri, gambar kanan); di mobile menjadi satu kolom dengan gambar di bawah atau di atas teks.

Ukur dari desain: lebar maksimum teks, jarak judul ke deskripsi, jarak ke tombol. Judul hero memakai ukuran fluid (clamp()) agar tidak terlalu besar di ponsel.

Dua tombol berdampingan bisa terlalu lebar di ponsel kecil. Pakai display: flex; flex-wrap: wrap; gap: 12px agar tombol kedua turun ke baris baru jika tidak muat, bukan memaksa halaman melebar.

Grup tombol di pratinjau belum bisa turun baris.

HTML
<section class="hero">
  <div class="teks">
    <h1>Kopi lokal, diseduh hari ini</h1>
    <p>Biji kopi dari Gayo, Toraja, dan Kintamani. Diantar hangat dalam 30 menit.</p>
    <div class="aksi"><a class="btn utama" href="#">Pesan sekarang</a><a class="btn kedua" href="#">Lihat menu lengkap</a></div>
  </div>
  <div class="gambar" role="img" aria-label="Secangkir kopi"></div>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; color: #1F2933; }
.hero { display: grid; gap: 24px; padding: 32px 16px; background: #FFF8EE; }
@media (min-width: 768px) { .hero { grid-template-columns: 1fr 1fr; align-items: center; padding: 64px 48px; } }
h1 { font-size: clamp(1.75rem, 1rem + 3vw, 3rem); line-height: 1.15; margin: 0 0 12px; color: #3E2723; }
.teks p { margin: 0 0 24px; color: #5D4037; max-width: 45ch; }
.aksi { display: flex; gap: 12px; }
.btn { padding: 12px 20px; border-radius: 12px; text-decoration: none; font-weight: 600; white-space: nowrap; }
.utama { background: #6D4C41; color: #fff; }
.kedua { border: 1px solid #6D4C41; color: #6D4C41; }
.gambar { aspect-ratio: 4 / 3; border-radius: 24px; background: radial-gradient(circle at 40% 40%, #D7B899, #6D4C41); }

Tantangan

  1. Beri .aksi flex-wrap: wrap agar tombol turun baris di layar sempit.

Soal latihan

  1. Tulis CSS hero dua kolom mulai 900px, dengan gambar di atas teks pada mobile.

    Petunjuk

    Mobile: order gambar -1. Desktop: grid 2 kolom dan order normal.

    Lihat jawaban
    CSS
    .hero { display: grid; gap: 24px; }
.hero .gambar { order: -1; }
@media (min-width: 900px) {
  .hero { grid-template-columns: 1.1fr 1fr; align-items: center; }
  .hero .gambar { order: 0; }
}

Poin penting

  • Hero: h1, penjelas singkat, 1–2 tombol, gambar.
  • Dua kolom di desktop, satu kolom di mobile.
  • flex-wrap agar tombol tidak memaksa halaman melebar.
