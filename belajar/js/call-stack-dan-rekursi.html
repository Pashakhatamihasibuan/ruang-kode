Call stack dan rekursi

Buka versi interaktif

Setiap kali fungsi dipanggil, engine mendorong sebuah stack frame (berisi argumen, variabel lokal, dan alamat kembali) ke call stack. Saat fungsi selesai, frame-nya diambil (LIFO: last in, first out). Stack trace pada error menunjukkan isi call stack saat error terjadi, jadi bacalah dari atas untuk menemukan sumber masalah.

Rekursi adalah fungsi yang memanggil dirinya sendiri. Setiap fungsi rekursif harus punya base case (kondisi berhenti) dan recursive case yang mendekati base case. Tanpa base case, call stack penuh dan muncul RangeError: Maximum call stack size exceeded (stack overflow), biasanya setelah sekitar 10 ribu frame.

Rekursi alami untuk data bersarang: pohon menu/kategori, komentar berbalas, struktur folder, JSON bersarang, dan DOM. Untuk kedalaman besar, ubah ke loop dengan stack manual. Memoization menyimpan hasil agar rekursi seperti Fibonacci tidak menghitung ulang.

JAVASCRIPT
function faktorial(n) {
  if (n <= 1) return 1;            // base case
  return n * faktorial(n - 1);     // recursive case
}
console.log(faktorial(5), faktorial(20));

function lacak(n, kedalaman = 0) {
  console.log(' '.repeat(kedalaman * 2) + `masuk lacak(${n})`);
  if (n > 0) lacak(n - 1, kedalaman + 1);
  console.log(' '.repeat(kedalaman * 2) + `keluar lacak(${n})`);
}
lacak(2);

const kategori = { nama: 'Elektronik', anak: [
  { nama: 'HP', anak: [{ nama: 'Android', anak: [] }, { nama: 'iPhone', anak: [] }] },
  { nama: 'Laptop', anak: [] },
] };
function cetakPohon(node, level = 0) {
  console.log('  '.repeat(level) + '- ' + node.nama);
  node.anak.forEach(a => cetakPohon(a, level + 1));
}
cetakPohon(kategori);

const memo = new Map();
function fib(n) {
  if (n < 2) return n;
  if (memo.has(n)) return memo.get(n);
  const h = fib(n - 1) + fib(n - 2);
  memo.set(n, h);
  return h;
}
console.log(fib(50));

RangeError: Maximum call stack size exceeded

Soal latihan

  1. Tulis fungsi rekursif totalUkuran(folder) yang menjumlahkan ukuran semua file di struktur folder bersarang {nama, file:[ukuran...], sub:[folder...]}.

    Petunjuk

    Jumlah file sendiri + jumlah totalUkuran setiap sub.

    Lihat jawaban
    JAVASCRIPT
    const root = {
  nama: 'proyek', file: [120, 80],
  sub: [
    { nama: 'src', file: [300, 45], sub: [{ nama: 'utils', file: [10], sub: [] }] },
    { nama: 'docs', file: [500], sub: [] },
  ],
};
function totalUkuran(f) {
  const sendiri = f.file.reduce((a, b) => a + b, 0);
  return sendiri + f.sub.reduce((a, s) => a + totalUkuran(s), 0);
}
console.log('total:', totalUkuran(root), 'KB');
    KELUARAN
    total: 1055 KB

Poin penting

  • Call stack LIFO; stack trace dibaca dari atas.
  • Rekursi butuh base case.
  • Stack overflow = RangeError Maximum call stack size exceeded.
  • Memoization untuk subproblem berulang.
