bigint, undefined, null, dan Symbol

Buka versi interaktif

bigint menyimpan bilangan bulat sebesar apa pun, ditulis dengan akhiran n (123n) atau BigInt('123'). Cocok untuk ID 64-bit dari database atau API (misalnya ID tweet), kriptografi, dan perhitungan bulat besar. bigint tidak bisa dicampur langsung dengan number dalam operasi aritmetika.

undefined berarti "belum diberi nilai": variabel tanpa nilai awal, parameter yang tidak dikirim, properti yang tidak ada, atau fungsi tanpa return. null berarti "sengaja kosong", diisi oleh programmer. typeof null menghasilkan "object", bug sejak versi pertama yang dipertahankan demi kompatibilitas.

Symbol adalah nilai unik yang dipakai sebagai kunci properti yang tidak akan bentrok. Dua Symbol('id') selalu berbeda. Symbol bawaan (well-known symbols) seperti Symbol.iterator dan Symbol.toPrimitive dipakai untuk mengatur perilaku objek. Properti bersimbol tidak muncul di for...in maupun JSON.stringify.

Soal latihan

  1. Hitung 2 pangkat 64 dengan number dan dengan bigint, lalu cetak keduanya untuk melihat perbedaan presisi.

    Petunjuk

    Gunakan 2 ** 64 dan 2n ** 64n.

    Lihat jawaban
    JAVASCRIPT
    console.log('number:', 2 ** 64);
console.log('bigint:', (2n ** 64n).toString());
    KELUARAN
    number: 18446744073709552000
bigint: 18446744073709551616

Poin penting

  • bigint untuk bilangan bulat besar, akhiran n, tidak dicampur number.
  • undefined = belum ada; null = sengaja kosong.
  • typeof null === "object" adalah bug historis.
  • Symbol selalu unik; cocok untuk kunci tersembunyi.
