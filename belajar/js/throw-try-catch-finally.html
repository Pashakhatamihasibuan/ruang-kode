throw, try, catch, finally

Buka versi interaktif

Saat terjadi kesalahan yang tidak bisa ditangani di tempat, throw menghentikan eksekusi dan melempar nilai ke atas tumpukan pemanggil sampai ditangkap catch. Jika tidak ada yang menangkap, program berhenti (di Node) atau error muncul di konsol (di browser).

try { } berisi kode yang mungkin gagal, catch (e) { } menanganinya, dan finally { } selalu dijalankan, baik sukses maupun gagal, bahkan setelah return. Finally cocok untuk membersihkan sumber daya: menutup koneksi, mematikan spinner loading, melepas kunci.

Praktik profesional: selalu throw new Error(...) (bukan string) agar ada stack trace; tangkap hanya error yang bisa kamu tangani dan lempar ulang sisanya; jangan menelan error diam-diam dengan catch kosong; dan sertakan cause (new Error(pesan, { cause: e }), ES2022) saat membungkus error agar penyebab asli tidak hilang. Parameter catch boleh dihilangkan (catch { }) jika tidak dipakai.

JAVASCRIPT
function bagi(a, b) {
  if (b === 0) throw new RangeError('pembagi tidak boleh nol');
  return a / b;
}

function proses(a, b) {
  console.log(`mulai ${a}/${b}`);
  try {
    return `hasil ${bagi(a, b)}`;
  } catch (e) {
    return `gagal: ${e.message}`;
  } finally {
    console.log('  finally: matikan spinner');   // tetap jalan walau ada return
  }
}
console.log(proses(10, 4));
console.log(proses(1, 0));

function bacaKonfig(teks) {
  try {
    return JSON.parse(teks);
  } catch (e) {
    throw new Error('konfigurasi rusak', { cause: e });   // bungkus dengan cause
  }
}
try {
  bacaKonfig('{port: 80}');
} catch (e) {
  console.log(e.message, '<-', e.cause.name);
}

Soal latihan

  1. Tulis ambilUmur(teks) yang mengubah teks ke number dan melempar TypeError jika bukan angka, serta RangeError jika di luar 0 sampai 120. Panggil untuk "25", "abc", "150" dan cetak nama error atau hasilnya.

    Petunjuk

    Number(teks), cek Number.isNaN, lalu rentang.

    Lihat jawaban
    JAVASCRIPT
    function ambilUmur(teks) {
  const n = Number(teks);
  if (teks.trim() === '' || Number.isNaN(n)) throw new TypeError(`'${teks}' bukan angka`);
  if (n < 0 || n > 120) throw new RangeError(`umur ${n} di luar rentang`);
  return n;
}
for (const t of ['25', 'abc', '150']) {
  try {
    console.log('umur:', ambilUmur(t));
  } catch (e) {
    console.log(`${e.name}: ${e.message}`);
  }
}
    KELUARAN
    umur: 25
TypeError: 'abc' bukan angka
RangeError: umur 150 di luar rentang

Poin penting

  • throw new Error(...) agar ada stack trace.
  • finally selalu jalan, cocok untuk cleanup.
  • Jangan menelan error dengan catch kosong.
  • Bungkus error dengan { cause } untuk konteks.
