JSON

Buka versi interaktif

JSON (JavaScript Object Notation) adalah format teks untuk pertukaran data, dipakai hampir semua REST API, file konfigurasi (package.json), dan penyimpanan seperti localStorage. Sintaksnya lebih ketat dari object JS: key wajib kutip dua, string kutip dua, tidak ada koma di akhir, tidak ada komentar, dan nilai hanya string, number, boolean, null, array, atau object.

JSON.stringify(nilai, replacer, spasi) mengubah nilai menjadi teks. Yang hilang atau berubah: undefined, fungsi, dan symbol dibuang (di array menjadi null), Date menjadi string ISO, Map/Set menjadi {}, NaN/Infinity menjadi null, dan BigInt melempar TypeError. Object bisa mengatur bentuk JSON-nya dengan metode toJSON().

JSON.parse(teks, reviver) mengubah teks menjadi nilai; teks tidak valid melempar SyntaxError, jadi selalu bungkus dengan try/catch saat datanya dari luar. Parameter reviver berguna untuk menghidupkan kembali tanggal. Ingat, JSON hanya data: jangan pernah memakai eval untuk mengurai JSON.

const pesanan = {
  id: 101,
  pelanggan: 'Dewi',
  item: [{ sku: 'KP-01', qty: 2 }],
  dibuat: new Date(Date.UTC(2026, 10, 20, 2, 30)),
  catatan: undefined,
  hitung() { return 1; },
  tag: new Set(['promo']),
};
const teks = JSON.stringify(pesanan);
console.log(teks);
console.log(JSON.stringify({ a: 1, b: [1, 2] }, null, 2));
console.log(JSON.stringify(pesanan, ['id', 'pelanggan']));     // replacer: pilih key

const balik = JSON.parse(teks, (k, v) => (k === 'dibuat' ? new Date(v) : v));
console.log(balik.dibuat instanceof Date, balik.dibuat.getUTCHours());

Soal latihan

  1. Simpan keranjang [{nama:"Kopi", qty:2}] sebagai teks JSON (seperti ke localStorage), lalu baca kembali dan tambahkan qty. Tangani juga teks rusak "[{nama:" dengan nilai default array kosong.

    Petunjuk

    Buat fungsi bacaAman(teks) dengan try/catch.

    Lihat jawaban
    JAVASCRIPT
    const simpan = JSON.stringify([{ nama: 'Kopi', qty: 2 }]);
console.log('disimpan:', simpan);
function bacaAman(teks) {
  try {
    return JSON.parse(teks);
  } catch {
    return [];
  }
}
const keranjang = bacaAman(simpan);
keranjang[0].qty += 1;
console.log(keranjang);
console.log(bacaAman('[{nama:'));

Poin penting

  • JSON: key dan string kutip dua, tanpa komentar dan koma akhir.
  • stringify membuang undefined/fungsi dan mengubah Date ke string.
  • parse dalam try/catch; reviver untuk tanggal.
  • Jangan pernah eval untuk JSON.

Cek pemahaman

Hasil JSON.stringify({a: undefined, b: 1})?

Jawaban: {"b":1}

Properti undefined dibuang.

JSON.parse("{'a': 1}") menghasilkan?

Jawaban: SyntaxError

JSON wajib memakai kutip dua.
