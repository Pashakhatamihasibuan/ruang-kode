Destructuring, spread, rest, dan presedensi

Buka versi interaktif

Destructuring membongkar array atau object ke variabel: const [a, b] = arr, const { nama, umur: usia = 17 } = obj (ganti nama dan nilai bawaan), dan bisa bersarang. Sangat umum di parameter fungsi dan React (const [state, setState] = useState()).

Spread ... menyebarkan isi iterable atau object: menyalin dan menggabung array ([...a, ...b]), object ({...default, ...opsi}, yang kanan menimpa yang kiri), atau argumen fungsi (Math.max(...arr)). Rest memakai tanda yang sama tetapi mengumpulkan sisa elemen: const [pertama, ...sisa] = arr.

Presedensi menentukan urutan evaluasi: kurung, lalu akses anggota dan panggilan, unary, **, * / %, + -, perbandingan, kesetaraan, &&, || dan ??, ternary, assignment. ?? tidak boleh dicampur langsung dengan ||/&& tanpa kurung (SyntaxError). Jika ragu, beri kurung: kode lebih jelas bagi pembaca.

JAVASCRIPT
const [kota1, , kota3 = 'Medan', ...lain] = ['Bandung', 'Bogor', undefined, 'Solo', 'Palu'];
console.log(kota1, kota3, lain);

const user = { id: 7, profil: { nama: 'Nia', kota: 'Malang' }, peran: 'admin' };
const { profil: { nama, kota }, peran: role = 'user', aktif = true, ...sisa } = user;
console.log(nama, kota, role, aktif, sisa);

let a = 1, b = 2;
[a, b] = [b, a];                                   // tukar tanpa variabel sementara
console.log(a, b);

const bawaan = { tema: 'terang', bahasa: 'id', ukuran: 14 };
const pilihan = { tema: 'gelap' };
console.log({ ...bawaan, ...pilihan });            // kanan menimpa kiri
const nilai = [70, 98, 85];
console.log(Math.max(...nilai), [...nilai, 60], [...'abc']);

function buatPesanan({ produk, jumlah = 1, catatan = '-' }) {   // destructuring parameter
  return `${jumlah}x ${produk} (${catatan})`;
}
console.log(buatPesanan({ produk: 'Martabak' }));

console.log(2 + 3 * 4 ** 2, (2 + 3) * 4, 1 + 2 + '3', '1' + 2 + 3, !true || true, 1 < 2 < 3, 3 > 2 > 1);
console.log((null || undefined) ?? 'aman pakai kurung');

Soal latihan

  1. Gabungkan konfigurasi bawaan {port: 3000, log: true, db: {host: "localhost"}} dengan {port: 8080}, lalu ambil port dan host dengan destructuring bersarang.

    Petunjuk

    {...bawaan, ...custom}; db tetap dari bawaan.

    Lihat jawaban
    JAVASCRIPT
    const bawaan = { port: 3000, log: true, db: { host: 'localhost' } };
const cfg = { ...bawaan, ...{ port: 8080 } };
const { port, db: { host } } = cfg;
console.log(port, host, cfg.log);
    KELUARAN
    8080 localhost true

Poin penting

  • Destructuring dengan rename, default, dan bersarang.
  • Spread menyebarkan, rest mengumpulkan.
  • {...a, ...b}: yang kanan menimpa.
  • Beri kurung saat ragu; ?? wajib kurung bila dicampur || atau &&.

Cek pemahaman

Hasil 3 > 2 > 1?

Jawaban: false

3 > 2 = true, lalu true > 1 berarti 1 > 1 = false.

Hasil { ...{a: 1, b: 2}, ...{b: 9} }?

Jawaban: {a: 1, b: 9}

Properti kanan menimpa.

Hasil 2 ** 3 ** 2?

Jawaban: 512

** asosiatif kanan: 3 ** 2 = 9, lalu 2 ** 9.
