Tipe primitif: string, number, boolean

Buka versi interaktif

JS punya 8 tipe data: tujuh primitif (string, number, bigint, boolean, undefined, null, symbol) dan object. Nilai primitif bersifat immutable (tidak bisa diubah, hanya diganti) dan dibandingkan berdasarkan nilainya.

string: teks dalam kutip satu, kutip dua, atau backtick (template literal, bisa multi-baris dan interpolasi). String immutable: metode seperti toUpperCase() mengembalikan string baru. number: satu tipe untuk bulat dan pecahan, berupa 64-bit floating point (IEEE 754), sehingga 0.1 + 0.2 tidak persis 0.3. Bilangan bulat aman hanya sampai Number.MAX_SAFE_INTEGER (2 pangkat 53 dikurangi 1). Ada nilai khusus Infinity, -Infinity, dan NaN (Not a Number, tetapi bertipe number).

boolean: true atau false. Untuk uang di aplikasi nyata, hindari pecahan float: simpan dalam satuan terkecil (rupiah atau sen) sebagai bilangan bulat, lalu format dengan Intl.NumberFormat.

Poin penting

  • 7 primitif + object.
  • Primitif immutable dan dibandingkan per nilai.
  • number = float 64-bit: hati-hati 0.1 + 0.2.
  • NaN bertipe number; cek dengan Number.isNaN.
  • Uang: bilangan bulat + Intl.NumberFormat.

Cek pemahaman

Jawaban: false

Hasilnya 0.30000000000000004 karena representasi biner float.

typeof NaN?

Jawaban: "number"

NaN adalah nilai number khusus.
