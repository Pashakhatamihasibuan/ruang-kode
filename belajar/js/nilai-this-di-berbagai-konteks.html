Nilai this di berbagai konteks

Buka versi interaktif

this ditentukan oleh cara fungsi dipanggil, bukan di mana ia ditulis (kecuali arrow function). Aturannya, dari prioritas tertinggi: (1) dipanggil dengan new: this = object baru; (2) explicit binding dengan call/apply/bind: this = object yang diberikan; (3) implicit binding, dipanggil sebagai metode obj.f(): this = obj; (4) default binding, dipanggil polos f(): undefined di strict, globalThis di sloppy.

Sendirian di tingkat atas: di skrip biasa browser this = window, di modul ES this = undefined, di CommonJS Node this = module.exports. Arrow function tidak punya this sendiri; ia memakai this dari scope luar tempat ia ditulis (lexical this), sehingga cocok untuk callback di dalam metode.

Jebakan paling umum: kehilangan this saat metode dilepas dari object-nya, misalnya const f = obj.metode; f() atau setTimeout(obj.metode, 100). Solusinya: bungkus dengan arrow, pakai bind, atau definisikan metode sebagai class field arrow.

JAVASCRIPT
console.log('tingkat atas modul ES:', this);

const toko = {
  nama: 'Toko Sinar',
  produk: ['kopi', 'teh'],
  info() { return `${this.nama} menjual ${this.produk.length} produk`; },   // implicit
  daftarBiasa() { return this.produk.map(function (p) { return `${this?.nama}: ${p}`; }); },
  daftarArrow() { return this.produk.map(p => `${this.nama}: ${p}`); },      // lexical this
};
console.log(toko.info());
console.log(toko.daftarBiasa());
console.log(toko.daftarArrow());

const lepas = toko.info;
try { lepas(); } catch (e) { console.log('metode dilepas:', e.name + ':', e.message); }
const terikat = toko.info.bind(toko);
console.log('setelah bind:', terikat());

function Produk(nama) { this.nama = nama; }   // new binding
console.log(new Produk('Gula Aren'));

class Tombol {
  label = 'Simpan';
  klikArrow = () => `klik ${this.label}`;     // class field arrow: this selalu instance
  klikBiasa() { return `klik ${this?.label}`; }
}
const t = new Tombol();
const { klikArrow, klikBiasa } = t;
console.log(klikArrow(), '|', klikBiasa());

Soal latihan

  1. Object timer punya nama: "Pomodoro" dan metode mulai() yang mengembalikan array 3 pesan "Pomodoro: detik ke-n" memakai Array.from dengan callback. Pastikan this benar.

    Petunjuk

    Gunakan arrow function sebagai callback Array.from.

    Lihat jawaban
    JAVASCRIPT
    const timer = {
  nama: 'Pomodoro',
  mulai() {
    return Array.from({ length: 3 }, (_, i) => `${this.nama}: detik ke-${i + 1}`);
  },
};
console.log(timer.mulai());

Poin penting

  • this ditentukan cara pemanggilan.
  • Prioritas: new, explicit, implicit, default.
  • Arrow memakai this dari luar.
  • Metode yang dilepas kehilangan this: bind atau arrow.
