Built-in objects

Buka versi interaktif

JS menyediakan banyak built-in objects (objek bawaan standar) yang siap pakai tanpa import. Kelompok pentingnya: dasar (Object, Function, Boolean, Symbol, Error), angka dan tanggal (Number, BigInt, Math, Date), teks (String, RegExp), koleksi (Array, Map, Set, WeakMap, WeakSet, typed arrays), terstruktur (JSON, ArrayBuffer), kontrol abstraksi (Promise, generator), refleksi (Reflect, Proxy), dan internasionalisasi (Intl).

Jangan tertukar dengan Web API (document, fetch, localStorage, setTimeout) yang disediakan browser, atau API Node (fs, process). Built-in objects adalah bagian dari bahasa itu sendiri sehingga tersedia di semua lingkungan. Objek global tingkat atas bisa diakses lewat globalThis.

Untuk tanggal, Date punya banyak kekurangan (bulan dimulai dari 0, zona waktu membingungkan). Proposal Temporal sedang menggantikannya dan sudah mulai tersedia di browser baru; sampai merata, banyak tim memakai pustaka seperti date-fns atau Day.js.

Poin penting

  • Built-in objects tersedia di semua lingkungan tanpa import.
  • Web API (document, fetch) bukan bagian dari bahasa.
  • Bulan di Date dimulai dari 0.
  • Intl untuk format angka dan tanggal lokal.
