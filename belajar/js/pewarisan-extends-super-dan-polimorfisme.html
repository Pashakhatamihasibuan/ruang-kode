Pewarisan: extends, super, dan polimorfisme

Buka versi interaktif

class Anak extends Induk membuat Anak mewarisi semua metode Induk lewat prototype chain. Di constructor Anak, wajib memanggil super(...) sebelum memakai this. super.metode() memanggil versi induk dari dalam metode yang di-override.

Polimorfisme: beberapa class punya metode bernama sama dengan perilaku berbeda, sehingga kode pemanggil cukup memanggil x.hitung() tanpa peduli jenisnya. instanceof mengecek apakah prototype sebuah class ada di rantai object. Class bawaan juga bisa diwarisi, misalnya extends Error atau extends EventTarget.

Prinsip desain yang dipegang tim profesional: composition over inheritance. Pewarisan yang dalam (lebih dari dua tingkat) membuat kode kaku; sering lebih baik menyusun object dari bagian-bagian kecil atau fungsi. Di ekosistem React modern, komponen class sudah jarang dan digantikan fungsi + hook, tetapi class tetap umum di backend (NestJS), pustaka, dan game.

JAVASCRIPT
class Pembayaran {
  constructor(nominal) { this.nominal = nominal; }
  biayaAdmin() { return 0; }
  total() { return this.nominal + this.biayaAdmin(); }
  toString() { return `${this.constructor.name}: Rp${this.total().toLocaleString('id-ID')}`; }
}
class Transfer extends Pembayaran {
  constructor(nominal, bank) {
    super(nominal);                       // wajib sebelum this
    this.bank = bank;
  }
  biayaAdmin() { return this.bank === 'BCA' ? 0 : 6500; }
}
class Kartu extends Pembayaran {
  biayaAdmin() { return Math.round(this.nominal * 0.02); }
  toString() { return super.toString() + ' (termasuk MDR 2%)'; }   // pakai versi induk
}
class QRIS extends Pembayaran {
  biayaAdmin() { return Math.round(this.nominal * 0.007); }
}

const daftar = [new Transfer(250000, 'BRI'), new Transfer(250000, 'BCA'), new Kartu(250000), new QRIS(250000)];
for (const p of daftar) console.log(String(p));   // polimorfisme
console.log(daftar[2] instanceof Kartu, daftar[2] instanceof Pembayaran, daftar[2] instanceof Transfer);
console.log(Object.getPrototypeOf(Kartu.prototype) === Pembayaran.prototype);

class Salah extends Pembayaran { constructor() { this.x = 1; super(0); } }
try { new Salah(); } catch (e) { console.log(e.name + ':', e.message); }

// composition: gabungkan kemampuan tanpa pewarisan dalam
const bisaDiskon = obj => ({ ...obj, diskon(p) { return obj.harga * (1 - p / 100); } });
const bisaPajak = obj => ({ ...obj, pajak() { return obj.harga * 0.11; } });
const produk = bisaPajak(bisaDiskon({ nama: 'Headset', harga: 300000 }));
console.log(produk.diskon(10), produk.pajak());

Soal latihan

  1. Buat class Bentuk dengan metode luas() yang mengembalikan 0 dan info(). Turunkan Persegi(sisi) dan Lingkaran(r) yang override luas(). Cetak info semua bentuk dalam satu array.

    Petunjuk

    info() memakai this.constructor.name dan this.luas().toFixed(2).

    Lihat jawaban
    JAVASCRIPT
    class Bentuk {
  luas() { return 0; }
  info() { return `${this.constructor.name} luas ${this.luas().toFixed(2)}`; }
}
class Persegi extends Bentuk {
  constructor(s) { super(); this.s = s; }
  luas() { return this.s ** 2; }
}
class Lingkaran extends Bentuk {
  constructor(r) { super(); this.r = r; }
  luas() { return Math.PI * this.r ** 2; }
}
for (const b of [new Persegi(4), new Lingkaran(3), new Bentuk()]) console.log(b.info());

    Persegi luas 16.00
Lingkaran luas 28.27
Bentuk luas 0.00

Poin penting

  • extends mewarisi lewat prototype chain.
  • super() wajib sebelum this di constructor anak.
  • super.metode() memanggil versi induk.
  • Polimorfisme: metode sama, perilaku beda.
  • Composition over inheritance.

Cek pemahaman

Apa yang terjadi jika constructor anak memakai this sebelum super()?

Jawaban: ReferenceError

this belum diinisialisasi sebelum super.

new Kartu() instanceof Pembayaran?

Jawaban: true

Pembayaran.prototype ada di rantai prototype Kartu.
