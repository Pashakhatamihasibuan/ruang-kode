Aritmetika, assignment, dan perbandingan

Buka versi interaktif

Aritmetika: + - * /, % (sisa bagi, tandanya mengikuti operand kiri), ** (pangkat), ++ dan --. Bentuk prefix ++i menaikkan lalu mengembalikan nilai baru; postfix i++ mengembalikan nilai lama lalu menaikkan.

Assignment: = dan bentuk gabungannya += -= *= /= %= **=, operator bitwise <<= >>= &= |= ^=, serta logical assignment ES2021: a ||= b (isi jika falsy), a &&= b (isi jika truthy), a ??= b (isi jika null/undefined).

Perbandingan: < > <= >=, === !==, == !=. Dua string dibandingkan per kode karakter (huruf besar lebih kecil dari huruf kecil), jadi untuk mengurutkan nama pakai localeCompare atau Intl.Collator.

Logical assignment (ES2021)
OperatorSama denganMengisi saat a
a ||= ba || (a = b)falsy (0, "", null, ...)
a &&= ba && (a = b)truthy
a ??= ba ?? (a = b)null atau undefined
JAVASCRIPT
console.log(17 % 5, -17 % 5, 2 ** 10, 7 / 2, Math.trunc(7 / 2));
let i = 5;
console.log(i++, i, ++i, i);          // postfix vs prefix

let poin = 100;
poin += 50; poin *= 2; poin -= 25; poin **= 1;
console.log('poin:', poin);

const opsi = { tema: '', bahasa: null, notif: true };
opsi.tema ||= 'terang';    // '' falsy -> diisi
opsi.bahasa ??= 'id';      // null -> diisi
opsi.notif &&= 'email';    // truthy -> diganti
console.log(opsi);

console.log('apel' < 'jeruk', 'Zebra' < 'apel', 'a'.charCodeAt(0), 'Z'.charCodeAt(0));
const nama = ['citra', 'Ani', 'budi', 'Dodi', 'Émile'];
console.log(nama.toSorted(), nama.toSorted((a, b) => a.localeCompare(b, 'id')));

Poin penting

  • % mengikuti tanda operand kiri; ** untuk pangkat.
  • i++ mengembalikan nilai lama, ++i nilai baru.
  • ||=, &&=, ??= untuk default yang ringkas.
  • localeCompare untuk mengurutkan teks.

Cek pemahaman

let a = 3; const b = a++ + 1; nilai b?

Jawaban: 4

a++ mengembalikan 3, lalu a menjadi 4.

Setelah let x = 0; x ||= 10; x ??= 20; nilai x?

Jawaban: 10

0 falsy sehingga diisi 10; 10 bukan nullish.
