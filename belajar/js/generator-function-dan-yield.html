Generator function dan yield

Buka versi interaktif

Generator function ditulis function*. Memanggilnya tidak langsung menjalankan isinya, tetapi mengembalikan object generator yang sekaligus iterator dan iterable. Setiap next() menjalankan kode sampai yield berikutnya, menyerahkan nilai, lalu menjeda dengan state tetap tersimpan. Ini cara termudah membuat iterator.

Karena lazy (menghitung hanya saat diminta), generator bisa mewakili urutan tak terbatas seperti ID berurutan atau deret Fibonacci, dan memproses data besar per potong tanpa memuat semuanya ke memori. yield* mendelegasikan ke iterable lain, dan next(nilai) bisa mengirim nilai masuk ke dalam generator.

ES2025 menambahkan iterator helpers: .map, .filter, .take, .drop, .flatMap, .reduce, .toArray langsung pada iterator, sehingga pipeline lazy bisa ditulis tanpa membuat array perantara. Async generator (async function*) dikonsumsi dengan for await...of, cocok untuk data berhalaman dari API atau stream.

JAVASCRIPT
function* langkahCheckout() {
  console.log('  (generator mulai)');
  yield 'keranjang';
  yield 'alamat';
  const metode = yield 'pembayaran';      // menerima nilai dari next()
  return `selesai dengan ${metode}`;
}
const g = langkahCheckout();
console.log('generator dibuat, belum jalan');
console.log(g.next(), g.next(), g.next());
console.log(g.next('QRIS'), g.next());

function* idBerurutan(awalan) {
  let n = 1;
  while (true) yield `${awalan}-${String(n++).padStart(4, '0')}`;   // tak terbatas, tetapi lazy
}
const idGen = idBerurutan('INV');
console.log(idGen.next().value, idGen.next().value);

function* fibonacci() { let [a, b] = [0, 1]; while (true) { yield a; [a, b] = [b, a + b]; } }
console.log(fibonacci().filter(n => n % 2 === 0).take(6).toArray());   // iterator helpers ES2025

function* gabung() { yield* [1, 2]; yield* 'ab'; }
console.log([...gabung()]);

async function* ambilHalaman() {               // async generator: data berhalaman
  const db = [['a', 'b'], ['c', 'd'], ['e']];
  for (let hal = 0; hal < db.length; hal++) {
    await new Promise(r => setTimeout(r, 10));
    yield db[hal];
  }
}
for await (const halaman of ambilHalaman()) console.log('halaman', halaman);

Soal latihan

  1. Buat generator potong(arr, ukuran) yang menghasilkan array per potongan (chunk). Uji dengan 7 angka dan ukuran 3.

    Petunjuk

    Loop i += ukuran, yield arr.slice(i, i + ukuran).

    Lihat jawaban
    JAVASCRIPT
    function* potong(arr, ukuran) {
  for (let i = 0; i < arr.length; i += ukuran) yield arr.slice(i, i + ukuran);
}
for (const bagian of potong([1, 2, 3, 4, 5, 6, 7], 3)) console.log(bagian);
    KELUARAN
    [ 1, 2, 3 ]
[ 4, 5, 6 ]
[ 7 ]

Poin penting

  • function* mengembalikan generator; isi jalan saat next().
  • yield menjeda dan menyerahkan nilai.
  • Lazy: bisa tak terbatas dan hemat memori.
  • yield* untuk delegasi; next(v) mengirim nilai masuk.
  • async function* + for await untuk data berhalaman.
