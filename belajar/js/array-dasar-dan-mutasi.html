Array: dasar dan mutasi

Buka versi interaktif

Array adalah koleksi berindeks mulai dari 0. Panjangnya dinamis dan isinya boleh campuran tipe, walau di praktik sebaiknya satu jenis. length selalu indeks terbesar + 1. Gunakan at(-1) untuk elemen terakhir.

Metode mutating mengubah array asli: push/pop (ujung belakang), unshift/shift (depan, lebih lambat karena menggeser indeks), splice (sisip/hapus di tengah), sort, reverse, fill. Di React dan Redux, state tidak boleh dimutasi, jadi pakai versi non-mutating: slice, concat, spread [...a], serta ES2023 toSorted, toReversed, toSpliced, with.

Pencarian: includes (ada atau tidak), indexOf (posisi), find/findIndex (dengan kondisi), findLast. Cek array kosong dengan arr.length === 0, karena array kosong tetap truthy.

Ambil potongan-slice(awal, akhir)
JAVASCRIPT
const antrean = ['Ani', 'Budi'];
antrean.push('Citra');               // tambah di belakang
antrean.unshift('Dodi');             // tambah di depan
console.log(antrean, antrean.length, antrean.at(-1));
console.log('dilayani:', antrean.shift(), '| sisa:', antrean);
antrean.splice(1, 1, 'Eko', 'Fani'); // dari indeks 1 hapus 1, sisipkan 2
console.log(antrean);

const nilai = [70, 95, 82];
const urut = nilai.toSorted((a, b) => b - a);   // tidak mengubah asli
const ganti = nilai.with(0, 75);
console.log(nilai, urut, ganti);
console.log(nilai.includes(95), nilai.indexOf(82), nilai.find(n => n > 80), nilai.findLast(n => n > 80));
console.log(Array.from({ length: 5 }, (_, i) => i * i), Array.of(7), new Array(3).fill(0));
console.log([[1, 2], [3, [4]]].flat(Infinity), Boolean([]));

Soal latihan

  1. Daftar tugas ["desain", "coding", "testing"]: sisipkan "review" sebelum "testing", hapus "desain", dan tampilkan hasil akhirnya tanpa memakai push.

    Petunjuk

    splice(indeks, jumlahHapus, ...sisipan).

    Lihat jawaban
    JAVASCRIPT
    const tugas = ['desain', 'coding', 'testing'];
tugas.splice(tugas.indexOf('testing'), 0, 'review');
tugas.splice(tugas.indexOf('desain'), 1);
console.log(tugas);
    KELUARAN
    [ 'coding', 'review', 'testing' ]

Poin penting

  • Indeks mulai 0; at(-1) untuk elemen terakhir.
  • Bedakan metode mutating dan non-mutating.
  • toSorted, toReversed, toSpliced, with (ES2023) untuk state immutable.
  • Array kosong itu truthy; cek length.
