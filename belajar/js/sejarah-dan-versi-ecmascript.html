Sejarah dan versi ECMAScript

Buka versi interaktif

Tahun 1995 Brendan Eich di Netscape membuat bahasa ini dalam sekitar 10 hari dengan nama Mocha, lalu LiveScript, lalu JavaScript. Agar tidak dikuasai satu perusahaan, bahasa ini distandarkan oleh Ecma International dengan nama ECMAScript (spesifikasi ECMA-262). "JavaScript" adalah implementasi paling populer dari standar itu.

Standar dikembangkan oleh komite TC39. Setiap fitur baru melalui stage 0 sampai 4; fitur yang mencapai stage 4 masuk ke rilis tahunan berikutnya. Sejak ES2015 (ES6), yang membawa let/const, arrow function, class, modul, Promise, dan template literal, ECMAScript dirilis setiap Juni dengan nama tahun: ES2016, ES2017, dan seterusnya.

Di dunia kerja kamu akan mendengar istilah "ES6+" atau "modern JavaScript", yang berarti kode memakai fitur sejak ES2015. Untuk browser lama, alat seperti Babel, esbuild, atau SWC melakukan transpile ke sintaks lama, dan polyfill (misalnya core-js) menambahkan fungsi yang belum ada. Situs caniuse.com dan tabel kompatibilitas MDN dipakai untuk mengecek dukungan.

JAVASCRIPT
// Beberapa fitur dari versi yang berbeda, semua didukung Node 22
const nilai = [70, 85, 92];                      // ES2015: const, array
const [pertama, ...sisa] = nilai;                 // ES2015: destructuring, rest
console.log(pertama, sisa);
console.log(nilai.includes(85));                  // ES2016: includes
console.log(Object.entries({ a: 1, b: 2 }));       // ES2017: Object.entries
const cfg = { tema: null };
console.log(cfg.tema ?? 'terang');                // ES2020: nullish coalescing
console.log(cfg.user?.nama);                      // ES2020: optional chaining
console.log(nilai.at(-1));                        // ES2022: at()
console.log(nilai.toSorted((a, b) => b - a), nilai); // ES2023: toSorted tidak mengubah asli
console.log(Object.groupBy([1, 2, 3, 4], n => n % 2 ? 'ganjil' : 'genap')); // ES2024

Poin penting

  • ECMAScript adalah standar, JavaScript implementasinya.
  • TC39 mengelola fitur lewat stage 0 sampai 4.
  • ES2015 adalah lompatan terbesar; sejak itu rilis tahunan.
  • Babel/esbuild untuk transpile, polyfill untuk API yang belum ada.
