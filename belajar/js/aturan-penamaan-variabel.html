Aturan penamaan variabel

Buka versi interaktif

Nama variabel (identifier) boleh berisi huruf, angka, _, dan $, tetapi tidak boleh diawali angka dan tidak boleh berupa kata kunci (reserved word) seperti class, return, new, let. JS case-sensitive: nama dan Nama adalah dua variabel berbeda.

Konvensi industri: camelCase untuk variabel dan fungsi (totalHarga), PascalCase untuk class dan komponen (KeranjangBelanja), UPPER_SNAKE_CASE untuk konstanta konfigurasi (MAX_RETRY), awalan is/has/can untuk boolean (isAktif), dan awalan # untuk field privat class.

Nama yang baik menjelaskan maksud, bukan tipe: hariSejakLogin lebih jelas dari d atau angka1. Satu huruf hanya wajar untuk indeks perulangan pendek (i, j). Di tim, pilih satu bahasa penamaan (Indonesia atau Inggris) dan konsisten.

JAVASCRIPT
const totalHarga = 125000;        // camelCase
const MAX_PERCOBAAN = 3;          // konstanta konfigurasi
const isMember = true;            // boolean dengan awalan is
const $tombol = 'elemen DOM';     // $ boleh (sering dipakai untuk elemen)
const _internal = 'hanya modul';  // _ menandai internal (konvensi)

let nama = 'rina', Nama = 'RINA';
console.log(nama === Nama);       // case-sensitive

// const 2tahun = 2;   SyntaxError: tidak boleh diawali angka
// const class = 'A';  SyntaxError: kata kunci
const hariSejakLogin = 4;
console.log(`${totalHarga} ${MAX_PERCOBAAN} ${isMember} ${hariSejakLogin}`);

Poin penting

  • Huruf, angka, _, $; tidak diawali angka; bukan kata kunci.
  • Case-sensitive.
  • camelCase, PascalCase, UPPER_SNAKE_CASE sesuai peran.
  • Nama menjelaskan maksud.
