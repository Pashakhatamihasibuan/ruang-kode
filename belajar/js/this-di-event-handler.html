this di event handler

Buka versi interaktif

Di browser, saat fungsi biasa dipasang dengan addEventListener, this di dalamnya adalah elemen tempat listener dipasang (sama dengan event.currentTarget). Dengan arrow function, this mengikuti scope luar, sehingga di modul bernilai undefined atau, di dalam class, instance class tersebut.

Gaya modern lebih eksplisit: pakai event.currentTarget (elemen yang memasang listener) atau event.target (elemen yang sebenarnya diklik, bisa anak di dalamnya) daripada mengandalkan this. Untuk event delegation, satu listener di induk memeriksa event.target.closest(selector).

Di komponen class (misalnya Web Components atau React class lama), metode yang dipakai sebagai handler harus di-bind di konstruktor atau ditulis sebagai class field arrow agar this tetap instance. Ingat juga untuk melepas listener dengan removeEventListener memakai referensi fungsi yang sama; fungsi hasil bind baru setiap kali dipanggil, jadi simpan hasilnya.

HTML
<button id="simpan">Simpan <span>💾</span></button>
<ul id="menu"><li data-id="1">Beranda</li><li data-id="2">Produk</li></ul>

<script type="module">
const btn = document.querySelector('#simpan');

btn.addEventListener('click', function (e) {
  console.log(this === btn, this === e.currentTarget);   // true true
  console.log(e.target.tagName);   // 'SPAN' jika ikon yang diklik
});

btn.addEventListener('click', (e) => {
  console.log(this);               // undefined (modul): arrow tidak punya this
  console.log(e.currentTarget.id); // 'simpan'
});

// event delegation
document.querySelector('#menu').addEventListener('click', (e) => {
  const li = e.target.closest('li');
  if (li) console.log('buka menu', li.dataset.id);
});

class Penghitung {
  n = 0;
  constructor(el) {
    this.el = el;
    this.klik = this.klik.bind(this);          // simpan hasil bind
    el.addEventListener('click', this.klik);
  }
  klik() { this.n++; this.el.textContent = `Diklik ${this.n}x`; }
  hancurkan() { this.el.removeEventListener('click', this.klik); }  // referensi sama
}
new Penghitung(btn);
</script>

Poin penting

  • Function biasa di addEventListener: this = elemen.
  • Arrow: this dari luar.
  • Lebih jelas pakai e.currentTarget dan e.target.
  • Simpan fungsi hasil bind agar bisa removeEventListener.
