Strict mode

Buka versi interaktif

Strict mode diaktifkan dengan 'use strict'; di awal file atau fungsi. Mode ini mengubah beberapa kesalahan diam-diam menjadi error, menutup fitur yang berbahaya, dan membantu engine mengoptimasi kode.

Perubahan utamanya: assign ke variabel yang belum dideklarasikan melempar ReferenceError (tanpa strict, diam-diam membuat global); this di fungsi biasa yang dipanggil tanpa object bernilai undefined (bukan objek global); menulis ke properti read-only atau object yang dibekukan melempar TypeError; parameter dengan nama ganda dan with dilarang; serta delete pada variabel atau properti yang tidak bisa dihapus melempar error.

Kabar baiknya, modul ES dan isi class otomatis strict. Kode modern dengan import/export (Vite, Next.js, Node ESM) sudah strict tanpa perlu menulis direktifnya. Contoh di bawah dijalankan sebagai CommonJS agar perbedaan mode non-strict (sloppy mode) dan strict terlihat.

JAVASCRIPT
function sloppy() {
  bocor = 'jadi global';          // tanpa deklarasi
  return typeof this;
}
console.log(sloppy(), typeof globalThis.bocor);

function ketat() {
  'use strict';
  try { tidakAda = 1; } catch (e) { console.log(e.name + ':', e.message); }
  const beku = Object.freeze({ a: 1 });
  try { beku.a = 2; } catch (e) { console.log(e.name + ':', e.message); }
  try { delete Object.prototype; } catch (e) { console.log(e.name + ':', e.message); }
  return typeof this;
}
console.log(ketat());

class Contoh { cek() { return (function () { return this; })(); } }
console.log('isi class otomatis strict:', new Contoh().cek());

Poin penting

  • 'use strict' mengubah kesalahan diam menjadi error.
  • this di fungsi biasa = undefined di strict.
  • Modul ES dan class otomatis strict.
  • Strict membantu menemukan bug lebih awal.
