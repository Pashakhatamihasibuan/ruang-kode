Class, constructor, dan anggota class

Buka versi interaktif

class (ES2015) adalah cara rapi menulis cetakan object di atas sistem prototype. constructor berjalan saat new dipanggil untuk mengisi data awal. Metode yang ditulis di badan class disimpan di prototype sehingga dibagi semua instance. Isi class selalu strict mode, dan class tidak di-hoist seperti fungsi (berada di TDZ).

Class field (stok = 0) mendeklarasikan properti instance langsung. Field dan metode privat berawalan # (#saldo) benar-benar tidak bisa diakses dari luar, berbeda dengan konvensi lama _saldo yang hanya kesepakatan. Getter/setter (get total(), set harga(v)) membuat properti terhitung atau tervalidasi yang diakses seperti properti biasa.

Static member (static dariJSON(), static #jumlah) milik class itu sendiri, bukan instance; cocok untuk factory method dan penghitung. Static block (static { }) menjalankan inisialisasi sekali. Prinsip enkapsulasi: sembunyikan state internal, buka hanya metode yang aman.

JAVASCRIPT
class RekeningBank {
  static #jumlahRekening = 0;              // privat statis
  #saldo = 0;                              // privat instance
  riwayat = [];                            // field publik

  constructor(pemilik, saldoAwal = 0) {
    this.pemilik = pemilik;
    this.setor(saldoAwal);
    RekeningBank.#jumlahRekening++;
  }
  setor(n) {
    if (n < 0) throw new RangeError('setoran negatif');
    this.#saldo += n;
    this.#catat('setor', n);
    return this;                           // memungkinkan chaining
  }
  tarik(n) {
    if (n > this.#saldo) throw new Error('saldo tidak cukup');
    this.#saldo -= n;
    this.#catat('tarik', n);
    return this;
  }
  #catat(jenis, n) { this.riwayat.push(`${jenis} ${n}`); }   // metode privat
  get saldo() { return this.#saldo; }       // getter: hanya baca
  static get jumlah() { return RekeningBank.#jumlahRekening; }
  static dariJSON(teks) { const d = JSON.parse(teks); return new RekeningBank(d.pemilik, d.saldo); }
}

const r = new RekeningBank('Sinta', 100000);
r.setor(50000).tarik(30000);
console.log(r.pemilik, r.saldo, r.riwayat);
try { r.saldo = 999; } catch (e) { console.log('getter tanpa setter:', e.name); }
try { r.tarik(1e9); } catch (e) { console.log('ditolak:', e.message); }
console.log(Object.keys(r), '#saldo' in r, typeof r.setor);
const r2 = RekeningBank.dariJSON('{"pemilik":"Yoga","saldo":5000}');
console.log(r2.saldo, RekeningBank.jumlah, typeof RekeningBank);
console.log(Object.getPrototypeOf(r) === RekeningBank.prototype, r.setor === r2.setor);

Soal latihan

  1. Buat class Keranjang dengan field privat #item (array), metode tambah(nama, harga, qty = 1) yang bisa dirantai, getter total, dan getter jumlahItem.

    Petunjuk

    Simpan objek {nama, harga, qty}; total = reduce harga * qty.

    Lihat jawaban
    JAVASCRIPT
    class Keranjang {
  #item = [];
  tambah(nama, harga, qty = 1) {
    this.#item.push({ nama, harga, qty });
    return this;
  }
  get total() { return this.#item.reduce((a, i) => a + i.harga * i.qty, 0); }
  get jumlahItem() { return this.#item.reduce((a, i) => a + i.qty, 0); }
}
const k = new Keranjang().tambah('Kopi', 45000, 2).tambah('Roti', 15000);
console.log(k.jumlahItem, 'item, total', k.total);
    KELUARAN
    3 item, total 105000

Poin penting

  • class = syntactic sugar di atas prototype.
  • Metode di prototype, field di instance.
  • #privat benar-benar tersembunyi.
  • Getter/setter untuk properti terhitung/tervalidasi.
  • Static untuk factory dan data tingkat class.
