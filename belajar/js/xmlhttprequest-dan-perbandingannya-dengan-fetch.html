XMLHttpRequest dan perbandingannya dengan fetch

Buka versi interaktif

XMLHttpRequest (XHR) adalah API lama (sejak awal 2000-an) yang memungkinkan AJAX: memuat data tanpa memuat ulang halaman, teknologi di balik Gmail dan Google Maps generasi awal. Walau namanya XML, XHR bisa mengambil JSON, teks, dan biner.

XHR berbasis event dan callback (onload, onerror, onprogress), bukan Promise, sehingga lebih bertele-tele. Kelebihan yang masih membuatnya dipakai: event upload.onprogress untuk progress bar unggah yang belum ada padanannya yang sederhana di fetch. Pustaka Axios di browser juga memakai XHR di baliknya.

Untuk kode baru, gunakan fetch. Kenali XHR karena masih ada di kode lama, plugin jQuery ($.ajax), dan pertanyaan wawancara. API ini hanya ada di browser, jadi contoh di bawah tidak dijalankan di Node.

JAVASCRIPT
// GET dengan XMLHttpRequest
const xhr = new XMLHttpRequest();
xhr.open('GET', '/api/produk');
xhr.responseType = 'json';
xhr.onload = () => {
  if (xhr.status >= 200 && xhr.status < 300) console.log('data', xhr.response);
  else console.error('HTTP', xhr.status);
};
xhr.onerror = () => console.error('jaringan gagal');
xhr.send();

// unggah file dengan progress bar
function unggah(file, onPersen) {
  return new Promise((resolve, reject) => {
    const x = new XMLHttpRequest();
    x.open('POST', '/api/unggah');
    x.upload.onprogress = e => e.lengthComputable && onPersen(Math.round(e.loaded / e.total * 100));
    x.onload = () => (x.status < 300 ? resolve(x.response) : reject(new Error(`HTTP ${x.status}`)));
    x.onerror = () => reject(new Error('jaringan gagal'));
    const fd = new FormData();
    fd.append('berkas', file);
    x.send(fd);
  });
}
await unggah(inputFile.files[0], p => (progress.value = p));

// padanannya dengan fetch (tanpa progress unggah)
const res = await fetch('/api/produk');
if (!res.ok) throw new Error(`HTTP ${res.status}`);
console.log(await res.json());

Poin penting

  • XHR adalah API AJAX lama berbasis event.
  • Kelebihan XHR: progress unggah.
  • Kode baru: fetch.
  • Axios memakai XHR di browser.
