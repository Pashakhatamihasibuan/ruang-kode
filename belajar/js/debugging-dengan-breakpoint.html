Debugging dengan breakpoint

Buka versi interaktif

console.log berguna, tetapi breakpoint jauh lebih kuat: eksekusi berhenti di baris tertentu sehingga kamu bisa melihat Scope (nilai semua variabel lokal, closure, global), Call Stack, dan mengubah nilai saat itu juga. Buka panel Sources, cari file dengan Ctrl+P, lalu klik nomor baris. Atau tulis debugger; di kode.

Kendali langkah: Resume (F8), Step over (F10, jalankan baris tanpa masuk fungsi), Step into (F11, masuk ke fungsi), Step out (Shift+F11). Jenis breakpoint lain: conditional breakpoint (hanya berhenti jika kondisi true, misalnya id === 42), logpoint (mencetak tanpa mengubah kode), DOM breakpoint (saat elemen berubah), XHR/fetch breakpoint (saat URL tertentu diminta), event listener breakpoint (saat klik, keydown), dan Pause on exceptions.

Kode produksi biasanya di-minify; aktifkan source map agar DevTools menampilkan kode aslinya. Untuk Node, jalankan node --inspect app.js lalu buka chrome://inspect, atau gunakan debugger bawaan VS Code. Alur kerja yang baik: reproduksi bug secara konsisten, pasang breakpoint di dekat gejala, telusuri call stack mundur ke penyebab, perbaiki, lalu tulis tes agar bug tidak kembali.

JAVASCRIPT
function hitungDiskon(keranjang, kode) {
  let total = 0;
  for (const item of keranjang) {
    total += item.harga * item.qty;
  }
  debugger;                         // eksekusi berhenti di sini saat DevTools terbuka
  if (kode === 'HEMAT10') total *= 0.9;
  return total;
}

// Conditional breakpoint (klik kanan nomor baris > Add conditional breakpoint):
//   item.qty > 100
// Logpoint (klik kanan > Add logpoint):
//   'item', item.nama, item.harga

# Debug Node.js dengan DevTools
$ node --inspect-brk server.js
Debugger listening on ws://127.0.0.1:9229/...
# buka chrome://inspect lalu klik "inspect"

Poin penting

  • Breakpoint menampilkan Scope dan Call Stack.
  • F8 resume, F10 step over, F11 step into, Shift+F11 step out.
  • Conditional breakpoint dan logpoint menghemat waktu.
  • Source map untuk kode yang di-minify; --inspect untuk Node.
