for...in dan for...of

Buka versi interaktif

for...of mengiterasi nilai dari objek iterable: array, string (per karakter Unicode, aman untuk emoji), Map, Set, arguments, NodeList, dan generator. Ini pilihan utama untuk array. Butuh indeks? Pakai arr.entries() dengan destructuring.

for...in mengiterasi key string enumerable sebuah object, termasuk yang diwarisi dari prototype. Untuk object biasa, gaya modern lebih memilih Object.keys, Object.values, atau Object.entries dengan for...of karena hanya mengambil properti milik sendiri. Jangan pakai for...in untuk array: key-nya string dan urutan atau properti tambahan bisa mengejutkan.

Object biasa bukan iterable, sehingga for (const x of obj) melempar TypeError. Urutan key object: key berbentuk bilangan bulat diurutkan naik lebih dulu, lalu key string sesuai urutan sisip.

const nilai = [90, 75, 88];
for (const n of nilai) console.log('nilai', n);
for (const [i, n] of nilai.entries()) console.log(`#${i + 1}: ${n}`);

for (const ch of 'Hi😀') console.log(ch);           // per karakter, emoji utuh
console.log('Hi😀'.length, [...'Hi😀'].length);

const produk = { nama: 'Sambal', harga: 18000, stok: 40 };
for (const key in produk) console.log(key, '=', produk[key]);
for (const [k, v] of Object.entries(produk)) console.log(`${k}: ${v}`);

const induk = { warisan: true };
const anak = Object.create(induk);
anak.milikSendiri = 1;
const dariForIn = [];
for (const k in anak) dariForIn.push(k);
console.log(dariForIn, Object.keys(anak));
console.log(Object.keys({ b: 1, 2: 'x', a: 2, 1: 'y' }));
try {
  for (const x of produk) console.log(x);

Soal latihan

  1. Object stok {kopi: 3, teh: 0, gula: 12, susu: 0}: cetak barang yang habis memakai Object.entries dan for...of.

    Petunjuk

    Destructuring [barang, jumlah] lalu cek jumlah === 0.

    Lihat jawaban
    JAVASCRIPT
    const stok = { kopi: 3, teh: 0, gula: 12, susu: 0 };
for (const [barang, jumlah] of Object.entries(stok)) {
  if (jumlah === 0) console.log(`${barang} habis`);
}

Poin penting

  • for...of untuk nilai iterable; for...in untuk key object.
  • for...in ikut properti warisan.
  • Object.entries + for...of untuk object.
  • Object biasa bukan iterable.

Cek pemahaman

Output for (const i in ["a","b"]) console.log(typeof i)?

Jawaban: "string" dua kali

Key array dibaca sebagai string.

Cara mendapatkan indeks dan nilai di for...of?

Jawaban: for (const [i, v] of arr.entries())

entries menghasilkan pasangan [indeks, nilai].

Kerjakan latihannya di aplikasi

Sebelumnya: for, while, dan do...while

Berikutnya: break, continue, dan label
