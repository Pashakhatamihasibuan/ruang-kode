for, while, dan do...while

Buka versi interaktif

for (awal; kondisi; langkah) cocok saat jumlah putaran diketahui. while (kondisi) mengulang selama kondisi true dan diperiksa sebelum setiap putaran, cocok saat jumlah putaran belum diketahui (misalnya membaca data sampai habis). do { } while (kondisi) memeriksa setelah putaran sehingga isinya pasti berjalan minimal sekali, cocok untuk "coba dulu lalu ulangi jika gagal".

Hati-hati dengan infinite loop: kondisi yang tidak pernah false akan membekukan tab browser karena JS single-threaded. Pastikan variabel kondisi berubah di setiap putaran, dan beri batas maksimum untuk loop percobaan ulang.

Penghitung let di for dibuat baru di setiap putaran, sehingga callback di dalam loop menangkap nilai yang benar. Dengan var, semua callback berbagi satu variabel (bug klasik yang dibahas di modul closure).

Memilih jenis loop
LoopKondisi diperiksaPakai saat
forSebelum putaranJumlah putaran/indeks diketahui
whileSebelum putaranUlang sampai kondisi berubah
do...whileSetelah putaranMinimal sekali jalan (retry, menu)
for...ofPer elemen iterableNilai array, string, Map, Set
for...inPer key enumerableKey object (jarang)
arr.forEachPer elemenEfek samping sederhana (tidak bisa break)
JAVASCRIPT
// for: jumlah putaran pasti
let total = 0;
for (let i = 1; i <= 5; i++) total += i;
console.log('1+2+3+4+5 =', total);

// while: tabungan sampai target
let saldo = 1_000_000, bulan = 0;
while (saldo < 1_500_000) {
  saldo += 150_000;
  bulan++;
}
console.log(`target tercapai di bulan ke-${bulan}, saldo ${saldo}`);

// do...while: percobaan ulang dengan batas
const hasilAcak = [false, false, true];   // simulasi: sukses di percobaan ke-3
let percobaan = 0, sukses;
do {
  sukses = hasilAcak[percobaan];
  percobaan++;
  console.log(`percobaan ${percobaan}: ${sukses ? 'berhasil' : 'gagal'}`);
} while (!sukses && percobaan < 5);

// mundur dan langkah 2
const hitung = [];
for (let i = 10; i > 0; i -= 3) hitung.push(i);
console.log(hitung);
KELUARAN
1+2+3+4+5 = 15
target tercapai di bulan ke-4, saldo 1600000
percobaan 1: gagal
percobaan 2: gagal
percobaan 3: berhasil
[ 10, 7, 4, 1 ]

Soal latihan

  1. Cetak tabel perkalian 7 dari 1 sampai 10 dengan format "7 x 3 = 21".

    Petunjuk

    for dari 1 sampai 10.

    Lihat jawaban
    JAVASCRIPT
    for (let i = 1; i <= 10; i++) {
  console.log(`7 x ${String(i).padStart(2)} = ${7 * i}`);
}
    KELUARAN
    7 x  1 = 7
7 x  2 = 14
7 x  3 = 21
7 x  4 = 28
7 x  5 = 35
7 x  6 = 42
7 x  7 = 49
7 x  8 = 56
7 x  9 = 63
7 x 10 = 70

  2. Pinjaman Rp5.000.000 dicicil Rp750.000 per bulan. Dengan while, hitung berapa bulan sampai lunas dan berapa cicilan terakhir.

    Petunjuk

    Kurangi sisa selama sisa > 0; cicilan terakhir = min(sisa, 750000).

    Lihat jawaban
    JAVASCRIPT
    let sisa = 5_000_000, bulan = 0, terakhir = 0;
while (sisa > 0) {
  terakhir = Math.min(sisa, 750_000);
  sisa -= terakhir;
  bulan++;
}
console.log(`lunas dalam ${bulan} bulan, cicilan terakhir ${terakhir}`);
    KELUARAN
    lunas dalam 7 bulan, cicilan terakhir 500000

Poin penting

  • for untuk jumlah pasti, while untuk kondisi, do...while minimal sekali.
  • Hindari infinite loop: kondisi harus berubah.
  • let di for membuat binding baru per putaran.
  • Pemisah angka 1_000_000 memudahkan membaca.
