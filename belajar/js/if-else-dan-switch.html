if...else dan switch

Buka versi interaktif

if (kondisi) { } else if (...) { } else { } memilih cabang berdasarkan kondisi yang dikonversi ke boolean (truthy/falsy). Untuk kode yang mudah dibaca, pakai guard clause atau early return: tangani kasus khusus di awal fungsi lalu return, sehingga tidak ada if bersarang dalam.

switch (nilai) membandingkan dengan case memakai ===. Tanpa break, eksekusi "jatuh" ke case berikutnya (fall-through), yang berguna untuk mengelompokkan beberapa case tetapi sering menjadi bug jika tidak disengaja. Bungkus isi case dengan kurung kurawal jika mendeklarasikan let/const.

Alternatif yang populer: object lookup (peta dari nilai ke hasil) yang lebih ringkas daripada switch panjang, dan operator ternary untuk pilihan dua nilai yang sederhana.

JAVASCRIPT
function ongkir(berat, kota) {
  if (berat <= 0) return 'berat tidak valid';     // guard clause
  if (berat > 30) return 'gunakan kargo';
  let tarif;
  if (kota === 'Jakarta') tarif = 9000;
  else if (kota === 'Bandung' || kota === 'Bogor') tarif = 11000;
  else tarif = 18000;
  return Math.ceil(berat) * tarif;
}
console.log(ongkir(1.2, 'Jakarta'), ongkir(3, 'Bogor'), ongkir(2, 'Ambon'), ongkir(0, 'Jakarta'));

function namaHari(i) {
  switch (i) {
    case 0: return 'Minggu';
    case 6: return 'Sabtu';
    case 1: case 2: case 3: case 4: case 5: return 'Hari kerja';   // fall-through disengaja
    default: return 'tidak dikenal';
  }
}
console.log([0, 3, 6, 9].map(namaHari));

switch ('1') { case 1: console.log('number'); break; default: console.log("switch memakai ===, '1' bukan 1"); }

const ikonStatus = { lunas: '✅', menunggu: '⏳', batal: '❌' };   // object lookup
for (const s of ['lunas', 'batal', 'refund']) console.log(s, ikonStatus[s] ?? '❔');

Soal latihan

  1. Tulis fungsi predikat(nilai): A (>= 85), B (>= 70), C (>= 55), D (>= 40), E selain itu; nilai di luar 0 sampai 100 menghasilkan "tidak valid". Uji dengan 92, 70, 41, 12, 105.

    Petunjuk

    Guard clause untuk validasi, lalu if berurutan dari terbesar.

    Lihat jawaban
    JAVASCRIPT
    function predikat(n) {
  if (n < 0 || n > 100) return 'tidak valid';
  if (n >= 85) return 'A';
  if (n >= 70) return 'B';
  if (n >= 55) return 'C';
  if (n >= 40) return 'D';
  return 'E';
}
for (const n of [92, 70, 41, 12, 105]) console.log(n, predikat(n));

Poin penting

  • Guard clause mengurangi if bersarang.
  • switch memakai === dan perlu break.
  • Fall-through boleh jika disengaja dan diberi komentar.
  • Object lookup sebagai pengganti switch panjang.

Cek pemahaman

switch ('2') { case 2: ... } masuk ke case 2?

Jawaban: Tidak, switch memakai ===

'2' !== 2.

Apa akibat lupa break di case?

Jawaban: Eksekusi lanjut ke case berikutnya
