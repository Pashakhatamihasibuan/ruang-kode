Object.is, SameValue, dan SameValueZero

Buka versi interaktif

Selain == dan ===, spesifikasi punya dua algoritma kesetaraan lain. SameValue dipakai oleh Object.is(a, b): sama seperti === kecuali NaN dianggap sama dengan NaN, dan +0 dibedakan dari -0.

SameValueZero sama dengan SameValue kecuali +0 dan -0 dianggap sama. Algoritma inilah yang dipakai Array.prototype.includes, key Map, dan nilai Set. Sementara indexOf dan lastIndexOf memakai === sehingga tidak bisa menemukan NaN.

Dalam praktik, Object.is dipakai pustaka seperti React untuk memutuskan apakah state berubah (useState, dependency useEffect, useMemo). Karena perbandingannya per referensi, memutasi object lalu men-set object yang sama tidak memicu render ulang; buat object baru.

console.log(NaN === NaN, Object.is(NaN, NaN));
console.log(0 === -0, Object.is(0, -0));
console.log([NaN].includes(NaN), [NaN].indexOf(NaN));     // SameValueZero vs ===
console.log([-0].includes(0), new Set([0, -0]).size);
const m = new Map([[NaN, 'bukan angka']]);
console.log(m.get(NaN));
console.log(1 / 0, 1 / -0);                               // kenapa -0 bisa penting

// cara kerja seperti React: bandingkan state lama dan baru dengan Object.is
function setState(lama, baru) {
  return Object.is(lama, baru) ? 'tidak render ulang' : 'render ulang';
}
const state = { items: [1] };
state.items.push(2);
console.log(setState(state, state));                     // mutasi: referensi sama
console.log(setState(state, { ...state, items: [...state.items, 3] }));

Soal latihan

  1. Tulis fungsi samaDangkal(a, b) yang membandingkan dua object satu tingkat memakai Object.is untuk setiap key (seperti shallowEqual di React). Uji dengan tiga pasangan.

    Petunjuk

    Cek jumlah key sama, lalu every key Object.is(a[k], b[k]).

    Lihat jawaban
    JAVASCRIPT
    function samaDangkal(a, b) {
  if (Object.is(a, b)) return true;
  const ka = Object.keys(a), kb = Object.keys(b);
  return ka.length === kb.length && ka.every(k => Object.hasOwn(b, k) && Object.is(a[k], b[k]));
}
const list = [1];
console.log(samaDangkal({ x: 1, y: NaN }, { x: 1, y: NaN }));
console.log(samaDangkal({ a: list }, { a: list }));
console.log(samaDangkal({ a: [1] }, { a: [1] }));

Poin penting

  • Object.is = SameValue: NaN sama, +0 beda -0.
  • includes, Map, Set = SameValueZero.
  • indexOf dan switch memakai ===.
  • React membandingkan state dengan Object.is: jangan mutasi.
