Lexical scoping dan closure

Buka versi interaktif

Lexical scoping berarti scope ditentukan oleh posisi kode saat ditulis, bukan saat dipanggil. Fungsi di dalam fungsi lain bisa mengakses variabel fungsi luarnya.

Closure adalah fungsi beserta referensi ke lingkungan leksikal tempat ia dibuat. Fungsi dalam tetap "mengingat" variabel luar walaupun fungsi luar sudah selesai. Ini dasar dari banyak pola: data privat, function factory, memoization, debounce/throttle, partial application, serta hook React (useState dan useEffect bergantung pada closure).

Jebakan klasik: var di loop dengan callback asinkron membuat semua callback berbagi satu variabel. let menyelesaikannya karena setiap putaran punya binding baru. Jebakan lain di React adalah stale closure: callback menangkap nilai state lama. Closure juga menahan variabel di memori selama fungsinya masih dirujuk, jadi lepaskan referensi (misalnya event listener) jika tidak dipakai lagi.

JAVASCRIPT
function buatPenghitung(awal = 0) {
  let n = awal;                         // ditangkap closure, privat
  return {
    tambah() { return ++n; },
    reset() { n = awal; return n; },
  };
}
const a = buatPenghitung(), b = buatPenghitung(100);
a.tambah(); a.tambah();
console.log(a.tambah(), b.tambah(), a.reset());

const buatPengali = faktor => angka => angka * faktor;   // function factory
const dobel = buatPengali(2), tripel = buatPengali(3);
console.log(dobel(7), tripel(7));

function buatFormatRp(prefix) {
  const fmt = new Intl.NumberFormat('id-ID');
  return n => `${prefix}${fmt.format(n)}`;
}
console.log(buatFormatRp('Rp')(2500000));

const hasilVar = [], hasilLet = [];
for (var i = 0; i < 3; i++) hasilVar.push(() => i);
for (let j = 0; j < 3; j++) hasilLet.push(() => j);
console.log(hasilVar.map(f => f()), hasilLet.map(f => f()));

function sekali(fn) {
  let sudah = false, hasil;
  return (...args) => (sudah ? hasil : ((sudah = true), (hasil = fn(...args))));
}
const inisialisasi = sekali(() => { console.log('koneksi dibuat'); return 'db'; });
console.log(inisialisasi(), inisialisasi());

Soal latihan

  1. Buat buatBatas(maks) yang mengembalikan fungsi coba(): setiap panggilan mengembalikan "percobaan ke-n" sampai maks, lalu "terkunci". Uji dengan maks 3 dan panggil 4 kali.

    Petunjuk

    Simpan hitungan di closure.

    Lihat jawaban
    JAVASCRIPT
    function buatBatas(maks) {
  let n = 0;
  return function coba() {
    if (n >= maks) return 'terkunci';
    n++;
    return `percobaan ke-${n}`;
  };
}
const login = buatBatas(3);
for (let i = 0; i < 4; i++) console.log(login());

Poin penting

  • Scope ditentukan saat kode ditulis (lexical).
  • Closure mengingat variabel luar setelah fungsi luar selesai.
  • Dasar data privat, factory, debounce, hook React.
  • let di loop mencegah bug closure var.
