Cara menjalankan JavaScript

Buka versi interaktif

1. Konsol browser. Tekan F12 (atau Ctrl+Shift+J / Cmd+Option+J), buka tab Console, ketik kode, lalu Enter. Cocok untuk mencoba potongan kecil dan memeriksa halaman yang sedang terbuka.

2. Di halaman HTML. Tulis kode di file terpisah dan muat dengan tag script di akhir body, atau di head dengan atribut defer agar HTML selesai dibaca dulu. Atribut type="module" mengaktifkan import/export dan strict mode, serta otomatis bersifat defer.

3. Node.js. Pasang Node versi LTS dari nodejs.org (atau lewat nvm/fnm), lalu jalankan node app.js. Ketik node saja untuk masuk REPL (Read-Eval-Print Loop). File berakhiran .mjs atau proyek dengan "type": "module" di package.json memakai modul ES.

4. Playground online seperti CodePen, JSFiddle, StackBlitz, atau tombol Jalankan di Ruang Kode. Di dunia kerja, editor yang umum adalah VS Code dengan ekstensi ESLint dan Prettier.

Cara memuat skrip di HTML
CaraKapan dijalankanUrutan antar skrip
script biasa di headSegera, menghentikan parsing HTMLSesuai urutan
script di akhir bodySetelah HTML di atasnya terbacaSesuai urutan
deferSetelah HTML selesai diparseSesuai urutan
asyncBegitu selesai diunduhTidak dijamin (cocok untuk analytics)
type="module"Seperti defer, mode strict, mendukung importSesuai urutan
HTML
<!-- index.html -->
<!doctype html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <title>Belajar JS</title>
  <script src="app.js" defer></script>        <!-- skrip biasa, jalan setelah HTML siap -->
  <script type="module" src="main.js"></script> <!-- modul ES -->
</head>
<body>
  <h1 id="judul">Halo</h1>
</body>
</html>

// app.js
document.querySelector('#judul').textContent = 'Halo dari JavaScript!';
console.log('Halaman siap');

# terminal
$ node --version
v22.22.0
$ node app-server.js
$ node                # masuk REPL, keluar dengan .exit atau Ctrl+D
> 2 ** 10
1024

Poin penting

  • Konsol DevTools untuk eksperimen cepat.
  • Di HTML: pakai defer atau type="module".
  • Node.js menjalankan JS di terminal; REPL untuk mencoba.
  • VS Code + ESLint + Prettier adalah setelan umum.
