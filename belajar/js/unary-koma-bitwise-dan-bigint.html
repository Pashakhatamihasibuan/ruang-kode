Unary, koma, bitwise, dan BigInt

Buka versi interaktif

Unary operator bekerja pada satu operand: typeof, delete (hapus properti), void (selalu undefined), +x (ke number), -x, !x, ~x (NOT bitwise), ++/--, serta await.

Operator koma mengevaluasi beberapa ekspresi dari kiri ke kanan dan mengembalikan yang terakhir. Pemakaian yang wajar hanya di bagian for dengan dua penghitung; di luar itu membuat kode sulit dibaca.

Bitwise (& | ^ ~ << >> >>>) mengubah operand menjadi bilangan bulat 32-bit lalu bekerja per bit. Dipakai untuk flag/izin yang digabung dalam satu angka, warna heksadesimal, hashing, dan grafis. Operator BigInt sama dengan number (+ - * / % **, bitwise kecuali >>>), pembagian dibulatkan ke nol, dan unary + tidak diizinkan.

const akun = { nama: 'Lia', token: 'rahasia' };

console.log(akun, typeof akun.token, void 0, -'5', +true);

for (let i = 0, j = 4; i < j; i++, j--) console.log('pasangan', i, j);   // koma di for
const x = (1, 2, 3);
console.log('koma mengembalikan yang terakhir:', x);

// flag izin dengan bitwise
const BACA = 1, TULIS = 2, HAPUS = 4;      // 001, 010, 100
let izin = BACA | TULIS;                   // gabung
console.log(izin.toString(2).padStart(3, '0'), Boolean(izin & TULIS), Boolean(izin & HAPUS));
izin |= HAPUS; izin &= ~TULIS;             // tambah HAPUS, cabut TULIS
console.log(izin.toString(2).padStart(3, '0'));

const warna = 0xff8800;                    // pecah warna hex ke RGB
console.log((warna >> 16) & 255, (warna >> 8) & 255, warna & 255);
console.log(5 ^ 3, ~5, 1 << 10, -16 >> 2, -16 >>> 28, 2 ** 32 | 0);

Soal latihan

  1. Ubah warna hex "#1E90FF" menjadi string "rgb(30, 144, 255)" memakai parseInt basis 16 dan operator geser bitwise.

    Petunjuk

    n = parseInt(hex.slice(1), 16); r = n >> 16 & 255.

    Lihat jawaban
    JAVASCRIPT
    const hex = '#1E90FF';
const n = parseInt(hex.slice(1), 16);
const r = (n >> 16) & 255, g = (n >> 8) & 255, b = n & 255;
console.log(`rgb(${r}, ${g}, ${b})`);
    KELUARAN
    rgb(30, 144, 255)

Poin penting

  • delete menghapus properti; void selalu undefined.
  • Operator koma hanya wajar di for.
  • Bitwise bekerja pada 32-bit; cocok untuk flag dan warna.
  • BigInt: pembagian dibulatkan ke nol, tanpa unary +.
