Built-in functions global

Buka versi interaktif

Selain metode pada object bawaan, JS punya beberapa fungsi global: parseInt, parseFloat, isNaN dan isFinite (versi lama yang melakukan koersi; lebih aman Number.isNaN dan Number.isFinite), encodeURIComponent/decodeURIComponent dan encodeURI/decodeURI, structuredClone, queueMicrotask, serta eval (hindari).

Lingkungan juga menambahkan fungsi global: setTimeout, setInterval, fetch, console, atob/btoa (Base64), crypto.randomUUID(), dan alert (browser saja). Semua tersedia di globalThis.

encodeURIComponent wajib dipakai saat menyusun query string dari input pengguna agar karakter seperti spasi, &, dan ? tidak merusak URL. Lebih baik lagi, pakai URL dan URLSearchParams. eval menjalankan teks sebagai kode: berbahaya (celah keamanan XSS), lambat, dan diblok oleh Content Security Policy.

Poin penting

  • Pakai Number.isNaN dan Number.isFinite.
  • encodeURIComponent atau URLSearchParams untuk input di URL.
  • structuredClone untuk salinan dalam.
  • Jangan pakai eval.
