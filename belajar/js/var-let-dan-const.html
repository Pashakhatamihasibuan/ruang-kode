var, let, dan const

Buka versi interaktif

Variabel adalah nama untuk sebuah nilai. JS punya tiga kata kunci: const untuk nama yang tidak akan di-assign ulang, let untuk nilai yang akan berubah, dan var (gaya lama sebelum ES2015).

Aturan praktis tim profesional (dan aturan ESLint prefer-const, no-var): pakai const secara bawaan, ganti ke let hanya jika memang perlu di-assign ulang, dan jangan memakai var di kode baru.

Penting: const mengunci ikatan (binding), bukan isinya. Objek atau array yang disimpan di const tetap bisa diubah isinya (mutasi). Untuk membekukan objek, pakai Object.freeze() (dangkal, hanya satu tingkat).

JAVASCRIPT
const PPN = 0.11;
let saldo = 100000;
saldo -= 25000;              // let boleh di-assign ulang
console.log('Saldo:', saldo);

try {
  PPN = 0.12;                 // const tidak boleh
} catch (e) {
  console.log(e.name + ':', e.message);
}

const keranjang = ['kopi'];
keranjang.push('teh');       // mutasi isi tetap boleh
console.log(keranjang);

const cfg = Object.freeze({ tema: 'gelap' });
try {
  cfg.tema = 'terang';       // modul ES = strict mode: TypeError
} catch (e) { console.log(e.name); }
console.log(cfg.tema, Object.isFrozen(cfg));

Soal latihan

  1. Buat const harga = 45000 dan let jumlah = 2. Tambah jumlah menjadi 3, lalu cetak total. Coba juga meng-assign ulang harga dan tangkap errornya.

    Petunjuk

    Bungkus assign ulang const dengan try/catch dan cetak e.name.

    Lihat jawaban
    JAVASCRIPT
    const harga = 45000;
let jumlah = 2;
jumlah = 3;
console.log('Total:', harga * jumlah);
try {
  harga = 50000;
} catch (e) {
  console.log('Gagal:', e.name);
}
    KELUARAN
    Total: 135000
Gagal: TypeError

Poin penting

  • Bawaan const, let jika perlu berubah, hindari var.
  • const mengunci binding, bukan isi objek.
  • Object.freeze membekukan satu tingkat.
