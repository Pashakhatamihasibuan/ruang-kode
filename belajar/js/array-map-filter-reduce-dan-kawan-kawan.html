Array: map, filter, reduce, dan kawan-kawan

Buka versi interaktif

Metode higher-order menerima fungsi callback dan menjadi inti gaya fungsional JS. map mengubah setiap elemen (panjang tetap), filter menyaring, reduce mengakumulasi menjadi satu nilai, forEach hanya menjalankan efek (tanpa nilai kembali), some/every mengecek kondisi, flatMap memetakan lalu meratakan satu tingkat.

Metode ini bisa dirantai (method chaining) sehingga transformasi data terbaca seperti pipeline. Untuk data sangat besar, satu reduce atau loop biasa bisa lebih hemat dibanding rantai panjang karena setiap tahap membuat array baru.

Selalu beri nilai awal pada reduce; tanpa itu, reduce pada array kosong melempar TypeError. Untuk mengelompokkan data, ES2024 menyediakan Object.groupBy dan Map.groupBy.

JAVASCRIPT
const pesanan = [
  { id: 1, kota: 'Bandung', total: 125000, status: 'lunas' },
  { id: 2, kota: 'Jakarta', total: 89000, status: 'batal' },
  { id: 3, kota: 'Bandung', total: 230000, status: 'lunas' },
  { id: 4, kota: 'Medan', total: 54000, status: 'lunas' },
];
const lunas = pesanan.filter(p => p.status === 'lunas');
console.log(lunas.map(p => p.id));
const omzet = lunas.reduce((acc, p) => acc + p.total, 0);
console.log('omzet:', omzet.toLocaleString('id-ID'));
console.log(pesanan.some(p => p.total > 200000), pesanan.every(p => p.total > 50000));

const perKota = Object.groupBy(lunas, p => p.kota);
for (const [kota, daftar] of Object.entries(perKota)) {
  console.log(kota.padEnd(8), daftar.reduce((a, p) => a + p.total, 0));
}
const tag = [['js', 'web'], ['node'], []].flatMap(t => t);
console.log(tag, [].reduce((a, b) => a + b, 0));

Soal latihan

  1. Dari data nilai [{nama:"Ani",n:88},{nama:"Budi",n:62},{nama:"Citra",n:75},{nama:"Dodi",n:91}], cetak nama yang lulus (n >= 70) diurutkan dari nilai tertinggi, dan rata-rata semua nilai dengan 1 desimal.

    Petunjuk

    filter, toSorted, map; reduce untuk jumlah lalu bagi length.

    Lihat jawaban
    JAVASCRIPT
    const data = [{ nama: 'Ani', n: 88 }, { nama: 'Budi', n: 62 }, { nama: 'Citra', n: 75 }, { nama: 'Dodi', n: 91 }];
const lulus = data.filter(d => d.n >= 70).toSorted((a, b) => b.n - a.n).map(d => d.nama);
console.log('Lulus:', lulus.join(', '));
const rata = data.reduce((a, d) => a + d.n, 0) / data.length;
console.log('Rata-rata:', rata.toFixed(1));
    KELUARAN
    Lulus: Dodi, Ani, Citra
Rata-rata: 79.0

Poin penting

  • map ubah, filter saring, reduce akumulasi.
  • Rantai metode membentuk pipeline data.
  • reduce selalu dengan nilai awal.
  • Object.groupBy untuk pengelompokan.

Cek pemahaman

Hasil [1, 2, 3].map(x => x * 2).filter(x => x > 2)?

Jawaban: [4, 6]

map menghasilkan [2,4,6], filter menyisakan [4,6].

Nilai kembali forEach?

Jawaban: undefined

forEach hanya untuk efek samping.
