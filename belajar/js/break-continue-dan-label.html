break, continue, dan label

Buka versi interaktif

break menghentikan loop (atau switch) terdekat seketika. continue melompati sisa putaran saat ini dan lanjut ke putaran berikutnya. Keduanya membuat kode lebih efisien, misalnya berhenti mencari begitu data ditemukan.

Untuk loop bersarang, label (luar: sebelum loop) memungkinkan break luar atau continue luar menargetkan loop luar. Fitur ini jarang dipakai; sering kali lebih bersih memindahkan loop ke fungsi dan memakai return.

forEach, map, dan metode callback lain tidak bisa di-break; return di dalam callback hanya melompati satu item. Jika butuh berhenti lebih awal, pakai for...of, atau some/find yang berhenti saat callback mengembalikan true.

JAVASCRIPT
const transaksi = [120, -1, 300, 0, 450, 999, 80];
let total = 0;
for (const t of transaksi) {
  if (t === 999) { console.log('penanda akhir, berhenti'); break; }
  if (t <= 0) { console.log('lewati nilai tidak valid:', t); continue; }
  total += t;
}
console.log('total valid:', total);

// label untuk keluar dari dua loop sekaligus
const kursi = [['A1', 'A2'], ['B1', 'B2'], ['C1', 'C2']];
const terisi = new Set(['A1', 'A2', 'B1']);
let dapat = null;
cari: for (const baris of kursi) {
  for (const k of baris) {
    if (!terisi.has(k)) { dapat = k; break cari; }
  }
}
console.log('kursi kosong pertama:', dapat);

// some berhenti di elemen pertama yang cocok
let diperiksa = 0;
const adaBesar = transaksi.some(t => { diperiksa++; return t > 400; });
console.log(adaBesar, 'diperiksa:', diperiksa);
KELUARAN
lewati nilai tidak valid: -1
lewati nilai tidak valid: 0
penanda akhir, berhenti
total valid: 870
kursi kosong pertama: B2
true diperiksa: 5

Soal latihan

  1. Cari bilangan prima pertama yang lebih besar dari 90 dengan while dan break; untuk cek prima pakai for dengan continue/break.

    Petunjuk

    Uji pembagi dari 2 sampai akar n.

    Lihat jawaban
    JAVASCRIPT
    let n = 91;
while (true) {
  let prima = n > 1;
  for (let d = 2; d * d <= n; d++) {
    if (n % d === 0) { prima = false; break; }
  }
  if (prima) break;
  n++;
}
console.log('prima pertama > 90:', n);
    KELUARAN
    prima pertama > 90: 97

Poin penting

  • break keluar dari loop; continue lompat ke putaran berikutnya.
  • Label untuk loop bersarang (jarang).
  • forEach tidak bisa di-break: pakai for...of, some, atau find.

Cek pemahaman

Output: for (let i=0;i&lt;5;i++){ if(i===2) continue; if(i===4) break; console.log(i) }

Jawaban: 0 1 3

2 dilewati, berhenti di 4.

Cara menghentikan iterasi lebih awal pada array?

Jawaban: for...of dengan break atau arr.some

forEach tidak bisa dihentikan.
