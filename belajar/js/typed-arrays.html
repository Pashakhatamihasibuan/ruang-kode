Typed Arrays

Buka versi interaktif

Typed arrays adalah tampilan berjenis (view) di atas blok memori mentah ArrayBuffer. Setiap elemen punya ukuran tetap: Uint8Array (0 sampai 255), Int16Array, Float32Array, Float64Array, BigInt64Array, dan lainnya. Panjangnya tetap dan semua elemen satu tipe.

Dipakai saat bekerja dengan data biner dan performa tinggi: piksel gambar di Canvas (Uint8ClampedArray), audio (Web Audio), WebGL/WebGPU, file yang diunggah (file.arrayBuffer()), WebSocket biner, kriptografi (crypto.getRandomValues), dan WebAssembly.

Nilai yang keluar rentang akan dibungkus (overflow), kecuali Uint8ClampedArray yang dipotong ke 0 sampai 255. Beberapa view bisa berbagi satu buffer, dan DataView membaca/menulis angka dengan urutan byte (endianness) tertentu, misalnya saat mengurai format file atau protokol jaringan.

JAVASCRIPT
const buf = new ArrayBuffer(8);              // 8 byte memori
const u8 = new Uint8Array(buf);
const u32 = new Uint32Array(buf);           // view lain pada buffer yang sama
u32[0] = 0x01020304;
console.log(u8, buf.byteLength);            // urutan byte little-endian

const piksel = new Uint8Array([250, 10]);
piksel[0] += 10;                            // overflow: 260 menjadi 4
const clamp = new Uint8ClampedArray([250, 10]);
clamp[0] += 10;                             // dipotong ke 255
clamp[1] = -20;                             // dipotong ke 0
console.log(piksel, clamp);

const f = Float32Array.from([0.1, 0.5]);
console.log(f[0], f.BYTES_PER_ELEMENT, Array.isArray(f));

const dv = new DataView(new ArrayBuffer(4));
dv.setUint16(0, 0xCAFE);                    // big-endian (bawaan DataView)
console.log(dv.getUint8(0).toString(16), dv.getUint8(1).toString(16));
console.log(new TextEncoder().encode('Hai'), new TextDecoder().decode(new Uint8Array([79, 75])));

Soal latihan

  1. Buat Uint8ClampedArray berisi satu piksel RGBA [200, 120, 40, 255]. Naikkan kecerahan R, G, B sebesar 80 dan cetak hasilnya.

    Petunjuk

    Loop indeks 0 sampai 2; nilai di atas 255 otomatis dipotong.

    Lihat jawaban
    JAVASCRIPT
    const px = new Uint8ClampedArray([200, 120, 40, 255]);
for (let i = 0; i < 3; i++) px[i] += 80;
console.log(px);
    KELUARAN
    Uint8ClampedArray(4) [ 255, 200, 120, 255 ]

Poin penting

  • Typed array = view berjenis di atas ArrayBuffer.
  • Panjang tetap, satu tipe, sangat cepat.
  • Dipakai untuk gambar, audio, file, WebGL, Wasm.
  • Overflow dibungkus; Clamped dipotong.
