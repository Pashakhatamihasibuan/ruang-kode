Object dan operator typeof

Buka versi interaktif

Object adalah kumpulan pasangan key-value (properti). Key berupa string atau symbol; value bisa apa saja, termasuk fungsi (disebut metode). Array, fungsi, Date, Map, dan hampir semua hal selain primitif adalah object.

Berbeda dengan primitif, object disimpan dan disalin berdasarkan referensi: dua variabel bisa menunjuk object yang sama, sehingga mengubah lewat satu variabel terlihat di variabel lain. Untuk menyalin, pakai spread {...obj} (dangkal) atau structuredClone(obj) (dalam).

typeof mengembalikan string nama tipe. Jebakannya: typeof null adalah "object", array juga "object" (cek dengan Array.isArray), sedangkan fungsi menghasilkan "function". Untuk object bawaan, instanceof atau Object.prototype.toString.call(x) memberi info lebih tepat.

const produk = {
  nama: 'Teh Melati',
  harga: 12000,
  'kode-sku': 'TM-01',             // key dengan tanda minus perlu kutip
  info() { return `${this.nama} Rp${this.harga}`; },
};
console.log(produk.nama, produk['kode-sku'], produk.info());
produk.stok = 30;                   // tambah properti
delete produk['kode-sku'];          // hapus properti
console.log(Object.keys(produk), 'harga' in produk);

const b = produk;                   // referensi yang sama
b.harga = 15000;
console.log(produk.harga, b === produk);
const salinan = { ...produk, harga: 9000 };
console.log(produk.harga, salinan.harga, salinan === produk);

Soal latihan

  1. Buat object mahasiswa berisi nama, nim, dan array nilai. Salin dengan structuredClone, ubah nilai pertama di salinan, lalu buktikan object asli tidak berubah.

    Petunjuk

    structuredClone menyalin sampai array di dalamnya.

    Lihat jawaban
    JAVASCRIPT
    const mahasiswa = { nama: 'Dewi', nim: '2301001', nilai: [80, 90] };
const salinan = structuredClone(mahasiswa);
salinan.nilai[0] = 100;
console.log('asli   :', mahasiswa.nilai);
console.log('salinan:', salinan.nilai);
    KELUARAN
    asli   : [ 80, 90 ]
salinan: [ 100, 90 ]

Poin penting

  • Object = kumpulan key-value; metode adalah properti berisi fungsi.
  • Object disalin berdasarkan referensi.
  • Spread untuk salinan dangkal, structuredClone untuk salinan dalam.
  • typeof punya jebakan: null dan array.
