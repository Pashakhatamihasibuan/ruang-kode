== versus ===

Buka versi interaktif

=== (strict equality, algoritma IsStrictlyEqual) membandingkan tanpa konversi: tipe berbeda langsung false. == (loose equality, algoritma IsLooselyEqual) mengonversi tipe lebih dulu dengan aturan yang rumit.

Ringkasan aturan ==: null dan undefined hanya sama satu sama lain; number vs string, string diubah ke number; boolean selalu diubah ke number lebih dulu (sehingga "true" == true justru false); object vs primitif, object diubah ke primitif. NaN tidak sama dengan apa pun, termasuk dirinya sendiri.

Standar industri: selalu pakai === dan !== (aturan ESLint eqeqeq). Satu-satunya pengecualian yang sering diterima adalah x == null untuk mengecek null atau undefined sekaligus. Object, array, dan fungsi dibandingkan berdasarkan referensi pada kedua operator: dua object dengan isi sama tetap tidak sama.

JAVASCRIPT
const kasus = [
  [1, '1'], [0, ''], [0, '0'], ['', '0'], [null, undefined], [null, 0],
  [false, 'false'], [true, 'true'], [true, '1'], [NaN, NaN], [[1], 1], [[], false],
];
console.log('a'.padEnd(10), 'b'.padEnd(11), '==    ===');
for (const [a, b] of kasus) {
  const tampil = v => (typeof v === 'string' ? `'${v}'` : Array.isArray(v) ? `[${v}]` : String(v));
  console.log(tampil(a).padEnd(10), tampil(b).padEnd(11), String(a == b).padEnd(5), a === b);
}
const p1 = { id: 1 }, p2 = { id: 1 }, p3 = p1;
console.log(p1 === p2, p1 == p2, p1 === p3);
const input = undefined;
console.log(input == null, input === null);

Poin penting

  • === tanpa konversi; == dengan koersi.
  • Pakai === (eqeqeq); x == null pengecualian yang umum.
  • Object dibandingkan berdasarkan referensi.
  • NaN tidak sama dengan dirinya.

Cek pemahaman

Hasil 'true' == true?

Jawaban: false

true diubah ke 1, "true" diubah ke NaN.

Hasil null == 0?

Jawaban: false

null hanya == undefined.

Hasil [] == false?

Jawaban: true

false -> 0, [] -> "" -> 0.
