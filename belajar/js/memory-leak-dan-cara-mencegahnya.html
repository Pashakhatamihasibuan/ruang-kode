Memory leak dan cara mencegahnya

Buka versi interaktif

Memory leak terjadi saat memori yang tidak dibutuhkan tetap terjangkau sehingga GC tidak bisa membersihkannya. Gejalanya: aplikasi makin lambat dan pemakaian memori terus naik setelah lama dipakai, terutama di SPA yang jarang dimuat ulang.

Penyebab paling umum: (1) variabel global tak sengaja atau cache global tanpa batas; (2) event listener yang tidak dilepas saat komponen hilang; (3) timer setInterval yang lupa di-clear; (4) closure yang menahan object besar; (5) detached DOM: elemen sudah dihapus dari halaman tetapi masih dirujuk variabel JS; (6) langganan WebSocket/observer yang tidak ditutup.

Pencegahan: batasi ukuran cache (misalnya LRU), gunakan WeakMap untuk metadata per object, selalu sediakan fungsi cleanup (return dari useEffect, removeEventListener, clearInterval, controller.abort()), dan gunakan opsi { signal } di addEventListener agar banyak listener bisa dilepas sekaligus. Ukur dengan panel Memory di DevTools sebelum dan sesudah perbaikan.

JAVASCRIPT
// 1. cache tanpa batas -> bocor; cache LRU dengan batas -> aman
class CacheLRU {
  #maks; #data = new Map();
  constructor(maks) { this.#maks = maks; }
  get(k) {
    if (!this.#data.has(k)) return undefined;
    const v = this.#data.get(k);
    this.#data.delete(k); this.#data.set(k, v);       // pindah ke paling baru
    return v;
  }
  set(k, v) {
    this.#data.delete(k);
    this.#data.set(k, v);
    if (this.#data.size > this.#maks) this.#data.delete(this.#data.keys().next().value);   // buang yang terlama
  }
  get kunci() { return [...this.#data.keys()]; }
}
const cache = new CacheLRU(3);
for (const id of [1, 2, 3]) cache.set(id, `profil-${id}`);
cache.get(1);
cache.set(4, 'profil-4');
console.log('isi cache:', cache.kunci);

// 2. listener + timer dengan cleanup memakai AbortController
const bus = new EventTarget();
function pasangWidget(nama) {
  const ctrl = new AbortController();
  let detak = 0;
  bus.addEventListener('pesan', e => console.log(`${nama} menerima ${e.detail}`), { signal: ctrl.signal });
  const timer = setInterval(() => detak++, 10);
  return function bersihkan() {
    ctrl.abort();                 // melepas semua listener dengan signal ini
    clearInterval(timer);
    console.log(`${nama} dibersihkan`);
  };
}
const bersihkan = pasangWidget('Widget Cuaca');
bus.dispatchEvent(new CustomEvent('pesan', { detail: 'hujan' }));
bersihkan();
bus.dispatchEvent(new CustomEvent('pesan', { detail: 'cerah' }));   // tidak ada yang menerima
console.log('event loop tidak tertahan timer, program selesai normal');

Poin penting

  • Leak = memori tak terpakai yang masih terjangkau.
  • Penyebab utama: listener, timer, cache, detached DOM.
  • Selalu tulis cleanup.
  • AbortController signal melepas banyak listener sekaligus.
