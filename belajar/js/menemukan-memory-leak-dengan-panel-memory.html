Menemukan memory leak dengan panel Memory

Buka versi interaktif

Langkah standar menemukan leak: (1) buka panel Memory, pilih Heap snapshot, ambil snapshot awal; (2) lakukan aksi yang dicurigai beberapa kali (buka dan tutup modal, pindah halaman di SPA); (3) klik ikon tempat sampah untuk memaksa GC; (4) ambil snapshot kedua; (5) pilih tampilan Comparison untuk melihat object yang bertambah dan tidak hilang.

Istilah di heap snapshot: Shallow size (memori object itu sendiri), Retained size (memori yang ikut bebas jika object ini dihapus; fokus ke angka ini), Retainers (rantai referensi yang menahan object tetap hidup; baca dari bawah untuk menemukan pelaku, misalnya listener atau variabel global), dan Detached (ketik "Detached" di filter untuk menemukan elemen DOM yang terlepas).

Alat lain: Allocation instrumentation on timeline (batang biru yang tetap ada menandakan memori tidak dibebaskan), panel Performance dengan centang Memory untuk melihat grafik JS heap naik terus (pola gergaji yang terus naik = leak), Performance monitor (jumlah node DOM dan listener secara langsung), serta performance.memory di Chrome.

JAVASCRIPT
// Contoh leak klasik di SPA: modal yang dibuka-tutup
const daftarModal = [];                       // global, terus bertambah

function bukaModal() {
  const el = document.createElement('div');
  el.className = 'modal';
  el.innerHTML = '<p>Promo hari ini</p><button>Tutup</button>';
  document.body.append(el);
  daftarModal.push(el);                       // BOCOR: elemen tetap dirujuk
  window.addEventListener('resize', () => posisikan(el));   // BOCOR: listener tidak dilepas
  el.querySelector('button').onclick = () => el.remove();
}

// Perbaikan
function bukaModalAman() {
  const el = document.createElement('div');
  const ctrl = new AbortController();
  el.innerHTML = '<p>Promo hari ini</p><button>Tutup</button>';
  document.body.append(el);
  window.addEventListener('resize', () => posisikan(el), { signal: ctrl.signal });
  el.querySelector('button').addEventListener('click', () => {
    ctrl.abort();                               // lepas listener
    el.remove();                                // tidak ada referensi tersisa
  }, { once: true });
}

// Di DevTools: Memory > Heap snapshot > buka/tutup modal 10x > snapshot lagi
// > Comparison > filter "Detached" > lihat Retainers: daftarModal dan listener resize

Poin penting

  • Snapshot, ulangi aksi, paksa GC, snapshot lagi, bandingkan.
  • Fokus ke Retained size dan Retainers.
  • Filter "Detached" untuk DOM yang bocor.
  • Grafik heap yang terus naik menandakan leak.
