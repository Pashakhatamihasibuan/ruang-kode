Callback dan callback hell

Buka versi interaktif

Callback adalah fungsi yang dikirim ke fungsi lain untuk dipanggil nanti, misalnya saat data siap. Konvensi lama Node adalah error-first callback: callback(err, hasil), di mana argumen pertama berisi error atau null.

Saat beberapa operasi asinkron bergantung satu sama lain, callback bersarang semakin dalam membentuk callback hell atau pyramid of doom: sulit dibaca, error harus ditangani di setiap tingkat, dan alur sulit diikuti. Masalah lain adalah inversion of control: kita menyerahkan kendali ke kode lain yang mungkin memanggil callback dua kali atau tidak sama sekali.

Solusinya adalah Promise dan async/await. API lama berbasis callback bisa diubah menjadi Promise (promisify), misalnya dengan util.promisify di Node atau membungkusnya dengan new Promise.

JAVASCRIPT
function ambilUser(id, cb) {
  setTimeout(() => (id > 0 ? cb(null, { id, nama: 'Rina' }) : cb(new Error('id tidak valid'))), 30);
}
function ambilPesanan(user, cb) { setTimeout(() => cb(null, [{ no: 'INV-7', total: 150000 }]), 30); }
function ambilPengiriman(pesanan, cb) { setTimeout(() => cb(null, { resi: 'JNE123', status: 'dikirim' }), 30); }

// callback hell: setiap langkah bersarang dan error dicek di setiap tingkat
ambilUser(1, (err, user) => {
  if (err) return console.log('gagal user', err.message);
  ambilPesanan(user, (err, pesanan) => {
    if (err) return console.log('gagal pesanan');
    ambilPengiriman(pesanan[0], (err, kirim) => {
      if (err) return console.log('gagal kirim');
      console.log(`[callback] ${user.nama} - ${pesanan[0].no} - ${kirim.status}`);
    });
  });
});

// promisify lalu tulis datar dengan async/await
const jadiPromise = fn => (...args) => new Promise((ok, gagal) => fn(...args, (err, v) => (err ? gagal(err) : ok(v))));
const [userP, pesananP, kirimP] = [ambilUser, ambilPesanan, ambilPengiriman].map(jadiPromise);
setTimeout(async () => {
  try {
    const user = await userP(1);
    const pesanan = await pesananP(user);
    const kirim = await kirimP(pesanan[0]);
    console.log(`[async] ${user.nama} - ${pesanan[0].no} - ${kirim.status}`);
    await userP(-1);
  } catch (e) {
    console.log('[async] satu catch untuk semua:', e.message);
  }
}, 200);
KELUARAN
[callback] Rina - INV-7 - dikirim
[async] Rina - INV-7 - dikirim
[async] satu catch untuk semua: id tidak valid

Poin penting

  • Callback = fungsi yang dipanggil nanti.
  • Error-first callback: cb(err, hasil).
  • Callback hell: bersarang, error berulang, inversion of control.
  • Promisify lalu pakai async/await.
