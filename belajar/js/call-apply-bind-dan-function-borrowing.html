call, apply, bind, dan function borrowing

Buka versi interaktif

Tiga metode milik setiap fungsi untuk explicit binding: f.call(thisArg, a, b) memanggil langsung dengan argumen satu per satu; f.apply(thisArg, [a, b]) memanggil langsung dengan argumen berupa array; f.bind(thisArg, a) tidak memanggil, tetapi mengembalikan fungsi baru yang this-nya terkunci permanen (dan bisa mengisi sebagian argumen di depan: partial application).

Function borrowing adalah meminjam metode dari object lain lewat call/apply. Contoh klasik: Array.prototype.slice.call(arguments) atau Array.prototype.map.call('abc', ...) untuk object array-like. Di kode modern, Array.from dan spread biasanya lebih bersih.

Catatan: this pada fungsi hasil bind tidak bisa diubah lagi oleh call/apply/bind berikutnya (kecuali dipanggil dengan new). Arrow function mengabaikan thisArg sepenuhnya. Sejak spread ada, apply lebih jarang dipakai: Math.max(...arr) menggantikan Math.max.apply(null, arr).

JAVASCRIPT
function perkenalan(salam, tanda) {
  return `${salam}, saya ${this.nama} dari ${this.kota}${tanda}`;
}
const rina = { nama: 'Rina', kota: 'Padang' };
const agus = { nama: 'Agus', kota: 'Kupang' };
console.log(perkenalan.call(rina, 'Halo', '!'));
console.log(perkenalan.apply(agus, ['Selamat pagi', '.']));
const sapaRina = perkenalan.bind(rina, 'Hai');      // partial: salam sudah diisi
console.log(sapaRina('!!'));
console.log(sapaRina.call(agus, '?'));              // bind tidak bisa diganti

// function borrowing
const admin = { nama: 'Admin', izin: ['baca', 'tulis'], ringkas() { return `${this.nama}: ${this.izin.join(', ')}`; } };
const tamu = { nama: 'Tamu', izin: ['baca'] };
console.log(admin.ringkas.call(tamu));
function gabung() { return Array.prototype.join.call(arguments, ' + '); }
console.log(gabung(1, 2, 3));
console.log(Array.prototype.map.call('abc', c => c.toUpperCase()));

console.log(Math.max.apply(null, [4, 9, 2]), Math.max(...[4, 9, 2]));
const kaliDua = ((a, b) => a * b).bind(null, 2);
console.log(kaliDua(21));
const arrow = () => typeof this;
console.log(arrow.call(rina));

Soal latihan

  1. Buat fungsi formatHarga(mataUang) yang memakai this.harga. Panggil untuk dua produk dengan call, dan buat versi terikat untuk produk pertama dengan bind.

    Petunjuk

    return `${mataUang} ${this.harga}` lalu call(produk, "Rp").

    Lihat jawaban
    JAVASCRIPT
    function formatHarga(mataUang) {
  return `${this.nama}: ${mataUang} ${this.harga.toLocaleString('id-ID')}`;
}
const p1 = { nama: 'Kopi', harga: 45000 };
const p2 = { nama: 'Teh', harga: 22000 };
console.log(formatHarga.call(p1, 'Rp'));
console.log(formatHarga.call(p2, 'Rp'));
const hargaKopi = formatHarga.bind(p1);
console.log(hargaKopi('IDR'));

Teh: Rp 22.000
Kopi: IDR 45.000

Poin penting

  • call dan apply memanggil langsung; bind mengembalikan fungsi baru.
  • apply menerima array argumen.
  • bind mendukung partial application.
  • Function borrowing: pinjam metode dengan call.
