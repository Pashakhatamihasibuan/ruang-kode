Map dan Set

Buka versi interaktif

Map adalah koleksi key-value di mana key bisa tipe apa saja (object, fungsi, number), urutan sisip terjaga, ukurannya tersedia lewat size, dan dioptimalkan untuk tambah/hapus yang sering. Gunakan Map untuk kamus dinamis (cache, indeks berdasarkan ID); gunakan object biasa untuk struktur data dengan field tetap.

Set menyimpan nilai unik. Cara tercepat menghapus duplikat: [...new Set(arr)]. Pengecekan has pada Set rata-rata O(1), jauh lebih cepat daripada includes pada array besar yang O(n). ES2025 menambahkan operasi himpunan: union, intersection, difference, symmetricDifference, isSubsetOf.

Keduanya iterable, jadi bisa dipakai di for...of, spread, dan destructuring. Kesetaraan key memakai algoritma SameValueZero: NaN dianggap sama dengan NaN, dan dua object berbeda tetap dua key berbeda walau isinya sama.

JAVASCRIPT
const stok = new Map();
stok.set('kopi', 12).set('teh', 30).set('gula', 0);
console.log(stok.get('teh'), stok.has('susu'), stok.size);
stok.delete('gula');
for (const [barang, jml] of stok) console.log(barang, '=>', jml);

const objKey = { id: 7 };
const sesi = new Map([[objKey, 'aktif']]);       // object sebagai key
console.log(sesi.get(objKey), sesi.get({ id: 7 }));
console.log(Object.fromEntries(stok), new Map(Object.entries({ a: 1 })));

const kunjungan = ['bdg', 'jkt', 'bdg', 'mdn', 'jkt'];
const unik = new Set(kunjungan);
console.log(unik, unik.size, [...unik]);
console.log(new Set([NaN, NaN, 0, -0]).size);

const kelasA = new Set(['Ani', 'Budi', 'Citra']);
const kelasB = new Set(['Budi', 'Dodi']);
console.log([...kelasA.intersection(kelasB)], [...kelasA.union(kelasB)], [...kelasA.difference(kelasB)]);

Soal latihan

  1. Hitung frekuensi kata pada kalimat "kopi susu kopi gula kopi susu" memakai Map, lalu cetak kata dan jumlahnya diurutkan dari yang terbanyak.

    Petunjuk

    map.set(k, (map.get(k) ?? 0) + 1), lalu [...map].sort.

    Lihat jawaban
    JAVASCRIPT
    const kata = 'kopi susu kopi gula kopi susu'.split(' ');
const frek = new Map();
for (const k of kata) frek.set(k, (frek.get(k) ?? 0) + 1);
for (const [k, n] of [...frek].sort((a, b) => b[1] - a[1])) console.log(k, n);

gula 1

Poin penting

  • Map: key tipe apa saja, size, urutan sisip.
  • Set: nilai unik, has O(1).
  • [...new Set(arr)] menghapus duplikat.
  • Kesetaraan key memakai SameValueZero.
