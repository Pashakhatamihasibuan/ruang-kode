Block, function, dan global scope

Buka versi interaktif

Scope menentukan dari mana sebuah variabel bisa diakses. Global scope: dideklarasikan di luar fungsi atau blok; bisa diakses di mana saja. Di browser, var global dan deklarasi fungsi global menjadi properti window; di modul ES, variabel tingkat atas hanya berlaku di modul itu (module scope).

Function scope: variabel di dalam fungsi hanya terlihat di dalam fungsi itu. Block scope: let dan const di dalam kurung kurawal (if, for, atau blok biasa) hanya terlihat di blok itu. var mengabaikan blok dan "bocor" ke fungsi pembungkusnya.

Scope bersarang membentuk scope chain: saat mencari nama, engine melihat scope saat ini, lalu scope luarnya, sampai global. Variabel dalam yang bernama sama dengan variabel luar disebut shadowing. Minimalkan variabel global karena rawan bentrok antar skrip dan sulit dilacak.

JAVASCRIPT
const aplikasi = 'Ruang Kode';            // global (module scope di file ini)

function hitungDiskon(harga) {
  const persen = 10;                      // function scope
  if (harga > 100000) {
    let bonus = 5000;                     // block scope
    var catatan = 'harga besar';          // var bocor ke seluruh fungsi
    console.log('di blok:', bonus, catatan);
  }
  console.log('di fungsi:', typeof bonus, catatan);
  return harga - harga * persen / 100;
}
console.log(hitungDiskon(200000));
console.log(typeof persen);               // tidak terlihat di luar fungsi

const nilai = 'luar';
{
  const nilai = 'dalam';                  // shadowing
  console.log(nilai, '-', aplikasi);      // scope chain sampai global
}
console.log(nilai);

for (var i = 0; i < 3; i++) {}

Soal latihan

  1. Buat fungsi buatSalam(jam): di dalam blok if/else deklarasikan const salam sesuai jam (pagi di bawah 11, siang di bawah 15, sisanya sore). Kembalikan salam itu dengan benar walaupun const ada di dalam blok.

    Petunjuk

    Deklarasikan let hasil di function scope, isi di blok, lalu return.

    Lihat jawaban
    JAVASCRIPT
    function buatSalam(jam) {
  let hasil;
  if (jam < 11) {
    const salam = 'Selamat pagi';
    hasil = salam;
  } else if (jam < 15) {
    const salam = 'Selamat siang';
    hasil = salam;
  } else {
    const salam = 'Selamat sore';
    hasil = salam;
  }
  return hasil;
}
console.log(buatSalam(8));
console.log(buatSalam(13));
console.log(buatSalam(17));
    KELUARAN
    Selamat pagi
Selamat siang
Selamat sore

Poin penting

  • Global, module, function, dan block scope.
  • var tidak mengenal block scope.
  • Scope chain mencari nama dari dalam ke luar.
  • Shadowing: nama dalam menutupi nama luar.
