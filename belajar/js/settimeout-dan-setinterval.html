setTimeout dan setInterval

Buka versi interaktif

setTimeout(fn, ms, ...args) menjadwalkan fn sekali setelah minimal ms milidetik (bisa lebih lambat jika thread sibuk). setInterval(fn, ms) menjalankannya berulang. Keduanya mengembalikan ID yang dipakai untuk membatalkan dengan clearTimeout/clearInterval.

Browser membatasi timer: tab di latar belakang dibatasi sekitar sekali per detik, dan timer bersarang lebih dari 5 tingkat minimal 4 ms. Untuk animasi gunakan requestAnimationFrame, bukan setInterval. Untuk polling yang memanggil server, setTimeout rekursif lebih aman daripada setInterval karena panggilan berikutnya baru dijadwalkan setelah yang sebelumnya selesai.

Dua pola wajib di frontend memakai timer dan closure: debounce (tunggu sampai pengguna berhenti mengetik, misalnya pencarian) dan throttle (batasi frekuensi, misalnya event scroll). Selalu bersihkan timer saat komponen dilepas (misalnya di cleanup useEffect) agar tidak bocor.

JAVASCRIPT
const mulai = Date.now();
const t = () => `${Math.round((Date.now() - mulai) / 100) * 100}ms`;

setTimeout((nama) => console.log(`[${t()}] halo ${nama}`), 100, 'Dina');
const batal = setTimeout(() => console.log('tidak pernah muncul'), 150);
clearTimeout(batal);

let ke = 0;
const id = setInterval(() => {
  ke++;
  console.log(`[${t()}] interval ke-${ke}`);
  if (ke === 3) { clearInterval(id); console.log('interval dihentikan'); }
}, 200);

function debounce(fn, tunggu) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), tunggu);
  };
}
const cari = debounce(q => console.log(`[${t()}] cari ke server: "${q}"`), 320);
['k', 'ko', 'kop', 'kopi'].forEach((q, i) => setTimeout(() => cari(q), i * 50));   // mengetik cepat

function throttle(fn, jeda) {
  let terakhir = 0;
  return (...args) => {
    const now = Date.now();
    if (now - terakhir >= jeda) { terakhir = now; fn(...args); }
  };
}
const onScroll = throttle(i => console.log('scroll diproses', i), 1000);
for (let i = 1; i <= 5; i++) onScroll(i);   // hanya yang pertama diproses

Poin penting

  • setTimeout sekali, setInterval berulang; batalkan dengan clear*.
  • Jeda adalah waktu minimal, bukan pasti.
  • requestAnimationFrame untuk animasi; setTimeout rekursif untuk polling.
  • Debounce dan throttle dibangun dari timer + closure.
