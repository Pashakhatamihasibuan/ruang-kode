Apa itu JavaScript

Buka versi interaktif

JavaScript (JS) adalah bahasa pemrograman yang membuat halaman web hidup: merespons klik, memvalidasi formulir, memuat data tanpa memuat ulang halaman, sampai menjalankan game. Bersama HTML (struktur) dan CSS (tampilan), JS adalah satu dari tiga bahasa inti web dan satu-satunya bahasa yang berjalan bawaan di semua browser.

Hari ini JS juga berjalan di luar browser: Node.js, Deno, dan Bun untuk server dan alat baris perintah, React Native untuk aplikasi mobile, Electron untuk aplikasi desktop (VS Code, Slack, Discord), bahkan perangkat IoT. Survei Stack Overflow menempatkan JS sebagai bahasa paling banyak dipakai lebih dari sepuluh tahun berturut-turut.

Ciri bahasanya: dinamis (tipe ditentukan saat berjalan), multi-paradigma (prosedural, berorientasi objek berbasis prototype, dan fungsional), single-threaded dengan event loop untuk pekerjaan asinkron, serta dijalankan oleh engine seperti V8 (Chrome, Node, Edge), SpiderMonkey (Firefox), dan JavaScriptCore (Safari) yang memakai kompilasi JIT agar cepat.

Jangan tertukar dengan Java: namanya mirip karena alasan pemasaran tahun 1995, tetapi bahasanya berbeda jauh.

Poin penting

  • JS adalah bahasa bawaan browser dan kini juga berjalan di server, mobile, dan desktop.
  • Dinamis, multi-paradigma, single-threaded dengan event loop.
  • Engine (V8, SpiderMonkey, JavaScriptCore) mengeksekusi kode dengan JIT.
