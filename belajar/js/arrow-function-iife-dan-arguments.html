Arrow function, IIFE, dan arguments

Buka versi interaktif

Arrow function ((a, b) => a + b) ringkas: satu parameter boleh tanpa kurung, satu ekspresi otomatis di-return (implicit return), dan untuk mengembalikan object literal bungkus dengan kurung () => ({ ... }). Arrow tidak punya this, arguments, super, maupun prototype sendiri, dan tidak bisa dipanggil dengan new.

IIFE (Immediately Invoked Function Expression), (function () { ... })(), langsung dijalankan saat didefinisikan. Dulu dipakai untuk membuat scope privat dan menghindari polusi global (pola module pattern). Kini perannya banyak digantikan modul ES dan block scope, tetapi masih muncul di kode lama, bundel, dan untuk menjalankan async di tingkat atas pada lingkungan lama.

Object arguments adalah object mirip array (array-like) berisi semua argumen pada fungsi biasa. Ia tidak punya metode array (ubah dengan Array.from) dan tidak ada di arrow function. Di kode modern, pakai rest parameter yang merupakan array asli.

Poin penting

  • Arrow: ringkas, implicit return, tanpa this/arguments sendiri.
  • Kembalikan object literal dengan ({ }).
  • IIFE untuk scope privat (pola lama).
  • arguments array-like; pakai rest parameter.
