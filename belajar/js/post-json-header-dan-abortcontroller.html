POST JSON, header, dan AbortController

Buka versi interaktif

Untuk mengirim data, isi opsi fetch: method (POST, PUT, PATCH, DELETE), headers (misalnya Content-Type: application/json dan Authorization: Bearer token), dan body berupa JSON.stringify(data). Untuk unggah file, kirim FormData dan jangan set Content-Type manual (browser mengisi boundary). Query string disusun dengan URLSearchParams.

AbortController membatalkan permintaan: kirim signal ke fetch, lalu panggil controller.abort(); fetch menolak dengan AbortError. Untuk batas waktu ada jalan pintas AbortSignal.timeout(ms) (menolak dengan TimeoutError). Pola ini penting untuk pencarian saat mengetik (batalkan permintaan lama) dan cleanup di useEffect React.

Opsi lain yang perlu dikenal: credentials: "include" untuk mengirim cookie lintas origin, cache, mode, dan keepalive. Permintaan lintas domain di browser tunduk pada CORS: server harus mengirim header Access-Control-Allow-Origin; error CORS tidak bisa diperbaiki dari sisi frontend.

JAVASCRIPT
import http from 'node:http';
// server API kecil di proses yang sama, supaya contoh fetch bisa dijalankan tanpa internet
const produk = [{ id: 1, nama: 'Kopi Gayo', harga: 85000 }, { id: 2, nama: 'Teh Melati', harga: 22000 }];
const server = http.createServer(async (req, res) => {
  const url = new URL(req.url, 'http://x');
  const kirim = (status, data) => { res.writeHead(status, { 'Content-Type': 'application/json' }); res.end(JSON.stringify(data)); };
  if (req.method === 'GET' && url.pathname === '/api/produk') return kirim(200, produk);
  if (req.method === 'GET' && url.pathname.startsWith('/api/produk/')) {
    const p = produk.find(x => x.id === Number(url.pathname.split('/').pop()));
    return p ? kirim(200, p) : kirim(404, { error: 'Produk tidak ditemukan' });
  }
  if (req.method === 'POST' && url.pathname === '/api/pesanan') {
    let body = '';
    for await (const potong of req) body += potong;
    const data = JSON.parse(body);
    if (req.headers.authorization !== 'Bearer token-demo') return kirim(401, { error: 'Belum login' });
    return kirim(201, { id: 501, ...data, status: 'dibuat' });
  }
  if (url.pathname === '/api/lambat') return setTimeout(() => kirim(200, { ok: true }), 500);
  kirim(404, { error: 'Rute tidak ada' });
});
await new Promise(r => server.listen(0, r));
const BASE = `http://localhost:${server.address().port}`;

async function buatPesanan(data, token) {
  const r = await fetch(`${BASE}/api/pesanan`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', ...(token && { Authorization: `Bearer ${token}` }) },
    body: JSON.stringify(data),
  });
  const body = await r.json();
  return `${r.status} ${JSON.stringify(body)}`;
}
console.log(await buatPesanan({ produkId: 1, qty: 2 }));
console.log(await buatPesanan({ produkId: 1, qty: 2 }, 'token-demo'));

const params = new URLSearchParams({ q: 'kopi susu', urut: 'termurah', hal: 1 });
console.log('query:', params.toString());

const ctrl = new AbortController();
const janji = fetch(`${BASE}/api/lambat`, { signal: ctrl.signal });
setTimeout(() => ctrl.abort(), 50);
try { await janji; } catch (e) { console.log('dibatalkan:', e.name); }

try {
  await fetch(`${BASE}/api/lambat`, { signal: AbortSignal.timeout(100) });
} catch (e) { console.log('kelamaan:', e.name); }
const cepat = await fetch(`${BASE}/api/lambat`, { signal: AbortSignal.timeout(2000) });
console.log('cukup waktu:', await cepat.json());
server.close();

Soal latihan

  1. Tulis fungsi pencarian di browser yang membatalkan permintaan sebelumnya setiap kali pengguna mengetik huruf baru.

    Petunjuk

    Simpan controller di luar fungsi; abort yang lama sebelum fetch baru; abaikan AbortError.

    Lihat jawaban
    JAVASCRIPT
    let ctrl;
async function cari(q) {
  ctrl?.abort();
  ctrl = new AbortController();
  try {
    const r = await fetch(`/api/cari?${new URLSearchParams({ q })}`, { signal: ctrl.signal });
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    tampilkan(await r.json());
  } catch (e) {
    if (e.name !== 'AbortError') tampilkanError(e);
  }
}
input.addEventListener('input', e => cari(e.target.value));

Poin penting

  • POST JSON: method, Content-Type, body JSON.stringify.
  • FormData untuk file, tanpa set Content-Type.
  • AbortController dan AbortSignal.timeout untuk membatalkan.
  • CORS diatur server, bukan frontend.

Cek pemahaman

Header wajib saat mengirim body JSON?

Jawaban: 'Content-Type': 'application/json'

Agar server tahu formatnya.

Nama error saat fetch dibatalkan dengan controller.abort()?

Jawaban: AbortError

TimeoutError hanya dari AbortSignal.timeout.
