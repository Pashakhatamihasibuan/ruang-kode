Promise

Buka versi interaktif

Promise adalah object yang mewakili hasil operasi asinkron di masa depan. Statusnya pending, lalu berubah sekali menjadi fulfilled (berhasil, dengan nilai) atau rejected (gagal, dengan alasan/error); keduanya disebut settled dan tidak bisa berubah lagi.

Konsumsi dengan .then(onSukses), .catch(onGagal), dan .finally(onSelesai). Setiap then mengembalikan Promise baru sehingga bisa dirantai; nilai yang di-return diteruskan ke then berikutnya, dan error melompat ke catch terdekat. Selalu return Promise di dalam then agar rantai menunggu, dan selalu akhiri dengan catch.

Kombinator: Promise.all (paralel, gagal jika satu gagal), Promise.allSettled (tunggu semua, laporkan status masing-masing), Promise.race (yang pertama settled, cocok untuk timeout), Promise.any (yang pertama sukses, AggregateError jika semua gagal). Promise.withResolvers() (ES2024) memberi promise beserta fungsi resolve/reject-nya.

JAVASCRIPT
const tunda = (ms, nilai, gagal = false) =>
  new Promise((resolve, reject) => setTimeout(() => (gagal ? reject(new Error(nilai)) : resolve(nilai)), ms));

const p = tunda(50, 'data siap');
console.log(p);                                   // masih pending
p.then(v => { console.log('then:', v); return v.length; })
 .then(n => console.log('panjang:', n))
 .finally(() => console.log('finally: selesai'));

tunda(60, 'server error', true)
  .then(() => console.log('tidak dijalankan'))
  .catch(e => { console.log('catch:', e.message); return 'nilai cadangan'; })
  .then(v => console.log('lanjut dengan', v));

const stok = () => tunda(80, { stok: 12 });
const harga = () => tunda(40, { harga: 85000 });
const ulasan = () => tunda(60, 'layanan ulasan mati', true);

setTimeout(async () => {
  console.log('all:', await Promise.all([stok(), harga()]));
  const hasil = await Promise.allSettled([stok(), ulasan()]);
  console.log('allSettled:', hasil.map(h => h.status));
  console.log('race:', await Promise.race([tunda(100, 'lambat'), tunda(10, 'cepat')]));
  console.log('any:', await Promise.any([ulasan(), harga()]));
  try { await Promise.all([stok(), ulasan()]); } catch (e) { console.log('all gagal:', e.message); }
  try { await Promise.any([ulasan(), ulasan()]); } catch (e) { console.log(e.name, e.errors.length); }
  const { promise, resolve } = Promise.withResolvers();
  setTimeout(() => resolve('diselesaikan dari luar'), 10);
  console.log(await promise);
}, 150);

Soal latihan

  1. Buat fungsi denganTimeout(promise, ms) memakai Promise.race yang menolak dengan Error "timeout" jika promise lebih lambat dari ms. Uji dengan proses 50 ms (batas 100) dan 200 ms (batas 100).

    Petunjuk

    Race antara promise asli dan promise yang reject setelah ms.

    Lihat jawaban
    JAVASCRIPT
    const tunda = (ms, v) => new Promise(r => setTimeout(() => r(v), ms));
function denganTimeout(p, ms) {
  const batas = new Promise((_, reject) => setTimeout(() => reject(new Error('timeout')), ms));
  return Promise.race([p, batas]);
}
denganTimeout(tunda(50, 'cepat selesai'), 100).then(console.log, e => console.log(e.message));
denganTimeout(tunda(200, 'lambat'), 100).then(console.log, e => console.log('gagal:', e.message));
    KELUARAN
    cepat selesai
gagal: timeout

Poin penting

  • Status: pending lalu fulfilled atau rejected, sekali saja.
  • then berantai; return nilai/Promise; akhiri dengan catch.
  • all, allSettled, race, any untuk banyak Promise.
  • Promise.all menjalankan secara paralel.
