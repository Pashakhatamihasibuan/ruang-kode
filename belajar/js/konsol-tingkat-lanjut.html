Konsol tingkat lanjut

Buka versi interaktif

Panel Console lebih dari sekadar console.log. Gunakan console.table untuk array object, console.group/groupEnd untuk mengelompokkan log, console.warn/console.error untuk tingkat keparahan (bisa difilter), console.count untuk menghitung berapa kali kode terpanggil, console.time/timeEnd untuk mengukur durasi, console.assert untuk mencatat jika kondisi salah, dan console.trace untuk melihat call stack.

Di konsol browser tersedia utilitas khusus: $0 (elemen yang dipilih di panel Elements), $('sel') dan $$('sel') (querySelector dan querySelectorAll), copy(obj) (salin ke clipboard), monitorEvents(el), dan Live Expression (ikon mata) untuk memantau nilai terus-menerus.

Di kode produksi, hapus log debug atau pakai pustaka logging dengan level (misalnya pino di Node). Banyak tim memasang aturan ESLint no-console dan menghapus console otomatis saat build.

Metode console
MetodeKegunaan
console.tableTampilkan array/object sebagai tabel
console.group / groupEndKelompokkan log bertingkat
console.countHitung berapa kali dipanggil
console.time / timeEndUkur durasi
console.assertLog hanya jika kondisi false
console.traceCetak call stack
console.warn / errorLevel peringatan / error (bisa difilter)
console.dirTampilkan properti object
JAVASCRIPT
const pesanan = [
  { id: 'INV-1', kota: 'Bandung', total: 125000 },
  { id: 'INV-2', kota: 'Medan', total: 89000 },
];
console.table(pesanan);

console.group('Checkout');
console.log('validasi alamat');
console.warn('stok tinggal 1');
console.groupEnd();

for (const p of pesanan) console.count('render baris');
console.assert(pesanan.length === 3, 'jumlah pesanan seharusnya 3');
console.log('%s membeli %d barang (%o)', 'Rani', 3, { vip: true });
console.dir({ a: { b: { c: { d: 1 } } } }, { depth: 0 });

Poin penting

  • table, group, count, time, assert, trace mempercepat debugging.
  • $0, $(), $$(), copy() hanya di konsol DevTools.
  • Live Expression untuk memantau nilai.
  • Bersihkan log di produksi.
