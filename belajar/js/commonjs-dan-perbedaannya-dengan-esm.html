CommonJS dan perbedaannya dengan ESM

Buka versi interaktif

CommonJS (CJS) adalah sistem modul bawaan Node sejak 2009, jauh sebelum ESM ada. Modul mengekspor dengan module.exports = ... atau exports.nama = ..., dan mengimpor dengan require('./file'). Banyak paket npm dan proyek Node lama masih memakainya.

Perbedaan penting: require bersifat sinkron dan dinamis (boleh di dalam if atau fungsi), nilai yang diimpor adalah salinan dari module.exports saat itu (bukan live binding), tersedia __dirname dan __filename, dan tidak ada top-level await. Di Node, file .cjs atau proyek tanpa "type": "module" dianggap CJS; file .mjs atau "type": "module" dianggap ESM.

Interoperabilitas: ESM bisa import modul CJS (module.exports menjadi default export). Sejak Node 22 versi terbaru, CJS juga bisa require() modul ESM yang tidak memakai top-level await. Untuk proyek baru, gunakan ESM; untuk menulis pustaka, banyak penulis menerbitkan keduanya (dual package) lewat field exports di package.json.

JAVASCRIPT
// main.cjs
const { hitungOngkir, TARIF } = require('./ongkir.cjs');
const log = require('./logger.cjs');
const path = require('node:path');

log.info(`ongkir 3 kg: ${hitungOngkir(3)}`);
console.log(TARIF, typeof require, typeof module.exports, path.basename(__filename));

const penghitung = require('./penghitung.cjs');
let { nilai } = penghitung;                 // salinan nilai saat itu
penghitung.tambah(); penghitung.tambah();
console.log('salinan:', nilai, '| dari objek:', penghitung.nilai, '| getter:', penghitung.ambil());

console.log(require('./ongkir.cjs') === require('./ongkir.cjs'));   // di-cache
if (process.env.MODE_DEBUG !== 'ya') {
  const opsional = require('./logger.cjs');   // require boleh di dalam if
  opsional.info('require kondisional jalan');
}

Poin penting

  • CJS: require dan module.exports, sinkron.
  • CJS menyalin nilai; ESM live binding.
  • .mjs/.cjs dan "type" di package.json menentukan sistem modul.
  • Proyek baru: ESM.
