Protokol iterable dan iterator

Buka versi interaktif

Sebuah object disebut iterable jika punya metode [Symbol.iterator]() yang mengembalikan iterator. Iterator adalah object dengan metode next() yang setiap dipanggil mengembalikan { value, done }; ketika done: true, iterasi selesai.

Protokol inilah yang dipakai for...of, spread [...x], destructuring array, Array.from, Promise.all, serta constructor Map dan Set. Array, string, Map, Set, arguments, NodeList, dan typed array sudah iterable bawaan; object biasa tidak.

Dengan mengimplementasikan Symbol.iterator, class buatanmu (misalnya Rentang, Playlist, atau daftar berhalaman) bisa langsung dipakai di for...of. Iterator juga bisa punya return() yang dipanggil saat loop dihentikan lebih awal (break), berguna untuk menutup sumber daya.

JAVASCRIPT
const arr = ['a', 'b'];
const it = arr[Symbol.iterator]();
console.log(it.next(), it.next(), it.next());

class Rentang {
  constructor(awal, akhir, langkah = 1) { Object.assign(this, { awal, akhir, langkah }); }
  [Symbol.iterator]() {
    let n = this.awal;
    const { akhir, langkah } = this;
    return {
      next: () => (n <= akhir ? { value: (n += langkah) - langkah, done: false } : { value: undefined, done: true }),
      return: () => { console.log('  (iterator ditutup lebih awal)'); return { done: true }; },
    };
  }
}
const r = new Rentang(1, 10, 3);
console.log([...r], Array.from(r, x => x * 10));
for (const x of r) { if (x > 4) break; console.log('for...of', x); }
const [pertama, kedua] = new Rentang(5, 100);   // destructuring juga menutup iterator
console.log(pertama, kedua, new Set(new Rentang(1, 3)));
console.log(typeof {}[Symbol.iterator], typeof 'teks'[Symbol.iterator], typeof new Map()[Symbol.iterator]);

Poin penting

  • Iterable punya [Symbol.iterator]() yang mengembalikan iterator.
  • Iterator punya next() yang mengembalikan { value, done }.
  • for...of, spread, destructuring memakai protokol ini.
  • return() dipanggil saat break.

Cek pemahaman

Bentuk nilai kembali next() pada iterator?

Jawaban: { value, done }

done menandai akhir iterasi.

Kenapa object biasa tidak bisa di-for...of?

Jawaban: Tidak punya Symbol.iterator

Object biasa bukan iterable.
