Prototype dan pewarisan prototipe

Buka versi interaktif

Setiap object di JS punya tautan tersembunyi ke object lain yang disebut prototype (dibaca dengan Object.getPrototypeOf(obj), di konsol tampil sebagai [[Prototype]] atau __proto__). Saat properti tidak ditemukan di object, engine mencarinya di prototype, lalu prototype dari prototype, dan seterusnya sampai null. Rantai ini disebut prototype chain.

Itulah sebabnya array kosong bisa memanggil map: metode itu tinggal di Array.prototype. Pewarisan prototipe (prototypal inheritance) berarti object mewarisi langsung dari object lain, bukan dari "cetakan" seperti di Java. Kata kunci class (ES2015) hanyalah sintaks yang lebih rapi di atas mekanisme prototype ini (syntactic sugar).

Buat object dengan prototype tertentu memakai Object.create(proto). Fungsi konstruktor menyimpan metode bersama di Fungsi.prototype. Jangan menambah metode ke prototype bawaan (Array.prototype.x = ...): praktik ini disebut monkey patching dan bisa bentrok dengan fitur bahasa di masa depan.

JAVASCRIPT
const hewan = {
  bersuara() { return `${this.nama} bersuara: ${this.suara}`; },
};
const kucing = Object.create(hewan);   // prototype kucing = hewan
kucing.nama = 'Oyen';
kucing.suara = 'meong';
console.log(kucing.bersuara());
console.log(Object.getPrototypeOf(kucing) === hewan, Object.hasOwn(kucing, 'bersuara'));

// fungsi konstruktor (gaya sebelum class)
function Akun(pemilik, saldo) {
  this.pemilik = pemilik;
  this.saldo = saldo;
}
Akun.prototype.setor = function (n) { this.saldo += n; return this.saldo; };
const a1 = new Akun('Rudi', 1000);
const a2 = new Akun('Tari', 500);
console.log(a1.setor(250), a1.setor === a2.setor);   // metode dibagi bersama

// rantai prototype sebuah array
let p = [1, 2];
const rantai = [];
while (p) { p = Object.getPrototypeOf(p); rantai.push(p === null ? 'null' : p.constructor.name + '.prototype'); }
console.log(rantai.join(' -> '));

Poin penting

  • Setiap object punya prototype; pencarian properti menelusuri prototype chain.
  • Metode bawaan tinggal di prototype seperti Array.prototype.
  • class adalah syntactic sugar di atas prototype.
  • Jangan memodifikasi prototype bawaan.
