Hoisting dan Temporal Dead Zone

Buka versi interaktif

Sebelum kode dijalankan, engine membuat execution context dan mendaftarkan semua deklarasi di scope itu. Efek ini disebut hoisting (seolah deklarasi "diangkat" ke atas).

Deklarasi fungsi di-hoist lengkap, jadi bisa dipanggil sebelum ditulis. var di-hoist dan langsung diisi undefined, sehingga membacanya sebelum baris deklarasi tidak error tetapi menghasilkan undefined (sumber bug klasik).

let, const, dan class juga di-hoist tetapi tidak diinisialisasi. Rentang dari awal scope sampai baris deklarasinya disebut Temporal Dead Zone (TDZ); mengaksesnya di sana melempar ReferenceError. TDZ justru membantu: error yang jelas lebih baik daripada undefined diam-diam.

Function expression dan arrow function mengikuti aturan variabelnya: const f = () => {} tidak bisa dipanggil sebelum barisnya.

Soal latihan

  1. Tunjukkan perbedaan deklarasi fungsi dan function expression: panggil keduanya sebelum barisnya, tangkap error untuk yang gagal.

Poin penting

  • Hoisting: deklarasi didaftarkan sebelum eksekusi.
  • Deklarasi fungsi bisa dipanggil sebelum ditulis.
  • var berisi undefined; let/const/class kena TDZ.
  • Tulis deklarasi di atas sebelum dipakai agar mudah dibaca.

Cek pemahaman

Output console.log(x); var x = 5;?

Jawaban: undefined

var di-hoist dan diisi undefined.

Output console.log(y); let y = 5;?

Jawaban: ReferenceError

y berada di Temporal Dead Zone.
