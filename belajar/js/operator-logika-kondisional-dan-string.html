Operator logika, kondisional, dan string

Buka versi interaktif

&&, ||, dan ?? tidak selalu mengembalikan boolean; mereka mengembalikan salah satu operand dan melakukan short-circuit (operand kanan tidak dievaluasi jika tidak perlu). a || b = a jika truthy, selain itu b. a && b = a jika falsy, selain itu b. a ?? b = a kecuali a null/undefined. ! membalik boolean, !! mengubah ke boolean.

Optional chaining ?. menghentikan akses jika nilai di kiri null/undefined dan menghasilkan undefined, termasuk untuk panggilan (fn?.()) dan indeks (arr?.[0]). Gabungan a?.b ?? 'default' sangat umum untuk data API yang tidak lengkap.

Operator kondisional (ternary) kondisi ? a : b adalah satu-satunya operator dengan tiga operand; cocok untuk memilih nilai, hindari ternary bersarang yang sulit dibaca. Operator string: + dan += menggabungkan string, tetapi template literal biasanya lebih jelas.

Soal latihan

  1. Dari respons API {produk: {nama: "Keripik", diskon: 0, varian: null}}, cetak nama, diskon (0 harus tetap 0), jumlah varian (0 jika null), dan nama penjual (default "Toko Resmi") yang tidak ada di data.

    Petunjuk

    Gunakan ?. dan ??, jangan ||.

    Lihat jawaban

Poin penting

  • &&, ||, ?? mengembalikan operand, bukan selalu boolean.
  • Short-circuit: sisi kanan bisa tidak dievaluasi.
  • ?. untuk data yang mungkin kosong; padukan dengan ??.
  • Ternary untuk memilih nilai, hindari bersarang.

Cek pemahaman

Hasil 0 || 'kosong'?

Jawaban: 'kosong'

0 falsy.

Hasil 0 ?? 'kosong'?

Jawaban: 0

?? hanya untuk null/undefined.

Hasil user?.profil?.foto jika user undefined?

Jawaban: undefined
