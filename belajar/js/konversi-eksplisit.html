Konversi eksplisit

Buka versi interaktif

Type conversion (atau explicit casting) adalah mengubah tipe dengan sengaja memakai fungsi. Type coercion (atau implicit casting) adalah konversi otomatis yang dilakukan engine saat operator bertemu tipe berbeda. Prinsip kode profesional: buat konversi eksplisit agar maksudnya jelas.

Ke string: String(x), x.toString() (gagal pada null/undefined), atau template literal. Ke number: Number(x) mengubah seluruh string (gagal = NaN), sedangkan parseInt(x, 10) dan parseFloat(x) membaca dari awal sampai karakter tidak valid. Selalu beri radix 10 pada parseInt. Unary +x sama dengan Number(x).

Ke boolean: Boolean(x) atau !!x. Hanya ada 8 nilai falsy: false, 0, -0, 0n, "", null, undefined, NaN. Selain itu truthy, termasuk "0", "false", [], dan {}.

Soal latihan

  1. Input dari form: ["15", "7.5", "abc", "", "20kg"]. Jumlahkan hanya yang merupakan angka valid menurut Number() dan bukan string kosong.

    Petunjuk

    Lewati jika x.trim() === "" atau Number.isNaN(Number(x)).

    Lihat jawaban
    JAVASCRIPT
    const input = ['15', '7.5', 'abc', '', '20kg'];
let total = 0;
for (const x of input) {
  if (x.trim() === '' || Number.isNaN(Number(x))) {
    console.log('lewati:', JSON.stringify(x));
    continue;
  }
  total += Number(x);
}
console.log('total:', total);
    KELUARAN
    lewati: "abc"
lewati: ""
lewati: "20kg"
total: 22.5

Poin penting

  • Conversion = sengaja; coercion = otomatis oleh engine.
  • Number() ketat; parseInt/parseFloat membaca awalan.
  • parseInt selalu dengan radix 10.
  • Hafalkan 8 nilai falsy; sisanya truthy.
