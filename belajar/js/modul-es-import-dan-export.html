Modul ES: import dan export

Buka versi interaktif

Modul memecah kode menjadi file kecil dengan scope sendiri: yang tidak di-export tidak terlihat dari luar. ES Modules (ESM) adalah standar resmi bahasa (ES2015) yang didukung semua browser modern dan Node.

Named export (export const, export function, atau export { a, b as c }) diimpor dengan nama yang sama di kurung kurawal; default export (export default, satu per modul) diimpor dengan nama bebas. import * as ns mengambil semuanya sebagai namespace, dan re-export (export { x } from './a.js') dipakai untuk file indeks (barrel file). Banyak tim menganjurkan named export karena lebih mudah dicari dan di-refactor.

Sifat penting ESM: statis (import harus di tingkat atas, sehingga bundler bisa melakukan tree shaking untuk membuang kode tak terpakai), otomatis strict mode, dieksekusi sekali lalu di-cache, binding impor bersifat live (read-only, mengikuti perubahan di modul asal), dan mendukung top-level await. import() dinamis memuat modul saat runtime dan mengembalikan Promise, dasar dari code splitting dan lazy loading halaman.

JAVASCRIPT
// main.mjs (file lain ada di tab penjelasan; semuanya dijalankan bersama)
import formatRupiah, { PPN, hitungTotal as total } from './lib/uang.mjs';
import * as teks from './lib/teks.mjs';
import { hitungan, tambah } from './lib/penghitung.mjs';

console.log(formatRupiah(total([50000, 25000])), 'PPN', PPN);
console.log(teks.slug('Belajar JavaScript Modern!'), Object.keys(teks));

console.log('sebelum:', hitungan);
tambah(); tambah();
console.log('sesudah:', hitungan);            // live binding
try { hitungan = 10; } catch (e) { console.log(e.name + ':', e.message); }

const { default: fmt } = await import('./lib/uang.mjs');   // import dinamis, modul di-cache
console.log(fmt === formatRupiah, import.meta.url.endsWith('main.mjs'));
if (new Date(0).getUTCFullYear() === 1970) {
  const { slug } = await import('./lib/teks.mjs');
  console.log('dimuat saat diperlukan:', slug('Halo Dunia'));
}

Poin penting

  • Modul punya scope sendiri; export yang terlihat.
  • Named export vs default export.
  • ESM statis, strict, dieksekusi sekali, live binding.
  • import() dinamis untuk code splitting.
  • Di browser: script type="module"; path relatif wajib lengkap dengan ekstensi.
