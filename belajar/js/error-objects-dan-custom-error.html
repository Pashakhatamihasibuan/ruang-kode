Error objects dan custom error

Buka versi interaktif

Semua error bawaan turunan dari Error dan punya name, message, stack, serta opsional cause. Tipe bawaan: SyntaxError (kode atau JSON tidak valid), ReferenceError (nama tidak dikenal, TDZ), TypeError (operasi pada tipe yang salah, misal memanggil undefined), RangeError (nilai di luar rentang), URIError, EvalError, dan AggregateError (banyak error sekaligus, dari Promise.any).

Untuk aplikasi nyata, buat custom error class dengan class ValidasiError extends Error, set this.name, dan tambahkan data (field yang salah, kode HTTP). Penanganannya kemudian memakai instanceof untuk membedakan error yang diharapkan (validasi, 404) dari bug tak terduga.

Di produksi, error yang tidak tertangkap dicatat oleh layanan error monitoring seperti Sentry. Di browser ada event window.onerror dan unhandledrejection; di Node ada process.on("uncaughtException"). Pesan error untuk pengguna harus ramah, sementara detail teknis hanya ke log.

JAVASCRIPT
class ValidasiError extends Error {
  constructor(field, pesan) {
    super(pesan);
    this.name = 'ValidasiError';
    this.field = field;
  }
}
class TidakDitemukanError extends Error {
  name = 'TidakDitemukanError';
  status = 404;
}

function daftar(user) {
  if (!user.email?.includes('@')) throw new ValidasiError('email', 'Format email salah');
  if (user.email === 'ada@contoh.id') throw new TidakDitemukanError('Paket tidak ditemukan');
  return 'terdaftar';
}

for (const u of [{ email: 'rina@contoh.id' }, { email: 'rina' }, { email: 'ada@contoh.id' }, null]) {
  try {
    console.log(daftar(u));
  } catch (e) {
    if (e instanceof ValidasiError) console.log(`[400] ${e.field}: ${e.message}`);
    else if (e instanceof TidakDitemukanError) console.log(`[${e.status}] ${e.message}`);
    else console.log(`[500] bug: ${e.name} - ${e.message}`);
  }
}
const e = new ValidasiError('nama', 'wajib');
console.log(e instanceof Error, e.stack.split('\n')[0]);

for (const kode of ['null.x', 'x.y.z', 'new Array(-1)', '[].reduce((a,b)=>a)']) {
  try { new Function(kode)(); } catch (err) { console.log(kode.padEnd(20), err.name); }
}

Poin penting

  • Error punya name, message, stack, cause.
  • TypeError dan ReferenceError paling sering ditemui.
  • Custom error dengan extends Error + instanceof.
  • Error monitoring (Sentry) untuk produksi.
