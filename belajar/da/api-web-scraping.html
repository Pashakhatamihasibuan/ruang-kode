API & web scraping

Buka versi interaktif

API adalah cara resmi mengambil data dari layanan lain dalam format JSON. Gunakan requests, sertakan kunci API di header, dan perhatikan batas permintaan (rate limit).

Web scraping mengambil data dari halaman HTML dengan BeautifulSoup saat API tidak tersedia. Periksa robots.txt dan syarat layanan situs, beri jeda antar permintaan, dan jangan mengambil data pribadi.

Simpan data mentah apa adanya lebih dulu, baru bersihkan; dengan begitu analisis bisa diulang.

PYTHON
import requests
import pandas as pd
from bs4 import BeautifulSoup

# API (JSON)
r = requests.get("https://api.contoh.id/v1/kurs", params={"dari": "USD"}, timeout=10)
r.raise_for_status()
kurs = pd.json_normalize(r.json()["data"])

# Scraping (HTML)
html = requests.get("https://contoh.id/harga-pangan", timeout=10).text
soup = BeautifulSoup(html, "html.parser")
baris = [[td.get_text(strip=True) for td in tr.select("td")] for tr in soup.select("table tr")[1:]]
pangan = pd.DataFrame(baris, columns=["komoditas", "harga", "satuan"])

Poin penting

  • API resmi lebih stabil daripada scraping.
  • Hormati robots.txt, rate limit, privasi.
  • Simpan mentah dulu.
