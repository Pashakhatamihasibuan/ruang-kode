Regresi linear sederhana

Buka versi interaktif

Regresi linear mencari garis y = a + b·x yang paling dekat dengan data. Koefisien b menjawab: jika x naik 1, y naik berapa rata-rata?

R² menyatakan berapa bagian variasi y yang dijelaskan oleh x (0 sampai 1).

Contoh di bawah menghitung regresi dengan NumPy: setiap tambahan Rp 1 juta iklan berasosiasi dengan sekian pengunjung tambahan.

PYTHON
import numpy as np

iklan = np.array([1, 2, 3, 4, 5, 6])          # juta rupiah
pengunjung = np.array([120, 190, 260, 300, 390, 450])

b, a = np.polyfit(iklan, pengunjung, 1)
prediksi = a + b * iklan
r2 = 1 - ((pengunjung - prediksi) ** 2).sum() / ((pengunjung - pengunjung.mean()) ** 2).sum()
print(f"pengunjung = {a:.1f} + {b:.1f} x iklan")
print(f"R2 = {r2:.3f}")
print("prediksi iklan 8 juta:", round(a + b * 8))
KELUARAN
pengunjung = 56.0 + 65.4 x iklan
R2 = 0.994
prediksi iklan 8 juta: 579

Poin penting

  • y = a + b·x; b = perubahan y per satuan x.
  • R² = proporsi variasi yang dijelaskan.
  • Prediksi di luar rentang data berisiko.

Cek pemahaman

Memprediksi untuk iklan Rp 50 juta dari data 1-6 juta berisiko karena?

Jawaban: Di luar rentang data (ekstrapolasi)

Hubungan bisa berubah di luar rentang yang diamati.
