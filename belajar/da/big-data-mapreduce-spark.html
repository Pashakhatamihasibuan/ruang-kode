Big data, MapReduce & Spark

Buka versi interaktif

Data disebut big data saat volume, velocity (kecepatan datang), atau variety (ragam format) melampaui kemampuan satu komputer. Solusinya: bagi pekerjaan ke banyak mesin.

MapReduce: tahap map memproses potongan data secara paralel dan mengeluarkan pasangan kunci-nilai; shuffle mengelompokkan menurut kunci; reduce menggabungkan setiap kelompok. Hadoop mempopulerkannya; Spark melakukannya di memori sehingga jauh lebih cepat.

Visualisasi di atas memperlihatkan alurnya. Kode di bawah meniru MapReduce menghitung kata pada tiga "potongan" ulasan dengan Python biasa.

PYTHON
from collections import defaultdict

potongan = [
    "kopi enak kirim cepat",
    "kopi wangi harga pas",
    "kirim lambat kopi enak",
]
# map: setiap potongan -> (kata, 1)
pasangan = [(kata, 1) for teks in potongan for kata in teks.split()]
# shuffle: kelompokkan menurut kunci
kelompok = defaultdict(list)
for kata, n in pasangan:
    kelompok[kata].append(n)
# reduce: jumlahkan tiap kelompok
hasil = {kata: sum(ns) for kata, ns in kelompok.items()}
print(sorted(hasil.items(), key=lambda x: (-x[1], x[0]))[:4])
KELUARAN
[('kopi', 3), ('enak', 2), ('kirim', 2), ('cepat', 1)]

Poin penting

  • Big data: volume, velocity, variety.
  • Map → shuffle → reduce.
  • Spark: MapReduce di memori, jauh lebih cepat.
