Python atau R?

Buka versi interaktif

Python serbaguna: analisis (pandas), otomasi, web scraping, dan machine learning. Paling banyak diminta lowongan di Indonesia.

R lahir untuk statistik: paket dplyr untuk manipulasi, ggplot2 untuk grafik, sangat kuat di riset dan akademik.

Pilih satu dan kuasai. Konsepnya sama: filter, pilih kolom, kelompokkan, agregasi, gabungkan.

CONTOH
# R + dplyr                              # Python + pandas
penjualan |>                              (penjualan
  filter(kota == "Jakarta") |>              .query("kota == 'Jakarta'")
  group_by(produk) |>                       .groupby("produk")
  summarise(unit = sum(jumlah)) |>          .agg(unit=("jumlah", "sum"))
  arrange(desc(unit))                       .sort_values("unit", ascending=False))

Poin penting

  • Python: serbaguna, paling banyak diminta.
  • R: statistik dan grafik akademik.
  • Konsepnya sama di keduanya.
