Python atau R?

Buka versi interaktif

Python serbaguna: analisis (pandas), otomasi, web scraping, dan machine learning. Paling banyak diminta lowongan di Indonesia.

R lahir untuk statistik: paket dplyr untuk manipulasi, ggplot2 untuk grafik, sangat kuat di riset dan akademik.

Pilih satu dan kuasai. Konsepnya sama: filter, pilih kolom, kelompokkan, agregasi, gabungkan.

CONTOH
# R + dplyr                              # Python + pandas
penjualan |>                              (penjualan
  filter(kota == "Jakarta") |>              .query("kota == 'Jakarta'")
  group_by(produk) |>                       .groupby("produk")
  summarise(unit = sum(jumlah)) |>          .agg(unit=("jumlah", "sum"))
  arrange(desc(unit))                       .sort_values("unit", ascending=False))

Soal latihan

  1. Pilih Python atau R untuk: (a) tim produk yang juga membangun API, (b) penelitian statistik di kampus, (c) analis yang bekerja dengan data engineer.

    Petunjuk

    Python: serba guna dan dekat dengan rekayasa. R: kuat di statistik dan akademik.

    Lihat jawaban
    CONTOH
    (a) Python: satu bahasa untuk analisis dan aplikasi.
(b) R: paket statistik lengkap dan umum di jurnal.
(c) Python: sama dengan alat engineer (Airflow, PySpark).

  2. Tulis padanan Python (pandas) dari kode R dplyr: df %>% filter(omzet > 0) %>% group_by(kota) %>% summarise(total = sum(omzet)).

    Petunjuk

    Rangkaian method pandas: query/loc, groupby, agg.

    Lihat jawaban
    PYTHON
    import pandas as pd

df = pd.DataFrame({"kota": ["Medan", "Medan", "Bandung"], "omzet": [10, -2, 7]})
print(df[df["omzet"] > 0].groupby("kota", as_index=False).agg(total=("omzet", "sum")))
    KELUARAN
          kota  total
0  Bandung      7
1    Medan     10

Poin penting

  • Python: serbaguna, paling banyak diminta.
  • R: statistik dan grafik akademik.
  • Konsepnya sama di keduanya.
