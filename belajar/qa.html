QA Engineer: Menjamin kualitas perangkat lunak dari kebutuhan sampai rilis

Dasar QA dan STLC, piramida testing, teknik desain test case (partisi, nilai batas, decision table, state transition), test case dan laporan bug, exploratory testing, pytest, mock, API testing, Playwright, tes flaky, k6, dan CI.

5 modul · 15 pelajaran

Mulai belajar di aplikasi

Modul 1: Dasar quality assurance

Pemula

Peran QA, beda QA, QC, dan testing, siklus pengujian (STLC), jenis pengujian, dan piramida testing.

  1. Apa itu QA dan apa kerjanya
  2. Jenis pengujian dan piramida testing
  3. Siklus pengujian (STLC) dan peran QA di Agile

Modul 2: Teknik desain test case

Pemula

Equivalence partitioning, boundary value analysis, decision table, dan state transition, lengkap dengan tes yang bisa dijalankan.

  1. Equivalence partitioning dan boundary value
  2. Decision table
  3. State transition testing

Modul 3: Manual testing dan laporan bug

Pemula

Menulis test case, exploratory testing, menulis laporan bug yang baik, severity dan priority, serta alat manajemen tes.

  1. Menulis test case yang baik
  2. Laporan bug, severity, dan priority
  3. Exploratory testing

Modul 4: Otomasi: unit, mock, dan API

Menengah

Pola Arrange-Act-Assert, pytest, test double (mock, stub), serta pengujian API REST.

  1. Unit test dengan pola Arrange-Act-Assert
  2. Mock dan stub
  3. Pengujian API REST

Modul 5: Otomasi UI, performa, dan CI

Lanjutan

End-to-end dengan Playwright dan Page Object Model, menangani tes flaky, uji performa dengan k6, dan menjalankan tes di CI.

  1. Tes E2E dengan Playwright
  2. Tes flaky dan strategi data uji
  3. Uji performa dengan k6 dan tes di CI
