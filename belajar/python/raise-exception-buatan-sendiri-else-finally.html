raise, exception buatan sendiri & else/finally

Buka versi interaktif

Kamu bisa melempar exception sendiri dengan raise ketika fungsi menerima data yang tidak masuk akal. Buat kelas exception khusus dengan menurunkan Exception, supaya pemanggil bisa menangkap jenis kesalahan yang spesifik.

Exception yang tidak ditangkap akan "naik" ke fungsi pemanggil, lalu pemanggilnya, dan seterusnya, sampai ada except yang cocok. Kalau tidak ada sama sekali, program berhenti dan menampilkan traceback: jejak lengkap pemanggilan dari bawah ke atas.

Struktur lengkapnya: try (kode yang mungkin gagal), except (penanganan), else (jalan jika tidak ada error), dan finally (selalu jalan). Tangkap exception yang spesifik; except: kosong bisa menyembunyikan bug.

PYTHON
class SaldoKurang(Exception):
    def __init__(self, kurang):
        super().__init__(f"saldo kurang Rp{kurang:,}")
        self.kurang = kurang

saldo = 50_000

def tarik(jumlah):
    global saldo
    if jumlah <= 0:
        raise ValueError("jumlah harus positif")
    if jumlah > saldo:
        raise SaldoKurang(jumlah - saldo)
    saldo -= jumlah

def layani(jumlah):
    print("memproses", jumlah)
    tarik(jumlah)
    print("berhasil")

for j in [20_000, 80_000, -5]:
    try:
        layani(j)
    except SaldoKurang as e:
        print("gagal:", e)
    except ValueError as e:
        print("input salah:", e)
    else:
        print("transaksi tercatat")
    finally:
        print("sisa", saldo)

Kode pemula vs kode rapi

Tangkap error yang spesifik

except: tanpa nama menangkap semua hal, termasuk salah ketik nama variabel dan Ctrl+C, sehingga bug tersembunyi. Sebutkan jenis error yang memang kamu harapkan.

KODE PEMULA
teks = "12a"
try:
    jumlah = int(teks)
except:
    jumlah = 0
print(jumlah)
KODE RAPI (BEST PRACTICE)
teks = "12a"
try:
    jumlah = int(teks)
except ValueError:
    jumlah = 0
print(jumlah)
KELUARAN KEDUANYA
0

Poin penting

  • raise melempar exception.
  • Exception buatan sendiri: class NamaError(Exception).
  • else jalan jika tidak ada error, finally selalu jalan.
  • Tangkap jenis exception yang spesifik.
