Koleksi: List, Set, Dict

Buka versi interaktif

Selain list, ada dua koleksi penting. Set adalah himpunan: tidak ada duplikat dan pengecekan in sangat cepat. Dictionary (dict) memasangkan kunci dengan nilai, misalnya kata dengan jumlah kemunculannya.

set dan dict bawaan Python sangat cepat. dict menyimpan urutan saat data dimasukkan, sedangkan set tidak menjamin urutan. Butuh hasil terurut? Pakai sorted(). Modul collections menambah Counter dan defaultdict untuk kasus menghitung.

Koleksi-koleksi ini adalah contoh abstract data type: kamu tahu operasinya (tambah, hapus, cari) tanpa perlu tahu cara kerjanya di dalam. Untuk menjelajahi isinya, gunakan for-each atau iterator.

PYTHON
def main():
    teks = "satu dua tiga dua satu satu"
    unik = set()
    jumlah = {}

    for kata in teks.split():
        unik.add(kata)
        jumlah[kata] = jumlah.get(kata, 0) + 1

    print(sorted(unik))
    print(jumlah)

main()
KELUARAN
['dua', 'satu', 'tiga']
{'satu': 3, 'dua': 2, 'tiga': 1}

Poin penting

  • d.get(k, 0) menghindari KeyError saat kunci belum ada.
  • Kunci dict unik. Mengisi d[k] = v pada kunci yang sama menimpa nilai lama.
  • Python dict menyimpan urutan saat data dimasukkan.
  • Pilih koleksi dari pertanyaannya: urutan penting? duplikat boleh? butuh pasangan?
