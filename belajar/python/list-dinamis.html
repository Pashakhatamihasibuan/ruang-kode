List Dinamis

Buka versi interaktif

List Python bisa tumbuh dan menyusut sendiri. Kamu bisa append, insert, remove, pop, dan mengubah elemen lewat indeks tanpa memikirkan ukuran.

List boleh berisi nilai apa saja, bahkan campuran tipe. Agar kode mudah dibaca, biasakan satu list berisi satu jenis data. Petunjuk tipe seperti list[str] membantu editor menemukan kesalahan.

Menyisip atau menghapus di tengah membuat elemen di belakangnya bergeser. Akibatnya, menghapus elemen sambil berjalan maju dengan loop indeks bisa melewatkan elemen. Solusinya: jalan mundur dari belakang, atau buat list baru.

PYTHON
def main():
    buah = []
    buah.append("apel")
    buah.append("jeruk")
    buah.insert(1, "mangga")     # sisip di indeks 1
    print(buah)                  # ['apel', 'mangga', 'jeruk']

    buah.pop(0)                  # sisanya bergeser ke kiri
    print(buah[0] + ", ukuran", len(buah))

    angka = [i * i for i in range(1, 6)]
    print(angka)

main()
KELUARAN
['apel', 'mangga', 'jeruk']
mangga, ukuran 2
[1, 4, 9, 16, 25]

Poin penting

  • len(lst) memberi jumlah elemen.
  • pop(1) menghapus indeks 1. remove("a") menghapus nilai "a".
  • in untuk mengecek keberadaan: "a" in lst.
  • Python: list comprehension [x * 2 for x in a] membuat list baru dengan ringkas.

Cek pemahaman

List berisi [a, b, c, d]. Setelah pop(1), isinya menjadi...

Jawaban: [a, c, d]

Indeks 1 adalah b. Setelah dihapus, c dan d bergeser ke kiri.

Apa hasil len(a) setelah a = [1, 2] lalu a.append(3)?

Jawaban: 3

append menambah satu elemen di akhir, jadi panjangnya 3.
