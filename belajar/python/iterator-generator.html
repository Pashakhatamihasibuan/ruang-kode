Iterator & generator

Buka versi interaktif

Iterator adalah objek yang memberikan elemen satu per satu lewat next(), dan melempar StopIteration jika habis. Loop for bekerja di atas protokol ini: ia memanggil iter() sekali lalu next() berulang kali.

Generator adalah cara termudah membuat iterator: fungsi biasa yang memakai yield alih-alih return. Setiap kali next() dipanggil, fungsi berjalan sampai yield berikutnya, menyerahkan nilai, lalu berhenti sejenak sambil mengingat posisinya.

Generator bersifat malas (lazy): nilai dibuat hanya saat diminta. Karena itu generator bisa mewakili deret tak hingga atau file berukuran gigabyte tanpa menghabiskan memori. Generator expression ditulis seperti list comprehension tetapi dengan kurung biasa: (x*x for x in data).

PYTHON
import sys

def hitung_mundur(n):
    print("mulai")
    while n > 0:
        yield n
        n -= 1
    print("habis")

g = hitung_mundur(3)
print(next(g))
print(next(g))
for x in g:
    print("loop", x)

def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

fib = fibonacci()
print([next(fib) for _ in range(8)])

daftar = [x * x for x in range(100_000)]
gen = (x * x for x in range(100_000))
print(sys.getsizeof(daftar) > 100_000, sys.getsizeof(gen) < 1000)
print(sum(gen))

Poin penting

  • Iterator: iter() lalu next() sampai StopIteration.
  • yield menyerahkan nilai dan menjeda fungsi.
  • Generator hemat memori karena lazy.
  • Generator hanya bisa dilalui sekali.
