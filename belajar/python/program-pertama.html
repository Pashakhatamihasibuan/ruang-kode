Program Pertama

Buka versi interaktif

Program adalah daftar instruksi yang dijalankan komputer satu per satu. Setiap instruksi disebut statement. Di Python, satu baris biasanya satu statement, dan baris-baris dalam satu blok ditandai dengan indentasi (spasi di awal baris).

Python diinterpretasi: interpreter membaca dan menjalankan kode baris demi baris, jadi kamu cukup menjalankan python halo.py. Kesalahan di sebuah baris baru ketahuan saat baris itu dijalankan.

Begitu program bertambah panjang, pecah menjadi bagian kecil bernama fungsi. Teknik ini disebut dekomposisi prosedural. Setiap bagian punya satu tugas yang jelas dan bisa dipanggil berkali-kali.

PYTHON
def sapa():
    # fungsi: memecah program jadi bagian kecil
    print("Selamat belajar!")

def main():
    print("Halo, dunia!")
    sapa()
    sapa()

main()
KELUARAN
Halo, dunia!
Selamat belajar!
Selamat belajar!

Poin penting

  • Program Python bisa langsung berisi statement, tanpa kelas atau method main.
  • Python menjalankan file dari atas ke bawah. Pola main() dipakai agar rapi.
  • Komentar diawali # dan diabaikan komputer.
  • Nama fungsi sebaiknya kata kerja, huruf kecil dengan garis bawah: cetak_laporan.
