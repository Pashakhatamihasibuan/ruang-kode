Pemeriksa tipe: mypy, pyright, pyrefly

Buka versi interaktif

Pemeriksa tipe statis membaca kode tanpa menjalankannya, lalu melaporkan pemakaian tipe yang tidak cocok. Bug seperti mengirim string ke fungsi yang butuh angka, atau lupa menangani kemungkinan None, ketahuan sebelum sampai ke pengguna.

mypy adalah pemeriksa tipe tertua dan menjadi acuan. pyright dari Microsoft sangat cepat dan menjadi mesin di balik fitur Pylance di VS Code. pyrefly dari Meta adalah pemeriksa baru berbasis Rust yang fokus pada kecepatan untuk proyek raksasa.

Biasanya pemeriksa tipe dijalankan otomatis di editor dan di pipeline CI, berdampingan dengan linter dan tes. Mode --strict mewajibkan semua fungsi beranotasi.

PYTHON
# toko.py
def diskon(harga: int, persen: int) -> int:
    return harga - harga * persen // 100

def cari_harga(nama: str) -> int | None:
    katalog = {"kopi": 85000}
    return katalog.get(nama)

total = diskon("85000", 10)          # salah tipe
h = cari_harga("teh")
print(h + 1000)                       # h bisa None

# $ mypy toko.py
# toko.py:8: error: Argument 1 to "diskon" has incompatible type "str"; expected "int"
# toko.py:10: error: Unsupported operand types for + ("None" and "int")
# Found 2 errors in 1 file (checked 1 source file)

# $ pyright toko.py      -> laporan serupa
# $ pyrefly check toko.py

Poin penting

  • Pemeriksa tipe menemukan bug tanpa menjalankan program.
  • mypy = acuan, pyright = cepat dan terintegrasi VS Code, pyrefly = baru dan sangat cepat.
  • Tangani None secara eksplisit: if h is not None.
  • Jalankan di CI agar kode baru selalu diperiksa.
