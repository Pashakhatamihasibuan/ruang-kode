Boolean logic: AND, OR, NOT, tabel kebenaran, dan De Morgan

Buka versi interaktif

Boolean adalah tipe data yang hanya punya dua nilai: true (benar) dan false (salah). Namanya diambil dari George Boole, matematikawan yang merumuskan aljabar logika. Setiap kondisi di if dan while pada akhirnya menghasilkan satu nilai boolean.

Operator perbandingan (==, !=, <, >, <=, >=) selalu menghasilkan boolean. Hasilnya bisa disimpan di variabel dengan nama yang jelas, misalnya nilaiCukup atau sudahLogin, sehingga kondisi panjang menjadi mudah dibaca.

AND bernilai true hanya jika kedua sisi true. OR bernilai true jika minimal satu sisi true. NOT membalik nilai. XOR bernilai true jika kedua sisi berbeda. Tabel kebenaran mendaftar semua kombinasi masukan: dua masukan berarti 2 × 2 = 4 baris.

Urutan pengerjaan: NOT dulu, lalu AND, baru OR. Karena itu true || false && false hasilnya true: bagian false && false dikerjakan lebih dulu. Agar tidak salah baca, pakai tanda kurung.

Hukum De Morgan: membalik AND menjadi OR dari kebalikannya, dan sebaliknya. !(a && b) sama dengan !a || !b, dan !(a || b) sama dengan !a && !b. Contoh sehari-hari: "tidak (nilai cukup dan hadir cukup)" sama artinya dengan "nilai kurang atau hadir kurang".

Short-circuit: AND berhenti jika sisi kiri sudah false, dan OR berhenti jika sisi kiri sudah true, karena hasilnya sudah pasti. Ini dipakai sebagai pengaman, misalnya pembagi != 0 && 10 / pembagi > 1 tidak pernah membagi dengan nol. Buka visual 3D di bawah, lalu ubah p, q, dan operatornya di panel Eksperimen.

Catatan Python: operator ditulis dengan kata (and, or, not), dan nilainya True/False berhuruf besar. Nilai seperti 0, "", [], dan None dianggap salah (falsy). and/or mengembalikan salah satu operandnya, misalnya nama or "tamu". Python juga mendukung perbandingan berantai 0 < x < 10.

PYTHON
# 1. Hasil perbandingan selalu boolean: True atau False
nilai, hadir = 82, 70
nilai_cukup = nilai >= 75
hadir_cukup = hadir >= 80
print("nilai_cukup =", nilai_cukup)
print("hadir_cukup =", hadir_cukup)

# 2. and, or, not (ditulis dengan kata)
print("AND: lulus =", nilai_cukup and hadir_cukup)
print("OR : remedial =", not nilai_cukup or not hadir_cukup)
print("NOT: not hadir_cukup =", not hadir_cukup)

# 3. Tabel kebenaran semua kombinasi p dan q
tf = [True, False]
print("p     q     AND   OR    XOR")
for p in tf:
    for q in tf:
        print(f"{p!s:<6}{q!s:<6}{p and q!s:<6}{p or q!s:<6}{p ^ q}")

# 4. Hukum De Morgan, dicek untuk semua kombinasi
hukum1 = all((not (p and q)) == (not p or not q) for p in tf for q in tf)
hukum2 = all((not (p or q)) == (not p and not q) for p in tf for q in tf)
print("De Morgan 1: not (p and q) == not p or not q ->", hukum1)
print("De Morgan 2: not (p or q) == not p and not q ->", hukum2)

# 5. Urutan: not dulu, lalu and, baru or
print("True or False and False =", True or False and False)

# 6. Short-circuit: sisi kanan tidak dihitung jika hasil sudah pasti
pembagi = 0
if pembagi != 0 and 10 / pembagi > 1:
    print("hasil bagi besar")
else:
    print("short-circuit: 10 / 0 tidak pernah dihitung")

Poin penting

  • AND true jika keduanya true; OR true jika salah satu true; NOT membalik.
  • Urutan pengerjaan: NOT, lalu AND, lalu OR. Pakai kurung agar jelas.
  • De Morgan: !(a && b) sama dengan !a || !b.
  • Short-circuit melewati sisi kanan jika hasilnya sudah pasti.

Cek pemahaman

p = true dan q = false. Berapa nilai p && q?

Jawaban: false

AND butuh kedua sisi true.

Hasil dari true || false && false adalah…

Jawaban: true

&& dikerjakan dulu: false && false = false, lalu true || false = true.

Menurut De Morgan, !(a && b) sama dengan…

Jawaban: !a || !b

AND yang dibalik menjadi OR dari kebalikan masing-masing.

Mengapa x != 0 && 10 / x > 1 aman saat x = 0?

Jawaban: Sisi kanan tidak dihitung karena sisi kiri sudah false

Short-circuit: hasil AND sudah pasti false.
