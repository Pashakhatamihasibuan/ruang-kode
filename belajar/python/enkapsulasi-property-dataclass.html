Enkapsulasi: property & dataclass

Buka versi interaktif

Python tidak punya private seperti Java. Konvensinya: nama yang diawali satu garis bawah (_saldo) berarti "internal, jangan disentuh dari luar". Dua garis bawah (__pin) membuat Python mengganti namanya (name mangling) sehingga lebih sulit diakses tanpa sengaja.

@property membuat method bisa diakses seperti atribut, sekaligus memberi tempat untuk validasi. Pengguna kelas menulis akun.saldo, tetapi di balik layar ada logika yang menjaga aturan.

@dataclass menulis otomatis __init__, __repr__, dan __eq__ untuk kelas pembawa data. Tambahkan frozen=True agar objeknya tidak bisa diubah, mirip record di Java.

PYTHON
from dataclasses import dataclass, field

class Rekening:
    def __init__(self, pemilik):
        self.pemilik = pemilik
        self._saldo = 0

    @property
    def saldo(self):
        return self._saldo

    @saldo.setter
    def saldo(self, nilai):
        if nilai < 0:
            raise ValueError("saldo tidak boleh negatif")
        self._saldo = nilai

r = Rekening("Andi")
r.saldo = 75_000
print(r.saldo)
try:
    r.saldo = -1
except ValueError as e:
    print(e)

@dataclass
class Produk:
    nama: str
    harga: int
    tag: list = field(default_factory=list)

@dataclass(frozen=True)
class Titik:
    x: int
    y: int

p = Produk("Kopi Gayo", 85000)
print(p)
print(p == Produk("Kopi Gayo", 85000))
t = Titik(1, 2)
try:
    t.x = 5
except Exception as e:
    print(type(e).__name__)

Kode pemula vs kode rapi

Kelas data dengan @dataclass

@dataclass membuat __init__, __repr__, dan __eq__ otomatis dari daftar field.

KODE PEMULA
class Produk:
    def __init__(self, nama, harga):
        self.nama = nama
        self.harga = harga

    def __repr__(self):
        return f"Produk(nama={self.nama!r}, harga={self.harga!r})"

print(Produk("Kopi Gayo", 85000))
KODE RAPI (BEST PRACTICE)
from dataclasses import dataclass

@dataclass
class Produk:
    nama: str
    harga: int

print(Produk("Kopi Gayo", 85_000))
KELUARAN KEDUANYA
Produk(nama='Kopi Gayo', harga=85000)

Poin penting

  • _nama = konvensi internal.
  • @property + setter untuk validasi.
  • @dataclass mengurangi kode boilerplate.
  • frozen=True membuat objek immutable.
