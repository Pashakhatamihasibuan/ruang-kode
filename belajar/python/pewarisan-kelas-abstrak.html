Pewarisan & Kelas Abstrak

Buka versi interaktif

Pewarisan membuat kelas baru dari kelas yang sudah ada. class Kucing(Hewan) berarti Kucing otomatis punya semua atribut dan method Hewan. Kelas induk disebut superclass, kelas anak disebut subclass. Hubungannya selalu "adalah": kucing adalah hewan.

Subclass boleh meng-override method induk untuk mengganti perilakunya. Karena itu, variabel h bisa menunjuk Kucing atau Anjing, dan h.suara() menjalankan versi milik objek sebenarnya. Inilah polimorfisme.

Python tidak punya kata kunci interface. Kontraknya cukup kesepakatan: objek yang punya method yang dibutuhkan boleh dipakai. Ini disebut duck typing. Bila kontrak ingin dipaksa, pakai kelas abstrak dari modul abc: boleh punya method lengkap dan method abstrak, tapi tidak bisa dibuat objeknya langsung.

PYTHON
from abc import ABC, abstractmethod

class Hewan(ABC):
    def __init__(self, nama):
        self.nama = nama

    @abstractmethod
    def suara(self):            # wajib di-override
        pass

    def kenalkan(self):
        return f"{self.nama} berkata {self.suara()}"

class Kucing(Hewan):
    def suara(self):
        return "Meong"

class Anjing(Hewan):
    def suara(self):
        return "Guk"

kebun = [Kucing("Tom"), Anjing("Spike")]
for h in kebun:
    print(h.kenalkan())         # polimorfisme
KELUARAN
Tom berkata Meong
Spike berkata Guk

Poin penting

  • super().__init__(...) memanggil konstruktor induk.
  • Kelas abstrak (ABC dan @abstractmethod) memaksa subclass menulis method tertentu.
  • Python mengizinkan banyak kelas induk sekaligus.
  • Override: method dengan nama sama di subclass. Python tidak punya overload; pakai nilai default parameter.
