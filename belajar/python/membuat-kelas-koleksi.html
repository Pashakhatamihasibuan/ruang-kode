Membuat Kelas Koleksi

Buka versi interaktif

Di bab ini kamu membangun list sederhana bernama ArrayIntList. Di dalamnya ada "array" internal berukuran tetap (_data) dan penghitung _size. Pengguna kelas hanya melihat method add, get, size, dan seterusnya.

Perbedaan size dan kapasitas adalah kunci. Kapasitas adalah panjang array internal. Size adalah berapa slot yang benar-benar terisi. Saat size sama dengan kapasitas, kelas membuat array baru dua kali lebih besar lalu menyalin isinya. Karena pembesaran jarang terjadi, rata-rata add tetap cepat.

Kelas yang baik memeriksa precondition, yaitu syarat yang harus dipenuhi pemanggil. Misalnya indeks untuk get harus di antara 0 dan size - 1. Bila dilanggar, lempar exception dengan pesan yang jelas, jangan diam-diam mengembalikan nilai sampah.

PYTHON
class ArrayIntList:
    def __init__(self):
        self._data = [0] * 4     # "array" internal
        self._size = 0           # jumlah slot terpakai

    def add(self, nilai):
        if self._size == len(self._data):          # penuh?
            self._data = self._data + [0] * len(self._data)
        self._data[self._size] = nilai
        self._size += 1

    def get(self, i):
        if i < 0 or i >= self._size:               # precondition
            raise IndexError(f"indeks: {i}")
        return self._data[i]

    def __len__(self):
        return self._size

Poin penting

  • Atribut diawali _. Pengguna tidak boleh mengubah _size langsung.
  • Slot di atas size berisi sisa data yang tidak dianggap ada.
  • Dokumentasikan precondition dan postcondition setiap method.
  • Python: method khusus __len__ dan __getitem__ membuat objekmu bisa dipakai seperti list.

Cek pemahaman
