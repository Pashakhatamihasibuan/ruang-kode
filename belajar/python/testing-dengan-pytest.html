Testing dengan pytest

Buka versi interaktif

pytest adalah framework tes paling populer di Python. Tes ditulis sebagai fungsi biasa yang namanya diawali test_, di file yang namanya diawali test_. Pemeriksaan cukup memakai assert biasa, dan pytest menampilkan detail nilai yang berbeda saat gagal.

pytest.raises memeriksa bahwa sebuah exception dilempar. @pytest.mark.parametrize menjalankan satu tes dengan banyak data. Fixture menyiapkan data atau sumber daya yang dipakai bersama beberapa tes, misalnya database sementara.

Jalankan semua tes dengan perintah pytest di folder proyek. Tambahkan -v untuk melihat nama setiap tes, dan pasang pytest-cov untuk mengukur seberapa banyak kode yang teruji.

PYTHON
# toko.py
def diskon(harga, persen):
    if not 0 <= persen <= 100:
        raise ValueError("persen harus 0..100")
    return harga - harga * persen // 100

# test_toko.py
import pytest
from toko import diskon

def test_diskon_sepuluh_persen():
    assert diskon(50_000, 10) == 45_000

def test_persen_salah():
    with pytest.raises(ValueError):
        diskon(1000, 150)

@pytest.mark.parametrize("harga, persen, harapan", [
    (100_000, 0, 100_000),
    (100_000, 100, 0),
    (80_000, 25, 60_000),
])
def test_banyak_kasus(harga, persen, harapan):
    assert diskon(harga, persen) == harapan

@pytest.fixture
def keranjang():
    return [("kopi", 85_000), ("teh", 25_000)]

def test_total(keranjang):
    assert sum(h for _, h in keranjang) == 110_000

# $ pytest -v
# test_toko.py::test_diskon_sepuluh_persen PASSED
# test_toko.py::test_persen_salah PASSED
# test_toko.py::test_banyak_kasus[100000-0-100000] PASSED   ... (3 kasus)
# test_toko.py::test_total PASSED
# ===== 6 passed in 0.02s =====

Poin penting

  • File dan fungsi tes diawali test_.
  • Cukup assert biasa.
  • parametrize untuk banyak data, fixture untuk persiapan bersama.
  • pytest-cov untuk mengukur cakupan tes.
