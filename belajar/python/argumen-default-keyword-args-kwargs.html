Argumen default, keyword, *args, **kwargs

Buka versi interaktif

Fungsi Python sangat fleksibel dalam menerima argumen. Parameter default punya nilai bawaan jika pemanggil tidak mengisinya. Keyword argument menyebut nama parameter saat memanggil, sehingga urutannya bebas dan kode lebih mudah dibaca.

*args mengumpulkan sejumlah argumen posisi menjadi tuple, dan **kwargs mengumpulkan argumen bernama menjadi dict. Ini berguna untuk fungsi yang jumlah masukannya tidak pasti.

Jebakan klasik: jangan memakai list atau dict sebagai nilai default (def f(x=[])), karena objek default hanya dibuat sekali dan dipakai bersama semua pemanggilan. Pakai None lalu buat list baru di dalam fungsi.

PYTHON
def sapa(nama, salam="Halo", tanda="!"):
    return f"{salam}, {nama}{tanda}"

print(sapa("Rina"))
print(sapa("Budi", tanda="?"))
print(sapa(salam="Selamat pagi", nama="Citra"))

def total(*harga, diskon=0):
    return sum(harga) * (100 - diskon) // 100

print(total(10000, 25000, 5000))
print(total(10000, 25000, diskon=10))

def profil(**data):
    return ", ".join(f"{k}={v}" for k, v in data.items())

print(profil(nama="Eko", kota="Medan"))

def tambah(item, wadah=None):
    if wadah is None:
        wadah = []
    wadah.append(item)
    return wadah

print(tambah(1), tambah(2))

Kode pemula vs kode rapi

Jangan pakai list sebagai nilai default

Nilai default dibuat sekali saja saat fungsi didefinisikan. List default akhirnya dipakai bersama oleh setiap panggilan, sehingga isi keranjang pembeli sebelumnya ikut terbawa. Pakai None lalu buat list baru di dalam fungsi.

KODE PEMULA
def tambah(barang, keranjang=[]):
    keranjang.append(barang)
    return keranjang

print(tambah("kopi"))
print(tambah("teh"))
KODE RAPI (BEST PRACTICE)
def tambah(barang, keranjang=None):
    if keranjang is None:
        keranjang = []
    keranjang.append(barang)
    return keranjang

print(tambah("kopi"))
print(tambah("teh"))

Poin penting

  • Parameter default ditulis setelah parameter wajib.
  • Keyword argument membuat pemanggilan jelas.
  • *args → tuple, **kwargs → dict.
  • Hindari default yang bisa diubah (list/dict).

Cek pemahaman

<code>def f(*args)</code>, isi args saat <code>f(1, 2, 3)</code>?

Jawaban: (1, 2, 3)

*args dikumpulkan menjadi tuple.

Kenapa <code>def f(x=[])</code> berbahaya?

Jawaban: List default dipakai bersama semua pemanggilan

Default dievaluasi sekali saat fungsi didefinisikan.
