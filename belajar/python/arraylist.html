ArrayList

Buka versi interaktif

Array berukuran tetap sering merepotkan. ArrayList adalah daftar yang bisa tumbuh dan menyusut sendiri. Kamu bisa add, remove, get, dan set tanpa memikirkan ukuran. List bawaan Python sudah bekerja seperti ini sejak awal.

ArrayList memakai generics: ArrayList<String> berarti daftar yang hanya berisi String. Generics hanya menerima tipe objek, jadi untuk angka kamu memakai wrapper class Integer, Double, dan seterusnya. Java mengubah int ke Integer secara otomatis (autoboxing).

Menyisip atau menghapus di tengah membuat elemen di belakangnya bergeser. Akibatnya, menghapus elemen sambil berjalan maju dengan loop indeks bisa melewatkan elemen. Solusinya: jalan mundur dari belakang, atau buat list baru.

PYTHON
def main():
    buah = []
    buah.append("apel")
    buah.append("jeruk")
    buah.insert(1, "mangga")     # sisip di indeks 1
    print(buah)                  # ['apel', 'mangga', 'jeruk']

    buah.pop(0)                  # sisanya bergeser ke kiri
    print(buah[0] + ", ukuran", len(buah))

    angka = [i * i for i in range(1, 6)]
    print(angka)

main()
KELUARAN
['apel', 'mangga', 'jeruk']
mangga, ukuran 2
[1, 4, 9, 16, 25]

Poin penting

  • list.size() di Java, len(lst) di Python.
  • remove(1) menghapus indeks 1. remove("a") menghapus nilai "a".
  • contains / in untuk mengecek keberadaan.
  • Python: list comprehension [x * 2 for x in a] membuat list baru dengan ringkas.

Cek pemahaman

List berisi [a, b, c, d]. Setelah remove(1), isinya menjadi...

Jawaban: [a, c, d]

Indeks 1 adalah b. Setelah dihapus, c dan d bergeser ke kiri.

Mengapa ArrayList<int> tidak boleh di Java?

Jawaban: Generics hanya menerima tipe objek, jadi pakai Integer

Tipe primitif bukan objek. Wrapper class Integer membungkusnya.

Kerjakan latihannya di aplikasi

Sebelumnya: Referensi (dua nama, satu array)

Berikutnya: add, sisip, hapus
