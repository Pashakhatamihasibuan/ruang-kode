deque, heapq & bisect: struktur data siap pakai

Buka versi interaktif

Setelah memahami cara kerja struktur data dari nol, saatnya memakai versi siap pakai yang cepat dari pustaka standar. collections.deque adalah antrean dua ujung dengan operasi tambah dan ambil di ujung mana pun dalam waktu O(1). Jangan memakai list.pop(0) untuk antrean karena O(n).

heapq mengubah list biasa menjadi min-heap: elemen terkecil selalu di indeks 0. Cocok untuk priority queue, misalnya memproses pesanan paling mendesak atau mencari k nilai terbesar dengan nlargest.

bisect melakukan binary search pada list yang sudah urut, untuk mencari posisi sisip atau menyisipkan sambil menjaga urutan.

PYTHON
from collections import deque
import heapq, bisect

antre = deque(["Ani", "Bayu"])
antre.append("Citra")
antre.appendleft("VIP")
print(antre.popleft(), list(antre))

riwayat = deque(maxlen=3)
for hal in ["beranda", "produk", "keranjang", "bayar"]:
    riwayat.append(hal)
print(list(riwayat))

tugas = []
heapq.heappush(tugas, (2, "balas email"))
heapq.heappush(tugas, (1, "server mati"))
heapq.heappush(tugas, (3, "rapat"))
print(heapq.heappop(tugas))
print(heapq.nlargest(2, [70, 95, 88, 60, 91]))

nilai = [55, 70, 85, 90]
print(bisect.bisect_left(nilai, 80))
bisect.insort(nilai, 80)
print(nilai)

Poin penting

  • deque untuk antrean, bukan list.pop(0).
  • deque(maxlen=n) menyimpan n item terakhir.
  • heapq = min-heap; simpan tuple (prioritas, data).
  • bisect = binary search pada list urut.

Cek pemahaman

Kenapa <code>list.pop(0)</code> lambat untuk antrean besar?

Jawaban: Semua elemen digeser: O(n)

deque.popleft() O(1).

<code>heapq.heappop</code> mengambil elemen?

Jawaban: Terkecil

heapq adalah min-heap.
