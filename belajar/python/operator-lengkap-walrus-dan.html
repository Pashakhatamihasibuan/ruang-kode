Operator lengkap: //, **, walrus, dan @

Buka versi interaktif

Selain + - * /, Python punya // (pembagian bulat ke bawah), % (sisa bagi), dan ** (pangkat). Ingat, / di Python 3 selalu menghasilkan float: 7 / 2 = 3.5.

Operator perbandingan bisa dirangkai seperti di matematika: 0 <= nilai <= 100. Operator identitas is memeriksa apakah dua nama menunjuk objek yang sama, sedangkan == memeriksa isinya. Pakai is hanya untuk None. Operator keanggotaan in memeriksa apakah elemen ada di dalam koleksi.

Operator walrus := (Python 3.8) memberi nilai sekaligus memakainya dalam ekspresi. Operator @ adalah perkalian matriks, dipakai pustaka seperti NumPy; kelas buatanmu bisa mendukungnya dengan method __matmul__.

PYTHON
print(7 / 2, 7 // 2, 7 % 2, 2 ** 10)
print(-7 // 2)              # dibulatkan ke bawah, bukan ke nol

nilai = 85
print(0 <= nilai <= 100)
print("a" in "kata", 3 in [1, 2, 3])

data = None
print(data is None)

skor = [70, 95, 88]
if (n := len(skor)) > 2:
    print(f"ada {n} skor")

class Matriks:
    def __init__(self, baris):
        self.b = baris
    def __matmul__(self, lain):
        return Matriks([[sum(a * b for a, b in zip(r, k)) for k in zip(*lain.b)] for r in self.b])

A = Matriks([[1, 2], [3, 4]])
B = Matriks([[5, 6], [7, 8]])
print((A @ B).b)

Kode pemula vs kode rapi

Perbandingan berantai

Python membaca 0 <= nilai <= 100 seperti matematika. Lebih pendek dan nilai di tengah hanya dihitung sekali.

KODE PEMULA
nilai = 87
if nilai >= 0 and nilai <= 100:
    print("valid")
KODE RAPI (BEST PRACTICE)
nilai = 87
if 0 <= nilai <= 100:
    print("valid")
KELUARAN KEDUANYA
valid

Poin penting

  • / selalu float, // bulat ke bawah.
  • Perbandingan berantai: a < b < c.
  • is untuk None, == untuk isi.
  • @ = perkalian matriks lewat __matmul__.
