unittest, doctest & tox

Buka versi interaktif

unittest (PyUnit) adalah framework tes bawaan Python, bergaya kelas seperti JUnit. Tes ditulis sebagai method di kelas turunan unittest.TestCase dan memakai method seperti assertEqual. pytest juga bisa menjalankan tes unittest, jadi keduanya bisa hidup berdampingan.

doctest menjalankan contoh yang ditulis di dalam docstring dengan format sesi interaktif (>>>). Ini menjaga contoh di dokumentasi selalu benar.

tox menjalankan rangkaian tes di beberapa lingkungan sekaligus, misalnya Python 3.11, 3.12, dan 3.13, masing-masing dalam virtual environment sendiri. Pustaka yang dipakai banyak orang memakai tox atau nox untuk memastikan kompatibilitas.

PYTHON
import unittest

def rupiah(n):
    """Format angka menjadi rupiah.

    >>> rupiah(1500000)
    'Rp1.500.000'
    >>> rupiah(0)
    'Rp0'
    """
    return f"Rp{n:,}".replace(",", ".")

class TesRupiah(unittest.TestCase):
    def test_ribuan(self):
        self.assertEqual(rupiah(85000), "Rp85.000")
    def test_tipe(self):
        self.assertIsInstance(rupiah(1), str)

if __name__ == "__main__":
    import doctest, io, contextlib
    hasil = doctest.testmod()
    print("doctest gagal:", hasil.failed, "dari", hasil.attempted)
    buf = io.StringIO()
    with contextlib.redirect_stderr(buf):
        r = unittest.main(exit=False).result
    print("unittest jalan:", r.testsRun, "gagal:", len(r.failures))
KELUARAN
doctest gagal: 0 dari 2
unittest jalan: 2 gagal: 0

Poin penting

  • unittest: bawaan, berbasis kelas TestCase.
  • doctest: contoh di docstring ikut diuji.
  • tox: menguji di banyak versi Python.
  • pytest bisa menjalankan tes unittest dan doctest.
