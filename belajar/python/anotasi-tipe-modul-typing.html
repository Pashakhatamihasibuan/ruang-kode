Anotasi tipe & modul typing

Buka versi interaktif

Python tetap dinamis, tetapi sejak 3.5 kamu bisa menambahkan anotasi tipe: def total(harga: list[int]) -> int. Anotasi tidak memengaruhi cara program berjalan. Gunanya sebagai dokumentasi, membantu IDE memberi saran, dan dibaca oleh pemeriksa tipe untuk menemukan bug sebelum program dijalankan.

Tipe bawaan bisa langsung dipakai: int, str, list[str], dict[str, int], tuple[int, int]. Nilai yang mungkin None ditulis str | None. Modul typing menambah alat seperti Callable, TypedDict, Literal, Protocol, dan TypeVar untuk fungsi generik.

Mulailah dari tanda tangan fungsi publik. Tidak perlu menganotasi setiap variabel lokal, karena pemeriksa tipe bisa menebaknya.

PYTHON
from typing import Callable, Literal, TypedDict, TypeVar

T = TypeVar("T")

class Produk(TypedDict):
    nama: str
    harga: int

Status = Literal["baru", "dikirim", "selesai"]

def termahal(data: list[Produk]) -> Produk | None:
    return max(data, key=lambda p: p["harga"]) if data else None

def terapkan(f: Callable[[int], int], nilai: list[int]) -> list[int]:
    return [f(x) for x in nilai]

def pertama(xs: list[T]) -> T:
    return xs[0]

def ubah_status(s: Status) -> str:
    return s.upper()

katalog: list[Produk] = [{"nama": "Kopi", "harga": 85000}, {"nama": "Teh", "harga": 25000}]
print(termahal(katalog))
print(terapkan(lambda x: x * 2, [1, 2, 3]))
print(pertama(["a", "b"]), ubah_status("dikirim"))
print(termahal.__annotations__["return"])

Poin penting

  • Anotasi tidak dicek saat runtime; alat statis yang memeriksanya.
  • X | None untuk nilai opsional.
  • TypedDict untuk dict berstruktur tetap.
  • TypeVar untuk fungsi generik.
