Logika & Perulangan Tak Pasti

Buka versi interaktif

Perulangan tak pasti dipakai ketika jumlah putaran belum diketahui, misalnya "ulangi sampai pengguna mengetik 0". Bentuknya while (kondisi). Pastikan sesuatu di dalam loop mengubah kondisi, atau loop akan berjalan selamanya.

Kondisi bisa digabung dengan logika boolean: AND (and), OR (or), dan NOT (not). and dan or memakai short-circuit: jika bagian kiri sudah menentukan hasil, bagian kanan tidak dievaluasi.

Ada dua pola klasik. Fencepost: untuk mencetak 1, 2, 3 kamu butuh 3 angka tapi hanya 2 koma, jadi satu bagian ditaruh di luar loop. Sentinel: nilai khusus (misalnya -1) yang menandai akhir masukan. Bilangan acak dibuat dengan Random atau modul random.

PYTHON
import random

def main():
    lemparan = 0
    dadu = 0
    while dadu != 6:                    # perulangan tak pasti
        dadu = random.randint(1, 6)     # 1..6
        lemparan += 1
        print("Dapat", dadu)
    print("Butuh", lemparan, "lemparan")

    hujan, punya_payung = True, False
    if hujan and not punya_payung:
        print("Tunggu reda dulu")

main()

(angka dadu acak, hasilmu bisa berbeda)

Poin penting

  • while mengecek kondisi sebelum setiap putaran. Bisa saja tidak pernah masuk.
  • Python tidak punya do/while. Polanya: while True: lalu break saat syaratnya terpenuhi.
  • not (a and b) sama dengan not a or not b (hukum De Morgan).
  • random.randint(1, 6) memberi angka 1 sampai 6, termasuk 6.
