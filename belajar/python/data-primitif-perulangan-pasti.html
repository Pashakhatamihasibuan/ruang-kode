Data Primitif & Perulangan Pasti

Buka versi interaktif

Data disimpan di variabel. Python menebak tipe data sendiri dari nilai yang diberikan: int untuk bilangan bulat, float untuk pecahan, bool untuk benar/salah (True/False), dan str untuk teks.

Ekspresi seperti 7 / 2 menghasilkan 3.5, karena di Python / selalu menghasilkan pecahan. Untuk pembagian bulat pakai //, hasilnya 3. Operator % memberi sisa bagi dan sering dipakai untuk cek genap/ganjil.

Perulangan pasti dipakai saat jumlah pengulangan sudah diketahui. Python memakai for i in range(awal, akhir), dengan akhir tidak ikut dihitung. Loop di dalam loop (nested loop) cocok untuk pola dua dimensi seperti segitiga bintang.

PYTHON
TINGGI = 4  # konstanta (konvensi huruf besar)

def main():
    a, b = 7, 2
    print(a // b)   # 3  (pembagian bulat)
    print(a % b)    # 1  (sisa bagi)
    print(a / b)    # 3.5

    for baris in range(1, TINGGI + 1):
        for k in range(baris):
            print("*", end="")
        print()

main()
KELUARAN

1
3.5

Poin penting

  • int(x), float(x), dan str(x) mengubah tipe sebuah nilai (konversi).
  • Urutan operasi: * / % dikerjakan sebelum + -.
  • range(1, 5) menghasilkan 1, 2, 3, 4.
  • Konstanta ditulis HURUF_BESAR, misalnya MAKS = 10. Python tidak melarang mengubahnya; ini kesepakatan antarprogrammer.

Cek pemahaman

Berapa hasil 7 % 3?

Jawaban: 1

7 dibagi 3 adalah 2 sisa 1. Operator % mengambil sisanya.

Nilai apa saja yang dihasilkan range(1, 5)?

Jawaban: 1, 2, 3, 4

Batas akhir range tidak ikut. range(1, 5) berhenti sebelum 5.
