Percabangan membuat program memilih. if menjalankan blok hanya bila kondisinya benar. Rantai if / elif / else dicek dari atas. Begitu satu kondisi benar, sisanya dilewati.

Kondisi dibangun dari operator relasional: <, >, <=, >=, ==, !=. Urutan kondisi penting. Jika skor >= 70 dicek lebih dulu, skor 95 akan ikut mendapat C.

Bab ini juga membahas algoritma kumulatif: menyiapkan variabel penampung (misalnya total = 0) di luar loop lalu menambahkannya sedikit demi sedikit di dalam loop. Pola ini dipakai untuk jumlah, rata-rata, nilai maksimum, dan sebagainya.

PYTHON
def huruf(skor):
    if skor >= 90:
        return "A"
    elif skor >= 80:
        return "B"
    elif skor >= 70:
        return "C"
    else:
        return "D"

def main():
    total = 0                           # penampung kumulatif
    for i in range(1, 11):
        total += i
    print("Jumlah 1..10 =", total)
    print(huruf(85))

main()
KELUARAN
Jumlah 1..10 = 55
B

Poin penting

  • Gunakan if/elif bila pilihan saling eksklusif. Gunakan beberapa if terpisah bila boleh lebih dari satu.
  • Di Python, == membandingkan isi string. is memeriksa apakah dua nama menunjuk objek yang sama.
  • Variabel penampung kumulatif dideklarasikan di luar loop.
  • Fungsi boleh punya beberapa return di cabang berbeda.

Cek pemahaman

Dengan fungsi huruf di atas, berapa hasil huruf(80)?

Jawaban: B

80 >= 90 salah, 80 >= 80 benar, jadi B. Kondisi berikutnya tidak dicek lagi.

Di Python, cara yang benar untuk membandingkan isi dua string adalah...

Jawaban: a == b

== membandingkan isi string karakter demi karakter. a = b adalah pengisian, bukan perbandingan.
