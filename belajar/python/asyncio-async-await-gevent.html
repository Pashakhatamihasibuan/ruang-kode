asyncio, async/await & gevent

Buka versi interaktif

asyncio menjalankan banyak tugas I/O secara bergantian dalam satu thread, dikendalikan oleh event loop. Fungsi yang ditulis dengan async def disebut coroutine. Di dalamnya, await berarti "tunggu hasil ini, dan selama menunggu, silakan jalankan tugas lain".

asyncio.gather menjalankan beberapa coroutine bersamaan dan mengumpulkan hasilnya. Karena hanya satu thread, tidak ada race condition di antara titik await. Ini membuat asyncio sangat efisien untuk server yang melayani ribuan koneksi.

Syaratnya, pustaka yang dipakai juga harus mendukung async, misalnya httpx atau aiohttp untuk HTTP. gevent adalah pendekatan lama: ia "menambal" pustaka standar agar kode sinkron biasa otomatis bergantian seperti async (greenlet).

PYTHON
import asyncio, time

async def ambil(nama, detik):
    print(f"mulai {nama}")
    await asyncio.sleep(detik)        # menunggu tanpa memblokir
    print(f"selesai {nama}")
    return f"{nama}:{detik}s"

async def main():
    mulai = time.perf_counter()
    hasil = await asyncio.gather(
        ambil("cuaca", 0.3),
        ambil("kurs", 0.1),
        ambil("berita", 0.2),
    )
    print(hasil)
    print("total sekitar", round(time.perf_counter() - mulai, 1), "detik")

asyncio.run(main())

Poin penting

  • async def membuat coroutine; await menyerahkan giliran.
  • Event loop menjalankan tugas bergantian dalam satu thread.
  • asyncio.gather untuk menjalankan bersamaan.
  • Ringkasan: CPU berat → multiprocessing; I/O banyak → asyncio atau thread.
