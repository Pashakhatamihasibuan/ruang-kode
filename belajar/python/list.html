List

Buka versi interaktif

List menyimpan banyak nilai di bawah satu nama. Setiap elemen punya indeks mulai dari 0. List 5 elemen punya indeks 0 sampai 4. Mengakses indeks 5 menghasilkan IndexError.

Pola paling umum adalah traversal: mengunjungi setiap elemen dengan loop untuk mencari maksimum, menjumlah, atau menghitung. for x in a cocok bila kamu tidak butuh indeksnya.

List adalah objek, jadi variabelnya menyimpan referensi (alamat), bukan isinya. b = a tidak menyalin isi. Keduanya menunjuk list yang sama, sehingga perubahan lewat b juga terlihat di a. Hal yang sama berlaku saat list dikirim sebagai parameter.

PYTHON
def main():
    a = [3, 8, 1, 9, 4]
    print(a[0])       # 3
    print(len(a))     # 5

    maks = a[0]
    for x in a:
        if x > maks:
            maks = x
    print("Maks:", maks)

    b = a             # b menunjuk list yang SAMA
    b[0] = 99
    print(a)

main()
KELUARAN
3
5
Maks: 9
[99, 8, 1, 9, 4]

Poin penting

  • List bisa tumbuh: a.append(x) menambah elemen di akhir.
  • Python mengizinkan indeks negatif: a[-1] adalah elemen terakhir.
  • Cetak list langsung dengan print(a).
  • List 2D: m = [[0] * 4 for _ in range(3)].

Cek pemahaman

List Python berisi 5 elemen. Berapa indeks elemen terakhir?

Jawaban: 4

Indeks mulai dari 0, jadi elemen terakhir ada di len(a) - 1. Python juga menerima a[-1].

Setelah b = a; b[0] = 99;, berapa nilai a[0]?

Jawaban: 99

a dan b adalah dua nama untuk array yang sama.
