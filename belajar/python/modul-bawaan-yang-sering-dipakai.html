Modul bawaan yang sering dipakai

Buka versi interaktif

Python dijuluki "batteries included" karena pustaka standarnya sangat lengkap. Sebelum memasang paket dari luar, cek dulu apakah modul bawaan sudah cukup.

Yang paling sering dipakai: math (fungsi matematika), random (angka dan pilihan acak), datetime (tanggal dan waktu), json (membaca dan menulis JSON), os dan sys (sistem operasi dan interpreter), collections (Counter, deque, defaultdict), itertools (kombinasi dan permutasi), statistics, serta csv.

Paket pihak ketiga yang populer: requests (HTTP), pandas (analisis data), numpy (komputasi angka), matplotlib (grafik), dan pytest (testing). Semuanya dipasang dengan pip.

PYTHON
import math, random, json, statistics, itertools
from datetime import date, timedelta

print(math.sqrt(144), math.pi.__round__(4), math.factorial(5))

random.seed(42)
print(random.randint(1, 6), random.choice(["kopi", "teh", "jus"]))

hari_ini = date(2024, 10, 28)
print(hari_ini + timedelta(days=5), hari_ini.strftime("%d/%m/%Y"))

data = {"nama": "Rina", "nilai": [80, 92]}
teks = json.dumps(data)
print(teks, json.loads(teks)["nilai"][1])

print(statistics.mean([80, 92, 75]), statistics.median([80, 92, 75]))
print(list(itertools.combinations("ABC", 2)))

Kode pemula vs kode rapi

Memeriksa "ada yang" dan "semuanya"

any dan all menggantikan loop dengan variabel penanda. Keduanya berhenti begitu jawabannya sudah pasti.

KODE PEMULA
stok = [5, 0, 12, 7]
ada_habis = False
for s in stok:
    if s == 0:
        ada_habis = True
        break
print(ada_habis)
KODE RAPI (BEST PRACTICE)
stok = [5, 0, 12, 7]
print(any(s == 0 for s in stok))
KELUARAN KEDUANYA
True

Poin penting

  • Cek pustaka standar sebelum memasang paket.
  • json.dumps/loads: dict ↔ teks JSON.
  • random.seed membuat hasil acak bisa diulang.
  • datetime.timedelta untuk menambah hari.
