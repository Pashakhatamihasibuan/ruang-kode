Pencarian & Pengurutan

Buka versi interaktif

Pencarian linear memeriksa elemen satu per satu dari depan. Mudah, tapi untuk sejuta data bisa butuh sejuta langkah. Binary search jauh lebih cepat: lihat elemen tengah, lalu buang separuh data yang pasti tidak berisi target. Syaratnya, data harus sudah terurut.

Kecepatan algoritma diukur dengan notasi Big-O, yaitu bagaimana jumlah langkah tumbuh seiring jumlah data n. Linear search O(n), binary search O(log n). Untuk sejuta data, log₂ hanya sekitar 20 langkah.

Selection sort mencari elemen terkecil lalu menukarnya ke depan, diulang untuk setiap posisi. Hasilnya O(n²). Merge sort membagi data menjadi dua, mengurutkan masing-masing secara rekursif, lalu menggabungkannya, dengan hasil O(n log n). Dalam praktik, pakai pengurutan bawaan bahasa.

PYTHON
def cari_biner(a, target):
    # data HARUS sudah terurut
    kiri, kanan = 0, len(a) - 1
    while kiri <= kanan:
        tengah = (kiri + kanan) // 2
        if a[tengah] == target:
            return tengah
        elif a[tengah] < target:
            kiri = tengah + 1
        else:
            kanan = tengah - 1
    return -1   # tidak ditemukan

def selection_sort(a):
    for i in range(len(a) - 1):
        m = i
        for j in range(i + 1, len(a)):
            if a[j] < a[m]:
                m = j
        a[i], a[m] = a[m], a[i]   # tukar

Poin penting

  • Binary search pada data acak memberi jawaban yang salah.
  • O(1) konstan, O(log n) logaritmik, O(n) linear, O(n²) kuadratik.
  • Arrays.sort dan sorted() sudah sangat dioptimalkan.
  • Python bisa menukar tanpa variabel bantu: a, b = b, a.
