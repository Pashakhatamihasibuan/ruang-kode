Django: aplikasi web lengkap

Buka versi interaktif

Django memakai pola MTV: Model (struktur data dan tabel database), Template (tampilan HTML), dan View (logika yang menerima request dan mengembalikan response). URL dipetakan ke view lewat file urls.py.

Model Django adalah ORM: kelas Python yang otomatis menjadi tabel. Perintah makemigrations dan migrate membuat dan memperbarui tabel sesuai model. Query ditulis dengan gaya Python: Produk.objects.filter(harga__gt=50000).

Daftarkan model di admin.py, dan kamu langsung mendapat panel admin untuk menambah, mengubah, dan menghapus data. Untuk REST API, tim biasanya menambahkan Django REST Framework.

PYTHON
# models.py
from django.db import models

class Produk(models.Model):
    nama = models.CharField(max_length=100)
    kategori = models.CharField(max_length=50)
    harga = models.PositiveIntegerField()

    def __str__(self):
        return self.nama

# views.py
from django.shortcuts import render
from .models import Produk

def daftar_mahal(request):
    produk = Produk.objects.filter(harga__gt=50000).order_by("-harga")
    return render(request, "toko/daftar.html", {"produk": produk})

# urls.py
from django.urls import path
from . import views
urlpatterns = [path("mahal/", views.daftar_mahal)]

# admin.py
from django.contrib import admin
admin.site.register(Produk)

# Terminal
# django-admin startproject toko_site
# python manage.py makemigrations && python manage.py migrate
# python manage.py createsuperuser
# python manage.py runserver      -> http://127.0.0.1:8000/admin

Poin penting

  • MTV: Model, Template, View.
  • ORM: Model.objects.filter(...).
  • Migrasi menjaga tabel sesuai model.
  • Panel admin otomatis dari model.
