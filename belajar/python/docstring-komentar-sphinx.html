Docstring, komentar & Sphinx

Buka versi interaktif

Komentar (#) menjelaskan kenapa sebuah kode ditulis begitu. Docstring adalah string di baris pertama fungsi, kelas, atau modul yang menjelaskan apa kegunaannya dan cara memakainya. Docstring bisa dibaca saat program berjalan lewat help(fungsi) atau fungsi.__doc__.

Ada beberapa gaya penulisan docstring yang populer: gaya Google, NumPy, dan reStructuredText. Pilih satu dan konsisten. Isi minimal: ringkasan satu baris, penjelasan parameter, nilai kembali, dan exception yang mungkin dilempar.

Sphinx mengubah docstring menjadi situs dokumentasi lengkap, seperti dokumentasi resmi Python dan banyak pustaka besar. Ekstensi autodoc mengambil docstring langsung dari kodemu.

PYTHON
def hitung_ongkir(berat_kg: float, kota: str) -> int:
    """Menghitung ongkos kirim dalam rupiah.

    Tarif dasar Rp10.000 per kg, ditambah biaya luar Jawa.

    Args:
        berat_kg: Berat paket dalam kilogram, harus lebih dari 0.
        kota: Kota tujuan.

    Returns:
        Ongkos kirim yang dibulatkan ke atas per kilogram.

    Raises:
        ValueError: Jika berat tidak positif.
    """
    if berat_kg <= 0:
        raise ValueError("berat harus positif")
    # dibulatkan ke atas karena kurir menghitung per kg penuh
    kg = -(-berat_kg // 1)
    tambahan = 15000 if kota not in {"Jakarta", "Bandung", "Surabaya"} else 0
    return int(kg * 10000 + tambahan)

print(hitung_ongkir(2.3, "Medan"))
print(hitung_ongkir.__doc__.splitlines()[0])

Poin penting

  • Komentar = kenapa; docstring = apa dan bagaimana memakai.
  • Docstring diakses lewat help() atau __doc__.
  • Pilih satu gaya: Google, NumPy, atau reST.
  • Sphinx + autodoc = situs dokumentasi dari docstring.
