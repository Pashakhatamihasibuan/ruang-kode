Scope variabel: aturan LEGB

Buka versi interaktif

Saat Python mencari sebuah nama, ia memeriksa empat tempat secara berurutan: Local (di dalam fungsi), Enclosing (fungsi luar yang membungkus), Global (tingkat file), lalu Built-in (seperti print, len). Urutan ini disebut aturan LEGB.

Memberi nilai pada sebuah nama di dalam fungsi otomatis membuatnya variabel lokal. Jadi jika kamu ingin mengubah variabel global, tulis global nama; untuk variabel fungsi luar, tulis nonlocal nama. Gunakan keduanya seperlunya, karena variabel global membuat program sulit dilacak.

Fungsi di dalam fungsi yang mengingat variabel luarnya disebut closure. Ini dasar dari decorator yang akan kamu pelajari nanti.

PYTHON
pajak = 0.11                     # global

def harga_akhir(harga):
    diskon = 0.05                # local
    return harga * (1 - diskon) * (1 + pajak)

print(round(harga_akhir(100000)))

hitungan = 0
def klik():
    global hitungan
    hitungan += 1

klik(); klik()
print(hitungan)

def buat_penghitung():
    n = 0                        # enclosing
    def tambah():
        nonlocal n
        n += 1
        return n
    return tambah

c = buat_penghitung()
c(); c()
print(c())

def rusak():
    try:
        hitungan += 1            # dianggap lokal, belum ada nilainya
    except UnboundLocalError as e:
        print("UnboundLocalError")

rusak()

Poin penting

  • Urutan pencarian nama: Local → Enclosing → Global → Built-in.
  • Assignment di dalam fungsi membuat variabel lokal.
  • global/nonlocal untuk mengubah variabel di luar.
  • Closure: fungsi dalam yang mengingat variabel fungsi luar.
