Semua jenis perulangan: for, while, do-while, for-each, break, continue

Buka versi interaktif

Perulangan (loop) menyuruh komputer mengulang sekelompok perintah tanpa kita menulis ulang. Semua jenis loop punya tiga bagian yang sama: nilai awal, kondisi kapan terus mengulang, dan perubahan di setiap putaran agar suatu saat berhenti. Bedanya ada pada kapan kondisi dicek dan apa yang diulang.

for dipakai ketika jumlah putaran sudah pasti, misalnya mencetak angka 1 sampai 3. Nilai awal, kondisi, dan perubahan ditulis dalam satu baris sehingga mudah dibaca.

while mengecek kondisi sebelum badan dijalankan. Jika kondisinya sudah salah sejak awal, badan tidak pernah dijalankan sama sekali (0 putaran). Cocok saat kita tidak tahu berapa kali harus mengulang.

do-while menjalankan badan dulu, baru mengecek kondisi di akhir. Akibatnya badan pasti jalan minimal sekali. Lihat contoh: x = 10 dan kondisinya x < 5 sudah salah, tetapi barisnya tetap tercetak satu kali. Inilah perbedaan terpenting antara while dan do-while.

for-each menelusuri setiap isi koleksi (array atau list) satu per satu tanpa mengurus indeks, sehingga tidak mungkin salah indeks. Loop bersarang adalah loop di dalam loop: untuk setiap putaran loop luar, loop dalam berjalan sampai selesai, seperti baris dan kolom tabel perkalian.

break menghentikan loop saat itu juga, sedangkan continue hanya melewati sisa badan pada putaran ini lalu lanjut ke putaran berikutnya. Buka visual 3D di bawah, pilih jenis loop di panel Eksperimen, dan bandingkan sendiri jalannya.

Catatan Python: tidak ada do-while. Polanya ditiru dengan while True: lalu break di akhir badan. for di Python sebenarnya sudah for-each: ia menelusuri isi range(), list, atau string.

PYTHON
# 1. for: jumlah putaran sudah pasti
for i in range(1, 4):
    print("for: i =", i)

# 2. while: kondisi dicek DULU, bisa 0 kali
n = 3
while n > 0:
    print("while: n =", n)
    n -= 1

# 3. do-while: Python tidak punya, tiru dengan while True + break
x = 10
while True:
    print("do-while: x =", x, "(tetap jalan sekali)")
    x += 1
    if not x < 5:
        break

# 4. for-each: for di Python memang menelusuri isi koleksi
buah = ["apel", "jeruk", "mangga"]
for b in buah:
    print("for-each:", b)

# 5. bersarang: loop di dalam loop
for baris in range(1, 3):
    isi = [str(baris * kolom) for kolom in range(1, 4)]
    print("nested:", " ".join(isi))

# 6. break: keluar dari loop lebih awal
hasil = []
for i in range(1, 11):
    if i == 4:
        break
    hasil.append(str(i))
print("break:", " ".join(hasil))

# 7. continue: lewati sisa badan untuk putaran ini saja
hasil = []
for i in range(1, 7):
    if i % 2 == 0:
        continue
    hasil.append(str(i))
print("continue:", " ".join(hasil))

Poin penting

  • for: jumlah putaran pasti; while: berhenti karena keadaan.
  • while mengecek kondisi di awal (bisa 0 kali), do-while di akhir (minimal 1 kali).
  • for-each membaca setiap isi koleksi tanpa indeks.
  • break keluar dari loop; continue melompat ke putaran berikutnya.
