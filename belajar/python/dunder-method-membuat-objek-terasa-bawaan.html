Dunder method: membuat objek terasa bawaan

Buka versi interaktif

Dunder method (double underscore) adalah method khusus dengan nama diapit dua garis bawah, seperti __init__. Python memanggilnya secara otomatis untuk operasi tertentu. Dengan mengisinya, objek buatanmu bisa dipakai seperti tipe bawaan.

__str__ menentukan tampilan untuk print, __repr__ untuk tampilan debug. __len__ membuat len(obj) bekerja, __getitem__ membuat obj[i] bekerja, dan __iter__ membuat objek bisa dipakai di for.

Operator juga punya dunder: __add__ untuk +, __eq__ untuk ==, __lt__ untuk < (yang juga membuat sorted bekerja). Teknik ini disebut operator overloading.

PYTHON
class Uang:
    def __init__(self, rupiah):
        self.rupiah = rupiah
    def __str__(self):
        return f"Rp{self.rupiah:,}".replace(",", ".")
    def __repr__(self):
        return f"Uang({self.rupiah})"
    def __add__(self, lain):
        return Uang(self.rupiah + lain.rupiah)
    def __eq__(self, lain):
        return self.rupiah == lain.rupiah
    def __lt__(self, lain):
        return self.rupiah < lain.rupiah

class Keranjang:
    def __init__(self):
        self.isi = []
    def tambah(self, nama, harga):
        self.isi.append((nama, Uang(harga)))
    def __len__(self):
        return len(self.isi)
    def __getitem__(self, i):
        return self.isi[i]
    def __iter__(self):
        return iter(self.isi)

k = Keranjang()
k.tambah("kopi", 85000)
k.tambah("teh", 25000)
print(len(k), k[1][0])
total = Uang(0)
for nama, harga in k:
    total = total + harga
print(total)
print(sorted([Uang(5), Uang(2), Uang(9)]))
print(Uang(100) == Uang(100))

Poin penting

  • __str__ untuk pengguna, __repr__ untuk programmer.
  • __len__, __getitem__, __iter__ membuat objek mirip koleksi.
  • __add__, __eq__, __lt__ untuk operator.
  • Jangan memanggil dunder langsung; biarkan Python yang memanggil.
