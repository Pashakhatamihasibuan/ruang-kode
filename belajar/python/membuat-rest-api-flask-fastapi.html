Membuat REST API: Flask & FastAPI

Buka versi interaktif

Flask menghubungkan URL ke fungsi dengan decorator @app.route (atau @app.get di versi baru). Fungsi mengembalikan dict, dan Flask mengubahnya menjadi JSON.

FastAPI tampak mirip, tetapi memanfaatkan type hint secara penuh. Parameter id: int di fungsi otomatis divalidasi dari URL. Body request dideklarasikan sebagai model Pydantic. FastAPI juga membuat dokumentasi interaktif di /docs secara otomatis.

FastAPI mendukung async def sehingga satu server bisa melayani banyak request yang sedang menunggu database atau API lain. Jalankan dengan server ASGI seperti uvicorn.

PYTHON
# ===== Flask =====
from flask import Flask
app = Flask(__name__)
PRODUK = {1: {"nama": "Kopi Gayo", "harga": 85000}}

@app.get("/produk/<int:pid>")
def detail(pid):
    p = PRODUK.get(pid)
    return p if p else ({"error": "tidak ada"}, 404)
# flask --app app run

# ===== FastAPI =====
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

api = FastAPI()

class ProdukBaru(BaseModel):
    nama: str
    harga: int

@api.get("/produk/{pid}")
async def ambil(pid: int):
    if pid not in PRODUK:
        raise HTTPException(status_code=404, detail="tidak ada")
    return PRODUK[pid]

@api.post("/produk", status_code=201)
async def tambah(p: ProdukBaru):
    pid = max(PRODUK) + 1
    PRODUK[pid] = p.model_dump()
    return {"id": pid, **PRODUK[pid]}
# uvicorn app:api --reload   -> dokumentasi di http://127.0.0.1:8000/docs

Poin penting

  • Route = pasangan method HTTP + URL → fungsi.
  • FastAPI memvalidasi parameter dari type hint.
  • Body request = model Pydantic.
  • Kode status: 200 OK, 201 Created, 404 Not Found.
