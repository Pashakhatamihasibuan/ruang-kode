Context manager: with

Buka versi interaktif

Sumber daya seperti file, koneksi database, atau kunci (lock) harus selalu ditutup, bahkan ketika terjadi error. Pernyataan with menjamin hal itu: saat blok selesai, dengan cara apa pun, sumber daya dibereskan otomatis.

Objek yang bisa dipakai dengan with disebut context manager. Ia punya method __enter__ (dijalankan saat masuk) dan __exit__ (dijalankan saat keluar). Cara lebih singkat untuk membuatnya adalah dekorator @contextmanager dari modul contextlib: kode sebelum yield adalah persiapan, sesudahnya adalah pembersihan.

Kamu bisa membuka beberapa context manager sekaligus dalam satu with, misalnya membaca satu file dan menulis ke file lain.

PYTHON
from contextlib import contextmanager
import time

with open("catatan.txt", "w") as f:
    f.write("baris 1\nbaris 2\n")
print(f.closed)

with open("catatan.txt") as sumber, open("salinan.txt", "w") as tujuan:
    for baris in sumber:
        tujuan.write(baris.upper())
print(open("salinan.txt").read().strip())

@contextmanager
def stopwatch(label):
    mulai = time.perf_counter()
    print(f"[{label}] mulai")
    try:
        yield
    finally:
        print(f"[{label}] selesai")

with stopwatch("hitung"):
    total = sum(range(1_000_000))
print(total)

class Kunci:
    def __enter__(self):
        print("kunci dipasang"); return self
    def __exit__(self, tipe, nilai, jejak):
        print("kunci dilepas", tipe.__name__ if tipe else "tanpa error")
        return True                          # telan exception

with Kunci():
    1 / 0
print("program lanjut")

Kode pemula vs kode rapi

Membuka file dengan with

Kalau terjadi error sebelum close(), file tetap terbuka. Blok with menutup file otomatis dalam keadaan apa pun.

KODE PEMULA
f = open("catatan.txt", "w")
f.write("belajar Python")
f.close()
f = open("catatan.txt")
print(f.read())
f.close()
KODE RAPI (BEST PRACTICE)
with open("catatan.txt", "w") as f:
    f.write("belajar Python")
with open("catatan.txt") as f:
    print(f.read())
KELUARAN KEDUANYA
belajar Python

Poin penting

  • with menjamin pembersihan meski ada error.
  • Context manager = __enter__ + __exit__.
  • @contextmanager: persiapan → yield → pembersihan.
  • __exit__ yang mengembalikan True menelan exception.
