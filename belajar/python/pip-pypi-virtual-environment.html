pip, PyPI & virtual environment

Buka versi interaktif

PyPI (Python Package Index) adalah gudang ratusan ribu paket Python. pip adalah alat bawaan untuk memasangnya: pip install requests. Daftar dependensi proyek biasanya dicatat di requirements.txt.

Masalahnya, jika semua proyek memasang paket ke tempat yang sama, versi bisa bentrok: proyek A butuh Django 4, proyek B butuh Django 5. Virtual environment (venv) memberi setiap proyek folder paketnya sendiri yang terisolasi. Aktifkan sebelum memasang paket.

uv adalah pengelola paket modern yang ditulis dengan Rust dan jauh lebih cepat dari pip. Ia bisa membuat venv, memasang paket, bahkan memasang versi Python sendiri. virtualenv adalah pendahulu venv yang masih banyak dipakai.

CONTOH
# 1. Buat dan aktifkan virtual environment
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 2. Pasang paket dari PyPI
pip install requests==2.32.3
pip list
pip freeze > requirements.txt      # catat versi persis

# 3. Di komputer lain / server
pip install -r requirements.txt

# Cara modern dengan uv (jauh lebih cepat)
uv venv
uv pip install requests
uv add pandas                      # tambah ke pyproject.toml
uv run main.py

deactivate                         # keluar dari venv

Poin penting

  • Satu proyek = satu virtual environment.
  • requirements.txt mencatat dependensi.
  • Jangan commit folder .venv ke Git.
  • uv: alternatif pip yang sangat cepat.
