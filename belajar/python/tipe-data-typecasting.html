Tipe data & typecasting

Buka versi interaktif

Python bertipe dinamis: kamu tidak menulis tipe saat membuat variabel, dan satu nama boleh menunjuk nilai bertipe berbeda di waktu lain. Tipe dasar yang paling sering dipakai: int, float, str, bool, dan None untuk "tidak ada nilai". Cek tipe dengan type(x).

Meski dinamis, Python bertipe kuat: "5" + 3 menghasilkan error, bukan "53" atau 8. Kamu harus mengubah tipe secara eksplisit dengan int(), float(), str(), atau bool(). Ini disebut typecasting.

Hati-hati: int(3.9) memotong menjadi 3, bukan membulatkan. int("3.9") malah error karena teksnya bukan bilangan bulat. Untuk pembulatan pakai round(). Nilai yang dianggap salah oleh bool(): 0, 0.0, string kosong, list kosong, dan None.

PYTHON
umur = "17"
print(type(umur))
umur = int(umur)            # str -> int
print(umur + 1)

harga = 9.99
print(int(harga))           # potong pecahan
print(round(harga))         # bulatkan
print(float("3.5") * 2)
print(str(2024) + " tahun")

print(bool(0), bool(""), bool([]), bool("0"), bool(None))

try:
    print("5" + 3)
except TypeError as e:
    print("TypeError:", e)

print(int("ff", 16))        # dari heksadesimal

Poin penting

  • Dinamis: tipe melekat pada nilai, bukan pada nama variabel.
  • Kuat: tipe berbeda tidak dicampur diam-diam.
  • int() memotong, round() membulatkan.
  • input() selalu menghasilkan str; ubah dulu sebelum dihitung.
