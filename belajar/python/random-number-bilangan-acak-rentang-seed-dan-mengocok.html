Random number: bilangan acak, rentang, seed, dan mengocok

Buka versi interaktif

Komputer tidak benar-benar melempar dadu. Ia memakai rumus yang menghasilkan deret angka yang terlihat acak, dimulai dari angka awal yang disebut seed. Karena itu namanya acak semu (pseudo-random). Bilangan acak dipakai untuk game, simulasi, mengambil sampel data, dan mengocok urutan soal kuis.

Hampir semua bahasa punya fungsi dasar yang menghasilkan desimal dari 0 sampai kurang dari 1 (0 ≤ r < 1). Angka 0 bisa keluar, tetapi angka 1 tidak pernah keluar.

Rumus bilangan bulat dari bawah sampai atas: floor(r × (atas − bawah + 1)) + bawah. Contoh dadu: r × 6 memberi 0 sampai 5,99…, floor membulatkan ke bawah menjadi 0 sampai 5, lalu +1 menjadi 1 sampai 6. Jika "+1" pada lebar rentang lupa ditulis, angka 6 tidak akan pernah keluar. Ini kesalahan off-by-one yang paling sering.

Setiap bahasa berbeda soal batas atas ikut atau tidak. randint(1, 6) di Python memasukkan 6, nextInt(6) di Java dan Dart memberi 0 sampai 5, sedangkan Random.nextInt(1, 7) di Kotlin tidak memasukkan 7. Selalu cek dokumentasinya.

Dengan seed yang sama, urutan angka acak selalu sama. Ini berguna untuk pengujian, mencari bug, dan memutar ulang permainan. Tanpa seed, biasanya seed diambil dari jam komputer sehingga hasilnya berbeda setiap kali dijalankan.

Memilih isi list secara acak sama dengan mengambil indeks acak dari 0 sampai panjang − 1. Mengocok list memakai algoritma Fisher-Yates. Untuk password, token, atau kode OTP, jangan memakai fungsi acak biasa; pakai generator kriptografis. Keluaran di bawah adalah contoh satu kali jalan, jadi angkamu akan berbeda. Coba juga visual 3D dan ubah rentang serta seed-nya.

Catatan Python: randint(a, b) memasukkan b, tetapi randrange(a, b) tidak. random.shuffle(xs) mengubah list itu sendiri dan mengembalikan None. random.sample(xs, k) memilih k isi tanpa pengulangan. Untuk keamanan, pakai modul secrets, misalnya secrets.token_hex().

PYTHON
import random

# 1. Desimal acak: 0.0 sampai KURANG DARI 1.0
r = random.random()
print(f"desimal: {r:.4f}")

# 2. Dadu 1..6: randint memasukkan KEDUA batas
print("5 dadu :", end="")
for i in range(5):
    print(" " + str(random.randint(1, 6)), end="")
print()

# 3. Rentang bebas bawah..atas
bawah, atas = 10, 20
print("10..20 :", random.randint(bawah, atas))

# 4. Lempar dadu sampai keluar angka 6
lemparan, hasil = 0, 0
while hasil != 6:
    hasil = random.randint(1, 6)
    lemparan += 1
print(f"dapat 6 setelah {lemparan} lemparan")

# 5. Memilih satu isi list dan mengocok list
menu = ["soto", "bakso", "gado-gado", "nasi goreng"]
print("menu   :", random.choice(menu))
kartu = [1, 2, 3, 4, 5]
random.shuffle(kartu)
print("kocok  :", kartu)

# 6. Seed sama menghasilkan urutan yang sama (berguna untuk pengujian)
a = random.Random(42)
b = random.Random(42)
sama = all(a.randint(0, 99) == b.randint(0, 99) for _ in range(5))
print("seed 42 dua kali, urutan sama:", sama)

Poin penting

  • Fungsi dasar memberi desimal 0 ≤ r < 1; angka 1 tidak pernah keluar.
  • Bulat bawah..atas: floor(r × (atas − bawah + 1)) + bawah.
  • Seed sama menghasilkan urutan sama; berguna untuk pengujian.
  • Untuk password dan token, pakai generator kriptografis.
