Pemrograman Fungsional

Buka versi interaktif

Pemrograman fungsional memandang program sebagai rangkaian fungsi yang mengubah data, bukan sebagai urutan perintah yang mengubah variabel. Fungsi bisa dikirim sebagai argumen, disimpan di variabel, dan dikembalikan dari fungsi lain. Fungsi seperti itu disebut higher-order function.

Lambda adalah fungsi tanpa nama yang ditulis ringkas, misalnya lambda n: n * 2. Tiga operasi utamanya: filter menyaring elemen, map mengubah setiap elemen, reduce menggabungkan semuanya menjadi satu nilai.

Python punya map, filter, functools.reduce, dan yang paling populer, list comprehension. Gaya ini mendorong fungsi murni dan data immutable, sehingga kode lebih mudah diuji dan aman dijalankan paralel.

PYTHON
from functools import reduce

angka = [1, 2, 3, 4, 5, 6]

genap = filter(lambda n: n % 2 == 0, angka)      # 2, 4, 6
kuadrat = map(lambda n: n * n, genap)            # 4, 16, 36
hasil = reduce(lambda a, b: a + b, kuadrat, 0)   # 56
print(hasil)

# gaya Pythonic: comprehension
print(sum(n * n for n in angka if n % 2 == 0))
print([s.upper() for s in ["budi", "ani", "sari"]])
KELUARAN
56
56
['BUDI', 'ANI', 'SARI']

Poin penting

  • map, filter, dan comprehension tidak mengubah list asal.
  • Fungsi bisa dikirim langsung: map(str.upper, kata) sama dengan map(lambda s: s.upper(), kata).
  • Python lebih menyukai comprehension daripada map/filter dengan lambda.
  • Hindari efek samping (mencetak, mengubah variabel luar) di dalam lambda.

Cek pemahaman

Apa hasil map "x * 10" pada [1, 2, 3]?

Jawaban: [10, 20, 30]

map mengubah setiap elemen dan menghasilkan koleksi baru dengan panjang yang sama.

Fungsi murni (pure function) adalah fungsi yang...

Jawaban: Hasilnya hanya bergantung pada input dan tanpa efek samping

Input sama selalu memberi output sama, dan tidak mengubah apa pun di luar dirinya.
