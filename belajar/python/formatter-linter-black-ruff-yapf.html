Formatter & linter: black, ruff, yapf

Buka versi interaktif

Tim profesional tidak berdebat soal spasi atau tanda kutip. Mereka memakai formatter yang merapikan kode secara otomatis dengan aturan seragam, biasanya mengikuti panduan gaya PEP 8.

black adalah formatter "tanpa kompromi" dengan sedikit pilihan konfigurasi, sehingga semua kode terlihat sama. yapf dari Google lebih bisa diatur. ruff adalah linter dan formatter super cepat berbasis Rust: ia menemukan masalah seperti import tak terpakai, variabel tidak didefinisikan, dan pola rawan bug, sekaligus bisa memformat seperti black.

Jalankan alat ini otomatis lewat pre-commit hook atau di CI, supaya kode yang masuk repositori selalu rapi.

PYTHON
# sebelum
import os,sys
def hitung( harga,diskon = 0 ):
  total=harga-harga*diskon/100
  return  total

# $ ruff check toko.py
# toko.py:1:8: F401 [*] 'os' imported but unused
# toko.py:1:11: F401 [*] 'sys' imported but unused
# $ ruff check --fix toko.py && ruff format toko.py     (atau: black toko.py)

# sesudah
def hitung(harga, diskon=0):
    total = harga - harga * diskon / 100
    return total

Poin penting

  • PEP 8 = panduan gaya resmi Python.
  • Formatter merapikan, linter mencari masalah.
  • ruff sangat cepat dan bisa menggantikan banyak alat.
  • Otomatiskan dengan pre-commit dan CI.
