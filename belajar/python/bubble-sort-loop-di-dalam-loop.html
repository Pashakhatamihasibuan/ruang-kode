Bubble sort: loop di dalam loop

Buka versi interaktif

Bubble sort mengurutkan data dengan cara paling sederhana: bandingkan dua angka yang bersebelahan, tukar jika urutannya salah, lalu geser ke pasangan berikutnya. Setelah satu putaran, angka terbesar pasti sudah "menggelembung" ke ujung kanan.

Algoritma ini memakai dua loop. Loop dalam (for) berjalan dari kiri ke kanan, jumlah pasangannya jelas. Loop luar (while) mengulang putaran selama masih ada pertukaran. Variabel penanda ada_tukar membuat program berhenti lebih awal jika data sudah terurut.

Setiap putaran, satu angka terbesar sudah di tempatnya, jadi loop dalam cukup sampai n - putaran. Detail kecil ini menghemat perbandingan yang tidak perlu.

Bubble sort lambat untuk data besar (sekitar n² perbandingan), jadi di dunia kerja kita memakai fungsi sort bawaan bahasa. Tetapi bubble sort adalah latihan terbaik untuk memahami loop bersarang, indeks, dan menukar nilai.

PYTHON
nilai = [64, 25, 12, 22, 11]
n = len(nilai)
ada_tukar = True
putaran = 0
# WHILE luar: berhenti jika satu putaran tidak ada pertukaran
while ada_tukar:
    ada_tukar = False
    putaran += 1
    # FOR dalam: bandingkan pasangan bersebelahan
    for j in range(n - putaran):
        if nilai[j] > nilai[j + 1]:
            nilai[j], nilai[j + 1] = nilai[j + 1], nilai[j]
            ada_tukar = True
    print(f"Putaran {putaran}: {nilai}")
print("Terurut:", nilai)

PSEUDOCODE
START
    DECLARE a : ARRAY[4] OF INTEGER
    a ← [25, 12, 22, 11]
    DECLARE j, t, putaran : INTEGER
    DECLARE adaTukar : BOOLEAN
    adaTukar ← true
    putaran ← 0
    WHILE adaTukar DO
        adaTukar ← false
        putaran ← putaran + 1
        FOR j ← 0 TO 3 - putaran DO
            IF a[j] > a[j + 1] THEN
                t ← a[j]
                a[j] ← a[j + 1]
                a[j + 1] ← t
                adaTukar ← true
            ENDIF
        ENDFOR
    ENDWHILE
    OUTPUT "Terurut: ", a
END

Soal latihan

  1. Urutkan nama ["Rina", "Agus", "Dewi", "Budi"] sesuai abjad dengan bubble sort.

    Petunjuk

    Logikanya sama, hanya cara membandingkan teks yang berbeda: Python memakai >, JavaScript/TypeScript memakai localeCompare, Java memakai compareTo.

    Lihat jawaban
    PYTHON
    nama = ["Rina", "Agus", "Dewi", "Budi"]
ada_tukar = True
while ada_tukar:
    ada_tukar = False
    for j in range(len(nama) - 1):
        if nama[j] > nama[j + 1]:
            nama[j], nama[j + 1] = nama[j + 1], nama[j]
            ada_tukar = True
print(nama)

  2. Ubah bubble sort agar mengurutkan dari besar ke kecil, lalu hitung berapa kali terjadi pertukaran untuk [3, 1, 4, 1, 5].

    Petunjuk

    Cukup balik tanda perbandingan menjadi <, dan tambah penghitung setiap kali menukar.

    Lihat jawaban
    PYTHON
    data = [3, 1, 4, 1, 5]
tukar = 0
for i in range(len(data) - 1):
    for j in range(len(data) - 1 - i):
        if data[j] < data[j + 1]:
            data[j], data[j + 1] = data[j + 1], data[j]
            tukar += 1
print(data, "pertukaran:", tukar)

Poin penting

  • Bandingkan pasangan bersebelahan, tukar jika salah urutan.
  • Loop dalam for (jumlah pasangan jelas), loop luar while (sampai tidak ada pertukaran).
  • Penanda pertukaran membuat sort berhenti lebih awal.
