pyproject.toml, Poetry, pipenv, PDM, Conda, pyenv

Buka versi interaktif

pyproject.toml adalah standar modern untuk mendeskripsikan proyek Python dalam satu file: nama, versi, dependensi, dan konfigurasi alat seperti ruff atau pytest. Hampir semua alat baru membaca file ini.

Poetry, PDM, dan pipenv adalah pengelola proyek yang menggabungkan virtual environment, pemasangan paket, dan lock file (daftar versi persis semua paket termasuk turunannya) agar hasil instalasi sama di semua komputer.

Conda populer di dunia data science karena juga bisa memasang pustaka non-Python seperti CUDA. pyenv berbeda fungsinya: ia mengelola banyak versi Python di satu komputer, misalnya 3.11 untuk proyek lama dan 3.13 untuk proyek baru.

CONTOH
# pyproject.toml
[project]
name = "toko-nusantara"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
    "requests>=2.32",
    "pydantic>=2.7",
]

[project.optional-dependencies]
dev = ["pytest>=8", "ruff>=0.5"]

[tool.ruff]
line-length = 100

# Perintah setara di beberapa alat
poetry add requests          # Poetry
pdm add requests             # PDM
pipenv install requests      # pipenv
conda install pandas         # Conda
pyenv install 3.13.0         # pasang versi Python
pyenv local 3.13.0           # pakai versi ini di folder proyek

Poin penting

  • pyproject.toml = satu file konfigurasi proyek.
  • Lock file menjamin versi paket identik.
  • Conda untuk data science dengan pustaka non-Python.
  • pyenv mengelola versi Python, bukan paket.
