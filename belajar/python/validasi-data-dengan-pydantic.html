Validasi data dengan Pydantic

Buka versi interaktif

Anotasi tipe biasa tidak memeriksa data saat program berjalan. Padahal data dari luar (form, API, file JSON) sering berantakan. Pydantic memakai anotasi tipe untuk memvalidasi dan mengonversi data saat runtime.

Kamu mendefinisikan model sebagai kelas turunan BaseModel. Saat membuat objek, Pydantic memeriksa setiap field: mengubah "85000" menjadi int jika memungkinkan, dan melempar ValidationError yang jelas jika tidak. Aturan tambahan ditulis dengan Field(gt=0) atau validator.

Pydantic menjadi fondasi FastAPI: setiap request JSON otomatis divalidasi berdasarkan model, dan dokumentasi API dibuat dari model yang sama.

PYTHON
from pydantic import BaseModel, Field, ValidationError

class Produk(BaseModel):
    nama: str = Field(min_length=2)
    harga: int = Field(gt=0)
    tag: list[str] = []

p = Produk(nama="Kopi Gayo", harga="85000")   # string diubah jadi int
print(p.harga + 1, p.model_dump())

try:
    Produk(nama="K", harga=-5)
except ValidationError as e:
    for err in e.errors():
        print(err["loc"][0], "->", err["msg"])

# Keluaran:
# 85001 {'nama': 'Kopi Gayo', 'harga': 85000, 'tag': []}
# nama -> String should have at least 2 characters
# harga -> Input should be greater than 0

Poin penting

  • Pydantic memvalidasi data saat runtime berdasarkan anotasi.
  • Konversi otomatis jika aman ("85000" → 85000).
  • Field(...) untuk aturan tambahan.
  • model_dump() mengubah model menjadi dict.
