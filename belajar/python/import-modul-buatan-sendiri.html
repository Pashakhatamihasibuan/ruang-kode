Import & modul buatan sendiri

Buka versi interaktif

Setiap file .py adalah modul. Kamu bisa memakai fungsi dari file lain dengan import. Folder berisi beberapa modul disebut paket (package). Memecah program ke beberapa modul membuat kode lebih teratur dan bisa dipakai ulang.

Ada beberapa gaya import: import math (pakai sebagai math.sqrt), from math import sqrt (langsung sqrt), dan import numpy as np (dengan nama alias). Hindari from x import * karena nama-nama bisa bertabrakan diam-diam.

Setiap modul punya variabel __name__. Nilainya "__main__" jika file dijalankan langsung, dan nama modulnya jika diimpor. Itu sebabnya kode uji coba ditaruh di dalam if __name__ == "__main__":.

PYTHON
# File: toko/harga.py
PAJAK = 0.11

def dengan_pajak(harga):
    return round(harga * (1 + PAJAK))

def rupiah(n):
    return f"Rp{n:,}".replace(",", ".")

if __name__ == "__main__":
    print("uji:", rupiah(dengan_pajak(10000)))   # hanya saat dijalankan langsung

# File: toko/__init__.py   (boleh kosong, menandai folder sebagai paket)

# File: main.py
from toko.harga import dengan_pajak, rupiah
import toko.harga as h

print(rupiah(dengan_pajak(85000)))
print(h.PAJAK)
# Keluaran:
# Rp94.350
# 0.11

Poin penting

  • Satu file = satu modul, satu folder = paket.
  • import x as y memberi alias.
  • Blok if __name__ == "__main__": tidak jalan saat diimpor.
  • Python mencari modul di folder kerja, lalu di site-packages.
