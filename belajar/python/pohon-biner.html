Pohon Biner

Buka versi interaktif

Pohon biner adalah struktur bercabang. Setiap node punya paling banyak dua anak: kiri dan kanan. Node paling atas disebut akar (root), node tanpa anak disebut daun (leaf). Karena setiap anak juga merupakan pohon, hampir semua kode pohon ditulis secara rekursif.

Binary search tree (BST) menambahkan aturan: semua nilai di kiri lebih kecil dari node, semua nilai di kanan lebih besar. Mencari nilai cukup menelusuri satu jalur dari akar, sehingga pada pohon seimbang hanya butuh O(log n) langkah.

Ada tiga urutan traversal klasik. Pre-order: akar, kiri, kanan. In-order: kiri, akar, kanan. Post-order: kiri, kanan, akar. Pada BST, in-order selalu menghasilkan data terurut.

PYTHON
class TreeNode:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

class BST:
    def __init__(self):
        self.root = None

    def add(self, v):
        self.root = self._add(self.root, v)

    def _add(self, node, v):
        if node is None:
            return TreeNode(v)               # tempat kosong ditemukan
        if v < node.data:
            node.left = self._add(node.left, v)
        else:
            node.right = self._add(node.right, v)
        return node

    def _in_order(self, node):              # kiri, akar, kanan
        if node is not None:
            self._in_order(node.left)
            print(node.data, end=" ")
            self._in_order(node.right)

Poin penting

  • Base case kode pohon hampir selalu node == null.
  • Pola root = add(root, v) membuat penyisipan rekursif menjadi rapi.
  • Memasukkan data yang sudah terurut ke BST membuatnya miring seperti linked list.
  • TreeSet dan TreeMap di Java memakai pohon seimbang.
