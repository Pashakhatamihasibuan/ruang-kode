Decorator

Buka versi interaktif

Decorator adalah fungsi yang menerima fungsi lain lalu mengembalikan versi yang "dibungkus" dengan perilaku tambahan, tanpa mengubah kode aslinya. Contoh kegunaannya: mencatat log, mengukur waktu, memeriksa login, atau menyimpan hasil (cache).

Menulis @catat di atas def bayar sama artinya dengan bayar = catat(bayar). Decorator bekerja berkat dua sifat Python: fungsi adalah objek yang bisa dioper, dan closure yang mengingat fungsi asli.

Gunakan functools.wraps di dalam decorator agar nama dan dokumentasi fungsi asli tetap terjaga. Pustaka standar juga punya decorator siap pakai seperti @functools.lru_cache untuk menyimpan hasil pemanggilan.

PYTHON
import functools, time

def catat(fungsi):
    @functools.wraps(fungsi)
    def pembungkus(*args, **kwargs):
        print(f"-> {fungsi.__name__}{args}")
        hasil = fungsi(*args, **kwargs)
        print(f"<- {hasil}")
        return hasil
    return pembungkus

def ulangi(n):                      # decorator dengan parameter
    def dekor(fungsi):
        @functools.wraps(fungsi)
        def pembungkus(*args):
            return [fungsi(*args) for _ in range(n)]
        return pembungkus
    return dekor

@catat
def bayar(harga, diskon=0):
    return harga - diskon

bayar(85000, 5000)
print(bayar.__name__)

@ulangi(3)
def sapa(nama):
    return f"hai {nama}"
print(sapa("Rina"))

@functools.lru_cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
print(fib(80))

Poin penting

  • @d di atas fungsi = f = d(f).
  • Decorator mengembalikan fungsi pembungkus.
  • functools.wraps menjaga nama fungsi asli.
  • lru_cache mempercepat fungsi rekursif yang berulang.

Cek pemahaman

<code>@catat</code> di atas <code>def f</code> setara dengan?

Jawaban: f = catat(f)

Decorator hanyalah gula sintaks.

Decorator bawaan untuk menyimpan hasil pemanggilan fungsi?

Jawaban: @lru_cache

lru_cache adalah memoization siap pakai.
