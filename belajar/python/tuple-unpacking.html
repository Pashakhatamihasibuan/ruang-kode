Tuple & unpacking

Buka versi interaktif

Tuple mirip list, tetapi immutable: setelah dibuat isinya tidak bisa diubah. Ditulis dengan kurung biasa: (3, 4). Tuple cocok untuk data yang memang satu paket dan tetap, seperti koordinat, tanggal, atau satu baris hasil database.

Karena immutable, tuple bisa dipakai sebagai kunci dictionary dan anggota set, sedangkan list tidak bisa.

Unpacking membongkar isi tuple ke beberapa variabel sekaligus: x, y = titik. Fungsi bisa mengembalikan beberapa nilai sebagai tuple. Tanda bintang menangkap sisanya: pertama, *sisa = data. Trik terkenal: menukar dua variabel cukup dengan a, b = b, a.

PYTHON
titik = (3, 4)
x, y = titik
print(x, y)

def statistik(data):
    return min(data), max(data), sum(data) / len(data)

lo, hi, rata = statistik([70, 85, 90, 65])
print(lo, hi, rata)

pertama, *tengah, terakhir = [1, 2, 3, 4, 5]
print(pertama, tengah, terakhir)

a, b = 10, 20
a, b = b, a
print(a, b)

jarak = {("Jakarta", "Bandung"): 150, ("Jakarta", "Bogor"): 60}
print(jarak[("Jakarta", "Bogor")])

try:
    titik[0] = 9
except TypeError:
    print("tuple tidak bisa diubah")

satu = (5,)
print(type(satu).__name__, type((5)).__name__)

Kode pemula vs kode rapi

Menukar dua variabel

Python bisa membongkar tuple di sisi kiri, jadi menukar nilai tidak perlu variabel sementara. Tanda * menampung sisanya.

KODE PEMULA
a = 5
b = 9
sementara = a
a = b
b = sementara
antrean = ["Sari", "Budi", "Rina", "Dewi"]
pertama = antrean[0]
sisa = antrean[1:]
print(a, b, pertama, sisa)
KODE RAPI (BEST PRACTICE)
a, b = 5, 9
a, b = b, a
pertama, *sisa = ["Sari", "Budi", "Rina", "Dewi"]
print(a, b, pertama, sisa)
KELUARAN KEDUANYA
9 5 Sari ['Budi', 'Rina', 'Dewi']

Poin penting

  • Tuple immutable, list mutable.
  • Tuple bisa menjadi kunci dict.
  • Unpacking: a, b = pasangan; bintang menangkap sisa.
  • Tuple satu elemen butuh koma: (5,).

Cek pemahaman

Mana yang bisa menjadi kunci dictionary?

Jawaban: (1, 2)

Kunci dict harus immutable (hashable).

Cara menukar nilai a dan b?

Jawaban: a, b = b, a

Unpacking tuple menukar keduanya sekaligus.
