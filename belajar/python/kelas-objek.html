Kelas & Objek

Buka versi interaktif

Kelas adalah cetak biru. Objek adalah benda nyata yang dibuat dari cetak biru itu. Kelas Titik mendefinisikan bahwa setiap titik punya x dan y (disebut field) serta bisa geser() (disebut method instance).

Konstruktor dijalankan saat objek dibuat dengan new Titik(3, 4) di Java atau Titik(3, 4) di Python. Tugasnya mengisi nilai awal field. Kata this (Java) dan self (Python) merujuk ke objek yang sedang dipakai.

Enkapsulasi berarti menyembunyikan field (private) dan hanya membuka method tertentu. Dengan begitu objek bisa menjaga datanya tetap valid. Method toString() / __str__ menentukan bagaimana objek tampil saat dicetak.

PYTHON
import math

class Titik:
    def __init__(self, x, y):         # konstruktor
        self._x = x                    # _ = "privat" (konvensi)
        self._y = y

    def geser(self, dx, dy):
        self._x += dx
        self._y += dy

    def jarak_ke_asal(self):
        return math.sqrt(self._x ** 2 + self._y ** 2)

    def __str__(self):
        return f"({self._x}, {self._y})"

p = Titik(3, 4)
print(p, "jarak", p.jarak_ke_asal())
p.geser(1, -1)
print(p)
KELUARAN
(3, 4) jarak 5.0
(4, 3)

Poin penting

  • Setiap objek punya salinan field sendiri.
  • Python tidak punya private. Konvensinya: awali nama dengan _.
  • Java memberi nilai default (0, null). Python mewajibkan field dibuat di __init__.
  • Method yang mengubah objek disebut mutator, yang hanya membaca disebut accessor.
