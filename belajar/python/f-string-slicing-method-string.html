f-string, slicing & method string

Buka versi interaktif

f-string adalah cara paling nyaman menyusun teks: tulis f sebelum kutip, lalu ekspresi di dalam kurung kurawal. Kamu juga bisa mengatur format: {harga:,} memberi pemisah ribuan, {x:.2f} dua angka di belakang koma, {nama:>10} rata kanan selebar 10.

Slicing mengambil potongan string dengan s[awal:akhir:langkah]. Indeks negatif dihitung dari belakang: s[-1] huruf terakhir, s[::-1] membalik string.

String immutable, jadi method seperti upper, strip, replace mengembalikan string baru. Method yang paling sering dipakai: split dan join untuk memecah dan menggabung, startswith, find, serta count.

PYTHON
nama = "  budi santoso "
rapi = nama.strip().title()
print(rapi)
print(rapi[:4], rapi[-7:], rapi[::-1])

harga = 1250000
print(f"Harga: Rp{harga:,}".replace(",", "."))
print(f"Rata-rata: {85.666:.2f}")
print(f"[{'kopi':>8}] [{'teh':<6}] [{7:03d}]")

kalimat = "saya belajar python dan sql"
kata = kalimat.split()
print(len(kata), kata[2])
print("-".join(kata))
print(kalimat.count("a"), kalimat.find("python"))
print(kalimat.startswith("saya"), "SQL" in kalimat.upper())

Kode pemula vs kode rapi

Mencetak nama variabel dan nilainya sekaligus

Tanda = di akhir f-string (Python 3.8) mencetak ekspresinya beserta nilainya. Sangat praktis untuk debugging cepat.

KODE PEMULA
harga = 85000
jumlah = 3
print("harga=" + str(harga) + ", jumlah=" + str(jumlah))
KODE RAPI (BEST PRACTICE)
harga = 85_000
jumlah = 3
print(f"{harga=}, {jumlah=}")
KELUARAN KEDUANYA
harga=85000, jumlah=3
Membalik teks

Slicing dengan langkah -1 membaca teks dari belakang.

KODE PEMULA
kata = "katak"
balik = ""
for huruf in kata:
    balik = huruf + balik
print(balik == kata)
KODE RAPI (BEST PRACTICE)
kata = "katak"
print(kata[::-1] == kata)
KELUARAN KEDUANYA
True

Poin penting

  • f-string: f"{ekspresi:format}".
  • Slicing [a:b] mengambil a sampai sebelum b.
  • s[::-1] membalik string.
  • "pemisah".join(list) kebalikan dari split.

Cek pemahaman

Hasil <code>"python"[1:4]</code>?

Jawaban: "yth"

Indeks 1 sampai sebelum 4.

Format f-string untuk dua desimal?

Jawaban: {x:.2f}

.2f = float dengan dua angka di belakang koma.
