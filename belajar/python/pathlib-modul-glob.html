pathlib & modul glob

Buka versi interaktif

Modul pathlib menyediakan objek Path untuk mengelola lokasi file dengan cara yang rapi dan lintas sistem operasi. Gabungkan path dengan operator /, ambil nama file dengan .name, ekstensi dengan .suffix, dan baca tulis dengan read_text/write_text.

Untuk mencari banyak file sekaligus dengan pola, pakai glob. Tanda * cocok dengan apa saja, ? satu karakter, dan ** masuk ke semua subfolder. Tersedia sebagai modul glob dan juga method Path.glob/rglob.

Contoh kebutuhan nyata: mengumpulkan semua laporan CSV di folder bulanan, mengganti nama foto secara massal, atau menghapus file sementara.

PYTHON
from pathlib import Path
import glob

folder = Path("laporan")
folder.mkdir(exist_ok=True)
for bulan in ["jan", "feb", "mar"]:
    (folder / f"penjualan_{bulan}.csv").write_text("produk,jumlah\nkopi,10\n")
(folder / "catatan.txt").write_text("rahasia")

csv = sorted(folder.glob("*.csv"))
print([p.name for p in csv])
print(csv[0].stem, csv[0].suffix)

print(sorted(glob.glob("laporan/penjualan_?a?.csv")))

total = sum(len(p.read_text().splitlines()) - 1 for p in csv)
print("total baris data:", total)

for p in folder.iterdir():
    p.unlink()
folder.rmdir()
print(folder.exists())

Poin penting

  • Path("a") / "b.txt" menggabung path.
  • .name, .stem, .suffix untuk bagian nama.
  • Pola glob: *, ?, **.
  • rglob mencari di semua subfolder.
