Kapan for, kapan while, kapan do-while

Buka versi interaktif

Semua loop bisa saling menggantikan, tetapi programmer yang baik memilih loop yang paling jujur menggambarkan niatnya. Pertanyaan kuncinya satu: apakah jumlah putarannya sudah diketahui sebelum loop dimulai?

Jika jumlahnya pasti (5 hari, 10 suku, setiap kursi 1 sampai 40), pakai for seperti for i in range(n). Jika yang diketahui hanya kondisi berhentinya (sampai saldo cukup, sampai data habis, sampai tidak ada pertukaran lagi), pakai while. Jika badan loop harus jalan minimal sekali sebelum dicek (menampilkan menu, meminta PIN), pakai do-while: while True: ... if kondisi_berhenti: break. Python memang tidak punya do-while, jadi polanya ditulis dengan while True dan break.

Untuk membaca setiap isi koleksi tanpa butuh nomor indeks, pakai for-each: for k in daftar. Lebih ringkas dan tidak mungkin salah indeks (error klasik "off by one").

Pada contoh kode di bawah, keempat jenis loop dipakai sesuai kasusnya masing-masing. Tebak keluarannya dulu, lalu coba latihan memilih loop di visual interaktif.

PYTHON
# FOR: jumlah pengulangan sudah diketahui (5 hari)
total = 0
for hari in range(1, 6):
    total += 10000
print("Tabungan 5 hari:", total)

# WHILE: berhenti saat kondisi tercapai, jumlah putaran belum diketahui
saldo, minggu = 0, 0
while saldo < 75000:
    saldo += 20000
    minggu += 1
print(f"Target tercapai di minggu ke-{minggu}")

# Python tidak punya do-while: pakai while True + break
pilihan_user = [2, 1, 0]
i = 0
while True:
    pilihan = pilihan_user[i]
    i += 1
    print("Menu dipilih:", pilihan)
    if pilihan == 0:
        break

# FOR atas koleksi: membaca setiap isi list
for k in ["Medan", "Bandung", "Makassar"]:
    print("Kirim ke", k)

Soal latihan

  1. Hitung mundur peluncuran roket: tampilkan 5, 4, 3, 2, 1 lalu "Meluncur!". Loop apa yang paling cocok?

    Petunjuk

    Awal dan akhir hitungan sudah pasti (5 sampai 1), jadi pakai for yang nilainya berkurang.

    Lihat jawaban
    PYTHON
    for detik in range(5, 0, -1):
    print(detik)
print("Meluncur!")
    KELUARAN
    5
4
3
2
1
Meluncur!

  2. Galon diisi 3 liter setiap menit, mulai dari kosong. Berapa menit sampai isinya minimal 19 liter? Tampilkan menit dan isinya.

    Petunjuk

    Jumlah menit belum diketahui, yang diketahui hanya kondisi berhenti (isi ≥ 19). Itu tanda while.

    Lihat jawaban
    PYTHON
    isi, menit = 0, 0
while isi < 19:
    isi += 3
    menit += 1
print(f"{menit} menit, isi {isi} liter")
    KELUARAN
    7 menit, isi 21 liter

Poin penting

  • Jumlah putaran diketahui → for.
  • Hanya kondisi berhenti yang diketahui → while.
  • Harus jalan minimal sekali → do-while.
  • Hanya membaca isi koleksi → for-each.
