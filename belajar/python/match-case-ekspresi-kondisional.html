match-case & ekspresi kondisional

Buka versi interaktif

Python 3.10 memperkenalkan match, mirip switch di bahasa lain tetapi lebih kuat karena bisa mencocokkan pola: nilai tetap, beberapa pilihan dengan |, bentuk tuple atau list, bahkan menangkap bagian data ke variabel.

Kasus case _: adalah penangkap sisa, seperti else. Tambahkan if setelah pola (disebut guard) untuk syarat tambahan.

Untuk pilihan dua nilai yang singkat, Python punya ekspresi kondisional: a if kondisi else b. Urutannya berbeda dari ternary di Java, jadi baca seperti kalimat: "a jika kondisi, kalau tidak b".

PYTHON
def jenis_hari(h):
    match h:
        case "sabtu" | "minggu":
            return "akhir pekan"
        case "senin" | "selasa" | "rabu" | "kamis" | "jumat":
            return "hari kerja"
        case _:
            return "tidak dikenal"

print(jenis_hari("sabtu"), "/", jenis_hari("rabu"))

def arah(perintah):
    match perintah.split():
        case ["jalan", tujuan]:
            return f"berjalan ke {tujuan}"
        case ["ambil", benda, *sisa] if sisa:
            return f"ambil {benda} dan {len(sisa)} barang lain"
        case ["ambil", benda]:
            return f"ambil {benda}"
        case _:
            return "perintah tidak dikenal"

print(arah("jalan utara"))
print(arah("ambil kunci peta senter"))
print(arah("ambil kunci"))

umur = 16
print("dewasa" if umur >= 17 else "remaja")

Poin penting

  • case a | b: untuk beberapa pilihan.
  • case _: menangkap semua sisa.
  • Pola bisa menangkap bagian data ke variabel.
  • Ekspresi kondisional: x if syarat else y.
