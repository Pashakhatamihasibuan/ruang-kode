Paradigma: prosedural, OOP, fungsional

Buka versi interaktif

Paradigma adalah gaya berpikir dalam menyusun program. Python mendukung beberapa paradigma sekaligus, dan programmer berpengalaman memilih yang paling cocok untuk masalahnya.

Prosedural: program adalah urutan langkah dan fungsi yang mengolah data. Cocok untuk skrip dan otomasi. Berorientasi objek: data dan perilakunya dibungkus dalam objek. Cocok untuk sistem dengan banyak entitas seperti toko, game, atau aplikasi bank. Fungsional: program dibangun dari fungsi murni tanpa efek samping, memakai map, filter, dan komposisi. Cocok untuk transformasi data.

Masalah yang sama bisa diselesaikan dengan ketiga gaya. Perhatikan contoh di bawah: ketiganya menghitung total belanja barang yang harganya di atas 20 ribu.

PYTHON
belanja = [("kopi", 85000), ("keripik", 15000), ("madu", 120000)]

# 1. Prosedural
total = 0
for nama, harga in belanja:
    if harga > 20000:
        total += harga
print("prosedural:", total)

# 2. Berorientasi objek
class Keranjang:
    def __init__(self, isi):
        self.isi = isi
    def total_di_atas(self, batas):
        return sum(h for _, h in self.isi if h > batas)
print("OOP:", Keranjang(belanja).total_di_atas(20000))

# 3. Fungsional
from functools import reduce
mahal = filter(lambda b: b[1] > 20000, belanja)
print("fungsional:", reduce(lambda a, b: a + b, map(lambda b: b[1], mahal), 0))
KELUARAN
prosedural: 205000
OOP: 205000
fungsional: 205000

Poin penting

  • Prosedural: langkah demi langkah.
  • OOP: data + perilaku dalam objek.
  • Fungsional: fungsi murni dan transformasi data.
  • Python multi-paradigma: campur sesuai kebutuhan.

Cek pemahaman

Paradigma yang menekankan fungsi tanpa efek samping?

Jawaban: Fungsional

Fungsi murni hanya bergantung pada input.

Untuk sistem dengan banyak entitas yang punya data dan perilaku, gaya yang cocok?

Jawaban: OOP

Objek memodelkan entitas.

Kerjakan latihannya di aplikasi

Sebelumnya: Duck typing (kontrak tanpa interface)

Berikutnya: List, dict & set comprehension
