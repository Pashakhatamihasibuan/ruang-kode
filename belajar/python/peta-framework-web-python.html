Peta framework web Python

Buka versi interaktif

Framework web menangani pekerjaan berulang: menerima request HTTP, mencocokkan URL ke fungsi, membaca data form atau JSON, dan mengirim response. Python punya banyak pilihan dengan filosofi berbeda.

Django: "batteries included", lengkap dengan ORM, panel admin, autentikasi, dan template. Flask: mikro dan fleksibel, kamu memilih sendiri komponennya. FastAPI: modern, async, berbasis type hint dan Pydantic, dengan dokumentasi API otomatis. Pyramid: bisa mulai kecil dan tumbuh besar.

Untuk performa async tinggi ada Sanic, Tornado, dan AIOHTTP. Plotly Dash khusus membuat dashboard data interaktif hanya dengan Python. Panduan cepat: aplikasi web lengkap dengan admin → Django; REST API modern → FastAPI; layanan kecil atau belajar → Flask.

PYTHON
# Dash: dashboard interaktif dalam satu file
from dash import Dash, html, dcc
import plotly.express as px

data = {"bulan": ["Jan", "Feb", "Mar"], "penjualan": [120, 150, 170]}
app = Dash(__name__)
app.layout = html.Div([
    html.H1("Penjualan Toko Nusantara"),
    dcc.Graph(figure=px.bar(data, x="bulan", y="penjualan")),
])

if __name__ == "__main__":
    app.run(debug=True)          # buka http://127.0.0.1:8050

Poin penting

  • Django: lengkap, cocok untuk aplikasi web penuh.
  • Flask: minimalis dan fleksibel.
  • FastAPI: API modern, async, validasi otomatis.
  • Sanic/Tornado/AIOHTTP: async; Dash: dashboard data.
