Format specifier: merapikan keluaran

Buka versi interaktif

Format specifier adalah kode kecil yang mengatur bagaimana sebuah nilai ditampilkan: berapa angka di belakang koma, selebar apa kolomnya, rata kiri atau kanan, diberi nol di depan, atau diberi pemisah ribuan. Nilainya tidak berubah, hanya tampilannya. Hampir semua program nyata membutuhkannya: struk belanja, laporan nilai, nomor invoice, dan log server.

Polanya mirip di semua bahasa: [perataan][lebar][.presisi][tipe]. Contoh %-10s berarti teks rata kiri selebar 10, %8.2f berarti desimal 2 angka dalam kolom selebar 8, dan %05d berarti bilangan bulat selebar 5 yang diisi nol di depan.

Python modern memakai f-string: f"{nilai:spesifikasi}". Perataan ditulis dengan simbol: < kiri, > kanan, ^ tengah. Tambahan khas Python: {x:,} untuk pemisah ribuan, {x:.0%} untuk persen, dan {x=} untuk debugging cepat yang mencetak nama variabel beserta nilainya.

Kamu juga akan menemui gaya lama "%s %d" % (a, b) dan "{}".format(x) di kode lama dan modul logging. Spesifikasinya sama, jadi cukup pelajari sekali. Untuk kode baru, f-string adalah standar industri karena paling mudah dibaca.

Contoh terakhir di kode adalah struk belanja: format di dalam loop membuat setiap baris punya lebar kolom yang sama, sehingga angka tersusun rapi ke kanan. Ini pola yang akan sering kamu pakai di soal-soal berikutnya.

PYTHON
nama = "Rina"
umur = 20
ipk = 3.4567
# f-string: {nilai:spesifikasi}
print(f"Nama: {nama}, umur {umur}, IPK {ipk:.2f}")

# lebar dan perataan: > kanan, < kiri, ^ tengah, 0 isi nol
print(f"[{nama:>8}] [{nama:<8}] [{nama:^8}] [{umur:05d}]")

# pemisah ribuan, persen, basis lain, notasi ilmiah
print(f"Gaji {7500000:,} | diskon {0.15:.0%} | hex {255:x} | biner {5:b}")
print(f"{123456.789:.3e} | {umur > 17} | {nama!r}")

# debugging cepat: {variabel=} mencetak nama dan nilainya
print(f"{umur=}, {ipk=:.1f}")

# gaya lama yang masih ditemui di kode lama dan logging
print("Nama: %s, umur %d, IPK %.2f" % (nama, umur, ipk))
print("Kode: INV-{:04d}".format(7))

# struk belanja
barang = ["Kopi susu", "Roti bakar", "Air mineral"]
harga = [18000, 22500, 5000]
print(f"{'Barang':<12} {'Harga':>10}")
for b, h in zip(barang, harga):
    print(f"{b:<12} {h:>10,}")
print(f"{'TOTAL':<12} {sum(harga):>10,}")

Soal latihan

  1. Tampilkan daftar 3 mahasiswa dengan kolom rapi: nomor (lebar 3, rata kanan), nama (lebar 10, rata kiri), dan IPK (2 angka desimal). Data: Ani 3.5, Budi 3.257, Citra 3.9.

    Petunjuk

    Gabungkan lebar dan perataan dengan presisi. Untuk IPK: lebar 5 dan 2 desimal, misalnya %5.2f atau {ipk:5.2f}.

    Lihat jawaban
    PYTHON
    data = [("Ani", 3.5), ("Budi", 3.257), ("Citra", 3.9)]
for no, (nama, ipk) in enumerate(data, start=1):
    print(f"{no:>3} {nama:<10} {ipk:5.2f}")

  2. Buat nomor antrean 5 pelanggan dengan format A-001 sampai A-005.

    Petunjuk

    Isi angka dengan nol di depan sampai 3 digit: %03d di Java, {n:03d} di Python, padStart(3, "0") di JavaScript/TypeScript.

    Lihat jawaban
    PYTHON
    for n in range(1, 6):
    print(f"A-{n:03d}")

Poin penting

  • Pola umum: [perataan][lebar][.presisi][tipe].
  • Lebar + perataan membuat kolom laporan lurus.
  • Untuk angka ke pengguna, pakai format lokal (id-ID).
  • Kode baru: f-string, template literal, atau String.format.

Cek pemahaman

Apa arti format %-10s?

Jawaban: Teks rata kiri selebar 10

Tanda minus berarti rata kiri, angka 10 adalah lebar kolom minimum.

Format apa yang menampilkan 7 sebagai 007?

Jawaban: %03d atau {x:03d}

Angka 0 di depan lebar berarti isi nol. Tanpa 0, sisa tempat diisi spasi.

3.14159 diformat dengan dua angka desimal hasilnya?

Jawaban: 3.14

Dibulatkan ke 2 angka di belakang koma: 3.14159 → 3.14.

Untuk menampilkan harga ke pengguna Indonesia, cara yang dianjurkan adalah?

Jawaban: Memakai format berbasis lokal id-ID

Format lokal menangani pemisah ribuan, desimal, dan simbol mata uang dengan benar.
