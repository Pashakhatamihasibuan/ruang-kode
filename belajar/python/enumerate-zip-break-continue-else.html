enumerate, zip, break, continue, else

Buka versi interaktif

Python mendorong loop yang langsung berjalan di atas data, bukan di atas indeks. Jika kamu butuh indeks sekaligus nilainya, pakai enumerate. Jika ingin berjalan di atas dua list sekaligus, pakai zip.

break menghentikan loop seketika, sedangkan continue melompat ke putaran berikutnya. Loop di Python juga boleh punya blok else, yang dijalankan hanya jika loop selesai tanpa break. Ini rapi untuk pola "cari, dan kalau tidak ketemu lakukan sesuatu".

range(awal, akhir, langkah) menghasilkan deret angka tanpa menyimpannya semua di memori. reversed dan sorted membantu berjalan terbalik atau berurutan tanpa mengubah data asli.

PYTHON
buah = ["apel", "jeruk", "mangga"]
for i, b in enumerate(buah, start=1):
    print(i, b)

harga = [12000, 8000, 15000]
for b, h in zip(buah, harga):
    print(f"{b}: {h}")

ganjil = []
for n in range(1, 10):
    if n % 2 == 0:
        continue
    if n > 7:
        break
    ganjil.append(n)
print(ganjil)

target = "durian"
for b in buah:
    if b == target:
        print("ketemu")
        break
else:
    print(target, "tidak ada")

print(list(range(10, 0, -3)), list(reversed(buah)))
KELUARAN
1 apel
2 jeruk
3 mangga
apel: 12000
jeruk: 8000
mangga: 15000
[1, 3, 5, 7]
durian tidak ada
[10, 7, 4, 1] ['mangga', 'jeruk', 'apel']

Kode pemula vs kode rapi

Nomor urut tanpa range(len())

enumerate memberi nomor dan isinya sekaligus, dan bisa dimulai dari 1. zip berjalan di beberapa list bersamaan.

KODE PEMULA
nama = ["Sari", "Budi", "Rina"]
nilai = [90, 78, 85]
for i in range(len(nama)):
    print(str(i + 1) + ". " + nama[i] + ": " + str(nilai[i]))
KODE RAPI (BEST PRACTICE)
nama = ["Sari", "Budi", "Rina"]
nilai = [90, 78, 85]
for no, (n, v) in enumerate(zip(nama, nilai), start=1):
    print(f"{no}. {n}: {v}")
KELUARAN KEDUANYA
1. Sari: 90
2. Budi: 78
3. Rina: 85

Poin penting

  • enumerate memberi pasangan (indeks, nilai).
  • zip berjalan di atas beberapa koleksi sekaligus.
  • for ... else: else jalan jika tidak ada break.
  • range hemat memori.
