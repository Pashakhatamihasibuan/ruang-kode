Dictionary lanjutan & operasi set

Buka versi interaktif

Dictionary menyimpan pasangan kunci dan nilai, dan sejak Python 3.7 urutan penyisipan terjaga. Ambil nilai dengan aman memakai d.get(k, cadangan) agar tidak muncul KeyError. setdefault dan collections.defaultdict memudahkan pola "kelompokkan".

Telusuri dictionary dengan items() untuk mendapat kunci dan nilai sekaligus. Gabungkan dua dictionary dengan operator | (Python 3.9). collections.Counter adalah dictionary khusus untuk menghitung.

Set punya operasi himpunan seperti di matematika: | gabungan, & irisan, - selisih, dan ^ beda simetris. Ini sangat cepat untuk pertanyaan seperti "siapa yang ikut kelas A tapi tidak ikut kelas B?".

PYTHON
from collections import Counter, defaultdict

stok = {"kopi": 40, "teh": 120}
print(stok.get("madu", 0))
stok |= {"madu": 15}
for nama, jml in stok.items():
    print(f"{nama:5} {jml}")

pesanan = ["kopi", "teh", "kopi", "madu", "kopi"]
print(Counter(pesanan).most_common(2))

per_kota = defaultdict(list)
for nama, kota in [("Andi", "Jakarta"), ("Budi", "Bandung"), ("Dewi", "Jakarta")]:
    per_kota[kota].append(nama)
print(dict(per_kota))

kelas_a = {"Andi", "Budi", "Citra"}
kelas_b = {"Budi", "Dewi"}
print(sorted(kelas_a & kelas_b), sorted(kelas_a - kelas_b), sorted(kelas_a | kelas_b))

Poin penting

  • get(k, default) mencegah KeyError.
  • items() untuk loop kunci dan nilai.
  • Counter untuk menghitung, defaultdict untuk mengelompokkan.
  • Set: & irisan, | gabungan, - selisih.

Cek pemahaman

<code>{"a":1}.get("b", 0)</code> menghasilkan?

Jawaban: 0

Nilai cadangan dikembalikan jika kunci tidak ada.

Operator set untuk anggota yang ada di kedua himpunan?

Jawaban: &

& adalah irisan.
