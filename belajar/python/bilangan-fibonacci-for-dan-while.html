Bilangan Fibonacci: for dan while

Buka versi interaktif

Deret Fibonacci dimulai dari 0 dan 1, lalu setiap suku adalah jumlah dua suku sebelumnya: 0, 1, 1, 2, 3, 5, 8, 13, ... Polanya muncul di banyak tempat, dari susunan biji bunga matahari sampai soal tes kerja programmer.

Kuncinya adalah dua variabel a dan b yang terus digeser: a menjadi b, dan b menjadi a + b. Python bisa menggeser keduanya sekaligus dengan a, b = b, a + b.

Perhatikan dua bagian contoh. "10 suku pertama" memakai for karena jumlah putarannya pasti 10. "Semua suku di bawah 100" memakai while karena kita tidak tahu ada berapa suku sampai benar-benar menghitungnya.

Visual di bawah menjalankan bagian while langkah demi langkah sebagai flowchart dan pseudocode. Perhatikan kolom Variabel: nilai yang berubah diberi warna.

PYTHON
# FOR: n suku pertama (jumlah putaran diketahui)
n = 10
a, b = 0, 1
deret = []
for _ in range(n):
    deret.append(a)
    a, b = b, a + b
print("10 suku pertama:", *deret)

# WHILE: semua suku di bawah 100 (jumlah putaran belum diketahui)
a, b = 0, 1
banyak = 0
while a < 100:
    banyak += 1
    a, b = b, a + b
print("Banyak suku di bawah 100:", banyak)

START
    DECLARE a, b, c, banyak : INTEGER
    a ← 0

    banyak ← 0

        banyak ← banyak + 1
        c ← a + b
        a ← b
        b ← c
    ENDWHILE
    OUTPUT "Banyak suku: ", banyak
END

Soal latihan

  1. Tampilkan hanya suku Fibonacci ke-20 (suku pertama adalah 0).

    Petunjuk

    Kamu tahu persis butuh 19 kali geser pasangan (a, b), jadi pakai for. Tidak perlu menyimpan semua suku.

    Lihat jawaban
    PYTHON
    a, b = 0, 1
for _ in range(19):
    a, b = b, a + b
print("Suku ke-20:", a)

  2. Cari suku Fibonacci pertama yang lebih dari 1000, dan suku ke berapa itu.

    Petunjuk

    Kamu tidak tahu butuh berapa suku, jadi pakai while dengan kondisi a <= 1000.

    Lihat jawaban
    PYTHON
    a, b, ke = 0, 1, 1
while a <= 1000:
    a, b = b, a + b
    ke += 1
print(f"Suku ke-{ke}: {a}")

Poin penting

  • Fibonacci butuh dua variabel yang terus digeser.
  • n suku pertama → for; suku di bawah batas → while.
  • Geser nilai dengan urutan yang benar agar nilai lama tidak hilang.

Cek pemahaman

Suku Fibonacci ke-8 (mulai dari 0) adalah?

Jawaban: 13

0, 1, 1, 2, 3, 5, 8, 13: suku ke-8 adalah 13.

Mengapa menghitung "suku di bawah 1000" memakai while?

Jawaban: Karena jumlah sukunya belum diketahui sebelum dihitung

Batasnya nilai, bukan banyak putaran.
