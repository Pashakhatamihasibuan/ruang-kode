Linked List

Buka versi interaktif

Linked list menyimpan data dalam node terpisah. Setiap node berisi data dan referensi next ke node berikutnya. Node terakhir menunjuk None. Kelas list hanya perlu mengingat front, yaitu node pertama.

Menambah di depan sangat murah: buat node baru yang next-nya menunjuk front lama, lalu pindahkan front. Tidak ada yang bergeser. Sebaliknya, mengakses elemen ke-i harus berjalan dari depan sebanyak i langkah.

Kunci menulis kode linked list adalah urutan mengubah referensi. Gambar kotak dan panah di kertas sebelum menulis kode. Pola umumnya: variabel current berjalan maju sampai berhenti tepat sebelum posisi yang ingin diubah.

PYTHON
class ListNode:
    def __init__(self, data, next=None):
        self.data = data
        self.next = next

class LinkedIntList:
    def __init__(self):
        self.front = None        # None bila kosong

    def add_first(self, nilai):
        self.front = ListNode(nilai, self.front)

    def add_last(self, nilai):
        if self.front is None:
            self.front = ListNode(nilai)
        else:
            cur = self.front
            while cur.next is not None:   # jalan ke node terakhir
                cur = cur.next
            cur.next = ListNode(nilai)

Poin penting

  • Selalu tangani kasus list kosong (front is None) secara terpisah.
  • current.next.next berbahaya bila current.next bernilai None.
  • Linked list cepat di ujung depan, array cepat untuk akses indeks.
  • collections.deque sudah tersedia untuk pemakaian nyata dan cepat di kedua ujung.

Cek pemahaman

Berapa biaya mengakses elemen ke-i pada linked list?

Jawaban: O(i), harus berjalan dari depan

Tidak ada indeks. Harus mengikuti next sebanyak i kali.

Berapa biaya addFirst pada linked list?

Jawaban: O(1)

Hanya membuat satu node dan mengubah front, berapa pun panjang list.
