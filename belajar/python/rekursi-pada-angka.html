Jumlah digit dari angka satu digit adalah angka itu sendiriif n < 10: return n
selain itu: digit terakhir + jumlah digit sisanyareturn n % 10 + jumlah_digit(n // 10)
PYTHON
def jumlah_digit(n):
    if n < 10: return n
    return n % 10 + jumlah_digit(n // 10)
