List, dict & set comprehension

Buka versi interaktif

Comprehension adalah cara Pythonic membuat koleksi baru dari koleksi lain dalam satu baris: [ekspresi for item in data if syarat]. Bacanya seperti kalimat: "ambil ekspresi untuk setiap item di data, jika syarat terpenuhi".

Bentuk yang sama tersedia untuk dictionary {k: v for ...} dan set {x for ...}. Comprehension biasanya lebih cepat dan lebih mudah dibaca daripada loop dengan append.

Tapi jangan berlebihan. Jika comprehension butuh dua loop bersarang dan beberapa syarat, tulis ulang sebagai loop biasa demi keterbacaan.

PYTHON
harga = {"kopi": 85000, "teh": 25000, "keripik": 15000, "madu": 120000}

kuadrat = [n * n for n in range(1, 6)]
print(kuadrat)

mahal = [nama for nama, h in harga.items() if h > 50000]
print(mahal)

diskon = {nama: h * 9 // 10 for nama, h in harga.items()}
print(diskon["kopi"])

huruf_awal = {nama[0] for nama in harga}
print(sorted(huruf_awal))

label = ["genap" if n % 2 == 0 else "ganjil" for n in range(4)]
print(label)

matriks = [[1, 2, 3], [4, 5, 6]]
print([x for baris in matriks for x in baris])
KELUARAN
[1, 4, 9, 16, 25]
['kopi', 'madu']
76500
['k', 'm', 't']
['genap', 'ganjil', 'genap', 'ganjil']
[1, 2, 3, 4, 5, 6]

Kode pemula vs kode rapi

Membuat list baru dari list lain

Pola "buat list kosong, loop, if, append" bisa ditulis sebagai comprehension. Lebih pendek dan biasanya lebih cepat.

KODE PEMULA
harga = [12000, 45000, 8000, 30000]
mahal = []
for h in harga:
    if h >= 10000:
        mahal.append(h * 2)
print(mahal)
KODE RAPI (BEST PRACTICE)
harga = [12_000, 45_000, 8_000, 30_000]
mahal = [h * 2 for h in harga if h >= 10_000]
print(mahal)
KELUARAN KEDUANYA
[24000, 90000, 60000]

Poin penting

  • [f(x) for x in data if syarat(x)].
  • Dict comprehension: {k: v for ...}.
  • if di akhir = saring; if-else di depan = pilih nilai.
  • Utamakan keterbacaan.

Cek pemahaman

Hasil <code>[x*2 for x in [1,2,3] if x != 2]</code>?

Jawaban: [2, 6]

2 disaring, lalu 1 dan 3 dikali dua.

Kurung untuk set comprehension?

Jawaban: { } tanpa titik dua

Kurung kurawal tanpa pasangan kunci:nilai.
