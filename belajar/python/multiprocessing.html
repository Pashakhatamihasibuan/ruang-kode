Multiprocessing

Buka versi interaktif

Untuk pekerjaan berat di CPU, seperti memproses gambar atau menghitung statistik besar, gunakan multiprocessing. Setiap proses punya interpreter Python dan GIL-nya sendiri, sehingga benar-benar berjalan paralel di beberapa inti CPU.

Cara termudah adalah ProcessPoolExecutor atau multiprocessing.Pool: berikan fungsi dan daftar data, lalu tugas dibagi ke beberapa proses.

Proses tidak berbagi memori seperti thread. Data dikirim antarproses dengan cara diserialisasi (pickle), jadi ada biaya tambahan. Selalu bungkus kode utama dengan if __name__ == "__main__":, karena di Windows dan macOS proses baru mengimpor ulang file utamamu.

PYTHON
from concurrent.futures import ProcessPoolExecutor
import math, os

def jumlah_prima(batas):
    return sum(1 for n in range(2, batas) if all(n % d for d in range(2, int(math.isqrt(n)) + 1)))

if __name__ == "__main__":
    tugas = [50_000, 60_000, 70_000, 80_000]
    with ProcessPoolExecutor() as ex:
        hasil = list(ex.map(jumlah_prima, tugas))
    print(hasil)
    print("inti CPU tersedia:", os.cpu_count() is not None)
KELUARAN
[5133, 6057, 6935, 7837]
inti CPU tersedia: True

Poin penting

  • Multiprocessing = paralel sungguhan, melewati GIL.
  • Cocok untuk tugas berat CPU.
  • Data antarproses dikirim lewat pickle.
  • Wajib if __name__ == "__main__":.
