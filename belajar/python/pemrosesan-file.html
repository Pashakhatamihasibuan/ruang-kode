Pemrosesan File

Buka versi interaktif

Program nyata membaca data dari file, bukan hanya dari keyboard. Di Java, Scanner yang sama bisa diarahkan ke new File("nilai.txt"). Di Python, gunakan open() di dalam blok with agar file otomatis ditutup.

Ada dua cara membaca. Berbasis token: membaca potongan yang dipisah spasi (next(), nextInt()). Berbasis baris: membaca satu baris utuh lalu memecahnya. Pola paling aman adalah membaca per baris, lalu memecah baris itu menjadi token.

Membuka file bisa gagal, misalnya karena file tidak ada. Java memaksa kamu menangani kemungkinan itu (throws FileNotFoundException), karena ini termasuk checked exception. Python melempar FileNotFoundError yang bisa ditangkap dengan try/except.

PYTHON
def main():
    with open("nilai.txt") as file:
        for baris in file:                   # "Budi 85 90"
            token = baris.split()
            nama = token[0]
            total = 0
            for t in token[1:]:
                total += int(t)
            print(nama + ":", total / (len(token) - 1))

main()
KELUARAN
Budi: 87.5
Sari: 85.0

Poin penting

  • hasNextInt() mengecek dulu sebelum nextInt(), supaya tidak crash.
  • str.split() memecah string berdasarkan spasi.
  • Menulis file: PrintStream di Java, open(nama, "w") di Python.
  • Isi contoh nilai.txt: dua baris, "Budi 85 90" dan "Sari 78 92".

Cek pemahaman

Token berikutnya adalah "abc". Apa hasil hasNextInt()?

Jawaban: false

hasNextInt hanya melihat, tidak membaca. "abc" bukan bilangan bulat, jadi false.

Mengapa memakai with open(...) di Python?

Jawaban: File otomatis ditutup walau terjadi error

Blok with menjamin file ditutup saat blok selesai.
