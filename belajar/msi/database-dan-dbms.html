Database dan DBMS

Buka versi interaktif

Banyak organisasi memulai dengan spreadsheet. Masalah muncul saat data membesar dan dipakai banyak orang: salinan file berbeda-beda, rumus terhapus, dan tidak ada yang tahu versi mana yang terbaru.

Database menyimpan data terstruktur dalam tabel yang saling berhubungan. Database Management System (DBMS) seperti MySQL, PostgreSQL, atau SQL Server mengatur akses banyak pengguna sekaligus, hak akses, cadangan, dan mencegah data ganda atau tidak konsisten.

Bahasa untuk bertanya ke database adalah SQL. Manajer tidak harus menulis SQL setiap hari, tetapi memahami dasarnya membantu saat meminta laporan ke tim data. Kamu bisa mencobanya langsung di jalur SQL Ruang Kode.

Soal latihan

  1. Sebutkan empat keuntungan DBMS dibanding menyimpan data di banyak file spreadsheet.

    Petunjuk

    Redundansi, konsistensi, akses bersama, keamanan.

    Lihat jawaban
    CONTOH
    1. Mengurangi data ganda (redundansi).
2. Menjaga konsistensi dengan aturan (constraint).
3. Banyak pengguna bisa mengakses bersamaan dengan aman.
4. Hak akses, cadangan, dan pemulihan lebih terkendali.

  2. Tulis query untuk menampilkan 5 produk dengan stok di bawah 10, urut dari stok terkecil.

    Petunjuk

    SELECT, WHERE, ORDER BY, LIMIT.

    Lihat jawaban
    SQL
    SELECT nama, stok
FROM produk
WHERE stok < 10
ORDER BY stok ASC
LIMIT 5;

Poin penting

  • Spreadsheet cocok untuk awal, bermasalah saat data besar dan banyak pengguna.
  • DBMS mengatur akses bersama, hak akses, konsistensi, dan cadangan.
  • SQL adalah bahasa untuk mengambil data dari database.
