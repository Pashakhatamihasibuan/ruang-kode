Jaringan dan cloud computing

Buka versi interaktif

Sistem informasi modern hampir selalu terhubung jaringan: LAN di dalam gedung, internet antarcabang, dan koneksi seluler untuk aplikasi di lapangan. Kualitas jaringan menentukan apakah sistem bisa dipakai di daerah dengan sinyal lemah, jadi pertimbangkan mode offline lalu sinkron saat tersambung.

Cloud computing berarti menyewa sumber daya komputasi lewat internet. SaaS (software as a service) memakai aplikasi jadi seperti Google Workspace atau aplikasi akuntansi online. PaaS menyediakan platform untuk menjalankan aplikasi buatan sendiri. IaaS menyewakan server virtual dan penyimpanan.

Keuntungan cloud: tanpa beli server di awal, mudah diperbesar, dan dicadangkan penyedia. Risikonya: biaya langganan terus berjalan, ketergantungan pada penyedia (vendor lock-in), dan aturan lokasi penyimpanan data. Pilihan on-premise (server sendiri) masih dipakai untuk data sangat sensitif atau koneksi internet yang tidak andal.

CONTOH
Pertanyaan sebelum berlangganan:
- data disimpan di negara mana?
- bisa ekspor data kalau pindah?
- biaya naik kalau pengguna bertambah?

Poin penting

  • Jaringan: LAN, internet, seluler; pertimbangkan mode offline.
  • SaaS = aplikasi jadi; PaaS = platform; IaaS = server sewaan.
  • Cloud: hemat modal awal, mudah diperbesar; risiko lock-in dan biaya berjalan.
