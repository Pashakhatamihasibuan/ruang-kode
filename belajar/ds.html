Modul 9: Proyek portofolio: 6 mini + 4 besar

Profesional

Proyek berstandar industri untuk jalur UI/UX Designer: kerjakan proyek mini lalu proyek besar, bandingkan dengan kode final yang bisa dibuka setelah mencoba sendiri, lalu sajikan di CV dan wawancara. Progresnya tercatat juga di menu Proyek Portofolio.

  1. Mini 1: Linter kontras token warna (WCAG 2.2)
  2. Mini 2: Generator design token DTCG ke CSS (terang & gelap)
  3. Mini 3: Type scale modular dan aturan panjang baris
  4. Mini 4: Analisis usability test: SUS, task success, dan prioritas temuan
  5. Mini 5: Audit aksesibilitas otomatis hasil slicing
  6. Mini 6: Card sorting untuk menyusun information architecture
  7. Besar 1: Design system multi-brand dengan token DTCG dan visual regression
  8. Besar 2: Redesign checkout e-commerce berbasis riset dan A/B test
  9. Besar 3: Portal layanan publik yang aksesibel (WCAG 2.2 AA) untuk semua warga
  10. Besar 4: UX fitur asisten AI di aplikasi perbankan
  11. Profil GitHub dan LinkedIn yang meyakinkan
  12. Menulis proyek di CV (lolos ATS)
  13. Menceritakan proyek saat wawancara (STAR)
  14. Take-home test dan live coding
