Package & modul

Buka versi interaktif

Package mengelompokkan kelas yang berkaitan, seperti folder. Nama package ditulis di baris pertama file, misalnya package com.toko.pesanan;, dan harus cocok dengan struktur folder. Konvensinya memakai nama domain terbalik agar unik di seluruh dunia.

Untuk memakai kelas dari package lain, tulis import. Kelas di java.lang (String, Math, System) otomatis tersedia tanpa import.

Sejak Java 9 ada module system. Sebuah modul adalah kumpulan package dengan file module-info.java yang menyatakan modul apa yang dibutuhkan (requires) dan package mana yang boleh dipakai pihak luar (exports). Ini membantu aplikasi besar menjaga batas antarbagian.

JAVA
// File: src/com/toko/model/Produk.java
package com.toko.model;

public class Produk {
    private final String nama;
    public Produk(String nama) { this.nama = nama; }
    public String getNama() { return nama; }
}

// File: src/com/toko/App.java
package com.toko;

import com.toko.model.Produk;
import java.util.List;

public class App {
    public static void main(String[] args) {
        List<Produk> daftar = List.of(new Produk("Kopi"));
        System.out.println(daftar.get(0).getNama());
    }
}

// File: src/module-info.java
module com.toko {
    requires java.sql;
    exports com.toko.model;
}

Poin penting

  • Satu file = satu package (baris package paling atas).
  • Struktur folder mengikuti nama package.
  • import hanya mempersingkat nama, tidak menyalin kode.
  • module-info.java: requires = butuh, exports = dibagikan.

Cek pemahaman

Kelas mana yang bisa dipakai tanpa import?

Jawaban: String

String ada di java.lang yang otomatis diimpor.

Di module-info, kata kunci untuk membagikan package?

Jawaban: exports

exports membuat package bisa dipakai modul lain.
