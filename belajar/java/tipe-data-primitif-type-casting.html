Tipe data primitif & type casting

Buka versi interaktif

Java punya delapan tipe primitif: byte, short, int, long untuk bilangan bulat, float dan double untuk pecahan, char untuk satu huruf, dan boolean untuk benar/salah. Setiap tipe punya ukuran tetap di memori, sehingga rentang nilainya terbatas.

Memindahkan nilai dari tipe kecil ke tipe besar disebut widening dan terjadi otomatis, karena tidak ada informasi yang hilang. Sebaliknya, dari tipe besar ke tipe kecil disebut narrowing. Java memaksa kamu menulis cast eksplisit seperti (int) 9.99, sebagai tanda kamu sadar ada bagian yang bisa terbuang.

Hati-hati dengan pembagian. 7 / 2 menghasilkan 3 karena kedua operand bertipe int. Ubah salah satunya menjadi double, misalnya (double) 7 / 2, untuk mendapat 3.5.

JAVA
public class Casting {
    public static void main(String[] args) {
        int jumlah = 7;
        double rata = jumlah;          // widening: otomatis
        double harga = 9.99;
        int dibulatkan = (int) harga;  // narrowing: buang pecahan
        long besar = 3_000_000_000L;
        int kecil = (int) besar;       // nilai meluap (overflow)
        char huruf = 'A';
        int kode = huruf;              // char -> int: kode Unicode

        System.out.println(rata);
        System.out.println(dibulatkan);
        System.out.println(kecil);
        System.out.println(kode);
        System.out.println(7 / 2);
        System.out.println((double) 7 / 2);
    }
}

Kode pemula vs kode rapi

Angka besar lebih mudah dibaca dengan garis bawah

Sejak Java 7, garis bawah boleh ditulis di antara digit: 1_000_000. Compiler mengabaikannya, nilainya tetap sama, tetapi mata manusia langsung tahu itu satu juta, bukan seratus ribu.

KODE PEMULA
long harga = 1000000;
long ongkir = 25000;
System.out.println(harga + ongkir);
KODE RAPI (BEST PRACTICE)
long harga = 1_000_000;
long ongkir = 25_000;
System.out.println(harga + ongkir);
KELUARAN KEDUANYA
1025000
Hasil perkalian int bisa meluap tanpa peringatan

Perkalian dua int tetap bertipe int, walaupun hasilnya disimpan ke long. Kalau melewati ±2,1 miliar, angkanya berputar menjadi negatif. Ubah salah satu operand menjadi long (akhiran L) sebelum dikalikan, atau pakai Math.multiplyExact agar luapan langsung jadi error.

KODE PEMULA
int hargaSatuan = 2_500_000;
int jumlah = 1_000;
long total = hargaSatuan * jumlah;
System.out.println(total);
KODE RAPI (BEST PRACTICE)
int hargaSatuan = 2_500_000;
int jumlah = 1_000;
long total = (long) hargaSatuan * jumlah;
System.out.println(total);

Poin penting

  • Urutan widening: byte → short → int → long → float → double.
  • Cast (int) memotong pecahan, bukan membulatkan. Pakai Math.round untuk pembulatan.
  • Narrowing di luar rentang menghasilkan overflow: angkanya "berputar" menjadi nilai aneh.
  • String bukan tipe primitif. Untuk mengubah teks ke angka pakai Integer.parseInt("42").
