Access specifier: public, private, protected

Buka versi interaktif

Access specifier menentukan siapa yang boleh melihat sebuah kelas, field, atau method. Ada empat tingkat: public (semua orang), protected (paket yang sama dan subclass), tanpa kata kunci atau package-private (hanya paket yang sama), dan private (hanya kelas itu sendiri).

Aturan praktis bootcamp: buat semua field private, lalu sediakan method public untuk akses yang memang diizinkan. Dengan begitu, aturan seperti "saldo tidak boleh negatif" dijaga di satu tempat.

Jika kode di luar kelas mencoba mengakses field private, compiler langsung menolak. Itu jauh lebih baik daripada bug yang baru ketahuan saat aplikasi sudah dipakai.

JAVA
class Rekening {
    private long saldo;              // hanya kelas ini yang boleh mengubah
    public final String pemilik;

    public Rekening(String pemilik) {
        this.pemilik = pemilik;
    }
    public void setor(long jumlah) {
        if (jumlah > 0) saldo += jumlah;
    }
    public boolean tarik(long jumlah) {
        if (jumlah <= 0 || jumlah > saldo) return false;
        saldo -= jumlah;
        return true;
    }
    public long getSaldo() { return saldo; }
}

public class Bank {
    public static void main(String[] args) {
        Rekening r = new Rekening("Andi");
        r.setor(100_000);
        System.out.println(r.tarik(250_000));
        System.out.println(r.tarik(40_000));
        System.out.println(r.pemilik + ": " + r.getSaldo());
        // r.saldo = 999_999;  // error: saldo has private access
    }
}

Poin penting

  • private < package-private < protected < public.
  • Field private + method public = enkapsulasi.
  • Satu file boleh punya banyak kelas, tapi hanya satu yang public dan namanya sama dengan file.
  • Getter tanpa setter membuat nilai hanya bisa dibaca dari luar.
