Struktur Data Lanjutan

Buka versi interaktif

Hashing adalah rahasia kecepatan HashMap dan HashSet. Sebuah fungsi hash mengubah kunci menjadi angka, lalu angka itu dipetakan ke indeks array yang disebut ember (bucket). Mencari kunci cukup menghitung hash-nya dan langsung melompat ke ember yang tepat, rata-rata O(1).

Dua kunci berbeda bisa jatuh di ember yang sama. Ini disebut collision. Salah satu solusinya adalah separate chaining: setiap ember menyimpan daftar kecil. Agar daftar tetap pendek, tabel diperbesar ketika load factor (jumlah data dibagi jumlah ember) terlalu tinggi.

Priority queue selalu mengeluarkan elemen dengan prioritas tertinggi, misalnya angka terkecil. Implementasinya memakai heap: pohon biner lengkap yang disimpan dalam array, dengan aturan setiap induk lebih kecil dari anaknya. Menambah dan mengambil elemen sama-sama O(log n).

JAVA
import java.util.*;

public class Lanjutan {
    public static void main(String[] args) {
        // HashMap memakai hashCode() untuk memilih ember
        Map<String, Integer> umur = new HashMap<>();
        umur.put("Ani", 20);
        System.out.println(umur.get("Ani"));     // rata-rata O(1)

        // PriorityQueue = min-heap: terkecil keluar duluan
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        pq.add(42);
        pq.add(7);
        pq.add(19);
        while (!pq.isEmpty()) {
            System.out.print(pq.remove() + " ");
        }
    }
}
KELUARAN
20
7 19 42

Poin penting

  • Di Java, objek yang dijadikan kunci harus meng-override equals dan hashCode secara konsisten.
  • Kunci HashMap sebaiknya immutable, misalnya String atau Integer, dengan equals dan hashCode yang konsisten.
  • Pada heap berbasis array, anak dari indeks i ada di 2i+1 dan 2i+2.
  • Heap dipakai di algoritma Dijkstra, penjadwalan, dan heap sort.
