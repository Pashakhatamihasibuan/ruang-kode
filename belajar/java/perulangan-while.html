MaksudKode
Selama n masih lebih dari 1while (n > 1)
bagi dua nn = n / 2;
dan hitung langkahnyalangkah++;
JAVA
int n = 20;
int langkah = 0;
while (n > 1) {
    n = n / 2;
    langkah++;
}
System.out.println(langkah);
