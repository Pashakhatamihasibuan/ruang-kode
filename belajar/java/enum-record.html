Enum & record

Buka versi interaktif

Enum adalah tipe dengan daftar nilai tetap, misalnya status pesanan atau hari. Dibanding memakai String bebas, enum mencegah salah ketik karena compiler hanya menerima nilai yang terdaftar. Enum juga bisa punya field dan method.

Record (Java 16+) adalah cara singkat membuat kelas pembawa data yang immutable. Cukup satu baris record Titik(int x, int y) {}, Java otomatis membuat konstruktor, getter x(), equals, hashCode, dan toString.

Pakai record untuk data yang tidak berubah seperti hasil query, DTO di API, atau koordinat. Pakai kelas biasa jika objek perlu diubah-ubah.

JAVA
enum Status {
    BARU("Menunggu"), DIKIRIM("Dalam perjalanan"), SELESAI("Diterima");
    private final String label;
    Status(String label) { this.label = label; }
    String label() { return label; }
}

record Pesanan(int id, String barang, Status status) {}

public class Toko {
    public static void main(String[] args) {
        Pesanan p = new Pesanan(101, "Kopi Gayo", Status.DIKIRIM);
        System.out.println(p);
        System.out.println(p.barang() + " - " + p.status().label());
        System.out.println(p.equals(new Pesanan(101, "Kopi Gayo", Status.DIKIRIM)));
        StringBuilder sb = new StringBuilder();
        for (Status s : Status.values()) {
            sb.append(s).append("(").append(s.ordinal()).append(") ");
        }
        System.out.println(sb.toString().trim());
        System.out.println(Status.valueOf("SELESAI").label());
    }
}
KELUARAN
Pesanan[id=101, barang=Kopi Gayo, status=DIKIRIM]
Kopi Gayo - Dalam perjalanan
true
BARU(0) DIKIRIM(1) SELESAI(2)
Diterima

Kode pemula vs kode rapi

Kelas data cukup ditulis sebagai record

Kelas yang hanya membawa data biasanya butuh field, konstruktor, getter, equals, hashCode, dan toString. record (Java 16) membuat semuanya otomatis dan nilainya tidak bisa diubah.

KODE PEMULA
class Produk {
    private final String nama;
    private final int harga;
    Produk(String nama, int harga) { this.nama = nama; this.harga = harga; }
    String nama() { return nama; }
    int harga() { return harga; }
    @Override public String toString() { return "Produk[nama=" + nama + ", harga=" + harga + "]"; }
}
Produk p = new Produk("Kopi Gayo", 85_000);
System.out.println(p);
System.out.println(p.harga());
KODE RAPI (BEST PRACTICE)
record Produk(String nama, int harga) {}
Produk p = new Produk("Kopi Gayo", 85_000);
System.out.println(p);
System.out.println(p.harga());
KELUARAN KEDUANYA
Produk[nama=Kopi Gayo, harga=85000]
85000

Poin penting

  • Status.values() memberi semua nilai enum berurutan.
  • Enum aman dipakai di switch.
  • Record immutable: field-nya final dan tidak ada setter.
  • Getter record memakai nama field: p.barang(), bukan getBarang().
