JDBC: Java bicara dengan database

Buka versi interaktif

JDBC (Java Database Connectivity) adalah API standar untuk menjalankan SQL dari Java. Alurnya: buka Connection dengan URL database, siapkan PreparedStatement, jalankan, lalu baca ResultSet baris demi baris.

Selalu pakai PreparedStatement dengan tanda tanya ? sebagai tempat nilai. Jangan menyambung input pengguna langsung ke string SQL, karena itu membuka celah SQL injection. Materi SQL di jalur SQL menjelaskan serangan ini secara visual.

Bungkus koneksi dengan try-with-resources supaya tertutup otomatis. Di aplikasi sungguhan, koneksi diambil dari connection pool seperti HikariCP agar tidak membuat koneksi baru setiap query.

JAVA
import java.sql.*;

public class DaftarProduk {
    public static void main(String[] args) throws SQLException {
        String url = "jdbc:postgresql://localhost:5432/toko";
        String sql = "SELECT nama, harga FROM produk WHERE kategori = ? AND harga <= ? ORDER BY harga";

        try (Connection con = DriverManager.getConnection(url, "app", "rahasia");
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setString(1, "Minuman");
            ps.setInt(2, 100_000);
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    System.out.println(rs.getString("nama") + " " + rs.getInt("harga"));
                }
            }
        }
    }
}

Poin penting

  • Connection → PreparedStatement → ResultSet.
  • Tanda ? diisi dengan setString, setInt, dan lainnya.
  • executeQuery untuk SELECT, executeUpdate untuk INSERT/UPDATE/DELETE.
  • Jangan pernah menyambung input pengguna ke SQL.
