Program Pertama

Buka versi interaktif

Program adalah daftar instruksi yang dijalankan komputer satu per satu. Setiap instruksi disebut statement. Di Java, statement diakhiri titik koma dan dikelompokkan dengan kurung kurawal.

Java dikompilasi: perintah javac memeriksa seluruh kode lalu menerjemahkannya menjadi bytecode, kemudian JVM menjalankannya. Kesalahan sintaks sudah ketahuan sebelum program berjalan.

Begitu program bertambah panjang, pecah menjadi bagian kecil bernama method. Teknik ini disebut dekomposisi prosedural. Setiap bagian punya satu tugas yang jelas dan bisa dipanggil berkali-kali.

JAVA
public class Halo {
    public static void main(String[] args) {
        System.out.println("Halo, dunia!");
        sapa();
        sapa();
    }

    // static method: memecah program jadi bagian kecil
    public static void sapa() {
        System.out.println("Selamat belajar!");
    }
}
KELUARAN
Halo, dunia!
Selamat belajar!
Selamat belajar!

Poin penting

  • Java wajib punya kelas dan method main sebagai titik awal.
  • Program Java selalu mulai dari method main, lalu dijalankan dari atas ke bawah.
  • Komentar (// untuk satu baris, /* ... */ untuk beberapa baris) diabaikan komputer.
  • Nama method/fungsi sebaiknya kata kerja: cetakLaporan, cetak_laporan.
