Framework web lain: Quarkus, Javalin, Play

Buka versi interaktif

Selain Spring Boot, ada beberapa framework web Java dengan karakter berbeda. Quarkus dirancang untuk cloud dan container: startup sangat cepat dan hemat memori, bahkan bisa dikompilasi menjadi native executable dengan GraalVM.

Javalin adalah framework mini yang sangat sederhana, cocok untuk belajar atau layanan kecil: beberapa baris sudah menjadi API. Play Framework bersifat reaktif dan tanpa state, populer untuk aplikasi web dengan Scala dan Java.

Pilih berdasarkan kebutuhan: Spring Boot untuk ekosistem terlengkap dan lowongan kerja terbanyak, Quarkus untuk microservice di Kubernetes, Javalin untuk API kecil yang cepat dibuat.

JAVA
// Javalin: REST API dalam beberapa baris
import io.javalin.Javalin;
import java.util.Map;

public class ApiMini {
    public static void main(String[] args) {
        var app = Javalin.create().start(7070);
        app.get("/halo", ctx -> ctx.result("Halo dari Javalin"));
        app.get("/produk/{id}", ctx -> {
            int id = Integer.parseInt(ctx.pathParam("id"));
            ctx.json(Map.of("id", id, "nama", "Kopi Gayo"));
        });
    }
}

// Quarkus: gaya anotasi JAX-RS
@Path("/halo")
public class HaloResource {
    @GET
    public String halo() { return "Halo dari Quarkus"; }
}

Poin penting

  • Spring Boot: ekosistem terbesar.
  • Quarkus: startup cepat, cocok untuk container.
  • Javalin: minimalis, mudah dipelajari.
  • Play: reaktif, tanpa state.
