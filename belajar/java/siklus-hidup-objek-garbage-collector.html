Siklus hidup objek & garbage collector

Buka versi interaktif

Setiap new membuat objek baru di area memori bernama heap. Variabel hanya menyimpan referensi (alamat) ke objek itu. Objek bisa punya banyak referensi sekaligus.

Ketika tidak ada lagi referensi yang menunjuk sebuah objek, objek itu tidak terjangkau. Di Java kamu tidak menghapus objek secara manual. Garbage collector (GC) milik JVM berkala mencari objek tak terjangkau lalu membebaskan memorinya.

Siklus hidupnya: dibuat (new + konstruktor), dipakai, tidak terjangkau, lalu dibersihkan GC. Kamu tidak bisa memastikan kapan GC berjalan, jadi jangan menaruh logika penting di sana. Untuk menutup file atau koneksi, pakai try-with-resources.

JAVA
class Kotak {
    String label;
    Kotak(String label) {
        this.label = label;
        System.out.println("Dibuat: " + label);
    }
}

public class Siklus {
    public static void main(String[] args) {
        Kotak a = new Kotak("A");
        Kotak b = new Kotak("B");
        Kotak c = a;          // dua referensi ke objek A
        a = null;             // A masih dijangkau lewat c
        b = null;             // B tidak terjangkau lagi -> calon GC
        System.out.println(c.label);
        c = new Kotak("C");   // A kini juga tidak terjangkau
        System.out.println(c.label);
    }
}
KELUARAN
Dibuat: A
Dibuat: B
A
Dibuat: C
C

Soal latihan

  1. Tandai kapan objek "Kopi" boleh dibersihkan garbage collector:
    Produk p = new Produk("Kopi");
    Produk q = p;
    p = null;
    q = new Produk("Teh");

    Petunjuk

    Objek bisa dibersihkan jika tidak ada lagi variabel yang merujuknya.

    Lihat jawaban
    CONTOH
    Baris 1: objek Kopi dirujuk p.
Baris 2: Kopi dirujuk p dan q.
Baris 3: p = null, Kopi masih dirujuk q.
Baris 4: q menunjuk Teh. Kopi tidak dirujuk siapa pun,
        sekarang Kopi boleh dibersihkan GC (kapan tepatnya ditentukan JVM).

  2. Pakai try-with-resources agar sumber daya ditutup otomatis. Buat kelas Koneksi yang implements AutoCloseable dan mencetak "dibuka", "dipakai", "ditutup".

    Petunjuk

    Jangan mengandalkan finalize() (sudah usang). Pakai AutoCloseable.

    Lihat jawaban
    JAVA
    class Koneksi implements AutoCloseable {
    Koneksi() { System.out.println("dibuka"); }
    void pakai() { System.out.println("dipakai"); }
    @Override public void close() { System.out.println("ditutup"); }
}

public class Main {
    public static void main(String[] args) {
        try (Koneksi k = new Koneksi()) {
            k.pakai();
        }
    }
}
    KELUARAN
    dibuka
dipakai
ditutup

Poin penting

  • Variabel menyimpan referensi, objeknya ada di heap.
  • Objek tanpa referensi menjadi calon garbage collection.
  • null berarti referensi tidak menunjuk objek apa pun.
  • GC berjalan otomatis; jangan bergantung pada waktunya.
