Overloading, overriding & binding

Buka versi interaktif

Overloading: beberapa method dengan nama sama tetapi daftar parameter berbeda, di kelas yang sama. Compiler memilih versi yang cocok berdasarkan tipe argumen saat kompilasi. Ini disebut static binding.

Overriding: subclass menulis ulang method milik superclass dengan tanda tangan yang sama. Versi yang dijalankan ditentukan oleh tipe objek sebenarnya saat program berjalan. Ini disebut dynamic binding dan menjadi dasar polimorfisme.

Tulis anotasi @Override di atas method yang menimpa. Jika kamu salah ketik nama atau parameter, compiler langsung memberi tahu.

JAVA
class Hewan {
    String suara() { return "..."; }
}
class Kucing extends Hewan {
    @Override
    String suara() { return "Meong"; }
}

public class Binding {
    static String jelaskan(Hewan h) { return "Hewan"; }
    static String jelaskan(Kucing k) { return "Kucing"; }

    static int tambah(int a, int b) { return a + b; }
    static double tambah(double a, double b) { return a + b; }

    public static void main(String[] args) {
        Hewan h = new Kucing();
        System.out.println(h.suara());       // dynamic: tipe objek
        System.out.println(jelaskan(h));     // static: tipe variabel
        System.out.println(tambah(2, 3));
        System.out.println(tambah(2.5, 3));
    }
}

Poin penting

  • Overloading = nama sama, parameter beda; dipilih saat kompilasi.
  • Overriding = tanda tangan sama di subclass; dipilih saat runtime.
  • Method static, private, dan final tidak bisa di-override.
  • Selalu pakai @Override.
