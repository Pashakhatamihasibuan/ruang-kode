Membuat Kelas Koleksi

Buka versi interaktif

Di bab ini kamu membangun versi sederhana ArrayList bernama ArrayIntList. Di dalamnya ada sebuah array biasa (elementData) dan penghitung size. Pengguna kelas hanya melihat method add, get, size, dan seterusnya.

Perbedaan size dan kapasitas adalah kunci. Kapasitas adalah panjang array internal. Size adalah berapa slot yang benar-benar terisi. Saat size sama dengan kapasitas, kelas membuat array baru dua kali lebih besar lalu menyalin isinya. Karena pembesaran jarang terjadi, rata-rata add tetap cepat.

Kelas yang baik memeriksa precondition, yaitu syarat yang harus dipenuhi pemanggil. Misalnya indeks untuk get harus di antara 0 dan size - 1. Bila dilanggar, lempar exception dengan pesan yang jelas, jangan diam-diam mengembalikan nilai sampah.

JAVA
import java.util.Arrays;

public class ArrayIntList {
    private int[] elementData;   // array internal
    private int size;            // jumlah slot terpakai

    public ArrayIntList() {
        elementData = new int[4];
        size = 0;
    }

    public void add(int nilai) {
        if (size == elementData.length) {         // penuh?
            elementData = Arrays.copyOf(elementData, size * 2);
        }
        elementData[size] = nilai;
        size++;
    }

    public int get(int i) {
        if (i < 0 || i >= size) {                 // precondition
            throw new IndexOutOfBoundsException("indeks: " + i);
        }
        return elementData[i];
    }

    public int size() {
        return size;
    }
}

Poin penting

  • Field selalu private. Pengguna tidak boleh mengubah size langsung.
  • Slot di atas size berisi sisa data yang tidak dianggap ada.
  • Dokumentasikan precondition dan postcondition setiap method.
  • Implementasikan Iterable agar objekmu bisa dipakai di for-each seperti list.

Cek pemahaman

Kapasitas 4 dan sudah berisi 4 elemen. Setelah add sekali lagi, kapasitasnya menjadi...

Jawaban: 8

Array internal digandakan dari 4 menjadi 8.

Mengapa size dan kapasitas dipisah?

Jawaban: Supaya add tidak perlu membuat array baru setiap kali

Slot cadangan membuat sebagian besar add cukup mengisi slot kosong.
