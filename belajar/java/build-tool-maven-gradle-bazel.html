Build tool: Maven, Gradle, Bazel

Buka versi interaktif

Proyek nyata punya puluhan library (dependency), tes, dan langkah pengemasan. Build tool mengotomatiskan semuanya: mengunduh library, mengompilasi, menjalankan tes, dan membungkus aplikasi menjadi file .jar siap dijalankan.

Maven memakai file XML pom.xml dan siklus hidup baku: validate → compile → test → package → install → deploy. Menjalankan satu tahap otomatis menjalankan tahap sebelumnya. Gradle memakai skrip Groovy/Kotlin (build.gradle.kts) yang lebih ringkas dan cepat berkat cache; Gradle juga menjadi standar proyek Android.

Bazel dari Google dirancang untuk monorepo raksasa dengan banyak bahasa. Untuk proyek belajar dan kebanyakan perusahaan, Maven atau Gradle sudah lebih dari cukup.

CONTOH
<!-- pom.xml (Maven) -->
<project>
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.toko</groupId>
  <artifactId>kasir</artifactId>
  <version>1.0.0</version>
  <properties>
    <maven.compiler.release>21</maven.compiler.release>
  </properties>
  <dependencies>
    <dependency>
      <groupId>org.junit.jupiter</groupId>
      <artifactId>junit-jupiter</artifactId>
      <version>5.10.2</version>
      <scope>test</scope>
    </dependency>
  </dependencies>
</project>

// build.gradle.kts (Gradle, isi yang setara)
plugins { java }
java { toolchain { languageVersion = JavaLanguageVersion.of(21) } }
repositories { mavenCentral() }
dependencies { testImplementation("org.junit.jupiter:junit-jupiter:5.10.2") }

# Perintah yang sering dipakai
mvn package          # compile + test + buat target/kasir-1.0.0.jar
./gradlew build      # setara di Gradle

Poin penting

  • Dependency ditulis dengan koordinat groupId:artifactId:version.
  • Library diunduh otomatis dari Maven Central.
  • Maven: konvensi kuat, XML. Gradle: skrip ringkas, build inkremental.
  • Tahap test berjalan otomatis sebelum package.
