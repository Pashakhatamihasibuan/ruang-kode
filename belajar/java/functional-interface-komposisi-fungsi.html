Functional interface & komposisi fungsi

Buka versi interaktif

Functional interface adalah interface dengan tepat satu method abstrak. Lambda bisa dipakai di mana pun functional interface diminta. Paket java.util.function menyediakan yang paling umum: Function<T,R> (ubah T jadi R), Predicate<T> (uji benar/salah), Consumer<T> (pakai tanpa hasil), dan Supplier<T> (hasilkan nilai).

Higher-order function adalah fungsi yang menerima atau mengembalikan fungsi lain. Contohnya method yang menerima Predicate untuk menentukan data mana yang disaring.

Komposisi fungsi merangkai fungsi kecil menjadi fungsi besar: f.andThen(g) menjalankan f lalu g, f.compose(g) menjalankan g dulu baru f. Predicate bisa digabung dengan and, or, dan negate.

JAVA
import java.util.function.*;

public class Fungsi {
    static Function<Integer, Integer> kaliDengan(int n) {   // mengembalikan fungsi
        return x -> x * n;
    }

    public static void main(String[] args) {
        Function<Integer, Integer> tambah10 = x -> x + 10;
        Function<Integer, Integer> kali2 = kaliDengan(2);
        System.out.println(tambah10.andThen(kali2).apply(5));
        System.out.println(tambah10.compose(kali2).apply(5));

        Predicate<String> panjang = s -> s.length() > 4;
        Predicate<String> awalanK = s -> s.startsWith("K");
        System.out.println(panjang.and(awalanK).test("Kopi"));
        System.out.println(panjang.and(awalanK).test("Keripik"));

        Supplier<String> sapa = () -> "Halo";
        Consumer<String> cetak = System.out::println;
        cetak.accept(sapa.get());

        BinaryOperator<Integer> maks = Math::max;
        System.out.println(maks.apply(3, 9));
    }
}

Poin penting

  • Functional interface = satu method abstrak; tandai dengan @FunctionalInterface.
  • Method reference Kelas::method adalah lambda yang lebih ringkas.
  • andThen = kiri ke kanan, compose = kanan ke kiri.
  • Fungsi yang mengembalikan fungsi memungkinkan "pabrik" perilaku.

Cek pemahaman
