Generics: kode yang aman tipe

Buka versi interaktif

Generics membuat kelas dan method bisa bekerja dengan berbagai tipe sambil tetap diperiksa compiler. List<String> hanya menerima String, sehingga kamu tidak perlu cast dan tidak akan kemasukan tipe lain.

Kamu bisa membuat kelas generik sendiri dengan parameter tipe seperti <T>. Huruf T adalah penampung yang diganti tipe sungguhan saat kelas dipakai: Kotak<Integer>, Kotak<String>.

Batas tipe (bounded type) seperti <T extends Number> berarti T harus Number atau turunannya, sehingga method di dalamnya boleh memanggil doubleValue(). Wildcard ? dipakai pada parameter yang menerima "list berisi tipe apa pun".

JAVA
import java.util.List;

class Kotak<T> {
    private final T isi;
    Kotak(T isi) { this.isi = isi; }
    T ambil() { return isi; }
}

public class Generik {
    static <T> T pertama(List<T> data) {
        return data.get(0);
    }
    static <T extends Number> double jumlah(List<T> angka) {
        double total = 0;
        for (T x : angka) total += x.doubleValue();
        return total;
    }
    static void cetak(List<?> apaSaja) {
        System.out.println("Isi: " + apaSaja);
    }

    public static void main(String[] args) {
        Kotak<String> k = new Kotak<>("rahasia");
        String s = k.ambil();             // tanpa cast
        System.out.println(s.toUpperCase());
        System.out.println(pertama(List.of(3, 1, 2)));
        System.out.println(jumlah(List.of(1.5, 2, 3L)));
        cetak(List.of('a', 'b'));
    }
}

RAHASIA

Soal latihan

  1. Buat kelas generik Pasangan<A, B> dan method generik terbesar yang menerima list bertipe T extends Comparable<T>.

    Petunjuk

    Bounded type: <T extends Comparable<T>>. Bandingkan dengan compareTo.

    Lihat jawaban
    JAVA
    import java.util.List;

record Pasangan<A, B>(A kiri, B kanan) {}

public class Main {
    static <T extends Comparable<T>> T terbesar(List<T> data) {
        T maks = data.get(0);
        for (T x : data) if (x.compareTo(maks) > 0) maks = x;
        return maks;
    }

    public static void main(String[] args) {
        Pasangan<String, Integer> p = new Pasangan<>("Kopi", 18000);
        System.out.println(p.kiri() + " " + p.kanan());
        System.out.println(terbesar(List.of(4, 19, 7)));
        System.out.println(terbesar(List.of("apel", "jeruk", "mangga")));
    }
}
    KELUARAN
    Kopi 18000
19
mangga

  2. Tulis method yang menjumlahkan list angka apa pun (Integer, Double) memakai wildcard.

    Petunjuk

    List<? extends Number> lalu panggil doubleValue().

    Lihat jawaban
    JAVA
    import java.util.List;

public class Main {
    static double jumlah(List<? extends Number> data) {
        double t = 0;
        for (Number n : data) t += n.doubleValue();
        return t;
    }

    public static void main(String[] args) {
        System.out.println(jumlah(List.of(1, 2, 3)));
        System.out.println(jumlah(List.of(1.5, 2.5)));
    }
}
    KELUARAN
    6.0
4.0

Kode pemula vs kode rapi

Menghitung kemunculan dengan merge

Pola "kalau kunci sudah ada tambah satu, kalau belum isi satu" bisa diganti Map.merge. Diamond <> juga membuat tipe tidak perlu ditulis dua kali.

KODE PEMULA
String[] belanja = {"kopi", "teh", "kopi", "gula", "kopi"};
TreeMap<String, Integer> hitung = new TreeMap<String, Integer>();
for (String b : belanja) {
    if (hitung.containsKey(b)) {
        hitung.put(b, hitung.get(b) + 1);
    } else {
        hitung.put(b, 1);
    }
}
System.out.println(hitung);
KODE RAPI (BEST PRACTICE)
String[] belanja = {"kopi", "teh", "kopi", "gula", "kopi"};
Map<String, Integer> hitung = new TreeMap<>();
for (String b : belanja) hitung.merge(b, 1, Integer::sum);
System.out.println(hitung);
KELUARAN KEDUANYA
{gula=1, kopi=3, teh=1}

Poin penting

  • Generics memindahkan kesalahan tipe dari runtime ke waktu kompilasi.
  • Nama parameter tipe yang lazim: T (type), E (element), K/V (key/value).
  • <> (diamond) membiarkan compiler menebak tipe di sisi kanan.
  • Generics tidak menerima primitif: pakai Integer, Double, dan lainnya.
