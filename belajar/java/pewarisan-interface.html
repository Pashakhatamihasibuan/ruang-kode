Pewarisan & Interface

Buka versi interaktif

Pewarisan membuat kelas baru dari kelas yang sudah ada. Kucing extends Hewan berarti Kucing otomatis punya semua field dan method Hewan. Kelas induk disebut superclass, kelas anak disebut subclass. Hubungannya selalu "adalah": kucing adalah hewan.

Subclass boleh meng-override method induk untuk mengganti perilakunya. Karena itu, variabel bertipe Hewan bisa menunjuk Kucing atau Anjing, dan h.suara() menjalankan versi milik objek sebenarnya. Inilah polimorfisme.

Interface adalah kontrak berisi daftar method tanpa isi. Kelas yang meng-implement-nya wajib menyediakan semua method itu. Kelas abstrak berada di tengah: boleh punya method lengkap dan method abstrak, tapi tidak bisa dibuat objeknya langsung. Lab "Critters" di buku ini melatih semua konsep tersebut.

JAVA
interface Bersuara {
    String suara();
}

abstract class Hewan implements Bersuara {
    protected String nama;
    public Hewan(String nama) { this.nama = nama; }
    public String kenalkan() {
        return nama + " berkata " + suara();
    }
}

class Kucing extends Hewan {
    public Kucing(String n) { super(n); }
    public String suara() { return "Meong"; }
}

class Anjing extends Hewan {
    public Anjing(String n) { super(n); }
    public String suara() { return "Guk"; }
}

public class Kebun {
    public static void main(String[] args) {
        Hewan[] kebun = { new Kucing("Tom"), new Anjing("Spike") };
        for (Hewan h : kebun) {
            System.out.println(h.kenalkan());   // polimorfisme
        }
    }
}
KELUARAN
Tom berkata Meong
Spike berkata Guk

Poin penting

  • super(...) memanggil konstruktor induk.
  • Java hanya mengizinkan satu superclass, tapi banyak interface.
  • Python mengizinkan banyak kelas induk sekaligus.
  • Override: nama dan parameter sama. Overload: nama sama, parameter berbeda.
