Kelas bersarang & initializer block

Buka versi interaktif

Kelas bisa ditulis di dalam kelas lain. Static nested class berdiri sendiri dan sering dipakai untuk kelas pembantu, misalnya Node di dalam LinkedList. Inner class (non-static) terikat pada objek luarnya dan bisa mengakses field objek itu.

Anonymous class adalah kelas tanpa nama yang dibuat sekaligus dipakai, biasanya untuk mengimplementasi interface sekali pakai. Sejak Java 8, banyak anonymous class diganti lambda.

Initializer block adalah blok { ... } di dalam kelas yang berjalan setiap objek dibuat, sebelum isi konstruktor. Versi static { ... } berjalan sekali saat kelas pertama kali dimuat, cocok untuk menyiapkan data statis.

JAVA
public class Luar {
    static int dimuat;
    int nomor;

    static {                         // sekali, saat kelas dimuat
        dimuat = 1;
        System.out.println("static block");
    }
    {                                // setiap objek dibuat
        nomor = 7;
        System.out.println("instance block");
    }
    Luar() { System.out.println("konstruktor, nomor=" + nomor); }

    static class Pembantu {           // static nested
        String sapa() { return "halo dari Pembantu"; }
    }
    class Dalam {                     // inner: butuh objek Luar
        int ambil() { return nomor * 2; }
    }

    public static void main(String[] args) {
        Luar o = new Luar();
        System.out.println(new Pembantu().sapa());
        Luar.Dalam d = o.new Dalam();
        System.out.println(d.ambil());
        Runnable r = new Runnable() {     // anonymous class
            public void run() { System.out.println("anonim jalan"); }
        };
        r.run();
    }
}

Poin penting

  • Urutan: static block (sekali) → instance block → konstruktor.
  • Static nested class tidak butuh objek luar.
  • Inner class dibuat lewat objek luar: luar.new Dalam().
  • Anonymous class untuk implementasi sekali pakai; lambda lebih ringkas.
