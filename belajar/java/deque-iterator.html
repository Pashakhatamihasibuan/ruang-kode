Deque & Iterator

Buka versi interaktif

Deque (double-ended queue, dibaca "dek") bisa ditambah dan diambil dari kedua ujung. ArrayDeque adalah implementasi yang cepat dan direkomendasikan untuk menggantikan kelas Stack lama maupun sebagai antrean.

Sebagai stack, pakai push, pop, dan peek. Sebagai queue, pakai offer, poll, dan peek. Satu kelas, dua peran.

Iterator adalah objek penunjuk yang berjalan di atas koleksi dengan hasNext() dan next(). Loop for-each sebenarnya memakai iterator di balik layar. Gunakan iterator secara langsung jika ingin menghapus elemen saat berjalan dengan it.remove(), karena menghapus lewat list saat for-each memicu ConcurrentModificationException.

JAVA
import java.util.*;

public class DekIter {
    public static void main(String[] args) {
        Deque<String> tumpuk = new ArrayDeque<>();
        tumpuk.push("piring1");
        tumpuk.push("piring2");
        System.out.println(tumpuk.pop());

        Deque<String> antre = new ArrayDeque<>();
        antre.offer("Ani");
        antre.offer("Bayu");
        antre.offerFirst("VIP");
        System.out.println(antre.poll() + " " + antre);

        List<Integer> nilai = new ArrayList<>(List.of(80, 45, 90, 30));
        Iterator<Integer> it = nilai.iterator();
        while (it.hasNext()) {
            if (it.next() < 50) it.remove();
        }
        System.out.println(nilai);
    }
}
KELUARAN
piring2
VIP [Ani, Bayu]
[80, 90]

Kode pemula vs kode rapi

Menghapus isi list sambil melooping

Menghapus elemen di dalam for-each membuat iterator bingung dan Java melempar ConcurrentModificationException. removeIf menghapus dengan aman dalam satu baris.

KODE PEMULA
List<Integer> stok = new ArrayList<>(List.of(5, 0, 12, 0, 7));
for (Integer s : stok) {
    if (s == 0) stok.remove(s);
}
System.out.println(stok);
KODE RAPI (BEST PRACTICE)
List<Integer> stok = new ArrayList<>(List.of(5, 0, 12, 0, 7));
stok.removeIf(s -> s == 0);
System.out.println(stok);

Poin penting

  • ArrayDeque lebih disarankan daripada Stack dan LinkedList.
  • Stack: push/pop/peek. Queue: offer/poll/peek.
  • offerFirst/offerLast memilih ujung.
  • Hapus saat iterasi hanya lewat iterator.remove() atau removeIf.
