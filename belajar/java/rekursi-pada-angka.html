Jumlah digit dari angka satu digit adalah angka itu sendiriif (n < 10) return n;
selain itu: digit terakhir + jumlah digit sisanyareturn n % 10 + jumlahDigit(n / 10);
JAVA
int jumlahDigit(int n) {
    if (n < 10) return n;
    return n % 10 + jumlahDigit(n / 10);
}
// dipanggil: jumlahDigit(472)
