ORM: Hibernate, Spring Data JPA, Ebean

Buka versi interaktif

Menulis JDBC untuk setiap tabel itu melelahkan. ORM (Object-Relational Mapping) memetakan kelas Java ke tabel database: satu objek = satu baris, satu field = satu kolom. Kamu bekerja dengan objek, ORM yang menulis SQL-nya.

JPA adalah standar anotasinya (@Entity, @Id, @ManyToOne), dan Hibernate adalah implementasi paling populer. Spring Data JPA melangkah lebih jauh: cukup tulis interface repository, dan query seperti findByKategori dibuat otomatis dari nama method.

Ebean adalah ORM alternatif yang lebih sederhana. Apa pun ORM-nya, tetap pahami SQL: kamu perlu membaca query yang dihasilkan untuk menemukan masalah performa seperti N+1 query.

JAVA
@Entity
@Table(name = "produk")
public class Produk {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String nama;
    private String kategori;
    private Integer harga;
    // getter & setter
}

public interface ProdukRepository extends JpaRepository<Produk, Long> {
    List<Produk> findByKategoriOrderByHargaAsc(String kategori);

    @Query("SELECT p FROM Produk p WHERE p.harga > :min")
    List<Produk> mahalDari(@Param("min") int min);
}

// Pemakaian di service
List<Produk> minuman = repo.findByKategoriOrderByHargaAsc("Minuman");
// SQL yang dibuat: select ... from produk where kategori=? order by harga asc

Poin penting

  • ORM memetakan kelas ke tabel.
  • JPA = standar, Hibernate = implementasi.
  • Spring Data membuat query dari nama method.
  • Tetap periksa SQL yang dihasilkan ORM.
