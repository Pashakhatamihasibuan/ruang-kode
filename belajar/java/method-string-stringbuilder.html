Method String & StringBuilder

Buka versi interaktif

String di Java adalah objek yang immutable: isinya tidak bisa diubah. Method seperti toUpperCase() atau replace() tidak mengubah string lama, melainkan mengembalikan string baru. Itu sebabnya kamu harus menyimpan hasilnya: s = s.trim();.

Membandingkan isi string wajib memakai equals, bukan ==. Operator == membandingkan alamat objek, sehingga dua string dengan isi sama bisa dianggap berbeda.

Kalau kamu menyambung teks berkali-kali di dalam loop, gunakan StringBuilder. Ia bisa diubah di tempat sehingga jauh lebih hemat daripada membuat string baru di setiap putaran.

JAVA
public class Teks {
    public static void main(String[] args) {
        String nama = "  Budi Santoso  ";
        String rapi = nama.trim();
        System.out.println(rapi.toUpperCase());
        System.out.println(rapi.length());
        System.out.println(rapi.indexOf("Santoso"));
        System.out.println(rapi.substring(0, 4));
        System.out.println(rapi.replace("Budi", "Bu"));
        System.out.println(rapi.contains("ant"));

        String a = "halo";
        String b = new String("halo");
        System.out.println(a == b);
        System.out.println(a.equals(b));

        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 5; i++) {
            sb.append(i).append(i < 5 ? "-" : "");
        }
        System.out.println(sb.toString());
        System.out.println(String.join(", ", "Java", "Python", "SQL"));
    }
}

Poin penting

  • String immutable: method string selalu mengembalikan string baru.
  • Bandingkan isi dengan equals atau equalsIgnoreCase.
  • substring(a, b) mengambil indeks a sampai sebelum b.
  • StringBuilder untuk menyusun teks panjang di dalam loop.

Cek pemahaman

Hasil <code>"kopi".substring(1, 3)</code>?

Jawaban: "op"

Indeks 1 sampai sebelum 3: huruf o dan p.

Cara benar membandingkan isi dua String?

Jawaban: a.equals(b)

== membandingkan alamat objek, equals membandingkan isi.
