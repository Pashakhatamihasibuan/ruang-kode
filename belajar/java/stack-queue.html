Stack & Queue

Buka versi interaktif

Stack (tumpukan) bekerja seperti tumpukan piring: yang terakhir ditaruh, pertama diambil (LIFO, last in first out). Operasinya push untuk menaruh, pop untuk mengambil, dan peek untuk melihat yang paling atas.

Queue (antrean) bekerja seperti antrean kasir: yang pertama datang, pertama dilayani (FIFO, first in first out). Elemen ditambah di belakang dan diambil dari depan.

Keduanya terlihat sederhana tetapi dipakai di mana-mana. Tombol undo dan pengecekan kurung seimbang memakai stack. Antrean cetak, penjadwalan proses, dan pencarian melebar (BFS) memakai queue.

JAVA
import java.util.*;

public class TumpukAntre {
    public static void main(String[] args) {
        Stack<String> tumpukan = new Stack<>();
        tumpukan.push("piring1");
        tumpukan.push("piring2");
        System.out.println(tumpukan.pop());   // LIFO

        Queue<String> antre = new LinkedList<>();
        antre.add("Ani");
        antre.add("Budi");
        System.out.println(antre.remove());   // FIFO
    }
}

Poin penting

  • Stack dan queue hanya mengizinkan akses di ujungnya. Tidak ada akses indeks.
  • Java: Stack atau ArrayDeque. Queue memakai LinkedList.
  • Python: list untuk stack, collections.deque untuk queue.
  • list.pop(0) di Python lambat (O(n)). Pakai deque.popleft().

Cek pemahaman

Push 1, 2, 3 ke stack, lalu pop sekali. Nilai apa yang keluar?

Jawaban: 3

LIFO: yang terakhir masuk (3) keluar pertama.

Antrean dokumen ke printer paling cocok memakai...

Jawaban: Queue

Dokumen dicetak sesuai urutan kedatangan: FIFO.
