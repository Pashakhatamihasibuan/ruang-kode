File modern dengan java.nio

Buka versi interaktif

Paket java.nio.file menyediakan cara modern dan ringkas untuk bekerja dengan file. Path mewakili lokasi file, dan kelas Files berisi method statis: writeString, readString, readAllLines, lines, exists, delete.

Untuk file besar, jangan baca semuanya sekaligus. Pakai Files.lines(path) yang menghasilkan stream baris demi baris, dan bungkus dengan try-with-resources supaya file ditutup otomatis.

Operasi file bisa gagal (file tidak ada, tidak punya izin), jadi method-method ini melempar IOException yang wajib ditangani.

JAVA
import java.io.IOException;
import java.nio.file.*;
import java.util.List;
import java.util.stream.Stream;

public class Berkas {
    public static void main(String[] args) throws IOException {
        Path p = Path.of("catatan.txt");
        Files.writeString(p, "kopi,85000\nteh,25000\nmadu,120000\n");

        List<String> baris = Files.readAllLines(p);
        System.out.println(baris.size() + " baris");

        try (Stream<String> s = Files.lines(p)) {
            int total = s.mapToInt(b -> Integer.parseInt(b.split(",")[1])).sum();
            System.out.println("Total " + total);
        }

        Files.writeString(p, "gula,18000\n", StandardOpenOption.APPEND);
        System.out.println(Files.readAllLines(p).get(3));
        System.out.println(Files.exists(p));
        Files.delete(p);
        System.out.println(Files.exists(p));
    }
}
KELUARAN
3 baris
Total 230000
gula,18000
true
false

Poin penting

  • Path.of("nama") membuat path.
  • Files.readAllLines untuk file kecil, Files.lines untuk file besar.
  • StandardOpenOption.APPEND menambah di akhir file.
  • Bungkus stream file dengan try-with-resources.
