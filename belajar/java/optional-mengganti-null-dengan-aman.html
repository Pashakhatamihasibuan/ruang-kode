Optional: mengganti null dengan aman

Buka versi interaktif

NullPointerException adalah salah satu bug paling sering di Java. Optional<T> adalah wadah yang mungkin berisi nilai, mungkin kosong. Dengan mengembalikan Optional, method memberi tahu pemanggilnya secara jelas: "hasilnya bisa tidak ada, tangani itu".

Daripada memeriksa if (x != null), kamu merangkai operasi: map untuk mengubah isi jika ada, filter untuk menyaring, orElse untuk nilai cadangan, dan ifPresent untuk menjalankan sesuatu hanya jika ada isinya.

Pakai Optional sebagai tipe kembalian method. Jangan memakainya untuk field atau parameter, dan hindari get() tanpa pemeriksaan karena akan melempar exception jika kosong.

JAVA
import java.util.*;

public class Opsional {
    static Map<String, String> kotaPelanggan = Map.of("Andi", "Jakarta", "Budi", "Bandung");

    static Optional<String> cariKota(String nama) {
        return Optional.ofNullable(kotaPelanggan.get(nama));
    }

    public static void main(String[] args) {
        System.out.println(cariKota("Andi").map(String::toUpperCase).orElse("-"));
        System.out.println(cariKota("Gita").map(String::toUpperCase).orElse("-"));
        cariKota("Budi").ifPresent(k -> System.out.println("Kirim ke " + k));
        System.out.println(cariKota("Andi").filter(k -> k.startsWith("B")).isPresent());
        String kota = cariKota("Zaki").orElseGet(() -> "Kota belum diisi");
        System.out.println(kota);
    }
}
KELUARAN
JAKARTA

Poin penting

  • Optional.ofNullable(x) membungkus nilai yang mungkin null.
  • orElse memberi nilai cadangan.
  • map hanya berjalan jika ada isi.
  • Jangan memanggil get() tanpa memeriksa isinya.
