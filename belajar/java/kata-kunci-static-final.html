Kata kunci static & final

Buka versi interaktif

static berarti "milik kelas, bukan milik objek". Field static hanya ada satu salinan yang dipakai bersama semua objek. Method static bisa dipanggil tanpa membuat objek, seperti Math.max. Karena tidak terikat objek, method static tidak bisa memakai this.

final berarti "tidak bisa diubah lagi". Variabel final hanya bisa diisi sekali. Method final tidak bisa di-override, dan kelas final tidak bisa diturunkan (contohnya String).

Gabungan static final dipakai untuk konstanta, ditulis HURUF_BESAR dengan garis bawah, misalnya static final double PAJAK = 0.11;.

JAVA
class Siswa {
    static int jumlah = 0;          // satu untuk semua objek
    static final int MAKS = 30;     // konstanta
    final String nis;               // diisi sekali di konstruktor
    String nama;

    Siswa(String nis, String nama) {
        this.nis = nis;
        this.nama = nama;
        jumlah++;
    }
    static boolean kelasPenuh() {
        return jumlah >= MAKS;
    }
}

public class Sekolah {
    public static void main(String[] args) {
        new Siswa("001", "Rina");
        new Siswa("002", "Sandi");
        Siswa s = new Siswa("003", "Tari");
        s.nama = "Tari A.";          // boleh: bukan final
        // s.nis = "999";            // error: cannot assign a value to final variable
        System.out.println(Siswa.jumlah);
        System.out.println(Siswa.kelasPenuh());
        System.out.println(s.nis + " " + s.nama);
    }
}
KELUARAN
3
false
003 Tari A.

Poin penting

  • Akses anggota static lewat nama kelas: Siswa.jumlah.
  • Method static tidak bisa langsung memakai field non-static.
  • final pada referensi objek: referensinya tetap, tapi isi objeknya masih bisa berubah.
  • Konstanta: static final + HURUF_BESAR.

Cek pemahaman

Jika 3 objek Siswa dibuat, berapa salinan field static <code>jumlah</code>?

Jawaban: 1

Field static milik kelas, hanya satu salinan.

Kelas final berarti?

Jawaban: Tidak bisa diturunkan

Kelas final tidak bisa punya subclass.
