Array

Buka versi interaktif

Array menyimpan banyak nilai bertipe sama di bawah satu nama. Setiap elemen punya indeks mulai dari 0. Array 5 elemen punya indeks 0 sampai 4. Mengakses indeks 5 menghasilkan ArrayIndexOutOfBoundsException. Ukuran array tetap setelah dibuat.

Pola paling umum adalah traversal: mengunjungi setiap elemen dengan loop untuk mencari maksimum, menjumlah, atau menghitung. For-each (for (int x : a) / for x in a) cocok bila kamu tidak butuh indeksnya.

Array dan list adalah objek, jadi variabelnya menyimpan referensi (alamat), bukan isinya. b = a tidak menyalin isi. Keduanya menunjuk array yang sama, sehingga perubahan lewat b juga terlihat di a. Hal yang sama berlaku saat array dikirim sebagai parameter.

JAVA
import java.util.Arrays;

public class Larik {
    public static void main(String[] args) {
        int[] a = {3, 8, 1, 9, 4};
        System.out.println(a[0]);         // 3
        System.out.println(a.length);     // 5

        int maks = a[0];
        for (int x : a) {                 // for-each
            if (x > maks) {
                maks = x;
            }
        }
        System.out.println("Maks: " + maks);

        int[] b = a;      // b menunjuk array yang SAMA
        b[0] = 99;
        System.out.println(Arrays.toString(a));
    }
}
KELUARAN
3
5
Maks: 9
[99, 8, 1, 9, 4]

Poin penting

  • Ukuran array Java tetap setelah dibuat: new int[5].
  • Elemen terakhir array adalah a[a.length - 1]. Java tidak mengenal indeks negatif.
  • Cetak array Java dengan Arrays.toString(a), bukan println(a).
  • Array 2D: int[][] m = new int[3][4];

Cek pemahaman

Array Java berisi 5 elemen. Berapa indeks elemen terakhir?

Jawaban: 4

Indeks mulai dari 0, jadi elemen terakhir ada di panjang - 1.

Setelah b = a; b[0] = 99;, berapa nilai a[0]?

Jawaban: 99

a dan b adalah dua nama untuk array yang sama.
