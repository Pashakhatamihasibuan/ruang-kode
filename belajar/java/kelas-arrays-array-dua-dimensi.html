Kelas Arrays & array dua dimensi

Buka versi interaktif

Kelas java.util.Arrays berisi alat bantu siap pakai: Arrays.toString untuk mencetak isi array, Arrays.sort untuk mengurutkan, Arrays.fill untuk mengisi semua elemen, dan Arrays.copyOf untuk menyalin.

Array dua dimensi adalah array berisi array. Bayangkan tabel: indeks pertama memilih baris, indeks kedua memilih kolom. Ini cocok untuk papan permainan, nilai siswa per mata pelajaran, atau kursi bioskop.

Untuk menelusurinya, pakai loop bersarang: loop luar berjalan per baris, loop dalam per kolom. Panjang baris adalah grid.length, panjang kolom adalah grid[r].length.

JAVA
import java.util.Arrays;

public class Tabel {
    public static void main(String[] args) {
        int[] nilai = {78, 92, 65, 88};
        Arrays.sort(nilai);
        System.out.println(Arrays.toString(nilai));

        int[] salinan = Arrays.copyOf(nilai, 6);
        System.out.println(Arrays.toString(salinan));

        int[][] kursi = new int[2][3];
        kursi[0][1] = 1;
        kursi[1][2] = 1;
        for (int r = 0; r < kursi.length; r++) {
            for (int c = 0; c < kursi[r].length; c++) {
                System.out.print((c > 0 ? " " : "") + (kursi[r][c] == 1 ? "X" : "."));
            }
            System.out.println();
        }
        System.out.println(Arrays.deepToString(kursi));
    }
}
KELUARAN
[65, 78, 88, 92]
[65, 78, 88, 92, 0, 0]
. X .
. . X
[[0, 1, 0], [0, 0, 1]]

Poin penting

  • Mencetak array langsung menampilkan alamat aneh. Pakai Arrays.toString.
  • Arrays.sort mengurutkan di tempat (array asli berubah).
  • Array 2D: tipe[][] nama = new tipe[baris][kolom];
  • Elemen array angka otomatis bernilai 0 saat dibuat.

Cek pemahaman

Bagaimana mengakses kolom ke-3 di baris pertama <code>grid</code>?

Jawaban: grid[0][2]

Indeks mulai dari 0: baris 0, kolom 2.

Isi awal <code>new int[3]</code>?

Jawaban: [0, 0, 0]

Elemen bertipe angka diisi 0 secara otomatis.
