Kelas & Objek

Buka versi interaktif

Kelas adalah cetak biru. Objek adalah benda nyata yang dibuat dari cetak biru itu. Kelas Titik mendefinisikan bahwa setiap titik punya x dan y (disebut field) serta bisa geser() (disebut method instance).

Konstruktor dijalankan saat objek dibuat dengan new Titik(3, 4). Tugasnya mengisi nilai awal field. Kata this merujuk ke objek yang sedang dipakai.

Enkapsulasi berarti menyembunyikan field (private) dan hanya membuka method tertentu. Dengan begitu objek bisa menjaga datanya tetap valid. Method toString() menentukan bagaimana objek tampil saat dicetak.

JAVA
public class Titik {
    private int x, y;                     // field (dienkapsulasi)

    public Titik(int x, int y) {          // konstruktor
        this.x = x;
        this.y = y;
    }

    public void geser(int dx, int dy) {
        x += dx;
        y += dy;
    }

    public double jarakKeAsal() {
        return Math.sqrt(x * x + y * y);
    }

    public String toString() {
        return "(" + x + ", " + y + ")";
    }

    public static void main(String[] args) {
        Titik p = new Titik(3, 4);
        System.out.println(p + " jarak " + p.jarakKeAsal());
        p.geser(1, -1);
        System.out.println(p);
    }
}
KELUARAN
(3, 4) jarak 5.0
(4, 3)

Poin penting

  • Setiap objek punya salinan field sendiri.
  • Field private hanya bisa diakses dari dalam kelasnya sendiri.
  • Java memberi nilai default pada field (0, false, null) bila konstruktor tidak mengisinya.
  • Method yang mengubah objek disebut mutator, yang hanya membaca disebut accessor.
