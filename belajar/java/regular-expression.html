Regular expression

Buka versi interaktif

Regular expression (regex) adalah pola untuk mencocokkan teks. Satu baris regex bisa menggantikan puluhan baris if dan substring. Contohnya memvalidasi email, mengambil nomor telepon dari kalimat, atau mengganti format tanggal.

Simbol dasar: \d angka, \w huruf/angka/garis bawah, \s spasi, . karakter apa pun, + satu atau lebih, * nol atau lebih, {3} tepat tiga kali, [abc] salah satu dari a, b, c, ^ awal, $ akhir. Tanda kurung ( ) membuat grup yang bisa diambil.

Di Java, garis miring terbalik harus ditulis dua kali di dalam string: "\\d+". Gunakan String.matches untuk validasi singkat, atau Pattern dan Matcher untuk mencari dan mengambil bagian teks.

JAVA
import java.util.regex.*;

public class Pola {
    public static void main(String[] args) {
        String email = "rina@kampus.ac.id";
        System.out.println(email.matches("[\\w.]+@[\\w.]+\\.[a-z]{2,}"));

        String teks = "Hubungi 0812-3456-7890 atau 0857-1111-2222";
        Matcher m = Pattern.compile("(\\d{4})-(\\d{4})-(\\d{4})").matcher(teks);
        while (m.find()) {
            System.out.println("Nomor: " + m.group() + " | awalan " + m.group(1));
        }

        String tgl = "2024-10-28";
        System.out.println(tgl.replaceAll("(\\d{4})-(\\d{2})-(\\d{2})", "$3/$2/$1"));
        System.out.println(String.join("|", "a, b ,c".split("\\s*,\\s*")));
    }
}
KELUARAN
true
Nomor: 0812-3456-7890 | awalan 0812
Nomor: 0857-1111-2222 | awalan 0857
28/10/2024
a|b|c

Poin penting

  • matches mencocokkan seluruh string.
  • Matcher.find() mencari kecocokan berikutnya di dalam teks.
  • Grup ( ) bisa dipakai lagi di penggantian sebagai $1, $2.
  • Di string Java, \d ditulis "\\d".
