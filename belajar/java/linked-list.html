Linked List

Buka versi interaktif

Linked list menyimpan data dalam node terpisah. Setiap node berisi data dan referensi next ke node berikutnya. Node terakhir menunjuk null (Python: None). Kelas list hanya perlu mengingat front, yaitu node pertama.

Menambah di depan sangat murah: buat node baru yang next-nya menunjuk front lama, lalu pindahkan front. Tidak ada yang bergeser. Sebaliknya, mengakses elemen ke-i harus berjalan dari depan sebanyak i langkah.

Kunci menulis kode linked list adalah urutan mengubah referensi. Gambar kotak dan panah di kertas sebelum menulis kode. Pola umumnya: variabel current berjalan maju sampai berhenti tepat sebelum posisi yang ingin diubah.

JAVA
class ListNode {
    int data;
    ListNode next;
    ListNode(int data, ListNode next) {
        this.data = data;
        this.next = next;
    }
}

public class LinkedIntList {
    private ListNode front;   // null bila kosong

    public void addFirst(int nilai) {
        front = new ListNode(nilai, front);
    }

    public void addLast(int nilai) {
        if (front == null) {
            front = new ListNode(nilai, null);
        } else {
            ListNode cur = front;
            while (cur.next != null) {   // jalan ke node terakhir
                cur = cur.next;
            }
            cur.next = new ListNode(nilai, null);
        }
    }
}

Poin penting

  • Selalu tangani kasus list kosong (front == null) secara terpisah.
  • current.next.next berbahaya bila current.next null.
  • Linked list cepat di ujung depan, array cepat untuk akses indeks.
  • java.util.LinkedList sudah tersedia untuk pemakaian nyata.

Cek pemahaman

Berapa biaya mengakses elemen ke-i pada linked list?

Jawaban: O(i), harus berjalan dari depan

Tidak ada indeks. Harus mengikuti next sebanyak i kali.

Berapa biaya addFirst pada linked list?

Jawaban: O(1)

Hanya membuat satu node dan mengubah front, berapa pun panjang list.
