Jaringan & kriptografi dasar

Buka versi interaktif

Untuk memanggil API lewat HTTP, Java 11+ punya HttpClient bawaan. Kamu membuat HttpRequest dengan URL dan method (GET, POST), mengirimnya, lalu membaca HttpResponse berisi kode status dan body. Untuk komunikasi tingkat rendah tersedia Socket dan ServerSocket.

Paket java.security dan javax.crypto menyediakan kriptografi. Hash seperti SHA-256 mengubah data menjadi sidik jari tetap yang tidak bisa dibalik, berguna untuk memeriksa keaslian file. Enkripsi (misalnya AES) menyandikan data agar bisa dibuka kembali dengan kunci.

Aturan emas keamanan: jangan pernah menyimpan kata sandi apa adanya, dan jangan membuat algoritma kripto sendiri. Untuk password, pakai algoritma khusus seperti bcrypt atau Argon2 dengan salt.

JAVA
import java.net.URI;
import java.net.http.*;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.HexFormat;

public class Jaringan {
    public static void main(String[] args) throws Exception {
        // Hash SHA-256: sidik jari data
        MessageDigest md = MessageDigest.getInstance("SHA-256");
        byte[] h = md.digest("halo".getBytes(StandardCharsets.UTF_8));
        System.out.println(HexFormat.of().formatHex(h).substring(0, 16) + "...");

        // Memanggil API lewat HTTP (butuh internet)
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest req = HttpRequest.newBuilder(URI.create("https://api.github.com/zen")).GET().build();
        HttpResponse<String> res = client.send(req, HttpResponse.BodyHandlers.ofString());
        System.out.println(res.statusCode());
        System.out.println(res.body());
    }
}

Poin penting

  • HttpClient untuk memanggil REST API.
  • Kode status 200 berarti berhasil, 404 tidak ditemukan, 500 error server.
  • Hash satu arah; enkripsi dua arah dengan kunci.
  • Simpan password dengan bcrypt/Argon2, bukan SHA mentah.
