Logika & Perulangan Tak Pasti

Buka versi interaktif

Perulangan tak pasti dipakai ketika jumlah putaran belum diketahui, misalnya "ulangi sampai pengguna mengetik 0". Bentuknya while (kondisi). Pastikan sesuatu di dalam loop mengubah kondisi, atau loop akan berjalan selamanya.

Kondisi bisa digabung dengan logika boolean: AND (&& / and), OR (|| / or), dan NOT (! / not). Keduanya memakai short-circuit: jika bagian kiri sudah menentukan hasil, bagian kanan tidak dievaluasi.

Ada dua pola klasik. Fencepost: untuk mencetak 1, 2, 3 kamu butuh 3 angka tapi hanya 2 koma, jadi satu bagian ditaruh di luar loop. Sentinel: nilai khusus (misalnya -1) yang menandai akhir masukan. Bilangan acak dibuat dengan Random atau modul random.

JAVA
import java.util.Random;

public class Dadu {
    public static void main(String[] args) {
        Random acak = new Random();
        int lemparan = 0;
        int dadu = 0;
        while (dadu != 6) {                 // perulangan tak pasti
            dadu = acak.nextInt(6) + 1;     // 1..6
            lemparan++;
            System.out.println("Dapat " + dadu);
        }
        System.out.println("Butuh " + lemparan + " lemparan");

        boolean hujan = true, punyaPayung = false;
        if (hujan && !punyaPayung) {
            System.out.println("Tunggu reda dulu");
        }
    }
}

Poin penting

  • while mengecek kondisi sebelum setiap putaran. Bisa saja tidak pernah masuk.
  • Java punya do/while yang pasti berjalan minimal sekali.
  • !(a && b) sama dengan !a || !b (hukum De Morgan).
  • nextInt(6) + 1 dan randint(1, 6) sama-sama memberi 1 sampai 6.

Cek pemahaman

Apa hasil true || (10 / 0 > 1) di Java?

Jawaban: true

Short-circuit: karena kiri sudah true, OR pasti true. Bagian kanan tidak pernah dihitung.

Masalah fencepost muncul ketika...

Jawaban: Ada n bagian tapi hanya n-1 pemisah, jadi satu bagian harus di luar loop

Seperti pagar: 4 tiang hanya butuh 3 kawat. Cetak satu elemen dulu, lalu loop mencetak "pemisah + elemen".
