Tanggal & waktu (java.time)

Buka versi interaktif

Paket java.time (Java 8+) menggantikan Date dan Calendar yang membingungkan. Kelas utamanya: LocalDate (tanggal saja), LocalTime (jam saja), LocalDateTime (keduanya), dan ZonedDateTime (dengan zona waktu seperti Asia/Jakarta).

Semua objek java.time immutable. Method seperti plusDays mengembalikan tanggal baru. Untuk selisih, pakai Period (tahun/bulan/hari) atau ChronoUnit.DAYS.between. Untuk tampilan, pakai DateTimeFormatter.

Simpan waktu di server dalam UTC atau dengan zona yang jelas, lalu ubah ke zona pengguna saat ditampilkan. Ini menghindari bug saat aplikasi dipakai lintas zona waktu.

JAVA
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.time.temporal.ChronoUnit;

public class Waktu {
    public static void main(String[] args) {
        LocalDate pesan = LocalDate.of(2024, 10, 28);
        LocalDate tiba = pesan.plusDays(5);
        System.out.println(tiba);
        System.out.println(tiba.getDayOfWeek());
        System.out.println(ChronoUnit.DAYS.between(pesan, tiba));

        DateTimeFormatter f = DateTimeFormatter.ofPattern("dd/MM/yyyy");
        System.out.println(tiba.format(f));

        Period umur = Period.between(LocalDate.of(2005, 8, 17), LocalDate.of(2024, 10, 28));
        System.out.println(umur.getYears() + " tahun " + umur.getMonths() + " bulan");

        ZonedDateTime jkt = LocalDateTime.of(2024, 10, 28, 9, 0).atZone(ZoneId.of("Asia/Jakarta"));
        System.out.println(jkt.withZoneSameInstant(ZoneId.of("Asia/Tokyo")).toLocalTime());
    }
}

Poin penting

  • LocalDate/LocalTime/LocalDateTime tanpa zona; ZonedDateTime dengan zona.
  • Objek java.time immutable: simpan hasil plusX.
  • Format dengan DateTimeFormatter.ofPattern.
  • ChronoUnit.DAYS.between(a, b) untuk selisih hari.
