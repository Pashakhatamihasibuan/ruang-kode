Anotasi

Buka versi interaktif

Anotasi adalah label yang ditempel pada kode dengan tanda @. Anotasi tidak mengubah logika secara langsung, tetapi memberi informasi tambahan kepada compiler, alat bantu, atau framework.

Anotasi bawaan yang sering kamu temui: @Override (pastikan benar-benar menimpa method), @Deprecated (tandai fitur usang), @SuppressWarnings (redam peringatan tertentu), dan @FunctionalInterface.

Framework memakai anotasi secara besar-besaran. Spring Boot memakai @RestController dan @GetMapping, JUnit memakai @Test, Hibernate memakai @Entity. Kamu juga bisa membuat anotasi sendiri dan membacanya lewat reflection.

JAVA
import java.lang.annotation.*;
import java.lang.reflect.Method;

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@interface Tugas {
    String pemilik();
    int prioritas() default 1;
}

public class Anotasi {
    @Tugas(pemilik = "Rina", prioritas = 3)
    public void kirimEmail() {}

    @Deprecated
    public void caraLama() {}

    @Override
    public String toString() { return "Anotasi demo"; }

    public static void main(String[] args) throws Exception {
        Method m = Anotasi.class.getMethod("kirimEmail");
        Tugas t = m.getAnnotation(Tugas.class);
        System.out.println(t.pemilik() + " prioritas " + t.prioritas());
        System.out.println(new Anotasi());
    }
}
KELUARAN
Rina prioritas 3
Anotasi demo

Poin penting

  • Anotasi = metadata, ditulis dengan @.
  • @Override mencegah salah ketik saat menimpa method.
  • @Retention(RUNTIME) membuat anotasi bisa dibaca saat program berjalan.
  • Framework seperti Spring dan JUnit dikendalikan lewat anotasi.
