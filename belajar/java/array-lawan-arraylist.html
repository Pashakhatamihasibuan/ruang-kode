Array lawan ArrayList

Buka versi interaktif

Array punya ukuran tetap yang ditentukan saat dibuat, dan bisa menyimpan tipe primitif secara langsung. ArrayList bisa tumbuh dan menyusut sendiri, punya banyak method siap pakai, tetapi hanya menyimpan objek. Angka primitif dibungkus otomatis menjadi Integer (autoboxing).

Pilih array jika jumlah data pasti dan performa sangat penting, misalnya piksel gambar. Pilih ArrayList untuk hampir semua kebutuhan sehari-hari: daftar belanja, hasil pencarian, atau data dari database.

Perhatikan perbedaan cara menulisnya: panjang array memakai field length, ukuran list memakai method size(). Akses elemen: arr[i] lawan list.get(i).

JAVA
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Banding {
    public static void main(String[] args) {
        int[] arr = new int[3];
        arr[0] = 10;
        System.out.println(arr.length + " " + Arrays.toString(arr));

        List<Integer> list = new ArrayList<>();
        list.add(10);
        list.add(20);
        list.add(0, 5);           // sisip di depan
        list.remove(Integer.valueOf(20));
        System.out.println(list.size() + " " + list);
        System.out.println(list.get(1) + " " + list.contains(10));

        List<String> tetap = List.of("a", "b");
        try {
            tetap.add("c");
        } catch (UnsupportedOperationException e) {
            System.out.println("List.of tidak bisa diubah");
        }
    }
}
KELUARAN
3 [10, 0, 0]
2 [5, 10]
10 true
List.of tidak bisa diubah

Kode pemula vs kode rapi

Daftar tetap cukup dengan List.of

List.of (Java 9) membuat daftar dalam satu baris. Daftarnya tidak bisa diubah, sehingga aman dibagikan ke bagian program lain. Kalau perlu menambah isi, bungkus dengan new ArrayList<>(List.of(...)).

KODE PEMULA
ArrayList<String> kota = new ArrayList<String>();
kota.add("Medan");
kota.add("Bandung");
kota.add("Makassar");
System.out.println(kota);
KODE RAPI (BEST PRACTICE)
var kota = List.of("Medan", "Bandung", "Makassar");
System.out.println(kota);
KELUARAN KEDUANYA
[Medan, Bandung, Makassar]

Poin penting

  • Array: ukuran tetap, length, bisa primitif.
  • ArrayList: ukuran dinamis, size(), hanya objek.
  • List.of(...) membuat list immutable.
  • Tulis tipe variabel sebagai interface: List<T> x = new ArrayList<>().
