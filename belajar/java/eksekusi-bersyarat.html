Percabangan membuat program memilih. if menjalankan blok hanya bila kondisinya benar. Rantai if / else if / else (Python: if / elif / else) dicek dari atas. Begitu satu kondisi benar, sisanya dilewati.

Kondisi dibangun dari operator relasional: <, >, <=, >=, ==, !=. Urutan kondisi penting. Jika skor >= 70 dicek lebih dulu, skor 95 akan ikut mendapat C.

Bab ini juga membahas algoritma kumulatif: menyiapkan variabel penampung (misalnya total = 0) di luar loop lalu menambahkannya sedikit demi sedikit di dalam loop. Pola ini dipakai untuk jumlah, rata-rata, nilai maksimum, dan sebagainya.

JAVA
public class Nilai {
    public static String huruf(int skor) {
        if (skor >= 90) {
            return "A";
        } else if (skor >= 80) {
            return "B";
        } else if (skor >= 70) {
            return "C";
        } else {
            return "D";
        }
    }

    public static void main(String[] args) {
        int total = 0;                       // penampung kumulatif
        for (int i = 1; i <= 10; i++) {
            total += i;
        }
        System.out.println("Jumlah 1..10 = " + total);
        System.out.println(huruf(85));
    }
}
KELUARAN
Jumlah 1..10 = 55
B

Poin penting

  • Gunakan if/else if bila pilihan saling eksklusif. Gunakan beberapa if terpisah bila boleh lebih dari satu.
  • Di Java, bandingkan isi String dengan .equals(), bukan ==.
  • Variabel penampung kumulatif dideklarasikan di luar loop.
  • Method boleh punya beberapa return di cabang berbeda.

Cek pemahaman

Dengan method huruf di atas, berapa hasil huruf(80)?

Jawaban: B

80 >= 90 salah, 80 >= 80 benar, jadi B. Kondisi berikutnya tidak dicek lagi.

Di Java, cara yang benar untuk membandingkan isi dua String adalah...

Jawaban: a.equals(b)

== membandingkan alamat objek, bukan isinya. equals membandingkan karakter demi karakter.
