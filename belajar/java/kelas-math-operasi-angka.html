Kelas Math & operasi angka

Buka versi interaktif

Selain operator + - * / %, Java menyediakan kelas Math berisi method statis yang siap pakai: pangkat, akar, nilai mutlak, pembulatan, minimum, dan maksimum. Kamu tidak perlu membuat objeknya, cukup panggil Math.namaMethod(...).

Ada tiga cara membulatkan: Math.round ke bilangan bulat terdekat, Math.floor selalu ke bawah, dan Math.ceil selalu ke atas. Untuk angka acak, pakai Math.random() yang menghasilkan double dari 0.0 sampai sebelum 1.0, atau kelas Random.

Untuk uang, hindari double karena pecahan biner tidak selalu tepat (0.1 + 0.2 tidak persis 0.3). Di aplikasi sungguhan, programmer memakai BigDecimal atau menyimpan nilai dalam satuan terkecil (rupiah tanpa koma).

JAVA
public class Hitung {
    public static void main(String[] args) {
        System.out.println(Math.pow(2, 10));
        System.out.println(Math.sqrt(144));
        System.out.println(Math.abs(-25));
        System.out.println(Math.max(17, 42));
        System.out.println(Math.round(2.5));
        System.out.println(Math.floor(2.9));
        System.out.println(Math.ceil(2.1));
        System.out.println(0.1 + 0.2);
        int dadu = (int) (Math.random() * 6) + 1;
        System.out.println(dadu >= 1 && dadu <= 6);
    }
}

Poin penting

  • Math.pow dan Math.sqrt selalu mengembalikan double.
  • Rumus angka acak 1 sampai n: (int)(Math.random() * n) + 1.
  • Perhatikan 0.1 + 0.2: double menyimpan pecahan secara mendekati.
  • % (modulus) berguna untuk cek genap/ganjil: x % 2 == 0.

Cek pemahaman

<code>Math.ceil(4.01)</code> menghasilkan?

Jawaban: 5.0

ceil selalu membulatkan ke atas dan mengembalikan double.

Kenapa double kurang cocok untuk menyimpan saldo bank?

Jawaban: Pecahannya tidak selalu tepat

Pecahan biner membuat 0.1 + 0.2 bukan tepat 0.3. Pakai BigDecimal atau satuan terkecil.
