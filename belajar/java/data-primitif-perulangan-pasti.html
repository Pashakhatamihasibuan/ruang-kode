Data Primitif & Perulangan Pasti

Buka versi interaktif

Data disimpan di variabel. Java mewajibkan kamu menulis tipe data: int untuk bilangan bulat, double untuk pecahan, boolean untuk benar/salah, char untuk satu karakter. Python menebak tipenya sendiri dari nilai yang diberikan.

Ekspresi seperti 7 / 2 punya jebakan. Di Java, pembagian dua int membuang pecahannya sehingga hasilnya 3. Di Python, / selalu menghasilkan pecahan (3.5), sedangkan // adalah pembagian bulat. Operator % memberi sisa bagi dan sering dipakai untuk cek genap/ganjil.

Perulangan pasti dipakai saat jumlah pengulangan sudah diketahui. Java memakai for (init; kondisi; update). Python memakai for i in range(awal, akhir), dengan akhir tidak ikut dihitung. Loop di dalam loop (nested loop) cocok untuk pola dua dimensi seperti segitiga bintang.

JAVA
public class Segitiga {
    public static final int TINGGI = 4;   // konstanta kelas

    public static void main(String[] args) {
        int a = 7, b = 2;
        System.out.println(a / b);           // 3  (pembagian bulat)
        System.out.println(a % b);           // 1  (sisa bagi)
        System.out.println((double) a / b);  // 3.5

        for (int baris = 1; baris <= TINGGI; baris++) {
            for (int k = 1; k <= baris; k++) {
                System.out.print("*");
            }
            System.out.println();
        }
    }
}

3
1

Poin penting

  • (double) a / b mengubah tipe sebelum membagi (casting).
  • Urutan operasi: * / % dikerjakan sebelum + -.
  • range(1, 5) menghasilkan 1, 2, 3, 4.
  • Konstanta ditulis HURUF_BESAR. Java memakai final.

Cek pemahaman

Berapa hasil 7 % 3?

Jawaban: 1

7 dibagi 3 adalah 2 sisa 1. Operator % mengambil sisanya.

Nilai apa saja yang dihasilkan range(1, 5)?

Jawaban: 1, 2, 3, 4

Batas akhir range tidak ikut. range(1, 5) berhenti sebelum 5.
