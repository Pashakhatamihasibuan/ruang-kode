Rekursi

Buka versi interaktif

Rekursi adalah method yang memanggil dirinya sendiri untuk menyelesaikan versi masalah yang lebih kecil. faktorial(4) sama dengan 4 * faktorial(3), dan seterusnya sampai faktorial(1).

Setiap rekursi butuh dua bagian. Base case adalah kasus paling kecil yang langsung dijawab tanpa rekursi. Recursive case memecah masalah dan memanggil diri sendiri dengan input yang mendekati base case. Tanpa base case, pemanggilan tidak pernah berhenti dan program kehabisan memori stack.

Rekursi sangat cocok untuk struktur yang bersifat rekursif: folder di dalam folder, pohon, dan fraktal. Bab ini juga mengenalkan backtracking: mencoba satu pilihan, dan bila buntu, mundur lalu mencoba pilihan lain.

JAVA
public class Rekursi {
    public static int faktorial(int n) {
        if (n <= 1) {
            return 1;                     // base case
        }
        return n * faktorial(n - 1);      // recursive case
    }

    public static String balik(String s) {
        if (s.length() <= 1) {
            return s;
        }
        return balik(s.substring(1)) + s.charAt(0);
    }

    public static void main(String[] args) {
        System.out.println(faktorial(4));
        System.out.println(balik("java"));
    }
}

Poin penting

  • Percayai pemanggilan rekursif: anggap ia sudah benar untuk input yang lebih kecil.
  • Setiap pemanggilan punya variabel sendiri di call stack.
  • Java: StackOverflowError. Python: RecursionError (batas sekitar 1000).
  • Sebagian rekursi bisa ditulis ulang dengan loop.

Cek pemahaman

Apa yang terjadi jika rekursi tidak punya base case?

Jawaban: StackOverflowError / RecursionError

Pemanggilan terus menumpuk sampai memori stack habis.

Berapa faktorial(3)?

Jawaban: 6

3 * 2 * 1 = 6.
