Dokumentasi dengan Javadoc

Buka versi interaktif

Javadoc adalah komentar khusus yang diawali /** dan ditulis tepat di atas kelas atau method. Alat javadoc mengubah komentar ini menjadi situs dokumentasi HTML, persis seperti dokumentasi resmi Java yang kamu baca saat mencari method String.

Gunakan tag standar: @param untuk setiap parameter, @return untuk nilai kembali, @throws untuk exception, dan {@code ...} untuk potongan kode. Kalimat pertama sebaiknya ringkasan satu baris tentang apa yang dilakukan method.

Dokumentasikan apa dan kenapa, bukan mengulang kode baris per baris. IDE seperti IntelliJ menampilkan Javadoc saat kursor diarahkan ke method, sehingga rekan tim langsung paham cara memakainya.

JAVA
/**
 * Menghitung harga setelah diskon.
 *
 * <p>Diskon dibulatkan ke bawah ke rupiah terdekat.
 *
 * @param harga  harga awal dalam rupiah, tidak boleh negatif
 * @param persen besar diskon, dari 0 sampai 100
 * @return harga akhir setelah diskon
 * @throws IllegalArgumentException jika {@code persen} di luar 0..100
 */
public static long hargaDiskon(long harga, int persen) {
    if (persen < 0 || persen > 100) {
        throw new IllegalArgumentException("persen harus 0..100");
    }
    return harga - harga * persen / 100;
}

// Buat situs dokumentasi:
// javadoc -d docs src/com/toko/*.java
// mvn javadoc:javadoc

Soal latihan

  1. Tulis Javadoc lengkap untuk method hitungCicilan(long pokok, double bungaTahunan, int bulan).

    Petunjuk

    @param untuk tiap parameter, @return, @throws.

    Lihat jawaban
    JAVA
    /**
 * Menghitung cicilan bulanan dengan bunga flat.
 *
 * @param pokok        jumlah pinjaman dalam rupiah, harus lebih dari 0
 * @param bungaTahunan bunga per tahun dalam persen, misalnya 12.0
 * @param bulan        lama cicilan dalam bulan
 * @return besar cicilan per bulan dalam rupiah
 * @throws IllegalArgumentException jika pokok atau bulan tidak positif
 */
public static long hitungCicilan(long pokok, double bungaTahunan, int bulan) {
    if (pokok <= 0 || bulan <= 0) throw new IllegalArgumentException("tidak valid");
    double bunga = pokok * bungaTahunan / 100 * bulan / 12;
    return Math.round((pokok + bunga) / bulan);
}

  2. Buat dokumentasi HTML dari folder src ke folder docs.

    Petunjuk

    Perintah javadoc dengan -d untuk folder tujuan.

    Lihat jawaban
    TERMINAL
    javadoc -d docs -sourcepath src -subpackages id.ruangkode
# buka docs/index.html di browser

Poin penting

  • Javadoc diawali /**, bukan /*.
  • Tag: @param, @return, @throws, {@code}.
  • Kalimat pertama = ringkasan.
  • Tulis kenapa dan bagaimana memakai, bukan menerjemahkan kode.

Cek pemahaman

Komentar Javadoc diawali dengan?

Jawaban: /**

Dua bintang menandai komentar dokumentasi.

Tag untuk menjelaskan nilai kembali?

Jawaban: @return

@return mendeskripsikan hasil method.
