Java Collections Framework

Buka versi interaktif

Selain List, ada dua koleksi penting. Set adalah himpunan: tidak ada duplikat dan pengecekan contains sangat cepat. Map (Python: dictionary) memasangkan kunci dengan nilai, misalnya kata dengan jumlah kemunculannya.

Java menyediakan beberapa implementasi. HashSet/HashMap sangat cepat tapi urutannya acak. TreeSet/TreeMap sedikit lebih lambat tapi selalu terurut. Kamu menulis kode terhadap interface (Set, Map) supaya implementasinya mudah diganti.

Koleksi-koleksi ini adalah contoh abstract data type: kamu tahu operasinya (tambah, hapus, cari) tanpa perlu tahu cara kerjanya di dalam. Untuk menjelajahi isinya, gunakan for-each atau iterator.

JAVA
import java.util.*;

public class HitungKata {
    public static void main(String[] args) {
        String teks = "satu dua tiga dua satu satu";
        Set<String> unik = new TreeSet<>();
        Map<String, Integer> jumlah = new TreeMap<>();

        for (String kata : teks.split(" ")) {
            unik.add(kata);
            jumlah.put(kata, jumlah.getOrDefault(kata, 0) + 1);
        }
        System.out.println(unik);
        System.out.println(jumlah);
    }
}
KELUARAN
[dua, satu, tiga]
{dua=2, satu=3, tiga=1}

Poin penting

  • map.getOrDefault(k, 0) dan d.get(k, 0) menghindari error kunci belum ada.
  • Kunci Map unik. put pada kunci yang sama menimpa nilai lama.
  • Python dict menyimpan urutan saat data dimasukkan.
  • Pilih koleksi dari pertanyaannya: urutan penting? duplikat boleh? butuh pasangan?
