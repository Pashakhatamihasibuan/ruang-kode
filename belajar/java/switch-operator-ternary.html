switch & operator ternary

Buka versi interaktif

Ketika sebuah nilai dibandingkan dengan banyak kemungkinan tetap, switch lebih rapi daripada rantai if-else. Sejak Java 14 ada switch expression dengan panah ->: tidak perlu break, dan hasilnya bisa langsung disimpan ke variabel.

Switch klasik dengan titik dua masih banyak ditemui di kode lama. Di sana kamu wajib menulis break, kalau tidak eksekusi "jatuh" ke case berikutnya (fall-through).

Untuk pilihan dua arah yang pendek, ada operator ternary: kondisi ? nilaiJikaBenar : nilaiJikaSalah. Pakai seperlunya, karena ternary bersarang cepat sulit dibaca.

JAVA
public class Hari {
    public static void main(String[] args) {
        int hari = 6;
        String jenis = switch (hari) {
            case 1, 2, 3, 4, 5 -> "Hari kerja";
            case 6, 7 -> "Akhir pekan";
            default -> "Tidak valid";
        };
        System.out.println(jenis);

        String nilai = "B";
        switch (nilai) {
            case "A":
                System.out.println("Istimewa");
                break;
            case "B":
                System.out.println("Baik");
                break;
            default:
                System.out.println("Tetap semangat");
        }

        int umur = 17;
        String status = umur >= 17 ? "boleh punya KTP" : "belum";
        System.out.println(status);
    }
}

Poin penting

  • Switch expression (->) tidak butuh break dan bisa mengembalikan nilai.
  • Switch bisa dipakai untuk int, char, String, dan enum.
  • Lupa break di switch klasik menyebabkan fall-through.
  • Ternary cocok untuk pilihan dua nilai yang sederhana.
