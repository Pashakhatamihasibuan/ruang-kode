Unit test dengan JUnit 5

Buka versi interaktif

Unit test adalah kode kecil yang memeriksa satu bagian program bekerja sesuai harapan. Tes dijalankan otomatis setiap kali kode berubah, sehingga bug ketahuan sebelum sampai ke pengguna.

JUnit 5 adalah framework tes paling populer di Java. Method tes diberi anotasi @Test, lalu memakai assertion seperti assertEquals(harapan, kenyataan) dan assertThrows. Pola yang dianjurkan: Arrange (siapkan), Act (jalankan), Assert (periksa).

TestNG adalah alternatif dengan fitur pengelompokan dan dependensi antartes yang kuat. Di kedua framework, tes ditaruh di src/test/java dan dijalankan dengan mvn test atau ./gradlew test.

JAVA
import static org.junit.jupiter.api.Assertions.*;
import org.junit.jupiter.api.*;

class Diskon {
    static long hitung(long harga, int persen) {
        if (persen < 0 || persen > 100) throw new IllegalArgumentException("persen salah");
        return harga - harga * persen / 100;
    }
}

class DiskonTest {
    @Test
    void diskonSepuluhPersen() {
        long hasil = Diskon.hitung(50_000, 10);   // act
        assertEquals(45_000, hasil);              // assert
    }

    @Test
    void persenNegatifDitolak() {
        assertThrows(IllegalArgumentException.class, () -> Diskon.hitung(1000, -5));
    }

    @ParameterizedTest
    @CsvSource({"100000, 0, 100000", "100000, 100, 0", "80000, 25, 60000"})
    void banyakKasus(long harga, int persen, long harapan) {
        assertEquals(harapan, Diskon.hitung(harga, persen));
    }
}

Poin penting

  • Satu tes memeriksa satu perilaku, dengan nama yang jelas.
  • Arrange, Act, Assert.
  • @ParameterizedTest menguji banyak data dengan satu method.
  • Tes yang baik cepat, mandiri, dan bisa diulang.
