Logging: SLF4J, Logback, Log4j2

Buka versi interaktif

System.out.println cukup untuk belajar, tetapi aplikasi produksi butuh logging: pesan bertingkat (TRACE, DEBUG, INFO, WARN, ERROR), dilengkapi waktu dan nama kelas, yang bisa diarahkan ke file atau layanan pemantauan, dan bisa diatur tanpa mengubah kode.

SLF4J adalah lapisan antarmuka (facade). Kode kamu hanya bicara dengan SLF4J, sedangkan implementasinya bisa Logback (bawaan Spring Boot) atau Log4j2 (sangat cepat). TinyLog adalah alternatif yang sangat ringan untuk aplikasi kecil.

Pakai placeholder {} alih-alih menyambung string, supaya teks hanya disusun jika level itu memang aktif. Jangan pernah mencatat data sensitif seperti password atau nomor kartu.

JAVA
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class Kasir {
    private static final Logger log = LoggerFactory.getLogger(Kasir.class);

    public void bayar(String idPesanan, long total) {
        log.info("Memproses pembayaran {} sebesar {}", idPesanan, total);
        if (total <= 0) {
            log.warn("Total tidak wajar untuk pesanan {}", idPesanan);
            return;
        }
        try {
            // ... panggil payment gateway
            log.debug("Respons gateway diterima");
        } catch (Exception e) {
            log.error("Pembayaran {} gagal", idPesanan, e);
        }
    }
}

// Contoh keluaran (format Logback):
// 10:15:02.341 INFO  Kasir - Memproses pembayaran 101 sebesar 85000

Poin penting

  • Level: TRACE < DEBUG < INFO < WARN < ERROR.
  • SLF4J = antarmuka, Logback/Log4j2 = mesin.
  • Pakai {}, bukan penyambungan string.
  • Level dan tujuan log diatur di file konfigurasi, misalnya logback.xml.
