Kelas abstrak & abstraksi

Buka versi interaktif

Abstraksi berarti menyembunyikan detail dan hanya menampilkan apa yang penting. Pengguna kelas cukup tahu sebuah Bentuk punya luas(), tanpa peduli rumusnya.

Kelas abstract adalah kelas setengah jadi. Ia boleh punya method biasa dan method abstrak (tanpa isi). Kelas abstrak tidak bisa dibuat objeknya langsung; subclass wajib melengkapi semua method abstraknya.

Gunakan kelas abstrak ketika beberapa kelas berbagi kode dan field yang sama, tetapi masing-masing punya cara sendiri untuk sebagian perilakunya.

JAVA
abstract class Bentuk {
    private final String nama;
    Bentuk(String nama) { this.nama = nama; }
    abstract double luas();                 // wajib diisi subclass
    String info() {                         // dipakai bersama
        return nama + ": " + String.format("%.2f", luas());
    }
}
class Lingkaran extends Bentuk {
    double r;
    Lingkaran(double r) { super("Lingkaran"); this.r = r; }
    double luas() { return Math.PI * r * r; }
}
class Persegi extends Bentuk {
    double s;
    Persegi(double s) { super("Persegi"); this.s = s; }
    double luas() { return s * s; }
}

public class Abstraksi {
    public static void main(String[] args) {
        Bentuk[] semua = { new Lingkaran(1), new Persegi(3) };
        for (Bentuk b : semua) System.out.println(b.info());
        // new Bentuk("x");  // error: Bentuk is abstract
    }
}
KELUARAN
Lingkaran: 3.14
Persegi: 9.00

Poin penting

  • Kelas abstrak tidak bisa di-new.
  • Method abstrak tidak punya badan dan diakhiri titik koma.
  • Subclass konkret wajib meng-override semua method abstrak.
  • Kelas abstrak boleh punya konstruktor dan field.
