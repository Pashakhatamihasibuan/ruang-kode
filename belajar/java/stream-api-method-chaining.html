Stream API & method chaining

Buka versi interaktif

Stream adalah aliran data yang diproses lewat rangkaian operasi. Kamu menulis apa yang diinginkan (saring, ubah, kumpulkan), bukan bagaimana cara looping-nya. Gaya merangkai panggilan a().b().c() ini disebut method chaining.

Operasi stream ada dua jenis. Intermediate (filter, map, sorted, limit) mengembalikan stream baru dan bersifat malas: belum ada yang dikerjakan. Terminal (collect, forEach, count, reduce) memicu seluruh pipeline berjalan.

Stream memproses elemen satu per satu melewati semua tahap, bukan tahap per tahap. Jadi dengan limit(2), pemrosesan berhenti begitu dua hasil didapat. Stream juga tidak mengubah koleksi asal.

JAVA
import java.util.*;
import java.util.stream.*;

public class Aliran {
    record Produk(String nama, String kategori, int harga) {}

    public static void main(String[] args) {
        List<Produk> data = List.of(
            new Produk("Kopi Gayo", "Minuman", 85000),
            new Produk("Teh Melati", "Minuman", 25000),
            new Produk("Keripik", "Camilan", 15000),
            new Produk("Kacang Mete", "Camilan", 60000),
            new Produk("Madu Hutan", "Minuman", 120000));

        List<String> mahal = data.stream()
            .filter(p -> p.harga() > 50000)
            .sorted(Comparator.comparingInt(Produk::harga))
            .map(Produk::nama)
            .collect(Collectors.toList());
        System.out.println(mahal);

        int total = data.stream().mapToInt(Produk::harga).sum();
        System.out.println(total);

        Map<String, Long> perKategori = data.stream()
            .collect(Collectors.groupingBy(Produk::kategori, TreeMap::new, Collectors.counting()));
        System.out.println(perKategori);

        String nama = IntStream.rangeClosed(1, 5)
            .filter(i -> i % 2 == 1)
            .mapToObj(i -> "#" + i)
            .collect(Collectors.joining(" "));
        System.out.println(nama);
    }
}

#1 #3 #5

Kode pemula vs kode rapi

Menyaring dan menjumlah dengan stream

Loop dengan variabel penampung dan if bisa ditulis sebagai rangkaian langkah yang terbaca seperti kalimat: saring, ubah, jumlahkan.

KODE PEMULA
int[] harga = {12_000, 45_000, 8_000, 30_000};
int total = 0;
for (int i = 0; i < harga.length; i++) {
    if (harga[i] >= 10_000) {
        total = total + harga[i] * 2;
    }
}
System.out.println(total);
KODE RAPI (BEST PRACTICE)
int[] harga = {12_000, 45_000, 8_000, 30_000};
int total = Arrays.stream(harga)
        .filter(h -> h >= 10_000)
        .map(h -> h * 2)
        .sum();
System.out.println(total);
KELUARAN KEDUANYA
174000

Poin penting

  • Pipeline: sumber → operasi intermediate → satu operasi terminal.
  • Tanpa operasi terminal, stream tidak melakukan apa pun (lazy).
  • Stream sekali pakai: setelah terminal, buat stream baru.
  • Collectors.groupingBy mirip GROUP BY di SQL.
