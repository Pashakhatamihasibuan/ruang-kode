Spring Boot & dependency injection

Buka versi interaktif

Dependency injection (DI) berarti sebuah kelas tidak membuat sendiri objek yang ia butuhkan, melainkan menerimanya dari luar, biasanya lewat konstruktor. Hasilnya: kelas lebih mudah diuji (dependency bisa diganti mock) dan bagian-bagian aplikasi tidak saling terikat erat.

Spring Boot adalah framework Java paling populer untuk membuat REST API dan aplikasi web. Ia punya container yang membuat dan menyambungkan objek (bean) secara otomatis. Kelas bertanda @Service, @Repository, atau @RestController dikelola Spring, dan dependency-nya disuntikkan lewat konstruktor.

Dengan beberapa anotasi, sebuah method menjadi endpoint HTTP: @GetMapping("/produk") menangani GET, dan objek yang dikembalikan otomatis diubah menjadi JSON.

JAVA
@SpringBootApplication
public class TokoApp {
    public static void main(String[] args) {
        SpringApplication.run(TokoApp.class, args);
    }
}

@Service
class ProdukService {
    private final ProdukRepository repo;
    ProdukService(ProdukRepository repo) {   // disuntikkan Spring
        this.repo = repo;
    }
    List<Produk> minuman() { return repo.findByKategoriOrderByHargaAsc("Minuman"); }
}

@RestController
@RequestMapping("/api/produk")
class ProdukController {
    private final ProdukService service;
    ProdukController(ProdukService service) { this.service = service; }

    @GetMapping("/minuman")
    List<Produk> daftarMinuman() { return service.minuman(); }
}
// GET http://localhost:8080/api/produk/minuman -> [{"id":2,"nama":"Teh Melati",...}]

Poin penting

  • DI: terima dependency lewat konstruktor, jangan new sendiri.
  • Lapisan umum: Controller → Service → Repository.
  • Spring Boot menyiapkan server web (Tomcat) secara otomatis.
  • Objek yang dikembalikan controller diubah menjadi JSON.
