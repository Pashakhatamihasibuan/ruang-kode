Pemrograman Fungsional

Buka versi interaktif

Pemrograman fungsional memandang program sebagai rangkaian fungsi yang mengubah data, bukan sebagai urutan perintah yang mengubah variabel. Fungsi bisa dikirim sebagai argumen, disimpan di variabel, dan dikembalikan dari fungsi lain. Fungsi seperti itu disebut higher-order function.

Lambda adalah fungsi tanpa nama yang ditulis ringkas, misalnya n -> n * 2. Tiga operasi utamanya: filter menyaring elemen, map mengubah setiap elemen, reduce menggabungkan semuanya menjadi satu nilai.

Java 8 menghadirkan Stream untuk menulis pipeline ini secara berantai. Gaya ini mendorong fungsi murni dan data immutable, sehingga kode lebih mudah diuji dan aman dijalankan paralel.

JAVA
import java.util.*;
import java.util.stream.*;

public class Fungsional {
    public static void main(String[] args) {
        List<Integer> angka = List.of(1, 2, 3, 4, 5, 6);

        int hasil = angka.stream()
                .filter(n -> n % 2 == 0)     // 2, 4, 6
                .map(n -> n * n)             // 4, 16, 36
                .reduce(0, Integer::sum);    // 56
        System.out.println(hasil);

        List<String> nama = List.of("budi", "ani", "sari");
        System.out.println(nama.stream()
                .map(String::toUpperCase)
                .collect(Collectors.toList()));
    }
}
KELUARAN
56
[BUDI, ANI, SARI]

Poin penting

  • Stream Java tidak mengubah list asal.
  • Method reference: String::toUpperCase sama dengan s -> s.toUpperCase().
  • Pakai Stream untuk mengolah data. Untuk logika yang rumit, loop biasa sering lebih mudah dibaca.
  • Hindari efek samping (mencetak, mengubah variabel luar) di dalam lambda.

Cek pemahaman

Apa hasil map "x * 10" pada [1, 2, 3]?

Jawaban: [10, 20, 30]

map mengubah setiap elemen dan menghasilkan koleksi baru dengan panjang yang sama.

Fungsi murni (pure function) adalah fungsi yang...

Jawaban: Hasilnya hanya bergantung pada input dan tanpa efek samping

Input sama selalu memberi output sama, dan tidak mengubah apa pun di luar dirinya.
