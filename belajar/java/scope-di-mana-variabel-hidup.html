Scope: di mana variabel hidup

Buka versi interaktif

Scope adalah wilayah kode tempat sebuah variabel bisa dipakai. Di Java, aturannya sederhana: variabel hanya hidup di dalam pasangan kurung kurawal { } tempat ia dideklarasikan, mulai dari baris deklarasinya.

Variabel yang dibuat di dalam method disebut variabel lokal. Ia lahir saat method dipanggil dan hilang saat method selesai. Variabel di kepala for hanya hidup selama perulangan. Field (variabel milik kelas) hidup selama objeknya ada.

Kalau kamu memakai variabel di luar scope-nya, compiler menolak dengan pesan cannot find symbol. Ini bukan musuh: scope yang sempit membuat program lebih mudah dibaca karena setiap nama hanya berlaku di area kecil.

JAVA
public class Scope {
    static int total = 0;               // field: hidup selama program

    static void tambah(int n) {          // n: parameter, lokal di method
        int dobel = n * 2;               // lokal
        total += dobel;
    }

    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {   // i hanya hidup di dalam for
            tambah(i);
        }
        // System.out.println(i);        // error: cannot find symbol
        System.out.println(total);
        {
            int sementara = 99;          // blok bebas punya scope sendiri
            System.out.println(sementara);
        }
    }
}

Poin penting

  • Scope ditentukan oleh kurung kurawal terdekat.
  • Parameter berperilaku seperti variabel lokal yang nilainya diisi pemanggil.
  • Dua method boleh punya variabel lokal dengan nama sama karena scope-nya terpisah.
  • Deklarasikan variabel sedekat mungkin dengan tempat pemakaiannya.
