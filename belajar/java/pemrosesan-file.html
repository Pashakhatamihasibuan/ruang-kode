Pemrosesan File

Buka versi interaktif

Program nyata membaca data dari file, bukan hanya dari keyboard. Di Java, Scanner yang sama bisa diarahkan ke new File("nilai.txt").

Ada dua cara membaca. Berbasis token: membaca potongan yang dipisah spasi (next(), nextInt()). Berbasis baris: membaca satu baris utuh lalu memecahnya. Pola paling aman adalah membaca per baris, lalu memecah baris itu menjadi token.

Membuka file bisa gagal, misalnya karena file tidak ada. Java memaksa kamu menangani kemungkinan itu (throws FileNotFoundException), karena ini termasuk checked exception.

JAVA
import java.io.*;
import java.util.*;

public class RataRata {
    public static void main(String[] args) throws FileNotFoundException {
        Scanner file = new Scanner(new File("nilai.txt"));
        while (file.hasNextLine()) {
            String baris = file.nextLine();      // "Budi 85 90"
            Scanner token = new Scanner(baris);
            String nama = token.next();
            int total = 0, n = 0;
            while (token.hasNextInt()) {
                total += token.nextInt();
                n++;
            }
            System.out.println(nama + ": " + (double) total / n);
        }
    }
}
KELUARAN
Budi: 87.5
Sari: 85.0

Poin penting

  • hasNextInt() mengecek dulu sebelum nextInt(), supaya tidak crash.
  • str.split() memecah string berdasarkan spasi.
  • Menulis file: PrintStream atau FileWriter.
  • Isi contoh nilai.txt: dua baris, "Budi 85 90" dan "Sari 78 92".

Cek pemahaman

Token berikutnya adalah "abc". Apa hasil hasNextInt()?

Jawaban: false

hasNextInt hanya melihat, tidak membaca. "abc" bukan bilangan bulat, jadi false.

Mengapa memakai try (Scanner sc = new Scanner(file)) (try-with-resources)?

Jawaban: File otomatis ditutup walau terjadi error

Try-with-resources menjamin file ditutup saat blok selesai, walau terjadi error.
