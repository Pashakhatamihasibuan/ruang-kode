BI analyst dan peran data lainnya

Buka versi interaktif

Business Intelligence (BI) mengubah data operasional menjadi informasi yang dipakai mengambil keputusan rutin: dashboard penjualan harian, laporan stok, KPI bulanan.

Perbedaan peran secara kasar: data analyst menjawab pertanyaan ad-hoc dengan analisis; BI analyst membangun model data, metrik, dan dashboard yang dipakai berulang oleh banyak orang; data engineer membangun pipeline yang mengalirkan data; data scientist membuat model prediksi.

Keahlian inti BI analyst: SQL, pemodelan data (skema bintang), satu alat BI (Power BI, Tableau, Looker), statistik dasar, dan yang sering dilupakan: memahami bisnis dan berkomunikasi.

Poin penting

  • BI = data menjadi keputusan rutin.
  • BI analyst: model data, metrik, dashboard berulang.
  • SQL + pemodelan + alat BI + bisnis + komunikasi.
