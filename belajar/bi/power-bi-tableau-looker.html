Power BI, Tableau & Looker

Buka versi interaktif

Power BI (Microsoft) paling banyak dipakai di perusahaan Indonesia karena terintegrasi dengan Excel dan Microsoft 365. Rumusnya memakai DAX. Tableau unggul dalam eksplorasi visual. Looker (Google) memakai lapisan semantik LookML yang didefinisikan sebagai kode.

Konsep yang sama di semua alat: model data (relasi fakta-dimensi), measure (perhitungan yang mengikuti filter, misalnya total omzet), dan calculated column (dihitung per baris saat data dimuat).

Kesalahan umum pemula: menghitung rata-rata dari persentase, atau membuat measure di kolom alih-alih di measure sehingga hasil tidak mengikuti filter.

CONTOH
-- DAX (Power BI)
Omzet Bersih =
SUMX ( fakta_penjualan,
       fakta_penjualan[jumlah] * fakta_penjualan[harga]
       * ( 100 - fakta_penjualan[diskon_persen] ) / 100 )

Omzet Bulan Lalu =
CALCULATE ( [Omzet Bersih], DATEADD ( dim_tanggal[tanggal], -1, MONTH ) )

Tumbuh MoM % =
DIVIDE ( [Omzet Bersih] - [Omzet Bulan Lalu], [Omzet Bulan Lalu] )

Poin penting

  • Power BI (DAX), Tableau, Looker (LookML).
  • Measure mengikuti filter; calculated column per baris.
  • Hati-hati merata-ratakan persentase.
