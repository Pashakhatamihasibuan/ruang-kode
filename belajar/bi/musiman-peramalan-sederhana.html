Musiman & peramalan sederhana

Buka versi interaktif

Banyak bisnis punya pola musiman: penjualan naik menjelang Lebaran, akhir tahun, atau tanggal gajian. Bandingkan dengan periode yang sama tahun lalu (year-over-year) agar tidak salah membaca kenaikan musiman sebagai pertumbuhan.

Rata-rata bergerak (moving average) menghaluskan fluktuasi dan menjadi dasar peramalan paling sederhana. Di SQL: AVG(x) OVER (ORDER BY periode ROWS BETWEEN 2 PRECEDING AND CURRENT ROW).

Untuk peramalan serius gunakan model deret waktu (ETS, ARIMA, Prophet) yang sudah tersedia di Power BI dan Tableau.

Rata-rata bergerak 3 bulan
WITH b AS (
  SELECT d.bulan, d.nama_bulan, SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100) AS omzet
  FROM fakta_penjualan f JOIN dim_tanggal d ON d.tanggal_id = f.tanggal_id
  GROUP BY d.bulan, d.nama_bulan
)
SELECT nama_bulan, omzet,
       ROUND(AVG(omzet) OVER (ORDER BY bulan ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)) AS ma3
FROM b ORDER BY bulan;
Omzet per hari dalam minggu
SELECT d.hari, COUNT(*) AS transaksi, SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100) AS omzet
FROM fakta_penjualan f JOIN dim_tanggal d ON d.tanggal_id = f.tanggal_id
GROUP BY d.hari ORDER BY omzet DESC;

Poin penting

  • Bandingkan YoY untuk data musiman.
  • Moving average menghaluskan tren.
  • Model deret waktu untuk ramalan serius.
