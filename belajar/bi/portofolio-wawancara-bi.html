BI Analyst · Modul 8 · Konsep & kode

Portofolio & wawancara BI

Buka versi interaktif

Portofolio BI yang meyakinkan berisi 2-3 proyek ujung-ke-ujung: pertanyaan bisnis, sumber data, model data, dashboard (tautan publik Tableau Public atau Power BI), dan ringkasan rekomendasi.

Wawancara biasanya terdiri dari tes SQL (JOIN, GROUP BY, window function), studi kasus ("omzet turun 15%, apa yang kamu periksa?"), dan presentasi dashboard.

Sertifikasi yang dikenal: Microsoft PL-300 (Power BI Data Analyst), Tableau Desktop Specialist, dan Google Data Analytics.

CONTOH
Kerangka studi kasus "omzet turun 15%"
1. Validasi data: apakah pipeline terlambat? definisi berubah?
2. Pecah metrik: omzet = transaksi × nilai rata-rata
3. Segmentasi: wilayah, kanal, produk, pelanggan baru/lama
4. Waktu: mulai kapan? musiman? ada peristiwa (libur, harga naik)?
5. Hipotesis → data pendukung → rekomendasi

Poin penting

  • 2-3 proyek ujung-ke-ujung dengan tautan publik.
  • Tes SQL + studi kasus + presentasi.
  • PL-300, Tableau Specialist, Google Data Analytics.

Cek pemahaman

Langkah pertama saat KPI turun tajam?

Jawaban: Pastikan datanya benar dan definisinya tidak berubah

Banyak "penurunan" ternyata masalah data.
