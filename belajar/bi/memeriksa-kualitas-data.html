Memeriksa kualitas data

Buka versi interaktif

Dashboard yang bagus dengan data salah lebih berbahaya daripada tidak ada dashboard. Periksa enam dimensi kualitas: kelengkapan, keunikan, validitas (nilai di rentang wajar), konsistensi antar sistem, akurasi, dan ketepatan waktu.

Jadikan pemeriksaan ini query rutin (atau tes dbt) yang berjalan sebelum dashboard diperbarui.

Jalankan contoh di bawah: periksa baris tanpa pasangan dimensi, diskon di luar rentang, dan kunci ganda.

Fakta tanpa dimensi (orphan)
SELECT COUNT(*) AS tanpa_produk
FROM fakta_penjualan f LEFT JOIN dim_produk p ON p.produk_id = f.produk_id
WHERE p.produk_id IS NULL;
Nilai di luar rentang wajar
SELECT COUNT(*) AS aneh FROM fakta_penjualan
WHERE jumlah <= 0 OR diskon_persen NOT BETWEEN 0 AND 50;
Harga transaksi beda dari harga katalog
SELECT p.nama, f.harga AS harga_trx, p.harga AS harga_katalog, COUNT(*) AS n
FROM fakta_penjualan f JOIN dim_produk p ON p.produk_id = f.produk_id
WHERE f.harga <> p.harga GROUP BY p.nama, f.harga, p.harga;

Tantangan

  1. Periksa keunikan: tampilkan tanggal_id, produk_id, toko_id yang muncul lebih dari sekali di fakta_penjualan beserta jumlahnya (kolom n).

Poin penting

  • Kelengkapan, keunikan, validitas, konsistensi, akurasi, ketepatan waktu.
  • Jadikan pemeriksaan query rutin atau tes dbt.
  • Orphan = fakta tanpa pasangan dimensi.
