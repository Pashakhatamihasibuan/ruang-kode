BI Analyst · Modul 9 · Proyek akhir

Dashboard kinerja penjualan semester 1

Buka versi interaktif

Manajemen Toko Nusantara ingin tahu toko dan produk mana yang mendorong pertumbuhan semester 1 2024, dan di mana margin tergerus diskon. Bangun model data, metrik, dan dashboard satu halaman beserta rekomendasi.

Teknologi: SQL + Power BI/Tableau

Fitur yang dibuat

  • Dokumen definisi metrik: omzet bersih, margin, MoM, kontribusi
  • Query SQL untuk setiap metrik dari skema bintang
  • Pemeriksaan kualitas data sebelum dashboard
  • 4 KPI dengan pembanding di bagian atas
  • Tren bulanan dengan moving average
  • Matriks toko x kategori dengan margin
  • Tata letak versi ponsel
  • Ringkasan 5 kalimat: konteks, temuan, implikasi, rekomendasi

Langkah kerja

  1. Definisikan metrik bersama pemangku kepentingan.
  2. Tulis query dan uji kualitas data.
  3. Bangun model di alat BI dan buat measure.
  4. Susun dashboard, minta masukan, perbaiki.
  5. Tulis ringkasan dan presentasikan.
metrik.sql
-- KPI ringkas semester 1
WITH f AS (
  SELECT f.*, d.bulan, d.kuartal, t.wilayah, p.kategori, p.hpp,
         f.jumlah * f.harga * (100 - f.diskon_persen) / 100 AS omzet
  FROM fakta_penjualan f
  JOIN dim_tanggal d ON d.tanggal_id = f.tanggal_id
  JOIN dim_toko t    ON t.toko_id    = f.toko_id
  JOIN dim_produk p  ON p.produk_id  = f.produk_id
)
SELECT kuartal,
       SUM(omzet) AS omzet,
       ROUND(100.0 * (SUM(omzet) - SUM(jumlah * hpp)) / SUM(omzet), 1) AS margin_persen,
       COUNT(*) AS transaksi
FROM f GROUP BY kuartal ORDER BY kuartal;
