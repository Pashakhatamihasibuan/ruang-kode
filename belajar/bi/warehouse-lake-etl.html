Warehouse, lake & ETL

Buka versi interaktif

Data warehouse (BigQuery, Snowflake, Redshift) menyimpan data terstruktur yang sudah dibersihkan untuk analitik. Data lake menyimpan data mentah dalam berbagai format dengan biaya murah. Data mart adalah potongan warehouse untuk satu departemen.

ETL (extract, transform, load) mengambil data dari sumber, membersihkan, lalu memuat ke warehouse. Pola modern ELT memuat mentah dulu lalu mentransformasi di dalam warehouse dengan SQL, sering memakai dbt.

dbt membuat setiap transformasi berupa berkas SELECT yang diberi versi di Git, diuji, dan terdokumentasi, sekaligus menggambar lineage: dari tabel mana sebuah angka berasal.

SQL
-- models/marts/fakta_penjualan.sql (dbt)
SELECT
    d.tanggal_id,
    t.produk_id,
    t.toko_id,
    t.jumlah,
    t.harga,
    COALESCE(t.diskon_persen, 0) AS diskon_persen
FROM {{ ref('stg_transaksi') }} t
JOIN {{ ref('dim_tanggal') }} d ON d.tanggal = t.tanggal
WHERE t.status = 'selesai'

-- models/marts/schema.yml
-- columns: produk_id → tests: [not_null, relationships: dim_produk]

Poin penting

  • Warehouse terstruktur; lake mentah; mart per departemen.
  • ETL vs ELT; ELT dengan dbt populer.
  • dbt: SQL berversi, diuji, lineage otomatis.
