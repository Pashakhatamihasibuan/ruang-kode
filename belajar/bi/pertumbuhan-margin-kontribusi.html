Pertumbuhan, margin & kontribusi

Buka versi interaktif

Metrik turunan yang paling sering diminta: pertumbuhan dibanding periode lalu (month-over-month), margin kotor = (omzet − HPP) / omzet, dan kontribusi = bagian satu kelompok terhadap total.

Window function membuat semuanya bisa dihitung dalam satu query: LAG untuk periode lalu, SUM(...) OVER () untuk total keseluruhan.

Selalu tampilkan angka absolut di samping persentase. "Naik 200%" bisa berarti dari 1 menjadi 3 transaksi.

Pertumbuhan omzet bulanan
WITH b AS (
  SELECT d.bulan, d.nama_bulan, SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100) AS omzet
  FROM fakta_penjualan f JOIN dim_tanggal d ON d.tanggal_id = f.tanggal_id
  GROUP BY d.bulan, d.nama_bulan
)
SELECT nama_bulan, omzet,
       LAG(omzet) OVER (ORDER BY bulan) AS bulan_lalu,
       ROUND(100.0 * (omzet - LAG(omzet) OVER (ORDER BY bulan)) / LAG(omzet) OVER (ORDER BY bulan), 1) AS tumbuh_persen
FROM b ORDER BY bulan;
Margin kotor per produk
SELECT p.nama,
       SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100) AS omzet,
       SUM(f.jumlah * p.hpp) AS hpp,
       ROUND(100.0 * (SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100) - SUM(f.jumlah * p.hpp)) / SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100), 1) AS margin_persen
FROM fakta_penjualan f JOIN dim_produk p ON p.produk_id = f.produk_id
GROUP BY p.nama ORDER BY margin_persen DESC;
Kontribusi tiap wilayah
SELECT t.wilayah, SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100) AS omzet,
       ROUND(100.0 * SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100) / SUM(SUM(f.jumlah * f.harga * (100 - f.diskon_persen) / 100)) OVER (), 1) AS kontribusi_persen
FROM fakta_penjualan f JOIN dim_toko t ON t.toko_id = f.toko_id
GROUP BY t.wilayah ORDER BY omzet DESC;

Tantangan

  1. Tampilkan kuartal dan jumlah transaksi (kolom transaksi) per kuartal dari dim_tanggal, urut kuartal.

Poin penting

  • MoM: LAG(...) OVER (ORDER BY periode).
  • Margin = (omzet − HPP) / omzet.
  • Kontribusi: SUM(x) / SUM(SUM(x)) OVER ().
  • Persentase selalu dengan angka absolut.
