CLV & analisis kohort

Buka versi interaktif

Customer Lifetime Value (CLV) memperkirakan total keuntungan dari satu pelanggan selama hubungannya: rata-rata nilai pesanan × frekuensi per tahun × lama bertahan × margin. CLV menentukan berapa biaya akuisisi (CAC) yang masih masuk akal.

Analisis kohort mengelompokkan pelanggan menurut bulan pertama mereka membeli, lalu melacak berapa persen yang kembali di bulan ke-1, ke-2, dan seterusnya. Hasilnya tabel segitiga yang memperlihatkan apakah retensi membaik.

Kohort lebih jujur daripada angka total: pertumbuhan pengguna baru bisa menyembunyikan retensi yang memburuk.

SQL
-- kohort berdasarkan bulan pembelian pertama (PostgreSQL)
WITH pertama AS (
  SELECT pelanggan_id, DATE_TRUNC('month', MIN(tanggal)) AS kohort
  FROM pesanan GROUP BY pelanggan_id
)
SELECT p.kohort,
       DATE_PART('month', AGE(DATE_TRUNC('month', o.tanggal), p.kohort)) AS bulan_ke,
       COUNT(DISTINCT o.pelanggan_id) AS pelanggan
FROM pesanan o JOIN pertama p USING (pelanggan_id)
GROUP BY 1, 2 ORDER BY 1, 2;

kohort   bulan_ke 0  1    2    3
Jan      100%       38%  29%  25%
Feb      100%       41%  33%
Mar      100%       45%

Soal latihan

  1. Hitung CLV sederhana: rata-rata belanja Rp150.000, 2 kali sebulan, margin 30%, rata-rata pelanggan bertahan 18 bulan.

    Petunjuk

    CLV = nilai belanja x frekuensi x margin x lama bertahan.

    Lihat jawaban
    PYTHON
    belanja, frekuensi, margin, bulan = 150_000, 2, 0.30, 18
clv = belanja * frekuensi * margin * bulan
print(f"Rp{clv:,.0f}".replace(",", "."))
    KELUARAN
    Rp1.620.000

  2. Buat tabel retensi kohort dari data pesanan: kohort = bulan pertama beli, kolom = bulan ke-berapa sejak itu.

    Petunjuk

    Bulan pertama per pelanggan dengan groupby().transform("min"), lalu selisih bulan, lalu pivot jumlah pelanggan unik.

    Lihat jawaban
    PYTHON
    import pandas as pd

df = pd.DataFrame({
    "pelanggan": ["A", "A", "B", "B", "C", "C", "D"],
    "bulan": pd.to_datetime(["2026-01", "2026-02", "2026-01", "2026-03", "2026-02", "2026-03", "2026-02"]),
})
df["kohort"] = df.groupby("pelanggan")["bulan"].transform("min")
df["ke"] = (df["bulan"].dt.year - df["kohort"].dt.year) * 12 + (df["bulan"].dt.month - df["kohort"].dt.month)
tabel = df.pivot_table(index=df["kohort"].dt.strftime("%Y-%m"), columns="ke", values="pelanggan", aggfunc="nunique", fill_value=0)
print(tabel)
    KELUARAN
    ke       0  1  2
kohort          
2026-01  2  1  1
2026-02  2  1  0

Poin penting

  • CLV ≈ nilai pesanan × frekuensi × lama × margin.
  • CLV dibanding CAC menentukan anggaran akuisisi.
  • Kohort: retensi per bulan bergabung.
