IF satu cabang

Buka versi interaktif

Bentuk percabangan paling sederhana hanya punya satu jalur: IF kondisi THEN ... ENDIF. Jika kondisi benar, langkah di dalamnya dijalankan. Jika salah, langkah itu dilewati begitu saja dan program lanjut ke baris setelah ENDIF.

Pakai IF satu cabang saat ada langkah tambahan yang hanya terjadi pada kondisi tertentu, sedangkan selain itu tidak ada yang perlu dilakukan. Contoh: memberi bonus, menampilkan peringatan stok menipis, atau menghapus ongkir.

Pola yang sering dipakai: isi nilai bawaan dulu, lalu ubah dengan IF. Pada contoh, ongkir ← 15000 sebagai bawaan; hanya jika belanja minimal 100 ribu, ongkir diubah menjadi 0. Cara ini menghindari ELSE dan memastikan variabel selalu punya nilai.

Jalankan dengan 120000, lalu 80000. Perhatikan baris di dalam IF dilewati pada input kedua.

PSEUDOCODE
START
    DECLARE belanja, ongkir : INTEGER
    INPUT belanja
    ongkir ← 15000
    IF belanja >= 100000 THEN
        ongkir ← 0
        OUTPUT "Selamat, gratis ongkir!"
    ENDIF
    OUTPUT "Total bayar: ", (belanja + ongkir)
END

Soal latihan

  1. Tulis pseudocode: jika stok kurang dari 5, tampilkan "Stok menipis". Setelah itu selalu tampilkan sisa stok.

    Petunjuk

    IF tanpa ELSE, lalu OUTPUT setelah ENDIF.

    Lihat jawaban
    CONTOH
    DECLARE stok : INTEGER
INPUT stok
IF stok < 5 THEN
    OUTPUT "Stok menipis"
ENDIF
OUTPUT "Sisa stok: ", stok
    KELUARAN
    Masukan 3 → Stok menipis, Sisa stok: 3

  2. Poin belanja = belanja DIV 10000. Member mendapat bonus 5 poin. Tulis dengan pola nilai bawaan lalu IF satu cabang.

    Petunjuk

    Hitung poin dulu, lalu tambahkan bonus hanya jika member.

    Lihat jawaban
    CONTOH
    DECLARE belanja, poin : INTEGER
DECLARE member : BOOLEAN
INPUT belanja
INPUT member
poin ← belanja DIV 10000
IF member THEN
    poin ← poin + 5
ENDIF
OUTPUT "Poin: ", poin
    KELUARAN
    belanja 87000, member → Poin: 13

Poin penting

  • IF tanpa ELSE: jika salah, langkahnya dilewati.
  • Cocok untuk langkah tambahan pada kondisi tertentu.
  • Pola nilai bawaan lalu diubah oleh IF.

Cek pemahaman

Belanja 80000 pada contoh. Berapa total bayar?

Jawaban: 95000

Ongkir bawaan 15000 tidak diubah.

Kapan IF satu cabang paling cocok?

Jawaban: Ada langkah tambahan hanya pada kondisi tertentu

Selain kondisi itu, tidak ada yang dilakukan.
