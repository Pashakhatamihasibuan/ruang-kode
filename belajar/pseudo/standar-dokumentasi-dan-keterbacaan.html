Pseudocode · Modul 6 · Konsep & kode

Standar dokumentasi dan keterbacaan

Buka versi interaktif

Pseudocode ditulis untuk dibaca manusia: dosen, rekan tim, atau dirimu sendiri enam bulan lagi. Algoritma yang benar tetapi sulit dibaca tetap merepotkan saat perlu diperbaiki.

Standar yang dipakai di dunia kerja dan kampus. (1) Kepala algoritma: nama, tujuan, input, output, dan penulis. (2) Nama bermakna: hargaSatuan, bukan h; fungsi diawali kata kerja (HitungPajak). (3) Konsisten: satu gaya kata kunci, satu gaya penamaan (camelCase atau snake_case), indentasi 4 spasi. (4) Konstanta bernama: CONSTANT PPN ← 0.11, bukan angka 0.11 yang muncul tiba-tiba (magic number).

(5) Komentar menjelaskan kenapa, bukan apa. // tambah 1 ke i tidak berguna; // indeks mulai 0, jadi batas n - 1 berguna. (6) Satu modul satu tugas, dan modul cukup pendek untuk dibaca dalam satu layar. (7) Sertakan contoh uji beserta hasil yang diharapkan.

Bandingkan versi sulit dibaca dan versi terdokumentasi di bagian contoh. Keduanya menghasilkan angka yang sama.

CONTOH
// ===== Sulit dibaca =====
INPUT a
INPUT b
c ← a * b
d ← c * 0.11
OUTPUT c + d

// ===== Terdokumentasi =====
// Nama    : HitungTotalBayar
// Tujuan  : menghitung total belanja termasuk PPN
// Input   : hargaSatuan (INTEGER), jumlah (INTEGER)
// Output  : totalBayar (REAL)
// Uji     : 15000, 4 -> 66600
CONSTANT TARIF_PPN ← 0.11      // PPN 11% sejak April 2022

DECLARE hargaSatuan, jumlah, subtotal : INTEGER
DECLARE pajak, totalBayar : REAL

INPUT hargaSatuan
INPUT jumlah
subtotal ← hargaSatuan * jumlah
pajak ← subtotal * TARIF_PPN
totalBayar ← subtotal + pajak
OUTPUT "Total bayar: ", totalBayar
KELUARAN
Masukan 15000 dan 4 → Total bayar: 66600

Soal latihan

  1. Tulis ulang agar mudah dibaca:
    INPUT x; INPUT y; z ← x * y * 0.5; OUTPUT z
    (menghitung luas segitiga).

    Petunjuk

    Tambahkan kepala algoritma, nama bermakna, dan konstanta untuk 0.5 jika perlu.

    Lihat jawaban
    CONTOH
    // Nama   : LuasSegitiga
// Tujuan : menghitung luas segitiga
// Input  : alas, tinggi (REAL)
// Output : luas (REAL)
// Uji    : alas 10, tinggi 6 -> 30
DECLARE alas, tinggi, luas : REAL
INPUT alas
INPUT tinggi
luas ← alas * tinggi / 2
OUTPUT "Luas segitiga: ", luas

  2. Sebutkan magic number pada potongan ini dan perbaiki:
    IF umur >= 17 THEN ... ; denda ← hari * 2000

    Petunjuk

    Angka penting tanpa nama sebaiknya menjadi konstanta.

    Lihat jawaban
    CONTOH
    Magic number: 17 dan 2000.
CONSTANT UMUR_MIN_KTP ← 17
CONSTANT DENDA_PER_HARI ← 2000
IF umur >= UMUR_MIN_KTP THEN ...
denda ← hari * DENDA_PER_HARI

Poin penting

  • Tulis untuk manusia: kepala algoritma, nama bermakna, konsisten.
  • Konstanta bernama menggantikan magic number.
  • Komentar menjelaskan kenapa, bukan apa.
