Loop bersarang

Buka versi interaktif

Loop di dalam loop disebut loop bersarang. Untuk setiap satu putaran loop luar, loop dalam berjalan penuh. Jika loop luar 4 kali dan dalam 5 kali, badan loop dalam berjalan 4 × 5 = 20 kali.

Pola segitiga bintang adalah latihan klasik. Loop luar i menentukan baris, loop dalam j menentukan banyak bintang di baris itu. Karena batas loop dalam adalah i, baris ke-1 punya 1 bintang, baris ke-4 punya 4.

Loop bersarang dipakai untuk tabel (baris × kolom), membandingkan setiap pasangan data, dan sorting. Ingat: makin dalam sarangnya, makin banyak langkahnya, sehingga program bisa lambat untuk data besar.

Jalankan visual dengan input 4, lalu coba 6.

PSEUDOCODE
START
    DECLARE n, i, j : INTEGER
    DECLARE baris : STRING
    INPUT n
    FOR i ← 1 TO n DO
        baris ← ""
        FOR j ← 1 TO i DO
            baris ← baris & "*"
        ENDFOR
        OUTPUT baris
    ENDFOR
END

Poin penting

  • Loop dalam berjalan penuh untuk setiap putaran loop luar.
  • Total langkah = putaran luar × putaran dalam.
  • Batas loop dalam boleh bergantung pada loop luar.

Cek pemahaman

Loop luar 1 sampai 3, loop dalam 1 sampai 4. Berapa kali badan dalam dijalankan?

Jawaban: 12

3 × 4 = 12.

Pada segitiga bintang n = 5, baris ke-3 berisi?

Jawaban: ***

Banyak bintang = nomor baris.
