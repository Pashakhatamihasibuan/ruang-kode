Variabel, tipe data, dan pengisian nilai

Buka versi interaktif

Variabel adalah kotak bernama untuk menyimpan nilai. Sebelum dipakai, variabel dideklarasikan beserta tipe-nya, agar jelas jenis isi yang boleh masuk: DECLARE umur : INTEGER. Tipe dasar: INTEGER (bilangan bulat), REAL (bilangan pecahan), STRING (teks), BOOLEAN (benar/salah), dan CHAR (satu huruf).

Pengisian nilai (assignment) ditulis dengan panah: umur ← 19. Bacanya dari kanan ke kiri: hitung nilai di kanan, lalu simpan ke variabel di kiri. Nilai lama di dalam kotak tertimpa dan hilang. Itulah sebabnya x ← x + 1 masuk akal: ambil x lama, tambah 1, simpan lagi ke x.

Beri nama variabel yang bermakna: hargaSatuan lebih jelas daripada h. Nama tidak boleh diawali angka dan tidak boleh berisi spasi. Variabel yang belum diisi nilainya tidak boleh dibaca, karena isinya belum jelas.

Contoh visual mengubah suhu Celcius ke Fahrenheit dengan tipe REAL, karena hasilnya bisa pecahan. Perhatikan kolom variabel: fahrenheit masih kosong sampai baris pengisian dijalankan. Coba input 100 atau -40.

PSEUDOCODE
START
    DECLARE celcius, fahrenheit : REAL
    INPUT celcius
    fahrenheit ← celcius * 9 / 5 + 32
    OUTPUT celcius, " C = ", fahrenheit, " F"
END

Soal latihan

  1. Ubah 135 menit menjadi jam dan menit memakai DIV dan MOD.

    Petunjuk

    DIV memberi hasil bagi bulat, MOD memberi sisa.

    Lihat jawaban
    CONTOH
    DECLARE total, jam, menit : INTEGER
total ← 135
jam ← total DIV 60
menit ← total MOD 60
OUTPUT jam, " jam ", menit, " menit"
    KELUARAN
    2 jam 15 menit

  2. Tukar isi variabel a = 3 dan b = 8 lalu tampilkan keduanya.

    Petunjuk

    Butuh variabel bantu t agar nilai a tidak hilang.

    Lihat jawaban
    CONTOH
    DECLARE a, b, t : INTEGER
a ← 3
b ← 8
t ← a
a ← b
b ← t
OUTPUT "a = ", a, ", b = ", b
    KELUARAN
    a = 8, b = 3

  3. Hitung rata-rata tiga nilai 80, 75, 92 dan tampilkan dengan tipe yang tepat.

    Petunjuk

    Rata-rata bisa pecahan, jadi pakai REAL.

    Lihat jawaban
    CONTOH
    DECLARE n1, n2, n3 : INTEGER
DECLARE rata : REAL
n1 ← 80
n2 ← 75
n3 ← 92
rata ← (n1 + n2 + n3) / 3
OUTPUT "Rata-rata: ", rata
    KELUARAN
    Rata-rata: 82.333...

Poin penting

  • Deklarasikan variabel dengan tipenya.
  • ← mengisi nilai: hitung kanan, simpan ke kiri, nilai lama tertimpa.
  • Nama variabel harus bermakna.
