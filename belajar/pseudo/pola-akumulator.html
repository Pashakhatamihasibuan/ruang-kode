Pola akumulator

Buka versi interaktif

Akumulator adalah variabel yang mengumpulkan hasil selama loop berjalan. Polanya selalu sama: (1) beri nilai awal sebelum loop, (2) perbarui di dalam loop, (3) pakai hasilnya setelah loop.

Empat akumulator yang paling sering: penjumlah (total ← 0, lalu total ← total + x), penghitung (lulus ← 0, lalu lulus ← lulus + 1 jika syarat terpenuhi), pengali (hasil ← 1, lalu hasil ← hasil * x, misalnya faktorial), dan pencari ekstrem (maksimum atau minimum).

Nilai awal harus sesuai jenisnya: penjumlah dan penghitung mulai dari 0, pengali mulai dari 1 (jika 0, hasilnya selalu 0). Untuk maksimum, ambil data pertama sebagai nilai awal; pada contoh dipakai kondisi i = 1 OR x > maks agar data pertama langsung menjadi maks.

Visual membaca 5 nilai dan menghitung empat hal sekaligus dalam satu loop. Coba ganti nilai-nilainya dan prediksi hasilnya sebelum menekan Jalankan.

PSEUDOCODE
START
    DECLARE i, x, total, lulus, maks : INTEGER
    DECLARE rata : REAL
    total ← 0
    lulus ← 0
    maks ← 0
    FOR i ← 1 TO 5 DO
        INPUT x
        total ← total + x
        IF x >= 75 THEN
            lulus ← lulus + 1
        ENDIF
        IF i = 1 or x > maks THEN
            maks ← x
        ENDIF
    ENDFOR
    rata ← total / 5
    OUTPUT "Total: ", total
    OUTPUT "Rata-rata: ", rata
    OUTPUT "Lulus: ", lulus, " orang"
    OUTPUT "Tertinggi: ", maks
END

Soal latihan

  1. Baca 6 suhu harian, lalu tampilkan suhu terendah dan berapa hari suhunya di atas 32.

    Petunjuk

    Dua akumulator: minimum (mulai dari data pertama) dan penghitung (mulai 0).

    Lihat jawaban
    CONTOH
    DECLARE i, x, minim, panas : INTEGER
panas ← 0
FOR i ← 1 TO 6 DO
    INPUT x
    IF i = 1 OR x < minim THEN
        minim ← x
    ENDIF
    IF x > 32 THEN
        panas ← panas + 1
    ENDIF
ENDFOR
OUTPUT "Terendah: ", minim
OUTPUT "Hari panas: ", panas
    KELUARAN
    30 33 29 35 31 34 → Terendah: 29, Hari panas: 3

  2. Hitung 2 pangkat 10 dengan akumulator pengali.

    Petunjuk

    Nilai awal pengali 1, kalikan 2 sebanyak 10 kali.

    Lihat jawaban
    CONTOH
    DECLARE i, hasil : INTEGER
hasil ← 1
FOR i ← 1 TO 10 DO
    hasil ← hasil * 2
ENDFOR
OUTPUT hasil
    KELUARAN
    1024

  3. Gabungkan huruf-huruf "R", "U", "A", "N", "G" menjadi satu kata dengan akumulator teks.

    Petunjuk

    Nilai awal "" lalu s ← s & huruf.

    Lihat jawaban
    CONTOH
    DECLARE huruf : ARRAY[0..4] OF CHAR
DECLARE s : STRING
DECLARE i : INTEGER
huruf ← ['R', 'U', 'A', 'N', 'G']
s ← ""
FOR i ← 0 TO 4 DO
    s ← s & huruf[i]
ENDFOR
OUTPUT s
    KELUARAN
    RUANG

Poin penting

  • Nilai awal sebelum loop, perbarui di dalam, pakai setelahnya.
  • Penjumlah 0, pengali 1, maksimum dari data pertama.
  • Satu loop bisa mengurus beberapa akumulator.

Cek pemahaman

Nilai awal yang benar untuk menghitung faktorial?

Jawaban: 1

Jika 0, hasil perkalian selalu 0.

Nilai 80, 65, 92, 75, 58. Berapa yang lulus (≥ 75)?

Jawaban: 3

80, 92, dan 75.
