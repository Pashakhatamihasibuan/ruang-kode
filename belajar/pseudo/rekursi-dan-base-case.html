Rekursi dan base case

Buka versi interaktif

Rekursi adalah fungsi yang memanggil dirinya sendiri dengan masalah yang lebih kecil. Contoh: faktorial. 5! = 5 × 4!, 4! = 4 × 3!, dan seterusnya sampai 1! = 1.

Setiap fungsi rekursif wajib punya dua bagian. Base case (kasus dasar): kondisi berhenti yang dijawab langsung tanpa memanggil diri sendiri, misalnya IF n <= 1 THEN RETURN 1. Recursive case: memanggil diri sendiri dengan input yang mendekati base case, misalnya RETURN n * Faktorial(n - 1).

Tanpa base case, atau jika inputnya tidak mendekati base case, fungsi memanggil dirinya terus sampai memori tumpukan (call stack) habis: stack overflow. Ini versi rekursi dari infinite loop.

Rekursi cocok untuk masalah yang bentuknya berulang ke dalam: struktur folder, pohon menu, binary search, dan Menara Hanoi. Untuk hitungan sederhana, versi loop biasanya lebih hemat memori. Visual di bawah menghitung faktorial dengan loop; bandingkan dengan versi rekursif di bagian contoh.

FUNCTION Faktorial(n : INTEGER) RETURNS INTEGER
    IF n <= 1 THEN            // base case
        RETURN 1
    ENDIF
    RETURN n * Faktorial(n - 1)   // recursive case
ENDFUNCTION

FUNCTION Pangkat(a : INTEGER, b : INTEGER) RETURNS INTEGER
    IF b = 0 THEN
        RETURN 1
    ENDIF
    RETURN a * Pangkat(a, b - 1)
ENDFUNCTION

START
    OUTPUT Faktorial(5)
    OUTPUT Pangkat(2, 10)
END

PSEUDOCODE
START
    DECLARE n, i, hasil : INTEGER
    INPUT n
    hasil ← 1
    FOR i ← 2 TO n DO
        hasil ← hasil * i
    ENDFOR
    OUTPUT n, "! = ", hasil
END

Soal latihan

  1. Tulis fungsi rekursif JumlahN(n) = 1 + 2 + ... + n.

    Petunjuk

    Base case: n = 0 mengembalikan 0. Recursive: n + JumlahN(n - 1).

    Lihat jawaban
    CONTOH
    FUNCTION JumlahN(n : INTEGER) RETURNS INTEGER
    IF n = 0 THEN
        RETURN 0
    ENDIF
    RETURN n + JumlahN(n - 1)
ENDFUNCTION

OUTPUT JumlahN(10)
    KELUARAN
    55

  2. Tulis fungsi rekursif Fib(n) untuk bilangan Fibonacci (Fib(0) = 0, Fib(1) = 1).

    Petunjuk

    Dua base case, lalu Fib(n - 1) + Fib(n - 2).

    Lihat jawaban
    CONTOH
    FUNCTION Fib(n : INTEGER) RETURNS INTEGER
    IF n <= 1 THEN
        RETURN n
    ENDIF
    RETURN Fib(n - 1) + Fib(n - 2)
ENDFUNCTION

OUTPUT Fib(10)
    KELUARAN
    55

  3. Terjemahkan Faktorial rekursif ke Python dan cetak faktorial 1 sampai 5.

    Petunjuk

    def faktorial(n): base case n <= 1.

    Lihat jawaban
    PYTHON
    def faktorial(n):
    if n <= 1:
        return 1
    return n * faktorial(n - 1)

for i in range(1, 6):
    print(i, faktorial(i))
    KELUARAN
    1 1
2 2
3 6
4 24
5 120

Poin penting

  • Rekursi: fungsi memanggil dirinya dengan masalah lebih kecil.
  • Wajib ada base case.
  • Input harus mendekati base case, jika tidak terjadi stack overflow.
