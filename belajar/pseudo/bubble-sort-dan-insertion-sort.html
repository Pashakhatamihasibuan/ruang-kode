Bubble sort dan insertion sort

Buka versi interaktif

Bubble sort mengurutkan dengan membandingkan pasangan bersebelahan dan menukarnya jika salah urutan. Setelah putaran pertama, angka terbesar sudah di ujung kanan, seperti gelembung yang naik. Menukar butuh variabel bantu t: t ← a[j], a[j] ← a[j + 1], a[j + 1] ← t.

Insertion sort bekerja seperti merapikan kartu di tangan. Ambil satu kartu (kunci), geser kartu-kartu di kirinya yang lebih besar satu langkah ke kanan, lalu sisipkan kunci di celah yang terbuka. Bagian kiri array selalu sudah terurut.

Keduanya butuh sekitar n² langkah untuk data acak, jadi lambat untuk data besar. Tetapi insertion sort sangat cepat untuk data yang hampir terurut, karena hampir tidak ada yang perlu digeser. Itulah sebabnya Python dan Java memakai insertion sort untuk potongan kecil di dalam algoritma sort bawaannya.

Visual menjalankan insertion sort pada [29, 10, 14, 37, 13]. Perhatikan kunci dan j, lalu lihat isi array berubah. Versi bubble sort ada di bagian contoh.

// Bubble sort
FOR i ← 0 TO n - 2 DO
    FOR j ← 0 TO n - 2 - i DO
        IF a[j] > a[j + 1] THEN
            t ← a[j]
            a[j] ← a[j + 1]
            a[j + 1] ← t
        ENDIF
    ENDFOR
ENDFOR

// Insertion sort
FOR i ← 1 TO n - 1 DO
    kunci ← a[i]
    j ← i - 1
    WHILE j >= 0 AND a[j] > kunci DO
        a[j + 1] ← a[j]
        j ← j - 1
    ENDWHILE
    a[j + 1] ← kunci
ENDFOR
KELUARAN
[29, 10, 14, 37, 13] → [10, 13, 14, 29, 37]
PSEUDOCODE
START
    DECLARE a : ARRAY[5] OF INTEGER
    a ← [29, 10, 14, 37, 13]
    DECLARE i, j, kunci : INTEGER
    FOR i ← 1 TO 4 DO
        kunci ← a[i]
        j ← i - 1
        WHILE j >= 0 and a[j] > kunci DO
            a[j + 1] ← a[j]
            j ← j - 1
        ENDWHILE
        a[j + 1] ← kunci
    ENDFOR
    OUTPUT "Terurut: ", a
END

Soal latihan

  1. Ubah bubble sort agar mengurutkan dari terbesar ke terkecil.

    Petunjuk

    Cukup balik tanda perbandingan: tukar jika a[j] < a[j + 1].

    Lihat jawaban
    CONTOH
    FOR i ← 0 TO n - 2 DO
    FOR j ← 0 TO n - 2 - i DO
        IF a[j] < a[j + 1] THEN
            t ← a[j]
            a[j] ← a[j + 1]
            a[j + 1] ← t
        ENDIF
    ENDFOR
ENDFOR
    KELUARAN
    [5, 1, 4, 2] → [5, 4, 2, 1]

  2. Tuliskan isi array [5, 1, 4, 2] setelah putaran luar pertama bubble sort menaik.

    Petunjuk

    Bandingkan pasangan bersebelahan dari kiri: (5,1) tukar, (5,4) tukar, (5,2) tukar.

    Lihat jawaban
    CONTOH
    Awal      : [5, 1, 4, 2]
j = 0     : [1, 5, 4, 2]
j = 1     : [1, 4, 5, 2]
j = 2     : [1, 4, 2, 5]
Setelah putaran 1, angka terbesar (5) sudah di ujung.

Poin penting

  • Bubble: tukar pasangan bersebelahan.
  • Insertion: sisipkan kunci ke bagian kiri yang sudah terurut.
  • Insertion sort unggul untuk data hampir terurut.
