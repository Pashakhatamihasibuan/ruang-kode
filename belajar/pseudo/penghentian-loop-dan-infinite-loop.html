Penghentian loop dan infinite loop

Buka versi interaktif

Setiap loop harus punya kondisi berhenti yang pasti tercapai. Tiga syaratnya: (1) variabel kondisi diberi nilai awal, (2) variabel itu berubah di dalam badan loop, dan (3) perubahannya menuju kondisi berhenti. Jika salah satunya hilang, terjadi infinite loop: program berputar selamanya dan tampak "hang".

Contoh infinite loop: i ← 1; WHILE i <= 5 DO OUTPUT i ENDWHILE (lupa menaikkan i). Atau i ← 1; WHILE i <> 10 DO i ← i + 2 ENDWHILE: i bernilai 1, 3, 5, 7, 9, 11, ... dan tidak pernah tepat 10. Pakai < atau <= daripada <> untuk kondisi berhenti.

Cara lain menghentikan loop: sentinel (nilai khusus seperti 0 atau -1 yang berarti "selesai"), flag (variabel BOOLEAN ketemu yang diubah menjadi benar), dan batas pengaman (maksimal 3 kali percobaan PIN). Banyak bahasa juga punya break untuk keluar paksa.

Visual menghitung banyak digit: n dibagi 10 terus sampai habis. Loop ini pasti berhenti karena n selalu mengecil dan suatu saat menjadi 0. Coba 7, 1000, dan 0.

PSEUDOCODE
START
    DECLARE n, digit : INTEGER
    INPUT n
    digit ← 0
    WHILE n > 0 DO
        n ← Int(n / 10)
        digit ← digit + 1
    ENDWHILE
    OUTPUT "Banyak digit: ", digit
END

Soal latihan

  1. Temukan dan perbaiki infinite loop berikut:
    n ← 10; WHILE n > 0 DO OUTPUT n; n ← n + 1 ENDWHILE

    Petunjuk

    Apakah n bergerak menuju kondisi berhenti?

    Lihat jawaban
    CONTOH
    n bertambah sehingga n > 0 selalu benar.
Perbaikan:
n ← 10
WHILE n > 0 DO
    OUTPUT n
    n ← n - 1
ENDWHILE

  2. Tulis algoritma login dengan batas pengaman: maksimal 3 kali percobaan password.

    Petunjuk

    Loop berhenti jika password benar ATAU percobaan sudah 3.

    Lihat jawaban
    CONTOH
    DECLARE pw : STRING
DECLARE coba : INTEGER
DECLARE berhasil : BOOLEAN
coba ← 0
berhasil ← FALSE
WHILE coba < 3 AND NOT berhasil DO
    INPUT pw
    coba ← coba + 1
    IF pw = "rahasia" THEN
        berhasil ← TRUE
    ENDIF
ENDWHILE
IF berhasil THEN
    OUTPUT "Masuk"
ELSE
    OUTPUT "Akun dikunci"
ENDIF

Poin penting

  • Nilai awal, berubah, dan menuju kondisi berhenti.
  • Hindari <> sebagai kondisi berhenti angka.
  • Sentinel, flag, dan batas pengaman.

Cek pemahaman

i ← 0; WHILE i <> 7 DO i ← i + 2. Apa yang terjadi?

Jawaban: Infinite loop

i: 0, 2, 4, 6, 8, ... tidak pernah tepat 7.

Apa itu nilai sentinel?

Jawaban: Nilai khusus penanda akhir input

Contoh: ketik 0 untuk selesai.
