Linear search: mencari satu per satu

Buka versi interaktif

Linear search memeriksa isi array satu per satu dari depan sampai data ditemukan atau array habis. Cara ini bekerja untuk data apa pun, terurut atau tidak.

Kita pakai WHILE dengan dua syarat: masih ada data (i < 6) dan belum ketemu (posisi = -1). Nilai -1 adalah tanda "belum ditemukan", karena tidak ada indeks negatif.

Jika data ada di depan, pencarian cepat. Jika di belakang atau tidak ada, semua data harus diperiksa. Untuk data besar yang terurut, binary search jauh lebih cepat (dibahas di modul latihan algoritma tiap bahasa).

Coba cari 18, 12, lalu 99 (tidak ada).

PSEUDOCODE
START
    DECLARE data : ARRAY[6] OF INTEGER
    data ← [12, 7, 30, 18, 25, 9]
    DECLARE cari, i, posisi : INTEGER
    INPUT cari
    posisi ← -1
    i ← 0
    WHILE i < 6 and posisi = -1 DO
        IF data[i] = cari THEN
            posisi ← i
        ENDIF
        i ← i + 1
    ENDWHILE
    IF posisi = -1 THEN
        OUTPUT cari, " tidak ditemukan"
    ELSE
        OUTPUT cari, " ada di indeks ", posisi
    ENDIF
END

Soal latihan

  1. Hitung berapa kali angka 7 muncul di array [7, 3, 7, 1, 7, 9].

    Petunjuk

    Jangan berhenti saat ketemu; teruskan sampai akhir sambil menghitung.

    Lihat jawaban
    CONTOH
    DECLARE a : ARRAY[0..5] OF INTEGER
DECLARE i, jumlah : INTEGER
a ← [7, 3, 7, 1, 7, 9]
jumlah ← 0
FOR i ← 0 TO 5 DO
    IF a[i] = 7 THEN
        jumlah ← jumlah + 1
    ENDIF
ENDFOR
OUTPUT "Muncul ", jumlah, " kali"

  2. Cari posisi nama "Budi" di daftar nama dan berhenti begitu ketemu. Tampilkan -1 jika tidak ada.

    Petunjuk

    WHILE dengan dua syarat: indeks masih di dalam array AND belum ketemu.

    Lihat jawaban
    CONTOH
    DECLARE nama : ARRAY[0..3] OF STRING
DECLARE i, posisi : INTEGER
nama ← ["Andi", "Budi", "Citra", "Dewi"]
i ← 0
posisi ← -1
WHILE i <= 3 AND posisi = -1 DO
    IF nama[i] = "Budi" THEN
        posisi ← i
    ENDIF
    i ← i + 1
ENDWHILE
OUTPUT posisi

Poin penting

  • Linear search memeriksa satu per satu.
  • -1 sebagai tanda belum ditemukan.
  • Berhenti saat ketemu atau data habis.

Cek pemahaman

Berapa langkah terburuk linear search untuk 100 data?

Jawaban: 100

Jika data di akhir atau tidak ada, semua diperiksa.

Kenapa memakai -1 sebagai nilai awal posisi?

Jawaban: Karena indeks tidak pernah negatif

-1 tidak mungkin menjadi indeks yang sah.
