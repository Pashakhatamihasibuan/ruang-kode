Prosedur dan fungsi

Buka versi interaktif

Saat algoritma makin panjang, kita memecahnya menjadi bagian kecil yang punya nama. Prosedur menjalankan serangkaian langkah tanpa mengembalikan nilai, misalnya PROCEDURE CetakGaris(n). Fungsi mengembalikan satu nilai, misalnya FUNCTION Luas(p, l) RETURNS INTEGER.

Nilai yang dikirim ke prosedur atau fungsi disebut parameter. Dengan parameter, satu fungsi bisa dipakai berkali-kali untuk data berbeda: Luas(8, 5) dan Luas(3, 4) memakai langkah yang sama.

Keuntungannya: kode tidak diulang-ulang, lebih mudah diuji per bagian, dan lebih mudah dibaca. Prinsip ini sama di semua bahasa dan juga ada di Flowgorithm (simbol Call).

CONTOH
FUNCTION Luas(p : INTEGER, l : INTEGER) RETURNS INTEGER
    RETURN p * l
ENDFUNCTION

PROCEDURE CetakGaris(n : INTEGER)
    DECLARE i : INTEGER
    FOR i <- 1 TO n DO
        OUTPUT "-"
    ENDFOR
ENDPROCEDURE

START
    OUTPUT Luas(8, 5)
    CALL CetakGaris(3)
END

Soal latihan

  1. Buat FUNCTION Maks(a, b) yang mengembalikan nilai terbesar, lalu pakai untuk mencari terbesar dari tiga angka.

    Petunjuk

    Maks(Maks(x, y), z).

    Lihat jawaban
    CONTOH
    FUNCTION Maks(a : INTEGER, b : INTEGER) RETURNS INTEGER
    IF a > b THEN
        RETURN a
    ELSE
        RETURN b
    ENDIF
ENDFUNCTION

OUTPUT Maks(Maks(12, 45), 30)

  2. Buat FUNCTION IsPrima(n) yang mengembalikan TRUE jika n bilangan prima.

    Petunjuk

    Periksa pembagi dari 2 selama d * d <= n.

    Lihat jawaban
    CONTOH
    FUNCTION IsPrima(n : INTEGER) RETURNS BOOLEAN
    DECLARE d : INTEGER
    IF n < 2 THEN
        RETURN FALSE
    ENDIF
    d ← 2
    WHILE d * d <= n DO
        IF n MOD d = 0 THEN
            RETURN FALSE
        ENDIF
        d ← d + 1
    ENDWHILE
    RETURN TRUE
ENDFUNCTION

Poin penting

  • Prosedur menjalankan langkah, fungsi mengembalikan nilai.
  • Parameter membuat satu fungsi bisa dipakai ulang.
