Fungsi dan nilai kembali

Buka versi interaktif

Fungsi adalah modul yang menerima input lewat parameter, menghitung, lalu mengembalikan satu nilai dengan RETURN. Bentuknya: FUNCTION Nama(parameter : TIPE) RETURNS TIPE ... ENDFUNCTION.

Nilai kembali bisa langsung dipakai di ekspresi: luas ← Luas(8, 5), OUTPUT Luas(3, 4) + 10, atau IF Luas(p, l) > 100 THEN. Begitu RETURN dijalankan, fungsi langsung selesai; baris di bawahnya tidak dijalankan.

Fungsi yang baik itu murni: hasilnya hanya bergantung pada parameternya, dan ia tidak menampilkan apa pun atau mengubah variabel di luar. Fungsi murni mudah diuji: Luas(8, 5) selalu 40. Jika ingin menampilkan sesuatu, serahkan ke pemanggilnya atau ke prosedur.

CONTOH
FUNCTION Luas(p : INTEGER, l : INTEGER) RETURNS INTEGER
    RETURN p * l
ENDFUNCTION

FUNCTION HargaSetelahDiskon(harga : REAL, persen : REAL) RETURNS REAL
    RETURN harga - harga * persen / 100
ENDFUNCTION

START
    OUTPUT Luas(8, 5)
    OUTPUT Luas(3, 4) + 10
    OUTPUT HargaSetelahDiskon(200000, 15)
END
KELUARAN
40
22
170000

Soal latihan

  1. Buat FUNCTION Maks(a, b) yang mengembalikan nilai terbesar, lalu pakai untuk mencari terbesar dari tiga angka.

    Petunjuk

    Maks(Maks(x, y), z).

    Lihat jawaban
    CONTOH
    FUNCTION Maks(a : INTEGER, b : INTEGER) RETURNS INTEGER
    IF a > b THEN
        RETURN a
    ELSE
        RETURN b
    ENDIF
ENDFUNCTION

OUTPUT Maks(Maks(12, 45), 30)
    KELUARAN
    45

  2. Buat FUNCTION IsPrima(n) yang mengembalikan TRUE jika n bilangan prima.

    Petunjuk

    Periksa pembagi dari 2 selama d * d <= n.

    Lihat jawaban
    CONTOH
    FUNCTION IsPrima(n : INTEGER) RETURNS BOOLEAN
    DECLARE d : INTEGER
    IF n < 2 THEN
        RETURN FALSE
    ENDIF
    d ← 2
    WHILE d * d <= n DO
        IF n MOD d = 0 THEN
            RETURN FALSE
        ENDIF
        d ← d + 1
    ENDWHILE
    RETURN TRUE
ENDFUNCTION
    KELUARAN
    IsPrima(29) → TRUE · IsPrima(21) → FALSE

Poin penting

  • Fungsi mengembalikan satu nilai dengan RETURN.
  • RETURN langsung mengakhiri fungsi.
  • Fungsi murni mudah diuji.

Cek pemahaman

Apa yang dicetak OUTPUT Luas(2, 3) * 2?

Jawaban: 12

Luas(2, 3) = 6, lalu × 2.
