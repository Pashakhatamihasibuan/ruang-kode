FOR, WHILE, dan DO-WHILE: contoh sederhana dan bedanya

Buka versi interaktif

Ketiga loop bisa menyelesaikan tugas yang sama. Bedanya ada pada kapan kondisi diperiksa dan siapa yang mengurus penghitung. Contoh di bawah mencetak 1 sampai 5 dengan ketiganya, dan hasilnya identik: 1 2 3 4 5.

FOR: penghitung diurus otomatis, cocok jika jumlah putaran pasti (cetak 10 baris, proses 30 mahasiswa). WHILE: kondisi dicek di awal, jadi bisa jalan 0 kali; cocok jika jumlah putaran belum diketahui (menabung sampai target, membaca data sampai habis). DO-WHILE / REPEAT-UNTIL: kondisi dicek di akhir, jadi pasti jalan minimal 1 kali; cocok untuk menu dan validasi input.

Perbedaan paling terasa muncul saat kondisi sudah salah sejak awal. Visual di bawah menjalankan ketiga loop dengan nilai awal n. Jalankan dengan n = 1: ketiganya mencetak 1 sampai 5. Lalu ganti n = 10: FOR dan WHILE tidak mencetak apa pun, sedangkan DO-WHILE tetap mencetak 10 satu kali, karena badannya jalan dulu sebelum kondisi diperiksa.

Cara memilih cepat: tanyakan "apakah aku tahu berapa kali?" Jika ya, FOR. Jika tidak, tanyakan "apakah badannya harus jalan minimal sekali?" Jika ya, DO-WHILE; jika tidak, WHILE.

PSEUDOCODE
START
    DECLARE i, n : INTEGER
    INPUT n
    OUTPUT "FOR:"
    FOR i ← n TO 5 DO
        OUTPUT i
    ENDFOR
    OUTPUT "WHILE:"
    i ← n
    WHILE i <= 5 DO
        OUTPUT i
        i ← i + 1
    ENDWHILE
    OUTPUT "DO-WHILE:"
    i ← n
    REPEAT
        OUTPUT i
        i ← i + 1
    UNTIL i > 5
END

Soal latihan

  1. Tulis tiga versi (FOR, WHILE, REPEAT-UNTIL) untuk mencetak bilangan genap 2 sampai 10.

    Petunjuk

    FOR pakai STEP 2. WHILE dan REPEAT-UNTIL: mulai i ← 2, tambah 2 setiap putaran.

    Lihat jawaban
    CONTOH
    // FOR
FOR i ← 2 TO 10 STEP 2 DO
    OUTPUT i
ENDFOR

// WHILE
i ← 2
WHILE i <= 10 DO
    OUTPUT i
    i ← i + 2
ENDWHILE

// REPEAT-UNTIL
i ← 2
REPEAT
    OUTPUT i
    i ← i + 2
UNTIL i > 10
    KELUARAN
    2 4 6 8 10 (ketiganya)

  2. Tulis hitung mundur 5 sampai 1 dengan FOR dan dengan WHILE.

    Petunjuk

    FOR pakai STEP -1. WHILE: kondisi i >= 1, kurangi i setiap putaran.

    Lihat jawaban
    CONTOH
    // FOR
FOR i ← 5 TO 1 STEP -1 DO
    OUTPUT i
ENDFOR

// WHILE
i ← 5
WHILE i >= 1 DO
    OUTPUT i
    i ← i - 1
ENDWHILE
    KELUARAN
    5 4 3 2 1

  3. Pilih loop yang paling tepat untuk setiap kasus dan beri alasan: (a) cetak 12 bulan, (b) baca angka sampai pengguna mengetik 0, (c) tampilkan menu ATM sampai pilih Keluar.

    Petunjuk

    Tanyakan: jumlahnya diketahui? Harus jalan minimal sekali?

    Lihat jawaban
    CONTOH
    (a) FOR: jumlahnya pasti 12.
(b) WHILE (atau REPEAT-UNTIL): jumlah input belum diketahui, berhenti di sentinel 0.
(c) DO-WHILE / REPEAT-UNTIL: menu harus tampil minimal sekali.

  4. Tulis ketiga loop di Python untuk mencetak 1 sampai 3. Ingat Python tidak punya do-while.

    Petunjuk

    FOR: range(1, 4). WHILE: i += 1. Do-while: while True lalu break.

    Lihat jawaban
    PYTHON
    # FOR
for i in range(1, 4):
    print(i)

# WHILE
i = 1
while i <= 3:
    print(i)
    i += 1

# DO-WHILE
i = 1
while True:
    print(i)
    i += 1
    if i > 3:
        break

Poin penting

  • Ketiga loop bisa mengerjakan tugas yang sama.
  • FOR: jumlah pasti. WHILE: cek di awal, bisa 0 kali. DO-WHILE: cek di akhir, minimal 1 kali.
  • Python tidak punya do-while; pakai while True dengan break.

Cek pemahaman

i ← 10, lalu WHILE i <= 5 DO OUTPUT i. Berapa kali OUTPUT jalan?

Jawaban: 0

Kondisi dicek di awal dan langsung salah.

i ← 10, lalu REPEAT OUTPUT i ... UNTIL i > 5. Berapa kali OUTPUT jalan?

Jawaban: 1

Badan jalan dulu, baru kondisi dicek.

Mencetak daftar 40 mahasiswa paling cocok memakai?

Jawaban: FOR

Jumlahnya sudah diketahui.

Meminta password sampai benar paling cocok memakai?

Jawaban: DO-WHILE

Harus meminta minimal sekali, jumlah percobaan belum diketahui.
