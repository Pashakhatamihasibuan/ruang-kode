Array: banyak nilai dalam satu nama

Buka versi interaktif

Array menyimpan banyak nilai sejenis dalam satu nama, misalnya 5 nilai ujian di nilai[0] sampai nilai[4]. Angka di dalam kurung siku disebut indeks dan dimulai dari 0 di kebanyakan bahasa (Java, Python, JavaScript, Flowgorithm).

Array hampir selalu diproses dengan FOR, karena jumlah isinya diketahui. Pola dasarnya: FOR i ← 0 TO n - 1. Kesalahan klasik adalah menulis TO n, yang mengakses satu kotak di luar array.

Mencari nilai tertinggi: anggap isi pertama sebagai yang tertinggi (maks ← nilai[0]), lalu bandingkan dengan setiap isi berikutnya. Jangan mulai dari maks ← 0, karena akan salah jika semua nilai negatif.

Visual meminta 5 input nilai. Ganti dengan angka lain dan prediksi hasilnya.

PSEUDOCODE
START
    DECLARE nilai : ARRAY[5] OF INTEGER
    DECLARE i, maks, total : INTEGER
    DECLARE rata : REAL
    FOR i ← 0 TO 4 DO
        INPUT nilai[i]
    ENDFOR
    maks ← nilai[0]
    total ← 0
    FOR i ← 0 TO 4 DO
        total ← total + nilai[i]
        IF nilai[i] > maks THEN
            maks ← nilai[i]
        ENDIF
    ENDFOR
    rata ← total / 5
    OUTPUT "Tertinggi: ", maks
    OUTPUT "Rata-rata: ", rata
END

Soal latihan

  1. Array suhu berisi 7 nilai seminggu: 31, 29, 33, 30, 28, 32, 34. Hitung rata-rata dan suhu terendah.

    Petunjuk

    Satu FOR cukup: jumlahkan sambil membandingkan dengan min ← suhu[0].

    Lihat jawaban
    CONTOH
    DECLARE suhu : ARRAY[0..6] OF INTEGER
DECLARE i, total, minim : INTEGER
suhu ← [31, 29, 33, 30, 28, 32, 34]
total ← 0
minim ← suhu[0]
FOR i ← 0 TO 6 DO
    total ← total + suhu[i]
    IF suhu[i] < minim THEN
        minim ← suhu[i]
    ENDIF
ENDFOR
OUTPUT "Rata-rata: ", total / 7
OUTPUT "Terendah: ", minim
    KELUARAN
    Rata-rata: 31
Terendah: 28

  2. Balik urutan isi array [1, 2, 3, 4, 5] menjadi [5, 4, 3, 2, 1] tanpa array baru.

    Petunjuk

    Tukar a[i] dengan a[n-1-i] untuk i dari 0 sampai n DIV 2 - 1.

    Lihat jawaban
    CONTOH
    DECLARE a : ARRAY[0..4] OF INTEGER
DECLARE i, t, n : INTEGER
a ← [1, 2, 3, 4, 5]
n ← 5
FOR i ← 0 TO n DIV 2 - 1 DO
    t ← a[i]
    a[i] ← a[n - 1 - i]
    a[n - 1 - i] ← t
ENDFOR
OUTPUT a
    KELUARAN
    [5, 4, 3, 2, 1]

Poin penting

  • Indeks array dimulai dari 0.
  • Proses array dengan FOR 0 sampai n - 1.
  • Nilai maksimum dimulai dari isi pertama, bukan 0.

Cek pemahaman

Array berisi 5 nilai. Indeks terakhirnya?

Jawaban: 4

Indeks 0 sampai 4.

Kenapa maks ← nilai[0], bukan maks ← 0?

Jawaban: Agar benar walau semua nilai negatif

Jika semua negatif, 0 akan keliru dianggap maksimum.
