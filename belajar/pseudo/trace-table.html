Trace table

Buka versi interaktif

Trace table (tabel jejak) adalah cara menjalankan algoritma di atas kertas, baris demi baris, sambil mencatat nilai setiap variabel. Setiap kolom satu variabel (ditambah kolom kondisi dan output), setiap baris satu langkah yang mengubah nilai.

Trace table dipakai untuk tiga hal: (1) memahami algoritma orang lain, (2) menemukan bug dengan membandingkan isi tabel dengan yang seharusnya, dan (3) menjawab soal ujian "apa output algoritma berikut?". Ini keterampilan wajib di ujian algoritma kampus dan tes masuk kerja.

Tipsnya: tulis hanya saat nilai berubah, catat hasil kondisi (benar/salah) di setiap pengecekan loop, dan jangan melompati langkah walaupun terasa jelas. Kesalahan biasanya bersembunyi di langkah yang kita anggap jelas.

Kolom variabel di visual adalah trace table otomatis. Isi tabel di bawah dengan tanganmu dulu untuk n = 5, baru jalankan visual dan cocokkan langkah demi langkah.

PSEUDOCODE
START
    DECLARE n, i, hasil : INTEGER
    INPUT n
    hasil ← 1
    FOR i ← 2 TO n DO
        hasil ← hasil * i
    ENDFOR
    OUTPUT n, "! = ", hasil
END

Soal latihan

  1. Buat trace table untuk:
    a ← 1; b ← 1; FOR i ← 1 TO 4 DO c ← a + b; a ← b; b ← c ENDFOR; OUTPUT b

    Petunjuk

    Kolom: i, c, a, b. Catat setiap putaran.

    Lihat jawaban
    CONTOH
    i | c | a | b
- | - | 1 | 1
1 | 2 | 1 | 2
2 | 3 | 2 | 3
3 | 5 | 3 | 5
4 | 8 | 5 | 8
OUTPUT 8
    KELUARAN
    8

  2. Trace algoritma ini dengan n = 6 dan tentukan outputnya:
    hitung ← 0; WHILE n <> 1 DO IF n MOD 2 = 0 THEN n ← n DIV 2 ELSE n ← 3 * n + 1 ENDIF; hitung ← hitung + 1 ENDWHILE; OUTPUT hitung

    Petunjuk

    Catat n dan hitung setiap putaran sampai n = 1.

    Lihat jawaban
    CONTOH
    n : 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1
hitung: 1   2    3   4    5   6   7   8
OUTPUT 8
    KELUARAN
    8

Poin penting

  • Satu kolom per variabel, satu baris per perubahan.
  • Catat hasil setiap kondisi.
  • Jangan melompati langkah yang terasa jelas.

Cek pemahaman

Pada trace di atas, berapa nilai hasil saat i = 4 selesai diproses?

Jawaban: 24

6 × 4 = 24.

Apa fungsi utama trace table?

Jawaban: Menjalankan algoritma di kertas untuk memahami dan mencari bug
