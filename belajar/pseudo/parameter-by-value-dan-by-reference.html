Parameter by value dan by reference

Buka versi interaktif

Ada dua cara mengirim data ke modul. By value (BYVAL): modul menerima salinan nilai. Mengubah parameter di dalam modul tidak mengubah variabel asli di pemanggil. Ini cara bawaan dan paling aman.

By reference (BYREF): modul menerima alamat variabel asli. Mengubah parameter berarti mengubah variabel pemanggil. Dipakai saat modul memang harus mengubah data pemanggil, misalnya prosedur Tukar(a, b) yang menukar isi dua variabel.

Analogi: by value seperti memberi fotokopi dokumen, coretan di fotokopi tidak mengubah aslinya. By reference seperti meminjamkan dokumen asli.

Di bahasa nyata: Java dan Python mengirim tipe dasar (int, float) secara by value. Objek dan list dikirim sebagai salinan referensi, sehingga isi list bisa diubah dari dalam fungsi. C++ dan C# punya penanda eksplisit (&, ref).

By value vs by reference
AspekBYVALBYREF
Yang dikirimSalinan nilaiAlamat variabel asli
Variabel pemanggilTidak berubahIkut berubah
KeamananAman dari perubahan tak sengajaHarus hati-hati
ContohLuas(p, l)Tukar(a, b)
CONTOH
PROCEDURE NaikkanByVal(BYVAL x : INTEGER)
    x ← x + 10
    OUTPUT "Di dalam: ", x
ENDPROCEDURE

PROCEDURE NaikkanByRef(BYREF x : INTEGER)
    x ← x + 10
ENDPROCEDURE

PROCEDURE Tukar(BYREF a : INTEGER, BYREF b : INTEGER)
    DECLARE t : INTEGER
    t ← a
    a ← b
    b ← t
ENDPROCEDURE

START
    nilai ← 5
    CALL NaikkanByVal(nilai)
    OUTPUT "Setelah ByVal: ", nilai
    CALL NaikkanByRef(nilai)
    OUTPUT "Setelah ByRef: ", nilai
    p ← 1
    q ← 2
    CALL Tukar(p, q)
    OUTPUT p, " ", q
END
KELUARAN
Di dalam: 15
Setelah ByVal: 5
Setelah ByRef: 15
2 1

Soal latihan

  1. Tulis prosedur Urutkan2(BYREF a, BYREF b) yang memastikan a ≤ b (tukar jika perlu).

    Petunjuk

    Pakai variabel bantu, tukar hanya jika a > b.

    Lihat jawaban
    CONTOH
    PROCEDURE Urutkan2(BYREF a : INTEGER, BYREF b : INTEGER)
    DECLARE t : INTEGER
    IF a > b THEN
        t ← a
        a ← b
        b ← t
    ENDIF
ENDPROCEDURE

x ← 9
y ← 4
CALL Urutkan2(x, y)
OUTPUT x, " ", y
    KELUARAN
    4 9

  2. Tebak output program berikut:
    PROCEDURE Ubah(BYVAL a, BYREF b): a ← 0; b ← 0
    p ← 5; q ← 7; CALL Ubah(p, q); OUTPUT p, q

    Petunjuk

    a menerima salinan, b menerima alamat asli.

    Lihat jawaban
    CONTOH
    p tetap 5 (BYVAL)
q menjadi 0 (BYREF)
    KELUARAN
    5 0

Poin penting

  • BYVAL mengirim salinan, aslinya aman.
  • BYREF mengirim alamat, aslinya ikut berubah.
  • Pakai BYREF hanya jika modul memang harus mengubah data pemanggil.

Cek pemahaman

x ← 3; CALL Gandakan(x) dengan BYVAL, di dalamnya x ← x * 2. Berapa x setelahnya?

Jawaban: 3

Yang diubah hanya salinannya.

Prosedur Tukar(a, b) harus memakai?

Jawaban: BYREF

Tujuannya memang mengubah variabel pemanggil.
