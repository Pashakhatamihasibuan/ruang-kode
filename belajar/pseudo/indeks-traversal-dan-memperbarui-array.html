Indeks, traversal, dan memperbarui array

Buka versi interaktif

Indeks adalah nomor kotak di array. Di kebanyakan bahasa, indeks dimulai dari 0, sehingga array berisi n data punya indeks 0 sampai n - 1. harga[2] berarti kotak ketiga. Beberapa buku pseudocode memakai indeks mulai 1; selalu periksa konvensi yang dipakai.

Traversal berarti mengunjungi setiap isi array satu per satu, biasanya dengan FOR. Maju: FOR i ← 0 TO n - 1. Mundur: FOR i ← n - 1 TO 0 STEP -1. Hampir semua algoritma array (jumlah, cari, hitung, urutkan) adalah traversal ditambah sedikit logika.

Memperbarui isi array sama seperti mengisi variabel, tetapi dengan indeks: harga[i] ← harga[i] + 1000. Di dalam traversal, kita bisa memperbarui setiap isi sekaligus, misalnya menaikkan semua harga 10%.

Visual menaikkan lima harga sebesar 10%, lalu menampilkannya dari indeks terakhir ke indeks pertama (traversal mundur).

Pola traversal
TujuanPseudocode
Maju semuaFOR i ← 0 TO n - 1
Mundur semuaFOR i ← n - 1 TO 0 STEP -1
Indeks genap sajaFOR i ← 0 TO n - 1 STEP 2
Mulai dari keduaFOR i ← 1 TO n - 1
Pasangan bersebelahanFOR i ← 0 TO n - 2 (pakai a[i] dan a[i + 1])
PSEUDOCODE
START
    DECLARE harga : ARRAY[5] OF INTEGER
    harga ← [12000, 8000, 15000, 5000, 20000]
    DECLARE i : INTEGER
    FOR i ← 0 TO 4 DO
        harga[i] ← harga[i] + Int(harga[i] * 10 / 100)
    ENDFOR
    OUTPUT "Harga baru: ", harga
    FOR i ← 4 TO 0 STEP -1 DO
        OUTPUT "Indeks ", i, ": ", harga[i]
    ENDFOR
END

Soal latihan

  1. Array a ← [4, 9, 2, 7, 5]. Tulis traversal yang menggandakan setiap isi di indeks genap saja.

    Petunjuk

    FOR i ← 0 TO 4 STEP 2.

    Lihat jawaban
    CONTOH
    FOR i ← 0 TO 4 STEP 2 DO
    a[i] ← a[i] * 2
ENDFOR
OUTPUT a
    KELUARAN
    [8, 9, 4, 7, 10]

  2. Hitung berapa pasangan bersebelahan yang naik (a[i] < a[i + 1]) pada [3, 5, 4, 6, 8, 2].

    Petunjuk

    Batas loop n - 2 agar a[i + 1] tidak keluar.

    Lihat jawaban
    CONTOH
    DECLARE a : ARRAY[0..5] OF INTEGER
DECLARE i, naik : INTEGER
a ← [3, 5, 4, 6, 8, 2]
naik ← 0
FOR i ← 0 TO 4 DO
    IF a[i] < a[i + 1] THEN
        naik ← naik + 1
    ENDIF
ENDFOR
OUTPUT naik
    KELUARAN
    3

  3. Di Python, naikkan setiap harga 10% lalu cetak dari belakang.

    Petunjuk

    Ubah lewat indeks: for i in range(len(h)). Cetak mundur dengan range(len(h) - 1, -1, -1).

    Lihat jawaban
    PYTHON
    h = [12000, 8000, 15000]
for i in range(len(h)):
    h[i] = h[i] + h[i] * 10 // 100
for i in range(len(h) - 1, -1, -1):
    print(i, h[i])
    KELUARAN
    2 16500
1 8800
0 13200

Poin penting

  • Indeks 0 sampai n - 1.
  • Traversal: kunjungi setiap isi dengan FOR.
  • Perbarui isi dengan a[i] ← ...

Cek pemahaman

Array 8 data. Traversal mundur dimulai dari indeks?

Jawaban: 7

Indeks terakhir = n - 1.

Untuk membandingkan a[i] dengan a[i + 1], batas akhir FOR adalah?

Jawaban: n - 2

Agar a[i + 1] tidak keluar dari array.
