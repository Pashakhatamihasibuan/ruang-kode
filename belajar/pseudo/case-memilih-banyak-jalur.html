CASE: memilih banyak jalur

Buka versi interaktif

Jika pilihan bergantung pada satu nilai yang tepat, misalnya kode menu 1, 2, 3, pakai CASE OF variabel ... OTHERWISE ... ENDCASE. Lebih rapi daripada IF bertingkat yang panjang, karena setiap pilihan berdiri di satu baris.

Bagian OTHERWISE menangani nilai yang tidak terdaftar, misalnya pengguna mengetik 9. Selalu sediakan OTHERWISE: pengguna pasti suatu saat mengetik sesuatu yang tidak kamu duga.

CASE di bahasa nyata: switch di Java, JavaScript, dan Dart; match di Python 3.10+; when di Kotlin. Hati-hati di Java dan JavaScript: setiap case butuh break, jika tidak, eksekusi "jatuh" ke case berikutnya.

Visual di bawah menjalankan logika yang sama dengan IF bertingkat (simulator belum punya simbol CASE). Bandingkan dengan pseudocode CASE di bagian contoh. Coba kode 1, 3, lalu 9.

CONTOH
DECLARE kode, harga : INTEGER
DECLARE menu : STRING
INPUT kode
CASE OF kode
    1 : menu ← "Kopi susu"
        harga ← 18000
    2 : menu ← "Teh tarik"
        harga ← 15000
    3 : menu ← "Jus jeruk"
        harga ← 20000
    OTHERWISE : menu ← "Tidak ada"
                harga ← 0
ENDCASE
OUTPUT menu, ": Rp", harga
KELUARAN
Teh tarik: Rp15000
PSEUDOCODE
START
    DECLARE kode, harga : INTEGER
    DECLARE menu : STRING
    INPUT kode
    IF kode = 1 THEN
        menu ← "Kopi susu"
        harga ← 18000
    ELSE
        IF kode = 2 THEN
            menu ← "Teh tarik"
            harga ← 15000
        ELSE
            IF kode = 3 THEN
                menu ← "Jus jeruk"
                harga ← 20000
            ELSE
                menu ← "Tidak ada"
                harga ← 0
            ENDIF
        ENDIF
    ENDIF
    OUTPUT menu, ": Rp", harga
END

Soal latihan

  1. Tulis CASE yang mengubah angka 1 sampai 7 menjadi nama hari (1 = Senin). Angka lain menghasilkan "Tidak valid".

    Petunjuk

    Tujuh pilihan ditambah OTHERWISE.

    Lihat jawaban
    CONTOH
    DECLARE k : INTEGER
DECLARE hari : STRING
INPUT k
CASE OF k
    1 : hari ← "Senin"
    2 : hari ← "Selasa"
    3 : hari ← "Rabu"
    4 : hari ← "Kamis"
    5 : hari ← "Jumat"
    6 : hari ← "Sabtu"
    7 : hari ← "Minggu"
    OTHERWISE : hari ← "Tidak valid"
ENDCASE
OUTPUT hari
    KELUARAN
    Masukan 5 → Jumat

  2. Tulis kalkulator sederhana: input a, b, dan operator (+, -, *, /). Pakai CASE untuk operatornya, dan jaga pembagian dengan nol.

    Petunjuk

    CASE pada STRING op. Di cabang "/" cek b = 0 dulu.

    Lihat jawaban
    CONTOH
    DECLARE a, b : REAL
DECLARE op : STRING
INPUT a
INPUT op
INPUT b
CASE OF op
    "+" : OUTPUT a + b
    "-" : OUTPUT a - b
    "*" : OUTPUT a * b
    "/" : IF b = 0 THEN
              OUTPUT "Tidak bisa membagi dengan nol"
          ELSE
              OUTPUT a / b
          ENDIF
    OTHERWISE : OUTPUT "Operator tidak dikenal"
ENDCASE
    KELUARAN
    12 * 3 → 36 · 7 / 0 → Tidak bisa membagi dengan nol

Poin penting

  • CASE untuk mencocokkan satu nilai tepat dengan banyak pilihan.
  • Selalu sediakan OTHERWISE.
  • Rentang nilai lebih cocok dengan IF bertingkat.

Cek pemahaman

Pengguna mengetik 9 pada menu 1 sampai 3. Bagian mana yang jalan?

Jawaban: OTHERWISE

OTHERWISE menangkap nilai yang tidak terdaftar.

Menentukan nilai huruf dari angka 0 sampai 100 lebih cocok memakai?

Jawaban: IF bertingkat

Berupa rentang, bukan nilai tepat.
