Variabel, tipe data, dan operator

Buka versi interaktif

Variabel adalah kotak bernama untuk menyimpan nilai. Sebelum dipakai, variabel dideklarasikan beserta tipe-nya, agar jelas jenis isi yang boleh masuk. Tipe dasar: INTEGER (bilangan bulat), REAL (bilangan pecahan), STRING (teks), BOOLEAN (benar/salah), dan CHAR (satu huruf).

Operator aritmetika: + - * /, ditambah mod (sisa bagi, 17 mod 5 = 2) dan div atau Int(a / b) (hasil bagi bulat, 17 div 5 = 3). Operator perbandingan: = <> < > <= >=, hasilnya selalu benar atau salah. Operator logika: and, or, not.

Urutan hitung mengikuti matematika: kurung dulu, lalu kali-bagi, lalu tambah-kurang. celcius * 9 / 5 + 32 dihitung dari kiri: kali 9, bagi 5, baru tambah 32. Saat ragu, pakai kurung agar pembaca tidak salah tafsir.

Contoh visual mengubah suhu Celcius ke Fahrenheit dengan tipe REAL, karena hasilnya bisa pecahan. Coba input 100 atau -40.

PSEUDOCODE
START
    DECLARE celcius, fahrenheit : REAL
    INPUT celcius
    fahrenheit ← celcius * 9 / 5 + 32
    OUTPUT celcius, " C = ", fahrenheit, " F"
END

Soal latihan

  1. Ubah 135 menit menjadi jam dan menit memakai DIV dan MOD.

    Petunjuk

    DIV memberi hasil bagi bulat, MOD memberi sisa.

    Lihat jawaban
    CONTOH
    DECLARE total, jam, menit : INTEGER
total ← 135
jam ← total DIV 60
menit ← total MOD 60
OUTPUT jam, " jam ", menit, " menit"
    KELUARAN
    2 jam 15 menit

  2. Tukar isi variabel a = 3 dan b = 8 lalu tampilkan keduanya.

    Petunjuk

    Butuh variabel bantu t agar nilai a tidak hilang.

    Lihat jawaban
    CONTOH
    DECLARE a, b, t : INTEGER
a ← 3
b ← 8
t ← a
a ← b
b ← t
OUTPUT "a = ", a, ", b = ", b
    KELUARAN
    a = 8, b = 3

  3. Hitung rata-rata tiga nilai 80, 75, 92 dan tampilkan dengan tipe yang tepat.

    Petunjuk

    Rata-rata bisa pecahan, jadi pakai REAL.

    Lihat jawaban
    CONTOH
    DECLARE n1, n2, n3 : INTEGER
DECLARE rata : REAL
n1 ← 80
n2 ← 75
n3 ← 92
rata ← (n1 + n2 + n3) / 3
OUTPUT "Rata-rata: ", rata
    KELUARAN
    Rata-rata: 82.333...

Poin penting

  • Deklarasikan variabel dengan tipenya.
  • mod = sisa bagi, div = hasil bagi bulat.
  • Kurung membuat urutan hitung jelas.

Cek pemahaman

Berapa 23 mod 4?

Jawaban: 3

23 = 4 × 5 + 3, sisanya 3.

Tipe yang tepat untuk menyimpan IPK 3.75?

Jawaban: REAL

IPK berupa bilangan pecahan.

Jawaban: salah
