Array multidimensi

Buka versi interaktif

Array dua dimensi (matriks) menyimpan data dalam bentuk tabel: baris dan kolom. Contoh: nilai 3 siswa untuk 4 mata pelajaran, DECLARE nilai : ARRAY[0..2, 0..3] OF INTEGER. Satu isi diakses dengan dua indeks: nilai[baris][kolom] atau nilai[baris, kolom].

Traversal matriks memakai loop bersarang: loop luar untuk baris, loop dalam untuk kolom. Total isi = jumlah baris × jumlah kolom. Pada contoh 3 × 4 = 12 nilai.

Pemakaian nyata: papan permainan (catur, tic-tac-toe), kursi bioskop, peta grid, gambar (setiap piksel), dan spreadsheet. Array tiga dimensi juga ada (misalnya nilai per siswa, per mapel, per semester), tetapi jarang dipakai.

Visual menghitung total dan rata-rata setiap siswa (setiap baris). Perhatikan total diisi 0 lagi di awal setiap baris, bukan sekali di awal program.

Matriks nilai[3][4]
Kolom 0Kolom 1Kolom 2Kolom 3
Baris 080759085
Baris 160706580
Baris 295889290
PSEUDOCODE
START
    DECLARE nilai : ARRAY[3, 4] OF INTEGER
    nilai ← [[80, 75, 90, 85], [60, 70, 65, 80], [95, 88, 92, 90]]
    DECLARE b, k, total : INTEGER
    FOR b ← 0 TO 2 DO
        total ← 0
        FOR k ← 0 TO 3 DO
            total ← total + nilai[b][k]
        ENDFOR
        OUTPUT "Siswa ", (b + 1), ": total ", total, ", rata-rata ", total / 4
    ENDFOR
END

Soal latihan

  1. Matriks 3 × 3 [[1, 2, 3], [4, 5, 6], [7, 8, 9]]. Hitung jumlah diagonal utama.

    Petunjuk

    Diagonal utama: m[i][i].

    Lihat jawaban
    CONTOH
    total ← 0
FOR i ← 0 TO 2 DO
    total ← total + m[i][i]
ENDFOR
OUTPUT total
    KELUARAN
    15

  2. Dari matriks nilai yang sama dengan pelajaran (3 siswa × 4 mapel), hitung rata-rata setiap mapel (kolom).

    Petunjuk

    Tukar loop: luar kolom, dalam baris. Reset total setiap kolom.

    Lihat jawaban
    CONTOH
    FOR k ← 0 TO 3 DO
    total ← 0
    FOR b ← 0 TO 2 DO
        total ← total + nilai[b][k]
    ENDFOR
    OUTPUT "Mapel ", k + 1, ": ", total / 3
ENDFOR
    KELUARAN
    Mapel 1: 78.33
Mapel 2: 77.67
Mapel 3: 82.33
Mapel 4: 85

Poin penting

  • Matriks = baris × kolom, akses dengan dua indeks.
  • Traversal dengan loop bersarang.
  • Reset akumulator per baris jika menghitung per baris.

Cek pemahaman

Pada tabel di atas, nilai[1][3] adalah?

Jawaban: 80

Baris 1 (kedua), kolom 3 (keempat).

Matriks 5 baris × 6 kolom berisi berapa data?

Jawaban: 30

5 × 6 = 30.
