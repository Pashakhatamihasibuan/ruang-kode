Off-by-one dan kesalahan logika

Buka versi interaktif

Kesalahan sintaks ditangkap oleh compiler. Kesalahan logika tidak: program berjalan, tetapi hasilnya salah. Jenis paling terkenal adalah off-by-one (meleset satu): loop berjalan satu kali terlalu banyak atau terlalu sedikit.

Visual di bawah sengaja berisi bug: array 5 data (indeks 0 sampai 4) diproses dengan FOR i ← 0 TO 5. Pada putaran terakhir, nilai[5] tidak ada. Simulator menampilkan hasilnya sebagai NaN (bukan angka); Java akan berhenti dengan ArrayIndexOutOfBoundsException, Python dengan IndexError. Perbaikannya: TO 4, atau umumnya TO n - 1.

Kesalahan logika lain yang sering: > tertukar dengan >= (nilai tepat 75 tidak lulus), akumulator tidak diisi nilai awal atau diisi di dalam loop, urutan IF bertingkat terbalik, AND tertukar dengan OR, dan pembagian bulat yang tidak disengaja (7 / 2 menjadi 3).

Cara melawannya: uji kasus batas (nilai minimum, maksimum, tepat di batas, data kosong, satu data), buat trace table, dan bandingkan dengan hasil hitungan manual.

PSEUDOCODE
START
    DECLARE nilai : ARRAY[5] OF INTEGER
    nilai ← [70, 85, 62, 91, 78]
    DECLARE i, total : INTEGER
    total ← 0
    FOR i ← 0 TO 5 DO
        total ← total + nilai[i]
    ENDFOR
    OUTPUT "Total: ", total
END

Soal latihan

  1. Temukan bug: algoritma ini seharusnya mencetak 1 sampai 10.
    i ← 1; WHILE i < 10 DO OUTPUT i; i ← i + 1 ENDWHILE

    Petunjuk

    Uji nilai batas: apakah 10 ikut tercetak?

    Lihat jawaban
    CONTOH
    Bug off-by-one: kondisi i < 10 berhenti sebelum 10, jadi hanya 1 sampai 9.
Perbaikan: WHILE i <= 10 DO

  2. Temukan bug logika: menghitung rata-rata nilai array 5 data.
    FOR i ← 0 TO 4 DO total ← 0; total ← total + a[i] ENDFOR; rata ← total / 5

    Petunjuk

    Di mana nilai awal akumulator diletakkan?

    Lihat jawaban
    CONTOH
    total ← 0 berada di dalam loop, sehingga total di-reset setiap putaran
dan hanya berisi a[4].
Perbaikan:
total ← 0
FOR i ← 0 TO 4 DO
    total ← total + a[i]
ENDFOR
rata ← total / 5

  3. Tuliskan 5 kasus uji untuk fungsi diskon: "belanja ≥ 100.000 dapat diskon 10%, belanja tidak boleh negatif".

    Petunjuk

    Uji tepat di batas, di bawah batas, nol, negatif, dan nilai besar.

    Lihat jawaban
    CONTOH
    99999  → tanpa diskon (tepat di bawah batas)
100000 → diskon 10000 (tepat di batas)
0      → tanpa diskon
-5000  → error: belanja tidak boleh negatif
5000000 → diskon 500000

Poin penting

  • Kesalahan logika tidak ditangkap compiler.
  • Off-by-one: batas loop meleset satu.
  • Selalu uji kasus batas.

Cek pemahaman

Array 10 data, indeks mulai 0. Batas FOR yang benar?

Jawaban: 0 TO 9

Indeks 0 sampai n - 1.

total ← 0 ditaruh di dalam loop. Akibatnya?

Jawaban: Total hanya berisi data terakhir

Total di-reset setiap putaran.
