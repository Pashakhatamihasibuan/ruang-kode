Operasi aritmetika dan urutan operator

Buka versi interaktif

Operator aritmetika: + - * /, ditambah MOD (sisa bagi, 17 MOD 5 = 2) dan DIV atau Int(a / b) (hasil bagi bulat, 17 DIV 5 = 3). MOD dan DIV sangat sering dipakai: mengecek genap-ganjil, memecah detik menjadi jam, dan mengambil digit terakhir angka.

Urutan operator (precedence) mengikuti matematika: kurung dulu, lalu kali, bagi, MOD, DIV, lalu tambah dan kurang. Operator dengan tingkat sama dihitung dari kiri ke kanan. Jadi 2 + 3 * 4 = 14, bukan 20, dan (2 + 3) * 4 = 20.

Jebakan klasik: rata-rata tiga nilai ditulis a + b + c / 3. Yang dibagi 3 hanya c! Yang benar (a + b + c) / 3. Saat ragu, pakai kurung agar pembaca dan komputer tidak salah tafsir.

Visual mengubah total detik menjadi jam, menit, dan detik. 7384 detik = 2 jam (7200), sisa 184 detik = 3 menit (180), sisa 4 detik. Coba 3661 dan 59.

PSEUDOCODE
START
    DECLARE total, jam, menit, detik : INTEGER
    INPUT total
    jam ← Int(total / 3600)
    menit ← Int((total mod 3600) / 60)
    detik ← total mod 60
    OUTPUT jam, " jam ", menit, " menit ", detik, " detik"
END

Soal latihan

  1. Hitung tanpa komputer: 8 + 12 / 4 * 2 - 3.

    Petunjuk

    Bagi dan kali dulu dari kiri ke kanan, baru tambah dan kurang.

    Lihat jawaban
    CONTOH
    12 / 4 = 3
3 * 2 = 6
8 + 6 - 3 = 11
    KELUARAN
    11

  2. Tulis pseudocode yang mengambil digit terakhir dan sisa angkanya dari bilangan 4728.

    Petunjuk

    Digit terakhir = n MOD 10, sisanya = n DIV 10.

    Lihat jawaban
    CONTOH
    DECLARE n : INTEGER
n ← 4728
OUTPUT "Digit terakhir: ", n MOD 10
OUTPUT "Sisanya: ", n DIV 10
    KELUARAN
    Digit terakhir: 8
Sisanya: 472

  3. Perbaiki rumus rata-rata yang salah ini: rata ← a + b + c / 3. Berapa hasil yang salah dan yang benar untuk a = 60, b = 70, c = 90?

    Petunjuk

    Hanya c yang dibagi 3 pada rumus salah.

    Lihat jawaban
    CONTOH
    Salah : 60 + 70 + 90 / 3 = 60 + 70 + 30 = 160
Benar : rata ← (a + b + c) / 3 = 220 / 3 = 73.33

Poin penting

  • MOD = sisa bagi, DIV = hasil bagi bulat.
  • Kurung, lalu kali-bagi, lalu tambah-kurang.
  • Rata-rata: (a + b + c) / 3, bukan a + b + c / 3.

Cek pemahaman

Berapa 23 MOD 4?

Jawaban: 3

23 = 4 × 5 + 3, sisanya 3.

Berapa 10 - 2 * 3?

Jawaban: 4

Kali dulu: 2 × 3 = 6, lalu 10 - 6 = 4.

Berapa 125 DIV 60?

Jawaban: 2

Hasil bagi bulat: 60 masuk 2 kali.
