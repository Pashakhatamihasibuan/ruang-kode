Ruang lingkup variabel dan enkapsulasi state

Buka versi interaktif

Ruang lingkup (scope) menentukan di mana sebuah variabel bisa dipakai. Variabel lokal dideklarasikan di dalam modul dan hanya hidup selama modul itu berjalan; setelah modul selesai, variabelnya hilang. Variabel global dideklarasikan di luar semua modul dan bisa dibaca serta diubah dari mana saja.

Variabel global terlihat praktis, tetapi berbahaya: jika ada bug, modul mana pun bisa menjadi penyebabnya. Aturan praktis: pakai variabel lokal dan parameter, kirim data masuk lewat parameter dan keluar lewat RETURN.

Dua modul boleh punya variabel lokal dengan nama sama tanpa saling mengganggu. i di prosedur A dan i di prosedur B adalah dua kotak berbeda.

Enkapsulasi state berarti menyembunyikan data di balik modul, dan hanya mengizinkan perubahan lewat modul itu. Contoh: saldo rekening hanya boleh berubah lewat Setor dan Tarik, yang memeriksa aturan (penarikan tidak boleh melebihi saldo). Inilah benih dari konsep class dan object di Java, Kotlin, Dart, dan Python.

Lokal vs global
AspekLokalGlobal
DideklarasikanDi dalam modulDi luar semua modul
Bisa dipakaiHanya di modul ituDi mana saja
UmurSelama modul berjalanSelama program berjalan
RisikoRendahBug sulit dilacak
CONTOH
DECLARE saldo : INTEGER          // state, hanya diubah lewat Setor dan Tarik
saldo ← 0

PROCEDURE Setor(jumlah : INTEGER)
    IF jumlah <= 0 THEN
        OUTPUT "Jumlah setoran tidak sah"
    ELSE
        saldo ← saldo + jumlah
    ENDIF
ENDPROCEDURE

PROCEDURE Tarik(jumlah : INTEGER)
    IF jumlah > saldo THEN
        OUTPUT "Saldo tidak cukup"
    ELSE
        saldo ← saldo - jumlah
    ENDIF
ENDPROCEDURE

FUNCTION Hitung() RETURNS INTEGER
    DECLARE i, total : INTEGER   // lokal: hilang setelah fungsi selesai
    total ← 0
    FOR i ← 1 TO 3 DO
        total ← total + i
    ENDFOR
    RETURN total
ENDFUNCTION

START
    CALL Setor(50000)
    CALL Tarik(80000)
    CALL Tarik(20000)
    OUTPUT "Saldo: ", saldo
    OUTPUT Hitung()
END
KELUARAN
Saldo tidak cukup
Saldo: 30000
6

Soal latihan

  1. Tebak output, lalu jelaskan:
    x ← 10 (global)
    PROCEDURE Uji(): DECLARE x (lokal); x ← 99; OUTPUT x
    CALL Uji(); OUTPUT x

    Petunjuk

    Variabel lokal bernama sama menutupi variabel global di dalam prosedur.

    Lihat jawaban
    CONTOH
    Di dalam Uji: 99 (x lokal)
Setelah Uji : 10 (x global tidak tersentuh)
    KELUARAN
    99
10

  2. Rancang modul penghitung antrean: state nomor hanya boleh berubah lewat prosedur AmbilNomor dan Reset.

    Petunjuk

    Prosedur menaikkan nomor dan menampilkannya; Reset mengembalikan ke 0.

    Lihat jawaban
    CONTOH
    DECLARE nomor : INTEGER
nomor ← 0

PROCEDURE AmbilNomor()
    nomor ← nomor + 1
    OUTPUT "Nomor antrean: ", nomor
ENDPROCEDURE

PROCEDURE Reset()
    nomor ← 0
ENDPROCEDURE

CALL AmbilNomor()
CALL AmbilNomor()
CALL Reset()
CALL AmbilNomor()
    KELUARAN
    Nomor antrean: 1
Nomor antrean: 2
Nomor antrean: 1

Poin penting

  • Variabel lokal hanya hidup di modulnya.
  • Hindari global; pakai parameter dan RETURN.
  • Enkapsulasi: state hanya diubah lewat modul yang memeriksa aturan.
