Aturan menulis pseudocode

Buka versi interaktif

Tidak ada satu standar resmi, tetapi buku dan kampus di Indonesia memakai kata kunci yang mirip. Di Ruang Kode kita memakai kata kunci berhuruf besar: DECLARE, INPUT, OUTPUT, IF, WHILE, FOR, dan tanda panah ← untuk mengisi nilai ke variabel.

Tiga aturan penting. Pertama, satu baris satu langkah. Kedua, indentasi (menjorok ke dalam) menunjukkan langkah mana yang ada di dalam IF atau loop. Ketiga, setiap blok ditutup dengan pasangannya: IF dengan ENDIF, WHILE dengan ENDWHILE.

Kenapa memakai ← dan bukan =? Karena total ← total + 5 berarti "hitung total + 5, lalu simpan ke total". Ini perintah, bukan persamaan matematika. Tanda = kita pakai untuk membandingkan, misalnya IF nilai = 100.

Di kampus, kamu mungkin melihat versi berbahasa Indonesia (BACA, TULIS, JIKA ... MAKA). Artinya sama persis; tabel di bawah memetakan keduanya.

PSEUDOCODE
START
    DECLARE a, b, c : INTEGER
    DECLARE rata : REAL
    INPUT a
    INPUT b
    INPUT c
    rata ← (a + b + c) / 3
    OUTPUT "Rata-rata: ", rata
END

Poin penting

  • Satu baris satu langkah, indentasi menunjukkan blok.
  • ← mengisi nilai, = membandingkan.
  • Setiap blok punya penutup (ENDIF, ENDWHILE, ENDFOR).
