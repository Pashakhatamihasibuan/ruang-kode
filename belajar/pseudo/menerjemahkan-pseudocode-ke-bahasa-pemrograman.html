Menerjemahkan pseudocode ke bahasa pemrograman

Buka versi interaktif

Setelah logikanya benar di pseudocode, menulis kode tinggal menerjemahkan baris demi baris. Struktur IF, WHILE, FOR tidak berubah; yang berubah hanya cara penulisannya. Inilah alasan pseudocode diajarkan sebelum bahasa pemrograman.

Perhatikan tiga jebakan saat menerjemahkan. Pertama, = pembanding di pseudocode menjadi == di Python, Java, dan JavaScript. Kedua, FOR i ← 1 TO n menjadi range(1, n + 1) di Python, karena batas akhir range tidak ikut. Ketiga, pembagian bulat: // di Python, / antar-int di Java, dan Math.floor(a / b) di JavaScript.

Kode Python di bawah adalah terjemahan langsung program "jumlah 1 sampai n" dari modul perulangan. Ubah nilai n, lalu jalankan.

# Terjemahan pseudocode: Jumlah1SampaiN
n = 5
total = 0
for i in range(1, n + 1):   # FOR i <- 1 TO n
    total = total + i
print(f"Jumlah 1 sampai {n} = {total}")

Soal latihan

  1. Terjemahkan ke Python:
    FOR i ← 1 TO 5 DO OUTPUT i * i ENDFOR

    Petunjuk

    FOR i ← 1 TO 5 menjadi range(1, 6) karena batas akhir range tidak ikut.

    Lihat jawaban
    PYTHON
    for i in range(1, 6):
    print(i * i)

  2. Terjemahkan ke Java: REPEAT INPUT pin UNTIL pin = "2468".

    Petunjuk

    REPEAT-UNTIL menjadi do-while dengan kondisi dibalik.

    Lihat jawaban
    JAVA
    Scanner in = new Scanner(System.in);
String pin;
do {
    pin = in.nextLine();
} while (!pin.equals("2468"));

Poin penting

  • Struktur logika tetap, hanya penulisannya berubah.
  • = pembanding menjadi ==.
  • range(1, n + 1) untuk FOR 1 TO n di Python.

Cek pemahaman

FOR i ← 1 TO 10 di Python ditulis?

Jawaban: range(1, 11)

Batas akhir range tidak ikut.

IF x = 5 THEN di Java ditulis?

Jawaban: if (x == 5)

= di Java adalah pengisian nilai.
