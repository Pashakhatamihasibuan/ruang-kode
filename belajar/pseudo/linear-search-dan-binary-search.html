Linear search dan binary search

Buka versi interaktif

Linear search memeriksa isi array satu per satu dari depan sampai data ditemukan atau array habis. Cara ini bekerja untuk data apa pun, terurut atau tidak. Kita pakai WHILE dengan dua syarat: masih ada data dan belum ketemu. Nilai -1 menjadi tanda "belum ditemukan", karena tidak ada indeks negatif.

Binary search jauh lebih cepat, tetapi datanya harus terurut. Caranya seperti mencari kata di kamus: buka bagian tengah. Jika yang dicari lebih besar, buang separuh kiri; jika lebih kecil, buang separuh kanan. Ulangi sampai ketemu atau tidak ada data tersisa (kiri > kanan).

Bedanya sangat besar untuk data banyak. 1.000.000 data: linear search butuh sampai 1.000.000 pemeriksaan, binary search paling banyak sekitar 20, karena setiap langkah membuang separuh data.

Visual menjalankan binary search pada 8 data terurut. Cari 31 (ketemu di langkah kedua), lalu 3, 52, dan 20 (tidak ada). Perhatikan kiri, kanan, dan tengah bergerak. Versi linear search ada di bagian contoh.

CONTOH
// Linear search: data boleh tidak terurut
i ← 0
posisi ← -1
WHILE i < n AND posisi = -1 DO
    IF data[i] = cari THEN
        posisi ← i
    ENDIF
    i ← i + 1
ENDWHILE

// Binary search: data WAJIB terurut
kiri ← 0
kanan ← n - 1
posisi ← -1
WHILE kiri <= kanan AND posisi = -1 DO
    tengah ← (kiri + kanan) DIV 2
    IF data[tengah] = cari THEN
        posisi ← tengah
    ELSE IF data[tengah] < cari THEN
        kiri ← tengah + 1
    ELSE
        kanan ← tengah - 1
    ENDIF
ENDWHILE
PSEUDOCODE
START
    DECLARE data : ARRAY[8] OF INTEGER
    data ← [3, 8, 12, 17, 23, 31, 40, 52]
    DECLARE cari, kiri, kanan, tengah, posisi : INTEGER
    INPUT cari
    kiri ← 0
    kanan ← 7
    posisi ← -1
    WHILE kiri <= kanan and posisi = -1 DO
        tengah ← Int((kiri + kanan) / 2)
        IF data[tengah] = cari THEN
            posisi ← tengah
        ELSE
            IF data[tengah] < cari THEN
                kiri ← tengah + 1
            ELSE
                kanan ← tengah - 1
            ENDIF
        ENDIF
    ENDWHILE
    IF posisi = -1 THEN
        OUTPUT cari, " tidak ditemukan"
    ELSE
        OUTPUT cari, " ada di indeks ", posisi
    ENDIF
END

Soal latihan

  1. Hitung berapa kali angka 7 muncul di array [7, 3, 7, 1, 7, 9].

    Petunjuk

    Jangan berhenti saat ketemu; teruskan sampai akhir sambil menghitung.

    Lihat jawaban
    CONTOH
    DECLARE a : ARRAY[0..5] OF INTEGER
DECLARE i, jumlah : INTEGER
a ← [7, 3, 7, 1, 7, 9]
jumlah ← 0
FOR i ← 0 TO 5 DO
    IF a[i] = 7 THEN
        jumlah ← jumlah + 1
    ENDIF
ENDFOR
OUTPUT "Muncul ", jumlah, " kali"
    KELUARAN
    Muncul 3 kali

  2. Cari posisi nama "Budi" di daftar nama dan berhenti begitu ketemu. Tampilkan -1 jika tidak ada.

    Petunjuk

    WHILE dengan dua syarat: indeks masih di dalam array AND belum ketemu.

    Lihat jawaban
    CONTOH
    DECLARE nama : ARRAY[0..3] OF STRING
DECLARE i, posisi : INTEGER
nama ← ["Andi", "Budi", "Citra", "Dewi"]
i ← 0
posisi ← -1
WHILE i <= 3 AND posisi = -1 DO
    IF nama[i] = "Budi" THEN
        posisi ← i
    ENDIF
    i ← i + 1
ENDWHILE
OUTPUT posisi
    KELUARAN
    1

Poin penting

  • Linear: bebas syarat, satu per satu.
  • Binary: data terurut, buang separuh setiap langkah.
  • -1 sebagai tanda belum ditemukan.
