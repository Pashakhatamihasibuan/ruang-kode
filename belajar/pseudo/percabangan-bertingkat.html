Percabangan bertingkat

Buka versi interaktif

Jika pilihannya lebih dari dua, misalnya nilai huruf A, B, C, D, kita menaruh IF di dalam ELSE. Ini disebut percabangan bertingkat (nested IF). Kondisi dicek dari atas ke bawah, dan begitu satu kondisi benar, sisanya tidak dicek lagi.

Urutan kondisi sangat penting. Jika kita mengecek nilai >= 55 lebih dulu, nilai 90 akan mendapat C, karena 90 juga ≥ 55. Aturannya: mulai dari kondisi paling ketat (nilai tertinggi) ke yang paling longgar.

Banyak bahasa punya CASE atau switch untuk memilih berdasarkan satu nilai tepat, misalnya kode menu 1, 2, 3. Untuk rentang nilai seperti 70 sampai 84, IF bertingkat lebih cocok.

Uji visual dengan 85, 84, 70, 55, dan 40. Kelima angka itu mencakup setiap jalur dan setiap batas.

Kasus uji nilai huruf
InputJalur yang dilewatiHasil
85nilai >= 85 benarA
84>= 85 salah, >= 70 benarB
55>= 85, >= 70 salah, >= 55 benarC
40semua salahD
PSEUDOCODE
START
    DECLARE nilai : INTEGER
    DECLARE huruf : STRING
    INPUT nilai
    IF nilai >= 85 THEN
        huruf ← "A"
    ELSE
        IF nilai >= 70 THEN
            huruf ← "B"
        ELSE
            IF nilai >= 55 THEN
                huruf ← "C"
            ELSE
                huruf ← "D"
            ENDIF
        ENDIF
    ENDIF
    OUTPUT "Nilai huruf: ", huruf
END

Poin penting

  • IF bertingkat untuk lebih dari dua pilihan.
  • Cek kondisi paling ketat lebih dulu.
  • Uji setiap jalur dan setiap batas.

Cek pemahaman

Jika urutan cek dibalik (>= 55 dulu), nilai 90 mendapat?

Jawaban: C

90 >= 55 sudah benar, jadi berhenti di C.

Berapa kasus uji minimal untuk menguji 4 jalur nilai huruf?

Jawaban: 4

Setiap jalur butuh minimal satu kasus.

Kerjakan latihannya di aplikasi

Sebelumnya: IF dan ELSE

Berikutnya: Operator logika: and, or, not
