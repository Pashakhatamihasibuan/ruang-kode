REPEAT-UNTIL: dicek di akhir

Buka versi interaktif

REPEAT ... UNTIL kondisi menjalankan badan loop dulu, baru memeriksa kondisi di akhir. Loop berhenti saat kondisinya benar. Karena dicek di akhir, badannya pasti jalan minimal sekali. Di Java, JavaScript, C, dan Flowgorithm bentuk ini disebut do-while.

Contoh sederhana, mencetak 1 sampai 5:
i ← 1
REPEAT
    OUTPUT i
    i ← i + 1
UNTIL i > 5
Perhatikan kondisinya: WHILE memakai i <= 5 (syarat lanjut), REPEAT-UNTIL memakai i > 5 (syarat berhenti).

Contoh paling tepat: validasi input. Kita harus meminta PIN dulu sebelum bisa memeriksanya. Dengan WHILE, kita terpaksa meminta PIN dua kali (sebelum loop dan di dalam loop). Do-while di Java dan JavaScript lanjut saat kondisi benar (while (pin != 2468)), REPEAT-UNTIL berhenti saat kondisi benar. Keduanya sama, hanya kondisinya dibalik.

Input di visual adalah tiga percobaan: 1111, 1234, lalu 2468. Ubah urutannya, misalnya langsung 2468, dan lihat badan loop tetap jalan sekali.

Cek kondisiDi awalDi akhir

Berhenti saatKondisi salahKondisi benar
Cocok untukMenunggu target tercapaiMenu dan validasi input
PSEUDOCODE
START
    DECLARE pin : STRING
    DECLARE coba : INTEGER
    coba ← 0
    REPEAT
        INPUT pin
        coba ← coba + 1
        IF pin <> "2468" THEN
            OUTPUT "PIN salah"
        ENDIF
    UNTIL pin = "2468"
    OUTPUT "PIN benar setelah ", coba, " kali"
END

Soal latihan

  1. Minta pengguna memasukkan nilai 0–100. Ulangi permintaan selama nilainya di luar rentang.

    Petunjuk

    REPEAT INPUT ... UNTIL nilai >= 0 AND nilai <= 100.

    Lihat jawaban
    CONTOH
    DECLARE nilai : INTEGER
REPEAT
    OUTPUT "Masukkan nilai (0-100): "
    INPUT nilai
UNTIL nilai >= 0 AND nilai <= 100
OUTPUT "Nilai diterima: ", nilai

  2. Jumlahkan angka yang dimasukkan sampai pengguna mengetik 0, lalu tampilkan totalnya.

    Petunjuk

    Angka 0 ikut dijumlahkan tidak masalah karena tidak mengubah total.

    Lihat jawaban
    CONTOH
    DECLARE x, total : INTEGER
total ← 0
REPEAT
    INPUT x
    total ← total + x
UNTIL x = 0
OUTPUT "Total: ", total
    KELUARAN
    Masukan 5, 8, 2, 0 → Total: 15

Poin penting

  • REPEAT-UNTIL jalan minimal sekali.
  • Berhenti saat kondisi UNTIL benar.
  • Do-while = REPEAT-UNTIL dengan kondisi dibalik.

Cek pemahaman

Loop yang paling cocok untuk menampilkan menu sampai pengguna memilih Keluar?

Jawaban: REPEAT-UNTIL

Menu harus tampil minimal sekali.

REPEAT ... UNTIL x > 10 berhenti saat?

Jawaban: x > 10 benar

UNTIL berhenti saat kondisinya benar.

Kerjakan latihannya di aplikasi

Sebelumnya: WHILE: perulangan bersyarat

Berikutnya: FOR, WHILE, dan DO-WHILE: contoh sederhana dan bedanya
