Bubble sort dalam pseudocode

Buka versi interaktif

Bubble sort mengurutkan dengan membandingkan pasangan bersebelahan dan menukarnya jika salah urutan. Setelah putaran pertama, angka terbesar sudah di ujung kanan.

Menukar dua nilai butuh variabel bantu t: t ← a[j], a[j] ← a[j + 1], a[j + 1] ← t. Tanpa t, nilai a[j] hilang tertimpa. Bayangkan menukar isi dua gelas: kamu butuh gelas ketiga.

Versi ini memakai dua FOR: luar i dari 0 sampai 3 (n - 2 untuk 5 data), dalam j dari 0 sampai 3 - i. Batas dalam mengecil karena bagian kanan sudah terurut.

Jalankan visual dan perhatikan isi array di kolom variabel berubah setiap kali terjadi pertukaran.

PSEUDOCODE
START
    DECLARE a : ARRAY[5] OF INTEGER
    a ← [29, 10, 14, 37, 13]
    DECLARE i, j, t : INTEGER
    FOR i ← 0 TO 3 DO
        FOR j ← 0 TO 3 - i DO
            IF a[j] > a[j + 1] THEN
                t ← a[j]
                a[j] ← a[j + 1]
                a[j + 1] ← t
            ENDIF
        ENDFOR
    ENDFOR
    OUTPUT "Terurut: ", a
END

Soal latihan

  1. Ubah bubble sort agar mengurutkan dari terbesar ke terkecil.

    Petunjuk

    Cukup balik tanda perbandingan: tukar jika a[j] < a[j + 1].

    Lihat jawaban
    CONTOH
    FOR i ← 0 TO n - 2 DO
    FOR j ← 0 TO n - 2 - i DO
        IF a[j] < a[j + 1] THEN
            t ← a[j]
            a[j] ← a[j + 1]
            a[j + 1] ← t
        ENDIF
    ENDFOR
ENDFOR

  2. Tuliskan isi array [5, 1, 4, 2] setelah putaran luar pertama bubble sort menaik.

    Petunjuk

    Bandingkan pasangan bersebelahan dari kiri: (5,1) tukar, (5,4) tukar, (5,2) tukar.

    Lihat jawaban
    CONTOH
    Awal      : [5, 1, 4, 2]
j = 0     : [1, 5, 4, 2]
j = 1     : [1, 4, 5, 2]
j = 2     : [1, 4, 2, 5]
Setelah putaran 1, angka terbesar (5) sudah di ujung.

Poin penting

  • Bandingkan dan tukar pasangan bersebelahan.
  • Menukar butuh variabel bantu.
  • Batas loop dalam mengecil setiap putaran.

Cek pemahaman

Kenapa menukar nilai butuh variabel t?

Jawaban: Agar nilai lama tidak hilang tertimpa

Seperti menukar isi dua gelas.

Setelah putaran pertama, apa yang pasti?

Jawaban: Nilai terbesar di ujung kanan

Nilai terbesar terbawa ke kanan.
