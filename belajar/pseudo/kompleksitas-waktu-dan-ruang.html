Kompleksitas waktu dan ruang

Buka versi interaktif

Kompleksitas waktu mengukur bagaimana jumlah langkah bertambah saat data bertambah. Kita tidak mengukur detik (karena bergantung komputer), melainkan pertumbuhannya, ditulis dengan notasi Big-O.

Yang paling sering: O(1) konstan, tidak bergantung jumlah data (mengakses a[5]). O(log n) logaritmik, membuang separuh setiap langkah (binary search). O(n) linear, satu loop (linear search, menjumlah array). O(n²) kuadratik, dua loop bersarang (bubble sort). Aturan cepat: hitung loop bersarang yang bergantung pada n.

Kompleksitas ruang mengukur memori tambahan yang dipakai. Menjumlah array cukup satu variabel total: O(1). Menyalin array ke array baru: O(n). Matriks n × n: O(n²). Rekursi juga memakai ruang untuk setiap panggilan di call stack.

Visual menghitung berapa kali badan loop bersarang dijalankan. Coba n = 4, 8, lalu 16. Saat n dua kali lipat, langkahnya menjadi empat kali lipat: itulah ciri O(n²).

PSEUDOCODE
START
    DECLARE n, i, j, langkah : INTEGER
    INPUT n
    langkah ← 0
    FOR i ← 1 TO n DO
        FOR j ← 1 TO n DO
            langkah ← langkah + 1
        ENDFOR
    ENDFOR
    OUTPUT "n = ", n, ", langkah = ", langkah
END

Soal latihan

  1. Tentukan kompleksitas waktu setiap potongan: (a) satu FOR 1 sampai n, (b) FOR i 1 sampai n berisi FOR j 1 sampai n, (c) WHILE n > 1 DO n ← n DIV 2, (d) OUTPUT a[0].

    Petunjuk

    Hitung loop yang bergantung n; membagi dua setiap langkah berarti log n.

    Lihat jawaban
    CONTOH
    (a) O(n)
(b) O(n²)
(c) O(log n)
(d) O(1)

  2. Dua loop berurutan (bukan bersarang), masing-masing 1 sampai n. Berapa kompleksitasnya, dan kenapa bukan O(n²)?

    Petunjuk

    Berurutan berarti dijumlah, bersarang berarti dikali.

    Lihat jawaban
    CONTOH
    n + n = 2n langkah → O(n).
Konstanta 2 diabaikan di Big-O.
O(n²) hanya jika loop kedua berada DI DALAM loop pertama.

Poin penting

  • Big-O mengukur pertumbuhan, bukan detik.
  • Satu loop O(n), dua loop bersarang O(n²), membuang separuh O(log n).
  • Ruang: memori tambahan, termasuk call stack.
