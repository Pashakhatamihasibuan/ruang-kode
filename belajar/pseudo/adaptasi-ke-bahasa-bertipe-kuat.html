Adaptasi ke bahasa bertipe kuat

Buka versi interaktif

Bahasa bertipe statis dan kuat seperti Java, Kotlin, Dart, C#, dan TypeScript memeriksa tipe data sebelum program dijalankan. Kabar baiknya: pseudocode kita sudah punya DECLARE x : INTEGER, jadi informasi tipenya sudah ada. Tinggal dipetakan ke tipe bahasa tujuan.

Hal yang perlu diperhatikan. Pertama, pilih tipe angka: INTEGER menjadi int (atau long untuk angka besar seperti rupiah triliunan), REAL menjadi double. Kedua, pembagian: di Java, 7 / 2 antar-int menghasilkan 3; agar 3.5, salah satunya harus double. Ketiga, INPUT harus diubah ke tipe yang tepat (sc.nextInt(), readln().toInt()).

Keempat, fungsi menulis tipe parameter dan tipe kembali secara eksplisit: FUNCTION Luas(p : INTEGER, l : INTEGER) RETURNS INTEGER menjadi static int luas(int p, int l) di Java. Kelima, perbandingan STRING di Java memakai .equals(), bukan ==.

Contoh di bawah menerjemahkan algoritma rekap nilai (pola akumulator) ke Java. Bandingkan baris demi baris dengan pseudocodenya.

JAVA
import java.util.Scanner;

public class RekapNilai {
    // FUNCTION RataRata(total : INTEGER, n : INTEGER) RETURNS REAL
    static double rataRata(int total, int n) {
        return (double) total / n;   // cegah pembagian bulat
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int total = 0, lulus = 0, maks = 0;      // DECLARE ... : INTEGER
        for (int i = 1; i <= 5; i++) {           // FOR i <- 1 TO 5
            int x = sc.nextInt();                // INPUT x
            total += x;
            if (x >= 75) lulus++;
            if (i == 1 || x > maks) maks = x;
        }
        System.out.println("Total: " + total);
        System.out.println("Rata-rata: " + rataRata(total, 5));
        System.out.println("Lulus: " + lulus + " orang");
        System.out.println("Tertinggi: " + maks);
    }
}
KELUARAN
Input: 80 65 92 75 58
Total: 370
Rata-rata: 74.0
Lulus: 3 orang
Tertinggi: 92

Soal latihan

  1. Terjemahkan fungsi pseudocode berikut ke Java:
    FUNCTION RataRata(a : INTEGER, b : INTEGER) RETURNS REAL ... RETURN (a + b) / 2
    dan pastikan RataRata(7, 8) menghasilkan 7.5.

    Petunjuk

    Tipe kembali double, dan bagi dengan 2.0 agar tidak terjadi pembagian bulat.

    Lihat jawaban
    JAVA
    public class Main {
    static double rataRata(int a, int b) {
        return (a + b) / 2.0;
    }

    public static void main(String[] args) {
        System.out.println(rataRata(7, 8));
    }
}
    KELUARAN
    7.5

  2. Petakan deklarasi pseudocode ini ke Kotlin dan Dart:
    DECLARE nama : STRING; DECLARE umur : INTEGER; DECLARE ipk : REAL; DECLARE aktif : BOOLEAN

    Petunjuk

    Kotlin: val/var nama: Tipe. Dart: Tipe nama.

    Lihat jawaban
    CONTOH
    // Kotlin
var nama: String = ""
var umur: Int = 0
var ipk: Double = 0.0
var aktif: Boolean = false

// Dart
String nama = "";
int umur = 0;
double ipk = 0.0;
bool aktif = false;

Poin penting

  • Tipe di DECLARE dipetakan ke tipe bahasa tujuan.
  • Waspadai pembagian bulat dan batas int.
  • Tulis tipe parameter dan tipe kembali fungsi.
