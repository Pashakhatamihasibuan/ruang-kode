Proyek mini: kasir sederhana

Buka versi interaktif

Saatnya menggabungkan semuanya. Kasir menerima harga dan jumlah barang berulang kali sampai kasir mengetik harga 0 (REPEAT-UNTIL), menjumlahkan total (akumulator), memberi diskon 10% jika total di atas 100 ribu (IF), lalu menghitung kembalian (IF-ELSE).

Nilai 0 sebagai tanda selesai disebut sentinel. Teknik ini umum saat jumlah data tidak diketahui sebelumnya.

Jalankan visual dengan input bawaan: 2 kopi seharga 25.000, 3 roti seharga 18.000, selesai, lalu bayar 150.000. Kemudian ubah inputnya agar total di bawah 100 ribu, atau uang bayarnya kurang.

Tantangan: tulis ulang algoritma ini di bahasa yang sedang kamu pelajari, lalu tambahkan pajak 11% setelah diskon.

PSEUDOCODE
START
    DECLARE harga, jumlah, total, bayar, kembali : INTEGER
    total ← 0
    REPEAT
        INPUT harga
        IF harga > 0 THEN
            INPUT jumlah
            total ← total + harga * jumlah
        ENDIF
    UNTIL harga = 0
    IF total > 100000 THEN
        total ← total - Int(total * 10 / 100)
        OUTPUT "Diskon 10% diberikan"
    ENDIF
    OUTPUT "Total: ", total
    INPUT bayar
    IF bayar >= total THEN
        kembali ← bayar - total
        OUTPUT "Kembalian: ", kembali
    ELSE
        OUTPUT "Uang kurang ", (total - bayar)
    ENDIF
END

Soal latihan

  1. Tambahkan pajak 11% yang dihitung dari total setelah diskon.

    Petunjuk

    pajak ← bayar * 0.11, lalu bayar ← bayar + pajak.

    Lihat jawaban
    CONTOH
    bayar ← total - diskon
pajak ← bayar * 0.11
bayar ← bayar + pajak
OUTPUT "Pajak: ", pajak
OUTPUT "Bayar: ", bayar

  2. Hitung kembalian. Jika uang pembeli kurang, minta masukan lagi.

    Petunjuk

    REPEAT INPUT uang UNTIL uang >= bayar, lalu kembali ← uang - bayar.

    Lihat jawaban
    CONTOH
    REPEAT
    OUTPUT "Uang pembeli: "
    INPUT uang
    IF uang < bayar THEN
        OUTPUT "Uang kurang ", bayar - uang
    ENDIF
UNTIL uang >= bayar
OUTPUT "Kembalian: ", uang - bayar

Poin penting

  • Sentinel (misalnya 0) menandai akhir input.
  • Gabungkan loop, akumulator, dan percabangan.
  • Uji juga kasus uang kurang.

Cek pemahaman

Kenapa loop kasir memakai REPEAT-UNTIL?

Jawaban: Harga harus diminta minimal sekali

Kita belum tahu jumlah barang, tetapi minimal sekali harus bertanya.

Apa itu nilai sentinel?

Jawaban: Nilai khusus penanda akhir input

Contoh: harga 0 berarti selesai.
