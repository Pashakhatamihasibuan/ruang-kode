Input dan output dasar

Buka versi interaktif

Hampir semua program mengikuti pola IPO: Input (terima data), Proses (olah data), Output (tampilkan hasil). INPUT nama berarti program berhenti sejenak, menunggu pengguna mengetik, lalu menyimpan ketikan itu ke variabel nama.

OUTPUT menampilkan teks atau isi variabel. Teks ditulis di antara tanda kutip, variabel tanpa kutip: OUTPUT "Halo ", nama. Perbedaan ini penting: OUTPUT "nama" menampilkan tulisan nama, sedangkan OUTPUT nama menampilkan isinya, misalnya Rina.

Program yang ramah selalu menampilkan prompt (pertanyaan) sebelum INPUT, agar pengguna tahu apa yang harus diketik. Di Flowgorithm dan di visual ini, teks dan variabel digabung dengan tanda &.

Jalankan visual. Ganti input nama dan umur, lalu lihat outputnya berubah tanpa mengubah satu baris pun algoritmanya.

PSEUDOCODE
START
    DECLARE nama : STRING
    DECLARE umur : INTEGER
    OUTPUT "Siapa namamu?"
    INPUT nama
    OUTPUT "Berapa umurmu?"
    INPUT umur
    OUTPUT "Halo ", nama, ", tahun depan umurmu ", (umur + 1)
END

Soal latihan

  1. Tulis pseudocode yang menanyakan nama kota asal, lalu menampilkan "Salam dari <kota>!".

    Petunjuk

    Tampilkan prompt dulu, INPUT ke variabel STRING, lalu OUTPUT gabungan teks dan variabel.

    Lihat jawaban
    CONTOH
    DECLARE kota : STRING
OUTPUT "Dari kota mana kamu?"
INPUT kota
OUTPUT "Salam dari ", kota, "!"
    KELUARAN
    Masukan Medan → Salam dari Medan!

  2. Tulis pseudocode yang menerima panjang sisi persegi, lalu menampilkan luas dan kelilingnya di dua baris.

    Petunjuk

    Luas = sisi × sisi, keliling = 4 × sisi. Satu OUTPUT per baris.

    Lihat jawaban
    CONTOH
    DECLARE sisi : INTEGER
OUTPUT "Panjang sisi: "
INPUT sisi
OUTPUT "Luas: ", sisi * sisi
OUTPUT "Keliling: ", 4 * sisi
    KELUARAN
    Masukan 6 → Luas: 36, Keliling: 24

  3. nama berisi "Andi". Tuliskan hasil dari OUTPUT "nama" dan OUTPUT nama.

    Petunjuk

    Teks di dalam kutip ditampilkan apa adanya.

    Lihat jawaban
    CONTOH
    OUTPUT "nama" → nama
OUTPUT nama   → Andi

Poin penting

  • Pola IPO: Input, Proses, Output.
  • Teks pakai kutip, variabel tanpa kutip.
  • Tampilkan prompt sebelum INPUT.
