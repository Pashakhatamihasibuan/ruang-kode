WHILE: ulangi selama kondisi benar

Buka versi interaktif

WHILE kondisi DO ... ENDWHILE memeriksa kondisi sebelum setiap putaran. Selama kondisinya benar, badan loop dijalankan. Pakai WHILE jika jumlah putaran belum diketahui, yang diketahui hanya kapan harus berhenti.

Badan loop harus mengubah sesuatu yang membuat kondisi akhirnya salah. Jika tidak, terjadi loop tak berhingga (infinite loop): program berputar selamanya. Pada contoh, saldo terus bertambah sehingga suatu saat ≥ 100000.

Jika kondisinya sudah salah sejak awal, badan WHILE tidak dijalankan sama sekali. Ini beda penting dengan REPEAT-UNTIL di pelajaran berikutnya.

Simulator di bawah akan berhenti dan memberi peringatan jika sebuah loop berputar lebih dari 1.500 langkah.

PSEUDOCODE
START
    DECLARE saldo, minggu : INTEGER
    saldo ← 0
    minggu ← 0
    WHILE saldo < 100000 DO
        saldo ← saldo + 30000
        minggu ← minggu + 1
    ENDWHILE
    OUTPUT "Tercapai di minggu ke-", minggu, ", saldo ", saldo
END

Poin penting

  • WHILE untuk jumlah putaran yang belum diketahui.
  • Kondisi dicek sebelum setiap putaran.
  • Badan loop harus menggerakkan kondisi ke arah berhenti.

Cek pemahaman

WHILE x < 0 dengan x = 5 di awal. Berapa kali badan loop jalan?

Jawaban: 0

Kondisi salah sejak awal.

Penyebab infinite loop?

Jawaban: Kondisi tidak pernah menjadi salah

Badan loop tidak mengubah kondisi.

Kerjakan latihannya di aplikasi

Sebelumnya: FOR: jumlah putaran sudah diketahui

Berikutnya: REPEAT-UNTIL: jalan minimal sekali
