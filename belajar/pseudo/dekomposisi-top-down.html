Dekomposisi top-down

Buka versi interaktif

Dekomposisi top-down adalah memecah masalah besar menjadi sub-masalah yang lebih kecil, lalu memecahnya lagi sampai setiap bagian cukup sederhana untuk ditulis langsung. Mulai dari gambaran besar ("buat kasir"), turun ke langkah utama ("baca belanjaan, hitung diskon, hitung kembalian"), lalu ke detail.

Setiap sub-masalah menjadi satu modul (prosedur atau fungsi) dengan satu tugas jelas. Program utama cukup memanggil modul-modul itu, sehingga terbaca seperti daftar isi. Modul bisa dikerjakan, diuji, dan diperbaiki terpisah, bahkan oleh orang yang berbeda.

Visual menjalankan kasir dalam satu blok panjang. Bagian contoh menunjukkan kasir yang sama setelah didekomposisi: program utama hanya empat baris, dan detailnya ada di fungsi masing-masing. Logikanya identik, tetapi jauh lebih mudah dibaca dan diubah.

Jalankan visual dengan input bawaan: 2 kopi seharga 25.000, 3 roti seharga 18.000, selesai (0), lalu bayar 150.000.

Pohon dekomposisi kasir
TingkatModulTugas
0KasirSeluruh transaksi
1BacaBelanjaanUlangi baca harga dan jumlah sampai 0
1TerapkanDiskonPotong 10% jika total > 100 ribu
1ProsesPembayaranTerima uang, hitung kembalian atau kekurangan
CONTOH
// Program utama: terbaca seperti daftar isi
START
    total ← BacaBelanjaan()
    total ← TerapkanDiskon(total)
    OUTPUT "Total: ", total
    CALL ProsesPembayaran(total)
END

FUNCTION BacaBelanjaan() RETURNS INTEGER
    DECLARE harga, jumlah, total : INTEGER
    total ← 0
    REPEAT
        INPUT harga
        IF harga > 0 THEN
            INPUT jumlah
            total ← total + harga * jumlah
        ENDIF
    UNTIL harga = 0
    RETURN total
ENDFUNCTION

FUNCTION TerapkanDiskon(total : INTEGER) RETURNS INTEGER
    IF total > 100000 THEN
        RETURN total - total * 10 DIV 100
    ENDIF
    RETURN total
ENDFUNCTION

PROCEDURE ProsesPembayaran(total : INTEGER)
    DECLARE bayar : INTEGER
    INPUT bayar
    IF bayar >= total THEN
        OUTPUT "Kembalian: ", bayar - total
    ELSE
        OUTPUT "Uang kurang ", total - bayar
    ENDIF
ENDPROCEDURE

Diskon 10% diberikan
Total: 94500

PSEUDOCODE
START
    DECLARE harga, jumlah, total, bayar, kembali : INTEGER
    total ← 0
    REPEAT
        INPUT harga
        IF harga > 0 THEN
            INPUT jumlah
            total ← total + harga * jumlah
        ENDIF
    UNTIL harga = 0
    IF total > 100000 THEN
        total ← total - Int(total * 10 / 100)
        OUTPUT "Diskon 10% diberikan"
    ENDIF
    OUTPUT "Total: ", total
    INPUT bayar
    IF bayar >= total THEN
        kembali ← bayar - total
        OUTPUT "Kembalian: ", kembali
    ELSE
        OUTPUT "Uang kurang ", (total - bayar)
    ENDIF
END

Soal latihan

  1. Tambahkan pajak 11% yang dihitung dari total setelah diskon.

    Petunjuk

    pajak ← bayar * 0.11, lalu bayar ← bayar + pajak.

    Lihat jawaban
    CONTOH
    bayar ← total - diskon
pajak ← bayar * 0.11
bayar ← bayar + pajak
OUTPUT "Pajak: ", pajak
OUTPUT "Bayar: ", bayar

  2. Hitung kembalian. Jika uang pembeli kurang, minta masukan lagi.

    Petunjuk

    REPEAT INPUT uang UNTIL uang >= bayar, lalu kembali ← uang - bayar.

    Lihat jawaban
    CONTOH
    REPEAT
    OUTPUT "Uang pembeli: "
    INPUT uang
    IF uang < bayar THEN
        OUTPUT "Uang kurang ", bayar - uang
    ENDIF
UNTIL uang >= bayar
OUTPUT "Kembalian: ", uang - bayar

Poin penting

  • Pecah masalah besar menjadi sub-masalah kecil.
  • Satu modul, satu tugas.
  • Program utama terbaca seperti daftar isi.
