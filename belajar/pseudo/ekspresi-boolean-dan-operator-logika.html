Ekspresi Boolean dan operator logika

Buka versi interaktif

Setiap percabangan bergantung pada ekspresi Boolean: ekspresi yang hasilnya hanya benar atau salah. Contoh: nilai >= 75, stok = 0, password <> "". Hasilnya bisa langsung dipakai di IF atau disimpan dulu di variabel BOOLEAN.

Kondisi nyata sering gabungan. "Boleh ikut ujian jika hadir minimal 75% dan sudah bayar". "Gratis ongkir jika belanja di atas 100 ribu atau member premium". Operator and butuh semua bagian benar; or cukup salah satu.

Contoh klasik: tahun kabisat. Aturannya: habis dibagi 4 tetapi tidak habis dibagi 100, atau habis dibagi 400. Jadi 2024 kabisat, 1900 bukan, 2000 kabisat. Satu kondisi gabungan menggantikan tiga IF bertingkat.

Saat mencampur and dan or, pakai kurung. Tanpa kurung, pembaca dan komputer bisa menafsirkan urutan yang berbeda.

Pada visual, hasil kondisi gabungan disimpan dulu di variabel Boolean kabisat, lalu IF cukup mengecek variabel itu. Memberi nama pada kondisi panjang membuat algoritma lebih mudah dibaca. Uji dengan 2024, 1900, 2000, dan 2023.

PSEUDOCODE
START
    DECLARE tahun : INTEGER
    DECLARE kabisat : BOOLEAN
    INPUT tahun
    kabisat ← (tahun mod 4 = 0 and tahun mod 100 <> 0) or tahun mod 400 = 0
    IF kabisat THEN
        OUTPUT tahun, " adalah tahun kabisat"
    ELSE
        OUTPUT tahun, " bukan tahun kabisat"
    ENDIF
END

Soal latihan

  1. Tentukan tahun kabisat: habis dibagi 4 dan tidak habis dibagi 100, atau habis dibagi 400.

    Petunjuk

    (t MOD 4 = 0 AND t MOD 100 <> 0) OR t MOD 400 = 0.

    Lihat jawaban
    CONTOH
    DECLARE t : INTEGER
INPUT t
IF (t MOD 4 = 0 AND t MOD 100 <> 0) OR t MOD 400 = 0 THEN
    OUTPUT t, " kabisat"
ELSE
    OUTPUT t, " bukan kabisat"
ENDIF
    KELUARAN
    2024 kabisat · 1900 bukan kabisat · 2000 kabisat

  2. Mahasiswa boleh ikut ujian jika kehadiran ≥ 75% dan tidak punya tunggakan. Tulis kondisinya.

    Petunjuk

    Gabungkan dengan AND dan NOT.

    Lihat jawaban
    CONTOH
    DECLARE hadir : INTEGER
DECLARE tunggakan : BOOLEAN
INPUT hadir
INPUT tunggakan
IF hadir >= 75 AND NOT tunggakan THEN
    OUTPUT "Boleh ikut ujian"
ELSE
    OUTPUT "Tidak boleh ikut ujian"
ENDIF

Poin penting

  • and: semua benar. or: salah satu benar. not: kebalikan.
  • Pakai kurung saat mencampur and dan or.
