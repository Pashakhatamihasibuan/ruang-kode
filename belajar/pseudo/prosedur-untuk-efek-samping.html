Prosedur untuk efek samping

Buka versi interaktif

Prosedur adalah modul yang tidak mengembalikan nilai. Ia dipanggil karena efek samping-nya: menampilkan sesuatu ke layar, mencetak struk, menyimpan data, atau mengubah isi variabel yang dikirim kepadanya. Dipanggil dengan CALL NamaProsedur(argumen).

Bedanya dengan fungsi: fungsi menjawab pertanyaan ("berapa luasnya?"), prosedur melakukan pekerjaan ("cetak garis sepanjang 20"). Karena tidak ada nilai kembali, prosedur tidak bisa dipakai di dalam ekspresi: x ← CetakGaris(3) salah.

Pisahkan perhitungan dari tampilan. Hitung dengan fungsi, tampilkan dengan prosedur. Contoh: total ← HitungTotal(...) lalu CALL CetakStruk(total). Dengan begitu, fungsi perhitungan bisa dipakai ulang di aplikasi web, mobile, maupun konsol.

Prosedur vs fungsi
AspekProsedurFungsi
Mengembalikan nilaiTidakYa, dengan RETURN
Cara memanggilCALL CetakGaris(3)x ← Luas(8, 5)
ContohMencetak strukMenghitung pajak
CONTOH
PROCEDURE CetakGaris(n : INTEGER)
    DECLARE i : INTEGER
    DECLARE s : STRING
    s ← ""
    FOR i ← 1 TO n DO
        s ← s & "-"
    ENDFOR
    OUTPUT s
ENDPROCEDURE

PROCEDURE CetakStruk(nama : STRING, total : INTEGER)
    CALL CetakGaris(20)
    OUTPUT "Pelanggan: ", nama
    OUTPUT "Total    : Rp", total
    CALL CetakGaris(20)
ENDPROCEDURE

START
    CALL CetakStruk("Rina", 66600)
END
KELUARAN
--------------------
Pelanggan: Rina
Total    : Rp66600
--------------------

Soal latihan

  1. Tulis prosedur CetakKotak(n) yang mencetak persegi bintang n × n.

    Petunjuk

    Loop bersarang di dalam prosedur, setiap baris dibangun sebagai teks.

    Lihat jawaban
    CONTOH
    PROCEDURE CetakKotak(n : INTEGER)
    DECLARE i, j : INTEGER
    DECLARE baris : STRING
    FOR i ← 1 TO n DO
        baris ← ""
        FOR j ← 1 TO n DO
            baris ← baris & "*"
        ENDFOR
        OUTPUT baris
    ENDFOR
ENDPROCEDURE

CALL CetakKotak(3)
    KELUARAN
    ***
***
***

  2. Pisahkan perhitungan dan tampilan: buat fungsi HitungTotal(harga, jumlah) dan prosedur CetakNota(barang, total).

    Petunjuk

    Fungsi mengembalikan angka, prosedur hanya menampilkan.

    Lihat jawaban
    CONTOH
    FUNCTION HitungTotal(harga : INTEGER, jumlah : INTEGER) RETURNS INTEGER
    RETURN harga * jumlah
ENDFUNCTION

PROCEDURE CetakNota(barang : STRING, total : INTEGER)
    OUTPUT "Barang: ", barang
    OUTPUT "Total : Rp", total
ENDPROCEDURE

CALL CetakNota("Pulpen", HitungTotal(3500, 4))
    KELUARAN
    Barang: Pulpen
Total : Rp14000

Poin penting

  • Prosedur dipanggil karena efek sampingnya.
  • Prosedur tidak bisa dipakai di dalam ekspresi.
  • Hitung dengan fungsi, tampilkan dengan prosedur.
