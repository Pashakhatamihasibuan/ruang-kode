Struktur record

Buka versi interaktif

Array menyimpan banyak data sejenis. Record (struct) menyimpan beberapa data berbeda jenis yang menjadi satu kesatuan. Contoh: satu mahasiswa punya NIM (STRING), nama (STRING), IPK (REAL), dan status aktif (BOOLEAN).

Record didefinisikan sebagai tipe baru: TYPE Mahasiswa ... ENDTYPE. Setiap bagian disebut field, diakses dengan titik: mhs.nama, mhs.ipk.

Kekuatan sebenarnya muncul saat record digabung dengan array: ARRAY[0..29] OF Mahasiswa menyimpan data satu kelas. Tanpa record, kita butuh empat array terpisah (nim[], nama[], ipk[], aktif[]) yang harus dijaga agar indeksnya selalu sejajar, dan itu rawan salah.

Record adalah cikal bakal class di Java dan Kotlin, data class di Kotlin, dataclass di Python, interface atau object di TypeScript, dan baris tabel di SQL.

Record di beberapa bahasa
BahasaBentuk
PseudocodeTYPE Mahasiswa ... ENDTYPE
Python@dataclass class Mahasiswa
Javarecord Mahasiswa(String nim, ...)
Kotlindata class Mahasiswa(val nim: String, ...)
TypeScripttype Mahasiswa = { nim: string; ... }
SQLSatu baris di tabel mahasiswa
CONTOH
TYPE Mahasiswa
    nim   : STRING
    nama  : STRING
    ipk   : REAL
    aktif : BOOLEAN
ENDTYPE

DECLARE kelas : ARRAY[0..2] OF Mahasiswa
DECLARE i : INTEGER
DECLARE terbaik : Mahasiswa

kelas[0] ← Mahasiswa("2301", "Rina", 3.62, TRUE)
kelas[1] ← Mahasiswa("2302", "Budi", 3.15, TRUE)
kelas[2] ← Mahasiswa("2303", "Sari", 3.88, FALSE)

terbaik ← kelas[0]
FOR i ← 1 TO 2 DO
    IF kelas[i].ipk > terbaik.ipk THEN
        terbaik ← kelas[i]
    ENDIF
ENDFOR
OUTPUT "IPK tertinggi: ", terbaik.nama, " (", terbaik.ipk, ")"
KELUARAN
IPK tertinggi: Sari (3.88)

Soal latihan

  1. Definisikan record Buku (judul, penulis, tahun, stok) lalu tampilkan judul semua buku yang stoknya 0 dari array 4 buku.

    Petunjuk

    TYPE ... ENDTYPE, lalu traversal array of record dengan pengecekan field stok.

    Lihat jawaban
    CONTOH
    TYPE Buku
    judul   : STRING
    penulis : STRING
    tahun   : INTEGER
    stok    : INTEGER
ENDTYPE

DECLARE rak : ARRAY[0..3] OF Buku
FOR i ← 0 TO 3 DO
    IF rak[i].stok = 0 THEN
        OUTPUT rak[i].judul
    ENDIF
ENDFOR

  2. Buat versi Python dengan dataclass Mahasiswa dan cari IPK tertinggi.

    Petunjuk

    from dataclasses import dataclass; pakai max(..., key=...).

    Lihat jawaban
    PYTHON
    from dataclasses import dataclass

@dataclass
class Mahasiswa:
    nim: str
    nama: str
    ipk: float

kelas = [Mahasiswa("2301", "Rina", 3.62), Mahasiswa("2302", "Budi", 3.15), Mahasiswa("2303", "Sari", 3.88)]
terbaik = max(kelas, key=lambda m: m.ipk)
print(terbaik.nama, terbaik.ipk)
    KELUARAN
    Sari 3.88

Poin penting

  • Record = beberapa field berbeda jenis dalam satu kesatuan.
  • Akses field dengan titik: mhs.nama.
  • Array of record lebih aman daripada beberapa array sejajar.
