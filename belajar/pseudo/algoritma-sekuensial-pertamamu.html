Algoritma sekuensial pertamamu

Buka versi interaktif

Algoritma sekuensial (runtunan) adalah algoritma yang langkahnya dijalankan berurutan dari atas ke bawah, tepat sekali, tanpa percabangan dan tanpa perulangan. Ini bentuk paling dasar, dan setiap algoritma yang lebih rumit tersusun dari runtunan kecil seperti ini.

Cara menyusunnya: (1) tulis masalahnya dalam satu kalimat, (2) tentukan input dan output, (3) tulis rumus prosesnya, (4) deklarasikan variabel, (5) susun langkahnya, dan (6) uji dengan data yang hasilnya sudah kamu hitung manual.

Urutan langkah menentukan hasil. Jika total ← subtotal + pajak ditulis sebelum pajak dihitung, total akan salah karena pajak belum punya nilai. Itulah inti algoritma sekuensial: setiap langkah hanya boleh memakai nilai yang sudah dihitung di atasnya.

Contoh: struk belanja dengan PPN 11%. Masalah: hitung total bayar. Input: harga dan jumlah. Output: subtotal, PPN, dan total. Hitung manual dulu: 15.000 × 4 = 60.000, PPN 6.600, total 66.600. Lalu jalankan visual dan cocokkan.

Lembar perencanaan algoritma
LangkahIsi untuk struk belanja
MasalahHitung total bayar termasuk PPN 11%
Inputharga (INTEGER), jumlah (INTEGER)
Outputsubtotal, pajak, total
Rumussubtotal = harga × jumlah; pajak = subtotal × 11 / 100; total = subtotal + pajak
Uji manual15000 dan 4 → 60000, 6600, 66600
PSEUDOCODE
START
    DECLARE harga, jumlah, subtotal : INTEGER
    DECLARE pajak, total : REAL
    INPUT harga
    INPUT jumlah
    subtotal ← harga * jumlah
    pajak ← subtotal * 11 / 100
    total ← subtotal + pajak
    OUTPUT "Subtotal: ", subtotal
    OUTPUT "PPN 11%: ", pajak
    OUTPUT "Total: ", total
END

Soal latihan

  1. Buat lembar perencanaan dan pseudocode untuk menghitung luas dan keliling lingkaran dari jari-jari.

    Petunjuk

    Input r (REAL). Luas = 3.14 × r × r, keliling = 2 × 3.14 × r. Uji manual dengan r = 10.

    Lihat jawaban
    CONTOH
    Masalah : luas dan keliling lingkaran
Input   : r (REAL)
Output  : luas, keliling

DECLARE r, luas, keliling : REAL
INPUT r
luas ← 3.14 * r * r
keliling ← 2 * 3.14 * r
OUTPUT "Luas: ", luas
OUTPUT "Keliling: ", keliling
    KELUARAN
    r = 10 → Luas: 314, Keliling: 62.8

  2. Tulis algoritma menghitung gaji bersih: gaji pokok ditambah tunjangan 500.000, lalu dipotong BPJS 4% dari gaji pokok.

    Petunjuk

    Hitung potongan dulu, baru gaji bersih. Uji: gaji pokok 5.000.000.

    Lihat jawaban
    CONTOH
    DECLARE pokok, potongan, bersih : REAL
INPUT pokok
potongan ← pokok * 4 / 100
bersih ← pokok + 500000 - potongan
OUTPUT "Gaji bersih: ", bersih
    KELUARAN
    pokok 5000000 → Gaji bersih: 5300000

Poin penting

  • Runtunan: langkah berurutan, masing-masing sekali.
  • Rencanakan masalah, input, output, rumus, lalu uji.
  • Langkah hanya boleh memakai nilai yang sudah dihitung.
