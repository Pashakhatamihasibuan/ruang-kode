IF dan ELSE

Buka versi interaktif

Program sering harus memilih: lulus atau remedial, stok cukup atau habis, password benar atau salah. Pilihan ini ditulis dengan IF kondisi THEN ... ELSE ... ENDIF. Kondisi adalah ekspresi yang hasilnya benar atau salah.

Jika kondisi benar, langkah di bawah THEN dijalankan. Jika salah, langkah di bawah ELSE yang dijalankan. Hanya satu jalur yang dipilih, tidak pernah keduanya. Bagian ELSE boleh tidak ada jika tidak ada yang perlu dilakukan saat kondisi salah.

Di flowchart, percabangan digambar sebagai belah ketupat dengan dua jalur keluar: Benar dan Salah. Kedua jalur bertemu lagi di satu titik sebelum program berlanjut.

Coba jalankan visual dengan nilai 68, lalu ganti menjadi 75. Perhatikan jalur mana yang dilewati. Nilai 75 adalah kasus batas: selalu uji nilai tepat di batas kondisi, karena di situlah kesalahan > versus >= sering terjadi.

PSEUDOCODE
START
    DECLARE nilai : INTEGER
    INPUT nilai
    IF nilai >= 75 THEN
        OUTPUT "Lulus"
    ELSE
        OUTPUT "Belum lulus, ikut remedial"
    ENDIF
END

Soal latihan

  1. Tentukan apakah sebuah bilangan positif, negatif, atau nol.

    Petunjuk

    Pakai IF, ELSE IF, ELSE.

    Lihat jawaban
    CONTOH
    DECLARE n : INTEGER
INPUT n
IF n > 0 THEN
    OUTPUT "Positif"
ELSE IF n < 0 THEN
    OUTPUT "Negatif"
ELSE
    OUTPUT "Nol"
ENDIF

  2. Ongkir gratis jika belanja minimal 100000, selain itu ongkir 15000. Tampilkan total bayar.

    Petunjuk

    Hitung ongkir dengan IF, lalu total ← belanja + ongkir.

    Lihat jawaban
    CONTOH
    DECLARE belanja, ongkir : INTEGER
INPUT belanja
IF belanja >= 100000 THEN
    ongkir ← 0
ELSE
    ongkir ← 15000
ENDIF
OUTPUT "Total: ", belanja + ongkir

Poin penting

  • IF memilih satu dari dua jalur.
  • ELSE opsional.
  • Selalu uji nilai tepat di batas kondisi.

Cek pemahaman

Jika kondisinya nilai > 75 dan nilai = 75, hasilnya?

Jawaban: Masuk jalur Salah

75 > 75 salah. Jika 75 harus lulus, pakai >=.

Simbol flowchart untuk percabangan?

Jawaban: Belah ketupat

Belah ketupat punya dua jalur keluar.

Kerjakan latihannya di aplikasi

Sebelumnya: Variabel, tipe data, dan operator

Berikutnya: Percabangan bertingkat
