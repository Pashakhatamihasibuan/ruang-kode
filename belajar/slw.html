Slicing Website: Dari desain Figma ke HTML dan CSS yang presisi

Membaca file desain dan redline, memecah layout jadi komponen, slicing navbar, hero, kartu, form, dan footer, responsif mobile-first, pixel-perfect, aset dan ikon, serah terima proyek, dan studi kasus slicing landing page step by step dari papan desain.

6 modul · 28 pelajaran

Mulai belajar di aplikasi

Modul 1: Persiapan slicing

Pemula

Apa itu slicing, membaca desain di Figma Dev Mode, memindahkan token desain ke CSS variables, dan menyusun HTML semantik dari desain.

  1. Apa itu slicing dan alurnya
  2. Membaca desain di Figma Dev Mode
  3. Token desain ke CSS variables
  4. HTML semantik dari desain

Modul 2: Slicing komponen

Pemula

Navbar responsif, hero section, tombol dan kartu dari komponen Figma, serta ikon dan gambar yang dioptimalkan.

  1. Navbar responsif
  2. Hero section
  3. Tombol dan kartu dari komponen Figma
  4. Ikon dan gambar yang dioptimalkan

Modul 3: Slicing section halaman

Menengah

Section fitur dengan grid, testimoni dengan scroll-snap, tabel harga dengan paket unggulan, serta footer dan form newsletter.

  1. Section fitur dengan grid
  2. Testimoni dengan scroll-snap
  3. Tabel harga dengan paket unggulan
  4. Footer dan form newsletter

Modul 4: Responsif dan pixel-perfect

Menengah

Mobile-first dengan breakpoint dari desain, gambar responsif dengan srcset, membandingkan hasil dengan desain, dan aksesibilitas hasil slicing.

  1. Mobile-first dan breakpoint dari desain
  2. Gambar responsif dengan srcset
  3. Pixel-perfect: membandingkan dengan desain
  4. Aksesibilitas hasil slicing

Modul 5: Proyek dan serah terima

Menengah

Proyek landing page lengkap, deploy hasil slicing, dan daftar periksa QA sebelum diserahkan ke klien.

  1. Proyek: landing page kedai kopi
  2. Deploy hasil slicing
  3. Daftar periksa QA sebelum serah terima

Menengah

Satu desain utuh, landing page roastery "Kopi Kita", di-slicing dari nol mengikuti alur kerja slicer profesional: audit desain, token, HTML semantik, layout mobile-first, komponen, breakpoint, state dan aksesibilitas, lalu QA dan serah terima.

  1. Contoh desain: papan Figma "Kopi Kita"
  2. Langkah 1: audit desain dan inventaris komponen
  3. Langkah 2: token desain menjadi CSS variables
  4. Langkah 3: kerangka HTML semantik
  5. Langkah 4: layout mobile-first untuk navbar dan hero
  6. Langkah 5: komponen kartu produk dan grid
  7. Langkah 6: breakpoint desktop
  8. Langkah 7: state, aksesibilitas, dan QA pixel-perfect
  9. Hasil akhir dan checklist serah terima
