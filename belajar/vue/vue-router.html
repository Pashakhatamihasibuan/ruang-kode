Vue Router

Buka versi interaktif

Vue Router adalah router resmi untuk aplikasi satu halaman (SPA). Daftarkan rute berisi path dan komponen, lalu tampilkan halaman aktif dengan <RouterView /> dan pindah halaman dengan <RouterLink to="/produk">.

Route dinamis memakai titik dua: /produk/:slug. Baca parameternya dengan useRoute().params.slug; navigasi lewat kode dengan useRouter().push(). Muat halaman secara malas dengan component: () => import('./views/Detail.vue') agar bundel awal kecil.

Navigation guard seperti router.beforeEach memeriksa sebelum pindah halaman, misalnya mengalihkan ke halaman masuk jika rute butuh login (meta: { butuhLogin: true }).

TYPESCRIPT
// src/router/index.ts
import { createRouter, createWebHistory } from 'vue-router'
import Beranda from '@/views/Beranda.vue'
import { useAuth } from '@/stores/auth'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', component: Beranda },
    { path: '/produk/:slug', component: () => import('@/views/DetailProduk.vue') },
    { path: '/pesanan', component: () => import('@/views/Pesanan.vue'), meta: { butuhLogin: true } },
    { path: '/:pathMatch(.*)*', component: () => import('@/views/TidakDitemukan.vue') },
  ],
})

router.beforeEach((to) => {
  const auth = useAuth()
  if (to.meta.butuhLogin && !auth.masuk) {
    return { path: '/masuk', query: { kembali: to.fullPath } }
  }
})

export default router

Poin penting

  • RouterView dan RouterLink.
  • :slug untuk rute dinamis, useRoute untuk membacanya.
  • beforeEach untuk melindungi rute.
