Vue.js · Modul 3 · Konsep & kode

Mengambil data dari API dan menangani status

Buka versi interaktif

Setiap tampilan yang memuat data punya tiga keadaan: memuat, error, dan berhasil (termasuk data kosong). Tampilkan ketiganya agar pengguna tidak melihat layar kosong tanpa penjelasan.

Pustaka seperti TanStack Query (Vue Query) atau Pinia Colada menangani cache, pengambilan ulang saat jendela fokus, dan retry otomatis. Untuk aplikasi kecil, composable useFetch sendiri sudah cukup.

Saat parameter rute berubah (pindah dari produk A ke B di halaman yang sama), komponen tidak dibuat ulang. Pakai watch pada route.params.slug untuk memuat data baru.

HTML
<script setup lang="ts">
import { ref, watch } from 'vue'
import { useRoute } from 'vue-router'
const route = useRoute()
const produk = ref(null), memuat = ref(false), error = ref('')

watch(() => route.params.slug, async (slug) => {
  memuat.value = true; error.value = ''
  try {
    const r = await fetch(`/api/produk/${slug}`)
    if (r.status === 404) throw new Error('Produk tidak ditemukan')
    produk.value = await r.json()
  } catch (e) {
    error.value = (e as Error).message
  } finally {
    memuat.value = false
  }
}, { immediate: true })
</script>

<template>
  <p v-if="memuat">Memuat…</p>
  <p v-else-if="error" role="alert">{{ error }}</p>
  <article v-else-if="produk"><h1>{{ produk.nama }}</h1></article>
</template>

Poin penting

  • Tangani memuat, error, berhasil, dan kosong.
  • watch params rute dengan immediate: true.
  • TanStack Query untuk cache dan retry.
