Build dan deploy

Buka versi interaktif

npm run build menghasilkan folder dist/ berisi file statis yang sudah diperkecil dan dipecah per rute. SPA bisa dihosting di mana saja yang melayani file statis: Netlify, Vercel, Cloudflare Pages, GitHub Pages, atau Nginx.

Dengan createWebHistory, server harus mengarahkan semua rute yang tidak dikenal ke index.html (fallback SPA). Tanpa itu, membuka /produk/kopi-gayo langsung akan menghasilkan 404 dari server.

Variabel lingkungan Vite harus berawalan VITE_ agar terbaca di kode, dan semuanya terlihat oleh pengguna, jadi jangan simpan rahasia di sana.

TERMINAL
$ npm run build

# netlify.toml / _redirects (fallback SPA)
/*    /index.html   200

# nginx
location / {
  try_files $uri $uri/ /index.html;
}

Poin penting

  • npm run build menghasilkan dist/.
  • Atur fallback ke index.html untuk history mode.
  • VITE_ terlihat publik, jangan untuk rahasia.
