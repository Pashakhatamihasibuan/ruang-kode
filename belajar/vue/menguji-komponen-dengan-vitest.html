Menguji komponen dengan Vitest

Buka versi interaktif

Vitest adalah test runner secepat Vite dengan API mirip Jest. Vue Test Utils me-mount komponen di lingkungan uji, lalu kita mencari elemen, memicu event, dan memeriksa hasilnya. Untuk tes E2E, pakai Playwright atau Cypress.

Uji dari sudut pandang pengguna: apa yang tampil dan apa yang terjadi saat tombol ditekan, bukan detail internal komponen. Pustaka @testing-library/vue mendorong gaya ini.

Jalankan dengan npm run test:unit. Mode watch otomatis menjalankan ulang tes saat file disimpan.

TYPESCRIPT
// src/components/__tests__/KartuProduk.spec.ts
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import KartuProduk from '../KartuProduk.vue'

describe('KartuProduk', () => {
  it('menampilkan nama dan harga', () => {
    const w = mount(KartuProduk, { props: { nama: 'Kopi Gayo', harga: 85000, stok: 3 } })
    expect(w.text()).toContain('Kopi Gayo')
    expect(w.text()).toContain('Rp85.000')
  })

  it('memancarkan beli saat tombol ditekan', async () => {
    const w = mount(KartuProduk, { props: { nama: 'Kopi Gayo', harga: 85000, stok: 3 } })
    await w.get('button').trigger('click')
    expect(w.emitted('beli')?.[0]).toEqual(['Kopi Gayo'])
  })

  it('tombol nonaktif saat stok habis', () => {
    const w = mount(KartuProduk, { props: { nama: 'Kopi Toraja', harga: 95000, stok: 0 } })
    expect(w.get('button').attributes('disabled')).toBeDefined()
  })
})
