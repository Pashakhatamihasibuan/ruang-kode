Form dan v-model

Buka versi interaktif

v-model membuat ikatan dua arah: ketik di input, data berubah; ubah data, input ikut berubah. Bekerja untuk input teks, textarea, checkbox (boolean atau array), radio, dan select.

Modifier: v-model.trim membuang spasi di tepi, v-model.number mengubah ke angka, v-model.lazy memperbarui saat input kehilangan fokus. Event form: @submit.prevent mencegah halaman dimuat ulang.

Validasi sederhana bisa dengan computed; untuk form besar pakai pustaka seperti VeeValidate atau FormKit.

HTML
<script setup lang="ts">
import { ref, computed } from 'vue'
const nama = ref('')
const jumlah = ref(1)
const kurir = ref('reguler')
const setuju = ref(false)
const valid = computed(() => nama.value.length >= 3 && jumlah.value > 0 && setuju.value)
function kirim() {
  alert(`Pesanan ${nama.value}: ${jumlah.value} pcs via ${kurir.value}`)
}
</script>

<template>
  <form @submit.prevent="kirim">
    <label>Nama <input v-model.trim="nama" /></label>
    <label>Jumlah <input v-model.number="jumlah" type="number" min="1" /></label>
    <select v-model="kurir">
      <option value="reguler">Reguler</option>
      <option value="kilat">Kilat</option>
    </select>
    <label><input type="checkbox" v-model="setuju" /> Saya setuju</label>
    <button :disabled="!valid">Pesan</button>
  </form>
</template>

Poin penting

  • v-model = ikatan dua arah.
  • Modifier .trim, .number, .lazy.
  • @submit.prevent untuk form.
