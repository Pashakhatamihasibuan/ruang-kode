Lifecycle hooks dan composable

Buka versi interaktif

Lifecycle hooks menjalankan kode di momen tertentu: onMounted (komponen sudah tampil di DOM, tempat memuat data atau memasang pustaka grafik), onUpdated, dan onUnmounted (bersihkan timer dan event listener agar tidak bocor memori).

Composable adalah fungsi berawalan use yang membungkus logika reaktif agar bisa dipakai ulang di banyak komponen, misalnya useFetch, useLocalStorage, atau useOnline. Ini pengganti mixin dari Vue 2.

Pustaka VueUse menyediakan lebih dari 200 composable siap pakai.

TYPESCRIPT
// composables/useFetch.ts
import { ref, onMounted } from 'vue'

export function useFetch<T>(url: string) {
  const data = ref<T | null>(null)
  const error = ref<string | null>(null)
  const memuat = ref(true)
  onMounted(async () => {
    try {
      const r = await fetch(url)
      if (!r.ok) throw new Error(`HTTP ${r.status}`)
      data.value = await r.json()
    } catch (e) {
      error.value = (e as Error).message
    } finally {
      memuat.value = false
    }
  })
  return { data, error, memuat }
}

// dipakai di komponen
const { data: produk, memuat, error } = useFetch<Produk[]>('/api/produk')

Poin penting

  • onMounted untuk memuat data, onUnmounted untuk membersihkan.
  • Composable = logika reaktif yang dipakai ulang.
  • VueUse menyediakan banyak composable.
