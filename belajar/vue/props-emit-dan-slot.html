Props, emit, dan slot

Buka versi interaktif

Komponen menerima data dari induk lewat props (defineProps) dan mengirim pesan ke induk lewat event (defineEmits). Prinsipnya one-way data flow: anak tidak boleh mengubah props langsung, melainkan memancarkan event agar induk yang mengubah data.

defineModel() (Vue 3.4+) mempersingkat pola props + emit untuk v-model pada komponen sendiri.

Slot membiarkan induk mengisi bagian dalam komponen, misalnya kartu dengan isi bebas. Named slot (<slot name="aksi">) untuk beberapa area.

HTML
<!-- components/KartuProduk.vue -->
<script setup lang="ts">
const props = defineProps<{ nama: string; harga: number; stok: number }>()
const emit = defineEmits<{ beli: [nama: string] }>()
</script>

<template>
  <article class="kartu">
    <h3>{{ props.nama }}</h3>
    <p>Rp{{ props.harga.toLocaleString('id-ID') }}</p>
    <slot name="lencana" />
    <button :disabled="props.stok === 0" @click="emit('beli', props.nama)">Beli</button>
  </article>
</template>

<!-- App.vue -->
<KartuProduk nama="Kopi Gayo" :harga="85000" :stok="12" @beli="tambahKeKeranjang">
  <template #lencana><span class="lencana">Terlaris</span></template>
</KartuProduk>

Soal latihan

  1. Buat komponen Lencana.vue dengan prop warna (default "hijau") dan slot bawaan untuk teksnya.

    Petunjuk

    withDefaults(defineProps...) dan <slot />.

    Lihat jawaban
    HTML
    <script setup lang="ts">
withDefaults(defineProps<{ warna?: string }>(), { warna: 'hijau' })
</script>

<template>
  <span :class="['lencana', warna]"><slot /></span>
</template>

Poin penting

  • Props turun, event naik.
  • Anak tidak mengubah props langsung.
  • Slot dan named slot untuk isi fleksibel.
