Pinia untuk state bersama

Buka versi interaktif

Jika banyak komponen butuh data yang sama (keranjang, pengguna yang login, tema), mengoper props berlapis-lapis menjadi repot (prop drilling). Pinia adalah store resmi Vue: satu tempat untuk state, getter (nilai turunan), dan action (fungsi yang mengubah state).

Gaya "setup store" memakai ref, computed, dan fungsi biasa, sama seperti di komponen. Pinia terintegrasi dengan Vue DevTools sehingga setiap perubahan state bisa dilacak.

Saat mengambil state dari store, pakai storeToRefs() agar reaktivitas tidak hilang ketika di-destructure.

TYPESCRIPT
// src/stores/keranjang.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useKeranjang = defineStore('keranjang', () => {
  const item = ref<{ id: number; nama: string; harga: number; qty: number }[]>([])
  const total = computed(() => item.value.reduce((s, i) => s + i.harga * i.qty, 0))
  const jumlah = computed(() => item.value.reduce((s, i) => s + i.qty, 0))

  function tambah(p: { id: number; nama: string; harga: number }) {
    const ada = item.value.find((i) => i.id === p.id)
    ada ? ada.qty++ : item.value.push({ ...p, qty: 1 })
  }
  function hapus(id: number) {
    item.value = item.value.filter((i) => i.id !== id)
  }
  return { item, total, jumlah, tambah, hapus }
})

// di komponen mana pun
import { storeToRefs } from 'pinia'
const keranjang = useKeranjang()
const { jumlah, total } = storeToRefs(keranjang)
keranjang.tambah({ id: 1, nama: 'Kopi Gayo', harga: 85000 })

Soal latihan

  1. Tambahkan action kosongkan() dan getter gratisOngkir (total ≥ 150.000) ke store keranjang.

    Petunjuk

    Fungsi biasa dan computed di setup store.

    Lihat jawaban
    TYPESCRIPT
    const gratisOngkir = computed(() => total.value >= 150000)
function kosongkan() {
  item.value = []
}
return { item, total, jumlah, gratisOngkir, tambah, hapus, kosongkan }

Poin penting

  • Pinia: state, getter, action dalam satu store.
  • Hindari prop drilling untuk data global.
  • storeToRefs saat destructure.
