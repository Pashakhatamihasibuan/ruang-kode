Template syntax dan direktif

Buka versi interaktif

Tampilkan nilai dengan interpolasi {{ nama }} (otomatis di-escape). Direktif adalah atribut khusus berawalan v-: v-bind:src atau singkatnya :src untuk mengikat atribut, v-on:click atau @click untuk event.

Percabangan dengan v-if, v-else-if, v-else (elemen benar-benar dibuat atau dibuang) dan v-show (hanya disembunyikan dengan CSS, cocok untuk yang sering berganti). Perulangan dengan v-for="p in produk" :key="p.id"; key wajib dan harus unik.

Jangan memakai v-if dan v-for pada elemen yang sama; saring data dulu dengan computed.

Direktif utama
DirektifSingkatanFungsi
v-bind:attr:attrMengikat atribut ke data
v-on:event@eventMenangani event
v-if / v-elseRender bersyarat
v-showTampil atau sembunyi dengan CSS
v-forPerulangan, wajib :key
v-modelIkatan dua arah untuk input
v-htmlHTML mentah, rawan XSS
HTML
<script setup lang="ts">
import { ref } from 'vue'

const produk = ref([
  { id: 1, nama: 'Kopi Gayo', harga: 85000, stok: 12, foto: '/gayo.jpg' },
  { id: 2, nama: 'Kopi Toraja', harga: 95000, stok: 0, foto: '/toraja.jpg' },
])
const rupiah = (n: number) => n.toLocaleString('id-ID')
</script>

<template>
  <ul>
    <li v-for="p in produk" :key="p.id">
      <img :src="p.foto" :alt="p.nama" width="80" />
      <strong>{{ p.nama }}</strong> Rp{{ rupiah(p.harga) }}
      <span v-if="p.stok === 0" class="habis">Stok habis</span>
      <button v-else @click="p.stok--">Beli ({{ p.stok }})</button>
    </li>
  </ul>
</template>

<style scoped>
.habis { color: #b91c1c; }
</style>

Soal latihan

  1. Tampilkan daftar nama kota dari array kota sebagai <li>, dan tampilkan "Belum ada kota" jika array kosong.

    Petunjuk

    v-if pada pesan kosong, v-else pada ul dengan v-for.

    Lihat jawaban
    HTML
    <p v-if="kota.length === 0">Belum ada kota</p>
<ul v-else>
  <li v-for="k in kota" :key="k">{{ k }}</li>
</ul>

Poin penting

  • {{ }} untuk teks, :attr untuk atribut, @event untuk event.
  • v-if membuang elemen, v-show menyembunyikan.
  • v-for selalu dengan :key unik.
