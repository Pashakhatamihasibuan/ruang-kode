ref, reactive, computed, dan watch

Buka versi interaktif

ref() membungkus nilai apa pun agar reaktif; di script diakses dengan .value, di template tanpa .value. reactive() membuat objek reaktif tanpa .value, tetapi kehilangan reaktivitas jika di-destructure. Banyak tim memilih ref untuk semuanya agar konsisten.

computed() menghitung nilai turunan dan menyimpannya (cache) sampai dependensinya berubah, misalnya total keranjang. watch() menjalankan efek samping saat data berubah, misalnya menyimpan ke localStorage atau memanggil API pencarian.

Aturan: jika hasilnya nilai yang ditampilkan, pakai computed; jika perlu melakukan sesuatu (memanggil API, menulis storage), pakai watch.

HTML
<script setup lang="ts">
import { ref, computed, watch } from 'vue'

const keranjang = ref([
  { nama: 'Kopi Gayo', harga: 85000, qty: 2 },
  { nama: 'Gula Aren', harga: 25000, qty: 1 },
])
const total = computed(() => keranjang.value.reduce((s, i) => s + i.harga * i.qty, 0))
const gratisOngkir = computed(() => total.value >= 150000)

watch(keranjang, (baru) => {
  localStorage.setItem('keranjang', JSON.stringify(baru))
}, { deep: true })
</script>

<template>
  <p>Total: Rp{{ total.toLocaleString('id-ID') }}</p>
  <p v-if="gratisOngkir">Selamat, kamu dapat gratis ongkir!</p>
</template>

Poin penting

  • ref + .value di script.
  • computed untuk nilai turunan (di-cache).
  • watch untuk efek samping.
