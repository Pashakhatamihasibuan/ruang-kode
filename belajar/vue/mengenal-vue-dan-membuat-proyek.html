Vue.js · Modul 1 · Konsep & kode

Mengenal Vue dan membuat proyek

Buka versi interaktif

Vue adalah framework JavaScript progresif untuk membangun antarmuka. "Progresif" artinya bisa dipakai sedikit demi sedikit: dari menambahkan interaksi ke satu halaman sampai aplikasi lengkap dengan router dan state management. Vue dikenal mudah dipelajari karena template-nya mirip HTML biasa.

Proyek baru dibuat dengan npm create vue@latest yang memakai Vite (server pengembangan sangat cepat). Kode ditulis dalam Single File Component (.vue) berisi tiga bagian: <script setup>, <template>, dan <style scoped>.

Vue 3 menyediakan dua gaya: Options API (data, methods, computed dalam objek) dan Composition API (fungsi seperti ref dan computed di script setup). Jalur ini memakai Composition API yang menjadi standar proyek baru.
