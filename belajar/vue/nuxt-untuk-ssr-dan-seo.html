Nuxt untuk SSR dan SEO

Buka versi interaktif

Aplikasi Vue biasa (SPA) merender di browser, sehingga HTML awalnya hampir kosong. Untuk SEO dan tampil awal yang cepat, pakai Nuxt: meta-framework Vue (padanan Next.js untuk React) dengan routing berbasis folder pages/, SSR, generasi statis, dan API server di folder server/.

Nuxt menyediakan auto-import (tidak perlu menulis import { ref } from 'vue'), useFetch yang aman untuk SSR, useHead dan useSeoMeta untuk metadata, serta modul resmi untuk gambar, konten, dan i18n.

Pilih SPA Vue untuk dasbor internal di balik login; pilih Nuxt untuk situs publik seperti toko, blog, dan landing page.

HTML
<!-- pages/produk/[slug].vue  ->  /produk/kopi-gayo -->
<script setup lang="ts">
const route = useRoute()
const { data: produk, error } = await useFetch(`/api/produk/${route.params.slug}`)
if (error.value) throw createError({ statusCode: 404, statusMessage: 'Produk tidak ditemukan' })

useSeoMeta({
  title: () => `${produk.value?.nama} | Tokoku`,
  description: () => produk.value?.deskripsi,
})
</script>

<template>
  <main>
    <h1>{{ produk?.nama }}</h1>
    <NuxtImg :src="produk?.foto" width="600" />
  </main>
</template>

Poin penting

  • Nuxt = Vue + SSR + routing folder + server.
  • useFetch dan useSeoMeta untuk SSR dan SEO.
  • SPA untuk dasbor, Nuxt untuk situs publik.
