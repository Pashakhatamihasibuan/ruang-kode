PostgreSQL dan tugas seorang DBA

Buka versi interaktif

PostgreSQL adalah database relasional open source yang dikembangkan sejak 1986. Ia dikenal patuh standar SQL, andal (ACID), dan mudah diperluas: tipe data JSONB, pencarian teks penuh, PostGIS untuk peta, dan pgvector untuk AI. Gojek, Tokopedia, Instagram, dan banyak startup memakainya.

Database Administrator (DBA) memastikan database aman, cepat, dan tidak kehilangan data. Tugas hariannya: membuat dan mengatur pengguna serta hak akses, memantau performa, menyetel konfigurasi, membuat indeks, menjadwalkan backup, menguji pemulihan, menyiapkan replikasi, dan meningkatkan versi.

Jalur ini mengikuti peta belajar PostgreSQL DBA. Kamu perlu dasar SQL (SELECT, JOIN, GROUP BY) dulu; jika belum, selesaikan jalur SQL di Ruang Kode.
