Instalasi dengan Docker dan psql

Buka versi interaktif

Cara tercepat mencoba PostgreSQL adalah Docker. Di server produksi, pasang dari repositori resmi (apt.postgresql.org untuk Ubuntu) atau pakai layanan terkelola seperti Amazon RDS, Google Cloud SQL, atau Supabase.

psql adalah klien baris perintah resmi. Perintah meta diawali garis miring terbalik: \l daftar database, \c nama pindah database, \dt daftar tabel, \d tabel struktur tabel, \du daftar role, \x tampilan vertikal, \timing menampilkan durasi query, dan \q keluar.

Simpan data di volume agar tidak hilang saat container dihapus, dan jangan pernah memakai kata sandi contoh di produksi.

Perintah meta psql
PerintahFungsi
\lDaftar database
\c dbPindah database
\dtDaftar tabel
\d tabelKolom, indeks, constraint
\duDaftar role
\dnDaftar schema
\xTampilan vertikal
\timingTampilkan durasi query
\i file.sqlJalankan file
\qKeluar
TERMINAL
docker run -d --name pg17 \
  -e POSTGRES_PASSWORD=rahasia_kuat \
  -v pgdata:/var/lib/postgresql/data \
  -p 5432:5432 postgres:17

docker exec -it pg17 psql -U postgres

postgres=# CREATE DATABASE tokodb;
postgres=# \c tokodb
tokodb=# \timing on
tokodb=# \dt
KELUARAN
CREATE DATABASE
You are now connected to database "tokodb" as user "postgres".
Timing is on.
Did not find any relations.

Soal latihan

  1. Tulis perintah psql untuk menghubungkan ke database tokodb di host 10.0.0.5 sebagai user analis.

    Petunjuk

    Opsi -h host, -U user, -d database.

    Lihat jawaban
    SQL
    psql -h 10.0.0.5 -U analis -d tokodb

Poin penting

  • Docker untuk belajar, paket resmi atau layanan terkelola untuk produksi.
  • Simpan data di volume.
  • Hafalkan \l, \c, \dt, \d, \du.

Cek pemahaman

Perintah psql untuk melihat struktur tabel produk?

Jawaban: \d produk

\d menampilkan kolom, indeks, dan constraint.
