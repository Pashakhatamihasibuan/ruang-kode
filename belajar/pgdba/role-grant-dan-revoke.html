Role, GRANT, dan REVOKE

Buka versi interaktif

Di PostgreSQL, pengguna dan grup sama-sama role. Role dengan atribut LOGIN bisa masuk; role tanpa LOGIN dipakai sebagai grup. Hak diberikan dengan GRANT dan dicabut dengan REVOKE.

Terapkan least privilege: aplikasi web cukup SELECT, INSERT, UPDATE, DELETE di schema-nya, bukan superuser. Buat role grup (baca_saja, aplikasi), beri hak ke grup, lalu masukkan pengguna ke grup. Saat karyawan keluar, cukup cabut keanggotaannya.

ALTER DEFAULT PRIVILEGES memastikan tabel yang dibuat nanti otomatis mendapat hak yang sama; tanpa ini, tabel baru tidak bisa dibaca role baca_saja.

SQL
CREATE ROLE baca_saja NOLOGIN;
GRANT USAGE ON SCHEMA penjualan TO baca_saja;
GRANT SELECT ON ALL TABLES IN SCHEMA penjualan TO baca_saja;
ALTER DEFAULT PRIVILEGES IN SCHEMA penjualan
  GRANT SELECT ON TABLES TO baca_saja;

CREATE ROLE dewi LOGIN PASSWORD 'ganti_segera' IN ROLE baca_saja;

SET ROLE dewi;
DELETE FROM penjualan.pelanggan WHERE id = 1;

Soal latihan

  1. Buat role grup aplikasi yang boleh SELECT, INSERT, UPDATE, DELETE di semua tabel schema penjualan, lalu buat user webapp sebagai anggotanya.

    Petunjuk

    GRANT USAGE pada schema, lalu GRANT hak DML, lalu CREATE ROLE ... IN ROLE.

    Lihat jawaban
    SQL
    CREATE ROLE aplikasi NOLOGIN;
GRANT USAGE ON SCHEMA penjualan TO aplikasi;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA penjualan TO aplikasi;
CREATE ROLE webapp LOGIN PASSWORD 'ganti_segera' IN ROLE aplikasi;

Poin penting

  • Pengguna dan grup sama-sama role.
  • Beri hak ke grup, masukkan pengguna ke grup.
  • ALTER DEFAULT PRIVILEGES untuk tabel yang dibuat nanti.
