JSONB dan tipe lanjutan

Buka versi interaktif

JSONB menyimpan JSON dalam bentuk biner yang bisa diindeks. Operator penting: -> mengambil nilai sebagai JSON, ->> sebagai teks, @> "mengandung", dan ? "punya kunci". Indeks GIN membuat pencarian @> cepat.

JSONB cocok untuk atribut yang bervariasi (spesifikasi produk elektronik berbeda dengan pakaian) atau payload dari API pihak ketiga. Jangan memasukkan semua ke JSONB: kolom yang sering difilter, di-JOIN, atau wajib ada sebaiknya kolom biasa dengan constraint.

Tipe lain yang berguna: tstzrange untuk rentang waktu, inet untuk alamat IP, dan enum untuk pilihan tetap.

SQL
ALTER TABLE produk ADD COLUMN spek jsonb DEFAULT '{}';

UPDATE produk SET spek = '{"asal": "Aceh", "roast": "medium", "berat_g": 250}'
WHERE nama = 'Kopi Gayo';

CREATE INDEX produk_spek_gin ON produk USING gin (spek);

SELECT nama, spek->>'asal' AS asal, (spek->>'berat_g')::int AS gram
FROM produk
WHERE spek @> '{"roast": "medium"}';

Soal latihan

  1. Ambil nama produk yang spek-nya punya kunci garansi.

    Petunjuk

    Operator ? memeriksa keberadaan kunci.

    Lihat jawaban
    SQL
    SELECT nama FROM produk WHERE spek ? 'garansi';

Poin penting

  • -> JSON, ->> teks, @> mengandung.
  • Indeks GIN untuk query JSONB.
  • Kolom penting tetap jadi kolom biasa.
