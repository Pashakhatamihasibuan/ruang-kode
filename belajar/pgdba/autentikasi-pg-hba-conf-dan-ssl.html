Autentikasi: pg_hba.conf dan SSL

Buka versi interaktif

File pg_hba.conf mengatur siapa boleh terhubung dari mana dan dengan metode apa. Setiap baris berisi: tipe koneksi, database, user, alamat, dan metode. Baris dibaca dari atas; baris pertama yang cocok yang dipakai.

Metode yang disarankan: scram-sha-256 untuk kata sandi (bukan md5 lama, apalagi trust). Batasi alamat ke jaringan aplikasi saja, jangan 0.0.0.0/0. Pakai hostssl agar koneksi wajib terenkripsi.

Setelah mengubah file, jalankan SELECT pg_reload_conf();. Periksa hasilnya di view pg_hba_file_rules untuk menemukan baris yang salah ketik.

TERMINAL
# TYPE   DATABASE  USER      ADDRESS          METHOD
local    all       postgres                   peer
hostssl  tokodb    webapp    10.0.1.0/24      scram-sha-256
hostssl  tokodb    +baca_saja 10.0.2.0/24     scram-sha-256
host     all       all       0.0.0.0/0        reject

# postgresql.conf
ssl = on
password_encryption = scram-sha-256
KELUARAN
SELECT pg_reload_conf();
 pg_reload_conf

Soal latihan

  1. Tulis baris pg_hba.conf agar user laporan hanya bisa masuk ke database tokodb dari IP 192.168.10.20 dengan SSL dan scram-sha-256.

    Petunjuk

    Alamat satu host memakai /32.

    Lihat jawaban
    SQL
    hostssl  tokodb  laporan  192.168.10.20/32  scram-sha-256

Poin penting

  • pg_hba.conf dibaca dari atas, baris pertama yang cocok menang.
  • Pakai scram-sha-256 dan hostssl.
  • Tutup dengan baris reject di akhir.
