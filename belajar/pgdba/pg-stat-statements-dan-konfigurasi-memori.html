pg_stat_statements dan konfigurasi memori

Buka versi interaktif

Extension pg_stat_statements mencatat statistik setiap bentuk query: berapa kali dipanggil, total waktu, rata-rata, dan baris. Ini titik awal tuning: perbaiki query dengan total waktu terbesar dulu, bukan yang paling lambat sekali jalan.

Parameter memori utama: shared_buffers sekitar 25% RAM; effective_cache_size sekitar 50 sampai 75% RAM (perkiraan cache OS untuk planner); work_mem per operasi sort atau hash (hati-hati, dikalikan jumlah koneksi dan operasi); maintenance_work_mem untuk VACUUM dan CREATE INDEX.

Untuk SSD, turunkan random_page_cost ke 1.1. Gunakan PGTune sebagai titik awal, lalu ukur. Ubah satu parameter dalam satu waktu dan catat dampaknya.

Titik awal konfigurasi server 16 GB RAM, SSD

SQL
CREATE EXTENSION IF NOT EXISTS pg_stat_statements;

SELECT left(query, 45) AS query, calls,
       round(total_exec_time) AS total_ms,
       round(mean_exec_time, 2) AS rata_ms
FROM pg_stat_statements
ORDER BY total_exec_time DESC
LIMIT 3;

ALTER SYSTEM SET work_mem = '32MB';
SELECT pg_reload_conf();

Poin penting

  • Perbaiki query dengan total waktu terbesar dulu.
  • shared_buffers sekitar 25% RAM.
  • work_mem per operasi, hati-hati dikalikan.
