Unit test dengan pola Arrange-Act-Assert

Buka versi interaktif

Unit test menguji satu unit kecil secara terisolasi dan berjalan dalam milidetik. Pola AAA: Arrange (siapkan data), Act (jalankan fungsi), Assert (periksa hasil). Nama tes sebaiknya menjelaskan perilaku, misalnya tes_diskon_member_10_persen.

Di Python, standar industri adalah pytest: cukup tulis fungsi berawalan test_ dan pakai assert. Fitur unggulannya: @pytest.mark.parametrize untuk banyak data sekaligus, fixture untuk persiapan bersama, dan laporan kegagalan yang jelas.

Contoh di bawah memakai pelari tes mini agar bisa dijalankan di browser. Di proyek nyata, simpan di tests/test_harga.py lalu jalankan pytest -v.

PYTHON

def jalankan(*tes):
    lulus = 0
    for t in tes:
        try:
            t()
            print('LULUS', t.__name__)
            lulus += 1
        except AssertionError as e:
            print('GAGAL', t.__name__, '-', e)
    print(f'{lulus}/{len(tes)} tes lulus')

def harga_akhir(harga, member=False, kupon=None):
    if harga < 0:
        raise ValueError('harga negatif')
    if member:
        harga = harga * 90 // 100
    if kupon == 'HEMAT5K':
        harga = max(0, harga - 5000)
    return harga

def tes_member_diskon_10_persen():
    # Arrange
    harga = 100000
    # Act
    hasil = harga_akhir(harga, member=True)
    # Assert
    assert hasil == 90000

def tes_kupon_tidak_membuat_negatif():
    assert harga_akhir(3000, kupon='HEMAT5K') == 0

def tes_harga_negatif_ditolak():
    try:
        harga_akhir(-1)
        assert False, 'harus error'
    except ValueError:
        pass

def tes_parametrize():
    for harga, member, kupon, harap in [(50000, False, None, 50000), (50000, True, 'HEMAT5K', 40000)]:
        assert harga_akhir(harga, member, kupon) == harap

jalankan(tes_member_diskon_10_persen, tes_kupon_tidak_membuat_negatif, tes_harga_negatif_ditolak, tes_parametrize)

LULUS tes_kupon_tidak_membuat_negatif
LULUS tes_harga_negatif_ditolak
LULUS tes_parametrize
4/4 tes lulus

    def slug(judul):
    return judul.strip().lower().replace(' ', '-')

def tes_slug():
    assert slug('Belajar Python Dasar') == 'belajar-python-dasar'
    assert slug('  Halo  ') == 'halo'

tes_slug()
print('tes_slug lulus')

Poin penting

  • Arrange, Act, Assert.
  • Nama tes = perilaku yang diuji.
  • pytest: assert biasa, parametrize, fixture.
