Tes E2E dengan Playwright

Buka versi interaktif

Playwright (Microsoft) menjalankan Chromium, Firefox, dan WebKit dengan satu API, menunggu elemen siap secara otomatis, dan menyediakan trace viewer untuk melihat ulang setiap langkah tes yang gagal. Alternatifnya Cypress dan Selenium.

Pilih locator yang tahan perubahan: berdasarkan peran dan teks yang dilihat pengguna (get_by_role, get_by_label), atau data-testid. Hindari selector CSS panjang seperti div > div:nth-child(3) > span yang patah saat desain berubah.

Page Object Model membungkus satu halaman menjadi kelas berisi locator dan aksi. Jika tombol berubah, cukup ubah di satu tempat.

PYTHON
from playwright.sync_api import Page, expect

class HalamanMasuk:
    def __init__(self, page: Page):
        self.page = page
        self.email = page.get_by_label('Email')
        self.sandi = page.get_by_label('Kata sandi')
        self.tombol = page.get_by_role('button', name='Masuk')

    def buka(self):
        self.page.goto('https://staging.toko.id/masuk')

    def masuk(self, email, sandi):
        self.email.fill(email)
        self.sandi.fill(sandi)
        self.tombol.click()

def test_masuk_berhasil(page: Page):
    h = HalamanMasuk(page)
    h.buka()
    h.masuk('rina@contoh.id', 'RahasiaKuat!9')
    expect(page.get_by_text('Halo, Rina')).to_be_visible()

def test_sandi_salah(page: Page):
    h = HalamanMasuk(page)
    h.buka()
    h.masuk('rina@contoh.id', 'salah')
    expect(page.get_by_role('alert')).to_have_text('Email atau kata sandi salah')

Soal latihan

  1. Tulis langkah Playwright untuk menambah produk "Kopi Gayo" ke keranjang dan memastikan lencana keranjang menunjukkan 1.

    Petunjuk

    get_by_role untuk tombol, expect(...).to_have_text.

    Lihat jawaban
    PYTHON
    page.goto('https://staging.toko.id/produk/kopi-gayo')
page.get_by_role('button', name='Tambah ke keranjang').click()
expect(page.get_by_test_id('jumlah-keranjang')).to_have_text('1')

Poin penting

  • Locator berdasarkan peran, label, atau data-testid.
  • Page Object Model: satu kelas per halaman.
  • Playwright menunggu otomatis dan punya trace viewer.
