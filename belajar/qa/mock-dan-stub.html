Mock dan stub

Buka versi interaktif

Unit test harus cepat dan pasti. Jika kode memanggil layanan luar (payment gateway, API ongkir, email, waktu sekarang), ganti dengan test double: stub mengembalikan jawaban tetap, mock juga mencatat bagaimana ia dipanggil sehingga bisa diperiksa, dan fake adalah implementasi sederhana (misalnya database di memori).

Python menyediakan unittest.mock: Mock(return_value=...), side_effect untuk melempar error, dan assert_called_once_with untuk memeriksa argumen.

Jangan berlebihan: terlalu banyak mock membuat tes hanya menguji mock-nya sendiri. Mock di batas sistem (jaringan, waktu, file), bukan logika internal.

PYTHON
from unittest.mock import Mock

def checkout(total, gateway, email):
    try:
        kode = gateway.tagih(total)
    except TimeoutError:
        return 'Pembayaran sedang sibuk, coba lagi'
    email.kirim('Terima kasih', f'Kode bayar {kode}')
    return 'berhasil'

# kasus berhasil
gateway = Mock()
gateway.tagih.return_value = 'QR-778'
email = Mock()
print(checkout(85000, gateway, email))
gateway.tagih.assert_called_once_with(85000)
email.kirim.assert_called_once_with('Terima kasih', 'Kode bayar QR-778')
print('argumen sesuai')

# kasus timeout
gateway.tagih.side_effect = TimeoutError
email2 = Mock()
print(checkout(85000, gateway, email2))
print('email terkirim?', email2.kirim.called)
KELUARAN
berhasil
argumen sesuai
Pembayaran sedang sibuk, coba lagi
email terkirim? False

Soal latihan

  1. Buat Mock layanan ongkir yang mengembalikan 18000, panggil dengan ("Medan", "Binjai"), lalu cetak hasil dan jumlah panggilannya.

    Petunjuk

    Mock().hitung.return_value = 18000; call_count.

    Lihat jawaban
    PYTHON
    from unittest.mock import Mock
ongkir = Mock()
ongkir.hitung.return_value = 18000
print(ongkir.hitung('Medan', 'Binjai'))
print(ongkir.hitung.call_count)
    KELUARAN
    18000
1

Poin penting

  • Stub = jawaban tetap; mock = juga memeriksa panggilan.
  • side_effect untuk mensimulasikan error.
  • Mock di batas sistem saja.
