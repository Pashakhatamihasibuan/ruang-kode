Pengujian API REST

Buka versi interaktif

Pengujian API memeriksa status code, isi respons (struktur dan nilai), header, waktu respons, serta perilaku untuk input salah (400), tanpa token (401), tanpa hak (403), dan data tidak ada (404). Tes API lebih cepat dan stabil daripada tes UI, jadi letakkan sebagian besar tes integrasi di sini.

Alat populer: Postman (manual dan koleksi otomatis dengan Newman), requests + pytest di Python, REST Assured di Java, dan Playwright APIRequestContext. Validasi struktur respons bisa memakai JSON Schema.

Selalu uji skenario negatif dan keamanan dasar: apakah pengguna A bisa membaca pesanan pengguna B dengan mengganti ID di URL? Ini celah IDOR yang sangat sering ditemukan.

PYTHON
import requests

BASE = 'https://staging.toko.id/api'

def test_ambil_produk():
    r = requests.get(f'{BASE}/produk/12', timeout=5)
    assert r.status_code == 200
    data = r.json()
    assert data['id'] == 12
    assert data['harga'] > 0
    assert r.elapsed.total_seconds() < 0.5

def test_pesanan_orang_lain_ditolak(token_rina):
    r = requests.get(f'{BASE}/pesanan/9001',  # milik Budi
                     headers={'Authorization': f'Bearer {token_rina}'})
    assert r.status_code in (403, 404)
