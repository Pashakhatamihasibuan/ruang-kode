State transition testing

Buka versi interaktif

Beberapa fitur punya keadaan (state) yang berubah karena peristiwa. Contoh: status pesanan (Dibuat → Dibayar → Dikirim → Selesai, atau Dibatalkan). State transition testing memeriksa bahwa transisi yang sah berhasil dan transisi yang tidak sah ditolak.

Gambar diagram state, lalu buat tabel: keadaan sekarang, peristiwa, keadaan berikutnya. Tes negatif sama pentingnya, misalnya pesanan yang sudah Dikirim tidak boleh dibatalkan begitu saja.

Teknik ini juga cocok untuk penguncian akun (salah sandi 5 kali), alur onboarding, dan mesin ATM.

PYTHON

def jalankan(*tes):
    lulus = 0
    for t in tes:
        try:
            t()
            print('LULUS', t.__name__)
            lulus += 1
        except AssertionError as e:
            print('GAGAL', t.__name__, '-', e)
    print(f'{lulus}/{len(tes)} tes lulus')

TRANSISI = {
    ('dibuat', 'bayar'): 'dibayar',
    ('dibuat', 'batal'): 'dibatalkan',
    ('dibayar', 'kirim'): 'dikirim',
    ('dibayar', 'batal'): 'dibatalkan',
    ('dikirim', 'terima'): 'selesai',
}

def ubah(status, peristiwa):
    if (status, peristiwa) not in TRANSISI:
        raise ValueError(f'{peristiwa} tidak boleh saat {status}')
    return TRANSISI[(status, peristiwa)]

def tes_alur_normal():
    s = 'dibuat'
    for p in ['bayar', 'kirim', 'terima']:
        s = ubah(s, p)
    assert s == 'selesai'

def tes_tidak_boleh_batal_setelah_kirim():
    try:
        ubah('dikirim', 'batal')
        assert False, 'seharusnya ditolak'
    except ValueError:
        pass

jalankan(tes_alur_normal, tes_tidak_boleh_batal_setelah_kirim)

LULUS tes_alur_normal
LULUS tes_tidak_boleh_batal_setelah_kirim
2/2 tes lulus

Soal latihan

  1. Simulasikan penguncian akun: setelah 3 kali salah sandi berturut-turut, status menjadi "terkunci". Cetak status setelah urutan percobaan salah, salah, benar, salah, salah, salah.

    Petunjuk

    Reset penghitung saat benar.

Poin penting

  • Uji transisi sah dan tidak sah.
  • Tabel: state, peristiwa, state berikutnya.
  • Cocok untuk status pesanan, penguncian akun, ATM.
