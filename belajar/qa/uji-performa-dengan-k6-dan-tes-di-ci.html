Uji performa dengan k6 dan tes di CI

Buka versi interaktif

Uji performa menjawab: berapa pengguna yang sanggup dilayani, seberapa cepat, dan di mana batasnya. Jenisnya: load (beban normal sampai puncak), stress (melewati batas sampai gagal), spike (lonjakan tiba-tiba, misalnya flash sale 12.12), dan soak (beban sedang berjam-jam untuk mendeteksi kebocoran memori).

k6 menulis skenario dengan JavaScript dan menetapkan threshold yang membuat tes gagal jika, misalnya, persentil 95 waktu respons di atas 500 ms. Ukur persentil (p95, p99), bukan rata-rata saja.

Hubungkan semuanya ke CI (GitHub Actions, GitLab CI): unit dan API test di setiap pull request, E2E smoke di setiap merge, regresi penuh dan performa terjadwal setiap malam. Simpan laporan dan trace sebagai artefak agar kegagalan mudah diselidiki.

JenisPola bebanPertanyaan

JAVASCRIPT
// flash-sale.js
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  stages: [
    { duration: '1m', target: 200 },
    { duration: '3m', target: 200 },
    { duration: '30s', target: 1000 },  // lonjakan
    { duration: '1m', target: 0 },
  ],
  thresholds: {
    http_req_duration: ['p(95)<500'],
    http_req_failed: ['rate<0.01'],
  },
};

export default function () {
  const r = http.get('https://staging.toko.id/api/produk?promo=1212');
  check(r, { 'status 200': (x) => x.status === 200 });
  sleep(1);
}
