Decision table

Buka versi interaktif

Decision table dipakai jika hasil bergantung pada kombinasi beberapa kondisi. Tulis semua kondisi sebagai baris, setiap kolom adalah satu kombinasi, lalu tentukan aksinya. Dengan n kondisi ya/tidak ada 2ⁿ kombinasi.

Contoh aturan ongkir toko online: gratis ongkir jika pelanggan member dan belanja minimal Rp150.000; jika hanya salah satu terpenuhi, diskon ongkir 50%; jika tidak keduanya, ongkir penuh.

Tabel membuat kombinasi yang terlupa langsung terlihat, dan setiap kolom menjadi satu test case.

def jalankan(*tes):
    lulus = 0
    for t in tes:
        try:
            t()
            print('LULUS', t.__name__)
            lulus += 1
        except AssertionError as e:
            print('GAGAL', t.__name__, '-', e)
    print(f'{lulus}/{len(tes)} tes lulus')

def ongkir(member, belanja, tarif=20000):
    if member and belanja >= 150000:
        return 0
    if member or belanja >= 150000:
        return tarif // 2
    return tarif

tabel = [
    # member, belanja, harapan
    (True,  200000, 0),
    (True,  100000, 10000),
    (False, 200000, 10000),
    (False, 100000, 20000),
]

def tes_tabel_keputusan():
    for member, belanja, harap in tabel:
        hasil = ongkir(member, belanja)
        assert hasil == harap, f'{member}, {belanja}: {hasil} != {harap}'

jalankan(tes_tabel_keputusan)

Soal latihan

  1. Buat decision table untuk login: email terdaftar (ya/tidak) dan kata sandi benar (ya/tidak). Cetak setiap kombinasi beserta pesan yang tepat.

    Petunjuk

    Empat kombinasi; jangan beri tahu apakah email terdaftar demi keamanan.

    Lihat jawaban

Poin penting

  • Untuk kombinasi beberapa kondisi.
  • 2 kondisi ya/tidak = 4 kolom.
  • Setiap kolom menjadi satu test case.
