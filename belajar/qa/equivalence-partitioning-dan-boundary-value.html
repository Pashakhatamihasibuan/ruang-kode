Equivalence partitioning dan boundary value

Buka versi interaktif

Kita tidak mungkin menguji semua input. Equivalence partitioning membagi input menjadi kelompok yang seharusnya diperlakukan sama, lalu cukup menguji satu wakil per kelompok. Contoh: umur pendaftar BPJS mandiri anak 0 sampai 17, dewasa 18 sampai 59, lansia 60 ke atas, dan kelompok tidak valid (negatif).

Boundary value analysis menguji tepat di batas karena bug sering muncul di sana (salah tulis < dan <=). Untuk batas 18, uji 17, 18, dan 19. Gabungan keduanya menghasilkan sedikit tes tetapi efektif.

Di bawah ini fungsi kategori umur dengan bug yang disengaja. Jalankan tesnya dan lihat tes batas mana yang menangkap bug itu.

PYTHON

def jalankan(*tes):
    lulus = 0
    for t in tes:
        try:
            t()
            print('LULUS', t.__name__)
            lulus += 1
        except AssertionError as e:
            print('GAGAL', t.__name__, '-', e)
    print(f'{lulus}/{len(tes)} tes lulus')

def kategori(umur):
    if umur < 0:
        return 'tidak valid'
    if umur < 18:
        return 'anak'
    if umur < 61:        # BUG: seharusnya < 60
        return 'dewasa'
    return 'lansia'

def tes_partisi():
    assert kategori(10) == 'anak'
    assert kategori(30) == 'dewasa'
    assert kategori(75) == 'lansia'
    assert kategori(-1) == 'tidak valid'

def tes_batas_18():
    assert [kategori(u) for u in (17, 18, 19)] == ['anak', 'dewasa', 'dewasa']

def tes_batas_60():
    hasil = kategori(60)
    assert hasil == 'lansia', f'umur 60 menjadi {hasil!r}'

jalankan(tes_partisi, tes_batas_18, tes_batas_60)
KELUARAN
LULUS tes_partisi
LULUS tes_batas_18
GAGAL tes_batas_60 - umur 60 menjadi 'dewasa'
2/3 tes lulus

Soal latihan

  1. Kata sandi valid jika panjangnya 8 sampai 20 karakter. Tulis daftar panjang yang diuji dengan boundary value analysis dan cetak hasil validasinya.

    Petunjuk

    Uji 7, 8, 9, 19, 20, 21.

    Lihat jawaban
    PYTHON
    def valid(pw):
    return 8 <= len(pw) <= 20
for n in [7, 8, 9, 19, 20, 21]:
    print(n, valid('a' * n))

    7 False
8 True

Poin penting

  • Satu wakil per kelompok input.
  • Uji tepat di batas: batas - 1, batas, batas + 1.
  • Tes partisi saja tidak menangkap bug batas.
