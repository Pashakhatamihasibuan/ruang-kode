Data Science & AI: Dari statistik sampai machine learning dan deep learning

Python dan pandas untuk data, matematika untuk ML, statistik, uji hipotesis dan t-test, A/B test, regresi dan deret waktu, EDA dan visualisasi dengan pandas dan Matplotlib, algoritma ML dari dasar sampai lanjut (linear dan logistic regression, KNN, Naive Bayes, decision tree, SVM, ensemble, gradient boosting, K-Means, DBSCAN, PCA, t-SNE, deteksi anomali, sistem rekomendasi), pembersihan data dan feature engineering, data tidak seimbang, jaringan saraf, embedding dan attention, MLOps, metrik bisnis per industri, kasus churn dan kredit, empat studi kasus end-to-end, karier, dan 10 proyek portofolio. Semua contoh Python dan grafiknya bisa dijalankan.

14 modul · 79 pelajaran

Mulai belajar di aplikasi

Modul 1: Peran data scientist dan alat utamanya

Pemula

Apa yang dikerjakan data scientist, alur proyek dari pertanyaan sampai model, lalu dua alat inti: NumPy dan pandas.

  1. Data scientist dan alur kerjanya
  2. NumPy: array, vektorisasi, dan broadcasting
  3. pandas: Series, DataFrame, dan membaca data
  4. Python inti untuk data: list, dict, kondisi, loop, dan fungsi
  5. pandas sehari-hari: membuat, menyimpan, mengurutkan, dan mengubah tipe
  6. Menyaring dan menggabungkan: isin, anti-join, apply, dan map

Modul 2: Matematika untuk machine learning

Pemula

Aljabar linear (vektor, matriks, perkalian matriks) dan kalkulus (turunan, gradient descent) yang dipakai di balik setiap model.

  1. Vektor, matriks, dan perkalian matriks
  2. Turunan dan gradient descent

Modul 3: Statistik dan probabilitas

Menengah

Statistik deskriptif, distribusi, sampling dan teorema limit pusat, uji hipotesis, serta A/B test yang benar.

  1. Statistik deskriptif dan distribusi
  2. Probabilitas, sampling, dan teorema limit pusat
  3. Uji hipotesis dan p-value
  4. A/B test: ukuran sampel, sensitivitas, dan metrik rasio
  5. Uji hipotesis langkah demi langkah: statistik uji dan nilai kritis
  6. Studi kasus t-test: apakah program voucher menaikkan belanja?

Modul 4: Ekonometrika: regresi dan deret waktu

Menengah

Regresi linear dan cara membacanya, deret waktu (tren, musiman, rolling), peramalan sederhana, serta mencocokkan distribusi.

  1. Regresi linear: menarik garis terbaik
  2. Deret waktu: tren, musiman, dan rolling
  3. Mencocokkan distribusi pada data

Modul 5: EDA dan visualisasi dengan pandas & Matplotlib

Pemula

Memahami data dengan pandas (info, describe, nilai hilang, groupby), lalu membuat grafik garis, batang, histogram, scatter, subplot, dan heatmap korelasi dengan Matplotlib.

  1. Memahami data: info, describe, dan nilai hilang
  2. Matplotlib: grafik garis, batang, dan histogram
  3. Matplotlib: scatter, subplot, dan anotasi
  4. Korelasi dan heatmap
  5. Empat tujuan grafik: perbandingan, distribusi, hubungan, dan komposisi
  6. Membersihkan data: duplikat, nilai mustahil, dan outlier
  7. EDA univariat, bivariat, dan multivariat
  8. Feature engineering: membuat variabel baru yang bermakna

Modul 6: Machine learning klasik dengan scikit-learn

Menengah

Membagi data latih dan uji, regresi dan metriknya, klasifikasi dengan confusion matrix, pohon keputusan dan random forest, clustering K-Means, serta validasi silang.

  1. Alur ML: fitur, target, dan train/test split
  2. Regresi dan metriknya: MAE, RMSE, R²
  3. Klasifikasi: logistic regression dan confusion matrix
  4. Decision tree dan random forest
  5. Clustering K-Means: mengelompokkan tanpa label
  6. Validasi silang dan mencegah overfitting
  7. Peta ML dan persiapan data sebelum model
  8. Data tidak seimbang: class_weight, oversampling, dan metrik yang jujur

Modul 7: Algoritma ML dasar, satu per satu

Menengah

Linear regression, regresi polinomial dengan Ridge/Lasso, logistic regression, K-Nearest Neighbors, Naive Bayes, dan decision tree. Tiap algoritma dibangun dari nol dengan NumPy lalu dicocokkan dengan scikit-learn.

  1. Linear regression dari nol
  2. Regresi polinomial, overfitting, Ridge dan Lasso
  3. Logistic regression dari nol
  4. K-Nearest Neighbors (KNN)
  5. Naive Bayes: klasifikasi teks
  6. Decision tree dari nol: Gini dan pemisahan terbaik

Modul 8: Machine learning lanjutan

Lanjutan

Feature engineering dengan Pipeline, gradient boosting dan tuning hyperparameter, serta reduksi dimensi dengan PCA.

  1. Feature engineering dan Pipeline
  2. Gradient boosting dan tuning hyperparameter
  3. PCA: meringkas banyak fitur

Modul 9: Algoritma ML lanjutan

Lanjutan

Support Vector Machine dan kernel, ensemble (bagging, AdaBoost, stacking), gradient boosting dari nol, clustering DBSCAN dan hierarki, deteksi anomali, t-SNE, sistem rekomendasi, serta peta memilih algoritma.

  1. Support Vector Machine dan kernel
  2. Ensemble: bagging, AdaBoost, dan stacking
  3. Gradient boosting dari nol
  4. Clustering lanjutan: DBSCAN dan hierarki
  5. Deteksi anomali: Isolation Forest
  6. t-SNE: peta 2D untuk data berdimensi tinggi
  7. Sistem rekomendasi: collaborative filtering
  8. Peta memilih algoritma

Modul 10: Deep learning

Lanjutan

Neuron dan jaringan saraf yang dibangun dari nol dengan NumPy, peta arsitektur (CNN, RNN, Transformer), serta embedding dan attention.

  1. Jaringan saraf dari nol dengan NumPy
  2. CNN, RNN, dan Transformer
  3. Embedding dan attention

Modul 11: MLOps: model sampai produksi

Profesional

Menyimpan model, membuat API prediksi, Docker dan CI/CD untuk model, memantau data drift, lalu proyek akhir end-to-end.

  1. Menyimpan model dan membuat API prediksi
  2. Docker, CI/CD, dan memantau data drift
  3. Proyek: memprediksi pelanggan yang akan churn

Modul 12: Dari model ke keputusan bisnis

Lanjutan

Menerjemahkan metrik model menjadi metrik bisnis di keuangan, pemasaran, kesehatan, dan logistik; menghitung nilai rupiah kampanye churn; memilih ambang persetujuan kredit; menyampaikan hasil ke pengambil keputusan; dan menyiapkan karier.

  1. Metrik bisnis per industri: keuangan, pemasaran, kesehatan, logistik
  2. Kasus churn: dari peluang ke rupiah
  3. Kasus kredit: menentukan ambang persetujuan pinjaman
  4. Menyampaikan hasil model ke pengambil keputusan
  5. Karier data scientist 2026-2030: peran, portofolio, dan wawancara

Modul 13: Studi kasus end-to-end

Profesional

Empat proyek lengkap dengan enam langkah yang sama seperti di tim data sungguhan: pemahaman bisnis, pembersihan, EDA, persiapan data, pemodelan dan evaluasi, lalu kesimpulan bisnis. Setiap proyek punya kode final berstandar industri yang bisa dibuka setelah mencoba sendiri.

  1. Studi kasus 1: Memprediksi paket yang akan terlambat
  2. Studi kasus 2: Mencegah pasien kembali dirawat dalam 30 hari
  3. Studi kasus 3: Menaksir harga wajar mobil bekas
  4. Studi kasus 4: Memprioritaskan lead penjualan B2B

Modul 14: Proyek portofolio: 6 mini + 4 besar

Profesional

Proyek berstandar industri untuk jalur Data Scientist: kerjakan proyek mini lalu proyek besar, bandingkan dengan kode final yang bisa dibuka setelah mencoba sendiri, lalu sajikan di CV dan wawancara. Progresnya tercatat juga di menu Proyek Portofolio.

  1. Mini 1: Prediksi pelanggan yang akan berhenti (churn)
  2. Mini 2: Estimasi harga rumah dengan validasi silang
  3. Mini 3: Klasifikasi sentimen ulasan marketplace
  4. Mini 4: Peramalan penjualan harian dengan backtest
  5. Mini 5: Deteksi transaksi penipuan dengan ambang berbasis biaya
  6. Mini 6: Rekomendasi produk "sering dibeli bersama"
  7. Besar 1: Platform prediksi churn sampai produksi (MLOps)
  8. Besar 2: Peramalan permintaan ritel multi-toko
  9. Besar 3: Asisten tanya-jawab dokumen dengan evaluasi (RAG + LLM)
  10. Besar 4: Credit scoring yang adil dan bisa dijelaskan
  11. Profil GitHub dan LinkedIn yang meyakinkan
  12. Menulis proyek di CV (lolos ATS)
  13. Menceritakan proyek saat wawancara (STAR)
  14. Take-home test dan live coding
