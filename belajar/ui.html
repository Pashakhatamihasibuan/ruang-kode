  1. Langkah 1: brief, masalah, dan target
  2. Langkah 2: riset cepat, benchmark, dan moodboard
  3. Langkah 3: user flow dan wireframe
  4. Langkah 4: style guide (warna, tipografi, jarak)
  5. Langkah 5: komponen, varian, dan auto layout
  6. Langkah 6: desain hi-fi, state layar, dan prototipe
  7. Langkah 7: handoff ke developer
