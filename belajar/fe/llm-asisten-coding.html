LLM & asisten coding

Buka versi interaktif

Large Language Model (LLM) dilatih memprediksi kata berikutnya dari teks dalam jumlah sangat besar. Hasilnya model yang bisa menjelaskan, menulis, dan memperbaiki kode, tetapi juga bisa keliru dengan percaya diri. Karena itu, hasilnya selalu perlu kamu baca dan uji.

Asisten coding seperti Claude Code, GitHub Copilot, dan Cursor membantu menulis kode, refactor, membuat tes dan dokumentasi, serta meninjau pull request. Agen AI bisa menjalankan perintah dan mengubah banyak file; MCP (Model Context Protocol) menghubungkan AI dengan alat dan data lain.

Prompt yang baik memberi konteks (proyek, teknologi), tugas yang jelas, batasan (gaya kode, pustaka yang boleh), dan contoh hasil yang diinginkan.

CONTOH
Konteks: proyek React + TypeScript + Tailwind, komponen di src/components.
Tugas: buat komponen KartuProduk yang menampilkan nama, harga (format Rupiah),
dan tombol "Tambah ke keranjang".
Batasan: tanpa pustaka tambahan, aksesibel (button asli, alt pada gambar),
tulis juga satu tes Vitest + Testing Library.
Contoh pemakaian: <KartuProduk nama="Kopi Gayo" harga={85000} onTambah={...} />

Soal latihan

  1. Tulis prompt yang baik untuk meminta asisten AI membuat komponen form login React.

    Petunjuk

    Beri konteks, batasan, dan kriteria selesai.

    Lihat jawaban
    CONTOH
    Buat komponen React (TypeScript) FormLogin:
- field email dan kata sandi dengan label
- validasi: email wajib dan valid, sandi minimal 8 karakter
- tampilkan pesan error di bawah field
- tombol nonaktif saat mengirim
- pakai Tailwind, tanpa library form
- sertakan satu tes dengan Testing Library

  2. Sebutkan tiga hal yang wajib kamu periksa sebelum memakai kode dari asisten AI.

    Petunjuk

    Kebenaran, keamanan, dan lisensi/dependensi.

    Lihat jawaban
    CONTOH
    1. Jalankan dan uji: apakah benar-benar bekerja, termasuk kasus tepi?
2. Keamanan: XSS, rahasia di kode, validasi input
3. Dependensi: package yang disarankan benar-benar ada dan terawat

Poin penting

  • LLM memprediksi teks; bisa salah dengan yakin.
  • Selalu baca, jalankan, dan uji kode hasil AI.
  • Prompt: konteks, tugas, batasan, contoh.
  • Agen dan MCP memperluas kemampuan AI.
