PWA & service worker

Buka versi interaktif

Progressive Web App adalah situs yang bisa dipasang di layar utama, bekerja offline, dan mengirim notifikasi. Syaratnya: HTTPS, file manifest.webmanifest (nama, ikon, warna), dan service worker.

Service worker adalah script yang berjalan di latar belakang dan bisa mencegat permintaan jaringan. Dengan itu, halaman dan aset bisa diambil dari cache saat sinyal hilang, hal yang penting di daerah dengan koneksi tidak stabil.

JAVASCRIPT
// sw.js — cache dulu, jaringan kemudian
const CACHE = "toko-v1";
self.addEventListener("install", e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(["/", "/app.js", "/gaya.css", "/offline.html"])));
});
self.addEventListener("fetch", e => {
  e.respondWith(
    caches.match(e.request).then(hit => hit || fetch(e.request).catch(() => caches.match("/offline.html")))
  );
});

// main.js
if ("serviceWorker" in navigator) navigator.serviceWorker.register("/sw.js");

Poin penting

  • PWA: HTTPS + manifest + service worker.
  • Service worker mencegat request dan memakai cache.
  • Penting untuk pengguna dengan koneksi tidak stabil.
