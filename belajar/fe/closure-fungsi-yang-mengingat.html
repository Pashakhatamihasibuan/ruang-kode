Closure: fungsi yang mengingat

Buka versi interaktif

Closure terjadi saat fungsi dibuat di dalam fungsi lain dan tetap bisa memakai variabel fungsi luar, bahkan setelah fungsi luar selesai dijalankan. Variabel itu "terkunci" bersama fungsinya.

Closure dipakai di mana-mana: event handler yang mengingat id produk, fungsi pabrik seperti buatPenghitung(), sampai hook React. Ia juga cara sederhana membuat data privat, karena variabel di dalamnya tidak bisa diubah dari luar kecuali lewat fungsi yang disediakan.

Jebakan klasik: var di dalam loop berbagi satu variabel untuk semua putaran, sehingga semua callback melihat nilai terakhir. let membuat variabel baru di setiap putaran.

JAVASCRIPT
function buatKeranjang() {
  let isi = [];                       // privat, tidak bisa diakses langsung
  return {
    tambah(barang) { isi.push(barang); return isi.length; },
    lihat() { return [...isi]; },
  };
}
const k = buatKeranjang();
k.tambah("kopi");
k.tambah("teh");
console.log(k.lihat(), k.isi);

const pakaiVar = [], pakaiLet = [];
for (var i = 0; i < 3; i++) pakaiVar.push(() => i);
for (let j = 0; j < 3; j++) pakaiLet.push(() => j);
console.log(pakaiVar.map((f) => f()), pakaiLet.map((f) => f()));
KELUARAN
[ 'kopi', 'teh' ] undefined
[ 3, 3, 3 ] [ 0, 1, 2 ]

Poin penting

  • Closure: fungsi membawa variabel lingkup luarnya.
  • Dipakai untuk handler, pabrik fungsi, data privat.
  • var di loop berbagi satu variabel.
  • let membuat variabel baru per putaran.

Cek pemahaman

Kenapa k.isi bernilai undefined?

Jawaban: isi adalah variabel di dalam closure, bukan properti objek

Variabel closure bersifat privat.

Kenapa pakaiVar menghasilkan [3, 3, 3]?

Jawaban: Semua fungsi berbagi satu variabel i yang akhirnya bernilai 3

var tidak membuat variabel baru per putaran.
