Cara browser menggambar halaman

Buka versi interaktif

Setelah HTML diterima, browser membangun DOM dari HTML dan CSSOM dari CSS, menggabungkannya menjadi render tree, menghitung ukuran dan posisi setiap kotak (layout), mewarnainya (paint), lalu menyusun lapisan (composite).

CSS menghambat tampilan dan script biasa menghambat pembacaan HTML. Karena itu CSS penting dimuat lebih awal dan script diberi defer.

Saat JavaScript mengubah lebar atau posisi elemen, browser mengulang layout dan paint (mahal). Mengubah transform dan opacity cukup mengulang composite (murah), itulah alasan animasi sebaiknya memakai keduanya.

Soal latihan

  1. Urutkan tahap rendering browser dan sebutkan properti CSS yang memicu layout ulang.

    Petunjuk

    DOM, CSSOM, render tree, layout, paint, composite. width/height/top memicu layout; transform/opacity hanya composite.

    Lihat jawaban
    CONTOH
    HTML → DOM, CSS → CSSOM → render tree → layout → paint → composite

Memicu layout ulang : width, height, top, left, margin, font-size
Hanya composite     : transform, opacity  (pakai ini untuk animasi)

  2. Perbaiki kode yang menyebabkan layout thrashing (membaca dan menulis ukuran bergantian di dalam loop).

    Petunjuk

    Baca semua ukuran dulu, baru tulis semuanya.

    Lihat jawaban
    JAVASCRIPT
    // buruk: baca-tulis bergantian
// for (const el of kotak) el.style.width = el.offsetWidth + 10 + "px";

// baik: baca semua, lalu tulis semua
const lebar = kotak.map(el => el.offsetWidth);
kotak.forEach((el, i) => { el.style.width = lebar[i] + 10 + "px"; });

Poin penting

  • HTML → DOM, CSS → CSSOM, lalu render tree.
  • Layout menghitung posisi, paint mewarnai, composite menyusun lapisan.
  • Ubah transform/opacity untuk animasi yang mulus.
