Tes end-to-end dengan Playwright

Buka versi interaktif

Tes end-to-end (E2E) menjalankan browser sungguhan dan meniru pengguna: membuka halaman, mengetik, mengklik, lalu memeriksa hasil. Tes ini paling lambat tapi paling meyakinkan, jadi tulis untuk alur terpenting saja, seperti login dan checkout.

Playwright mendukung Chromium, Firefox, dan WebKit sekaligus, serta menunggu elemen siap secara otomatis. Cypress adalah alternatif populer dengan antarmuka interaktif.

TYPESCRIPT
import { test, expect } from "@playwright/test";

test("pembeli bisa menambah produk ke keranjang", async ({ page }) => {
  await page.goto("https://tokonusantara.id");
  await page.getByRole("searchbox", { name: "Cari produk" }).fill("kopi");
  await page.getByRole("button", { name: "Tambah Kopi Gayo" }).click();
  await expect(page.getByText("1 barang di keranjang")).toBeVisible();
});
// $ npx playwright test
//   ✓ pembeli bisa menambah produk ke keranjang (1.2s)

Poin penting

  • Piramida tes: banyak unit, sedikit E2E.
  • Playwright: lintas browser, auto-wait.
  • Tulis E2E untuk alur paling penting.
