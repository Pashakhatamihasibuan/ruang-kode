XSS & risiko OWASP

Buka versi interaktif

OWASP Top 10 adalah daftar risiko keamanan web paling umum: kontrol akses yang rusak, kegagalan kriptografi, injeksi (SQL injection, XSS), desain tidak aman, konfigurasi salah, komponen usang, autentikasi lemah, dan lainnya.

Di frontend, risiko paling sering adalah XSS (cross-site scripting): input pengguna ditampilkan sebagai HTML sehingga script penyerang ikut berjalan. Lawannya: tampilkan input dengan textContent, bukan innerHTML, dan sanitasi HTML jika benar-benar perlu.

HTML
<label>Komentar: <input id="k" value="&lt;img src=x onerror=&quot;document.body.style.background='#B23A2E'&quot;&gt;"></label>
<button id="a">Tampilkan (innerHTML)</button> <button id="b">Tampilkan (textContent)</button>
<div id="out" style="margin-top:8px;padding:8px;border:1px solid #ddd"></div>
JAVASCRIPT
const out = document.getElementById("out"), k = document.getElementById("k");
document.getElementById("a").onclick = () => { out.innerHTML = k.value; };      // berbahaya
document.getElementById("b").onclick = () => { out.textContent = k.value; };    // aman

Poin penting

  • Kenali OWASP Top 10.
  • XSS terjadi saat input pengguna dirender sebagai HTML.
  • Pakai textContent; sanitasi bila harus menampilkan HTML.
  • React otomatis meng-escape teks di JSX.
