Linter & formatter

Buka versi interaktif

Formatter seperti Prettier merapikan gaya penulisan otomatis (spasi, tanda kutip, panjang baris), sehingga tim tidak berdebat soal gaya. Linter seperti ESLint mencari pola kode yang berpotensi bug, misalnya variabel tidak dipakai atau dependensi useEffect yang terlewat.

Biome menggabungkan keduanya dalam satu alat yang sangat cepat. Jalankan otomatis saat menyimpan file dan sebelum commit.

JSON
// package.json
{
  "scripts": {
    "lint": "eslint .",
    "format": "prettier --write ."
  }
}
// $ npm run lint
// src/App.jsx
//   12:9  warning  'total' is assigned a value but never used   no-unused-vars
//   20:6  warning  React Hook useEffect has a missing dependency: 'id'   react-hooks/exhaustive-deps

Poin penting

  • Formatter: gaya seragam otomatis.
  • Linter: deteksi pola rawan bug.
  • Biome menggabungkan keduanya.
