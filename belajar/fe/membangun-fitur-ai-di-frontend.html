Membangun fitur AI di frontend

Buka versi interaktif

Fitur AI di aplikasi (chatbot, ringkasan, pencarian semantik) memanggil API model dari penyedia seperti Anthropic, OpenAI, atau Google. Kunci API tidak boleh ada di kode frontend; panggil lewat server atau fungsi serverless milikmu.

Jawaban model dikirim bertahap (streaming) agar pengguna langsung melihat teks muncul, bukan menunggu jawaban utuh. Di frontend, baca stream dengan response.body.getReader().

JAVASCRIPT
// Frontend: membaca jawaban yang di-stream dari server kita sendiri
async function tanya(pertanyaan, tulis) {
  const res = await fetch("/api/tanya", { method: "POST", body: JSON.stringify({ pertanyaan }) });
  const reader = res.body.getReader();
  const dec = new TextDecoder();
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    tulis(dec.decode(value, { stream: true }));   // tampilkan potongan teks segera
  }
}
// Server (/api/tanya) yang memegang kunci API dan meneruskan stream dari penyedia model.

Poin penting

  • Kunci API selalu di server.
  • Streaming membuat jawaban terasa cepat.
  • Tampilkan status, tangani error, dan beri tahu bahwa jawaban bisa keliru.
