CSR, SSR & SSG

Buka versi interaktif

CSR (client-side rendering): server mengirim HTML hampir kosong, JavaScript membangun halaman di browser. Interaktif setelah JS dimuat, tapi tampilan pertama lebih lambat dan kurang ramah SEO.

SSR (server-side rendering): HTML dibuat di server untuk setiap permintaan, lalu JavaScript "menghidupkannya" (hydration). SSG (static site generation): HTML dibuat sekali saat build, sangat cepat dan murah.

Framework meta seperti Next.js (React), Nuxt (Vue), SvelteKit, dan Astro bisa mencampur ketiganya per halaman. Situs dokumentasi atau blog cocok dengan SSG; dashboard pribadi cocok dengan CSR; toko online cocok dengan SSR/SSG campuran.

Poin penting

  • CSR: dirender di browser.
  • SSR: dirender di server per permintaan.
  • SSG: dirender saat build.
  • Framework meta mencampur per halaman.
