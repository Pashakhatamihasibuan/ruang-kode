Frontend · Modul 13 · Proyek akhir

Dashboard cuaca & kualitas udara

Buka versi interaktif

Bangun aplikasi yang menampilkan cuaca dan kualitas udara beberapa kota Indonesia dari API publik, lengkap dengan pencarian, favorit, mode gelap, dan dukungan offline sederhana.

Teknologi: React + Vite + TypeScript

Fitur yang dibuat

  • Proyek Vite + React + TypeScript dengan ESLint dan Prettier
  • Pencarian kota dengan debounce dan keadaan loading/error
  • Data diambil dengan TanStack Query (cache dan retry)
  • Kota favorit tersimpan di localStorage
  • Mode gelap dengan variabel CSS dan prefers-color-scheme
  • Skor Lighthouse performa dan aksesibilitas minimal 90
  • Minimal 3 unit test (Vitest) dan 1 tes E2E (Playwright)
  • Kunci API (jika ada) tidak bocor ke kode frontend
  • Terbit di Vercel/Netlify dengan deploy otomatis dari GitHub

Langkah kerja

  1. Rancang tampilan di kertas atau Figma.
  2. Bangun komponen dengan data tiruan.
  3. Sambungkan API dan tangani semua keadaan.
  4. Ukur dengan Lighthouse, tulis tes, lalu terbitkan.
src/hooks/useCuaca.ts
import { useQuery } from "@tanstack/react-query";

export type Cuaca = { kota: string; suhu: number; kondisi: string };

export function useCuaca(lat: number, lon: number) {
  return useQuery({
    queryKey: ["cuaca", lat, lon],
    queryFn: async (): Promise<Cuaca> => {
      const url = `https://api.open-meteo.com/v1/forecast?latitude=${lat}&longitude=${lon}&current=temperature_2m,weather_code`;
      const res = await fetch(url);
      if (!res.ok) throw new Error("Gagal memuat cuaca");
      const j = await res.json();
      return { kota: `${lat},${lon}`, suhu: j.current.temperature_2m, kondisi: String(j.current.weather_code) };
    },
    staleTime: 10 * 60 * 1000,
  });
}
