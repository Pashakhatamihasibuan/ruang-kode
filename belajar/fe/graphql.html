GraphQL

Buka versi interaktif

Di REST, setiap sumber data punya alamat sendiri (/produk, /produk/1/ulasan). Di GraphQL, ada satu endpoint dan klien menulis query yang menyebut persis kolom yang dibutuhkan. Tidak ada data berlebih, dan data bertingkat diambil sekali jalan.

Klien seperti Apollo dan Relay mengelola cache hasil query di frontend.

CONTOH
# query dari klien
query {
  produk(id: 1) {
    nama
    harga
    ulasan(terbaru: 2) { bintang komentar }
  }
}

# respons server: bentuknya sama dengan query
{ "data": { "produk": { "nama": "Kopi Gayo", "harga": 85000,
  "ulasan": [ { "bintang": 5, "komentar": "Wangi!" }, { "bintang": 4, "komentar": "Mantap" } ] } } }

Poin penting

  • Satu endpoint, klien menentukan bentuk data.
  • Tidak ada over-fetching.
  • Apollo/Relay mengelola cache.
