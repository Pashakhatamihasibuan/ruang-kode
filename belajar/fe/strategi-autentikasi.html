Strategi autentikasi

Buka versi interaktif

Session cookie: server menyimpan sesi dan browser menyimpan id-nya di cookie HttpOnly; Secure; SameSite yang tidak bisa dibaca JavaScript. Cara paling aman untuk aplikasi web biasa.

Token (JWT): server memberi token bertanda tangan yang dikirim di header Authorization. Cocok untuk API dan aplikasi mobile, tapi jangan simpan di localStorage jika situs rentan XSS. OAuth / OpenID Connect untuk "Masuk dengan Google". Passkey menggantikan kata sandi dengan kunci di perangkat.

CONTOH
# Login berhasil, server mengirim cookie sesi:
Set-Cookie: sid=8f2c1e...; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=86400

# Permintaan berikutnya otomatis membawa cookie:
GET /akun
Cookie: sid=8f2c1e...

# Alternatif token untuk API:
GET /api/pesanan
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...

Poin penting

  • Cookie HttpOnly + Secure + SameSite untuk sesi web.
  • JWT untuk API/mobile; hati-hati tempat penyimpanannya.
  • OAuth/OIDC untuk login pihak ketiga.
  • Passkey: tanpa kata sandi.
