Web API: storage, observer & lainnya

Buka versi interaktif

Browser menyediakan banyak Web API: localStorage menyimpan data kecil yang bertahan setelah browser ditutup, IntersectionObserver memberi tahu saat elemen masuk layar (untuk lazy load atau animasi muncul), Clipboard, Geolocation, Notification, dan lainnya.

Selalu periksa ketersediaan API dan bungkus akses storage dengan try/catch, karena bisa ditolak di mode privat.

HTML
<p>Kunjungan ke pratinjau ini: <b id="n">?</b></p>
<div style="height:220px;overflow:auto;border:1px solid #ddd" id="area">
  <div style="height:300px"></div>
  <p id="target" class="kotak">Saya muncul saat terlihat</p>
  <div style="height:60px"></div>
</div>
CSS
body{font:14px system-ui,sans-serif}.kotak{opacity:0;transform:translateY(20px);transition:all .5s;background:#E9EFF5;padding:10px;border-radius:8px}.kotak.tampak{opacity:1;transform:none}
JAVASCRIPT
try {
  const n = Number(localStorage.getItem("kunjungan") || 0) + 1;
  localStorage.setItem("kunjungan", n);
  document.getElementById("n").textContent = n;
} catch (e) { document.getElementById("n").textContent = "storage tidak tersedia"; }

const io = new IntersectionObserver(es => es.forEach(en => {
  if (en.isIntersecting) en.target.classList.add("tampak");
}), { root: document.getElementById("area") });
io.observe(document.getElementById("target"));

Tantangan

  1. Gulir kotak di pratinjau sampai teks "Saya muncul saat terlihat" tampak.

Kode pemula vs kode rapi

Salin objek bersarang dengan structuredClone

Spread hanya menyalin lapisan teratas, sehingga objek di dalamnya masih dipakai bersama. structuredClone (bawaan browser dan Node 17+) menyalin seluruh isi, termasuk tanggal dan Map.

KODE PEMULA
const asli = { nama: "Sari", alamat: { kota: "Medan" } };
const salinan = { ...asli };
salinan.alamat.kota = "Bandung";
console.log(asli.alamat.kota);
KODE RAPI (BEST PRACTICE)
const asli = { nama: "Sari", alamat: { kota: "Medan" } };
const salinan = structuredClone(asli);
salinan.alamat.kota = "Bandung";
console.log(asli.alamat.kota);

Poin penting

  • localStorage untuk data kecil yang bertahan.
  • IntersectionObserver untuk mendeteksi elemen terlihat.
  • Bungkus akses storage dengan try/catch.
