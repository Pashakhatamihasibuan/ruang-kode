Bundler & Vite

Buka versi interaktif

Kode modern terdiri dari ratusan modul, JSX, dan TypeScript yang tidak bisa langsung dijalankan browser lama. Bundler menggabungkan dan mengoptimasi semuanya: menghapus kode yang tidak dipakai (tree shaking), memecah file (code splitting), dan mengecilkan ukuran (minify).

Vite kini menjadi pilihan utama: saat pengembangan ia menyajikan modul ES langsung sehingga sangat cepat, dan saat build ia memakai Rollup (atau Rolldown). esbuild dan SWC adalah kompiler super cepat yang ditulis dengan Go dan Rust.

Selain npm, ada pnpm (hemat ruang disk), Yarn, dan Bun (runtime sekaligus package manager yang sangat cepat).

JAVASCRIPT
// vite.config.js
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";

export default defineConfig({
  plugins: [react()],
  build: {
    sourcemap: true,
    rollupOptions: { output: { manualChunks: { react: ["react", "react-dom"] } } },
  },
});
// $ npm run build
// dist/assets/react-8f2c.js   142 kB │ gzip: 45 kB
// dist/assets/index-1b7d.js    18 kB │ gzip:  6 kB

Poin penting

  • Bundler: gabung, tree shaking, code splitting, minify.
  • Vite cepat saat dev, Rollup/Rolldown saat build.
  • esbuild dan SWC adalah kompiler cepat.
  • pnpm, Yarn, Bun alternatif npm.
