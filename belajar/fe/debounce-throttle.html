Debounce & throttle

Buka versi interaktif

Event seperti input, scroll, dan resize bisa terpicu puluhan kali per detik. Kalau setiap event memanggil API pencarian, server kebanjiran dan hasilnya datang tidak berurutan.

Debounce menunggu sampai event berhenti selama jeda tertentu, lalu menjalankan fungsi sekali. Cocok untuk kotak pencarian: kirim permintaan 300 ms setelah pengguna berhenti mengetik. Throttle menjalankan fungsi paling banyak sekali per selang waktu, cocok untuk scroll atau menyimpan posisi.

Contoh di bawah mensimulasikan 5 ketukan cepat lalu jeda. Debounce hanya mencari sekali dengan kata terakhir.

JAVASCRIPT
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}

const panggilan = [];
const cari = debounce((kata) => {
  panggilan.push(kata);
  console.log("cari ke server:", kata);
}, 300);

["k", "ko", "kop", "kopi", "kopi g"].forEach((kata, i) => setTimeout(() => cari(kata), i * 50));
setTimeout(() => console.log("jumlah panggilan:", panggilan.length), 700);
KELUARAN
cari ke server: kopi g
jumlah panggilan: 1

Poin penting

  • Debounce: jalankan sekali setelah event berhenti.
  • Throttle: paling banyak sekali per selang waktu.
  • Pencarian: debounce ±300 ms.
  • Scroll/resize: throttle atau requestAnimationFrame.
