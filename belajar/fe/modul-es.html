Modul ES

Buka versi interaktif

Kode besar dipecah menjadi modul: satu file satu tanggung jawab. export membagikan fungsi atau nilai, import memakainya. Ada named export (bisa banyak) dan default export (satu per file).

Di browser, pakai <script type="module">. Modul otomatis memakai mode ketat dan bersifat defer. import() dinamis memuat modul hanya saat dibutuhkan, cara dasar code splitting.

JAVASCRIPT
// format.js
export const rupiah = n => "Rp" + n.toLocaleString("id-ID");
export default function judul(s) { return s[0].toUpperCase() + s.slice(1); }

// main.js
import judul, { rupiah } from "./format.js";
console.log(judul("kopi"), rupiah(85000));   // Kopi Rp85.000

// muat grafik hanya saat tombol diklik
document.querySelector("#lihat").onclick = async () => {
  const { gambarGrafik } = await import("./grafik.js");
  gambarGrafik();
};

Poin penting

  • export/import untuk membagi kode.
  • Named export banyak, default export satu.
  • type="module" di browser.
  • import() dinamis untuk memuat saat perlu.

Cek pemahaman

Sintaks memakai named export rupiah?

Jawaban: import { rupiah } from "./format.js"

Named export memakai kurung kurawal.
