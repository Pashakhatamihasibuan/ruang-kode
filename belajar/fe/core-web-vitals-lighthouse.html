Core Web Vitals & Lighthouse

Buka versi interaktif

Google mengukur pengalaman pengguna dengan Core Web Vitals: LCP (Largest Contentful Paint, kapan konten utama tampil, target di bawah 2,5 detik), INP (Interaction to Next Paint, seberapa cepat halaman merespons klik, di bawah 200 ms), dan CLS (Cumulative Layout Shift, seberapa banyak tata letak melompat, di bawah 0,1).

Lighthouse di Chrome DevTools mengaudit performa, aksesibilitas, SEO, dan praktik terbaik, lalu memberi saran konkret. Tab Network dan Performance di DevTools menunjukkan file mana yang lambat.

Cara cepat memperbaiki: kompres gambar (WebP/AVIF) dan beri ukuran, lazy load gambar di bawah, kurangi JavaScript, pakai code splitting, dan muat font dengan font-display: swap.

Poin penting

  • LCP < 2,5 s, INP < 200 ms, CLS < 0,1.
  • Lighthouse memberi skor dan saran.
  • Gambar dan JavaScript adalah penyebab paling umum situs lambat.
