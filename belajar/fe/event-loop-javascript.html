Event loop JavaScript

Buka versi interaktif

JavaScript di browser berjalan di satu thread. Agar halaman tidak membeku saat menunggu jaringan atau timer, pekerjaan yang menunggu diserahkan ke browser, lalu callback-nya diantrekan.

Ada dua antrean: microtask (Promise, await) dan macrotask (setTimeout, event klik). Setelah kode sinkron selesai, semua microtask dijalankan dulu, baru satu macrotask, dan seterusnya. Tebak urutan keluaran sebelum menjalankan.

Promise.resolve().then(() => console.log("3. promise (microtask)"));
console.log("2. selesai kode sinkron");

Kode pemula vs kode rapi

Jalankan permintaan bersamaan dengan Promise.all

Tiga await berturut-turut menunggu satu per satu. Kalau permintaannya tidak saling bergantung, Promise.all menjalankannya bersamaan, sehingga waktu tunggunya hanya selama permintaan terlama.

KODE PEMULA
const tunda = (ms, v) => new Promise((r) => setTimeout(() => r(v), ms));
(async () => {
  const mulai = Date.now();
  const produk = await tunda(300, "produk");
  const ulasan = await tunda(300, "ulasan");
  const stok = await tunda(300, "stok");
  console.log(produk, ulasan, stok);
  console.log("±" + Math.round((Date.now() - mulai) / 100) * 100 + " ms");
})();
KODE RAPI (BEST PRACTICE)
const tunda = (ms, v) => new Promise((r) => setTimeout(() => r(v), ms));
(async () => {
  const mulai = Date.now();
  const [produk, ulasan, stok] = await Promise.all([
    tunda(300, "produk"), tunda(300, "ulasan"), tunda(300, "stok"),
  ]);
  console.log(produk, ulasan, stok);
  console.log("±" + Math.round((Date.now() - mulai) / 100) * 100 + " ms");
})();

Poin penting

  • Satu thread, tidak memblokir lewat antrean callback.
  • Urutan: sinkron, semua microtask, lalu macrotask.
  • setTimeout 0 tetap menunggu kode sinkron dan microtask.
