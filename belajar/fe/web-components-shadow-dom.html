Web Components & Shadow DOM

Buka versi interaktif

Web Components adalah komponen bawaan browser tanpa framework. Custom element mendefinisikan tag sendiri seperti <kartu-produk>. Shadow DOM membungkus HTML dan CSS-nya sehingga tidak bocor ke luar dan tidak terganggu gaya luar. <template> menyimpan potongan HTML yang belum dirender.

Web Components bisa dipakai di React, Vue, atau HTML biasa, cocok untuk design system lintas framework.

HTML
<kartu-produk nama="Kopi Gayo" harga="85000"></kartu-produk>
<kartu-produk nama="Teh Melati" harga="25000"></kartu-produk>
<p class="kartu">Paragraf luar dengan class kartu tidak terpengaruh gaya di dalam komponen.</p>
JAVASCRIPT
class KartuProduk extends HTMLElement {
  connectedCallback() {
    const root = this.attachShadow({ mode: "open" });
    const harga = Number(this.getAttribute("harga")).toLocaleString("id-ID");
    root.innerHTML = `
      <style>.kartu{border:1px solid #2E5E8C;border-radius:10px;padding:8px 12px;margin:6px 0;font:14px sans-serif}
             b{color:#2E5E8C}</style>
      <div class="kartu"><b>${this.getAttribute("nama")}</b> · Rp${harga}</div>`;
  }
}
customElements.define("kartu-produk", KartuProduk);

Tantangan

  1. Tambahkan satu <kartu-produk> lagi untuk "Madu Hutan" seharga 120000.

Poin penting

  • customElements.define membuat tag baru (wajib ada tanda hubung).
  • Shadow DOM mengisolasi HTML dan CSS.
  • Bisa dipakai di framework mana pun.
