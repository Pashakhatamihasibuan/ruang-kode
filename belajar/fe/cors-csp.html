CORS & CSP

Buka versi interaktif

Browser menerapkan same-origin policy: JavaScript dari tokonusantara.id tidak boleh membaca respons dari api.lain.com kecuali server itu mengizinkan lewat header CORS (Access-Control-Allow-Origin). Error CORS diperbaiki di server, bukan di frontend.

Content Security Policy membatasi sumber script, gaya, dan gambar. Jika penyerang berhasil menyisipkan <script> lewat komentar, CSP yang ketat mencegahnya berjalan.

CONTOH
# Browser (dari https://tokonusantara.id) meminta:
GET https://api.tokonusantara.id/produk
Origin: https://tokonusantara.id

# Server mengizinkan:
Access-Control-Allow-Origin: https://tokonusantara.id
Content-Security-Policy: default-src 'self'; script-src 'self'; img-src 'self' https://cdn.tokonusantara.id

Poin penting

  • Same-origin policy membatasi baca lintas domain.
  • CORS diatur di server lewat header.
  • CSP membatasi sumber script dan konten.
