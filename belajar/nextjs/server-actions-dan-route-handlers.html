Server Actions dan Route Handlers

Buka versi interaktif

Server Action adalah fungsi async bertanda 'use server' yang bisa dipanggil langsung dari form. Tidak perlu membuat endpoint API sendiri: form mengirim data, fungsi berjalan di server, lalu panggil revalidatePath atau redirect. Form tetap bekerja walau JavaScript belum termuat.

Server Action adalah endpoint publik: selalu validasi input (misalnya dengan Zod) dan periksa izin pengguna di dalamnya. Di sisi client, useActionState menampilkan pesan error dan status menunggu.

Route Handler (app/api/.../route.ts) dipakai jika butuh endpoint HTTP biasa: webhook payment gateway, API untuk aplikasi mobile, atau integrasi pihak ketiga.

TYPESCRIPT
// app/ulasan/actions.ts
'use server';
import { z } from 'zod';
import { revalidatePath } from 'next/cache';

const Skema = z.object({
  slug: z.string(),
  rating: z.coerce.number().int().min(1).max(5),
  komentar: z.string().min(5, 'Komentar minimal 5 karakter'),
});

export async function kirimUlasan(_: unknown, form: FormData) {
  const hasil = Skema.safeParse(Object.fromEntries(form));
  if (!hasil.success) return { error: hasil.error.issues[0].message };
  await db.ulasan.create({ data: hasil.data });
  revalidatePath(`/produk/${hasil.data.slug}`);
  return { error: null };
}

// app/api/webhook/pembayaran/route.ts
export async function POST(req: Request) {
  const body = await req.json();
  // verifikasi tanda tangan webhook dulu!
  await tandaiLunas(body.order_id);
  return Response.json({ ok: true });
}

Soal latihan

  1. Buat form di Client Component yang memakai useActionState dengan action kirimUlasan dan menampilkan pesan error.

    Petunjuk

    useActionState(action, stateAwal) mengembalikan [state, formAction, pending].

    Lihat jawaban
    KODE
    'use client';
import { useActionState } from 'react';
import { kirimUlasan } from './actions';

export default function FormUlasan({ slug }: { slug: string }) {
  const [state, action, pending] = useActionState(kirimUlasan, { error: null });
  return (
    <form action={action}>
      <input type="hidden" name="slug" value={slug} />
      <input name="rating" type="number" min={1} max={5} required />
      <textarea name="komentar" />
      {state.error && <p role="alert">{state.error}</p>}
      <button disabled={pending}>{pending ? 'Mengirim…' : 'Kirim ulasan'}</button>
    </form>
  );
}

Poin penting

  • 'use server' untuk fungsi yang dipanggil dari form.
  • Validasi input dan cek izin di setiap Server Action.
  • Route Handler untuk webhook dan API publik.
