Next.js · Modul 4 · Konsep & kode

Optimasi gambar dan font

Buka versi interaktif

next/image otomatis mengubah ukuran gambar sesuai layar, mengirim format modern (WebP, AVIF), memuat malas (lazy) gambar di bawah layar, dan mencegah tata letak bergeser karena lebar dan tinggi sudah diketahui. Beri priority untuk gambar utama di atas layar agar LCP cepat.

next/font mengunduh font Google saat build dan menyajikannya dari domain sendiri: tidak ada permintaan ke server Google saat halaman dibuka dan tidak ada teks berkedip.

Kedua fitur ini langsung memperbaiki skor Core Web Vitals (LCP, CLS, INP) yang memengaruhi peringkat pencarian.

KODE
import Image from 'next/image';
import { Plus_Jakarta_Sans } from 'next/font/google';

const font = Plus_Jakarta_Sans({ subsets: ['latin'], weight: ['400', '700'] });

export default function Hero() {
  return (
    <section className={font.className}>
      <Image
        src="/kopi-gayo.jpg"
        alt="Biji kopi Gayo dalam karung goni"
        width={1200}
        height={630}
        sizes="(max-width: 768px) 100vw, 50vw"
        priority
      />
      <h1>Kopi Nusantara, dipanggang setiap minggu</h1>
    </section>
  );
}

Poin penting

  • next/image: ukuran, format, lazy, tanpa CLS.
  • priority untuk gambar utama.
  • next/font: font disajikan sendiri.
