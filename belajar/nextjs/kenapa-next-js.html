Kenapa Next.js

Buka versi interaktif

Next.js adalah framework React dari Vercel untuk membangun aplikasi web lengkap. React sendiri hanya pustaka UI; Next.js menambahkan routing berbasis folder, rendering di server (SSR dan statis) yang bagus untuk SEO dan kecepatan, pengambilan data, optimasi gambar dan font, serta API di proyek yang sama.

Next.js modern memakai App Router (folder app/) dengan React Server Components: komponen berjalan di server secara bawaan, sehingga JavaScript yang dikirim ke browser lebih sedikit. Pages Router (folder pages/) masih ada di proyek lama.

Prasyarat: HTML, CSS, JavaScript modern, dan dasar React (komponen, props, state). Selesaikan jalur React dan TypeScript di Ruang Kode jika belum.
