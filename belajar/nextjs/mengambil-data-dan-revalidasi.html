Next.js · Modul 3 · Konsep & kode

Mengambil data dan revalidasi

Buka versi interaktif

Di Server Component, ambil data langsung dengan await fetch() atau query database. Tidak perlu useEffect, dan rahasia API tetap di server.

Atur kesegaran data: fetch(url, { next: { revalidate: 60 } }) menyimpan hasil dan memperbaruinya paling lama setiap 60 detik (ISR); { cache: 'no-store' } selalu mengambil data baru; { next: { tags: ['produk'] } } memberi label agar bisa dihapus dengan revalidateTag('produk') setelah data berubah.

Jalankan beberapa permintaan secara paralel dengan Promise.all agar tidak saling menunggu.

KODE
// app/page.tsx
type Produk = { id: number; nama: string; harga: number };

async function ambilProduk(): Promise<Produk[]> {
  const r = await fetch('https://api.tokoku.id/produk', {
    next: { revalidate: 60, tags: ['produk'] },
  });
  if (!r.ok) throw new Error('Gagal memuat produk');
  return r.json();
}

async function ambilPromo() {
  const r = await fetch('https://api.tokoku.id/promo', { cache: 'no-store' });
  return r.json();
}

export default async function Beranda() {
  const [produk, promo] = await Promise.all([ambilProduk(), ambilPromo()]);
  return (
    <main>
      <p className="bg-amber-100 p-2">{promo.teks}</p>
      <ul>{produk.map((p) => <li key={p.id}>{p.nama}: Rp{p.harga.toLocaleString('id-ID')}</li>)}</ul>
    </main>
  );
}

Poin penting

  • await fetch langsung di Server Component.
  • revalidate, no-store, dan tag.
  • Promise.all untuk permintaan paralel.
