Route dinamis dan metadata

Buka versi interaktif

Folder dengan kurung siku seperti app/produk/[slug]/page.tsx menangkap bagian URL apa pun: /produk/kopi-gayo memberi params.slug = 'kopi-gayo'. Di Next.js 15, params adalah Promise sehingga perlu di-await.

generateStaticParams membuat halaman statis untuk daftar slug saat build, sehingga halaman produk populer siap seketika. Panggil notFound() jika data tidak ada.

Untuk SEO, ekspor generateMetadata agar setiap halaman punya judul, deskripsi, dan gambar Open Graph sendiri.

KODE
// app/produk/[slug]/page.tsx
import { notFound } from 'next/navigation';
import { ambilProduk, semuaSlug } from '@/lib/produk';

export async function generateStaticParams() {
  return (await semuaSlug()).map((slug) => ({ slug }));
}

export async function generateMetadata({ params }: { params: Promise<{ slug: string }> }) {
  const p = await ambilProduk((await params).slug);
  return { title: p ? `${p.nama} | Tokoku` : 'Tidak ditemukan' };
}

export default async function DetailProduk({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  const p = await ambilProduk(slug);
  if (!p) notFound();
  return (
    <main className="p-4">
      <h1 className="text-2xl font-bold">{p.nama}</h1>
      <p>Rp{p.harga.toLocaleString('id-ID')}</p>
    </main>
  );
}

Soal latihan

  1. Buat halaman app/kategori/[nama]/page.tsx yang menampilkan judul "Kategori: {nama}".

    Petunjuk

    Ambil nama dari params yang di-await.

    Lihat jawaban
    KODE
    export default async function Kategori({ params }: { params: Promise<{ nama: string }> }) {
  const { nama } = await params;
  return <h1>Kategori: {decodeURIComponent(nama)}</h1>;
}

Poin penting

  • [slug] = segmen dinamis.
  • params di-await di Next.js 15.
  • generateStaticParams dan generateMetadata.
