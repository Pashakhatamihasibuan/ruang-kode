Streaming dengan loading dan Suspense

Buka versi interaktif

Jika satu bagian halaman lambat (misalnya rekomendasi produk), jangan biarkan seluruh halaman menunggu. Bungkus bagian itu dengan <Suspense fallback={...}>: bagian cepat tampil dulu, bagian lambat dialirkan (streaming) begitu siap.

File loading.tsx otomatis menjadi fallback Suspense untuk seluruh halaman di folder itu. Gunakan skeleton yang menyerupai bentuk konten agar tata letak tidak meloncat.

Hasilnya waktu tampil pertama lebih cepat, sesuatu yang terasa jelas pada koneksi seluler yang lambat.

KODE
// app/produk/[slug]/page.tsx
import { Suspense } from 'react';

export default async function Detail({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  const p = await ambilProduk(slug);           // cepat
  return (
    <main>
      <h1>{p.nama}</h1>
      <Suspense fallback={<div className="h-40 animate-pulse rounded bg-gray-200" />}>
        <Rekomendasi slug={slug} />            {/* lambat, dialirkan belakangan */}
      </Suspense>
    </main>
  );
}

async function Rekomendasi({ slug }: { slug: string }) {
  const daftar = await ambilRekomendasi(slug);  // 2 detik
  return <ul>{daftar.map((r) => <li key={r.id}>{r.nama}</li>)}</ul>;
}

Poin penting

  • Suspense membuat bagian lambat tidak menahan halaman.
  • loading.tsx = fallback untuk satu folder.
  • Skeleton menjaga tata letak stabil.
