Next.js · Modul 2 · Konsep & kode

Pola komposisi dan batas client

Buka versi interaktif

Begitu file diberi 'use client', semua yang di-import oleh file itu ikut menjadi kode client. Karena itu letakkan 'use client' sedalam mungkin di pohon komponen.

Server Component tetap bisa dirender di dalam Client Component jika dikirim sebagai children atau prop. Contoh: penyedia tema (Client) membungkus halaman (Server).

Props dari server ke client harus bisa diserialisasi (string, angka, objek biasa, array). Fungsi biasa tidak bisa dikirim, kecuali Server Action.

KODE
// app/providers.tsx
'use client';
import { ThemeProvider } from 'next-themes';
export function Providers({ children }: { children: React.ReactNode }) {
  return <ThemeProvider attribute="class">{children}</ThemeProvider>;
}

// app/layout.tsx (Server)
import { Providers } from './providers';
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="id" suppressHydrationWarning>
      <body><Providers>{children}</Providers></body>   {/* children tetap Server Component */}
    </html>
  );
}

Poin penting

  • 'use client' sedalam mungkin.
  • Server Component boleh jadi children dari Client Component.
  • Props harus bisa diserialisasi.
