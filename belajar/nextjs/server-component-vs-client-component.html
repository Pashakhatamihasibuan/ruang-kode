Server Component vs Client Component

Buka versi interaktif

Di App Router, semua komponen adalah Server Component secara bawaan: dijalankan di server, boleh async, bisa langsung membaca database atau rahasia API, dan kodenya tidak dikirim ke browser.

Tambahkan 'use client' di baris pertama file untuk membuat Client Component jika butuh interaktivitas: useState, useEffect, event seperti onClick, atau API browser seperti localStorage.

Prinsipnya: biarkan sebanyak mungkin di server, dan jadikan Client Component hanya "pulau" kecil yang interaktif, misalnya tombol tambah ke keranjang di dalam halaman produk yang dirender server.

Kapan memakai yang mana
KebutuhanServerClient
Ambil data dari database atau API rahasiaYaTidak
useState, useEffectTidakYa
onClick, onChangeTidakYa
localStorage, windowTidakYa
Mengurangi JS di browserYaTidak
async/await langsung di komponenYaTidak
KODE
// components/TombolKeranjang.tsx
'use client';
import { useState } from 'react';

export default function TombolKeranjang({ nama }: { nama: string }) {
  const [jumlah, setJumlah] = useState(0);
  return (
    <button onClick={() => setJumlah(jumlah + 1)} className="rounded bg-amber-700 px-4 py-2 text-white">
      Tambah {nama} ({jumlah})
    </button>
  );
}

// app/produk/[slug]/page.tsx  (Server Component)
import TombolKeranjang from '@/components/TombolKeranjang';
export default async function Detail() {
  const p = await db.produk.findFirst();   // langsung ke database, aman
  return (
    <main>
      <h1>{p.nama}</h1>
      <TombolKeranjang nama={p.nama} />
    </main>
  );
}

Poin penting

  • Bawaan: Server Component.
  • 'use client' untuk state, event, API browser.
  • Jadikan Client Component sekecil mungkin.
