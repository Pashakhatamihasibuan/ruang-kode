App Router: page, layout, dan link

Buka versi interaktif

Di App Router, folder adalah rute. File page.tsx membuat rute bisa dibuka; app/produk/page.tsx menjadi /produk. File layout.tsx membungkus halaman di folder itu dan turunannya, dan tidak di-render ulang saat berpindah halaman, cocok untuk navbar dan sidebar.

File khusus lain: loading.tsx (tampilan saat memuat), error.tsx (penanganan error), not-found.tsx (404). Folder dalam kurung seperti (toko) mengelompokkan rute tanpa memengaruhi URL.

Pindah halaman dengan komponen <Link href="/produk"> (tanpa memuat ulang halaman dan otomatis prefetch). Untuk navigasi lewat kode, pakai useRouter() dari next/navigation di Client Component.

File khusus App Router
FileFungsi
page.tsxIsi halaman, membuat rute bisa diakses
layout.tsxKerangka bersama, tetap saat navigasi
loading.tsxUI saat memuat (Suspense)
error.tsxUI saat error, harus Client Component
not-found.tsxHalaman 404
route.tsAPI endpoint (Route Handler)
KODE
// app/layout.tsx
import Link from 'next/link';
import './globals.css';

export const metadata = { title: 'Tokoku', description: 'Kopi Nusantara' };

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="id">
      <body>
        <nav className="flex gap-4 p-4">
          <Link href="/">Beranda</Link>
          <Link href="/produk">Produk</Link>
        </nav>
        {children}
      </body>
    </html>
  );
}

// app/produk/page.tsx  ->  /produk
export default function HalamanProduk() {
  return <h1 className="text-2xl font-bold">Semua produk</h1>;
}

Poin penting

  • Folder = rute, page.tsx = halaman.
  • layout.tsx membungkus dan tidak di-render ulang.
  • Link untuk navigasi tanpa reload.
