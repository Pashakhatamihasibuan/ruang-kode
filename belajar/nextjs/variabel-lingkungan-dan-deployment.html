Variabel lingkungan dan deployment

Buka versi interaktif

Simpan rahasia di .env.local (tidak masuk Git). Variabel biasa hanya terbaca di server. Variabel berawalan NEXT_PUBLIC_ ikut dikirim ke browser, jadi jangan pernah memberi awalan itu pada kunci rahasia.

Deploy paling mudah ke Vercel: hubungkan repositori GitHub, setiap push ke main otomatis rilis, dan setiap pull request mendapat URL pratinjau. Alternatif: Netlify, Cloudflare, atau server sendiri dengan output: 'standalone' dan Docker.

Sebelum rilis jalankan npm run build secara lokal untuk melihat ukuran setiap rute dan mana yang statis atau dinamis.

TERMINAL
# .env.local
DATABASE_URL=postgres://...
AUTH_SECRET=rahasia-panjang
NEXT_PUBLIC_SITE_URL=https://tokoku.id

$ npm run build

Poin penting

  • NEXT_PUBLIC_ = terlihat di browser.
  • Vercel: push otomatis rilis, PR dapat pratinjau.
  • npm run build menunjukkan rute statis dan dinamis.
