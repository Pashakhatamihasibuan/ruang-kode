Hydration dan kesalahan umum

Buka versi interaktif

Hydration adalah proses React di browser "menghidupkan" HTML dari server dengan menempelkan event handler. Jika HTML dari server berbeda dengan render pertama di client, muncul hydration mismatch.

Penyebab umum: memakai Date.now() atau Math.random() saat render, membaca window atau localStorage langsung di render, dan format tanggal yang bergantung zona waktu browser.

Solusi: baca nilai browser di useEffect, kirim nilai yang sama dari server, atau muat komponen khusus browser dengan dynamic(() => import(...), { ssr: false }).

KODE
'use client';
import { useEffect, useState } from 'react';

// salah: server dan browser bisa berbeda
// return <p>{localStorage.getItem('nama')}</p>;

export default function Sapaan() {
  const [nama, setNama] = useState<string | null>(null);
  useEffect(() => {
    setNama(localStorage.getItem('nama'));
  }, []);
  return <p>Halo, {nama ?? 'tamu'}</p>;
}
KELUARAN
Error: Hydration failed because the server rendered HTML didn't match the client.
  + Halo, Rina
  - Halo, tamu

Poin penting

  • Hydration menempelkan interaksi ke HTML server.
  • Hindari nilai acak, waktu, dan window saat render.
  • Baca API browser di useEffect.
