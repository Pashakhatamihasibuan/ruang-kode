Remote, push & pull

Buka versi interaktif

Remote adalah salinan repositori di server, biasanya diberi nama origin. Hubungkan dengan git remote add origin URL, lalu kirim commit dengan git push -u origin main (flag -u cukup sekali).

git fetch mengunduh commit baru dari remote tanpa mengubah cabangmu. git pull = fetch + merge. Biasakan pull sebelum mulai bekerja.

git clone URL mengunduh repositori lengkap beserta riwayatnya. Untuk autentikasi, GitHub memakai kunci SSH atau token, bukan kata sandi akun.

TERMINAL
$ git remote add origin git@github.com:sariw/toko-nusantara.git
$ git push -u origin main
Enumerating objects: 9, done.
To github.com:sariw/toko-nusantara.git
 * [new branch]      main -> main
branch 'main' set up to track 'origin/main'.

$ git pull
Updating c4e8b21..e02f7aa
Fast-forward
 README.md | 12 ++++++++++++

$ git clone https://github.com/sariw/toko-nusantara.git

Kode pemula vs kode rapi

Push paksa yang tidak menimpa kerja teman

--force menimpa remote tanpa melihat, sehingga commit teman yang baru di-push bisa hilang. --force-with-lease menolak push kalau remote sudah berubah sejak terakhir kamu ambil.

KODE PEMULA
git push --force
KODE RAPI (BEST PRACTICE)
git push --force-with-lease

Poin penting

  • origin = nama remote default.
  • push mengirim, fetch mengunduh, pull = fetch + merge.
  • clone untuk salinan baru.
  • Pakai SSH key atau token.
