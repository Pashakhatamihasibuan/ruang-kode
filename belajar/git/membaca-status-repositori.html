Membaca status repositori

Buka versi interaktif

Setiap berkas di repositori berada di salah satu dari tiga tempat: working directory (berkas yang kamu edit), staging area (perubahan yang sudah dipilih untuk commit berikutnya), dan repositori (riwayat commit di folder .git).

git status adalah perintah yang paling sering dipakai. Ia memberi tahu cabang aktif, berkas yang berubah, dan berkas yang belum dilacak, sekaligus menyarankan perintah berikutnya.

Biasakan menjalankan git status sebelum dan sesudah setiap perintah. Kebiasaan ini mencegah sebagian besar kesalahan pemula.

TERMINAL
$ git status
On branch main
Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
        modified:   index.html

Changes not staged for commit:
  (use "git add <file>..." to update what will be committed)
        modified:   gaya.css

Untracked files:
  (use "git add <file>..." to include in what will be committed)
        logo.svg

Poin penting

  • Tiga tempat: working directory, staging area, repositori.
  • git status menunjukkan posisi setiap berkas.
  • Untracked = berkas baru yang belum pernah di-add.

Cek pemahaman

Dari keluaran di atas, berkas mana yang akan masuk commit berikutnya?

Jawaban: index.html

Hanya berkas di "Changes to be committed" yang ikut.

logo.svg berstatus?

Jawaban: Untracked, belum pernah dilacak

Perlu git add agar mulai dilacak.
