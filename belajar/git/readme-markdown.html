README & Markdown

Buka versi interaktif

README.md adalah halaman depan repositori: apa proyek ini, cara memasang, cara menjalankan, dan cara berkontribusi. Recruiter sering hanya membaca README.

Markdown memakai simbol sederhana: # judul, **tebal**, - daftar, [teks](url) link, dan tiga backtick untuk blok kode.

Repositori bernama sama dengan username-mu (sariw/sariw) menjadi README profil yang tampil di halaman GitHub-mu.
