Keamanan & aturan cabang

Buka versi interaktif

Branch protection melindungi main: wajib lewat PR, wajib minimal satu persetujuan, dan wajib lulus tes sebelum boleh digabung. Ini mencegah push langsung yang tidak sengaja merusak produksi.

Simpan kunci API di Secrets (Settings → Secrets and variables → Actions), lalu panggil di workflow sebagai ${{ secrets.NAMA }}. Nilainya disamarkan di log.

Aktifkan Dependabot agar GitHub membuka PR otomatis saat ada versi dependensi yang menambal celah keamanan.

CONTOH
Settings → Branches → Add rule: main
  [x] Require a pull request before merging
      Required approvals: 1
  [x] Require status checks to pass: Tes
  [x] Do not allow bypassing the above settings

# di workflow
- run: npm run deploy
  env:
    API_KEY: ${{ secrets.API_KEY }}

Poin penting

  • Lindungi main: PR, review, tes wajib.
  • Rahasia di Secrets, bukan di kode.
  • Dependabot menjaga dependensi tetap aman.
