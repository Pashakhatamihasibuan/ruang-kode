Menyelesaikan konflik merge

Buka versi interaktif

Konflik terjadi saat dua cabang mengubah baris yang sama. Git tidak menebak; ia menandai bagian itu dan menunggu keputusanmu.

Di antara <<<<<<< dan ======= adalah versi cabangmu sekarang (HEAD); di antara ======= dan >>>>>>> versi cabang yang digabung. Edit berkas sampai benar, hapus penandanya, lalu git add dan git commit.

Konflik itu normal, bukan tanda gagal. Kurangi frekuensinya dengan cabang berumur pendek dan sering menarik perubahan terbaru dari main.

CONTOH
<<<<<<< HEAD
<button class="tombol">Beli sekarang</button>
=======
<button class="tombol tombol--utama">Tambah ke keranjang</button>
>>>>>>> fitur-keranjang

# setelah diputuskan:
<button class="tombol tombol--utama">Beli sekarang</button>

$ git add index.html
$ git commit -m "merge: gabung fitur-keranjang"

Poin penting

  • Konflik = baris yang sama diubah di dua cabang.
  • HEAD di atas =======, cabang lain di bawah.
  • Edit, hapus penanda, add, commit.

Cek pemahaman

Setelah mengedit berkas berkonflik, langkah berikutnya?

Jawaban: git add lalu git commit

git add menandai konflik sudah diselesaikan.
