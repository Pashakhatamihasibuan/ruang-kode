Portofolio di GitHub Pages dengan alur PR

Buka versi interaktif

Buat repositori portofolio, kerjakan setiap bagian di cabang terpisah, gabungkan lewat pull request yang lulus tes otomatis, lalu terbitkan ke GitHub Pages.

Teknologi: Git + GitHub

Fitur yang dibuat

  • Repositori dengan README lengkap dan lisensi
  • .gitignore untuk node_modules, dist, dan .env
  • Minimal 3 cabang fitur yang digabung lewat pull request
  • Satu konflik merge yang diselesaikan dan dicatat di PR
  • Pesan commit mengikuti Conventional Commits
  • Branch protection di main: wajib PR dan tes lulus
  • Workflow Actions yang memeriksa HTML setiap PR
  • Situs terbit di username.github.io

Langkah kerja

  1. Buat repositori dan commit pertama.
  2. Push ke GitHub dan aktifkan branch protection.
  3. Kerjakan bagian "Tentang", "Proyek", "Kontak" di cabang masing-masing.
  4. Buka PR, minta teman mereview, gabungkan.
  5. Aktifkan Pages dari main.
.github/workflows/cek.yml
name: Cek HTML
on: [pull_request]
jobs:
  cek:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npx --yes html-validate "**/*.html"
urutan-perintah.sh
git init && git add . && git commit -m "feat: kerangka portofolio"
git remote add origin git@github.com:sariw/portofolio.git
git push -u origin main

git switch -c bagian-proyek
git commit -am "feat: kartu tiga proyek"
git push -u origin bagian-proyek
# buka PR di GitHub, tunggu tes hijau, minta review, merge

git switch main && git pull
git branch -d bagian-proyek
Kerjakan latihannya di aplikasi
