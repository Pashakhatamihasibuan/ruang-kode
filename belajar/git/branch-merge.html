Branch & merge

Buka versi interaktif

Branch adalah penunjuk ringan ke sebuah commit. Membuat cabang fitur-keranjang memungkinkanmu bereksperimen tanpa mengganggu main yang harus selalu siap rilis.

git switch -c nama membuat dan pindah ke cabang baru. Setelah fitur selesai, kembali ke main lalu git merge nama.

Jika main tidak berubah sejak cabang dibuat, Git cukup menggeser penunjuk main (fast-forward). Jika keduanya punya commit baru, Git membuat merge commit dengan dua induk.

TERMINAL
$ git switch -c fitur-keranjang
Switched to a new branch 'fitur-keranjang'
$ git commit -am "feat: tombol tambah ke keranjang"

$ git switch main
$ git merge fitur-keranjang
Updating a71be04..c4e8b21
Fast-forward
 index.html | 4 ++++
 1 file changed, 4 insertions(+)

$ git branch -d fitur-keranjang
Deleted branch fitur-keranjang (was c4e8b21).

Poin penting

  • Branch = penunjuk ke commit, murah dibuat.
  • git switch -c untuk cabang baru.
  • Fast-forward: cukup geser penunjuk; selain itu merge commit.
  • Hapus cabang setelah digabung.
