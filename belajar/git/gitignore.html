.gitignore

Buka versi interaktif

Tidak semua berkas pantas masuk repositori: folder node_modules (bisa dipasang ulang), hasil build dist/, berkas sistem .DS_Store, dan terutama rahasia seperti .env yang berisi kunci API.

Tuliskan pola nama berkas di .gitignore di akar proyek. Git akan berhenti menampilkannya sebagai untracked. Tanda ! membuat pengecualian.

Penting: .gitignore tidak berlaku untuk berkas yang sudah di-commit. Kalau kunci API terlanjur masuk riwayat, ganti kuncinya, karena riwayat Git bisa dibaca siapa pun yang punya salinan.

CONTOH
# dependensi dan hasil build
node_modules/
dist/

# rahasia: jangan pernah di-commit
.env
.env.*
!.env.example

# berkas sistem dan editor
.DS_Store
.vscode/
*.log

Poin penting

  • Abaikan dependensi, hasil build, log, dan rahasia.
  • Pola: folder/, *.ext, ! untuk pengecualian.
  • Berkas yang terlanjur di-commit tetap ada di riwayat.
