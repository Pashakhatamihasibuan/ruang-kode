Apa itu version control & Git?

Buka versi interaktif

Version control mencatat setiap perubahan pada berkas sehingga kamu bisa melihat siapa mengubah apa, kapan, dan kenapa, lalu kembali ke versi mana pun. Tanpa itu, folder proyek cepat dipenuhi final.html, final-revisi.html, final-benar-benar.html.

Git adalah version control terdistribusi: setiap salinan proyek menyimpan riwayat lengkap, jadi kamu bisa bekerja dan membuat commit tanpa internet. Sistem lama seperti SVN bersifat terpusat, setiap commit harus terhubung ke server.

GitHub bukan Git. GitHub adalah layanan yang menyimpan repositori Git di internet dan menambahkan fitur kolaborasi: pull request, issue, review, dan Actions. Alternatifnya GitLab dan Bitbucket.

TERMINAL
$ git --version
git version 2.47.0

$ git config --global user.name "Sari Wulandari"
$ git config --global user.email "sari@contoh.id"
$ git config --global init.defaultBranch main
$ git config --list | grep user
user.name=Sari Wulandari
user.email=sari@contoh.id

Poin penting

  • Version control = riwayat perubahan yang bisa dikembalikan.
  • Git terdistribusi: riwayat lengkap ada di setiap salinan.
  • GitHub adalah tempat menyimpan dan berkolaborasi, Git adalah alatnya.
  • Atur nama dan email sekali dengan git config --global.
