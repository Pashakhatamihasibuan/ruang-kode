Issue, label & project board

Buka versi interaktif

Issue mencatat bug, ide fitur, atau pertanyaan. Issue yang baik untuk bug berisi langkah mereproduksi, hasil yang diharapkan, hasil sebenarnya, dan lingkungan (browser, versi).

Hubungkan PR dengan issue lewat kata kunci di deskripsi: Closes #42. Saat PR digabung, issue otomatis ditutup.

Projects menyusun issue dalam papan kanban (Todo, In progress, Done) sehingga tim melihat pekerjaan yang sedang berjalan.

CONTOH
Judul: Total keranjang salah saat jumlah produk 0

Langkah:
1. Tambah "Kopi Gayo" ke keranjang
2. Ubah jumlah menjadi 0
Diharapkan: produk hilang, total Rp 0
Terjadi: total tetap Rp 85.000
Lingkungan: Chrome 130, Android 14

Label: bug, prioritas-tinggi
---
PR #57: fix: hapus item berjumlah 0 dari keranjang
Closes #42

Poin penting

  • Issue bug: langkah, harapan, kenyataan, lingkungan.
  • Closes #nomor menutup issue saat PR digabung.
  • Projects untuk papan kerja tim.

Cek pemahaman

Bagaimana PR menutup issue #42 secara otomatis?

Jawaban: Tulis "Closes #42" di deskripsi PR
