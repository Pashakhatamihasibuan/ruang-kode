Riwayat & perbedaan: log dan diff

Buka versi interaktif

git log menampilkan riwayat dari commit terbaru. Versi ringkas git log --oneline --graph menampilkan satu baris per commit beserta gambar cabang.

git diff menunjukkan baris yang berubah tetapi belum di-stage. git diff --staged menunjukkan apa yang akan masuk commit. Baris diawali - dihapus, + ditambahkan.

Sebelum commit, lihat git diff --staged agar tidak ada berkas debug atau kata sandi yang ikut tersimpan.

TERMINAL
$ git log --oneline
a71be04 (HEAD -> main) style: warna tombol beli
5c2d9e1 feat: daftar produk
3f9a1c2 feat: halaman awal toko

$ git diff
diff --git a/gaya.css b/gaya.css
@@ -1,3 +1,3 @@
 .tombol {
-  background: #2563eb;
+  background: #b4532a;
 }

Poin penting

  • git log --oneline untuk riwayat ringkas.
  • git diff = belum di-stage; --staged = akan di-commit.
  • HEAD menunjuk commit tempat kamu berada sekarang.

Cek pemahaman

Perintah untuk melihat perubahan yang SUDAH di-stage?

Jawaban: git diff --staged

Tanpa --staged, diff hanya menampilkan yang belum di-stage.

Pada diff, baris berawalan + artinya?

Jawaban: Baris ditambahkan

Tanda - untuk baris yang dihapus.
