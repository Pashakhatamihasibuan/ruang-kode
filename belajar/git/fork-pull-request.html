Fork & pull request

Buka versi interaktif

Fork adalah salinan repositori orang lain di akunmu sendiri. Dipakai untuk berkontribusi ke proyek open source tempat kamu tidak punya hak tulis.

Pull request (PR) adalah permintaan agar perubahan di cabangmu digabung ke cabang tujuan. Di PR, rekan tim membaca diff, memberi komentar per baris, dan menyetujui. CI otomatis menjalankan tes.

PR yang mudah direview: kecil (di bawah 400 baris), satu tujuan, judul jelas, deskripsi berisi apa yang berubah, kenapa, dan cara mengujinya, plus tangkapan layar untuk perubahan tampilan.

TERMINAL
# 1. Fork lewat tombol Fork di GitHub, lalu:
$ git clone git@github.com:sariw/kamus-daerah.git
$ cd kamus-daerah
$ git remote add upstream https://github.com/komunitas/kamus-daerah.git

# 2. Kerjakan di cabang sendiri
$ git switch -c tambah-bahasa-sunda
$ git commit -am "feat: 120 kosakata bahasa Sunda"
$ git push -u origin tambah-bahasa-sunda

# 3. Buka Pull Request di GitHub: tambah-bahasa-sunda -> komunitas:main

# 4. Selaraskan dengan proyek asal
$ git fetch upstream && git rebase upstream/main

Poin penting

  • Fork = salinan di akunmu; upstream = proyek asal.
  • PR = minta perubahan digabung, tempat review.
  • PR kecil dan berdeskripsi jelas lebih cepat disetujui.
