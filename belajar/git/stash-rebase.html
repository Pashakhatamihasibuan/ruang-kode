Stash & rebase

Buka versi interaktif

git stash menyimpan sementara perubahan yang belum di-commit, membuat working directory bersih. Berguna saat harus pindah cabang mendadak untuk memperbaiki bug. Kembalikan dengan git stash pop.

git rebase main memindahkan commit cabangmu seolah dibuat di atas main terbaru, menghasilkan riwayat lurus tanpa merge commit.

Aturan emas: jangan rebase commit yang sudah di-push dan dipakai orang lain, karena rebase membuat hash baru dan menulis ulang riwayat.

TERMINAL
$ git stash
Saved working directory and index state WIP on fitur-ongkir: 5c2d9e1
$ git switch main && git switch -c perbaikan-harga
# ... perbaiki, commit ...
$ git switch fitur-ongkir
$ git stash pop

$ git rebase main
Successfully rebased and updated refs/heads/fitur-ongkir.

Poin penting

  • stash = simpan sementara, pop = kembalikan.
  • rebase = tanam ulang commit di atas basis baru.
  • Jangan rebase riwayat yang sudah dibagikan.
