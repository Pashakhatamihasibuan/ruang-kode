GitHub Pages & Actions

Buka versi interaktif

GitHub Pages menerbitkan situs statis gratis langsung dari repositori di alamat username.github.io/repo. Cocok untuk portofolio.

GitHub Actions menjalankan alur kerja otomatis saat terjadi peristiwa (push, PR). Berkasnya YAML di .github/workflows/. Contoh umum: menjalankan tes di setiap PR lalu menerbitkan situs dari main.

Setiap job berjalan di mesin baru, jadi langkah pertama selalu actions/checkout untuk mengambil kode.

YAML
# .github/workflows/tes.yml
name: Tes
on:
  pull_request:
  push:
    branches: [main]
jobs:
  tes:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npm test

Poin penting

  • Pages: hosting situs statis gratis.
  • Actions: otomatisasi berbasis peristiwa (CI/CD).
  • Workflow YAML di .github/workflows/.
