Serializer dan validasi

Buka versi interaktif

Serializer mengubah objek model menjadi JSON (untuk response) dan memvalidasi JSON masuk (untuk request). Satu serializer bisa menampilkan field tambahan yang hanya dibaca, misalnya nama kategori.

Validasi bertingkat: tipe dan panjang otomatis dari model, validate_<field> untuk satu field, dan validate() untuk aturan antar field. Error dikembalikan sebagai 400 dengan pesan per field, yang nanti ditampilkan frontend di bawah input yang salah.

Untuk pesanan, frontend hanya mengirim id produk dan jumlah. Harga dan total dihitung server; jangan pernah percaya harga dari browser.

PYTHON
# toko/serializers.py
from rest_framework import serializers
from .models import Produk, Pesanan, ItemPesanan

class ProdukSerializer(serializers.ModelSerializer):
    kategori_nama = serializers.CharField(source='kategori.nama', read_only=True)

    class Meta:
        model = Produk
        fields = ['id', 'nama', 'harga', 'stok', 'aktif', 'kategori', 'kategori_nama']

    def validate_nama(self, v):
        if len(v.strip()) < 3:
            raise serializers.ValidationError('Nama minimal 3 huruf.')
        return v.strip()

class ItemMasukSerializer(serializers.Serializer):
    produk = serializers.PrimaryKeyRelatedField(queryset=Produk.objects.filter(aktif=True))
    jumlah = serializers.IntegerField(min_value=1, max_value=99)

class PesananSerializer(serializers.ModelSerializer):
    item = ItemMasukSerializer(many=True, write_only=True)

    class Meta:
        model = Pesanan
        fields = ['id', 'item', 'total', 'dibuat']
        read_only_fields = ['total', 'dibuat']

    def validate_item(self, item):
        if not item:
            raise serializers.ValidationError('Pesanan minimal berisi 1 produk.')
        return item

    def create(self, validated_data):
        validated_data.pop('item')          # item disimpan di view, setelah stok dicek
        return Pesanan.objects.create(**validated_data)
KELUARAN

{
  "nama": ["Nama minimal 3 huruf."],
  "harga": ["Pastikan nilai ini lebih besar dari 0."]

Poin penting

  • Serializer: objek ↔ JSON + validasi.
  • Error 400 per field untuk ditampilkan di form.
  • Harga dan total selalu dihitung server.

Cek pemahaman

Kenapa total pesanan tidak diterima dari frontend?

Jawaban: Pengguna bisa mengubah request dan membayar lebih murah

Data dari browser tidak bisa dipercaya.
