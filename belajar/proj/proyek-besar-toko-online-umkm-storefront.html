Proyek besar (capstone) jalur Frontend. Masalahnya nyata: UMKM ingin berjualan online tanpa biaya marketplace. Kerjakan dalam sekitar 4 minggu dengan rencana mingguan di bawah.

Perlakukan seperti pekerjaan di tim: tulis kebutuhan dulu, pecah menjadi issue di GitHub Projects, kerjakan per branch dan pull request, dan catat keputusan teknis di README. Nilai dirimu dengan rubrik di modul pertama jalur ini.

PROYEK BESAR: Toko online UMKM (storefront)

Masalah
  UMKM ingin berjualan online tanpa biaya marketplace.

Fitur wajib
  1. Katalog dengan filter, pencarian, dan pagination
  2. Halaman detail produk dengan SEO (metadata, Open Graph)
  3. Keranjang tersimpan dan checkout ke WhatsApp/payment sandbox
  4. Login dan riwayat pesanan
  5. Aksesibel dan cepat (Core Web Vitals hijau)

Stack yang disarankan
  Next.js App Router, TypeScript, Tailwind, TanStack Query atau Server Actions, Playwright, Vercel

Rencana 4 minggu
  Minggu 1: desain komponen dan halaman katalog
  Minggu 2: detail, keranjang, checkout
  Minggu 3: login, riwayat, state error/kosong
  Minggu 4: test E2E, performa, deploy

Standar industri yang dinilai
  Komponen terpisah dan bisa dipakai ulang, semua keadaan UI ditangani, skor Lighthouse dicantumkan di README

Keluaran
  [ ] Repo dengan README lengkap, keputusan teknis, dan screenshot
  [ ] Demo online atau video 2 menit
  [ ] Test/bukti pengujian dan CI hijau (untuk proyek kode)
  [ ] Ringkasan 1 paragraf untuk CV dan LinkedIn

Poin penting

  • Masalah: UMKM ingin berjualan online tanpa biaya marketplace.
  • Stack: Next.js App Router, TypeScript, Tailwind, TanStack Query atau Server Actions, Playwright, Vercel.
  • Rencana 4 minggu; dinilai dengan rubrik standar industri.
