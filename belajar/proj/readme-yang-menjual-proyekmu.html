# KasirKu

Aplikasi kasir dan stok untuk kedai kopi kecil: catat pesanan,
stok berkurang otomatis, dan lihat laporan penjualan harian.

![Tangkapan layar](docs/screenshot.png)

Demo: https://kasirku.vercel.app  (akun: demo@kasirku.id / demo1234)

## Fitur
- Login kasir dan admin (JWT)
- Kelola produk dan stok, pencarian, pagination
- Pesanan mengurangi stok secara atomik (tidak bisa minus)
- Laporan penjualan per hari

## Stack
React + TypeScript + TanStack Query | Django REST Framework | PostgreSQL 16
Docker Compose, GitHub Actions, pytest, Vitest, Playwright

## Menjalankan
cp .env.example .env
docker compose up --build
# web: http://localhost:5173  api: http://localhost:8000/api/

## Keputusan teknis
- Stok dikurangi dengan select_for_update di dalam transaksi agar dua
  kasir tidak menjual barang terakhir yang sama.
- Harga disimpan sebagai DECIMAL, bukan float, agar tidak ada selisih sen.

## Rencana berikutnya
- Cetak struk PDF, mode offline
