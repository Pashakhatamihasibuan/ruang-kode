Proyek besar: Aplikasi antrean klinik

Buka versi interaktif

Proyek besar (capstone) jalur Mobile (Flutter / Android). Masalahnya nyata: Pasien klinik kecil menunggu berjam-jam tanpa tahu giliran. Kerjakan dalam sekitar 4 minggu dengan rencana mingguan di bawah.

Perlakukan seperti pekerjaan di tim: tulis kebutuhan dulu, pecah menjadi issue di GitHub Projects, kerjakan per branch dan pull request, dan catat keputusan teknis di README. Nilai dirimu dengan rubrik di modul pertama jalur ini.

Yang membedakan proyek ini dari tutorial: arsitektur berlapis (UI-state-data), menangani koneksi putus, APK ringan, aksesibel (ukuran sentuh, label). Itulah yang akan kamu ceritakan saat wawancara.

PROYEK BESAR: Aplikasi antrean klinik

Masalah
  Pasien klinik kecil menunggu berjam-jam tanpa tahu giliran.

Fitur wajib
  1. Ambil nomor antrean dan pilih poli
  2. Lihat posisi antrean secara real time
  3. Notifikasi saat giliran tinggal 3 orang
  4. Admin memanggil nomor berikutnya
  5. Bekerja di HP Android kelas bawah dan koneksi lambat

Stack yang disarankan
  Flutter (Riverpod, go_router) atau Kotlin Compose (ViewModel, Room), Firebase/Supabase, FCM, test widget/UI

Rencana 4 minggu
  Minggu 1: slicing layar dari desain dan navigasi
  Minggu 2: data antrean real time
  Minggu 3: notifikasi dan mode offline
  Minggu 4: test, ukuran APK, rilis di Play Store internal testing

Standar industri yang dinilai
  Arsitektur berlapis (UI-state-data), menangani koneksi putus, APK ringan, aksesibel (ukuran sentuh, label)

Keluaran
  [ ] Repo dengan README lengkap, keputusan teknis, dan screenshot
  [ ] Demo online atau video 2 menit
  [ ] Test/bukti pengujian dan CI hijau (untuk proyek kode)
  [ ] Ringkasan 1 paragraf untuk CV dan LinkedIn

Poin penting

  • Masalah: Pasien klinik kecil menunggu berjam-jam tanpa tahu giliran.
  • Stack: Flutter (Riverpod, go_router) atau Kotlin Compose (ViewModel, Room), Firebase/Supabase, FCM, test widget/UI.
  • Rencana 4 minggu; dinilai dengan rubrik standar industri.
