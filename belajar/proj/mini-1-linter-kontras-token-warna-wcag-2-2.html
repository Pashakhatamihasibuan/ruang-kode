Mini 1: Linter kontras token warna (WCAG 2.2)

Buka versi interaktif

Masalah. Tim desain punya palet tema terang dan gelap, tetapi developer sering menemukan teks abu-abu yang sulit dibaca setelah build. Kamu diminta membuat pemeriksa otomatis untuk semua pasangan warna token sebelum handoff.

Fitur wajib:
1. Hitung luminans relatif dan rasio kontras sesuai rumus WCAG
2. Periksa setiap pasangan token teks/latar di kedua tema
3. Ambang berbeda: teks 4,5:1, komponen UI dan teks besar 3:1
4. Laporan LULUS/GAGAL dan jumlah pasangan yang harus diperbaiki

Penyelesaian langkah demi langkah:
1. Ubah hex ke RGB 0-1, linierkan (gamma sRGB), lalu bobot 0,2126/0,7152/0,0722.
2. Rasio = (L terang + 0,05) / (L gelap + 0,05).
3. Simpan pasangan sebagai data (fg, bg, jenis) agar mudah ditambah.
4. Cetak tabel per tema dan ringkasan akhir untuk dipakai di CI.

Kembangkan sendiri: baca token dari file JSON Figma Variables, sarankan warna pengganti terdekat yang lulus, dan jalankan di GitHub Actions setiap kali token berubah.

# Linter kontras WCAG 2.2 untuk token warna tema terang & gelap
def lum(hexwarna):
    h = hexwarna.lstrip("#")
    r, g, b = (int(h[i:i + 2], 16) / 255 for i in (0, 2, 4))
    f = lambda c: c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b)

def rasio(a, b):
    la, lb = sorted([lum(a), lum(b)], reverse=True)
    return (la + 0.05) / (lb + 0.05)

TEMA = {
    "terang": {"bg": "#FFFFFF", "surface": "#F4F6F8", "text": "#1B1F24", "muted": "#8A94A0",
               "primary": "#0B6BCB", "on-primary": "#FFFFFF", "danger": "#E5484D", "border": "#D0D7DE"},
    "gelap":  {"bg": "#0E1116", "surface": "#161B22", "text": "#E6EDF3", "muted": "#7D8590",
               "primary": "#4493F8", "on-primary": "#0E1116", "danger": "#F85149", "border": "#30363D"},
}
# (teks/komponen, latar, jenis) -> jenis menentukan ambang: teks 4.5, besar/UI 3.0
PASANGAN = [("text", "bg", "teks"), ("text", "surface", "teks"), ("muted", "bg", "teks"),
            ("on-primary", "primary", "teks"), ("primary", "bg", "teks"), ("danger", "bg", "teks"),
            ("border", "bg", "ui")]
AMBANG = {"teks": 4.5, "ui": 3.0}

gagal = 0
for nama, t in TEMA.items():
    print(f"TEMA {nama}")
    for fg, bg, jenis in PASANGAN:
        r = rasio(t[fg], t[bg])
        ok = r >= AMBANG[jenis]
        gagal += not ok
        print(f"  {'LULUS' if ok else 'GAGAL'}  {fg:<10} di {bg:<8} {r:5.2f}:1  (min {AMBANG[jenis]})")
print(f"{gagal} pasangan gagal -> perbaiki token sebelum handoff" if gagal else "semua lulus")
