Proyek mini: Data Engineer

Buka versi interaktif

Tiga proyek mini ini melatih keterampilan inti jalur Data Engineer satu per satu (materinya ada di jalur Python, SQL, Git, Python Analisis Data, Data Engineer). Masing-masing cukup dikerjakan dalam 3–7 hari.

Kerjakan berurutan. Setiap proyek mini harus "selesai" menurut definisi di bawah: berfungsi termasuk kasus gagal, ada README, dan bisa didemokan. Proyek mini yang tuntas lebih berharga daripada proyek besar yang setengah jadi.

Setelah ketiganya selesai, keterampilannya akan dipakai bersama di proyek besar jalur ini.

BRIEF PROYEK MINI: ETL harian dari API publik

Tujuan latihan : Python, requests, PostgreSQL
Fitur wajib    : Ambil data, bersihkan, muat tanpa duplikat (upsert), log setiap langkah
Tantangan      : Jadwalkan dengan cron/GitHub Actions

Definisi selesai
[ ] Semua fitur wajib berjalan, termasuk input salah dan data kosong
[ ] Repo publik dengan README (screenshot, cara menjalankan)
[ ] Minimal satu test atau bukti pengujian
[ ] Bisa didemokan dalam 2 menit

Waktu ideal: 3-7 hari per proyek mini

Poin penting

  • ETL harian dari API publik.
  • Model data gudang (star schema).
  • Streaming klik sederhana.

Cek pemahaman

Kapan sebuah proyek mini dianggap selesai?

Jawaban: Fitur wajib berjalan termasuk kasus gagal, ada README, dan bisa didemokan

Selesai = bisa dipakai dan ditunjukkan.
