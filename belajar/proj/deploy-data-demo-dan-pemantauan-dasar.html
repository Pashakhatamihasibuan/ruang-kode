Proyek Portofolio · Modul 1 · Konsep & kode

Deploy, data demo, dan pemantauan dasar

Buka versi interaktif

Proyek yang hanya jalan di laptop sulit dinilai. Pilihan deploy gratis atau murah: Vercel/Netlify untuk frontend, Render/Railway/Fly.io untuk API, dan Neon/Supabase untuk PostgreSQL terkelola.

Siapkan perintah seed yang mengisi data contoh agar demo langsung terlihat hidup. Atur variabel lingkungan di dashboard penyedia, bukan di kode: DATABASE_URL, SECRET_KEY, ALLOWED_HOSTS, CORS_ALLOWED_ORIGINS, VITE_API_URL.

Tambahkan endpoint /api/health yang mengecek koneksi database, dan catat error dengan logging (atau Sentry versi gratis). Saat wawancara, cerita "saya menemukan bug di produksi dari log lalu memperbaikinya" sangat bernilai.

TERMINAL
# backend: perintah seed data demo
python manage.py migrate
python manage.py loaddata demo_produk.json
python manage.py createsuperuser --noinput   # DJANGO_SUPERUSER_* dari env

# variabel lingkungan produksi (diisi di dashboard Render/Vercel)
DATABASE_URL=postgres://...neon.tech/kasirku
SECRET_KEY=<acak 50 karakter>
DEBUG=False
ALLOWED_HOSTS=kasirku-api.onrender.com
CORS_ALLOWED_ORIGINS=https://kasirku.vercel.app
VITE_API_URL=https://kasirku-api.onrender.com/api

Poin penting

  • Frontend, API, dan database bisa di-host gratis.
  • Seed data demo dan akun demo.
  • Konfigurasi lewat environment variable; ada health check.
