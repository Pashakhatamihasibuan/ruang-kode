Besar 2: Aplikasi e-commerce Android native dengan Compose dan arsitektur modular

Buka versi interaktif

Masalah. Brand fesyen lokal dengan 200 ribu pengguna aktif ingin aplikasi Android yang cepat di HP entry-level, tetap bisa menjelajah katalog saat offline, dan checkout aman dengan payment gateway Indonesia.

Fitur wajib:
1. Modularisasi per fitur dan core (build lebih cepat, tim paralel)
2. Katalog offline-first: Paging 3 + RemoteMediator + Room
3. Checkout dengan idempotency key dan status final dari webhook server, bukan dari klien
4. Hilt untuk DI, Compose + Material 3, navigasi type-safe
5. Performa: Baseline Profiles, R8, pengukuran dengan Macrobenchmark

Penyelesaian langkah demi langkah:
1. Buat modul core dan design system (warna, tipografi, komponen) lebih dulu.
2. Implementasikan katalog dengan RemoteMediator; uji mode pesawat.
3. Bangun keranjang (Room) dan checkout dengan idempotencyKey per sesi.
4. Integrasi payment gateway; tampilkan "menunggu konfirmasi" sampai server menerima webhook.
5. Buat Baseline Profile dan ukur startup sebelum/sesudah dengan Macrobenchmark.

Standar industri yang dinilai: offline-first, modular, checkout idempoten dan tidak memercayai status dari klien, startup diukur dan dioptimasi, ANR rate < 0,47% dan crash rate < 1,09% (ambang Android vitals)

Arsitektur dan stack (Kotlin 2.x, Jetpack Compose, Material 3, Hilt, Room, Paging 3, Retrofit/OkHttp + kotlinx.serialization, Navigation Compose, Coil, Midtrans/Xendit SDK, Firebase, Macrobenchmark)

Poin penting

  • Proyek besar: Aplikasi e-commerce Android native dengan Compose dan arsitektur modular.
  • Stack: Kotlin 2.x, Jetpack Compose, Material 3, Hilt, Room, Paging 3, Retrofit/OkHttp + kotlinx.serialization, Navigation Compose, Coil, Midtrans/Xendit SDK, Firebase, Macrobenchmark.
  • Kerjakan dulu sendiri, lalu buka kode final untuk code review.

Jawaban: Callback di klien bisa dimanipulasi atau hilang; sumber kebenaran adalah webhook gateway ke server
