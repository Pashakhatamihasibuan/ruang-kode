Besar 3: Pipeline pemantau harga pangan harian

Buka versi interaktif

Masalah. Dinas ketahanan pangan dan pedagang butuh peringatan dini saat harga cabai, bawang, atau beras melonjak di suatu provinsi. Data tersebar di banyak sumber, sering terlambat, dan pengambilan manual memakan waktu berjam-jam.

Fitur wajib:
1. Pengambilan data paralel yang sopan (semaphore) dengan retry, exponential backoff, dan jitter
2. Validasi setiap baris dengan Pydantic; baris rusak dilaporkan, bukan disimpan
3. Penyimpanan idempoten (upsert) agar aman dijalankan ulang
4. Deteksi anomali dengan modified z-score berbasis median
5. Orkestrasi berbentuk DAG, laporan harian, notifikasi, dan data quality report

Penyelesaian langkah demi langkah:
1. Petakan sumber data, ketentuan penggunaannya, dan jadwal pembaruannya.
2. Bangun pengambil async dengan retry; uji dengan server tiruan yang sengaja gagal.
3. Tambahkan validasi dan upsert; jalankan dua kali untuk membuktikan idempoten.
4. Kalibrasi ambang anomali dengan data historis bersama ahli pangan.
5. Jadwalkan pipeline, buat dashboard dan notifikasi, lalu pantau kualitas datanya.

Standar industri yang dinilai: pengambilan data sopan dan legal, idempoten, validasi eksplisit, anomali dengan statistik yang tahan outlier, observability kualitas data, dan dokumentasi sumber

Arsitektur dan stack (Python 3.12, asyncio, httpx, Pydantic, PostgreSQL/SQLite, Airflow atau GitHub Actions cron, Metabase)
BagianIsi
Ingesthttpx AsyncClient, Semaphore(5), backoff + jitter, User-Agent jelas
ValidasiPydantic: komoditas dikenal, rentang harga wajar, tanggal valid
Storagetabel harga dengan kunci unik (tanggal, provinsi, komoditas), upsert
Analitikmedian & MAD 30 hari, modified z-score > 3,5 = anomali
OrkestrasiDAG: ambil -> validasi -> simpan -> anomali -> laporan/notifikasi/dashboard
Observabilityfreshness, jumlah baris, provinsi gagal, durasi tiap tugas

  • Stack: Python 3.12, asyncio, httpx, Pydantic, PostgreSQL/SQLite, Airflow atau GitHub Actions cron, Metabase.
  • Kerjakan dulu sendiri, lalu buka kode final untuk code review.
