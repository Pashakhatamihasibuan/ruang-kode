Besar 3: Pipeline pemantau harga pangan harian

Buka versi interaktif

Masalah. Dinas ketahanan pangan dan pedagang butuh peringatan dini saat harga cabai, bawang, atau beras melonjak di suatu provinsi. Data tersebar di banyak sumber, sering terlambat, dan pengambilan manual memakan waktu berjam-jam.

Fitur wajib:
1. Pengambilan data paralel yang sopan (semaphore) dengan retry, exponential backoff, dan jitter
2. Validasi setiap baris dengan Pydantic; baris rusak dilaporkan, bukan disimpan
3. Penyimpanan idempoten (upsert) agar aman dijalankan ulang
4. Deteksi anomali dengan modified z-score berbasis median
5. Orkestrasi berbentuk DAG, laporan harian, notifikasi, dan data quality report

Penyelesaian langkah demi langkah:
1. Petakan sumber data, ketentuan penggunaannya, dan jadwal pembaruannya.
2. Bangun pengambil async dengan retry; uji dengan server tiruan yang sengaja gagal.
3. Tambahkan validasi dan upsert; jalankan dua kali untuk membuktikan idempoten.
4. Kalibrasi ambang anomali dengan data historis bersama ahli pangan.
5. Jadwalkan pipeline, buat dashboard dan notifikasi, lalu pantau kualitas datanya.

Standar industri yang dinilai: pengambilan data sopan dan legal, idempoten, validasi eksplisit, anomali dengan statistik yang tahan outlier, observability kualitas data, dan dokumentasi sumber

Arsitektur dan stack (Python 3.12, asyncio, httpx, Pydantic, PostgreSQL/SQLite, Airflow atau GitHub Actions cron, Metabase)

# Pipeline pemantau harga pangan harian: ambil -> validasi -> simpan -> deteksi anomali -> laporan
# Dijalankan terjadwal (cron/GitHub Actions/Airflow) pukul 10.00 WIB
# ---- pipeline/ambil.py
import asyncio, random
import httpx
from pydantic import BaseModel, Field, field_validator

class Harga(BaseModel):
    tanggal: str
    provinsi: str
    komoditas: str
    harga: int = Field(gt=0, lt=1_000_000)
    @field_validator("komoditas")
    @classmethod
    def kenal(cls, v):
        if v not in KOMODITAS: raise ValueError(f"komoditas tidak dikenal: {v}")
        return v

KOMODITAS = {"beras medium", "beras premium", "cabai merah", "bawang merah", "telur ayam", "minyak goreng", "gula pasir"}
SEM = asyncio.Semaphore(5)                                  # sopan ke server sumber

async def ambil(client: httpx.AsyncClient, prov: str, tanggal: str, coba=5) -> list[Harga]:
    for i in range(coba):
        try:
            async with SEM:
                r = await client.get(f"{SUMBER_API}/harga", params={"prov": prov, "tgl": tanggal}, timeout=15)
            if r.status_code == 429 or r.status_code >= 500: raise httpx.HTTPStatusError("retry", request=r.request, response=r)
            r.raise_for_status()
            return [Harga(**x) for x in r.json()["data"]]
        except (httpx.TransportError, httpx.HTTPStatusError):
            await asyncio.sleep(min(60, 2 ** i) + random.random())     # exponential backoff + jitter
    raise RuntimeError(f"gagal ambil {prov} setelah {coba} percobaan")

async def ambil_semua(tanggal):
    async with httpx.AsyncClient(headers={"User-Agent": "pemantau-harga/1.0"}) as c:
        hasil = await asyncio.gather(*(ambil(c, p, tanggal) for p in PROVINSI), return_exceptions=True)
    gagal = [p for p, h in zip(PROVINSI, hasil) if isinstance(h, Exception)]
    return [x for h in hasil if not isinstance(h, Exception) for x in h], gagal

# ---- pipeline/anomali.py
from statistics import median
def anomali(riwayat: list[int], hari_ini: int, k=3.5):
    """Modified z-score berbasis median & MAD: tahan outlier, cocok untuk harga yang melonjak musiman."""
    med = median(riwayat); mad = median(abs(x - med) for x in riwayat) or 1
    z = 0.6745 * (hari_ini - med) / mad
    return z if abs(z) > k else None
