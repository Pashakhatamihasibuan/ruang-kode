Besar 3: Asisten belajar AI dengan jawaban streaming dan sumber (RAG)

Buka versi interaktif

Masalah. Mahasiswa ingin bertanya tentang materi kuliah (PDF modul) dan mendapat jawaban yang menyebut halaman sumbernya, bukan jawaban AI yang mengarang.

Fitur wajib:
1. Unggah PDF materi; teks dipotong (chunk) dan disimpan sebagai embedding
2. Chat dengan jawaban yang mengalir kata demi kata (streaming)
3. Setiap jawaban menampilkan potongan sumber dan nomor halaman
4. Tombol hentikan, salin, dan coba lagi; riwayat percakapan
5. Batas penggunaan per pengguna dan penanganan error API

Penyelesaian langkah demi langkah:
1. Buat tabel potongan(id, dokumen_id, halaman, isi, embedding vector(1024)) dengan index HNSW pgvector.
2. Saat unggah: ekstrak teks per halaman, potong dengan tumpang tindih kecil agar kalimat tidak terputus, simpan embedding.
3. Saat bertanya: cari 5 potongan paling mirip, susun prompt "jawab hanya dari konteks, sebut halaman, katakan tidak tahu jika tidak ada".
4. Kirim jawaban sebagai stream dengan AI SDK; kirim juga metadata sumber agar UI menampilkannya.
5. Di UI, tampilkan status mengetik, tombol hentikan, dan kartu sumber yang bisa diklik.
6. Uji dengan 20 pertanyaan yang jawabannya diketahui; catat ketepatan dan kasus "tidak tahu".

Standar industri yang dinilai: jawaban bersumber dan bisa diverifikasi, kunci API tidak pernah di browser, rate limit dan error ditangani, evaluasi ketepatan dengan set pertanyaan uji

Arsitektur dan stack (Next.js 15, TypeScript, Vercel AI SDK, Claude API (Anthropic), PostgreSQL + pgvector, Drizzle ORM, Vercel)
BagianIsi
IngestRoute Handler /api/dokumen: ekstrak teks PDF → chunk ±800 karakter → embedding → simpan ke tabel potongan(vector)
Tanya/api/chat: embedding pertanyaan → ambil 5 potongan terdekat (cosine) → kirim ke model sebagai konteks → stream jawaban
UIuseChat dari AI SDK: pesan, status streaming, stop(), reload()
KeamananKunci API hanya di server; rate limit per pengguna; instruksi model dibatasi ke konteks
KODE
// app/api/chat/route.ts
import { anthropic } from '@ai-sdk/anthropic';
import { streamText, embed } from 'ai';
import { sql } from 'drizzle-orm';
import { db } from '@/lib/db';
import { modelEmbedding } from '@/lib/embedding';
import { batasiPengguna } from '@/lib/ratelimit';

export async function POST(req: Request) {
  const { messages, userId } = await req.json();
  if (!(await batasiPengguna(userId))) return new Response('Batas pertanyaan hari ini tercapai.', { status: 429 });

  const tanya = messages.at(-1).content as string;
  const { embedding } = await embed({ model: modelEmbedding, value: tanya });
  const vektor = JSON.stringify(embedding);
  const sumber = await db.execute(sql`
    SELECT halaman, isi, 1 - (embedding <=> ${vektor}::vector) AS skor
    FROM potongan ORDER BY embedding <=> ${vektor}::vector LIMIT 5`);

  const konteks = sumber.rows.map((s: any) => `[hal. ${s.halaman}] ${s.isi}`).join('\n---\n');
  const hasil = streamText({
    model: anthropic('claude-sonnet-4-5'),
    system: 'Kamu asisten belajar. Jawab dalam bahasa Indonesia HANYA berdasarkan KONTEKS. ' +
            'Sebut nomor halaman seperti (hal. 12). Jika jawabannya tidak ada di konteks, katakan belum ada di materi.\n\nKONTEKS:\n' + konteks,
    messages,
    maxOutputTokens: 800,
  });
  return hasil.toUIMessageStreamResponse({ messageMetadata: () => ({ sumber: sumber.rows.map((s: any) => ({ halaman: s.halaman, cuplikan: s.isi.slice(0, 160) })) }) });
}

// app/chat/page.tsx
'use client';
import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const { messages, sendMessage, status, stop, regenerate, error } = useChat();
  const [teks, setTeks] = useState('');
  return (
    <main>
      <ol aria-live="polite">
        {messages.map(m => (
          <li key={m.id} className={m.role}>
            {m.parts.map((p, i) => p.type === 'text' ? <p key={i}>{p.text}</p> : null)}
            {m.role === 'assistant' && (m.metadata as any)?.sumber?.map((s: any) =>
              <details key={s.halaman}><summary>Sumber: hal. {s.halaman}</summary>{s.cuplikan}…</details>)}
          </li>
        ))}
      </ol>
      {error && <p role="alert">Gagal menjawab. <button onClick={() => regenerate()}>Coba lagi</button></p>}
      <form onSubmit={e => { e.preventDefault(); if (teks.trim()) { sendMessage({ text: teks }); setTeks(''); } }}>
        <label htmlFor="t">Tanya materi</label>
        <textarea id="t" value={teks} onChange={e => setTeks(e.target.value)} />
        {status === 'streaming' ? <button type="button" onClick={stop}>Hentikan</button> : <button disabled={status === 'submitted'}>Kirim</button>}
      </form>
    </main>
  );
}
