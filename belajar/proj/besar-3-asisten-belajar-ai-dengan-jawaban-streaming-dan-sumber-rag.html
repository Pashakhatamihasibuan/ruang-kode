Besar 3: Asisten belajar AI dengan jawaban streaming dan sumber (RAG)

Buka versi interaktif

Masalah. Mahasiswa ingin bertanya tentang materi kuliah (PDF modul) dan mendapat jawaban yang menyebut halaman sumbernya, bukan jawaban AI yang mengarang.

Fitur wajib:
1. Unggah PDF materi; teks dipotong (chunk) dan disimpan sebagai embedding
2. Chat dengan jawaban yang mengalir kata demi kata (streaming)
3. Setiap jawaban menampilkan potongan sumber dan nomor halaman
4. Tombol hentikan, salin, dan coba lagi; riwayat percakapan
5. Batas penggunaan per pengguna dan penanganan error API

Penyelesaian langkah demi langkah:
1. Buat tabel potongan(id, dokumen_id, halaman, isi, embedding vector(1024)) dengan index HNSW pgvector.
2. Saat unggah: ekstrak teks per halaman, potong dengan tumpang tindih kecil agar kalimat tidak terputus, simpan embedding.
3. Saat bertanya: cari 5 potongan paling mirip, susun prompt "jawab hanya dari konteks, sebut halaman, katakan tidak tahu jika tidak ada".
4. Kirim jawaban sebagai stream dengan AI SDK; kirim juga metadata sumber agar UI menampilkannya.
5. Di UI, tampilkan status mengetik, tombol hentikan, dan kartu sumber yang bisa diklik.
6. Uji dengan 20 pertanyaan yang jawabannya diketahui; catat ketepatan dan kasus "tidak tahu".

Standar industri yang dinilai: jawaban bersumber dan bisa diverifikasi, kunci API tidak pernah di browser, rate limit dan error ditangani, evaluasi ketepatan dengan set pertanyaan uji

Arsitektur dan stack (Next.js 15, TypeScript, Vercel AI SDK, Claude API (Anthropic), PostgreSQL + pgvector, Drizzle ORM, Vercel)
BagianIsi
IngestRoute Handler /api/dokumen: ekstrak teks PDF → chunk ±800 karakter → embedding → simpan ke tabel potongan(vector)
Tanya/api/chat: embedding pertanyaan → ambil 5 potongan terdekat (cosine) → kirim ke model sebagai konteks → stream jawaban
UIuseChat dari AI SDK: pesan, status streaming, stop(), reload()
KeamananKunci API hanya di server; rate limit per pengguna; instruksi model dibatasi ke konteks
