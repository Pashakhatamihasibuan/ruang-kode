Proyek Portofolio · Modul 2 · Konsep & kode

ViewSet, router, pencarian, dan pagination

Buka versi interaktif

ModelViewSet memberi lima aksi sekaligus (list, retrieve, create, update, destroy), dan router membuat URL-nya otomatis. Tambahkan SearchFilter dan OrderingFilter agar ?search=kopi&ordering=-harga langsung berfungsi.

Optimalkan query: select_related('kategori') mengambil kategori dalam satu JOIN, bukan satu query per produk (masalah N+1). Masalah ini sering ditanyakan di wawancara backend.

Uji API dengan curl atau HTTPie sebelum membuat frontend. Jika respons sudah benar di sini, bug di frontend nanti pasti di sisi frontend.

PYTHON
# toko/views.py
from rest_framework import viewsets, filters
from .models import Produk
from .serializers import ProdukSerializer
from .permissions import AdminAtauHanyaBaca

class ProdukViewSet(viewsets.ModelViewSet):
    queryset = Produk.objects.select_related('kategori').filter(aktif=True)
    serializer_class = ProdukSerializer
    permission_classes = [AdminAtauHanyaBaca]
    filter_backends = [filters.SearchFilter, filters.OrderingFilter]
    search_fields = ['nama', 'kategori__nama']
    ordering_fields = ['nama', 'harga', 'stok']

# config/urls.py
from django.urls import include, path
from rest_framework.routers import DefaultRouter
from rest_framework_simplejwt.views import TokenObtainPairView, TokenRefreshView
from toko.views import ProdukViewSet, PesananViewSet

router = DefaultRouter()
router.register('produk', ProdukViewSet)
router.register('pesanan', PesananViewSet, basename='pesanan')
urlpatterns = [
    path('api/', include(router.urls)),
    path('api/auth/token/', TokenObtainPairView.as_view()),
    path('api/auth/refresh/', TokenRefreshView.as_view()),
]

Poin penting

  • ModelViewSet + router = CRUD lengkap.
  • SearchFilter, OrderingFilter, pagination bawaan.
  • select_related mencegah N+1 query.

Cek pemahaman

Masalah N+1 query terjadi saat?

Jawaban: Setiap baris memicu query tambahan untuk data relasinya

Solusi: select_related / prefetch_related.

Kerjakan latihannya di aplikasi

Sebelumnya: Serializer dan validasi

Berikutnya: Auth JWT dan izin per peran
