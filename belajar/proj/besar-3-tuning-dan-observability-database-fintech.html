Besar 3: Tuning dan observability database fintech

Buka versi interaktif

Masalah. Aplikasi pembayaran mengalami latensi p99 naik dari 80 ms ke 2 detik setiap tanggal gajian. CPU database 95%, koneksi penuh, dan tim saling menyalahkan antara aplikasi dan database. Kamu diminta menemukan akar masalah dengan data dan menyiapkan observability berkelanjutan.

Fitur wajib:
1. Baseline metrik: TPS, latensi, koneksi, cache hit, I/O, lock waits
2. pg_stat_statements + auto_explain untuk menemukan query terberat dan rencana buruknya
3. Konfigurasi memori/WAL/autovacuum sesuai hardware dan beban
4. PgBouncer transaction pooling untuk mengendalikan koneksi
5. Dashboard dan laporan mingguan Top-10 query untuk tim engineering

Penyelesaian langkah demi langkah:
1. Kumpulkan baseline 1 minggu termasuk tanggal gajian sebelumnya.
2. Urutkan query berdasarkan total waktu; perbaiki 3 teratas bersama developer dan ukur ulang.
3. Pasang PgBouncer dan sesuaikan konfigurasi; uji dengan pgbench dan replay beban.
4. Bangun dashboard + alert dan laporan mingguan otomatis.
5. Bandingkan metrik sebelum dan sesudah di tanggal gajian berikutnya; dokumentasikan.

Standar industri yang dinilai: keputusan berbasis metrik sebelum/sesudah, query terberat ditangani di akar masalah, koneksi dikendalikan pooler, observability berkelanjutan dan bisa dibaca developer

Arsitektur dan stack (PostgreSQL 16, pg_stat_statements, auto_explain, PgBouncer, postgres_exporter + Prometheus + Grafana, pganalyze/pgBadger, pgbench untuk uji beban)
BagianIsi
Diagnosiskorelasikan lonjakan dengan pg_stat_statements per jam; cari query dengan persen beban tertinggi
Queryindeks yang tepat, hapus N+1 dari ORM, batasi kolom, keyset pagination
Koneksi8.000 klien → 60 koneksi server per pool; query_wait_timeout untuk gagal cepat
Konfigurasishared_buffers 25%, random_page_cost 1.1 (NVMe), checkpoint diratakan, autovacuum agresif
ObservabilityGrafana: TPS, p95/p99, lock waits, replikasi, bloat; log query > 500 ms
Prosesreview indeks di setiap PR yang mengubah query; laporan Top-10 setiap Senin
