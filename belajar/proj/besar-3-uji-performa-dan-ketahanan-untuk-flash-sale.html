Besar 3: Uji performa dan ketahanan untuk flash sale

Buka versi interaktif

Masalah. E-commerce elektronik akan menjalankan flash sale 12.12 dengan perkiraan 10x trafik normal. Tahun lalu situs melambat 40 detik dan 300 unit terjual melebihi stok (oversell). Tim QA memimpin pengujian performa dan ketahanan sebelum hari H.

Fitur wajib:
1. Model beban realistis dari data analitik (rasio browsing:checkout, puncak per detik)
2. Skenario load, spike, stress, dan soak 4 jam dengan k6
3. Threshold otomatis: p95/p99 per endpoint, error rate, nol oversell
4. Chaos experiment: pod mati dan latensi cache saat puncak
5. Observabilitas: korelasi hasil k6 dengan metrik server di Grafana

Penyelesaian langkah demi langkah:
1. Ambil data trafik 12.12 tahun lalu dan susun model beban bersama tim bisnis.
2. Tulis skrip k6 per skenario dengan threshold; jalankan baseline di beban normal.
3. Naikkan beban bertahap, temukan bottleneck lewat Grafana/trace, perbaiki bersama developer, ulangi.
4. Jalankan chaos experiment dan soak test; pastikan tidak ada oversell.
5. Tulis laporan kapasitas, runbook hari H, dan pantau langsung saat flash sale.

Standar industri yang dinilai: beban dimodelkan dari data nyata, threshold otomatis di pipeline, nol oversell di semua skenario, pemulihan dari kegagalan terukur, laporan kapasitas sebelum hari H

Arsitektur dan stack (k6 (OSS/Cloud), Grafana + Prometheus + Tempo, Kubernetes, Chaos Mesh, Redis, PostgreSQL, GitHub Actions)
BagianIsi
Model beban300 RPS browsing tetap + lonjakan checkout 50 → 3.000 RPS dalam 60 detik
Lingkunganstaging seukuran produksi, data sintetis 2 juta produk, CDN aktif
Kriteriaproduk p95 < 300 ms, checkout p95 < 800 ms dan p99 < 2 s, error < 0,5%, oversell = 0

JAVASCRIPT
// perf/flash-sale.js — k6: simulasi flash sale 12.12 (lonjakan 10x dalam 60 detik)
import http from 'k6/http';
import { check, group, sleep } from 'k6';
import { Trend, Rate } from 'k6/metrics';

const checkoutDur = new Trend('checkout_duration', true);
const oversell = new Rate('oversell');

export const options = {
  scenarios: {
    browsing: { executor: 'constant-arrival-rate', rate: 300, timeUnit: '1s', duration: '10m', preAllocatedVUs: 500 },
    lonjakan: { executor: 'ramping-arrival-rate', startRate: 50, timeUnit: '1s', preAllocatedVUs: 2000, startTime: '2m',
                stages: [{ target: 3000, duration: '60s' }, { target: 3000, duration: '3m' }, { target: 50, duration: '1m' }],
                exec: 'beliFlashSale' },
  },
  thresholds: {
    'http_req_duration{name:produk}': ['p(95)<300'],
    checkout_duration: ['p(95)<800', 'p(99)<2000'],
    http_req_failed: ['rate<0.005'],
    oversell: ['rate==0'],                                     // stok tidak boleh terjual melebihi persediaan
  },
};

export default function () {
  http.get(`${__ENV.BASE}/api/produk/flash`, { tags: { name: 'produk' } });
  sleep(Math.random() * 3);
}

export function beliFlashSale() {
  group('checkout flash sale', () => {
    const r = http.post(`${__ENV.BASE}/api/flash/checkout`, JSON.stringify({ sku: 'HP-X12', qty: 1 }),
                        { headers: { 'Content-Type': 'application/json', 'Idempotency-Key': `${__VU}-${__ITER}` } });
    checkoutDur.add(r.timings.duration);
    check(r, { 'diterima atau habis': x => [201, 409].includes(x.status) });
    oversell.add(r.status === 201 && r.json('sisa_stok') < 0);
  });
}
