Besar 4: Asisten keuangan dengan AI on-device dan cloud (Flutter)

Buka versi interaktif

Masalah. Fintech tabungan mikro ingin fitur "tanya keuanganmu": pengguna bertanya dalam bahasa sehari-hari tentang pengeluarannya. Data keuangan sensitif, banyak pengguna berkuota terbatas, dan jawaban angka tidak boleh salah.

Fitur wajib:
1. Router AI: aturan/kalkulator untuk hitungan, model on-device untuk teks pendek, cloud hanya dengan izin
2. Kategorisasi transaksi on-device dengan ambang keyakinan dan konfirmasi pengguna
3. PII disamarkan sebelum meninggalkan perangkat; sakelar cloud mati secara default
4. Transparansi: lencana sumber jawaban, umpan balik 👍/👎, disclaimer saran keuangan
5. Evaluasi otomatis (akurasi angka, kebocoran PII) di CI sebelum rilis

Penyelesaian langkah demi langkah:
1. Kumpulkan 150 pertanyaan nyata dan jawaban acuan sebelum menulis kode AI.
2. Bangun kalkulator berbasis aturan untuk semua pertanyaan hitungan.
3. Integrasikan model on-device; ukur ukuran unduhan, RAM, dan latensi di HP 4 GB.
4. Tambahkan jalur cloud dengan App Check, PII masking, dan sakelar izin.
5. Jalankan evaluasi otomatis di CI; rilis bertahap dengan Remote Config.

Standar industri yang dinilai: angka selalu dari perhitungan, privasi by design, transparansi sumber jawaban, evaluasi otomatis sebelum rilis, fallback offline, biaya cloud terkendali

Arsitektur dan stack (Flutter, Riverpod, MediaPipe LLM Inference / LiteRT (model kecil on-device), Firebase AI Logic (Gemini) + App Check, drift (SQLite terenkripsi), Remote Config, GitHub Actions)
BagianIsi
Jalur jawabanaturan (angka pasti) → on-device (privat, gratis) → cloud (izin + online)
Modelmodel teks kecil terkuantisasi diunduh setelah instalasi lewat Wi-Fi; versi dikontrol Remote Config
PrivasiPII masking, data mentah tidak dikirim, hanya ringkasan; persetujuan terpisah (UU PDP)
Keandalantimeout 8 detik, fallback, jawaban "tidak tahu" lebih baik dari mengarang
Evaluasi150 kasus uji JSONL: akurasi angka 100%, nol PII ke cloud, skor relevansi dinilai manusia per rilis
Biayakuota cloud per pengguna per hari, cache jawaban umum, pemantauan token

// lib/ai/asisten_router.dart  (AI on-device dulu, cloud bila perlu dan diizinkan)
enum Jalur { perangkat, cloud, aturan }

class AsistenRouter {
  AsistenRouter(this._lokal, this._cloud, this._izin, this._jaringan);
  final ModelLokal _lokal;            // model kecil (misal Gemma) via MediaPipe/LiteRT
  final ModelCloud _cloud;            // Gemini lewat Firebase AI Logic (App Check aktif)
  final IzinPengguna _izin;
  final StatusJaringan _jaringan;

  Future<Jawaban> tanya(String teks, List<Transaksi> konteks) async {
    final aman = Pii.samarkan(teks);                                      // nomor rekening, NIK, HP disamarkan
    final ringkas = Ringkas.transaksi(konteks, maksBaris: 40);          // grounding: angka dari data, bukan tebakan

    if (Intent.adalahHitungan(aman)) {                                    // "total jajan minggu ini" -> dihitung, bukan ditebak
      return Jawaban(Kalkulator.jawab(aman, konteks), jalur: Jalur.aturan);
    }
    if (_lokal.tersedia && aman.length < 600) {
      final r = await _lokal.hasilkan(Prompt.keuangan(aman, ringkas)).timeout(const Duration(seconds: 8), onTimeout: () => '');
      if (r.isNotEmpty) return Jawaban(r, jalur: Jalur.perangkat);
    }
    if (_izin.bolehCloud && await _jaringan.online) {
      final r = await _cloud.hasilkan(Prompt.keuangan(aman, ringkas));
      return Jawaban(r, jalur: Jalur.cloud);
    }
    return const Jawaban('Saya belum bisa menjawab tanpa koneksi. Coba pertanyaan yang lebih singkat.', jalur: Jalur.aturan);
  }
}

// lib/ai/kategorisasi.dart  (klasifikasi transaksi on-device: cepat, gratis, privat)
class Kategorisasi {
  Kategorisasi(this._model);
  final ModelTeksKecil _model;                                          // TFLite/LiteRT, < 5 MB
  static const ambang = 0.7;

  Future<String> tebak(String keterangan) async {
    final aturan = AturanKataKunci.cocok(keterangan);                   // "GOPAY", "PLN", "INDOMARET"
    if (aturan != null) return aturan;
    final (label, skor) = await _model.klasifikasi(keterangan);
    return skor >= ambang ? label : 'Perlu dicek';                     // skor rendah -> minta konfirmasi pengguna
  }
}
