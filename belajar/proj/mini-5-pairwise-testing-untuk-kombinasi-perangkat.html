Mini 5: Pairwise testing untuk kombinasi perangkat

Buka versi interaktif

Masalah. Aplikasi mobile bank harus diuji di berbagai OS, ukuran layar, jaringan, bahasa, dan tema: 108 kombinasi. Tim hanya punya waktu untuk belasan. Buat generator pairwise (all-pairs) agar setiap pasangan nilai tetap teruji.

Fitur wajib:
1. Parameter dan nilainya sebagai data
2. Menghitung semua pasangan nilai yang harus tercakup
3. Algoritme greedy memilih kombinasi minimal
4. Tabel hasil siap dipakai sebagai matriks perangkat

Penyelesaian langkah demi langkah:
1. Hitung semua kombinasi dengan itertools.product.
2. Fungsi pasangan(baris) menghasilkan setiap pasangan (parameter, nilai) dari dua kolom.
3. Selama masih ada pasangan belum tercakup, pilih baris yang menutup paling banyak.
4. Cetak jumlah test dan penghematannya dibanding pengujian penuh.

Kembangkan sendiri: tambahkan batasan (tablet tidak dengan Android 11) dan bandingkan hasilnya dengan alat PICT dari Microsoft.

PYTHON
from itertools import combinations, product

# Kombinasi konfigurasi aplikasi mobile bank: uji semua = 3*3*3*2*2 = 108 kombinasi
PARAM = {
    "OS":       ["Android 11", "Android 14", "iOS 18"],
    "layar":    ["360px", "412px", "tablet"],
    "jaringan": ["4G", "3G lambat", "Wi-Fi"],
    "bahasa":   ["ID", "EN"],
    "tema":     ["terang", "gelap"],
}
nama = list(PARAM)
semua = list(product(*PARAM.values()))

def pasangan(baris):
    return {((i, baris[i]), (j, baris[j])) for i, j in combinations(range(len(baris)), 2)}

perlu = set().union(*(pasangan(b) for b in semua))
terpilih = []
while perlu:                                     # greedy: ambil baris yang menutup pasangan terbanyak
    terbaik = max(semua, key=lambda b: len(pasangan(b) & perlu))
    terpilih.append(terbaik); perlu -= pasangan(terbaik)

print(f"semua kombinasi: {len(semua)}  ->  pairwise: {len(terpilih)} test (hemat {1 - len(terpilih)/len(semua):.0%})")
print(" | ".join(f"{n:<10}" for n in nama))
for b in terpilih:
    print(" | ".join(f"{v:<10}" for v in b))
print("Setiap pasangan nilai dari dua parameter mana pun muncul minimal sekali.")
