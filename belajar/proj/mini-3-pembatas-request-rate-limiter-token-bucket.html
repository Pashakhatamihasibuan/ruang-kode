Mini 3: Pembatas request (rate limiter) token bucket

Buka versi interaktif

Masalah. API login dan API AI mahal sering disalahgunakan bot. Setiap pengguna perlu dibatasi, misalnya 5 request per 10 detik dengan sedikit kelonggaran.

Fitur wajib:
1. Batas per pengguna/IP, tidak memengaruhi pengguna lain
2. Mengizinkan ledakan kecil (burst) lalu mengisi ulang perlahan
3. Mengembalikan 429 dan header Retry-After
4. Bisa diuji tanpa menunggu waktu sungguhan

Penyelesaian langkah demi langkah:
1. Token bucket: setiap pengguna punya ember berkapasitas N token; setiap request mengambil 1 token; token terisi ulang r per detik.
2. Hitung isi ulang secara malas saat request datang: token += (sekarang - terakhir) × r, dibatasi kapasitas.
3. Jika token < 1, tolak dan hitung berapa detik sampai token berikutnya tersedia.
4. Suntikkan fungsi waktu (jam) agar test bisa memajukan waktu sesuka hati. Di produksi simpan state di Redis.

Kembangkan sendiri: pasang sebagai middleware Django yang memakai Redis (INCR + EXPIRE atau skrip Lua) agar berlaku di beberapa server.

PYTHON
import math

class TokenBucket:
    def __init__(self, kapasitas, isi_per_detik, jam):
        self.k, self.r, self.jam = kapasitas, isi_per_detik, jam
        self.ember = {}                       # kunci -> (token, waktu_terakhir)

    def izinkan(self, kunci):
        now = self.jam()
        token, t = self.ember.get(kunci, (self.k, now))
        token = min(self.k, token + (now - t) * self.r)
        if token >= 1:
            self.ember[kunci] = (token - 1, now)
            return True, 0
        self.ember[kunci] = (token, now)
        return False, math.ceil((1 - token) / self.r)   # detik untuk Retry-After

waktu = [0.0]
rl = TokenBucket(kapasitas=5, isi_per_detik=0.5, jam=lambda: waktu[0])

hasil = [rl.izinkan('ip-1')[0] for _ in range(7)]
print('7 request beruntun dari ip-1:', hasil)
print('ip-2 tidak terpengaruh      :', rl.izinkan('ip-2'))
print('ip-1 ditolak, Retry-After   :', rl.izinkan('ip-1')[1], 'detik')
waktu[0] += 4
print('4 detik kemudian            :', [rl.izinkan('ip-1')[0] for _ in range(3)])
