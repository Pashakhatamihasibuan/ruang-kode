Besar 4: UX fitur asisten AI di aplikasi perbankan

Buka versi interaktif

Masalah. Bank digital menambahkan asisten AI yang bisa menjawab pertanyaan produk, menjelaskan transaksi, dan mengusulkan tindakan (blokir kartu, transfer rutin). Risikonya besar: jawaban keliru, kepercayaan berlebihan, dan aksi keuangan yang tidak diinginkan.

Fitur wajib:
1. Batas kemampuan AI dijelaskan sejak awal; jawaban diberi label AI dan sumber
2. Tingkat keyakinan memengaruhi tampilan; keyakinan rendah menawarkan eskalasi ke petugas
3. Aksi berisiko melalui pratinjau, konfirmasi eksplisit, dan verifikasi PIN/biometrik
4. Persetujuan data terpisah, tidak dicentang otomatis, dan bisa ditarik (UU PDP)
5. Umpan balik per jawaban dan evaluasi kualitas berkala dengan skenario uji

Penyelesaian langkah demi langkah:
1. Petakan pertanyaan nasabah dari data CS dan pilih kasus di mana AI benar-benar menambah nilai.
2. Rancang pola percakapan, label, dan state (memuat, tidak yakin, gagal, offline).
3. Uji prototype dengan nasabah termasuk skenario jawaban salah untuk mengukur kepercayaan berlebihan.
4. Rancang alur aksi berisiko dengan pratinjau dan verifikasi; review bersama tim risiko dan legal.
5. Rilis bertahap ke 5% pengguna, pantau metrik kualitas dan keselamatan, iterasi.

Standar industri yang dinilai: pengguna tahu sedang berinteraksi dengan AI, jawaban bersumber, aksi keuangan selalu dikonfirmasi manusia, persetujuan data sesuai UU PDP, kualitas dan keselamatan diukur sebelum dan sesudah rilis

Arsitektur dan stack (Figma, prototyping percakapan (Voiceflow/Figma), React/React Native, Claude API dengan tool use, analitik event, Google PAIR Guidebook, Microsoft HAX Toolkit)
BagianIsi
Ekspektasionboarding singkat: apa yang bisa dan tidak bisa, contoh pertanyaan, tautan cara kerja
Transparansilabel AI, sumber per jawaban, keyakinan memengaruhi apakah sumber dibuka otomatis
Kontrolterima/edit/tolak usulan, batalkan, riwayat tindakan, eskalasi ke manusia selalu tersedia
KeamananAI hanya mengusulkan; eksekusi tetap lewat alur transaksi biasa dengan verifikasi
Privasiizin granular, data minimum, retensi percakapan dijelaskan, log persetujuan
Evaluasigolden set 200 pertanyaan, rasio jawaban dengan sumber benar, tingkat eskalasi, CSAT, insiden aksi salah = 0

// components/AsistenJawaban.tsx — pola UX fitur AI di aplikasi bank (transparansi, kontrol, human-in-the-loop)
type Sumber = { judul: string; url: string };
type Jawaban = { teks: string; sumber: Sumber[]; yakin: 'tinggi' | 'sedang' | 'rendah'; aksi?: AksiUsulan };
type AksiUsulan = { jenis: 'transfer' | 'blokir_kartu'; ringkasan: string; payload: unknown };

export function AsistenJawaban({ j, onUmpanBalik, onEskalasi }: Props) {
  return (
    <article className="jawaban-ai" aria-live="polite">
      <header className="label-ai">
        <IkonAI aria-hidden /> Dibuat oleh AI · bisa keliru · <a href="/bantuan/asisten">Cara kerja asisten</a>
      </header>

      <Markdown>{j.teks}</Markdown>

      {j.sumber.length > 0 && (
        <details open={j.yakin !== 'tinggi'}>
          <summary>Sumber ({j.sumber.length})</summary>
          <ul>{j.sumber.map(s => <li key={s.url}><a href={s.url}>{s.judul}</a></li>)}</ul>
        </details>
      )}

      {j.yakin === 'rendah' && (
        <p className="peringatan">Asisten belum yakin. <button onClick={onEskalasi}>Hubungi petugas</button></p>
      )}

      {j.aksi && <PratinjauAksi aksi={j.aksi} />}

      <footer className="umpan-balik">
        <span id="ub">Apakah jawaban ini membantu?</span>
        <button aria-describedby="ub" onClick={() => onUmpanBalik('ya')}>Ya</button>
        <button aria-describedby="ub" onClick={() => onUmpanBalik('tidak')}>Tidak</button>
      </footer>
    </article>
  );
}

// Aksi berisiko tidak pernah dieksekusi otomatis: pratinjau -> konfirmasi eksplisit -> PIN/biometrik -> bisa dibatalkan
function PratinjauAksi({ aksi }: { aksi: AksiUsulan }) {
  const [tahap, setTahap] = useState<'pratinjau' | 'verifikasi' | 'selesai'>('pratinjau');
  if (tahap === 'pratinjau') return (
    <section className="pratinjau" aria-label="Usulan tindakan">
      <h3>Periksa sebelum dijalankan</h3>
      <p>{aksi.ringkasan}</p>
      <button className="utama" onClick={() => setTahap('verifikasi')}>Lanjutkan</button>
      <button onClick={() => track('ai_aksi_ditolak', { jenis: aksi.jenis })}>Batalkan</button>
    </section>
  );
  if (tahap === 'verifikasi') return <VerifikasiPIN onSukses={() => setTahap('selesai')} />;
  return <p role="status">Selesai. <a href="/riwayat">Lihat di riwayat</a></p>;
}

// Persetujuan data (UU PDP + peraturan pelaksana): terpisah dari S&K, tidak dicentang otomatis, bisa ditarik
export function PersetujuanAI() {
  return (
    <fieldset>
      <legend>Izin penggunaan data untuk asisten</legend>
      <label><input type="checkbox" name="riwayat_transaksi" /> Pakai riwayat transaksi 90 hari untuk menjawab pertanyaan saya</label>
      <label><input type="checkbox" name="perbaikan_model" /> Izinkan percakapan saya (tanpa nama & nomor) dipakai memperbaiki layanan</label>
      <p>Izin bisa dicabut kapan saja di <a href="/profil/privasi">Profil &gt; Privasi</a>.</p>
    </fieldset>
  );
}
