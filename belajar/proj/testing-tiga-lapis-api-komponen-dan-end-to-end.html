Testing tiga lapis: API, komponen, dan end-to-end

Buka versi interaktif

Test API dengan pytest-django dan APIClient: paling bernilai karena menguji aturan bisnis dan izin langsung. Test komponen dengan Vitest + Testing Library: memastikan tampilan menampilkan pesan yang benar untuk tiap keadaan. Test end-to-end dengan Playwright: membuka browser sungguhan dan menjalankan alur utama (login → cari → buat pesanan).

Ikuti piramida: banyak test API dan unit, beberapa test komponen, sedikit test E2E untuk alur paling penting. Setiap bug yang ditemukan sebaiknya diikuti test yang mereproduksinya agar tidak kembali.

Jalankan semuanya di CI. Saat wawancara, tunjukkan satu test yang menjaga aturan bisnis: itu bukti kamu berpikir seperti engineer.

PYTHON
# backend/toko/tests/test_pesanan.py
import pytest
from django.contrib.auth.models import User
from rest_framework.test import APIClient
from toko.models import Kategori, Produk

@pytest.fixture
def kasir_client(db):
    c = APIClient()
    c.force_authenticate(User.objects.create_user('kasir1', password='x'))
    return c

@pytest.fixture
def kopi(db):
    return Produk.objects.create(kategori=Kategori.objects.create(nama='Biji'), nama='Kopi Gayo', harga=28000, stok=3)

def test_pesanan_mengurangi_stok_dan_hitung_total(kasir_client, kopi):
    r = kasir_client.post('/api/pesanan/', {'item': [{'produk': kopi.id, 'jumlah': 2}]}, format='json')
    assert r.status_code == 201
    assert r.data['total'] == '56000.00'
    kopi.refresh_from_db()
    assert kopi.stok == 1

def test_stok_kurang_ditolak(kasir_client, kopi):
    r = kasir_client.post('/api/pesanan/', {'item': [{'produk': kopi.id, 'jumlah': 5}]}, format='json')
    assert r.status_code == 400
    kopi.refresh_from_db()
    assert kopi.stok == 3            # tidak berubah karena rollback

def test_kasir_tidak_boleh_ubah_produk(kasir_client, kopi):
    assert kasir_client.patch(f'/api/produk/{kopi.id}/', {'harga': 1}).status_code == 403

Poin penting

  • Test API untuk aturan bisnis dan izin.
  • Test komponen untuk keadaan tampilan; E2E untuk alur utama.
  • Setiap bug → test baru.
