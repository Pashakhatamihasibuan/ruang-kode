PROYEK BESAR: Pipeline data transportasi kota

Masalah
  Pemerintah kota ingin dashboard jumlah penumpang per halte yang diperbarui setiap hari.

Fitur wajib
  1. Ingest data mentah (CSV/API) ke data lake (MinIO/S3)
  2. Transformasi dengan dbt ke star schema di warehouse
  3. Orkestrasi dengan Airflow: retry, alert, backfill
  4. Pemeriksaan kualitas data
  5. Dashboard di atas mart

Stack yang disarankan
  Python, Airflow, dbt, PostgreSQL/DuckDB, MinIO, Docker Compose, Great Expectations atau test dbt

Rencana 4 minggu
  Minggu 1: arsitektur dan ingest
  Minggu 2: model dbt dan test
  Minggu 3: DAG Airflow, backfill, alert
  Minggu 4: dashboard, dokumentasi, diagram arsitektur

Standar industri yang dinilai
  Pipeline idempoten (aman dijalankan ulang), kualitas data diuji, diagram arsitektur di README

Keluaran
  [ ] Repo dengan README lengkap, keputusan teknis, dan screenshot
  [ ] Demo online atau video 2 menit
  [ ] Test/bukti pengujian dan CI hijau (untuk proyek kode)
  [ ] Ringkasan 1 paragraf untuk CV dan LinkedIn

Poin penting

  • Masalah: Pemerintah kota ingin dashboard jumlah penumpang per halte yang diperbarui setiap hari.
  • Stack: Python, Airflow, dbt, PostgreSQL/DuckDB, MinIO, Docker Compose, Great Expectations atau test dbt.
  • Rencana 4 minggu; dinilai dengan rubrik standar industri.
