Besar 4: PWA offline-first untuk kas koperasi desa

Buka versi interaktif

Masalah. Bendahara koperasi di desa dengan sinyal tidak stabil perlu mencatat setoran dan pinjaman anggota tanpa takut data hilang saat internet putus.

Fitur wajib:
1. Bisa dipasang di layar utama HP dan dibuka tanpa internet
2. Catat setoran/penarikan anggota saat offline; disimpan lokal di IndexedDB
3. Sinkron otomatis saat online, dengan penanda "belum terkirim"
4. Konflik ditangani: data tidak ganda walau dikirim ulang
5. Laporan saldo per anggota dan ekspor CSV

Penyelesaian langkah demi langkah:
1. Pasang vite-plugin-pwa: manifest (nama, ikon, warna) dan precache aset build.
2. Buat database Dexie; setiap transaksi diberi crypto.randomUUID() di HP, bukan id dari server.
3. Simpan dulu ke IndexedDB (optimistic), tampilkan langsung di daftar dengan label "belum terkirim".
4. Fungsi sinkron() dipanggil saat event online, saat aplikasi dibuka, dan setiap 60 detik; kirim batch dan tandai terkirim hanya untuk uuid yang diterima server.
5. Server menolak duplikat dengan ON CONFLICT (uuid) DO NOTHING, jadi kirim ulang aman.
6. Uji skenario offline dengan Playwright; ukur ukuran aplikasi agar ringan di HP kelas bawah.

Standar industri yang dinilai: bekerja tanpa internet, tidak ada data ganda saat kirim ulang, status sinkron terlihat jelas, diuji dalam mode offline

Arsitektur dan stack (React + TypeScript (Vite), vite-plugin-pwa (Workbox), Dexie (IndexedDB), API REST mana pun, Playwright mode offline)
BagianIsi
Cangkang aplikasiService worker men-cache HTML, JS, CSS (precache) sehingga aplikasi terbuka tanpa internet
Data lokalDexie: tabel transaksi {uuid, anggota, jenis, nominal, waktu, terkirim}
SinkronAntrian: kirim yang terkirim=0 ke POST /api/transaksi/batch; server memakai uuid sebagai kunci unik (idempoten)
UjiPlaywright context.setOffline(true): catat transaksi, lalu online dan pastikan terkirim sekali
KODE
// src/db.ts
import Dexie, { type Table } from 'dexie';
export type Transaksi = { uuid: string; anggota: string; jenis: 'setor' | 'tarik'; nominal: number; waktu: string; terkirim: 0 | 1 };
class KasDB extends Dexie {
  transaksi!: Table<Transaksi, string>;
  constructor() { super('kas-koperasi'); this.version(1).stores({ transaksi: 'uuid, anggota, terkirim, waktu' }); }
}
export const db = new KasDB();

// src/sinkron.ts
let berjalan = false;
export async function sinkron() {
  if (berjalan || !navigator.onLine) return;
  berjalan = true;
  try {
    const antre = await db.transaksi.where('terkirim').equals(0).limit(100).toArray();
    if (!antre.length) return;
    const r = await fetch('/api/transaksi/batch', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(antre) });
    if (!r.ok) throw new Error('HTTP ' + r.status);
    const { diterima } = (await r.json()) as { diterima: string[] };   // uuid yang sudah tersimpan di server
    await db.transaksi.where('uuid').anyOf(diterima).modify({ terkirim: 1 });
  } catch (e) {
    console.warn('Sinkron gagal, dicoba lagi nanti', e);
  } finally { berjalan = false; }
}
addEventListener('online', sinkron);
setInterval(sinkron, 60_000);

// src/App.tsx (potongan)
import { useLiveQuery } from 'dexie-react-hooks';
export function Catat() {
  const daftar = useLiveQuery(() => db.transaksi.orderBy('waktu').reverse().limit(30).toArray(), []);
  async function simpan(anggota: string, jenis: 'setor' | 'tarik', nominal: number) {
    await db.transaksi.add({ uuid: crypto.randomUUID(), anggota, jenis, nominal, waktu: new Date().toISOString(), terkirim: 0 });
    sinkron();                                   // langsung coba kirim jika online
  }
  return <ul>{daftar?.map(t => <li key={t.uuid}>{t.anggota} {t.jenis} Rp{t.nominal.toLocaleString('id-ID')} {t.terkirim ? '✓' : '⏳ belum terkirim'}</li>)}</ul>;
}
