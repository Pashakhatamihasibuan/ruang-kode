Besar 2: Booking layanan tanpa jadwal bentrok (barbershop/klinik)

Buka versi interaktif

Masalah. Barbershop dan klinik kecil sering double booking karena reservasi lewat chat. Pelanggan ingin melihat slot kosong dan memesan sendiri.

Fitur wajib:
1. Daftar layanan dengan durasi dan staf yang bisa mengerjakan
2. Slot kosong dihitung dari jam kerja, libur, dan booking yang ada
3. Dua pelanggan tidak mungkin memesan slot staf yang sama (dijamin database)
4. Pengingat WhatsApp/email H-1 dan pembatalan dengan tautan
5. Zona waktu benar (WIB/WITA/WIT)

Penyelesaian langkah demi langkah:
1. Simpan waktu booking sebagai DateTimeRangeField dalam UTC; tampilkan sesuai zona waktu cabang.
2. Pasang ExclusionConstraint dengan ekstensi btree_gist: inilah penjamin utama tidak ada bentrok, bahkan saat dua request datang bersamaan.
3. Tangkap IntegrityError dan balas 409 "slot baru saja diambil".
4. Fungsi slot kosong ditulis murni dan diuji dengan banyak kasus (istirahat siang, libur, booking di tengah).
5. Tautan batal memakai django.core.signing sehingga tidak perlu login.

Standar industri yang dinilai: bentrok dicegah oleh constraint database (bukan hanya cek di kode), konflik dibalas 409, waktu disimpan UTC, fungsi slot diuji

Arsitektur dan stack (Django 5, DRF, PostgreSQL (range type + exclusion constraint), Celery, Redis, pytest, Docker)
BagianIsi
ModelStaf, Layanan(durasi), JamKerja(staf, hari, mulai, selesai), Booking(staf, waktu tstzrange, status)
Anti-bentrokExclusionConstraint: waktu tidak boleh tumpang tindih (&&) untuk staf yang sama (=) bila status aktif
SlotFungsi murni: jam kerja − booking − jeda, dipecah per durasi layanan
NotifikasiCelery Beat: pengingat H-1, tautan batal bertanda tangan
PYTHON
# booking/models.py
from django.contrib.postgres.constraints import ExclusionConstraint
from django.contrib.postgres.fields import DateTimeRangeField, RangeOperators
from django.db import models

class Booking(models.Model):
    staf = models.ForeignKey('Staf', on_delete=models.PROTECT)
    layanan = models.ForeignKey('Layanan', on_delete=models.PROTECT)
    pelanggan = models.ForeignKey('Pelanggan', on_delete=models.PROTECT)
    waktu = DateTimeRangeField()
    status = models.CharField(max_length=10, default='AKTIF')

    class Meta:
        constraints = [ExclusionConstraint(
            name='tanpa_bentrok',
            expressions=[('staf', RangeOperators.EQUAL), ('waktu', RangeOperators.OVERLAPS)],
            condition=models.Q(status='AKTIF'))]

# booking/slot.py  (fungsi murni, mudah diuji)
from datetime import datetime, timedelta

def slot_kosong(jam_kerja, terpakai, durasi, langkah=timedelta(minutes=15)):
    """jam_kerja & terpakai: list (mulai, selesai). Kembalikan waktu mulai yang muat."""
    hasil = []
    for mulai, selesai in jam_kerja:
        t = mulai
        while t + durasi <= selesai:
            if all(t + durasi <= a or t >= b for a, b in terpakai):
                hasil.append(t)
            t += langkah
    return hasil

from psycopg.types.range import Range

class BookingViewSet(viewsets.ModelViewSet):
    def create(self, req):
        s = BookingMasukSerializer(data=req.data); s.is_valid(raise_exception=True)

        try:
            with transaction.atomic():
                b = Booking.objects.create(staf=s.validated_data['staf'], layanan=lay, pelanggan=req.user.pelanggan,

# tests/test_slot.py
def test_slot_menghindari_booking_dan_istirahat():
    h = lambda j, m=0: datetime(2026, 12, 1, j, m)
    kerja = [(h(9), h(12)), (h(13), h(17))]                 # istirahat 12-13
    slot = slot_kosong(kerja, [(h(10), h(11))], timedelta(minutes=45), timedelta(minutes=30))
    assert h(9) in slot and h(10) not in slot and h(11) in slot and h(12) not in slot
