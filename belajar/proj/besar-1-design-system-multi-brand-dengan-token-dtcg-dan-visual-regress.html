Besar 1: Design system multi-brand dengan token DTCG dan visual regression

Buka versi interaktif

Masalah. Grup ritel punya 3 brand (supermarket, apotek, elektronik) dengan aplikasi web dan mobile terpisah. Tombol saja ada 27 versi, tema gelap tidak konsisten, dan setiap rebranding butuh 3 bulan kerja developer.

Fitur wajib:
1. Token tiga lapis (primitive → semantic → component) format DTCG, 3 brand × 2 mode
2. Pipeline token ke CSS, Android, dan iOS dari satu sumber
3. Pustaka komponen React dengan semua state (default, hover, focus, disabled, loading, error)
4. Dokumentasi Storybook dengan panduan kapan dipakai dan contoh salah/benar
5. CI: lint kontras, tes aksesibilitas per story, visual regression, semver + changelog

Penyelesaian langkah demi langkah:
1. Audit inventaris UI: tangkap semua varian tombol, warna, dan jarak dari produk yang berjalan.
2. Definisikan token primitive dan semantic bersama tim brand; uji kontras otomatis.
3. Bangun komponen inti (Button, Input, Select, Dialog, Toast) dengan semua state dan dokumentasi.
4. Siapkan pipeline token + Storybook + Chromatic di CI dan rilis versi 1.0.
5. Migrasikan satu alur per brand (checkout) sebagai bukti, ukur adopsi, lalu lanjutkan bertahap.

Standar industri yang dinilai: satu sumber token untuk semua platform, setiap komponen punya semua state dan dokumentasi, aksesibilitas diuji otomatis, perubahan visual direview, rilis bersemver dengan changelog

Arsitektur dan stack (Figma Variables, Tokens Studio, DTCG 2025.10, Style Dictionary v4, React + TypeScript, Storybook 9, Chromatic/Playwright, Changesets, GitHub Actions)
BagianIsi
Tokenprimitive (skala warna 50-950, spacing 4pt) → semantic (peran per mode) → component (button, input, card)
Distribusipaket @grup/tokens dan @grup/ui di registry internal, versi semver
