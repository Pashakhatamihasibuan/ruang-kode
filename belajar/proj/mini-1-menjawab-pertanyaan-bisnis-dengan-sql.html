Mini 1: Menjawab pertanyaan bisnis dengan SQL

Buka versi interaktif

Masalah. Pemilik toko kopi online bertanya: kota mana paling besar omzetnya, bagaimana tren bulanan, dan siapa 3 pelanggan terbaik di tiap kota?

Fitur wajib:
1. Omzet dan jumlah pesanan per kota, diurutkan
2. Tren omzet per bulan dan pertumbuhan dibanding bulan lalu (MoM)
3. Top 3 pelanggan per kota dengan window function
4. Setiap jawaban ditutup satu kalimat kesimpulan

Penyelesaian langkah demi langkah:
1. Muat data ke database (di sini SQLite di memori) lalu jawab dengan SQL murni.
2. GROUP BY kota + SUM, COUNT, dan ORDER BY.
3. strftime('%Y-%m') untuk bulan, lalu LAG() untuk bulan sebelumnya; MoM = (sekarang − lalu) / lalu.
4. ROW_NUMBER() OVER (PARTITION BY kota ORDER BY total DESC) lalu ambil peringkat ≤ 3.

Kembangkan sendiri: hitung kontribusi persen tiap kota dengan SUM() OVER () dan buat view untuk dashboard.
