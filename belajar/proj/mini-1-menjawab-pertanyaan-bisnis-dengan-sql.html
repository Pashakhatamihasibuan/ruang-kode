Mini 1: Menjawab pertanyaan bisnis dengan SQL

Buka versi interaktif

Masalah. Pemilik toko kopi online bertanya: kota mana paling besar omzetnya, bagaimana tren bulanan, dan siapa 3 pelanggan terbaik di tiap kota?

Fitur wajib:
1. Omzet dan jumlah pesanan per kota, diurutkan
2. Tren omzet per bulan dan pertumbuhan dibanding bulan lalu (MoM)
3. Top 3 pelanggan per kota dengan window function
4. Setiap jawaban ditutup satu kalimat kesimpulan

Penyelesaian langkah demi langkah:
1. Muat data ke database (di sini SQLite di memori) lalu jawab dengan SQL murni.
2. GROUP BY kota + SUM, COUNT, dan ORDER BY.
3. strftime('%Y-%m') untuk bulan, lalu LAG() untuk bulan sebelumnya; MoM = (sekarang − lalu) / lalu.
4. ROW_NUMBER() OVER (PARTITION BY kota ORDER BY total DESC) lalu ambil peringkat ≤ 3.

Kembangkan sendiri: hitung kontribusi persen tiap kota dengan SUM() OVER () dan buat view untuk dashboard.

PYTHON
import sqlite3, numpy as np, pandas as pd
rng = np.random.default_rng(11)
n = 1200
df = pd.DataFrame({
    'id_pesanan': range(1, n + 1),
    'tanggal': pd.to_datetime('2026-01-01') + pd.to_timedelta(rng.integers(0, 181, n), unit='D'),
    'pelanggan': rng.integers(1, 301, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan', 'Makassar'], n, p=[.35, .2, .2, .15, .1]),
    'kategori': rng.choice(['Kopi', 'Teh', 'Camilan', 'Alat Seduh'], n, p=[.45, .2, .25, .1]),
})
harga = {'Kopi': 65000, 'Teh': 40000, 'Camilan': 25000, 'Alat Seduh': 210000}
df['jumlah'] = rng.integers(1, 4, n)
df['nilai'] = df['kategori'].map(harga) * df['jumlah']
con = sqlite3.connect(':memory:')
df.assign(tanggal=df['tanggal'].dt.strftime('%Y-%m-%d')).to_sql('pesanan', con, index=False)
q = lambda s: pd.read_sql(s, con)

print(q('''SELECT kota, COUNT(*) AS pesanan, SUM(nilai) AS omzet
           FROM pesanan GROUP BY kota ORDER BY omzet DESC'''))

print(q('''WITH b AS (SELECT strftime('%Y-%m', tanggal) AS bulan, SUM(nilai) AS omzet FROM pesanan GROUP BY bulan)
           SELECT bulan, omzet,
                  ROUND(100.0 * (omzet - LAG(omzet) OVER (ORDER BY bulan)) / LAG(omzet) OVER (ORDER BY bulan), 1) AS mom_persen
           FROM b'''))

print(q('''WITH t AS (SELECT kota, pelanggan, SUM(nilai) AS total FROM pesanan GROUP BY kota, pelanggan),
                r AS (SELECT *, ROW_NUMBER() OVER (PARTITION BY kota ORDER BY total DESC) AS peringkat FROM t)
           SELECT kota, peringkat, pelanggan, total FROM r WHERE peringkat <= 3 AND kota IN ('Jakarta', 'Medan')'''))
print('Kesimpulan: Jakarta menyumbang omzet terbesar; fokuskan promo retensi pada pelanggan teratas tiap kota.')
