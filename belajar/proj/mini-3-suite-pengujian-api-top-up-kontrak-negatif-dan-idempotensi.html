Mini 3: Suite pengujian API top-up: kontrak, negatif, dan idempotensi

Buka versi interaktif

Masalah. Fintech mengalami saldo pengguna bertambah dua kali saat aplikasi melakukan retry karena jaringan putus. Buat suite pengujian API yang memeriksa kode status, kontrak respons, kasus negatif, dan perilaku idempoten.

Fitur wajib:
1. Server API lokal sungguhan sebagai sistem yang diuji
2. Kasus positif dan negatif (422, 404, 400) dengan kode status tepat
3. Validasi kontrak respons per kode status
4. Uji retry: 3 permintaan dengan Idempotency-Key sama hanya memproses sekali

Penyelesaian langkah demi langkah:
1. Jalankan HTTPServer di port acak pada thread terpisah.
2. Buat fungsi post() yang mengembalikan (kode, isi) termasuk untuk HTTPError.
3. Simpan kontrak sebagai skema sederhana per kode status dan cek tipe setiap field.
4. Kirim permintaan yang sama 3 kali dengan key tetap dan pastikan saldo hanya naik sekali.

Kembangkan sendiri: tulis ulang dengan pytest + httpx, ambil kontrak dari file OpenAPI dengan schemathesis, dan tambahkan uji konkurensi dua retry yang tiba bersamaan.
