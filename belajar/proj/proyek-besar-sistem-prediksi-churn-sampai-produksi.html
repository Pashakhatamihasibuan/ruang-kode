Proyek besar (capstone) jalur Data Scientist. Masalahnya nyata: Perusahaan langganan ingin menghubungi pelanggan berisiko sebelum mereka berhenti. Kerjakan dalam sekitar 4 minggu dengan rencana mingguan di bawah.

Perlakukan seperti pekerjaan di tim: tulis kebutuhan dulu, pecah menjadi issue di GitHub Projects, kerjakan per branch dan pull request, dan catat keputusan teknis di README. Nilai dirimu dengan rubrik di modul pertama jalur ini.

Yang membedakan proyek ini dari tutorial: tidak ada kebocoran data, metrik sesuai bisnis, eksperimen tercatat, model bisa dipanggil lewat API. Itulah yang akan kamu ceritakan saat wawancara.

PROYEK BESAR: Sistem prediksi churn sampai produksi

Masalah
  Perusahaan langganan ingin menghubungi pelanggan berisiko sebelum mereka berhenti.

Fitur wajib
  1. EDA dan definisi target yang bebas kebocoran data
  2. Pipeline fitur + model (boosting) dengan validasi silang
  3. Pilih ambang berdasarkan biaya bisnis
  4. API prediksi (FastAPI) dengan Docker
  5. Pemantauan drift dan laporan dampak

Stack yang disarankan
  Python, pandas, scikit-learn, LightGBM, MLflow, FastAPI, Docker, GitHub Actions

Rencana 4 minggu
  Minggu 1: EDA dan definisi masalah
  Minggu 2: fitur, model, validasi
  Minggu 3: API, Docker, test
  Minggu 4: pemantauan, model card, presentasi

Standar industri yang dinilai
  Tidak ada kebocoran data, metrik sesuai bisnis, eksperimen tercatat, model bisa dipanggil lewat API

Keluaran
  [ ] Repo dengan README lengkap, keputusan teknis, dan screenshot
  [ ] Demo online atau video 2 menit
  [ ] Test/bukti pengujian dan CI hijau (untuk proyek kode)
  [ ] Ringkasan 1 paragraf untuk CV dan LinkedIn

Poin penting

  • Masalah: Perusahaan langganan ingin menghubungi pelanggan berisiko sebelum mereka berhenti.
  • Stack: Python, pandas, scikit-learn, LightGBM, MLflow, FastAPI, Docker, GitHub Actions.
  • Rencana 4 minggu; dinilai dengan rubrik standar industri.
