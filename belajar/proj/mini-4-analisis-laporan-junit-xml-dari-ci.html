Mini 4: Analisis laporan JUnit XML dari CI

Buka versi interaktif

Masalah. Pipeline E2E sering merah dan tim mulai mengabaikannya. Buat analis laporan JUnit XML dari beberapa run CI untuk membedakan regresi nyata, tes flaky, dan lonjakan durasi.

Fitur wajib:
1. Membaca JUnit XML (format standar pytest, Playwright, Maven)
2. Riwayat lulus/gagal per tes lintas run
3. Klasifikasi: regresi, kemungkinan flaky, lonjakan durasi
4. Ringkasan pass rate untuk laporan harian

Penyelesaian langkah demi langkah:
1. Parse setiap XML dengan ElementTree dan iterasi elemen testcase.
2. Kumpulkan riwayat (L/G), durasi, dan pesan kegagalan per nama tes.
3. Gagal-lulus-gagal dengan timeout = kandidat flaky; gagal berturut-turut sejak run tertentu = regresi.
4. Cetak tabel dan pass rate; kirim ke Slack di pipeline nyata.

Kembangkan sendiri: simpan hasil ke SQLite setiap run, hitung flakiness rate 30 hari, dan buat otomatis tiket Jira untuk tes yang flaky lebih dari 5%.
