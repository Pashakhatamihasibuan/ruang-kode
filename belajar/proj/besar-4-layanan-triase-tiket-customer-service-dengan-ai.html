Besar 4: Layanan triase tiket customer service dengan AI

Buka versi interaktif

Masalah. Tim CS menerima ratusan pesan per hari. Mereka butuh sistem yang otomatis meringkas, memberi kategori dan prioritas, serta menyarankan balasan, dengan manusia tetap memutuskan.

Fitur wajib:
1. Terima tiket dari email/form/WhatsApp ke satu antrean
2. LLM menghasilkan ringkasan, kategori, prioritas, dan draf balasan dalam JSON terstruktur
3. Agen CS menyetujui, mengedit, atau menolak saran (human-in-the-loop)
4. Data pribadi (nomor HP, NIK) disamarkan sebelum dikirim ke model
5. Evaluasi: akurasi kategori dibanding label manusia, biaya per tiket, waktu respons

Penyelesaian langkah demi langkah:
1. Definisikan kategori yang tetap (Pembayaran, Pengiriman, Akun, Produk, Lainnya) dan aturan prioritas.
2. Saring data pribadi dulu, lalu panggil model dengan instruksi jelas dan skema keluaran; validasi dengan Pydantic, ulangi sekali jika tidak valid.
3. Jalankan di Celery dengan retry dan batas waktu; jika model gagal, tiket tetap masuk antrean tanpa saran.
4. Simpan saran terpisah dari keputusan agen; catat apakah agen menyetujui atau mengedit.
5. Buat perintah manage.py evaluasi_triase untuk menghitung akurasi pada set berlabel.

Standar industri yang dinilai: keluaran AI terstruktur dan divalidasi, manusia tetap memutuskan, data pribadi disamarkan, kualitas diukur dengan set evaluasi

Arsitektur dan stack (Django 5, DRF, Celery, PostgreSQL, Claude API (structured output via tool use), pytest, Langfuse/log sendiri untuk evaluasi)
BagianIsi
AlurTiket masuk → Celery triase → simpan saran → agen meninjau → balasan dikirim
Keluaran modelSkema tetap {ringkasan, kategori, prioritas, draf_balasan, yakin} divalidasi Pydantic
PrivasiRegex menyamarkan nomor HP, email, NIK sebelum dikirim; teks asli tetap di database
EvaluasiSet 200 tiket berlabel; laporan akurasi per kategori setiap ganti prompt/model
PYTHON
# triase/llm.py
import json, re
import anthropic
from pydantic import BaseModel, Field, ValidationError
from typing import Literal

class Saran(BaseModel):
    ringkasan: str = Field(max_length=300)
    kategori: Literal['Pembayaran', 'Pengiriman', 'Akun', 'Produk', 'Lainnya']
    prioritas: Literal['tinggi', 'sedang', 'rendah']
    draf_balasan: str
    yakin: float = Field(ge=0, le=1)

POLA = [(re.compile(r'(\+62|0)8\d{8,11}'), '[NOMOR_HP]'), (re.compile(r'\b\d{16}\b'), '[NIK]'),
        (re.compile(r'[\w.+-]+@[\w-]+\.[\w.]+'), '[EMAIL]')]

def samarkan(teks: str) -> str:
    for pola, ganti in POLA:
        teks = pola.sub(ganti, teks)
    return teks

klien = anthropic.Anthropic()
INSTRUKSI = ('Kamu membantu tim CS toko online Indonesia. Baca tiket, lalu panggil tool simpan_saran. '
             'Prioritas tinggi jika uang pelanggan tertahan atau akun diretas. Balasan sopan, bahasa Indonesia, '
             'jangan menjanjikan pengembalian dana.')

def triase(teks_tiket: str) -> Saran:
    for percobaan in range(2):
        r = klien.messages.create(
            model='claude-sonnet-4-5', max_tokens=800, system=INSTRUKSI,
            tools=[{'name': 'simpan_saran', 'description': 'Simpan hasil triase', 'input_schema': Saran.model_json_schema()}],
            tool_choice={'type': 'tool', 'name': 'simpan_saran'},
            messages=[{'role': 'user', 'content': samarkan(teks_tiket)}])
        try:
            return Saran.model_validate(r.content[0].input)
        except ValidationError:
            continue
    raise ValueError('Keluaran model tidak valid')

# triase/tasks.py
@shared_task(autoretry_for=(anthropic.APIConnectionError, anthropic.RateLimitError), retry_backoff=True, max_retries=4, time_limit=60)
def proses_tiket(tiket_id):
    t = Tiket.objects.get(pk=tiket_id)
    try:
        s = triase(t.isi)
    except ValueError:
        t.status = 'PERLU_MANUAL'; t.save(); return
    SaranAI.objects.update_or_create(tiket=t, defaults=s.model_dump())
    t.status = 'MENUNGGU_TINJAUAN'; t.save()

# triase/management/commands/evaluasi_triase.py
class Command(BaseCommand):
    def handle(self, *a, **kw):
        data = Tiket.objects.filter(label_manual__isnull=False)[:200]
        benar = sum(triase(t.isi).kategori == t.label_manual for t in data)
        self.stdout.write(f'Akurasi kategori: {benar}/{len(data)} = {benar / len(data):.0%}')
