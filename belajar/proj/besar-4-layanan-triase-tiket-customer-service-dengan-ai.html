Besar 4: Layanan triase tiket customer service dengan AI

Buka versi interaktif

Masalah. Tim CS menerima ratusan pesan per hari. Mereka butuh sistem yang otomatis meringkas, memberi kategori dan prioritas, serta menyarankan balasan, dengan manusia tetap memutuskan.

Fitur wajib:
1. Terima tiket dari email/form/WhatsApp ke satu antrean
2. LLM menghasilkan ringkasan, kategori, prioritas, dan draf balasan dalam JSON terstruktur
3. Agen CS menyetujui, mengedit, atau menolak saran (human-in-the-loop)
4. Data pribadi (nomor HP, NIK) disamarkan sebelum dikirim ke model
5. Evaluasi: akurasi kategori dibanding label manusia, biaya per tiket, waktu respons

Penyelesaian langkah demi langkah:
1. Definisikan kategori yang tetap (Pembayaran, Pengiriman, Akun, Produk, Lainnya) dan aturan prioritas.
2. Saring data pribadi dulu, lalu panggil model dengan instruksi jelas dan skema keluaran; validasi dengan Pydantic, ulangi sekali jika tidak valid.
3. Jalankan di Celery dengan retry dan batas waktu; jika model gagal, tiket tetap masuk antrean tanpa saran.
4. Simpan saran terpisah dari keputusan agen; catat apakah agen menyetujui atau mengedit.
5. Buat perintah manage.py evaluasi_triase untuk menghitung akurasi pada set berlabel.

Standar industri yang dinilai: keluaran AI terstruktur dan divalidasi, manusia tetap memutuskan, data pribadi disamarkan, kualitas diukur dengan set evaluasi

Arsitektur dan stack (Django 5, DRF, Celery, PostgreSQL, Claude API (structured output via tool use), pytest, Langfuse/log sendiri untuk evaluasi)
BagianIsi
AlurTiket masuk → Celery triase → simpan saran → agen meninjau → balasan dikirim
Keluaran modelSkema tetap {ringkasan, kategori, prioritas, draf_balasan, yakin} divalidasi Pydantic
PrivasiRegex menyamarkan nomor HP, email, NIK sebelum dikirim; teks asli tetap di database
EvaluasiSet 200 tiket berlabel; laporan akurasi per kategori setiap ganti prompt/model

Poin penting

  • Proyek besar: Layanan triase tiket customer service dengan AI.
  • Stack: Django 5, DRF, Celery, PostgreSQL, Claude API (structured output via tool use), pytest, Langfuse/log sendiri untuk evaluasi.
  • Kerjakan dulu sendiri, lalu buka kode final untuk code review.
