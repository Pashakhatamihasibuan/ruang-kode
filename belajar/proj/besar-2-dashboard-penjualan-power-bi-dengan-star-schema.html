Besar 2: Dashboard penjualan Power BI dengan star schema

Buka versi interaktif

Masalah. Distributor FMCG punya data penjualan dari 3 sistem (ERP, kasir, marketplace). Laporan dibuat manual di Excel setiap Senin dan sering salah.

Fitur wajib:
1. Model star schema: fakta penjualan + dimensi tanggal, produk, toko, sales
2. Pembersihan dan penggabungan sumber dengan Power Query atau SQL
3. Measure DAX: omzet, margin, YoY, target vs realisasi, peringkat produk
4. Halaman ringkasan eksekutif, analisis wilayah, dan drill-through produk
5. Row-level security: manajer area hanya melihat wilayahnya; refresh terjadwal

Penyelesaian langkah demi langkah:
1. Petakan sumber data dan tentukan grain fakta: satu baris = satu produk per transaksi per toko.
2. Buat dimensi dengan surrogate key; tabel kalender lengkap dengan kolom libur nasional dan minggu ISO.
3. Muat dan bersihkan di Power Query (atau view SQL); relasi satu-ke-banyak satu arah dari dimensi ke fakta.
4. Tulis measure DAX terpusat; visual hanya memakai measure, bukan kolom mentah.
5. Desain halaman: pertanyaan utama di kiri atas, filter konsisten, drill-through ke detail produk.
6. Publikasikan, atur refresh terjadwal dan RLS, uji angka dengan query SQL independen.

Standar industri yang dinilai: grain fakta jelas, measure terpusat, RLS diuji dengan "View as role", angka diverifikasi silang dengan SQL

Arsitektur dan stack (SQL Server/PostgreSQL, Power Query, Power BI Desktop & Service, DAX, (opsional) Microsoft Fabric)
BagianIsi
FaktaFaktaPenjualan(tanggal_key, produk_key, toko_key, sales_key, qty, nilai, hpp)
DimensiDimTanggal (kalender lengkap, libur nasional), DimProduk, DimToko(wilayah, area), DimSales
MeasureOmzet, Margin %, Omzet YoY %, Pencapaian Target %, Peringkat Produk
KeamananRLS: DimToko[area] = USERPRINCIPALNAME() dipetakan ke tabel akses
CONTOH
-- DAX: measure inti (tabel _Measures)
Omzet = SUM ( FaktaPenjualan[nilai] )
HPP = SUM ( FaktaPenjualan[hpp] )
Margin % = DIVIDE ( [Omzet] - [HPP], [Omzet] )

Omzet Tahun Lalu = CALCULATE ( [Omzet], SAMEPERIODLASTYEAR ( DimTanggal[Tanggal] ) )
Omzet YoY % = DIVIDE ( [Omzet] - [Omzet Tahun Lalu], [Omzet Tahun Lalu] )

Target = SUM ( Target[nilai_target] )
Pencapaian % = DIVIDE ( [Omzet], [Target] )
Status Target = SWITCH ( TRUE (), [Pencapaian %] >= 1, "✅ Tercapai", [Pencapaian %] >= 0.9, "⚠️ Hampir", "❌ Di bawah" )

Peringkat Produk = RANKX ( ALLSELECTED ( DimProduk[nama] ), [Omzet], , DESC, DENSE )
Omzet Kumulatif = CALCULATE ( [Omzet], DATESYTD ( DimTanggal[Tanggal] ) )

-- RLS (Manage roles -> ManajerArea)
-- DimToko: [area] IN CALCULATETABLE ( VALUES ( Akses[area] ), Akses[email] = USERPRINCIPALNAME () )

-- SQL: view dimensi kalender (sumber DimTanggal)
CREATE VIEW dim_tanggal AS
SELECT d::date AS tanggal, CAST(to_char(d, 'YYYYMMDD') AS int) AS tanggal_key,
       EXTRACT(year FROM d) AS tahun, EXTRACT(month FROM d) AS bulan, to_char(d, 'TMMonth') AS nama_bulan,
       EXTRACT(isodow FROM d) IN (6, 7) AS akhir_pekan, l.nama IS NOT NULL AS libur_nasional
FROM generate_series('2024-01-01'::date, '2027-12-31', '1 day') d
LEFT JOIN libur_nasional l ON l.tanggal = d::date;

-- Uji silang angka dashboard (harus sama dengan kartu Omzet bulan Oktober 2026)
SELECT SUM(nilai) FROM fakta_penjualan f JOIN dim_tanggal t USING (tanggal_key)
WHERE t.tahun = 2026 AND t.bulan = 10;
