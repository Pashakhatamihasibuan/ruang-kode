Proyek Portofolio · Modul 2 · Konsep & kode

Model, migrasi, dan admin

Buka versi interaktif

Tulis model sesuai rancangan tabel. DecimalField untuk uang, PositiveIntegerField untuk stok, dan Meta.constraints untuk CHECK sehingga aturan juga ada di database.

makemigrations membuat berkas migrasi dari perubahan model, migrate menjalankannya ke database. Berkas migrasi ikut di-commit.

Daftarkan model ke Django admin: kamu langsung punya panel untuk mengisi data demo tanpa menulis frontend apa pun.

PYTHON
# toko/models.py
from django.conf import settings
from django.db import models

class Kategori(models.Model):
    nama = models.CharField(max_length=60, unique=True)
    def __str__(self): return self.nama

class Produk(models.Model):
    kategori = models.ForeignKey(Kategori, on_delete=models.PROTECT, related_name='produk')
    nama = models.CharField(max_length=120)
    harga = models.DecimalField(max_digits=12, decimal_places=2)
    stok = models.PositiveIntegerField(default=0)
    aktif = models.BooleanField(default=True)
    dibuat = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ['nama']
        constraints = [models.CheckConstraint(condition=models.Q(harga__gt=0), name='harga_positif')]

class Pesanan(models.Model):
    kasir = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.PROTECT)
    total = models.DecimalField(max_digits=12, decimal_places=2, default=0)
    dibuat = models.DateTimeField(auto_now_add=True, db_index=True)

class ItemPesanan(models.Model):
    pesanan = models.ForeignKey(Pesanan, on_delete=models.CASCADE, related_name='item')
    produk = models.ForeignKey(Produk, on_delete=models.PROTECT)
    jumlah = models.PositiveIntegerField()
    harga_saat = models.DecimalField(max_digits=12, decimal_places=2)

# terminal
# python manage.py makemigrations toko
# python manage.py migrate

Poin penting

  • Model = tabel; DecimalField untuk uang.
  • Constraint juga dideklarasikan di model.
  • makemigrations + migrate, migrasi di-commit.

Cek pemahaman

on_delete=PROTECT pada produk di item pesanan berarti?

Jawaban: Produk yang pernah dijual tidak bisa dihapus

Melindungi riwayat transaksi; nonaktifkan produk sebagai gantinya.
