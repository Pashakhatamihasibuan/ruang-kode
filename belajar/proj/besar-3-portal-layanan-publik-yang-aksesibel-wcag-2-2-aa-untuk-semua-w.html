Besar 3: Portal layanan publik yang aksesibel (WCAG 2.2 AA) untuk semua warga

Buka versi interaktif

Masalah. Pemerintah daerah meluncurkan portal layanan kependudukan (KTP, KK, akta). Penggunanya beragam: lansia, penyandang disabilitas netra, warga di daerah 3G, dan pengguna HP 2 GB RAM. Versi lama gagal audit aksesibilitas dan antrean di kantor tetap panjang.

Fitur wajib:
1. Riset kontekstual di kantor layanan dan wawancara kelompok rentan (lansia, netra, literasi rendah)
2. Bahasa sederhana, ikon berlabel, bantuan konsisten di setiap halaman (3.2.6)
3. Formulir bertahap dengan simpan otomatis, tanpa input ulang (3.3.7), error terhubung ke field
4. Login dengan OTP yang bisa ditempel atau passkey (3.3.8), tanpa CAPTCHA teka-teki
5. Tes otomatis axe + keyboard + reflow 320px di CI, plus uji manual dengan screen reader

Penyelesaian langkah demi langkah:
1. Lakukan riset di 3 kantor layanan dan rekrut partisipan dari kelompok rentan.
2. Susun service blueprint dari warga sampai petugas back-office.
3. Rancang dan uji formulir bertahap dengan bahasa sederhana; ulangi tiap 2 minggu.
4. Bangun dengan HTML semantik dan tes otomatis aksesibilitas di setiap PR.
5. Audit manual dengan screen reader, terbitkan pernyataan aksesibilitas, dan pantau metrik layanan.

Standar industri yang dinilai: WCAG 2.2 AA lulus otomatis dan manual, bisa dipakai dengan keyboard dan screen reader, berfungsi di jaringan lambat dan HP murah, bahasa sederhana, pernyataan aksesibilitas publik

Arsitektur dan stack (Figma, GOV-style design pattern, HTML semantik + progressive enhancement, Next.js atau Astro (SSR, JS minimal), Playwright + axe-core, NVDA/TalkBack/VoiceOver, Lighthouse CI)
BagianIsi
Prinsipmulai dari kebutuhan warga, satu hal per halaman, bekerja tanpa JavaScript, hemat data
Kontentingkat keterbacaan setara kelas 6 SD, istilah dijelaskan, contoh isian (NIK 16 angka)
AksesibilitasWCAG 2.2 AA; fokus tidak tertutup header tempel (2.4.11), target ≥ 24px dan praktiknya 48px
Kinerjahalaman < 200 KB, LCP < 2,5 s di 3G, berfungsi di Android 9+
Privasidata minimum, persetujuan terpisah, penjelasan tujuan per data (UU PDP)
Pengukurancompletion rate online, waktu layanan, antrean fisik, CSAT, laporan aksesibilitas publik
TYPESCRIPT
// tests/a11y.spec.ts — Playwright + axe: setiap halaman layanan diuji WCAG 2.2 AA di CI
import { test, expect } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

const HALAMAN = ['/', '/layanan/ktp', '/layanan/ktp/formulir', '/antrean', '/status', '/bantuan'];

for (const url of HALAMAN) {
  test(`a11y ${url}`, async ({ page }) => {
    await page.goto(url);
    const hasil = await new AxeBuilder({ page }).withTags(['wcag2a', 'wcag2aa', 'wcag21aa', 'wcag22aa']).analyze();
    expect(hasil.violations, JSON.stringify(hasil.violations.map(v => v.id))).toEqual([]);
  });
}

test('formulir bisa diselesaikan hanya dengan keyboard', async ({ page }) => {
  await page.goto('/layanan/ktp/formulir');
  await page.keyboard.press('Tab');                                  // skip link muncul pertama
  await expect(page.getByRole('link', { name: 'Langsung ke isi' })).toBeFocused();
  await page.getByLabel('NIK').fill('3201234567890001');
  await page.getByLabel('Nomor HP').fill('081234567890');
  await page.getByRole('button', { name: 'Lanjut' }).press('Enter');
  await expect(page.getByRole('heading', { name: 'Unggah dokumen' })).toBeVisible();
});

test('pesan error terhubung ke field dan diumumkan', async ({ page }) => {
  await page.goto('/layanan/ktp/formulir');
  await page.getByRole('button', { name: 'Lanjut' }).click();
  const nik = page.getByLabel('NIK');
  await expect(nik).toHaveAttribute('aria-invalid', 'true');
  await expect(nik).toHaveAccessibleDescription('NIK harus 16 angka. Lihat di KTP lama atau Kartu Keluarga.');
});

test('zoom 200% dan lebar 320px tanpa scroll horizontal (1.4.10 Reflow)', async ({ page }) => {
  await page.setViewportSize({ width: 320, height: 640 });
  await page.goto('/layanan/ktp');
  const lebar = await page.evaluate(() => document.documentElement.scrollWidth);
  expect(lebar).toBeLessThanOrEqual(320);
});

test('login tanpa tes kognitif (3.3.8): OTP bisa ditempel', async ({ page }) => {
  await page.goto('/masuk');
  const otp = page.getByLabel('Kode OTP');
  await expect(otp).toHaveAttribute('autocomplete', 'one-time-code');
  await expect(otp).not.toHaveAttribute('onpaste', /.+/);
});

Poin penting

  • Proyek besar: Portal layanan publik yang aksesibel (WCAG 2.2 AA) untuk semua warga.
  • Stack: Figma, GOV-style design pattern, HTML semantik + progressive enhancement, Next.js atau Astro (SSR, JS minimal), Playwright + axe-core, NVDA/TalkBack/VoiceOver, Lighthouse CI.
  • Berkas inti penyelesaian ada di bawah; sisanya mengikuti pola yang sama.

Cek pemahaman

Apa tuntutan kriteria WCAG 2.2 3.3.8 Accessible Authentication (Minimum)?

Jawaban: Login tidak boleh bergantung pada tes kognitif seperti mengingat atau menyalin karakter tanpa alternatif; izinkan paste, password manager, OTP, atau passkey

Kriteria baru di WCAG 2.2.
