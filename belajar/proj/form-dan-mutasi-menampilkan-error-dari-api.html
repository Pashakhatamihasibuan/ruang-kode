Form dan mutasi: menampilkan error dari API

Buka versi interaktif

Untuk mengubah data, pakai useMutation. Setelah berhasil, panggil invalidateQueries(['produk']) agar daftar produk otomatis dimuat ulang dengan data terbaru.

Validasi dua kali: di browser untuk umpan balik cepat (wajib diisi, angka positif), dan di server sebagai sumber kebenaran. Error 400 dari DRF berbentuk {"nama": ["..."]}, jadi bisa langsung ditampilkan di bawah input yang tepat.

Nonaktifkan tombol saat menyimpan agar tidak terkirim dua kali, hubungkan pesan error dengan input lewat aria-describedby, dan beri tahu pengguna saat berhasil.

KODE
// src/pages/FormProduk.tsx
import { useState } from 'react';
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { api, ApiError, type Produk } from '../api/client';

type Masukan = { nama: string; harga: string; stok: number; kategori: number };

export default function FormProduk() {
  const qc = useQueryClient();
  const [f, setF] = useState<Masukan>({ nama: '', harga: '', stok: 0, kategori: 1 });
  const simpan = useMutation({
    mutationFn: (data: Masukan) => api<Produk>('/produk/', { method: 'POST', body: JSON.stringify(data) }),
    onSuccess: () => { qc.invalidateQueries({ queryKey: ['produk'] }); setF({ nama: '', harga: '', stok: 0, kategori: 1 }); },
  });
  const err = simpan.error instanceof ApiError ? (simpan.error.data as Record<string, string[]>) : {};

  return (
    <form onSubmit={(e) => { e.preventDefault(); simpan.mutate(f); }} noValidate>
      <label htmlFor="nama">Nama produk</label>
      <input id="nama" value={f.nama} required aria-invalid={!!err.nama} aria-describedby="nama-err"
             onChange={(e) => setF({ ...f, nama: e.target.value })} />
      {err.nama && <p id="nama-err" role="alert">{err.nama[0]}</p>}

      <label htmlFor="harga">Harga (Rp)</label>
      <input id="harga" inputMode="numeric" value={f.harga} aria-describedby="harga-err"
             onChange={(e) => setF({ ...f, harga: e.target.value.replace(/\D/g, '') })} />
      {err.harga && <p id="harga-err" role="alert">{err.harga[0]}</p>}

      {simpan.error instanceof ApiError && simpan.error.status === 403 && <p role="alert">Hanya admin yang boleh menambah produk.</p>}
      <button disabled={simpan.isPending}>{simpan.isPending ? 'Menyimpan...' : 'Simpan produk'}</button>
      {simpan.isSuccess && <p role="status">Produk tersimpan.</p>}
    </form>
  );
}

Poin penting

  • useMutation + invalidateQueries untuk menyegarkan data.
  • Server adalah sumber kebenaran validasi; tampilkan error per field.
  • Tombol nonaktif saat menyimpan; error terhubung ke input.
