Mini 4: Membaca hasil A/B test halaman checkout

Buka versi interaktif

Masalah. Tim produk mengubah tombol checkout. Versi B tampak lebih banyak konversinya. Apakah perbedaan ini nyata atau kebetulan, dan seberapa besar dampaknya?

Fitur wajib:
1. Hitung tingkat konversi tiap versi
2. Uji dua proporsi (z-test) dan p-value
3. Selang kepercayaan 95% untuk selisih konversi
4. Rekomendasi dalam bahasa bisnis, termasuk perkiraan tambahan pesanan per bulan

Penyelesaian langkah demi langkah:
1. Konversi = jumlah membeli ÷ jumlah pengunjung.
2. Hitung proporsi gabungan dan galat baku; z = selisih ÷ galat baku; p-value dua sisi dari distribusi normal.
3. Selang kepercayaan selisih: selisih ± 1,96 × galat baku (tanpa penggabungan).
4. Terjemahkan ke dampak: selisih × pengunjung bulanan. Sebutkan juga batas bawahnya agar tidak terlalu optimis.

Kembangkan sendiri: hitung ukuran sampel minimum sebelum tes dimulai, dan periksa sample ratio mismatch (pembagian trafik tidak 50:50).

PYTHON
from math import sqrt, erf

A = {'pengunjung': 8200, 'beli': 287}
B = {'pengunjung': 8150, 'beli': 342}
pa, pb = A['beli'] / A['pengunjung'], B['beli'] / B['pengunjung']

p = (A['beli'] + B['beli']) / (A['pengunjung'] + B['pengunjung'])
se0 = sqrt(p * (1 - p) * (1 / A['pengunjung'] + 1 / B['pengunjung']))
z = (pb - pa) / se0
phi = lambda x: 0.5 * (1 + erf(x / sqrt(2)))
p_value = 2 * (1 - phi(abs(z)))

se = sqrt(pa * (1 - pa) / A['pengunjung'] + pb * (1 - pb) / B['pengunjung'])
bawah, atas = (pb - pa) - 1.96 * se, (pb - pa) + 1.96 * se

print(f'Konversi A: {pa:.2%}  B: {pb:.2%}  (naik {(pb - pa) / pa:.0%} relatif)')
print(f'z = {z:.2f}, p-value = {p_value:.4f}')
print(f'Selang 95% selisih: {bawah:.2%} s.d. {atas:.2%}')
bulanan = 250_000
print(f'Perkiraan tambahan pesanan/bulan: {bawah * bulanan:,.0f} s.d. {atas * bulanan:,.0f}')
print('Rekomendasi:', 'rilis versi B' if p_value < 0.05 and bawah > 0 else 'lanjutkan pengujian')
