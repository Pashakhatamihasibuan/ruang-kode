Mini 1: Dompet pribadi offline dengan Flutter dan Riverpod

Buka versi interaktif

Masalah. Mahasiswa di Yogyakarta ingin mencatat pemasukan dan pengeluaran tanpa internet, melihat saldo bulan berjalan, dan tahu kategori yang paling boros. Data tidak boleh hilang saat aplikasi ditutup.

Fitur wajib:
1. Model transaksi dengan nominal bilangan bulat (rupiah)
2. Penyimpanan lokal SQLite (sqflite) dengan query per bulan
3. State management Riverpod AsyncNotifier: loading, error, data
4. Hapus dengan geser (optimistic update + rollback bila gagal)
5. Ringkasan saldo dan pengeluaran per kategori, lengkap dengan unit test

Penyelesaian langkah demi langkah:
1. Tulis Transaksi dengan toMap/fromMap; nominal int, bukan double.
2. Repo memakai where tanggal >= awal AND < akhir agar akurat di pergantian bulan.
3. AsyncNotifierProvider; UI memakai data.when(loading, error, data) sehingga tiga state wajib ditangani.
4. Simpan daftar lama, ubah state dulu, kembalikan di blok catch.
5. hitungRingkasan fungsi murni sehingga mudah dites tanpa widget.

Kembangkan sendiri: tambahkan anggaran bulanan per kategori dengan peringatan 80%, grafik donat (fl_chart), dan ekspor CSV.
