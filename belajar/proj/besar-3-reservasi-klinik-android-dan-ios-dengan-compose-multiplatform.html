Besar 3: Reservasi klinik Android dan iOS dengan Compose Multiplatform

Buka versi interaktif

Masalah. Jaringan klinik pratama di Jawa Barat ingin satu aplikasi untuk Android dan iOS: pilih dokter, booking slot, antrean digital, dan pengingat. Tim hanya 3 developer, jadi kode harus dibagi sebanyak mungkin tanpa mengorbankan rasa native.

Fitur wajib:
1. Logika, data, dan UI bersama dengan Kotlin Multiplatform + Compose Multiplatform
2. Booking idempoten; slot penuh ditangani dengan jelas
3. Cache slot dan antrean booking offline yang dikirim ulang otomatis
4. Interop native: notifikasi lokal, kalender, dan login biometrik per platform
5. Keamanan data kesehatan: enkripsi lokal, TLS pinning, persetujuan data sensitif

Penyelesaian langkah demi langkah:
1. Mulai dari wizard KMP dengan target Android dan iOS; jalankan di kedua simulator di hari pertama.
2. Tulis domain dan repository di commonMain, lengkap dengan tes.
3. Bangun layar booking dengan Compose Multiplatform; uji gestur kembali iOS.
4. Tambahkan expect/actual untuk notifikasi, biometrik, dan kalender.
5. Lakukan audit keamanan dan alur persetujuan sebelum uji coba di satu klinik.

Standar industri yang dinilai: ≥ 70% kode bersama, perilaku native terjaga di iOS, booking idempoten, offline queue, data kesehatan terenkripsi dan sesuai UU PDP

Arsitektur dan stack (Kotlin Multiplatform, Compose Multiplatform, Ktor client, kotlinx.serialization, SQLDelight (+SQLCipher), Koin, kotlinx-datetime, Swift/SwiftUI interop, Xcode Cloud / GitHub Actions)
BagianIsi
Source setcommonMain (domain, data, UI), androidMain/iosMain (notifikasi, biometrik, driver DB)
DataKtor + SQLDelight; repository cache-first dengan Flow
UICompose Multiplatform dengan resources bersama; komponen kecil disesuaikan per platform (expect/actual)
SinkronisasiAntrean aksi offline; WorkManager (Android) dan BGTaskScheduler (iOS)
KeamananKeystore/Keychain, SQLCipher, certificate pinning, log tanpa data pasien
KualitascommonTest untuk domain/data, UI test per platform, crash reporting

Poin penting

  • Proyek besar: Reservasi klinik Android dan iOS dengan Compose Multiplatform.
  • Stack: Kotlin Multiplatform, Compose Multiplatform, Ktor client, kotlinx.serialization, SQLDelight (+SQLCipher), Koin, kotlinx-datetime, Swift/SwiftUI interop, Xcode Cloud / GitHub Actions.
  • Kerjakan dulu sendiri, lalu buka kode final untuk code review.
