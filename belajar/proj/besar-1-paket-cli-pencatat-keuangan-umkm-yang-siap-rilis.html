Besar 1: Paket CLI pencatat keuangan UMKM yang siap rilis

Buka versi interaktif

Masalah. Jutaan UMKM masih mencatat keuangan di buku tulis sehingga tidak tahu laba bulanan dan kewajiban PPh final 0,5%. Dibutuhkan alat baris perintah yang sederhana, datanya aman di laptop sendiri, dan dirilis sebagai paket Python profesional.

Fitur wajib:
1. Model transaksi tervalidasi dengan Pydantic (tidak ada nominal negatif atau kategori kosong)
2. Penyimpanan SQLite dengan transaksi atomik dan indeks tanggal
3. Laporan bulanan: pemasukan, pengeluaran, laba, dan PPh final sesuai ambang omzet Rp500 juta
4. CLI dengan Typer dan tabel Rich; dapat dipasang dengan pip install
5. Test, linting, type check, dan rilis otomatis ke PyPI lewat CI

Penyelesaian langkah demi langkah:
1. Tulis user story dan contoh perintah yang diinginkan pemilik UMKM.
2. Rancang model dan fungsi laporan sebagai fungsi murni, lalu tulis test lebih dulu untuk aturan pajak.
3. Bangun repositori SQLite dengan transaksi dan indeks; uji dengan basis data sementara.
4. Bangun CLI, uji alur dari awal sampai laporan, tambahkan ekspor CSV.
5. Siapkan CI, dokumentasi README, lalu rilis versi 1.0.0 ke PyPI.

Standar industri yang dinilai: struktur paket standar (src layout, pyproject), logika bisnis berupa fungsi murni yang teruji, validasi input, transaksi database atomik, type check ketat, CI dan rilis otomatis yang dapat diulang

Arsitektur dan stack (Python 3.12, Typer, Pydantic v2, SQLite, Rich, pytest, ruff, mypy, GitHub Actions, PyPI trusted publishing)
BagianIsi
Struktursrc layout, pyproject.toml (PEP 621), entry point catatku
Domainmodel.py (Pydantic), laporan.py (perhitungan pajak murni, mudah diuji)
Datarepo.py: SQLite + context manager transaksi; migrasi skema berversi
Antarmukacli.py: Typer, keluaran Rich, ekspor CSV
Kualitaspytest + coverage 85%, ruff, mypy --strict, pre-commit
Rilistag versi -> build -> PyPI; semantic versioning dan CHANGELOG

Poin penting

  • Proyek besar: Paket CLI pencatat keuangan UMKM yang siap rilis.
  • Stack: Python 3.12, Typer, Pydantic v2, SQLite, Rich, pytest, ruff, mypy, GitHub Actions, PyPI trusted publishing.
  • Kerjakan dulu sendiri, lalu buka kode final untuk code review.
