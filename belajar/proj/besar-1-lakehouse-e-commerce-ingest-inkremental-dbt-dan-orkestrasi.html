Besar 1: Lakehouse e-commerce: ingest inkremental, dbt, dan orkestrasi

Buka versi interaktif

Masalah. Brand ritel omnichannel punya data di marketplace, toko online, POS 60 gerai, dan iklan digital. Setiap tim punya angka omzet berbeda. Mereka butuh satu platform data dengan definisi metrik tunggal yang diperbarui setiap pagi.

Fitur wajib:
1. Ingest inkremental dari API dan database ke lapisan bronze (Parquet/Iceberg di object storage)
2. Transformasi dbt berlapis: staging → intermediate → marts, dengan model contract
3. Tes data otomatis (unique, not_null, relationships, accepted_values, freshness)
4. Orkestrasi Airflow dengan dbt per model sebagai task, retry, dan SLA jam 07.00
5. Dokumentasi dan lineage otomatis; semantic layer untuk metrik omzet, AOV, repeat rate

Penyelesaian langkah demi langkah:
1. Inventarisasi sumber dan definisikan metrik bersama bisnis (tulis di dokumen definisi metrik).
2. Bangun ingest inkremental satu sumber dulu sampai stabil, lalu tambah sumber lain.
3. Tulis model dbt staging dengan contract dan tes, kemudian marts fakta/dimensi.
4. Hubungkan Airflow + Cosmos; tambah SLA, retry, dan alert.
5. Publikasikan dokumentasi, lineage, dan semantic layer; matikan spreadsheet lama.

Standar industri yang dinilai: satu definisi metrik, pipeline idempoten dan inkremental, tes data di setiap model, SLA terpantau, biaya per query terkendali, dokumentasi dan lineage tersedia

Arsitektur dan stack (dlt / Airbyte, Google Cloud Storage atau S3, Apache Iceberg, BigQuery / Snowflake / Trino, dbt Core, Airflow + Astronomer Cosmos, OpenLineage, Looker / Metabase)
BagianIsi
Lapisanbronze (mentah, append) → silver (bersih, dedup, tipe benar) → gold (fakta & dimensi, metrik)

# ingest/sumber_order.py  (dlt: ekstrak inkremental dari API marketplace ke lake)
import dlt
from dlt.sources.helpers import requests

@dlt.resource(name="order", write_disposition="merge", primary_key="order_id")
def order(updated_at=dlt.sources.incremental("updated_at", initial_value="2026-01-01T00:00:00Z")):
    url = "https://api.toko-contoh.id/v2/orders"
    params = {"updated_since": updated_at.last_value, "limit": 500}
    while url:
        r = requests.get(url, params=params, timeout=30); r.raise_for_status()
        body = r.json(); yield body["data"]
        url, params = body.get("next"), None

pipeline = dlt.pipeline("marketplace", destination="filesystem", dataset_name="bronze")   # -> Iceberg/Parquet di GCS/S3

-- models/staging/stg_order.sql  (dbt)
{{ config(materialized='incremental', unique_key='order_id', incremental_strategy='merge',
          partition_by={'field': 'tanggal', 'data_type': 'date'}) }}
select
    cast(order_id as int64)                         as order_id,
    date(timestamp(created_at), 'Asia/Jakarta')     as tanggal,
    lower(trim(status))                             as status,
    cast(total as numeric)                          as total,
    toko_id, pelanggan_id, updated_at
from {{ source('bronze', 'order') }}
{% if is_incremental() %}
where updated_at > (select max(updated_at) from {{ this }})
{% endif %}

# models/staging/_stg.yml
models:
  - name: stg_order
    config: { contract: { enforced: true } }
    columns:
      - name: order_id
        data_type: int64
        data_tests: [unique, not_null]
      - name: tanggal
        data_type: date
      - name: status
        data_type: string
        data_tests:
          - accepted_values: { values: [dibuat, dibayar, dikirim, selesai, batal] }
      - name: toko_id
        data_type: int64
        data_tests:
          - relationships: { to: ref('dim_toko'), field: toko_id }

# dags/marketplace_harian.py  (Airflow + Cosmos menjalankan dbt per model sebagai task)
with DAG("marketplace_harian", schedule="0 2 * * *", start_date=datetime(2026, 1, 1), catchup=False) as dag:
    ingest = PythonOperator(task_id="dlt_ingest", python_callable=lambda: pipeline.run(order()))
    dbt = DbtTaskGroup(group_id="dbt", project_config=ProjectConfig("/opt/dbt/marketplace"),
                       render_config=RenderConfig(test_behavior=TestBehavior.AFTER_EACH))
    ingest >> dbt
