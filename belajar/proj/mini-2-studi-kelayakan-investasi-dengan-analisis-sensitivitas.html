Mini 2: Studi kelayakan investasi dengan analisis sensitivitas

Buka versi interaktif

Masalah. Jaringan 25 apotek ingin membeli aplikasi pemesanan dan stok senilai Rp1,35 M. Direksi bertanya: masih layakkah jika manfaatnya meleset atau adopsi lambat? Buat analisis NPV, IRR, payback, dan sensitivitas.

Fitur wajib:
1. Arus kas 5 tahun dengan kurva adopsi bertahap
2. NPV pada tingkat diskonto 11%, IRR dengan metode biseksi, payback
3. Skenario sensitivitas: manfaat turun, investasi naik, adopsi lambat, gabungan
4. Kesimpulan layak/tidak per skenario

Penyelesaian langkah demi langkah:
1. Susun manfaat per sumber (stok kedaluwarsa, lembur, penjualan hilang) dan biaya operasional.
2. Tulis fungsi npv, irr (cari tingkat diskonto saat NPV = 0), dan payback.
3. Bungkus pembentukan arus kas dalam fungsi berparameter agar skenario mudah diganti.
4. Tampilkan tabel sensitivitas untuk dibahas di rapat investasi.

Kembangkan sendiri: tambahkan simulasi Monte Carlo (1.000 skenario acak) dan tampilkan peluang NPV negatif.

# Kelayakan aplikasi pemesanan & stok untuk 25 apotek: NPV, IRR, payback, dan analisis sensitivitas
INVESTASI = 1_350_000_000
BIAYA_OPS = 210_000_000                          # per tahun: cloud, lisensi, tim dukungan
MANFAAT = {"stok kedaluwarsa berkurang": 380_000_000, "lembur admin berkurang": 145_000_000,
           "penjualan hilang karena stok kosong": 320_000_000}
TAHUN, R = 5, 0.11

def arus(skala_manfaat=1.0, skala_biaya=1.0, adopsi=(0.4, 0.8, 1, 1, 1)):
    m = sum(MANFAAT.values()) * skala_manfaat
    return [-INVESTASI * skala_biaya] + [m * a - BIAYA_OPS for a in adopsi]

def npv(cf, r=R): return sum(c / (1 + r) ** t for t, c in enumerate(cf))
def irr(cf):
    lo, hi = -0.9, 1.0
    for _ in range(100):
        mid = (lo + hi) / 2
        lo, hi = (mid, hi) if npv(cf, mid) > 0 else (lo, mid)
    return mid
def payback(cf):
    kum = cf[0]
    for t, c in enumerate(cf[1:], 1):
        if kum + c >= 0: return t - 1 + -kum / c
        kum += c

cf = arus()
rp = lambda x: ("-" if x < 0 else "") + f"Rp{abs(x) / 1e6:,.0f} jt".replace(",", ".")
print("arus kas:", [rp(c) for c in cf])
print(f"NPV {rp(npv(cf))} | IRR {irr(cf):.1%} | payback {payback(cf):.1f} tahun")
print("\nSENSITIVITAS NPV")
for label, kw in [("manfaat -30%", dict(skala_manfaat=0.7)), ("investasi +25%", dict(skala_biaya=1.25)),
                  ("adopsi lambat", dict(adopsi=(0.2, 0.5, 0.7, 0.9, 1))), ("skenario buruk gabungan", dict(skala_manfaat=0.8, skala_biaya=1.2, adopsi=(0.2, 0.5, 0.7, 0.9, 1)))]:
    v = npv(arus(**kw))
    print(f"  {label:<24} {rp(v):>14}  {'masih layak' if v > 0 else 'TIDAK layak'}")
