Besar 2: Dashboard operasional real-time

Buka versi interaktif

Masalah. Manajer gudang ingin melihat pesanan masuk, stok kritis, dan kinerja kurir secara langsung tanpa memuat ulang halaman.

Fitur wajib:
1. Kartu KPI (pesanan hari ini, omzet, stok kritis) yang diperbarui otomatis
2. Grafik pesanan per jam dan tabel yang bisa diurutkan dan difilter
3. Data baru masuk lewat Server-Sent Events tanpa reload
4. Filter tanggal tersimpan di URL agar bisa dibagikan
5. Tampilan bisa dipakai di tablet dan dengan keyboard

Penyelesaian langkah demi langkah:
1. Buat kontrak data (Ringkasan, Pesanan) dan API tiruan dengan MSW agar frontend bisa dikembangkan tanpa backend.
2. Ambil ringkasan dengan TanStack Query; kunci query memuat rentang tanggal dari URL.
3. Buka EventSource sekali di hook useStreamPesanan; setiap event memperbarui cache dengan setQueryData sehingga semua komponen ikut berubah.
4. Tutup koneksi saat komponen dilepas; tampilkan indikator "terputus, mencoba lagi".
5. Grafik dan tabel diberi alternatif teks (ringkasan angka) untuk pembaca layar.

Standar industri yang dinilai: data real-time memperbarui satu sumber (cache query), koneksi putus ditangani, filter di URL, grafik punya alternatif teks

Arsitektur dan stack (React + TypeScript (Vite), TanStack Query, TanStack Table, Recharts, SSE, MSW untuk data tiruan, Vitest)
BagianIsi
Data awaluseQuery GET /api/ringkasan?dari=..&sampai=..
PembaruanEventSource /api/stream: setiap event "pesanan" memperbarui cache query
TabelTanStack Table: sort, filter, pagination di sisi klien untuk ≤ 5.000 baris
UjiMSW meniru API dan stream; Vitest untuk fungsi agregasi

Poin penting

  • Proyek besar: Dashboard operasional real-time.
  • Stack: React + TypeScript (Vite), TanStack Query, TanStack Table, Recharts, SSE, MSW untuk data tiruan, Vitest.
  • Kerjakan dulu sendiri, lalu buka kode final untuk code review.
