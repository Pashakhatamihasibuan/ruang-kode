Mini 1: Skema toko dengan constraint dan audit trail harga

Buka versi interaktif

Masalah. Toko online sering menemukan stok minus, SKU berantakan, dan tidak ada yang tahu siapa yang mengubah harga saat promo salah. Rancang skema inti yang menolak data salah di level database dan mencatat setiap perubahan harga secara otomatis.

Fitur wajib:
1. Identity column, foreign key dengan ON DELETE RESTRICT
2. CHECK constraint untuk format SKU, harga > 0, stok ≥ 0
3. Tabel audit dan trigger BEFORE UPDATE OF harga
4. Bukti: baris salah ditolak dan perubahan harga tercatat beserta pelakunya

Penyelesaian langkah demi langkah:
1. Buat tabel referensi dulu (kategori), lalu produk dengan constraint lengkap.
2. Tulis fungsi trigger PL/pgSQL yang membandingkan OLD dan NEW dengan IS DISTINCT FROM.
3. Pasang trigger hanya untuk kolom harga agar perubahan stok tidak membanjiri audit.
4. Uji dengan data salah (harus ditolak) dan dua perubahan harga (harus tercatat).

Kembangkan sendiri: tambahkan ekstensi pgaudit untuk mencatat semua DDL, dan buat laporan perubahan harga harian untuk tim promo.

SQL
-- Skema inti toko online dengan constraint dan audit trail perubahan harga
CREATE TABLE kategori (id smallint GENERATED ALWAYS AS IDENTITY PRIMARY KEY, nama text NOT NULL UNIQUE);
CREATE TABLE produk (
  id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  sku        text NOT NULL UNIQUE CHECK (sku ~ '^[A-Z]{3}-[0-9]{4}$'),
  nama       text NOT NULL,
  kategori_id smallint NOT NULL REFERENCES kategori ON DELETE RESTRICT,
  harga      numeric(12,0) NOT NULL CHECK (harga > 0),
  stok       integer NOT NULL DEFAULT 0 CHECK (stok >= 0),
  diubah     timestamptz NOT NULL DEFAULT now()
);
CREATE TABLE audit_harga (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY, produk_id bigint NOT NULL,
  harga_lama numeric(12,0), harga_baru numeric(12,0), oleh text NOT NULL DEFAULT current_user, waktu timestamptz NOT NULL DEFAULT now()
);

CREATE FUNCTION catat_harga() RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
  IF NEW.harga IS DISTINCT FROM OLD.harga THEN
    INSERT INTO audit_harga (produk_id, harga_lama, harga_baru) VALUES (OLD.id, OLD.harga, NEW.harga);
    NEW.diubah := now();
  END IF;
  RETURN NEW;
END $$;
CREATE TRIGGER trg_audit_harga BEFORE UPDATE OF harga ON produk FOR EACH ROW EXECUTE FUNCTION catat_harga();

-- Perubahan harga tercatat otomatis

UPDATE produk SET harga = 87000 WHERE sku = 'KOP-0001';

  • Kode penyelesaian lengkap ada di bawah; ketik ulang, jangan disalin.

Cek pemahaman
