Mini 5: Segmentasi pelanggan RFM

Buka versi interaktif

Masalah. Budget promo terbatas. Marketing ingin tahu pelanggan mana yang paling berharga, mana yang mulai hilang, dan mana yang baru.

Fitur wajib:
1. Hitung Recency (hari sejak beli terakhir), Frequency (jumlah pesanan), Monetary (total belanja)
2. Skor 1–5 untuk setiap dimensi dengan kuantil
3. Petakan skor ke segmen bernama: Juara, Setia, Berisiko, Hampir Hilang, Baru
4. Ringkasan ukuran dan nilai tiap segmen beserta aksi yang disarankan

Penyelesaian langkah demi langkah:
1. Agregasi per pelanggan dengan groupby().agg(), tanggal acuan = sehari setelah transaksi terakhir.
2. pd.qcut(..., 5, labels=...); untuk recency labelnya dibalik (makin baru makin tinggi). Pakai rank(method="first") agar nilai kembar tidak membuat qcut gagal.
3. Aturan segmen sederhana berbasis skor R dan F, mudah dijelaskan ke tim marketing.
4. Tabel segmen: jumlah pelanggan, rata-rata belanja, porsi omzet.

Kembangkan sendiri: simpan hasil segmen ke tabel database dan pantau perpindahan segmen tiap bulan.

import sqlite3, numpy as np, pandas as pd
rng = np.random.default_rng(11)
n = 1200
df = pd.DataFrame({
    'id_pesanan': range(1, n + 1),
    'tanggal': pd.to_datetime('2026-01-01') + pd.to_timedelta(rng.integers(0, 181, n), unit='D'),
    'pelanggan': rng.integers(1, 301, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan', 'Makassar'], n, p=[.35, .2, .2, .15, .1]),
    'kategori': rng.choice(['Kopi', 'Teh', 'Camilan', 'Alat Seduh'], n, p=[.45, .2, .25, .1]),
})
harga = {'Kopi': 65000, 'Teh': 40000, 'Camilan': 25000, 'Alat Seduh': 210000}
df['jumlah'] = rng.integers(1, 4, n)
df['nilai'] = df['kategori'].map(harga) * df['jumlah']
acuan = df['tanggal'].max() + pd.Timedelta(days=1)
rfm = df.groupby('pelanggan').agg(R=('tanggal', lambda t: (acuan - t.max()).days), F=('id_pesanan', 'count'), M=('nilai', 'sum'))
rfm['r'] = pd.qcut(rfm['R'].rank(method='first'), 5, labels=[5, 4, 3, 2, 1]).astype(int)
rfm['f'] = pd.qcut(rfm['F'].rank(method='first'), 5, labels=[1, 2, 3, 4, 5]).astype(int)

def segmen(x):
    if x.r >= 4 and x.f >= 4: return 'Juara'
    if x.f >= 4: return 'Setia'
    if x.r >= 4 and x.f <= 2: return 'Baru'
    if x.r <= 2 and x.f >= 3: return 'Berisiko'
    if x.r <= 2: return 'Hampir Hilang'
    return 'Perlu Perhatian'

rfm['segmen'] = rfm.apply(segmen, axis=1)
ring = rfm.groupby('segmen').agg(pelanggan=('M', 'size'), rata_belanja=('M', 'mean'), omzet=('M', 'sum'))
ring['porsi_omzet_%'] = (100 * ring['omzet'] / ring['omzet'].sum()).round(1)
print(ring.sort_values('omzet', ascending=False).round(0))
AKSI = {'Juara': 'program loyalitas, akses produk baru', 'Berisiko': 'voucher personal + survei alasan', 'Hampir Hilang': 'kampanye win-back murah'}
for s, a in AKSI.items(): print(f'{s:13}: {a}')
