PROYEK BESAR: Analisis churn dan retensi aplikasi langganan

Masalah
  Tim produk ingin tahu kenapa pengguna berhenti berlangganan dan apa yang bisa dilakukan.

Fitur wajib
  1. Rumuskan pertanyaan bisnis dan metrik (retensi, churn, LTV)
  2. SQL untuk menyiapkan tabel analisis dari data mentah
  3. EDA dan analisis kohort di Python
  4. Dashboard interaktif untuk manajer
  5. Laporan 1 halaman: temuan, rekomendasi, dampak yang diperkirakan

Stack yang disarankan
  PostgreSQL/BigQuery, Python (pandas, Matplotlib), Power BI atau Looker Studio, GitHub

Rencana 4 minggu
  Minggu 1: pertanyaan, metrik, dan pemahaman data
  Minggu 2: SQL dan pembersihan
  Minggu 3: analisis kohort dan segmentasi
  Minggu 4: dashboard dan presentasi rekomendasi

Standar industri yang dinilai
  Setiap grafik punya kesimpulan, asumsi ditulis, rekomendasi bisa ditindaklanjuti, query bisa dijalankan ulang

Keluaran
  [ ] Repo dengan README lengkap, keputusan teknis, dan screenshot
  [ ] Demo online atau video 2 menit
  [ ] Test/bukti pengujian dan CI hijau (untuk proyek kode)
  [ ] Ringkasan 1 paragraf untuk CV dan LinkedIn

Poin penting

  • Masalah: Tim produk ingin tahu kenapa pengguna berhenti berlangganan dan apa yang bisa dilakukan.
  • Stack: PostgreSQL/BigQuery, Python (pandas, Matplotlib), Power BI atau Looker Studio, GitHub.
  • Rencana 4 minggu; dinilai dengan rubrik standar industri.
