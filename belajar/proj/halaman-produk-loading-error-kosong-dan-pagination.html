Proyek Portofolio · Modul 2 · Konsep & kode

Halaman produk: loading, error, kosong, dan pagination

Buka versi interaktif

Tampilan yang siap produksi menangani semua keadaan, bukan hanya saat data berhasil: memuat (skeleton), gagal (pesan dan tombol coba lagi), kosong (ajakan bertindak), dan berhasil.

useQuery mengembalikan isPending, isError, dan data. Kunci query ['produk', cari, page] membuat setiap kombinasi pencarian dan halaman disimpan di cache sendiri. Tunda pencarian beberapa ratus milidetik (debounce) agar tidak mengirim request di setiap ketikan.

Pagination memakai next dan previous dari API. placeholderData: keepPreviousData mempertahankan daftar lama saat halaman berikutnya dimuat sehingga layar tidak berkedip.

KODE
// src/pages/DaftarProduk.tsx
import { useEffect, useState } from 'react';
import { useQuery, keepPreviousData } from '@tanstack/react-query';
import { ambilProduk } from '../api/client';

const rupiah = (v: string) => Number(v).toLocaleString('id-ID', { style: 'currency', currency: 'IDR', maximumFractionDigits: 0 });

export default function DaftarProduk() {
  const [ketik, setKetik] = useState('');
  const [cari, setCari] = useState('');
  const [page, setPage] = useState(1);
  useEffect(() => { const t = setTimeout(() => { setCari(ketik); setPage(1); }, 300); return () => clearTimeout(t); }, [ketik]);

  const q = useQuery({ queryKey: ['produk', cari, page], queryFn: () => ambilProduk(cari, page), placeholderData: keepPreviousData });

  return (
    <main>
      <label htmlFor="cari">Cari produk</label>
      <input id="cari" value={ketik} onChange={(e) => setKetik(e.target.value)} />

      {q.isPending && <p aria-busy="true">Memuat produk...</p>}
      {q.isError && (
        <div role="alert">
          Gagal memuat produk: {q.error.message}
          <button onClick={() => q.refetch()}>Coba lagi</button>
        </div>
      )}
      {q.data && q.data.results.length === 0 && <p>Tidak ada produk untuk "{cari}".</p>}
      {q.data && q.data.results.length > 0 && (
        <table>
          <thead><tr><th>Produk</th><th>Kategori</th><th>Harga</th><th>Stok</th></tr></thead>
          <tbody>
            {q.data.results.map((p) => (
              <tr key={p.id}><td>{p.nama}</td><td>{p.kategori_nama}</td><td>{rupiah(p.harga)}</td>
                <td className={p.stok < 5 ? 'stok-tipis' : ''}>{p.stok}</td></tr>
            ))}
          </tbody>
        </table>
      )}
      <nav aria-label="Halaman">
        <button disabled={!q.data?.previous} onClick={() => setPage(page - 1)}>Sebelumnya</button>
        <span>Halaman {page}</span>
        <button disabled={!q.data?.next} onClick={() => setPage(page + 1)}>Berikutnya</button>
      </nav>
    </main>
  );
}

Poin penting

  • Tangani loading, error, kosong, dan berhasil.
  • Query key memuat parameter; debounce pencarian.
  • Pagination dari next/previous API.
