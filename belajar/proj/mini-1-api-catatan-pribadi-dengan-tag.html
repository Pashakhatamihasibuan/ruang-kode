Mini 1: API catatan pribadi dengan tag

Buka versi interaktif

Masalah. Aplikasi catatan butuh API di mana setiap pengguna hanya bisa melihat dan mengubah catatannya sendiri, dan bisa memfilter berdasarkan tag.

Fitur wajib:
1. CRUD catatan lewat REST API
2. Catatan hanya terlihat oleh pemiliknya (pengguna lain mendapat 404)
3. Tag banyak-ke-banyak dan filter ?tag=kuliah
4. Test untuk aturan kepemilikan

Penyelesaian langkah demi langkah:
1. Model Catatan dengan pemilik (FK ke User) dan tags (ManyToMany ke Tag).
2. Batasi queryset di get_queryset() ke pemilik=request.user; data orang lain otomatis 404, bukan 403, sehingga keberadaannya tidak bocor.
3. Serializer menerima daftar nama tag lalu get_or_create setiap tag.
4. Test dengan dua pengguna: A tidak bisa membaca catatan B.

Kembangkan sendiri: pencarian full-text dan berbagi catatan ke pengguna lain dengan izin baca saja.
