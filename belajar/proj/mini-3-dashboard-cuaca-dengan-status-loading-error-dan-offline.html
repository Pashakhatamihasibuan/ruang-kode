Mini 3: Dashboard cuaca dengan status loading, error, dan offline

Buka versi interaktif

Masalah. Petani dan pengemudi ojol ingin cek prakiraan hujan beberapa jam ke depan dengan cepat, dan aplikasi tidak boleh "diam" saat sinyal jelek.

Fitur wajib:
1. Cari kota lalu tampilkan suhu dan peluang hujan 24 jam
2. Status memuat, gagal (dengan tombol coba lagi), dan offline
3. Batalkan request lama saat pengguna mengetik kota baru
4. Simpan kota terakhir

Penyelesaian langkah demi langkah:
1. Pakai API gratis Open-Meteo: geocoding untuk koordinat, forecast untuk data per jam.
2. Satu fungsi tampilkan(state) menggambar layar dari objek status: {tahap: "muat"|"galat"|"siap", data, pesan}.
3. Gunakan AbortController: setiap pencarian baru membatalkan request sebelumnya agar hasil lama tidak menimpa yang baru.
4. Dengarkan event online/offline, simpan kota di localStorage.

Kembangkan sendiri: simpan respons terakhir ke cache agar tetap tampil saat offline, dan grafik peluang hujan dengan <canvas>.
