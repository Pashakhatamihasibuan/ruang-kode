Mini 4: Peramalan penjualan harian dengan backtest

Buka versi interaktif

Masalah. Kedai kopi dengan 1 gudang ingin meramal penjualan 4 minggu ke depan untuk memesan bahan baku. Pola mingguan dan efek tanggal gajian sangat terasa.

Fitur wajib:
1. Fitur kalender (hari, tanggal, bulan) dan lag yang tidak membocorkan masa depan
2. Backtest beberapa lipatan berbasis waktu (bukan acak)
3. Bandingkan dengan seasonal naive (nilai minggu lalu)
4. Metrik MAPE yang mudah dipahami tim gudang

Penyelesaian langkah demi langkah:
1. Susun data harian lengkap tanpa tanggal bolong.
2. Lag minimal 7 hari karena peramalan dilakukan seminggu sebelumnya.
3. Latih sampai tanggal potong, uji 28 hari sesudahnya; ulangi untuk beberapa tanggal potong.
4. Model hanya layak dipakai jika konsisten mengalahkan seasonal naive.

Kembangkan sendiri: tambahkan fitur hari libur nasional dan Ramadan, lalu buat prediksi kuantil P10/P90 untuk stok pengaman.

PYTHON
import numpy as np, pandas as pd
from sklearn.ensemble import HistGradientBoostingRegressor

rng = np.random.default_rng(4)
tgl = pd.date_range('2025-01-01', '2026-10-31', freq='D')
t = np.arange(len(tgl))
pola_minggu = np.array([0.9, 0.85, 0.9, 1.0, 1.15, 1.35, 1.25])[tgl.dayofweek]
gajian = np.where(tgl.day >= 25, 1.2, 1.0)
y = (200 + 0.12 * t) * pola_minggu * gajian + rng.normal(0, 12, len(t))
s = pd.DataFrame({'tanggal': tgl, 'unit': y.round()})

def fitur(d):
    d = d.copy()
    d['hari'] = d.tanggal.dt.dayofweek; d['tgl'] = d.tanggal.dt.day; d['bulan'] = d.tanggal.dt.month
    for lag in (7, 14, 28): d[f'lag{lag}'] = d.unit.shift(lag)
    d['rata7_lag7'] = d.unit.shift(7).rolling(7).mean()
    return d.dropna()

d = fitur(s)
kolom = ['hari', 'tgl', 'bulan', 'lag7', 'lag14', 'lag28', 'rata7_lag7']
mape = lambda a, b: np.mean(np.abs(a - b) / a) * 100
print('Backtest 3 lipatan (tiap lipatan memprediksi 28 hari berikutnya):')
for akhir in ['2026-08-31', '2026-09-30', '2026-10-03']:
    latih = d[d.tanggal <= akhir]; uji = d[(d.tanggal > akhir)].head(28)
    m = HistGradientBoostingRegressor(max_iter=300, learning_rate=0.05, random_state=0).fit(latih[kolom], latih.unit)
    naif = uji['lag7']
    print(f'  s.d. {akhir}: MAPE model {mape(uji.unit, m.predict(uji[kolom])):.1f}% | seasonal naive {mape(uji.unit, naif):.1f}%')
print('Catatan: fitur hanya memakai lag >= 7 hari, jadi model bisa meramal 7 hari ke depan tanpa membocorkan masa depan.')
KELUARAN
Backtest 3 lipatan (tiap lipatan memprediksi 28 hari berikutnya):
  s.d. 2026-08-31: MAPE model 4.3% | seasonal naive 10.7%
  s.d. 2026-09-30: MAPE model 3.8% | seasonal naive 9.4%
  s.d. 2026-10-03: MAPE model 3.9% | seasonal naive 9.8%
Catatan: fitur hanya memakai lag >= 7 hari, jadi model bisa meramal 7 hari ke depan tanpa membocorkan masa depan.
