Mini 4: Unggah foto produk dengan validasi dan thumbnail

Buka versi interaktif

Masalah. Penjual mengunggah foto dari HP berukuran 5–10 MB. Server harus menolak berkas berbahaya dan membuat versi kecil agar katalog cepat dimuat.

Fitur wajib:
1. Hanya JPEG/PNG/WebP, maksimal 5 MB, diperiksa dari isi berkas (bukan nama)
2. Simpan versi asli dan thumbnail 400 px dalam WebP
3. Nama berkas acak agar tidak menimpa dan tidak bisa ditebak
4. Pembuatan thumbnail di latar belakang agar respons cepat

Penyelesaian langkah demi langkah:
1. Buka berkas dengan Pillow dan cek img.format; berkas teks yang diganti namanya menjadi .jpg akan gagal dibuka.
2. Koreksi orientasi EXIF dari kamera HP dengan ImageOps.exif_transpose, lalu hapus metadata lokasi.
3. Simpan ke uuid4().hex + ekstensi; di produksi gunakan storage S3-compatible (django-storages).
4. Kirim tugas Celery buat_thumbnail.delay(id) setelah transaksi commit.

Kembangkan sendiri: URL bertanda tangan (presigned) agar HP mengunggah langsung ke storage tanpa melewati server.

PYTHON
# produk/validators.py
from PIL import Image, ImageOps, UnidentifiedImageError
from django.core.exceptions import ValidationError

MAKS = 5 * 1024 * 1024
FORMAT = {'JPEG', 'PNG', 'WEBP'}

def validasi_foto(berkas):
    if berkas.size > MAKS:
        raise ValidationError('Ukuran foto maksimal 5 MB.')
    try:
        with Image.open(berkas) as img:
            img.verify()                       # cek isi berkas benar-benar gambar
            if img.format not in FORMAT:
                raise ValidationError('Format harus JPEG, PNG, atau WebP.')
    except UnidentifiedImageError:
        raise ValidationError('Berkas bukan gambar yang valid.')
    berkas.seek(0)

# produk/models.py
import uuid
from django.db import models, transaction

def jalur_foto(obj, nama):
    return f'produk/{uuid.uuid4().hex}.{nama.rsplit(".", 1)[-1].lower()}'

class FotoProduk(models.Model):
    produk = models.ForeignKey('Produk', on_delete=models.CASCADE, related_name='foto')
    asli = models.ImageField(upload_to=jalur_foto, validators=[validasi_foto])
    thumb = models.ImageField(upload_to='produk/thumb/', blank=True)

    def save(self, *a, **kw):
        baru = self.pk is None
        super().save(*a, **kw)
        if baru:
            transaction.on_commit(lambda: buat_thumbnail.delay(self.pk))

# produk/tasks.py
from io import BytesIO
from celery import shared_task
from django.core.files.base import ContentFile

@shared_task(autoretry_for=(OSError,), retry_backoff=True, max_retries=3)
def buat_thumbnail(pk):
    f = FotoProduk.objects.get(pk=pk)
    with Image.open(f.asli) as img:
        img = ImageOps.exif_transpose(img).convert('RGB')     # putar sesuai kamera, buang EXIF
        img.thumbnail((400, 400))
        buf = BytesIO()
        img.save(buf, 'WEBP', quality=80)
    f.thumb.save(f'{uuid.uuid4().hex}.webp', ContentFile(buf.getvalue()), save=True)
