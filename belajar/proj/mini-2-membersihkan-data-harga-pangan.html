Mini 2: Membersihkan data harga pangan

Buka versi interaktif

Masalah. Data harga cabai dari beberapa pasar dikirim lewat spreadsheet: format angka campur aduk, nama pasar tidak konsisten, ada duplikat dan nilai mustahil.

Fitur wajib:
1. Ubah "Rp 45.000", "45000", "45rb" menjadi angka
2. Seragamkan nama pasar (spasi, huruf besar-kecil, singkatan)
3. Hapus duplikat dan tandai pencilan (harga ≤ 0 atau terlalu jauh dari median)
4. Laporan sebelum/sesudah: jumlah baris dan masalah yang diperbaiki

Penyelesaian langkah demi langkah:
1. Tulis fungsi ke_angka() yang menangani titik ribuan, "rb", dan teks kosong.
2. Normalisasi teks: str.strip().str.title() lalu peta singkatan dengan kamus.
3. Hapus hanya duplikat yang persis sama setelah dinormalisasi; baris dengan kunci sama tetapi harga berbeda dibiarkan dan diperiksa lewat aturan pencilan. Pencilan dengan aturan median ± 3 × MAD per komoditas.
4. Simpan log perbaikan agar proses bisa diaudit dan diulang (reproducible).

Kembangkan sendiri: jadikan fungsi pembersihan modul Python dengan test pytest, lalu jalankan otomatis setiap ada berkas baru.

PYTHON
import numpy as np, pandas as pd

mentah = pd.DataFrame({
    'tanggal': ['2026-11-01', '2026-11-01', '2026-11-01', '2026-11-02', '2026-11-02', '2026-11-02', '2026-11-02', '2026-11-03'],
    'pasar': ['Pasar Petisah', 'pasar petisah ', 'Psr. Sukaramai', 'Pasar Sukaramai', 'Pasar Petisah', 'Pasar Petisah', 'Pasar Sukaramai', 'Pasar Petisah'],
    'komoditas': ['Cabai Merah'] * 8,
    'harga': ['Rp 45.000', 'Rp 45.000', '47rb', '46500', '450000', '44.000', '', '0'],
})

def ke_angka(x):
    x = str(x).lower().replace('rp', '').replace(' ', '')
    if not x: return np.nan
    if x.endswith('rb'): return float(x[:-2].replace(',', '.')) * 1000
    return float(x.replace('.', ''))

PETA = {'Psr. Sukaramai': 'Pasar Sukaramai'}
log = []
df = mentah.copy()
df['harga'] = df['harga'].map(ke_angka)
df['pasar'] = df['pasar'].str.strip().str.title().replace(PETA)
n = len(df); df = df.drop_duplicates(); log.append(f'duplikat persis dihapus: {n - len(df)}')
n = len(df); df = df.dropna(subset=['harga']); log.append(f'harga kosong dihapus: {n - len(df)}')

med = df.groupby('komoditas')['harga'].transform('median')
mad = (df['harga'] - med).abs().groupby(df['komoditas']).transform('median')
df['pencilan'] = (df['harga'] <= 0) | ((df['harga'] - med).abs() > 3 * mad.clip(lower=1000))
log.append(f"pencilan ditandai: {int(df['pencilan'].sum())} -> {df.loc[df['pencilan'], 'harga'].tolist()}")

print('baris mentah:', len(mentah), '| baris bersih:', int((~df['pencilan']).sum()))
print(*log, sep='\n')
print(df[~df['pencilan']].groupby(['tanggal', 'pasar'])['harga'].mean())
