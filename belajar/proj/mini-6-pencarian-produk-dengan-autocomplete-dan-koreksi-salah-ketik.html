Mini 6: Pencarian produk dengan autocomplete dan koreksi salah ketik

Buka versi interaktif

Masalah. Pengguna aplikasi sering salah ketik ("kpoi", "mleati") dan tidak menemukan produk, sehingga penjualan hilang. Toko butuh kotak pencarian dengan saran otomatis dan koreksi ejaan tanpa layanan pihak ketiga.

Fitur wajib:
1. Autocomplete berbasis trie, diurutkan dari produk terpopuler
2. Koreksi salah ketik dengan edit distance (Damerau-Levenshtein: hapus, sisip, ganti, tukar huruf)
3. Batas toleransi sesuai panjang kata
4. Pencarian multi-kata dengan saran "maksud Anda"
5. Hasil kosong ditangani dengan jelas

Penyelesaian langkah demi langkah:
1. Masukkan setiap nama produk ke trie beserta skor popularitas.
2. Untuk awalan, turun ke simpul awalan lalu kumpulkan semua kata di bawahnya, urutkan skor menurun.
3. Edit distance dengan tabel DP O(m x n); tukar dua huruf bersebelahan (kpoi -> kopi) dihitung satu langkah.
4. Kata pendek hanya boleh salah 1 huruf, kata panjang 2, agar tidak terlalu longgar.
5. Cocokkan semua kata hasil koreksi ke nama produk; tampilkan saran jika ada kata yang dikoreksi.

Kembangkan sendiri: tambahkan sinonim (susu = milk), pembobotan BM25, dan ukur waktu pencarian untuk 100.000 produk.

PYTHON
# Pencarian produk toleran salah ketik: trie untuk autocomplete + edit distance (DP) untuk koreksi
PRODUK = {"kopi gayo arabika": 950, "kopi toraja": 610, "kopi susu literan": 1200, "kopiah hitam": 80, "teh melati": 430,
          "teh tarik": 520, "gula aren cair": 700, "susu oat": 390, "keripik singkong": 860, "kerupuk udang": 300}

class Trie:
    def __init__(self): self.anak, self.skor = {}, None
    def tambah(self, kata, skor):
        n = self
        for c in kata: n = n.anak.setdefault(c, Trie())
        n.skor = skor
    def awalan(self, p, k=3):
        n = self
        for c in p:
            if c not in n.anak: return []
            n = n.anak[c]
        hasil, st = [], [(n, p)]
        while st:
            x, s = st.pop()
            if x.skor is not None: hasil.append((-x.skor, s))
            st.extend((a, s + c) for c, a in x.anak.items())
        return [s for _, s in sorted(hasil)[:k]]

def jarak_edit(a, b):                          # Damerau-Levenshtein (OSA): DP O(len(a) x len(b))
    d = [[i + j if i * j == 0 else 0 for j in range(len(b) + 1)] for i in range(len(a) + 1)]
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            d[i][j] = min(d[i - 1][j] + 1, d[i][j - 1] + 1, d[i - 1][j - 1] + (a[i - 1] != b[j - 1]))
            if i > 1 and j > 1 and a[i - 1] == b[j - 2] and a[i - 2] == b[j - 1]:
                d[i][j] = min(d[i][j], d[i - 2][j - 2] + 1)          # tukar dua huruf bersebelahan
    return d[-1][-1]

KATA = sorted({w for nama in PRODUK for w in nama.split()})
def koreksi(w):
    if w in KATA: return w
    batas = 1 if len(w) <= 4 else 2
    kandidat = sorted((jarak_edit(w, k), k) for k in KATA)
    d, k = kandidat[0]
    return k if d <= batas else None

trie = Trie()
for nama, skor in PRODUK.items(): trie.tambah(nama, skor)

def cari(teks):
    kata = teks.lower().split()
    benar = [koreksi(w) or w for w in kata]
    hasil = [n for n in sorted(PRODUK, key=lambda n: -PRODUK[n]) if all(w in n.split() for w in benar)]
    saran = f" (maksud Anda: '{' '.join(benar)}'?)" if benar != kata else ""
    return hasil[:3], saran

for awal in ["ko", "kopi s", "te", "ke"]:
    print(f"autocomplete {awal!r:<9} -> {trie.awalan(awal)}")
for q in ["kopi", "kpoi toraja", "teh mleati", "sus oat", "kripik", "laptop"]:
    hasil, saran = cari(q)
    print(f"cari {q!r:<14} -> {hasil or 'tidak ditemukan'}{saran}")
