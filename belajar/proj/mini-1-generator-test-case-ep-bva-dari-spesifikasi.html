Mini 1: Generator test case EP + BVA dari spesifikasi

Buka versi interaktif

Masalah. Tim QA menulis test case formulir satu per satu di spreadsheet dan sering melewatkan nilai batas. Buat generator yang membaca spesifikasi field lalu menurunkan test case equivalence partitioning dan boundary value secara otomatis, sekaligus menjalankannya ke validator.

Fitur wajib:
1. Spesifikasi field sebagai data (tipe, min, max, kelipatan)
2. Nilai batas min-1, min, min+1, tengah, max-1, max, max+1
3. Kasus khusus: kelipatan nominal dan teks berisi spasi saja
4. Eksekusi ke sistem dan laporan test case yang gagal

Penyelesaian langkah demi langkah:
1. Tulis SPEK sebagai daftar dict agar mudah ditambah field baru.
2. Fungsi kasus(f) menghasilkan pasangan (nilai, seharusnya diterima?).
3. Untuk field berkelipatan, kasus yang bukan kelipatan harus ditolak.
4. Bandingkan hasil validator dengan harapan, beri nomor TC, dan kumpulkan yang gagal.

Kembangkan sendiri: baca spesifikasi dari OpenAPI (minimum, maximum, maxLength, multipleOf) dan ekspor test case ke CSV yang bisa diimpor ke Qase atau TestRail.

PYTHON
# Generator test case EP + BVA dari spesifikasi field formulir pendaftaran
SPEK = [
    {"field": "usia", "tipe": "int", "min": 17, "max": 65},
    {"field": "nama", "tipe": "str", "min": 2, "max": 50},
    {"field": "nominal_topup", "tipe": "int", "min": 10_000, "max": 2_000_000, "kelipatan": 1_000},
]

def kasus(f):
    lo, hi = f["min"], f["max"]
    if f["tipe"] == "int":
        nilai = [(lo - 1, False), (lo, True), (lo + 1, True), ((lo + hi) // 2, True), (hi - 1, True), (hi, True), (hi + 1, False)]
        if "kelipatan" in f:
            k = f["kelipatan"]
            nilai = [(v, ok and v % k == 0) for v, ok in nilai] + [(lo + k // 2, False)]
        return [(str(v), ok) for v, ok in nilai]
    panjang = [lo - 1, lo, hi, hi + 1]
    return [("x" * n, lo <= n <= hi) for n in panjang] + [("   ", False)]

def validasi(field, teks):            # sistem yang diuji (ada 1 bug)
    if field == "usia": return teks.isdigit() and 17 <= int(teks) <= 65
    if field == "nama": return 2 <= len(teks.strip()) <= 50
    if field == "nominal_topup":
        v = int(teks); return 10_000 <= v <= 2_000_000          # lupa cek kelipatan 1.000

no, bug = 0, []
for f in SPEK:
    print(f"[{f['field']}]")
    for v, harap in kasus(f):
        no += 1
        dapat = validasi(f["field"], v)
        tampil = v if v.isdigit() else repr(v) if len(v) <= 12 else f"'x'*{len(v)}"
        tanda = "" if dapat == harap else "  <-- BUG"
        if tanda: bug.append((f"TC-{no:02}", f["field"], v))
        print(f"  TC-{no:02} {tampil:<12} harap {'terima' if harap else 'tolak':<6} dapat {'terima' if dapat else 'tolak':<6}{tanda}")
print(f"{no} test case, {len(bug)} gagal:", [b[0] for b in bug], "-> satu akar masalah: aturan kelipatan 1.000 tidak dicek")
