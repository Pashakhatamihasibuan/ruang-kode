Besar 1: Platform kelas online (LMS) dengan pembayaran

Buka versi interaktif

Masalah. Guru les dan kursus kecil ingin menjual kelas video, memberi kuis, dan memantau progres murid tanpa membayar platform mahal.

Fitur wajib:
1. Peran guru, murid, admin dengan izin berbeda
2. Guru membuat kelas → modul → pelajaran (video/teks) dan kuis
3. Murid membeli kelas (pembayaran sandbox), menonton, mengerjakan kuis, melihat progres
4. Sertifikat PDF otomatis saat progres 100%
5. Dashboard guru: murid aktif, pendapatan, nilai rata-rata kuis

Penyelesaian langkah demi langkah:
1. Rancang model dan relasi; pakai order untuk urutan modul dan pelajaran.
2. Buat permission per objek dan test untuk setiap peran (guru lain tidak boleh mengubah kelas).
3. Checkout membuat Pendaftaran MENUNGGU dan transaksi gateway; webhook mengaktifkan pendaftaran.
4. Endpoint progres: tandai pelajaran selesai, hitung persentase dengan agregasi database.
5. Saat 100%, Celery membuat sertifikat PDF dengan WeasyPrint dan mengirim email.
6. Dashboard guru memakai satu query agregasi (annotate) untuk menghindari N+1.

Standar industri yang dinilai: izin per objek diuji untuk setiap peran, pembayaran idempoten, tugas berat di Celery, dashboard tanpa N+1 query

Arsitektur dan stack (Django 5, DRF, PostgreSQL, Redis, Celery, Midtrans/Xendit sandbox, WeasyPrint, pytest, Docker Compose, Render)

# kelas/permissions.py
from rest_framework.permissions import BasePermission, SAFE_METHODS

class IsGuruPemilik(BasePermission):
    def has_object_permission(self, req, view, kelas):
        return req.method in SAFE_METHODS or kelas.guru_id == req.user.id

class IsTerdaftar(BasePermission):
    message = 'Beli kelas ini untuk membuka pelajaran.'
    def has_object_permission(self, req, view, pelajaran):
        k = pelajaran.modul.kelas
        return pelajaran.gratis or k.guru_id == req.user.id or \
            k.pendaftaran.filter(murid=req.user, status='AKTIF').exists()

# kelas/views.py
from django.db.models import Count, Q, Avg
from rest_framework import viewsets, decorators, response

class PelajaranViewSet(viewsets.ReadOnlyModelViewSet):
    serializer_class = PelajaranSerializer
    permission_classes = [IsAuthenticated, IsTerdaftar]
    queryset = Pelajaran.objects.select_related('modul__kelas')

    @decorators.action(detail=True, methods=['post'])
    def selesai(self, req, pk=None):
        p = self.get_object()
        Progres.objects.get_or_create(murid=req.user, pelajaran=p)
        kelas = p.modul.kelas
        total = Pelajaran.objects.filter(modul__kelas=kelas).count()
        beres = Progres.objects.filter(murid=req.user, pelajaran__modul__kelas=kelas).count()
        persen = round(100 * beres / total)
        if persen == 100:
            buat_sertifikat.delay(req.user.id, kelas.id)
        return response.Response({'persen': persen})

class DashboardGuru(viewsets.ViewSet):
    def list(self, req):
        data = (Kelas.objects.filter(guru=req.user)
                .annotate(murid_aktif=Count('pendaftaran', filter=Q(pendaftaran__status='AKTIF')),
                          nilai_kuis=Avg('modul__kuis__jawaban__nilai'))
                .values('id', 'judul', 'harga', 'murid_aktif', 'nilai_kuis'))
        return response.Response([{**d, 'pendapatan': d['harga'] * d['murid_aktif']} for d in data])

# kelas/tasks.py
from weasyprint import HTML
@shared_task
def buat_sertifikat(murid_id, kelas_id):
    s, dibuat = Sertifikat.objects.get_or_create(murid_id=murid_id, kelas_id=kelas_id)
    if not dibuat:
        return
    html = render_to_string('sertifikat.html', {'s': s})
    s.pdf.save(f'{s.kode}.pdf', ContentFile(HTML(string=html).write_pdf()))

# tests/test_izin.py
def test_murid_belum_bayar_tidak_bisa_buka(api_murid, pelajaran_berbayar):
    r = api_murid.get(f'/api/pelajaran/{pelajaran_berbayar.id}/')
    assert r.status_code == 403 and 'Beli kelas' in r.data['detail']
