Besar 1: Platform kelas online (LMS) dengan pembayaran

Buka versi interaktif

Masalah. Guru les dan kursus kecil ingin menjual kelas video, memberi kuis, dan memantau progres murid tanpa membayar platform mahal.

Fitur wajib:
1. Peran guru, murid, admin dengan izin berbeda
2. Guru membuat kelas → modul → pelajaran (video/teks) dan kuis
3. Murid membeli kelas (pembayaran sandbox), menonton, mengerjakan kuis, melihat progres
4. Sertifikat PDF otomatis saat progres 100%
5. Dashboard guru: murid aktif, pendapatan, nilai rata-rata kuis

Penyelesaian langkah demi langkah:
1. Rancang model dan relasi; pakai order untuk urutan modul dan pelajaran.
2. Buat permission per objek dan test untuk setiap peran (guru lain tidak boleh mengubah kelas).
3. Checkout membuat Pendaftaran MENUNGGU dan transaksi gateway; webhook mengaktifkan pendaftaran.
4. Endpoint progres: tandai pelajaran selesai, hitung persentase dengan agregasi database.
5. Saat 100%, Celery membuat sertifikat PDF dengan WeasyPrint dan mengirim email.
6. Dashboard guru memakai satu query agregasi (annotate) untuk menghindari N+1.

Standar industri yang dinilai: izin per objek diuji untuk setiap peran, pembayaran idempoten, tugas berat di Celery, dashboard tanpa N+1 query

Arsitektur dan stack (Django 5, DRF, PostgreSQL, Redis, Celery, Midtrans/Xendit sandbox, WeasyPrint, pytest, Docker Compose, Render)
BagianIsi
ModelKelas, Modul, Pelajaran, Pendaftaran(murid, kelas, status), Progres(murid, pelajaran), Kuis, Jawaban
IzinIsGuruPemilik untuk mengubah kelas; IsTerdaftar untuk membuka pelajaran berbayar
PembayaranPendaftaran MENUNGGU → webhook terverifikasi → AKTIF (idempoten)
Latar belakangCelery: sertifikat PDF, email selamat datang, rekap mingguan guru
