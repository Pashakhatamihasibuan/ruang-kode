Yang membedakan proyek ini dari tutorial: lapisan controller-service-repository, DTO terpisah dari entity, test pemesanan bersamaan. Itulah yang akan kamu ceritakan saat wawancara.

CONTOH
PROYEK BESAR: Sistem reservasi lapangan futsal

Masalah
  Pemilik lapangan masih mencatat jadwal di buku dan sering terjadi jadwal ganda.

Fitur wajib
  1. Daftar dan login (JWT) untuk penyewa dan admin
  2. Lihat slot kosong per lapangan dan tanggal
  3. Pesan slot tanpa bentrok (constraint + transaksi)
  4. Admin mengelola lapangan, harga, dan jam operasional
  5. Laporan pendapatan bulanan

Stack yang disarankan
  Java 21, Spring Boot 3, Spring Security, JPA, PostgreSQL, Flyway, JUnit 5, Testcontainers, Docker

Rencana 4 minggu
  Minggu 1: skema database dengan Flyway, entity, repository
  Minggu 2: API slot dan pemesanan, cegah bentrok
  Minggu 3: keamanan JWT dan peran
  Minggu 4: test integrasi Testcontainers, Docker, deploy

Standar industri yang dinilai
  Lapisan controller-service-repository, DTO terpisah dari entity, test pemesanan bersamaan

Keluaran
  [ ] Repo dengan README lengkap, keputusan teknis, dan screenshot
  [ ] Demo online atau video 2 menit
  [ ] Test/bukti pengujian dan CI hijau (untuk proyek kode)
  [ ] Ringkasan 1 paragraf untuk CV dan LinkedIn

Poin penting

  • Masalah: Pemilik lapangan masih mencatat jadwal di buku dan sering terjadi jadwal ganda.
  • Stack: Java 21, Spring Boot 3, Spring Security, JPA, PostgreSQL, Flyway, JUnit 5, Testcontainers, Docker.
  • Rencana 4 minggu; dinilai dengan rubrik standar industri.
