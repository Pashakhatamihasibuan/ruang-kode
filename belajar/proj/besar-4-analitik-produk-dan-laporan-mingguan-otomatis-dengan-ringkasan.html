Besar 4: Analitik produk dan laporan mingguan otomatis dengan ringkasan AI

Buka versi interaktif

Masalah. Startup edtech punya data event (daftar, mulai kelas, selesai pelajaran, bayar) tetapi tim produk menunggu analis setiap minggu untuk angka funnel dan aktivasi.

Fitur wajib:
1. Metrik AARRR: akuisisi, aktivasi, retensi, revenue, referral dengan definisi tertulis
2. Funnel daftar → mulai kelas → selesai 3 pelajaran → bayar, per kanal dan platform
3. Laporan mingguan otomatis setiap Senin 08.00 ke Slack/email berisi angka, grafik, dan perubahan penting
4. Ringkasan naratif dibuat LLM dari angka yang sudah dihitung (bukan dari data mentah), dengan pengecekan angka
5. Notifikasi anomali jika metrik turun di luar batas wajar

Penyelesaian langkah demi langkah:
1. Tulis definisi metrik dan event (tracking plan) bersama tim produk.
2. SQL funnel: untuk setiap pengguna, waktu pertama tiap langkah; langkah dihitung hanya jika urutannya benar dan dalam 14 hari.
3. Skrip Python menghitung metrik minggu ini vs minggu lalu dan rata-rata 4 minggu, menandai anomali (z-score > 2).
4. Kirim JSON metrik ke LLM untuk narasi singkat; tolak narasi jika ada angka yang tidak ada di JSON.
5. Jadwalkan dengan GitHub Actions; simpan rahasia (kunci API, webhook) di Secrets.

Standar industri yang dinilai: tracking plan tertulis, funnel menghormati urutan dan jendela waktu, laporan otomatis dan bisa diaudit, narasi AI dibatasi pada angka yang dihitung

Arsitektur dan stack (SQL (BigQuery/PostgreSQL), Python, Matplotlib, GitHub Actions (cron), Slack webhook, Claude API)

-- sql/funnel.sql : funnel 14 hari sejak daftar
WITH daftar AS (
  SELECT user_id, MIN(waktu) AS t0, ANY_VALUE(kanal) AS kanal FROM events WHERE nama_event = 'daftar'
  AND waktu >= @mulai AND waktu < @akhir GROUP BY user_id
),
langkah AS (
  SELECT d.user_id, d.kanal,
    MIN(IF(e.nama_event = 'mulai_kelas', e.waktu, NULL)) AS t1,
    MIN(IF(e.nama_event = 'selesai_pelajaran_3', e.waktu, NULL)) AS t2,
    MIN(IF(e.nama_event = 'bayar', e.waktu, NULL)) AS t3
  FROM daftar d LEFT JOIN events e ON e.user_id = d.user_id AND e.waktu BETWEEN d.t0 AND TIMESTAMP_ADD(d.t0, INTERVAL 14 DAY)
  GROUP BY 1, 2
)
SELECT kanal, COUNT(*) AS daftar, COUNTIF(t1 IS NOT NULL) AS mulai,
       COUNTIF(t2 > t1) AS aktif, COUNTIF(t3 > t2) AS bayar
FROM langkah GROUP BY kanal;

# laporan.py
import json, os, re, requests, anthropic
metrik = hitung_metrik()          # dict angka minggu ini, minggu lalu, rata-rata 4 minggu, flag anomali

narasi = anthropic.Anthropic().messages.create(
    model='claude-sonnet-4-5', max_tokens=400,
    system='Tulis ringkasan mingguan 5 poin untuk tim produk, bahasa Indonesia. Gunakan HANYA angka dari JSON. '
           'Sebut perubahan terbesar dan anomali. Jangan menebak penyebab tanpa data.',
    messages=[{'role': 'user', 'content': json.dumps(metrik)}]).content[0].text

def semua_angka(x):
    if isinstance(x, dict): return [a for v in x.values() for a in semua_angka(v)]
    if isinstance(x, list): return [a for v in x for a in semua_angka(v)]
    return [x] if isinstance(x, (int, float)) else []

angka_json = {f'{v:g}' for v in semua_angka(metrik)} | {str(round(v)) for v in semua_angka(metrik)}
angka_narasi = set(re.findall(r'\d+(?:[.,]\d+)?', narasi))
asing = {a for a in angka_narasi if a.replace(',', '.') not in angka_json}
if asing:
    narasi = '(Ringkasan AI dinonaktifkan minggu ini: ada angka yang tidak cocok dengan data.)'

requests.post(os.environ['SLACK_WEBHOOK'], json={'text': f"*Laporan produk minggu {metrik['minggu']}*\n{narasi}"})
