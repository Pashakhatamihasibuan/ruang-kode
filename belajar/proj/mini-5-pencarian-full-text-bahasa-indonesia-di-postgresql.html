Mini 5: Pencarian full-text bahasa Indonesia di PostgreSQL

Buka versi interaktif

Masalah. Pencarian icontains lambat dan tidak menemukan "kopi susu" saat pengguna mengetik "susu kopi". Toko butuh pencarian yang memberi peringkat relevansi.

Fitur wajib:
1. Cari di nama (bobot tinggi) dan deskripsi (bobot rendah)
2. Urutkan berdasarkan relevansi
3. Toleran salah ketik ringan dengan trigram
4. Tetap cepat untuk 100 ribu produk (index GIN)

Penyelesaian langkah demi langkah:
1. Tambah kolom SearchVectorField yang diisi trigger/GeneratedField, dengan bobot A untuk nama dan B untuk deskripsi.
2. Cari dengan SearchQuery(..., search_type="websearch") agar pengguna bisa memakai tanda kutip dan minus.
3. Jika hasil kosong, jatuh ke TrigramSimilarity untuk salah ketik.
4. Buat index GIN untuk vektor dan untuk trigram.

Kembangkan sendiri: kamus sinonim (es = ice, susu = milk) dan analitik kata kunci yang tidak menemukan hasil.

PYTHON
# produk/models.py
from django.contrib.postgres.indexes import GinIndex
from django.contrib.postgres.search import SearchVector, SearchVectorField
from django.db import models

class Produk(models.Model):
    nama = models.CharField(max_length=120)
    deskripsi = models.TextField(blank=True)
    cari = models.GeneratedField(
        expression=SearchVector('nama', weight='A', config='simple') + SearchVector('deskripsi', weight='B', config='simple'),
        output_field=SearchVectorField(), db_persist=True)

    class Meta:
        indexes = [GinIndex(fields=['cari']), GinIndex(name='produk_nama_trgm', fields=['nama'], opclasses=['gin_trgm_ops'])]

# produk/search.py
from django.contrib.postgres.search import SearchQuery, SearchRank, TrigramSimilarity
from django.db.models import F

def cari_produk(teks: str, batas=20):
    q = SearchQuery(teks, config='simple', search_type='websearch')
    hasil = (Produk.objects.filter(cari=q)
             .annotate(skor=SearchRank(F('cari'), q)).order_by('-skor')[:batas])
    if hasil:
        return list(hasil)
    # cadangan untuk salah ketik: "kopi gyo" -> "Kopi Gayo"
    return list(Produk.objects.annotate(skor=TrigramSimilarity('nama', teks))
                .filter(skor__gt=0.25).order_by('-skor')[:batas])
