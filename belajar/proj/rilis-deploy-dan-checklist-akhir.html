Proyek Portofolio · Modul 2 · Konsep & kode

Rilis: deploy dan checklist akhir

Buka versi interaktif

Urutan deploy: database terkelola (Neon/Supabase) → API (Render/Railway) dengan DATABASE_URL dari langkah pertama → frontend (Vercel) dengan VITE_API_URL menunjuk ke API. Terakhir, tambahkan domain frontend ke CORS_ALLOWED_ORIGINS.

Sebelum membagikan link, jalankan checklist di bawah. Lalu rekam video demo 1–2 menit: masalah yang diselesaikan, alur utama, dan satu keputusan teknis yang kamu banggakan.

Selamat: kamu sekarang punya proyek yang mencakup seluruh perjalanan data, dari tombol di layar sampai baris di database. Gunakan pola yang sama untuk proyek besar di modul berikutnya.

CONTOH
Checklist rilis KasirKu

Database
[ ] Migrasi jalan di produksi, data demo ter-seed
[ ] Backup otomatis aktif (bawaan Neon/Supabase)

API
[ ] DEBUG=False, SECRET_KEY dari env, ALLOWED_HOSTS benar
[ ] CORS hanya mengizinkan domain frontend
[ ] /api/health mengembalikan 200
[ ] Test dan lint hijau di CI

Frontend
[ ] VITE_API_URL menunjuk ke API produksi
[ ] Semua keadaan: loading, error, kosong sudah dicoba
[ ] Bisa dipakai di layar HP dan dengan keyboard

Dokumentasi
[ ] README: demo, akun demo, screenshot, cara menjalankan, keputusan teknis
[ ] Video demo 1-2 menit
[ ] Link repo dan demo di CV dan LinkedIn

Poin penting

  • Deploy berurutan: database, API, frontend, lalu CORS.
  • Checklist keamanan dan kualitas sebelum dibagikan.
  • Video demo singkat memperkuat portofolio.
