Besar 3: Asisten tanya-jawab dokumen dengan evaluasi (RAG + LLM)

Buka versi interaktif

Masalah. Perusahaan asuransi ingin asisten internal yang menjawab pertanyaan agen tentang polis dan SOP dari ribuan PDF, dengan sumber yang bisa dicek, dan kualitas jawabannya terukur sebelum dirilis.

Fitur wajib:
1. Pipeline ingest: ekstrak PDF, potong (chunking), embedding, simpan di pgvector
2. Retrieval hibrida (vektor + kata kunci) dan reranking
3. Jawaban LLM wajib menyertakan kutipan sumber; menolak jika tidak ada dasar
4. Set evaluasi 150 pertanyaan: recall@5 retrieval, faithfulness, ketepatan jawaban
5. Guardrail: masking data pribadi dan log audit

Penyelesaian langkah demi langkah:
1. Kumpulkan dokumen dan buat golden set pertanyaan bersama ahli (jawaban + halaman sumber).
2. Ingest dan uji recall@5 retrieval dulu, sebelum menyentuh LLM.
3. Tambahkan BM25 dan reranking jika recall rendah untuk istilah teknis polis.
4. Tulis prompt dengan aturan kutipan; uji faithfulness dengan LLM-as-judge dan cek manual 30 sampel.
5. Jadikan evaluasi test otomatis di CI: rilis gagal jika recall@5 atau faithfulness turun.
6. Pasang tracing, batas biaya, dan masking PII sebelum dibuka ke agen.

Standar industri yang dinilai: golden set dibuat bersama ahli, retrieval diukur terpisah dari generasi, kutipan wajib, evaluasi otomatis di CI, PII dimasking

Arsitektur dan stack (Python, PostgreSQL + pgvector, Claude API, FastAPI, pytest, Langfuse/OpenTelemetry)
BagianIsi
Ingestpypdf/unstructured → chunk 800 token tumpang tindih 100 → embedding → tabel chunk(id, dok, halaman, teks, embedding)
Retrievaltop-20 vektor + top-20 BM25 → gabung (RRF) → rerank → 5 chunk
GenerasiClaude dengan prompt: jawab hanya dari konteks, sebut [dok:halaman], katakan tidak tahu bila perlu
Evaluasigolden set pertanyaan → recall@5, LLM-as-judge faithfulness, review manusia sampel
Observabilitastrace tiap permintaan: latensi, token, biaya, skor

  • Proyek besar: Asisten tanya-jawab dokumen dengan evaluasi (RAG + LLM).
  • Stack: Python, PostgreSQL + pgvector, Claude API, FastAPI, pytest, Langfuse/OpenTelemetry.
  • Kerjakan dulu sendiri, lalu buka kode final untuk code review.
