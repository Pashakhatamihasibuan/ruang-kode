Transaksi: pesanan yang mengurangi stok dengan aman

Buka versi interaktif

Membuat pesanan menyentuh beberapa tabel: kurangi stok, buat pesanan, buat item. Semua harus berhasil bersama atau gagal bersama. Bungkus dengan transaction.atomic(); jika ada error di tengah, semua perubahan dibatalkan (rollback).

Masalah race condition: dua kasir menjual kopi terakhir pada detik yang sama. Keduanya membaca stok = 1, keduanya menjual, stok jadi −1. Solusinya select_for_update(), yang mengunci baris produk sampai transaksi selesai sehingga kasir kedua menunggu dan melihat stok terbaru.

Kunci baris dalam urutan id yang sama (order_by('id')) untuk mencegah deadlock. Ini contoh "keputusan teknis" yang bagus ditulis di README dan diceritakan saat wawancara.

PYTHON
# toko/views.py (lanjutan)
from decimal import Decimal
from django.db import transaction
from rest_framework import mixins, viewsets, serializers
from .models import Produk, Pesanan, ItemPesanan
from .serializers import PesananSerializer

class PesananViewSet(mixins.CreateModelMixin, mixins.ListModelMixin, viewsets.GenericViewSet):
    serializer_class = PesananSerializer

    def get_queryset(self):
        return Pesanan.objects.filter(kasir=self.request.user).order_by('-dibuat')

    @transaction.atomic
    def perform_create(self, serializer):
        item = serializer.validated_data['item']
        ids = {i['produk'].id for i in item}
        stok = {p.id: p for p in Produk.objects.select_for_update().filter(id__in=ids).order_by('id')}

        total = Decimal('0')
        for i in item:
            p = stok[i['produk'].id]
            if p.stok < i['jumlah']:
                raise serializers.ValidationError({'item': f'Stok {p.nama} tinggal {p.stok}.'})
            p.stok -= i['jumlah']
            total += p.harga * i['jumlah']
        Produk.objects.bulk_update(stok.values(), ['stok'])

        pesanan = serializer.save(kasir=self.request.user, total=total)
        ItemPesanan.objects.bulk_create(
            ItemPesanan(pesanan=pesanan, produk=stok[i['produk'].id],
                        jumlah=i['jumlah'], harga_saat=stok[i['produk'].id].harga) for i in item)

Poin penting

  • transaction.atomic: semua berhasil atau semua batal.
  • select_for_update mencegah dua kasir menjual stok yang sama.
  • Kunci dalam urutan yang sama untuk mencegah deadlock.
