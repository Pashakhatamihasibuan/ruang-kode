Mini 4: Formulir pendaftaran multi-langkah dengan validasi dan draf otomatis

Buka versi interaktif

Masalah. Aplikasi koperasi simpan pinjam kehilangan banyak calon anggota di formulir pendaftaran: pesan error membingungkan, dan isian hilang saat pengguna berpindah aplikasi untuk mencari data.

Fitur wajib:
1. Tiga langkah: data diri, alamat, konfirmasi dengan indikator progres
2. Validasi per langkah dengan pesan spesifik yang menempel di field
3. Format lokal: nomor HP 08/+628, alamat sampai RT/RW
4. Draf tersimpan otomatis ke DataStore (debounce 500 ms)
5. Persetujuan data pribadi terpisah dari S&K, tidak tercentang otomatis (UU PDP)

Penyelesaian langkah demi langkah:
1. data class FormDaftar sebagai satu sumber kebenaran; UI hanya mengirim perubahan.
2. Validasi.langkah() mengembalikan peta field → pesan; tampil lewat supportingText.
3. Regex ^(\+62|0)8\d{8,11}$ setelah spasi dan tanda hubung dibuang.
4. distinctUntilChanged().debounce(500) lalu DataStore.edit; hapus draf setelah sukses.
5. Dua Checkbox terpisah; hanya S&K yang wajib untuk lanjut, persetujuan pemasaran opsional.

Kembangkan sendiri: tambahkan pilihan provinsi/kota bertingkat dari API wilayah, unggah foto KTP dengan kompresi, dan uji UI dengan Compose testing.
