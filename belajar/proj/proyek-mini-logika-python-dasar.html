Proyek mini: Logika & Python dasar

Buka versi interaktif

Tiga proyek mini ini melatih keterampilan inti jalur Logika & Python dasar satu per satu (materinya ada di jalur Pseudocode, Flowgorithm, Python, Struktur Data & Algoritma). Masing-masing cukup dikerjakan dalam 3–7 hari.

Kerjakan berurutan. Setiap proyek mini harus "selesai" menurut definisi di bawah: berfungsi termasuk kasus gagal, ada README, dan bisa didemokan. Proyek mini yang tuntas lebih berharga daripada proyek besar yang setengah jadi.

Setelah ketiganya selesai, keterampilannya akan dipakai bersama di proyek besar jalur ini.

BRIEF PROYEK MINI: Kasir konsol dengan diskon

Tujuan latihan : Input, percabangan, perulangan, format Rupiah
Fitur wajib    : Tambah item, diskon bertingkat, struk rapi, validasi input bukan angka
Tantangan      : Simpan transaksi ke CSV

Definisi selesai
[ ] Semua fitur wajib berjalan, termasuk input salah dan data kosong
[ ] Repo publik dengan README (screenshot, cara menjalankan)
[ ] Minimal satu test atau bukti pengujian
[ ] Bisa didemokan dalam 2 menit

Waktu ideal: 3-7 hari per proyek mini

Poin penting

  • Kasir konsol dengan diskon.
  • Pengelola tugas di terminal.
  • Pemecah teka-teki dan kuis algoritma.
