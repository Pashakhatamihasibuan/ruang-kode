Besar 3: Analisis harga dan efektivitas promo marketplace

Buka versi interaktif

Masalah. Brand skincare lokal sering memberi diskon besar di tanggal kembar (11.11, 12.12), tetapi tidak tahu apakah promo benar-benar menambah penjualan atau hanya menggeser pembelian dan menggerus margin.

Fitur wajib:
1. Kumpulkan data harian penjualan, harga, diskon, dan iklan per produk
2. Estimasi elastisitas harga (persen perubahan penjualan per persen perubahan harga)
3. Ukur dampak promo: lonjakan selama promo dan penurunan sebelum/sesudah (pull-forward)
4. Hitung profit tambahan bersih promo, bukan hanya omzet
5. Rekomendasi kedalaman diskon per produk

Penyelesaian langkah demi langkah:
1. Rapikan data harian dan tandai hari promo; pastikan setiap tanggal ada (isi 0 jika tidak ada penjualan).
2. Model log-log per kategori; koefisien log(harga) adalah elastisitas. Kendalikan musim dan iklan.
3. Hitung lift promo dan efek pull-forward; promo yang sehat punya lift bersih positif setelah dikurangi penurunan sesudahnya.
4. Bandingkan profit, bukan omzet: diskon 40% bisa menaikkan omzet tetapi menurunkan profit.
5. Simulasikan diskon 10/20/30% dengan elastisitas untuk merekomendasikan kedalaman diskon optimal.

Standar industri yang dinilai: dampak diukur terhadap baseline, pull-forward dihitung, keputusan berdasarkan profit, asumsi dan batasan model ditulis

Arsitektur dan stack (Python (pandas, statsmodels), SQL, Matplotlib, Google Sheets/Looker Studio untuk tim marketing)
BagianIsi
Datapenjualan_harian(produk, tanggal, unit, harga_jual, diskon, biaya_iklan), hpp_produk
Elastisitasregresi log-log: log(unit) ~ log(harga) + hari + bulan + iklan
Dampak promobaseline = rata-rata 28 hari sebelum; bandingkan unit 7 hari sebelum, saat, dan 14 hari sesudah
Profit(harga − hpp − biaya per unit) × unit, dibanding baseline
PYTHON
import numpy as np, pandas as pd
import statsmodels.formula.api as smf

d = pd.read_csv('penjualan_harian.csv', parse_dates=['tanggal'])
d['harga_efektif'] = d['harga_jual'] * (1 - d['diskon'])
d['hari'] = d['tanggal'].dt.day_name(); d['bulan'] = d['tanggal'].dt.month
d['log_unit'] = np.log1p(d['unit']); d['log_harga'] = np.log(d['harga_efektif'])

# 1) elastisitas harga per kategori
for kat, g in d.groupby('kategori'):
    m = smf.ols('log_unit ~ log_harga + C(hari) + C(bulan) + np.log1p(biaya_iklan)', data=g).fit()
    lo, hi = m.conf_int().loc['log_harga']
    print(f'{kat:12} elastisitas {m.params["log_harga"]:.2f} (95%: {lo:.2f} s.d. {hi:.2f})')

# 2) lift dan pull-forward promo 11.11
def dampak(g, mulai, akhir):
    base = g[(g.tanggal >= mulai - pd.Timedelta(days=35)) & (g.tanggal < mulai - pd.Timedelta(days=7))]['unit'].mean()
    jendela = lambda a, b: g[(g.tanggal >= a) & (g.tanggal <= b)]['unit'].sum() - base * ((b - a).days + 1)
    sebelum = jendela(mulai - pd.Timedelta(days=7), mulai - pd.Timedelta(days=1))
    saat = jendela(mulai, akhir)
    sesudah = jendela(akhir + pd.Timedelta(days=1), akhir + pd.Timedelta(days=14))
    return dict(lift_saat=saat, efek_sebelum=sebelum, efek_sesudah=sesudah, lift_bersih=saat + sebelum + sesudah)

hpp = pd.read_csv('hpp_produk.csv').set_index('produk')['hpp']
for p, g in d.groupby('produk'):
    x = dampak(g, pd.Timestamp('2026-11-11'), pd.Timestamp('2026-11-11'))
    promo = g[g.tanggal == '2026-11-11'].iloc[0]
    untung_per_unit = promo.harga_efektif - hpp[p] - 3500     # biaya admin/kirim per unit
    print(p, {k: round(v) for k, v in x.items()}, '| profit tambahan ≈', round(x['lift_bersih'] * untung_per_unit))

# 3) simulasi kedalaman diskon dengan elastisitas e
def simulasi(harga, hpp, unit_base, e):
    for disk in (0.1, 0.2, 0.3, 0.4):
        unit = unit_base * (1 - disk) ** e
        print(f'diskon {disk:.0%}: unit {unit:5.0f}  profit {unit * (harga * (1 - disk) - hpp):12,.0f}')
simulasi(harga=129000, hpp=52000, unit_base=40, e=-2.1)
