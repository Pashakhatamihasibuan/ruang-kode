Docker Compose: satu perintah untuk semuanya

Buka versi interaktif

Docker Compose menjalankan database, API, dan frontend bersama dengan satu perintah. Perekrut atau rekan tim cukup menjalankan docker compose up tanpa memasang PostgreSQL atau Python di laptopnya.

Setiap layanan punya Dockerfile. Di dalam jaringan Compose, layanan saling memanggil dengan nama layanannya, misalnya API terhubung ke host db, bukan localhost. Gunakan healthcheck agar API menunggu database benar-benar siap.

Data PostgreSQL disimpan di volume agar tidak hilang saat container dihapus.

TERMINAL
# docker-compose.yml
services:
  db:
    image: postgres:16
    environment:
      POSTGRES_DB: kasirku
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes: [pgdata:/var/lib/postgresql/data]
    healthcheck:
      test: ["CMD", "pg_isready", "-U", "postgres"]
      interval: 5s
      retries: 10

  api:
    build: ./backend
    env_file: .env
    environment:
      DATABASE_URL: postgres://postgres:${DB_PASSWORD}@db:5432/kasirku
    command: sh -c "python manage.py migrate && gunicorn config.wsgi -b 0.0.0.0:8000"
    ports: ["8000:8000"]
    depends_on:
      db: { condition: service_healthy }

  web:
    build: ./frontend
    environment:
      VITE_API_URL: http://localhost:8000/api
    ports: ["5173:5173"]
    depends_on: [api]

volumes:
  pgdata:

Poin penting

  • Satu perintah menjalankan db, api, web.
  • Antar layanan memanggil dengan nama layanan (db).
  • healthcheck + depends_on; data di volume.

Cek pemahaman

Di dalam Compose, API terhubung ke PostgreSQL dengan host?

Jawaban: db (nama layanan)

localhost di dalam container adalah container itu sendiri.
