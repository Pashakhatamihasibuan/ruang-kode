Mini 1: Pipeline ETL harian yang idempoten dengan karantina

Buka versi interaktif

Masalah. Toko Nusantara mengirim file penjualan harian dari tiga cabang. Isinya sering kotor (qty berisi huruf, harga negatif, baris dobel), dan ketika job dijalankan ulang, laporan omzet ikut dobel.

Fitur wajib:
1. Baca file per tanggal dan validasi setiap baris
2. Baris rusak masuk tabel karantina beserta alasan dan isi aslinya
3. Duplikat order_id dalam satu file dibuang
4. Muat ulang per partisi tanggal dalam satu transaksi (idempoten)
5. Tabel log_run untuk audit setiap eksekusi

Penyelesaian langkah demi langkah:
1. Fungsi validasi() mengembalikan alasan penolakan atau None.
2. Simpan baris rusak sebagai JSON agar bisa diperbaiki dan dimuat ulang.
3. Himpunan dilihat per file mendeteksi order_id yang muncul dua kali.
4. with db: membungkus DELETE partisi + INSERT; gagal di tengah berarti tidak ada yang berubah.
5. Catat jumlah dimuat, dikarantina, dan duplikat per run.

Kembangkan sendiri: ganti sumber menjadi folder berpartisi tanggal=YYYY-MM-DD, tulis keluaran Parquet, dan jadwalkan dengan Airflow.
