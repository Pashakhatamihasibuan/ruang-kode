Mini 4: Deteksi lonjakan transaksi real-time dengan sliding window

Buka versi interaktif

Masalah. Tim risiko payment gateway ingin diberi tahu dalam hitungan detik saat sebuah merchant tiba-tiba menerima banyak transaksi bernilai besar (indikasi kartu curian atau pencucian uang). Event datang dari Kafka dan bisa terkirim dua kali.

Fitur wajib:
1. Proses event satu per satu, bukan per batch harian
2. Deduplikasi event_id (at-least-once delivery)
3. Sliding window 60 detik per merchant
4. Alert saat lebih dari 4 transaksi atau total lebih dari Rp5 juta dalam jendela
5. Jendela otomatis membuang event lama

Penyelesaian langkah demi langkah:
1. Loop atas aliran event; state disimpan per merchant.
2. Himpunan sudah; di produksi Redis SET ber-TTL atau state store Flink.
3. deque per merchant; buang dari kiri selama event lebih tua dari t − 60.
4. Hitung jumlah dan total jendela setiap event masuk.
5. Kirim alert ke topik risk.alerts dan kanal tim risiko.

Kembangkan sendiri: implementasikan ulang dengan Kafka + Flink SQL (HOP window) atau Spark Structured Streaming, termasuk watermark untuk event terlambat.
