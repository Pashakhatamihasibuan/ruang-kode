PROYEK BESAR: Aplikasi keuangan pribadi CLI

Masalah
  Mahasiswa sering tidak tahu ke mana uang sakunya habis.

Fitur wajib
  1. Catat pemasukan/pengeluaran dengan kategori dan tanggal
  2. Laporan bulanan per kategori dan sisa anggaran
  3. Impor mutasi rekening dari CSV
  4. Data tersimpan di SQLite
  5. Perintah CLI yang rapi (argparse atau Typer)

Stack yang disarankan
  Python 3.12, SQLite, Typer, pytest, Ruff

Rencana 4 minggu
  Minggu 1: model data dan perintah tambah/daftar
  Minggu 2: laporan dan anggaran
  Minggu 3: impor CSV dan penanganan data rusak
  Minggu 4: test, README, rilis di PyPI atau GitHub Release

Standar industri yang dinilai
  Struktur paket (src/), test untuk perhitungan laporan, pesan error yang jelas untuk input salah

Keluaran
  [ ] Repo dengan README lengkap, keputusan teknis, dan screenshot
  [ ] Demo online atau video 2 menit
  [ ] Test/bukti pengujian dan CI hijau (untuk proyek kode)
  [ ] Ringkasan 1 paragraf untuk CV dan LinkedIn

Poin penting

  • Masalah: Mahasiswa sering tidak tahu ke mana uang sakunya habis.
  • Stack: Python 3.12, SQLite, Typer, pytest, Ruff.
  • Rencana 4 minggu; dinilai dengan rubrik standar industri.
