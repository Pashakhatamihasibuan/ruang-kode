Profil GitHub dan LinkedIn yang meyakinkan

Buka versi interaktif

Buat profil README GitHub (repo bernama sama dengan username) berisi satu kalimat siapa kamu, stack utama, dan 3–4 proyek unggulan dengan link demo. Pin repo terbaikmu; sembunyikan latihan tutorial.

Di LinkedIn, isi bagian Featured dengan link demo proyek besar, dan tulis pengalaman proyek seperti pengalaman kerja: apa masalahnya, apa yang kamu bangun, hasilnya.

Konsistensi lebih penting daripada jumlah: tiga proyek yang rapi, selesai, dan bisa dibuka jauh lebih baik daripada dua puluh repo kosong.
