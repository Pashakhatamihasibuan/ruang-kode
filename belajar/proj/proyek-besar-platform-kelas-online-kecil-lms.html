Proyek besar: Platform kelas online kecil (LMS)

Buka versi interaktif

Proyek besar (capstone) jalur Backend Python (Django). Masalahnya nyata: Guru les ingin menjual kelas video dan memantau progres murid. Kerjakan dalam sekitar 4 minggu dengan rencana mingguan di bawah.

Perlakukan seperti pekerjaan di tim: tulis kebutuhan dulu, pecah menjadi issue di GitHub Projects, kerjakan per branch dan pull request, dan catat keputusan teknis di README. Nilai dirimu dengan rubrik di modul pertama jalur ini.

Yang membedakan proyek ini dari tutorial: izin diuji untuk setiap endpoint, webhook aman dari duplikasi, query dioptimalkan (tanpa N+1). Itulah yang akan kamu ceritakan saat wawancara.

PROYEK BESAR: Platform kelas online kecil (LMS)

Masalah
  Guru les ingin menjual kelas video dan memantau progres murid.

Fitur wajib
  1. Peran guru dan murid
  2. Guru membuat kelas, modul, dan kuis
  3. Murid mendaftar, menonton, mengerjakan kuis, melihat progres
  4. Pembayaran sandbox (Midtrans/Xendit) dengan webhook
  5. Email notifikasi dengan Celery

Stack yang disarankan
  Django, DRF, PostgreSQL, Redis, Celery, pytest, Docker Compose, Render

Rencana 4 minggu
  Minggu 1: model kelas-modul-pelajaran-progres
  Minggu 2: API dan izin per peran
  Minggu 3: pembayaran dan webhook idempoten
  Minggu 4: background task, test, deploy
