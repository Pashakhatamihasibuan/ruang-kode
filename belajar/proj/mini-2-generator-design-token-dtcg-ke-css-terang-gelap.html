Mini 2: Generator design token DTCG ke CSS (terang & gelap)

Buka versi interaktif

Masalah. Design system startup masih menyalin warna hex manual dari Figma ke kode. Buat pipeline kecil yang mengubah token format DTCG tiga lapis (primitive, semantic, component) menjadi CSS variables untuk dua tema.

Fitur wajib:
1. Membaca token DTCG dengan $type dan $value
2. Menyelesaikan alias berantai seperti {semantic.color.action}
3. Mode terang/gelap dari satu sumber
4. Menolak komponen yang merujuk warna primitive langsung

Penyelesaian langkah demi langkah:
1. Simpan token sebagai JSON; lapisan semantic menyimpan nilai per mode.
2. Tulis fungsi ambil(jalur) dan selesaikan(nilai, mode) yang mengikuti alias sampai nilai akhir.
3. Ratakan pohon token menjadi nama variabel --lapis-nama.
4. Cetak :root dan [data-theme="dark"], lalu jalankan aturan arsitektur.

Kembangkan sendiri: ganti dengan Style Dictionary v4 atau Terrazzo, tambahkan keluaran Android XML dan Swift, dan publikasikan paket npm @perusahaan/tokens dengan changelog.
