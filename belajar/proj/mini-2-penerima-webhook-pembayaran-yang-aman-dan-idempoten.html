Mini 2: Penerima webhook pembayaran yang aman dan idempoten

Buka versi interaktif

Masalah. Payment gateway mengirim notifikasi "pembayaran berhasil" ke server. Penyerang bisa memalsukannya, dan gateway bisa mengirim notifikasi yang sama berkali-kali.

Fitur wajib:
1. Tolak webhook yang tanda tangannya salah
2. Notifikasi yang sama hanya diproses sekali
3. Status hanya boleh maju (MENUNGGU → DIBAYAR), tidak mundur
4. Selalu balas cepat 200 agar gateway tidak mengulang terus

Penyelesaian langkah demi langkah:
1. Hitung HMAC-SHA256 dari body mentah dengan kunci rahasia, bandingkan dengan hmac.compare_digest (aman dari timing attack).
2. Simpan id event yang sudah diproses; jika sudah ada, langsung balas "duplikat".
3. Gunakan tabel transisi status yang diizinkan.
4. Pisahkan logika ke fungsi murni agar mudah diuji (kode di bawah bisa dijalankan).

Kembangkan sendiri: pasang di view Django (request.body mentah, csrf_exempt) dan proses berat di Celery agar balasan tetap cepat.

PYTHON
import hashlib, hmac, json

RAHASIA = b'kunci-rahasia-dari-dashboard'
BOLEH = {('MENUNGGU', 'DIBAYAR'), ('MENUNGGU', 'KEDALUWARSA'), ('DIBAYAR', 'DIKEMBALIKAN')}
pesanan = {'PSN-41': 'MENUNGGU'}
sudah_diproses = set()            # di produksi: tabel dengan UNIQUE(event_id)

def tanda_tangan(body: bytes) -> str:
    return hmac.new(RAHASIA, body, hashlib.sha256).hexdigest()

def terima_webhook(body: bytes, sig: str):
    if not hmac.compare_digest(tanda_tangan(body), sig):
        return 401, 'tanda tangan salah'
    e = json.loads(body)
    if e['event_id'] in sudah_diproses:
        return 200, 'duplikat, diabaikan'
    lama, baru = pesanan.get(e['order_id']), e['status']
    if (lama, baru) not in BOLEH:
        sudah_diproses.add(e['event_id'])
        return 200, f'transisi {lama} -> {baru} ditolak'
    pesanan[e['order_id']] = baru
    sudah_diproses.add(e['event_id'])
    return 200, f'{e["order_id"]}: {lama} -> {baru}'

body = json.dumps({'event_id': 'ev-1', 'order_id': 'PSN-41', 'status': 'DIBAYAR'}).encode()
print(terima_webhook(body, tanda_tangan(body)))
print(terima_webhook(body, tanda_tangan(body)))           # dikirim ulang oleh gateway
print(terima_webhook(body, 'palsu123'))                   # dipalsukan
mundur = json.dumps({'event_id': 'ev-2', 'order_id': 'PSN-41', 'status': 'MENUNGGU'}).encode()
print(terima_webhook(mundur, tanda_tangan(mundur)))
print('status akhir:', pesanan)

Cek pemahaman

Kenapa memakai hmac.compare_digest, bukan ==?
