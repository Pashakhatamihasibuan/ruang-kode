Design System · Modul 5 · Praktik langsung

Komponen tombol lengkap dengan state

Buka versi interaktif

Komponen sistem harus menangani semua state: default, hover, fokus keyboard, ditekan, nonaktif, dan memuat. State yang terlupa adalah sumber bug tampilan paling umum.

Varian (primary, secondary, danger) dan ukuran (sm, md, lg) dibuat lewat kelas atau prop, bukan dengan menyalin komponen. Target sentuh minimal 44px, dan saat memuat tombol diberi aria-busy serta tetap memiliki label yang terbaca.

Tugas: lengkapi state fokus keyboard dengan :focus-visible yang memakai outline 3px, lalu tekan Tab di pratinjau untuk mencobanya.

HTML
<div class="baris">
  <button class="btn btn--primary">Simpan</button>
  <button class="btn btn--secondary">Batal</button>
  <button class="btn btn--danger">Hapus akun</button>
  <button class="btn btn--primary" disabled>Nonaktif</button>
  <button class="btn btn--primary" aria-busy="true"><span class="putar" aria-hidden="true"></span>Menyimpan…</button>
</div>
CSS
:root{--action:#0F766E;--danger:#B91C1C;--line:#C9CFCC;--r:12px}
body{font:16px/1.5 system-ui,sans-serif;padding:24px}
.baris{display:flex;flex-wrap:wrap;gap:12px}
.btn{display:inline-flex;align-items:center;gap:8px;min-height:44px;padding:0 18px;border-radius:var(--r);border:1px solid transparent;font:600 15px system-ui;cursor:pointer;transition:transform .1s,filter .15s}
.btn--primary{background:var(--action);color:#fff}
.btn--secondary{background:#fff;color:#1C1B19;border-color:var(--line)}
.btn--danger{background:var(--danger);color:#fff}
.btn:hover{filter:brightness(1.08)}
.btn:active{transform:scale(.97)}
.btn:disabled{opacity:.45;cursor:not-allowed;filter:none}
.btn[aria-busy=true]{cursor:progress}
.putar{width:14px;height:14px;border-radius:50%;border:2px solid #fff6;border-top-color:#fff;animation:p .8s linear infinite}
@keyframes p{to{transform:rotate(360deg)}}
@media (prefers-reduced-motion:reduce){.putar{animation-duration:3s}}

Tantangan

  1. Tambahkan aturan .btn:focus-visible dengan outline 3px agar fokus keyboard terlihat.

Poin penting

  • State: default, hover, focus, active, disabled, loading.
  • Varian & ukuran lewat kelas/prop.
  • Target sentuh ≥ 44px; fokus selalu terlihat.

Cek pemahaman

Kenapa memakai :focus-visible, bukan :focus?

Jawaban: Outline hanya muncul untuk navigasi keyboard, tidak saat diklik mouse

Pengguna mouse tidak terganggu, pengguna keyboard tetap terbantu.
