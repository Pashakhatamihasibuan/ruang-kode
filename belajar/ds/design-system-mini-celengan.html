Design System · Modul 7 · Proyek akhir

Design system mini "Celengan"

Buka versi interaktif

Rapikan aplikasi tabungan fiktif yang tumbuh tanpa aturan menjadi design system mini: token tiga lapis, lima komponen inti dengan semua state, mode gelap, dan dokumentasi.

Teknologi: Figma + CSS + Storybook

Fitur yang dibuat

  • Audit visual dengan jumlah warna, ukuran huruf, dan varian tombol sebelum-sesudah
  • Token primitif, semantik, komponen dalam format DTCG
  • Mode gelap hanya dengan mengganti token semantik
  • Komponen Button, TextField, Checkbox, Modal, Toast dengan semua state
  • Kontras semua pasangan teks lulus WCAG 2.2 AA
  • Halaman dokumentasi: kapan dipakai, kapan tidak, contoh benar/salah
  • Changelog dengan semantic versioning
  • Pilot di satu layar dan catatan hasilnya

Langkah kerja

  1. Audit dan tentukan token.
  2. Bangun komponen di Figma dan CSS.
  3. Uji kontras dan keyboard.
  4. Tulis dokumentasi, rilis v1.0.0.

}
