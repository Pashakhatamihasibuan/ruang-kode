Fondasi dan tokens.json (DTCG 2025.10)

Buka versi interaktif

Papan fondasi menampilkan warna semantik lengkap dengan rasio kontras WCAG, skala tipografi rasio 1,2, spasi grid 4/8, radius, dan elevasi. Nama tokennya sama persis dengan isi tokens.json.

tokens.json memakai format DTCG 2025.10: warna ditulis sebagai objek {colorSpace, components, hex}, token semantik merujuk primitif dengan alias seperti {color.brand.primer}, dan ada token motion (durasi, cubic-bezier).

Impor ke Figma lewat Tokens Studio atau plugin Variables Import, lalu buat mode terang/gelap dengan tokens-gaya-gelap.json.

Lapisan token
LapisanContohDipakai oleh
Primitifcolor.brand.primer = #8A4B2AToken semantik saja
Semantikcolor.action.primary = {color.brand.primer}Komponen
Komponenbutton.primary.bg = {color.action.primary}Satu komponen

Poin penting

  • Komponen merujuk token semantik, bukan nilai mentah.
  • DTCG 2025.10: format tukar token antar alat.
