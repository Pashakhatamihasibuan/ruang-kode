Design System · Modul 3 · Konsep & kode

Ikon, ilustrasi & motion yang konsisten

Buka versi interaktif

Bahasa desain tidak berhenti di warna dan huruf. Ikon perlu satu gaya: ukuran grid sama (misalnya 24×24), ketebalan garis sama, sudut sama. Mencampur ikon garis dan ikon terisi dari pustaka berbeda langsung terlihat tidak rapi.

Ilustrasi perlu aturan palet, proporsi tokoh, dan kapan dipakai (biasanya empty state dan onboarding, bukan di setiap layar). Motion juga bagian bahasa: durasi standar (misalnya 150 ms untuk hover, 250 ms untuk panel), kurva easing, dan arah gerak yang sama.

Semua ini dibakukan sebagai token dan pedoman. Hormati prefers-reduced-motion agar pengguna yang sensitif terhadap gerakan tidak terganggu.

CSS
:root {
  --icon-size-sm: 16px;
  --icon-size-md: 24px;
  --icon-stroke: 1.75;

  --motion-duration-fast: 150ms;   /* hover, fokus */
  --motion-duration-base: 250ms;   /* panel, dropdown */
  --motion-easing-standard: cubic-bezier(.2, 0, 0, 1);
}

@media (prefers-reduced-motion: reduce) {
  :root { --motion-duration-fast: 0ms; --motion-duration-base: 0ms; }
}

.dropdown { transition: opacity var(--motion-duration-base) var(--motion-easing-standard); }

Poin penting

  • Ikon: satu grid, satu ketebalan garis, satu gaya.
  • Ilustrasi punya aturan kapan dipakai.
  • Motion dibakukan sebagai token durasi dan easing.
  • Hormati prefers-reduced-motion.
