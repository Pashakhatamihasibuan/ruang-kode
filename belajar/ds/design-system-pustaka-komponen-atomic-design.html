Design system, pustaka komponen & atomic design

Buka versi interaktif

Design system adalah satu sumber kebenaran untuk membangun produk: prinsip, bahasa visual, design token, komponen di Figma dan di kode, pedoman penggunaan, serta proses kontribusi. Pustaka komponen hanyalah satu bagiannya, yaitu kode tombol, input, modal, dan seterusnya.

Atomic design (Brad Frost) menyusun antarmuka dari kecil ke besar: atom (label, ikon, input), molekul (kolom pencarian = input + tombol), organisme (header), template (kerangka halaman), dan halaman (template berisi data nyata).

Contoh terbuka yang layak dipelajari: Material Design (Google), Carbon (IBM), Polaris (Shopify), Primer (GitHub), dan Atlassian Design System.

CONTOH
Design system
├─ Prinsip & bahasa desain   "Jelas lebih dulu, baru indah"
├─ Token                     color.action.primary, space.200
├─ Komponen                  Button, TextField, Modal (Figma + kode)
├─ Pola                      Form pendaftaran, empty state
├─ Pedoman                   kapan dipakai, kapan tidak, contoh benar/salah
└─ Tata kelola               kontribusi, versi, changelog

Poin penting

  • Design system ⊃ pustaka komponen.
  • Atom → molekul → organisme → template → halaman.
  • Pelajari sistem terbuka: Material, Carbon, Polaris, Primer.
