Skala tipografi & jarak

Buka versi interaktif

Skala tipografi dibuat dengan rasio, misalnya 1,25 (major third): 16 → 20 → 25 → 31 → 39. Dengan skala, ukuran huruf tidak dipilih acak per layar. Lihat visualisasi dan coba rasio lain.

Teks isi 16px dengan line-height 1,5 dan panjang baris 45-80 karakter. Gunakan rem agar menghormati pengaturan ukuran huruf pengguna.

Jarak memakai skala 4 atau 8: space.100 = 8px, space.200 = 16px, dan seterusnya. Grid 4 kolom di ponsel, 8 di tablet, 12 di desktop; breakpoint umum 600, 1024, 1440.

CSS
:root{
  --font-size-100: .8rem;   /* 12.8px keterangan */
  --font-size-200: 1rem;    /* 16px  isi        */
  --font-size-300: 1.25rem; /* 20px            */
  --font-size-400: 1.563rem;/* 25px  judul kecil */
  --font-size-500: 1.953rem;/* 31px  judul      */
  --space-050: .25rem; --space-100: .5rem;
  --space-200: 1rem;   --space-300: 1.5rem; --space-400: 2rem;
}

Poin penting

  • Skala tipografi dengan rasio tetap.
  • Isi 16px, line-height 1,5, 45-80 karakter.
  • Jarak skala 4/8; ukuran dalam rem.
