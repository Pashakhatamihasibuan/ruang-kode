Token: primitif, semantik, komponen

Buka versi interaktif

Design token adalah keputusan desain yang diberi nama: warna, ukuran huruf, jarak, radius, bayangan, durasi animasi. Token disimpan sekali, lalu diekspor ke CSS, Android, iOS, dan Figma.

Susun tiga lapis. Primitif: nilai mentah (teal.700 = #0F766E). Semantik: peran (color.action.primary → teal.700). Komponen: pemakaian spesifik (button.primary.bg → color.action.primary). Komponen hanya boleh merujuk token semantik atau komponen.

Format pertukaran yang kini dipakai banyak alat adalah spesifikasi DTCG (Design Tokens Community Group), versi stabil 2025.10. Lihat visualisasi: ganti tema dan perhatikan hanya lapis primitif yang berubah.

JSON
{
  "teal":  { "700": { "$type": "color", "$value": "#0F766E" },
             "300": { "$type": "color", "$value": "#5EEAD4" } },
  "color": {
    "action": { "primary": { "$value": "{teal.700}" } },
    "text":   { "default": { "$value": "{gray.900}" } }
  },
  "button": {
    "primary": { "bg": { "$value": "{color.action.primary}" } }
  }
}

Kode pemula vs kode rapi

Komponen memakai token semantik, bukan kode warna

Kode heksa di dalam komponen harus dicari satu per satu saat brand berganti warna. Token semantik menyebut perannya, sehingga perubahan cukup di satu tempat dan mode gelap tinggal mengganti nilai token.

KODE PEMULA
.tombol-utama { background: #2563EB; color: #FFFFFF; }
.tombol-utama:hover { background: #1D4ED8; }
KODE RAPI (BEST PRACTICE)
:root {
  --blue-600: #2563EB;  /* primitif */
  --blue-700: #1D4ED8;
  --color-action-primary: var(--blue-600);        /* semantik */
  --color-action-primary-hover: var(--blue-700);
  --color-on-action: #FFFFFF;
}
.tombol-utama { background: var(--color-action-primary); color: var(--color-on-action); }
.tombol-utama:hover { background: var(--color-action-primary-hover); }

Poin penting

  • Token = keputusan desain bernama.
  • Primitif → semantik → komponen.
  • Nama menurut peran: color.text.default, bukan gray900.
  • Format DTCG untuk pertukaran antar alat.
