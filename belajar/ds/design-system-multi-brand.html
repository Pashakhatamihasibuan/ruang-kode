Design system multi-brand

Buka versi interaktif

Kit proyek Design system multi-brand berisi tiga brand (Nusa Group, Nusa Pay, Nusa Mart) dengan struktur token yang sama. Papan "satu komponen, tiga brand" membuktikan bahwa komponen tidak berubah, hanya token semantik yang berganti.

Di Figma, buat satu koleksi Variables dengan tiga mode (satu per brand), lalu ganti mode di frame untuk melihat brand lain.

Poin penting

  • Multi-brand = satu komponen, banyak set token.
  • Figma Variables: satu mode per brand.
