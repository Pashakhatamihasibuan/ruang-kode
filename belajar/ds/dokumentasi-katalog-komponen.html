Dokumentasi & katalog komponen

Buka versi interaktif

Dokumentasi yang dipakai menjawab tiga pertanyaan per komponen: kapan dipakai, kapan tidak, dan bagaimana (props, contoh kode, contoh benar dan salah).

Storybook adalah katalog komponen standar di sisi kode: setiap state dijadikan "story" yang bisa diuji visual dan aksesibilitasnya. Di sisi desain, pustaka Figma dengan variabel dan Code Connect menghubungkan komponen Figma ke kodenya.

Token disinkronkan otomatis dengan alat seperti Tokens Studio atau Style Dictionary agar Figma dan kode tidak pernah berbeda.

CONTOH
Button
Kapan dipakai   : memicu aksi di halaman ini (simpan, bayar)
Kapan tidak     : pindah halaman → pakai Link
Varian          : primary (1 per layar), secondary, danger
Ukuran          : sm 36px, md 44px (default), lg 52px
Aksesibilitas   : label teks wajib; ikon saja → aria-label

Poin penting

  • Dokumentasi: kapan, kapan tidak, bagaimana.
  • Storybook untuk katalog dan uji visual.
  • Sinkronkan token Figma dan kode otomatis.
