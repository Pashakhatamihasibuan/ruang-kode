Token lintas platform: format DTCG

Buka versi interaktif

Token yang hanya hidup di Figma atau hanya di CSS akan cepat berbeda. Solusinya: simpan token di satu berkas sumber, lalu hasilkan CSS, kode Android, dan iOS darinya.

Format yang kini dipakai banyak alat adalah format DTCG (Design Tokens Community Group, W3C). Versi stabil pertamanya, 2025.10, dirilis Oktober 2025. Setiap token punya $value dan $type, dan token bisa merujuk token lain dengan kurung kurawal.

Alat seperti Style Dictionary atau Tokens Studio membaca berkas ini dan menulis variabel CSS, berkas Kotlin, Swift, dan lainnya. Perubahan warna brand cukup di satu tempat, lalu semua platform ikut berubah lewat pipeline build.

JSON
{
  "color": {
    "blue": {
      "600": { "$value": "#2563EB", "$type": "color" }
    },
    "action": {
      "primary": { "$value": "{color.blue.600}", "$type": "color",
                   "$description": "Latar tombol utama" }
    }
  },
  "space": {
    "md": { "$value": "16px", "$type": "dimension" }
  }
}

/* hasil build untuk web */
:root {
  --color-blue-600: #2563EB;
  --color-action-primary: var(--color-blue-600);
  --space-md: 16px;
}

Poin penting

  • Satu sumber token, banyak keluaran platform.
  • DTCG: $value, $type, dan rujukan {token.lain}.
  • Style Dictionary / Tokens Studio menghasilkan kode.
  • Perubahan brand cukup di satu berkas.

Cek pemahaman

Apa arti "$value": "{color.blue.600}"?

Jawaban: Token ini merujuk nilai token color.blue.600

Kurung kurawal adalah rujukan antartoken.

Keuntungan utama berkas token tunggal?

Jawaban: Web, Android, dan iOS memakai nilai yang sama

Satu sumber mencegah nilai berbeda di tiap platform.

Kerjakan latihannya di aplikasi

Sebelumnya: Mode gelap dengan token CSS

Berikutnya: Komponen tombol lengkap dengan state
