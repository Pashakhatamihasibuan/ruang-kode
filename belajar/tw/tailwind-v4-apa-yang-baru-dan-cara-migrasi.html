Tailwind v4: apa yang baru dan cara migrasi

Buka versi interaktif

Tailwind v4 (rilis 2025) ditulis ulang agar jauh lebih cepat. Perubahan terbesar: konfigurasi pindah dari tailwind.config.js ke CSS. Kamu cukup menulis @import "tailwindcss"; dan mengatur tema dengan @theme.

Deteksi file otomatis (tidak perlu lagi mengisi content), warna bawaan memakai ruang warna OKLCH yang lebih cerah, dan fitur CSS modern seperti container query (@container dan @md:) sudah bawaan.

Beberapa nama kelas berubah, misalnya shadow-sm menjadi shadow-xs dan rounded sekarang setara rounded-sm lama. Jalankan npx @tailwindcss/upgrade untuk memigrasi proyek v3 secara otomatis, lalu periksa hasilnya.

@import "tailwindcss";

@theme {
  --color-merek: #B4532A;
  --font-judul: "Fraunces", serif;
  --breakpoint-3xl: 1920px;
}

/* kelas buatan sendiri */
@utility tengah {
  display: grid;
  place-items: center;
}

Soal latihan

  1. Tambahkan titik henti khusus 3xl = 1920px dan warna aksen di Tailwind v4.

    Petunjuk

    Variabel --breakpoint-* dan --color-* di dalam @theme.

    Lihat jawaban
    CSS
    @import "tailwindcss";

@theme {
  --breakpoint-3xl: 1920px;
  --color-aksen: #0F5F8A;
}

  2. Buat kartu yang berubah menjadi dua kolom saat wadahnya (bukan layar) selebar md, memakai container query v4.

    Petunjuk

    Induk diberi kelas @container, anak memakai @md:grid-cols-2.

    Lihat jawaban
    HTML
    <div class="@container">
  <div class="grid grid-cols-1 @md:grid-cols-2 gap-4">
    <img src="kopi.jpg" alt="Kopi Gayo" class="rounded-lg">
    <p>Kopi Gayo dari dataran tinggi Aceh.</p>
  </div>
</div>

Poin penting

  • v4: @import "tailwindcss" dan @theme.
  • Deteksi file otomatis, container query bawaan.
  • npx @tailwindcss/upgrade untuk migrasi.
