Form yang rapi

Buka versi interaktif

Form dibangun dari utilitas biasa: block, w-full, border, rounded-lg, px-3 py-2, dan focus:ring.

Untuk keadaan tidak valid, pakai variant invalid:border-rose-500. Plugin resmi @tailwindcss/forms menyamakan gaya bawaan input di semua browser.

Tetap pakai <label> yang terhubung ke input lewat for/id agar mudah diakses.

HTML
<form class="max-w-sm p-6 space-y-4">
  <div>
    <label for="email" class="block text-sm font-medium text-slate-700">Email</label>
    <input id="email" type="email" required class="mt-1 block w-full border border-slate-300 rounded-lg px-3 py-2 focus:ring-2 focus:ring-sky-400 outline-none">
  </div>
  <div>
    <label for="sandi" class="block text-sm font-medium text-slate-700">Kata sandi</label>
    <input id="sandi" type="password" class="mt-1 block w-full border border-slate-300 rounded-lg px-3 py-2">
  </div>
  <button class="w-full py-2 bg-sky-600 text-white rounded-lg">Masuk</button>
</form>

Tantangan

  1. Samakan input kata sandi dengan input email: tambahkan focus:ring-2 dan focus:ring-sky-400.

Soal latihan

  1. Tambahkan pesan error merah di bawah input email yang hanya terlihat jika input tidak valid dan sudah diisi.

    Petunjuk

    Kelas peer pada input, lalu p dengan hidden peer-[&:not(:placeholder-shown):invalid]:block. Bentuk lebih sederhana: invalid:border-rose-500 pada input.

    Lihat jawaban
    HTML
    <input type="email" placeholder=" " class="peer block w-full border rounded-lg px-3 py-2 invalid:[&:not(:placeholder-shown)]:border-rose-500">
<p class="hidden mt-1 text-sm text-rose-600 peer-[&:not(:placeholder-shown):invalid]:block">Format email belum benar.</p>

  2. Buat select dan textarea yang gayanya seragam dengan input lain.

    Petunjuk

    Pakai kelas yang sama: block w-full border rounded-lg px-3 py-2.

    Lihat jawaban
    HTML
    <select class="block w-full border border-slate-300 rounded-lg px-3 py-2">
  <option>Flutter</option><option>Compose</option>
</select>
<textarea rows="3" class="mt-3 block w-full border border-slate-300 rounded-lg px-3 py-2" placeholder="Catatan"></textarea>

Poin penting

  • Form = utilitas biasa + focus:ring.
  • invalid: untuk validasi visual; @tailwindcss/forms untuk gaya dasar input.
