Menu ponsel dengan sedikit JavaScript

Buka versi interaktif

Tailwind hanya mengurus tampilan. Untuk interaksi seperti membuka menu, cukup JavaScript kecil yang menambah atau membuang kelas: menu.classList.toggle('hidden').

Jangan lupa aksesibilitas: perbarui aria-expanded pada tombol agar pembaca layar tahu menu sedang terbuka atau tertutup.

Di proyek React atau Vue, kelas ditentukan dari state, misalnya className={buka ? 'block' : 'hidden'}.

HTML
<nav class="bg-slate-900 text-white">
  <div class="flex items-center justify-between p-4">
    <b>RuangKode</b>
    <button id="tombol" class="px-3 py-1 border border-white/40 rounded" aria-expanded="false" aria-controls="menu">Menu</button>
  </div>
  <div id="menu" class="hidden flex-col gap-2 px-4 pb-4">
    <a class="block">Beranda</a><a class="block">Kursus</a><a class="block">Masuk</a>
  </div>
</nav>
JAVASCRIPT
const tombol = document.getElementById('tombol');
const menu = document.getElementById('menu');
tombol.addEventListener('click', () => {
  // tulis kodemu di sini: tampilkan/sembunyikan menu
});

Tantangan

  1. Lengkapi JavaScript: saat tombol diklik, toggle kelas hidden pada menu dan perbarui aria-expanded. Klik tombolnya sekali lalu tekan Periksa.

Poin penting

  • Tailwind untuk gaya, JS kecil untuk interaksi.
  • classList.toggle('hidden').
  • Perbarui aria-expanded.
