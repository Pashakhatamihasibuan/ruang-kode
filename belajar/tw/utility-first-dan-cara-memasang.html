Utility-first dan cara memasang

Buka versi interaktif

Tailwind CSS adalah framework utility-first: alih-alih menulis CSS sendiri, kamu menempelkan kelas kecil yang masing-masing melakukan satu hal, misalnya p-4 (padding), bg-sky-600 (warna latar), rounded-lg (sudut membulat).

Untuk belajar dan mencoba cepat, cukup pasang Play CDN: <script src="https://cdn.tailwindcss.com"></script>. Pratinjau di halaman ini memakai cara itu (Tailwind 3.4). Untuk proyek sungguhan, pasang lewat npm agar CSS yang dihasilkan kecil dan hanya berisi kelas yang dipakai.

Cara pasang Tailwind v4 di proyek Vite: npm install tailwindcss @tailwindcss/vite, tambahkan plugin tailwindcss() di vite.config.js, lalu tulis @import "tailwindcss"; di file CSS utama. Di v3 kamu memakai tailwind.config.js dan tiga baris @tailwind base; @tailwind components; @tailwind utilities;.

Kelas di Tailwind v3 dan v4 hampir sama, jadi yang kamu pelajari di sini berlaku di keduanya.

HTML
<div class="max-w-sm mx-auto mt-6 p-6 bg-white rounded-xl shadow-md">
  <h1 class="text-2xl font-bold text-slate-800">Toko Nusantara</h1>
  <p class="mt-2 text-slate-600">Kopi, teh, dan camilan pilihan.</p>
  <button class="mt-4 px-4 py-2 bg-sky-600 text-white rounded-lg">Belanja sekarang</button>
</div>

Tantangan

  1. Ubah tombol menjadi hijau: ganti bg-sky-600 dengan bg-emerald-600.

Soal latihan

  1. Buat kartu profil: lebar maksimal max-w-xs, padding 6, latar putih, sudut rounded-2xl, bayangan shadow-lg, berisi nama tebal dan peran berwarna abu-abu.

    Petunjuk

    Gabungkan kelas di satu div, lalu kelas teks di h2 dan p.

    Lihat jawaban
    HTML
    <div class="max-w-xs p-6 bg-white rounded-2xl shadow-lg">
  <h2 class="text-xl font-bold text-slate-900">Rina Siregar</h2>
  <p class="text-slate-500">Flutter Developer</p>
</div>

  2. Tulis isi file CSS utama dan potongan konfigurasi Vite untuk memasang Tailwind v4.

    Petunjuk

    Plugin @tailwindcss/vite dan satu baris @import.

    Lihat jawaban
    HTML
    <!-- src/style.css -->
@import "tailwindcss";

<!-- vite.config.js -->
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'
export default defineConfig({ plugins: [tailwindcss()] })

Poin penting

  • Utility-first: satu kelas, satu tugas gaya.
  • Play CDN untuk mencoba; npm + Vite untuk proyek.
  • v4: @import "tailwindcss"; v3: tailwind.config.js + @tailwind.
