Tema dan konfigurasi

Buka versi interaktif

Warna merek, font, dan jarak sendiri didaftarkan di tema. Di v3 lewat tailwind.config.js bagian theme.extend. Di Play CDN, isi tailwind.config = {...} di skrip.

Di v4, tema ditulis di CSS: @theme { --color-merek: #B4532A; --font-judul: "Fraunces", serif; }. Setelah itu kelas bg-merek dan font-judul langsung tersedia.

Contoh di bawah mendaftarkan warna merek lewat skrip konfigurasi.

HTML
<script>
  tailwind.config = { theme: { extend: { colors: { merek: '#B4532A', krem: '#FBF3E4' } } } }
</script>
<div class="p-6 bg-krem">
  <h1 class="text-2xl font-bold text-merek">Kedai Kopi Senja</h1>
  <button id="pesan" class="mt-3 px-4 py-2 text-white rounded-lg bg-slate-700">Pesan</button>
</div>

Tantangan

  1. Pakai warna tema: ganti bg-slate-700 pada tombol dengan bg-merek.

Soal latihan

  1. Daftarkan font "Fraunces" sebagai font-judul dan jarak khusus 18 = 4.5rem lewat konfigurasi Play CDN.

    Petunjuk

    theme.extend.fontFamily dan theme.extend.spacing.

    Lihat jawaban
    HTML
    <script>
  tailwind.config = { theme: { extend: {
    fontFamily: { judul: ['Fraunces', 'serif'] },
    spacing: { 18: '4.5rem' }
  } } }
</script>
<h1 class="font-judul text-3xl mt-18">Kedai Kopi Senja</h1>

  2. Tulis versi Tailwind v4 dari konfigurasi warna merek #B4532A dan krem #FBF3E4.

    Petunjuk

    Di v4, tema ditulis di CSS dengan @theme dan variabel --color-*.

    Lihat jawaban
    HTML
    @import "tailwindcss";

@theme {
  --color-merek: #B4532A;
  --color-krem: #FBF3E4;
}

Poin penting

  • v3: theme.extend di tailwind.config.js.
  • v4: @theme { --color-*: ... } di CSS.

Cek pemahaman

Setelah --color-merek didaftarkan di @theme (v4), kelas apa yang muncul?

Jawaban: bg-merek, text-merek, border-merek, dll.

Tailwind membuat semua utilitas warna dari token itu.
