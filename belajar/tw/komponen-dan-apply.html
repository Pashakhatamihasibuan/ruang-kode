Komponen dan @apply

Buka versi interaktif

Kelas yang panjang dan berulang bisa disatukan. Cara yang disarankan: buat komponen di framework kamu (React, Vue, Blade) agar kelas ditulis sekali.

Alternatifnya, @apply di file CSS: .btn { @apply px-4 py-2 rounded-lg bg-sky-600 text-white; }. Di Play CDN, tulis di dalam <style type="text/tailwindcss">.

Gunakan @apply secukupnya. Kalau semuanya dipindah ke CSS, kamu kehilangan manfaat utama Tailwind: gaya terlihat langsung di HTML.

HTML
<style type="text/tailwindcss">
  .btn { @apply px-4 py-2 rounded-lg font-medium text-white; }
  .btn-utama { @apply bg-sky-600 hover:bg-sky-700; }
</style>
<div class="p-6 flex gap-3">
  <button class="btn btn-utama">Simpan</button>
  <button class="btn btn-utama">Kirim</button>
  <button id="hapus" class="btn bg-slate-500">Hapus</button>
</div>

Tantangan

  1. Tambahkan kelas komponen .btn-bahaya berisi @apply bg-rose-600;, lalu pakai di tombol Hapus menggantikan bg-slate-500.

Soal latihan

  1. Buat kelas komponen .kartu dengan @apply (padding 6, latar putih, sudut xl, bayangan) dan pakai di dua kartu.

    Petunjuk

    Tulis di <style type="text/tailwindcss">.

    Lihat jawaban
    HTML
    <style type="text/tailwindcss">
  .kartu { @apply p-6 bg-white rounded-xl shadow; }
</style>
<div class="kartu">Dart</div>
<div class="kartu mt-4">Kotlin</div>

Poin penting

  • Utamakan komponen di framework.
  • @apply menyatukan utilitas menjadi satu kelas CSS.

Cek pemahaman

Di Play CDN, @apply ditulis di mana?

Jawaban: &lt;style type="text/tailwindcss">

Play CDN hanya memproses style dengan type text/tailwindcss.

Kekurangan memakai @apply berlebihan?

Jawaban: Gaya tidak lagi terlihat langsung di HTML

Manfaat utama utility-first hilang.
