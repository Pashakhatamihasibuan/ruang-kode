Template dan inheritance

Buka versi interaktif

Bahasa template Django memakai {{ variabel }} untuk menampilkan nilai (otomatis di-escape sehingga aman dari XSS), {% tag %} untuk logika (for, if, url, static), dan filter seperti {{ harga|floatformat:0 }} atau {{ nama|upper }}.

Template inheritance: buat base.html berisi kerangka (head, navbar, footer) dengan {% block %}, lalu halaman lain {% extends "base.html" %} dan hanya mengisi blok yang berbeda.

Logika berat taruh di view atau model, bukan di template. Template cukup menampilkan.

HTML
{# templates/base.html #}
<!doctype html>
<html lang="id">
<head><title>{% block judul %}Tokoku{% endblock %}</title></head>
<body>
  <nav><a href="{% url 'katalog:daftar' %}">Produk</a></nav>
  <main>{% block isi %}{% endblock %}</main>
</body>
</html>

{# katalog/templates/katalog/daftar.html #}
{% extends 'base.html' %}
{% block judul %}Semua produk{% endblock %}
{% block isi %}
  {% for p in page_obj %}
    <article>
      <h2><a href="{% url 'katalog:detail' p.slug %}">{{ p.nama }}</a></h2>
      <p>Rp{{ p.harga|floatformat:0 }} · {{ p.kategori }}</p>
      {% if p.stok == 0 %}<span>Stok habis</span>{% endif %}
    </article>
  {% empty %}
    <p>Belum ada produk.</p>
  {% endfor %}
{% endblock %}

Poin penting

  • {{ }} menampilkan, {% %} logika, | filter.
  • Variabel otomatis di-escape.
  • extends dan block untuk kerangka bersama.
