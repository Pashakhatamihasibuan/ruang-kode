View dan URL

Buka versi interaktif

Function-based view (FBV) adalah fungsi yang menerima request dan mengembalikan response. Class-based view (CBV) seperti ListView, DetailView, CreateView mengurangi kode berulang untuk pola umum. FBV lebih eksplisit; CBV lebih ringkas.

Di urls.py, path() menerima pola, view, dan nama. Konverter seperti <int:pk> dan <slug:slug> mengambil bagian URL. Beri nama setiap rute dan pakai reverse() atau tag {% url %}, jangan menulis URL manual.

get_object_or_404 mengembalikan halaman 404 yang benar jika data tidak ada, bukan error 500.

PYTHON
# katalog/views.py
from django.shortcuts import render, get_object_or_404
from django.views.generic import ListView
from .models import Produk

def detail(request, slug):
    produk = get_object_or_404(Produk, slug=slug, aktif=True)
    return render(request, 'katalog/detail.html', {'produk': produk})

class DaftarProduk(ListView):
    model = Produk
    paginate_by = 12
    template_name = 'katalog/daftar.html'
    def get_queryset(self):
        return Produk.objects.filter(aktif=True).select_related('kategori')

# katalog/urls.py
from django.urls import path
from . import views
app_name = 'katalog'
urlpatterns = [
    path('', views.DaftarProduk.as_view(), name='daftar'),
    path('<slug:slug>/', views.detail, name='detail'),
]

# tokoku/urls.py
urlpatterns = [path('admin/', admin.site.urls), path('produk/', include('katalog.urls'))]

Poin penting

  • FBV eksplisit, CBV ringkas untuk pola umum.
  • Beri nama rute, pakai reverse dan {% url %}.
  • get_object_or_404 untuk data yang tidak ada.
