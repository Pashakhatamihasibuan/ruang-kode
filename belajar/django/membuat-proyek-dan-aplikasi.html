Membuat proyek dan aplikasi

Buka versi interaktif

Selalu pakai virtual environment agar paket tiap proyek terpisah. Pasang Django, lalu buat proyek (konfigurasi keseluruhan) dengan django-admin startproject. Di dalam proyek, buat aplikasi (fitur yang berdiri sendiri, misalnya katalog, pesanan, akun) dengan python manage.py startapp.

Daftarkan aplikasi di INSTALLED_APPS pada settings.py. File penting lain: urls.py (rute utama), wsgi.py dan asgi.py (titik masuk server), serta manage.py (perintah administrasi).

Jalankan server pengembangan dengan python manage.py runserver lalu buka http://127.0.0.1:8000.
