Django dan pola MTV

Buka versi interaktif

Django adalah framework web Python dengan prinsip "batteries included": ORM, panel admin, autentikasi, form, migrasi database, dan perlindungan keamanan sudah tersedia. Instagram, Pinterest, Disqus, dan banyak sistem informasi kampus serta pemerintahan dibangun dengan Django.

Django memakai pola MTV: Model (struktur data dan akses database), Template (tampilan HTML), dan View (logika yang menerima request dan mengembalikan response). URLconf menghubungkan alamat URL ke view.

Alur sebuah request: browser meminta /produk/12/ → middleware → urls.py mencari pola yang cocok → view mengambil data lewat model → view me-render template → response HTML kembali ke browser.

Poin penting

  • Django: batteries included.
  • Model, Template, View + URLconf.
  • Request lewat middleware, urls, view, lalu template.
