Model, field, dan relasi

Buka versi interaktif

Model adalah kelas Python yang mewakili tabel. Setiap atribut adalah field (kolom): CharField, TextField, IntegerField, DecimalField untuk uang, BooleanField, DateTimeField, SlugField, ImageField.

Relasi: ForeignKey (banyak ke satu: banyak produk dalam satu kategori), ManyToManyField (produk punya banyak tag), dan OneToOneField (satu profil untuk satu user). Parameter on_delete wajib: CASCADE, PROTECT, atau SET_NULL.

Tambahkan __str__ agar objek tampil rapi di admin, dan kelas Meta untuk urutan bawaan, nama tampilan, serta indeks.

PYTHON
from django.db import models

class Kategori(models.Model):
    nama = models.CharField(max_length=60, unique=True)
    def __str__(self):
        return self.nama

class Produk(models.Model):
    kategori = models.ForeignKey(Kategori, on_delete=models.PROTECT, related_name='produk')
    nama = models.CharField(max_length=120)
    slug = models.SlugField(unique=True)
    harga = models.DecimalField(max_digits=12, decimal_places=2)
    stok = models.PositiveIntegerField(default=0)
    aktif = models.BooleanField(default=True)
    dibuat = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ['-dibuat']
        verbose_name_plural = 'produk'

    def __str__(self):
        return f'{self.nama} (Rp{self.harga:,.0f})'

Soal latihan

  1. Buat model Ulasan yang terhubung ke Produk, berisi nama pengulas, rating 1 sampai 5, komentar, dan waktu dibuat.

    Petunjuk

    ForeignKey ke Produk, PositiveSmallIntegerField dengan validator.

    Lihat jawaban
    PYTHON
    from django.core.validators import MinValueValidator, MaxValueValidator

class Ulasan(models.Model):
    produk = models.ForeignKey(Produk, on_delete=models.CASCADE, related_name='ulasan')
    pengulas = models.CharField(max_length=80)
    rating = models.PositiveSmallIntegerField(validators=[MinValueValidator(1), MaxValueValidator(5)])
    komentar = models.TextField(blank=True)
    dibuat = models.DateTimeField(auto_now_add=True)

Poin penting

  • Model = tabel, field = kolom.
  • ForeignKey, ManyToMany, OneToOne dengan on_delete.
  • Uang pakai DecimalField.
