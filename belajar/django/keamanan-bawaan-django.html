Keamanan bawaan Django

Buka versi interaktif

Django melindungi banyak serangan secara bawaan: XSS (template meng-escape variabel), CSRF (token di setiap form POST), SQL injection (ORM memakai parameter), clickjacking (header X-Frame-Options), dan hash kata sandi yang kuat.

Perlindungan itu bisa jebol jika dimatikan: hindari |safe dan mark_safe untuk data pengguna, jangan menyusun SQL mentah dengan f-string (pakai parameter %s), dan jangan menonaktifkan CSRF tanpa alasan kuat.

Untuk produksi aktifkan HTTPS: SECURE_SSL_REDIRECT, SESSION_COOKIE_SECURE, CSRF_COOKIE_SECURE, dan HSTS. Perintah check --deploy memeriksa semuanya.

PYTHON
# berbahaya: SQL injection
Produk.objects.raw(f"SELECT * FROM katalog_produk WHERE nama = '{q}'")

# aman: parameter
Produk.objects.raw('SELECT * FROM katalog_produk WHERE nama = %s', [q])

$ python manage.py check --deploy

Poin penting

  • XSS, CSRF, SQL injection, clickjacking dicegah bawaan.
  • Jangan pakai |safe untuk input pengguna.
  • check --deploy sebelum rilis.
