Settings penting dan variabel lingkungan

Buka versi interaktif

Ubah LANGUAGE_CODE = 'id' dan TIME_ZONE = 'Asia/Jakarta' agar pesan bawaan dan admin berbahasa Indonesia. Biarkan USE_TZ = True agar waktu disimpan dalam UTC dan ditampilkan sesuai zona waktu.

Jangan menulis rahasia (SECRET_KEY, kata sandi database) langsung di settings. Baca dari variabel lingkungan, misalnya dengan paket django-environ, dan simpan file .env di luar Git.

Di produksi: DEBUG = False (jika True, halaman error membocorkan konfigurasi), isi ALLOWED_HOSTS, dan pakai PostgreSQL alih-alih SQLite. Jalankan python manage.py check --deploy untuk daftar pemeriksaan keamanan.

PYTHON
# tokoku/settings.py
import environ
env = environ.Env()
environ.Env.read_env(BASE_DIR / '.env')

SECRET_KEY = env('SECRET_KEY')
DEBUG = env.bool('DEBUG', default=False)
ALLOWED_HOSTS = env.list('ALLOWED_HOSTS', default=['localhost'])

DATABASES = {'default': env.db('DATABASE_URL')}

LANGUAGE_CODE = 'id'
TIME_ZONE = 'Asia/Jakarta'
USE_TZ = True

INSTALLED_APPS = [
    'django.contrib.admin', 'django.contrib.auth', 'django.contrib.contenttypes',
    'django.contrib.sessions', 'django.contrib.messages', 'django.contrib.staticfiles',
    'katalog',
]

Soal latihan

  1. Tulis isi file .env untuk pengembangan lokal dengan PostgreSQL.

    Petunjuk

    SECRET_KEY, DEBUG, ALLOWED_HOSTS, DATABASE_URL.

    Lihat jawaban
    TERMINAL
    SECRET_KEY=ganti-dengan-string-acak-panjang
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
DATABASE_URL=postgres://toko:rahasia@localhost:5432/tokodb

Poin penting

  • Bahasa id dan zona Asia/Jakarta.
  • Rahasia dari variabel lingkungan.
  • DEBUG = False dan ALLOWED_HOSTS di produksi.
