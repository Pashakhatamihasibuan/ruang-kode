Form, ModelForm, dan validasi

Buka versi interaktif

Form Django menangani tiga hal: menampilkan input HTML, memvalidasi data, dan mengubah data menjadi tipe Python di cleaned_data. ModelForm membuat form langsung dari model, termasuk validasi field.

Validasi khusus ditulis di metode clean_namafield() (satu field) atau clean() (beberapa field). Lempar ValidationError dengan pesan yang jelas bagi pengguna.

Setiap form POST wajib menyertakan {% csrf_token %} untuk mencegah serangan CSRF. Setelah berhasil menyimpan, lakukan redirect (pola Post/Redirect/Get) agar tombol refresh tidak mengirim ulang form.

PYTHON
# katalog/forms.py
from django import forms
from .models import Ulasan

class UlasanForm(forms.ModelForm):
    class Meta:
        model = Ulasan
        fields = ['pengulas', 'rating', 'komentar']

    def clean_komentar(self):
        k = self.cleaned_data['komentar']
        if 'http' in k:
            raise forms.ValidationError('Komentar tidak boleh berisi tautan.')
        return k

# katalog/views.py
from django.shortcuts import redirect

def tambah_ulasan(request, slug):
    produk = get_object_or_404(Produk, slug=slug)
    form = UlasanForm(request.POST or None)
    if request.method == 'POST' and form.is_valid():
        ulasan = form.save(commit=False)
        ulasan.produk = produk
        ulasan.save()
        return redirect('katalog:detail', slug=slug)
    return render(request, 'katalog/ulasan.html', {'form': form, 'produk': produk})

Soal latihan

  1. Tambahkan validasi di UlasanForm: rating 1 atau 2 wajib disertai komentar minimal 10 karakter.

    Petunjuk

    Pakai clean() karena melibatkan dua field.

    Lihat jawaban

    def clean(self):

Poin penting

  • ModelForm = form dari model.
  • clean_field() dan clean() untuk validasi khusus.
  • csrf_token dan redirect setelah POST.
