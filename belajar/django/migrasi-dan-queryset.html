Migrasi dan QuerySet

Buka versi interaktif

Setiap perubahan model dicatat sebagai migrasi: makemigrations membuat file migrasi, migrate menerapkannya ke database. Simpan file migrasi di Git agar semua anggota tim dan server punya skema yang sama.

QuerySet adalah query yang malas (lazy): belum menyentuh database sampai hasilnya dipakai. Metode utama: all(), filter(), exclude(), get(), order_by(), values(), annotate(), aggregate(). Lookup memakai dua garis bawah: harga__lte, nama__icontains, kategori__nama.

Coba di python manage.py shell. Untuk melihat SQL yang dihasilkan, cetak str(qs.query).

PYTHON
>>> from katalog.models import Produk, Kategori
>>> from django.db.models import Count, Avg
>>> kopi = Kategori.objects.create(nama='Kopi')
>>> Produk.objects.create(kategori=kopi, nama='Kopi Gayo', slug='kopi-gayo', harga=85000, stok=20)
>>> Produk.objects.create(kategori=kopi, nama='Kopi Toraja', slug='kopi-toraja', harga=95000, stok=0)
>>> Produk.objects.filter(harga__lte=90000, stok__gt=0)
>>> Produk.objects.filter(kategori__nama='Kopi').aggregate(Avg('harga'))
>>> Kategori.objects.annotate(jumlah=Count('produk')).values('nama', 'jumlah')

Soal latihan

  1. Ambil 5 produk aktif termahal yang stoknya lebih dari 0.

    Petunjuk

    filter, order_by dengan tanda minus, slicing.

    Lihat jawaban
    PYTHON
    Produk.objects.filter(aktif=True, stok__gt=0).order_by('-harga')[:5]

Poin penting

  • makemigrations lalu migrate.
  • QuerySet malas, baru dijalankan saat dipakai.
  • Lookup dengan dua garis bawah.
