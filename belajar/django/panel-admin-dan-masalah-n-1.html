Panel admin dan masalah N+1

Buka versi interaktif

Panel admin Django memberi antarmuka CRUD siap pakai. Buat akun dengan createsuperuser, daftarkan model di admin.py, lalu atur list_display, list_filter, search_fields, dan prepopulated_fields.

Waspadai masalah N+1: menampilkan 50 produk beserta nama kategorinya bisa menghasilkan 1 + 50 query. Gunakan select_related untuk ForeignKey dan OneToOne (JOIN), serta prefetch_related untuk ManyToMany dan relasi balik (dua query lalu digabung di Python).

Alat django-debug-toolbar menampilkan jumlah dan durasi query setiap halaman saat pengembangan.

PYTHON
# katalog/admin.py
from django.contrib import admin
from .models import Kategori, Produk

@admin.register(Produk)
class ProdukAdmin(admin.ModelAdmin):
    list_display = ['nama', 'kategori', 'harga', 'stok', 'aktif']
    list_filter = ['aktif', 'kategori']
    search_fields = ['nama']
    list_editable = ['harga', 'stok']
    prepopulated_fields = {'slug': ['nama']}
    list_select_related = ['kategori']   # cegah N+1

admin.site.register(Kategori)

# di view: 1 query dengan JOIN, bukan 51 query
produk = Produk.objects.select_related('kategori').all()[:50]

Poin penting

  • admin.py: list_display, list_filter, search_fields.
  • select_related untuk FK, prefetch_related untuk M2M.
  • Pantau jumlah query dengan debug toolbar.
