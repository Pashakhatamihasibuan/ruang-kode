Menulis tes di Django

Buka versi interaktif

Django menyediakan TestCase yang membuat database uji terpisah dan membungkus setiap tes dalam transaksi yang di-rollback. self.client mensimulasikan browser untuk menguji view, URL, template, dan status code.

Banyak tim memakai pytest-django karena sintaksnya lebih ringkas dan fixture-nya kuat, plus factory_boy untuk membuat data uji.

Prioritaskan tes untuk logika bisnis (model dan service), izin akses (siapa boleh apa), dan API. Jalankan dengan python manage.py test atau pytest.

PYTHON
from django.test import TestCase
from django.urls import reverse

class ProdukTest(TestCase):
    @classmethod
    def setUpTestData(cls):
        kopi = Kategori.objects.create(nama='Kopi')
        cls.p = Produk.objects.create(kategori=kopi, nama='Kopi Gayo', slug='kopi-gayo', harga=85000, stok=3)

    def test_detail_tampil(self):
        r = self.client.get(reverse('katalog:detail', args=['kopi-gayo']))
        self.assertEqual(r.status_code, 200)
        self.assertContains(r, 'Kopi Gayo')

    def test_produk_nonaktif_404(self):
        self.p.aktif = False
        self.p.save()
        r = self.client.get(reverse('katalog:detail', args=['kopi-gayo']))
        self.assertEqual(r.status_code, 404)

    def test_pesanan_butuh_login(self):
        r = self.client.get('/pesanan/saya/')
        self.assertRedirects(r, '/akun/login/?next=/pesanan/saya/')
