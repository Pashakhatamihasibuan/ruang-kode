API dengan Django REST Framework

Buka versi interaktif

Django REST Framework (DRF) adalah paket standar untuk membangun API JSON. Tiga komponen utama: serializer (mengubah model ke JSON dan memvalidasi input), viewset (kumpulan aksi list, retrieve, create, update, destroy), dan router (membuat URL otomatis).

DRF menyediakan halaman API yang bisa dijelajahi di browser, pagination, filter, throttling, serta kelas izin seperti IsAuthenticated dan IsAuthenticatedOrReadOnly.

Untuk aplikasi mobile atau frontend terpisah (React, Next.js, Flutter), pakai autentikasi token: JWT dengan paket djangorestframework-simplejwt.

PYTHON
# katalog/serializers.py
from rest_framework import serializers
class ProdukSerializer(serializers.ModelSerializer):
    kategori = serializers.StringRelatedField()
    class Meta:
        model = Produk
        fields = ['id', 'nama', 'slug', 'harga', 'stok', 'kategori']

# katalog/api.py
from rest_framework import viewsets, permissions
class ProdukViewSet(viewsets.ModelViewSet):
    queryset = Produk.objects.filter(aktif=True).select_related('kategori')
    serializer_class = ProdukSerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]
    lookup_field = 'slug'

# tokoku/urls.py
from rest_framework.routers import DefaultRouter
router = DefaultRouter()
router.register('produk', ProdukViewSet)
urlpatterns += [path('api/', include(router.urls))]

Soal latihan

  1. Buat serializer untuk model Ulasan yang menolak komentar berisi kata "spam".

    Petunjuk

    Metode validate_komentar di ModelSerializer.

    Lihat jawaban
    PYTHON
    class UlasanSerializer(serializers.ModelSerializer):
    class Meta:
        model = Ulasan
        fields = ['id', 'pengulas', 'rating', 'komentar']

    def validate_komentar(self, nilai):
        if 'spam' in nilai.lower():
            raise serializers.ValidationError('Komentar terdeteksi sebagai spam.')
        return nilai

Poin penting

  • Serializer, viewset, router.
  • Kelas izin seperti IsAuthenticatedOrReadOnly.
  • JWT untuk frontend dan mobile.
