Bootstrap 5 · Modul 2 · Praktik langsung

Navbar yang bisa dilipat

Buka versi interaktif

Navbar Bootstrap otomatis berubah menjadi menu hamburger di layar kecil. Kuncinya: navbar-expand-lg (melebar mulai lg), tombol navbar-toggler, dan wadah collapse navbar-collapse.

Tombol pembuka memakai atribut data-bs-toggle="collapse" dan data-bs-target="#menu". Tidak perlu menulis JavaScript sendiri, bundle Bootstrap yang menanganinya.

Pratinjau ini sempit, jadi kamu akan melihat tombol hamburger. Klik untuk membuka menu.

HTML
<nav class="navbar navbar-expand-lg bg-dark" data-bs-theme="dark">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">RuangKode</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#menu" aria-controls="menu" aria-expanded="false" aria-label="Buka menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav">
        <li class="nav-item"><a class="nav-link active" href="#">Beranda</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Kursus</a></li>
      </ul>
    </div>
  </div>
</nav>

Tantangan

  1. Tambahkan item menu ketiga "Masuk" di dalam .navbar-nav.

Soal latihan

  1. Ubah navbar agar melebar mulai md (bukan lg) dan menu rata kanan.

    Petunjuk

    navbar-expand-md; tambahkan ms-auto pada ul.navbar-nav.

    Lihat jawaban
    HTML
    <nav class="navbar navbar-expand-md bg-body-tertiary">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">RuangKode</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#menu" aria-controls="menu" aria-expanded="false" aria-label="Buka menu"><span class="navbar-toggler-icon"></span></button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link" href="#">Beranda</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Kursus</a></li>
      </ul>
    </div>
  </div>
</nav>

Poin penting

  • navbar-expand-{bp} menentukan kapan menu melebar.
  • data-bs-toggle="collapse" + data-bs-target="#id".
