Form dan validasi

Buka versi interaktif

Input memakai form-control, pilihan form-select, kotak centang form-check-input, label form-label.

Validasi bawaan: beri form atribut novalidate dan kelas needs-validation. Saat dikirim, tambahkan kelas was-validated agar Bootstrap menampilkan .invalid-feedback di bawah input yang salah.

Kamu juga bisa menandai satu input secara manual dengan is-invalid atau is-valid.

HTML
<form id="daftar" class="container py-3 needs-validation" novalidate>
  <div class="mb-3">
    <label for="nama" class="form-label">Nama</label>
    <input id="nama" class="form-control" required>
    <div class="invalid-feedback">Nama wajib diisi.</div>
  </div>
  <div class="mb-3">
    <label for="kelas" class="form-label">Kelas</label>
    <select id="kelas" class="form-select"><option>Flutter</option><option>Compose</option></select>
  </div>
  <button class="btn btn-primary">Daftar</button>
</form>
JAVASCRIPT
const f = document.getElementById('daftar');
f.addEventListener('submit', e => {
  e.preventDefault();
  // tandai form agar Bootstrap menampilkan pesan validasi
  f.classList.add('was-validated');
  if (f.checkValidity()) console.log('Terkirim:', f.nama.value);
});

Tantangan

  1. Tambahkan input email (type="email", kelas form-control, required) beserta pesan invalid-feedback.

Soal latihan

  1. Buat dua field berdampingan (Nama depan, Nama belakang) mulai md memakai grid di dalam form.

    Petunjuk

    div.row.g-3 lalu col-md-6 untuk setiap field.

    Lihat jawaban
    HTML
    <form class="row g-3">
  <div class="col-md-6"><label class="form-label" for="dp">Nama depan</label><input id="dp" class="form-control"></div>
  <div class="col-md-6"><label class="form-label" for="bl">Nama belakang</label><input id="bl" class="form-control"></div>
</form>

  2. Buat kotak centang persetujuan yang wajib dicentang, terpisah dari kotak centang langganan berita.

    Petunjuk

    form-check + form-check-input + form-check-label; required hanya pada persetujuan.

    Lihat jawaban
    HTML
    <div class="form-check">
  <input class="form-check-input" type="checkbox" id="setuju" required>
  <label class="form-check-label" for="setuju">Saya menyetujui pemrosesan data untuk pendaftaran</label>
  <div class="invalid-feedback">Centang untuk melanjutkan.</div>
</div>
<div class="form-check">
  <input class="form-check-input" type="checkbox" id="berita">
  <label class="form-check-label" for="berita">Kirimi saya info kelas baru (opsional)</label>
</div>

Poin penting

  • form-control, form-select, form-check-input, form-label.
  • novalidate + was-validated menampilkan invalid-feedback.

Cek pemahaman

Kelas apa yang membuat Bootstrap menampilkan pesan validasi untuk seluruh form?

Jawaban: was-validated

was-validated dipasang pada form.

Kelas untuk menandai satu input tidak valid secara manual?

Jawaban: is-invalid

is-valid untuk yang benar.
