Memasang Bootstrap 5

Buka versi interaktif

Bootstrap adalah framework CSS dengan komponen siap pakai (tombol, kartu, navbar, modal) dan sistem grid. Versi 5 tidak lagi membutuhkan jQuery.

Cara cepat: tambahkan CSS di <head> dan bundle JS di akhir <body> dari CDN jsDelivr: bootstrap@5.3.3/dist/css/bootstrap.min.css dan bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js. Bundle sudah berisi Popper untuk dropdown dan tooltip.

Lewat npm: npm install bootstrap, lalu import "bootstrap/dist/css/bootstrap.min.css" dan import "bootstrap" di file JS utama.

Pratinjau di halaman ini sudah memuat Bootstrap 5.3, jadi kamu cukup menulis HTML.

HTML
<div class="container py-4">
  <h1 class="display-6">Toko Nusantara</h1>
  <p class="lead">Kopi, teh, dan camilan pilihan.</p>
  <button class="btn btn-primary">Belanja sekarang</button>
</div>

Tantangan

  1. Ubah tombol menjadi hijau dengan mengganti btn-primary menjadi btn-success.

Soal latihan

  1. Tulis kerangka HTML lengkap yang memuat Bootstrap 5.3.3 dari CDN jsDelivr.

    Petunjuk

    link CSS di head, script bundle sebelum </body>, dan meta viewport.

    Lihat jawaban
    HTML
    <!doctype html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Toko</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <h1 class="container">Halo, Bootstrap!</h1>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

  2. Buat tiga tombol berdampingan: Simpan (primary), Batal (outline-secondary), Hapus (danger, kecil).

    Petunjuk

    btn btn-primary, btn btn-outline-secondary, btn btn-danger btn-sm.

    Lihat jawaban
    HTML
    <div class="d-flex gap-2">
  <button class="btn btn-primary">Simpan</button>
  <button class="btn btn-outline-secondary">Batal</button>
  <button class="btn btn-danger btn-sm">Hapus</button>
</div>

Poin penting

  • Bootstrap 5 = komponen + grid + utilitas, tanpa jQuery.
  • CSS di head, bootstrap.bundle.min.js di akhir body.

Cek pemahaman

Apa isi bootstrap.bundle.min.js selain JS Bootstrap?

Popper dibutuhkan dropdown, tooltip, dan popover.
