Bootstrap 5 · Modul 3 · Praktik langsung

Variabel CSS, Sass, dan mode gelap

Buka versi interaktif

Bootstrap 5.3 menyimpan warna dan ukuran di variabel CSS berawalan --bs-. Kamu bisa menimpanya: :root { --bs-primary: #B4532A; --bs-primary-rgb: 180,83,42; }. Untuk tombol, ubah variabel komponennya, misalnya .btn-primary { --bs-btn-bg: #B4532A; }.

Untuk kustomisasi menyeluruh, pakai Sass: npm install bootstrap sass, lalu di main.scss tulis $primary: #B4532A; sebelum @import "bootstrap/scss/bootstrap";. Semua komponen ikut berubah.

Mode gelap: tambahkan data-bs-theme="dark" pada <html> atau pada satu elemen saja.

HTML
<div class="container py-3">
  <button id="utama" class="btn btn-primary">Tombol utama</button>
  <div id="kotak" class="card mt-3"><div class="card-body">Kartu ini bisa dibuat gelap.</div></div>
</div>
CSS
.btn-primary {
  --bs-btn-bg: #B4532A;
  --bs-btn-border-color: #B4532A;
  --bs-btn-hover-bg: #8F3F1F;
}

Tantangan

  1. Buat kartu tampil gelap dengan menambahkan atribut data-bs-theme="dark" pada #kotak.

Soal latihan

  1. Ubah sudut membulat semua komponen menjadi lebih besar lewat variabel CSS.

    Petunjuk

    Timpa --bs-border-radius (dan variannya) di :root.

    Lihat jawaban
    HTML
    <style>
  :root {
    --bs-border-radius: .75rem;
    --bs-border-radius-lg: 1rem;
    --bs-border-radius-sm: .5rem;
  }
</style>

  2. Tulis file Sass yang mengganti warna primer menjadi #B4532A dan font dasar menjadi Inter.

    Petunjuk

    Variabel Sass ditulis sebelum @import bootstrap.

    Lihat jawaban
    HTML
    // main.scss
$primary: #B4532A;
$font-family-base: "Inter", system-ui, sans-serif;

@import "bootstrap/scss/bootstrap";

Poin penting

  • Variabel --bs-* bisa ditimpa di CSS.
  • Sass: ubah $primary dll. sebelum import Bootstrap.
  • data-bs-theme="dark" untuk mode gelap.
