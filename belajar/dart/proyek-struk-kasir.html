Proyek: struk kasir

Buka versi interaktif

Proyek ini menggabungkan semua yang sudah dipelajari: class Item dengan getter subtotal, list sebagai keranjang, loop untuk menjumlahkan, operator ternary untuk diskon, dan padLeft/padRight untuk struk yang rapi.

Fungsi rp() menambahkan titik pemisah ribuan tanpa package. Di aplikasi Flutter sungguhan, pakai NumberFormat dari package intl.

Jalankan di dartpad.dev, lalu kerjakan tantangan di bawah untuk mengembangkannya.

KODE
class Item {
  final String nama;
  final int harga;
  final int qty;
  const Item(this.nama, this.harga, this.qty);
  int get subtotal => harga * qty;
}

String rp(int n) {
  final s = n.toString();
  final b = StringBuffer();
  for (var i = 0; i < s.length; i++) {
    if (i > 0 && (s.length - i) % 3 == 0) b.write('.');
    b.write(s[i]);
  }
  return b.toString();
}

void main() {
  const keranjang = [
    Item('Kopi susu', 18000, 2),
    Item('Roti bakar', 22500, 1),
    Item('Air mineral', 5000, 3),
  ];
  print('${'Barang'.padRight(14)}${'Qty'.padLeft(4)}${'Subtotal'.padLeft(10)}');
  print('-' * 28);
  var total = 0;
  for (final it in keranjang) {
    print('${it.nama.padRight(14)}${it.qty.toString().padLeft(4)}${rp(it.subtotal).padLeft(10)}');
    total += it.subtotal;
  }
  final diskon = total >= 50000 ? total ~/ 10 : 0;
  print('-' * 28);
  print('${'Total'.padRight(18)}${rp(total).padLeft(10)}');
  print('${'Diskon 10%'.padRight(18)}${rp(diskon).padLeft(10)}');
  print('${'Bayar'.padRight(18)}${rp(total - diskon).padLeft(10)}');
}

Soal latihan

  1. Tambahkan PPN 11% (dibulatkan) yang dihitung dari harga setelah diskon, lalu tampilkan total akhir.

    Petunjuk

    ppn = (setelahDiskon * 11 / 100).round(). round() membulatkan .5 ke atas.

    Lihat jawaban
    KODE
      final setelahDiskon = total - diskon;
  final ppn = (setelahDiskon * 11 / 100).round();
  print('${'PPN 11%'.padRight(18)}${rp(ppn).padLeft(10)}');
  print('${'Total akhir'.padRight(18)}${rp(setelahDiskon + ppn).padLeft(10)}');

  2. Cetak barang diurutkan dari subtotal terbesar.

    Petunjuk

    Salin list dulu ([...keranjang]) karena list const tidak bisa diurutkan, lalu sort dengan compareTo terbalik.

    Lihat jawaban
    KODE
      final urut = [...keranjang]..sort((a, b) => b.subtotal.compareTo(a.subtotal));
  for (final it in urut) {
    print('${it.nama}: ${rp(it.subtotal)}');
  }

  3. Ubah diskon menjadi bertingkat: 15% jika total ≥ 100.000, 10% jika ≥ 50.000, selain itu 0. Pakai switch expression.

    Petunjuk

    switch (total) { >= 100000 => total * 15 ~/ 100, >= 50000 => total ~/ 10, _ => 0 }

    Lihat jawaban
    KODE
      final diskon = switch (total) {
    >= 100000 => total * 15 ~/ 100,
    >= 50000 => total ~/ 10,
    _ => 0,
  };

Poin penting

  • Class + getter untuk data barang.
  • Loop + akumulator untuk total.
  • padLeft/padRight untuk struk berkolom.
