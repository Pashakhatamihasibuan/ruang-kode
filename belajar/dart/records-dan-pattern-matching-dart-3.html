Records dan pattern matching (Dart 3)

Buka versi interaktif

Record mengelompokkan beberapa nilai tanpa membuat class: (double, double) atau dengan nama ({String nama, int umur}). Cocok untuk fungsi yang mengembalikan lebih dari satu nilai.

Pattern membongkar data: final (lo, hi) = minMax(data);. Dengan if (json case {...}) kamu bisa memeriksa bentuk JSON sekaligus mengambil nilainya, tanpa casting manual.

switch pada sealed class memeriksa semua kemungkinan. Jika ada turunan baru yang lupa ditangani, Dart memberi error saat kompilasi. Pola ini sangat dipakai untuk status layar Flutter: Memuat, Sukses, Gagal.

KODE
(double, double) minMax(List<double> xs) {
  var lo = xs.first, hi = xs.first;
  for (final x in xs) {
    if (x < lo) lo = x;
    if (x > hi) hi = x;
  }
  return (lo, hi);
}

sealed class Bentuk {}
class Lingkaran extends Bentuk {
  final double r;
  Lingkaran(this.r);
}
class Persegi extends Bentuk {
  final double s;
  Persegi(this.s);
}

double luas(Bentuk b) => switch (b) {
      Lingkaran(r: final r) => 3.14 * r * r,
      Persegi(s: final s) => s * s,
    };

void main() {
  final (lo, hi) = minMax([3.5, 1.2, 9.8]);
  print('min $lo, max $hi');

  final user = (nama: 'Rina', umur: 20);
  print('${user.nama} ${user.umur}');

  final json = {'nama': 'Budi', 'nilai': [80, 90]};
  if (json case {'nama': String n, 'nilai': [int a, int b]}) {
    print('$n rata-rata ${(a + b) / 2}');
  }

  print(luas(Lingkaran(2)));
  print(luas(Persegi(3)));
}
KELUARAN
min 1.2, max 9.8
Rina 20
Budi rata-rata 85.0
12.56
9.0

Soal latihan

  1. Buat fungsi yang mengembalikan record (int jumlah, double rata) dari [4, 8, 6], lalu bongkar hasilnya.

    Petunjuk

    return (total, total / xs.length); lalu final (j, r) = ringkas(...).

    Lihat jawaban
    KODE
    (int, double) ringkas(List<int> xs) {
  final total = xs.fold(0, (a, b) => a + b);
  return (total, total / xs.length);
}

void main() {
  final (j, r) = ringkas([4, 8, 6]);
  print('Jumlah $j, rata-rata $r');
}
    KELUARAN
    Jumlah 18, rata-rata 6.0

  2. Kelompokkan umur [8, 15, 30] menjadi anak (< 13), remaja (13–17), dewasa, memakai switch expression dengan relational pattern.

    Petunjuk

    Kasus: < 13 =>, >= 13 && < 18 =>, _ =>.

    Lihat jawaban
    KODE
    String kategori(int u) => switch (u) {
      < 13 => 'anak',
      >= 13 && < 18 => 'remaja',
      _ => 'dewasa',
    };

void main() {
  for (final u in [8, 15, 30]) {
    print('$u: ${kategori(u)}');
  }
}
    KELUARAN
    8: anak
15: remaja
30: dewasa

Poin penting

  • Record (a, b) untuk banyak nilai kembalian.
  • Pattern membongkar record, list, map, dan objek.
  • switch + sealed class memeriksa semua kasus.
