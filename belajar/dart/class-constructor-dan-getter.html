Class, constructor, dan getter

Buka versi interaktif

Class adalah cetak biru objek. Dart punya constructor ringkas: Produk(this.nama, this.harga); langsung mengisi field. Field final membuat objek immutable (tidak bisa diubah setelah dibuat), gaya yang dianjurkan di Flutter.

Named constructor memberi cara lain membuat objek, misalnya Produk.fromJson(map) untuk data dari API. Getter (get) adalah properti yang dihitung, misalnya harga setelah pajak.

Override toString() agar objek mudah dibaca saat di-print. Untuk membandingkan isi objek, package seperti equatable atau freezed sering dipakai di proyek Flutter.

KODE
class Produk {
  final String nama;
  final int harga;
  const Produk(this.nama, this.harga);

  // named constructor dari data JSON
  Produk.fromJson(Map<String, dynamic> json)
      : nama = json['nama'] as String,
        harga = json['harga'] as int;

  int get hargaPajak => (harga * 1.11).round();

  @override
  String toString() => 'Produk($nama, $harga)';
}

void main() {
  const kopi = Produk('Kopi Gayo', 85000);
  final teh = Produk.fromJson({'nama': 'Teh Tarik', 'harga': 15000});
  print(kopi);
  print('${teh.nama} + pajak: ${teh.hargaPajak}');
}
KELUARAN
Produk(Kopi Gayo, 85000)
Teh Tarik + pajak: 16650

Soal latihan

  1. Buat class Rekening dengan saldo privat _saldo, method setor dan tarik (tolak jika saldo kurang), dan getter saldo.

    Petunjuk

    Nama berawalan _ bersifat privat di file itu.

    Lihat jawaban
    KODE
    class Rekening {
  int _saldo = 0;
  int get saldo => _saldo;

  void setor(int n) => _saldo += n;

  bool tarik(int n) {
    if (n > _saldo) return false;
    _saldo -= n;
    return true;
  }
}

void main() {
  final r = Rekening();
  r.setor(100000);
  print('Tarik 30000: ${r.tarik(30000)}');
  print('Tarik 90000: ${r.tarik(90000)}');
  print('Saldo: ${r.saldo}');
}
    KELUARAN
    Tarik 30000: true
Tarik 90000: false
Saldo: 70000

  2. Tambahkan named constructor Mahasiswa.baru(nama) yang mengisi semester 1, dan override toString.

    Petunjuk

    Named constructor bisa memanggil constructor utama dengan : this(...).

    Lihat jawaban
    KODE
    class Mahasiswa {
  final String nama;
  final int semester;
  Mahasiswa(this.nama, this.semester);
  Mahasiswa.baru(String nama) : this(nama, 1);

  @override
  String toString() => '$nama (semester $semester)';
}

void main() {
  print(Mahasiswa('Rina', 5));
  print(Mahasiswa.baru('Budi'));
}
    KELUARAN
    Rina (semester 5)
Budi (semester 1)

Poin penting

  • Constructor ringkas this.field.
  • Named constructor seperti fromJson untuk data API.
  • get untuk properti yang dihitung.
