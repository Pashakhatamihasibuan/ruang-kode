Fungsi, parameter bernama, dan arrow function

Buka versi interaktif

Fungsi Dart ditulis dengan tipe kembalian di depan: int tambah(int a, int b) { return a + b; }. Fungsi satu ekspresi bisa memakai arrow: int kali(int a, int b) => a * b;.

Parameter bernama ditulis dalam kurung kurawal dan dipanggil dengan namanya: sapa(nama: 'Rina'). Tambahkan required jika wajib, atau beri nilai bawaan. Pola ini dipakai di semua widget Flutter, misalnya Text('Halo', style: ...) dan Padding(padding: ..., child: ...).

Fungsi adalah nilai: bisa disimpan di variabel dan dikirim ke fungsi lain. Contohnya onPressed: () { ... } di tombol Flutter.

KODE
int kali(int a, int b) => a * b;

String sapa({required String nama, String salam = 'Halo'}) {
  return '$salam, $nama!';
}

double hitungTotal(double harga, {int jumlah = 1, double diskon = 0}) =>
    harga * jumlah * (1 - diskon);

void main() {
  print(kali(4, 5));
  print(sapa(nama: 'Rina'));
  print(sapa(nama: 'Budi', salam: 'Selamat pagi'));
  print(hitungTotal(20000, jumlah: 3, diskon: 0.1));
  final klik = () => print('Tombol ditekan');
  klik();
}
KELUARAN
20
Halo, Rina!
Selamat pagi, Budi!
54000.0
Tombol ditekan

Soal latihan

  1. Buat fungsi luas({required double p, required double l}) dengan arrow, lalu panggil untuk p=5, l=3.

    Petunjuk

    double luas({required double p, required double l}) => p * l;

    Lihat jawaban
    KODE
    double luas({required double p, required double l}) => p * l;

void main() {
  print(luas(p: 5, l: 3));
}
    KELUARAN
    15.0

  2. Buat fungsi sapa(String nama, [String? gelar]) dengan parameter posisi opsional.

    Petunjuk

    Parameter opsional posisi ditulis dalam kurung siku.

    Lihat jawaban
    KODE
    String sapa(String nama, [String? gelar]) =>
    gelar == null ? 'Halo, $nama' : 'Halo, $gelar $nama';

void main() {
  print(sapa('Rina'));
  print(sapa('Budi', 'Dr.'));
}
    KELUARAN
    Halo, Rina
Halo, Dr. Budi

Poin penting

  • => untuk fungsi satu ekspresi.
  • Parameter bernama {required ...} dipakai di semua widget Flutter.
  • Fungsi bisa disimpan dan dikirim sebagai nilai.
