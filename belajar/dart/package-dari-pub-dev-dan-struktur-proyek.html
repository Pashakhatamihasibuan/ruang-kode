Package dari pub.dev dan struktur proyek

Buka versi interaktif

Ekosistem Dart dan Flutter ada di pub.dev. Package ditambahkan dengan dart pub add nama (atau flutter pub add nama), yang otomatis menuliskannya di pubspec.yaml.

Saat memilih package, lihat skor Likes, Pub Points, tanda Flutter Favorite, penerbit terverifikasi, dan tanggal rilis terakhir. Package yang lama tidak diperbarui berisiko tidak cocok dengan versi Flutter terbaru.

Perintah penting: dart pub get (unduh dependensi), dart format . (merapikan kode), dart analyze (mencari masalah), dan dart test (menjalankan tes).

Soal latihan

  1. Tulis perintah terminal untuk menambahkan package http dan intl, serta lints sebagai dev dependency.

    Petunjuk

    dart pub add, dengan --dev untuk dev dependency.

    Lihat jawaban
    TERMINAL
    dart pub add http intl
dart pub add --dev lints

  2. Pakai package intl untuk menampilkan 7500000 sebagai Rupiah.

    Petunjuk

    NumberFormat.currency(locale: 'id_ID', symbol: 'Rp', decimalDigits: 0).

    Lihat jawaban
    YAML
    import 'package:intl/intl.dart';

void main() {
  final rp = NumberFormat.currency(locale: 'id_ID', symbol: 'Rp', decimalDigits: 0);
  print(rp.format(7500000));
}
    KELUARAN
    Rp7.500.000

Poin penting

  • Tambah package dengan pub add.
  • Periksa Likes, Pub Points, dan tanggal rilis.
  • format, analyze, test sebelum commit.
