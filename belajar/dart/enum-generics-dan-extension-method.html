Enum, generics, dan extension method

Buka versi interaktif

Enum mendaftar pilihan yang pasti, misalnya status pesanan. Dart mendukung enhanced enum: enum boleh punya field dan constructor, seperti ukuran gelas yang menyimpan volume ml.

Generics membuat class atau fungsi yang bekerja untuk berbagai tipe tanpa kehilangan keamanan tipe. List<int> adalah contoh yang sudah kamu pakai. Kamu bisa membuat sendiri, misalnya Kotak<T> atau Hasil<T> untuk respons API.

Extension method menambah method ke tipe yang sudah ada tanpa mengubah aslinya. Contoh: 1250000.rp menghasilkan teks Rupiah. Banyak package Flutter memakai extension, misalnya context.go() dari go_router.

KODE
enum Status { menunggu, dikirim, selesai }

enum Ukuran {
  kecil(250), sedang(350), besar(500);
  final int ml;
  const Ukuran(this.ml);
}

class Kotak<T> {
  final T isi;
  Kotak(this.isi);
  String info() => 'Kotak berisi $isi ($T)';
}

extension Rupiah on int {
  String get rp {
    final s = toString();
    final b = StringBuffer();
    for (var i = 0; i < s.length; i++) {
      if (i > 0 && (s.length - i) % 3 == 0) b.write('.');
      b.write(s[i]);
    }
    return 'Rp$b';
  }
}

void main() {
  final s = Status.dikirim;
  print('${s.name} indeks ${s.index}');
  for (final u in Ukuran.values) {
    print('${u.name}: ${u.ml} ml');
  }
  print(Kotak<int>(7).info());
  print(Kotak('kopi').info());
  print(1250000.rp);
}
KELUARAN
dikirim indeks 1
kecil: 250 ml
sedang: 350 ml
besar: 500 ml
Kotak berisi 7 (int)
Kotak berisi kopi (String)
Rp1.250.000

Soal latihan

  1. Buat extension judul pada String yang mengubah 'belajar dart itu seru' menjadi 'Belajar Dart Itu Seru'.

    Petunjuk

    split(' '), ubah huruf pertama setiap kata dengan toUpperCase, lalu join(' ').

    Lihat jawaban
    KODE
    extension Judul on String {
  String get judul => split(' ')
      .map((k) => k.isEmpty ? k : k[0].toUpperCase() + k.substring(1))
      .join(' ');
}

void main() {
  print('belajar dart itu seru'.judul);
}
    KELUARAN
    Belajar Dart Itu Seru

  2. Buat fungsi generik terbesar<T extends Comparable<T>>(List<T> xs) dan uji dengan angka dan teks.

    Petunjuk

    Bandingkan dengan compareTo; > 0 berarti lebih besar.

    Lihat jawaban
    KODE
    T terbesar<T extends Comparable<T>>(List<T> xs) {
  var m = xs.first;
  for (final x in xs) {
    if (x.compareTo(m) > 0) m = x;
  }
  return m;
}

void main() {
  print(terbesar([3, 9, 2]));
  print(terbesar(['apel', 'zaitun', 'mangga']));
}
    KELUARAN
    9
zaitun

  3. Buat enum Status dengan field label berbahasa Indonesia, lalu cetak label semua status.

    Petunjuk

    Enhanced enum: menunggu('Menunggu bayar'), ...; final String label; const Status(this.label);

    Lihat jawaban
    KODE
    enum Status {
  menunggu('Menunggu bayar'),
  dikirim('Sedang dikirim'),
  selesai('Sudah diterima');

  final String label;
  const Status(this.label);
}

void main() {
  for (final s in Status.values) {
    print('${s.index + 1}. ${s.label}');
  }
}
    KELUARAN
    1. Menunggu bayar
2. Sedang dikirim
3. Sudah diterima

Poin penting

  • Enhanced enum boleh punya field.
  • Generics <T> menjaga keamanan tipe.
  • Extension menambah method ke tipe yang ada.
