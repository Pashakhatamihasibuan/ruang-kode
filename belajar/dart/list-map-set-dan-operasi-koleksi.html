List, Map, Set dan operasi koleksi

Buka versi interaktif

List menyimpan data berurutan ([1, 2, 3]), Map menyimpan pasangan kunci-nilai ({'kopi': 18000}), dan Set menyimpan data unik ({'a', 'b'}).

Daripada menulis loop manual, Dart punya method yang deklaratif: where (filter), map (ubah setiap isi), fold (jumlahkan), any/every, dan sort. Hasil map dan where adalah Iterable, jadi tambahkan .toList() jika butuh List.

Dart juga punya collection if dan collection for di dalam literal list. Fitur ini sangat sering dipakai di Flutter untuk menyusun daftar widget: [if (login) Text('Profil'), for (final m in menu) Text(m)].

KODE
void main() {
  final harga = [18000, 22500, 5000, 30000];
  final mahal = harga.where((h) => h > 20000).toList();
  final diskon = harga.map((h) => h * 0.9).toList();
  final total = harga.fold(0, (sum, h) => sum + h);
  print('Mahal: $mahal');
  print('Diskon: $diskon');
  print('Total: $total');

  final stok = {'kopi': 12, 'teh': 0};
  stok['roti'] = 5;
  print('Habis: ${stok.entries.where((e) => e.value == 0).map((e) => e.key).toList()}');

  final login = true;
  final menu = ['Beranda', if (login) 'Profil', for (final x in ['A', 'B']) 'Kategori $x'];
  print(menu);
}
KELUARAN
Mahal: [22500, 30000]
Diskon: [16200.0, 20250.0, 4500.0, 27000.0]
Total: 75500
Habis: [teh]
[Beranda, Profil, Kategori A, Kategori B]

Soal latihan

  1. Dari nilai [70, 85, 90, 60, 95], hitung rata-rata, nilai tertinggi, dan jumlah yang lulus (≥ 75).

    Petunjuk

    fold untuk jumlah, reduce untuk maksimum, where(...).length untuk yang lulus.

    Lihat jawaban
    KODE
    void main() {
  final nilai = [70, 85, 90, 60, 95];
  final rata = nilai.fold(0, (a, b) => a + b) / nilai.length;
  final maks = nilai.reduce((a, b) => a > b ? a : b);
  final lulus = nilai.where((n) => n >= 75).length;
  print('Rata-rata: $rata');
  print('Tertinggi: $maks');
  print('Lulus: $lulus');
}
    KELUARAN
    Rata-rata: 80.0
Tertinggi: 95
Lulus: 3

  2. Hitung frekuensi setiap huruf di kata 'banana' memakai Map.

    Petunjuk

    f[c] = (f[c] ?? 0) + 1 untuk setiap huruf.

    Lihat jawaban
    KODE
    void main() {
  final f = <String, int>{};
  for (final c in 'banana'.split('')) {
    f[c] = (f[c] ?? 0) + 1;
  }
  print(f);
}
    KELUARAN
    {b: 1, a: 3, n: 2}

Poin penting

  • where = filter, map = ubah, fold = gabungkan.
  • Tambahkan toList() jika butuh List.
  • collection if/for dipakai untuk daftar widget.

Cek pemahaman

Method untuk mengambil isi yang memenuhi syarat?

Jawaban: where

where menyaring.

Hasil [1, if (false) 2, 3]?
