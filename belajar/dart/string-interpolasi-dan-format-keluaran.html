String, interpolasi, dan format keluaran

Buka versi interaktif

Dart menyisipkan nilai ke string dengan interpolasi: '$nama' untuk variabel dan '${a + b}' untuk ekspresi. Ini cara utama menyusun teks di Dart; tidak ada printf.

Untuk merapikan angka: toStringAsFixed(2) membulatkan ke 2 desimal, padLeft(5) dan padRight(10) mengatur lebar kolom, padLeft(3, '0') mengisi nol di depan, dan toRadixString(16) mengubah ke heksadesimal.

Untuk angka dan uang yang tampil ke pengguna, industri memakai package intl: NumberFormat.currency(locale: 'id_ID', symbol: 'Rp', decimalDigits: 0) menghasilkan Rp7.500.000, dan DateFormat('d MMMM y', 'id_ID') untuk tanggal. Package ini perlu ditambahkan dengan dart pub add intl.

KODE
void main() {
  const nama = 'Rina';
  const ipk = 3.4567;
  print('Nama: $nama, IPK ${ipk.toStringAsFixed(2)}');

  // lebar kolom dan isi nol
  print('[${nama.padLeft(8)}] [${nama.padRight(8)}]');
  print('INV-${7.toString().padLeft(4, '0')}');
  print('hex ${255.toRadixString(16)}, biner ${5.toRadixString(2)}');

  // struk berkolom
  final barang = {'Kopi susu': 18000, 'Roti bakar': 22500};
  barang.forEach((nama, harga) {
    print('${nama.padRight(12)}${harga.toString().padLeft(8)}');
  });
}

Soal latihan

  1. Buat tabel nilai rata kiri-kanan untuk Andi 85.5, Budi 90, Citra 78.4. Nama lebar 10, nilai lebar 6 dengan 1 desimal.

    Petunjuk

    nama.padRight(10) dan nilai.toStringAsFixed(1).padLeft(6).

    Lihat jawaban
    KODE
    void main() {
  final nilai = {'Andi': 85.5, 'Budi': 90.0, 'Citra': 78.4};
  print('${'Nama'.padRight(10)}${'Nilai'.padLeft(6)}');
  nilai.forEach((n, v) {
    print('${n.padRight(10)}${v.toStringAsFixed(1).padLeft(6)}');
  });
}

  2. Ubah daftar nomor [7, 42, 315] menjadi kode faktur INV-0007, INV-0042, INV-0315.

    Petunjuk

    toString().padLeft(4, '0').

    Lihat jawaban
    KODE
    void main() {
  for (final n in [7, 42, 315]) {
    print('INV-${n.toString().padLeft(4, '0')}');
  }
}

Poin penting

  • Interpolasi $x dan ${ekspresi}.
  • toStringAsFixed, padLeft, padRight untuk format.
  • Package intl untuk uang dan tanggal lokal.
