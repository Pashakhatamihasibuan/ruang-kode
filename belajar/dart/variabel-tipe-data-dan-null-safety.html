Variabel, tipe data, dan null safety

Buka versi interaktif

Dart bertipe statis, tetapi bisa menebak tipe sendiri. var nama = 'Rina'; otomatis bertipe String. Tipe dasarnya: int, double, num (int atau double), String, bool, List, Map, dan Set.

final berarti nilainya hanya bisa diisi sekali (ditentukan saat program berjalan). const berarti nilainya sudah pasti saat kompilasi. Di Flutter, const membuat widget tidak perlu dibuat ulang, sehingga aplikasi lebih hemat.

Null safety: variabel biasa tidak boleh berisi null. Jika memang boleh kosong, tambahkan tanda tanya: String? alamat;. Operator ?? memberi nilai cadangan, ?. memanggil hanya jika tidak null, dan ! memaksa (berbahaya jika ternyata null). Fitur ini mencegah error "null" yang paling sering membuat aplikasi tertutup sendiri.

KODE
void main() {
  var nama = 'Rina';        // String
  int umur = 20;
  double ipk = 3.75;
  final kampus = 'UNIMED';   // diisi sekali
  const pajak = 0.11;        // pasti saat kompilasi

  String? alamat;            // boleh null
  print('$nama, $umur tahun, IPK $ipk');
  print('Kampus: $kampus, pajak $pajak');
  print('Alamat: ${alamat ?? 'belum diisi'}');
  print('Panjang alamat: ${alamat?.length}');
}
KELUARAN
Rina, 20 tahun, IPK 3.75
Kampus: UNIMED, pajak 0.11
Alamat: belum diisi
Panjang alamat: null

Soal latihan

  1. Hitung luas lingkaran berjari-jari 7 dengan const pi = 3.141592653589793, tampilkan 2 desimal.

    Petunjuk

    Luas = pi × r × r, lalu toStringAsFixed(2).

    Lihat jawaban
    KODE
    void main() {
  const pi = 3.141592653589793;
  final r = 7;
  final luas = pi * r * r;
  print('Luas: ${luas.toStringAsFixed(2)}');
}

  2. Variabel String? nama belum diisi. Tampilkan panjang nama, atau 0 jika null, tanpa memakai if.

    Petunjuk

    Gabungkan ?. dan ??.

    Lihat jawaban
    KODE
    void main() {
  String? nama;
  print('Panjang: ${nama?.length ?? 0}');
  nama = 'Budi';
  print('Panjang: ${nama?.length ?? 0}');
}

Poin penting

  • var menebak tipe; final diisi sekali; const pasti saat kompilasi.
  • Tanpa ?, variabel tidak boleh null.
  • ?? memberi nilai cadangan.
