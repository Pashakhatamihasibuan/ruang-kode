Future, async, dan await

Buka versi interaktif

Mengambil data dari internet butuh waktu. Agar aplikasi tidak macet, Dart memakai Future: janji bahwa nilai akan tersedia nanti. Fungsi yang mengembalikan Future ditandai async, dan di dalamnya kita menunggu hasil dengan await.

Selama menunggu, aplikasi tetap bisa merespons sentuhan. Di Flutter, Future biasanya ditampilkan dengan widget FutureBuilder atau dikelola oleh state management.

Error pada kode asinkron ditangkap dengan try / catch seperti biasa, dan finally untuk langkah yang selalu dijalankan (misalnya mematikan indikator loading).

KODE
Future<String> ambilNama(int id) async {
  await Future.delayed(const Duration(milliseconds: 500));
  if (id <= 0) throw ArgumentError('id tidak valid');
  return 'Pengguna #$id';
}

Future<void> main() async {
  print('Memuat...');
  final nama = await ambilNama(7);
  print(nama);
  try {
    await ambilNama(0);
  } catch (e) {
    print('Gagal: $e');
  } finally {
    print('Selesai memuat');
  }
}
KELUARAN
Memuat...
Pengguna #7
Gagal: Invalid argument(s): id tidak valid
Selesai memuat

Soal latihan

  1. Simulasikan mengunduh tiga file secara berurutan (masing-masing 300 ms), lalu cetak "Semua selesai".

    Petunjuk

    Pakai for dan await Future.delayed di dalam main yang async.

    Lihat jawaban
    KODE
    Future<void> unduh(String f) async {
  await Future.delayed(const Duration(milliseconds: 300));
  print('$f selesai');
}

Future<void> main() async {
  for (final f in ['a.pdf', 'b.pdf', 'c.pdf']) {
    await unduh(f);
  }
  print('Semua selesai');
}

  2. Jalankan dua permintaan sekaligus dengan Future.wait, dan tangkap error dari fungsi yang melempar Exception('Server sibuk').

    Petunjuk

    Future.wait menunggu semua; error ditangkap try/catch.

    Lihat jawaban
    KODE
    Future<int> stok() async => 12;
Future<int> harga() async => throw Exception('Server sibuk');

Future<void> main() async {
  final hasil = await Future.wait([stok(), stok()]);
  print('Stok: $hasil');
  try {
    await harga();
  } catch (e) {
    print('Gagal: $e');
  }
}

Poin penting

  • Future = nilai yang datang nanti.
  • async menandai fungsi, await menunggu hasil.
  • try/catch/finally juga untuk kode async.
