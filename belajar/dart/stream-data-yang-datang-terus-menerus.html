Stream: data yang datang terus-menerus

Buka versi interaktif

Jika Future memberi satu nilai, Stream memberi banyak nilai seiring waktu: lokasi GPS, pesan chat, atau hitung mundur. Stream dibaca dengan await for atau listen.

Fungsi async* menghasilkan Stream dengan yield. Di Flutter, Stream ditampilkan dengan StreamBuilder, dan banyak library (Firebase, BLoC) memakai Stream di baliknya.

KODE
Stream<int> hitungMundur(int dari) async* {
  for (var i = dari; i >= 1; i--) {
    await Future.delayed(const Duration(milliseconds: 300));
    yield i;
  }
}

Future<void> main() async {
  await for (final detik in hitungMundur(3)) {
    print('Sisa $detik');
  }
  print('Waktu habis!');
}
KELUARAN
Sisa 3
Sisa 2
Sisa 1
Waktu habis!

Soal latihan

  1. Dari Stream angka 1–6, ambil yang genap lalu kuadratkan.

    Petunjuk

    Stream.fromIterable, lalu where dan map seperti pada List.

    Lihat jawaban
    KODE
    Future<void> main() async {
  final s = Stream.fromIterable([1, 2, 3, 4, 5, 6])
      .where((x) => x.isEven)
      .map((x) => x * x);
  await for (final x in s) {
    print(x);
  }
}

  2. Buat fungsi async* yang menghasilkan nama hari kerja satu per satu.

    Petunjuk

    Pakai for-in di dalam async* lalu yield.

    Lihat jawaban
    KODE
    Stream<String> hariKerja() async* {
  for (final h in ['Senin', 'Selasa', 'Rabu', 'Kamis', 'Jumat']) {
    yield h;
  }
}

Future<void> main() async {
  final semua = await hariKerja().toList();
  print(semua.join(', '));
}

Poin penting

  • Stream = banyak nilai seiring waktu.
  • async* + yield membuat Stream.
  • StreamBuilder menampilkannya di Flutter.
