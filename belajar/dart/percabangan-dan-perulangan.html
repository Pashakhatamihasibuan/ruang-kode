Percabangan dan perulangan

Buka versi interaktif

Percabangan memakai if, else if, else. Dart 3 punya switch expression yang ringkas: final huruf = switch (nilai ~/ 10) { 10 || 9 => 'A', 8 => 'B', _ => 'C' };. Operator ~/ adalah pembagian bulat.

Perulangan: for klasik saat jumlah putaran diketahui, for-in untuk membaca isi koleksi, while saat hanya kondisi berhenti yang diketahui, dan do-while saat badan loop harus jalan minimal sekali. break keluar dari loop, continue lompat ke putaran berikutnya.

Aturan memilih loop sama di semua bahasa: lihat apa yang sudah kamu ketahui sebelum loop dimulai.

KODE
void main() {
  final nilai = 87;
  final huruf = switch (nilai ~/ 10) {
    10 || 9 => 'A',
    8 => 'B',
    7 => 'C',
    _ => 'D',
  };
  print('Nilai $nilai = $huruf');

  for (var i = 1; i <= 3; i++) {
    print('Putaran $i');
  }
  for (final kota in ['Medan', 'Padang']) {
    print('Kirim ke $kota');
  }
  var saldo = 0, minggu = 0;
  while (saldo < 50000) {
    saldo += 20000;
    minggu++;
  }
  print('Target di minggu ke-$minggu');
}
KELUARAN

Putaran 1
Putaran 2
Putaran 3
Kirim ke Medan

Target di minggu ke-3

Soal latihan

  1. FizzBuzz 1 sampai 15: cetak Fizz untuk kelipatan 3, Buzz untuk kelipatan 5, FizzBuzz untuk keduanya.

    Petunjuk

    Periksa kelipatan 15 lebih dulu.

    Lihat jawaban
    KODE
    void main() {
  for (var i = 1; i <= 15; i++) {
    if (i % 15 == 0) {
      print('FizzBuzz');
    } else if (i % 3 == 0) {
      print('Fizz');
    } else if (i % 5 == 0) {
      print('Buzz');
    } else {
      print(i);
    }
  }
}

  2. Jumlahkan bilangan genap dari 1 sampai 100 memakai continue untuk melewati bilangan ganjil.

    Petunjuk

    Jika i % 2 != 0, continue.

    Lihat jawaban
    KODE
    void main() {
  var total = 0;
  for (var i = 1; i <= 100; i++) {
    if (i % 2 != 0) continue;
    total += i;
  }
  print('Jumlah genap: $total');
}

  3. Cetak segitiga bintang 4 baris (baris ke-i berisi i bintang).

    Petunjuk

    Operator * pada String mengulang teks: '*' * i.

    Lihat jawaban
    KODE
    void main() {
  for (var i = 1; i <= 4; i++) {
    print('*' * i);
  }
}

Poin penting

  • switch expression Dart 3 mengembalikan nilai.
  • ~/ adalah pembagian bulat.
  • for, for-in, while, do-while dipilih sesuai yang diketahui.
