Inheritance, abstract class, dan mixin

Buka versi interaktif

extends mewarisi class lain. abstract class tidak bisa dibuat objeknya langsung dan berisi method yang wajib diisi turunan. Pola ini persis seperti StatelessWidget di Flutter: kamu mewarisi lalu mengisi method build.

Mixin (with) menambahkan kemampuan ke class tanpa pewarisan, misalnya kemampuan Logger atau Diskonable. Satu class bisa memakai beberapa mixin sekaligus.

Dart 3 menambahkan sealed class: daftar turunan sudah pasti, sehingga switch bisa memeriksa bahwa semua kasus sudah ditangani. Cocok untuk status layar: Memuat, Sukses, Gagal.

KODE
abstract class Pembayaran {
  final int jumlah;
  Pembayaran(this.jumlah);
  String proses();
}

mixin Pencatat {
  void catat(String pesan) => print('[LOG] $pesan');
}

class Qris extends Pembayaran with Pencatat {
  Qris(super.jumlah);
  @override
  String proses() {
    catat('QRIS dipindai');
    return 'Bayar $jumlah lewat QRIS';
  }
}

class Transfer extends Pembayaran {
  final String bank;
  Transfer(super.jumlah, this.bank);
  @override
  String proses() => 'Transfer $jumlah ke $bank';
}

void main() {
  final daftar = <Pembayaran>[Qris(50000), Transfer(120000, 'BSI')];
  for (final p in daftar) {
    print(p.proses());
  }
}
KELUARAN
[LOG] QRIS dipindai
Bayar 50000 lewat QRIS
Transfer 120000 ke BSI

Soal latihan

  1. Buat abstract class Bentuk dengan method luas(), lalu turunan Lingkaran(r) dan Persegi(s). Cetak luas keduanya dengan 2 desimal.

    Petunjuk

    Lingkaran: 3.14159 × r × r. Override di setiap turunan.

    Lihat jawaban
    KODE
    abstract class Bentuk {
  double luas();
}

class Lingkaran extends Bentuk {
  final double r;
  Lingkaran(this.r);
  @override
  double luas() => 3.14159 * r * r;
}

class Persegi extends Bentuk {
  final double s;
  Persegi(this.s);
  @override
  double luas() => s * s;
}

void main() {
  final daftar = <Bentuk>[Lingkaran(2), Persegi(3)];
  for (final b in daftar) {
    print('${b.runtimeType}: ${b.luas().toStringAsFixed(2)}');
  }
}

  2. Buat mixin Logger dengan method log(pesan), lalu pakai di class Pesanan.

    Petunjuk

    mixin Logger { ... } lalu class Pesanan with Logger.

    Lihat jawaban
    KODE
    mixin Logger {
  void log(String m) => print('[LOG] $m');
}

class Pesanan with Logger {
  void bayar() {
    log('Pesanan dibayar');
  }
}

void main() {
  Pesanan().bayar();
}

Poin penting

  • extends mewarisi; abstract mewajibkan method diisi.
  • with menambahkan mixin.
  • sealed class untuk status yang pasti.
