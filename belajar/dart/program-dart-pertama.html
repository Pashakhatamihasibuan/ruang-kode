Program Dart pertama

Buka versi interaktif

Dart adalah bahasa buatan Google yang dipakai untuk membangun aplikasi Flutter (Android, iOS, web, desktop dari satu kode). Sintaksnya mirip Java dan JavaScript: ada kurung kurawal, titik koma, dan tipe data, tetapi lebih ringkas.

Setiap program Dart dimulai dari fungsi main(). Perintah print() menampilkan teks ke konsol. Kamu bisa mencoba Dart tanpa memasang apa pun di dartpad.dev, atau memasang Dart SDK (sudah ikut terpasang bersama Flutter) lalu menjalankan dart run nama_file.dart.

Komentar ditulis dengan // untuk satu baris dan /* ... */ untuk beberapa baris. Komentar dokumentasi memakai ///.

KODE
void main() {
  // titik awal program
  print('Halo, Ruang Kode!');
  print('Dart dipakai untuk Flutter');
}
KELUARAN
Halo, Ruang Kode!
Dart dipakai untuk Flutter

Soal latihan

  1. Cetak biodata tiga baris: nama, program studi, dan kota asalmu.

    Petunjuk

    Panggil print() tiga kali di dalam main().

    Lihat jawaban
    KODE
    void main() {
  print('Nama: Rina Siregar');
  print('Prodi: Teknik Informatika');
  print('Kota: Medan');
}

  2. Cetak kalimat It's Dart time yang mengandung tanda kutip satu.

    Petunjuk

    Pakai tanda kutip dua untuk string, atau tulis \' di dalam kutip satu.

    Lihat jawaban
    KODE
    void main() {
  print("It's Dart time");
  print('It\'s Dart time');
}

Poin penting

  • Program dimulai dari main().
  • print() menampilkan teks.
  • Coba Dart langsung di dartpad.dev.
