Exception: try, catch, finally, dan throw

Buka versi interaktif

Program yang baik tidak tertutup saat input salah. Kode yang berisiko dibungkus try. Error ditangkap dengan on TipeError catch (e) untuk jenis tertentu, atau catch (e) untuk semua. Blok finally selalu dijalankan, berhasil atau gagal.

Kamu bisa melempar error sendiri dengan throw. Untuk aturan bisnis, buat class exception sendiri yang implements Exception, misalnya SaldoKurang. Pesan error jadi jelas dan bisa ditangkap secara khusus.

Untuk input angka dari pengguna, int.tryParse(s) lebih aman daripada int.parse(s): hasilnya null jika teks bukan angka, sehingga tidak perlu try/catch.

KODE
class SaldoKurang implements Exception {
  final int kurang;
  SaldoKurang(this.kurang);
  @override
  String toString() => 'Saldo kurang Rp$kurang';
}

void tarik(int saldo, int jumlah) {
  if (jumlah > saldo) throw SaldoKurang(jumlah - saldo);
  print('Tarik $jumlah berhasil');
}

void main() {
  try {
    final n = int.parse('12a');
    print(n);
  } on FormatException {
    print('Format salah, masukkan angka saja');
  } finally {
    print('Selesai memeriksa input');
  }

  try {
    tarik(50000, 80000);
  } on SaldoKurang catch (e) {
    print(e);
  }

  final angka = int.tryParse('99x') ?? 0;
  print('tryParse: $angka');
}

Soal latihan

  1. Buat fungsi bagi(a, b) yang melempar Exception('Pembagi nol') jika b = 0. Tangkap errornya di main.

    Petunjuk

    if (b == 0) throw Exception(...); lalu try/catch di pemanggil.

    Lihat jawaban
    KODE
    double bagi(int a, int b) {
  if (b == 0) throw Exception('Pembagi nol');
  return a / b;
}

void main() {
  print(bagi(10, 4));
  try {
    print(bagi(5, 0));
  } catch (e) {
    print('Gagal: $e');
  }
}

  2. Validasi daftar input umur ['20', 'abc', '-5', '17']: cetak 'valid', 'bukan angka', atau 'tidak boleh negatif'.

    Petunjuk

    int.tryParse lalu periksa null dan < 0.

    Lihat jawaban
    KODE
    void main() {
  for (final s in ['20', 'abc', '-5', '17']) {
    final n = int.tryParse(s);
    if (n == null) {
      print('$s: bukan angka');
    } else if (n < 0) {
      print('$s: tidak boleh negatif');
    } else {
      print('$s: valid');
    }
  }
}

Poin penting

  • try/on/catch/finally.
  • Exception sendiri dengan implements Exception.
  • tryParse untuk input pengguna.

Cek pemahaman

Blok yang selalu dijalankan, ada error atau tidak?

Jawaban: finally

finally cocok untuk menutup koneksi atau mematikan loading.

Jawaban: null

tryParse mengembalikan null jika gagal.
