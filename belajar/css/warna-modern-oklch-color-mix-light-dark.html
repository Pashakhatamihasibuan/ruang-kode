Warna modern: oklch, color-mix & light-dark

Buka versi interaktif

Selain heksa dan rgb(), CSS modern punya oklch(): lightness, chroma (kepekatan), dan hue. Keunggulannya, perubahan lightness terasa merata di mata manusia, sehingga membuat skala warna 100 sampai 900 jauh lebih mudah.

color-mix() mencampur dua warna langsung di CSS, misalnya membuat latar lembut dari warna brand tanpa menambah token baru. light-dark() memilih nilai untuk tema terang atau gelap sesuai color-scheme.

Ketiganya didukung browser modern sejak 2023 sampai 2024. Untuk browser lama, tulis nilai cadangan heksa di baris sebelumnya; browser akan memakai baris terakhir yang dipahaminya.

CSS
:root {
  color-scheme: light dark;
  --brand: oklch(55% 0.15 255);                  /* biru */
  --brand-soft: color-mix(in oklch, var(--brand) 15%, white);
  --teks: light-dark(#152033, #E4EAF2);
  --latar: light-dark(#F2F4F8, #0C121B);
}

.tombol {
  background: #255DA2;          /* cadangan untuk browser lama */
  background: var(--brand);
}
.tombol:hover { background: oklch(from var(--brand) calc(l - 0.08) c h); }
.badge { background: var(--brand-soft); color: var(--brand); }

Poin penting

  • oklch: lightness, chroma, hue; skala warna lebih merata.
  • color-mix() mencampur warna di CSS.
  • light-dark() memilih nilai sesuai tema.
  • Beri nilai cadangan untuk browser lama.
