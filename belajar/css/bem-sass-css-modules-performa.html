BEM, Sass, CSS Modules & performa

Buka versi interaktif

Di proyek besar, nama class mudah bentrok. BEM (Block__Element--Modifier) memberi aturan penamaan: .kartu, .kartu__judul, .kartu--promo. Specificity tetap rendah dan maksud setiap class jelas.

Sass menambah fitur seperti nesting, mixin, dan fungsi, lalu dikompilasi menjadi CSS biasa. PostCSS memproses CSS dengan plugin, misalnya menambahkan prefix browser otomatis. CSS Modules dan CSS-in-JS membuat nama class unik per komponen secara otomatis.

Untuk performa: kirim CSS sekecil mungkin, hapus aturan yang tidak dipakai, dan muat CSS kritis lebih awal karena CSS menghambat tampilnya halaman.

KODE
// Sass dengan penamaan BEM
$aksen: #B4532A;

@mixin kartu-dasar {
  border-radius: 12px;
  padding: 16px;
}

.kartu {
  @include kartu-dasar;
  border: 1px solid #ddd;

  &__judul { font-weight: 600; }        // .kartu__judul
  &--promo { border-color: $aksen; }    // .kartu--promo
}

Poin penting

  • BEM: blok__elemen--modifier.
  • Sass dikompilasi menjadi CSS biasa.
  • CSS Modules membuat nama class unik otomatis.
  • CSS menghambat tampil halaman: jaga tetap ramping.
