Aturan, selector & deklarasi

Buka versi interaktif

CSS (Cascading Style Sheets) mengatur tampilan HTML. Satu aturan terdiri dari selector (elemen mana) dan blok deklarasi di dalam kurung kurawal. Setiap deklarasi adalah pasangan properti: nilai;.

Contoh: h1 { color: #B4532A; font-size: 32px; } berarti "semua h1 berwarna terakota dan berukuran 32 piksel". Komentar ditulis /* ... */.

Ubah nilai di panel CSS dan lihat hasilnya langsung.

HTML
<h1>Toko Nusantara</h1>
<p>Kopi, teh, dan camilan pilihan.</p>
<p class="promo">Promo: gratis ongkir!</p>
CSS
/* aturan untuk semua h1 */
h1 {
  color: #B4532A;
  font-family: Georgia, serif;
}
p {
  color: #444;
  line-height: 1.6;
}
.promo {
  background: #FBE7A8;
  padding: 6px 10px;
}

Tantangan

  1. Buat semua paragraf berukuran huruf 18px.

Poin penting

  • Aturan = selector + { deklarasi }.
  • Deklarasi = properti: nilai; dan diakhiri titik koma.
  • Komentar CSS: /* ... */.
