Box model

Buka versi interaktif

Setiap elemen digambar sebagai kotak berlapis: content (isi), padding (jarak di dalam), border (garis tepi), dan margin (jarak ke elemen lain).

Secara bawaan, width hanya mengukur isi, jadi padding dan border menambah lebar total. Dengan box-sizing: border-box, width sudah termasuk padding dan border. Hampir semua proyek modern memasang *{box-sizing:border-box}.

Margin vertikal dua blok yang bersebelahan bisa runtuh (collapse) menjadi satu, diambil yang terbesar. outline mirip border tapi tidak memakan ruang, sering dipakai untuk penanda fokus.

HTML
<div class="kotak a">content-box: lebar 200 + padding + border</div>
<div class="kotak b">border-box: lebar tepat 200</div>
CSS
.kotak { width: 200px; padding: 20px; border: 6px solid #2E5E8C; margin: 12px 0; background: #E9EFF5; font: 13px sans-serif; }
.a { box-sizing: content-box; }
.b { box-sizing: border-box; }

Tantangan

  1. Ubah kotak .a agar lebar totalnya juga tepat 200px.

Poin penting

  • Lapisan kotak: content, padding, border, margin.
  • border-box: width sudah termasuk padding dan border.
  • Margin vertikal bisa runtuh.
  • outline tidak memakan ruang.

Cek pemahaman

width 200px, padding 20px, border 5px, content-box. Lebar total?

Jawaban: 250px

200 + 2×20 + 2×5 = 250.

Yang memberi jarak di dalam border?

Jawaban: padding

Padding ada di antara isi dan border.
