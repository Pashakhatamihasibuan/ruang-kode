Variabel CSS & tema

Buka versi interaktif

Custom property (variabel CSS) ditulis --nama: nilai dan dipakai dengan var(--nama). Berbeda dengan variabel Sass, variabel CSS hidup di browser: bisa diubah oleh media query, oleh class, atau oleh JavaScript.

Ini dasar dari tema terang-gelap dan design token. Tulis semua warna di :root, lalu ganti nilainya untuk tema gelap.

HTML
<div class="kartu"><h3>Mode tema</h3><p>Klik tombol untuk ganti tema.</p>
<button onclick="document.documentElement.classList.toggle('gelap')">Ganti tema</button></div>
CSS
:root { --bg: #FAFAF7; --teks: #1C1B19; --aksen: #B4532A; --radius: 12px; }
:root.gelap { --bg: #181816; --teks: #ECEAE4; --aksen: #E39A73; }
body { background: var(--bg); color: var(--teks); font-family: sans-serif; transition: background .3s; }
.kartu { border: 2px solid var(--aksen); border-radius: var(--radius); padding: 12px 16px; }
button { background: var(--aksen); color: var(--bg); border: 0; padding: 6px 14px; border-radius: 99px; }

Tantangan

  1. Ganti --radius menjadi 0px agar kartu bersudut tajam.

Poin penting

  • --nama untuk mendefinisikan, var(--nama) untuk memakai.
  • Variabel CSS bisa diubah saat halaman berjalan.
  • Dasar tema gelap dan design token.
