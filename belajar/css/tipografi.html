CSS · Modul 3 · Praktik langsung

Tipografi

Buka versi interaktif

font-family berisi daftar huruf cadangan: font-family: "Inter", system-ui, sans-serif. Jika Inter gagal dimuat, browser memakai berikutnya. Google Fonts menyediakan ratusan huruf gratis lewat tag link.

Untuk keterbacaan: ukuran dasar 16px atau lebih, line-height 1.5–1.7 untuk paragraf, dan panjang baris 45–75 karakter. Tebal diatur font-weight (400 normal, 600 semi tebal, 700 tebal).

Properti teks lain: text-align, text-decoration, text-transform: uppercase, letter-spacing, dan text-shadow.

HTML
<p class="eyebrow">Cerita kopi</p>
<h1>Dari kebun Gayo ke cangkirmu</h1>
<p class="isi">Kopi Gayo tumbuh di ketinggian 1.200 meter di Aceh Tengah. Petani memetik buah merah satu per satu, lalu mengolahnya dengan proses giling basah yang membuat rasanya bersih dan seimbang.</p>
CSS
body { font-family: system-ui, sans-serif; color: #1C1B19; }
.eyebrow { text-transform: uppercase; letter-spacing: .12em; font-size: .75rem; font-weight: 600; color: #6E6B64; }
h1 { font: 400 2rem/1.1 Georgia, serif; margin: .2em 0 .5em; }
.isi { font-size: 1rem; line-height: 1.7; max-width: 60ch; }

Tantangan

  1. Ubah line-height paragraf .isi menjadi 2.

Poin penting

  • Selalu tulis font cadangan di font-family.
  • Paragraf nyaman: 16px+, line-height 1.5–1.7, 45–75 karakter.
  • Shorthand font: gaya tebal ukuran/line-height keluarga.

Jawaban: 1.5–1.7
