Media query & mobile-first

Buka versi interaktif

Mayoritas pengguna internet Indonesia membuka situs dari ponsel. Pendekatan mobile-first: tulis gaya untuk layar kecil dulu, lalu tambahkan @media (min-width: 640px) { ... } untuk layar yang lebih lebar.

Media query juga bisa memeriksa preferensi pengguna: prefers-color-scheme: dark untuk mode gelap dan prefers-reduced-motion untuk mengurangi animasi.

Ubah lebar pratinjau dengan tombol di atasnya untuk melihat tata letak berubah.

HTML
<div class="tata"><aside>Filter</aside><main>Daftar produk</main></div>
CSS
.tata { display: grid; gap: 10px; font: 14px sans-serif; }
.tata > * { background: #E9EFF5; padding: 14px; border-radius: 10px; }
/* layar lebar: dua kolom */
@media (min-width: 480px) {
  .tata { grid-template-columns: 140px 1fr; }
}
@media (prefers-color-scheme: dark) {
  .tata > * { background: #1A2330; color: #ECEAE4; }
}

Kode pemula vs kode rapi

Ukuran huruf yang ikut lebar layar dengan clamp()

clamp(min, ideal, maks) membuat judul membesar mulus mengikuti lebar layar dan tidak pernah lebih kecil atau lebih besar dari batasnya. Tidak perlu tiga media query.

KODE PEMULA
h1 { font-size: 24px; }
@media (min-width: 600px) { h1 { font-size: 32px; } }
@media (min-width: 1000px) { h1 { font-size: 44px; } }
KODE RAPI (BEST PRACTICE)
h1 { font-size: clamp(1.5rem, 1rem + 2.5vw, 2.75rem); }

Poin penting

  • Mobile-first: gaya dasar untuk ponsel, min-width untuk layar lebar.
  • Media query bisa memeriksa tema gelap dan preferensi animasi.
  • Selalu pasang meta viewport di HTML.
