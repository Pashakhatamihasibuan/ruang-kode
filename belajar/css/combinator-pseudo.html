Combinator & pseudo

Buka versi interaktif

Combinator memilih berdasarkan hubungan: nav a (keturunan), ul > li (anak langsung), h2 + p (saudara tepat setelahnya), h2 ~ p (semua saudara setelahnya). Selector atribut: a[href^="https"], input[type="email"].

Pseudo-class memilih keadaan: :hover, :focus-visible, :checked, :nth-child(2n), :not(.aktif), :has(img). Pseudo-element menata bagian elemen: ::before, ::after, ::first-letter, ::placeholder.

HTML
<ul class="daftar">
  <li>Kopi Gayo</li><li class="habis">Rendang Kaleng</li><li>Teh Melati</li><li>Keripik</li>
</ul>
<a href="https://roadmap.sh">Tautan luar</a> · <a href="#bawah">Tautan dalam</a>
CSS
.daftar > li { padding: 6px; font: 14px sans-serif; }
.daftar > li:nth-child(even) { background: #F2F1EC; }
.daftar li:not(.habis):hover { background: #FBE7A8; }
.habis::after { content: " (habis)"; color: #B23A2E; font-size: 12px; }
a[href^="https"]::after { content: " ↗"; }

Tantangan

  1. Buat baris pertama daftar bercetak tebal memakai :first-child.

Poin penting

  • spasi = keturunan, > = anak langsung, + = saudara berikutnya, ~ = semua saudara berikutnya.
  • Pseudo-class untuk keadaan, pseudo-element untuk bagian.
  • :has() memilih induk berdasarkan isinya.
