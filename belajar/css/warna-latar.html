Warna & latar

Buka versi interaktif

Warna bisa ditulis dengan nama (tomato), hex (#B4532A), rgb(180 83 42), atau hsl(18 62% 44%). HSL paling mudah diatur manusia: hue (0–360 derajat roda warna), saturation, lightness. Tambahkan alpha untuk transparansi: rgb(0 0 0 / 50%).

Properti background bisa berisi warna, gambar, atau gradien seperti linear-gradient(135deg, #B4532A, #2E5E8C). box-shadow memberi bayangan dan opacity membuat seluruh elemen transparan.

Pastikan kontras teks dengan latar cukup: minimal 4.5:1 untuk teks biasa.

HTML
<div class="kartu">
  <h3>Promo Oktober</h3>
  <p>Diskon 20% semua kopi.</p>
</div>
<div class="label">hsl(18 62% 44%)</div>
CSS
.kartu {
  background: linear-gradient(135deg, hsl(18 62% 44%), hsl(208 50% 36%));
  color: white;
  padding: 16px 20px;
  border-radius: 14px;
  box-shadow: 0 10px 24px rgb(0 0 0 / 25%);
  font-family: sans-serif;
}
.label { margin-top: 12px; display: inline-block; padding: 4px 10px; border-radius: 99px; background: hsl(18 62% 44% / 15%); color: hsl(18 62% 34%); font: 12px monospace; }

Tantangan

  1. Ubah sudut gradien kartu menjadi 90deg.

Poin penting

  • Hex, rgb, dan hsl menulis warna yang sama dengan cara berbeda.
  • HSL mudah diubah: geser lightness untuk versi terang/gelap.
  • Gradien ditulis di background-image.
  • Kontras teks minimal 4.5:1.
