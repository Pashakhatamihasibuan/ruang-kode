Position & z-index

Buka versi interaktif

position menentukan cara elemen ditempatkan. static (bawaan) mengikuti alur. relative bergeser dari posisi aslinya dan menjadi patokan bagi anak absolute. absolute keluar dari alur dan diposisikan terhadap leluhur terdekat yang non-static.

fixed menempel pada layar (misalnya tombol chat), sticky mengikuti alur lalu menempel saat digulir (misalnya header tabel).

z-index mengatur elemen mana di atas, tapi hanya berlaku di dalam stacking context yang sama. Elemen dengan opacity kurang dari 1, transform, atau position + z-index membuat stacking context baru.

HTML
<div class="kartu">
  <span class="badge">BARU</span>
  <h3>Madu Hutan</h3>
  <p>Gulir panel ini untuk melihat sticky.</p>
  <div class="gulir"><div class="judul">Ulasan</div><p>Enak!</p><p>Kental.</p><p>Asli.</p><p>Mantap.</p></div>
</div>
CSS
.kartu{position:relative;border:1px solid #ddd;border-radius:12px;padding:12px;font:14px sans-serif;width:260px}
.badge{position:absolute;top:-10px;right:12px;background:#B23A2E;color:#fff;font-size:11px;padding:2px 8px;border-radius:99px}
.gulir{height:90px;overflow:auto;border:1px solid #eee}
.judul{position:sticky;top:0;background:#F2F1EC;font-weight:600;padding:2px 6px}

Tantangan

  1. Pindahkan badge ke pojok kiri atas kartu (gunakan left).

Poin penting

  • relative menjadi patokan anak absolute.
  • absolute keluar dari alur normal.
  • fixed menempel di layar, sticky menempel saat digulir.
  • z-index hanya bersaing di stacking context yang sama.
