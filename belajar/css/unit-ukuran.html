Unit ukuran

Buka versi interaktif

px adalah unit absolut. Unit relatif menyesuaikan konteks: % (persen dari induk), em (dari ukuran huruf elemen itu), rem (dari ukuran huruf root, biasanya 16px), vw/vh (persen lebar/tinggi layar), dan ch (lebar karakter "0").

Pakai rem untuk ukuran huruf agar menghormati pengaturan ukuran huruf pengguna. Fungsi calc() mencampur unit (calc(100% - 2rem)), min()/max() memilih nilai, dan clamp(min, ideal, max) membuat ukuran fleksibel dengan batas.

HTML
<div class="wadah">
  <h2>Judul fleksibel</h2>
  <p class="baca">Paragraf ini dibatasi sekitar 45 karakter per baris agar nyaman dibaca, apa pun lebar layarnya.</p>
  <div class="bar"></div>
</div>
CSS
html { font-size: 16px; }
h2 { font-size: clamp(1.25rem, 4vw, 2.5rem); }
.baca { max-width: 45ch; font-size: 1rem; }
.bar { width: calc(100% - 2rem); height: .5rem; background: #2F7A52; border-radius: 1em; }

Poin penting

  • rem untuk ukuran huruf, menghormati pengaturan pengguna.
  • % dan vw untuk lebar fleksibel.
  • calc() mencampur unit, clamp() membatasi ukuran fleksibel.
  • ch cocok untuk membatasi panjang baris.

Cek pemahaman

1.5rem bila root 16px?

Jawaban: 24px

1.5 × 16 = 24.

clamp(1rem, 4vw, 2rem) berarti?

Jawaban: 4vw, tapi tidak kurang dari 1rem dan tidak lebih dari 2rem

clamp menjaga nilai di antara batas bawah dan atas.
