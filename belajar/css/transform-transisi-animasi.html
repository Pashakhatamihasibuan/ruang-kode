Transform, transisi & animasi

Buka versi interaktif

transform menggeser (translate), memutar (rotate), dan mengubah skala (scale) tanpa mengganggu tata letak elemen lain.

transition menghaluskan perubahan nilai, misalnya saat hover: transition: transform .2s ease. @keyframes membuat animasi bertahap yang bisa berulang.

Animasikan transform dan opacity saja bila bisa, karena paling ringan untuk browser. Hormati prefers-reduced-motion.

HTML
<button class="tombol">Arahkan kursor</button>
<div class="loader" aria-label="Memuat"></div>
CSS
.tombol { padding: 10px 18px; border: 0; border-radius: 99px; background: #1C1B19; color: #fff; transition: transform .2s ease, box-shadow .2s; }
.tombol:hover { transform: translateY(-3px) scale(1.04); box-shadow: 0 8px 18px rgb(0 0 0 / 25%); }
.loader { width: 28px; height: 28px; margin-top: 16px; border: 3px solid #ddd; border-top-color: #2E5E8C; border-radius: 50%; animation: putar 1s linear infinite; }
@keyframes putar { to { transform: rotate(360deg); } }
@media (prefers-reduced-motion: reduce) { .loader { animation-duration: 3s; } }

Poin penting

  • transform tidak menggeser elemen lain.
  • transition untuk perubahan halus, keyframes untuk animasi bertahap.
  • Animasikan transform dan opacity.
  • Hormati prefers-reduced-motion.
