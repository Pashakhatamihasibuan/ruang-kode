Grid

Buka versi interaktif

Grid menata dalam dua arah sekaligus: baris dan kolom. grid-template-columns: repeat(3, 1fr) membuat tiga kolom sama lebar; fr berarti bagian dari sisa ruang.

Pola paling berguna untuk kartu produk: repeat(auto-fill, minmax(160px, 1fr)). Kolom otomatis bertambah atau berkurang sesuai lebar layar, tanpa media query.

Item bisa membentang dengan grid-column: span 2, atau ditempatkan dengan nama area lewat grid-template-areas.

HTML
<div class="galeri">
  <div class="besar">Kopi Gayo</div><div>Teh Melati</div><div>Keripik</div>
  <div>Mete</div><div>Sambal</div><div>Madu</div>
</div>
CSS
.galeri { display: grid; grid-template-columns: repeat(auto-fill, minmax(110px, 1fr)); gap: 10px; font: 13px sans-serif; }
.galeri div { background: #E9EFF5; border-radius: 10px; padding: 18px 10px; text-align: center; }
.galeri .besar { grid-column: span 2; background: #F6ECE5; }

Tantangan

  1. Buat kotak "Kopi Gayo" juga membentang 2 baris.

Poin penting

  • Grid untuk dua arah, flexbox untuk satu arah.
  • fr = bagian dari sisa ruang.
  • repeat(auto-fill, minmax(…, 1fr)) membuat galeri responsif.
  • span membentangkan item.
