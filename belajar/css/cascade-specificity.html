Cascade & specificity

Buka versi interaktif

Kalau dua aturan mengatur properti yang sama, siapa yang menang? Browser memeriksa berurutan: pentingnya (!important), lalu specificity (kekuatan selector), lalu urutan (yang ditulis belakangan menang).

Specificity dihitung sebagai tiga angka (a, b, c): a = jumlah id, b = jumlah class, atribut, dan pseudo-class, c = jumlah elemen dan pseudo-element. Bandingkan dari kiri: (1,0,0) mengalahkan (0,9,9).

Gaya inline mengalahkan semuanya kecuali !important. Hindari !important; jika butuh, biasanya selectormu terlalu rumit.

HTML
<p id="info" class="pesan penting">Warna apa saya?</p>
CSS
p { color: gray; }               /* (0,0,1) */
.pesan { color: green; }         /* (0,1,0) */
p.pesan.penting { color: blue; } /* (0,2,1) menang dari .pesan */
.pesan { color: orange; }        /* (0,1,0) kalah walau ditulis belakangan */

Tantangan

  1. Tanpa menghapus aturan yang ada, buat paragraf berwarna merah rgb(255, 0, 0) dengan selector id.

Poin penting

  • Urutan penentuan: !important, specificity, lalu urutan tulis.
  • Specificity (id, class, elemen) dibandingkan dari kiri.
  • Inline style sangat kuat; hindari !important.

Cek pemahaman

Mana yang menang: #menu a atau .nav .menu a?

Jawaban: #menu a (1,0,1)

Satu id mengalahkan berapa pun class.
