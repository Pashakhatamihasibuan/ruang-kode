Display & alur normal

Buka versi interaktif

Dalam alur normal, elemen block (div, p, h1) mengambil satu baris penuh dan tersusun ke bawah, sedangkan elemen inline (span, a, strong) mengalir di dalam baris seperti kata. Elemen inline tidak bisa diberi width/height.

inline-block mengalir seperti inline tapi bisa diberi ukuran. display: none menghapus elemen dari tata letak, sedangkan visibility: hidden menyembunyikan tapi tetap memakan ruang.

float dulu dipakai untuk tata letak, kini hanya untuk membuat teks mengalir di sekitar gambar. Untuk tata letak, pakai flexbox atau grid.

HTML
<div class="blok">blok 1</div><div class="blok">blok 2</div>
<p>Teks dengan <span class="in">inline</span> dan <span class="ib">inline-block</span> di dalam baris.</p>
<p>Kotak <span class="hilang">A</span> display none, kotak <span class="sembunyi">B</span> visibility hidden.</p>
CSS
.blok{background:#E9EFF5;margin:4px 0;padding:4px}
.in{background:#FBE7A8;width:200px}
.ib{display:inline-block;width:120px;background:#E7F2EB;text-align:center}
.hilang{display:none}.sembunyi{visibility:hidden;background:#ccc}

Poin penting

  • block satu baris penuh, inline mengalir dalam baris.
  • inline-block: dalam baris tapi bisa diberi ukuran.
  • display:none menghapus, visibility:hidden menyisakan ruang.
