:has(): selector induk & nesting

Buka versi interaktif

Selama bertahun-tahun CSS tidak bisa memilih elemen berdasarkan isinya. :has() mengubah itu: .kartu:has(img) memilih kartu yang berisi gambar, dan form:has(:invalid) memilih form yang masih punya isian salah.

Ini membuat banyak JavaScript kecil tidak diperlukan lagi, misalnya menandai label saat checkbox di dalamnya dicentang. Hati-hati memakai :has() pada elemen yang sangat umum seperti body, karena browser harus memeriksa ulang saat isinya berubah.

CSS kini juga mendukung nesting tanpa Sass: aturan untuk anak elemen ditulis di dalam blok induknya, dan & merujuk induk itu sendiri.

CSS
/* kartu dengan gambar memakai tata letak dua kolom */
.kartu:has(img) { display: grid; grid-template-columns: 120px 1fr; gap: 12px; }

/* tombol kirim redup selama ada isian yang salah */
form:has(:invalid) button[type="submit"] { opacity: .5; }

/* label ikut tersorot saat pilihannya dicentang */
.pilihan:has(input:checked) { border-color: var(--brand); background: var(--brand-soft); }

/* nesting bawaan CSS */
.menu {
  display: flex;
  & a { padding: 8px 12px; }
  & a:hover { text-decoration: underline; }
}

Poin penting

  • :has() memilih elemen berdasarkan isinya.
  • Mengganti JavaScript kecil untuk status visual.
  • Hindari :has() pada elemen sangat umum.
  • Nesting bawaan dengan & tanpa Sass.
