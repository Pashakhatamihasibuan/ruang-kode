Gambar responsif, aspect-ratio & object-fit

Buka versi interaktif

Gambar sering menjadi bagian terberat halaman. srcset dan sizes memberi browser beberapa ukuran sehingga HP tidak mengunduh gambar selebar desktop. <picture> menambahkan format modern seperti AVIF dan WebP dengan cadangan JPEG.

aspect-ratio menjaga proporsi kotak, misalnya 16/9 untuk video atau 1/1 untuk foto produk, bahkan sebelum gambar dimuat, sehingga tata letak tidak bergeser (CLS). object-fit: cover mengisi kotak tanpa membuat gambar gepeng.

Gabungkan dengan loading="lazy" untuk gambar di bawah layar, tetapi jangan untuk gambar utama di atas layar, karena justru memperlambat LCP.

HTML
<picture>
  <source type="image/avif" srcset="kopi-400.avif 400w, kopi-800.avif 800w">
  <source type="image/webp" srcset="kopi-400.webp 400w, kopi-800.webp 800w">
  <img src="kopi-800.jpg" alt="Kopi Gayo dalam kemasan 250 gram"
       srcset="kopi-400.jpg 400w, kopi-800.jpg 800w"
       sizes="(min-width: 768px) 33vw, 100vw"
       width="800" height="800" loading="lazy">
</picture>

<style>
.foto-produk {
  width: 100%;
  aspect-ratio: 1 / 1;
  object-fit: cover;
  border-radius: 12px;
}
</style>

Poin penting

  • srcset + sizes: browser memilih ukuran yang pas.
  • picture untuk AVIF/WebP dengan cadangan.
  • aspect-ratio mencegah tata letak bergeser.
  • Jangan lazy-load gambar utama di atas layar.
