Container query

Buka versi interaktif

Media query melihat lebar layar. Container query melihat lebar wadah komponen, sehingga kartu yang sama bisa tampil berbeda di sidebar sempit dan di area utama yang lebar.

Tandai wadah dengan container-type: inline-size, lalu tulis @container (min-width: 300px) { ... }. Gambar responsif cukup diberi max-width: 100% dan height: auto; object-fit: cover memotong gambar agar pas tanpa gepeng.

HTML
<div class="sempit wadah"><div class="kartu"><div class="img"></div><p>Kopi Gayo<br><b>Rp85.000</b></p></div></div>
<div class="lebar wadah"><div class="kartu"><div class="img"></div><p>Kopi Gayo<br><b>Rp85.000</b></p></div></div>
CSS
.wadah { container-type: inline-size; margin-bottom: 10px; font: 13px sans-serif; }
.sempit { width: 180px; } .lebar { width: 100%; max-width: 420px; }
.kartu { display: grid; gap: 8px; border: 1px solid #ddd; border-radius: 10px; padding: 8px; }
.img { background: linear-gradient(135deg,#B4532A,#2E5E8C); aspect-ratio: 16/9; border-radius: 6px; }
@container (min-width: 300px) {
  .kartu { grid-template-columns: 120px 1fr; align-items: center; }
}

Poin penting

  • Container query melihat lebar wadah, bukan layar.
  • container-type: inline-size menandai wadah.
  • max-width:100% dan object-fit menjaga gambar tetap rapi.
