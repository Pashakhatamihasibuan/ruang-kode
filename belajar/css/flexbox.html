Flexbox

Buka versi interaktif

Flexbox menata elemen dalam satu arah: baris atau kolom. Pasang display: flex pada induk; anak-anaknya menjadi flex item.

justify-content mengatur posisi di sumbu utama (start, center, space-between), align-items di sumbu silang, gap memberi jarak, dan flex-wrap: wrap mengizinkan pindah baris.

Pada item, flex: 1 berarti "ambil sisa ruang". Mainkan pengatur di visual, lalu coba di editor.

HTML
<nav class="bar">
  <strong>Toko Nusantara</strong>
  <div class="menu"><a href="#">Produk</a><a href="#">Promo</a><a href="#">Kontak</a></div>
  <button>Keranjang (2)</button>
</nav>
CSS
.bar { display: flex; justify-content: space-between; align-items: center; gap: 16px; padding: 10px 14px; background: #F2F1EC; border-radius: 12px; font: 14px sans-serif; flex-wrap: wrap; }
.menu { display: flex; gap: 12px; }
.menu a { color: #1C1B19; }

Tantangan

  1. Buat menu link tersusun vertikal (kolom).

Poin penting

  • display:flex pada induk.
  • justify-content = sumbu utama, align-items = sumbu silang.
  • gap untuk jarak, flex-wrap untuk pindah baris.
  • flex:1 mengambil sisa ruang.
