Selector sederhana

Buka versi interaktif

Selector elemen memilih berdasarkan nama tag (p), selector class memakai titik (.harga), selector id memakai pagar (#keranjang), dan * memilih semua elemen.

Beberapa selector bisa digabung dengan koma agar berbagi gaya: h1, h2, h3 { ... }. Selector juga bisa digabung tanpa spasi untuk syarat ganda: p.promo berarti paragraf yang punya class promo.

Kebiasaan baik: utamakan class. Hindari id untuk gaya, karena id sangat kuat dan sulit ditimpa.

HTML
<h2>Keranjang</h2>
<p class="item">Kopi Gayo <span class="harga">Rp85.000</span></p>
<p class="item habis">Rendang Kaleng <span class="harga">Rp75.000</span></p>
<p id="total">Total: Rp85.000</p>
CSS
* { box-sizing: border-box; }
h2, #total { font-family: Georgia, serif; }
.item { padding: 6px; border-bottom: 1px solid #ddd; }
.harga { float: right; font-weight: 600; }
p.habis { color: #999; text-decoration: line-through; }
#total { font-size: 20px; }

Tantangan

  1. Buat semua elemen dengan class harga berwarna hijau rgb(47, 122, 82).

Poin penting

  • .class, #id, tag, dan * adalah selector sederhana.
  • Koma mengelompokkan selector.
  • Utamakan class untuk gaya.
