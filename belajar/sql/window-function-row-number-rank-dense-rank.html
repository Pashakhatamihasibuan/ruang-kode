Window function: ROW_NUMBER, RANK, DENSE_RANK

Buka versi interaktif

Window function menghitung nilai berdasarkan sekelompok baris yang berkaitan, tetapi tidak menggabungkan baris seperti GROUP BY. Setiap baris tetap muncul, dengan kolom tambahan hasil perhitungan. Sintaksnya: fungsi() OVER (PARTITION BY ... ORDER BY ...).

PARTITION BY membagi baris menjadi kelompok (jendela), dan ORDER BY di dalam OVER menentukan urutan di setiap kelompok. ROW_NUMBER memberi nomor urut 1, 2, 3 tanpa kembar. RANK memberi peringkat yang sama untuk nilai sama lalu melompat (1, 1, 3). DENSE_RANK tidak melompat (1, 1, 2).

Pola terkenal: "ambil N teratas per kelompok", misalnya produk termahal di setiap kategori. Hitung ROW_NUMBER per kategori di CTE, lalu saring nomor 1.

Peringkat harga dalam kategori
SELECT nama, kategori, harga,
  ROW_NUMBER() OVER (PARTITION BY kategori ORDER BY harga DESC) AS no,
  RANK() OVER (PARTITION BY kategori ORDER BY harga DESC) AS peringkat
FROM produk;
RANK vs DENSE_RANK pada nilai kembar
SELECT pesanan_id, produk_id, jumlah,
  RANK() OVER (ORDER BY jumlah DESC) AS rank_,
  DENSE_RANK() OVER (ORDER BY jumlah DESC) AS dense
FROM detail_pesanan;
Termahal per kategori
WITH urut AS (
  SELECT nama, kategori, harga,
         ROW_NUMBER() OVER (PARTITION BY kategori ORDER BY harga DESC) AS no
  FROM produk
)
SELECT kategori, nama, harga FROM urut WHERE no = 1;

Tantangan

  1. Tampilkan nama karyawan, divisi, gaji, dan peringkat gaji di divisinya (alias peringkat, pakai DENSE_RANK, gaji tertinggi = 1).

Kode pemula vs kode rapi

Peringkat tanpa subquery berkorelasi

Subquery berkorelasi dijalankan ulang untuk setiap baris. Window function menghitung peringkat semua baris dalam satu kali jalan.

KODE PEMULA
SELECT nama, harga,
       (SELECT COUNT(*) FROM produk p2 WHERE p2.harga > p1.harga) + 1 AS peringkat
FROM produk p1
ORDER BY peringkat
LIMIT 4;
KODE RAPI (BEST PRACTICE)
SELECT nama, harga,
       RANK() OVER (ORDER BY harga DESC) AS peringkat
FROM produk
ORDER BY peringkat
LIMIT 4;
KELUARAN KEDUANYA
nama           | harga  | peringkat
---------------+--------+----------
Madu Hutan     | 120000 | 1
Kopi Gayo      | 85000  | 2
Rendang Kaleng | 75000  | 3
Kacang Mete    | 60000  | 4

Poin penting

  • Window function tidak mengurangi jumlah baris.
  • OVER (PARTITION BY ... ORDER BY ...).
  • ROW_NUMBER unik; RANK melompat; DENSE_RANK rapat.
  • Top-N per kelompok: ROW_NUMBER di CTE, lalu WHERE no <= N.

Cek pemahaman

Nilai 100, 100, 90 dengan RANK menghasilkan?

Jawaban: 1, 1, 3

RANK melompat setelah nilai kembar.

Perbedaan GROUP BY dengan window function?

Jawaban: GROUP BY menggabungkan baris; window tetap mempertahankan setiap baris

Window menambah kolom tanpa menghilangkan baris.
