Query rekursif

Buka versi interaktif

WITH RECURSIVE membuat CTE yang memanggil dirinya sendiri, cocok untuk data berbentuk hierarki atau pohon: struktur organisasi, kategori bertingkat, atau rute.

Bentuknya selalu dua bagian yang digabung UNION ALL. Anchor adalah titik awal (misalnya direktur yang tidak punya atasan). Bagian rekursif men-JOIN tabel dengan hasil putaran sebelumnya untuk menemukan tingkat berikutnya. Proses berulang sampai putaran baru tidak menghasilkan baris lagi.

Pastikan ada kondisi berhenti. Tanpa itu, rekursi bisa berjalan tanpa akhir; simulator ini menghentikannya setelah 1000 putaran.

Deret angka 1 sampai 10
WITH RECURSIVE angka(n) AS (
  SELECT 1
  UNION ALL
  SELECT n + 1 FROM angka WHERE n < 10
)
SELECT n FROM angka;
Struktur organisasi
WITH RECURSIVE bagan AS (
  SELECT id, nama, jabatan, 0 AS tingkat, nama AS jalur
  FROM karyawan WHERE atasan_id IS NULL
  UNION ALL
  SELECT k.id, k.nama, k.jabatan, b.tingkat + 1, b.jalur || ' > ' || k.nama
  FROM karyawan k JOIN bagan b ON k.atasan_id = b.id
)
SELECT tingkat, nama, jabatan, jalur FROM bagan ORDER BY jalur;
Kalender 7 hari
WITH RECURSIVE hari(t) AS (
  SELECT '2024-11-01'
  UNION ALL
  SELECT DATE(t, '+1 day') FROM hari WHERE t < '2024-11-07'
)
SELECT t, STRFTIME('%w', t) AS hari_ke FROM hari;

Tantangan

  1. Dengan WITH RECURSIVE, tampilkan nama semua bawahan (langsung maupun tidak langsung) dari Umi (id 3). Satu kolom: nama.

Poin penting

  • Anchor UNION ALL bagian rekursif.
  • Bagian rekursif men-JOIN hasil putaran sebelumnya.
  • Berhenti saat putaran tidak menghasilkan baris.
  • Cocok untuk pohon dan hierarki.
