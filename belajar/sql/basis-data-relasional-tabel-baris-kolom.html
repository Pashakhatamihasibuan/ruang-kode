Basis data relasional: tabel, baris, kolom

Buka versi interaktif

Basis data adalah kumpulan data yang tersimpan rapi dan bisa dicari dengan cepat. Basis data relasional menyimpan data dalam tabel, mirip lembar kerja spreadsheet. Setiap kolom punya nama dan tipe data, dan setiap baris adalah satu catatan, misalnya satu pelanggan.

Kata "relasional" berasal dari hubungan antartabel. Tabel pesanan tidak menyalin nama pelanggan, melainkan menyimpan pelanggan_id yang menunjuk ke tabel pelanggan. Data jadi tidak berulang dan mudah diperbarui.

SQL (Structured Query Language) adalah bahasa untuk berbicara dengan basis data relasional seperti PostgreSQL, MySQL, SQLite, SQL Server, dan Oracle. Di kursus ini kamu memakai Toko Nusantara, database contoh yang berjalan langsung di browser. Coba jalankan query di bawah.

Lihat semua pelanggan
SELECT * FROM pelanggan;
Lihat semua produk
SELECT * FROM produk;
Pesanan yang sudah masuk
SELECT * FROM pesanan;

Tantangan

  1. Tampilkan seluruh isi tabel karyawan.

Poin penting

  • Tabel = kumpulan baris dengan kolom yang sama.
  • Baris = satu catatan (record); kolom = satu atribut (field).
  • Relasi dibuat dengan menyimpan id tabel lain.
  • SQL dipakai hampir di semua basis data relasional.
