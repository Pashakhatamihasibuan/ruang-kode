CASE, COALESCE & NULLIF

Buka versi interaktif

CASE adalah if-else di dalam SQL. Bentuknya CASE WHEN kondisi THEN nilai ... ELSE nilai END. Ia bisa dipakai di SELECT untuk membuat label, di ORDER BY untuk urutan khusus, bahkan di dalam SUM untuk menghitung bersyarat.

COALESCE(a, b, c) mengembalikan nilai pertama yang tidak NULL. Sangat berguna untuk memberi nilai cadangan: COALESCE(kota, 'Belum diisi').

NULLIF(a, b) mengembalikan NULL jika a sama dengan b. Trik klasiknya mencegah pembagian dengan nol: total / NULLIF(jumlah, 0).

Label dengan CASE
SELECT nama, harga,
  CASE WHEN harga >= 75000 THEN 'premium'
       WHEN harga >= 30000 THEN 'menengah'
       ELSE 'hemat' END AS kelas
FROM produk;
Menghitung bersyarat
SELECT COUNT(*) AS semua,
  SUM(CASE WHEN status = 'selesai' THEN 1 ELSE 0 END) AS selesai,
  SUM(CASE WHEN status = 'batal' THEN 1 ELSE 0 END) AS batal
FROM pesanan;
COALESCE
SELECT nama, COALESCE(kota, 'Belum diisi') AS kota FROM pelanggan;
NULLIF mencegah bagi nol
SELECT nama, stok, harga / NULLIF(stok, 0) AS harga_per_stok FROM produk;

Tantangan

  1. Tampilkan nama produk dan status stok (alias status_stok): 'habis' jika stok 0, 'menipis' jika stok di bawah 50, selain itu 'aman'.

Kode pemula vs kode rapi

Nilai cadangan untuk NULL

COALESCE mengambil nilai pertama yang tidak NULL. Lebih pendek dari CASE WHEN ... IS NULL.

KODE PEMULA
SELECT nama,
       CASE WHEN kota IS NULL THEN 'Belum diisi' ELSE kota END AS kota
FROM pelanggan
ORDER BY id
LIMIT 4;
KODE RAPI (BEST PRACTICE)
SELECT nama, COALESCE(kota, 'Belum diisi') AS kota
FROM pelanggan
ORDER BY id
LIMIT 4;
KELUARAN KEDUANYA
nama  | kota
------+---------
Andi  | Jakarta
Budi  | Bandung
Citra | Surabaya
Dewi  | Jakarta

Poin penting

  • CASE WHEN ... THEN ... ELSE ... END.
  • Kondisi dicek berurutan; yang pertama benar dipakai.
  • COALESCE = nilai cadangan untuk NULL.
  • NULLIF(x, 0) mencegah pembagian dengan nol.
