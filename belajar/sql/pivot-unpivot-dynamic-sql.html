Pivot, unpivot & dynamic SQL

Buka versi interaktif

Pivot memutar baris menjadi kolom, misalnya dari daftar "status per pesanan" menjadi satu baris berisi jumlah pesanan baru, dikirim, selesai, dan batal. SQL Server dan Oracle punya operator PIVOT, tetapi cara yang bekerja di semua database adalah agregasi bersyarat: SUM(CASE WHEN ... THEN 1 ELSE 0 END) untuk setiap kolom.

Unpivot adalah kebalikannya: kolom-kolom diubah menjadi baris, biasanya dengan beberapa SELECT yang digabung UNION ALL.

Dynamic SQL adalah query yang teksnya disusun saat program berjalan, misalnya ketika daftar kolom pivot baru diketahui saat itu. Ia dijalankan dengan EXECUTE (PostgreSQL), sp_executesql (SQL Server), atau PREPARE (MySQL). Dynamic SQL sangat rawan SQL injection, jadi nilai dari pengguna wajib dikirim sebagai parameter, dan nama kolom atau tabel harus divalidasi terhadap daftar yang diizinkan.

Pivot: status pesanan menjadi kolom
SELECT
  SUM(CASE WHEN status = 'baru' THEN 1 ELSE 0 END) AS baru,
  SUM(CASE WHEN status = 'dikirim' THEN 1 ELSE 0 END) AS dikirim,
  SUM(CASE WHEN status = 'selesai' THEN 1 ELSE 0 END) AS selesai,
  SUM(CASE WHEN status = 'batal' THEN 1 ELSE 0 END) AS batal
FROM pesanan;
Pivot per bulan
SELECT strftime('%Y-%m', tanggal) AS bulan,
  SUM(CASE WHEN status = 'selesai' THEN 1 ELSE 0 END) AS selesai,
  SUM(CASE WHEN status <> 'selesai' THEN 1 ELSE 0 END) AS lainnya
FROM pesanan GROUP BY bulan;
Unpivot: kolom menjadi baris
SELECT nama, 'harga' AS atribut, harga AS nilai FROM produk WHERE id = 1
UNION ALL
SELECT nama, 'stok', stok FROM produk WHERE id = 1;

Tantangan

  1. Buat pivot dari tabel produk: satu baris dengan kolom minuman, camilan, dan lainnya berisi jumlah produk di setiap kelompok (lainnya = selain Minuman dan Camilan).

Soal latihan

  1. Buat pivot jumlah karyawan per divisi menjadi satu baris (kolom gudang, penjualan, pusat).

    Petunjuk

    SUM(CASE WHEN divisi = ... THEN 1 ELSE 0 END).

    Lihat jawaban
    SQL
    SELECT
  SUM(CASE WHEN divisi = 'Gudang' THEN 1 ELSE 0 END) AS gudang,
  SUM(CASE WHEN divisi = 'Penjualan' THEN 1 ELSE 0 END) AS penjualan,
  SUM(CASE WHEN divisi = 'Pusat' THEN 1 ELSE 0 END) AS pusat
FROM karyawan;
    KELUARAN
    gudang | penjualan | pusat
-------+-----------+------
3      | 4         | 1

  2. Unpivot data Madu Hutan: ubah kolom harga dan stok menjadi baris (atribut, nilai).

    Petunjuk

    Dua SELECT digabung UNION ALL.

    Lihat jawaban
    SQL
    SELECT nama, 'harga' AS atribut, harga AS nilai FROM produk WHERE nama = 'Madu Hutan'
UNION ALL
SELECT nama, 'stok', stok FROM produk WHERE nama = 'Madu Hutan';
    KELUARAN
    nama       | atribut | nilai
-----------+---------+-------
Madu Hutan | harga   | 120000
Madu Hutan | stok    | 15

Poin penting

  • Pivot portabel: SUM(CASE WHEN ...) per kolom.
  • Unpivot: UNION ALL beberapa SELECT.
  • Dynamic SQL = teks query disusun saat runtime.
  • Dynamic SQL wajib memakai parameter dan whitelist.
