Operator

Buka versi interaktif

SQL punya operator aritmetika (+ - * / %), perbandingan (= <> != < > <= >=), logika (AND, OR, NOT), dan penyambung teks || (di MySQL memakai fungsi CONCAT).

Ada juga operator khusus yang sangat sering dipakai: BETWEEN a AND b untuk rentang (termasuk kedua ujung), IN (...) untuk daftar pilihan, LIKE untuk pola teks dengan % (apa saja) dan _ (satu karakter), serta IS NULL.

Perhatikan prioritas: AND dikerjakan sebelum OR. Selalu pakai kurung saat mencampur keduanya agar maksudmu jelas. Dan ingat, = NULL tidak pernah benar; gunakan IS NULL.

Aritmetika: nilai stok
SELECT nama, harga, stok, harga * stok AS nilai_stok FROM produk;
Perbandingan & logika
SELECT nama, kategori, harga FROM produk
WHERE (kategori = 'Minuman' OR kategori = 'Camilan') AND harga < 50000;
BETWEEN, IN, LIKE
SELECT nama, harga FROM produk
WHERE harga BETWEEN 20000 AND 90000
  AND kategori IN ('Minuman', 'Bumbu')
  AND nama LIKE '%a%';
NULL perlu IS NULL
SELECT nama FROM pelanggan WHERE kota IS NULL;

Tantangan

  1. Tampilkan nama dan harga produk yang namanya diawali huruf K dan harganya kurang dari 50000.

Poin penting

  • AND sebelum OR; pakai kurung.
  • BETWEEN termasuk kedua batas.
  • LIKE: % = apa saja, _ = satu karakter.
  • NULL dibandingkan dengan IS NULL / IS NOT NULL.
