UPDATE & DELETE

Buka versi interaktif

UPDATE tabel SET kolom = nilai WHERE kondisi mengubah baris yang memenuhi kondisi. Nilai baru boleh berupa rumus dari nilai lama, misalnya menaikkan harga 10%: SET harga = harga * 1.1.

DELETE FROM tabel WHERE kondisi menghapus baris. Peringatan terbesar di SQL: tanpa WHERE, UPDATE dan DELETE mengenai semua baris. Kebiasaan aman: jalankan dulu SELECT dengan WHERE yang sama untuk melihat baris mana yang akan terkena, baru ubah menjadi UPDATE atau DELETE.

Database juga menjaga relasi. Menghapus pelanggan yang masih punya pesanan akan ditolak oleh foreign key, kecuali tabelnya dibuat dengan ON DELETE CASCADE.

Cek dulu dengan SELECT
SELECT nama, harga FROM produk WHERE kategori = 'Minuman';
Lalu UPDATE
UPDATE produk SET harga = harga + 5000 WHERE kategori = 'Minuman';
SELECT nama, harga FROM produk WHERE kategori = 'Minuman';
Ubah beberapa kolom
UPDATE pesanan SET status = 'selesai' WHERE id = 107;
SELECT * FROM pesanan WHERE id = 107;
DELETE yang ditolak foreign key
DELETE FROM pelanggan WHERE id = 1;
DELETE yang aman
DELETE FROM detail_pesanan WHERE pesanan_id = 105;
SELECT COUNT(*) AS sisa FROM detail_pesanan;

Tantangan

  1. Ubah stok produk Rendang Kaleng menjadi 25.

Poin penting

  • Selalu tulis WHERE pada UPDATE dan DELETE.
  • Uji dengan SELECT sebelum mengubah.
  • Nilai baru boleh rumus dari nilai lama.
  • Foreign key melindungi data yang masih dirujuk.
