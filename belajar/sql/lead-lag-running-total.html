LEAD, LAG & running total

Buka versi interaktif

LAG(kolom) mengambil nilai dari baris sebelumnya di jendela, dan LEAD(kolom) dari baris berikutnya. Keduanya sangat berguna untuk membandingkan baris dengan tetangganya: selisih penjualan bulan ini dengan bulan lalu, atau jarak hari antarpesanan.

Parameter kedua adalah jarak (default 1), dan parameter ketiga nilai cadangan jika tidak ada baris tetangga: LAG(harga, 1, 0).

Fungsi agregat juga bisa dipakai sebagai window function. SUM(x) OVER (ORDER BY tanggal) menghasilkan running total (total berjalan), dan dengan PARTITION BY total berjalan dihitung ulang untuk setiap kelompok.

Pesanan sebelumnya & berikutnya
SELECT id, tanggal,
  LAG(tanggal) OVER (ORDER BY tanggal) AS sebelumnya,
  LEAD(tanggal) OVER (ORDER BY tanggal) AS berikutnya
FROM pesanan;
Jarak hari dari pesanan sebelumnya per pelanggan
SELECT pelanggan_id, id, tanggal,
  JULIANDAY(tanggal) - JULIANDAY(LAG(tanggal) OVER (PARTITION BY pelanggan_id ORDER BY tanggal)) AS jarak_hari
FROM pesanan ORDER BY pelanggan_id, tanggal;
Running total item terjual
SELECT s.tanggal, SUM(d.jumlah) AS item,
  SUM(SUM(d.jumlah)) OVER (ORDER BY s.tanggal) AS kumulatif
FROM pesanan s JOIN detail_pesanan d ON d.pesanan_id = s.id
GROUP BY s.tanggal ORDER BY s.tanggal;

Tantangan

  1. Tampilkan id, tanggal, dan id pesanan sebelumnya (alias id_sebelumnya, pakai LAG dengan nilai cadangan 0) dari tabel pesanan, urut berdasarkan tanggal.

Poin penting

  • LAG = baris sebelumnya, LEAD = baris berikutnya.
  • LAG(kolom, jarak, cadangan).
  • SUM(...) OVER (ORDER BY ...) = running total.
  • PARTITION BY untuk menghitung ulang per kelompok.
