ACID & tingkat isolasi

Buka versi interaktif

Transaksi yang baik memenuhi ACID. Atomicity: semua atau tidak sama sekali. Consistency: data selalu berpindah dari keadaan valid ke keadaan valid, semua constraint terpenuhi. Isolation: transaksi yang berjalan bersamaan tidak saling mengacaukan. Durability: setelah COMMIT, data bertahan meski server mati.

Isolasi sempurna itu mahal, jadi database menawarkan beberapa tingkat isolasi. Dari yang paling longgar: READ UNCOMMITTED (bisa membaca data yang belum di-commit, disebut dirty read), READ COMMITTED (default PostgreSQL), REPEATABLE READ (default MySQL InnoDB), dan SERIALIZABLE (paling ketat, seolah transaksi berjalan bergiliran).

Semakin ketat, semakin sedikit anomali (dirty read, non-repeatable read, phantom read), tetapi semakin besar kemungkinan transaksi saling menunggu atau dibatalkan. Simulator ini berjalan untuk satu pengguna, jadi bagian ini dipelajari lewat visualisasi dan contoh sintaks.

Atomicity: satu gagal, semua batal
BEGIN;
UPDATE rekening SET saldo = saldo + 100000 WHERE id = 2;
UPDATE rekening SET saldo = saldo - 900000 WHERE id = 1;
-- perintah kedua melanggar CHECK (saldo >= 0)
ROLLBACK;
SELECT * FROM rekening;

Poin penting

  • ACID: Atomicity, Consistency, Isolation, Durability.
  • Empat tingkat isolasi: READ UNCOMMITTED → SERIALIZABLE.
  • Anomali: dirty read, non-repeatable read, phantom read.
  • Lebih ketat = lebih aman, tetapi lebih banyak saling tunggu.
