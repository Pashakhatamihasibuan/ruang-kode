Fungsi tanggal & waktu

Buka versi interaktif

Setiap database punya fungsi tanggal sendiri. Di SQLite (dan simulator ini) tanggal disimpan sebagai teks ISO YYYY-MM-DD, lalu diolah dengan DATE, TIME, DATETIME/TIMESTAMP, dan STRFTIME. Contoh: DATE('2024-10-28', '+7 days').

SQL Server memakai DATEADD(day, 7, tanggal) untuk menambah dan DATEPART(month, tanggal) untuk mengambil bagian tanggal. PostgreSQL memakai tanggal + INTERVAL '7 days' dan EXTRACT(MONTH FROM tanggal). Simulator ini juga menerima DATEADD, DATEPART, DATEDIFF, dan EXTRACT supaya kamu bisa mencoba gaya-gaya itu.

Tanggal ISO bisa dibandingkan dan diurutkan seperti teks biasa karena urutannya tahun, bulan, lalu hari. Itu sebabnya format ini sangat dianjurkan.

Gaya SQLite
SELECT DATE('2024-10-28', '+7 days') AS seminggu,
       DATE('2024-10-28', 'start of month') AS awal_bulan,
       STRFTIME('%d/%m/%Y', '2024-10-28') AS format_indo;
Gaya SQL Server: DATEADD & DATEPART
SELECT id, tanggal,
       DATEADD(day, 3, tanggal) AS estimasi_tiba,
       DATEPART(month, tanggal) AS bulan
FROM pesanan;
Selisih hari & EXTRACT
SELECT nama, bergabung,
       DATEDIFF(day, bergabung, '2024-12-31') AS hari_menjadi_member,
       EXTRACT(YEAR FROM bergabung) AS tahun
FROM pelanggan;
Waktu sekarang
SELECT CURRENT_DATE AS hari_ini, CURRENT_TIMESTAMP AS sekarang;

Tantangan

  1. Tampilkan id pesanan dan tanggal jatuh tempo (alias jatuh_tempo) yaitu 14 hari setelah tanggal pesanan, untuk pesanan berstatus baru.

Poin penting

  • Simpan tanggal dalam format ISO.
  • SQLite: DATE/STRFTIME dengan pengubah teks.
  • SQL Server: DATEADD, DATEPART, DATEDIFF.
  • PostgreSQL: INTERVAL dan EXTRACT.
