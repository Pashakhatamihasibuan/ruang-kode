GRANT, REVOKE & SQL injection

Buka versi interaktif

Prinsip hak akses minimum (least privilege): setiap pengguna dan aplikasi hanya diberi izin yang benar-benar diperlukan. GRANT SELECT ON produk TO kasir memberi izin membaca, REVOKE mencabutnya. Aplikasi web sebaiknya tidak memakai akun admin database.

Ancaman paling terkenal adalah SQL injection: input pengguna disambung langsung ke teks query, sehingga penyerang bisa menyisipkan perintah SQL sendiri. Input ' OR '1'='1 di form login bisa membuat kondisi WHERE selalu benar. Visualisasi di bawah memperlihatkan bagaimana query berubah.

Pertahanannya: selalu pakai parameterized query / prepared statement (tanda ? atau $1), validasi input, batasi hak akses, enkripsi data sensitif, simpan password sebagai hash, dan cadangkan database secara rutin. Integritas data juga dijaga oleh constraint yang sudah kamu pelajari.

GRANT dan REVOKE (disimulasikan)
GRANT SELECT, INSERT ON pesanan TO kasir;
REVOKE INSERT ON pesanan FROM kasir;
Inilah yang terjadi saat input disambung mentah-mentah
-- input pengguna: ' OR '1'='1
SELECT * FROM pelanggan WHERE nama = '' OR '1'='1';

Poin penting

  • Least privilege: beri izin seperlunya.
  • GRANT memberi, REVOKE mencabut.
  • Jangan pernah menyambung input ke query; pakai parameter.
  • Hash password, enkripsi data sensitif, backup rutin.
