GROUP BY

Buka versi interaktif

GROUP BY membagi baris menjadi kelompok berdasarkan nilai kolom tertentu, lalu fungsi agregat dihitung per kelompok. Misalnya jumlah produk per kategori, atau total belanja per pelanggan.

Aturan emas: setiap kolom di SELECT harus berupa kolom yang ada di GROUP BY, atau dibungkus fungsi agregat. PostgreSQL menolak query yang melanggar aturan ini, sedangkan SQLite dan MySQL lama diam-diam mengambil nilai dari baris sembarang. Jangan bergantung pada perilaku itu.

Kamu bisa mengelompokkan berdasarkan beberapa kolom, atau berdasarkan ekspresi seperti bulan dari tanggal.

Jumlah produk per kategori
SELECT kategori, COUNT(*) AS jumlah, SUM(stok) AS total_stok
FROM produk GROUP BY kategori;
Pesanan per pelanggan
SELECT pelanggan_id, COUNT(*) AS banyak_pesanan
FROM pesanan GROUP BY pelanggan_id ORDER BY banyak_pesanan DESC;
Per bulan
SELECT strftime('%Y-%m', tanggal) AS bulan, COUNT(*) AS pesanan
FROM pesanan GROUP BY bulan ORDER BY bulan;
Dua kolom
SELECT pelanggan_id, status, COUNT(*) AS n FROM pesanan
GROUP BY pelanggan_id, status ORDER BY pelanggan_id;

Tantangan

  1. Tampilkan setiap status pesanan beserta banyaknya pesanan (kolom status dan jumlah).

Poin penting

  • GROUP BY = satu baris hasil per kelompok.
  • Kolom SELECT: ada di GROUP BY atau di dalam agregat.
  • Boleh mengelompokkan dengan ekspresi.
  • ORDER BY tetap diperlukan untuk urutan.
