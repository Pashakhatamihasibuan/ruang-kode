SELECT & FROM

Buka versi interaktif

SELECT memilih kolom apa yang ingin ditampilkan, dan FROM menentukan dari tabel mana. SELECT * berarti semua kolom. Di aplikasi sungguhan, sebutkan kolom yang dibutuhkan saja agar data yang dikirim lebih sedikit.

Kolom bisa diberi nama baru dengan AS (alias), dan kamu bisa menampilkan hasil perhitungan, bukan hanya kolom mentah. Tabel juga bisa diberi alias pendek, misalnya FROM produk p, yang sangat berguna saat query melibatkan banyak tabel.

SELECT tidak mengubah data sama sekali. Ia hanya membaca dan menghasilkan tabel hasil (result set). Jadi silakan bereksperimen sebebasnya.

Pilih kolom tertentu
SELECT nama, kategori FROM produk;
Alias kolom dan perhitungan
SELECT nama AS produk, harga, harga * 1.11 AS harga_dengan_pajak FROM produk;
Alias tabel
SELECT p.nama, p.stok FROM produk AS p;
Tanpa tabel: SQL sebagai kalkulator
SELECT 85000 * 3 AS total, 'Toko ' || 'Nusantara' AS nama;

Tantangan

  1. Tampilkan nama pelanggan dengan alias pembeli, dan kotanya dengan alias asal.

Kode pemula vs kode rapi

Sebutkan kolom yang dibutuhkan

SELECT * praktis saat menjelajah, tetapi di aplikasi sebaiknya kolom disebutkan. Data yang dikirim lebih sedikit, dan query tidak berubah perilaku diam-diam saat tabel mendapat kolom baru.

KODE PEMULA
SELECT * FROM produk ORDER BY harga DESC LIMIT 3;
KODE RAPI (BEST PRACTICE)
SELECT nama, harga FROM produk ORDER BY harga DESC LIMIT 3;

Poin penting

  • SELECT = kolom apa, FROM = tabel mana.
  • Hindari SELECT * di aplikasi produksi.
  • AS memberi alias kolom atau tabel.
  • SELECT hanya membaca, tidak mengubah data.
