CTE: WITH

Buka versi interaktif

CTE (Common Table Expression) memberi nama pada sebuah query sementara dengan WITH nama AS (SELECT ...), lalu nama itu bisa dipakai seperti tabel di query utama. CTE hanya hidup selama satu statement.

Kegunaan utamanya keterbacaan: query panjang dipecah menjadi langkah-langkah bernama yang dibaca dari atas ke bawah, seperti resep. Satu WITH bisa berisi beberapa CTE yang dipisah koma, dan CTE belakangan boleh memakai CTE sebelumnya.

Bandingkan dengan subquery bersarang yang harus dibaca dari dalam ke luar. CTE biasanya jauh lebih mudah dipahami, terutama oleh rekan tim.

Satu CTE
WITH total_per_pesanan AS (
  SELECT pesanan_id, SUM(jumlah) AS item FROM detail_pesanan GROUP BY pesanan_id
)
SELECT * FROM total_per_pesanan WHERE item >= 5 ORDER BY item DESC;
Beberapa CTE berantai
WITH nilai AS (
  SELECT s.pelanggan_id, SUM(d.jumlah * pr.harga) AS total
  FROM pesanan s
  JOIN detail_pesanan d ON d.pesanan_id = s.id
  JOIN produk pr ON pr.id = d.produk_id
  WHERE s.status <> 'batal'
  GROUP BY s.pelanggan_id
), rata AS (
  SELECT AVG(total) AS r FROM nilai
)
SELECT p.nama, n.total
FROM nilai n JOIN pelanggan p ON p.id = n.pelanggan_id, rata
WHERE n.total > rata.r
ORDER BY n.total DESC;

Tantangan

  1. Dengan CTE bernama stok_kategori yang berisi kategori dan SUM(stok) AS total, tampilkan kategori yang total stoknya di atas 100.

Poin penting

  • WITH nama AS (query) SELECT ... FROM nama.
  • Beberapa CTE dipisah koma.
  • CTE hanya berlaku untuk satu statement.
  • Pilih CTE demi keterbacaan.
