INSERT: menambah baris

Buka versi interaktif

INSERT INTO tabel (kolom, ...) VALUES (nilai, ...) menambah baris baru. Sebutkan nama kolom secara eksplisit: urutan nilai mengikuti urutan kolom yang kamu tulis, dan kolom yang tidak disebut akan memakai nilai DEFAULT atau NULL.

Satu INSERT bisa menambah banyak baris sekaligus dengan beberapa kelompok VALUES yang dipisah koma. Kamu juga bisa menyalin hasil query ke tabel lain dengan INSERT INTO ... SELECT ....

Kolom id INTEGER PRIMARY KEY terisi otomatis jika dikosongkan. Di PostgreSQL ini disebut SERIAL/IDENTITY, di MySQL AUTO_INCREMENT. Database akan menolak data yang melanggar aturan tabel, misalnya NOT NULL atau CHECK.

Tambah satu produk
INSERT INTO produk (nama, kategori, harga, stok)
VALUES ('Gula Aren', 'Bumbu', 18000, 60);
SELECT * FROM produk WHERE nama = 'Gula Aren';
Tambah beberapa baris sekaligus
INSERT INTO pelanggan (nama, kota, bergabung) VALUES
  ('Indra', 'Makassar', '2024-10-01'),
  ('Joko', 'Semarang', '2024-10-05');
SELECT * FROM pelanggan ORDER BY id DESC LIMIT 2;
Ditolak: nama wajib diisi
INSERT INTO produk (kategori, harga) VALUES ('Minuman', 10000);

Tantangan

  1. Tambahkan pelanggan baru bernama Kiki dari Malang yang bergabung tanggal 2024-11-20.

Soal latihan

  1. Tambahkan dua produk sekaligus: Gula Aren (Bumbu, 22.000, stok 60) dan Kopi Toraja (Minuman, 95.000, stok 25), lalu tampilkan produk id 9 dan 10.

    Petunjuk

    Satu INSERT dengan beberapa kelompok VALUES.

    Lihat jawaban
    SQL
    INSERT INTO produk (id, nama, kategori, harga, stok) VALUES
  (9, 'Gula Aren', 'Bumbu', 22000, 60),
  (10, 'Kopi Toraja', 'Minuman', 95000, 25);
SELECT id, nama, harga FROM produk WHERE id >= 9;
    KELUARAN
    id | nama        | harga
---+-------------+------
9  | Gula Aren   | 22000
10 | Kopi Toraja | 95000

  2. Tambahkan pesanan baru id 120 untuk pelanggan 5 tanggal 2024-12-01 tanpa menyebut status, lalu lihat status bawaannya.

    Petunjuk

    Kolom yang tidak diisi memakai DEFAULT.

    Lihat jawaban
    SQL
    INSERT INTO pesanan (id, pelanggan_id, tanggal) VALUES (120, 5, '2024-12-01');
SELECT id, status FROM pesanan WHERE id = 120;
    KELUARAN
    id  | status
----+-------
120 | baru

Poin penting

  • Selalu sebutkan daftar kolom.
  • Kolom yang tidak disebut memakai DEFAULT/NULL.
  • Banyak baris: VALUES (...), (...).
  • INSERT INTO ... SELECT menyalin data.

Cek pemahaman

Kolom stok tidak disebut saat INSERT dan punya DEFAULT 0. Nilainya?

Jawaban: 0

DEFAULT dipakai.

Kenapa sebaiknya menyebut nama kolom di INSERT?

Jawaban: Agar tidak rusak jika urutan atau jumlah kolom tabel berubah

Query jadi tahan perubahan skema.
