Stored procedure & function

Buka versi interaktif

Stored procedure adalah kumpulan perintah SQL yang disimpan di dalam database dengan sebuah nama, bisa menerima parameter, dan dipanggil dengan CALL nama(...). Function mirip, tetapi mengembalikan nilai dan bisa dipakai di dalam SELECT.

Kelebihannya: logika yang dipakai banyak aplikasi tersimpan di satu tempat, lebih sedikit bolak-balik jaringan, dan hak akses bisa diberikan ke procedure tanpa membuka tabelnya. Kekurangannya: lebih sulit dites, di-version control, dan dipindah antar jenis database.

Sintaksnya sangat berbeda antar database (PL/pgSQL di PostgreSQL, T-SQL di SQL Server, dan versi MySQL). SQLite tidak punya stored procedure, sehingga bagian ini disajikan sebagai contoh untuk dibaca. Di simulator, kamu bisa meniru function sederhana memakai view atau ekspresi.

Meniru "function" dengan ekspresi di view
CREATE VIEW v_harga_pajak AS
SELECT nama, harga, ROUND(harga * 1.11) AS harga_pajak FROM produk;
SELECT * FROM v_harga_pajak WHERE harga_pajak > 50000;
Simulator menolak CREATE PROCEDURE
CREATE PROCEDURE tambah_stok() BEGIN END;

Poin penting

  • Procedure dipanggil dengan CALL; function dipakai di SELECT.
  • Logika terpusat di database.
  • Sulit dites dan tidak portabel antar database.
  • Sintaks berbeda tiap database.
