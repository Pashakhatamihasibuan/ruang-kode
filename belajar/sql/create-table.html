CREATE TABLE

Buka versi interaktif

CREATE TABLE membuat tabel baru: nama tabel, lalu daftar kolom beserta tipe data dan aturannya. Perintah yang mengatur struktur seperti ini disebut DDL (Data Definition Language).

Rancang tabel dengan hati-hati: beri setiap tabel primary key, pilih tipe data yang tepat, dan tambahkan aturan (constraint) untuk menjaga data tetap benar sejak awal. Memperbaiki data yang terlanjur kotor jauh lebih mahal.

CREATE TABLE IF NOT EXISTS tidak error jika tabel sudah ada. CREATE TABLE baru AS SELECT ... membuat tabel dari hasil query, berguna untuk salinan atau laporan.

Buat tabel kategori
CREATE TABLE kategori (
  id INTEGER PRIMARY KEY,
  nama TEXT NOT NULL UNIQUE,
  aktif INTEGER DEFAULT 1
);
INSERT INTO kategori (nama) VALUES ('Minuman'), ('Camilan');
SELECT * FROM kategori;
Tabel dari hasil query
CREATE TABLE produk_mahal AS
SELECT nama, harga FROM produk WHERE harga > 70000;
SELECT * FROM produk_mahal;

Tantangan

  1. Buat tabel ulasan dengan kolom id (INTEGER PRIMARY KEY), produk_id (INTEGER), bintang (INTEGER), dan komentar (TEXT). Lalu tambahkan satu ulasan: produk 1, bintang 5, komentar Mantap.

Poin penting

  • CREATE TABLE nama (kolom tipe aturan, ...).
  • Setiap tabel butuh primary key.
  • IF NOT EXISTS mencegah error tabel ganda.
  • CREATE TABLE ... AS SELECT menyalin hasil query.
