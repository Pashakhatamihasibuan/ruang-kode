ORDER BY, LIMIT & DISTINCT

Buka versi interaktif

ORDER BY mengurutkan hasil. Default-nya naik (ASC), tambahkan DESC untuk turun. Kamu bisa mengurutkan dengan beberapa kolom: kolom kedua dipakai ketika nilai kolom pertama sama. Tanpa ORDER BY, urutan hasil tidak dijamin.

LIMIT n membatasi jumlah baris, dan OFFSET m melewati m baris pertama. Pasangan ini dipakai untuk "10 produk termahal" atau paginasi halaman 2, 3, dan seterusnya. SQL Server memakai TOP n atau OFFSET ... FETCH.

DISTINCT membuang baris hasil yang kembar, misalnya untuk melihat daftar kota tanpa pengulangan.

Termahal ke termurah
SELECT nama, harga FROM produk ORDER BY harga DESC;
Urut dua kolom
SELECT nama, kategori, harga FROM produk ORDER BY kategori, harga DESC;
Tiga teratas
SELECT nama, stok FROM produk ORDER BY stok DESC LIMIT 3;
Halaman kedua (2 per halaman)
SELECT id, nama FROM pelanggan ORDER BY id LIMIT 2 OFFSET 2;
Kota tanpa duplikat
SELECT DISTINCT kota FROM pelanggan ORDER BY kota;

Tantangan

  1. Tampilkan nama dan tanggal bergabung dari 3 pelanggan yang paling baru bergabung, urut dari yang terbaru.

Poin penting

  • ASC naik (default), DESC turun.
  • Tanpa ORDER BY, urutan tidak dijamin.
  • LIMIT/OFFSET untuk top-N dan paginasi.
  • DISTINCT membuang baris kembar.
