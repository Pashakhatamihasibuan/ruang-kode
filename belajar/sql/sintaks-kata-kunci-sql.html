Sintaks & kata kunci SQL

Buka versi interaktif

Perintah SQL disebut statement dan biasanya diakhiri titik koma. Setiap statement disusun dari kata kunci (keyword) seperti SELECT, FROM, WHERE, nama tabel dan kolom, nilai, serta operator.

Kata kunci tidak peka huruf besar-kecil: select sama dengan SELECT. Konvensi umum adalah menulis kata kunci dengan huruf besar agar mudah dibedakan dari nama tabel. Teks (string) diapit kutip tunggal: 'Jakarta'. Komentar ditulis dengan -- untuk satu baris.

Kata kunci SQL terbagi menjadi beberapa kelompok: DQL untuk membaca data (SELECT), DML untuk mengubah data (INSERT, UPDATE, DELETE), DDL untuk struktur (CREATE, ALTER, DROP), DCL untuk hak akses (GRANT, REVOKE), dan TCL untuk transaksi (BEGIN, COMMIT, ROLLBACK).

Huruf besar atau kecil sama saja
select nama, kota from pelanggan;
Teks diapit kutip tunggal
SELECT nama FROM pelanggan WHERE kota = 'Bandung';
Komentar dan beberapa baris
-- produk yang stoknya habis
SELECT nama, stok
FROM produk
WHERE stok = 0;

Tantangan

  1. Tampilkan kolom nama dan harga dari tabel produk.

Poin penting

  • Statement diakhiri titik koma.
  • Kata kunci tidak peka huruf besar-kecil.
  • Teks memakai kutip tunggal; kutip ganda untuk nama kolom khusus.
  • Kelompok perintah: DQL, DML, DDL, DCL, TCL.
