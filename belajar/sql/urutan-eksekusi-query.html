Urutan eksekusi query

Buka versi interaktif

Query ditulis dimulai dari SELECT, tetapi database tidak menjalankannya dari SELECT. Urutan logisnya: FROM (ambil tabel dan gabungan), WHERE (saring baris), GROUP BY (kelompokkan), HAVING (saring kelompok), SELECT (hitung kolom hasil), DISTINCT, ORDER BY (urutkan), lalu LIMIT.

Urutan ini menjelaskan banyak "keanehan". Alias yang dibuat di SELECT tidak bisa dipakai di WHERE, karena WHERE berjalan lebih dulu. Sebaliknya, ORDER BY boleh memakai alias karena berjalan setelah SELECT.

Putar visualisasi di bawah langkah demi langkah. Di setiap pelajaran SQL berikutnya, tombol Jelaskan langkah di editor juga bisa memvisualisasikan query buatanmu sendiri.

Query lengkap dengan semua klausa
SELECT kategori, COUNT(*) AS jumlah, AVG(harga) AS rata
FROM produk
WHERE stok > 0
GROUP BY kategori
HAVING COUNT(*) >= 2
ORDER BY rata DESC
LIMIT 2;
Alias di ORDER BY boleh
SELECT nama, harga * stok AS nilai FROM produk ORDER BY nilai DESC;

Tantangan

  1. Tampilkan nama dan nilai stok (harga * stok, alias nilai) untuk produk yang stoknya lebih dari 0, urut dari nilai terbesar.

Poin penting

  • Urutan: FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT.
  • Alias SELECT tidak bisa dipakai di WHERE (di kebanyakan database).
  • ORDER BY bisa memakai alias.
  • Pahami urutan ini untuk membaca query rumit.
