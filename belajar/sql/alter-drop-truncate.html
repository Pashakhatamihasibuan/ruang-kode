ALTER, DROP & TRUNCATE

Buka versi interaktif

ALTER TABLE mengubah struktur tabel yang sudah ada: menambah kolom (ADD COLUMN), menghapus kolom (DROP COLUMN), mengganti nama kolom atau tabel (RENAME), dan mengubah tipe kolom.

DROP TABLE menghapus tabel beserta seluruh isinya dan strukturnya. TRUNCATE TABLE mengosongkan semua baris tetapi strukturnya tetap, biasanya jauh lebih cepat daripada DELETE tanpa WHERE dan mereset penghitung id. (SQLite asli tidak punya TRUNCATE; simulator ini menyediakannya agar kamu bisa mencoba.)

Perintah-perintah ini sulit dibatalkan. Di perusahaan, perubahan struktur dilakukan lewat file migrasi yang ditinjau tim, bukan diketik langsung di database produksi.

Tambah kolom
ALTER TABLE produk ADD COLUMN berat_gram INTEGER DEFAULT 250;
SELECT nama, berat_gram FROM produk LIMIT 3;
Ganti nama kolom
ALTER TABLE pelanggan RENAME COLUMN kota TO domisili;
SELECT nama, domisili FROM pelanggan LIMIT 3;
TRUNCATE: kosongkan isi
TRUNCATE TABLE detail_pesanan;
SELECT COUNT(*) AS sisa FROM detail_pesanan;
DROP ditolak karena masih dirujuk
DROP TABLE pelanggan;

Tantangan

  1. Tambahkan kolom email bertipe TEXT ke tabel pelanggan.

Poin penting

  • ALTER: ADD/DROP/RENAME COLUMN, RENAME TO.
  • DROP = struktur dan isi hilang.
  • TRUNCATE = isi hilang, struktur tetap.
  • Perubahan struktur lewat migrasi yang ditinjau.
