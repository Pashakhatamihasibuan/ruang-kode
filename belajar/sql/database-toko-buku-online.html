Database toko buku online

Buka versi interaktif

Rancang database toko buku "Pustaka Nusantara": buku, penulis, pelanggan, pesanan. Isi data contoh, lalu jawab pertanyaan bisnis dengan query.

Teknologi: SQL (PostgreSQL/SQLite)

Fitur yang dibuat

  • Diagram ERD dengan relasi banyak-ke-banyak buku-penulis
  • CREATE TABLE dengan PRIMARY KEY, FOREIGN KEY, CHECK, NOT NULL
  • Minimal 20 buku, 10 penulis, 15 pelanggan, 40 pesanan
  • Index untuk kolom yang sering dicari
  • View laporan_penjualan_bulanan
  • Transaksi pemesanan yang mengurangi stok secara atomik
  • Query: 5 penulis terlaris, pelanggan tanpa pesanan 90 hari, pertumbuhan MoM
  • Window function untuk peringkat buku per genre

Langkah kerja

  1. Rancang ERD dan normalisasi sampai 3NF.
  2. Tulis DDL dan data contoh.
  3. Tambah index, view, dan transaksi.
  4. Jawab pertanyaan bisnis.
skema.sql
CREATE TABLE penulis (id INTEGER PRIMARY KEY, nama TEXT NOT NULL);
CREATE TABLE buku (
  id INTEGER PRIMARY KEY,
  judul TEXT NOT NULL,
  genre TEXT,
  harga INTEGER CHECK (harga > 0),
  stok INTEGER NOT NULL DEFAULT 0 CHECK (stok >= 0)
);
CREATE TABLE buku_penulis (
  buku_id INTEGER REFERENCES buku(id),
  penulis_id INTEGER REFERENCES penulis(id),
  PRIMARY KEY (buku_id, penulis_id)
);

SELECT b.judul, p.nama, b.stok FROM buku b
JOIN buku_penulis bp ON bp.buku_id = b.id
JOIN penulis p ON p.id = bp.penulis_id
ORDER BY b.judul;
