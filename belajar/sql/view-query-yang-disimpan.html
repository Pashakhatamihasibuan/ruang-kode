View: query yang disimpan

Buka versi interaktif

View adalah query SELECT yang disimpan dengan sebuah nama, lalu dipakai seperti tabel. View tidak menyimpan data sendiri: setiap kali dipanggil, query aslinya dijalankan ulang, sehingga hasilnya selalu mengikuti data terbaru.

Kegunaannya: menyederhanakan query rumit yang sering dipakai (misalnya laporan penjualan dengan 4 JOIN), memberi nama yang bermakna, dan membatasi akses, misalnya tim marketing hanya diberi akses ke view tanpa kolom sensitif.

Buat dengan CREATE VIEW, ubah dengan CREATE OR REPLACE VIEW (PostgreSQL/MySQL) atau DROP lalu CREATE ulang, dan hapus dengan DROP VIEW. Menghapus view tidak menyentuh tabel aslinya.

Buat view laporan
CREATE VIEW v_penjualan AS
SELECT s.id AS pesanan, p.nama AS pembeli, SUM(d.jumlah * pr.harga) AS total
FROM pesanan s
JOIN pelanggan p ON p.id = s.pelanggan_id
JOIN detail_pesanan d ON d.pesanan_id = s.id
JOIN produk pr ON pr.id = d.produk_id
GROUP BY s.id, p.nama;
SELECT * FROM v_penjualan WHERE total > 100000 ORDER BY total DESC;
View selalu mengikuti data terbaru
CREATE VIEW v_habis AS SELECT nama FROM produk WHERE stok = 0;
UPDATE produk SET stok = 0 WHERE id = 6;
SELECT * FROM v_habis;
Ubah lalu hapus
CREATE VIEW v_kota AS SELECT DISTINCT kota FROM pelanggan;
CREATE OR REPLACE VIEW v_kota AS SELECT DISTINCT kota FROM pelanggan WHERE kota IS NOT NULL;
SELECT * FROM v_kota;
DROP VIEW v_kota;

Tantangan

  1. Buat view bernama v_minuman berisi nama dan harga produk berkategori Minuman.

Poin penting

  • View = query bernama, dipakai seperti tabel.
  • Data tidak disalin; selalu terbaru.
  • Untuk menyederhanakan dan membatasi akses.
  • DROP VIEW tidak menghapus tabel.
