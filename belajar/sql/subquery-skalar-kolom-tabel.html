Subquery skalar, kolom & tabel

Buka versi interaktif

Subquery adalah SELECT di dalam kurung yang dipakai oleh query lain. Bentuknya menentukan di mana ia boleh dipakai. Skalar mengembalikan satu nilai, bisa dipakai di mana pun nilai tunggal diperlukan, misalnya WHERE harga > (SELECT AVG(harga) FROM produk).

Subquery kolom mengembalikan satu kolom banyak baris, dipakai bersama IN, ANY, atau ALL. Subquery tabel mengembalikan banyak kolom dan baris, dipakai di FROM sebagai tabel sementara (wajib diberi alias).

Subquery bisa bersarang beberapa tingkat. Database menjalankan yang paling dalam lebih dulu. Jika sudah lebih dari dua tingkat, pertimbangkan CTE (WITH) agar lebih mudah dibaca.

Skalar: di atas rata-rata
SELECT nama, harga FROM produk
WHERE harga > (SELECT AVG(harga) FROM produk);
Kolom: pelanggan yang pernah memesan
SELECT nama FROM pelanggan
WHERE id IN (SELECT pelanggan_id FROM pesanan);
Tabel: di FROM
SELECT kategori, rata FROM (
  SELECT kategori, AVG(harga) AS rata FROM produk GROUP BY kategori
) AS t
WHERE rata > 40000;
Bersarang: pembeli Kopi Gayo
SELECT nama FROM pelanggan WHERE id IN (
  SELECT pelanggan_id FROM pesanan WHERE id IN (
    SELECT pesanan_id FROM detail_pesanan WHERE produk_id = (
      SELECT id FROM produk WHERE nama = 'Kopi Gayo')));

Tantangan

  1. Tampilkan nama dan harga produk termahal memakai subquery skalar MAX.

Poin penting

  • Skalar = satu nilai; kolom = satu kolom; tabel = banyak kolom.
  • Subquery di FROM wajib alias.
  • IN untuk subquery kolom.
  • Bersarang dijalankan dari dalam ke luar.
