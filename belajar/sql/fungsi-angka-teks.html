Fungsi angka & teks

Buka versi interaktif

Fungsi angka: ABS nilai mutlak, ROUND(x, n) membulatkan ke n desimal, CEILING/CEIL ke atas, FLOOR ke bawah, MOD(a, b) atau a % b sisa bagi.

Fungsi teks: UPPER/LOWER mengubah huruf, LENGTH panjang teks, SUBSTRING(teks, mulai, panjang) mengambil potongan (posisi mulai dari 1), REPLACE mengganti, dan CONCAT atau operator || untuk menyambung.

Nama fungsi sedikit berbeda antar database (misalnya LEN di SQL Server, CHAR_LENGTH di MySQL), tetapi konsepnya sama. Simulator ini menerima beberapa variasi nama yang umum.

Fungsi angka
SELECT ABS(-7) AS mutlak, ROUND(85000 * 1.11, -2) AS bulat_ratusan,
       CEILING(4.1) AS atas, FLOOR(4.9) AS bawah, MOD(17, 5) AS sisa;
Harga per 1000 dibulatkan
SELECT nama, ROUND(harga / 1000.0, 1) AS ribu FROM produk;
Fungsi teks
SELECT UPPER(nama) AS besar, LOWER(kategori) AS kecil, LENGTH(nama) AS panjang,
       SUBSTRING(nama, 1, 4) AS awal, REPLACE(nama, ' ', '_') AS slug
FROM produk;
Menyambung teks
SELECT CONCAT(nama, ' (', kota, ')') AS label, nama || ' - ' || COALESCE(kota, '?') AS label2
FROM pelanggan;

Tantangan

  1. Tampilkan nama pelanggan dalam huruf besar (alias nama_besar) dan 3 huruf pertama kotanya (alias kode_kota), untuk pelanggan yang kotanya tidak NULL.

Poin penting

  • ROUND, CEILING, FLOOR, ABS, MOD untuk angka.
  • UPPER, LOWER, LENGTH, SUBSTRING, REPLACE, CONCAT untuk teks.
  • SUBSTRING dimulai dari posisi 1.
  • CONCAT mengabaikan NULL; || dengan NULL menghasilkan NULL.

Cek pemahaman

<code>SUBSTRING('Jakarta', 2, 3)</code>?

Jawaban: 'aka'

Mulai huruf ke-2, ambil 3 huruf.

<code>FLOOR(7.9)</code>?

Jawaban: 7

FLOOR selalu ke bawah.
