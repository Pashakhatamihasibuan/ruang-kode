BEGIN, COMMIT, ROLLBACK & SAVEPOINT

Buka versi interaktif

Transfer Rp100.000 dari Andi ke Budi terdiri dari dua UPDATE: kurangi saldo Andi, tambah saldo Budi. Bagaimana jika listrik padam di antara keduanya? Uang hilang. Transaksi menyatukan beberapa perintah menjadi satu kesatuan: semua berhasil, atau tidak ada sama sekali.

Mulai dengan BEGIN. Perubahan setelahnya masih sementara. COMMIT menyimpannya secara permanen, sedangkan ROLLBACK membatalkan semuanya kembali ke kondisi sebelum BEGIN.

SAVEPOINT nama membuat titik simpan di tengah transaksi. ROLLBACK TO nama membatalkan hanya perubahan setelah titik itu, sementara transaksi tetap berjalan. Ikuti visualisasinya, lalu coba sendiri di editor.

Transfer yang di-COMMIT
BEGIN;
UPDATE rekening SET saldo = saldo - 100000 WHERE id = 1;
UPDATE rekening SET saldo = saldo + 100000 WHERE id = 2;
COMMIT;
SELECT * FROM rekening;
Dibatalkan dengan ROLLBACK
BEGIN;
UPDATE rekening SET saldo = 0;
SELECT * FROM rekening;
ROLLBACK;
SELECT * FROM rekening;
SAVEPOINT
BEGIN;
UPDATE rekening SET saldo = saldo + 50000 WHERE id = 1;
SAVEPOINT bonus;
UPDATE rekening SET saldo = saldo + 999999 WHERE id = 2;
ROLLBACK TO bonus;
COMMIT;
SELECT * FROM rekening;

Tantangan

  1. Dalam satu transaksi, pindahkan saldo 50000 dari rekening 2 ke rekening 1, lalu COMMIT.

Poin penting

  • BEGIN → perintah-perintah → COMMIT atau ROLLBACK.
  • Semua atau tidak sama sekali.
  • SAVEPOINT untuk membatalkan sebagian.
  • Di luar transaksi, setiap perintah otomatis di-commit (autocommit).
