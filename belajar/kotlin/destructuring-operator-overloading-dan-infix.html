Destructuring, operator overloading, dan infix

Buka versi interaktif

Destructuring memecah objek menjadi beberapa variabel: val (nama, harga) = produk. Data class otomatis mendukungnya lewat fungsi component1(), component2(), dan seterusnya; begitu juga Pair dan entri Map.

Operator overloading membuat operator seperti +, *, [], atau in bekerja untuk class sendiri dengan fungsi bertanda operator (plus, times, get, contains).

Fungsi infix bisa dipanggil tanpa titik dan kurung, misalnya 1 to "satu". Pakai seperlunya agar kode tetap mudah dibaca.

KODE
data class Uang(val rupiah: Long) {
    operator fun plus(lain: Uang) = Uang(rupiah + lain.rupiah)
    operator fun times(n: Int) = Uang(rupiah * n)
    override fun toString() = "Rp" + "%,d".format(rupiah).replace(',', '.')
}

data class Item(val nama: String, val harga: Uang, val qty: Int)

infix fun Int.kali(item: Item) = item.harga * this

fun main() {
    val kopi = Item("Kopi Gayo", Uang(85_000), 2)
    val (nama, harga, qty) = kopi
    println("$nama $harga x$qty")
    val total = kopi.harga * kopi.qty + Uang(25_000)
    println("Total $total")
    println(3 kali kopi)
    for ((k, v) in mapOf("Medan" to 18_000, "Binjai" to 12_000)) println("$k: $v")
}

Poin penting

  • Destructuring lewat componentN().
  • operator fun plus, times, get, contains.
  • infix untuk pemanggilan tanpa titik.
