Class, data class, dan sealed class

Buka versi interaktif

Class Kotlin ringkas: constructor utama ditulis di judul, class Akun(val pemilik: String, var saldo: Int). Class bersifat final secara bawaan; tambahkan open agar bisa diwarisi.

data class otomatis membuat toString, equals, hashCode, dan copy. Ini cocok untuk model data dari API. copy(saldo = 0) membuat salinan dengan satu nilai diubah, gaya yang dianjurkan untuk state di Compose.

sealed class/interface membatasi turunan. Dengan when, kompiler memastikan semua kasus ditangani: pola standar untuk status layar Loading, Success, Error.

KODE
data class Pengguna(val nama: String, val kota: String)

sealed interface UiState {
    data object Loading : UiState
    data class Success(val data: List<Pengguna>) : UiState
    data class Error(val pesan: String) : UiState
}

fun tampilkan(state: UiState) = when (state) {
    UiState.Loading -> "Memuat..."
    is UiState.Success -> "Ada ${state.data.size} pengguna"
    is UiState.Error -> "Gagal: ${state.pesan}"
}

fun main() {
    val rina = Pengguna("Rina", "Medan")
    val pindah = rina.copy(kota = "Bandung")
    println(rina)
    println(pindah)
    println(rina == Pengguna("Rina", "Medan"))
    println(tampilkan(UiState.Loading))
    println(tampilkan(UiState.Success(listOf(rina, pindah))))
    println(tampilkan(UiState.Error("tidak ada internet")))
}
KELUARAN
Pengguna(nama=Rina, kota=Medan)
Pengguna(nama=Rina, kota=Bandung)
true
Memuat...
Ada 2 pengguna
Gagal: tidak ada internet

Soal latihan

  1. Buat data class Produk(nama, harga), salin dengan harga baru memakai copy, dan bandingkan dua objek berisi sama.

    Petunjuk

    data class otomatis membuat toString, equals, dan copy.

    Lihat jawaban
    KODE
    data class Produk(val nama: String, val harga: Int)

fun main() {
    val p = Produk("Kopi", 18000)
    val p2 = p.copy(harga = 20000)
    println(p)
    println(p2)
    println(p == Produk("Kopi", 18000))
}
    KELUARAN
    Produk(nama=Kopi, harga=18000)
Produk(nama=Kopi, harga=20000)
true

  2. Buat sealed interface Hasil dengan Sukses(data) dan Gagal(pesan), lalu tampilkan dengan when.

    Petunjuk

    when pada sealed type tidak butuh else.

    Lihat jawaban
    KODE
    sealed interface Hasil
data class Sukses(val data: List<String>) : Hasil
data class Gagal(val pesan: String) : Hasil

fun tampil(h: Hasil) = when (h) {
    is Sukses -> "${h.data.size} produk"
    is Gagal -> "Error: ${h.pesan}"
}

fun main() {
    println(tampil(Sukses(listOf("Kopi", "Teh"))))
    println(tampil(Gagal("offline")))
}
    KELUARAN
    2 produk
Error: offline

Poin penting

  • data class: toString, equals, copy otomatis.
  • Class final secara bawaan; open untuk diwarisi.
  • sealed + when untuk status layar.

Cek pemahaman

Kenapa when pada sealed class tidak butuh else?

Jawaban: Kompiler tahu semua turunannya

Fungsi yang dibuat otomatis oleh data class?

Jawaban: toString, equals, hashCode, copy
