Exception, require, dan Result

Buka versi interaktif

Kotlin menangkap error dengan try / catch / finally. Bedanya dengan Java: try adalah ekspresi, jadi bisa mengembalikan nilai: val n = try { s.toInt() } catch (e: NumberFormatException) { 0 }.

Untuk memeriksa syarat, pakai require(kondisi) { "pesan" } (argumen salah, melempar IllegalArgumentException) dan check(...) (keadaan objek salah). Buat exception sendiri dengan mewarisi Exception.

runCatching { ... } membungkus hasil dalam Result: berhasil atau gagal, tanpa try/catch. Ambil nilainya dengan getOrDefault, getOrNull, atau fold. Untuk input teks, toIntOrNull() paling sederhana.

KODE
class SaldoKurang(val kurang: Int) : Exception("Saldo kurang Rp$kurang")

fun tarik(saldo: Int, jumlah: Int): Int {
    require(jumlah > 0) { "Jumlah harus positif" }
    if (jumlah > saldo) throw SaldoKurang(jumlah - saldo)
    return saldo - jumlah
}

fun main() {
    try {
        println("12a".toInt())
    } catch (e: NumberFormatException) {
        println("Format salah, masukkan angka saja")
    } finally {
        println("Selesai memeriksa input")
    }

    try {
        tarik(50000, 80000)
    } catch (e: SaldoKurang) {
        println(e.message)
    }

    val angka = "99x".toIntOrNull() ?: 0
    println("toIntOrNull: $angka")

    val gagal = runCatching { tarik(50000, -1) }
    println(gagal.exceptionOrNull()?.message)
    val sisa = runCatching { tarik(50000, 20000) }.getOrDefault(0)
    println("Sisa: $sisa")
}
KELUARAN
Format salah, masukkan angka saja
Selesai memeriksa input
Saldo kurang Rp30000
toIntOrNull: 0
Jumlah harus positif
Sisa: 30000

Soal latihan

  1. Buat fungsi bagi(a, b) yang melempar IllegalArgumentException("Pembagi nol") jika b = 0, lalu tangkap di main.

    Petunjuk

    require(b != 0) { "Pembagi nol" } sudah melempar IllegalArgumentException.

    Lihat jawaban
    KODE
    fun bagi(a: Int, b: Int): Double {
    require(b != 0) { "Pembagi nol" }
    return a.toDouble() / b
}

fun main() {
    println(bagi(10, 4))
    try {
        println(bagi(5, 0))
    } catch (e: IllegalArgumentException) {
        println("Gagal: ${e.message}")
    }
}

  2. Validasi input umur ["20", "abc", "-5", "17"] dengan when: valid, bukan angka, atau tidak boleh negatif.

    Petunjuk

    val n = s.toIntOrNull(); when { n == null -> ...; n < 0 -> ...; else -> ... }

    Lihat jawaban
    KODE
    fun main() {
    for (s in listOf("20", "abc", "-5", "17")) {
        val n = s.toIntOrNull()
        val hasil = when {
            n == null -> "bukan angka"
            n < 0 -> "tidak boleh negatif"
            else -> "valid"
        }
        println("$s: $hasil")
    }
}

Poin penting

  • try adalah ekspresi.
  • require/check untuk syarat.
  • runCatching menghasilkan Result.

Cek pemahaman

Exception yang dilempar require(false)?

Jawaban: IllegalArgumentException

check yang melempar IllegalStateException.

Hasil runCatching { error("x") }.getOrDefault(5)?

Jawaban: 5
