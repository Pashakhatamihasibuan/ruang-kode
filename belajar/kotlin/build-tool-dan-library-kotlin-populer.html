Build tool dan library Kotlin populer

Buka versi interaktif

Proyek Kotlin dan Android memakai Gradle dengan file build.gradle.kts (Kotlin DSL). Dependensi ditambahkan di blok dependencies, dan versinya biasanya dikelola terpusat di version catalog gradle/libs.versions.toml.

Library yang sering dipakai: Ktor dan Retrofit (HTTP), kotlinx.serialization (JSON), Room (database SQLite Android), Hilt atau Koin (dependency injection), Coil (memuat gambar), dan JUnit + MockK (pengujian).

Soal latihan

  1. Tulis blok dependencies Gradle Kotlin DSL untuk coroutines, kotlinx.serialization, dan JUnit 5.

    Petunjuk

    implementation untuk kode utama, testImplementation untuk tes.

    Lihat jawaban
    KODE
    plugins {
    kotlin("jvm") version "2.0.21"
    kotlin("plugin.serialization") version "2.0.21"
}

dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.9.0")
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.7.3")
    testImplementation(kotlin("test"))
}

tasks.test { useJUnitPlatform() }

  2. Tulis perintah Gradle untuk menjalankan tes dan membangun aplikasi Android versi rilis.

    Petunjuk

    Pakai wrapper ./gradlew.

    Lihat jawaban
    TERMINAL
    ./gradlew test
./gradlew assembleRelease
./gradlew bundleRelease   # App Bundle untuk Google Play

Poin penting

  • Gradle Kotlin DSL: build.gradle.kts.
  • Version catalog libs.versions.toml.
  • Retrofit/Ktor, Room, Hilt/Koin, Coil.
