Pengujian Kotlin: JUnit 5, kotest, dan MockK

Buka versi interaktif

Unit test Kotlin di JVM biasanya memakai JUnit 5 dengan kotlin.test (assertEquals, assertFailsWith). Nama fungsi tes boleh berupa kalimat di antara backtick agar laporan mudah dibaca.

kotest menawarkan gaya spesifikasi yang lebih ekspresif (shouldBe) dan property-based testing. MockK adalah pustaka mock khusus Kotlin yang mendukung fungsi suspend (coEvery, coVerify), object, dan extension function.

Untuk coroutine, pakai runTest dari kotlinx-coroutines-test agar delay dilewati secara virtual dan tes tetap cepat. Jalankan semua tes dengan ./gradlew test.

KODE
class KeranjangTest {
    private val repo = mockk<ProdukRepository>()

    @Test
    fun `total menjumlahkan harga kali jumlah`() {
        val k = Keranjang()
        k.tambah(Item("Kopi", 85_000), 2)
        assertEquals(170_000, k.total())
    }

    @Test
    fun `jumlah nol ditolak`() {
        assertFailsWith<IllegalArgumentException> { Keranjang().tambah(Item("Kopi", 85_000), 0) }
    }

    @Test
    fun `checkout memanggil repository sekali`() = runTest {
        coEvery { repo.kirimPesanan(any()) } returns "INV-001"
        val hasil = Checkout(repo).bayar(Keranjang())
        assertEquals("INV-001", hasil)
        coVerify(exactly = 1) { repo.kirimPesanan(any()) }
    }
}
KELUARAN
$ ./gradlew test

KeranjangTest > total menjumlahkan harga kali jumlah() PASSED
KeranjangTest > jumlah nol ditolak() PASSED
KeranjangTest > checkout memanggil repository sekali() PASSED

Poin penting

  • JUnit 5 + kotlin.test, nama tes dengan backtick.
  • MockK: coEvery dan coVerify untuk suspend.
  • runTest untuk coroutine.
