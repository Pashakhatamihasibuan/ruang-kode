Flow: aliran data asinkron

Buka versi interaktif

Flow adalah versi coroutine dari Stream: memancarkan banyak nilai seiring waktu. Buat dengan builder flow { emit(x) } atau asFlow(), lalu baca dengan collect.

Flow bisa diolah seperti koleksi: map, filter, take, debounce (menunggu pengguna berhenti mengetik), dan combine (menggabungkan dua sumber).

StateFlow menyimpan satu nilai terkini dan memberi tahu pengamatnya setiap kali berubah. Di Android, ViewModel memakai MutableStateFlow untuk state layar, dan Compose membacanya dengan collectAsStateWithLifecycle().

KODE
import kotlinx.coroutines.*
import kotlinx.coroutines.flow.*

fun hitungMundur(dari: Int): Flow<Int> = flow {
    for (i in dari downTo 1) {
        delay(300)
        emit(i)
    }
}

fun main() = runBlocking {
    hitungMundur(3).collect { println("Sisa $it") }
    println("Waktu habis!")

    val hasil = (1..6).asFlow()
        .filter { it % 2 == 0 }
        .map { it * it }
        .toList()
    println("Kuadrat genap: $hasil")

    val suhu = MutableStateFlow(28)
    println("Suhu awal: ${suhu.value}")
    suhu.value = 31
    println("Suhu kini: ${suhu.value}")
}
KELUARAN
Sisa 3
Sisa 2
Sisa 1
Waktu habis!
Kuadrat genap: [4, 16, 36]
Suhu awal: 28
Suhu kini: 31

Soal latihan

  1. Buat Flow nama hari kerja, lalu ambil tiga yang pertama.

    Petunjuk

    flowOf(...) lalu take(3).toList().

    Lihat jawaban
    KODE
    import kotlinx.coroutines.flow.*
import kotlinx.coroutines.runBlocking

fun main() = runBlocking {
    val hari = flowOf("Senin", "Selasa", "Rabu", "Kamis", "Jumat")
    println(hari.take(3).toList())
}
    KELUARAN
    [Senin, Selasa, Rabu]

  2. Jumlahkan angka 1 sampai 5 dari sebuah Flow memakai reduce.

    Petunjuk

    (1..5).asFlow().reduce { a, b -> a + b }.

    Lihat jawaban
    KODE
    import kotlinx.coroutines.flow.*
import kotlinx.coroutines.runBlocking

fun main() = runBlocking {
    println((1..5).asFlow().reduce { a, b -> a + b })
}
    KELUARAN
    15

Poin penting

  • flow { emit() } dan collect.
  • Operator: map, filter, take, debounce, combine.
  • StateFlow menyimpan nilai terkini untuk UI.

Cek pemahaman

Kapan kode di dalam flow { } mulai berjalan?

Jawaban: Saat collect dipanggil

Flow bersifat dingin (cold).

Kerjakan latihannya di aplikasi

Sebelumnya: Generics, enum class, dan object

Berikutnya: Proyek: struk kasir
