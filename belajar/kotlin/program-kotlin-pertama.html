Program Kotlin pertama

Buka versi interaktif

Kotlin adalah bahasa buatan JetBrains yang sejak 2019 menjadi bahasa utama Android pilihan Google. Kotlin berjalan di JVM (bisa memakai semua library Java), dan lewat Kotlin Multiplatform juga bisa berjalan di iOS, web, dan desktop.

Program dimulai dari fun main(). Titik koma tidak wajib, dan println() menampilkan teks. Coba Kotlin langsung di play.kotlinlang.org, atau pasang IntelliJ IDEA / Android Studio yang sudah membawa Kotlin.

Dibanding Java, Kotlin jauh lebih ringkas: tidak perlu class pembungkus untuk main, tipe bisa ditebak, dan banyak pola umum (data class, null safety, lambda) sudah tersedia di bahasa.

KODE
fun main() {
    // titik awal program
    println("Halo, Ruang Kode!")
    println("Kotlin dipakai untuk Android")
}
KELUARAN
Halo, Ruang Kode!
Kotlin dipakai untuk Android

Soal latihan

  1. Cetak biodata tiga baris: nama, program studi, dan kota asalmu.

    Petunjuk

    Panggil println() tiga kali di dalam fun main().

    Lihat jawaban
    KODE
    fun main() {
    println("Nama: Rina Siregar")
    println("Prodi: Teknik Informatika")
    println("Kota: Medan")
}

  2. Tebak keluarannya, lalu buktikan: print("A"); print("B"); println(); println("C").

    Petunjuk

    print tidak menambah baris baru, println menambahkannya.

    Lihat jawaban
    KODE
    fun main() {
    print("A")
    print("B")
    println()
    println("C")
}

Poin penting

  • Program dimulai dari fun main().
  • Titik koma opsional.
  • Coba di play.kotlinlang.org.
