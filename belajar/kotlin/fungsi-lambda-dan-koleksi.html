Fungsi, lambda, dan koleksi

Buka versi interaktif

Fungsi ditulis fun nama(param: Tipe): TipeKembali. Fungsi satu ekspresi bisa memakai =: fun kali(a: Int, b: Int) = a * b. Parameter bisa punya nilai bawaan dan dipanggil dengan nama: hitung(harga = 20000, jumlah = 3).

Lambda adalah fungsi tanpa nama: { x -> x * 2 }. Jika parameternya satu, cukup it. Jika lambda adalah argumen terakhir, tulis di luar kurung: daftar.filter { it > 20000 }. Pola ini dipakai di seluruh Jetpack Compose.

Koleksi Kotlin dibedakan: listOf (tidak bisa diubah) dan mutableListOf (bisa diubah), begitu juga mapOf/mutableMapOf. Operasi penting: filter, map, sumOf, groupBy, sortedBy, first, any.

KODE
data class Produk(val nama: String, val harga: Int, val kategori: String)

fun hitungTotal(harga: Int, jumlah: Int = 1, diskon: Double = 0.0) =
    (harga * jumlah * (1 - diskon)).toInt()

fun main() {
    val produk = listOf(
        Produk("Kopi Gayo", 85000, "kopi"),
        Produk("Teh Tarik", 15000, "teh"),
        Produk("Kopi Toraja", 90000, "kopi"),
    )
    println(hitungTotal(20000, jumlah = 3, diskon = 0.1))
    println(produk.filter { it.harga > 20000 }.map { it.nama })
    println("Total: ${produk.sumOf { it.harga }}")
    println(produk.groupBy { it.kategori }.mapValues { it.value.size })
    println(produk.sortedBy { it.harga }.first().nama)
}
KELUARAN
54000
[Kopi Gayo, Kopi Toraja]
Total: 190000
{kopi=2, teh=1}
Teh Tarik

Soal latihan

  1. Dari nilai [70, 85, 90, 60, 95], hitung rata-rata, tertinggi, dan jumlah yang lulus (≥ 75).

    Petunjuk

    average(), max(), count { it >= 75 }.

    Lihat jawaban
    KODE
    fun main() {
    val nilai = listOf(70, 85, 90, 60, 95)
    println("Rata-rata: ${nilai.average()}")
    println("Tertinggi: ${nilai.max()}")
    println("Lulus: ${nilai.count { it >= 75 }}")
}
    KELUARAN
    Rata-rata: 80.0
Tertinggi: 95
Lulus: 3

  2. Hitung frekuensi huruf di "banana".

    Petunjuk

    groupingBy { it }.eachCount().

    Lihat jawaban
    KODE
    fun main() {
    println("banana".groupingBy { it }.eachCount())
}
    KELUARAN
    {b=1, a=3, n=2}

  3. Buat fungsi dengan parameter bawaan luas(p: Double, l: Double = p), lalu panggil untuk persegi panjang 5×3 dan persegi 4.

    Petunjuk

    Parameter bawaan boleh memakai parameter sebelumnya.

    Lihat jawaban
    KODE
    fun luas(p: Double, l: Double = p) = p * l

fun main() {
    println(luas(5.0, 3.0))
    println(luas(4.0))
}
    KELUARAN
    15.0
16.0

Poin penting

  • Nilai bawaan dan argumen bernama.
  • Lambda dengan it; lambda terakhir di luar kurung.
  • listOf tidak bisa diubah, mutableListOf bisa.

Cek pemahaman

Hasil listOf(1, 2, 3).map { it * 10 }?

Jawaban: [10, 20, 30]

map mengubah setiap isi.

Nama parameter otomatis di lambda satu parameter?

Jawaban: it

it dipakai jika parameter tidak diberi nama.
