Proyek: struk kasir

Buka versi interaktif

Proyek ini menggabungkan data class dengan properti terhitung, listOf, sumOf, ekspresi if, dan padEnd/padStart untuk struk yang rapi.

Fungsi rp() menambahkan titik ribuan memakai chunked. Di aplikasi Android sungguhan, pakai NumberFormat.getCurrencyInstance(Locale("id", "ID")).

Jalankan di play.kotlinlang.org, lalu kerjakan tantangannya.

KODE
data class Item(val nama: String, val harga: Int, val qty: Int) {
    val subtotal: Int get() = harga * qty
}

fun rp(n: Int) = n.toString().reversed().chunked(3).joinToString(".").reversed()

fun main() {
    val keranjang = listOf(
        Item("Kopi susu", 18000, 2),
        Item("Roti bakar", 22500, 1),
        Item("Air mineral", 5000, 3),
    )
    println("Barang".padEnd(14) + "Qty".padStart(4) + "Subtotal".padStart(10))
    println("-".repeat(28))
    for (b in keranjang) {
        println(b.nama.padEnd(14) + b.qty.toString().padStart(4) + rp(b.subtotal).padStart(10))
    }
    val total = keranjang.sumOf { it.subtotal }
    val diskon = if (total >= 50000) total / 10 else 0
    println("-".repeat(28))
    println("Total".padEnd(18) + rp(total).padStart(10))
    println("Diskon 10%".padEnd(18) + rp(diskon).padStart(10))
    println("Bayar".padEnd(18) + rp(total - diskon).padStart(10))
}

Soal latihan

  1. Tambahkan PPN 11% (dibulatkan) dari harga setelah diskon, lalu tampilkan total akhir.

    Petunjuk

    import kotlin.math.roundToInt; (setelahDiskon * 11 / 100.0).roundToInt().

    Lihat jawaban
    KODE
        val setelahDiskon = total - diskon
    val ppn = (setelahDiskon * 11 / 100.0).roundToInt()
    println("PPN 11%".padEnd(18) + rp(ppn).padStart(10))
    println("Total akhir".padEnd(18) + rp(setelahDiskon + ppn).padStart(10))

  2. Cetak barang diurutkan dari subtotal terbesar.

    Petunjuk

    sortedByDescending { it.subtotal }.

    Lihat jawaban
    KODE
        for (b in keranjang.sortedByDescending { it.subtotal }) {
        println("${b.nama}: ${rp(b.subtotal)}")
    }

  3. Ubah diskon menjadi bertingkat dengan when: 15% jika total ≥ 100.000, 10% jika ≥ 50.000, selain itu 0.

    Petunjuk

    when { total >= 100000 -> ...; total >= 50000 -> ...; else -> 0 }

    Lihat jawaban
    KODE
        val diskon = when {
        total >= 100_000 -> total * 15 / 100
        total >= 50_000 -> total / 10
        else -> 0
    }

Poin penting

  • data class + properti terhitung.
  • sumOf untuk total.
  • padEnd/padStart untuk struk berkolom.
