Extension function dan scope function

Buka versi interaktif

Extension function menambah fungsi ke class yang sudah ada tanpa mewarisinya: fun Int.keRupiah(): String lalu dipanggil 85000.keRupiah(). Android KTX dan Compose penuh dengan extension.

Scope function membuat kode lebih ringkas: let (jalankan jika tidak null, objek sebagai it), apply (atur properti objek lalu kembalikan objeknya), also (efek samping seperti log), run dan with.

Jangan berlebihan: scope function yang bersarang terlalu dalam justru sulit dibaca.

KODE
import java.text.NumberFormat
import java.util.Locale

fun Int.keRupiah(): String {
    val f = NumberFormat.getNumberInstance(Locale.GERMANY) // titik sebagai pemisah ribuan
    return "Rp" + f.format(this)
}

fun String.inisial() = split(" ").joinToString("") { it.first().uppercase() }

fun main() {
    println(85000.keRupiah())
    println("rina sari dewi".inisial())

    val email: String? = "rina@kampus.ac.id"
    email?.let { println("Kirim ke $it") }

    val daftar = mutableListOf<String>().apply {
        add("Kopi")
        add("Teh")
    }.also { println("Isi: $it") }
    println(daftar.size)
}
KELUARAN
Rp85.000
RSD
Kirim ke rina@kampus.ac.id
Isi: [Kopi, Teh]
2

Soal latihan

  1. Buat extension Int.rupiah() yang menambahkan titik ribuan tanpa NumberFormat.

    Petunjuk

    Balik teksnya, potong per 3 dengan chunked(3), gabung dengan titik, lalu balik lagi.

    Lihat jawaban
    KODE
    fun Int.rupiah() = "Rp" + toString().reversed().chunked(3).joinToString(".").reversed()

fun main() {
    println(1250000.rupiah())
    println(500.rupiah())
}
    KELUARAN
    Rp1.250.000
Rp500

  2. Pakai let agar pesan hanya dikirim jika email tidak null, dan apply untuk mengisi objek.

    Petunjuk

    email?.let { ... } dan Objek().apply { field = ... }.

    Lihat jawaban
    KODE
    class Pesan {
    var ke = ""
    var isi = ""
}

fun main() {
    val email: String? = "rina@mail.com"
    email?.let { println("Kirim ke $it") }
    val p = Pesan().apply {
        ke = "Budi"
        isi = "Rapat jam 9"
    }
    println("${p.ke}: ${p.isi}")
}
    KELUARAN
    Kirim ke rina@mail.com
Budi: Rapat jam 9

Poin penting

  • Extension menambah fungsi ke class yang ada.
  • let untuk nilai nullable, apply untuk mengatur objek.
  • Jangan menumpuk scope function terlalu dalam.

Cek pemahaman

Scope function yang mengembalikan objek itu sendiri setelah diatur?

Jawaban: apply

apply mengembalikan objek penerima.

Scope function yang mengembalikan objek itu sendiri dan memakai this?

Jawaban: apply

apply untuk mengisi objek.
