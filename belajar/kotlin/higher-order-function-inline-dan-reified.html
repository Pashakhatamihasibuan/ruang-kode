Higher-order function, inline, dan reified

Buka versi interaktif

Higher-order function menerima atau mengembalikan fungsi. map, filter, dan forEach adalah contohnya. Tipe fungsi ditulis seperti (Int) -> Int, dan lambda terakhir bisa ditulis di luar kurung.

Setiap lambda biasanya menjadi objek. Fungsi inline menyalin isinya ke tempat pemanggilan sehingga tidak ada objek tambahan; pustaka standar memakai ini untuk map, filter, dan scope function.

Karena tipe generik dihapus saat runtime, T::class biasanya tidak bisa dipakai. Pada fungsi inline, tanda reified membuat tipe T tetap diketahui, misalnya untuk menyaring list berdasarkan tipe.

KODE
fun ulang(n: Int, aksi: (Int) -> Unit) {
    for (i in 1..n) aksi(i)
}

fun pengali(k: Int): (Int) -> Int = { it * k }

inline fun <reified T> List<Any>.hanya(): List<T> = filterIsInstance<T>()

inline fun ukur(label: String, blok: () -> Unit) {
    blok()
    println("$label selesai")
}

fun main() {
    ulang(3) { print("$it ") }
    println()
    val kaliTiga = pengali(3)
    println(listOf(1, 2, 3).map(kaliTiga))
    val campur: List<Any> = listOf(1, "dua", 3.0, "empat", 5)
    println(campur.hanya<String>())
    println(campur.hanya<Int>().sum())
    ukur("Hitung") { println("menghitung...") }
}
KELUARAN
1 2 3 
[3, 6, 9]
[dua, empat]
6
menghitung...
Hitung selesai

Soal latihan

  1. Tulis fungsi terapkan(n: Int, f: (Int) -> Int): Int yang menerapkan f dua kali, lalu cetak hasil terapkan(3) { it * it }.

    Petunjuk

    f(f(n)).

    Lihat jawaban
    KODE
    fun terapkan(n: Int, f: (Int) -> Int): Int = f(f(n))

fun main() {
    println(terapkan(3) { it * it })
}
    KELUARAN
    81

Poin penting

  • Tipe fungsi (A) -> B, lambda di luar kurung.
  • inline menghindari objek lambda.
  • reified membuat T diketahui saat runtime.
