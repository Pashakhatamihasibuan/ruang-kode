Coroutines: kode asinkron yang mudah dibaca

Buka versi interaktif

Mengambil data dari internet tidak boleh dilakukan di thread utama Android, karena layar akan macet. Kotlin memakai coroutines: fungsi suspend bisa "berhenti sejenak" menunggu tanpa memblokir thread.

launch memulai coroutine tanpa hasil, async memulai coroutine yang mengembalikan hasil (diambil dengan await()). Dua async berjalan bersamaan, sehingga dua permintaan 500 ms selesai dalam sekitar 500 ms, bukan 1 detik.

Di Android, coroutine dijalankan di viewModelScope atau lifecycleScope agar otomatis dibatalkan saat layar ditutup. Library kotlinx-coroutines juga menyediakan Flow untuk aliran data, mirip Stream di Dart. Contoh di bawah memakai runBlocking, yang hanya cocok untuk main dan tes.

KODE
import kotlinx.coroutines.*

suspend fun ambilProfil(): String {
    delay(500)          // pura-pura menunggu jaringan
    return "Rina"
}

suspend fun ambilSaldo(): Int {
    delay(500)
    return 150_000
}

fun main() = runBlocking {
    val mulai = System.currentTimeMillis()
    val profil = async { ambilProfil() }
    val saldo = async { ambilSaldo() }
    println("${profil.await()} punya saldo ${saldo.await()}")
    val lama = System.currentTimeMillis() - mulai
    println(if (lama < 900) "Selesai bersamaan (sekitar 0,5 detik)" else "Berurutan")
}
KELUARAN
Rina punya saldo 150000
Selesai bersamaan (sekitar 0,5 detik)

Soal latihan

  1. Ambil stok dari dua gudang secara paralel dengan async, lalu jumlahkan.

    Petunjuk

    Dua async di dalam coroutineScope, lalu await() keduanya.

    Lihat jawaban
    KODE
    import kotlinx.coroutines.*

suspend fun stok(gudang: String): Int {
    delay(1000)
    return if (gudang == "Medan") 12 else 30
}

fun main() = runBlocking {
    val a = async { stok("Medan") }
    val b = async { stok("Binjai") }
    println("Total stok: ${a.await() + b.await()}") // sekitar 1 detik, bukan 2
}
    KELUARAN
    Total stok: 42

  2. Batalkan permintaan yang lebih lama dari 500 ms dengan withTimeoutOrNull.

    Petunjuk

    Hasilnya null jika waktu habis; pakai elvis untuk pesan.

    Lihat jawaban
    KODE
    import kotlinx.coroutines.*

fun main() = runBlocking {
    val data = withTimeoutOrNull(500) {
        delay(1000)
        "data"
    }
    println(data ?: "Waktu habis")
}
    KELUARAN
    Waktu habis

Poin penting

  • suspend menunggu tanpa memblokir thread.
  • async + await untuk menjalankan bersamaan.
  • viewModelScope membatalkan coroutine saat layar ditutup.
