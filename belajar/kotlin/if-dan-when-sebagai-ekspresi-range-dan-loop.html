if dan when sebagai ekspresi, range dan loop

Buka versi interaktif

Di Kotlin, if dan when adalah ekspresi: hasilnya bisa langsung disimpan. when menggantikan switch dan jauh lebih fleksibel: bisa mencocokkan nilai, rentang (in 80..89), atau tipe (is String).

Loop for memakai range: 1..5 (1 sampai 5), 0 until n (0 sampai n - 1), 10 downTo 1, dan step 2. Membaca koleksi cukup for (x in daftar), dan butuh indeks pakai for ((i, x) in daftar.withIndex()).

while dan do { } while () tetap ada untuk kasus yang jumlah putarannya belum diketahui.

KODE
fun main() {
    val nilai = 87
    val huruf = when (nilai) {
        in 90..100 -> "A"
        in 80..89 -> "B"
        in 70..79 -> "C"
        else -> "D"
    }
    val status = if (nilai >= 75) "Lulus" else "Remedial"
    println("$nilai = $huruf, $status")

    for (i in 1..3) print("$i ")
    println()
    for (i in 10 downTo 0 step 5) print("$i ")
    println()
    for ((i, kota) in listOf("Medan", "Padang").withIndex()) {
        println("$i: $kota")
    }
}
KELUARAN
87 = B, Lulus
1 2 3 
10 5 0 
0: Medan
1: Padang

Soal latihan

  1. FizzBuzz 1 sampai 15 memakai when tanpa argumen.

    Petunjuk

    Cabang pertama i % 15 == 0, lalu % 3, lalu % 5, else angkanya.

    Lihat jawaban
    KODE
    fun main() {
    for (i in 1..15) {
        println(
            when {
                i % 15 == 0 -> "FizzBuzz"
                i % 3 == 0 -> "Fizz"
                i % 5 == 0 -> "Buzz"
                else -> i
            }
        )
    }
}

  2. Jumlahkan bilangan genap 2 sampai 100 dengan range ber-step.

    Petunjuk

    (2..100 step 2) lalu sum().

    Lihat jawaban
    KODE
    fun main() {
    println("Jumlah genap: ${(2..100 step 2).sum()}")
}

  3. Cetak segitiga bintang terbalik 4 baris.

    Petunjuk

    for (i in 4 downTo 1) dan "*".repeat(i).

    Lihat jawaban
    KODE
    fun main() {
    for (i in 4 downTo 1) println("*".repeat(i))
}

Poin penting

  • if dan when menghasilkan nilai.
  • Range: .., until, downTo, step.
  • withIndex() untuk indeks dan isi.

Cek pemahaman

for (i in 0 until 3) menghasilkan?

Jawaban: 0 1 2

until tidak menyertakan batas akhir.

Isi dari 1 until 4?

Jawaban: 1, 2, 3

until tidak menyertakan batas atas.
