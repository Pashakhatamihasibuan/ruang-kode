val, var, tipe data, dan null safety

Buka versi interaktif

val untuk nilai yang tidak bisa diisi ulang (mirip final), var untuk variabel yang bisa berubah. Gunakan val sebagai pilihan utama. Tipe ditebak otomatis, atau ditulis setelah titik dua: val umur: Int = 20.

Tipe dasar: Int, Long, Double, Boolean, Char, String. Semua adalah objek, jadi bisa memanggil method seperti 20.toString().

Null safety: tipe biasa tidak boleh null. Tambahkan ? agar boleh: var alamat: String? = null. Pakai ?. (panggil jika tidak null), ?: (operator Elvis, nilai cadangan), dan hindari !! yang melempar error jika ternyata null.

Operator null safety
OperatorArtiContoh
T?Tipe boleh nullString?
?.Panggil jika tidak nullalamat?.length
?:Elvis: nilai cadanganalamat ?: "-"
!!Paksa, error jika nullalamat!!.length
letJalankan blok jika tidak nullalamat?.let { println(it) }
KODE
fun main() {
    val nama = "Rina"          // String, tidak bisa diisi ulang
    var umur: Int = 20
    umur += 1
    val ipk = 3.75             // Double
    var alamat: String? = null // boleh null

    println("$nama, $umur tahun, IPK $ipk")
    println("Alamat: ${alamat ?: "belum diisi"}")
    println("Panjang alamat: ${alamat?.length}")
    alamat = "Medan"
    println("Panjang alamat: ${alamat?.length}")
}
KELUARAN
Rina, 21 tahun, IPK 3.75
Alamat: belum diisi
Panjang alamat: null
Panjang alamat: 5

Soal latihan

  1. Hitung luas lingkaran berjari-jari 7 memakai Math.PI, bulatkan ke 2 desimal tanpa format string.

    Petunjuk

    kotlin.math.round(x * 100) / 100.

    Lihat jawaban
    KODE
    import kotlin.math.round

fun main() {
    val r = 7
    val luas = Math.PI * r * r
    println("Luas: ${round(luas * 100) / 100}")
}
    KELUARAN
    Luas: 153.94

  2. Variabel val nama: String? = null. Tampilkan panjang nama atau 0 jika null, dalam satu ekspresi.

    Petunjuk

    Gabungkan ?. dan elvis ?:.

    Lihat jawaban
    KODE
    fun main() {
    var nama: String? = null
    println("Panjang: ${nama?.length ?: 0}")
    nama = "Budi"
    println("Panjang: ${nama?.length ?: 0}")
}
    KELUARAN
    Panjang: 0
Panjang: 4

  3. Ubah teks "42" dan "4x2" menjadi Int dengan aman; jika gagal pakai -1.

    Petunjuk

    toIntOrNull() mengembalikan null jika bukan angka.

    Lihat jawaban
    KODE
    fun main() {
    for (s in listOf("42", "4x2")) {
        println("$s -> ${s.toIntOrNull() ?: -1}")
    }
}
    KELUARAN
    42 -> 42
4x2 -> -1

Poin penting

  • val utama, var hanya jika perlu berubah.
  • Tipe dengan ? boleh null.
  • ?: memberi nilai cadangan; hindari !!.

Cek pemahaman

Hasil println(x ?: 0) jika x null?

Jawaban: 0
