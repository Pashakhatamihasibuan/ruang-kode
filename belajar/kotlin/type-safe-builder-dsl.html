Type-safe builder (DSL)

Buka versi interaktif

Kotlin memungkinkan membuat DSL (domain-specific language) yang terbaca seperti konfigurasi. Kuncinya: lambda dengan receiver (Builder.() -> Unit), sehingga di dalam kurung kurawal kita bisa memanggil fungsi builder tanpa awalan.

Contoh DSL nyata: build.gradle.kts, routing Ktor, Jetpack Compose (Column { Text() }), dan kotlinx.html. Anotasi @DslMarker mencegah salah memanggil fungsi builder luar dari dalam blok yang bersarang.

Buat DSL hanya jika struktur yang dibangun memang bertingkat dan sering dipakai; untuk kasus sederhana, data class dan argumen bernama sudah cukup.

KODE
class Struk {
    private val baris = mutableListOf<Pair<String, Int>>()
    var toko = ""
    fun item(nama: String, harga: Int, qty: Int = 1) { baris += nama to harga * qty }
    fun cetak() {
        println("== $toko ==")
        baris.forEach { (n, h) -> println("${n.padEnd(12)}${h.toString().padStart(8)}") }
        println("TOTAL".padEnd(12) + baris.sumOf { it.second }.toString().padStart(8))
    }
}

fun struk(isi: Struk.() -> Unit) = Struk().apply(isi)

fun main() {
    struk {
        toko = "Kopi Kita"
        item("Kopi Gayo", 85000)
        item("Gula Aren", 25000, qty = 2)
    }.cetak()
}
KELUARAN
== Kopi Kita ==
Kopi Gayo      85000
Gula Aren      50000
TOTAL         135000

Poin penting

  • Lambda dengan receiver: Builder.() -> Unit.
  • Gradle KTS, Ktor, dan Compose adalah DSL.
  • @DslMarker untuk mencegah salah lingkup.
