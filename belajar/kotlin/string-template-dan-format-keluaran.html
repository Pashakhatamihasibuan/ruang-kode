String template dan format keluaran

Buka versi interaktif

Kotlin menyisipkan nilai dengan string template: "$nama" dan "${a + b}". Untuk format seperti printf, pakai "%.2f".format(ipk) atau String.format(...). Spesifikasinya sama dengan Java: %s, %d, %.2f, %-10s, %05d, %,d.

Fungsi padStart dan padEnd juga tersedia, dan raw string """...""" dengan trimIndent() memudahkan teks banyak baris.

Pemisah ribuan mengikuti lokal. Untuk format Indonesia tulis String.format(Locale("id", "ID"), "%,d", 7500000) yang menghasilkan 7.500.000, atau NumberFormat.getCurrencyInstance(Locale("id", "ID")) untuk Rupiah. Contoh di bawah memakai Locale.US agar hasilnya sama di komputer mana pun.

KODE
import java.util.Locale

fun main() {
    val nama = "Rina"
    val ipk = 3.4567
    println("Nama: $nama, IPK ${"%.2f".format(Locale.US, ipk)}")
    println("[%8s] [%-8s] [%05d]".format(nama, nama, 42))
    println("INV-" + 7.toString().padStart(4, '0'))
    println("Gaji " + "%,d".format(Locale.US, 7500000))

    val barang = mapOf("Kopi susu" to 18000, "Roti bakar" to 22500)
    for ((item, harga) in barang) {
        println("%-12s %,8d".format(Locale.US, item, harga))
    }
}
KELUARAN
Nama: Rina, IPK 3.46
[    Rina] [Rina    ] [00042]
INV-0007
Gaji 7,500,000
Kopi susu      18,000
Roti bakar     22,500

Soal latihan

  1. Buat tabel nilai: Andi 85.5, Budi 90.0, Citra 78.4. Nama rata kiri lebar 10, nilai rata kanan lebar 6.

    Petunjuk

    "%-10s%6s".format(nama, nilai.toString()).

    Lihat jawaban
    KODE
    fun main() {
    val nilai = mapOf("Andi" to 85.5, "Budi" to 90.0, "Citra" to 78.4)
    println("%-10s%6s".format("Nama", "Nilai"))
    for ((n, v) in nilai) {
        println("%-10s%6s".format(n, v.toString()))
    }
}

  2. Ubah nomor [7, 42, 315] menjadi INV-0007, INV-0042, INV-0315 memakai format specifier.

    Petunjuk

    %04d mengisi nol sampai lebar 4.

    Lihat jawaban
    KODE
    fun main() {
    for (n in listOf(7, 42, 315)) println("INV-%04d".format(n))
}

Poin penting

  • $nama dan ${ekspresi}.
  • "%.2f".format(x) memakai spesifikasi gaya printf.
  • Locale("id","ID") untuk format Indonesia.

Cek pemahaman

Jawaban: %03d

0 di depan lebar berarti isi nol.
