Pewarisan, interface, dan visibility

Buka versi interaktif

Class Kotlin secara bawaan final (tidak bisa diwarisi). Tandai dengan open agar bisa diwarisi, dan method dengan open agar bisa di-override. abstract class tidak bisa dibuat objeknya dan bisa berisi method tanpa isi.

Interface mendefinisikan kemampuan; satu class bisa mengimplementasikan banyak interface, dan interface boleh punya implementasi bawaan.

Visibility: public (bawaan), private (dalam class atau file), protected (class dan turunannya), internal (dalam satu modul Gradle).

KODE
interface BisaDiskon {
    fun diskon(harga: Int): Int = harga
}

abstract class Pembayaran(val jumlah: Int) {
    abstract fun proses(): String
    protected fun rupiah(n: Int) = "Rp" + "%,d".format(n).replace(',', '.')
}

class Qris(jumlah: Int) : Pembayaran(jumlah), BisaDiskon {
    override fun diskon(harga: Int) = harga - 2_000
    override fun proses() = "QRIS ${rupiah(diskon(jumlah))}"
}

open class Transfer(jumlah: Int, private val bank: String) : Pembayaran(jumlah) {
    override fun proses() = "Transfer ${rupiah(jumlah)} ke $bank"
}

fun main() {
    val daftar: List<Pembayaran> = listOf(Qris(50_000), Transfer(120_000, "BSI"))
    daftar.forEach { println(it.proses()) }
}
KELUARAN
QRIS Rp48.000
Transfer Rp120.000 ke BSI

Soal latihan

  1. Buat interface Bentuk dengan fungsi luas(), implementasikan Persegi(sisi) dan Segitiga(alas, tinggi), lalu cetak luas Persegi(4) dan Segitiga(6, 3).

    Petunjuk

    Pakai Double; luas segitiga = 0.5 × alas × tinggi.

    Lihat jawaban
    KODE
    interface Bentuk { fun luas(): Double }
class Persegi(val s: Double) : Bentuk { override fun luas() = s * s }
class Segitiga(val a: Double, val t: Double) : Bentuk { override fun luas() = 0.5 * a * t }

fun main() {
    listOf(Persegi(4.0), Segitiga(6.0, 3.0)).forEach { println(it.luas()) }
}
    KELUARAN
    16.0
9.0

Poin penting

  • Class final secara bawaan; pakai open.
  • Satu class, banyak interface.
  • public, internal, protected, private.
