Generics, enum class, dan object

Buka versi interaktif

enum class mendaftar pilihan pasti dan boleh punya properti: enum class Ukuran(val ml: Int). Daftar semua nilainya ada di Ukuran.entries, dan when pada enum tidak butuh else jika semua cabang ditulis.

Generics membuat class dan fungsi yang bekerja untuk banyak tipe: class Kotak<T>(val isi: T). Batas tipe ditulis <T : Comparable<T>> agar isi bisa dibandingkan.

object membuat singleton, objek yang hanya ada satu, misalnya konfigurasi aplikasi. companion object berisi anggota milik class (mirip static di Java), sering dipakai untuk factory seperti Pengguna.tamu().

KODE
enum class Ukuran(val ml: Int) { KECIL(250), SEDANG(350), BESAR(500) }

class Kotak<T>(val isi: T) {
    fun info() = "Kotak berisi $isi"
}

fun <T : Comparable<T>> terbesar(xs: List<T>): T =
    xs.reduce { a, b -> if (a > b) a else b }

object Konfigurasi {
    const val VERSI = "1.0.0"
    var mode = "terang"
}

class Pengguna private constructor(val nama: String) {
    companion object {
        fun tamu() = Pengguna("Tamu")
    }
}

fun main() {
    for (u in Ukuran.entries) println("${u.name}: ${u.ml} ml (urutan ${u.ordinal})")
    println(Ukuran.valueOf("SEDANG").ml)
    println(Kotak(7).info())
    println(Kotak("kopi").info())
    println(terbesar(listOf(3, 9, 2)))
    println(terbesar(listOf("apel", "zaitun", "mangga")))
    Konfigurasi.mode = "gelap"
    println("Versi ${Konfigurasi.VERSI}, mode ${Konfigurasi.mode}")
    println(Pengguna.tamu().nama)
}

Soal latihan

  1. Buat enum Status dengan properti label, lalu cetak nomor urut dan labelnya.

    Petunjuk

    enum class Status(val label: String) { MENUNGGU("Menunggu bayar"), ... }

    Lihat jawaban
    KODE
    enum class Status(val label: String) {
    MENUNGGU("Menunggu bayar"),
    DIKIRIM("Sedang dikirim"),
    SELESAI("Sudah diterima")
}

fun main() {
    for (s in Status.entries) println("${s.ordinal + 1}. ${s.label}")
}

  2. Buat fungsi generik tukar yang membalik isi Pair.

    Petunjuk

    fun <A, B> tukar(p: Pair<A, B>) = Pair(p.second, p.first).

    Lihat jawaban
    KODE
    fun <A, B> tukar(p: Pair<A, B>): Pair<B, A> = Pair(p.second, p.first)

fun main() {
    println(tukar(1 to "satu"))
}

  3. Buat object Penghitung dengan fungsi naik() yang mengembalikan nilai berikutnya.

    Petunjuk

    object menyimpan var nilai yang sama untuk seluruh program.

    Lihat jawaban
    KODE
    object Penghitung {
    private var n = 0
    fun naik() = ++n
}

fun main() {
    Penghitung.naik()
    Penghitung.naik()
    println("Nilai: ${Penghitung.naik()}")
}

Poin penting

  • enum class boleh punya properti; entries berisi semua nilai.
  • Generics <T> dengan batas tipe.
  • object = singleton; companion object = anggota class.
