Delegation: by lazy, observable, dan class delegation

Buka versi interaktif

Kata kunci by menyerahkan pekerjaan ke objek lain. val x by lazy { } menghitung nilai sekali saat pertama dipakai, cocok untuk objek mahal. Delegates.observable menjalankan kode setiap nilai berubah.

Class delegation (class A(b: B) : Antarmuka by b) meneruskan semua fungsi interface ke objek lain, lalu kita hanya meng-override yang perlu diubah. Ini alternatif pewarisan yang lebih fleksibel ("composition over inheritance").

Di Android, by viewModels() dan by remember { mutableStateOf() } adalah delegation juga.

KODE
import kotlin.properties.Delegates

class Toko {
    val katalog: List<String> by lazy {
        println("Memuat katalog...")
        listOf("Kopi Gayo", "Kopi Toraja")
    }
    var stok: Int by Delegates.observable(10) { _, lama, baru ->
        println("Stok berubah $lama -> $baru")
    }
}

interface Pencatat { fun catat(pesan: String) }
class PencatatKonsol : Pencatat { override fun catat(pesan: String) = println("[LOG] $pesan") }
class Kasir(log: Pencatat) : Pencatat by log

fun main() {
    val t = Toko()
    println("Toko dibuat")
    println(t.katalog.size)
    println(t.katalog.first())
    t.stok = 7
    Kasir(PencatatKonsol()).catat("Transaksi 1")
}

Poin penting

  • by lazy: dihitung sekali saat pertama dipakai.
  • observable: kode setiap nilai berubah.
  • Class delegation: composition over inheritance.
