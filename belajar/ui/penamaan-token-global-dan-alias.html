Penamaan token global dan alias

Buka versi interaktif

Token disusun dalam tiga lapis. Global atau primitive: nilai mentah tanpa makna, misalnya blue-600: #1D5FA8, space-4: 16px. Alias atau semantic: peran, merujuk ke global, misalnya color-action-primary: {blue-600}, color-text-danger: {red-700}. Component: khusus satu komponen, merujuk ke alias, misalnya button-primary-bg: {color-action-primary}.

Komponen hanya boleh memakai token alias atau component, tidak pernah global langsung. Dengan begitu, rebranding dari biru ke hijau cukup mengubah satu baris alias. Dark mode cukup mengubah ke mana alias menunjuk.

Pola penamaan yang umum: kategori-peran-varian-state, misalnya color-bg-surface, color-text-muted, color-border-input-focus. Pakai kata yang dipahami desainer dan developer, dan konsisten dalam satu bahasa.

Pratinjau baru punya token global. Buat token alias untuk aksi utama.

HTML
<button class="tombol">Bayar sekarang</button>
CSS
:root {
  /* global */
  --blue-600: #1D5FA8;
  --green-600: #1E7B45;
  --white: #FFFFFF;
  /* alias: tulis di sini */
}
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.tombol { background: var(--color-action-primary, #999); color: var(--white); border: 0; padding: 16px 24px; border-radius: 10px; font: inherit; font-weight: 600; }

Tantangan

  1. Tambahkan token alias --color-action-primary: var(--green-600) di :root. Tombol akan berubah hijau tanpa menyentuh aturan .tombol.

Soal latihan

  1. Kelompokkan token ini ke global, alias, atau component: blue-600, color-text-muted, button-primary-bg, space-4, color-border-focus, card-radius.

    Petunjuk

    Global = nilai mentah; alias = peran; component = khusus komponen.

    Lihat jawaban
    CONTOH
    Global    : blue-600, space-4
Alias     : color-text-muted, color-border-focus
Component : button-primary-bg, card-radius

Poin penting

  • Tiga lapis: global, alias (semantic), component.
  • Komponen tidak memakai token global langsung.
  • Pola nama: kategori-peran-varian-state.
