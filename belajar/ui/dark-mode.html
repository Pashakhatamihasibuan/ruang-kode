Dark mode

Buka versi interaktif

Dark mode bukan sekadar membalik warna. Prinsipnya: (1) latar abu-abu sangat gelap (#121212 sampai #1C1B1F), bukan hitam murni, agar bayangan dan lapisan tetap terlihat; (2) teks putih yang sedikit diredam (sekitar 87% opasitas) agar tidak menyilaukan; (3) elevasi ditunjukkan dengan latar yang sedikit lebih terang, bukan bayangan; (4) warna aksen dikurangi saturasinya dan dinaikkan lightness-nya (tingkat 200 sampai 300), karena warna pekat bergetar di atas latar gelap.

Implementasi yang rapi memakai token: komponen hanya memakai var(--bg), var(--fg), var(--surface). Lalu tema gelap cukup mendefinisikan ulang nilai token di @media (prefers-color-scheme: dark) atau di [data-theme="dark"].

Kontras tetap wajib diuji di kedua tema. Gambar dan ilustrasi juga perlu dicek: logo hitam akan hilang di latar gelap.

Aplikasi di pratinjau sudah memakai token, tetapi tema gelapnya belum ditulis.

HTML
<div class="app" data-theme="dark">
  <div class="kartu">
    <h3>Ringkasan belajar</h3>
    <p>3 pelajaran selesai hari ini.</p>
    <button>Lanjutkan</button>
  </div>
</div>
CSS
:root, [data-theme="light"] { --bg: #FFFFFF; --surface: #F3F4F6; --fg: #111827; --accent: #1D5FA8; --on-accent: #FFFFFF; }
/* tulis token tema gelap di sini */

body { margin: 0; font-family: system-ui, sans-serif; }
.app { background: var(--bg); color: var(--fg); padding: 24px; min-height: 100vh; box-sizing: border-box; }
.kartu { background: var(--surface); padding: 24px; border-radius: 16px; max-width: 320px; }
button { background: var(--accent); color: var(--on-accent); border: 0; padding: 10px 20px; border-radius: 10px; }

Tantangan

  1. Tulis aturan [data-theme="dark"] yang mengisi token: --bg: #121417, --surface: #1E2227, --fg: #E6E8EB, --accent: #8DB8F2, --on-accent: #0B1B33.

Soal latihan

  1. Tulis token warna untuk tema terang dan gelap yang mengikuti pengaturan sistem, dengan penimpa manual lewat data-theme.

    Petunjuk

    Bare :root, media query dengan :not, dan [data-theme].

    Lihat jawaban
    CSS
    :root { --bg: #FFFFFF; --fg: #111827; --surface: #F3F4F6; }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --bg: #121417; --fg: #E6E8EB; --surface: #1E2227; }
}
:root[data-theme="dark"] { --bg: #121417; --fg: #E6E8EB; --surface: #1E2227; }
body { background: var(--bg); color: var(--fg); }

Poin penting

  • Latar abu-abu sangat gelap, bukan hitam murni.
  • Elevasi dengan latar lebih terang, aksen lebih lembut.
  • Komponen memakai token, tema hanya mengganti nilainya.
