State dan hierarki tombol

Buka versi interaktif

Hierarki tombol: primary (latar penuh, satu per layar untuk aksi utama), secondary (garis tepi atau latar lembut), tertiary atau text button (hanya teks, untuk aksi ringan seperti "Batal"). Aksi berbahaya (hapus) memakai warna danger, dan sebaiknya bukan tombol yang paling menonjol.

Setiap tombol butuh tujuh state: default, hover (desktop), focus-visible (navigasi keyboard), pressed atau active, disabled, loading, dan kadang selected. State yang paling sering terlupa adalah focus: tanpa garis fokus yang jelas, pengguna keyboard tidak tahu sedang berada di mana.

Gunakan :focus-visible, bukan :focus, agar garis fokus muncul saat navigasi keyboard tetapi tidak saat tombol diklik dengan mouse. WCAG 2.2 meminta indikator fokus yang jelas: garis minimal 2 px dengan kontras 3:1.

Tombol di pratinjau sudah punya hover dan disabled, tetapi belum punya fokus. Tekan Tab di pratinjau untuk melihat masalahnya.

HTML
<div class="aksi">
  <button class="btn primary">Simpan</button>
  <button class="btn secondary">Pratinjau</button>
  <button class="btn tertiary">Batal</button>
  <button class="btn primary" disabled>Kirim</button>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.aksi { display: flex; gap: 8px; flex-wrap: wrap; }
.btn { font: inherit; font-weight: 600; padding: 10px 20px; border-radius: 10px; border: 1px solid transparent; cursor: pointer; outline: none; min-height: 44px; }
.primary { background: #1D5FA8; color: #fff; }
.primary:hover { background: #174C86; }
.secondary { background: #fff; color: #1D5FA8; border-color: #1D5FA8; }
.secondary:hover { background: #E8F1FB; }
.tertiary { background: transparent; color: #1D5FA8; }
.btn:disabled { background: #E4E7EB; color: #7B8794; border-color: transparent; cursor: not-allowed; }

Tantangan

  1. Tambahkan aturan .btn:focus-visible dengan outline minimal 2px dan outline-offset 2px.

Soal latihan

  1. Tulis state loading untuk tombol: teks disembunyikan, muncul spinner, dan tombol tidak bisa diklik.

    Petunjuk

    Pakai atribut aria-busy dan pointer-events.

    Lihat jawaban
    CSS
    .btn[aria-busy="true"] { color: transparent; pointer-events: none; position: relative; }
.btn[aria-busy="true"]::after {
  content: ""; position: absolute; inset: 0; margin: auto; width: 18px; height: 18px;
  border: 2px solid #fff; border-right-color: transparent; border-radius: 50%;
  animation: putar .7s linear infinite;
}
@keyframes putar { to { transform: rotate(360deg); } }

Poin penting

  • Primary satu per layar, secondary, tertiary.
  • State: default, hover, focus-visible, pressed, disabled, loading.
  • Focus-visible minimal 2 px, kontras 3:1.

Cek pemahaman

Berapa tombol primary yang disarankan dalam satu layar?

Jawaban: Satu

Satu aksi utama yang jelas.

Kenapa memakai :focus-visible, bukan :focus?

Jawaban: Garis fokus muncul untuk keyboard, tidak saat diklik mouse

Tetap aksesibel tanpa mengganggu pengguna mouse.
