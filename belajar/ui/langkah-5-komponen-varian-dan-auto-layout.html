Langkah 5: komponen, varian, dan auto layout

Buka versi interaktif

Ubah elemen berulang menjadi komponen Figma: tombol, input, kartu menu, chip kategori, bar keranjang. Setiap komponen punya varian (primer, sekunder, teks) dan properti (ukuran, ikon kiri, state). Bangun dengan auto layout agar ukurannya mengikuti isi dan mudah dibaca developer.

Wajib lengkap: state default, hover, pressed, focus, disabled, loading untuk tombol; default, focus, filled, error, disabled untuk input. Komponen yang statenya tidak lengkap akan membuat developer menebak.

Beri nama layer dan komponen dengan rapi (Button/Primary/Large), dan pakai variables untuk warna serta jarak agar mode gelap tinggal berganti mode.

CONTOH
Komponen: Button
  Properti : Varian = Primer | Sekunder | Teks
             Ukuran = Besar (48) | Sedang (40)
             Ikon kiri = ya | tidak
             State = Default | Hover | Pressed | Focus | Disabled | Loading
  Auto layout: horizontal, padding 16 x 12, gap 8, hug contents
  Token    : fill = color/action/primary, teks = color/text/on-primary, radius = radius/md (12)

Komponen: Kartu menu
  Slot     : foto 64 x 64 r8 · nama (16 semibold) · keterangan (14) · harga (16 bold) · tombol tambah
  Varian   : Normal | Habis (foto 50% + label 'Habis') | Di keranjang (stepper - 1 +)

Poin penting

  • Komponen + varian + properti.
  • State lengkap untuk setiap komponen interaktif.
  • Auto layout dan variables untuk konsistensi.
