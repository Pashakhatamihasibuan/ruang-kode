UI Design · Modul 2 · Praktik langsung

Peran tipografi semantik

Buka versi interaktif

Daripada menamai gaya teks dengan ukurannya ("Inter 24 Bold"), design system modern menamainya dengan peran: display (angka atau judul sangat besar), headline (judul halaman), title (judul kartu dan dialog), body (isi), dan label (tombol, tab, chip, keterangan kecil). Material 3 memakai lima peran ini, masing-masing dalam ukuran large, medium, dan small.

Kenapa peran? Karena ukuran bisa berubah (misalnya di tablet semua sedikit lebih besar), tetapi peran tidak. Developer cukup menulis title-medium, dan jika desainer mengubah ukurannya, seluruh aplikasi ikut berubah.

Setiap peran adalah paket: ukuran, line-height, ketebalan, tracking, dan kadang huruf kapital. Di Figma, simpan sebagai Text Style dengan nama bertingkat seperti Title/Medium. Di kode, simpan sebagai kelas atau token.

Pratinjau sudah punya kelas peran, tetapi .label belum lengkap.

HTML
<section class="kartu">
  <p class="label">Progres minggu ini</p>
  <p class="display">86%</p>
  <h3 class="title">Kelas UI Design</h3>
  <p class="body">Kamu sudah menyelesaikan 26 dari 30 pelajaran. Tinggal modul handoff.</p>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; color: #1D1B20; }
.kartu { max-width: 340px; padding: 24px; border-radius: 16px; background: #F3EDF7; }
.kartu > * { margin: 0 0 8px; }
.display { font-size: 45px; line-height: 52px; font-weight: 400; letter-spacing: 0; }
.title { font-size: 16px; line-height: 24px; font-weight: 500; letter-spacing: 0.15px; }
.body { font-size: 14px; line-height: 20px; font-weight: 400; letter-spacing: 0.25px; }
.label { font-size: 12px; line-height: 16px; }

Tantangan

  1. Lengkapi peran .label: tebal 500, huruf kapital (uppercase), dan letter-spacing positif.

Soal latihan

  1. Buat token peran tipografi headline-small, title-medium, body-large, dan label-large sebagai CSS variables shorthand font.

    Petunjuk

    Shorthand font: tebal ukuran/line-height keluarga.

    Lihat jawaban
    CSS
    :root {
  --font-family: system-ui, sans-serif;
  --headline-small: 400 24px/32px var(--font-family);
  --title-medium: 500 16px/24px var(--font-family);
  --body-large: 400 16px/24px var(--font-family);
  --label-large: 500 14px/20px var(--font-family);
}
h2 { font: var(--headline-small); }

Poin penting

  • Namai gaya teks dengan peran, bukan ukuran.
  • Peran: display, headline, title, body, label.
  • Satu peran = paket ukuran, line-height, tebal, tracking.

Cek pemahaman

Nama gaya teks mana yang paling tahan perubahan?

Jawaban: title-large

Peran tidak berubah walau ukurannya diubah.

Teks pada tombol dan tab memakai peran?

Jawaban: label

Label untuk teks kontrol yang pendek.
