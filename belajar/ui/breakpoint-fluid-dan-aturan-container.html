Breakpoint fluid dan aturan container

Buka versi interaktif

Breakpoint adalah lebar layar tempat tata letak berubah. Titik yang umum: < 600 (ponsel), 600 sampai 839 (tablet tegak dan lipat), 840 sampai 1199 (tablet mendatar, laptop kecil), ≥ 1200 (desktop). Material 3 menamainya compact, medium, expanded, large, dan extra-large. Tentukan breakpoint dari konten yang mulai rusak, bukan dari merek perangkat.

Di antara breakpoint, layout harus fluid: kolom melebar mengikuti layar. Grid web yang umum: 4 kolom di ponsel (margin 16 px), 8 kolom di tablet (margin 24 sampai 32 px), 12 kolom di desktop. Container membatasi lebar maksimum isi (misalnya 1200 px) agar baris teks tidak terlalu panjang di monitor lebar.

Teknik CSS tanpa media query: grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)) membuat kartu otomatis 1, 2, 3, atau 4 kolom sesuai ruang. Container query (@container) membuat komponen menyesuaikan lebar induknya, bukan lebar layar.

Grid kartu di pratinjau terkunci 3 kolom dan sesak di layar kecil.

HTML
<div class="container">
  <div class="grid">
    <div class="kartu">Dart</div><div class="kartu">Flutter</div><div class="kartu">Kotlin</div>
    <div class="kartu">Compose</div><div class="kartu">KMP</div><div class="kartu">UI Design</div>
  </div>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; }
.container { max-width: 1200px; margin: 0 auto; padding: 16px clamp(16px, 4vw, 32px); }
.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; }
.kartu { padding: 24px 16px; border-radius: 12px; background: #E8F1FB; font-weight: 600; }

Tantangan

  1. Ubah .grid menjadi fluid: grid-template-columns: repeat(auto-fit, minmax(160px, 1fr)).

Soal latihan

  1. Buat komponen kartu yang berubah menjadi horizontal saat induknya minimal 480px, memakai container query.

    Petunjuk

    container-type: inline-size, lalu @container.

    Lihat jawaban
    CSS
    .wadah { container-type: inline-size; }
.kartu { display: grid; gap: 12px; }
@container (min-width: 480px) {
  .kartu { grid-template-columns: 160px 1fr; }
}

Poin penting

  • Breakpoint dari konten: compact, medium, expanded.
  • 4, 8, 12 kolom; container membatasi lebar maksimum.
  • auto-fit + minmax dan container query.

Cek pemahaman

Konten yang menentukan.

repeat(auto-fit, minmax(240px, 1fr)) di layar 1000 px menghasilkan berapa kolom (abaikan gap)?

Jawaban: 4

1000 / 240 = 4 kolom muat.
