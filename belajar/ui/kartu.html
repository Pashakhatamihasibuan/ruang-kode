Kartu

Buka versi interaktif

Kartu mengelompokkan informasi tentang satu hal: satu produk, satu artikel, satu kelas. Anatominya: media (gambar), header (judul, subjudul), isi singkat, dan aksi. Tidak semua bagian wajib, tetapi urutannya sebaiknya konsisten di seluruh produk.

Gambar di kartu harus punya rasio tetap (16:9, 4:3, atau 1:1), agar grid kartu rapi walau foto aslinya berbeda ukuran. Di CSS: aspect-ratio: 16 / 9 dengan object-fit: cover. Di Figma: frame dengan rasio tetap dan gambar mode Fill.

Jika seluruh kartu bisa diklik, jangan taruh terlalu banyak tombol di dalamnya, karena target klik bertumpuk membingungkan. Pilih: kartu yang bisa diklik dengan satu tujuan, atau kartu statis dengan tombol aksi yang jelas.

Area media di kartu pratinjau belum punya rasio, sehingga tingginya nol.

HTML
<article class="kartu">
  <div class="media" role="img" aria-label="Ilustrasi kelas Flutter"></div>
  <div class="isi">
    <p class="label">Mobile · Pemula</p>
    <h3>Flutter dari Nol</h3>
    <p>Bangun aplikasi Android dan iOS pertamamu dalam 4 minggu.</p>
    <a href="#" class="aksi">Lihat kelas</a>
  </div>
</article>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; background: #F4F5F7; }
.kartu { max-width: 320px; background: #fff; border-radius: 16px; overflow: hidden; box-shadow: 0 1px 3px rgb(0 0 0 / .12); }
.media { width: 100%; background: linear-gradient(135deg, #0D5DB8, #63D9B5); }
.isi { padding: 16px 24px 24px; }
.isi > * { margin: 0 0 8px; }
.label { font-size: 12px; color: #52606D; text-transform: uppercase; letter-spacing: .06em; }
.aksi { color: #0D5DB8; font-weight: 600; }

Tantangan

  1. Beri .media rasio aspect-ratio: 16 / 9.

Soal latihan

  1. Buat grid kartu 1 sampai 4 kolom otomatis dengan gambar 4:3 yang tidak gepeng.

    Petunjuk

    auto-fill minmax dan object-fit.

    Lihat jawaban
    CSS
    .grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); gap: 16px; }
.kartu img { width: 100%; aspect-ratio: 4 / 3; object-fit: cover; display: block; }

Poin penting

  • Satu kartu, satu hal.
  • Media dengan rasio tetap dan object-fit: cover.
  • Pilih: seluruh kartu bisa diklik, atau tombol aksi yang jelas.

Cek pemahaman

Kenapa gambar kartu diberi aspect-ratio tetap?

Jawaban: Agar grid rapi walau ukuran foto asli berbeda

Tinggi kartu menjadi seragam.

Kartu yang seluruhnya bisa diklik berisi 4 tombol berbeda. Masalahnya?

Jawaban: Target klik bertumpuk dan membingungkan

Pilih satu pola interaksi.

Kerjakan latihannya di aplikasi

Sebelumnya: State dan hierarki tombol

Berikutnya: Modal, sheet, dan popover
