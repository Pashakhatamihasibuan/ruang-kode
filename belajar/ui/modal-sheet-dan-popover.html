Modal, sheet, dan popover

Buka versi interaktif

Ketiganya adalah lapisan di atas konten. Modal dialog menghentikan alur dan meminta keputusan (konfirmasi hapus, form singkat); latar di belakangnya digelapkan (scrim) dan tidak bisa diklik. Bottom sheet muncul dari bawah layar ponsel, mudah dijangkau jempol, cocok untuk pilihan dan filter. Popover atau menu kecil menempel pada elemen pemicunya, tanpa menghentikan alur.

Aturan pakai: modal hanya untuk hal yang benar-benar butuh perhatian, karena setiap modal memotong pekerjaan pengguna. Selalu sediakan cara keluar yang jelas (tombol tutup, tombol Batal, tombol Esc, tap di scrim). Di dalam modal, fokus keyboard harus terkunci (focus trap) dan kembali ke pemicu saat ditutup.

Di HTML modern, pakai <dialog> dengan showModal() untuk modal, dan atribut popover untuk popover. Keduanya sudah menangani lapisan, Esc, dan aksesibilitas dasar.

Sheet di pratinjau masih mengalir di dalam halaman. Tempelkan ke bawah layar.

HTML
<main class="hal"><h2>Daftar kelas</h2><p>Ketuk Filter untuk menyaring kelas.</p></main>
<div class="scrim"></div>
<section class="sheet" aria-label="Filter">
  <div class="pegangan"></div>
  <h3>Filter kelas</h3>
  <label><input type="checkbox" checked> Gratis</label>
  <label><input type="checkbox"> Bersertifikat</label>
  <button>Terapkan</button>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; min-height: 100vh; }
.hal { padding: 16px; }
.scrim { position: fixed; inset: 0; background: rgb(0 0 0 / .4); }
.sheet { background: #fff; border-radius: 20px 20px 0 0; padding: 12px 24px 24px; display: grid; gap: 12px; z-index: 1; }
.pegangan { width: 32px; height: 4px; border-radius: 2px; background: #9AA5B1; margin: 0 auto 8px; }
.sheet h3 { margin: 0; }
.sheet button { padding: 12px; border: 0; border-radius: 12px; background: #1D5FA8; color: #fff; font: inherit; font-weight: 600; }

Tantangan

  1. Jadikan .sheet bottom sheet: position: fixed, menempel di bawah (left: 0; right: 0; bottom: 0).

Soal latihan

  1. Tulis modal konfirmasi hapus memakai elemen dialog, dengan tombol Batal dan Hapus.

    Petunjuk

    dialog + form method="dialog" menutup otomatis.

    Lihat jawaban
    HTML
    <button onclick="konfirmasi.showModal()">Hapus kelas</button>
<dialog id="konfirmasi" aria-labelledby="judul-hapus">
  <h2 id="judul-hapus">Hapus kelas ini?</h2>
  <p>Progres belajar di kelas ini akan hilang.</p>
  <form method="dialog">
    <button value="batal">Batal</button>
    <button value="hapus" class="danger">Hapus</button>
  </form>
</dialog>

Poin penting

  • Modal menghentikan alur, sheet dari bawah, popover menempel pada pemicu.
  • Selalu ada cara keluar: tutup, Batal, Esc, tap scrim.
  • Pakai dialog dan atribut popover.
