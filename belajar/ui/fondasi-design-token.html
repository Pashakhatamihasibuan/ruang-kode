Fondasi design token

Buka versi interaktif

Design token adalah keputusan desain yang diberi nama dan disimpan sebagai data: warna, ukuran huruf, jarak, radius, bayangan, durasi animasi. Bukan #1D5FA8 yang ditulis di 40 tempat, melainkan color.brand.600 yang dirujuk 40 kali. Mengubah satu token mengubah seluruh produk.

Token ditulis sekali dalam format netral (JSON mengikuti spesifikasi DTCG, Design Tokens Community Group), lalu diubah otomatis menjadi CSS variables, konstanta Dart, Kotlin, atau Swift dengan alat seperti Style Dictionary. Di Figma, token disimpan sebagai Variables.

Kategori token dasar: color, typography (keluarga, ukuran, tebal, line-height), spacing, radius, shadow atau elevation, motion (durasi, easing), dan breakpoint.

Tombol di pratinjau masih memakai warna dan angka langsung. Ganti dengan token.

HTML
<button class="tombol">Mulai belajar</button>
CSS
:root {
  --color-brand-600: #1D5FA8;
  --color-white: #FFFFFF;
  --space-2: 16px;
  --space-3: 24px;
  --radius-md: 10px;
}
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.tombol { background: #1D5FA8; color: #FFFFFF; padding: 16px 24px; border-radius: 10px; border: 0; font: inherit; font-weight: 600; }

Tantangan

  1. Ubah .tombol agar semua nilainya memakai token: var(--color-brand-600), var(--color-white), var(--space-2), var(--space-3), dan var(--radius-md).

Soal latihan

  1. Tulis token tombol dalam format JSON DTCG: warna latar, warna teks, dan radius.

    Petunjuk

    Setiap token punya $value dan $type.

    Lihat jawaban
    CONTOH
    {
  "button": {
    "bg":     { "$type": "color",     "$value": "{color.action.primary}" },
    "text":   { "$type": "color",     "$value": "{color.white}" },
    "radius": { "$type": "dimension", "$value": "10px" }
  }
}

Poin penting

  • Token = keputusan desain bernama, disimpan sebagai data.
  • Format DTCG, diubah ke banyak platform dengan Style Dictionary.
  • Kategori: color, typography, spacing, radius, shadow, motion.
