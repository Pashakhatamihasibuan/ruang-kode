Anatomi input form

Buka versi interaktif

Input form yang lengkap terdiri dari: label (selalu terlihat, di atas input), field (kotak isian), placeholder opsional (contoh format, bukan pengganti label), helper text (petunjuk di bawah), pesan error (menggantikan helper saat salah), serta penanda wajib atau opsional.

Kesalahan paling umum: memakai placeholder sebagai label. Saat pengguna mulai mengetik, placeholder hilang dan pengguna lupa field itu untuk apa. Placeholder juga biasanya abu-abu muda dan gagal kontras.

Di kode, label harus terhubung ke input dengan <label for="id">, agar pembaca layar menyebutkan labelnya dan mengklik label ikut memfokuskan input. Pesan error dihubungkan dengan aria-describedby, dan field yang salah diberi aria-invalid="true".

Field email di pratinjau hanya punya placeholder. Tambahkan label yang terhubung.

HTML
<form class="form">
  <div class="field">
    <input id="email" type="email" placeholder="Email" aria-describedby="email-help">
    <p id="email-help" class="help">Kami kirim kode verifikasi ke alamat ini.</p>
  </div>
</form>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; color: #1F2933; }
.form { max-width: 320px; }
label { display: block; font-size: 14px; font-weight: 600; margin-bottom: 4px; }
input { width: 100%; box-sizing: border-box; padding: 12px; font-size: 16px; border: 1px solid #7B8794; border-radius: 8px; }
input:focus { outline: 2px solid #1D5FA8; outline-offset: 2px; }
.help { font-size: 13px; color: #52606D; margin: 4px 0 0; }

Tantangan

  1. Tambahkan <label for="email">Email</label> di atas input, lalu ubah placeholder menjadi contoh format seperti nama@contoh.com.

Soal latihan

  1. Buat field kata sandi lengkap: label, input, helper "Minimal 8 karakter", dan tombol tampilkan sandi dengan aria-label.

    Petunjuk

    Helper dihubungkan dengan aria-describedby.

    Lihat jawaban
    HTML
    <label for="sandi">Kata sandi</label>
<div class="sandi">
  <input id="sandi" type="password" aria-describedby="sandi-help" autocomplete="new-password">
  <button type="button" aria-label="Tampilkan kata sandi">👁</button>
</div>
<p id="sandi-help">Minimal 8 karakter.</p>

Poin penting

  • Label selalu terlihat, placeholder hanya contoh format.
  • label for menghubungkan label ke input.
  • Error: aria-invalid dan aria-describedby.

Cek pemahaman

Kenapa placeholder tidak boleh menggantikan label?

Jawaban: Hilang saat mengetik dan biasanya kontrasnya rendah

Pengguna lupa field itu untuk apa.

Atribut apa yang menghubungkan pesan error ke input?

Jawaban: aria-describedby

Pembaca layar membacakan pesan itu saat input difokuskan.

Kerjakan latihannya di aplikasi

Sebelumnya: Dark mode

Berikutnya: State dan hierarki tombol
