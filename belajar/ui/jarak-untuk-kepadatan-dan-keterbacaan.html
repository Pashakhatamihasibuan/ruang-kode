Jarak untuk kepadatan dan keterbacaan

Buka versi interaktif

Kepadatan (density) adalah seberapa banyak informasi di satu layar. Aplikasi kasir, dashboard, dan tabel data butuh kepadatan tinggi agar pengguna ahli melihat banyak data sekaligus. Aplikasi belajar, onboarding, dan halaman marketing butuh kepadatan rendah agar nyaman dibaca.

Tiga alat pengatur kepadatan: padding di dalam komponen (sel tabel, tombol), gap antar elemen, dan line-height teks. Untuk paragraf, line-height 1,4 sampai 1,6 kali ukuran huruf. Untuk sel tabel, padding vertikal 8 px (padat) sampai 16 px (lega).

Banyak design system menyediakan mode kepadatan: comfortable dan compact. Material 3 menyebutnya density scale (0, -1, -2, -3), setiap tingkat mengurangi tinggi komponen 4 dp. Jangan memadatkan target sentuh di bawah 44 sampai 48 px di ponsel.

Tabel di pratinjau terlalu sesak untuk dibaca santai. Longgarkan.

HTML
<table class="tabel">
  <thead><tr><th>Kelas</th><th>Siswa</th><th>Selesai</th></tr></thead>
  <tbody>
    <tr><td>Flutter Dasar</td><td>1.240</td><td>68%</td></tr>
    <tr><td>Kotlin Pemula</td><td>980</td><td>72%</td></tr>
    <tr><td>UI Design</td><td>1.530</td><td>81%</td></tr>
  </tbody>
</table>
<p class="teks">Persentase selesai dihitung dari siswa yang menuntaskan semua pelajaran dan kuis dalam 60 hari sejak mendaftar.</p>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; color: #1F2933; }
.tabel { border-collapse: collapse; width: 100%; max-width: 420px; font-size: 14px; }
.tabel th, .tabel td { padding: 2px 4px; border-bottom: 1px solid #E4E7EB; text-align: left; }
.teks { max-width: 420px; font-size: 14px; line-height: 1.1; }

Tantangan

  1. Beri sel tabel padding vertikal minimal 12px, dan paragraf .teks line-height minimal 1.5.

Soal latihan

  1. Buat dua mode kepadatan tabel dengan atribut data: comfortable (padding sel 16px) dan compact (padding sel 8px).

    Petunjuk

    Pakai selector atribut pada tabel.

    Lihat jawaban
    CSS
    table[data-density="comfortable"] td { padding: 16px; }
table[data-density="compact"] td { padding: 8px 12px; }

Poin penting

  • Kepadatan tinggi untuk pengguna ahli, rendah untuk bacaan santai.
  • Atur dengan padding, gap, dan line-height.
  • Target sentuh tetap 44 sampai 48 px.

Cek pemahaman

Dashboard gudang untuk staf yang memantau ratusan barang paling cocok dengan kepadatan?

Jawaban: Tinggi

Pengguna ahli butuh melihat banyak data sekaligus.

Line-height yang nyaman untuk paragraf?

Jawaban: 1.4 sampai 1.6

Cukup lega tanpa terlihat terpisah-pisah.
