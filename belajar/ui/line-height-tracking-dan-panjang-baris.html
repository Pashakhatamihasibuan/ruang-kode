Line height, tracking, dan panjang baris

Buka versi interaktif

Line height (leading) adalah jarak antar baris. Paragraf butuh 1,4 sampai 1,6; judul besar cukup 1,1 sampai 1,25, karena jarak yang terlalu lega membuat baris judul terlihat terpisah.

Tracking (letter-spacing) adalah jarak antar huruf. Teks kecil berhuruf kapital (label, overline) butuh tracking positif sekitar 0,04 sampai 0,1 em agar terbaca. Judul sangat besar justru sedikit dirapatkan (-0,01 sampai -0,02 em).

Panjang baris (measure) yang nyaman adalah 45 sampai 75 karakter, ideal sekitar 65. Baris terlalu panjang membuat mata kehilangan awal baris berikutnya. Di CSS, satuan ch (lebar karakter 0) pas untuk ini: max-width: 65ch.

Artikel di pratinjau terlalu rapat dan terlalu lebar di layar besar. Perbaiki.

HTML
<article class="artikel">
  <p class="overline">Tips belajar</p>
  <h2>Belajar 30 menit sehari lebih efektif daripada 5 jam sekali seminggu</h2>
  <p class="isi">Otak memperkuat ingatan saat kita mengulang materi dengan jeda. Teknik ini disebut spaced repetition. Mulailah dengan satu pelajaran pendek, kerjakan kuisnya, lalu ulangi pelajaran yang sama dua hari kemudian sebelum lanjut ke materi baru.</p>
</article>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; color: #1F2933; }
.overline { font-size: 12px; text-transform: uppercase; color: #8A4B2A; margin: 0; }
h2 { font-size: 28px; line-height: 1.6; margin: 8px 0 16px; }
.isi { font-size: 17px; line-height: 1.15; }

Tantangan

  1. Atur: .artikel max-width 65ch, .isi line-height 1.6, dan .overline letter-spacing positif.

Soal latihan

  1. Tulis CSS untuk: overline 12px kapital tracking 0.08em, judul 32px line-height 1.2 tracking -0.01em, paragraf 17px line-height 1.6 max 65ch.

    Petunjuk

    Tiga aturan terpisah.

    Lihat jawaban
    CSS

Poin penting

  • Paragraf 1,4–1,6; judul besar 1,1–1,25.
  • Label kapital kecil: tracking positif.
  • Panjang baris 45–75 karakter, max-width: 65ch.

Cek pemahaman

Panjang baris ideal untuk paragraf?

Jawaban: Sekitar 65 karakter

Antara 45 dan 75.

Label kecil huruf kapital sebaiknya diberi tracking?

Jawaban: Positif

Huruf kapital kecil terlihat terlalu rapat tanpa tracking.
