Prinsip Gestalt

Buka versi interaktif

Gestalt adalah prinsip psikologi tentang cara otak mengelompokkan apa yang dilihat. Lima yang paling sering dipakai di UI: proximity (yang berdekatan dianggap satu kelompok), similarity (yang mirip dianggap sejenis), common region (yang berada di satu bingkai dianggap satu kelompok), closure (otak melengkapi bentuk yang terputus), dan figure-ground (memisahkan objek dari latar).

Proximity paling sering salah di form. Jika jarak label ke input-nya sama dengan jarak label ke input di atasnya, pengguna ragu label itu milik input yang mana. Aturannya: jarak di dalam kelompok harus jelas lebih kecil daripada jarak antar kelompok.

Similarity dipakai untuk link dan tombol: semua yang bisa diklik memakai warna yang sama, dan warna itu tidak dipakai untuk teks biasa. Common region dipakai untuk kartu: satu kartu, satu produk.

Form di pratinjau punya jarak yang sama di mana-mana. Perbaiki dengan proximity.

HTML
<form class="form">
  <div class="grup"><label class="lbl" for="n">Nama lengkap</label><input id="n"></div>
  <div class="grup"><label class="lbl" for="e">Email</label><input id="e" type="email"></div>
  <div class="grup"><label class="lbl" for="p">Nomor HP</label><input id="p" type="tel"></div>
</form>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; color: #1F2933; }
.form { max-width: 320px; }
.grup { margin-bottom: 12px; }
.lbl { display: block; font-size: 14px; font-weight: 600; margin-bottom: 12px; }
input { width: 100%; box-sizing: border-box; padding: 10px 12px; border: 1px solid #9AA5B1; border-radius: 8px; font-size: 16px; }

Tantangan

  1. Terapkan proximity: jarak label ke input (.lbl margin-bottom) maksimal 8px, dan jarak antar .grup minimal 24px.

Soal latihan

  1. Sebutkan prinsip Gestalt yang dipakai pada: (a) kartu produk berbingkai, (b) semua tautan berwarna sama, (c) ikon lingkaran putus-putus yang tetap terbaca sebagai lingkaran.

    Petunjuk

    Common region, similarity, closure.

    Lihat jawaban
    CONTOH
    (a) Common region
(b) Similarity
(c) Closure

  2. Tulis CSS jarak untuk daftar pengaturan: jarak judul grup ke item pertama 8px, antar item 4px, antar grup 32px.

    Petunjuk

    Jarak di dalam kelompok lebih kecil dari jarak antar kelompok.

    Lihat jawaban
    CSS
    .grup { margin-bottom: 32px; }
.grup h3 { margin: 0 0 8px; }
.grup .item + .item { margin-top: 4px; }

Poin penting

  • Proximity: jarak di dalam kelompok lebih kecil dari jarak antar kelompok.
  • Similarity: yang bisa diklik punya satu gaya yang konsisten.
  • Common region: satu bingkai, satu kelompok.

Cek pemahaman

Label berjarak 12px ke input-nya dan 12px ke input di atasnya. Prinsip apa yang dilanggar?

Jawaban: Proximity

Jarak yang sama membuat kelompok tidak jelas.

Semua link berwarna biru dan bergaris bawah. Ini memakai prinsip?

Jawaban: Similarity
