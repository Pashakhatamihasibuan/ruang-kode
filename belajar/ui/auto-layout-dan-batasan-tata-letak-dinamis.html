Auto layout dan batasan tata letak dinamis

Buka versi interaktif

Auto layout di Figma membuat frame menyusun anaknya otomatis, persis seperti flexbox di CSS: arah (horizontal atau vertikal), gap (jarak antar anak), padding, dan perataan. Saat teks tombol berubah dari "Simpan" menjadi "Simpan perubahan", tombol ikut melebar sendiri.

Setiap anak punya aturan ukuran: Hug contents (selebar isinya, sama dengan width: auto), Fill container (mengisi sisa ruang, sama dengan flex: 1), atau Fixed (ukuran tetap). Ditambah min dan max width agar tidak terlalu sempit atau lebar.

Constraints (batasan) mengatur perilaku elemen saat frame induk diubah ukurannya: menempel kiri, kanan, kiri-dan-kanan (melar), tengah, atau skala. Desain yang memakai auto layout dan constraints dengan benar sudah "responsif" sejak di Figma, dan developer tinggal menerjemahkannya ke flex dan grid.

Baris notifikasi di pratinjau: teks harus Fill, tombol harus Hug di kanan.

HTML
<div class="notif">
  <span class="ikon">🔔</span>
  <p class="isi">Kelas Kotlin dimulai besok pukul 19.00 WIB.</p>
  <button class="tutup">Tutup</button>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; }
.notif { display: flex; align-items: center; gap: 12px; padding: 12px 16px; background: #FFF7E6; border-radius: 12px; max-width: 520px; }
.isi { margin: 0; }
.tutup { font: inherit; border: 0; background: none; color: #8A4B2A; font-weight: 600; padding: 8px; }

Tantangan

  1. Jadikan .isi Fill container (flex: 1) agar tombol Tutup terdorong ke kanan.

Soal latihan

  1. Terjemahkan pengaturan Figma ini ke CSS: frame auto layout horizontal, gap 12, padding 16 24, align center; anak 1 Fixed 40×40, anak 2 Fill, anak 3 Hug.

    Petunjuk

    flex, gap, padding, align-items, flex: none / 1.

    Lihat jawaban
    CONTOH
    .baris { display: flex; align-items: center; gap: 12px; padding: 16px 24px; }
.anak1 { width: 40px; height: 40px; flex: none; }
.anak2 { flex: 1; min-width: 0; }
.anak3 { flex: none; }

Poin penting

  • Auto layout = flexbox: arah, gap, padding, perataan.
  • Hug = auto, Fill = flex: 1, Fixed = ukuran tetap.
  • Constraints mengatur perilaku saat induk diubah ukurannya.
