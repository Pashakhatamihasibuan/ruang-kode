Perataan dan keseimbangan

Buka versi interaktif

Perataan (alignment) membuat elemen terasa terhubung walau berjauhan. Setiap elemen sebaiknya sejajar dengan sesuatu: tepi kiri judul sejajar dengan tepi kiri paragraf, tombol sejajar dengan input di atasnya. Di Figma, perhatikan garis merah petunjuk saat menggeser elemen.

Untuk teks lebih dari dua baris, rata kiri paling mudah dibaca, karena mata selalu kembali ke titik awal yang sama. Rata tengah cocok untuk judul pendek atau empty state, tetapi melelahkan untuk paragraf. Jangan mencampur rata kiri dan rata tengah dalam satu kartu.

Keseimbangan adalah sebaran "berat visual" di layar. Simetris terasa formal dan stabil (halaman login). Asimetris terasa dinamis (hero dengan teks di kiri dan gambar besar di kanan), tetapi tetap butuh grid agar tidak terlihat berantakan.

Kartu di pratinjau mencampur rata tengah dan rata kiri. Samakan perataannya.

HTML
<article class="isi">
  <h3 class="tengah">Promo Akhir Bulan</h3>
  <p>Diskon 20% untuk semua kelas mobile sampai 30 November.</p>
  <p class="tengah">Gunakan kode RUANG20 saat pembayaran.</p>
  <a href="#">Lihat syarat</a>
</article>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.isi { max-width: 340px; padding: 24px; background: #FFF7E6; border-radius: 12px; }
.isi > * { margin: 0 0 8px; }
.tengah { text-align: center; }

Tantangan

  1. Buat semua isi kartu rata kiri, sejajar satu garis.

Soal latihan

  1. Halaman login: logo, judul, dua input, tombol, dan link "Lupa sandi". Usulkan perataan dan keseimbangannya, beri alasan.

    Petunjuk

    Login sederhana cocok simetris; input dan tombol sejajar satu kolom.

    Lihat jawaban
    CONTOH
    Keseimbangan simetris: satu kolom di tengah, lebar maks 400px.
Logo dan judul rata tengah (teks pendek).
Label, input, tombol rata kiri dalam kolom yang sama, lebar penuh.
Link "Lupa sandi" rata kanan di bawah field sandi, sejajar tepi kanan input.

Poin penting

  • Setiap elemen sejajar dengan sesuatu.
  • Paragraf: rata kiri. Rata tengah hanya untuk teks pendek.
  • Simetris terasa stabil, asimetris terasa dinamis.
