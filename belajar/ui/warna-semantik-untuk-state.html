Warna semantik untuk state

Buka versi interaktif

Warna semantik diberi nama berdasarkan makna, bukan rupanya: success (hijau), warning (kuning atau oranye), error atau danger (merah), dan info (biru). Setiap makna punya pasangan latar lembut, border, dan teks gelap dari skala yang sama.

Aturan WCAG 1.4.1: warna tidak boleh menjadi satu-satunya penanda. Sekitar 1 dari 12 laki-laki buta warna merah-hijau. Jadi field error diberi warna merah dan ikon dan pesan teks yang menjelaskan. Status pesanan diberi warna dan label "Lunas" atau "Batal".

Jangan memakai merah untuk hal yang bukan bahaya atau error (misalnya warna merek), karena pengguna akan mengira ada masalah. Di Indonesia, merah juga dipakai untuk harga diskon; itu boleh, selama konsisten dan tidak dicampur dengan pesan error di layar yang sama.

Alert ketiga di pratinjau seharusnya error, tetapi tampil seperti info biasa.

HTML
<div class="alert success"><b>✓</b> Pembayaran berhasil diterima.</div>
<div class="alert warning"><b>!</b> Kuota tersisa 2 kursi.</div>
<div class="alert info"><b>i</b> Kartu kredit ditolak oleh bank.</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; display: grid; gap: 8px; max-width: 420px; }
.alert { padding: 12px 16px; border-radius: 10px; border-left: 4px solid; display: flex; gap: 10px; }
.success { background: #E7F6EC; border-color: #1E7B45; color: #14532D; }
.warning { background: #FFF4E0; border-color: #B45309; color: #7C2D12; }
.info { background: #E8F1FB; border-color: #1D5FA8; color: #173B66; }
.error { background: #FDECEC; border-color: #B42318; color: #7A1A12; }

Tantangan

  1. Ubah alert ketiga menjadi state error: ganti kelas info menjadi error, ganti ikonnya menjadi ✕, dan awali pesannya dengan kata Gagal: agar tidak bergantung pada warna saja.

Soal latihan

  1. Tulis markup field error yang tidak bergantung pada warna saja: label, input dengan aria-invalid, ikon, dan pesan yang terhubung.

    Petunjuk

    aria-invalid dan aria-describedby.

    Lihat jawaban
    HTML
    <label for="hp">Nomor HP</label>
<input id="hp" type="tel" aria-invalid="true" aria-describedby="hp-err">
<p id="hp-err" class="error"><span aria-hidden="true">⚠</span> Nomor HP minimal 10 digit, contoh: 081234567890</p>

Poin penting

  • Namai warna berdasarkan makna: success, warning, error, info.
  • Warna tidak boleh satu-satunya penanda: tambahkan ikon dan teks.
  • Merah hanya untuk bahaya dan error.

Cek pemahaman

Field error hanya diberi border merah. Apa masalahnya?

Jawaban: Pengguna buta warna tidak tahu ada error

WCAG 1.4.1: jangan mengandalkan warna saja.

Nama token mana yang semantik?

Jawaban: --color-error

Menyebut makna, bukan rupa.
