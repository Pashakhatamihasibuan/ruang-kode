Redlining dan spesifikasi

Buka versi interaktif

Redlining adalah memberi anotasi ukuran pada desain: jarak, padding, ukuran huruf, radius, warna, dan perilaku. Dulu digambar manual dengan garis merah; sekarang Figma Dev Mode menampilkannya otomatis saat developer mengklik elemen, lengkap dengan nilai token.

Yang tetap harus ditulis desainer, karena tidak terlihat di gambar statis: perilaku responsif (apa yang melar, apa yang tetap), semua state (hover, focus, disabled, loading, error, empty), teks terpanjang (nama 40 huruf, harga Rp1.250.000.000), animasi (durasi, easing), dan logika (kapan tombol aktif, validasi apa).

Spesifikasi yang baik memakai nama token, bukan angka mentah: tulis "padding space-2 / space-3, radius-md, color-action-primary", bukan "16px, 24px, 10px, #1D5FA8". Developer tinggal mencocokkan token yang sama di kode.

Tombol di pratinjau belum sesuai spesifikasi: padding 16px atas-bawah dan 24px kiri-kanan, radius 12px.

HTML
<div class="spes">
  <button class="tombol">Konfirmasi pesanan</button>
  <ul>
    <li>Padding: space-2 (16px) atas-bawah, space-3 (24px) kiri-kanan</li>
    <li>Radius: radius-lg (12px)</li>
    <li>Tinggi minimum: 48px</li>
  </ul>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.spes ul { font-size: 14px; color: #52606D; padding-left: 20px; }
.tombol { font: inherit; font-weight: 600; background: #1D5FA8; color: #fff; border: 0; padding: 10px 14px; border-radius: 4px; }

Tantangan

  1. Sesuaikan .tombol dengan spesifikasi: padding 16px 24px, border-radius 12px, min-height 48px.

Soal latihan

  1. Tulis spesifikasi lengkap untuk komponen input pencarian (bukan hanya ukuran).

    Petunjuk

    Ukuran, token, state, perilaku, teks panjang, aksesibilitas.

    Lihat jawaban
    CONTOH
    Tinggi 48, padding space-2, radius-full, ikon 20 kiri
Token: color-bg-surface, color-border-input, color-text-muted (placeholder)
State: default, focus (border 2px color-border-focus), filled (tampil tombol hapus), disabled
Perilaku: cari setelah berhenti mengetik 300 ms; Enter langsung cari; Esc mengosongkan
Teks panjang: terpotong dengan elipsis, tidak melebarkan input
Aksesibilitas: role="search", label tersembunyi "Cari kelas", tombol hapus aria-label="Hapus pencarian"

Poin penting

  • Dev Mode menampilkan ukuran otomatis.
  • Tulis yang tak terlihat: responsif, state, teks terpanjang, animasi, logika.
  • Spesifikasi memakai nama token.
