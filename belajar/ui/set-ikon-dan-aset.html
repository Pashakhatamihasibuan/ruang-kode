Set ikon dan aset

Buka versi interaktif

Ikon dalam satu produk harus berasal dari satu set dengan gaya seragam: grid yang sama (biasanya 24 × 24 dengan area aman 2 px), ketebalan garis sama (1,5 atau 2 px), sudut sama, dan gaya sama (outline atau filled). Set populer: Material Symbols, Lucide, Phosphor, Heroicons. Mencampur set membuat UI terasa "tambal sulam".

Format: SVG untuk ikon dan ilustrasi sederhana (tajam di semua ukuran, bisa diwarnai dengan currentColor). PNG atau WebP untuk foto dan gambar kompleks, diekspor @1x, @2x, @3x untuk mobile. Di Figma, atur Export settings pada setiap aset dan beri nama dengan pola konsisten: ic_cart_24.svg, img_onboarding_1@2x.png.

Aksesibilitas ikon: ikon dekoratif diberi aria-hidden="true". Tombol yang hanya berisi ikon wajib punya nama yang bisa dibaca: aria-label="Keranjang". Target sentuhnya tetap minimal 44 sampai 48 px walau ikonnya 24 px.

Tombol keranjang di pratinjau hanya berisi ikon dan tidak punya nama.

HTML
<button class="ikon-btn">
  <svg width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="9" cy="20" r="1.5"/><circle cx="18" cy="20" r="1.5"/><path d="M2 3h3l2.6 12.4a2 2 0 0 0 2 1.6h8.8a2 2 0 0 0 2-1.6L22 7H6"/></svg>
</button>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.ikon-btn { width: 48px; height: 48px; display: grid; place-items: center; border: 0; border-radius: 12px; background: #E8F1FB; color: #1D5FA8; }

Tantangan

  1. Beri tombol aria-label="Keranjang", dan beri SVG di dalamnya aria-hidden="true".

Soal latihan

  1. Buat aturan penamaan file untuk 3 ikon dan 2 ilustrasi onboarding yang diekspor untuk Android dan iOS.

    Petunjuk

    Pola: jenis_nama_ukuran, kepadatan @2x @3x.

Poin penting

  • Satu set ikon dengan grid, garis, dan gaya seragam.
  • SVG untuk ikon, PNG/WebP @1x @2x @3x untuk gambar.
  • Tombol ikon wajib punya aria-label, ikon dekoratif aria-hidden.
