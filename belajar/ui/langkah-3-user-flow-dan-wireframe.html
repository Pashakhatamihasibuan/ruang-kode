Langkah 3: user flow dan wireframe

Buka versi interaktif

User flow menggambarkan langkah pengguna mencapai tujuan: Buka aplikasi → pilih outlet → pilih menu → atur gula dan es → keranjang → bayar QRIS → lihat estimasi siap. Tandai titik keputusan dan kondisi error (outlet tutup, stok habis, bayar gagal).

Wireframe adalah kerangka hitam putih yang membahas struktur dan prioritas, bukan warna. Pratinjau menampilkan wireframe beranda: lokasi outlet di atas, pencarian, banner, kategori, daftar menu dengan tombol tambah, dan bar keranjang menempel di bawah (zona jempol).

Buat 2 sampai 3 alternatif wireframe dan uji cepat dengan rekan sebelum memilih satu. Mengubah kotak abu-abu jauh lebih murah daripada mengubah desain hi-fi.
