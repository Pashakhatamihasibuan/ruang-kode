Pola navigasi mobile

Buka versi interaktif

Pola navigasi utama di ponsel: bottom navigation bar (3 sampai 5 tujuan utama, selalu terlihat, mudah dijangkau jempol), tab bar atas (berpindah antar tampilan dalam satu bagian), navigation drawer (menu samping untuk banyak tujuan, tapi tersembunyi sehingga jarang ditemukan), dan top app bar dengan tombol kembali.

Aturan bottom navigation: setiap item punya ikon dan label (label tidak boleh disembunyikan, ikon saja sering disalahpahami), item aktif ditandai dengan lebih dari warna (indikator pill di Material 3, ikon filled di iOS), dan target sentuh minimal 48 dp tinggi.

Di kode, tandai item aktif dengan aria-current="page". Hormati area aman (safe area) di bawah layar iPhone dan Android modern dengan padding-bottom: env(safe-area-inset-bottom).

Bottom nav di pratinjau belum menandai halaman aktif dan terlalu pendek.

HTML
<nav class="bottom-nav" aria-label="Navigasi utama">
  <a href="#" class="item"><span aria-hidden="true">🏠</span>Beranda</a>
  <a href="#" class="item aktif"><span aria-hidden="true">📚</span>Kelas</a>
  <a href="#" class="item"><span aria-hidden="true">🏆</span>Peringkat</a>
  <a href="#" class="item"><span aria-hidden="true">👤</span>Profil</a>
</nav>
CSS
body { font-family: system-ui, sans-serif; margin: 0; min-height: 100vh; background: #F4F5F7; }
.bottom-nav { position: fixed; left: 0; right: 0; bottom: 0; display: flex; background: #fff; border-top: 1px solid #E4E7EB; padding-bottom: env(safe-area-inset-bottom); }
.item { flex: 1; display: flex; flex-direction: column; align-items: center; gap: 2px; padding: 4px 0; font-size: 12px; color: #52606D; text-decoration: none; }
.aktif { color: #0D5DB8; font-weight: 600; }

Tantangan

  1. Beri item Kelas aria-current="page", dan buat setiap .item minimal 56px tingginya (misalnya min-height: 56px).

Soal latihan

  1. Aplikasi punya 7 tujuan: Beranda, Kelas, Jadwal, Peringkat, Pesan, Profil, Pengaturan. Rancang navigasi mobile-nya.

    Petunjuk

    Bottom nav maksimal 5; sisanya ke Profil atau menu lain.

    Lihat jawaban
    CONTOH
    Bottom nav (4): Beranda, Kelas, Jadwal, Profil
Pesan: ikon di top app bar (dengan badge)
Peringkat: tab di halaman Kelas
Pengaturan: di dalam halaman Profil

Poin penting

  • Bottom nav: 3–5 tujuan, ikon + label, mudah dijangkau.
  • Item aktif ditandai lebih dari warna, aria-current="page".
  • Target 48 dp dan safe area bawah.
