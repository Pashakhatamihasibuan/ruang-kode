Skala tipe modular

Buka versi interaktif

Skala tipe modular adalah daftar ukuran huruf yang dihitung dari ukuran dasar dikali rasio berulang. Dasar 16 px dengan rasio 1,25 (major third): 16 → 20 → 25 → 31,25 → 39. Dengan rasio 1,2 (minor third): 16 → 19,2 → 23 → 27,6.

Rasio kecil (1,125 sampai 1,2) cocok untuk aplikasi padat dan layar kecil, karena beda antar tingkat halus. Rasio besar (1,333 sampai 1,5) cocok untuk halaman marketing dengan judul besar. Hasil hitungan biasanya dibulatkan ke angka genap atau kelipatan 4.

Keuntungannya: ukuran huruf tidak dipilih asal-asalan, sehingga semua judul terasa satu keluarga. Di CSS, rasio bisa disimpan sebagai variabel dan dihitung dengan calc(), sehingga mengubah satu angka mengubah seluruh skala.

Pratinjau memakai rasio 1,5, terlalu dramatis untuk halaman aplikasi. Ubah rasionya.

HTML
<div class="contoh">
  <h1>Judul halaman (fs-3)</h1>
  <h2>Subjudul (fs-2)</h2>
  <h3>Judul kartu (fs-1)</h3>
  <p>Teks isi memakai ukuran dasar 16 px.</p>
</div>
CSS
:root {
  --r: 1.5;
  --fs-0: 1rem;
  --fs-1: calc(var(--fs-0) * var(--r));
  --fs-2: calc(var(--fs-1) * var(--r));
  --fs-3: calc(var(--fs-2) * var(--r));
}
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; }
h1 { font-size: var(--fs-3); margin: 0 0 8px; }
h2 { font-size: var(--fs-2); margin: 0 0 8px; }
h3 { font-size: var(--fs-1); margin: 0 0 8px; }
p { font-size: var(--fs-0); }

Tantangan

  1. Ubah --r menjadi 1.25 (major third). h1 akan menjadi sekitar 31,25px.

Soal latihan

  1. Hitung skala tipe dasar 16 dengan rasio 1,2 untuk 4 tingkat ke atas, lalu bulatkan ke bilangan bulat.

    Petunjuk

    16 × 1,2 berulang.

    Lihat jawaban
    CONTOH
    16
16 × 1,2 = 19,2  → 19 (atau 20)
19,2 × 1,2 = 23,04 → 23 (atau 24)
23,04 × 1,2 = 27,65 → 28
27,65 × 1,2 = 33,18 → 33 (atau 32)

Poin penting

  • Skala = ukuran dasar × rasio berulang.
  • Rasio kecil untuk aplikasi, besar untuk marketing.
  • Simpan rasio di variabel agar mudah diubah.

Cek pemahaman

Dasar 16 dan rasio 1,25. Berapa tingkat kedua (16 × 1,25 × 1,25)?

Jawaban: 25

16 × 1,5625 = 25.

Aplikasi kasir yang padat cocok dengan rasio?

Jawaban: 1.125 sampai 1.2

Beda antar tingkat halus, hemat ruang.
