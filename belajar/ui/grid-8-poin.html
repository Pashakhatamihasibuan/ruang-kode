Grid 8 poin

Buka versi interaktif

Grid 8 poin berarti semua ukuran dan jarak memakai kelipatan 8: 8, 16, 24, 32, 40, 48, 64. Untuk penyesuaian halus (ikon, jarak teks kecil) boleh setengahnya, 4. Material Design, Apple, dan hampir semua design system memakai sistem ini.

Kenapa 8? Layar umum (360, 768, 1280, 1440 px) habis dibagi 8, dan kelipatan 8 tetap utuh saat diskalakan 1,5× atau 2× di layar beresolusi tinggi. Yang lebih penting: tim tidak perlu berdebat apakah jarak itu 13 atau 14 piksel. Pilihannya terbatas, keputusan lebih cepat, dan hasilnya konsisten.

Di Figma, atur nudge amount (Shift + panah) menjadi 8, aktifkan layout grid 8 px, dan pakai nilai spacing auto layout dari skala yang sama. Di kode, simpan skalanya sebagai token: --space-1: 8px; --space-2: 16px; ....

Kartu di pratinjau memakai angka acak (13px, 7px, 10px). Rapikan ke grid 8.

HTML
<section class="kartu">
  <h3>Kelas Flutter Dasar</h3>
  <p>12 pelajaran · 4 jam</p>
  <ul class="daftar"><li>Widget dan layout</li><li>State dan form</li><li>Navigasi</li></ul>
</section>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; }
.kartu { max-width: 320px; padding: 13px 7px; border: 1px solid #D5D9E0; border-radius: 10px; }
.kartu h3 { margin: 0 0 5px; }
.daftar { display: grid; gap: 10px; padding-left: 20px; }

Tantangan

  1. Ubah padding .kartu dan gap pada .daftar menjadi kelipatan 8 (misalnya padding 24px, gap 8px).

Soal latihan

  1. Rapikan nilai berikut ke grid 8 (atau 4 untuk detail): 13, 18, 22, 30, 45, 6.

    Petunjuk

    Bulatkan ke kelipatan 8 terdekat; nilai kecil boleh 4.

    Lihat jawaban
    CONTOH
    13 → 12 atau 16
18 → 16
22 → 24
30 → 32
45 → 48
6  → 4 atau 8

  2. Buat token spacing skala 8 dari 4 sampai 64 sebagai CSS variables.

    Petunjuk

    Satu variabel per langkah.

    Lihat jawaban
    CSS
    :root {
  --space-0-5: 4px;
  --space-1: 8px;
  --space-2: 16px;
  --space-3: 24px;
  --space-4: 32px;
  --space-5: 40px;
  --space-6: 48px;
  --space-8: 64px;
}

Poin penting

  • Semua jarak dan ukuran kelipatan 8, setengahnya 4 untuk detail.
  • Pilihan terbatas mempercepat keputusan dan menjaga konsistensi.
  • Simpan skala sebagai token spacing.

Cek pemahaman

Mana yang TIDAK mengikuti grid 8 poin?

Jawaban: 18px

18 bukan kelipatan 8 (atau 4).

Keuntungan utama grid 8 poin bagi tim?

Jawaban: Pilihan jarak terbatas sehingga konsisten

Tidak ada lagi perdebatan 13 atau 14 piksel.
