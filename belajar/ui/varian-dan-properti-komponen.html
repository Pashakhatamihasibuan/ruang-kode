Varian dan properti komponen

Buka versi interaktif

Satu komponen punya banyak bentuk. Di Figma, bentuk-bentuk itu disusun sebagai variants dalam satu component set, dengan properties: Size = sm | md | lg, Variant = primary | secondary | danger, State = default | hover | disabled, Icon = true | false. Pengguna komponen tinggal memilih dari panel kanan.

Selain variant property, Figma punya boolean property (tampilkan atau sembunyikan ikon), text property (ubah label tanpa membongkar komponen), dan instance swap (ganti ikon dengan ikon lain). Desain yang baik membatasi jumlah kombinasi agar tidak meledak: 3 ukuran × 3 varian × 4 state = 36 varian sudah banyak.

Properti di Figma sebaiknya bernama sama dengan prop di kode: <Button size="lg" variant="danger"> di React, Button(size = Size.Large) di Compose. Di CSS, varian bisa memakai kelas modifier (.btn--lg) atau atribut data ([data-size="lg"]).

Tombol di pratinjau sudah punya ukuran sm dan md. Lengkapi ukuran lg.

HTML
<div class="baris">
  <button class="btn" data-size="sm">Kecil</button>
  <button class="btn" data-size="md">Sedang</button>
  <button class="btn" data-size="lg">Besar</button>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.baris { display: flex; gap: 8px; align-items: center; flex-wrap: wrap; }
.btn { font: inherit; font-weight: 600; border: 0; border-radius: 10px; background: #1D5FA8; color: #fff; box-sizing: border-box; }
.btn[data-size="sm"] { height: 32px; padding: 0 12px; font-size: 14px; }
.btn[data-size="md"] { height: 40px; padding: 0 16px; font-size: 15px; }

Tantangan

  1. Tambahkan aturan .btn[data-size="lg"] dengan tinggi 48px, padding kiri-kanan 24px, dan font-size 16px.

Soal latihan

  1. Rancang properti komponen Badge: ukuran, warna semantik, ikon. Hitung jumlah varian jika semua dibuat sebagai variant.

    Petunjuk

    Kalikan jumlah nilai setiap properti; ikon sebaiknya boolean property.

    Lihat jawaban
    CONTOH
    Size    : sm, md                     (2)
Tone    : neutral, success, warning, error, info (5)
Icon    : boolean property (bukan variant)
Jumlah variant = 2 × 5 = 10 (ikon tidak menggandakan karena boolean)

Poin penting

  • Variants dalam satu component set, diatur lewat properties.
  • Boolean, text, dan instance swap property.
  • Nama properti Figma = nama prop di kode.
