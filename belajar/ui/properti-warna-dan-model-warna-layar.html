Properti warna dan model warna layar

Buka versi interaktif

Setiap warna punya tiga properti: hue (rona: merah, biru, hijau, diukur 0 sampai 360 derajat di roda warna), saturation (kepekatan: abu-abu sampai menyala), dan lightness atau value (gelap sampai terang).

Layar membuat warna dari cahaya merah, hijau, dan biru: model RGB, ditulis heksadesimal (#8A4B2A) atau rgb(138 75 42). Untuk desainer, HSL lebih intuitif: hsl(21 53% 35%), karena membuat versi lebih terang cukup menaikkan angka lightness. Model OKLCH yang lebih baru membuat perubahan lightness terasa merata di semua hue, sehingga kini dipakai Tailwind v4.

Cetak memakai CMYK (tinta), bukan RGB. Itulah sebabnya warna yang menyala di layar bisa terlihat kusam saat dicetak. Untuk produk digital, bekerja di ruang warna sRGB (atau Display P3 untuk layar modern) dan selalu cek di perangkat nyata.

Tombol di pratinjau memakai HSL dengan hue dari variabel. Ubah hue-nya.

HTML
<div class="baris">
  <button class="tombol">Daftar sekarang</button>
  <span class="kode">hsl(var(--hue) 70% 40%)</span>
</div>
CSS
:root { --hue: 21; }
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
.baris { display: flex; gap: 16px; align-items: center; flex-wrap: wrap; }
.tombol { background: hsl(var(--hue) 70% 40%); color: #fff; border: 0; padding: 12px 24px; border-radius: 10px; font-size: 16px; }
.kode { font-family: ui-monospace, monospace; color: #52606D; }

Tantangan

  1. Ubah --hue menjadi 210 agar tombol menjadi biru, tanpa menyentuh saturation dan lightness.

Soal latihan

  1. Ubah warna hsl(210 70% 40%) menjadi versi lebih terang untuk latar, versi lebih gelap untuk teks, dan versi abu-abu.

    Petunjuk

    Ubah lightness untuk terang-gelap, saturation untuk abu-abu.

    Lihat jawaban
    CONTOH
    Latar terang : hsl(210 70% 94%)
Teks gelap   : hsl(210 70% 22%)
Abu-abu      : hsl(210 8% 40%)

Poin penting

  • Hue, saturation, lightness.
  • Layar memakai RGB; HSL dan OKLCH lebih mudah diatur desainer.
  • Cetak memakai CMYK, warna bisa berbeda.
