Layout dashboard desktop

Buka versi interaktif

Dashboard desktop biasanya terdiri dari: sidebar navigasi (lebar tetap 240 sampai 280 px, bisa diciutkan menjadi ikon), header (judul halaman, pencarian, profil), dan area utama berisi kartu KPI di atas, grafik di tengah, dan tabel detail di bawah. Urutan ini mengikuti cara orang membaca: ringkasan dulu, detail kemudian.

Letakkan angka terpenting di kiri atas area utama, karena pembaca bahasa Latin memindai dengan pola F. Kartu KPI berisi: label, angka besar, perubahan (naik 12% dibanding minggu lalu) dengan ikon panah, bukan hanya warna.

CSS Grid dengan grid-template-areas membuat struktur dashboard terbaca seperti peta. Di layar kecil, ubah area menjadi satu kolom dan sidebar menjadi drawer atau bottom nav.

Dashboard di pratinjau belum punya struktur. Susun dengan grid-template-areas.

HTML
<div class="dash">
  <aside class="side">Menu</aside>
  <header class="head">Ringkasan penjualan</header>
  <main class="main">
    <div class="kpi"><small>Pendapatan</small><b>Rp48,2 jt</b><span>▲ 12%</span></div>
    <div class="kpi"><small>Pesanan</small><b>1.284</b><span>▲ 4%</span></div>
    <div class="kpi"><small>Retur</small><b>23</b><span>▼ 2%</span></div>
  </main>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; }
.dash { display: grid; min-height: 100vh; gap: 0; }
.side { grid-area: sidebar; background: #0F172A; color: #CBD5E1; padding: 16px; }
.head { grid-area: header; padding: 16px 24px; border-bottom: 1px solid #E4E7EB; font-weight: 700; }
.main { grid-area: main; padding: 24px; display: grid; grid-template-columns: repeat(auto-fit, minmax(140px, 1fr)); gap: 16px; align-content: start; }
.kpi { display: grid; gap: 4px; padding: 16px; border-radius: 12px; background: #F5F7FA; }
.kpi b { font-size: 24px; }

Tantangan

  1. Beri .dash struktur: grid-template-columns: 200px 1fr dan grid-template-areas: "sidebar header" "sidebar main".

Soal latihan

  1. Ubah dashboard menjadi satu kolom di bawah 840px: sidebar disembunyikan, header di atas main.

    Petunjuk

    Media query yang mengubah grid-template-areas.

    Lihat jawaban
    CSS
    @media (max-width: 839px) {
  .dash { grid-template-columns: 1fr; grid-template-areas: "header" "main"; }
  .side { display: none; }
}

Poin penting

  • Sidebar, header, area utama: KPI, grafik, tabel.
  • Angka terpenting di kiri atas (pola F).
  • grid-template-areas sebagai peta layout.

Cek pemahaman

Di mana angka terpenting dashboard diletakkan?

Jawaban: Kiri atas

Mata memindai dengan pola F.

Kartu KPI menampilkan perubahan turun hanya dengan warna merah. Perbaikannya?

Jawaban: Tambahkan ikon panah dan teks persentase

Jangan mengandalkan warna saja.
