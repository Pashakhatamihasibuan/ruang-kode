Hierarki visual

Buka versi interaktif

Hierarki visual adalah urutan mata pengguna membaca layar: apa yang dilihat pertama, kedua, dan terakhir. Desainer mengatur urutan itu dengan ukuran, ketebalan, warna dan kontras, posisi, serta ruang kosong di sekitar elemen.

Aturan praktis: setiap layar punya satu hal terpenting (judul, angka utama, atau tombol aksi utama). Jika semua elemen sama besar dan sama tebal, mata tidak tahu harus mulai dari mana, dan pengguna merasa layar itu "ramai" walau isinya sedikit.

Uji cepat: squint test. Sipitkan mata sampai layar buram. Elemen yang masih terlihat jelas adalah puncak hierarkimu. Jika yang menonjol justru label kecil atau ikon dekoratif, hierarkinya terbalik.

Kartu produk di pratinjau dibuat rata semua: judul, harga, dan deskripsi sama ukuran. Perbaiki hierarkinya.

HTML
<article class="kartu">
  <p class="kategori">Kopi susu</p>
  <h2 class="judul">Es Kopi Gula Aren</h2>
  <p class="harga">Rp18.000</p>
  <p class="desk">Espresso, susu segar, dan gula aren asli dari Banten.</p>
  <button class="aksi">Tambah ke keranjang</button>
</article>
CSS
body { font-family: system-ui, sans-serif; background: #F4F1EC; margin: 0; padding: 24px; color: #2B2724; }
.kartu { max-width: 320px; background: #fff; border-radius: 16px; padding: 24px; }
.kartu p, .kartu h2 { font-size: 16px; font-weight: 400; margin: 0 0 8px; }
.kategori { color: #7A716A; }
.aksi { margin-top: 16px; width: 100%; padding: 12px; border: 0; border-radius: 10px; background: #8A4B2A; color: #fff; font-size: 16px; }

Tantangan

  1. Jadikan judul puncak hierarki: .judul minimal 24px dan tebal minimal 700. Buat .harga tebal minimal 600.

Soal latihan

  1. Lakukan squint test pada halaman beranda aplikasi bank atau e-commerce di ponselmu. Tulis tiga elemen yang paling menonjol, lalu nilai: apakah itu memang yang terpenting?

    Petunjuk

    Sipitkan mata atau buramkan tangkapan layar. Bandingkan dengan tujuan utama halaman.

    Lihat jawaban
    CONTOH
    Contoh jawaban (aplikasi e-commerce):
1. Banner promo besar  → menonjol, tapi bukan tujuan utama pengguna
2. Kolom pencarian      → seharusnya paling menonjol
3. Ikon keranjang       → cukup
Rekomendasi: perbesar kolom pencarian, kecilkan banner.

  2. Tulis CSS untuk kartu notifikasi dengan hierarki: judul 18px tebal 700, isi 14px abu-abu tua, waktu 12px abu-abu.

    Petunjuk

    Bedakan dengan ukuran, tebal, dan warna sekaligus.

    Lihat jawaban
    CSS
    .notif-judul { font-size: 18px; font-weight: 700; color: #111827; }
.notif-isi   { font-size: 14px; color: #374151; }
.notif-waktu { font-size: 12px; color: #6B7280; }

Poin penting

  • Hierarki diatur dengan ukuran, tebal, kontras, posisi, dan ruang kosong.
  • Satu layar, satu hal terpenting.
  • Squint test untuk memeriksa hierarki.

Cek pemahaman

Apa tanda hierarki visual yang buruk?

Jawaban: Semua elemen sama besar dan sama tebal

Mata tidak tahu harus mulai dari mana.

Squint test dipakai untuk?

Jawaban: Melihat elemen mana yang paling menonjol

Yang tetap terlihat saat buram adalah puncak hierarki.
