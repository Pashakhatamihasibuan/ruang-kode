Memilih typeface

Buka versi interaktif

Typeface (keluarga huruf) membawa kepribadian. Sans-serif (Inter, Plus Jakarta Sans, Roboto) netral dan jelas di layar, pilihan aman untuk UI. Serif (Lora, Merriweather) terasa editorial dan tepercaya, cocok untuk judul atau bacaan panjang. Monospace (JetBrains Mono) untuk kode dan angka yang harus sejajar.

Kriteria memilih font UI: (1) tinggi huruf kecil (x-height) cukup besar agar terbaca di ukuran 12 sampai 14 px, (2) bentuk I l 1 dan O 0 mudah dibedakan, (3) punya cukup ketebalan (400, 500, 600, 700), (4) mendukung karakter bahasa target, dan (5) lisensinya jelas. Google Fonts aman untuk proyek komersial.

Batasi maksimal dua keluarga: satu untuk judul, satu untuk isi, atau satu keluarga saja dengan beberapa ketebalan. Font sistem (system-ui) memuat instan dan terasa "asli" di setiap perangkat, sehingga banyak aplikasi besar memakainya.

Halaman di pratinjau memakai font dekoratif untuk teks UI. Ganti dengan font sistem.

HTML
<main class="hal">
  <h1>Pengaturan akun</h1>
  <p>Ubah nama, email, dan kata sandi. Perubahan email perlu dikonfirmasi lewat tautan yang kami kirim.</p>
  <p class="kecil">Kode verifikasi: Il1O0 · terakhir diubah 12/11/2026</p>
</main>
CSS
body { margin: 0; padding: 24px; font-family: "Brush Script MT", "Comic Sans MS", cursive; color: #1F2933; }
.hal { max-width: 420px; }
.kecil { font-size: 13px; color: #52606D; }

Tantangan

  1. Ganti font-family body menjadi tumpukan font sistem yang diawali system-ui.

Soal latihan

  1. Pilih pasangan font untuk aplikasi belajar anak SD dan untuk aplikasi laporan keuangan perusahaan. Jelaskan alasannya.

    Petunjuk

    Pertimbangkan kepribadian, keterbacaan angka, dan x-height.

    Lihat jawaban
    CONTOH
    Aplikasi anak: Nunito atau Baloo 2 (bulat, ramah, x-height besar) + font sistem untuk teks panjang.
Laporan keuangan: Inter atau IBM Plex Sans (netral, angka tabular sejajar) + IBM Plex Mono untuk kode akun.

  2. Tulis tag link Google Fonts untuk Plus Jakarta Sans ketebalan 400, 600, 700 dan CSS pemakaiannya dengan fallback.

    Petunjuk

    Pakai display=swap dan tumpukan fallback sistem.

    Lihat jawaban
    HTML
    <link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;600;700&display=swap" rel="stylesheet">

<style>
  body { font-family: "Plus Jakarta Sans", system-ui, sans-serif; }
</style>

Poin penting

  • Sans-serif untuk UI, serif untuk editorial, mono untuk kode.
  • Periksa x-height, I l 1 dan O 0, ketebalan, dan lisensi.
  • Maksimal dua keluarga huruf.
