Palet tint dan shade

Buka versi interaktif

Satu warna merek tidak cukup. UI butuh skala: versi sangat terang untuk latar (50, 100), menengah untuk border (200, 300), warna utama (500, 600), dan gelap untuk teks dan hover (700, 800, 900). Tint = dicampur putih (lebih terang), shade = dicampur hitam (lebih gelap).

Cara membuat skala: tentukan warna utama di tingkat 500 atau 600, lalu ubah lightness bertahap dengan hue tetap. Sedikit menggeser hue dan menaikkan saturasi di tingkat gelap membuat warna terlihat lebih hidup. Alat bantu: uicolors.app, Tailwind palette generator, atau color-mix(in oklch, warna 60%, black) di CSS modern.

Skala ini juga kunci aksesibilitas: pasangan yang aman biasanya berjarak minimal 4 sampai 5 tingkat, misalnya teks 800 di atas latar 100, atau teks putih di atas tombol 600.

Palet di pratinjau baru sampai 700. Tambahkan tingkat 900.

HTML
<div class="palet">
  <div class="chip c100">100</div><div class="chip c300">300</div><div class="chip c500">500</div><div class="chip c700">700</div>
</div>
<p class="contoh">Lencana: <span class="lencana">Terverifikasi</span></p>
CSS
:root { --h: 152; }
body { font-family: system-ui, sans-serif; margin: 0; padding: 16px; }
.palet { display: grid; grid-template-columns: repeat(auto-fill, minmax(64px, 1fr)); gap: 8px; }
.chip { height: 64px; border-radius: 10px; display: grid; place-items: end start; padding: 6px; font-size: 12px; }
.c100 { background: hsl(var(--h) 60% 92%); }
.c300 { background: hsl(var(--h) 55% 72%); }
.c500 { background: hsl(var(--h) 60% 42%); color: #fff; }
.c700 { background: hsl(var(--h) 65% 28%); color: #fff; }
.lencana { background: hsl(var(--h) 60% 92%); color: hsl(var(--h) 65% 28%); padding: 2px 10px; border-radius: 99px; }

Tantangan

  1. Tambahkan chip <div class="chip c900">900</div> dan beri .c900 latar yang lebih gelap dari 700 (misalnya lightness 16%) dengan teks putih.

Soal latihan

  1. Buat skala 100 sampai 900 (5 tingkat) untuk hue 352 (merah merek) memakai hsl.

    Petunjuk

    Hue tetap, lightness turun.

    Lihat jawaban
    CSS
    :root {
  --red-100: hsl(352 85% 94%);
  --red-300: hsl(352 75% 76%);
  --red-500: hsl(352 70% 50%);
  --red-700: hsl(352 75% 34%);
  --red-900: hsl(352 80% 18%);
}

Poin penting

  • Skala 50–900: terang untuk latar, gelap untuk teks.
  • Tint dicampur putih, shade dicampur hitam.
  • Pasangan aman berjarak 4–5 tingkat.
