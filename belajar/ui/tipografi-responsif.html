Tipografi responsif

Buka versi interaktif

Ukuran judul yang pas di laptop (48 px) terlalu besar di ponsel 360 px, dan sebaliknya. Cara lama memakai media query: 28 px di ponsel, lalu 40 px mulai lebar 768 px. Hasilnya melompat di titik tertentu.

Cara modern memakai tipografi fluid dengan clamp(minimum, ideal, maksimum): font-size: clamp(1.75rem, 1rem + 3vw, 3rem). Ukuran tumbuh halus mengikuti lebar layar, tetapi tidak pernah di bawah 28 px atau di atas 48 px. Bagian ideal selalu campuran rem dan vw, agar teks tetap ikut membesar saat pengguna memperbesar ukuran huruf di pengaturan browser.

Teks isi biasanya cukup 16 px sampai 18 px tanpa fluid. Jangan pernah membuat teks isi di bawah 16 px di ponsel, karena iOS akan otomatis memperbesar halaman saat input bertulisan lebih kecil dari 16 px difokuskan.

Ubah judul hero di pratinjau menjadi fluid. Lalu ubah lebar jendela pratinjau untuk melihatnya tumbuh.

HTML
<header class="hero">
  <h1>Belajar coding dari nol, dalam Bahasa Indonesia</h1>
  <p>Gratis, interaktif, dan bisa dipakai offline.</p>
</header>
CSS
body { font-family: system-ui, sans-serif; margin: 0; }
.hero { padding: 32px 16px; background: #0F172A; color: #F8FAFC; }
.hero h1 { font-size: 48px; line-height: 1.15; margin: 0 0 12px; }
.hero p { font-size: 18px; margin: 0; color: #CBD5E1; }

Tantangan

  1. Ganti font-size judul .hero h1 dengan clamp(), misalnya clamp(1.75rem, 1rem + 3vw, 3rem).

Soal latihan

  1. Buat judul fluid dari 24px (layar 360px) sampai 40px, dan subjudul dari 18px sampai 24px.

    Petunjuk

    clamp(min, rem + vw, max).

    Lihat jawaban
    CSS
    h1 { font-size: clamp(1.5rem, 1rem + 2.5vw, 2.5rem); }
h2 { font-size: clamp(1.125rem, 1rem + 1vw, 1.5rem); }

Poin penting

  • clamp(min, ideal, max) untuk ukuran fluid.
  • Bagian ideal campur rem dan vw agar zoom tetap bekerja.
  • Teks isi minimal 16 px di ponsel.

Cek pemahaman

Kenapa bagian ideal clamp sebaiknya memakai rem + vw, bukan vw saja?

Jawaban: Agar teks tetap membesar saat pengguna menambah ukuran huruf

vw saja mengabaikan pengaturan ukuran huruf pengguna.

clamp(1.75rem, 1rem + 3vw, 3rem) di layar sangat lebar menghasilkan?

Jawaban: 3rem
