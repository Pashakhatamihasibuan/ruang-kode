Kontras WCAG

Buka versi interaktif

WCAG (Web Content Accessibility Guidelines) mengukur kontras sebagai rasio luminansi dua warna, dari 1:1 (sama) sampai 21:1 (hitam di atas putih). Standar AA yang dipakai hampir semua regulasi: teks normal minimal 4,5:1, teks besar (24 px, atau 18,66 px tebal) minimal 3:1, dan komponen UI seperti border input dan ikon minimal 3:1. Level AAA: 7:1.

Pelanggaran paling umum: teks abu-abu muda di atas putih. #9CA3AF di atas putih hanya 2,5:1, terlihat "elegan" di monitor desainer, tetapi tidak terbaca di bawah sinar matahari atau oleh pengguna lansia. #6B7280 sudah 4,8:1.

Alat cek: plugin Figma (Stark, Contrast), panel Accessibility di Chrome DevTools, atau webaim.org/resources/contrastchecker. Tes otomatis di bawah menghitung rasio dengan rumus WCAG yang sama.

Teks keterangan di pratinjau gagal AA. Gelapkan warnanya.

HTML
<div class="kartu">
  <h3>Ujian akhir modul</h3>
  <p class="ket">Dibuka Senin, 10 November 2026 pukul 08.00 WIB. Durasi 45 menit.</p>
</div>
CSS
body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; background: #fff; }
.kartu { max-width: 340px; padding: 24px; border: 1px solid #E5E7EB; border-radius: 12px; background: #FFFFFF; }
h3 { margin: 0 0 8px; color: #111827; }
.ket { margin: 0; font-size: 15px; color: #9CA3AF; }

Tantangan

  1. Ubah warna .ket agar kontrasnya dengan latar putih minimal 4.5:1 (misalnya #4B5563).

Soal latihan

  1. Nilai pasangan ini terhadap WCAG AA: (a) teks #FFFFFF di atas #1D5FA8, (b) teks #9CA3AF di atas #FFFFFF, (c) border input #D1D5DB di atas #FFFFFF.

    Petunjuk

    Teks normal 4,5:1, komponen UI 3:1.

    Lihat jawaban
    CONTOH
    (a) sekitar 6,4:1 → lulus AA untuk teks
(b) sekitar 2,5:1 → gagal (butuh 4,5:1)
(c) sekitar 1,5:1 → gagal untuk komponen UI (butuh 3:1); pakai #6B7280 atau lebih gelap

  2. Tulis gaya placeholder yang tetap lulus kontras 4,5:1 di atas putih.

    Petunjuk

    Gelapkan abu-abunya.

    Lihat jawaban
    CSS
    input::placeholder { color: #6B7280; opacity: 1; }

Poin penting

  • AA: teks normal 4,5:1, teks besar dan komponen UI 3:1.
  • Abu-abu muda di atas putih adalah pelanggaran paling umum.
  • Cek dengan plugin Figma atau DevTools.

Cek pemahaman

Kontras minimal teks normal untuk WCAG AA?

Jawaban: 4.5:1

Border input harus berkontras minimal berapa terhadap latarnya?

Jawaban: 3:1
