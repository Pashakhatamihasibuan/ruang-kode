Empat keadaan data: memuat, error, kosong, ada

Buka versi interaktif

Komponen yang mengambil data punya setidaknya empat keadaan: memuat, error, kosong, dan ada data. Pemula sering hanya menulis keadaan terakhir, sehingga pengguna melihat layar putih saat koneksi lambat atau saat belum ada data.

Tangani keempatnya secara eksplisit dan berurutan. Gunakan skeleton yang menyerupai bentuk isi agar layar tidak meloncat, pesan error yang bisa ditindaklanjuti dengan tombol coba lagi, dan empty state yang mengajak bertindak.

Pustaka seperti TanStack Query sudah menyediakan isPending, isError, dan refetch, sehingga kamu tinggal menampilkan setiap keadaan.

JSX
function DaftarPesanan() {
  const { data, isPending, isError, refetch } = useQuery({
    queryKey: ["pesanan"],
    queryFn: () => fetch("/api/pesanan").then((r) => r.json()),
  });

  if (isPending) return <SkeletonList baris={3} />;
  if (isError) return (
    <div role="alert">
      Pesanan gagal dimuat. <button onClick={() => refetch()}>Coba lagi</button>
    </div>
  );
  if (data.length === 0) return (
    <EmptyState judul="Belum ada pesanan" aksi={<a href="/katalog">Mulai belanja</a>} />
  );
  return <ul>{data.map((p) => <li key={p.id}>{p.nomor}</li>)}</ul>;
}

Poin penting

  • Empat keadaan: memuat, error, kosong, ada data.
  • Skeleton mencegah layar meloncat.
  • Error disertai tombol coba lagi.
  • Empty state mengajak bertindak.
