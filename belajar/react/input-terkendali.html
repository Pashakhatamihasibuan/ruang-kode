Input terkendali

Buka versi interaktif

Pada controlled input, nilai input berasal dari state dan setiap ketikan memperbarui state lewat onChange. React menjadi satu-satunya sumber kebenaran, sehingga mudah memvalidasi dan menampilkan pesan error saat itu juga.

Kirim form dengan onSubmit dan panggil e.preventDefault(). Tampilkan error di dekat input dan hubungkan dengan aria-describedby agar dibacakan.

CSS
body{font:14px system-ui,sans-serif}form{display:grid;gap:4px;max-width:260px}small{color:#B23A2E;min-height:1em}
JSX
function App() {
  const [form, setForm] = useState({ nama: "", email: "" });
  const [kirim, setKirim] = useState(false);
  const ubah = e => setForm({ ...form, [e.target.name]: e.target.value });
  const err = {
    nama: form.nama.trim().length < 3 ? "Nama minimal 3 huruf" : "",
    email: !/^\S+@\S+\.\S+$/.test(form.email) ? "Format email belum benar" : "",
  };
  const valid = !err.nama && !err.email;
  return (
    <form onSubmit={e => { e.preventDefault(); setKirim(true); }}>
      <label htmlFor="nama">Nama</label>
      <input id="nama" name="nama" value={form.nama} onChange={ubah} aria-describedby="e-nama" />
      <small id="e-nama">{form.nama && err.nama}</small>
      <label htmlFor="email">Email</label>
      <input id="email" name="email" value={form.email} onChange={ubah} aria-describedby="e-email" />
      <small id="e-email">{form.email && err.email}</small>
      <button disabled={!valid}>Daftar</button>
      {kirim && <p>Terima kasih, {form.nama}!</p>}
    </form>
  );
}

Tantangan

  1. Isi nama dan email yang valid, lalu tekan Daftar.

Poin penting

  • Controlled input: value dari state, onChange memperbarui state.
  • Validasi saat mengetik dan saat kirim.
  • Hubungkan pesan error dengan aria-describedby.
