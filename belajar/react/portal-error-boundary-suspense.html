Portal, error boundary & suspense

Buka versi interaktif

Portal merender anak ke node DOM lain, misalnya modal yang harus berada di luar elemen dengan overflow tersembunyi: ReactDOM.createPortal(isi, document.body).

Error boundary menangkap error saat render di komponen anak dan menampilkan cadangan, sehingga satu komponen rusak tidak membuat seluruh aplikasi putih. Saat ini error boundary masih ditulis sebagai komponen kelas.

Suspense menampilkan cadangan (misalnya loader) selama anak menunggu kode atau data, dipakai bersama React.lazy atau framework seperti Next.js.

CSS
body{font:14px system-ui,sans-serif}.modal{position:fixed;inset:20% 10% auto;background:#fff;border:1px solid #ccc;border-radius:12px;padding:12px;box-shadow:0 20px 40px #0003}.err{color:#B23A2E}
JSX
class Pengaman extends React.Component {
  constructor(p) { super(p); this.state = { error: null }; }
  static getDerivedStateFromError(error) { return { error }; }
  render() {
    return this.state.error
      ? <p className="err">Ups, bagian ini gagal dimuat: {this.state.error.message}</p>
      : this.props.children;
  }
}

function Rusak() { throw new Error("data harga kosong"); }

function Modal({ onTutup }) {
  return ReactDOM.createPortal(
    <div className="modal"><p>Saya dirender di document.body lewat portal.</p><button onClick={onTutup}>Tutup</button></div>,
    document.body
  );
}

function App() {
  const [buka, setBuka] = useState(false);
  return (
    <div>
      <button onClick={() => setBuka(true)}>Buka modal</button>
      {buka && <Modal onTutup={() => setBuka(false)} />}
      <Pengaman><Rusak /></Pengaman>
      <p>Bagian lain tetap jalan.</p>
    </div>
  );
}

Poin penting

  • Portal merender ke luar pohon DOM induk.
  • Error boundary mencegah satu error merusak seluruh aplikasi.
  • Suspense menampilkan cadangan saat menunggu.
