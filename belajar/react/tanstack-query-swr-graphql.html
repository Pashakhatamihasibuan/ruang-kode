TanStack Query, SWR & GraphQL

Buka versi interaktif

TanStack Query dan SWR mengurus hal yang merepotkan: cache, muat ulang di latar belakang, retry, pagination, dan berbagi data yang sama antar-komponen. Kode komponen menjadi pendek.

Untuk API GraphQL, klien seperti Apollo, urql, dan Relay melakukan hal serupa dengan query GraphQL. RTK Query adalah pilihan bagi proyek yang memakai Redux Toolkit.

JSX
import { useQuery, useMutation, useQueryClient } from "@tanstack/react-query";

function DaftarProduk() {
  const { data, isPending, error } = useQuery({
    queryKey: ["produk"],
    queryFn: () => fetch("/api/produk").then(r => r.json()),
    staleTime: 60_000,            // dianggap segar 1 menit
  });
  const qc = useQueryClient();
  const tambah = useMutation({
    mutationFn: p => fetch("/api/produk", { method: "POST", body: JSON.stringify(p) }),
    onSuccess: () => qc.invalidateQueries({ queryKey: ["produk"] }),   // muat ulang daftar
  });
  if (isPending) return <p>Memuat…</p>;
  if (error) return <p>Gagal: {error.message}</p>;
  return <ul>{data.map(p => <li key={p.id}>{p.nama}</li>)}</ul>;
}

Poin penting

  • queryKey menjadi kunci cache.
  • invalidateQueries memuat ulang data setelah perubahan.
  • Apollo/urql/Relay untuk GraphQL.
