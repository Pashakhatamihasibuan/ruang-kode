useRef, useMemo & useCallback

Buka versi interaktif

useRef menyimpan nilai yang bertahan antar-render tanpa memicu render ulang, dan sering dipakai untuk menunjuk elemen DOM, misalnya memfokuskan input.

useMemo mengingat hasil perhitungan berat dan menghitung ulang hanya saat dependensinya berubah. useCallback mengingat fungsi agar identitasnya tetap sama. Keduanya alat optimasi: pakai saat ada masalah performa yang terukur, bukan di semua tempat.

Aturan hooks: panggil hanya di tingkat atas komponen (tidak di dalam if atau loop), dan hanya dari komponen atau hook lain.

JSX
function App() {
  const inputRef = useRef(null);
  const [cari, setCari] = useState("");
  const [klik, setKlik] = useState(0);

  const angka = useMemo(() => {
    // anggap ini perhitungan berat
    return Array.from({ length: 2000 }, (_, i) => i).filter(n => String(n).includes(cari || "x"));
  }, [cari]);

  return (
    <div>
      <input ref={inputRef} value={cari} onChange={e => setCari(e.target.value)} placeholder="Cari angka" />
      <button onClick={() => inputRef.current.focus()}>Fokus ke input</button>
      <p>{angka.length} angka cocok</p>
      <button onClick={() => setKlik(k => k + 1)}>Klik {klik}</button>
      <p><small>Klik tombol tidak menghitung ulang daftar angka karena useMemo.</small></p>
    </div>
  );
}

Poin penting

  • useRef: nilai bertahan tanpa render ulang; akses DOM.
  • useMemo mengingat hasil, useCallback mengingat fungsi.
  • Optimasi hanya bila perlu.
  • Hooks dipanggil di tingkat atas komponen.
