Menguji komponen

Buka versi interaktif

React Testing Library menguji komponen seperti pengguna memakainya: cari elemen berdasarkan teks atau peran (role), klik, lalu periksa hasilnya. Jalankan dengan Vitest atau Jest.

Tes end-to-end dengan Playwright atau Cypress menjalankan browser sungguhan dan menguji alur lengkap, misalnya dari memilih produk sampai checkout.

JSX
import { render, screen } from "@testing-library/react";
import userEvent from "@testing-library/user-event";
import { test, expect } from "vitest";
import Penghitung from "./Penghitung";

test("tombol + menambah jumlah", async () => {
  render(<Penghitung />);
  await userEvent.click(screen.getByRole("button", { name: "+" }));
  await userEvent.click(screen.getByRole("button", { name: "+" }));
  expect(screen.getByText(/di keranjang: 2/)).toBeInTheDocument();
});

Poin penting

  • Uji perilaku yang dilihat pengguna, bukan detail internal.
  • Cari elemen lewat role dan teks.
  • Playwright/Cypress untuk alur end-to-end.
