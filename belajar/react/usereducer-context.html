useReducer & Context

Buka versi interaktif

Saat state rumit dengan banyak jenis perubahan, useReducer mengumpulkan semua logika di satu fungsi reducer: (state, aksi) => stateBaru. Komponen cukup mengirim aksi: dispatch({ type: "tambah", id }).

Context mengirim data ke banyak komponen jauh di bawah tanpa meneruskan props berlapis-lapis (prop drilling). Buat dengan createContext, sediakan dengan <Ctx.Provider value={...}>, baca dengan useContext(Ctx). Cocok untuk tema, bahasa, atau pengguna yang login.

JSX
const KeranjangCtx = React.createContext(null);

function reducer(state, aksi) {
  switch (aksi.type) {
    case "tambah": return { ...state, [aksi.nama]: (state[aksi.nama] || 0) + 1 };
    case "kosongkan": return {};
    default: return state;
  }
}

function TombolBeli({ nama }) {
  const { dispatch } = useContext(KeranjangCtx);
  return <button onClick={() => dispatch({ type: "tambah", nama })}>Beli {nama}</button>;
}

function Ringkasan() {
  const { isi, dispatch } = useContext(KeranjangCtx);
  const total = Object.values(isi).reduce((a, b) => a + b, 0);
  return <p>{total} barang <button onClick={() => dispatch({ type: "kosongkan" })}>Kosongkan</button></p>;
}

function App() {
  const [isi, dispatch] = useReducer(reducer, {});
  return (
    <KeranjangCtx.Provider value={{ isi, dispatch }}>
      <TombolBeli nama="Kopi" /> <TombolBeli nama="Teh" />
      <Ringkasan />
    </KeranjangCtx.Provider>
  );
}

Tantangan

  1. Klik tombol beli sampai keranjang berisi 4 barang.

Poin penting

  • useReducer: logika perubahan state di satu fungsi.
  • Context menghindari prop drilling.
  • Provider menyediakan, useContext membaca.
