Zustand, Jotai & kawan-kawan

Buka versi interaktif

Context cukup untuk data yang jarang berubah. Untuk state global yang sering berubah (keranjang, filter, data pengguna), pustaka state management lebih praktis dan efisien.

Zustand membuat store kecil dengan satu fungsi, tanpa provider. Jotai memecah state menjadi atom-atom kecil. Redux Toolkit masih banyak dipakai di perusahaan besar. MobX memakai pendekatan observable. Untuk data dari server, gunakan TanStack Query (modul berikutnya), bukan store global.

JAVASCRIPT
import { create } from "zustand";

export const useKeranjang = create(set => ({
  isi: [],
  tambah: produk => set(s => ({ isi: [...s.isi, produk] })),
  kosongkan: () => set({ isi: [] }),
}));

// di komponen mana pun, tanpa Provider:
function Ikon() {
  const jumlah = useKeranjang(s => s.isi.length);   // hanya render ulang jika jumlah berubah
  return <span>🛒 {jumlah}</span>;
}

Poin penting

  • Context untuk data yang jarang berubah.
  • Zustand: store sederhana tanpa provider.
  • Pilih selector agar render ulang seminimal mungkin.
  • Data server ditangani pustaka data fetching.
