useEffect & siklus hidup

Buka versi interaktif

useEffect menjalankan efek samping setelah render: mengambil data, memasang timer, atau berlangganan event. Array dependensi menentukan kapan efek dijalankan ulang: [] hanya sekali saat komponen muncul, [id] setiap kali id berubah.

Kembalikan fungsi cleanup untuk membersihkan, misalnya mematikan timer saat komponen hilang. Ini pengganti siklus hidup componentDidMount/Unmount di komponen kelas.

Jangan pakai useEffect untuk menghitung nilai turunan dari state; hitung saja langsung saat render.

JSX
function Jam() {
  const [detik, setDetik] = useState(0);
  useEffect(() => {
    const t = setInterval(() => setDetik(d => d + 1), 1000);
    return () => clearInterval(t);        // cleanup
  }, []);                                  // sekali saat muncul
  return <p>Sudah belajar {detik} detik</p>;
}

function App() {
  const [tampil, setTampil] = useState(true);
  useEffect(() => { document.title = tampil ? "Fokus" : "Istirahat"; }, [tampil]);
  return (
    <div>
      <button onClick={() => setTampil(t => !t)}>{tampil ? "Istirahat" : "Mulai lagi"}</button>
      {tampil && <Jam />}
    </div>
  );
}

Kode pemula vs kode rapi

Nilai turunan tidak perlu state dan effect

Total yang bisa dihitung dari state lain cukup dihitung saat render. Menyimpannya di state lalu menyinkronkan dengan useEffect menambah satu render ekstra dan rawan tidak sinkron.

KODE PEMULA
const [keranjang, setKeranjang] = useState([]);
const [total, setTotal] = useState(0);
useEffect(() => {
  setTotal(keranjang.reduce((t, b) => t + b.harga, 0));
}, [keranjang]);
KODE RAPI (BEST PRACTICE)
const [keranjang, setKeranjang] = useState([]);
const total = keranjang.reduce((t, b) => t + b.harga, 0);

Poin penting

  • useEffect untuk efek samping setelah render.
  • [] sekali, [x] setiap x berubah, tanpa array setiap render.
  • Kembalikan cleanup untuk timer dan langganan.
  • Nilai turunan dihitung saat render, bukan lewat efek.
