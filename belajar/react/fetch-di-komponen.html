Fetch di komponen

Buka versi interaktif

Pola dasar mengambil data: simpan data, loading, dan error di state, panggil API di useEffect, dan tampilkan ketiga keadaan itu. Abaikan respons yang datang setelah komponen hilang atau parameter berubah.

Axios adalah alternatif fetch dengan fitur interceptor dan JSON otomatis. Contoh di bawah memakai API tiruan agar berjalan di mana saja.

CSS
body{font:14px system-ui,sans-serif}.err{color:#B23A2E}button{margin-right:4px}
JSX
const DB = { kopi: ["Kopi Gayo", "Kopi Toraja"], teh: ["Teh Melati", "Teh Hijau"] };
const api = kat => new Promise((ok, gagal) => setTimeout(() =>
  kat === "error" ? gagal(new Error("Server sedang sibuk")) : ok(DB[kat] || []), 700));

function App() {
  const [kat, setKat] = useState("kopi");
  const [st, setSt] = useState({ loading: true, data: [], error: null });
  useEffect(() => {
    let aktif = true;
    setSt(s => ({ ...s, loading: true, error: null }));
    api(kat).then(data => aktif && setSt({ loading: false, data, error: null }))
            .catch(error => aktif && setSt({ loading: false, data: [], error }));
    return () => { aktif = false; };
  }, [kat]);
  return (
    <div>
      {["kopi", "teh", "error"].map(k => <button key={k} onClick={() => setKat(k)}>{k}</button>)}
      {st.loading ? <p>Memuat…</p> : st.error ? <p className="err">{st.error.message}</p>
        : <ul>{st.data.map(n => <li key={n}>{n}</li>)}</ul>}
    </div>
  );
}

Poin penting

  • Tangani tiga keadaan: loading, error, data.
  • Abaikan respons usang dengan flag atau AbortController.
  • Axios: alternatif fetch dengan fitur tambahan.
