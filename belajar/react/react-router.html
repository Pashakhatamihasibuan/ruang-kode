React Router

Buka versi interaktif

Aplikasi React biasanya satu halaman HTML (SPA). Router memetakan alamat URL ke komponen tanpa memuat ulang halaman, sehingga tombol back browser tetap bekerja.

Dengan React Router: definisikan rute, pakai <Link> alih-alih <a>, baca parameter dengan useParams, dan pindah halaman lewat kode dengan useNavigate. TanStack Router adalah alternatif dengan dukungan TypeScript yang lebih ketat.

JSX
import { createBrowserRouter, RouterProvider, Link, useParams, Outlet } from "react-router-dom";

function Layout() {
  return (<><nav><Link to="/">Beranda</Link> · <Link to="/produk/1">Kopi Gayo</Link></nav><Outlet /></>);
}
function DetailProduk() {
  const { id } = useParams();          // "/produk/1" → id = "1"
  return <h1>Produk #{id}</h1>;
}

const router = createBrowserRouter([
  { path: "/", element: <Layout />, children: [
    { index: true, element: <h1>Beranda</h1> },
    { path: "produk/:id", element: <DetailProduk /> },
    { path: "*", element: <h1>Halaman tidak ditemukan</h1> },
  ]},
]);

export default function App() { return <RouterProvider router={router} />; }

Poin penting

  • Router memetakan URL ke komponen.
  • Link mencegah muat ulang halaman.
  • useParams membaca bagian dinamis URL.
  • Rute * untuk halaman 404.
