Props

Buka versi interaktif

Props adalah data yang dikirim dari komponen induk ke anak, seperti argumen fungsi: <KartuProduk nama="Teh" harga={25000} />. Anak menerimanya sebagai objek; biasanya langsung di-destructure: function KartuProduk({ nama, harga }).

Props bersifat hanya-baca: anak tidak boleh mengubahnya. Prop khusus children berisi apa pun yang ditulis di antara tag pembuka dan penutup, sehingga komponen bisa membungkus komponen lain.

CSS
body{font:14px system-ui,sans-serif}.kartu{border:1px solid #ddd;border-radius:10px;padding:8px 12px;margin:6px 0}.promo{border-color:#B4532A;background:#F6ECE5}
JSX
function KartuProduk({ nama, harga, promo = false }) {
  return (
    <div className={"kartu" + (promo ? " promo" : "")}>
      <h3>{nama}</h3>
      <p>Rp{harga.toLocaleString("id-ID")}</p>
    </div>
  );
}

function Bingkai({ judul, children }) {
  return <section><h2>{judul}</h2>{children}</section>;
}

function App() {
  return (
    <Bingkai judul="Katalog">
      <KartuProduk nama="Kopi Gayo" harga={85000} promo />
      <KartuProduk nama="Teh Melati" harga={25000} />
    </Bingkai>
  );
}

Tantangan

  1. Tambahkan kartu "Madu Hutan" seharga 120000 dengan prop promo.

Poin penting

  • Props dikirim dari induk ke anak.
  • Props hanya-baca.
  • Angka dan ekspresi ditulis di { }, teks boleh pakai tanda kutip.
  • children untuk membungkus isi.
