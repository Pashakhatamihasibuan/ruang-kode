Next.js, React Native & TypeScript

Buka versi interaktif

Next.js adalah framework React yang menambahkan routing berbasis folder, server-side rendering, React Server Components, dan API route. Halaman dirender di server sehingga cepat tampil dan ramah SEO. Astro cocok untuk situs konten yang sebagian besar statis.

React Native memakai konsep React yang sama untuk membuat aplikasi Android dan iOS sungguhan. TypeScript kini menjadi standar di proyek React profesional: props dan state punya tipe yang diperiksa sebelum aplikasi berjalan.

KODE
// app/produk/[id]/page.tsx  (Next.js App Router, Server Component)
type Produk = { id: number; nama: string; harga: number };

export default async function Halaman({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const res = await fetch(`https://api.tokonusantara.id/produk/${id}`, { next: { revalidate: 60 } });
  const p: Produk = await res.json();
  return (
    <main>
      <h1>{p.nama}</h1>
      <p>Rp{p.harga.toLocaleString("id-ID")}</p>
    </main>
  );
}

Poin penting

  • Next.js: routing folder, SSR, Server Components.
  • Astro untuk situs konten.
  • React Native untuk aplikasi mobile.
  • TypeScript memeriksa props sebelum berjalan.
