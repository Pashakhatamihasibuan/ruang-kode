Komponen & JSX

Buka versi interaktif

React membangun antarmuka dari komponen: fungsi yang mengembalikan tampilan. Nama komponen diawali huruf kapital, misalnya KartuProduk, dan dipakai seperti tag HTML: <KartuProduk />.

Tampilan ditulis dengan JSX, sintaks mirip HTML di dalam JavaScript. Perbedaannya: className pengganti class, htmlFor pengganti for, setiap tag harus ditutup, dan ekspresi JavaScript ditulis di dalam { }. Satu komponen harus mengembalikan satu elemen induk, atau fragment <>...</>.

Proyek nyata biasanya dibuat dengan npm create vite@latest. Di sini, pratinjau langsung menjalankan komponen App.

CSS
body{font:14px system-ui,sans-serif}.kartu{border:1px solid #ddd;border-radius:10px;padding:8px 12px;margin:6px 0}
JSX
function KartuProduk() {
  const nama = "Kopi Gayo";
  const harga = 85000;
  return (
    <div className="kartu">
      <h3>{nama}</h3>
      <p>Rp{harga.toLocaleString("id-ID")}</p>
    </div>
  );
}

function App() {
  return (
    <>
      <h2>Produk pilihan</h2>
      <KartuProduk />
      <KartuProduk />
    </>
  );
}

Tantangan

  1. Tampilkan tiga kartu produk.

Poin penting

  • Komponen = fungsi yang mengembalikan JSX.
  • Nama komponen diawali huruf kapital.
  • className, htmlFor, dan tag tertutup di JSX.
  • { } untuk ekspresi JavaScript.
