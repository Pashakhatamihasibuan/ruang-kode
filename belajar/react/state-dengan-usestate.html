State dengan useState

Buka versi interaktif

State adalah data milik komponen yang bisa berubah, misalnya jumlah barang di keranjang. const [jumlah, setJumlah] = useState(0) memberi nilai sekarang dan fungsi untuk menggantinya.

Saat setter dipanggil, React me-render ulang komponen dengan nilai baru. Jangan mengubah state langsung (jumlah++), selalu lewat setter. Jika nilai baru bergantung pada nilai lama, pakai bentuk fungsi: setJumlah(j => j + 1).

Untuk array dan objek, buat salinan baru: setDaftar([...daftar, item]), bukan daftar.push(item).

CSS
body{font:14px system-ui,sans-serif}.kartu{border:1px solid #ddd;border-radius:10px;padding:8px 12px}button{width:32px;height:32px;margin-right:6px}
JSX
function Penghitung() {
  const [jumlah, setJumlah] = useState(0);
  return (
    <div className="kartu">
      <p>Kopi Gayo di keranjang: <b>{jumlah}</b></p>
      <button onClick={() => setJumlah(j => Math.max(0, j - 1))}>−</button>
      <button onClick={() => setJumlah(j => j + 1)}>+</button>
      <p>Subtotal: Rp{(jumlah * 85000).toLocaleString("id-ID")}</p>
    </div>
  );
}

function App() {
  return <Penghitung />;
}

Tantangan

  1. Klik tombol + sampai jumlahnya 3.

Poin penting

  • useState mengembalikan [nilai, setter].
  • Memanggil setter memicu render ulang.
  • Pakai setter berbentuk fungsi bila bergantung nilai lama.
  • Jangan mutasi array/objek state; buat salinan.

Cek pemahaman

Kenapa jumlah++ tidak memperbarui tampilan?

Jawaban: React tidak tahu ada perubahan tanpa setter

Hanya setter yang menjadwalkan render ulang.
