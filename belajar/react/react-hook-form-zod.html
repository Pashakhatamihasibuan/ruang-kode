React Hook Form & Zod

Buka versi interaktif

Untuk form besar, pustaka seperti React Hook Form (atau Formik) mengurangi kode berulang dan render ulang. Ia mendaftarkan input dengan register dan menyediakan error secara terstruktur.

Zod mendefinisikan skema validasi sekali, lalu dipakai di frontend dan backend, sekaligus menghasilkan tipe TypeScript otomatis. Pustaka sejenis: Valibot dan Yup.

KODE
import { useForm } from "react-hook-form";
import { z } from "zod";
import { zodResolver } from "@hookform/resolvers/zod";

const Skema = z.object({
  nama: z.string().min(3, "Nama minimal 3 huruf"),
  email: z.string().email("Format email belum benar"),
  umur: z.coerce.number().int().min(17, "Minimal 17 tahun"),
});
type Daftar = z.infer<typeof Skema>;

export function FormDaftar() {
  const { register, handleSubmit, formState: { errors } } =
    useForm<Daftar>({ resolver: zodResolver(Skema) });
  return (
    <form onSubmit={handleSubmit(data => console.log(data))}>
      <input {...register("nama")} />  <small>{errors.nama?.message}</small>
      <input {...register("email")} /> <small>{errors.email?.message}</small>
      <input {...register("umur")} />  <small>{errors.umur?.message}</small>
      <button>Daftar</button>
    </form>
  );
}

Poin penting

  • React Hook Form: register, handleSubmit, errors.
  • Zod: satu skema untuk validasi dan tipe.
  • z.infer menghasilkan tipe TypeScript dari skema.
