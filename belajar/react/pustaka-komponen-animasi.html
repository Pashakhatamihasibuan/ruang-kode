Pustaka komponen & animasi

Buka versi interaktif

Pustaka komponen siap pakai seperti Material UI dan Chakra UI mempercepat pembuatan antarmuka. Pustaka headless seperti Radix UI, React Aria, dan Ark UI menyediakan perilaku dan aksesibilitas (keyboard, fokus, ARIA) tanpa gaya, sehingga tampilannya bebas kamu atur. shadcn/ui menyalin komponen berbasis Radix + Tailwind langsung ke proyekmu.

Untuk animasi, Framer Motion (kini bernama Motion) dan react-spring menyediakan animasi deklaratif dan berbasis fisika.

JSX
import * as Dialog from "@radix-ui/react-dialog";
import { motion } from "framer-motion";

export function KonfirmasiHapus({ onHapus }) {
  return (
    <Dialog.Root>
      <Dialog.Trigger>Hapus</Dialog.Trigger>
      <Dialog.Portal>
        <Dialog.Overlay className="fixed inset-0 bg-black/40" />
        <Dialog.Content asChild>
          <motion.div initial={{ opacity: 0, y: 12 }} animate={{ opacity: 1, y: 0 }}
                      className="fixed top-1/3 left-1/2 -translate-x-1/2 bg-white p-6 rounded-xl">
            <Dialog.Title>Hapus produk?</Dialog.Title>
            <button onClick={onHapus}>Ya, hapus</button>
            <Dialog.Close>Batal</Dialog.Close>
          </motion.div>
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
}

Poin penting

  • Pustaka bergaya (MUI, Chakra) vs headless (Radix, React Aria).
  • Headless: perilaku dan aksesibilitas, tanpa gaya.
  • Framer Motion untuk animasi deklaratif.
