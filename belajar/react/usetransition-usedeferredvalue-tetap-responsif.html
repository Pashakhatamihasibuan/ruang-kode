useTransition & useDeferredValue: tetap responsif

Buka versi interaktif

Saat pengguna mengetik di kotak pencarian yang menyaring ribuan produk, setiap ketukan memicu render berat dan input terasa tersendat. React 18 menyediakan dua hook untuk menandai pembaruan yang tidak mendesak.

useDeferredValue(nilai) mengembalikan versi nilai yang boleh tertinggal. Input tetap memakai nilai terbaru dan selalu responsif, sementara daftar berat memakai nilai yang ditunda. useTransition melakukan hal serupa untuk pembaruan state yang kamu picu sendiri, dan memberi isPending untuk indikator.

Ini bukan debounce: React tetap merender secepat mungkin, tetapi bisa menghentikan render lama jika ada ketukan baru. Ukur dulu dengan React DevTools Profiler sebelum menambahkan optimasi.

JSX
function CariProduk({ semuaProduk }) {
  const [kata, setKata] = useState("");
  const kataTunda = useDeferredValue(kata);
  const hasil = useMemo(
    () => semuaProduk.filter((p) => p.nama.toLowerCase().includes(kataTunda.toLowerCase())),
    [semuaProduk, kataTunda]
  );
  const usang = kata !== kataTunda;

  return (
    <>
      <input value={kata} onChange={(e) => setKata(e.target.value)} placeholder="Cari produk" />
      <ul style={{ opacity: usang ? 0.6 : 1 }}>
        {hasil.map((p) => <li key={p.id}>{p.nama}</li>)}
      </ul>
    </>
  );
}

Poin penting

  • useDeferredValue: nilai yang boleh tertinggal.
  • Input tetap responsif, daftar berat menyusul.
  • useTransition untuk pembaruan state tidak mendesak.
  • Ukur dengan Profiler sebelum mengoptimasi.
