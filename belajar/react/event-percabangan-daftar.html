Event, percabangan & daftar

Buka versi interaktif

Event di React ditulis camelCase: onClick, onChange, onSubmit, dan diberi fungsi, bukan pemanggilan fungsi: onClick={hapus}, bukan onClick={hapus()}.

Percabangan memakai JavaScript biasa: {stok > 0 ? <Beli /> : <Habis />} atau {promo && <Badge />}. Hati-hati: {0 && ...} menampilkan angka 0.

Daftar dibuat dengan map. Setiap elemen wajib punya key unik dan stabil, biasanya id dari data. Jangan pakai indeks array jika urutan bisa berubah.

CSS
body{font:14px system-ui,sans-serif}.ok{color:#2F7A52}.habis{color:#B23A2E}
JSX
const PRODUK = [
  { id: 1, nama: "Kopi Gayo", stok: 40 },
  { id: 7, nama: "Rendang Kaleng", stok: 0 },
  { id: 2, nama: "Teh Melati", stok: 120 },
];

function App() {
  const [hanyaAda, setHanyaAda] = useState(false);
  const daftar = hanyaAda ? PRODUK.filter(p => p.stok > 0) : PRODUK;
  return (
    <div>
      <label>
        <input type="checkbox" checked={hanyaAda} onChange={e => setHanyaAda(e.target.checked)} />
        {" "}Hanya yang tersedia
      </label>
      <ul>
        {daftar.map(p => (
          <li key={p.id}>
            {p.nama} {p.stok > 0 ? <span className="ok">tersedia</span> : <span className="habis">habis</span>}
          </li>
        ))}
      </ul>
    </div>
  );
}

Tantangan

  1. Centang "Hanya yang tersedia" sehingga produk habis tidak tampil.

Poin penting

  • Event camelCase, berisi fungsi.
  • Percabangan dengan ternary atau &&.
  • Daftar dengan map dan key unik yang stabil.
