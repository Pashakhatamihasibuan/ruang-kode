Komposisi, render props & HOC

Buka versi interaktif

React menyarankan komposisi, bukan pewarisan kelas: komponen kecil digabung lewat props dan children. Komponen Modal tidak perlu tahu isinya; ia cukup menampilkan children.

Render props adalah prop berisi fungsi yang mengembalikan JSX, sehingga komponen bisa berbagi perilaku sambil membiarkan pemakainya menentukan tampilan. Higher-order component (HOC) adalah fungsi yang menerima komponen dan mengembalikan komponen baru yang ditambahi kemampuan.

Kedua pola ini kini sebagian besar digantikan custom hook, tapi masih banyak ditemui di kode dan pustaka lama.

JSX
// Komposisi
function Kartu({ judul, children }) {
  return <section className="kartu"><h3>{judul}</h3>{children}</section>;
}
<Kartu judul="Promo"><p>Diskon 20%</p></Kartu>

// Render props
function Mouse({ render }) {
  const [pos, setPos] = useState({ x: 0, y: 0 });
  return <div onMouseMove={e => setPos({ x: e.clientX, y: e.clientY })}>{render(pos)}</div>;
}
<Mouse render={({ x, y }) => <p>Kursor di {x}, {y}</p>} />

// Higher-order component
function denganLogin(Komponen) {
  return function Terlindungi(props) {
    const user = useContext(UserCtx);
    return user ? <Komponen {...props} /> : <p>Silakan masuk dulu.</p>;
  };
}
const HalamanAkun = denganLogin(Akun);

Poin penting

  • Utamakan komposisi lewat props dan children.
  • Render props: prop berupa fungsi yang mengembalikan JSX.
  • HOC: fungsi komponen → komponen.
  • Custom hook adalah cara modern berbagi perilaku.
