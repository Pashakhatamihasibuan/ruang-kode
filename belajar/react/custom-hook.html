Custom hook

Buka versi interaktif

Logika berisi hook yang dipakai di beberapa komponen bisa diekstrak menjadi custom hook: fungsi biasa yang namanya diawali use dan memanggil hook lain.

Contoh: useLocalStorage menyimpan state ke localStorage agar tidak hilang saat halaman dimuat ulang. Setiap komponen yang memakainya mendapat state sendiri.

JSX
function useLocalStorage(kunci, awal) {
  const [nilai, setNilai] = useState(() => {
    try { return JSON.parse(localStorage.getItem(kunci)) ?? awal; } catch { return awal; }
  });
  useEffect(() => {
    try { localStorage.setItem(kunci, JSON.stringify(nilai)); } catch {}
  }, [kunci, nilai]);
  return [nilai, setNilai];
}

function App() {
  const [nama, setNama] = useLocalStorage("nama-pembeli", "");
  return (
    <div>
      <label>Nama pembeli <input value={nama} onChange={e => setNama(e.target.value)} /></label>
      <p>Halo, {nama || "tamu"}! Muat ulang pratinjau: namamu tetap ada.</p>
    </div>
  );
}

Poin penting

  • Custom hook = fungsi berawalan use yang memanggil hook.
  • Berbagi logika, bukan berbagi state.
  • Contoh umum: useFetch, useLocalStorage, useDebounce.
