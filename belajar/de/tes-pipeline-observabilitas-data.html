Tes pipeline & observabilitas data

Buka versi interaktif

Pipeline diuji seperti perangkat lunak: unit test untuk fungsi transformasi, integration test untuk sambungan ke database, end-to-end untuk alur penuh, dan smoke test setelah deploy.

Di produksi, pantau lima pilar observabilitas data: kesegaran (data terakhir masuk kapan), volume (jumlah baris wajar), skema (kolom berubah), distribusi (nilai aneh), dan lineage (dampak ke hilir).

Contoh di bawah adalah pemeriksaan sederhana yang bisa dijalankan setelah setiap muatan; di dunia nyata dipakai dbt tests, Great Expectations, atau Soda.

PYTHON
from datetime import datetime, timedelta

muatan = {"baris": 41_250, "kolom": ["id", "tanggal", "kota", "total"],
          "terakhir": datetime(2024, 10, 2, 2, 14), "total_negatif": 0}
kemarin = {"baris": 43_900}
sekarang = datetime(2024, 10, 2, 7, 0)

cek = {
    "segar (< 6 jam)": sekarang - muatan["terakhir"] < timedelta(hours=6),
    "volume (±20%)": abs(muatan["baris"] / kemarin["baris"] - 1) <= 0.20,
    "skema sama": muatan["kolom"] == ["id", "tanggal", "kota", "total"],
    "tidak ada total negatif": muatan["total_negatif"] == 0,
}
for nama, ok in cek.items():
    print(("LULUS " if ok else "GAGAL ") + nama)
print("pipeline sehat" if all(cek.values()) else "kirim peringatan ke on-call")
KELUARAN
LULUS segar (< 6 jam)
LULUS volume (±20%)
LULUS skema sama
LULUS tidak ada total negatif
pipeline sehat
