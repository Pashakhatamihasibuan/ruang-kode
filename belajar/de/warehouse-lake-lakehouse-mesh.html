Warehouse, lake, lakehouse & mesh

Buka versi interaktif

Warehouse (Snowflake, BigQuery, Redshift) untuk data terstruktur yang siap dianalisis. Lake (S3, GCS, Azure Blob) untuk semua data mentah dengan biaya murah. Lakehouse (Delta Lake, Apache Iceberg) menambahkan transaksi ACID dan skema di atas berkas lake sehingga satu tempat melayani BI dan ML.

Arsitektur berlapis yang umum disebut medallion: bronze (mentah), silver (dibersihkan), gold (siap bisnis).

Data mesh adalah pendekatan organisasi: setiap domain (penjualan, gudang) memiliki dan menerbitkan data sebagai produk, dengan platform bersama. Data fabric lebih ke lapisan teknologi yang menyatukan akses dan metadata lintas sumber.

CONTOH
s3://toko-lake/
  bronze/transaksi/dt=2024-10-01/part-0001.json     ← apa adanya dari Kafka
  silver/transaksi/dt=2024-10-01/part-0001.parquet  ← tipe benar, duplikat dibuang
  gold/fakta_penjualan/                             ← model bintang, siap BI
  gold/fitur_pelanggan/                             ← fitur untuk model ML

Poin penting

  • Warehouse terstruktur; lake mentah; lakehouse = keduanya.
  • Medallion: bronze → silver → gold.
  • Mesh = kepemilikan per domain.
