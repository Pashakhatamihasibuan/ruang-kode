Orkestrasi dengan Airflow

Buka versi interaktif

Orkestrator menjadwalkan tugas, mengatur urutan (A sebelum B), mencoba ulang saat gagal, dan memberi tampilan status. Apache Airflow paling populer; alternatifnya Prefect, Dagster, dan Luigi.

Pipeline Airflow ditulis sebagai DAG (directed acyclic graph) dalam Python. Setiap tugas idealnya idempoten dan menerima tanggal eksekusi sebagai parameter, sehingga bisa backfill ke tanggal lampau.

Orkestrator mengatur, tidak memproses data berat. Pekerjaan berat diserahkan ke warehouse, Spark, atau dbt.

PYTHON
from datetime import datetime
from airflow.decorators import dag, task

@dag(schedule="0 2 * * *", start_date=datetime(2024, 1, 1), catchup=False,
     default_args={"retries": 3})
def penjualan_harian():

    @task
    def ekstrak(ds=None):
        return salin_dari_postgres(tanggal=ds, ke=f"s3://toko-lake/bronze/transaksi/dt={ds}/")

    @task
    def muat(path: str, ds=None):
        timpa_partisi("silver.transaksi", tanggal=ds, sumber=path)   # idempoten

    @task
    def transformasi():
        jalankan("dbt build --select marts.penjualan")

    muat(ekstrak()) >> transformasi()

penjualan_harian()

Poin penting

  • Orkestrator: jadwal, urutan, retry, status.
  • DAG Python; tugas idempoten berparameter tanggal.
  • Orkestrator mengatur, mesin lain memproses.
