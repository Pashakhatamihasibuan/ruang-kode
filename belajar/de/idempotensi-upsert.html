Idempotensi & upsert

Buka versi interaktif

Pipeline pasti pernah gagal di tengah jalan lalu dijalankan ulang. Pipeline idempoten menghasilkan hasil yang sama berapa kali pun dijalankan untuk input yang sama, sehingga tidak ada data ganda.

Teknik umum: upsert (INSERT ... ON CONFLICT DO UPDATE), menimpa satu partisi tanggal secara utuh (delete + insert dalam transaksi), dan kunci deduplikasi dari sumber.

Contoh di bawah memuat batch yang sama dua kali. Dengan INSERT biasa baris jadi ganda; dengan upsert hasilnya tetap.

PYTHON
import sqlite3

batch = [(101, "2024-10-01", 255000), (102, "2024-10-01", 250000)]

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE naif (id INTEGER, tanggal TEXT, total INTEGER)")
con.execute("CREATE TABLE aman (id INTEGER PRIMARY KEY, tanggal TEXT, total INTEGER)")

for percobaan in range(2):           # pipeline dijalankan ulang
    con.executemany("INSERT INTO naif VALUES (?, ?, ?)", batch)
    con.executemany("""INSERT INTO aman VALUES (?, ?, ?)
        ON CONFLICT(id) DO UPDATE SET tanggal = excluded.tanggal, total = excluded.total""", batch)

print("naif:", con.execute("SELECT COUNT(*), SUM(total) FROM naif").fetchone())
print("aman:", con.execute("SELECT COUNT(*), SUM(total) FROM aman").fetchone())
KELUARAN
naif: (4, 1010000)
aman: (2, 505000)

Soal latihan

  1. Tulis upsert PostgreSQL: masukkan stok produk, atau perbarui jika kode produk sudah ada.

    Petunjuk

    INSERT ... ON CONFLICT (kunci) DO UPDATE SET ... = EXCLUDED....

    Lihat jawaban
    SQL
    INSERT INTO stok (kode, jumlah, diperbarui)
VALUES ('K1', 40, NOW())
ON CONFLICT (kode)
DO UPDATE SET jumlah = EXCLUDED.jumlah,
              diperbarui = EXCLUDED.diperbarui;

  2. Tunjukkan bahwa memuat data harian dua kali tidak membuat data ganda jika memakai upsert berdasarkan kunci.

    Petunjuk

    Pakai dict sebagai tabel: kunci yang sama ditimpa, bukan ditambah.

    Lihat jawaban
    PYTHON
    tabel = {}

def muat(baris):
    for r in baris:
        tabel[(r["tanggal"], r["kode"])] = r     # upsert berdasarkan kunci

harian = [{"tanggal": "2026-11-01", "kode": "K1", "jumlah": 5},
          {"tanggal": "2026-11-01", "kode": "T1", "jumlah": 3}]
muat(harian)
muat(harian)          # dijalankan ulang
print(len(tabel))
    KELUARAN
    2

Kode pemula vs kode rapi

Upsert agar pipeline aman dijalankan ulang

Pipeline yang gagal di tengah sering dijalankan ulang. INSERT biasa menghasilkan baris ganda, sedangkan INSERT ... ON CONFLICT DO UPDATE (PostgreSQL, SQLite) memperbarui baris yang sudah ada, sehingga hasilnya sama berapa kali pun dijalankan.

KODE PEMULA
import sqlite3
db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE stok (sku TEXT, jumlah INT)")
for _ in range(2):  # pipeline dijalankan dua kali
    db.execute("INSERT INTO stok VALUES ('KOPI-01', 40)")
print(db.execute("SELECT * FROM stok").fetchall())
KODE RAPI (BEST PRACTICE)
import sqlite3
db = sqlite3.connect(":memory:")
db.execute("CREATE TABLE stok (sku TEXT PRIMARY KEY, jumlah INT)")
for _ in range(2):  # pipeline dijalankan dua kali
    db.execute("""INSERT INTO stok VALUES ('KOPI-01', 40)
                  ON CONFLICT(sku) DO UPDATE SET jumlah = excluded.jumlah""")
print(db.execute("SELECT * FROM stok").fetchall())

Poin penting

  • Idempoten = aman dijalankan ulang.
  • Upsert, timpa partisi, kunci deduplikasi.
  • Uji dengan menjalankan pipeline dua kali.
