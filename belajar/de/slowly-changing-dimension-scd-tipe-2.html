Slowly changing dimension (SCD tipe 2)

Buka versi interaktif

Atribut dimensi kadang berubah: pelanggan pindah kota. SCD tipe 1 menimpa nilai lama, riwayat hilang. SCD tipe 2 menutup baris lama (berlaku_sampai) dan menambah baris baru, sehingga penjualan lama tetap tercatat di kota lama.

Setiap versi punya surrogate key sendiri, kolom berlaku_dari, berlaku_sampai, dan penanda aktif. Fakta menyimpan surrogate key versi yang berlaku saat transaksi.

Kode di bawah menerapkan SCD tipe 2 dengan pandas untuk satu perubahan.

PYTHON
import pandas as pd

dim = pd.DataFrame([
    {"sk": 1, "pelanggan_id": 41, "kota": "Bandung", "berlaku_dari": "2023-01-15", "berlaku_sampai": "9999-12-31", "aktif": True},
    {"sk": 2, "pelanggan_id": 42, "kota": "Medan",   "berlaku_dari": "2023-03-02", "berlaku_sampai": "9999-12-31", "aktif": True},
])
perubahan = {"pelanggan_id": 41, "kota": "Jakarta", "tanggal": "2024-06-01"}

lama = (dim["pelanggan_id"] == perubahan["pelanggan_id"]) & dim["aktif"]
if dim.loc[lama, "kota"].iloc[0] != perubahan["kota"]:
    dim.loc[lama, ["berlaku_sampai", "aktif"]] = [perubahan["tanggal"], False]
    baru = {"sk": dim["sk"].max() + 1, "pelanggan_id": 41, "kota": perubahan["kota"],
            "berlaku_dari": perubahan["tanggal"], "berlaku_sampai": "9999-12-31", "aktif": True}
    dim = pd.concat([dim, pd.DataFrame([baru])], ignore_index=True)
print(dim.to_string(index=False))

Poin penting

  • Tipe 1 menimpa; tipe 2 menyimpan riwayat.
  • Surrogate key per versi + rentang berlaku.
  • Fakta merujuk versi yang berlaku saat transaksi.
