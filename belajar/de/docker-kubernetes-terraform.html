Docker, Kubernetes & Terraform

Buka versi interaktif

Docker membungkus kode beserta dependensinya dalam image, sehingga job berjalan sama di laptop dan server. Kubernetes menjalankan dan mengatur banyak kontainer: penjadwalan, restart otomatis, skala.

Infrastructure as Code (Terraform, OpenTofu, AWS CDK) menulis bucket, dataset, dan izin akses sebagai kode yang direview di pull request, alih-alih klik di konsol.

CI/CD menjalankan tes (unit, dbt test) di setiap PR dan menerapkan perubahan otomatis setelah digabung.

CONTOH
# Dockerfile untuk job ETL
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY etl/ etl/
CMD ["python", "-m", "etl.penjualan_harian"]

# Terraform: bucket lake
resource "google_storage_bucket" "lake" {
  name     = "toko-lake"
  location = "asia-southeast2"   # Jakarta
  uniform_bucket_level_access = true
}

Poin penting

  • Docker: lingkungan sama di mana saja.
  • Kubernetes: mengatur banyak kontainer.
  • IaC + CI/CD: infrastruktur direview dan diuji.
