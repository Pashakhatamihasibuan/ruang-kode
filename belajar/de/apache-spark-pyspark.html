Apache Spark & PySpark

Buka versi interaktif

Spark memproses data di banyak mesin dengan API DataFrame yang mirip pandas dan SQL. Driver membagi pekerjaan menjadi task yang dijalankan executor di setiap node.

Transformasi Spark bersifat lazy: filter dan groupBy hanya menyusun rencana; eksekusi terjadi saat action seperti write atau count. Operasi yang memindahkan data antar node (groupBy, join) disebut shuffle dan paling mahal.

Hadoop (HDFS untuk penyimpanan, YARN untuk sumber daya) adalah generasi sebelumnya; kini Spark lebih sering berjalan di Kubernetes, Databricks, atau layanan cloud (EMR, Dataproc).

PYTHON
from pyspark.sql import SparkSession, functions as F

spark = SparkSession.builder.appName("omzet_harian").getOrCreate()

trx = spark.read.parquet("s3://toko-lake/silver/transaksi/")
harian = (trx.filter(F.col("status") == "selesai")
             .groupBy("tanggal", "kota")                    # shuffle
             .agg(F.sum("total").alias("omzet"), F.count("*").alias("n")))

(harian.write.mode("overwrite")
       .partitionBy("tanggal")
       .parquet("s3://toko-lake/gold/omzet_harian/"))       # action

Poin penting

  • Driver → task → executor.
  • Lazy: transformasi menyusun rencana, action mengeksekusi.
  • Shuffle paling mahal.
