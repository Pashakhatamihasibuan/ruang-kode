Linux & shell untuk data

Buka versi interaktif

Hampir semua server data berjalan di Linux. Kuasai navigasi (cd, ls), melihat berkas besar tanpa membukanya (head, tail, wc -l), mencari (grep), dan pipa | untuk merangkai perintah.

Untuk jaringan: curl menguji API, ssh masuk ke server, dan pahami port, DNS, serta firewall karena banyak pipeline gagal hanya karena koneksi ditolak.

Penjadwal paling sederhana adalah cron. Saat jumlah job bertambah dan saling bergantung, pindah ke orkestrator seperti Airflow.

TERMINAL
$ wc -l penjualan_2024.csv
1048577 penjualan_2024.csv
$ head -3 penjualan_2024.csv
id,tanggal,kota,omzet
1,2024-01-01,Jakarta,255000
2,2024-01-01,Bandung,250000
$ cut -d, -f3 penjualan_2024.csv | sort | uniq -c | sort -rn | head -3
 412880 Jakarta
 230114 Surabaya
 198322 Bandung
$ curl -s https://api.contoh.id/health

Kode pemula vs kode rapi

Satu perintah lebih baik dari rantai cat

grep bisa membaca file sendiri dan menghitung baris yang cocok dengan -c, jadi cat dan wc tidak perlu. awk bisa menjumlah kolom CSV tanpa membuka spreadsheet.

KODE PEMULA
cat penjualan.csv | grep Medan | wc -l
KODE RAPI (BEST PRACTICE)
grep -c Medan penjualan.csv
awk -F, '$2 == "Medan" { total += $3 } END { print total }' penjualan.csv

Poin penting

  • head, tail, wc, grep, cut, sort, uniq, pipa.
  • curl, ssh, port, DNS.
  • cron untuk jadwal sederhana.
