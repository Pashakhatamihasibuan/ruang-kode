Pipeline penjualan harian Toko Nusantara

Buka versi interaktif

Bangun pipeline yang setiap malam mengambil transaksi dari database kasir, menyimpannya di lake (bronze/silver), memodelkan skema bintang dengan dbt, dan memperbarui dashboard, lengkap dengan tes dan peringatan.

Teknologi: Python + Airflow + dbt + Postgres/BigQuery

Fitur yang dibuat

  • Ekstraksi inkremental per tanggal dari Postgres
  • Penyimpanan Parquet terpartisi tanggal (bronze → silver)
  • Pemuatan idempoten: dijalankan dua kali hasilnya sama
  • DAG Airflow dengan retry dan backfill
  • Model dbt fakta_penjualan + dim_produk + dim_toko + dim_pelanggan (SCD tipe 2)
  • dbt tests: not_null, unique, relationships, rentang nilai
  • Pemeriksaan kesegaran dan volume dengan peringatan
  • README dengan diagram arsitektur dan cara menjalankan lewat Docker Compose

Langkah kerja

  1. Siapkan Postgres dan data contoh dengan Docker Compose.
  2. Tulis ekstraksi inkremental dan simpan ke Parquet.
  3. Buat DAG Airflow dan uji backfill 7 hari.
  4. Bangun model dbt dan tesnya.
  5. Tambahkan pemeriksaan kualitas dan dokumentasi.
docker-compose.yml
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: rahasia
    ports: ["5432:5432"]
  airflow:
    image: apache/airflow:2.10.3
    command: standalone
    volumes: ["./dags:/opt/airflow/dags", "./lake:/data/lake"]
    ports: ["8080:8080"]

       t.jumlah, t.harga, t.diskon_persen
FROM {{ ref('stg_transaksi') }} t
JOIN {{ ref('dim_tanggal') }} d ON d.tanggal = t.tanggal
JOIN {{ ref('dim_pelanggan') }} p
  ON p.pelanggan_id = t.pelanggan_id
 AND t.tanggal >= p.berlaku_dari AND t.tanggal < p.berlaku_sampai
