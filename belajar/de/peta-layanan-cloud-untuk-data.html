Peta layanan cloud untuk data

Buka versi interaktif

Ketiga cloud besar punya padanan untuk hampir setiap kebutuhan. Pelajari satu dengan baik; konsepnya mudah dipindahkan.

Serverless (BigQuery, Lambda, Cloud Run) berarti kamu membayar per pemakaian tanpa mengurus server, cocok untuk beban yang naik-turun.

Perhatikan biaya: query yang memindai seluruh tabel besar di BigQuery bisa mahal. Partisi tabel dan pilih kolom seperlunya.

CONTOH
Kebutuhan          AWS                 GCP                  Azure
Penyimpanan objek  S3                  Cloud Storage        Blob Storage
Warehouse          Redshift            BigQuery             Synapse
Spark terkelola    EMR                 Dataproc             HDInsight / Databricks
Streaming          Kinesis / MSK       Pub/Sub              Event Hubs
Orkestrasi         MWAA (Airflow)      Cloud Composer       Data Factory
Fungsi serverless  Lambda              Cloud Functions/Run  Functions

Poin penting

  • Pelajari satu cloud; konsep berpindah.
  • Serverless: bayar per pemakaian.
  • Partisi dan pilih kolom untuk menekan biaya.
