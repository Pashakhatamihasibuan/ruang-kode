HTML · Modul 5 · Praktik langsung

Validasi bawaan

Buka versi interaktif

HTML bisa memeriksa input sebelum form dikirim tanpa JavaScript. required mewajibkan isi, minlength/maxlength membatasi panjang, min/max/step untuk angka, dan pattern memakai regular expression.

Pseudo-class CSS :invalid dan :valid bisa dipakai untuk memberi warna. Tetap ingat: validasi di browser hanya untuk kenyamanan. Server tetap wajib memeriksa ulang karena data bisa dikirim tanpa lewat form.

Coba tekan Kirim dengan isian kosong atau kode pos yang salah.

HTML
<form onsubmit="event.preventDefault();document.getElementById('hasil').textContent='Valid, siap dikirim!'">
  <label for="kp">Kode pos (5 angka)</label><br>
  <input id="kp" name="kodepos" required pattern="[0-9]{5}" inputmode="numeric"><br>
  <label for="jml">Jumlah (1–10)</label><br>
  <input id="jml" name="jumlah" type="number" min="1" max="10" required><br>
  <label for="pw">Kata sandi (min. 8 karakter)</label><br>
  <input id="pw" type="password" minlength="8" required><br><br>
  <button>Kirim</button>
  <p id="hasil" aria-live="polite"></p>
</form>
CSS
input:invalid{border-color:#B23A2E}input:valid{border-color:#2F7A52}input{border:2px solid #ccc;padding:4px;border-radius:6px}

Tantangan

  1. Wajibkan input kode pos tepat 5 angka dan tambahkan input email yang required.

Poin penting

  • required, min/max, minlength, pattern adalah validasi bawaan.
  • :invalid dan :valid untuk umpan balik visual.
  • Server tetap wajib memvalidasi ulang.
