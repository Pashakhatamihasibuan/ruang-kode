Cara web bekerja

Buka versi interaktif

Saat kamu mengetik tokonusantara.id lalu menekan Enter, browser lebih dulu bertanya ke DNS (buku telepon internet): "alamat IP domain ini berapa?". Setelah mendapat alamat IP, browser mengirim permintaan HTTP ke server di alamat itu.

Server adalah komputer yang menyimpan file situs, biasanya disewa dari layanan hosting. Server membalas dengan respons HTTP: kode status (200 berarti berhasil, 404 berarti tidak ditemukan) dan isi berupa dokumen HTML.

Browser lalu membaca HTML dari atas ke bawah, meminta file tambahan seperti CSS, gambar, dan JavaScript, lalu menggambar halamannya di layar. Seluruh proses ini biasanya selesai dalam hitungan milidetik.

CONTOH
GET /index.html HTTP/1.1
Host: tokonusantara.id
Accept: text/html

HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

<!DOCTYPE html>
<html lang="id">...</html>

Poin penting

  • DNS menerjemahkan nama domain menjadi alamat IP.
  • Browser mengirim request HTTP, server membalas dengan response.
  • Kode status 200 = berhasil, 404 = tidak ditemukan, 500 = error di server.
  • HTTPS adalah HTTP yang dienkripsi.
