HTML · Modul 5 · Konsep & kode

Tipe input modern & datalist

Buka versi interaktif

Memilih type yang tepat memberi banyak hal gratis. type="email" memeriksa format email, type="tel" menampilkan papan angka telepon di HP, type="date" memberi pemilih tanggal, dan type="range" membuat slider.

inputmode mengatur keyboard tanpa mengubah validasi, misalnya inputmode="numeric" untuk kode OTP. autocomplete membantu browser dan pengelola kata sandi mengisi otomatis, misalnya autocomplete="one-time-code" untuk OTP dari SMS.

<datalist> memberi saran sambil tetap mengizinkan isian bebas, cocok untuk nama kota. Untuk daftar yang wajib dipilih, tetap pakai <select>.

HTML
<form>
  <label for="email">Email</label>
  <input id="email" type="email" autocomplete="email" required>

  <label for="otp">Kode OTP</label>
  <input id="otp" inputmode="numeric" autocomplete="one-time-code" pattern="[0-9]{6}" maxlength="6">

  <label for="kirim">Tanggal kirim</label>
  <input id="kirim" type="date" min="2026-11-01">

  <label for="budget">Budget maksimal: <output id="nilai">500000</output></label>
  <input id="budget" type="range" min="50000" max="2000000" step="50000" value="500000"
         oninput="nilai.value = this.value">

  <label for="kota">Kota</label>
  <input id="kota" list="daftar-kota" autocomplete="address-level2">
  <datalist id="daftar-kota">
    <option value="Medan"><option value="Bandung"><option value="Makassar">
  </datalist>
</form>

Poin penting

  • type yang tepat memberi validasi dan keyboard yang sesuai.
  • inputmode mengatur keyboard tanpa validasi.
  • autocomplete=one-time-code untuk OTP.
  • datalist: saran dengan isian bebas.

Cek pemahaman

Atribut agar HP menampilkan keyboard angka untuk OTP?

Jawaban: inputmode="numeric"

inputmode menentukan jenis keyboard virtual.

Beda datalist dan select?

Jawaban: datalist memberi saran tetapi isian bebas tetap boleh

select hanya menerima pilihan yang tersedia.
