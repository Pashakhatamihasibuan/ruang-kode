Open Graph & data terstruktur

Buka versi interaktif

Saat link dibagikan di WhatsApp atau media sosial, yang muncul adalah judul, deskripsi, dan gambar dari tag Open Graph (og:title, og:description, og:image). Tanpa tag ini, pratinjau link sering kosong atau mengambil teks acak.

Data terstruktur dengan format JSON-LD dan kosakata schema.org menjelaskan isi halaman kepada mesin pencari: ini produk dengan harga sekian, ini artikel oleh penulis tertentu, ini kursus. Google memakainya untuk hasil penelusuran yang lebih kaya.

Tambahkan juga <link rel="canonical"> agar halaman yang bisa diakses lewat beberapa URL dianggap satu halaman. Periksa hasilnya dengan Rich Results Test dari Google.

HTML
<head>
  <title>Kopi Gayo 250 g · Toko Nusantara</title>
  <meta name="description" content="Kopi arabika Gayo sangrai medium, 250 gram. Dikirim dari Aceh.">
  <link rel="canonical" href="https://toko.contoh.id/produk/kopi-gayo">

  <meta property="og:type" content="product">
  <meta property="og:title" content="Kopi Gayo 250 g">
  <meta property="og:description" content="Arabika Gayo sangrai medium. Rp85.000">
  <meta property="og:image" content="https://toko.contoh.id/img/kopi-gayo-1200x630.jpg">

  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "Product",
    "name": "Kopi Gayo 250 g",
    "offers": { "@type": "Offer", "price": 85000, "priceCurrency": "IDR",
                "availability": "https://schema.org/InStock" }
  }
  </script>
</head>

Poin penting

  • Open Graph mengatur pratinjau saat link dibagikan.
  • og:image ideal 1200×630 piksel.
  • JSON-LD + schema.org menjelaskan isi ke mesin pencari.
  • canonical menyatukan URL ganda.
