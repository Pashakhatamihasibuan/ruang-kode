Performa & keamanan di HTML

Buka versi interaktif

HTML juga menentukan seberapa cepat halaman tampil. Priority hints seperti fetchpriority="high" memberi tahu browser gambar mana yang paling penting (misalnya gambar utama di atas), dan <link rel="preload"> meminta file kritis diunduh lebih awal.

Content Security Policy (CSP) adalah daftar sumber yang diizinkan memuat script, gaya, dan gambar. Jika penyerang berhasil menyisipkan script dari domain lain, browser menolaknya. CSP biasanya dikirim lewat header HTTP, tapi bisa juga lewat meta tag.

HTML
<head>
  <!-- unduh font utama lebih awal -->
  <link rel="preload" href="/font/inter.woff2" as="font" type="font/woff2" crossorigin>
  <!-- hanya izinkan script dari situs sendiri -->
  <meta http-equiv="Content-Security-Policy"
        content="default-src 'self'; img-src 'self' https://cdn.tokonusantara.id">
</head>
<body>
  <img src="/img/banner.webp" fetchpriority="high" width="1200" height="400" alt="Promo kopi Oktober">
  <img src="/img/footer.webp" loading="lazy" width="600" height="200" alt="">
</body>

Poin penting

  • fetchpriority="high" untuk gambar utama di layar pertama.
  • loading="lazy" untuk gambar di bawah.
  • preload untuk file kritis seperti font.
  • CSP membatasi sumber script dan gaya.
