div, span, class & data-*

Buka versi interaktif

<div> (blok) dan <span> (sebaris) adalah wadah tanpa makna. Pakai keduanya hanya untuk kebutuhan gaya atau pengelompokan ketika tidak ada elemen semantik yang cocok.

class dipakai CSS dan JavaScript untuk memilih sekelompok elemen. id menunjuk satu elemen unik, misalnya target link #id atau label for.

Atribut data-* menyimpan data tambahan milikmu sendiri, misalnya data-harga="85000". JavaScript membacanya lewat elemen.dataset.harga.

HTML
<div class="kartu" data-id="1" data-harga="85000">
  <h3>Kopi Gayo</h3>
  <p>Harga: <span class="harga">Rp85.000</span></p>
  <button>Tambah</button>
</div>
<div class="kartu" data-id="2" data-harga="25000">
  <h3>Teh Melati</h3>
  <p>Harga: <span class="harga">Rp25.000</span></p>
  <button>Tambah</button>
</div>
<p id="total">Total: Rp0</p>
<script>
let total = 0;
document.querySelectorAll('.kartu button').forEach(b => b.onclick = () => {
  total += Number(b.closest('.kartu').dataset.harga);
  document.getElementById('total').textContent = 'Total: Rp' + total.toLocaleString('id-ID');
});
</script>
CSS
.kartu{border:1px solid #ddd;border-radius:10px;padding:8px 12px;margin-bottom:8px;font:14px sans-serif}.harga{color:#2F7A52;font-weight:600}

Tantangan

  1. Tambahkan kartu ketiga dengan data-harga="15000".

Poin penting

  • div dan span tidak punya makna; pakai seperlunya.
  • class untuk kelompok, id untuk satu elemen unik.
  • data-* menyimpan data, dibaca dengan dataset.
