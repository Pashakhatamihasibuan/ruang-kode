Memuat JavaScript

Buka versi interaktif

JavaScript ditulis di <script>, baik langsung maupun dari file: <script src="app.js"></script>. Browser menghentikan pembacaan HTML saat bertemu script biasa sampai script selesai diunduh dan dijalankan.

Karena itu, taruh script di akhir body, atau pakai defer di head: file diunduh paralel dan dijalankan setelah HTML selesai dibaca, sesuai urutan. async menjalankan secepatnya tanpa urutan, cocok untuk skrip analitik. type="module" otomatis bersifat defer.

HTML
<button id="sapa">Sapa saya</button>
<p id="pesan"></p>
<script>
  // Script di akhir body: elemen di atas sudah ada
  document.getElementById('sapa').addEventListener('click', () => {
    const jam = new Date().getHours();
    const waktu = jam < 11 ? 'pagi' : jam < 15 ? 'siang' : jam < 18 ? 'sore' : 'malam';
    document.getElementById('pesan').textContent = 'Selamat ' + waktu + '!';
  });
</script>

Tantangan

  1. Ubah agar tombol juga mengganti teks tombol menjadi "Sudah disapa".

Poin penting

  • Script biasa menghentikan pembacaan HTML.
  • defer: unduh paralel, jalan setelah HTML siap, berurutan.
  • async: jalan secepatnya tanpa urutan.
