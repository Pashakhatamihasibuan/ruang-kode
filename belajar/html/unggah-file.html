Unggah file

Buka versi interaktif

<input type="file"> memungkinkan pengguna memilih file. Atribut accept membatasi jenisnya (misalnya image/* atau .pdf) dan multiple mengizinkan banyak file.

Form yang mengunggah file harus memakai method="post" dan enctype="multipart/form-data". Seperti validasi lain, server tetap harus memeriksa ukuran dan jenis file karena atribut accept mudah dilewati.

HTML
<form method="post" enctype="multipart/form-data">
  <label for="foto">Foto bukti transfer (JPG/PNG)</label><br>
  <input id="foto" name="foto" type="file" accept="image/png,image/jpeg">
  <p id="info">Belum ada file.</p>
</form>
<script>
document.getElementById('foto').onchange = e => {
  const f = e.target.files[0];
  document.getElementById('info').textContent =
    f ? f.name + ' (' + Math.round(f.size / 1024) + ' KB)' : 'Belum ada file.';
};
</script>

Poin penting

  • type="file" untuk memilih file.
  • accept membatasi jenis, multiple untuk banyak file.
  • Wajib enctype="multipart/form-data" dan method post.
