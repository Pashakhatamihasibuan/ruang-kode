Memasang CSS

Buka versi interaktif

Ada tiga cara memberi gaya. Inline lewat atribut style pada satu elemen; internal lewat <style> di head; dan eksternal lewat file terpisah <link rel="stylesheet" href="gaya.css">.

Untuk situs nyata, pakai file eksternal: satu file bisa dipakai banyak halaman dan disimpan di cache browser. Inline sulit dirawat dan menang dari hampir semua aturan lain, jadi pakai seperlunya.

HTML
<!-- eksternal (contoh, file tidak ada di sini) -->
<link rel="stylesheet" href="gaya.css">
<!-- internal -->
<style>
  .promo { background: #FBE7A8; padding: 8px 12px; border-radius: 8px; }
</style>
<p class="promo">Diskon 20% untuk semua kopi.</p>
<!-- inline -->
<p style="color: #B23A2E; font-weight: 600;">Stok terbatas!</p>

Poin penting

  • Inline: atribut style, hanya satu elemen.
  • Internal: tag style di head.
  • Eksternal: file .css lewat link, paling mudah dirawat.
