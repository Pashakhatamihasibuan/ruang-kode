details, summary & dialog: interaksi tanpa JavaScript

Buka versi interaktif

Beberapa interaksi umum sudah disediakan HTML. <details> dan <summary> membuat bagian yang bisa dibuka-tutup, misalnya FAQ, lengkap dengan dukungan keyboard dan pembaca layar. Atribut name yang sama pada beberapa details membuatnya saling menutup seperti akordeon.

<dialog> membuat jendela modal. Dibuka dengan showModal(), ia otomatis berada di atas halaman, menutup dengan tombol Esc, dan menahan fokus di dalamnya. Form dengan method="dialog" di dalamnya menutup dialog saat dikirim.

Atribut popover (didukung browser utama sejak 2024) membuat menu atau tooltip yang ditutup saat klik di luar, tanpa satu baris JavaScript pun.

HTML
<h2>Pertanyaan umum</h2>
<details name="faq" open>
  <summary>Berapa lama pengiriman?</summary>
  <p>2 sampai 4 hari kerja untuk Pulau Jawa.</p>
</details>
<details name="faq">
  <summary>Bisa bayar di tempat (COD)?</summary>
  <p>Bisa untuk pesanan di bawah Rp1.000.000.</p>
</details>

<button popovertarget="menu-akun">Akun ▾</button>
<div id="menu-akun" popover>
  <a href="/pesanan">Pesanan saya</a><br>
  <a href="/keluar">Keluar</a>
</div>

<button onclick="konfirmasi.showModal()">Batalkan pesanan</button>
<dialog id="konfirmasi">
  <form method="dialog">
    <p>Yakin membatalkan pesanan #1024?</p>
    <button value="tidak">Kembali</button>
    <button value="ya">Ya, batalkan</button>
  </form>
</dialog>

Poin penting

  • details/summary: buka-tutup bawaan, aksesibel.
  • name yang sama: akordeon.
  • dialog + showModal(): modal dengan Esc dan fokus.
  • popover: menu yang ditutup saat klik di luar.
