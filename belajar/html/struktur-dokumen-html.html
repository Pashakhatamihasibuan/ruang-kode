Struktur dokumen HTML

Buka versi interaktif

HTML (HyperText Markup Language) bukan bahasa pemrograman, melainkan bahasa markup: ia memberi label pada isi halaman, misalnya "ini judul", "ini paragraf", "ini gambar".

Setiap dokumen dimulai dengan <!DOCTYPE html> agar browser memakai mode standar. Elemen <html> membungkus semuanya dan berisi dua bagian: <head> untuk informasi tentang halaman (judul tab, set karakter, deskripsi) dan <body> untuk isi yang terlihat.

Ubah teks di editor, lalu lihat pratinjaunya berubah. Coba juga ganti isi <title>: judul itu muncul di tab browser, bukan di halaman.

HTML
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Toko Nusantara</title>
</head>
<body>
  <h1>Selamat datang di Toko Nusantara</h1>
  <p>Kopi, teh, dan camilan pilihan dari seluruh Indonesia.</p>
</body>
</html>

Tantangan

  1. Tambahkan satu paragraf baru berisi kata promo di dalam body.

Poin penting

  • DOCTYPE memberi tahu browser bahwa ini HTML modern.
  • head berisi metadata, body berisi isi yang terlihat.
  • lang="id" membantu pembaca layar dan mesin pencari.
  • meta viewport wajib agar tampilan pas di ponsel.
