Form, label & input

Buka versi interaktif

<form> membungkus kontrol input. Atribut action menentukan alamat tujuan data dan method caranya (GET menaruh data di URL, POST di badan permintaan).

Setiap input wajib punya label. Hubungkan dengan <label for="id-input">. Label membuat area klik lebih besar dan dibacakan pembaca layar. Placeholder bukan pengganti label karena hilang saat pengguna mengetik.

Atribut name menjadi nama data yang dikirim. Pilih type yang tepat (email, tel, number, date, password): di ponsel, keyboard yang muncul ikut menyesuaikan.

HTML
<form action="/daftar" method="post">
  <p>
    <label for="nama">Nama lengkap</label><br>
    <input id="nama" name="nama" type="text" autocomplete="name">
  </p>
  <p>
    <label for="email">Email</label><br>
    <input id="email" name="email" type="email" autocomplete="email">
  </p>
  <p>
    <label><input type="checkbox" name="promo"> Kirimi saya info promo</label>
  </p>
  <fieldset>
    <legend>Metode bayar</legend>
    <label><input type="radio" name="bayar" value="qris" checked> QRIS</label>
    <label><input type="radio" name="bayar" value="va"> Virtual account</label>
  </fieldset>
  <p><label for="kota">Kota</label><br>
    <select id="kota" name="kota"><option>Jakarta</option><option>Bandung</option></select></p>
  <button type="submit">Daftar</button>
</form>

Tantangan

  1. Tambahkan input nomor HP (type="tel") lengkap dengan label yang terhubung.

Poin penting

  • Setiap input butuh label yang terhubung lewat for/id.
  • name adalah kunci data yang dikirim.
  • Pilih type yang sesuai agar keyboard ponsel tepat.
  • fieldset dan legend mengelompokkan pilihan.
