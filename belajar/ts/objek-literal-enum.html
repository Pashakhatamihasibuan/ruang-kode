Objek, literal & enum

Buka versi interaktif

Tipe objek menyebut setiap properti: { nama: string; harga: number; promo?: boolean }. Tanda ? berarti opsional, dan readonly berarti tidak boleh diubah.

Literal type membatasi nilai ke beberapa pilihan: "baru" | "dikirim" | "selesai". Ini sering lebih disukai daripada enum, yang menghasilkan objek di JavaScript. Enum tetap berguna untuk kumpulan konstanta bernama.

TYPESCRIPT
type Status = "baru" | "dikirim" | "selesai";

const pesanan: { id: number; status: Status; catatan?: string } = {
  id: 101,
  status: "dikirim",
};

enum Kurir { JNE = "jne", JNT = "jnt", SiCepat = "sicepat" }

console.log(pesanan.id, pesanan.status, pesanan.catatan ?? "tanpa catatan");
console.log(Kurir.SiCepat, Object.keys(Kurir).length);
// pesanan.status = "hilang";  // error: Type '"hilang"' is not assignable to type 'Status'.
KELUARAN
101 dikirim tanpa catatan
sicepat 3

Poin penting

  • ? untuk properti opsional, readonly untuk tidak bisa diubah.
  • Literal union membatasi nilai yang sah.
  • Enum membuat objek di JavaScript; literal union tidak.
