Fungsi & tipe generik

Buka versi interaktif

Generics adalah parameter tipe. function pertama<T>(arr: T[]): T | undefined bekerja untuk array apa pun dan tetap tahu tipe elemennya. Tanpa generics kamu terpaksa memakai any dan kehilangan informasi tipe.

Constraint <T extends { id: number }> membatasi T agar setidaknya punya properti tertentu. Tipe juga bisa generik, misalnya type Hasil<T> = { ok: true; data: T } | { ok: false; error: string }.

TYPESCRIPT
function pertama<T>(arr: T[]): T | undefined {
  return arr[0];
}

function cariById<T extends { id: number }>(daftar: T[], id: number): T | undefined {
  return daftar.find(x => x.id === id);
}

type Hasil<T> = { ok: true; data: T } | { ok: false; error: string };

function bagi(a: number, b: number): Hasil<number> {
  return b === 0 ? { ok: false, error: "pembagi nol" } : { ok: true, data: a / b };
}

const produk = [{ id: 1, nama: "Kopi" }, { id: 2, nama: "Teh" }];
console.log(pertama(["a", "b"]), pertama([10, 20]));
console.log(cariById(produk, 2)?.nama);
const h = bagi(10, 0);
console.log(h.ok ? h.data : h.error);
KELUARAN
a 10
Teh
pembagi nol

Poin penting

  • Generics = parameter tipe.
  • Tipe elemen tetap diketahui, tanpa any.
  • extends membatasi T.
  • Tipe generik seperti Hasil.
