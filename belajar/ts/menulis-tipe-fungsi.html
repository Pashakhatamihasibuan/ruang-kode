Menulis tipe fungsi

Buka versi interaktif

Tulis tipe setiap parameter; tipe kembalian biasanya bisa ditebak, tapi menuliskannya membuat maksudmu jelas. Parameter opsional memakai ?, parameter bawaan memakai =, dan rest parameter memakai ...nama: T[].

Tipe fungsi juga bisa dijadikan alias: type Diskon = (harga: number) => number, berguna untuk callback.

TYPESCRIPT
type Diskon = (harga: number) => number;

const potong10: Diskon = h => h * 0.9;
const potong20: Diskon = h => h * 0.8;

function bayar(harga: number, diskon?: Diskon, ongkir = 15000): number {
  const setelah = diskon ? diskon(harga) : harga;
  return setelah + ongkir;
}

function jumlahkan(...angka: number[]): number {
  return angka.reduce((a, b) => a + b, 0);
}

console.log(bayar(100000));
console.log(bayar(100000, potong20, 0));
console.log(jumlahkan(85000, 25000, 15000));
KELUARAN

80000
125000

Poin penting

  • Selalu beri tipe parameter.
  • ? opsional, = nilai bawaan, ... rest.
  • Alias tipe fungsi untuk callback.

Cek pemahaman

Tipe untuk "fungsi menerima number, mengembalikan number"?

Jawaban: (n: number) => number

Parameter harus diberi nama di tipe fungsi.

Sebelumnya: any, unknown, never & void
