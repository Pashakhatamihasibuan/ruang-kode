Decorator & alat ekosistem

Buka versi interaktif

Decorator adalah fungsi yang membungkus kelas atau method untuk menambah perilaku, misalnya mencatat log atau mengukur waktu. Framework seperti Angular dan NestJS memakainya secara luas.

Ekosistem sehari-hari: typescript-eslint untuk linting, Prettier atau Biome untuk format, tsx untuk menjalankan, tsup/Vite untuk build, dan Zod untuk validasi data saat berjalan yang sekaligus menghasilkan tipe.

TYPESCRIPT
function catat(asli: any, konteks: ClassMethodDecoratorContext) {
  return function (this: unknown, ...args: unknown[]) {
    console.log(`panggil ${String(konteks.name)}(${args.join(", ")})`);
    return asli.apply(this, args);
  };
}

class Kasir {
  @catat
  bayar(total: number, uang: number) { return uang - total; }
}

console.log("kembalian", new Kasir().bayar(85000, 100000));
KELUARAN
panggil bayar(85000, 100000)
kembalian 15000

Poin penting

  • Decorator membungkus kelas/method.
  • typescript-eslint, Prettier, tsx, tsup, Zod.
  • Zod memvalidasi saat berjalan dan menghasilkan tipe.
