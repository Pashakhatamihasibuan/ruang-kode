Interface & extends

Buka versi interaktif

Interface mendefinisikan bentuk objek. Ia bisa extends interface lain untuk menambah properti, dan bisa berisi method.

TypeScript memakai structural typing: objek cocok dengan interface jika bentuknya cocok, tanpa perlu menyatakan "implements". Ini berbeda dengan Java.

TYPESCRIPT
interface Produk {
  id: number;
  nama: string;
  harga: number;
}

interface ProdukDigital extends Produk {
  urlUnduh: string;
  hitungDiskon(persen: number): number;
}

const ebook: ProdukDigital = {
  id: 9, nama: "E-book Resep Kopi", harga: 49000, urlUnduh: "https://contoh.id/resep.pdf",
  hitungDiskon(p) { return this.harga * (1 - p / 100); },
};

function label(p: Produk): string {        // ProdukDigital juga diterima
  return `#${p.id} ${p.nama}`;
}
console.log(label(ebook), ebook.hitungDiskon(10));
KELUARAN
#9 E-book Resep Kopi 44100

Poin penting

  • interface untuk bentuk objek.
  • extends menambah properti.
  • Structural typing: cocok jika bentuknya cocok.

Cek pemahaman

Bolehkah objek ProdukDigital dikirim ke fungsi yang meminta Produk?

Jawaban: Boleh, karena punya semua properti Produk
