TypeScript · Modul 10 · Konsep & kode

Modul, deklarasi & augmentasi

Buka versi interaktif

TypeScript modern memakai modul ES (import/export). import type mengimpor tipe saja sehingga hilang sepenuhnya dari hasil JavaScript. Namespace adalah cara lama, kini jarang dipakai.

Pustaka JavaScript tanpa tipe dijelaskan dengan file deklarasi .d.ts, yang banyak tersedia di paket @types/.... Kamu juga bisa menulis ambient module sendiri atau menambah properti ke tipe global (augmentation), misalnya menambah window.dataLayer.

TYPESCRIPT
// tipe.ts
export type Produk = { id: number; nama: string };

// layanan.ts
import type { Produk } from "./tipe";          // hilang saat dikompilasi

// global.d.ts — menambah properti ke window
declare global {
  interface Window { dataLayer: unknown[] }
}
export {};

// modul-tanpa-tipe.d.ts
declare module "kalkulator-ongkir" {
  export function hitung(beratKg: number, kota: string): number;
}

Poin penting

  • Pakai modul ES; namespace sudah jarang.
  • import type untuk tipe saja.
  • .d.ts dan @types untuk pustaka JavaScript.
  • declare global untuk augmentasi.
