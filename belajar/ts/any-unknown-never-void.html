any, unknown, never & void

Buka versi interaktif

any mematikan pemeriksaan tipe; hindari karena menghilangkan manfaat TypeScript. unknown adalah versi aman: nilainya bisa apa saja, tapi kamu wajib memeriksa tipenya sebelum memakai.

void untuk fungsi yang tidak mengembalikan nilai. never untuk nilai yang mustahil terjadi, misalnya fungsi yang selalu melempar error, atau cabang yang seharusnya tidak pernah tercapai.

TYPESCRIPT
function cetak(pesan: string): void {
  console.log("LOG:", pesan);
}

function gagal(pesan: string): never {
  throw new Error(pesan);
}

function panjang(x: unknown): number {
  if (typeof x === "string") return x.length;     // aman setelah diperiksa
  if (Array.isArray(x)) return x.length;
  return 0;
}

cetak("mulai");
console.log(panjang("halo"), panjang([1, 2, 3]), panjang(42));
try { gagal("stok habis"); } catch (e) { console.log((e as Error).message); }
KELUARAN
LOG: mulai
4 3 0
stok habis

Kode pemula vs kode rapi

Pakai unknown, bukan any

any mematikan pemeriksaan tipe, sehingga salah ketik baru ketahuan saat program jalan. unknown memaksa kamu memeriksa tipenya dulu, lalu TypeScript membantumu sepenuhnya.

KODE PEMULA
const data: any = JSON.parse('{"harga": 85000}');
console.log(data.hargaa * 2);
KODE RAPI (BEST PRACTICE)
const data: unknown = JSON.parse('{"harga": 85000}');
if (typeof data === "object" && data !== null && "harga" in data && typeof data.harga === "number") {
  console.log(data.harga * 2);
}

Poin penting

  • Hindari any.
  • unknown wajib diperiksa sebelum dipakai.
  • void: tidak mengembalikan nilai.
  • never: tidak mungkin terjadi.
