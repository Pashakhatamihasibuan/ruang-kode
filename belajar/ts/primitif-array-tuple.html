Primitif, array & tuple

Buka versi interaktif

Tipe primitif: string, number, boolean, null, undefined, bigint, symbol. Seringkali kamu tidak perlu menulis tipe karena TypeScript menebaknya (type inference): let stok = 40 sudah bertipe number.

Array ditulis string[] atau Array<string>. Tuple adalah array dengan panjang dan tipe per posisi tetap: [string, number], cocok untuk pasangan seperti nama dan harga.

TYPESCRIPT
let stok = 40;                      // ditebak: number
const nama: string = "Kopi Gayo";
const aktif: boolean = true;
const kategori: string[] = ["Minuman", "Camilan"];
const item: [string, number] = ["Teh Melati", 25000];

const [n, h] = item;
console.log(nama, stok, aktif);
console.log(kategori.length, n, h);
// stok = "banyak";   // error: Type 'string' is not assignable to type 'number'.
KELUARAN
Kopi Gayo 40 true
2 Teh Melati 25000

Kode pemula vs kode rapi

Pemisah angka di TypeScript dan JavaScript

Sama seperti Java dan Python, JavaScript modern (ES2021) dan TypeScript menerima 1_000_000. Nilainya tetap angka biasa.

KODE PEMULA
const harga: number = 1000000;
const ongkir: number = 25000;
console.log(harga + ongkir);
KODE RAPI (BEST PRACTICE)
const harga = 1_000_000;
const ongkir = 25_000;
console.log(harga + ongkir);
KELUARAN KEDUANYA
1025000

Poin penting

  • Biarkan TypeScript menebak tipe jika jelas.
  • Array: T[] atau Array.
  • Tuple: panjang dan tipe per posisi tetap.
