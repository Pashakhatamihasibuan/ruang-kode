keyof, mapped & conditional types

Buka versi interaktif

keyof T menghasilkan union nama properti T. Gabungkan dengan T[K] untuk fungsi seperti ambil(obj, "nama") yang tahu tipe hasilnya.

Mapped type mengubah setiap properti: { [K in keyof T]: ... }. Begitulah Partial dan Readonly dibuat. Conditional type T extends U ? X : Y memilih tipe berdasarkan syarat, dan infer menangkap bagian tipe.

TYPESCRIPT
function ambil<T, K extends keyof T>(obj: T, kunci: K): T[K] {
  return obj[kunci];
}

type Opsional<T> = { [K in keyof T]?: T[K] };
type JadiString<T> = { [K in keyof T]: string };
type IsiArray<T> = T extends (infer E)[] ? E : never;

const p = { nama: "Kopi Gayo", harga: 85000 };
const h = ambil(p, "harga");                 // number
const form: JadiString<typeof p> = { nama: "Kopi Gayo", harga: "85000" };
const draf: Opsional<typeof p> = { nama: "Draf" };
type X = IsiArray<string[]>;                 // string
const x: X = "ok";
console.log(h + 1, form.harga + "!", draf.harga ?? "-", x);
KELUARAN
85001 85000! - ok

Poin penting

  • keyof T = union nama properti.
  • T[K] = tipe properti K.
  • Mapped type: [K in keyof T].
  • Conditional + infer untuk memilih dan menangkap tipe.

Cek pemahaman

keyof { a: 1; b: 2 } adalah?

Jawaban: "a" | "b"
