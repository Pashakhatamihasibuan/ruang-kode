as, as const, ! & satisfies

Buka versi interaktif

as memberi tahu kompiler "percayalah, tipenya ini". Ia tidak memeriksa apa pun saat berjalan, jadi pakai seperlunya. ! (non-null assertion) menyatakan nilai pasti tidak null; salah pakai berarti error saat program jalan.

as const membuat nilai literal dan readonly, berguna untuk daftar konstanta. satisfies memeriksa bahwa nilai cocok dengan tipe tertentu tanpa kehilangan tipe yang lebih spesifik.

TYPESCRIPT
const KATEGORI = ["Minuman", "Camilan", "Bumbu"] as const;
type Kategori = typeof KATEGORI[number];          // "Minuman" | "Camilan" | "Bumbu"

const warna = {
  Minuman: "#2E5E8C",
  Camilan: "#B4532A",
  Bumbu: "#2F7A52",
} satisfies Record<Kategori, string>;

const k: Kategori = "Camilan";
console.log(k, warna[k], KATEGORI.length);
const data = JSON.parse('{"nama":"Kopi"}') as { nama: string };
console.log(data.nama.toUpperCase());
KELUARAN
Camilan #B4532A 3
KOPI

Poin penting

  • as tidak memeriksa saat berjalan.
  • ! pada nilai yang ternyata null menyebabkan crash.
  • as const: literal + readonly.
  • satisfies: cek tipe tanpa melebarkan.
