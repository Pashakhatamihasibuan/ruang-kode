TypeScript · Modul 8 · Konsep & kode

Exclude, Extract, ReturnType & lainnya

Buka versi interaktif

Untuk union: Exclude<U, X> membuang anggota, Extract<U, X> mengambil anggota yang cocok, NonNullable<T> membuang null dan undefined.

Untuk fungsi dan kelas: ReturnType, Parameters, InstanceType, dan Awaited (isi dari Promise). Ini berguna saat memakai fungsi pustaka yang tipenya tidak diekspor.

TYPESCRIPT
type Status = "baru" | "dikirim" | "selesai" | "batal";
type Aktif = Exclude<Status, "selesai" | "batal">;          // "baru" | "dikirim"
type Final = Extract<Status, "selesai" | "batal" | "x">;   // "selesai" | "batal"

async function ambilPesanan(id: number) {
  return { id, status: "dikirim" as Status, total: 135000 };
}
type Pesanan = Awaited<ReturnType<typeof ambilPesanan>>;
type Arg = Parameters<typeof ambilPesanan>;                 // [id: number]

const a: Aktif = "dikirim";
const f: Final = "batal";
const args: Arg = [101];
ambilPesanan(...args).then((p: Pesanan) => console.log(a, f, p.total));
KELUARAN
dikirim batal 135000

Poin penting

  • Exclude/Extract untuk anggota union.
  • NonNullable membuang null/undefined.
  • ReturnType, Parameters, InstanceType, Awaited untuk fungsi dan kelas.

Cek pemahaman

Tipe isi dari Promise<string>?

Jawaban: Awaited<Promise<string>> = string

Awaited membuka Promise.

Sebelumnya: Partial, Pick, Omit, Readonly & Record
