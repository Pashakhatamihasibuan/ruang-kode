Kelas abstrak & polimorfisme

Buka versi interaktif

Kelas abstrak tidak bisa dibuat objeknya langsung; ia menjadi kerangka bersama dengan method abstract yang wajib diisi kelas turunan.

Polimorfisme: kode yang bekerja dengan tipe induk otomatis memanggil versi method milik objek sebenarnya. Kata kunci override menegaskan bahwa method menimpa milik induk; aktifkan opsi noImplicitOverride agar wajib ditulis.

TYPESCRIPT
abstract class Pengiriman {
  constructor(protected beratKg: number) {}
  abstract tarifPerKg(): number;
  biaya(): number { return Math.max(1, Math.ceil(this.beratKg)) * this.tarifPerKg(); }
}

class Reguler extends Pengiriman { tarifPerKg() { return 10000; } }
class Kilat extends Pengiriman {
  tarifPerKg() { return 18000; }
  override biaya(): number { return super.biaya() + 5000; }   // tambah biaya asuransi
}

const kiriman: Pengiriman[] = [new Reguler(1.2), new Kilat(1.2), new Reguler(0.3)];
kiriman.forEach(k => console.log(k.constructor.name, k.biaya()));
KELUARAN
Reguler 20000
Kilat 41000
Reguler 10000

Poin penting

  • abstract class: kerangka, tidak bisa di-new.
  • abstract method wajib diimplementasikan.
  • override menimpa method induk.
  • Polimorfisme lewat tipe induk.
