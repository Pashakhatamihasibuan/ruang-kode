Type alias, union & intersection

Buka versi interaktif

type memberi nama untuk tipe apa saja: objek, union, tuple, atau fungsi. Union A | B berarti "salah satu", intersection A & B berarti "keduanya sekaligus".

Kapan interface dan kapan type? Keduanya hampir setara untuk objek. Pakai interface untuk bentuk objek yang bisa diperluas, dan type untuk union, tuple, atau tipe turunan.

TYPESCRIPT
type Id = number | string;
type Bertanggal = { dibuat: string };
type Pelanggan = { id: Id; nama: string } & Bertanggal;

const a: Pelanggan = { id: 1, nama: "Andi", dibuat: "2023-01-15" };
const b: Pelanggan = { id: "PLG-008", nama: "Hadi", dibuat: "2024-09-03" };

function tampil(id: Id): string {
  return typeof id === "number" ? id.toString().padStart(4, "0") : id;
}
console.log(tampil(a.id), tampil(b.id), b.dibuat);

Kode pemula vs kode rapi

Optional chaining dan ?? untuk data bersarang

?. berhenti dengan undefined begitu ada bagian yang kosong, dan ?? memberi nilai cadangan. Tidak perlu rangkaian &&.

KODE PEMULA
type Pelanggan = { nama: string; alamat?: { kota?: string } };
const p: Pelanggan = { nama: "Sari" };
let kota: string;
if (p && p.alamat && p.alamat.kota) {
  kota = p.alamat.kota;
} else {
  kota = "-";
}
console.log(kota);
KODE RAPI (BEST PRACTICE)
type Pelanggan = { nama: string; alamat?: { kota?: string } };
const p: Pelanggan = { nama: "Sari" };
console.log(p.alamat?.kota ?? "-");
