Template literal & tipe rekursif

Buka versi interaktif

Template literal type menyusun string pada level tipe: `on${Capitalize<E>}` mengubah "klik" menjadi "onKlik". Berguna untuk nama event, rute, atau kunci CSS.

Tipe rekursif merujuk dirinya sendiri, misalnya struktur pohon kategori atau JSON.

TYPESCRIPT
type Peristiwa = "klik" | "ubah";
type Handler = `on${Capitalize<Peristiwa>}`;      // "onKlik" | "onUbah"

type Kategori = { nama: string; anak?: Kategori[] };
const pohon: Kategori = { nama: "Minuman", anak: [{ nama: "Kopi", anak: [{ nama: "Arabika" }] }, { nama: "Teh" }] };

function hitung(k: Kategori): number {
  return 1 + (k.anak ?? []).reduce((n, a) => n + hitung(a), 0);
}

const h: Handler = "onKlik";
console.log(h, hitung(pohon));
KELUARAN
onKlik 4

Poin penting

  • Template literal type menyusun string tipe.
  • Capitalize, Uppercase, Lowercase adalah helper bawaan.
  • Tipe rekursif untuk pohon dan JSON.
