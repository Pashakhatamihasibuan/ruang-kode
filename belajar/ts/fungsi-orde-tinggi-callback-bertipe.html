Fungsi orde tinggi & callback bertipe

Buka versi interaktif

Fungsi di TypeScript bisa diterima dan dikembalikan seperti nilai lain. Fungsi yang menerima atau mengembalikan fungsi disebut fungsi orde tinggi. Tipe fungsi ditulis seperti (harga: number) => number.

Memberi nama pada tipe fungsi dengan type membuat kode lebih mudah dibaca, misalnya type Aturan = (harga: number) => number. Fungsi yang mengembalikan fungsi lain sering dipakai untuk membuat aturan yang bisa dikonfigurasi, seperti diskon dengan persentase tertentu.

Saat callback dikirim ke map atau filter, TypeScript menebak tipe parameternya dari array, jadi kamu jarang perlu menuliskannya.

TYPESCRIPT
type Aturan = (harga: number) => number;

const diskon = (persen: number): Aturan => (harga) => harga * (1 - persen / 100);
const ongkir = (biaya: number): Aturan => (harga) => harga + biaya;

function terapkan(harga: number, ...aturan: Aturan[]): number {
  return aturan.reduce((h, f) => f(h), harga);
}

console.log(terapkan(100_000, diskon(10), ongkir(15_000)));
console.log(terapkan(100_000, ongkir(15_000), diskon(10)));
const hargaAkhir = [50_000, 80_000].map(diskon(20));
console.log(hargaAkhir);

Poin penting

  • Tipe fungsi: (param: Tipe) => Hasil.
  • Beri nama tipe fungsi dengan type.
  • Fungsi bisa mengembalikan fungsi yang sudah dikonfigurasi.
  • Tipe parameter callback ditebak dari konteks.
