Kenapa TypeScript?

Buka versi interaktif

TypeScript adalah JavaScript ditambah tipe. Kamu menulis anotasi seperti harga: number, lalu kompiler memeriksa kesalahan sebelum program dijalankan: salah ketik nama properti, lupa menangani null, atau mengirim string ke fungsi yang butuh angka.

Tipe dihapus saat kompilasi, sehingga hasilnya JavaScript biasa yang berjalan di browser atau Node. Semua JavaScript valid juga TypeScript valid, jadi proyek bisa dipindahkan bertahap.

Bonus terbesar sehari-hari: editor tahu bentuk setiap data, sehingga autocomplete dan refactor menjadi akurat.

TYPESCRIPT
function totalHarga(harga: number, jumlah: number): number {
  return harga * jumlah;
}

const produk = { nama: "Kopi Gayo", harga: 85000 };
console.log(totalHarga(produk.harga, 2));
// totalHarga("85000", 2);   // error: Argument of type 'string' is not assignable to parameter of type 'number'.
KELUARAN
170000

Poin penting

  • TypeScript = JavaScript + tipe.
  • Kesalahan tertangkap sebelum program jalan.
  • Tipe dihapus saat kompilasi.
  • Bisa diadopsi bertahap.
