Pustaka keranjang belanja bertipe

Buka versi interaktif

Tulis modul keranjang belanja yang aman tipe: produk, item, diskon, dan ringkasan pembayaran. Jalankan dengan Node dan uji dengan Vitest.

Teknologi: TypeScript + Node

Fitur yang dibuat

  • tsconfig dengan "strict": true dan tanpa any
  • Tipe Produk, Item, dan Diskon berbentuk discriminated union (persen, potongan tetap, gratis ongkir)
  • Kelas Keranjang dengan field privat dan method tambah, kurangi, hapus
  • Fungsi ringkasan mengembalikan Hasil<T> (ok/error) alih-alih melempar error
  • Validasi input dari JSON dengan unknown + type guard (atau Zod)
  • Pemeriksaan exhaustiveness dengan never
  • Minimal 5 tes Vitest

Langkah kerja

  1. Definisikan semua tipe dulu.
  2. Tulis kelas dan fungsi; biarkan kompiler menuntunmu.
  3. Tambahkan validasi untuk data dari luar.
  4. Tulis tes dan jalankan npx tsc --noEmit.
keranjang.ts
type Produk = { id: number; nama: string; harga: number };
type Diskon = { jenis: "persen"; nilai: number } | { jenis: "potong"; nilai: number } | { jenis: "ongkir" };
type Hasil<T> = { ok: true; data: T } | { ok: false; error: string };

export class Keranjang {
  #isi = new Map<number, { produk: Produk; jumlah: number }>();
  tambah(p: Produk, n = 1): void {
    const lama = this.#isi.get(p.id);
    this.#isi.set(p.id, { produk: p, jumlah: (lama?.jumlah ?? 0) + n });
  }
  ringkasan(d?: Diskon, ongkir = 15000): Hasil<{ subtotal: number; potongan: number; total: number }> {
    if (this.#isi.size === 0) return { ok: false, error: "Keranjang kosong" };
    const subtotal = [...this.#isi.values()].reduce((t, i) => t + i.produk.harga * i.jumlah, 0);
    let potongan = 0;
    if (d) {
      switch (d.jenis) {
        case "persen": potongan = Math.round(subtotal * d.nilai / 100); break;
        case "potong": potongan = Math.min(d.nilai, subtotal); break;
        case "ongkir": potongan = ongkir; break;
        default: { const cek: never = d; return cek; }
      }
    }
    return { ok: true, data: { subtotal, potongan, total: subtotal + ongkir - potongan } };
  }
}

const k = new Keranjang();
k.tambah({ id: 1, nama: "Kopi Gayo", harga: 85000 }, 2);
console.log(k.ringkasan({ jenis: "persen", nilai: 10 }));
