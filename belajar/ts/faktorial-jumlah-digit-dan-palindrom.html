Faktorial, jumlah digit, dan palindrom

Buka versi interaktif

Tiga soal ini melatih kapan memakai for dan kapan while. Faktorial 5! = 1 × 2 × 3 × 4 × 5: banyak perkaliannya pasti, jadi for.

Jumlah digit 90417 = 9 + 0 + 4 + 1 + 7 = 21. Kita tidak tahu angkanya punya berapa digit, jadi pakai while: ambil digit terakhir dengan % 10, lalu buang dengan pembagian bulat Math.floor(x / 10). Berhenti saat angkanya habis (0).

Palindrom adalah kata yang sama jika dibaca dari depan dan belakang, seperti "katak". Pakai dua penunjuk: satu dari kiri, satu dari kanan, bergerak ke tengah selama kiri < kanan. Begitu ada huruf yang berbeda, langsung break.

TYPESCRIPT
function faktorial(n: number): number {
  let hasil = 1;
  for (let i = 2; i <= n; i++) hasil *= i;   // FOR: n kali
  return hasil;
}

function jumlahDigit(angka: number): number {
  let sisa = angka, jumlah = 0;
  while (sisa > 0) {                          // WHILE: digit belum diketahui
    jumlah += sisa % 10;
    sisa = Math.floor(sisa / 10);
  }
  return jumlah;
}

function isPalindrom(kata: string): boolean {
  let kiri = 0, kanan = kata.length - 1;
  while (kiri < kanan) {                      // WHILE: dua penunjuk
    if (kata[kiri] !== kata[kanan]) return false;
    kiri++;
    kanan--;
  }
  return true;
}

Soal latihan

  1. Balik angka 12345 menjadi 54321 tanpa mengubahnya menjadi teks.

    Petunjuk

    Ambil digit terakhir dengan % 10, tempel ke hasil dengan hasil * 10 + digit, buang digit terakhir dengan pembagian bulat. Ulangi selama angka > 0.

    Lihat jawaban
    TYPESCRIPT
    let angka: number = 12345, balik: number = 0;
while (angka > 0) {
  balik = balik * 10 + (angka % 10);
  angka = Math.floor(angka / 10);
}
console.log("Dibalik:", balik);

  2. Hitung 2 pangkat 10 dengan loop, tanpa operator pangkat.

    Petunjuk

    Perkalian diulang tepat 10 kali, jadi for.

    Lihat jawaban
    TYPESCRIPT
    let hasil: number = 1;
for (let i = 0; i < 10; i++) {
  hasil *= 2;
}
console.log("2^10 =", hasil);

Poin penting

  • % 10 mengambil digit terakhir, bagi 10 (bulat) membuangnya.
  • Banyak digit tidak diketahui → while.
  • Dua penunjuk bergerak ke tengah untuk memeriksa palindrom.
