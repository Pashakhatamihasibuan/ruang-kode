Type guard & discriminated union

Buka versi interaktif

Narrowing: setelah pemeriksaan typeof, instanceof, in, atau perbandingan, TypeScript tahu tipe yang lebih sempit di dalam cabang itu.

Discriminated union adalah pola paling berguna: setiap varian punya properti penanda yang sama (misalnya jenis), dan switch pada penanda itu membuat setiap cabang aman. Tambahkan pemeriksaan never agar TypeScript protes jika ada varian baru yang lupa ditangani.

Type predicate x is T membuat fungsi pemeriksa milikmu sendiri.

TYPESCRIPT
type Bayar =
  | { jenis: "qris"; merchant: string }
  | { jenis: "va"; bank: string; nomor: string }
  | { jenis: "cod" };

function keterangan(b: Bayar): string {
  switch (b.jenis) {
    case "qris": return "QRIS " + b.merchant;
    case "va": return `VA ${b.bank} ${b.nomor}`;
    case "cod": return "Bayar di tempat";
    default: { const cek: never = b; return cek; }
  }
}

const adalahVA = (b: Bayar): b is Extract<Bayar, { jenis: "va" }> => b.jenis === "va";

const daftar: Bayar[] = [{ jenis: "qris", merchant: "Toko Nusantara" }, { jenis: "va", bank: "BCA", nomor: "8808" }, { jenis: "cod" }];
daftar.forEach(b => console.log(keterangan(b)));
console.log(daftar.filter(adalahVA).map(b => b.bank));
KELUARAN
QRIS Toko Nusantara
VA BCA 8808
Bayar di tempat
[ 'BCA' ]

Poin penting

  • typeof, instanceof, in, dan === mempersempit tipe.
  • Discriminated union: properti penanda + switch.
  • Cek never memastikan semua varian ditangani.
  • Type predicate: fungsi pemeriksa sendiri.
