TypeScript · Modul 1 · Konsep & kode

Memasang & menjalankan

Buka versi interaktif

Pasang TypeScript per proyek: npm install -D typescript, lalu buat tsconfig.json dengan npx tsc --init. Opsi terpenting: "strict": true (aktifkan semua pemeriksaan ketat), target (versi JavaScript keluaran), dan module.

npx tsc memeriksa tipe dan menghasilkan file .js. Untuk menjalankan langsung, pakai tsx atau ts-node, atau Node 22 ke atas yang bisa membuang anotasi tipe sendiri. Untuk mencoba cepat tanpa instalasi, ada TypeScript Playground di situs resmi.

TERMINAL
$ npm install -D typescript
$ npx tsc --init
# tsconfig.json (potongan)
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "strict": true,
    "outDir": "dist"
  }
}
$ npx tsc            # periksa tipe + hasilkan dist/*.js
$ npx tsx main.ts    # jalankan langsung
$ node main.ts       # Node 23+ (Node 22 dengan --experimental-strip-types)

Poin penting

  • typescript dipasang sebagai devDependency.
  • Selalu nyalakan "strict": true.
  • tsc memeriksa dan mengompilasi; tsx/ts-node menjalankan langsung.

Cek pemahaman

Opsi tsconfig yang menyalakan semua pemeriksaan ketat?

Jawaban: "strict": true

Sangat disarankan untuk proyek baru.
