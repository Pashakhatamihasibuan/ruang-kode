Kelas & modifier akses

Buka versi interaktif

Kelas TypeScript menambahkan modifier akses: public (bawaan), private (hanya di kelas itu), protected (kelas itu dan turunannya), serta readonly.

Parameter properties menyingkat konstruktor: menulis constructor(private saldo: number) otomatis membuat dan mengisi properti saldo. Untuk privasi sungguhan saat berjalan, JavaScript punya #field.

TYPESCRIPT
class Rekening {
  #riwayat: string[] = [];
  constructor(public readonly pemilik: string, private saldo: number) {}

  setor(n: number): void {
    this.saldo += n;
    this.#riwayat.push("setor " + n);
  }
  tarik(n: number): boolean {
    if (n > this.saldo) return false;
    this.saldo -= n;
    this.#riwayat.push("tarik " + n);
    return true;
  }
  get info(): string { return `${this.pemilik}: ${this.saldo} (${this.#riwayat.length} transaksi)`; }
}

const r = new Rekening("Andi", 500000);
r.setor(100000);
console.log(r.tarik(900000), r.tarik(200000));
console.log(r.info);
// r.saldo = 0;   // error: Property 'saldo' is private and only accessible within class 'Rekening'.
KELUARAN
false true
Andi: 400000 (2 transaksi)

Poin penting

  • public, private, protected, readonly.
  • Parameter properties meringkas konstruktor.
  • private hanya saat kompilasi; #field privat saat berjalan.
