Partial, Pick, Omit, Readonly & Record

Buka versi interaktif

Utility types membuat tipe baru dari tipe lama. Partial<T> membuat semua properti opsional (cocok untuk data update), Pick<T, K> mengambil sebagian properti, Omit<T, K> membuang sebagian, Readonly<T> membuat tidak bisa diubah, dan Record<K, V> membuat objek berkunci K bernilai V.

TYPESCRIPT
interface Produk { id: number; nama: string; harga: number; stok: number }

type UbahProduk = Partial<Omit<Produk, "id">>;
type Ringkas = Pick<Produk, "nama" | "harga">;
type StokPerKota = Record<"Jakarta" | "Bandung", number>;

function ubah(p: Produk, perubahan: UbahProduk): Produk {
  return { ...p, ...perubahan };
}

const kopi: Readonly<Produk> = { id: 1, nama: "Kopi Gayo", harga: 85000, stok: 40 };
const baru = ubah(kopi, { harga: 80000 });
const r: Ringkas = { nama: baru.nama, harga: baru.harga };
const stok: StokPerKota = { Jakarta: 25, Bandung: 15 };
console.log(r, stok.Bandung);
// kopi.harga = 1;   // error: Cannot assign to 'harga' because it is a read-only property.
KELUARAN
{ nama: 'Kopi Gayo', harga: 80000 } 15

Poin penting

  • Partial: semua opsional.
  • Pick/Omit: ambil/buang properti.
  • Readonly: tidak bisa diubah.
  • Record: peta kunci ke nilai.
