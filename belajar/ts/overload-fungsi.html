Overload fungsi

Buka versi interaktif

Overload menulis beberapa tanda tangan untuk satu fungsi, sehingga tipe kembalian bisa berbeda tergantung argumennya. Tulis tanda tangan overload dulu, lalu satu implementasi yang menangani semuanya.

Sering kali union type atau generics sudah cukup; pakai overload jika hubungan input-output tidak bisa diungkapkan dengan cara lain.

TYPESCRIPT
function format(nilai: number): string;
function format(nilai: Date): string;
function format(nilai: number | Date): string {
  if (typeof nilai === "number") return "Rp" + nilai.toLocaleString("id-ID");
  return nilai.toISOString().slice(0, 10);
}

console.log(format(85000));
console.log(format(new Date("2024-10-01T00:00:00Z")));
KELUARAN
Rp85.000
2024-10-01

Poin penting

  • Beberapa tanda tangan, satu implementasi.
  • Implementasi tidak terlihat dari luar.
  • Utamakan union atau generics jika cukup.
