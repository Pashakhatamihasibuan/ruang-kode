Overload fungsi

Buka versi interaktif

Overload menulis beberapa tanda tangan untuk satu fungsi, sehingga tipe kembalian bisa berbeda tergantung argumennya. Tulis tanda tangan overload dulu, lalu satu implementasi yang menangani semuanya.

Sering kali union type atau generics sudah cukup; pakai overload jika hubungan input-output tidak bisa diungkapkan dengan cara lain.

TYPESCRIPT
function format(nilai: number): string;
function format(nilai: Date): string;
function format(nilai: number | Date): string {
  if (typeof nilai === "number") return "Rp" + nilai.toLocaleString("id-ID");
  return nilai.toISOString().slice(0, 10);
}

console.log(format(85000));
console.log(format(new Date("2024-10-01T00:00:00Z")));
KELUARAN
Rp85.000
2024-10-01

Soal latihan

  1. Buat fungsi format dengan overload: menerima number mengembalikan string Rupiah, menerima Date mengembalikan tanggal.

    Petunjuk

    Tulis beberapa tanda tangan, lalu satu implementasi.

    Lihat jawaban
    TYPESCRIPT
    function format(x: number): string;
function format(x: Date): string;
function format(x: number | Date): string {
  return typeof x === "number" ? "Rp" + x.toLocaleString("id-ID") : x.toISOString().slice(0, 10);
}
console.log(format(18000));
console.log(format(new Date("2026-01-15T00:00:00Z")));
    KELUARAN
    Rp18.000
2026-01-15

  2. Kapan union type lebih baik daripada overload?

    Petunjuk

    Jika tipe kembalian tidak bergantung pada tipe masukan.

    Lihat jawaban
    CONTOH
    Jika semua masukan menghasilkan tipe keluaran yang sama, cukup union:
  function panjang(x: string | unknown[]): number
Overload hanya perlu jika tipe keluaran berubah sesuai tipe masukan.

Poin penting

  • Beberapa tanda tangan, satu implementasi.
  • Implementasi tidak terlihat dari luar.
  • Utamakan union atau generics jika cukup.
