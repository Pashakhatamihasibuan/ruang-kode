Kompleksitas waktu dan ruang

Buka versi interaktif

Kompleksitas waktu menghitung langkah, kompleksitas ruang menghitung memori tambahan. Sering ada pertukaran (trade-off): memakai memori lebih untuk menghemat waktu, misalnya menyimpan hasil yang sudah dihitung.

Contoh klasik: mencari apakah list berisi angka ganda. Cara polos membandingkan semua pasangan, O(n²) waktu dan O(1) ruang. Cara dengan set mencatat angka yang sudah dilihat, O(n) waktu tetapi O(n) ruang.

Dalam wawancara, sebutkan keduanya: "Solusi ini O(n) waktu dan O(n) ruang." Di produksi, pilih berdasarkan batasan: perangkat murah dengan RAM kecil mungkin lebih butuh hemat memori, server dengan jutaan request butuh hemat waktu.

PYTHON
def ada_ganda_polos(data):
    for i in range(len(data)):
        for j in range(i + 1, len(data)):
            if data[i] == data[j]:
                return True
    return False

def ada_ganda_set(data):
    dilihat = set()
    for x in data:
        if x in dilihat:
            return True
        dilihat.add(x)
    return False

nilai = [70, 85, 90, 85, 60]
print(ada_ganda_polos(nilai), ada_ganda_set(nilai))
KELUARAN
True True

Soal latihan

  1. Cetak angka pertama yang muncul dua kali di [4, 7, 2, 7, 4] dengan cara O(n).

    Petunjuk

    Pakai set untuk mencatat yang sudah dilihat.

    Lihat jawaban
    PYTHON
    data = [4, 7, 2, 7, 4]
dilihat = set()
for x in data:
    if x in dilihat:
        print(x)
        break
    dilihat.add(x)
    KELUARAN
    7

Poin penting

  • Waktu = jumlah langkah, ruang = memori tambahan.
  • Set atau dict sering menukar memori dengan kecepatan.
  • Selalu sebutkan kompleksitas waktu dan ruang.

Cek pemahaman

Kompleksitas ruang <code>ada_ganda_set</code>?

Jawaban: O(n)

Set bisa berisi hingga n elemen.

Kerjakan latihannya di aplikasi

Sebelumnya: Notasi Big-O: O(1), O(n), O(n²), O(log n)

Berikutnya: Array dan list dinamis
