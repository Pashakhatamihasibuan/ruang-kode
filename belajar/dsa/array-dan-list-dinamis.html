Array dan list dinamis

Buka versi interaktif

Array menyimpan elemen berurutan di memori yang bersebelahan, jadi akses berdasarkan indeks itu O(1). List Python adalah array dinamis: ukurannya otomatis membesar saat penuh dengan menyalin isinya ke tempat yang lebih besar.

Biaya operasi: append di akhir rata-rata O(1); insert(0, x) atau pop(0) di awal O(n) karena semua elemen harus digeser; mencari nilai dengan in O(n).

Matriks (array 2 dimensi) adalah list berisi list. Hati-hati membuat matriks dengan [[0]*3]*3: ketiga baris menunjuk list yang sama. Pakai list comprehension [[0]*3 for _ in range(3)].

PYTHON
nilai = [80, 75, 92]
nilai.append(88)        # O(1)
nilai.insert(0, 60)     # O(n): semua bergeser
print(nilai, nilai[2])

salah = [[0] * 3] * 3
salah[0][0] = 9
print(salah)

benar = [[0] * 3 for _ in range(3)]
benar[0][0] = 9
print(benar)
KELUARAN
[60, 80, 75, 92, 88] 75
[[9, 0, 0], [9, 0, 0], [9, 0, 0]]
[[9, 0, 0], [0, 0, 0], [0, 0, 0]]

Soal latihan

  1. Putar list [1, 2, 3, 4, 5] ke kanan 2 langkah sehingga menjadi [4, 5, 1, 2, 3].

    Petunjuk

    Pakai slicing: k elemen terakhir di depan.

    Lihat jawaban
    PYTHON
    data = [1, 2, 3, 4, 5]
k = 2
print(data[-k:] + data[:-k])
    KELUARAN
    [4, 5, 1, 2, 3]

Poin penting

  • Akses indeks O(1), sisip atau hapus di awal O(n).
  • append rata-rata O(1).
  • Buat matriks dengan list comprehension.

Cek pemahaman

Operasi list mana yang O(n)?

Jawaban: pop(0)

Semua elemen setelahnya digeser.
