Dynamic programming: memoization dan tabulation

Buka versi interaktif

Dynamic programming (DP) dipakai jika masalah punya submasalah yang tumpang tindih dan struktur optimal (jawaban terbaik dibangun dari jawaban terbaik submasalah). Kuncinya: setiap submasalah dihitung sekali saja.

Dua gaya: memoization (top-down, rekursi + cache, misalnya functools.lru_cache) dan tabulation (bottom-up, isi tabel dari kasus terkecil). Tabulation menghindari batas rekursi dan sering bisa dihemat memorinya.

Langkah menyusun DP: (1) definisikan dp[i] dengan kalimat jelas; (2) tulis hubungan antar keadaan; (3) tentukan kasus dasar; (4) tentukan urutan pengisian. Contoh: banyak cara naik n anak tangga jika tiap langkah 1 atau 2 anak tangga.

PYTHON
from functools import lru_cache

@lru_cache(maxsize=None)
def cara_memo(n):
    if n <= 1:
        return 1
    return cara_memo(n - 1) + cara_memo(n - 2)

def cara_tabel(n):
    dp = [1] * (n + 1)
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp

print(cara_memo(10))
print(cara_tabel(10))

# kembalian koin minimum (Rupiah)
def koin_min(koin, total):
    dp = [0] + [float('inf')] * total
    for x in range(1, total + 1):
        for k in koin:
            if k <= x:
                dp[x] = min(dp[x], dp[x - k] + 1)
    return dp[total]

print('Koin untuk Rp1.300:', koin_min([100, 200, 500, 1000], 1300))

Soal latihan

  1. Hitung banyak jalur dari pojok kiri atas ke kanan bawah grid 4 × 5 jika hanya boleh bergerak ke kanan atau ke bawah.

    Petunjuk

    dp[r][c] = dp[r-1][c] + dp[r][c-1], baris dan kolom pertama bernilai 1.

    Lihat jawaban
    PYTHON
    R, K = 4, 5
dp = [[1] * K for _ in range(R)]
for r in range(1, R):
    for c in range(1, K):
        dp[r][c] = dp[r - 1][c] + dp[r][c - 1]
print(dp[R - 1][K - 1])
    KELUARAN
    35

Poin penting

  • DP = submasalah tumpang tindih + struktur optimal.
  • Memoization (top-down) atau tabulation (bottom-up).
  • Definisikan dp[i] dengan kalimat dulu.
