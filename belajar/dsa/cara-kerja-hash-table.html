Cara kerja hash table

Buka versi interaktif

Hash table menyimpan pasangan kunci dan nilai. Fungsi hash mengubah kunci menjadi angka, lalu angka itu dipetakan ke indeks array (ember atau bucket). Karena langsung ke indeks, cari, tambah, dan hapus rata-rata O(1).

Dua kunci bisa jatuh ke ember yang sama: collision. Solusinya chaining (setiap ember berisi list kecil) atau open addressing (cari ember kosong berikutnya). Jika tabel terlalu penuh (load factor tinggi), tabel diperbesar dan semua kunci di-hash ulang.

Di Python, dict dan set adalah hash table. Kuncinya harus hashable (tidak bisa diubah): string, angka, tuple boleh; list tidak boleh.

PYTHON
class TabelHash:
    def __init__(self, ukuran=5):
        self.ember = [[] for _ in range(ukuran)]
    def _idx(self, kunci):
        return sum(ord(c) for c in kunci) % len(self.ember)
    def simpan(self, kunci, nilai):
        e = self.ember[self._idx(kunci)]
        for pasangan in e:
            if pasangan[0] == kunci:
                pasangan[1] = nilai
                return
        e.append([kunci, nilai])
    def ambil(self, kunci):
        for k, v in self.ember[self._idx(kunci)]:
            if k == kunci:
                return v

t = TabelHash()
t.simpan('apel', 12000)
t.simpan('pela', 9000)   # huruf sama, hash sama: collision
print(t.ambil('apel'), t.ambil('pela'))
print(t.ember)
KELUARAN
12000 9000
[[], [], [], [['apel', 12000], ['pela', 9000]], []]

Poin penting

  • Hash mengubah kunci menjadi indeks ember.
  • Collision diatasi dengan chaining atau open addressing.
  • dict dan set Python adalah hash table.
