Pola dict dan set untuk soal nyata

Buka versi interaktif

Banyak soal menjadi O(n) dengan dict: two sum (simpan angka yang sudah dilihat beserta indeksnya), anagram (bandingkan hitungan huruf), dan pengelompokan (kunci = ciri, nilai = list).

collections.Counter menghitung frekuensi dalam satu baris, defaultdict(list) membuat list kosong otomatis. Operasi set seperti irisan (&), gabungan (|), dan selisih (-) juga cepat.

Contoh: mencari pelanggan yang membeli di dua bulan berturut-turut cukup januari & februari.

PYTHON
from collections import Counter, defaultdict

def two_sum(data, target):
    dilihat = {}
    for i, x in enumerate(data):
        if target - x in dilihat:
            return dilihat[target - x], i
        dilihat[x] = i

print(two_sum([2, 7, 11, 15], 9))
print(Counter('kasur') == Counter('rusak'))

kelompok = defaultdict(list)
for kata in ['makan', 'nakam', 'tidur', 'durit', 'minum']:
    kelompok[''.join(sorted(kata))].append(kata)
print(list(kelompok.values()))

jan = {'Ani', 'Budi', 'Cici'}
feb = {'Budi', 'Cici', 'Dodi'}
print(sorted(jan & feb), sorted(feb - jan))

Soal latihan

  1. Cetak huruf pertama yang tidak berulang di "aabbcdeec".

    Petunjuk

    Hitung dengan Counter, lalu telusuri string dari awal.

    Lihat jawaban
    PYTHON
    from collections import Counter
s = 'aabbcdeec'
c = Counter(s)
for ch in s:
    if c[ch] == 1:
        print(ch)
        break

Poin penting

  • Two sum: simpan pasangan yang dicari di dict.
  • Counter untuk frekuensi, defaultdict untuk kelompok.
  • Operasi set: &, |, -.
