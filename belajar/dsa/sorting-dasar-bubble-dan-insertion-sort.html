Sorting dasar: bubble dan insertion sort

Buka versi interaktif

Bubble sort membandingkan pasangan bersebelahan dan menukarnya jika urutannya salah; elemen terbesar "menggelembung" ke akhir setiap putaran. Insertion sort mengambil elemen satu per satu dan menyisipkannya ke posisi yang tepat di bagian yang sudah terurut, seperti merapikan kartu di tangan.

Keduanya O(n²) pada kasus terburuk, tetapi insertion sort sangat cepat untuk data yang hampir terurut (mendekati O(n)). Karena itu Timsort (algoritma bawaan Python) memakai insertion sort untuk potongan kecil.

Keduanya stabil: dua data dengan nilai sama tetap pada urutan aslinya. Stabilitas penting saat mengurutkan berdasarkan beberapa kolom.

PYTHON
def bubble(data):
    a = data[:]
    tukar = 0
    for i in range(len(a)):
        for j in range(len(a) - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                tukar += 1
    return a, tukar

def insertion(data):
    a = data[:]
    for i in range(1, len(a)):
        kunci, j = a[i], i - 1
        while j >= 0 and a[j] > kunci:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = kunci
    return a

print(bubble([5, 2, 9, 1, 6]))
print(insertion([5, 2, 9, 1, 6]))
KELUARAN
([1, 2, 5, 6, 9], 5)
[1, 2, 5, 6, 9]

for i in range(len(a)):

Poin penting

  • Bubble: tukar pasangan bersebelahan.
  • Insertion: sisipkan ke bagian terurut.
  • O(n²), tetapi insertion cepat untuk data hampir terurut.
