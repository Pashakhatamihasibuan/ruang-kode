Algoritma, struktur data, dan kenapa penting

Buka versi interaktif

Algoritma adalah langkah-langkah pasti untuk menyelesaikan masalah. Struktur data adalah cara menyimpan data agar langkah-langkah itu efisien. Keduanya selalu berpasangan: algoritma pencarian cepat butuh data yang tersusun dengan cara tertentu.

Contoh sehari-hari: mencari nama di daftar absen yang acak berarti memeriksa satu per satu. Jika daftar terurut, kamu bisa membuka bagian tengah lalu membuang separuh daftar setiap langkah. Data yang sama, struktur berbeda, kecepatan sangat berbeda.

Di dunia kerja, struktur data muncul di mana-mana: antrean pesanan ojek online (queue), riwayat tombol Undo (stack), indeks database (tree), rute peta (graph), dan cache (hash table). Wawancara teknis di perusahaan teknologi juga hampir selalu menguji topik ini.

PYTHON
absen = ['Rina', 'Budi', 'Sari', 'Andi', 'Dewi', 'Tono']

# cara 1: periksa satu per satu (linear search)
langkah = 0
for nama in absen:
    langkah += 1
    if nama == 'Tono':
        break
print('Linear search:', langkah, 'langkah')

# cara 2: set (hash) langsung tahu ada atau tidak
himpunan = set(absen)
print('Ada Tono?', 'Tono' in himpunan)
KELUARAN
Linear search: 6 langkah
Ada Tono? True

Soal latihan

  1. Hitung berapa langkah linear search untuk menemukan "Sari" di daftar absen di atas.

    Petunjuk

    Tambah penghitung setiap memeriksa satu nama, berhenti saat ketemu.

    Lihat jawaban
    PYTHON
    absen = ['Rina', 'Budi', 'Sari', 'Andi', 'Dewi', 'Tono']
langkah = 0
for nama in absen:
    langkah += 1
    if nama == 'Sari':
        break
print(langkah)
    KELUARAN
    3

Poin penting

  • Algoritma = langkah, struktur data = cara menyimpan.
  • Struktur yang tepat membuat algoritma jauh lebih cepat.
  • Stack, queue, tree, graph, dan hash table dipakai setiap hari di aplikasi nyata.
