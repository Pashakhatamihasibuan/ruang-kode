Stack (LIFO)

Buka versi interaktif

Stack bekerja seperti tumpukan piring: yang terakhir ditaruh, pertama diambil (LIFO). Operasinya push (taruh), pop (ambil), dan peek (lihat atas), semuanya O(1). Di Python cukup pakai list dengan append dan pop().

Stack dipakai untuk Undo, tombol Back di browser, call stack fungsi, dan memeriksa kurung seimbang. Setiap kurung buka di-push; setiap kurung tutup harus cocok dengan kurung buka teratas.

Variasi penting: monotonic stack menjaga isi tetap terurut dan menjawab soal seperti "hari berikutnya dengan suhu lebih tinggi" dalam O(n).

PYTHON
def seimbang(teks):
    pasangan = {')': '(', ']': '[', '}': '{'}
    tumpukan = []
    for ch in teks:
        if ch in '([{':
            tumpukan.append(ch)
        elif ch in pasangan:
            if not tumpukan or tumpukan.pop() != pasangan[ch]:
                return False
    return not tumpukan

for t in ['(a + b) * [c]', '{[}]', '((']:
    print(t, '->', seimbang(t))
KELUARAN
(a + b) * [c] -> True
{[}] -> False
(( -> False

    PYTHON
    tumpukan = list('algoritma')

while tumpukan:
    hasil += tumpukan.pop()

Poin penting

  • LIFO: terakhir masuk, pertama keluar.
  • push dan pop O(1) dengan list.
  • Kurung seimbang adalah soal stack klasik.
