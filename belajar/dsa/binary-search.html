Binary search

Buka versi interaktif

Binary search mencari di data terurut dengan membandingkan elemen tengah, lalu membuang separuh yang pasti tidak berisi target. Setiap langkah membagi dua ruang pencarian: O(log n). Satu juta data cukup sekitar 20 langkah.

Bagian yang sering salah: kondisi loop (kiri <= kanan) dan pergeseran batas (tengah + 1 atau tengah - 1). Salah satu tanda saja menyebabkan loop tak berujung.

Python punya modul bisect untuk mencari posisi sisip di list terurut. Binary search juga dipakai untuk "menebak jawaban", misalnya kapasitas minimum truk agar semua paket terkirim dalam D hari.

PYTHON
import bisect

def cari(data, target):
    kiri, kanan = 0, len(data) - 1
    langkah = 0
    while kiri <= kanan:
        langkah += 1
        tengah = (kiri + kanan) // 2
        if data[tengah] == target:
            return tengah, langkah
        if data[tengah] < target:
            kiri = tengah + 1
        else:
            kanan = tengah - 1
    return -1, langkah

data = list(range(0, 2000, 2))   # 1000 angka genap
print(cari(data, 1234))
print(cari(data, 7))
print('posisi sisip 7:', bisect.bisect_left(data, 7))
KELUARAN
(617, 10)
(-1, 10)
posisi sisip 7: 4

Soal latihan

  1. Cari akar kuadrat bulat dari 2000 (bilangan bulat terbesar x dengan x² ≤ 2000) memakai binary search.

    Petunjuk

    Cari di rentang 0 sampai 2000; simpan jawaban terakhir yang valid.

    Lihat jawaban
    PYTHON
    n = 2000
kiri, kanan, jawab = 0, n, 0
while kiri <= kanan:
    t = (kiri + kanan) // 2
    if t * t <= n:
        jawab = t
        kiri = t + 1
    else:
        kanan = t - 1
print(jawab)
    KELUARAN
    44

Poin penting

  • Syarat: data terurut.
  • O(log n): 1000 data ≤ 10 langkah.
  • Perhatikan kiri <= kanan dan ±1.
