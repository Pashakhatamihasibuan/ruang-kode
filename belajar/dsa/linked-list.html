Linked list

Buka versi interaktif

Linked list adalah rangkaian simpul (node); setiap simpul menyimpan data dan penunjuk ke simpul berikutnya. Berbeda dengan array, simpul tidak harus bersebelahan di memori.

Kelebihan: menyisipkan atau menghapus di awal O(1), tanpa menggeser elemen. Kekurangan: mengakses elemen ke-i harus berjalan dari kepala, O(n). Variasinya: doubly linked list (punya penunjuk ke belakang juga) dan circular (simpul terakhir menunjuk ke kepala).

Soal wawancara favorit: membalik linked list, mendeteksi siklus (pointer cepat dan lambat), dan mencari simpul tengah.

PYTHON
class Node:
    def __init__(self, data, berikut=None):
        self.data = data
        self.berikut = berikut

def cetak(kepala):
    hasil = []
    while kepala:
        hasil.append(str(kepala.data))
        kepala = kepala.berikut
    print(' -> '.join(hasil))

kepala = Node(1, Node(2, Node(3)))
kepala = Node(0, kepala)   # sisip di awal, O(1)
cetak(kepala)

def balik(kepala):
    sebelum = None
    while kepala:
        kepala.berikut, sebelum, kepala = sebelum, kepala, kepala.berikut
    return sebelum

cetak(balik(kepala))
KELUARAN
0 -> 1 -> 2 -> 3
3 -> 2 -> 1 -> 0

Poin penting

  • Simpul = data + penunjuk ke simpul berikutnya.
  • Sisip di awal O(1), akses ke-i O(n).
  • Membalik linked list: tiga penunjuk.
