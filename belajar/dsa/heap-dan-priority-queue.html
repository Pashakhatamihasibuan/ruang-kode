Heap dan priority queue

Buka versi interaktif

Heap adalah binary tree lengkap yang disimpan di array. Pada min-heap, setiap induk lebih kecil atau sama dengan anaknya, jadi elemen terkecil selalu di indeks 0. Ambil minimum O(1), sisip dan hapus O(log n).

Heap adalah implementasi priority queue: antrean yang mengeluarkan prioritas tertinggi dulu, misalnya pasien IGD paling darurat atau tugas server paling penting. Modul heapq Python menyediakan min-heap; untuk max-heap simpan nilai negatif.

Pola wawancara: mencari k elemen terbesar dengan min-heap berukuran k, O(n log k), lebih cepat daripada mengurutkan semua data jika k kecil.

PYTHON
import heapq

igd = []
heapq.heappush(igd, (3, 'Demam ringan'))
heapq.heappush(igd, (1, 'Serangan jantung'))
heapq.heappush(igd, (2, 'Patah tulang'))
while igd:
    prioritas, kasus = heapq.heappop(igd)
    print(prioritas, kasus)

nilai = [70, 95, 88, 60, 99, 75, 91]
print('3 terbesar:', heapq.nlargest(3, nilai))

h = []
for x in nilai:
    heapq.heappush(h, x)
    if len(h) > 3:
        heapq.heappop(h)
print('heap ukuran 3:', sorted(h, reverse=True))
KELUARAN
1 Serangan jantung
2 Patah tulang
3 Demam ringan
3 terbesar: [99, 95, 91]
heap ukuran 3: [99, 95, 91]

Soal latihan

  1. Gabungkan tiga list terurut [1, 4, 7], [2, 5, 8], [3, 6, 9] menjadi satu list terurut dengan heapq.merge.

    Petunjuk

    heapq.merge menerima beberapa iterable terurut.

    Lihat jawaban
    PYTHON
    import heapq
print(list(heapq.merge([1, 4, 7], [2, 5, 8], [3, 6, 9])))
    KELUARAN
    [1, 2, 3, 4, 5, 6, 7, 8, 9]

Poin penting

  • Min-heap: terkecil selalu di depan.
  • Sisip dan hapus O(log n).
  • heapq + nilai negatif = max-heap.
