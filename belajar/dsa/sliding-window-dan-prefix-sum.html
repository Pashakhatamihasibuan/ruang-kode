Sliding window dan prefix sum

Buka versi interaktif

Sliding window menjaga "jendela" sepanjang k elemen yang bergeser. Daripada menjumlah ulang k elemen setiap geser (O(n·k)), tambahkan elemen yang masuk dan kurangi elemen yang keluar (O(n)).

Prefix sum menyimpan jumlah kumulatif: pre[i] = jumlah elemen sebelum indeks i. Jumlah rentang [a, b) cukup dihitung pre[b] - pre[a] dalam O(1) setelah persiapan O(n).

Contoh nyata: penjualan harian toko. Sliding window mencari 3 hari berturut-turut dengan omzet tertinggi; prefix sum menjawab cepat "berapa total omzet hari ke-2 sampai ke-5?"

PYTHON
omzet = [120, 90, 150, 200, 80, 170, 60]
k = 3
jendela = sum(omzet[:k])
terbaik, mulai = jendela, 0
for i in range(k, len(omzet)):
    jendela += omzet[i] - omzet[i - k]
    if jendela > terbaik:
        terbaik, mulai = jendela, i - k + 1
print(f'3 hari terbaik mulai hari ke-{mulai + 1}, total {terbaik}')

pre = [0]
for x in omzet:
    pre.append(pre[-1] + x)
print('Hari 2 sampai 5:', pre[5] - pre[1])
KELUARAN
3 hari terbaik mulai hari ke-4, total 450
Hari 2 sampai 5: 520

Soal latihan

  1. Cari panjang substring terpanjang tanpa huruf berulang di "abcabcbb".

    Petunjuk

    Jendela dengan set; geser kiri saat huruf sudah ada.

    Lihat jawaban
    PYTHON
    s = 'abcabcbb'
ada = set()
kiri = terbaik = 0
for kanan, ch in enumerate(s):
    while ch in ada:
        ada.remove(s[kiri])
        kiri += 1
    ada.add(ch)
    terbaik = max(terbaik, kanan - kiri + 1)
print(terbaik)
    KELUARAN
    3

Poin penting

  • Sliding window: tambah yang masuk, kurangi yang keluar.
  • Prefix sum: jumlah rentang dalam O(1).
  • Keduanya mengubah O(n·k) menjadi O(n).

Cek pemahaman

Dengan prefix sum, jumlah elemen indeks 2 sampai 4 (inklusif)?

Jawaban: pre[5] - pre[2]

Rentang [2, 5).
