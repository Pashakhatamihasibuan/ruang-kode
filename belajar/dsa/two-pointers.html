Two pointers

Buka versi interaktif

Two pointers memakai dua indeks yang bergerak di array, biasanya satu dari kiri dan satu dari kanan. Teknik ini mengubah banyak solusi O(n²) menjadi O(n).

Contoh: di list terurut, cari dua angka yang jumlahnya target. Jika jumlah terlalu kecil, geser pointer kiri ke kanan; jika terlalu besar, geser pointer kanan ke kiri. Setiap langkah membuang satu kemungkinan.

Pola lain: membalik string, memeriksa palindrom, menggabungkan dua list terurut, dan menghapus duplikat di tempat.

PYTHON
def dua_jumlah(data, target):
    kiri, kanan = 0, len(data) - 1
    while kiri < kanan:
        s = data[kiri] + data[kanan]
        if s == target:
            return data[kiri], data[kanan]
        if s < target:
            kiri += 1
        else:
            kanan -= 1
    return None

def palindrom(teks):
    t = teks.lower().replace(' ', '')
    i, j = 0, len(t) - 1
    while i < j:
        if t[i] != t[j]:
            return False
        i += 1; j -= 1
    return True

print(dua_jumlah([1, 3, 4, 6, 8, 11], 10))
print(palindrom('Kasur ini rusak'))
KELUARAN
(4, 6)
True

Soal latihan

  1. Balik list [1, 2, 3, 4, 5] di tempat (tanpa list baru) dengan two pointers.

    Petunjuk

    Tukar data[i] dan data[j], lalu i naik dan j turun.

    Lihat jawaban
    PYTHON
    data = [1, 2, 3, 4, 5]
i, j = 0, len(data) - 1
while i < j:
    data[i], data[j] = data[j], data[i]
    i += 1
    j -= 1
print(data)
    KELUARAN
    [5, 4, 3, 2, 1]

Poin penting

  • Dua indeks bergerak saling mendekat.
  • Butuh data terurut untuk soal jumlah.
  • O(n) waktu, O(1) ruang.
