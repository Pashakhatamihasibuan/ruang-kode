Binary search tree

Buka versi interaktif

Binary search tree (BST) punya aturan: semua nilai di subtree kiri lebih kecil dari simpul, semua di kanan lebih besar. Mencari, menyisip, dan menghapus O(tinggi): O(log n) jika seimbang, O(n) jika miring seperti linked list.

Penelusuran inorder pada BST selalu menghasilkan data terurut. Ini cara cepat memeriksa apakah sebuah tree benar-benar BST.

Agar tetap seimbang, ada BST yang menyeimbangkan diri sendiri: AVL tree dan red-black tree. Database memakai kerabatnya, B-tree, untuk indeks.

PYTHON
class Simpul:
    def __init__(self, v):
        self.v, self.kiri, self.kanan = v, None, None

def sisip(akar, v):
    if akar is None:
        return Simpul(v)
    if v < akar.v:
        akar.kiri = sisip(akar.kiri, v)
    else:
        akar.kanan = sisip(akar.kanan, v)
    return akar

def cari(akar, v, langkah=1):
    if akar is None:
        return None
    if v == akar.v:
        return langkah
    return cari(akar.kiri if v < akar.v else akar.kanan, v, langkah + 1)

def inorder(s):
    return inorder(s.kiri) + [s.v] + inorder(s.kanan) if s else []

akar = None
for x in [50, 30, 70, 20, 40, 60, 80]:
    akar = sisip(akar, x)
print(inorder(akar))
print('60 ditemukan dalam', cari(akar, 60), 'langkah')
print('65 ada?', cari(akar, 65))
KELUARAN
[20, 30, 40, 50, 60, 70, 80]
60 ditemukan dalam 3 langkah
65 ada? None

Soal latihan

  1. Cari nilai minimum dan maksimum di BST [50, 30, 70, 20, 40, 60, 80].

    Petunjuk

    Minimum: terus ke kiri. Maksimum: terus ke kanan.

    Lihat jawaban
    PYTHON
    class S:
    def __init__(self, v):
        self.v, self.kiri, self.kanan = v, None, None
def sisip(a, v):
    if not a:
        return S(v)
    if v < a.v:
        a.kiri = sisip(a.kiri, v)
    else:
        a.kanan = sisip(a.kanan, v)
    return a
akar = None
for x in [50, 30, 70, 20, 40, 60, 80]:
    akar = sisip(akar, x)
mn = akar
while mn.kiri:
    mn = mn.kiri
mx = akar
while mx.kanan:
    mx = mx.kanan
print(mn.v, mx.v)
    KELUARAN
    20 80

Poin penting

  • Kiri lebih kecil, kanan lebih besar.
  • Inorder BST = data terurut.
  • Seimbang O(log n), miring O(n).
