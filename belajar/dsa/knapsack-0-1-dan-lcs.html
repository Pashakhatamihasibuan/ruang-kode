Knapsack 0/1 dan LCS

Buka versi interaktif

Knapsack 0/1: tas berkapasitas W dan daftar barang dengan berat dan nilai; setiap barang diambil utuh atau tidak sama sekali. dp[w] = nilai maksimum dengan kapasitas w. Untuk setiap barang, perbarui dari kapasitas besar ke kecil agar barang tidak terpakai dua kali.

Longest Common Subsequence (LCS) mencari panjang urutan karakter terpanjang yang muncul di dua string (tidak harus bersebelahan). Dipakai pada git diff, pembanding DNA, dan pendeteksi plagiarisme.

Keduanya O(n × W) dan O(n × m): jauh lebih cepat daripada mencoba semua kombinasi O(2ⁿ).

PYTHON
def knapsack(barang, W):
    dp = [0] * (W + 1)
    for berat, nilai in barang:
        for w in range(W, berat - 1, -1):
            dp[w] = max(dp[w], dp[w - berat] + nilai)
    return dp[W]

# (berat kg, nilai ribu Rp) untuk ransel pendakian 10 kg
barang = [(5, 60), (3, 50), (4, 70), (2, 30)]
print('Nilai maksimum:', knapsack(barang, 10))

def lcs(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[-1][-1]

print('LCS:', lcs('ALGORITMA', 'LOGARITMA'))

Poin penting

  • Knapsack 0/1: loop kapasitas dari besar ke kecil.
  • LCS: cocok tambah 1 dari diagonal, jika tidak ambil maksimum.
  • DP mengubah O(2ⁿ) menjadi polinomial.
