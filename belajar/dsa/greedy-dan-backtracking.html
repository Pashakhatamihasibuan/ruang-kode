Greedy dan backtracking

Buka versi interaktif

Algoritma greedy selalu mengambil pilihan terbaik saat ini tanpa melihat ke depan. Cepat dan sederhana, tetapi hanya benar untuk masalah tertentu. Contoh benar: menjadwalkan rapat sebanyak mungkin dengan memilih yang selesai paling awal.

Contoh greedy yang salah: kembalian koin dengan pecahan 1, 3, 4 untuk total 6. Greedy mengambil 4 + 1 + 1 (3 koin), padahal 3 + 3 hanya 2 koin. Jika ragu, gunakan DP.

Backtracking mencoba semua kemungkinan secara sistematis dan mundur begitu jalur tidak mungkin berhasil. Dipakai untuk permutasi, sudoku, dan N-Queens.

PYTHON
rapat = [('A', 9, 10), ('B', 9, 12), ('C', 10, 11), ('D', 11, 13), ('E', 12, 14)]
terpilih, selesai = [], 0
for nama, mulai, akhir in sorted(rapat, key=lambda r: r[2]):
    if mulai >= selesai:
        terpilih.append(nama)
        selesai = akhir
print('Rapat terpilih:', terpilih)

def greedy_koin(koin, total):
    hasil = []
    for k in sorted(koin, reverse=True):
        while total >= k:
            total -= k
            hasil.append(k)
    return hasil
print('Greedy 1,3,4 untuk 6:', greedy_koin([1, 3, 4], 6))

def permutasi(sisa, jalur=''):
    if not sisa:
        print(jalur, end=' ')
        return
    for i, ch in enumerate(sisa):
        permutasi(sisa[:i] + sisa[i + 1:], jalur + ch)
permutasi('ABC')
print()
KELUARAN
Rapat terpilih: ['A', 'C', 'D']
Greedy 1,3,4 untuk 6: [4, 1, 1]
ABC ACB BAC BCA CAB CBA

Soal latihan

  1. Cetak semua subset dari [1, 2, 3] memakai backtracking.

    Petunjuk

    Untuk setiap elemen: ambil atau tidak, lalu lanjut ke elemen berikutnya.

    Lihat jawaban
    PYTHON
    data = [1, 2, 3]
hasil = []
def bt(i, jalur):
    if i == len(data):
        hasil.append(jalur[:])
        return
    jalur.append(data[i])
    bt(i + 1, jalur)
    jalur.pop()
    bt(i + 1, jalur)
bt(0, [])
print(hasil)
    KELUARAN
    [[1, 2, 3], [1, 2], [1, 3], [1], [2, 3], [2], [3], []]

Poin penting

  • Greedy: ambil terbaik saat ini, harus dibuktikan benar.
  • Jadwal rapat: urutkan menurut waktu selesai.
  • Backtracking: coba, mundur jika gagal.

Cek pemahaman

Untuk koin 1, 3, 4 dan total 6, greedy memberi 3 koin. Jawaban optimal?

Jawaban: 2 koin (3 + 3)

Greedy tidak selalu optimal.
