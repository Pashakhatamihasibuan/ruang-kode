Merge sort dan quick sort

Buka versi interaktif

Merge sort memakai strategi divide and conquer: belah list jadi dua, urutkan masing-masing secara rekursif, lalu gabungkan dua list terurut. Selalu O(n log n), stabil, tetapi butuh memori tambahan O(n).

Quick sort memilih pivot, memisahkan elemen yang lebih kecil ke kiri dan yang lebih besar ke kanan, lalu mengurutkan kedua sisi. Rata-rata O(n log n) dan hemat memori, tetapi O(n²) jika pivot selalu buruk (misalnya data sudah terurut dan pivot elemen pertama).

Dalam praktik, pakai sorted() atau list.sort() (Timsort, O(n log n), stabil). Pelajari merge dan quick sort untuk memahami divide and conquer dan untuk wawancara.

PYTHON
def merge_sort(a):
    if len(a) <= 1:
        return a
    t = len(a) // 2
    kiri, kanan = merge_sort(a[:t]), merge_sort(a[t:])
    hasil, i, j = [], 0, 0
    while i < len(kiri) and j < len(kanan):
        if kiri[i] <= kanan[j]:
            hasil.append(kiri[i]); i += 1
        else:
            hasil.append(kanan[j]); j += 1
    return hasil + kiri[i:] + kanan[j:]

def quick_sort(a):
    if len(a) <= 1:
        return a
    pivot = a[len(a) // 2]
    return (quick_sort([x for x in a if x < pivot])
            + [x for x in a if x == pivot]
            + quick_sort([x for x in a if x > pivot]))

data = [38, 27, 43, 3, 9, 82, 10]
print(merge_sort(data))
print(quick_sort(data))
print(sorted(data, reverse=True))

Poin penting

  • Divide and conquer: belah, selesaikan, gabungkan.
  • Merge sort selalu O(n log n) dan stabil.
  • Quick sort cepat rata-rata, tetapi hati-hati memilih pivot.
