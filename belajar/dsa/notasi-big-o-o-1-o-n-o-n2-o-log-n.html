Notasi Big-O: O(1), O(n), O(n²), O(log n)

Buka versi interaktif

Big-O menjawab pertanyaan: jika data membesar n kali, berapa kali lipat pekerjaannya? Kita tidak menghitung detik (tergantung komputer), melainkan pertumbuhan jumlah langkah terhadap ukuran input n.

Urutan dari yang tercepat: O(1) konstan (ambil elemen ke-i), O(log n) logaritmik (binary search), O(n) linear (satu loop), O(n log n) (merge sort), O(n²) kuadratik (loop bersarang), O(2ⁿ) eksponensial (mencoba semua kombinasi).

Aturan praktis: buang konstanta dan suku kecil. 3n + 5 menjadi O(n), n² + n menjadi O(n²). Big-O biasanya menyatakan kasus terburuk; ada juga Big-Ω (terbaik) dan Big-Θ (batas ketat), tetapi Big-O yang paling sering dipakai.

Kelas kompleksitas
Big-ONamaContoh
O(1)KonstanAkses list[i], cek kunci di dict
O(log n)LogaritmikBinary search
O(n)LinearMencari di list tak terurut
O(n log n)LinearitmikMerge sort, sorted()
O(n²)KuadratikBubble sort, loop bersarang
O(2ⁿ)EksponensialFibonacci rekursif polos
PYTHON
def hitung_langkah(n):
    linear = n
    kuadrat = n * n
    log = 0
    x = n
    while x > 1:
        x //= 2
        log += 1
    return log, linear, kuadrat

for n in [8, 64, 1024]:
    lg, lin, kd = hitung_langkah(n)
    print(f'n={n:5}  log n={lg:3}  n={lin:5}  n²={kd}')

n=    8  log n=  3  n=    8  n²=64
n=   64  log n=  6  n=   64  n²=4096
n= 1024  log n= 10  n= 1024  n²=1048576

Soal latihan

  1. Tulis fungsi yang menghitung berapa pasangan (i, j) dengan i < j dari list berisi 5 angka, lalu cetak hasilnya. Kompleksitasnya O(n²).

    Petunjuk

    Dua loop bersarang, j mulai dari i + 1.

    Lihat jawaban
    PYTHON
    angka = [3, 1, 4, 1, 5]
jumlah = 0
for i in range(len(angka)):
    for j in range(i + 1, len(angka)):
        jumlah += 1
print(jumlah)
    KELUARAN
    10

Poin penting

  • Big-O mengukur pertumbuhan langkah, bukan detik.
  • Buang konstanta dan suku yang lebih kecil.
  • Untuk n = 1024: log n = 10, tetapi n² lebih dari satu juta.

Cek pemahaman

Kompleksitas <code>5n² + 3n + 7</code>?

Jawaban: O(n²)

Suku terbesar tanpa konstanta.

Dua loop bersarang masing-masing n kali?

Jawaban: O(n²)

n × n langkah.
