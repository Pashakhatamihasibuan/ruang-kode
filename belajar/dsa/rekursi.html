Rekursi

Buka versi interaktif

Rekursi adalah fungsi yang memanggil dirinya sendiri dengan masalah yang lebih kecil. Setiap fungsi rekursif butuh kasus dasar (kapan berhenti) dan langkah rekursif (mengecilkan masalah). Tanpa kasus dasar, program berakhir dengan RecursionError.

Setiap panggilan disimpan di call stack. Python membatasi kedalaman sekitar 1000, jadi rekursi sangat dalam lebih baik diubah menjadi loop.

Fibonacci rekursif polos sangat lambat (O(2ⁿ)) karena menghitung hal yang sama berulang kali. Solusinya memoization: simpan hasil yang sudah dihitung. Ini pintu masuk ke dynamic programming.

PYTHON
def faktorial(n):
    if n <= 1:          # kasus dasar
        return 1
    return n * faktorial(n - 1)

panggilan = 0
def fib(n):
    global panggilan
    panggilan += 1
    return n if n < 2 else fib(n - 1) + fib(n - 2)

memo = {}
def fib_memo(n):
    if n < 2:
        return n
    if n not in memo:
        memo[n] = fib_memo(n - 1) + fib_memo(n - 2)
    return memo[n]

print(faktorial(5))
print(fib(20), 'dengan', panggilan, 'panggilan')
print(fib_memo(80))

120

Soal latihan

  1. Tulis fungsi rekursif yang menjumlah digit angka 2024.

    Petunjuk

    jumlah(n) = n % 10 + jumlah(n // 10), berhenti saat n = 0.

    Lihat jawaban
    PYTHON
    def jumlah_digit(n):
    if n == 0:
        return 0
    return n % 10 + jumlah_digit(n // 10)
print(jumlah_digit(2024))
    KELUARAN
    8

Poin penting

  • Wajib ada kasus dasar.
  • Setiap panggilan memakai call stack.
  • Memoization menghilangkan perhitungan berulang.
