Binary tree dan penelusuran

Buka versi interaktif

Tree adalah struktur bertingkat: satu akar (root), setiap simpul punya anak, dan simpul tanpa anak disebut daun. Contoh nyata: folder di komputer, struktur organisasi, dan DOM halaman web. Binary tree membatasi setiap simpul paling banyak dua anak.

Penelusuran depth-first ada tiga: preorder (akar, kiri, kanan), inorder (kiri, akar, kanan), postorder (kiri, kanan, akar). Penelusuran breadth-first (level order) memakai queue untuk mengunjungi tingkat demi tingkat.

Tinggi tree adalah jumlah tingkat dari akar ke daun terjauh. Banyak operasi bergantung pada tinggi, jadi tree yang seimbang lebih cepat.

PYTHON
from collections import deque

class Simpul:
    def __init__(self, v, kiri=None, kanan=None):
        self.v, self.kiri, self.kanan = v, kiri, kanan

#        A
#      B   C
#     D E    F
akar = Simpul('A', Simpul('B', Simpul('D'), Simpul('E')), Simpul('C', None, Simpul('F')))

def pre(s):  return [s.v] + pre(s.kiri) + pre(s.kanan) if s else []
def ino(s):  return ino(s.kiri) + [s.v] + ino(s.kanan) if s else []
def post(s): return post(s.kiri) + post(s.kanan) + [s.v] if s else []
def tinggi(s): return 1 + max(tinggi(s.kiri), tinggi(s.kanan)) if s else 0

def level(s):
    q, hasil = deque([s]), []
    while q:
        x = q.popleft()
        hasil.append(x.v)
        q.extend(c for c in (x.kiri, x.kanan) if c)
    return hasil

print('pre  ', pre(akar))
print('in   ', ino(akar))
print('post ', post(akar))
print('level', level(akar), 'tinggi', tinggi(akar))
KELUARAN
pre   ['A', 'B', 'D', 'E', 'C', 'F']
in    ['D', 'B', 'E', 'A', 'C', 'F']
post  ['D', 'E', 'B', 'F', 'C', 'A']
level ['A', 'B', 'C', 'D', 'E', 'F'] tinggi 3

Soal latihan

  1. Hitung jumlah daun pada tree contoh (A sampai F).

    Petunjuk

    Daun: tidak punya anak kiri dan kanan.

    Lihat jawaban
    PYTHON
    class S:
    def __init__(self, v, k=None, n=None):
        self.v, self.kiri, self.kanan = v, k, n
akar = S('A', S('B', S('D'), S('E')), S('C', None, S('F')))
def daun(s):
    if not s:
        return 0
    if not s.kiri and not s.kanan:
        return 1
    return daun(s.kiri) + daun(s.kanan)
print(daun(akar))
    KELUARAN
    3

Poin penting

  • Akar, anak, daun, tinggi.
  • Pre, in, post order: posisi akar berbeda.
  • Level order memakai queue.
