Topological sort

Buka versi interaktif

Topological sort mengurutkan simpul graph berarah tanpa siklus (DAG) sehingga setiap sisi A → B membuat A muncul sebelum B. Contoh: urutan mata kuliah prasyarat, urutan build modul, atau langkah resep.

Algoritma Kahn: hitung in-degree (jumlah panah masuk) setiap simpul, masukkan simpul ber-in-degree 0 ke queue, keluarkan satu per satu sambil mengurangi in-degree tetangganya.

Jika di akhir masih ada simpul yang belum keluar, berarti graph punya siklus: tidak ada urutan yang valid (misalnya A prasyarat B dan B prasyarat A).

PYTHON
from collections import deque

prasyarat = {
    'Algoritma Dasar': ['Struktur Data', 'Basis Data'],
    'Struktur Data': ['Analisis Algoritma'],
    'Basis Data': ['Sistem Informasi'],
    'Analisis Algoritma': ['Kecerdasan Buatan'],
    'Sistem Informasi': [],
    'Kecerdasan Buatan': [],
}

def kahn(g):
    masuk = {s: 0 for s in g}
    for s in g:
        for t in g[s]:
            masuk[t] += 1
    q = deque(s for s in g if masuk[s] == 0)
    urutan = []
    while q:
        s = q.popleft()
        urutan.append(s)
        for t in g[s]:
            masuk[t] -= 1
            if masuk[t] == 0:
                q.append(t)
    return urutan if len(urutan) == len(g) else 'ada siklus'

for i, mk in enumerate(kahn(prasyarat), 1):
    print(i, mk)
print(kahn({'A': ['B'], 'B': ['A']}))
KELUARAN
1 Algoritma Dasar
2 Struktur Data
3 Basis Data
4 Analisis Algoritma
5 Sistem Informasi
6 Kecerdasan Buatan
ada siklus

Soal latihan

  1. Tentukan urutan memasak: beli bahan → potong sayur → tumis, beli bahan → masak nasi, tumis → sajikan, masak nasi → sajikan.

    Petunjuk

    Bentuk dict, lalu jalankan Kahn.

Poin penting

  • Hanya untuk graph berarah tanpa siklus (DAG).
  • Kahn: mulai dari in-degree 0.
  • Sisa simpul berarti ada siklus.
