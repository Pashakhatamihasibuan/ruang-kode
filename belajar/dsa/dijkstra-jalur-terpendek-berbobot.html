Dijkstra: jalur terpendek berbobot

Buka versi interaktif

Jika sisi punya bobot (jarak, waktu, ongkos), BFS tidak cukup. Algoritma Dijkstra selalu memproses simpul dengan jarak sementara terkecil memakai priority queue, lalu memperbarui jarak tetangganya jika lewat simpul itu lebih dekat (relaksasi).

Kompleksitasnya O((V + E) log V) dengan heap. Syaratnya: tidak ada bobot negatif. Untuk bobot negatif pakai Bellman-Ford; untuk peta besar, aplikasi navigasi memakai A* yang menambahkan perkiraan jarak ke tujuan.

Contoh di bawah menghitung waktu tempuh terpendek (menit) antar titik di sebuah kota.

PYTHON
import heapq

jalan = {
    'Rumah': {'Pasar': 10, 'Sekolah': 25},
    'Pasar': {'Sekolah': 8, 'Kantor': 30},
    'Sekolah': {'Kantor': 12},
    'Kantor': {},
}

def dijkstra(g, awal):
    jarak = {s: float('inf') for s in g}
    jarak[awal] = 0
    asal = {}
    pq = [(0, awal)]
    while pq:
        d, s = heapq.heappop(pq)
        if d > jarak[s]:
            continue
        for t, w in g[s].items():
            if d + w < jarak[t]:
                jarak[t] = d + w
                asal[t] = s
                heapq.heappush(pq, (jarak[t], t))
    return jarak, asal

jarak, asal = dijkstra(jalan, 'Rumah')
print(jarak)
rute, s = [], 'Kantor'
while s != 'Rumah':
    rute.append(s)
    s = asal[s]
print(' -> '.join(['Rumah'] + rute[::-1]))
KELUARAN
{'Rumah': 0, 'Pasar': 10, 'Sekolah': 18, 'Kantor': 30}
Rumah -> Pasar -> Sekolah -> Kantor

Soal latihan

  1. Dengan graph jalan di atas, hitung jarak terpendek dari Pasar ke setiap titik.

    Petunjuk

    Jalankan dijkstra dengan awal Pasar.

Poin penting

  • Proses simpul dengan jarak terkecil lebih dulu.
  • Relaksasi: perbarui jika lebih dekat.
  • Tidak boleh ada bobot negatif.
