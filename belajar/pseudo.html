Pseudocode: Menulis algoritma sebelum menulis kode

Enam modul: konstruksi logika inti, percabangan (IF, CASE, guard clause), perulangan (FOR, WHILE, DO-WHILE), desain modular dan rekursi, koleksi data (array, record, searching, sorting), serta verifikasi dan translasi ke Python dan bahasa bertipe kuat.

6 modul · 37 pelajaran

Mulai belajar di aplikasi

Modul 1: Konstruksi logika inti

Pemula

Tujuan pseudocode yang tidak terikat bahasa, kata kunci standar, variabel dan tipe data, input-output, operator aritmetika, dan algoritma sekuensial pertama.

  1. Tujuan pseudocode yang tidak terikat bahasa
  2. Kata kunci standar dan gaya penulisan
  3. Variabel, tipe data, dan pengisian nilai
  4. Input dan output dasar
  5. Operasi aritmetika dan urutan operator
  6. Algoritma sekuensial pertamamu

Modul 2: Percabangan kondisional

Pemula

Ekspresi Boolean, IF satu cabang, IF-ELSE, CASE, percabangan bersarang, dan guard clause untuk menangani kesalahan.

  1. Ekspresi Boolean dan operator logika
  2. IF satu cabang
  3. IF-ELSE: dua jalur
  4. CASE: memilih banyak jalur
  5. Percabangan bersarang
  6. Guard clause untuk menangani kesalahan

Modul 3: Proses perulangan

Pemula

FOR, WHILE, REPEAT-UNTIL, perbandingan ketiganya dengan contoh sederhana, penghentian loop, loop bersarang, dan pola akumulator.

  1. FOR: perulangan pasti
  2. WHILE: perulangan bersyarat
  3. REPEAT-UNTIL: dicek di akhir
  4. FOR, WHILE, dan DO-WHILE: contoh sederhana dan bedanya
  5. Penghentian loop dan infinite loop
  6. Loop bersarang
  7. Pola akumulator

Modul 4: Desain modular

Menengah

Dekomposisi top-down, fungsi dan nilai kembali, prosedur, parameter by value dan by reference, ruang lingkup variabel, dan rekursi.

  1. Dekomposisi top-down
  2. Fungsi dan nilai kembali
  3. Prosedur untuk efek samping
  4. Parameter by value dan by reference
  5. Ruang lingkup variabel dan enkapsulasi state
  6. Rekursi dan base case

Modul 5: Koleksi data

Menengah

Array satu dimensi, indeks dan traversal, array multidimensi, record, linear dan binary search, bubble sort dan insertion sort.

  1. Array satu dimensi
  2. Indeks, traversal, dan memperbarui array
  3. Array multidimensi
  4. Struktur record
  5. Linear search dan binary search
  6. Bubble sort dan insertion sort

Modul 6: Verifikasi dan translasi

Menengah

Trace table, off-by-one dan kesalahan logika, kompleksitas waktu dan ruang, menerjemahkan ke Python, adaptasi ke bahasa bertipe kuat, dan standar dokumentasi.

  1. Trace table
  2. Off-by-one dan kesalahan logika
  3. Kompleksitas waktu dan ruang
  4. Menerjemahkan pseudocode ke Python
  5. Adaptasi ke bahasa bertipe kuat
  6. Standar dokumentasi dan keterbacaan
