Data tidak seimbang: class_weight, oversampling, dan metrik yang jujur

Buka versi interaktif

Di banyak masalah nyata kelas penting sangat jarang: penipuan 1%, gagal bayar 5%, pasien kembali dirawat 10%. Model yang selalu menebak "tidak" sudah mendapat akurasi 95% tetapi tidak berguna. Karena itu akurasi menyesatkan; pakai precision, recall, F1, dan PR-AUC (average precision).

Tiga cara menangani: (1) class_weight="balanced" agar kesalahan pada kelas langka dihukum lebih berat (paling sederhana, tanpa mengubah data); (2) resampling data latih: oversampling kelas langka (acak atau SMOTE dari pustaka imbalanced-learn) atau undersampling kelas mayoritas; (3) menggeser ambang keputusan sesuai biaya.

Aturan wajib: resampling hanya pada data latih, tidak pernah pada data uji, karena data uji harus mencerminkan dunia nyata. Gunakan stratify=y saat membagi data agar proporsi kelas langka sama di latih dan uji.

PYTHON
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.utils import resample
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, average_precision_score

rng = np.random.default_rng(5)
n = 4000
X = pd.DataFrame({'telat_bayar': rng.poisson(0.6, n), 'rasio_utang': rng.beta(2, 5, n), 'lama_kerja': rng.integers(0, 20, n)})
logit = -4.4 + 0.9 * X['telat_bayar'] + 3.0 * X['rasio_utang'] - 0.05 * X['lama_kerja']
y = (rng.random(n) < 1 / (1 + np.exp(-logit))).astype(int)
print(f'proporsi gagal bayar: {y.mean():.1%}')
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)

def nilai(nama, model, Xl, yl):
    model.fit(Xl, yl)
    p = model.predict(X_te)
    ap = average_precision_score(y_te, model.predict_proba(X_te)[:, 1])
    print(f'{nama:22} akurasi={accuracy_score(y_te, p):.3f} precision={precision_score(y_te, p, zero_division=0):.2f} '
          f'recall={recall_score(y_te, p):.2f} F1={f1_score(y_te, p):.2f} PR-AUC={ap:.3f}')

nilai('tanpa penanganan', LogisticRegression(max_iter=1000), X_tr, y_tr)
nilai('class_weight=balanced', LogisticRegression(max_iter=1000, class_weight='balanced'), X_tr, y_tr)

latih = X_tr.assign(y=y_tr)
langka = latih[latih.y == 1]
banyak = latih[latih.y == 0]
naik = pd.concat([banyak, resample(langka, n_samples=len(banyak), replace=True, random_state=0)])
nilai('oversampling (latih)', LogisticRegression(max_iter=1000), naik.drop(columns='y'), naik['y'])

Poin penting

  • Kelas langka: akurasi menyesatkan.
  • Pakai precision, recall, F1, PR-AUC.
  • class_weight, resampling (hanya data latih), atau geser ambang.
  • stratify=y saat split.
