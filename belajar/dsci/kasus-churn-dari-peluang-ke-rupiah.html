Kasus churn: dari peluang ke rupiah

Buka versi interaktif

Tim retensi punya anggaran kampanye: setiap pelanggan yang dihubungi diberi voucher Rp50.000. Jika pelanggan yang hampir churn berhasil ditahan, perusahaan mempertahankan margin sekitar Rp600.000 per tahun, tetapi tidak semua yang dihubungi mau bertahan (misalnya 35% berhasil).

Dengan peluang churn dari model, nilai harapan menghubungi satu pelanggan = p_churn × tingkat_berhasil × nilai_pelanggan − biaya. Urutkan pelanggan dari peluang tertinggi, lalu jumlahkan nilai harapan untuk setiap ukuran kampanye. Titik puncak kurva laba menunjukkan berapa banyak pelanggan yang layak dihubungi.

Bandingkan dengan dua strategi patokan: menghubungi semua orang dan memilih acak. Angka yang dibawa ke rapat bukan "AUC 0,78", melainkan "menghubungi 25% pelanggan teratas memberi laba bersih Rp X, Y kali lipat dibanding acak".

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_predict

X = df[['umur', 'lama_bulan', 'belanja_bln', 'keluhan']]
p = cross_val_predict(LogisticRegression(max_iter=1000), X, df['churn'], cv=5, method='predict_proba')[:, 1]

biaya, berhasil, nilai = 50_000, 0.35, 600_000
urut = np.sort(p)[::-1]
laba_kum = np.cumsum(urut * berhasil * nilai - biaya)
porsi = np.arange(1, len(urut) + 1) / len(urut)
terbaik = laba_kum.argmax()
acak = porsi * len(p) * (df['churn'].mean() * berhasil * nilai - biaya)

print(f'hubungi semua : Rp{laba_kum[-1]:,.0f}')
print(f'hubungi {porsi[terbaik]:.0%} teratas ({terbaik + 1} orang): Rp{laba_kum[terbaik]:,.0f}')
print(f'acak dengan jumlah sama: Rp{acak[terbaik]:,.0f}')

plt.figure(figsize=(6.2, 3.4))
plt.plot(porsi, laba_kum / 1e6, label='urut menurut model')
plt.plot(porsi, acak / 1e6, '--', color='gray', label='acak')
plt.axvline(porsi[terbaik], color='tab:red', linewidth=1)
plt.xlabel('porsi pelanggan dihubungi'); plt.ylabel('laba bersih (juta Rp)')
plt.title('Kurva laba kampanye retensi'); plt.legend()
KELUARAN
hubungi semua : Rp908,920
hubungi 40% teratas (121 orang): Rp6,604,691
acak dengan jumlah sama: Rp302,500

Poin penting

  • Nilai harapan = p × berhasil × nilai − biaya.
  • Kurva laba menunjukkan ukuran kampanye terbaik.
  • Selalu bandingkan dengan acak dan "hubungi semua".

Cek pemahaman

p churn 0,4, tingkat berhasil 35%, nilai pelanggan Rp600.000, biaya Rp50.000. Nilai harapan menghubungi?

Jawaban: Rp34.000

0,4 × 0,35 × 600.000 − 50.000 = 34.000.

Kenapa laba turun jika semua pelanggan dihubungi?

Jawaban: Pelanggan berpeluang churn rendah tetap memakan biaya voucher

Nilai harapan negatif di bagian bawah daftar.
