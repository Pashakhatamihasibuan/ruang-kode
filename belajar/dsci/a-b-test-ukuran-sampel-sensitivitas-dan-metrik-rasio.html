A/B test: ukuran sampel, sensitivitas, dan metrik rasio

Buka versi interaktif

A/B test membagi pengguna secara acak ke versi A (kontrol) dan B (perubahan), lalu membandingkan metrik. Tentukan sebelum mulai: metrik utama, efek minimum yang berarti, dan ukuran sampel. Jangan mengintip lalu berhenti saat hasil "kebetulan" signifikan.

Menaikkan sensitivitas tanpa menambah pengguna: pakai metrik dengan varians lebih kecil, buang outlier ekstrem, atau CUPED (mengurangi variasi memakai data sebelum eksperimen).

Metrik rasio seperti "pendapatan per sesi" punya jebakan: unit acak (pengguna) berbeda dengan unit metrik (sesi), jadi variansnya perlu dihitung dengan delta method atau bootstrap per pengguna, bukan rumus biasa.

PYTHON
import numpy as np
from scipy import stats

def n_per_grup(p0, naik, alpha=0.05, power=0.8):
    p1 = p0 + naik
    za, zb = stats.norm.ppf(1 - alpha / 2), stats.norm.ppf(power)
    pb = (p0 + p1) / 2
    return int(np.ceil((za * np.sqrt(2 * pb * (1 - pb)) + zb * np.sqrt(p0 * (1 - p0) + p1 * (1 - p1))) ** 2 / naik ** 2))

print('Konversi 5% -> 6% butuh', n_per_grup(0.05, 0.01), 'pengguna per grup')
print('Konversi 5% -> 5.5% butuh', n_per_grup(0.05, 0.005), 'pengguna per grup')

# hasil eksperimen
konv = np.array([480, 552]); n = np.array([9000, 9000])
p = konv / n
pool = konv.sum() / n.sum()
z = (p[1] - p[0]) / np.sqrt(pool * (1 - pool) * (2 / 9000))
print(f'A {p[0]:.2%}, B {p[1]:.2%}, z = {z:.2f}, p = {2 * (1 - stats.norm.cdf(abs(z))):.4f}')
KELUARAN
Konversi 5% -> 6% butuh 8158 pengguna per grup
Konversi 5% -> 5.5% butuh 31234 pengguna per grup
A 5.33%, B 6.13%, z = 2.31, p = 0.0210

Poin penting

  • Tentukan metrik, efek minimum, dan ukuran sampel di awal.
  • Efek kecil butuh sampel jauh lebih besar.
  • Metrik rasio butuh delta method atau bootstrap.
