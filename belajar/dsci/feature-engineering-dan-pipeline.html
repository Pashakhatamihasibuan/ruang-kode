Feature engineering dan Pipeline

Buka versi interaktif

Model hanya sepandai fiturnya. Feature engineering membuat fitur yang lebih bermakna: rasio (keluhan per bulan berlangganan), kelompok umur, hari dalam minggu dari tanggal, atau jumlah transaksi 30 hari terakhir.

Kolom kategori seperti kota diubah menjadi angka dengan one-hot encoding. Kolom angka diskalakan dengan StandardScaler. ColumnTransformer menerapkan langkah berbeda ke kolom berbeda, dan Pipeline merangkai pra-pemrosesan dengan model menjadi satu objek.

Keuntungan Pipeline: tidak ada kebocoran data saat cross-validation, dan seluruh proses bisa disimpan sebagai satu berkas untuk dipakai di produksi. Perhatikan juga hasilnya: tidak semua fitur baru menaikkan skor. Selalu ukur, jangan menebak.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score

df['keluhan_per_bln'] = df['keluhan'] / df['lama_bulan']
df['baru'] = (df['lama_bulan'] <= 6).astype(int)

def buat_pipe(angka, kategori):
    langkah = [('angka', StandardScaler(), angka)]
    if kategori:
        langkah.append(('kat', OneHotEncoder(handle_unknown='ignore'), kategori))
    return Pipeline([('pra', ColumnTransformer(langkah)), ('model', LogisticRegression(max_iter=1000))])

dasar = ['umur', 'lama_bulan', 'belanja_bln', 'keluhan']
for nama, angka, kat in [('fitur dasar', dasar, []),
                         ('+ kota (one-hot)', dasar, ['kota']),
                         ('+ pelanggan baru', dasar + ['baru'], ['kota']),
                         ('+ keluhan/bulan', dasar + ['baru', 'keluhan_per_bln'], ['kota'])]:
    s = cross_val_score(buat_pipe(angka, kat), df, df['churn'], cv=5, scoring='roc_auc')
    print(f'{nama:18}: AUC {s.mean():.3f}')

pipe = buat_pipe(dasar + ['baru'], ['kota']).fit(df, df['churn'])
print(pipe.named_steps['pra'].get_feature_names_out())

Poin penting

  • Fitur bermakna sering lebih berpengaruh daripada model rumit.
  • One-hot untuk kategori, scaler untuk angka.
  • Pipeline mencegah kebocoran dan mudah disimpan.
