Empat tujuan grafik: perbandingan, distribusi, hubungan, dan komposisi

Buka versi interaktif

Pilih grafik dari pertanyaannya, bukan dari selera. Hampir semua pertanyaan masuk ke salah satu dari empat tujuan: perbandingan (kategori mana yang lebih besar, bagaimana berubah dari waktu ke waktu), distribusi (bagaimana sebaran nilai), hubungan (apakah dua variabel bergerak bersama), dan komposisi (bagian dari keseluruhan).

Pasangan yang aman: perbandingan → batang (kategori) atau garis (waktu); distribusi → histogram atau box plot; hubungan → scatter (dan heatmap korelasi untuk banyak variabel); komposisi → batang bertumpuk 100%. Pie chart hanya layak untuk 2–3 bagian; lebih dari itu mata manusia sulit membandingkan sudut.

Aturan yang dipakai tim data profesional: judul berupa kesimpulan ("Churn tertinggi di Medan"), bukan nama variabel; urutkan batang; mulai sumbu batang dari nol; dan beri warna menonjol hanya pada hal yang ingin disorot.

Memilih grafik dari tujuan
TujuanPertanyaanGrafik yang aman
PerbandinganMana yang lebih besar? Bagaimana tren?Batang terurut, garis untuk waktu
DistribusiBagaimana sebarannya? Ada outlier?Histogram, box plot

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
import matplotlib.pyplot as plt

df['segmen'] = pd.cut(df['lama_bulan'], [0, 6, 24, 48], labels=['baru', 'menengah', 'setia'])
fig, ax = plt.subplots(2, 2, figsize=(9, 6))

# perbandingan
rata = df.groupby('kota')['belanja_bln'].mean().sort_values()
ax[0, 0].barh(rata.index, rata.values, color='tab:gray')
ax[0, 0].set_title('Perbandingan: belanja rata-rata per kota')

# distribusi
data_box = [df.loc[df.churn == c, 'lama_bulan'] for c in (0, 1)]
ax[0, 1].boxplot(data_box)
ax[0, 1].set_xticks([1, 2], ['bertahan', 'churn'])
ax[0, 1].set_title('Distribusi: lama berlangganan')

# hubungan
ax[1, 0].scatter(df['lama_bulan'], df['belanja_bln'], c=df['churn'], cmap='coolwarm', s=10)
ax[1, 0].set_xlabel('lama (bulan)'); ax[1, 0].set_ylabel('belanja')
ax[1, 0].set_title('Hubungan: lama vs belanja (merah = churn)')

# komposisi
komp = pd.crosstab(df['segmen'], df['churn'], normalize='index') * 100
ax[1, 1].bar(komp.index.astype(str), komp[0], label='bertahan', color='tab:blue')
ax[1, 1].bar(komp.index.astype(str), komp[1], bottom=komp[0], label='churn', color='tab:red')
ax[1, 1].set_title('Komposisi: % churn per segmen'); ax[1, 1].legend(loc='lower right')
fig.tight_layout()
print(komp.round(1))

Poin penting

  • Empat tujuan: perbandingan, distribusi, hubungan, komposisi.
  • Judul grafik = kesimpulan.
  • Pie hanya untuk 2-3 bagian.
  • Sorot satu hal dengan warna.
