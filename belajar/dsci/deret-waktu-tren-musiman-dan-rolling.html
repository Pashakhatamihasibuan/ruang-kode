Deret waktu: tren, musiman, dan rolling

Buka versi interaktif

Deret waktu adalah data yang diukur berurutan menurut waktu: penjualan harian, suhu per jam, jumlah pengguna per minggu. Biasanya terdiri dari tren (naik/turun jangka panjang), musiman (pola berulang, misalnya ramai di akhir pekan), dan sisa acak.

Di pandas, jadikan tanggal sebagai indeks (DatetimeIndex), lalu resample("W") untuk merangkum per minggu dan rolling(7).mean() untuk rata-rata bergerak yang meredam naik-turun harian.

Peramalan sederhana yang sering jadi patokan: naive (besok = hari ini), rata-rata musiman, dan rata-rata bergerak. Model canggih seperti ARIMA atau Prophet harus bisa mengalahkan patokan ini, kalau tidak, pakai yang sederhana.

PYTHON
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(2)
tgl = pd.date_range('2026-01-01', periods=120, freq='D')
tren = np.linspace(100, 160, 120)
musim = np.where(tgl.dayofweek >= 5, 35, 0)       # Sabtu-Minggu ramai
jual = pd.Series(tren + musim + rng.normal(0, 8, 120), index=tgl).round()

print(jual.resample('ME').sum().astype(int))
print('Rata-rata per hari:')
print(jual.groupby(jual.index.day_name()).mean().round(1).sort_values())

plt.figure(figsize=(7, 3.2))
plt.plot(jual, color='lightgray', label='harian')
plt.plot(jual.rolling(7).mean(), color='tab:blue', label='rata-rata 7 hari')
plt.title('Penjualan harian: tren naik + ramai akhir pekan'); plt.legend()
