Karier data scientist 2026-2030: peran, portofolio, dan wawancara

Buka versi interaktif

Lowongan "data scientist" kini terbagi menjadi beberapa peran: product/analytics data scientist (eksperimen, metrik, SQL kuat), ML/applied scientist (membangun model prediksi), ML engineer/MLOps (membawa model ke produksi), dan AI engineer (membangun aplikasi di atas LLM: RAG, evaluasi, agen). Fondasinya sama: Python, SQL, statistik, dan kemampuan menerjemahkan masalah bisnis.

Portofolio yang dilirik perekrut: 3–4 proyek yang menyelesaikan masalah bisnis nyata dari awal sampai akhir, masing-masing dengan README yang menjelaskan masalah, data, pendekatan, hasil dalam angka bisnis, dan batasan; kode rapi dalam repositori (bukan satu notebook panjang); dan minimal satu model yang bisa dicoba (API atau aplikasi kecil). Kualitas lebih penting daripada jumlah.

Tahap wawancara yang umum: penyaringan CV, tes SQL dan Python, statistik dan eksperimen (A/B test), studi kasus ML ("bagaimana kamu membangun model deteksi penipuan?"), take-home project atau presentasi, lalu wawancara perilaku. Latih menjelaskan proyekmu dengan struktur masalah → pendekatan → hasil → apa yang akan kamu lakukan berbeda.

CONTOH
Rencana 90 hari menuju lamaran pertama

Bulan 1  Fondasi
  - Python, pandas, SQL: 30 menit latihan setiap hari
  - Statistik: uji hipotesis, selang kepercayaan, A/B test

Bulan 2  Proyek end-to-end
  - 2 studi kasus (klasifikasi + regresi) dengan 6 langkah:
    pemahaman bisnis, pembersihan, EDA, persiapan, model, kesimpulan bisnis
  - README berisi angka bisnis, bukan hanya akurasi

Bulan 3  Produksi dan lamaran
  - 1 model disajikan lewat API + Docker, dipantau driftnya
  - Profil GitHub dan LinkedIn rapi, 3 proyek tersemat
  - Latihan wawancara: SQL, statistik, studi kasus ML, presentasi 10 menit

Poin penting

  • Peran: analytics DS, applied scientist, ML engineer, AI engineer.
  • Portofolio: 3-4 proyek end-to-end dengan angka bisnis.
  • Wawancara: SQL, statistik, studi kasus ML, presentasi.
