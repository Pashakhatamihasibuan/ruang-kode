Proyek: memprediksi pelanggan yang akan churn

Buka versi interaktif

Proyek akhir merangkai semuanya untuk tim retensi toko online: pertanyaan (siapa yang perlu dihubungi bulan ini?), EDA, fitur, model dengan Pipeline dan cross-validation, ambang sesuai anggaran, lalu rekomendasi.

Misalkan tim hanya sanggup menghubungi 20% pelanggan. Urutkan pelanggan dari peluang churn tertinggi, ambil 20% teratas, lalu ukur berapa persen pelanggan churn yang tertangkap (recall@20%) dibandingkan memilih acak.

Kembangkan sendiri: tambahkan fitur, bandingkan model boosting, buat grafik lift, simpan Pipeline, lalu tulis ringkasan satu halaman untuk manajer: masalah, pendekatan, hasil dalam angka bisnis, dan risiko.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
import matplotlib.pyplot as plt
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_predict

df['keluhan_per_bln'] = df['keluhan'] / df['lama_bulan']
angka = ['umur', 'lama_bulan', 'belanja_bln', 'keluhan', 'keluhan_per_bln']
pipe = Pipeline([('pra', ColumnTransformer([('a', StandardScaler(), angka), ('k', OneHotEncoder(), ['kota'])])),
                 ('m', LogisticRegression(max_iter=1000))])
peluang = cross_val_predict(pipe, df[angka + ['kota']], df['churn'], cv=5, method='predict_proba')[:, 1]

urut = df.assign(p=peluang).sort_values('p', ascending=False)
top = urut.head(int(len(df) * 0.2))
recall = top['churn'].sum() / df['churn'].sum()
print(f'Churn total: {df.churn.sum()} pelanggan ({df.churn.mean():.0%})')
print(f'Hubungi 20% teratas -> menangkap {recall:.0%} pelanggan churn (acak: 20%)')

tangkap = urut['churn'].cumsum() / df['churn'].sum()
plt.figure(figsize=(5.6, 3.4))
plt.plot(np.arange(1, len(df) + 1) / len(df), tangkap, label='model')
plt.plot([0, 1], [0, 1], '--', color='gray', label='acak')
plt.axvline(0.2, color='tab:red', linewidth=1)
plt.xlabel('porsi pelanggan dihubungi'); plt.ylabel('porsi churn tertangkap')
plt.title('Kurva gain: model vs acak'); plt.legend()
KELUARAN
Churn total: 75 pelanggan (25%)
Hubungi 20% teratas -> menangkap 44% pelanggan churn (acak: 20%)

Poin penting

  • Mulai dari keputusan bisnis, bukan dari model.
  • Ukur hasil dengan angka yang dipahami bisnis (recall@20%).
  • Akhiri dengan rekomendasi dan risiko yang jelas.
