Uji hipotesis dan p-value

Buka versi interaktif

Uji hipotesis menjawab: "apakah perbedaan ini nyata atau hanya kebetulan sampling?" Kita mulai dari H0 (tidak ada beda) lalu menghitung p-value: peluang melihat perbedaan sebesar ini jika H0 benar.

Jika p-value lebih kecil dari ambang α (biasanya 0,05), kita menolak H0. p-value bukan peluang H0 benar, dan "tidak signifikan" bukan berarti "tidak ada beda": bisa jadi sampelnya terlalu kecil.

Uji yang sering dipakai: t-test (membandingkan dua rata-rata), uji proporsi / chi-square (membandingkan persentase, misalnya tingkat konversi), dan Mann-Whitney untuk data yang jauh dari normal. Selalu laporkan juga besar efeknya, bukan hanya p-value.

PYTHON
import numpy as np
from scipy import stats

rng = np.random.default_rng(10)
lama = rng.normal(52, 12, 80)   # menit belajar per hari, tampilan lama
baru = rng.normal(57, 12, 80)   # tampilan baru

t, p = stats.ttest_ind(baru, lama)
print(f'rata-rata lama {lama.mean():.1f}, baru {baru.mean():.1f}')
print(f't = {t:.2f}, p-value = {p:.4f}')
print('Tolak H0 (ada beda nyata)' if p < 0.05 else 'Belum cukup bukti')

d = (baru.mean() - lama.mean()) / np.sqrt((baru.var(ddof=1) + lama.var(ddof=1)) / 2)
print(f"besar efek (Cohen's d) = {d:.2f}")
KELUARAN
rata-rata lama 48.7, baru 55.7
t = 4.09, p-value = 0.0001
Tolak H0 (ada beda nyata)
besar efek (Cohen's d) = 0.65

Poin penting

  • H0: tidak ada beda. p-value: peluang data sekstrem ini jika H0 benar.
  • p < α → tolak H0.
  • Laporkan besar efek, bukan hanya p-value.

Cek pemahaman

p-value = 0,03 artinya?

Jawaban: Jika tidak ada beda, data sekstrem ini muncul 3% kali

Definisi p-value bersyarat pada H0.
