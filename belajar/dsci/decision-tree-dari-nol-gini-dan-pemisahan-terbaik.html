Decision tree dari nol: Gini dan pemisahan terbaik

Buka versi interaktif

Decision tree memilih pertanyaan yang paling "memurnikan" kelompok. Ukuran ketidakmurnian yang umum adalah Gini: 1 − Σ pᵢ². Kelompok yang isinya satu kelas punya Gini 0; kelompok 50:50 punya Gini 0,5.

Untuk setiap fitur dan setiap kemungkinan ambang, hitung rata-rata Gini kedua sisi (ditimbang jumlah anggotanya). Pemisahan dengan Gini terkecil dipilih, lalu proses diulang di setiap cabang. Inilah yang dilakukan DecisionTreeClassifier.

Kode di bawah mencari pemisahan pertama secara manual, lalu membandingkannya dengan akar pohon scikit-learn. Hasilnya sama: scikit-learn menulis ambangnya sebagai titik tengah 2,5, yang setara dengan <= 2 karena jumlah keluhan selalu bilangan bulat.

PYTHON
import numpy as np
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(2)
keluhan = rng.poisson(1.5, 120)
lama = rng.integers(1, 36, 120)
churn = ((keluhan >= 3) | (lama <= 3)).astype(int) ^ (rng.random(120) < 0.1)
X = np.column_stack([keluhan, lama]); nama = ['keluhan', 'lama_bulan']

def gini(y):
    if len(y) == 0: return 0
    p = np.bincount(y, minlength=2) / len(y)
    return 1 - (p ** 2).sum()

print('Gini semua data:', round(gini(churn), 3))
terbaik = (9, None, None)
for f in range(2):
    for t in np.unique(X[:, f]):
        kiri, kanan = churn[X[:, f] <= t], churn[X[:, f] > t]
        g = (len(kiri) * gini(kiri) + len(kanan) * gini(kanan)) / len(churn)
        if g < terbaik[0]: terbaik = (g, f, t)
g, f, t = terbaik
print(f'pemisahan terbaik (manual): {nama[f]} <= {t}  -> Gini {g:.3f}')

pohon = DecisionTreeClassifier(max_depth=1).fit(X, churn)
print(f'akar pohon scikit-learn  : {nama[pohon.tree_.feature[0]]} <= {pohon.tree_.threshold[0]:.1f}')
KELUARAN
Gini semua data: 0.45
pemisahan terbaik (manual): keluhan <= 2  -> Gini 0.297
akar pohon scikit-learn  : keluhan <= 2.5

Poin penting

  • Gini = 1 − Σp²; 0 berarti murni.
  • Coba semua fitur dan ambang, ambil Gini tertimbang terkecil.
  • Ulangi di tiap cabang sampai batas kedalaman.
