Docker, CI/CD, dan memantau data drift

Buka versi interaktif

Docker membungkus kode, model, dan versi pustaka ke dalam satu image sehingga berjalan sama di laptop dan server. CI/CD (misalnya GitHub Actions) menjalankan tes otomatis setiap ada perubahan: tes kode, tes kualitas data, dan tes bahwa model baru tidak lebih buruk dari yang lama sebelum dipasang.

Setelah dipasang, model bisa menurun diam-diam karena dunia berubah: pelanggan baru berbeda dari data latih (data drift) atau hubungan fitur-target berubah (concept drift). Pantau sebaran fitur dan metrik bisnis secara rutin.

Ukuran drift yang populer: PSI (population stability index). Aturan praktis: PSI < 0,1 aman, 0,1–0,25 perlu diperhatikan, > 0,25 sebaiknya latih ulang. Alat yang sering dipakai: MLflow (pelacakan eksperimen dan registri model), Evidently (laporan drift), dan Airflow untuk jadwal latih ulang.

PYTHON
import numpy as np

def psi(lama, baru, bins=10):
    batas = np.percentile(lama, np.linspace(0, 100, bins + 1))
    batas[0], batas[-1] = -np.inf, np.inf
    a = np.histogram(lama, batas)[0] / len(lama)
    b = np.histogram(baru, batas)[0] / len(baru)
    a, b = np.clip(a, 1e-4, None), np.clip(b, 1e-4, None)
    return float(((b - a) * np.log(b / a)).sum())

rng = np.random.default_rng(0)
latih = rng.normal(350, 120, 5000)          # belanja saat model dilatih
for bulan, geser in [('Jan', 0), ('Feb', 15), ('Mar', 60), ('Apr', 120)]:
    sekarang = rng.normal(350 + geser, 120, 2000)
    nilai = psi(latih, sekarang)
    status = 'aman' if nilai < 0.1 else 'waspada' if nilai < 0.25 else 'LATIH ULANG'
    print(f'{bulan}: PSI={nilai:.3f}  {status}')

Poin penting

  • Docker = lingkungan yang sama di mana saja.
  • CI/CD menguji kode, data, dan kualitas model sebelum rilis.
  • Pantau drift (PSI) dan latih ulang saat perlu.

Cek pemahaman

PSI fitur belanja naik ke 0,4. Tindakan yang tepat?

Jawaban: Selidiki penyebabnya dan latih ulang model

PSI > 0,25 = pergeseran besar.
