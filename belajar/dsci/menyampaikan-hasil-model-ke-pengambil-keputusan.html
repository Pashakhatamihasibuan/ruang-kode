Menyampaikan hasil model ke pengambil keputusan

Buka versi interaktif

Hasil model baru bernilai jika dipahami dan dipakai. Struktur satu halaman yang umum dipakai di industri: (1) keputusan yang diminta, (2) temuan utama dalam angka bisnis, (3) bagaimana model bekerja dalam satu kalimat, (4) faktor yang paling berpengaruh, (5) risiko dan batasan, (6) langkah berikutnya. Mulai dari kesimpulan, bukan dari proses.

Untuk menjelaskan faktor berpengaruh, permutation importance adalah cara yang jujur dan bisa dipakai untuk model apa pun: acak satu kolom di data uji, lalu lihat seberapa besar skor model turun. Untuk penjelasan per orang ("kenapa pelanggan ini dinilai berisiko"), tim biasanya memakai SHAP.

Hindari jargon (ROC-AUC, log loss) di slide utama; taruh di lampiran. Sebutkan ketidakpastian dengan jujur ("perkiraan laba Rp120–180 juta"), dan sepakati cara memantau keberhasilan setelah model dipakai.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance
from sklearn.model_selection import train_test_split
from sklearn.metrics import roc_auc_score

X = df[['umur', 'lama_bulan', 'belanja_bln', 'keluhan']]; y = df['churn']
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
m = RandomForestClassifier(n_estimators=200, min_samples_leaf=5, random_state=0).fit(X_tr, y_tr)
imp = permutation_importance(m, X_te, y_te, scoring='roc_auc', n_repeats=20, random_state=0)
urut = sorted(zip(X.columns, imp.importances_mean), key=lambda x: -x[1])

nama = {'keluhan': 'jumlah keluhan', 'lama_bulan': 'lama berlangganan', 'belanja_bln': 'belanja bulanan', 'umur': 'umur'}
p = m.predict_proba(X_te)[:, 1]
atas = np.argsort(-p)[:int(len(p) * 0.2)]
tangkap = y_te.iloc[atas].sum() / y_te.sum()

print('RINGKASAN UNTUK TIM RETENSI')
print('1. Keputusan: siapa yang dihubungi dalam kampanye bulan depan.')
print(f'2. Temuan: menghubungi 20% pelanggan teratas menangkap {tangkap:.0%} pelanggan yang akan berhenti (acak: 20%).')
print('3. Cara kerja: model belajar dari riwayat pelanggan yang pernah berhenti.')
print('4. Faktor terkuat: ' + ', '.join(nama[f] for f, v in urut[:2] if v > 0) + '.')
print('5. Risiko: data hanya 300 pelanggan; pantau hasil kampanye sebelum diperluas.')
print('6. Berikutnya: uji coba A/B kampanye pada 2 kota selama 4 minggu.')
print(f'[lampiran] ROC-AUC uji = {roc_auc_score(y_te, p):.3f}; importance:', {f: round(float(v), 3) for f, v in urut})
KELUARAN
