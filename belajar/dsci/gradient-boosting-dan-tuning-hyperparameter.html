Gradient boosting dan tuning hyperparameter

Buka versi interaktif

Gradient boosting membangun pohon kecil satu per satu; setiap pohon baru belajar memperbaiki kesalahan pohon-pohon sebelumnya. Untuk data tabel, boosting (XGBoost, LightGBM, CatBoost, atau HistGradientBoosting di scikit-learn) sering menjadi model terkuat.

Hyperparameter adalah pengaturan yang dipilih sebelum belajar: jumlah pohon, kedalaman, learning rate. Cari kombinasi terbaik dengan GridSearchCV (coba semua) atau RandomizedSearchCV (coba acak, lebih hemat), selalu dengan cross-validation.

Jangan menyetel hyperparameter berdasarkan data test. Simpan data test sampai akhir sebagai ujian terakhir yang jujur.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.metrics import roc_auc_score

X = df[['umur', 'lama_bulan', 'belanja_bln', 'keluhan']]; y = df['churn']
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)

grid = GridSearchCV(HistGradientBoostingClassifier(random_state=0),
                    {'learning_rate': [0.03, 0.1], 'max_depth': [2, 3], 'max_iter': [100, 200]},
                    cv=4, scoring='roc_auc')
grid.fit(X_tr, y_tr)
print('terbaik:', grid.best_params_)
print('AUC cv  :', round(grid.best_score_, 3))
print('AUC test:', round(roc_auc_score(y_te, grid.predict_proba(X_te)[:, 1]), 3))
KELUARAN
terbaik: {'learning_rate': 0.03, 'max_depth': 2, 'max_iter': 100}
AUC cv  : 0.799
AUC test: 0.801

Poin penting

  • Boosting: pohon kecil berurutan memperbaiki kesalahan.
  • Tuning dengan GridSearchCV/RandomizedSearchCV + CV.
  • Data test hanya dipakai sekali di akhir.
