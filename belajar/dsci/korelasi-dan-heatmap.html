Korelasi dan heatmap

Buka versi interaktif

Korelasi Pearson (−1 sampai 1) mengukur seberapa kuat dua variabel bergerak bersama secara linear. Dekat 1: naik bersama; dekat −1: satu naik yang lain turun; dekat 0: tidak ada hubungan linear (bisa saja ada hubungan melengkung).

df.corr(numeric_only=True) menghasilkan matriks korelasi, dan heatmap membuatnya mudah dibaca. Di tahap EDA, korelasi membantu memilih fitur yang mungkin berguna untuk model dan menemukan fitur yang saling kembar (multikolinearitas).

Ingat: korelasi bukan sebab-akibat, dan sangat peka terhadap outlier. Selalu lihat scatter plot-nya juga.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
import matplotlib.pyplot as plt

kor = df.drop(columns='kota').corr().round(2)
print(kor['churn'].sort_values())

fig, ax = plt.subplots(figsize=(5.2, 4.2))
im = ax.imshow(kor, cmap='RdBu_r', vmin=-1, vmax=1)
ax.set_xticks(range(len(kor)), kor.columns, rotation=45, ha='right')
ax.set_yticks(range(len(kor)), kor.columns)
for i in range(len(kor)):
    for j in range(len(kor)):
        ax.text(j, i, kor.iloc[i, j], ha='center', va='center', fontsize=8)
fig.colorbar(im)
ax.set_title('Matriks korelasi')

Poin penting

  • Korelasi −1..1 mengukur hubungan linear.
  • Heatmap memudahkan membaca matriks korelasi.
  • Bukan sebab-akibat; cek scatter dan outlier.
