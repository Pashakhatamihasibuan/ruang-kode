K-Nearest Neighbors (KNN)

Buka versi interaktif

KNN tidak benar-benar "belajar". Ia menyimpan semua data latih, lalu untuk titik baru mencari k tetangga terdekat dan mengambil suara terbanyak (klasifikasi) atau rata-ratanya (regresi).

Nilai k mengatur kehalusan: k = 1 mengikuti setiap titik sehingga batasnya bergerigi dan mudah overfit; k besar lebih halus tetapi bisa mengabaikan pola kecil. Karena berbasis jarak, fitur wajib distandardisasi.

Kelemahannya: prediksi lambat untuk data besar (harus menghitung jarak ke semua titik) dan buruk jika fiturnya sangat banyak. Kelebihannya: sederhana, tanpa asumsi bentuk data.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import train_test_split

X, y = make_moons(300, noise=0.3, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, random_state=0)

# KNN dari nol untuk satu titik
titik = np.array([0.5, 0.2])
jarak = np.sqrt(((X_tr - titik) ** 2).sum(axis=1))
k5 = np.argsort(jarak)[:5]
print('5 tetangga terdekat punya label:', y_tr[k5], '-> tebak', np.bincount(y_tr[k5]).argmax())

xx, yy = np.meshgrid(np.linspace(-2, 3, 150), np.linspace(-1.5, 2, 150))
fig, ax = plt.subplots(1, 3, figsize=(9.6, 2.8))
for a, k in zip(ax, [1, 15, 100]):
    m = KNeighborsClassifier(k).fit(X_tr, y_tr)
    print(f'k={k:3}: akurasi latih={m.score(X_tr, y_tr):.2f}  uji={m.score(X_te, y_te):.2f}')
    a.contourf(xx, yy, m.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape), alpha=0.3, cmap='coolwarm')
    a.scatter(X_tr[:, 0], X_tr[:, 1], c=y_tr, s=8, cmap='coolwarm')
    a.set_title(f'k = {k}', fontsize=10); a.set_xticks([]); a.set_yticks([])
fig.tight_layout()
KELUARAN
5 tetangga terdekat punya label: [0 0 1 0 0] -> tebak 0
k=  1: akurasi latih=1.00  uji=0.88
k= 15: akurasi latih=0.94  uji=0.92
k=100: akurasi latih=0.84  uji=0.80

Poin penting

  • KNN: suara terbanyak dari k tetangga terdekat.
  • k kecil bergerigi (overfit), k besar halus.
  • Standardisasi fitur karena berbasis jarak.

Cek pemahaman

Kenapa akurasi latih KNN dengan k = 1 selalu 1,00?

Jawaban: Tetangga terdekat setiap titik latih adalah dirinya sendiri

Itu tanda menghafal, bukan belajar.
