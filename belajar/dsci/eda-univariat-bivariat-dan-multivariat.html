EDA univariat, bivariat, dan multivariat

Buka versi interaktif

Univariat: satu kolom pada satu waktu. Untuk angka lihat pusat, sebaran, kemiringan, dan outlier; untuk kategori lihat frekuensi dan kategori langka. Bivariat: hubungan dua kolom, terutama setiap fitur terhadap target, misalnya churn rate per kelompok lama berlangganan.

Multivariat: tiga kolom atau lebih sekaligus. Di sinilah pola yang tersembunyi muncul: churn tinggi di pelanggan baru, tetapi jauh lebih tinggi lagi pada pelanggan baru yang membayar manual. Alat yang sering dipakai: pd.crosstab atau pivot_table dua dimensi, lalu ditampilkan sebagai heatmap.

Tutup setiap EDA dengan daftar temuan yang bisa ditindaklanjuti: fitur yang menjanjikan untuk model, masalah data yang harus diperbaiki, dan hipotesis untuk diuji. EDA tanpa kesimpulan hanyalah kumpulan grafik.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
import matplotlib.pyplot as plt

rng2 = np.random.default_rng(3)
df['metode_bayar'] = np.where(rng2.random(len(df)) < 0.35 + 0.35 * df['churn'], 'transfer manual', 'autodebet')
df['kel_lama'] = pd.cut(df['lama_bulan'], [0, 6, 12, 24, 48], labels=['0-6', '7-12', '13-24', '25-48'])

# univariat
print('kemiringan belanja:', round(df['belanja_bln'].skew(), 2))
print(df['metode_bayar'].value_counts(normalize=True).round(2))

# bivariat: fitur vs target
print((df.groupby('kel_lama', observed=True)['churn'].mean() * 100).round(1))

# multivariat: lama x metode bayar -> churn rate
pv = df.pivot_table(index='kel_lama', columns='metode_bayar', values='churn', aggfunc='mean', observed=True) * 100
print(pv.round(1))

fig, ax = plt.subplots(figsize=(5.4, 3.4))
im = ax.imshow(pv.values, cmap='Reds', vmin=0, vmax=100)
ax.set_xticks(range(pv.shape[1]), pv.columns); ax.set_yticks(range(pv.shape[0]), pv.index)
for i in range(pv.shape[0]):
    for j in range(pv.shape[1]):
        ax.text(j, i, f'{pv.values[i, j]:.0f}%', ha='center', va='center')
ax.set_ylabel('lama berlangganan (bulan)')
ax.set_title('Churn tertinggi: pelanggan baru + transfer manual')
fig.colorbar(im)

Poin penting

  • Univariat: satu kolom. Bivariat: fitur vs target.
  • Multivariat: pivot dua dimensi + heatmap.
  • Akhiri EDA dengan temuan yang bisa ditindaklanjuti.
