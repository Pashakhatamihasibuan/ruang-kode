Matplotlib: grafik garis, batang, dan histogram

Buka versi interaktif

Matplotlib adalah pustaka grafik dasar Python; Seaborn dan grafik bawaan pandas dibangun di atasnya. Pola kerjanya: buat fig, ax = plt.subplots(), gambar di ax, lalu beri judul, label sumbu, dan legenda.

Pilih grafik dari pertanyaannya: garis untuk perubahan menurut waktu, batang untuk membandingkan kategori (urutkan dari besar ke kecil), histogram untuk melihat sebaran satu variabel.

Aturan yang membuat grafik jujur: sumbu batang mulai dari nol, judul menyatakan kesimpulan ("Churn tertinggi di Medan"), dan jangan memakai warna lebih dari yang perlu.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
import matplotlib.pyplot as plt

churn = (df.groupby('kota')['churn'].mean() * 100).sort_values(ascending=False)
print(churn.round(1))

fig, ax = plt.subplots(1, 2, figsize=(9, 3.2))
ax[0].bar(churn.index, churn.values, color=['tab:red'] + ['tab:gray'] * 3)
ax[0].set_title(f'Churn tertinggi di {churn.index[0]}')
ax[0].set_ylabel('% churn')
ax[1].hist(df['belanja_bln'], bins=25, color='tab:blue', edgecolor='white')
ax[1].set_title('Sebaran belanja per bulan')
ax[1].set_xlabel('ribu rupiah')
fig.tight_layout()

Poin penting

  • fig, ax = plt.subplots(), gambar di ax.
  • Garis = waktu, batang = kategori, histogram = sebaran.
  • Judul berisi kesimpulan, batang mulai dari nol.
