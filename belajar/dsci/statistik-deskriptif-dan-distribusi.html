Statistik deskriptif dan distribusi

Buka versi interaktif

Sebelum membuat model, rangkum data: pusat (rata-rata, median), sebaran (simpangan baku, IQR), dan bentuk (simetris atau miring). Rata-rata mudah tertarik oleh nilai ekstrem; median lebih tahan.

Data penghasilan, harga rumah, dan waktu tunggu biasanya miring ke kanan: banyak nilai kecil, sedikit nilai sangat besar. Pada data seperti ini rata-rata lebih besar dari median, dan histogram adalah cara tercepat untuk melihatnya.

Distribusi yang sering muncul: normal (tinggi badan, galat pengukuran), binomial (jumlah sukses dari n percobaan), Poisson (jumlah kejadian per waktu, misalnya keluhan per bulan), dan eksponensial (waktu antar kejadian).

PYTHON
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
gaji = rng.lognormal(mean=8.4, sigma=0.5, size=1000).round(-1)  # ribu rupiah
print('rata-rata :', round(gaji.mean()))
print('median    :', round(np.median(gaji)))
print('std       :', round(gaji.std()))
q1, q3 = np.percentile(gaji, [25, 75])
print('IQR       :', round(q3 - q1))

plt.figure(figsize=(6, 3.2))
plt.hist(gaji, bins=40, color='tab:blue', edgecolor='white')
plt.axvline(gaji.mean(), color='tab:red', label='rata-rata')
plt.axvline(np.median(gaji), color='black', linestyle='--', label='median')
plt.title('Gaji miring ke kanan: rata-rata > median')
plt.xlabel('gaji (ribu)'); plt.legend()
KELUARAN
rata-rata : 4891
median    : 4375
std       : 2620
IQR       : 2938

Poin penting

  • Pusat, sebaran, bentuk.
  • Data miring kanan: rata-rata > median.
  • Kenali distribusi normal, binomial, Poisson, eksponensial.
