Vektor, matriks, dan perkalian matriks

Buka versi interaktif

Dalam machine learning, satu baris data adalah vektor (daftar fitur), dan seluruh dataset adalah matriks X berukuran n baris × p fitur. Model linear menghitung prediksi dengan perkalian matriks: ŷ = X · w + b, dengan w berisi bobot setiap fitur.

Dot product dua vektor = jumlah perkalian elemen yang berpasangan. Ia juga mengukur seberapa searah dua vektor; dibagi panjang keduanya menjadi cosine similarity, dasar sistem rekomendasi dan pencarian teks.

Aturan bentuk: matriks (n × p) dikali (p × k) menghasilkan (n × k). Jumlah kolom matriks kiri harus sama dengan jumlah baris matriks kanan; di NumPy operatornya @.

PYTHON
import numpy as np

# 3 rumah x 2 fitur: luas (m2), jumlah kamar
X = np.array([[60, 2],
              [90, 3],
              [120, 4]])
w = np.array([5.0, 40.0])   # juta per m2, juta per kamar
b = 100
print('Prediksi harga (juta):', X @ w + b)
print('Bentuk:', X.shape, '@', w.shape, '->', (X @ w).shape)

a = np.array([1, 2, 3]); c = np.array([2, 4, 6.5])
cos = a @ c / (np.linalg.norm(a) * np.linalg.norm(c))
print('cosine similarity:', round(cos, 4))
KELUARAN
Prediksi harga (juta): [480. 670. 860.]
Bentuk: (3, 2) @ (2,) -> (3,)
cosine similarity: 0.9993

Poin penting

  • Data = matriks, satu baris = vektor fitur.
  • Model linear: ŷ = X·w + b.
  • (n×p) @ (p×k) = (n×k).
