Feature engineering: membuat variabel baru yang bermakna

Buka versi interaktif

Feature engineering mengubah data mentah menjadi sinyal yang lebih mudah dipelajari model. Jenis yang paling sering: rasio (keluhan per bulan), kelompok (lama berlangganan dijadikan rentang), bagian tanggal (hari dalam minggu, jam, apakah tanggal gajian), penanda (is_new, is_weekend), dan agregat dari tabel transaksi (frekuensi, total, dan jarak hari sejak transaksi terakhir, atau RFM).

Fitur yang baik lahir dari pemahaman bisnis: "pelanggan yang lama tidak bertransaksi cenderung pergi" menjadi fitur hari_sejak_terakhir. Uji cepat setiap fitur baru dengan melihat hubungannya ke target (churn rate per kelompok), lalu pastikan lewat validasi silang.

Bahaya terbesarnya adalah kebocoran data: fitur yang memakai informasi setelah titik prediksi, misalnya "jumlah tiket pembatalan" yang baru ada setelah pelanggan memutuskan pergi. Selalu tetapkan tanggal potong dan hitung fitur hanya dari data sebelum tanggal itu.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(11)
trx = pd.DataFrame({
    'id': rng.integers(1, 7, 40),
    'tanggal': pd.Timestamp('2026-01-01') + pd.to_timedelta(rng.integers(0, 150, 40), unit='D'),
    'nilai': rng.gamma(3, 40_000, 40).round(-3),
})
potong = pd.Timestamp('2026-05-01')                   # titik prediksi
lalu = trx[trx['tanggal'] < potong]                   # hanya data SEBELUM tanggal potong

fitur = (lalu.groupby('id')
             .agg(frekuensi=('nilai', 'size'), total=('nilai', 'sum'), terakhir=('tanggal', 'max'))
             .assign(hari_sejak_terakhir=lambda d: (potong - d['terakhir']).dt.days,
                     rata_per_trx=lambda d: (d['total'] / d['frekuensi']).round(-2),
                     tidak_aktif_30=lambda d: (d['hari_sejak_terakhir'] > 30).astype(int))
             .drop(columns='terakhir'))
print(fitur)

lalu = lalu.assign(hari=lalu['tanggal'].dt.day_name(), akhir_pekan=lalu['tanggal'].dt.dayofweek >= 5)
print(lalu.groupby('akhir_pekan')['nilai'].mean().round(-2))
print('transaksi setelah tanggal potong (tidak boleh dipakai sebagai fitur):', (trx['tanggal'] >= potong).sum())

Soal latihan

  1. Dari DataFrame pd.DataFrame({"belanja": [300, 120, 900], "lama_bulan": [10, 2, 30]}), buat kolom belanja_per_bulan_langganan (belanja dibagi lama_bulan, dibulatkan 1 desimal) dan kolom baru (1 jika lama_bulan ≤ 6).

    Petunjuk

    Pakai assign atau operasi kolom langsung.

    Lihat jawaban
    PYTHON
    import pandas as pd
df = pd.DataFrame({'belanja': [300, 120, 900], 'lama_bulan': [10, 2, 30]})
df['belanja_per_bulan_langganan'] = (df['belanja'] / df['lama_bulan']).round(1)
df['baru'] = (df['lama_bulan'] <= 6).astype(int)
print(df.to_string(index=False))

Poin penting

  • Jenis fitur: rasio, kelompok, bagian tanggal, penanda, agregat (RFM).
  • Fitur baik berasal dari pemahaman bisnis.
  • Tetapkan tanggal potong untuk mencegah kebocoran data.
