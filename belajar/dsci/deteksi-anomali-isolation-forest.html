Deteksi anomali: Isolation Forest

Buka versi interaktif

Anomali adalah data yang sangat berbeda dari kebanyakan: transaksi kartu kredit mencurigakan, sensor mesin yang tidak wajar, login dari pola aneh. Biasanya labelnya hampir tidak ada, jadi dipakai pendekatan unsupervised.

Isolation Forest membuat pohon acak yang memotong data secara acak. Titik normal berada di kerumunan sehingga butuh banyak potongan untuk diisolasi; titik anomali terpencil sehingga terisolasi dalam sedikit potongan. Makin pendek jalurnya, makin anomali.

contamination adalah perkiraan proporsi anomali. Alternatif lain: skor-z sederhana, Local Outlier Factor, atau DBSCAN. Perhatikan hasilnya: transaksi 260 ribu pukul 3 pagi tidak tertangkap karena nominalnya wajar, dan ada satu transaksi normal yang ikut ditandai. Model anomali memberi daftar untuk diperiksa, bukan vonis.

PYTHON
import numpy as np
from sklearn.ensemble import IsolationForest

rng = np.random.default_rng(8)
normal = np.column_stack([rng.normal(250, 60, 500), rng.normal(14, 3, 500)])   # nominal (ribu), jam transaksi
aneh = np.array([[4800, 3], [3900, 2], [5200, 4], [260, 3], [3100, 14]])
X = np.vstack([normal, aneh])

iso = IsolationForest(contamination=0.01, random_state=0).fit(X)
label = iso.predict(X)            # -1 = anomali
skor = iso.score_samples(X)        # makin kecil makin aneh
print('jumlah ditandai anomali:', (label == -1).sum())
for i in np.argsort(skor)[:6]:
    print(f'nominal {X[i, 0]:6.0f} ribu, jam {X[i, 1]:4.1f} -> skor {skor[i]:.3f}', '(sisipan)' if i >= 500 else '')

Poin penting

  • Anomali = sangat berbeda dari mayoritas.
  • Isolation Forest: anomali cepat terisolasi.
  • contamination = perkiraan proporsi anomali.
