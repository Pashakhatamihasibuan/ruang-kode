Python inti untuk data: list, dict, kondisi, loop, dan fungsi

Buka versi interaktif

Sebelum pandas, kuasai lima bahan dasar Python yang dipakai setiap hari: list (daftar berurutan), dict (pasangan kunci-nilai, cocok untuk satu baris data), if/elif/else, for/while beserta break dan continue, serta fungsi dengan nilai bawaan (default). Satu transaksi biasanya disimpan sebagai dict, dan banyak transaksi sebagai list berisi dict.

Data scientist biasanya menulis kode di Jupyter Lab atau notebook di VS Code: kode dijalankan per sel, hasil dan grafik langsung tampil di bawahnya, dan sel Markdown dipakai untuk catatan. Kebiasaan yang dicari tim: jalankan ulang dari atas (Restart & Run All) sebelum dibagikan, beri judul tiap bagian, dan pindahkan fungsi yang sudah stabil ke berkas .py agar bisa diuji.

Contoh di bawah mengolah transaksi mentah tanpa pustaka apa pun: lewati transaksi batal dengan continue, berhenti saat bertemu penanda akhir data dengan break, lalu menghitung total per kota dengan dict. Pola ini persis yang nanti dikerjakan pandas dalam satu baris, jadi memahaminya membuat pandas terasa masuk akal.

PYTHON
transaksi = [
    {'kota': 'Medan', 'nilai': 120_000, 'status': 'selesai'},
    {'kota': 'Bandung', 'nilai': 85_000, 'status': 'batal'},
    {'kota': 'Medan', 'nilai': 64_000, 'status': 'selesai'},
    {'kota': 'Jakarta', 'nilai': 310_000, 'status': 'selesai'},
    {'kota': None, 'nilai': 0, 'status': 'AKHIR'},       # penanda akhir berkas
    {'kota': 'Bandung', 'nilai': 999_000, 'status': 'selesai'},
]

def kategori(nilai, batas_besar=200_000):
    """Kelompokkan nilai transaksi; batas bisa diubah lewat argumen."""
    if nilai >= batas_besar:
        return 'besar'
    elif nilai >= 80_000:
        return 'sedang'
    return 'kecil'

total_kota = {}
for t in transaksi:
    if t['status'] == 'AKHIR':
        break                      # data setelah penanda diabaikan
    if t['status'] != 'selesai':
        continue                   # lewati yang batal
    total_kota[t['kota']] = total_kota.get(t['kota'], 0) + t['nilai']
    print(f"{t['kota']:8} {t['nilai']:>8,}  {kategori(t['nilai'])}")

print(total_kota)
print('dengan batas 100 ribu:', [kategori(t['nilai'], batas_besar=100_000) for t in transaksi[:4]])
KELUARAN
Medan     120,000  sedang
Medan      64,000  kecil
Jakarta   310,000  besar
{'Medan': 184000, 'Jakarta': 310000}
dengan batas 100 ribu: ['besar', 'sedang', 'kecil', 'besar']

Soal latihan

  1. Buat fungsi faktorial(n) memakai loop for, lalu cetak hasil untuk n = 0, 1, 5, dan 10. Ingat 0! = 1.

    Petunjuk

    Mulai dari hasil = 1 lalu kalikan 2 sampai n.

    Lihat jawaban
    PYTHON
    def faktorial(n):
    hasil = 1
    for i in range(2, n + 1):
        hasil *= i
    return hasil

for n in [0, 1, 5, 10]:
    print(n, faktorial(n))
    KELUARAN
    0 1
1 1
5 120
10 3628800

  2. Dari list [12, 7, 0, 30, -1, 9], jumlahkan angka sampai bertemu -1 (penanda akhir) dan lewati angka 0.

    Petunjuk

    Pakai break untuk -1 dan continue untuk 0.

    Lihat jawaban
    PYTHON
    total = 0
for x in [12, 7, 0, 30, -1, 9]:
    if x == -1:
        break
    if x == 0:
        continue
    total += x
print(total)
    KELUARAN
    49

Poin penting

  • Satu baris data = dict, banyak baris = list berisi dict.
  • continue melewati satu putaran, break menghentikan loop.
  • Fungsi dengan nilai default membuat aturan bisnis mudah diubah.
  • Notebook: jalankan ulang dari atas sebelum dibagikan.

Cek pemahaman

Transaksi berstatus batal harus dilewati tetapi loop tetap berlanjut. Kata kunci yang tepat?

Jawaban: continue

continue melompat ke putaran berikutnya.

<code>kategori(150_000, batas_besar=100_000)</code> menghasilkan?

Jawaban: 'besar'

150 ribu ≥ batas 100 ribu.
