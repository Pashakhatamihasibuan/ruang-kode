Probabilitas, sampling, dan teorema limit pusat

Buka versi interaktif

Kita jarang punya data seluruh populasi; yang ada hanya sampel. Sampel harus diambil secara acak agar mewakili. Statistik dari sampel (misalnya rata-rata) selalu sedikit meleset dari nilai populasi; selisih wajar ini disebut galat sampling.

Teorema limit pusat (CLT): jika kita mengambil banyak sampel berukuran n lalu menghitung rata-ratanya, rata-rata itu membentuk distribusi normal, walaupun data aslinya tidak normal. Sebarannya mengecil sebesar σ / √n (standard error).

Inilah alasan kita bisa membuat selang kepercayaan dan uji hipotesis untuk rata-rata, bahkan pada data miring seperti waktu tunggu atau belanja.

PYTHON
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(3)
populasi = rng.exponential(scale=10, size=100_000)   # waktu tunggu (menit), sangat miring

fig, ax = plt.subplots(1, 3, figsize=(9, 2.8), sharey=False)
ax[0].hist(populasi, bins=50, color='gray'); ax[0].set_title('data asli')
for i, n in enumerate([5, 50]):
    rata = [rng.choice(populasi, n).mean() for _ in range(2000)]
    ax[i + 1].hist(rata, bins=40, color='tab:blue')
    ax[i + 1].set_title(f'rata-rata sampel n={n}')
    print(f'n={n:2}: std rata-rata = {np.std(rata):.2f}, teori σ/√n = {populasi.std() / np.sqrt(n):.2f}')
fig.tight_layout()
KELUARAN
n= 5: std rata-rata = 4.38, teori σ/√n = 4.47
n=50: std rata-rata = 1.40, teori σ/√n = 1.41

Poin penting

  • Sampel acak mewakili populasi.
  • CLT: rata-rata sampel mendekati normal.
  • Standard error = σ/√n mengecil saat n membesar.

Cek pemahaman

Jika ukuran sampel dinaikkan 4 kali, standard error menjadi?

Jawaban: Setengahnya

√4 = 2.
