Alur ML: fitur, target, dan train/test split

Buka versi interaktif

Machine learning terawasi (supervised) belajar dari contoh berlabel: fitur X (umur, lama berlangganan, belanja, keluhan) dan target y (churn atau tidak). Jika targetnya angka disebut regresi; jika kategori disebut klasifikasi.

Model harus dinilai pada data yang tidak pernah dilihat saat belajar. Karena itu data dibagi: train (biasanya 70–80%) untuk melatih dan test untuk menguji. stratify=y menjaga proporsi kelas sama di keduanya.

Semua model scikit-learn punya pola yang sama: model.fit(X_train, y_train) untuk belajar, model.predict(X_test) untuk menebak, lalu bandingkan dengan jawaban aslinya. Selalu bandingkan dengan patokan paling bodoh, misalnya selalu menebak "tidak churn". Lihat hasilnya: akurasi model sama dengan patokan karena 75% pelanggan memang tidak churn, tetapi AUC (kemampuan mengurutkan siapa yang paling berisiko) jauh lebih tinggi. Karena itu akurasi saja tidak cukup; metrik yang tepat dibahas dua pelajaran lagi.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score

X = df[['umur', 'lama_bulan', 'belanja_bln', 'keluhan']]
y = df['churn']
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
print('train:', X_tr.shape, ' test:', X_te.shape)
print('proporsi churn train/test:', round(y_tr.mean(), 3), round(y_te.mean(), 3))

patokan = DummyClassifier(strategy='most_frequent').fit(X_tr, y_tr)
model = LogisticRegression(max_iter=1000).fit(X_tr, y_tr)
print('akurasi patokan:', round(patokan.score(X_te, y_te), 3), ' AUC:', round(roc_auc_score(y_te, patokan.predict_proba(X_te)[:, 1]), 3))
print('akurasi model  :', round(model.score(X_te, y_te), 3), ' AUC:', round(roc_auc_score(y_te, model.predict_proba(X_te)[:, 1]), 3))

Poin penting

  • X = fitur, y = target; regresi vs klasifikasi.
  • Nilai model di data test yang tidak pernah dilihat.
  • Pola sklearn: fit, predict, score; bandingkan dengan patokan.
