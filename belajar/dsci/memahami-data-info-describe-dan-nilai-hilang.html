Memahami data: info, describe, dan nilai hilang

Buka versi interaktif

EDA (exploratory data analysis) adalah tahap "berkenalan" dengan data sebelum membangun model. Tiga pertanyaan pertama: apa saja kolomnya dan tipenya, apakah ada nilai hilang atau aneh, dan bagaimana sebaran tiap kolom.

df.info() menampilkan tipe dan jumlah nilai tidak kosong, df.describe() merangkum angka, df.isna().sum() menghitung nilai hilang per kolom, dan value_counts() menghitung kategori.

Keputusan menangani nilai hilang harus masuk akal secara bisnis: hapus baris jika sedikit dan acak, isi median untuk angka yang miring, isi kategori "Tidak diketahui", atau buat kolom penanda is_missing karena "data kosong" kadang justru informatif.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
df.loc[[3, 17, 42, 99], 'belanja_bln'] = np.nan   # anggap ada yang kosong

print(df.describe().round(1))
print(df.isna().sum())
print(df['kota'].value_counts())
med = df['belanja_bln'].median()
df['belanja_bln'] = df['belanja_bln'].fillna(med)
print('Diisi median:', med, '| sisa kosong:', df['belanja_bln'].isna().sum())

Soal latihan

  1. Dari data pelanggan, hitung persentase churn per kota (dibulatkan 1 desimal).

    Petunjuk

    groupby('kota')['churn'].mean() lalu kali 100.

    Lihat jawaban
    PYTHON
    import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
