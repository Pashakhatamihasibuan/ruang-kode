Peta ML dan persiapan data sebelum model

Buka versi interaktif

Dua pertanyaan menentukan jenis masalah. Ada target (label) atau tidak? Jika ada, itu supervised learning; jika tidak (misalnya mengelompokkan pelanggan), itu unsupervised. Targetnya angka atau kelas? Angka (harga, jumlah) berarti regresi; kelas (churn ya/tidak, jenis penyakit) berarti klasifikasi.

Persiapan sebelum model: kategori diubah menjadi angka (one-hot untuk kategori tanpa urutan seperti kota, ordinal untuk yang berurutan seperti Basic < Standar < Premium), fitur angka diskalakan untuk model berbasis jarak atau gradien (logistic regression, KNN, SVM), lalu data dibagi latih dan uji.

Urutannya penting: bagi data dulu, baru pelajari skala dan encoding dari data latih saja. Jika StandardScaler di-fit pada seluruh data, statistik data uji ikut bocor ke model. Cara aman dan standar industri adalah memasukkan semua langkah ke dalam Pipeline.

PYTHON
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder, StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression

masalah = {'Tebak harga rumah': ('supervised', 'regresi'),
           'Tebak pelanggan churn': ('supervised', 'klasifikasi'),
           'Kelompokkan pelanggan': ('unsupervised', 'clustering')}
for m, (a, b) in masalah.items():
    print(f'{m:22} -> {a:12} | {b}')

rng = np.random.default_rng(0)
n = 400
df = pd.DataFrame({'kota': rng.choice(['Medan', 'Bandung', 'Jakarta'], n),
                   'paket': rng.choice(['Basic', 'Standar', 'Premium'], n),
                   'lama_bulan': rng.integers(1, 48, n), 'keluhan': rng.poisson(1.2, n)})
df['churn'] = (rng.random(n) < 0.15 + 0.1 * df['keluhan'].clip(0, 4) - 0.003 * df['lama_bulan']).astype(int)

X, y = df.drop(columns='churn'), df['churn']
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)
pra = ColumnTransformer([
    ('kota', OneHotEncoder(handle_unknown='ignore'), ['kota']),
    ('paket', OrdinalEncoder(categories=[['Basic', 'Standar', 'Premium']]), ['paket']),
    ('angka', StandardScaler(), ['lama_bulan', 'keluhan']),
])
pipe = Pipeline([('pra', pra), ('model', LogisticRegression(max_iter=1000))]).fit(X_tr, y_tr)
print('kolom setelah praproses:', list(pipe.named_steps['pra'].get_feature_names_out()))
print('akurasi uji:', round(pipe.score(X_te, y_te), 3))
KELUARAN
Tebak harga rumah      -> supervised   | regresi

Kelompokkan pelanggan  -> unsupervised | clustering
kolom setelah praproses: ['kota__kota_Bandung', 'kota__kota_Jakarta', 'kota__kota_Medan', 'paket__paket', 'angka__lama_bulan', 'angka__keluhan']
akurasi uji: 0.78

Poin penting

  • Ada target → supervised; tidak ada → unsupervised.
  • Target angka → regresi; kelas → klasifikasi.
  • One-hot untuk kategori tanpa urutan, ordinal untuk yang berurutan.
  • Split dulu, fit praproses di data latih (Pipeline).
