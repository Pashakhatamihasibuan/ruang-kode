Gradient boosting dari nol

Buka versi interaktif

Gradient boosting untuk regresi bisa ditulis dalam beberapa baris: mulai dari tebakan rata-rata, hitung residual (selisih nilai asli dan tebakan), latih pohon kecil untuk menebak residual itu, lalu tambahkan sebagian kecil (learning rate) tebakan pohon ke model. Ulangi.

Setiap pohon baru memperbaiki kesalahan gabungan pohon-pohon sebelumnya. Learning rate kecil butuh lebih banyak pohon tetapi biasanya lebih akurat. XGBoost, LightGBM, dan CatBoost adalah versi yang sangat dioptimalkan dari ide ini, ditambah regularisasi dan trik kecepatan.

Grafik menunjukkan kurva model setelah 1, 10, dan 100 pohon: makin banyak pohon, makin mengikuti pola. Hasilnya cocok dengan GradientBoostingRegressor.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import GradientBoostingRegressor

rng = np.random.default_rng(5)
x = np.sort(rng.uniform(0, 10, 120)); y = np.sin(x) * 3 + x * 0.5 + rng.normal(0, 0.5, 120)
X = x[:, None]

lr, tebak, pohon = 0.1, np.full_like(y, y.mean()), []
simpan = {}
for i in range(1, 101):
    residual = y - tebak
    t = DecisionTreeRegressor(max_depth=2).fit(X, residual)
    tebak = tebak + lr * t.predict(X); pohon.append(t)
    if i in (1, 10, 100):
        simpan[i] = tebak.copy()
        print(f'{i:3} pohon: MSE = {((y - tebak) ** 2).mean():.3f}')

sk = GradientBoostingRegressor(n_estimators=100, learning_rate=0.1, max_depth=2, random_state=0).fit(X, y)
print(f'scikit-learn 100 pohon: MSE = {((y - sk.predict(X)) ** 2).mean():.3f}')

plt.figure(figsize=(5.6, 3.4))
plt.scatter(x, y, s=10, color='gray')
for i, w in zip(simpan, ['#f4a261', '#2a9d8f', '#c2185b']):
    plt.plot(x, simpan[i], color=w, lw=2, label=f'{i} pohon')
plt.legend(); plt.title('Gradient boosting: tiap pohon memperbaiki residual')
KELUARAN
  1 pohon: MSE = 5.859
 10 pohon: MSE = 1.778
100 pohon: MSE = 0.141
scikit-learn 100 pohon: MSE = 0.141

Poin penting

  • Mulai dari rata-rata, latih pohon pada residual.
  • Tambahkan lr × tebakan pohon; ulangi.
  • XGBoost/LightGBM/CatBoost = versi optimal.
