Kasus kredit: menentukan ambang persetujuan pinjaman

Buka versi interaktif

Lembaga pembiayaan ingin menyetujui sebanyak mungkin pengajuan tanpa menaikkan kredit macet. Model memberi PD (probability of default) setiap pemohon. Kebijakannya sederhana: setujui jika PD di bawah ambang. Ambang rendah berarti aman tetapi sedikit nasabah; ambang tinggi berarti banyak nasabah tetapi bad rate naik.

Untuk memilih ambang, buat tabel approval rate vs bad rate dan hitung laba harapan setiap ambang: nasabah lancar memberi bunga, nasabah macet menimbulkan kerugian sebesar LGD × plafon. Pilih ambang dengan laba terbesar yang masih di bawah batas risiko yang ditetapkan manajemen risiko.

Di industri, PD sering diubah menjadi skor kredit (misalnya 300–850) dengan aturan PDO (points to double the odds) agar mudah dipakai petugas. Model kredit juga wajib bisa dijelaskan dan diaudit keadilannya, karena keputusan menolak pinjaman berdampak langsung pada orang.

PYTHON
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(8)
n = 6000
X = pd.DataFrame({'telat_bayar_12bln': rng.poisson(0.5, n), 'rasio_cicilan': rng.beta(2, 5, n),
                  'lama_kerja_thn': rng.integers(0, 25, n), 'pinjaman_aktif': rng.integers(0, 5, n)})
logit = -3.6 + 0.8 * X.telat_bayar_12bln + 3.2 * X.rasio_cicilan - 0.06 * X.lama_kerja_thn + 0.25 * X.pinjaman_aktif
y = (rng.random(n) < 1 / (1 + np.exp(-logit))).astype(int)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.4, stratify=y, random_state=0)
pd_hat = LogisticRegression(max_iter=1000).fit(X_tr, y_tr).predict_proba(X_te)[:, 1]

plafon, bunga, lgd = 10_000_000, 0.18, 0.65
baris = []
for ambang in [0.03, 0.05, 0.08, 0.12, 0.20, 1.0]:
    setuju = pd_hat < ambang
    macet = y_te[setuju]
    laba = ((1 - macet) * plafon * bunga - macet * plafon * lgd).sum()
    baris.append([ambang, setuju.mean(), macet.mean() if setuju.any() else 0, laba / 1e6])
tabel = pd.DataFrame(baris, columns=['ambang_PD', 'approval', 'bad_rate', 'laba_juta'])
print(tabel.round(3).to_string(index=False))
print('ambang dengan laba terbesar:', tabel.loc[tabel.laba_juta.idxmax(), 'ambang_PD'])

# PD -> skor kredit: 600 poin = odds 50:1, setiap 20 poin odds menjadi 2x
odds = (1 - pd_hat) / pd_hat
skor = 600 + 20 / np.log(2) * np.log(odds / 50)
print('contoh PD -> skor:', [(round(float(a), 3), int(b)) for a, b in zip(pd_hat[:3], skor[:3])])

plt.figure(figsize=(5.8, 3.3))
plt.plot(tabel.approval, tabel.bad_rate * 100, 'o-')
for _, r in tabel.iterrows():
    plt.annotate(f'PD<{r.ambang_PD:g}', (r.approval, r.bad_rate * 100), textcoords='offset points', xytext=(4, -10), fontsize=8)
plt.xlabel('approval rate'); plt.ylabel('bad rate (%)')
plt.title('Makin banyak disetujui, makin tinggi bad rate')

Poin penting

  • Kebijakan: setujui jika PD < ambang.
  • Pilih ambang dari tabel approval, bad rate, dan laba.
  • PD bisa diubah menjadi skor kredit dengan PDO.
  • Model kredit wajib bisa dijelaskan dan adil.
