Regresi polinomial, overfitting, Ridge dan Lasso

Buka versi interaktif

Hubungan di dunia nyata sering melengkung. Regresi polinomial menambahkan fitur x², x³, ... lalu tetap memakai linear regression. Derajat terlalu rendah membuat underfitting (garis lurus untuk data melengkung); derajat terlalu tinggi membuat overfitting (kurva liar yang menghafal titik).

Regularisasi menambahkan denda pada koefisien besar. Ridge (L2) mengecilkan semua koefisien; Lasso (L1) bisa membuat koefisien tepat nol sehingga sekaligus memilih fitur. Kekuatan denda diatur dengan alpha: makin besar, makin sederhana modelnya.

Perhatikan error uji di hasil: derajat 15 tanpa regularisasi punya error latih terkecil tetapi error uji paling besar. Dengan Ridge, derajat 15 kembali jinak dan error ujinya mendekati derajat 4.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.metrics import mean_squared_error

rng = np.random.default_rng(1)
x = np.sort(rng.uniform(0, 1, 15)); y = np.sin(2 * np.pi * x) + rng.normal(0, 0.3, 15)
xu = np.sort(rng.uniform(0, 1, 200)); yu = np.sin(2 * np.pi * xu) + rng.normal(0, 0.3, 200)

model = {
    'derajat 1': make_pipeline(PolynomialFeatures(1), LinearRegression()),
    'derajat 4': make_pipeline(PolynomialFeatures(4), LinearRegression()),
    'derajat 15': make_pipeline(PolynomialFeatures(15), StandardScaler(), LinearRegression()),
    'derajat 15 + Ridge': make_pipeline(PolynomialFeatures(15), StandardScaler(), Ridge(alpha=0.1)),
}
xs = np.linspace(0, 1, 200)
fig, ax = plt.subplots(1, 4, figsize=(9.6, 2.6), sharey=True)
for a, (nama, m) in zip(ax, model.items()):
    m.fit(x[:, None], y)
    latih = mean_squared_error(y, m.predict(x[:, None]))
    uji = mean_squared_error(yu, m.predict(xu[:, None]))
    print(f'{nama:18}: error latih={latih:.3f}  error uji={uji:.3f}')
    a.scatter(x, y, s=10); a.plot(xs, m.predict(xs[:, None]), color='crimson')
    a.set_ylim(-2, 2); a.set_title(nama, fontsize=9)
fig.tight_layout()
KELUARAN
derajat 1         : error latih=0.302  error uji=0.270
derajat 4         : error latih=0.075  error uji=0.103
derajat 15        : error latih=0.034  error uji=7.698
derajat 15 + Ridge: error latih=0.098  error uji=0.132

Poin penting

  • Derajat rendah underfit, derajat tinggi overfit.
  • Ridge (L2) mengecilkan koefisien; Lasso (L1) bisa menolkan.
  • Pilih derajat/alpha dengan error uji atau cross-validation.
