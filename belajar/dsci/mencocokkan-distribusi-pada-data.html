Mencocokkan distribusi pada data

Buka versi interaktif

Banyak keputusan membutuhkan model peluang: berapa stok aman, berapa lama pelanggan menunggu, berapa peluang klaim asuransi di atas Rp10 juta. Caranya: pilih distribusi yang masuk akal, lalu cocokkan (fit) parameternya ke data.

scipy.stats menyediakan .fit() untuk puluhan distribusi. Setelah itu kita bisa menghitung peluang dan kuantil, misalnya "95% hari permintaan tidak lebih dari X".

Periksa kecocokan dengan membandingkan kuantil data dan model, atau uji Kolmogorov-Smirnov. Pilih distribusi berdasarkan sifat data: bilangan cacah → Poisson, waktu tunggu → eksponensial atau gamma, jumlah yang selalu positif dan miring → lognormal.

PYTHON
import numpy as np
from scipy import stats

rng = np.random.default_rng(4)
permintaan = rng.gamma(shape=6, scale=8, size=365).round()   # unit per hari

bentuk, loc, skala = stats.gamma.fit(permintaan, floc=0)
print(f'gamma: shape={bentuk:.2f}, scale={skala:.2f}')
stok = stats.gamma.ppf(0.95, bentuk, loc, skala)
print(f'Stok agar 95% hari tidak kehabisan: {stok:.0f} unit')
print(f'Data nyata di atas angka itu: {(permintaan > stok).mean():.1%} hari')

ks = stats.kstest(permintaan, 'gamma', args=(bentuk, loc, skala))
print(f'KS p-value = {ks.pvalue:.3f}')
KELUARAN
gamma: shape=5.30, scale=9.08
Stok agar 95% hari tidak kehabisan: 87 unit
Data nyata di atas angka itu: 4.9% hari
KS p-value = 0.461

Poin penting

  • Pilih distribusi sesuai sifat data, lalu fit parameternya.
  • Kuantil menjawab pertanyaan stok dan risiko.
  • Cek kecocokan dengan kuantil atau uji KS.
