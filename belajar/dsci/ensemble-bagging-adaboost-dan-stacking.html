Ensemble: bagging, AdaBoost, dan stacking

Buka versi interaktif

Ensemble menggabungkan banyak model lemah menjadi satu model kuat. Bagging (bootstrap aggregating) melatih model yang sama pada sampel acak data lalu merata-ratakan suaranya; random forest adalah bagging pohon ditambah pemilihan fitur acak. Bagging terutama mengurangi varians (overfitting).

Boosting melatih model berurutan; AdaBoost memberi bobot lebih pada data yang salah ditebak oleh model sebelumnya. Boosting terutama mengurangi bias (underfitting).

Stacking melatih beberapa model berbeda (misalnya logistic regression, KNN, pohon), lalu sebuah model "meta" belajar cara terbaik menggabungkan tebakan mereka. Hasil di bawah: satu pohon paling lemah; semua ensemble lebih baik.

PYTHON
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import BaggingClassifier, RandomForestClassifier, AdaBoostClassifier, StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = make_classification(600, n_features=12, n_informative=6, flip_y=0.05, random_state=4)
model = {
    'satu pohon': DecisionTreeClassifier(random_state=0),
    'bagging 100 pohon': BaggingClassifier(DecisionTreeClassifier(), n_estimators=100, random_state=0),
    'random forest': RandomForestClassifier(200, random_state=0),
    'AdaBoost': AdaBoostClassifier(n_estimators=200, random_state=0),
    'stacking': StackingClassifier([('lr', LogisticRegression(max_iter=1000)),
                                    ('knn', make_pipeline(StandardScaler(), KNeighborsClassifier(15))),
                                    ('rf', RandomForestClassifier(100, random_state=0))],
                                   final_estimator=LogisticRegression()),
}
for nama, m in model.items():
    s = cross_val_score(m, X, y, cv=5)
    print(f'{nama:18}: akurasi {s.mean():.3f} ± {s.std():.3f}')
KELUARAN
satu pohon        : akurasi 0.813 ± 0.024
bagging 100 pohon : akurasi 0.880 ± 0.025
random forest     : akurasi 0.892 ± 0.019
AdaBoost          : akurasi 0.852 ± 0.022
stacking          : akurasi 0.890 ± 0.017

Poin penting

  • Bagging mengurangi varians; random forest = bagging pohon.
  • Boosting mengurangi bias, berurutan.
  • Stacking: model meta menggabungkan model berbeda.
