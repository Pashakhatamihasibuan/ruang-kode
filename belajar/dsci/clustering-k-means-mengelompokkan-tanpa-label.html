Clustering K-Means: mengelompokkan tanpa label

Buka versi interaktif

Unsupervised learning mencari pola tanpa target. K-Means membagi data ke k kelompok: pilih k pusat acak, masukkan setiap titik ke pusat terdekat, geser pusat ke rata-rata anggotanya, ulangi sampai stabil.

Fitur harus distandardisasi dulu, kalau tidak, kolom berskala besar (belanja dalam ribuan) mendominasi jarak. Memilih k: lihat penurunan inertia (metode siku) atau skor silhouette, lalu pastikan kelompoknya masuk akal bagi bisnis.

Contoh pemakaian: segmentasi pelanggan untuk promo yang berbeda, mengelompokkan toko berdasarkan pola penjualan, atau mendeteksi transaksi yang jauh dari semua kelompok (anomali).

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(0)
pusat = np.array([[2, 150], [6, 420], [12, 260]])     # frekuensi beli/bln, belanja
X = np.vstack([rng.normal(c, [1.0, 40], (60, 2)) for c in pusat])
Z = StandardScaler().fit_transform(X)

for k in range(1, 6):
    print(f'k={k}: inertia={KMeans(k, n_init=10, random_state=0).fit(Z).inertia_:.0f}')

km = KMeans(3, n_init=10, random_state=0).fit(Z)
plt.figure(figsize=(5.6, 3.6))
plt.scatter(X[:, 0], X[:, 1], c=km.labels_, cmap='viridis', s=14)
c = StandardScaler().fit(X).inverse_transform(km.cluster_centers_)
plt.scatter(c[:, 0], c[:, 1], marker='X', s=180, color='red', edgecolor='black')
plt.xlabel('frekuensi beli per bulan'); plt.ylabel('belanja (ribu)')
plt.title('3 segmen pelanggan dari K-Means')
for i, (f, b) in enumerate(c):
    print(f'segmen {i}: beli {f:.1f}x/bln, belanja {b:.0f} ribu')

Poin penting

  • K-Means: tetapkan ke pusat terdekat, geser pusat, ulangi.
  • Standardisasi fitur sebelum clustering.
  • Pilih k dengan metode siku dan akal sehat bisnis.
