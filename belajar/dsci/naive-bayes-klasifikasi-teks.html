Naive Bayes: klasifikasi teks

Buka versi interaktif

Naive Bayes memakai teorema Bayes: P(kelas | data) ∝ P(data | kelas) · P(kelas). Disebut "naif" karena menganggap setiap fitur (misalnya setiap kata) saling bebas. Anggapan ini jarang benar, tetapi hasilnya sering tetap bagus.

Untuk teks, MultinomialNB menghitung seberapa sering tiap kata muncul di setiap kelas. Kata "gratis" dan "hadiah" sering di spam, kata "rapat" sering di pesan biasa. Model ini sangat cepat dilatih dan menjadi patokan wajib untuk klasifikasi teks.

Ada juga GaussianNB untuk fitur angka (menganggap tiap fitur berdistribusi normal per kelas). CountVectorizer mengubah kalimat menjadi tabel jumlah kata.

PYTHON
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

pesan = ['selamat anda menang hadiah gratis', 'klaim hadiah pulsa gratis sekarang', 'promo gratis klik link ini',
         'menang undian mobil klaim sekarang', 'besok rapat jam sembilan', 'tolong kirim laporan rapat',
         'nanti makan siang bareng', 'laporan keuangan sudah saya kirim']
label = ['spam'] * 4 + ['biasa'] * 4

vec = CountVectorizer()
X = vec.fit_transform(pesan)
nb = MultinomialNB().fit(X, label)

for kata in ['gratis', 'rapat', 'klaim']:
    j = vec.vocabulary_[kata]
    peluang = {str(c): round(float(v), 2) for c, v in zip(nb.classes_, nb.feature_log_prob_[:, j])}
    print(f'log P({kata} | kelas):', peluang)

uji = ['gratis hadiah untuk anda', 'kirim laporan sebelum rapat', 'klaim laporan gratis']
for teks, p in zip(uji, nb.predict_proba(vec.transform(uji))):
    print(f'{teks:30} -> ' + ', '.join(f'{c}={v:.2f}' for c, v in zip(nb.classes_, p)))
KELUARAN
log P(gratis | kelas): {'biasa': -3.81, 'spam': -2.48}
log P(rapat | kelas): {'biasa': -2.71, 'spam': -3.87}
log P(klaim | kelas): {'biasa': -3.81, 'spam': -2.77}
gratis hadiah untuk anda       -> biasa=0.05, spam=0.95
kirim laporan sebelum rapat    -> biasa=0.97, spam=0.03
klaim laporan gratis           -> biasa=0.23, spam=0.77

Poin penting

  • Bayes: peluang kelas dikali peluang data di kelas itu.
  • "Naif": fitur dianggap saling bebas.
  • MultinomialNB + CountVectorizer = patokan klasifikasi teks.
