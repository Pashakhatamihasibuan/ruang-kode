Clustering lanjutan: DBSCAN dan hierarki

Buka versi interaktif

K-Means mengasumsikan kelompok berbentuk bulat dan butuh k di depan. DBSCAN mengelompokkan berdasarkan kepadatan: titik yang punya cukup tetangga (min_samples) dalam radius eps menjadi inti kelompok. Ia bisa menemukan kelompok berbentuk aneh dan menandai titik yang terisolasi sebagai noise (label −1).

Clustering hierarki (agglomerative) mulai dengan setiap titik sebagai kelompok sendiri, lalu terus menggabungkan dua kelompok terdekat. Hasilnya pohon (dendrogram) yang bisa dipotong di tingkat mana pun.

Pada data berbentuk bulan sabit di bawah, K-Means gagal memisahkan dengan benar, sedangkan DBSCAN dan agglomerative (linkage single, dipotong pada jarak 0,3) berhasil. Agglomerative menaruh tiap pencilan sebagai kelompok kecil tersendiri, DBSCAN menandainya sebagai noise.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.metrics import adjusted_rand_score

X, y = make_moons(300, noise=0.06, random_state=2)
X = np.vstack([X, [[-1.2, 1.3], [2.3, -0.8], [0.5, 1.6]]])     # 3 titik pencilan

model = {'K-Means k=2': KMeans(2, n_init=10, random_state=0),
         'DBSCAN': DBSCAN(eps=0.2, min_samples=5),
         'Agglomerative': AgglomerativeClustering(n_clusters=None, distance_threshold=0.3, linkage='single')}
fig, ax = plt.subplots(1, 3, figsize=(9.6, 2.8))
for a, (nama, m) in zip(ax, model.items()):
    lab = m.fit_predict(X)
    print(f'{nama:14}: kecocokan dengan bentuk asli={adjusted_rand_score(y, lab[:300]):.2f}  kelompok={len(set(lab) - {-1})}  noise={np.sum(lab == -1)}')
    a.scatter(X[:, 0], X[:, 1], c=lab, s=8, cmap='viridis')
    a.scatter(X[lab == -1, 0], X[lab == -1, 1], marker='x', color='red', s=40)
    a.set_title(nama, fontsize=10); a.set_xticks([]); a.set_yticks([])
fig.tight_layout()
KELUARAN
K-Means k=2   : kecocokan dengan bentuk asli=0.24  kelompok=2  noise=0
DBSCAN        : kecocokan dengan bentuk asli=1.00  kelompok=2  noise=3
Agglomerative : kecocokan dengan bentuk asli=1.00  kelompok=5  noise=0

Poin penting

  • DBSCAN: berbasis kepadatan, tanpa k, menandai noise.
  • Agglomerative: gabungkan kelompok terdekat berulang.
  • K-Means hanya cocok untuk kelompok bulat.
