Linear regression dari nol

Buka versi interaktif

Linear regression mencari garis y = w·x + b yang paling dekat dengan semua titik. "Paling dekat" artinya jumlah kuadrat selisih (MSE) paling kecil. Ini algoritma ML paling dasar, dan banyak algoritma lain adalah pengembangannya.

Ada dua cara mencari w dan b. Rumus tertutup (normal equation) langsung menghitung jawabannya: w = (XᵀX)⁻¹Xᵀy. Gradient descent mulai dari tebakan acak lalu bergeser sedikit demi sedikit melawan arah turunan. Rumus tertutup cepat untuk data kecil; gradient descent dipakai saat data dan fitur sangat banyak.

Lihat hasilnya: ketiga cara (rumus, gradient descent, dan scikit-learn) memberi koefisien yang sama. Koefisien w dibaca sebagai "setiap tambahan 1 m² menaikkan harga sekitar w juta".

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(3)
luas = rng.uniform(30, 150, 40)                       # m²
harga = 120 + 9.5 * luas + rng.normal(0, 90, 40)       # juta rupiah

# 1) rumus tertutup: tambahkan kolom 1 untuk intersep b
X = np.column_stack([np.ones_like(luas), luas])
b, w = np.linalg.solve(X.T @ X, X.T @ harga)
print(f'rumus tertutup  : w={w:.3f}  b={b:.1f}')

# 2) gradient descent (fitur distandardisasi agar stabil)
z = (luas - luas.mean()) / luas.std()
w2, b2, lr = 0.0, 0.0, 0.1
for _ in range(500):
    err = (w2 * z + b2) - harga
    w2 -= lr * 2 * (err * z).mean()
    b2 -= lr * 2 * err.mean()
w_gd = w2 / luas.std(); b_gd = b2 - w_gd * luas.mean()
print(f'gradient descent: w={w_gd:.3f}  b={b_gd:.1f}')

# 3) scikit-learn
m = LinearRegression().fit(luas.reshape(-1, 1), harga)
print(f'scikit-learn    : w={m.coef_[0]:.3f}  b={m.intercept_:.1f}')
print('tebak harga rumah 100 m²:', round(m.predict([[100]])[0]), 'juta')

plt.figure(figsize=(5.6, 3.6))
plt.scatter(luas, harga, s=16)
xs = np.array([30, 150])
plt.plot(xs, w * xs + b, color='crimson', lw=2, label=f'y = {w:.1f}x + {b:.0f}')
plt.xlabel('luas (m²)'); plt.ylabel('harga (juta)'); plt.legend()
plt.title('Garis linear regression terbaik')
KELUARAN

tebak harga rumah 100 m²: 1058 juta

Soal latihan

  1. Dengan NumPy, cari w dan b untuk titik x = [1, 2, 3, 4] dan y = [3, 5, 7, 9] memakai np.polyfit(x, y, 1).

    Petunjuk

    polyfit derajat 1 mengembalikan [w, b].

Poin penting

  • Linear regression meminimalkan MSE.
  • Rumus tertutup vs gradient descent: hasil sama.
  • Koefisien = perubahan y untuk setiap tambahan 1 x.
