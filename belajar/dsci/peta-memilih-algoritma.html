Peta memilih algoritma

Buka versi interaktif

Tidak ada algoritma terbaik untuk semua masalah ("no free lunch"). Mulailah dari pertanyaan: targetnya angka, kategori, atau tidak ada? Berapa banyak data? Seberapa penting model mudah dijelaskan?

Alur kerja yang aman: buat patokan sederhana (rata-rata atau kelas terbanyak), lalu model linear, lalu random forest atau gradient boosting. Bandingkan dengan cross-validation dan metrik yang sesuai bisnis. Naik ke deep learning hanya untuk data gambar, suara, teks panjang, atau data yang sangat besar.

CONTOH
Pertanyaan pertama: apa targetnya?

  angka (regresi)      -> Linear/Ridge/Lasso -> Random Forest -> Gradient Boosting
  kategori (klasifikasi)-> Logistic Regression / Naive Bayes (teks) -> RF -> Boosting
  tidak ada label      -> K-Means / DBSCAN / Hierarki (kelompok)
                          PCA / t-SNE (meringkas, visualisasi)
                          Isolation Forest (anomali)
  rating pengguna-item -> Matrix factorization (rekomendasi)
  gambar/suara/teks    -> CNN / RNN / Transformer (deep learning)

Poin penting

  • Mulai dari patokan, lalu linear, lalu ensemble.
  • Pilih berdasarkan jenis target, ukuran data, dan kebutuhan penjelasan.
  • Deep learning untuk data tidak terstruktur.
