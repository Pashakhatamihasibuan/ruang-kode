Support Vector Machine dan kernel

Buka versi interaktif

SVM mencari garis pemisah dengan margin (jarak ke titik terdekat dari tiap kelas) selebar mungkin. Titik-titik di tepi margin disebut support vector; hanya merekalah yang menentukan garisnya.

Jika data tidak bisa dipisah garis lurus, kernel trick memetakan data ke ruang berdimensi lebih tinggi secara implisit. Kernel rbf (Gaussian) paling umum. Parameter C mengatur seberapa keras kesalahan dihukum (C besar = margin sempit, rawan overfit), gamma mengatur seberapa jauh pengaruh satu titik.

SVM kuat untuk data berukuran sedang dan berdimensi tinggi (misalnya teks). Untuk data ratusan ribu baris, ia lambat; pakai model linear atau boosting.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.svm import SVC
from sklearn.model_selection import cross_val_score

X, y = make_moons(200, noise=0.2, random_state=1)
xx, yy = np.meshgrid(np.linspace(-1.6, 2.6, 160), np.linspace(-1.2, 1.7, 160))
fig, ax = plt.subplots(1, 3, figsize=(9.6, 2.8))
for a, (judul, m) in zip(ax, [('linear', SVC(kernel='linear')), ('rbf, C=1', SVC(kernel='rbf', C=1)), ('rbf, C=1000', SVC(kernel='rbf', C=1000, gamma=5))]):
    print(f'{judul:12}: akurasi CV={cross_val_score(m, X, y, cv=5).mean():.3f}', end='')
    m.fit(X, y); print(f'  support vector={len(m.support_)}')
    Z = m.decision_function(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
    a.contourf(xx, yy, Z > 0, alpha=0.25, cmap='coolwarm')
    a.contour(xx, yy, Z, levels=[-1, 0, 1], colors='k', linestyles=['--', '-', '--'], linewidths=1)
    a.scatter(X[:, 0], X[:, 1], c=y, s=8, cmap='coolwarm')
    a.set_title(judul, fontsize=10); a.set_xticks([]); a.set_yticks([])
fig.tight_layout()
KELUARAN
linear      : akurasi CV=0.875  support vector=71
rbf, C=1    : akurasi CV=0.955  support vector=53
rbf, C=1000 : akurasi CV=0.950  support vector=18

Poin penting

  • SVM memaksimalkan margin; support vector menentukan garis.
  • Kernel rbf menangani pola melengkung.
  • C dan gamma besar = rawan overfit.
