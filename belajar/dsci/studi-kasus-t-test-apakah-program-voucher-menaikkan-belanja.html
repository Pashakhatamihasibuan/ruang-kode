Studi kasus t-test: apakah program voucher menaikkan belanja?

Buka versi interaktif

Sebuah aplikasi kedai kopi menguji voucher "beli 2 gratis 1" selama dua minggu. Pelanggan dibagi acak: kontrol (tanpa voucher) dan perlakuan (mendapat voucher). Pertanyaan bisnis: apakah belanja per pelanggan naik cukup besar untuk menutup biaya voucher?

Karena dua kelompok berisi orang yang berbeda, kita memakai t-test dua sampel independen. Varians dua kelompok tidak dijamin sama, jadi pakai versi Welch (equal_var=False), yang menjadi pilihan aman di industri. H1 satu arah: perlakuan > kontrol, sehingga alternative="greater". Jika pelanggan yang sama diukur sebelum dan sesudah, pakai t-test berpasangan (ttest_rel).

Signifikan secara statistik belum tentu menguntungkan. Hitung selang kepercayaan selisih rata-rata dan bandingkan dengan biaya voucher per pelanggan. Keputusan diambil dari angka rupiah, bukan dari p-value saja.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

rng = np.random.default_rng(21)
kontrol = rng.gamma(4, 18_000, 420).round(-2)       # belanja 2 minggu (rupiah)
voucher = rng.gamma(4, 21_000, 410).round(-2)
biaya_voucher = 4_500                               # rata-rata biaya per pelanggan perlakuan

hasil = stats.ttest_ind(voucher, kontrol, equal_var=False, alternative='greater')
selisih = voucher.mean() - kontrol.mean()
se = np.sqrt(voucher.var(ddof=1) / len(voucher) + kontrol.var(ddof=1) / len(kontrol))
ci = stats.t.interval(0.95, df=min(len(voucher), len(kontrol)) - 1, loc=selisih, scale=se)

print(f'kontrol : Rp{kontrol.mean():,.0f} (n={len(kontrol)})')
print(f'voucher : Rp{voucher.mean():,.0f} (n={len(voucher)})')
print(f'selisih : Rp{selisih:,.0f}, 95% CI Rp{ci[0]:,.0f} s.d. Rp{ci[1]:,.0f}')
print(f'Welch t = {hasil.statistic:.2f}, p (satu sisi) = {hasil.pvalue:.4f}')
margin = 0.35                                        # margin kotor kedai
untung = selisih * margin - biaya_voucher
print(f'tambahan laba kotor per pelanggan: Rp{selisih * margin:,.0f} - biaya Rp{biaya_voucher:,} = Rp{untung:,.0f}')
print('Keputusan:', 'lanjutkan voucher' if hasil.pvalue < 0.05 and untung > 0 else 'jangan diperluas dulu')

plt.figure(figsize=(6.4, 3.2))
bins = np.linspace(0, 250_000, 40)
plt.hist(kontrol, bins=bins, alpha=0.6, label='kontrol')
plt.hist(voucher, bins=bins, alpha=0.6, label='voucher')
plt.axvline(kontrol.mean(), color='tab:blue', linestyle='--')
plt.axvline(voucher.mean(), color='tab:orange', linestyle='--')
plt.xlabel('belanja 2 minggu (Rp)'); plt.title('Sebaran belanja: kontrol vs voucher'); plt.legend()
KELUARAN
kontrol : Rp72,993 (n=420)
voucher : Rp81,516 (n=410)
selisih : Rp8,523, 95% CI Rp3,441 s.d. Rp13,605
Welch t = 3.30, p (satu sisi) = 0.0005
tambahan laba kotor per pelanggan: Rp2,983 - biaya Rp4,500 = Rp-1,517
Keputusan: jangan diperluas dulu

Poin penting

  • Dua kelompok berbeda: t-test independen (Welch).
  • Orang yang sama sebelum-sesudah: t-test berpasangan.
  • Laporkan selang kepercayaan selisih, bukan hanya p-value.
  • Keputusan akhir memakai laba setelah biaya.

Cek pemahaman

Data belanja pelanggan yang sama sebelum dan sesudah mendapat voucher. Uji yang tepat?

Jawaban: t-test berpasangan (ttest_rel)

Pengamatan berpasangan per orang.

Hasil signifikan (p &lt; 0,05) tetapi tambahan laba lebih kecil dari biaya voucher. Keputusan?

Jawaban: Jangan diperluas, efeknya nyata tetapi tidak menguntungkan

Signifikansi statistik ≠ manfaat bisnis.
