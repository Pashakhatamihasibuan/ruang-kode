CNN, RNN, dan Transformer

Buka versi interaktif

CNN (convolutional neural network) memakai filter kecil yang digeser di seluruh gambar untuk mendeteksi tepi, tekstur, lalu bentuk. Dipakai untuk klasifikasi gambar, deteksi objek, dan citra medis.

RNN/LSTM membaca urutan satu per satu sambil membawa "ingatan", cocok untuk deret waktu dan teks pendek. Transformer menggantikannya untuk teks: memakai attention agar setiap kata bisa melihat semua kata lain sekaligus, dan menjadi dasar model bahasa besar (LLM) serta model gambar modern.

Arsitektur lain: autoencoder (memampatkan lalu merekonstruksi, untuk deteksi anomali), GAN dan diffusion (menghasilkan gambar). Di praktik, data scientist jarang melatih dari nol; biasanya memakai model pralatih lalu fine-tuning. Contoh di bawah menunjukkan operasi konvolusi sederhana yang menemukan tepi.

PYTHON
import numpy as np

gambar = np.array([[0, 0, 0, 9, 9, 9],
                   [0, 0, 0, 9, 9, 9],
                   [0, 0, 0, 9, 9, 9],
                   [0, 0, 0, 9, 9, 9]])
filter_tepi = np.array([[-1, 0, 1],
                        [-1, 0, 1],
                        [-1, 0, 1]])

h, w = gambar.shape
hasil = np.zeros((h - 2, w - 2), dtype=int)
for i in range(h - 2):
    for j in range(w - 2):
        hasil[i, j] = (gambar[i:i + 3, j:j + 3] * filter_tepi).sum()
print(hasil)
print('Nilai besar = ada tepi vertikal di tengah gambar')
