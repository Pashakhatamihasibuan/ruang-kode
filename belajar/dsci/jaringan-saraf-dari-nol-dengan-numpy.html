Jaringan saraf dari nol dengan NumPy

Buka versi interaktif

Satu neuron menghitung jumlah berbobot masukannya, lalu melewatkannya ke fungsi aktivasi (sigmoid, ReLU) agar bisa menangkap pola yang tidak lurus. Banyak neuron disusun berlapis menjadi jaringan saraf (fully connected network).

Belajarnya sama dengan gradient descent: hitung prediksi (forward), hitung loss, hitung turunan loss terhadap setiap bobot dari belakang ke depan (backpropagation), lalu geser bobot. PyTorch dan TensorFlow menghitung turunan ini otomatis.

Contoh klasik: XOR. Satu garis lurus tidak bisa memisahkannya, tetapi jaringan dengan satu lapisan tersembunyi bisa. Inilah alasan deep learning mampu mengenali wajah, suara, dan teks.

PYTHON
import numpy as np
import matplotlib.pyplot as plt

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)          # XOR
rng = np.random.default_rng(1)
W1, b1 = rng.normal(0, 1, (2, 4)), np.zeros(4)
W2, b2 = rng.normal(0, 1, (4, 1)), np.zeros(1)
sig = lambda z: 1 / (1 + np.exp(-z))

riwayat = []
for ep in range(3000):
    h = np.tanh(X @ W1 + b1)            # forward
    p = sig(h @ W2 + b2)
    loss = np.mean((p - y) ** 2)
    riwayat.append(loss)
    g2 = 2 * (p - y) / 4 * p * (1 - p)  # backpropagation
    gW2, gb2 = h.T @ g2, g2.sum(0)
    g1 = (g2 @ W2.T) * (1 - h ** 2)
    gW1, gb1 = X.T @ g1, g1.sum(0)
    for w, g in [(W1, gW1), (b1, gb1), (W2, gW2), (b2, gb2)]:
        w -= 2.0 * g
print('loss akhir:', round(loss, 5))
print('prediksi XOR:', p.round(2).ravel())

plt.figure(figsize=(5.6, 3))
plt.plot(riwayat); plt.yscale('log')
plt.xlabel('epoch'); plt.ylabel('loss'); plt.title('Loss turun saat jaringan belajar XOR')

Poin penting

  • Neuron = jumlah berbobot + aktivasi.
  • Forward, loss, backpropagation, update bobot.
  • Lapisan tersembunyi memungkinkan pola tidak linear seperti XOR.
