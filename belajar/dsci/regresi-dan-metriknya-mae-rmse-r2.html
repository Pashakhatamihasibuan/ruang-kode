Regresi dan metriknya: MAE, RMSE, R²

Buka versi interaktif

Untuk target angka, kita mengukur seberapa jauh tebakan dari nilai asli. MAE (rata-rata selisih mutlak) mudah dijelaskan: "rata-rata meleset Rp40 ribu". RMSE menghukum kesalahan besar lebih berat. R² membandingkan dengan menebak rata-rata saja.

Model regresi yang umum: LinearRegression (cepat, mudah dijelaskan), Ridge/Lasso (linear dengan regularisasi agar tidak overfit; Lasso bisa membuat koefisien nol sehingga sekaligus memilih fitur), dan model pohon untuk hubungan yang tidak lurus.

Saat memakai fitur dengan skala berbeda (umur puluhan, belanja ratusan), lakukan standardisasi agar regularisasi adil untuk semua fitur.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression, Lasso
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# tebak belanja per bulan dari fitur lain
X = df[['umur', 'lama_bulan', 'keluhan']]
y = df['belanja_bln'] + 2.5 * df['lama_bulan']   # buat target punya hubungan nyata
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, random_state=1)

for nama, m in [('Linear', LinearRegression()), ('Lasso', Lasso(alpha=5))]:
    m.fit(X_tr, y_tr)
    p = m.predict(X_te)
    print(f'{nama:6}: MAE={mean_absolute_error(y_te, p):.1f}  RMSE={mean_squared_error(y_te, p) ** 0.5:.1f}  R2={r2_score(y_te, p):.3f}')
    print('        koef:', dict(zip(X.columns, m.coef_.round(2))))

Poin penting

  • MAE mudah dijelaskan, RMSE menghukum kesalahan besar.
  • R² dibandingkan menebak rata-rata.
  • Ridge/Lasso mengurangi overfitting; Lasso juga memilih fitur.
