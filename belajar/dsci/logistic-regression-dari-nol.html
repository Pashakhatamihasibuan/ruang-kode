Logistic regression dari nol

Buka versi interaktif

Untuk klasifikasi ya/tidak, garis lurus tidak cocok karena hasilnya bisa di luar 0–1. Logistic regression memasukkan hasil garis ke fungsi sigmoid σ(z) = 1 / (1 + e⁻ᶻ) sehingga keluarannya selalu peluang antara 0 dan 1.

Yang diminimalkan bukan MSE, melainkan log loss (cross-entropy): hukuman besar jika model yakin tetapi salah. Turunannya ternyata sederhana, (p − y)·x, sehingga gradient descent mudah ditulis sendiri.

Koefisien dibaca sebagai log-odds: koefisien positif menaikkan peluang kelas 1. Hasil buatan sendiri di bawah hampir sama dengan scikit-learn (sedikit beda karena scikit-learn memakai regularisasi bawaan).

PYTHON
import numpy as np
from sklearn.linear_model import LogisticRegression

rng = np.random.default_rng(0)
jam_belajar = rng.uniform(0, 10, 200)
lulus = (rng.random(200) < 1 / (1 + np.exp(-(jam_belajar - 5) * 1.2))).astype(int)

sigmoid = lambda z: 1 / (1 + np.exp(-z))
z = (jam_belajar - jam_belajar.mean()) / jam_belajar.std()
w, b = 0.0, 0.0
for i in range(2000):
    p = sigmoid(w * z + b)
    w -= 0.1 * ((p - lulus) * z).mean()
    b -= 0.1 * (p - lulus).mean()
    if i in (0, 100, 1999):
        loss = -np.mean(lulus * np.log(p) + (1 - lulus) * np.log(1 - p))
        print(f'iterasi {i:4}: log loss = {loss:.3f}')

w_asli = w / jam_belajar.std(); b_asli = b - w_asli * jam_belajar.mean()
print(f'dari nol    : w={w_asli:.2f}  b={b_asli:.2f}')
m = LogisticRegression(C=1e6).fit(jam_belajar[:, None], lulus)
print(f'scikit-learn: w={m.coef_[0][0]:.2f}  b={m.intercept_[0]:.2f}')
for j in [2, 5, 8]:
    print(f'belajar {j} jam -> peluang lulus {sigmoid(w_asli * j + b_asli):.2f}')

iterasi  100: log loss = 0.318
iterasi 1999: log loss = 0.261
dari nol    : w=1.18  b=-6.32

belajar 8 jam -> peluang lulus 0.96

Poin penting

  • Sigmoid mengubah skor menjadi peluang 0–1.
  • Log loss menghukum keyakinan yang salah.
  • Gradien: (p − y)·x.
