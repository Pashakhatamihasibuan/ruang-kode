t-SNE: peta 2D untuk data berdimensi tinggi

Buka versi interaktif

PCA hanya menangkap pola lurus. t-SNE (dan saudaranya UMAP) mempertahankan tetangga: titik yang mirip di ruang 64 dimensi akan berdekatan di peta 2D. Hasilnya sering memperlihatkan kelompok dengan jelas.

Contoh: gambar angka tulisan tangan 8×8 piksel (64 fitur). Setelah t-SNE, angka yang sama berkumpul. perplexity kira-kira jumlah tetangga yang diperhatikan (5–50).

Hati-hati membaca t-SNE: jarak antar kelompok dan ukuran kelompok tidak bermakna, dan hasilnya berbeda setiap random_state. Pakai untuk eksplorasi visual, bukan sebagai fitur model.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.manifold import TSNE
from sklearn.decomposition import PCA

d = load_digits()
X, y = d.data[:600], d.target[:600]
print('ukuran data:', X.shape)

fig, ax = plt.subplots(1, 2, figsize=(8.4, 3.4))
for a, (nama, Z) in zip(ax, [('PCA', PCA(2).fit_transform(X)),
                            ('t-SNE', TSNE(2, perplexity=30, random_state=0, init='pca').fit_transform(X))]):
    sc = a.scatter(Z[:, 0], Z[:, 1], c=y, cmap='tab10', s=6)
    for k in range(10):
        a.text(*np.median(Z[y == k], axis=0), str(k), fontsize=11, weight='bold')
    a.set_title(nama, fontsize=10); a.set_xticks([]); a.set_yticks([])
fig.tight_layout()
print('t-SNE memisahkan 10 angka jauh lebih jelas daripada PCA')
KELUARAN
ukuran data: (600, 64)
t-SNE memisahkan 10 angka jauh lebih jelas daripada PCA

Poin penting

  • t-SNE/UMAP mempertahankan tetangga, bukan jarak global.
  • Bagus untuk melihat kelompok di data berdimensi tinggi.
  • Jarak antar kelompok tidak bermakna.
