NumPy: array, vektorisasi, dan broadcasting

Buka versi interaktif

NumPy menyimpan angka dalam array bertipe sama yang tersusun rapat di memori. Operasi pada seluruh array sekaligus (vektorisasi) berjalan di kode C, puluhan kali lebih cepat daripada loop Python.

Broadcasting membuat array dengan bentuk berbeda bisa dioperasikan bersama: menambah satu angka ke semua elemen, atau mengurangi rata-rata tiap kolom dari matriks. Atribut shape memberi tahu bentuk array, misalnya (3, 4) berarti 3 baris 4 kolom.

Hampir semua pustaka data (pandas, scikit-learn, PyTorch) dibangun di atas array NumPy, jadi memahami shape, indexing, dan axis akan sangat membantu.

PYTHON
import numpy as np

harga = np.array([12000, 15000, 9000, 22000])
jumlah = np.array([3, 1, 5, 2])
print('Total per item:', harga * jumlah)
print('Omzet:', (harga * jumlah).sum())

# broadcasting: diskon 10% untuk semua
print('Setelah diskon:', harga * 0.9)

nilai = np.array([[80, 70, 90],
                  [60, 85, 75]])
print('shape:', nilai.shape)
print('rata-rata per kolom:', nilai.mean(axis=0))
print('rata-rata per baris:', nilai.mean(axis=1).round(1))
KELUARAN
Total per item: [36000 15000 45000 44000]
Omzet: 140000
Setelah diskon: [10800. 13500.  8100. 19800.]
shape: (2, 3)
rata-rata per kolom: [70.  77.5 82.5]
rata-rata per baris: [80.  73.3]

Poin penting

  • Array NumPy: satu tipe, cepat, mendukung operasi vektor.
  • Broadcasting menyesuaikan bentuk secara otomatis.
  • axis=0 per kolom, axis=1 per baris.
