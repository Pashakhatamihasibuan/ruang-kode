Matplotlib: scatter, subplot, dan anotasi

Buka versi interaktif

Scatter plot menunjukkan hubungan dua variabel angka. Warna atau ukuran titik bisa menambah variabel ketiga, misalnya churn (ya/tidak).

Subplot menata beberapa grafik dalam satu gambar agar mudah dibandingkan; sharey=True menyamakan skala sumbu y. Anotasi (ax.annotate, ax.axhline) menunjuk bagian penting supaya pembaca tidak perlu menebak.

Untuk eksplorasi cepat, df.plot(kind=...) dari pandas sudah cukup. Untuk laporan, atur ukuran, label, dan warna dengan Matplotlib agar rapi. Seaborn mempermudah grafik statistik (boxplot, violin, pairplot), dan Plotly membuat grafik interaktif untuk dashboard.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
import matplotlib.pyplot as plt

fig, ax = plt.subplots(1, 2, figsize=(9, 3.4), sharey=True)
for nilai, warna, nama in [(0, 'tab:blue', 'bertahan'), (1, 'tab:red', 'churn')]:
    d = df[df['churn'] == nilai]
    ax[0].scatter(d['lama_bulan'], d['belanja_bln'], s=12, alpha=0.6, color=warna, label=nama)
ax[0].set_xlabel('lama berlangganan (bulan)'); ax[0].set_ylabel('belanja/bln')
ax[0].legend(); ax[0].set_title('Churn menumpuk di pelanggan baru')

rata = df.groupby('keluhan')['belanja_bln'].mean()
ax[1].plot(rata.index, rata.values, 'o-')
ax[1].axhline(df['belanja_bln'].mean(), color='gray', linestyle='--')
ax[1].annotate('rata-rata semua', (rata.index.max(), df['belanja_bln'].mean()), ha='right', va='bottom')
ax[1].set_xlabel('jumlah keluhan'); ax[1].set_title('Belanja vs keluhan')
fig.tight_layout()
print('Rata-rata lama berlangganan: churn', round(df[df.churn == 1].lama_bulan.mean(), 1),
      'vs bertahan', round(df[df.churn == 0].lama_bulan.mean(), 1))
KELUARAN
Rata-rata lama berlangganan: churn 16.9 vs bertahan 26.8

Poin penting

  • Scatter untuk hubungan dua angka; warna untuk variabel ketiga.
  • Subplot untuk membandingkan; anotasi untuk menunjuk.
  • pandas .plot untuk cepat, Seaborn/Plotly untuk statistik dan interaktif.
