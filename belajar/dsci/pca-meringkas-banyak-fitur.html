PCA: meringkas banyak fitur

Buka versi interaktif

PCA (principal component analysis) mencari arah baru dalam data yang menangkap variasi terbesar. Komponen pertama menyimpan variasi paling banyak, komponen kedua berikutnya, dan seterusnya, semuanya saling tegak lurus.

Gunanya: memvisualisasikan data berdimensi tinggi dalam 2D, mengurangi fitur yang saling kembar, dan mempercepat model. explained_variance_ratio_ menunjukkan berapa persen informasi yang dipertahankan setiap komponen.

Standardisasi dulu sebelum PCA. Kelemahannya: komponen baru sulit dijelaskan ("komponen 1" bukan kolom asli), jadi untuk laporan bisnis sering lebih baik memilih fitur asli.

PYTHON
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

iris = load_iris()
Z = StandardScaler().fit_transform(iris.data)       # 4 fitur ukuran bunga
pca = PCA(n_components=2).fit(Z)
P2 = pca.transform(Z)
print('variasi yang dijelaskan:', pca.explained_variance_ratio_.round(3))
print('total 2 komponen:', round(pca.explained_variance_ratio_.sum(), 3))

plt.figure(figsize=(5.6, 3.6))
for k, nama in enumerate(iris.target_names):
    plt.scatter(P2[iris.target == k, 0], P2[iris.target == k, 1], s=14, label=nama)
plt.xlabel('komponen 1'); plt.ylabel('komponen 2')
plt.title('4 fitur iris diringkas ke 2D dengan PCA'); plt.legend()
KELUARAN
variasi yang dijelaskan: [0.73  0.229]
total 2 komponen: 0.958

Poin penting

  • PCA mencari arah variasi terbesar.
  • explained_variance_ratio_ = informasi yang tersimpan.
  • Standardisasi dulu; komponen sulit dijelaskan.
