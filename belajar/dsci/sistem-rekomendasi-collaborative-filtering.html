Sistem rekomendasi: collaborative filtering

Buka versi interaktif

Collaborative filtering merekomendasikan berdasarkan pola rating banyak pengguna: "pengguna yang mirip denganmu menyukai ini". Datanya berupa matriks pengguna × item yang sebagian besar kosong.

Matrix factorization memecah matriks rating menjadi dua matriks kecil: vektor selera tiap pengguna dan vektor ciri tiap item. Hasil kali keduanya mengisi sel yang kosong, yaitu tebakan rating untuk film yang belum ditonton.

Kode di bawah melatih faktorisasi dengan gradient descent hanya pada sel yang terisi, lalu merekomendasikan film dengan tebakan rating tertinggi. Pendekatan lain: content-based (berdasarkan ciri item) dan model hybrid.

PYTHON
import numpy as np

film = ['Aksi1', 'Aksi2', 'Aksi3', 'Drama1', 'Drama2', 'Drama3']
R = np.array([[5, 4, 0, 1, 0, 1],      # 0 = belum menonton
              [4, 0, 5, 1, 2, 0],
              [5, 5, 4, 0, 1, 1],
              [1, 0, 1, 5, 4, 0],
              [0, 1, 2, 4, 0, 5],
              [1, 2, 0, 0, 5, 4]], dtype=float)
ada = R > 0

rng = np.random.default_rng(0)
k = 2                                   # 2 faktor selera
U = rng.normal(0, 0.3, (6, k)); V = rng.normal(0, 0.3, (6, k))
for ep in range(3000):
    E = np.where(ada, R - U @ V.T, 0)
    U += 0.01 * (E @ V - 0.02 * U)
    V += 0.01 * (E.T @ U - 0.02 * V)
print('RMSE pada rating yang ada:', round(np.sqrt((E[ada] ** 2).mean()), 3))

tebak = U @ V.T
for u in [1, 4]:
    belum = [(film[j], round(tebak[u, j], 1)) for j in range(6) if not ada[u, j]]
    print(f'pengguna {u}: tebakan rating film yang belum ditonton {belum}')
    print(f'   rekomendasi -> {max(belum, key=lambda x: x[1])[0]}')
KELUARAN

   rekomendasi -> Aksi2
pengguna 4: tebakan rating film yang belum ditonton [('Aksi1', np.float64(1.0)), ('Drama2', np.float64(4.5))]
   rekomendasi -> Drama2

Poin penting

  • Collaborative filtering: belajar dari pola rating banyak orang.
  • Matrix factorization: rating ≈ selera pengguna · ciri item.
  • Latih hanya pada sel yang terisi.
