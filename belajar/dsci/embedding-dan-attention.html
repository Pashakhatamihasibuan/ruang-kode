Embedding dan attention

Buka versi interaktif

Embedding mengubah kata, produk, atau pengguna menjadi vektor angka sehingga yang maknanya mirip letaknya berdekatan. Kemiripan diukur dengan cosine similarity. Inilah dasar pencarian semantik, rekomendasi, dan RAG (retrieval-augmented generation).

Attention menghitung seberapa besar setiap elemen harus "memperhatikan" elemen lain: skor = query · key, dinormalkan dengan softmax menjadi bobot yang berjumlah 1, lalu dipakai untuk merata-ratakan value.

Contoh di bawah memakai vektor kecil buatan tangan. Model nyata memakai ratusan sampai ribuan dimensi yang dipelajari dari data dalam jumlah sangat besar.

PYTHON
import numpy as np

emb = {
    'kopi':   np.array([0.9, 0.1, 0.0]),
    'teh':    np.array([0.8, 0.2, 0.1]),
    'laptop': np.array([0.0, 0.1, 0.95]),
    'mouse':  np.array([0.1, 0.0, 0.9]),
}
cos = lambda a, b: a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
for kata in ['teh', 'laptop', 'mouse']:
    print(f'kopi ~ {kata:6}: {cos(emb["kopi"], emb[kata]):.2f}')

def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

Q = emb['mouse']
K = np.array([emb[k] for k in emb])
bobot = softmax(K @ Q / np.sqrt(3))
for k, b in zip(emb, bobot):
    print(f'attention mouse -> {k:6}: {b:.2f}')
KELUARAN
kopi ~ teh   : 0.98
kopi ~ laptop: 0.01
kopi ~ mouse : 0.11
attention mouse -> kopi  : 0.20
attention mouse -> teh   : 0.20
attention mouse -> laptop: 0.30
attention mouse -> mouse : 0.30

Poin penting

  • Embedding: makna mirip → vektor berdekatan.
  • Attention: softmax(query·key) sebagai bobot.
  • Dasar pencarian semantik, rekomendasi, RAG, dan LLM.
