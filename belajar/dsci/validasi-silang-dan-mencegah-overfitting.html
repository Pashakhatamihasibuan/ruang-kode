Validasi silang dan mencegah overfitting

Buka versi interaktif

Satu kali train/test split bisa beruntung atau sial. K-fold cross-validation membagi data menjadi k bagian, melatih k kali dengan bagian berbeda sebagai data uji, lalu merata-ratakan skornya. Hasilnya lebih bisa dipercaya, dan simpangan bakunya menunjukkan seberapa stabil model.

Overfitting: model terlalu rumit, skor latih tinggi tetapi skor uji rendah. Underfitting: model terlalu sederhana, keduanya rendah. Obatnya: regularisasi, batasi kedalaman pohon, tambah data, atau kurangi fitur.

Kebocoran data (data leakage) adalah musuh terbesar: misalnya standardisasi dihitung dari seluruh data sebelum dibagi, atau fitur yang baru diketahui setelah kejadian (seperti "tanggal berhenti berlangganan"). Gunakan Pipeline agar semua langkah hanya belajar dari data latih.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.tree import DecisionTreeClassifier

X = df[['umur', 'lama_bulan', 'belanja_bln', 'keluhan']]; y = df['churn']
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
for d in [1, 2, 3, 5, 8, None]:
    m = DecisionTreeClassifier(max_depth=d, random_state=0)
    s = cross_val_score(m, X, y, cv=cv, scoring='roc_auc')
    latih = m.fit(X, y).score(X, y)
    print(f'depth={str(d):4}  AUC cv={s.mean():.3f} ± {s.std():.3f}   akurasi latih={latih:.2f}')

Poin penting

  • Cross-validation memberi skor rata-rata dan kestabilan.
  • Overfit: latih tinggi, uji rendah. Underfit: keduanya rendah.
  • Cegah kebocoran data dengan Pipeline.
