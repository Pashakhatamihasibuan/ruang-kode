Turunan dan gradient descent

Buka versi interaktif

Turunan mengukur seberapa cepat suatu fungsi berubah. Jika kita punya fungsi loss (seberapa salah model), turunannya memberi tahu arah mana bobot harus digeser agar loss turun.

Gradient descent mengulang satu langkah sederhana: w = w - lr × turunan. lr (learning rate) mengatur besar langkah: terlalu kecil membuat belajar lambat, terlalu besar membuat bobot melompat-lompat dan tidak pernah sampai.

Contoh: loss L(w) = (w - 3)² + 1 paling kecil di w = 3. Turunannya 2(w - 3). Mulai dari w = -2, setiap langkah mendekati 3. Hampir semua model, dari regresi sampai jaringan saraf raksasa, dilatih dengan ide ini.

PYTHON
import numpy as np
import matplotlib.pyplot as plt

L = lambda w: (w - 3) ** 2 + 1
dL = lambda w: 2 * (w - 3)

w, lr = -2.0, 0.2
jejak = [w]
for langkah in range(10):
    w = w - lr * dL(w)
    jejak.append(w)
print('w akhir:', round(w, 4), ' loss:', round(L(w), 4))

xs = np.linspace(-3, 8, 100)
plt.figure(figsize=(6, 3.4))
plt.plot(xs, L(xs), label='loss L(w)')
plt.plot(jejak, [L(v) for v in jejak], 'o-', color='tab:orange', label='langkah')
plt.xlabel('bobot w'); plt.ylabel('loss')
plt.title('Gradient descent menuruni lembah loss')
plt.legend()
KELUARAN
w akhir: 2.9698  loss: 1.0009

Poin penting

  • Turunan = arah dan kecuraman perubahan.
  • w = w − lr × turunan, diulang.
  • Learning rate terlalu besar bisa gagal konvergen.
