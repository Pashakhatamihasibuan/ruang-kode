Regresi linear: menarik garis terbaik

Buka versi interaktif

Regresi linear mencari garis y = a + b·x yang paling dekat dengan semua titik data, dengan meminimalkan jumlah kuadrat selisih (OLS, ordinary least squares). Koefisien b dibaca: "setiap x naik 1, y naik rata-rata b".

R² menyatakan berapa bagian variasi y yang dijelaskan model (0 sampai 1). Hati-hati: korelasi bukan sebab-akibat. Ekonometrika mengajarkan cara berpikir tentang variabel pengganggu (confounder) sebelum mengklaim "X menyebabkan Y".

Asumsi penting: hubungan kira-kira linear, galat (residual) tidak berpola, dan tidak ada outlier yang mendominasi. Plot residual adalah cara cepat memeriksanya.

PYTHON
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(5)
iklan = rng.uniform(1, 20, 40)                 # juta rupiah
penjualan = 30 + 4.2 * iklan + rng.normal(0, 8, 40)

b, a = np.polyfit(iklan, penjualan, 1)
pred = a + b * iklan
r2 = 1 - ((penjualan - pred) ** 2).sum() / ((penjualan - penjualan.mean()) ** 2).sum()
print(f'penjualan = {a:.1f} + {b:.2f} x iklan')
print(f'R2 = {r2:.3f}')
print('Prediksi iklan 25 juta:', round(a + b * 25, 1))

plt.figure(figsize=(6, 3.4))
plt.scatter(iklan, penjualan, label='data')
xs = np.linspace(0, 21, 2)
plt.plot(xs, a + b * xs, color='tab:red', label='garis OLS')
plt.xlabel('biaya iklan (juta)'); plt.ylabel('penjualan (unit)')
plt.title('Regresi linear'); plt.legend()
KELUARAN
penjualan = 29.1 + 4.28 x iklan
R2 = 0.915
Prediksi iklan 25 juta: 136.1

Poin penting

  • OLS meminimalkan jumlah kuadrat galat.
  • Koefisien = perubahan rata-rata y per satu x.
  • R² = porsi variasi yang dijelaskan; bukan bukti sebab-akibat.

Cek pemahaman

R² = 0,85 artinya?

Jawaban: 85% variasi y dijelaskan model
