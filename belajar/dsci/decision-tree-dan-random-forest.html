Decision tree dan random forest

Buka versi interaktif

Decision tree belajar serangkaian pertanyaan ya/tidak, misalnya "keluhan > 2?" lalu "lama_bulan < 6?". Mudah dijelaskan ke orang bisnis, tetapi pohon yang terlalu dalam menghafal data latih (overfitting). Batasi dengan max_depth atau min_samples_leaf.

Random forest melatih ratusan pohon pada sampel acak data dan fitur, lalu menggabungkan suaranya. Hasilnya jauh lebih stabil dan akurat daripada satu pohon. Ia juga memberi feature importance: fitur mana yang paling banyak dipakai untuk memisahkan kelas.

Model pohon tidak butuh standardisasi dan bisa menangkap hubungan tidak lurus serta interaksi antar fitur. Kelemahannya: kurang pandai memprediksi di luar rentang data latih.

PYTHON
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 300
df = pd.DataFrame({
    'umur': rng.integers(18, 60, n),
    'lama_bulan': rng.integers(1, 48, n),
    'belanja_bln': rng.normal(350, 120, n).round(0).clip(50),
    'keluhan': rng.poisson(1.2, n),
    'kota': rng.choice(['Jakarta', 'Bandung', 'Surabaya', 'Medan'], n),
})
skor = -1.2 + 0.9 * df['keluhan'] - 0.06 * df['lama_bulan'] - 0.003 * (df['belanja_bln'] - 350)
df['churn'] = (rng.random(n) < 1 / (1 + np.exp(-skor))).astype(int)
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import roc_auc_score

X = df[['umur', 'lama_bulan', 'belanja_bln', 'keluhan']]; y = df['churn']
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)

for d in [2, None]:
    t = DecisionTreeClassifier(max_depth=d, random_state=0).fit(X_tr, y_tr)
    print(f'pohon depth={d}: akurasi latih={t.score(X_tr, y_tr):.2f}, uji={t.score(X_te, y_te):.2f}')

print(export_text(DecisionTreeClassifier(max_depth=2, random_state=0).fit(X_tr, y_tr), feature_names=list(X.columns)))

rf = RandomForestClassifier(n_estimators=200, min_samples_leaf=5, random_state=0).fit(X_tr, y_tr)
print('Random forest AUC:', round(roc_auc_score(y_te, rf.predict_proba(X_te)[:, 1]), 3))
for f, v in sorted(zip(X.columns, rf.feature_importances_), key=lambda x: -x[1]):
    print(f'  {f:12} {v:.2f}')

Poin penting

  • Pohon = rangkaian pertanyaan; mudah dijelaskan.
  • Pohon dalam overfit: latih tinggi, uji turun.
  • Random forest menggabungkan banyak pohon dan memberi feature importance.
