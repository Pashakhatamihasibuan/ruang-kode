Menyimpan model dan membuat API prediksi

Buka versi interaktif

Model yang hanya hidup di notebook belum memberi nilai. Langkah pertama: simpan Pipeline terlatih dengan joblib.dump (atau format ONNX), beserta versi pustaka dan versi data latihnya.

Lalu bungkus dalam API, misalnya dengan FastAPI: endpoint POST /prediksi menerima JSON fitur pelanggan dan mengembalikan peluang churn. Validasi masukan dengan Pydantic agar data aneh ditolak sebelum masuk model.

Pilihan penyajian: online (API real-time, misalnya saat pelanggan membuka aplikasi) atau batch (skor semua pelanggan setiap malam lalu disimpan di tabel). Batch lebih sederhana dan cukup untuk banyak kebutuhan bisnis.

PYTHON
# latih.py
import joblib
from sklearn.pipeline import Pipeline
# ... bangun dan latih pipe seperti di bab sebelumnya
joblib.dump(pipe, 'model_churn_v3.joblib')

# api.py  (jalankan: uvicorn api:app --reload)
import joblib, pandas as pd
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()
model = joblib.load('model_churn_v3.joblib')

class Pelanggan(BaseModel):
    umur: int = Field(ge=17, le=100)
    lama_bulan: int = Field(ge=0)
    belanja_bln: float = Field(ge=0)
    keluhan: int = Field(ge=0)
    kota: str

@app.post('/prediksi')
def prediksi(p: Pelanggan):
    X = pd.DataFrame([p.model_dump()])
    X['keluhan_per_bln'] = X['keluhan'] / X['lama_bulan'].clip(lower=1)
    return {'peluang_churn': round(float(model.predict_proba(X)[0, 1]), 3), 'versi': 'v3'}

Poin penting

  • Simpan Pipeline utuh beserta versinya.
  • API dengan FastAPI + validasi Pydantic.
  • Online vs batch: pilih yang paling sederhana yang cukup.
