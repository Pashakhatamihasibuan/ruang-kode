# 2.3 Tabel perkalian

Cetak tabel perkalian 7 dari 7 × 1 sampai 7 × 5.

## Langkah dari kalimat ke kode

1. Yang berubah setiap baris hanya pengalinya: 1 sampai 5.
2. Gunakan for dengan i dari 1 sampai 5.
3. Isi badan: cetak 7 x i = 7 * i.

## Keluaran yang diharapkan

```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
