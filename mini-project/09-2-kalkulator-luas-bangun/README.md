# 9.2 Kalkulator luas bangun

Interface Bentuk menjanjikan method luas(). Persegi, PersegiPanjang, dan Segitiga menepatinya. Hitung total luas semua bangun.

## Langkah dari kalimat ke kode

1. Tulis interface Bentuk dengan satu method luas().
2. Setiap kelas implements Bentuk dan menulis rumusnya sendiri.
3. Simpan semuanya dalam satu array bertipe Bentuk.

## Keluaran yang diharapkan

```
Persegi: 16
PersegiPanjang: 15
Segitiga: 12
Total: 43
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
