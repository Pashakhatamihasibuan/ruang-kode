# 6.1 Rapor dari file

File nilai.txt berisi nama dan dua nilai per baris. Baca filenya dan cetak rata-rata setiap siswa.

## Langkah dari kalimat ke kode

1. Buka file, lalu ulangi selama masih ada baris.
2. Pecah baris menjadi token: nama, nilai1, nilai2.
3. Ubah token angka ke int sebelum dijumlah.

## Keluaran yang diharapkan

```
Budi: 85
Sari: 80
Tono: 65
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
