# 2.2 Konversi detik ke jam

Durasi video 3725 detik. Ubah menjadi format jam, menit, dan detik.

## Langkah dari kalimat ke kode

1. 1 jam = 3600 detik. jam = total / 3600.
2. Sisa setelah jam diambil: total % 3600.
3. menit = sisa / 60, detik = sisa % 60.

## Keluaran yang diharapkan

```
1 jam 2 menit 5 detik
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
