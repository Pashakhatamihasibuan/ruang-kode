# 18.2 Daftar tugas prioritas

Tugas datang dengan prioritas (angka kecil = paling mendesak): Cuci piring 3, Kerjakan PR 1, Main game 5, Belajar ujian 2. Kerjakan sesuai prioritas.

## Langkah dari kalimat ke kode

1. Masukkan semua tugas ke priority queue berdasarkan angkanya.
2. Selama tidak kosong: ambil yang terkecil.
3. Python: simpan sebagai tuple (prioritas, nama).

## Keluaran yang diharapkan

```
1. Kerjakan PR
2. Belajar ujian
3. Cuci piring
5. Main game
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
