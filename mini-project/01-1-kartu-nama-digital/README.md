# 1.1 Kartu nama digital

Cetak kartu nama kamu dengan bingkai dari tanda bintang. Isinya nama, jurusan, dan hobi.

## Langkah dari kalimat ke kode

1. Satu baris tampilan = satu statement cetak.
2. Cetak bingkai atas, tiga baris isi, lalu bingkai bawah.
3. Perhatikan urutan: atas ke bawah.

## Keluaran yang diharapkan

```
************************
* Nama   : Rina        *
* Jurusan: Informatika *
* Hobi   : Membaca     *
************************
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
