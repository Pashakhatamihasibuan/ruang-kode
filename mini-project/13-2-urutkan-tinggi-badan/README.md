# 13.2 Urutkan tinggi badan

Urutkan tinggi badan 165, 150, 172, 158 dengan selection sort dan cetak isi array setelah setiap putaran.

## Langkah dari kalimat ke kode

1. Putaran i: cari indeks minimum dari i sampai akhir.
2. Tukar minimum ke posisi i.
3. Cetak array di akhir setiap putaran.

## Keluaran yang diharapkan

```
Putaran 1: [150, 165, 172, 158]
Putaran 2: [150, 158, 172, 165]
Putaran 3: [150, 158, 165, 172]
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
