# 4.1 Konversi nilai ke huruf

Ubah nilai 95, 82, 74, dan 50 menjadi huruf: A (≥ 90), B (≥ 80), C (≥ 70), selain itu D.

## Langkah dari kalimat ke kode

1. Buat method huruf(nilai) berisi rantai if / else if / else.
2. Urutkan dari syarat paling tinggi.
3. Panggil untuk setiap nilai.

## Keluaran yang diharapkan

```
95 -> A
82 -> B
74 -> C
50 -> D
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
