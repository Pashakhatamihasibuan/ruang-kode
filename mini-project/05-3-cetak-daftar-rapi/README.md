# 5.3 Cetak daftar rapi

Cetak angka 1 sampai 5 dalam format [1, 2, 3, 4, 5], tanpa koma berlebih di akhir.

## Langkah dari kalimat ke kode

1. Cetak "[" dan angka pertama di luar loop.
2. Loop dari 2: cetak ", " lalu angkanya.
3. Tutup dengan "]".

## Keluaran yang diharapkan

```
[1, 2, 3, 4, 5]
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
