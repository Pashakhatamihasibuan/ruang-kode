# 4.2 Statistik nilai kelas

Dari nilai 78, 92, 65, 88, 70, hitung total, rata-rata (bilangan bulat), dan nilai tertinggi.

## Langkah dari kalimat ke kode

1. Siapkan total = 0 dan maks = elemen pertama.
2. Dalam loop: total += nilai, dan perbarui maks jika lebih besar.
3. rata-rata = total / banyak data.

## Keluaran yang diharapkan

```
Total     : 393
Rata-rata : 78
Tertinggi : 92
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
