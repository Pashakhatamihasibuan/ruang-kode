# 9.1 Kebun binatang

Kelas Hewan punya method suara(). Kucing dan Anjing mewarisi Hewan dan meng-override suara(). Cetak suara semua hewan dalam satu daftar.

## Langkah dari kalimat ke kode

1. "Kucing adalah sejenis hewan" → Kucing extends Hewan.
2. Override: tulis ulang method dengan nama yang sama.
3. Satu loop memanggil suara(); versi yang jalan ditentukan objeknya.

## Keluaran yang diharapkan

```
Oyen: Meong
Doggo: Guk guk
Ikan: ...
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
