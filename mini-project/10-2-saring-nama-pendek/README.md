# 10.2 Saring nama pendek

Dari daftar nama, hapus semua nama yang kurang dari 4 huruf. Lakukan langsung di list yang sama.

## Langkah dari kalimat ke kode

1. Hapus sambil berjalan MUNDUR agar tidak ada yang terlewat.
2. i mulai dari size − 1 sampai 0.
3. Syarat hapus: panjang nama < 4.

## Keluaran yang diharapkan

Java:

```
[Budi, Sari, Tono]
```

Python:

```
['Budi', 'Sari', 'Tono']
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
