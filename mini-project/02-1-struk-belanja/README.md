# 2.1 Struk belanja

Kamu membeli 3 buku seharga 12500 dan 2 pulpen seharga 4000. Hitung subtotal setiap barang dan total bayar, lalu cetak struknya.

## Langkah dari kalimat ke kode

1. Simpan harga dan jumlah setiap barang di variabel.
2. subtotal = harga × jumlah.
3. total = subtotal buku + subtotal pulpen.

## Keluaran yang diharapkan

```
Buku   : 37500
Pulpen : 8000
Total  : 45500
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
