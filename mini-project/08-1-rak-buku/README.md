# 8.1 Rak buku

Buat kelas Buku dengan field judul dan halaman. Buat dua objek buku dan cetak informasinya lewat method info().

## Langkah dari kalimat ke kode

1. Kata benda "buku" → kelas Buku. Sifatnya (judul, halaman) → field.
2. Konstruktor mengisi field.
3. Setiap objek punya isi field sendiri.

## Keluaran yang diharapkan

```
Laskar Pelangi (529 hlm)
Bumi (440 hlm)
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
