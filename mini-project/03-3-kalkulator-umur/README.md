# 3.3 Kalkulator umur

Tanyakan tahun lahir pengguna, lalu cetak umurnya di tahun 2026. (Contoh input: 2008)

## Langkah dari kalimat ke kode

1. Tampilkan pertanyaan dulu.
2. Baca input sebagai bilangan bulat.
3. umur = 2026 − tahunLahir.

## Contoh input

```
2008
```

## Keluaran yang diharapkan

```
Tahun lahir: Umurmu 18 tahun
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
