# 7.2 Di atas rata-rata

Dari nilai 70, 85, 60, 90, 75, hitung rata-ratanya, lalu cetak nilai yang di atas rata-rata beserta indeksnya.

## Langkah dari kalimat ke kode

1. Traversal pertama: jumlahkan untuk rata-rata.
2. Traversal kedua: bandingkan setiap a[i] dengan rata-rata.
3. Pakai i < length agar tidak kelewatan.

## Keluaran yang diharapkan

```
Rata-rata: 76
a[1] = 85
a[3] = 90
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
