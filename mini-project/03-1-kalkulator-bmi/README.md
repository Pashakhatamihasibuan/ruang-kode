# 3.1 Kalkulator BMI

Buat method bmi(berat, tinggiCm) yang mengembalikan BMI (berat / tinggi² dalam meter), dibulatkan 1 angka di belakang koma. Hitung untuk 2 orang.

## Langkah dari kalimat ke kode

1. Parameter: berat (kg) dan tinggi (cm).
2. Ubah tinggi ke meter: tinggi / 100.0.
3. return hasilnya, lalu panggil method dua kali dengan data berbeda.

## Keluaran yang diharapkan

```
Andi: 20.8
Bela: 20.0
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
