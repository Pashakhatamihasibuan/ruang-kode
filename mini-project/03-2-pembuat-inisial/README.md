# 3.2 Pembuat inisial

Dari nama lengkap "Budi Santoso", buat inisial "B.S." dan hitung jumlah hurufnya tanpa spasi.

## Langkah dari kalimat ke kode

1. Cari posisi spasi dengan indexOf / find.
2. Huruf pertama ada di indeks 0, huruf kedua tepat setelah spasi.
3. Jumlah huruf = panjang − 1 (satu spasi).

## Keluaran yang diharapkan

```
Inisial: B.S.
Jumlah huruf: 11
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
