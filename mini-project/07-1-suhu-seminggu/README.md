# 7.1 Suhu seminggu

Simpan suhu 7 hari (31, 29, 33, 30, 28, 32, 34) dalam array. Cetak suhu hari pertama, hari ketiga, dan hari terakhir.

## Langkah dari kalimat ke kode

1. Hari ke-k ada di indeks k − 1.
2. Hari terakhir = indeks panjang − 1.
3. Jangan menulis 7 langsung, pakai length / len.

## Keluaran yang diharapkan

```
Hari 1  : 31
Hari 3  : 33
Terakhir: 34
```

## Menjalankan solusi

```bash
javac Main.java && java Main
python3 main.py
```
